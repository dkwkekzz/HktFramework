# C01 Acceptance — 완료 판정 기준

Phase 12 의 Acceptance Gate 10종을 C01 구체 검증 항목으로 번역한 체크리스트.
판정 주체: `advprotog-cycle-integrator` (계획·구현 세션이 스스로 VERIFIED 를 선언하지 않는다).
상태 기계는 Phase 14 를 따른다: PLANNED → CONTRACTED → … → VERIFIED.

## 1. MMORPG Identity Gate

- [ ] 탐험 가능한 공유 지역 — 협곡 장소 8종·경로 4종을 2+ 플레이어가 같은 상태로 탐험
- [ ] 복수의 플레이 역할 — 8역할 중 최소 6개가 서로 다른 플레이 경로로 실증됨
- [ ] 반복 가능한 Gameplay Loop — 6루프 각각 2회 이상 반복 시 다른 상황 발생
- [ ] 자율 주체·세력 — 8주체가 무개입 시뮬에서 목적 선택·행동 (SC-C01-C-01)
- [ ] 희소 자원·경제적 선택 — 재고·소유권·가격이 실제 선택을 바꿈
- [ ] 성장과 가능성 확장 — 성장 전후 가능 행동 집합 차이 (SC-C01-G1-01)
- [ ] 협력·경쟁하는 플레이어 — 공동 사냥/호위 + 소유권/수주 경쟁 실증
- [ ] 저장되는 세계 변화 — 재접속 후 유지 (SC-C01-N3-01)

하나라도 완전히 없으면 Cycle 이 아니라 시스템 프로토타입 — VERIFIED 불가.

## 2. Gameplay Loop Gate

- [ ] 진입 신호가 세계 안에 존재 (흔적·소문·가격·공고 — 퀘스트 마커 아님)
- [ ] 각 루프에서 복수 행동 선택 존재
- [ ] 행동에 비용·위험·기회비용 존재
- [ ] 결과가 세계·경제·관계·성장을 변경
- [ ] 변경 상태가 다음 루프의 입력이 됨 (LOOP-REGION 경유 확인)
- [ ] 반복 시 상태·주체 때문에 다른 상황 발생 (동일 순서 재생 금지)

## 3. World Autonomy Gate

- [ ] 무개입 시 주체가 목적을 선택 (SC-C01-C-01)
- [ ] 생태·경제·조직 상태가 제한 해상도로 진행
- [ ] Situation 5종이 발생·악화·해소됨
- [ ] 결과가 고정 타임라인이 아니라 현재 상태에서 계산됨

## 4. Multiplayer Gate

- [ ] 2+ 플레이어가 같은 세계 상태를 봄
- [ ] 동시 충돌을 권위 서버가 결정 (SC-C01-E3-01, N0-01)
- [ ] 협력·경쟁·거래 중 둘 이상이 실제 이익·위험 생성
- [ ] 한 플레이어의 행동이 다른 플레이어의 선택을 바꿈 (SC-C01-02-M1)

## 5. Progression Gate

- [ ] 플레이 전후 가능한 행동이 달라짐
- [ ] 지식·숙련·관계·권한 중 하나 이상 변화
- [ ] 성장이 비용·세계 규칙을 우회하는 무제한 해금이 아님 (SC-C01-G-02)

## 6. Economy Gate

- [ ] 생산·소비가 실제 재고를 바꿈
- [ ] 운송·위험·희소성 중 하나가 교환 가치에 영향 (SC-C01-05-E1)
- [ ] 플레이어와 NPC 가 같은 자원 상태 사용
- [ ] 경제 결과가 새 계약·갈등·전략 생성 (SC-C01-02-M1 → 유인 변화)

## 7. Persistence Gate

- [ ] 세계 상태 저장 (SC-C01-N3-01)
- [ ] 재접속 후 결과 유지
- [ ] 사건 로그+스냅샷 복구, 해시 일치 (SC-C01-N3-02)
- [ ] 저장된 변화가 다음 Situation·NPC 행동에 사용됨 (SC-C01-01-P1)

## 8. Player Comprehension Gate

개발자 콘솔 없이, 세계 현상만으로:

- [ ] 현재 지역 변화를 인지 (제단 빛·발자국·가격·공고)
- [ ] 주체들이 무엇을 원하는지 추론 가능
- [ ] 자신의 개입 방법을 발견 가능 (5개 Situation 각각 2+ 개입군)
- [ ] 행동 결과로 무엇이 달라졌는지 확인 가능
- [ ] 내부 Dependency Graph·수식이 플레이어 UI 에 노출되지 않음 (SC-C01-X-02)

## 9. Developer Explainability Gate

- [ ] Lab 에서 임의 결과를 공리→주체→의존→가능성→요구→세계→지각→의도→충돌→사건→변화 경로로 추적
- [ ] TRACE.graph.json 의 모든 플레이 증거가 공리·주체·의존성 노드에 연결 (cycle:trace 0 오류)

## 10. Determinism · Regression Gate

- [ ] 같은 시드·입력 → 같은 최종 상태 해시 (SC-C01-V-01)
- [ ] 차이 발생 시 최초 차이 Tick·상태 경로 출력 (SC-C01-V-02)
- [ ] SCENARIOS.md 의 전체 Scenario 통과
- [ ] 이전 Cycle 회귀: 해당 없음 (최초 Cycle) — 본 Scenario 세트를 C02 회귀 자산으로 동결
- [ ] 저장·불러오기 리플레이 통과

## 플레이 테스트 (Phase 13)

자동 검증 후 실제 플레이로 확인하고 `evidence/PLAYTEST.md` 에 기록:

- [ ] 플레이어가 스스로 활동을 발견하는가
- [ ] 역할 간 플레이가 실제로 다른가
- [ ] 전투 외 행동도 세계에 의미 있는 영향을 주는가
- [ ] 다른 플레이어가 기회이자 위험인가
- [ ] 세계 변화가 다음 행동을 유도하는가
- [ ] 반복 플레이에서 같은 순서만 재생되지 않는가
- [ ] NPC 행동이 이해 가능한가
- [ ] 성장이 새로운 가능성을 여는가

문제는 기능 요청이 아니라 `약한 Loop → 미발생 Situation → 부족한 모듈 출력 → 수정 Step / 다음 Cycle 후보` 경로로 변환한다.

## 최종 플레이 장면 (Cycle 완료 판정 장면)

> 두 명 이상의 플레이어가 접속한 협곡에서, 국경석 이동으로 시작된 마물 이동로 붕괴(ST-C01-01)를
> 각자 다른 역할(예: 사냥꾼은 마물 요격, 제작자는 치료제 납품, 협상가는 국가와 개발 중단 거래,
> 밀수업자는 대피 물자 운송)로 개입하고, 그 결과(마물 경로·신 안정도·시장 가격·평판)가
> 저장·재접속 후에도 유지되며, 무개입 영역에서는 세계가 스스로 악화·진행되어
> 새로운 Situation (치료 재료 부족·호위 위기)이 상태 계산으로 발생해 있는 것을 확인한다.
