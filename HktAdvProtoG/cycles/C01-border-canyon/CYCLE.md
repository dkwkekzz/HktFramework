# C01. 국경 협곡 개척지 (Border Canyon Frontier)

> 상태: PLANNED · 기준 문서: [docs/Design-ModulePlan-CycleWorkflow.md](../../docs/Design-ModulePlan-CycleWorkflow.md) §14
> 기계 판독 계약: [CYCLE.yaml](CYCLE.yaml) · Step: [STEPS.md](STEPS.md) · Scenario: [SCENARIOS.md](SCENARIOS.md) · 판정: [ACCEPTANCE.md](ACCEPTANCE.md) · 역추적: [TRACE.graph.json](TRACE.graph.json)

## 1. 플레이어 판타지

플레이어는 아직 완전히 통제되지 않은 국경 협곡에 들어가
**탐험가 · 사냥꾼 · 채집제작자 · 상인운송자 · 호위꾼 · 밀수업자 · 중개협상가 · 의례 연구자** 중
자신의 역할을 선택한다. 다른 플레이어 및 세계 주체(국가·마을·치료사·밀수 조직·거대 마물·국경 신)와
협력하거나 경쟁하면서 지역의 생태·경제·세력 관계와 신의 영역을 바꾼다.

플레이어가 반복하는 것은 퀘스트 목록 소화가 아니라,
**흔적과 소문에서 기회를 발견 → 역할에 맞게 준비 → 개입 → 세계가 변함 → 변한 세계가 새 기회를 만듦**의 순환이다.

## 2. 세계 약속

- 모든 장소와 자원은 주체의 의존성과 세계 요구에서 생성된다 (임의 배치 없음).
- 모든 NPC·조직·생물·신은 플레이어 없이도 목적을 선택하고 행동한다.
- 전투·거래·제작·정보·사회 행동이 **같은 세계 상태**를 사용한다.
- 플레이어의 결과는 저장되어 다음 접속과 다음 Situation 을 바꾼다.
- 퀘스트를 받지 않아도 흔적·소문·가격·NPC 행동을 통해 개입 기회를 발견한다.

## 3. 이전 기준선

- 이전 VERIFIED Cycle: **없음** (최초 Cycle)
- 상태·이벤트 버전: Foundation(Phase 0) 산출 스키마 v1 — **Foundation 완료가 C01 구현의 선행 게이트다**
- 필수 회귀 Scenario: 없음. 대신 Foundation 결정성 스모크(같은 시드 → 같은 상태 해시)를 통과해야 C01-V 에 진입한다.

## 4. 깊이 증가

- **주 깊이 축**: `causalDepth` — 공리→주체→의존→가능성→요구→세계→사건→성장의 전체 인과 사슬을 최초로 관통시킨다.
- **보조 깊이 축**: `worldDepth`(협곡 1개 지역의 규칙·상태·공간·압축 역사), `onlineDepth`(단일 프로세스 권위 서버·소수 동시 접속·저장/재접속)
- **유지할 기존 축**: 없음 (최초 Cycle). 모든 MMORPG 축은 "최소 연결" 수준으로 존재해야 한다 (§7).
- **이번 Cycle 비범위**:
  - `economicDepth` 심화 — 생산 체인·창고·조직 재정은 Cycle 2
  - `subjectDepth`/`strategicDepth` 심화 — 가치관 기반 능력 생성·표현 계통은 Cycle 3 (G5 의념 능력은 "조건·대응 정보 발견"까지만)
  - `socialDepth` 심화 — 법률·파벌·정치는 Cycle 4
  - `spatialDepth` 심화 — 다지역·지역 간 전파는 Cycle 5
  - `onlineDepth` 심화 — 관심 영역 최적화·대규모 동접·서버 복구는 Cycle 6 (N1·N2 는 최소 구현)
  - `productionDepth` 심화 — AI 후보 대량 생성·자동 수정은 Cycle 7 (A 는 1종 후보의 정적 검증 통과까지만)

## 5. 지역 범위

크기: 약 2km × 2km 국경 협곡 1개 지역.

- **장소**: 국경 마을 1, 국가 초소 1, 광산 1, 국경 신 제단(+국경석) 1, 치료 재료 습지 1, 거대 마물 이동 협곡 1, 밀수 동굴·우회 통로 1, 전망·흔적 조사 지점 여러 개
- **이동 구조**: 교역로 1(마을↔초소↔외부), 마물 이동로(제단 영역 의존), 밀수 우회로(은폐), 습지 샛길
- **생산 지점**: 광산(광물), 습지(약초·의례 재료), 마물(기관·부산물), 마을 경작지(식량)
- **위험 지점**: 마물 이동 협곡, 붕괴 후 마을 동쪽 통로, 운송로 매복 구간, 습지 심부
- **사회 공간**: 마을 시장·게시판, 초소(신고·계약·단속), 제단(의례), 밀수 동굴(암거래)

## 6. 주체·세력·생태

| 주체 | 목적과 의존성 | 자율 행동 |
|---|---|---|
| 마을 주민 | 식량·안전·치료 | 경작, 대피, 소문 전파, 부상 |
| 치료사 집단 | 약초·마물 기관·환자 보호·지식 | 채집, 치료, 재료 매입, 제작 |
| 상인 | 재고·운송로·이익 | 시세 갱신, 운송대 편성, 호위 모집 |
| 국경 관리인·국가 조직 | 광맥·국경 통제·정당성 | 광산 확장, 순찰, 단속, 사건 은폐 |
| 밀수 조직 | 은폐 통로·거래 상대·단속 회피 | 밀수 운송, 정보 판매, 통로 개척 |
| 거대 마물 | 이동로·먹이·기관 회복·번식지 | 경로 선택, 사냥, 회복, 영역 이동 |
| 국경 신 | 국경석 앵커·의례·숭배·영역 안정 | 영역 유지/약화, 현상 발생 |
| 자원 군락·생태 개체군 | 재생 조건 | 성장·고갈·재생 |

모두 플레이어 접근과 무관하게 목적을 선택하고 서로의 상태를 바꾼다 (World Autonomy Gate).

## 7. 플레이어 역할

| 역할 | 주 루프 | 다른 역할과의 연결 |
|---|---|---|
| 탐험가 | 탐험·정보 | 흔적·경로 정보를 사냥꾼·상인·밀수업자에게 판매 |
| 사냥꾼 | 사냥·전투 | 기관·부산물을 치료사·제작자에 공급, 호위 겸업 |
| 채집·제작자 | 채집·제작 | 치료제·도구를 시장·계약에 공급 |
| 상인·운송자 | 경제·운송 | 호위 수요 창출, 시세 형성 |
| 호위꾼 | 전투+운송 | 운송 계약의 위험 축을 담당 |
| 밀수업자 | 경제+사회 | 단속 회피 운송, 우회로 정보 거래 |
| 중개·협상가 | 사회·세력 | 세력 간 계약 중개, 기만·평판 게임 |
| 의례 연구자 | 사회+성장 | 의례 재료 수요, 신 영역 안정화, 능력 조건 조사 |

모든 플레이어가 같은 전투 목표를 따라가는 구조는 완료로 인정하지 않는다 (§3.4).

## 8. 핵심 Gameplay Loop

각 루프는 `초기 동기 → 정보 획득 → 준비 → 행동 → 위험/충돌 → 보상 → 세계 상태 변화 → 새로운 가능성` 구조를 가진다.
Phase 4 검증 질문 6개(시작 이유 / 기회 신호 / 반복 변화 / 멀티플레이 추가 선택 / 바꾸는 상태 / 다음 루프 입력)에 대한 답은 각 루프 표기와 [CYCLE.yaml](CYCLE.yaml) `coreGameplayLoops` 에 있다.

### 탐험 — LOOP-EXPLORE (탐험·정보 루프)

소문·현상 발견 → 흔적 조사 → 위험·자원·주체 위치 추론 → 지도·믿음 갱신 → 경로·계약·사냥 기회 발견.

- 시작 이유: 새 흔적·소문·가격 변동이 미지의 기회를 암시
- 반복 변화: 마물 경로·신 안정도·세력 활동이 매번 다른 흔적을 만든다
- 멀티플레이: 정보 판매·공유·선점 경쟁
- 바꾸는 상태: 플레이어 지식·지도·소문 상태 → 다음 루프(사냥·운송·밀수)의 입력

### 전투·사냥 — LOOP-HUNT (사냥·전투 루프)

마물 흔적 분석 → 도구·약품·역할 준비 → 추적·유인·차단 → 전투·포획·회피 → 해체·운반 → 생태·시장·세력 상태 변화.

- 시작 이유: 기관 수요(치료 재료 부족), 마을 위협, 계약 보상
- 반복 변화: 마물의 부상·학습·경로 변경, 개체군 상태
- 멀티플레이: 공동 사냥, 같은 기관 소유권 경쟁, 해체물 분배
- 바꾸는 상태: 마물 개체·경로, 기관 재고, 마을 위협도 → 제작·경제 루프 입력

### 채집·제작 — LOOP-CRAFT (채집·제작 루프)

광물·약초·기관 획득 → 품질 판별 → 가공 → 치료제·추적 도구·의례 도구·장비 제작 → 사용·판매·납품 → 더 위험한 가능성 해금.

- 시작 이유: 치료 수요·계약 납품·자기 장비
- 반복 변화: 군락 고갈·재생, 재료 품질, 제작 숙련
- 멀티플레이: 재료 거래, 독점, 위조
- 바꾸는 상태: 재고·품질·제작식 지식 → 경제·사냥 루프 입력

### 경제·운송 — LOOP-TRADE (경제·운송 루프)

지역 수요·재고 확인 → 생산지·판매처·운송로 선택 → 호위/밀수/정상 거래 결정 → 운송 중 위험·경쟁 → 거래·손실·압수 → 재고·교환 가치·세력 재정 변화.

- 시작 이유: 시세 차익, 계약 보상, 재료 조달
- 반복 변화: 운송로 안전도·시세·단속 강도
- 멀티플레이: 호위 고용, 매복·약탈, 시세 경쟁, 밀수 대 단속
- 바꾸는 상태: 시장 재고·가격·운송로 안전도 → 사회·지역 변화 루프 입력

### 사회·세력 — LOOP-SOCIAL (사회·세력 루프)

주체의 요구·갈등 파악 → 계약·거래·협상·기만·위협 → 약속 수행/위반 → 신뢰·평판·권한·적대 변화 → 새로운 정보·지역·서비스 접근.

- 시작 이유: 접근 권한·계약 보상·세력 보호 획득
- 반복 변화: 관계·평판·계약 이력이 누적되어 선택지가 달라진다
- 멀티플레이: 계약 중개, 평판 경쟁, 배신과 그 대가
- 바꾸는 상태: 세력 관계·평판·계약 상태 → 모든 루프의 접근 조건 입력

### 성장

- 지역 지식·지도 갱신 (탐험) · 마물 흔적 판별 숙련 (사냥) · 제작식 획득 (제작)
- 세력 신뢰·거래 권한 (사회) · 새 우회로·생산지 접근 (탐험+사회)
- 의념 능력의 조건·대응 정보 발견 (의례 연구) · 가능성 그래프 신규 전략 해금 (G1)

성장 결과가 다음 플레이 방식과 세계 요구를 실제로 바꿔야 한다 (§3.6).

### 지역 변화 — LOOP-REGION (지역 변화 루프)

플레이어·주체 행동 축적 → 국경석·마물 경로·광산·시장·마을 상태 변화 → 새로운 Situation 발생 → 경로 폐쇄/개방 → 새로운 자원·위험·세력 행동.

- 이 루프는 나머지 5개 루프의 출력을 입력으로 받아 다음 Situation 을 계산하는 메타 루프다.
- 플레이어가 없어도 진행된다 (자율 에스컬레이션).

## 9. 자원 경제

- **생산**: 광산→광물, 습지→약초·의례 재료, 마물→기관·부산물, 경작지→식량, 제작→치료제·추적 도구·의례 안정화 도구·장비
- **소비**: 치료(약초·기관·치료제), 의례(의례 재료·도구), 전투·운송(소모품·장비), 주민 생존(식량)
- **운송**: 교역로(정상+호위) 대 밀수 우회로(은폐+단속 위험), 운송 중 물량은 상태로 존재
- **소유권**: 기관·광물 등 고유 자원은 권위 서버가 확정하는 단일 소유자
- **희소성**: 군락 고갈·마물 개체 수·광산 생산량이 실제 재고를 제한
- **가격·교환 가치**: 세력별 교환 가치 + 위험 비용(운송로 안전도) 반영, 재고·수요에서 계산

## 10. 멀티플레이

- **협력**: 공동 사냥·호위·의례, 계약 역할 분담, 정보 공유
- **경쟁**: 같은 고유 자원(기관·광맥) 소유권 경쟁, 호위 계약 수주 경쟁, 시세 경쟁
- **거래**: 플레이어 간 자원·정보·계약 거래가 지역 가격·안전·평판에 영향
- **동시 충돌**: 동시 획득·동시 계약·전투 개입은 권위 서버가 한 번만 확정 (E3+N0)

## 11. 영속 상태

국경석 위치·상태, 신의 안정도, 마물 위치·부상·이동 경로, 광산 생산량·지배 상태,
교역로 안전도, 시장 재고·교환 가치, 마을 식량·부상자·신뢰, 세력 관계·계약,
플레이어 평판·지식·제작법·약속, 발견된 장소와 소문.
모두 저장되어 다음 접속·다음 Situation·다음 Cycle 의 입력이 된다.

| ST-C01-03 | 광산·밀수 통로 충돌 | 국가의 광산 확장이 밀수 통로·마물 서식지를 침범. 3자 이해 충돌. |
| ST-C01-04 | 제단 의례 공백 | 의례 재료·집전자 부족으로 신 안정도 하락 가속. 안정화 대 방치 대 이용. |
| ST-C01-05 | 교역로 호위 위기 | 운송 위험 급등 → 호위 수요·운임 급등 → 정상 운송 대 밀수 대 약탈 경쟁. |

모든 Situation 은 퀘스트 데이터가 아니라 현재 세계 상태에서 계산되는 압력 구조이며,
플레이어가 없어도 발생·악화·해소된다.

## 14. 인과 추적

O → S → D → P → Q → W → R → E → G → C → X → N → A.
플레이어에게 보이는 모든 현상·역할·결과는 [TRACE.graph.json](TRACE.graph.json) 에서
하나 이상의 공리·주체·의존성 노드까지 역추적된다. 대표 사슬:

```text
"마을 동쪽에서 새 마물 발자국 발견" (플레이 증거)
← X: 흔적 오브젝트 표시 ← R: 현상 생성·지각 ← E: 이동 사건
← C: 마물 복합 주체 경로 실행 ← P: 경로 전략 선택 ← D: 이동로 의존 결핍
← W: 신 영역 규칙 약화 ← Q: 신의 영역 유지 요구 ← S: 국경 신 원형
← O: "신의 유지 조건" 공리
```
