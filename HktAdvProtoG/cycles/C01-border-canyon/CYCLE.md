## 1. 플레이어 판타지

플레이어는 국경 협곡 사냥터의 **사냥꾼**이다. 마물의 흔적을 읽고, 준비하고, 추적·사냥하고,
잡은 것을 해체해 팔거나 장비로 만든다. 마을을 위협하는 포식 마물을 토벌하고,
조합 계약과 부산물 시세 속에서 살아간다.

역할은 사냥이라는 하나의 직업 안의 분업이다:
**추적꾼**(흔적·정보) · **사냥꾼**(전투) · **해체·제작자**(가공) · **부산물 상인**(거래·운송).

반복하는 것: **흔적 발견 → 준비 → 추적·사냥 → 해체·가공 → 판매·계약 → 생태와 시세가 변함 → 다음 사냥이 달라짐**.

## 2. 세계 약속

- 마물은 스폰 포인트가 아니다 — 먹이·서식지·포식압에 따라 번식·이동·행동하는 개체군이다.
- 사냥 대상·장소·시세는 주체 의존성과 생태 상태에서 계산된다 (임의 배치 없음).
- 과잉 사냥과 사냥 공백은 각각 다른 문제를 만든다 — 균형 자체가 콘텐츠다.
- 사냥·해체·제작·거래가 같은 세계 상태를 사용한다.
- 결과는 저장되어 다음 접속의 생태·시세·계약을 바꾼다.

## 3. 이전 기준선

- 이전 VERIFIED Cycle: **없음** (최초 Cycle)
- 상태·이벤트 버전: Foundation(Phase 0) 산출 스키마 v1 — **Foundation 완료가 C01 구현의 선행 게이트**

- **보조 깊이 축**: `worldDepth`(협곡 1지역의 생태·공간·압축 역사), `onlineDepth`(단일 프로세스 권위 서버·소수 동접·저장/재접속)
- **유지할 기존 축**: 없음 (최초 Cycle)
- **이번 Cycle 비범위**:
  - **국경 신·의례·의념 능력** — 원 §14 설계에서 이월 (후속 Cycle)
  - **국가·밀수 조직·단속** — 이월 (후속 Cycle)
  - `economicDepth` 심화 (생산 체인·조직 재정) — Cycle 2 계열
  - `subjectDepth`/`strategicDepth` 심화 (능력 생성) — Cycle 3 계열
  - `socialDepth` 심화 (정치·법률), `spatialDepth` 심화 (다지역), `onlineDepth` 심화 (대규모 동접), `productionDepth` 심화 (AI 대량 생성)

## 5. 지역 범위

크기: 약 2km × 2km 국경 협곡 사냥터 1개 지역.

- **장소 (6)**: 사냥꾼 전초 마을(시장·조합·게시판) 1, 마을 목장 1, 초식 무리 서식 골짜기 1, 포식 마물 둥지 협곡 1, 약초·먹이 군락 습지 1, 전망 바위(흔적 조사 지점) 여러 개
- **이동 구조**: 마물 이동로(먹이·포식압 의존), 사냥로, 외부 운송로(얇게)
- **생산 지점**: 무리 서식지(가죽·기관·고기), 습지(약초·미끼 재료), 목장(식량)
- **위험 지점**: 둥지 협곡, 무리 발정기 골짜기, 마을 접근 경로(ST-01 발생 시)
- **사회 공간**: 전초 마을 시장·조합 게시판(계약·시세·소문)

## 6. 주체·세력·생태 (6)

| 주체 | 목적과 의존성 | 자율 행동 |
|---|---|---|
| 마을 주민 | 안전·식량 | 목축, 대피, 소문 전파, 피해 보고 |
| 사냥꾼 조합 | 마을 방위·사냥 질서·평판 | 토벌·조절 계약 발급, 계약 평가, 치료제 매입 |
| 부산물 상인 | 재고·시세·이익 | 시세 갱신, 매입·매도, 외부 운송대 편성 |
| 초식 무리 (뿔사슴 무리) | 먹이·번식지·이동로 | 채식, 번식, 이동, 군락 훼손 |
| 거대 포식 마물 | 먹이(무리)·둥지·회복 | 사냥, 경로 선택, 둥지 이동, 부상 회복·학습 |
| 자원 군락 (약초·먹이) | 재생 조건 | 성장·고갈·재생 |

**중앙 갈등 = 사냥 균형**: 과잉 사냥 → 무리 감소 → 포식 마물 먹이 부족 → 마을 접근 (ST-01) + 시세 폭락 (ST-05).
사냥 공백 → 무리 과잉 번식 → 군락 황폐화 (ST-02) → 약초·먹이 부족 → 역시 ST-01.
어느 쪽으로도 기울면 문제가 생기고, 플레이어들의 사냥량이 그 방향을 결정한다.

## 7. 플레이어 역할 (4 — 모두 사냥 루프의 분업)

| 역할 | 주 루프 | 다른 역할과의 연결 |
|---|---|---|
| 추적꾼 | 추적·정보 | 흔적·위치 정보를 사냥꾼·상인에 판매, 사냥 계획 제공 |
| 사냥꾼 | 사냥·전투 | 부산물을 해체·제작자에 공급, 토벌·조절 계약 수행 |
| 해체·제작자 | 해체·가공·제작 | 장비·치료제·미끼를 사냥꾼·시장에 공급 |
| 부산물 상인 | 거래·운송 | 시세 형성, 매입·비축·외부 판매, 계약 중개 |

## 8. 핵심 Gameplay Loop

각 루프는 `초기 동기 → 정보 획득 → 준비 → 행동 → 위험/충돌 → 보상 → 세계 상태 변화 → 새로운 가능성` 구조.
Phase 4 검증 질문 6개의 답은 [CYCLE.yaml](CYCLE.yaml) `coreGameplayLoops` 에 있다.

### 탐험 — LOOP-TRACK (추적·정보 루프)

흔적·소문 발견 → 조사(발자국·훼손·배설물) → 마물 종·수·상태·방향 추론 → 지도·믿음 갱신 → 사냥 계획·정보 판매.

- 반복 변화: 개체군 이동·번식·부상 상태가 매번 다른 흔적을 만든다
- 멀티플레이: 정보 판매, 희귀 흔적 선점 경쟁

### 전투·사냥 — LOOP-HUNT (사냥·전투 루프)

계약·정보 확인 → 장비·치료제·미끼 준비 → 추적·유인·차단 → 전투·포획·회피 → 해체·운반.

- 반복 변화: 대상 개체의 부상·학습·위치, 무리 구성, 경쟁 사냥꾼
- 멀티플레이: 공동 사냥(역할 분담), 같은 개체 소유권 경쟁, 해체물 분배

### 채집·제작 — LOOP-CRAFT (해체·가공·제작 루프)

부산물·약초 획득 → 품질 판별 → 가공 → 장비·치료제·미끼·추적 도구 제작 → 사용·판매·조합 납품 → 더 위험한 사냥 가능.

- 반복 변화: 재료 품질 분포, 군락 상태, 제작 숙련
- 멀티플레이: 재료 거래, 희귀 재료 경쟁

### 경제·운송 — LOOP-TRADE (거래·계약 루프)

시세·계약 확인 → 매매·납품·비축·외부 운송 선택 → 거래·손실 → 재고·시세·평판 변화.

- 반복 변화: 공급량(사냥 결과)·수요(마을 상태)에 따른 시세 변동
- 멀티플레이: 시세 경쟁, 매점, 계약 수주 경쟁, 플레이어 간 거래

### 사회·세력

별도 루프로 승격하지 않고 LOOP-HUNT·LOOP-TRADE 안의 **조합 계약·평판**으로 유지한다:
계약 수행/위반 → 평판·계약 등급 변화 → 고액 토벌 계약·희귀 정보 접근이 달라진다.

### 성장

흔적 판별 숙련(추적) · 전투·해체 숙련(사냥) · 제작식 획득(제작) · 조합 평판·계약 등급(사회) · 서식지·경로 지식(탐험).
성장 결과가 다음 사냥 방식(추적 정확도·해체 수율·수주 가능 계약)을 실제로 바꾼다.

### 지역 변화 — LOOP-ECOLOGY (생태 변화 메타 루프)

사냥량·개체수·먹이·군락 상태 축적 → 번식·이동·포식압 계산 → Situation 발생·해소 → 서식지·시세·위협 재편.
플레이어가 없어도 진행된다 (자율 에스컬레이션).

## 9. 자원 경제

- **생산**: 사냥→가죽·기관·고기, 습지→약초·미끼 재료, 목장→식량
- **소비**: 제작(가죽·기관·약초), 치료(치료제), 사냥 준비(미끼·소모품), 주민 생존(식량·고기)
- **운송**: 마을 시장 중심 + 외부 운송로(얇게 — 고가 부산물 반출)
- **소유권**: 사냥한 개체·부산물은 권위 서버가 확정하는 단일 소유자
- **희소성**: 개체군 수·군락 재생 속도가 실재 공급을 제한 — 남획하면 실제로 마른다
- **가격**: 재고·수요·희귀도에서 계산. 공급 과잉 → 폭락, 사냥 공백 → 폭등 (ST-05)

## 10. 멀티플레이

- **협력**: 공동 사냥(추적·유인·전투·해체 분담), 대형 토벌 계약 파티, 재료·정보 공유
- **경쟁**: 같은 개체(특히 희귀 개체) 소유권 경쟁, 계약 수주 경쟁, 시세 경쟁·매점
- **거래**: 플레이어 간 부산물·정보·제작물 거래가 시세·평판에 반영
- **동시 충돌**: 동시 포획·동시 계약은 권위 서버가 한 번만 확정 (E3+N0)

## 11. 영속 상태

개체군 수·구성·이동 경로, 포식 마물 위치·부상·학습, 군락 상태, 시장 재고·시세,
마을 위협도·목장 피해, 조합 계약 상태·플레이어 평판·계약 등급,
플레이어 숙련·제작식·지도·발견 흔적. 모두 저장되어 다음 접속의 입력이 된다.

## 15. Module Step

전체 목록·필수 필드는 [STEPS.md](STEPS.md). V→A 19 Step, 모드 CREATE/EXTEND (SKIP 없음).

## 부록 A. 범위 결정 기록

### 초판 (2026-08-05, 폐기)

§14 원문 그대로 5세력(국가·마을·치료사·밀수·마물·신) 개척지, 8역할, 루프 6종.
**폐기 이유**: 사용자 판단 — 첫 Cycle 로 범위 과대. 검증 안 된 인과 파이프라인 위에
세력 5개·전략 9계열·공리 7종을 한 번에 올리는 것은 최초 관통 비용을 불필요하게 키운다.

### 재설계 (현재)

사냥꾼 판타지 하나로 좁히고, 헌법이 삭제를 금지하는 8요소(§20.7)는 사냥에 종속시켜 유지:

| | 초판 | 재설계 |
|---|---|---|
| 판타지 | 개척자 (8역할) | 사냥꾼 (분업 4역할) |
| 주체 | 8 (신·국가·밀수 포함) | 6 (마을·조합·상인·무리·포식 마물·군락) |
| 공리 | 7 | 5 (신 유지·능력 흔적 이월) |
| 전략 계열 | 9 | 6 (추적·사냥·채집·해체제작·거래·계약) |
| 루프 | 6 | 5 (사회는 계약·평판으로 흡수) |
| 중앙 갈등 | 국경석→신→마물 (외생 사건) | 사냥 균형 (플레이어 행동이 직접 원인) |
| Situation | 5 (세력 갈등형) | 5 (생태·경제 되먹임형) |

이월된 §14 원문 설계는 "세력과 신의 협곡" 후속 Cycle 후보로 보존 (§20).
재설계에서도 Identity Gate 8요소·모듈 V→A 전 관통·Situation 최소 5개는 유지 —
축소는 폭(주체·전략·공리 수)에서만 이루어졌고 구조 삭제는 없다.
