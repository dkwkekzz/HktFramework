# C01 Scenario 목록 — 검증 분해

Scenario 는 Cycle 목표가 아니라 검증 단위다 (헌법 §1.4).
각 Situation 을 정상·실패·경계·멀티플레이·저장복구로 분해하고,
종류별 검증 질문은 Phase 6 표(인과·공간·경제·사회·충돌·멀티플레이·영속·회귀)를 따른다.
회귀 Scenario: 이전 Cycle 없음 — 이 목록 전체가 C02 이후의 영구 회귀 자산이 된다.

표기: `SC-C01-<모듈>-<번호>` (담당 Step 은 STEPS.md 의 produces/verification 과 대응).
