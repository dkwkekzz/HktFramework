# HTJ — STATE (진행 상태)

> 프로젝트 전체 작업 진행 상태. 현재까지 무엇을 했고, 목적을 위해 앞으로 무엇을 해야 하는지 기록한다. 각 step 은 한 줄 요약으로 쌓는다. 너무 길어지면 §시리즈 인덱스를 요약한다. **권위 있는 SSOT — step 시작 전 필독.**

## §1. NOW — 지금 어디까지

- **step_0004 닫음** — **별의 점화 = 임계 방출(밀도 게이트)**. `releaseEnergy` 에 점화 임계(`crit`)를 가법적으로 추가 — `P ≥ crit` 인 밀집한 연료만 방출 = **별**, 옅은 배경은 어두운 가스로 남는다. 별은 author 하지 않는다(형태·위치·수명 = 연료 분포+임계의 결과). 처음으로 세계에 *국소 구조* 등장. 균일 법칙이 불균일 결과를 낳는 첫 사례. `crit=0` → step_0003 와 byte-동일(회귀 0).
- **step_0003 닫음** — 에너지의 *탄생* = 잠재력 방출(potential→energy). 둘째 장 `potential`+둘째 법칙(`dE=rate·P`, 자발적 지수 붕괴). **Σ(potential+energy) 보존** — 생성은 형태 변환. 확산을 먹이는 지속 source.
- **step_0002 닫음** — 세계를 처음 *굴리는 법칙*. **확산 = 열역학 제2법칙**. 중앙 핫스팟이 총량 보존하며(제1) 식어 퍼져 균일 평형 수렴(엔트로피↑ → ln(N³)).
- **세계 = 격자 + 장(fields) 모델**: `world.fields`(이름→장 배열) + 장-단위 통일 API(`addField/get/set/total/count/max/fingerprint(name)`). 장은 둘 — `energy`·`potential`(둘 다 연속 밀도, Float64). 법칙은 둘 — 확산(`htj-energy`)·방출(`htj-potential`, 임계 게이트 포함).
- **세계 ↔ 확인용 분리(단방향)**: `engine/htj-world.js`(격자+장) · `htj-energy.js`(확산·엔트로피) · `htj-potential.js`(방출+임계 점화) · `viewer*`(확인용 — `draw` 가 `field`·`colormap` 으로 임의 장 렌더, `pick` 으로 픽킹). `verify.js` 는 engine 만 의존.
- **뷰어 = step 갤러리**: 드롭다운 step 선택(0001 정적 공 / 0002 클릭주입·확산 / 0003 저장고·방출 / 0004 별밭·임계 점화). 동역학은 step별 `advance(world,params)` 훅으로 일반화. 방출율은 `release` step, 점화 임계는 `ignite` step 에서만 노출. step 추가 시 `STEPS` 레지스트리에 한 항목.

## §2. NEXT — 다음 할 일

- **step_0005 후보**: 지금 별은 *고립*돼 타다 꺼질 뿐 — 점화가 이웃으로 *번지지* 않는다(밀도 게이트는 자기 자리만 봄). 진짜 창발(전파·패턴)로 가려면 점화가 *이웃 상태에 반응* — (a) 온도 점화(방출열 E 가 이웃을 임계 위로 데우면 연쇄 점화 → 진행파/별 군집), (b) 역변환(energy→potential)으로 식은 곳에 연료 재응결 → 점화-소멸 순환. 검증축: *author 없이* 점화가 공간적으로 조직되는가.
- step 은 `htj-step` 스킬로 시작한다.

## §3. 큰 목표를 향한 좌표

> 정해진 규칙으로 스스로 굴러가는 세계 → 그 위에서 아이템·캐릭터 같은 복잡계가 *창발* → 플레이어가 다양한 상호작용.

무대·눈(0001) → 확산(0002) → 에너지의 탄생(잠재력 방출, 0003) → **별의 점화(임계 방출, 0004)** 까지 왔다. 0004 에서 처음으로 *국소 구조*(별 = 임계 넘긴 영역)가 author 없이 등장 — "균일한 법칙이 불균일한 결과를 낳는다"의 첫 사례. 다만 점화는 *자기 자리만* 보아 이웃으로 번지지 않는다(고립된 별). 다음 좌표는 점화가 *이웃에 반응*해 공간적으로 조직되는 것 — 진행파·군집 등 패턴 창발의 첫 다리.

## §4. 열린 격차 / 결정 대기

- 점화가 *국소·비전파* — 이웃 반응(온도 점화)·역변환(재응결 순환)은 step_0005+ 에서 확정.
- 렌더가 표면 셀만 그려 내부 분포·*두 장 동시 비교*(potential↔energy, 별 내부·점화 경계)가 안 됨 — 공간 결합을 볼 때 슬라이스/투명/이중 채널 도입(step_0001부터 이어진 격차).
