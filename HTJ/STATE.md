# HTJ — STATE (진행 상태)

> 프로젝트 전체 작업 진행 상태. 현재까지 무엇을 했고, 목적을 위해 앞으로 무엇을 해야 하는지 기록한다. 각 step 은 한 줄 요약으로 쌓는다. 너무 길어지면 §시리즈 인덱스를 요약한다. **권위 있는 SSOT — step 시작 전 필독.**

## §1. NOW — 지금 어디까지

- **step_0005 닫음** — **빛나는 별 = 경계 복사(sink)**. 셋째 법칙 `radiate`(`htj-radiate.js`): 경계 셀 에너지가 세계 밖(차가운 우주)으로 빠져나가 `world.radiated` 장부에 적재 → 닫힌 상자가 *열린 계*가 되지만 **Σ(P)+Σ(E)+radiated 보존**. 큰 연료 코어가 계속 점화 + 확산 + 복사 → source↔sink 사이 **영구 그래디언트**(뜨거운 중심→차가운 바깥) = 처음으로 *지속하는 비평형 구조*(열적 죽음 회피). 뷰어에 **절대 색 스케일** 추가(에너지 손실·진행을 눈으로 추적).
- **step_0004 닫음** — **별의 점화 = 임계 방출(밀도 게이트)**. `releaseEnergy` 에 점화 임계(`crit`)를 가법적으로 추가 — `P ≥ crit` 인 밀집한 연료만 방출 = **별**, 옅은 배경은 어두운 가스로 남는다. 별은 author 하지 않는다(형태·위치·수명 = 연료 분포+임계의 결과). 처음으로 세계에 *국소 구조* 등장. 균일 법칙이 불균일 결과를 낳는 첫 사례. `crit=0` → step_0003 와 byte-동일(회귀 0).
- **step_0003 닫음** — 에너지의 *탄생* = 잠재력 방출(potential→energy). 둘째 장 `potential`+둘째 법칙(`dE=rate·P`, 자발적 지수 붕괴). **Σ(potential+energy) 보존** — 생성은 형태 변환. 확산을 먹이는 지속 source.
- **step_0002 닫음** — 세계를 처음 *굴리는 법칙*. **확산 = 열역학 제2법칙**. 중앙 핫스팟이 총량 보존하며(제1) 식어 퍼져 균일 평형 수렴(엔트로피↑ → ln(N³)).
- **세계 = 격자 + 장(fields) + 장부**: `world.fields`(이름→장 배열) + 장-단위 통일 API(`addField/get/set/total/count/max/fingerprint(name)`) + `world.radiated`(세계 밖 복사 장부, 지연 초기화). 장은 둘 — `energy`·`potential`. 법칙은 셋 — 확산(`htj-energy`)·방출+임계점화(`htj-potential`)·복사 sink(`htj-radiate`).
- **세계 ↔ 확인용 분리(단방향)**: `engine/htj-world.js`(격자+장) · `htj-energy.js`(확산·엔트로피) · `htj-potential.js`(방출+임계 점화) · `htj-radiate.js`(경계 복사 sink+회계) · `viewer*`(확인용 — `draw` 가 `field`·`colormap`·`max`(절대/상대) 로 렌더, `pick` 으로 픽킹). `verify.js` 는 engine 만 의존.
- **뷰어 = step 갤러리**: 드롭다운 step 선택(0001 정적 공 / 0002 확산 / 0003 방출 / 0004 임계 점화 / 0005 빛나는 별·복사 sink). 동역학은 step별 `advance(world,params)` 훅. 방출율=`release`·점화임계=`ignite`·복사율=`radiate` step 에서만 노출. **색 기준(상대 평균/절대 고정)** 전역 토글. step 추가 시 `STEPS` 레지스트리에 한 항목.

## §2. NEXT — 다음 할 일

- **step_0006 후보**: 별빛(복사된 에너지)이 지금은 그냥 `radiated` 장부로 사라진다. 진짜 우주라면 그 빛이 *다른 곳에 도달해 무언가를 한다* — (a) 복사 에너지가 다른 셀/물질에 *흡수*되어 데우거나 반응 촉발(빛→물질 상호작용), (b) 여러 별(코어)을 두어 *서로의 빛을 주고받는* 계. 검증축: 복사가 단순 손실이 아니라 *원거리 결합*이 되는가. (별도 미해결: 점화가 이웃으로 *번지지* 않음 — 온도 점화/자기촉매로 진행파·군집.)
- step 은 `htj-step` 스킬로 시작한다.

## §3. 큰 목표를 향한 좌표

> 정해진 규칙으로 스스로 굴러가는 세계 → 그 위에서 아이템·캐릭터 같은 복잡계가 *창발* → 플레이어가 다양한 상호작용.

무대·눈(0001) → 확산(0002) → 에너지의 탄생(0003) → 별의 점화(0004) → **빛나는 별(복사 sink, 0005)** 까지 왔다. 0005 에서 처음으로 *지속하는 비평형 구조*(영구 그래디언트=빛나는 별)가 섰다 — source(별)+흐름(확산)+sink(복사)의 균형이 균일 열적 죽음을 *피한다*. 다음 좌표는 복사된 빛이 *다른 곳과 결합*(흡수·별-별 상호작용)하는 것, 그리고 점화가 *이웃에 반응*해 공간적으로 조직되는 것(진행파·군집).

## §4. 열린 격차 / 결정 대기

- 복사된 빛이 *단순 손실*(장부로만) — 흡수/원거리 결합은 step_0006+. 점화의 *비전파*(이웃 반응)도 미해결.
- 렌더가 표면 셀만 그려 *내부의 별 자체*·두 장 동시 비교(potential↔energy)가 안 됨 — 슬라이스/투명/이중 채널 도입(step_0001부터 이어진 격차).
