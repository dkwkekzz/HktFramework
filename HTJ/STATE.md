# HTJ — STATE (진행 상태)

> 프로젝트 전체 작업 진행 상태. 현재까지 무엇을 했고, 목적을 위해 앞으로 무엇을 해야 하는지 기록한다. 각 step 은 한 줄 요약으로 쌓는다. 너무 길어지면 §시리즈 인덱스를 요약한다. **권위 있는 SSOT — step 시작 전 필독.**

## §1. NOW — 지금 어디까지

- **step_0001 닫음** — 기반 무대 완성. 셀로 된 N³ 3D 공간 + 결정론(지문) + 3D voxel 렌더러 + 헤드리스 캡처(눈 검증)를 세움.
- `engine/` 3모듈(의존성 0, 브라우저·Node 공용): `htj-world.js`(격자·시드·지문) · `htj-render.js`(자작 voxel 렌더) · `capture.js`(playwright 캡처+눈검증). `viewer.html` 단일 뷰어.
- 아직 **법칙(동역학) 0개** — 스텝은 셀을 바꾸지 않는다(카운터만). 무대와 눈만 준비됨.

## §2. NEXT — 다음 할 일

- **step_0002 후보**: 셀에 *보존되는 양 하나*를 넣고, 이웃과 주고받는 **가장 단순한 국소 법칙**(예: 확산 — 총량 보존)을 얹는다. 검증축: 총량 정확 보존(수치) + 덩어리가 퍼지는 시계열(눈/캡처). `viewer.html` "스텝"이 이때 처음 셀을 실제로 바꾼다.
- step 은 `htj-step` 스킬로 시작한다.

## §3. 큰 목표를 향한 좌표

> 정해진 규칙으로 스스로 굴러가는 세계 → 그 위에서 아이템·캐릭터 같은 복잡계가 *창발* → 플레이어가 다양한 상호작용.

무대(공간)와 눈(렌더+캡처)을 세웠다. 다음 한 걸음은 "규칙 하나가 시간에 따라 세계를 결정론적으로 굴린다"를 검증 가능하게 세우는 것 — 보존량 + 국소 법칙.

## §4. 열린 격차 / 결정 대기

- 세계의 셀 값이 아직 *추상 uint8*(0=빈칸)일 뿐 — "보존되는 양"의 의미는 step_0002 에서 확정.
- 렌더가 표면 셀만 그려 내부 값 띠(2/3)는 안 보임 — 슬라이스/투명 표현은 보존량을 색으로 보일 필요가 생길 때 도입.
