# step_0049 — SW5 열전도: 온도 차를 평형화 (0002 확산의 SPH 판)

> [design/sphere-world.md](../../design/sphere-world.md) §6 SW5 — "구체 떼가 가스처럼 거동(**압력·확산**)". 지금 SPH 스택엔 압력은 있으나 *확산*이 없었다. 이 step 이 **0002 확산(열역학 제2법칙)의 SPH 판**을 더한다 — 격자 유체가 하던 일을 구체가 대신하는 격자 은퇴(SW5 최후)의 한 벽돌. (긴 설명은 viewer `note` 0049 가 집.)

## 논의 (법칙 step·새 법칙 하나)

- **세계를 어떻게 변형?** 이웃 쌍 사이로 비열E(u=internalE/질량)를 흘려 *온도 차를 평형화*한다. 0046 점성이 bulk 운동을 식혔다면 이건 온도 차를 식힌다. 라플라시안 SPH 근사(Brookshaw): `du_i/dt = Σ_j m_j(κ_i+κ_j)/(ρ_iρ_j)(u_i−u_j)(r·∇W)/(r²+ε)`. r·∇W<0 → i 뜨거우면 식고 j 데움 = 열 hot→cold.
- **무엇으로 검증?** ① 새 거동=열 확산(평형화) ② 총 내부E 정확 보존(대칭 교환 Σ=0) ③ 단방향=온도 분산 단조↓(엔트로피↑) ④ 운동/KE 불변(U 만 재분배) ⑤ 항등/안전(균일 u 무변화·κ=0→회귀0·빈/단일) ⑥ 결정론.
- **무엇이 보존/변하나?** 쌍 계수 K_ij 가 i↔j 대칭(질량가중 교환) → **총 내부E 정확 보존**(재분배만). 운동량·KE 안 건드림 → 총E 자동 보존. 열은 hot→cold 한 방향 → **엔트로피↑·비가역**. κ=0→회귀0·신규 함수→구조적 회귀0.

## 구현 — `sphThermalConduction` (engine/htj-sph.js, 가법·VERSION 7→8)

```
du_i/dt = Σ_j m_j (2κ)/(ρ_iρ_j) (u_j−u_i) (r_ij·∇_iW)/(r²+ε)   // 대칭 쌍 교환
dE_i = +m_j·w·(u_j−u_i), dE_j = −m_i·w·(...)  → Σ m_i du_i = 0  // 총 내부E 보존
```
**CFL 서브스텝 가드**(0012 advect 선례): explicit 확산은 조건부 안정 — 입자별 감쇠율 A_i=Σ_j m_j w_ij 의 최댓값으로 nSub 을 잡아 `dt_sub·maxA ≤ 0.4` 보장 → 어떤 dt 에도 발산 없이 안정(보존은 불변). 위치 고정이라 쌍 가중치는 서브스텝 간 재사용. opts: `{ kappa(0), h(1) }`.
