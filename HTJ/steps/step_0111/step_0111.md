# step_0111 — (조립·버그수정) 걷기: 무거운 자유 구체 지면 위를 편법 0 으로 걷는다

> [design/playable-world.md](../../design/playable-world.md) PW-A 핵심. 조립 step(engine 변경 0·0027 관성+0028 중력+0037 접촉+0057/58 마찰+0109 제어). 긴 설명은 viewer `note`(scenes/step_0111.js)가 집.

## ⚠ 버그 수정 — 원칙 위반(지면 개념 + 고정 코드) 제거

**무엇이 왜 틀렸나**: 옛 0111 은 *평평한 앵커 줄*을 지면 삼아 매 틱 `a.px=a.py=0` 으로 그 운동량을 *지워* 부동성을 위조하고, 중력도 법칙이 아니라 `-mg` 로 손수 박았다. 이는 (ㄱ) "지면"이라는 *타입 개념*을 만들고 (ㄴ) 물리가 아니라 *고정 코드*로 붙잡은 것 — **"세계는 법칙뿐, 그 위에 물체가 있을 뿐"** 절대 원칙 위반. **바로잡음**: 지면 = 아주 무거운 *자유* 구체(M≫m)일 뿐. 캐릭터는 오직 관성(0027)+중력(0028 쌍힘·"아래"=행성 쪽 창발)+접촉=전자기 반발(0037)+마찰(0057/58)+제어(0109)로 선다·걷는다. **고정 코드 0·`-mg` 0·앵커 0.** (선례: 0110 은 처음부터 이 모델이었고, 0111~0118 이 평지+고정으로 어긋났다 → 0111 부터 교정.)

## 논의 (조립 step·편법 0)

- **세계를 어떻게 변형?** 무거운 자유 구체 표면에 선 캐릭터(0110)에 접선 제어 힘 → 마찰(0057)+구름 저항(0058)이 접지를 잡아 *곡면을 걷는다*. 안 움직임=행성 무게(관성)·안 날아감=궤도속도(4.5)≫걷는속도(≈1).
- **무엇으로 검증?** ① 고정 없이 선다 ② 걷기(각도 휘어 돎) ③ 안 날아감(d≈R+r·v≪궤도) ④ 멈춤 ⑤ **편법 부재**(제어 없이 계 운동량 보존=고정 없음의 증거) ⑥ 결정론.
- **무엇이 보존/변하나?** engine 불변. 부품 법칙은 부품 verify 가 보증. 새로 생긴 건 *편법 없는 곡면 보행*.

## 구현 — viewer 조립 (engine 변경 0·고정/박기 0)

```js
En.applyEntityGravity(es, DT, { G:0.03, soft:1 });             // 중력(쌍힘)="아래"는 행성 질량 쪽 창발
En.applyEntityContact(es, DT, { k:60, cDamp:8 });              // 접촉 반발(전자기)
if (f) { const [tx,ty]=tang(); ch.px += f*tx*DT; ch.py += f*ty*DT; }  // 제어=접선(걷기·0109)
En.applyEntityFriction(es, DT, { k:60, mu:8, cTan:14 });       // 마찰=발판
En.applyEntityRollingResistance(es, DT, { k:60, muRoll:4, cRoll:8 });  // 구름 저항(속도 유계)
En.stepEntities(es, DT);                                       // 관성(행성도 자유 — 안 지움·anchored 0·-mg 0)
```
