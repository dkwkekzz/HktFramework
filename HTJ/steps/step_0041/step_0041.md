# step_0041 — SPH 압력 힘: 중력↔압력 균형으로 유한 가스 공 (구체 세계 SW5 둘째 벽돌)

> [design/sphere-world.md](../../design/sphere-world.md) §6 **SW5** / §3 — 밀도(0040) 위에 상태식 P=f(ρ)와 ∇W 대칭 쌍힘을 얹어 구체 떼를 *가스처럼* 밀어낸다. **0008(격자 단거리 반발 P=Kρ^γ)·0010(열압력)의 SPH 판.**

## 논의 — 이 step 의 의미

0040 이 SPH 의 토대(밀도)를 *재기만* 했다면, 이 step 은 그 밀도로 **힘**을 만든다 — 밀도가 높은 곳일수록 큰 압력으로 입자를 밀어낸다. 이게 구체 떼를 *가스/유체처럼* 거동하게 하는 첫 힘이다.

- **세계를 어떻게 변형?** 밀도 ρ_i 에서 상태식 P_i = k·ρ_i^γ(항상 ≥0 → 항상 반발)로 압력을 만들고, **Monaghan 대칭 운동량식** a_i = −Σ_j m_j(P_i/ρ_i² + P_j/ρ_j²)∇_i W_ij 로 민다. 빽빽한 곳이 퍼지고, 중력과 맞서면 *유한한 가스 공*(별/행성처럼)에서 멈춘다.
- **무엇으로 검증?** ① 운동량 정확 보존(대칭 쌍힘·뉴턴3·기계 정밀도) ② 압축 → 반발(가까운 두 입자가 서로 밀려남) ③ 균일 → 힘 ≈ 0(압력 기울기 0) ④ 커널 기울기 반대칭(∇_iW=−∇_jW·r→0 에서 0) ⑤ 항등/안전(k=0 → early-return) ⑥ 결정론. + 눈(압축 가스 덩어리가 퍼짐 / 중력+압력 = 유한 공).
- **무엇이 보존/변하나?** 보존: **운동량**(∇_jW=−∇_iW → F_ji=−F_ij → ΣF=0·정확). 변함: 위치·속도(가스가 퍼짐)·KEcm·energy. **정직한 한계**: 압력은 *힘*만 — 압력 일↔내부에너지 닫힘(KE↔u)은 후속 SPH 열 벽돌(0008 반발 힘 → 0010 열압력 에너지 닫힘과 *같은 순서*). 그래서 이 단위는 운동량은 정확 보존하나 총E 는 아직 닫히지 않는다(압력이 implicit 열저장고에서 일을 꺼냄).

## 구현 — `kernelGradW` · `sphPressureForce` (engine/htj-sph.js, 가법)

기존 함수(`kernelW`·`sphDensity`) 한 줄도 안 건드림 → **신규 함수 = 회귀 0**. 노브 k=0 이면 early-return.

**`kernelGradW(dx,dy,dz, h)`** — 커널 기울기 ∇_i W(r_i−r_j, h), 모든 SPH 쌍힘의 방향·크기:

```
∇_i W = (dW/dr)·(r_i−r_j)/r,  dW/dr = (σ/h)·f'(q),  σ=1/(π h³),  q=r/h
f'(q) = −3q + 2.25q²   (0≤q<1) · −0.75(2−q)²  (1≤q<2) · 0  (q≥2)
r→0 에서 f'(0)=0 → 기울기 0(특이점 없음). 반대칭 ∇_iW = −∇_jW(쌍힘 보존의 뿌리).
```

**`sphPressureForce(particles, dt, {stiffness, gamma, h})`** — 밀도 갱신(sphDensity 재사용) → P_i=k·ρ_i^γ → 대칭 쌍힘:

```
a_i = −Σ_j m_j (P_i/ρ_i² + P_j/ρ_j²) ∇_i W_ij
쌍 (i,j): a_i += −m_j·term·∇_iW · a_j += −m_i·term·∇_jW(=+∇_iW)  → Δp_i+Δp_j = m_i a_i dt + m_j a_j dt = 0(정확)
```

**왜 운동량이 정확한가** — 쌍 (i,j)의 충격량이 정확히 +/− 짝이다(∇_jW=−∇_iW). 쌍 루프라 구조적으로 ΣΔp=0(0028 중력 쌍힘과 동형). 상태식 P 가 무엇이든 보존은 성립(힘이 대칭이라). P≥0 이라 *항상 반발* → 가스가 퍼진다.

## 쉽게 풀어 쓴 설명

앞 단계(0040)에서 "여기 공이 얼마나 빽빽한가"(밀도)를 쟀다. 이번엔 그 밀도로 **밀어내는 힘**을 만든다 — **빽빽한 곳일수록 세게 민다**(압력). 그래서 한곳에 뭉친 가스가 *스스로 퍼진다*. 미는 방식이 핵심인데, 두 공 사이의 힘을 항상 **정확히 반반씩 반대 방향**으로 준다(한쪽을 왼쪽으로 민 만큼 다른쪽을 오른쪽으로) — 그래서 전체의 "움직이는 기세(운동량)"는 한 톨도 안 변한다. 재밌는 건 **중력과 짝지을 때**다: 중력은 안으로 당기고 압력은 밖으로 밀어서 — 중력만 있으면 가스가 한 점으로 찌부러지지만, 압력이 있으면 **딱 적당한 크기의 공**에서 멈춰 숨쉰다. 이게 바로 별이나 행성이 *무한히 안 찌부러지고 둥근 공으로 서 있는* 이유고, 나중에 "캐릭터가 딛는 땅"도 결국 이렇게 **압력으로 떠받쳐진 큰 공**이다. (아직은 미는 *힘*만 넣었다 — 밀면서 생기는 열 계산은 다음 단계. 온도를 먼저 재고 열압력을 나중에 닫았던 0009→0010 과 똑같은 순서다.)

## 이 step 이 목적에 남긴 것 + 다음 연결

구체 떼가 이제 *가스처럼 군다* — 밀도가 힘이 됐다. 0040(밀도 측정) 위에 압력(힘)이 서서, 구체 세계가 **유체/가스 표현**을 갖추기 시작했다(SW5). 중력↔압력 균형은 0008 의 SPH 판 — *법칙은 author(알려진 유체역학)·구조는 창발(가스 공·별)*.

**다음 = SW5 셋째 벽돌(SPH 열/에너지 닫힘 또는 점성)**: ① 압력이 한 일을 내부에너지로 닫아(du_i/dt = (P_i/ρ_i²)Σ m_j v_ij·∇W_ij) **총E 를 보존**(0010 열압력 되먹임의 SPH 판) — 그러면 가스가 압축으로 데워지고 팽창으로 식는다. ② 또는 점성(소산)으로 충격 감쇠. 그 뒤 격자 유체 은퇴(측정된 필요 후·design §5 난점 3).

**정직한 한계(이 단위)**: ① 압력은 *힘*만 — 압력 일↔내부E 닫힘(총E 보존)은 다음 벽돌(운동량은 정확 보존). ② 점성(끈적함·충격 처리) 없음. ③ 평활길이 h 고정(적응 h 후속). ④ 이웃 탐색 O(N²)·격자 유체 은퇴는 SW5 마지막. 여기선 *압력 힘 한 법칙*만.
