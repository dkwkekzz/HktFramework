# step_0062 — (M2) 형태 hash 사전(DNA): 합친 덩어리 형태를 정규화 hash 로 압축·dedup

> 병합·형태 DNA 트랙 둘째 벽돌(M2). 새 엔진 모듈 `htj-shapedna.js` + `coalesceSettled` 에 tagMerge 훅(가법).
> 설계: [design/merge-dna.md](../../design/merge-dna.md) §3·§4 M2. 긴 산문은 step 문서가 집(viewer EXEMPT).

## 논의 (세계를 어떻게 변형 · 무엇으로 검증 · 무엇 보존/변함)

- **변형**: M1(0061)이 *확실한 병합*을 세웠으나 합친 개체는 모양 잃은 민둥 구. 개체마다 구성원 세부를 다 들면 압축 0(확장성 없음). 이 step 은 구성원 배치를 **정규화**(평행이동·스케일 불변 양자화)해 **shapeHash(DNA)**로 압축하고, 세계 형태 사전(`shapeDict: hash→canonical`)에 **dedup** → 개체는 hash 만·사전은 K(형태종류)개로 공유(K ≪ N).
- **검증**: ① 정규화(평행이동·스케일·미세 흔듦→같은 hash) ② 구별(다른 배치·개수→다른 hash) ③ dedup(N 클러스터→사전 K≪N) ④ 보존/안전(hash 는 물리 안 건드림·순수 + M1 통합 tagMerge) ⑤ 결정론.
- **보존/변함**: 물리량 전부 불변(hash·사전은 *표현*·메타데이터)·결정론·M1 회귀0(coalesceSettled 에 *옵션* tagMerge 훅 가법·미지정=0061 동일). 새 모듈 `htj-shapedna.js`.

## 구현 (법칙 식 · 진입점)

`htj-shapedna.js`(신규·VERSION 1):

```
shapeDNA(members, opts) → { hash, canonical }     // 순수
  CoM = 질량가중 중심;  rel_i = r_i − CoM           // 평행이동 불변
  s = RMS(|rel|);  q_i = round(rel_i / s / quantum) // 스케일 불변 + 양자화(quantum=0.25)
  key = count + ':' + sort(q_i).join(';');          // 순서 불변(정렬)·개수도 형태
  hash = FNV1a(key)
registerShape(dict, members, opts) → hash           // dedup: dict[hash]=canonical (없을 때만)
hashToUnit(hash) → [0,1)                             // 색/뷰 매핑(결정론 유틸)
```

- `htj-entity.js :: coalesceSettled` 에 **`opts.tagMerge(members)`** 훅 추가(VER 9→10): 합칠 때 콜백 반환값을 `merged.shapeHash` 에 부착. 미지정 → 태깅 안 함 = **0061 거동 동일**(회귀0). 통합: `tagMerge: mem => registerShape(worldDict, mem)`.
- 정규화는 **평행이동·스케일 불변**(회전은 미정규화 = M2 한계·PCA 정렬은 후속). 손실 양자화로 *비슷한 덩어리가 한 hash 로 dedup* — 사전이 K≪N 으로 작게.

## 다음

합친 개체가 *형태 코드(DNA)*를 들게 됐다 = "원소는 hash 만·형태는 세계 사전이 공유"(K≪N 확장성). 다음 = **M3 DNA 로 렌더** — viewer 가 `shapeDict[entity.shapeHash]` 를 읽어 *민둥 구가 아니라 대략 윤곽*으로 그린다(큰 원이 지형 모양으로 돌아온다·사용자 "큰 원이 지형 안 됨" 문제의 답). 한계: 회전 미정규화(회전한 같은 모양→다른 hash·PCA 정렬은 후속)·정규화 양자화 해상도(quantum)는 형태 충실도↔dedup 율 trade.
