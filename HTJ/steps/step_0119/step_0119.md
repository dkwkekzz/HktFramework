# step_0119 — (RG1) 강체 분자 골격: 분자 하나가 DNA 구조를 충돌 껍질로

> 설계 권위: [design/rigid-ground.md](../../design/rigid-ground.md) §4·§5 RG1. 긴 산문은 `viewer/scenes/step_0119.js`의 `note`(산문의 집).

## 논의

- **세계 변형**: 수박게임 합치기(0036/0061)로 뭉친 *분자*(합쳐진 한 엔티티)가 지금까지 매끈한 구(`equivalentRadius`)로만 충돌했고 DNA 구조는 *기록만* 됐다. RG1 은 그 구조를 분자의 *충돌 껍질*로 읽게 한다 — 분자는 *안 쪼갬*(한 강체), 껍질은 body-frame 구조 오프셋(`reconstructShape`·0063). 새 법칙 `applyShellContact` + `stepEntity` θ 적분(B안 게이트).
- **검증**: ① 캐릭터가 DNA 구조 껍질에 *막힘*(바운딩 구 아님)·분자 중심 침투 0 ② *제어 없이* Σp·ΣL(원점) 정확 보존(고정/핀 0 = 진짜 자유 강체·편법 부재의 급소) ③ 분자 free(무게=부동성·안 쪼갬) ④ off-center 타격 → 강체 회전(θ).
- **보존/변함**: 접촉점 equal-opposite → 계 총 운동량·각운동량 *구성적 보존*. 변함 = 분자 px/Lz/θ(반작용 합산)·캐릭터 px/Lz(−반작용)·감쇠 KE→internalE(비가역).

## 구현

`engine/htj-entity.js` (VERSION 12→13):

```
applyShellContact(others, body, shell, dt, {k,cDamp}):
  분자 자세(CoM + 회전 theta)로 shell 오프셋 배치 → 충돌 표면
  캐릭터-껍질 겹침 시 접촉점 p(개체 표면)에서:
    J = (k·overlap − c·vn)·dt·n̂           # 반발 + 감쇠(역전 방지 클램프)
    분자:    px += J ;  Lz += (p−CoM)×J     # 합력 + 토크(스핀)
    캐릭터:  px −= J ;  Lz += (p−중심)×(−J)
  같은 접촉점·equal-opposite → Σp·ΣL(원점) 정확 보존
stepEntity: theta!=null & inertia → theta += (Lz/I)·dt   # B안·게이트(theta 없으면 회귀 0)
```

진입점: `En.applyShellContact([ch], body, shell, DT, {k:60,cDamp:8})` + `En.stepEntities([body,ch], DT)`. 껍질 = `reconstructShape` 점들의 CoM 기준 오프셋, `inertia = Σ m_i|r_i|²`.
