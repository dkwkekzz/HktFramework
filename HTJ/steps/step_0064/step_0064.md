# step_0064 — (TW3 강·완성) SPH bed friction 으로 물이 경사를 흘러내려 하류 댐에 고인다

> 환경 트랙 TW3 첫(=핵심) 벽돌. 새 엔진 법칙 `sphBedFriction`(htj-sph.js·VERSION 14→15) — 물(SPH 입자)이 *정적 지형 바닥*을 따라 미끄러지는 **접선 운동**에 속도비례 항력(→열).
> 설계: [design/environment.md](../../design/environment.md) §3 TW3. 긴 산문은 viewer `note`(STEPS '0064')가 집.

## 논의 (세계를 어떻게 변형 · 무엇으로 검증 · 무엇 보존/변함)

- **변형**: TW2(0060 `sphBoundaryForce`)는 물을 지형에 *얹었지만*(법선 반발+법선 감쇠) 경사면을 따라 *미끄러지는(접선)* 운동엔 저항이 0 → 기울인 바닥 위 물이 **끝없이 가속**(종단속도 없음 = 강이 아니라 탄도 추락). 이 step 이 그 빠진 벽돌 = **바닥 접선 항력**: 접촉 입자의 접선 슬립을 속도비례로 소산→열 → **종단속도**(유한)로 *일정 속도 흐름* = 강.
- **검증**: ① 새 거동 = 종단속도(drag=0 끝없이 가속 vs drag>0 유한 정상) ② 소산/보존 = 접선만 줄고 법선 불변·잃은 KE→internalE 정확·질량 불변 ③ 창발(조립 강) = 물이 내리막 램프를 흘러내려 하류 댐에 고임·흐름 유한(이탈 0) ④ drag=0→회귀0(=0060 단독) ⑤ 결정론.
- **보존/변함**: 질량·결정론·기존 SPH/엔티티 회귀0 **보존**. 새로 추가 = 접선 슬립 소산(잃은 운동량은 무한질량 앵커=외부 경계로·잃은 KE→열·비가역). 0060 `sphBoundaryForce`(법선)는 *전혀* 안 건드림 — 법선=0060·접선=이 step 의 직교 분해.

## 구현 (법칙 식 · 진입점)

`htj-sph.js :: sphBedFriction(particles, anchors, dt, opts)` (VERSION 14→15·신규 export):

```
각 입자 p, 각 앵커 A(정적 구), pen=(R+skin)−|p−A| > 0(접촉)이면:
  n̂ = (p−A)/|·|,  v = p.p/m
  v_t = v − (v·n̂)n̂                                 // 접선(슬립) 속도
  Δp_t = −min(drag·dt, 1)·m·v_t                     // 접선 운동량 일부 제거(속도비례·0..v_t = 역전 없음)
  잃은 KE → p.internalE                              // 비가역 열(시간의 화살)·법선 vn 불변
```

- 속도비례(점성형) 항력 → 경사에서 g·sinθ 와 균형 = **종단속도 v_term ≈ g·sinθ/drag**(유한). Coulomb(속도무관)과 달리 종단속도를 준다. **0046(입자↔입자 점성)의 바닥↔입자 판**·**0057(접촉 접선 마찰)의 SPH↔앵커 판**.
- `drag=0`/앵커 없음/dt=0 → early-return(회귀0). 신규 함수라 기존 호출처 0 → 구조적 회귀0.
- 검증·캡처 장면 = 중력(수직)+`sphPressureForce`(0041)+`sphViscosity`(0046)+`sphBoundaryForce`(0060 법선)+이 step(접선)의 *조립*. 기울인 램프 바닥(우측 高→좌측 低·큰 구 오른쪽-위)이 물을 흘려보내고, 댐(좌)이 고임을 만든다.
