## 논의 (렌더 트랙·engine 물리 불변)

- **세계를 어떻게 변형?** 물리 변형 0 — 정착은 기존 entity 법칙(0059 조립). `terrainSurface` 에 **매끄러운 퇴적 노브 `smooth`**(가법)만 더한다: 퇴적 delta(쌓인 물질=heights−base)를 K 회 *쌍대칭 확산*(인접 정점끼리 높이를 λ씩 나눔)해 개별 구 봉우리를 둔덕으로 편다. base 지형은 *불변*(평활은 delta 에만).
- **무엇으로 검증?** ① 매끄러움(거칠기 Σ인접차²·최대 인접점프 감소=새 법칙) ② 융기 유지·일방 퇴적(여전히 차오름·base 아래로 안 꺼짐) ③ 부피 보존(Σdelta — 확산은 재분배·공용 가드) ④ 항등(smooth=0→0066 byte 동일·공용 가드) ⑤ 결정론(공용 가드). 눈: 톱니 표면 → 매끄러운 둔덕.
- **무엇이 보존/변하나?** 물리량 전부 불변(표면은 읽기만). Σ퇴적 부피 보존(확산 쌍대칭). 새로 보이는 것: *퇴적 표면이 매끄럽다*.

## 구현 — terrainSurface 가법 확장(smooth: 퇴적 delta 확산 이완)

```
terrainSurface(anchors, {up, deposits, smooth, smoothRate}) — deposits splat(0066) 후:
  if smooth>0: delta = heights − baseH(퇴적 전); K회 확산: d[k] += λ·Σ_n(d[n]−d[k]) (인접쌍 ±λΔ 상쇄)
               heights = baseH + delta
  쌍대칭 → Σdelta 정확 보존(재분배) · λ≤¼ convex → delta≥0(일방 퇴적·깎임 아님) · Neumann 경계
  (smooth=0/무지정 → 블록 건너뜀 → 0066 표면 byte 동일·회귀0)
```
정착=기존 물리·표면=읽기 이완(세계↔확인용 단방향)·engine 물리 불변(가법·VER 2→3).
