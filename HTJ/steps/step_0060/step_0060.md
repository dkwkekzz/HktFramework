# step_0060 — (TW2 착수) 바다 = 물이 정적 지형 분지에 고여 수평 수면

> 환경 트랙 TW2 첫 벽돌. 새 엔진 법칙 `sphBoundaryForce`(htj-sph.js) — 물(SPH 입자)이 *정적 지형 앵커*를 느끼는 경계.
> 설계: [design/environment.md](../../design/environment.md) §3 TW2. 긴 산문은 viewer `note`(STEPS '0060')가 집.

## 논의 (세계를 어떻게 변형 · 무엇으로 검증 · 무엇 보존/변함)

- **변형**: SPH 물리 스택(0040~)+동역학(0026~)은 섰지만 물이 *지형*(정적 앵커·0056/0059)을 느끼는 결합이 없어 물이 지형을 그냥 통과했다. 이 step 이 그 *유일하게 빠진 벽돌* = SPH↔앵커 경계를 더한다 → 물이 분지에 갇혀 **수평 수면**으로 고인다.
- **검증**: ① 반발·관통 없음 ② 행성/분지 위 물이 *수평 표면(등z·등퍼텐셜)* 으로 퍼져 정착(중력+압력) ③ 질량 불변·낙하 KE→열 소산·앵커 밖=불변 ④ k=0 회귀0 ⑤ 결정론.
- **보존/변함**: 질량·결정론·기존 SPH/엔티티 회귀0 **보존**. 새로 추가 = 물↔정적 지형 경계 결합(앵커=무한질량 외부 경계가 운동량 흡수·0056 정신).

## 구현 (법칙 식 · 진입점)

`htj-sph.js :: sphBoundaryForce(particles, anchors, dt, opts)` (VERSION 13→14·신규 export):

```
각 입자 p, 각 앵커 A(정적 구):
  pen = (A.radius + skin) − |p − A.center|
  pen > 0 이면 (표면 안):
    n̂ = (p − A.center)/|·|                          // 바깥 법선
    p.p += k·pen·dt · n̂                              // ① Hooke 반발(입자에만 — 앵커=무한질량 외부 경계)
    if damp: 안쪽 법선 속도(vn<0)만 0 까지 없애(역전 금지·0037 클램프) → 잃은 KE → internalE  // ② 비가역 소산
```

- 앵커는 *읽기만*(`anchors=[{cx,cy,cz,radius}]`). 쌍힘 아님 — 운동량은 외부 경계로 빠진다(0056 과 동일·물 입자끼리 보존 아님).
- `k=0`/앵커 없음 → early-return(회귀0). 신규 함수라 기존 호출처 0 → 구조적 회귀0.
- 검증·캡처 장면 = 중력(아래)+`sphPressureForce`(0041)+`sphViscosity`(0046)+이 경계의 *조립*. 분지(바닥+벽 정적 앵커)가 균일 중력 누출(0059)을 가둔다.
