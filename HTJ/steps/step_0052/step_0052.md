# step_0052 — SW5 복사 냉각: 열의 출구 = 빛 (계의 첫 에너지 sink)

> [design/sphere-world.md](../../design/sphere-world.md) §6 SW5 — 압력(0041)·점성(0046)·전도(0049)는 에너지를 *재분배*만 한다(KE↔U·U↔U). 계 밖으로 나갈 출구가 없어 붕괴열이 갇힌다. 이 법칙은 그 출구 = **빛** = **0005/0013(열의 출구=빛·질량 보존)의 SPH 판**. (긴 설명은 viewer `note` 0052 가 집.)

## 논의 (법칙 step·새 법칙 하나)

- **세계를 어떻게 변형?** 각 입자가 제 내부E 일부를 회색 복사(빛)로 방출해 식는다: `u_i ← u_floor + (u_i−u_floor)·(1−dt·coolRate)`, 잃은 열은 `radiated` 장부로 쌓인다. 계의 *첫 에너지 sink* — 이전 법칙은 모두 재분배만 했다.
- **무엇으로 검증?** ① 냉각 정의(기하 감쇠·질량 불변) ② 질량·운동량·KE 불변 ③ 열→빛 회계(ΣU 감소=Σradiated) ④ 바닥 온도(floor 아래 안 식음) ⑤ 항등/안전(coolRate=0→회귀0·빈) ⑥ 결정론.
- **무엇이 보존/변하나?** 빛은 *열에서* 나오지 질량 아님(0005 질량소실 닫음) → 질량·운동량·KE **불변**, 총E=KE+u 만 줄어든다(빛이 계를 떠나). **열+빛 합 일정**(heat→light 회계). coolRate=0→회귀0(신규 함수→구조적 회귀0).

## 구현 — `sphRadiativeCooling(particles, dt, opts)` (engine/htj-sph.js, 가법·VERSION 9→10)

```
f = max(0, 1 − dt·coolRate)
floorE = floor·m_i                          // 바닥 내부E (u_floor·m)
above = internalE − floorE
above > 0 → lost = above·(1−f); internalE −= lost; radiated += lost   // 빛 장부
energy = KEcm + internalE                    // 총E↓ (빛이 계 떠남)·질량 불변
```
opts: `{ coolRate(0), floor(0·바닥 비내부E) }`. 빛 장부는 입자별 `e.radiated`(Lagrangian·총빛=Σe.radiated). coolRate=0 또는 dt=0 → early-return.
