# step_0004 — 별의 점화: 임계 방출(밀도 게이트)

> step_0003 의 방출은 *무조건적*이었다 — 잠재력이 있는 모든 셀이 똑같은 율로 방출해, "여기가 방출체(별)다"라고 가리킬 대상이 없었다. 사용자의 질문: **"에너지를 방출하는 별은 어떤 형태로 나타나는가?"** 이 step 이 답한다 — 별은 박아넣는 객체가 아니라, *잠재력 밀도가 점화 임계를 넘긴 영역*이다.

## 논의 — 무엇을, 왜 (시작 질문에 답하며)

**Q. 에너지를 방출하는 별은 어떤 형태로 나타나는가?** — step_0003 에선 방출이 공간 전체에 균일해 별이라 부를 *대상*이 없었다. 별의 정체는:

> 방출을 **조건적(밀도 게이트)** 으로 만든다. 잠재력 밀도 `P ≥ crit` 인 셀만 방출한다 = **별**(밀집한 연료). `crit` 미만(옅게 깔린 배경)은 잠잠히 남는다 = **어두운 성간 가스**. 별의 "형태"는 author 하지 않는다 — *임계를 넘긴 영역의 모양*이 곧 별이다.

후보 셋(① 밀도 게이트 / ② 온도 점화·자기촉매 / ③ 응집 후 점화=인력) 중 **① 임계 점화(밀도 게이트)** 를 택했다 — step_0003 에 가장 단순하게 가법(`crit=0` → 무조건 방출 = 회귀 0), 그러면서 "별 = 국소 점화 영역"을 곧장 세운다. 함께 따라오는 거동:
- **수명**: 별은 타며 `P↓` → `P<crit` 이 되면 점화가 꺼진다. 임계 *아래* 잔여 연료는 잠긴다(점화 못 함).
- **국소성**: 별은 전체가 아니라 코어만 — 처음으로 세계에 *국소 구조*(전체보다 작은, 경계가 또렷한 객체)가 등장한다.

**무엇으로 검증하나**: (a) 수치 — 게이트(가스는 방출 0)·별의 형태(에너지 탄생 셀 = 초기 P≥crit 셀)·보존·가법(crit=0 byte-동일)·수명(점화 정지)·비음수·결정론·항등·통합(별빛이 가스로 확산). (b) 눈 — 가스 채운 상자 → 코어만 빛나는 별 → 별빛이 퍼지는 시계열.

## 구현 — 세계(engine) ⊥ 확인용(viewer)

법칙은 step_0003 방출에 **한 줄 게이트**: `if (crit > 0 && P[i] < crit) continue;`. `crit=0` 이면 그 가지가 죽어 step_0003 와 *byte-동일*(가법성/회귀 0).

- **`engine/htj-potential.js`** — `releaseEnergy(world, rate, {crit})` 에 점화 임계 게이트를 가법적으로 추가(`crit` 기본 0 → 무조건). `seedStarField(world, {core, background, r})`: 옅은 균일 배경(가스) 위에 2차 봉우리 코어(별의 연료)를 까는 *별밭 정물*. `htj-world.js`·`htj-energy.js` 불변.
- **`viewer.html`** — step 갤러리에 **0004(별의 점화)** 추가. `advance` = 임계 방출+확산. **점화 임계** 입력은 점화 step 에서만 노출(step별 `ignite` 플래그). 장 드롭다운으로 potential↔energy 전환.
- **`viewer/capture.js`** (가법 `--star` 모드) — 별밭(잠재력)·점화 직후(코어만 빛남)·확산 후 세 프레임 캡처 + 점화 국소성·수명·확산을 픽셀로 단언.

## 쉽게 풀어 쓴 설명

step_0003 에선 연료가 *어디 있든 똑같이* 조금씩 탔다 — 온 우주가 균일하게 미지근해질 뿐, "별"이라 부를 게 없었다. 이번엔 규칙에 단서를 하나 단다: **"연료가 충분히 빽빽한 곳에서만 불이 붙는다."** 그래서 옅게 깔린 가스(연료가 묽음)는 깜깜한 채로 있고, 한데 뭉친 *코어*만 점화해 빛난다 — 이게 **별**이다. 별은 우리가 "여기 별 하나"라고 찍어 넣은 게 아니라, *연료가 임계보다 진한 영역*이 저절로 별이 된 것이다(그 모양도 연료 분포가 정한다). 별은 타면서 연료가 줄어 점점 작아지다 임계 아래로 떨어지면 꺼진다(수명). 그리고 별이 만든 빛(열)은 step_0002 의 확산을 타고 주변 가스로 번진다. 핵심은 여전히 — 빛이 늘어난 만큼 연료가 줄어, 총합은 변하지 않는다(보존). 숫자로도(점화 셀 = 임계 위 셀 정확히 일치, 가스 방출 0, 총합 오차 0) 그림으로도(가스 상자 → 빨간 별 → 퍼지는 별빛) 확인했다.

## 남긴 의미 · 다음 연결

- **남긴 것**: 세계에 처음으로 **국소 구조**(별 = 임계 넘긴 영역)가 등장했다. 방출을 *조건적*으로 만든 게 핵심 — 균일한 법칙(어디든 같은 규칙)이 *불균일한 결과*(여긴 별, 저긴 가스)를 낳는 첫 사례다. 별은 author 하지 않았다: 모양·위치·수명 모두 연료 분포와 임계의 *결과*다. 게이트는 step_0003 에 byte-동일하게 가법(crit=0).
- **다음(step_0005 후보)**: 지금 별은 *고립*돼 타다 꺼질 뿐 — 점화가 이웃으로 *번지지* 않는다(밀도 게이트는 자기 자리만 본다). 진짜 창발(전파·패턴)로 가려면 점화가 *이웃 상태에 반응*해야 한다 — 후보: (a) 온도 점화(방출열 E 가 이웃을 임계 위로 데우면 연쇄 점화 → 진행파/별의 군집), (b) 역변환(energy→potential)으로 식은 곳에 연료 재응결 → 점화-소멸의 순환. 검증축: *author 없이* 점화가 공간적으로 조직되는가.
- **열린 격차**: 렌더가 표면 셀만 그려, 코어 봉우리(내부)와 점화 구의 *내부 분포*가 겉에서 안 보인다(잠재력 장은 가스 표면만 파랗게 보임). 별의 내부 구조·점화 경계를 볼 때 슬라이스/투명 표현이 필요 — step_0001 부터 이어진 격차.
