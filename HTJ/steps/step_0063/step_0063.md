# step_0063 — (M3) DNA 로 렌더: 합친 개체를 shapeHash 로 원래 윤곽으로 그린다

> 병합·형태 DNA 트랙 셋째 벽돌(M3·렌더 트랙). 순수 기하 복원 `reconstructShape`(htj-shapedna.js) + viewer 렌더 경로.
> 설계: [design/merge-dna.md](../../design/merge-dna.md) §4 M3. 긴 산문은 viewer `note`(STEPS '0063')가 집.

## 논의 (세계를 어떻게 변형 · 무엇으로 검증 · 무엇 보존/변함)

- **변형(렌더만·engine 불변)**: M1(0061) 병합 + M2(0062) shapeHash·세계 사전까지 섰으나, 합친 개체는 *그릴* 때 여전히 큰 원 하나였다("큰 원이 지형 모양 안 됨"). M3 은 그 코드를 **발현**: viewer 가 `reconstructShape(개체, 사전)` 로 shapeHash→canonical 형태를 꺼내 개체 위치·반경에 맞춰 **구성원 점 무리(원래 윤곽)**로 그린다. 같은 모양=같은 윤곽·같은 색(DNA).
- **검증**: ① 형태 복원(hash→count개 점·민둥 구 아님) ② 위치·스케일 따라감(개체 이동/반경에 강체) ③ DNA 없음→null(단일 구 폴백) ④ 순수/불변(읽기만) ⑤ 결정론 + 눈(L/직선/삼각 윤곽).
- **보존/변함**: engine·물리 *전부 불변*(렌더 트랙·회귀0 구조적)·결정론. `reconstructShape` 추가(VER 1→2)·viewer 렌더 경로 가법(사전 없으면 기존 단일 구).

## 구현 (법칙 식 · 진입점)

`htj-shapedna.js :: reconstructShape(entity, dict, opts)` (VER 1→2·순수):

```
canon = dict[entity.shapeHash];  없으면 null(단일 구 폴백)
각 canonical 점 q_i:  world_i = entity.center + q_i · (quantum · radius · spread)
                      sub 반경 = radius / count^⅓ · subScale   (≈원래 구성원 크기)
→ [{cx,cy,cz,r}] (어디에 그릴지만 계산·픽셀은 viewer/capture)
```

- canonical 은 정규화(스케일 불변)점 → 절대 크기 잃음 → **개체 반경에 비례**해 펼침(proportion 보존).
- `viewer.html` 렌더 경로: `world.__shapeDict` 있으면 각 개체를 reconstructShape 로 펼쳐 `drawClumps`(점 무리)·없으면 기존 단일 구(가법). `htj-shapedna.js` 스크립트 추가. **drawClumps·htj-capture.js·engine 불변** — 확장은 viewer 매핑에만.
- **세계↔확인용 단방향**: reconstructShape 는 *위치만* 계산(렌더 의존 0·Node 에서 verify), 픽셀은 viewer/capture.
