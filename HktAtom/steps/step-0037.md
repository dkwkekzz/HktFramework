# step-0037 — ⑳ 플라스마 합류: 자유전자 개체와 이온화 기체 (사용자 게이트 9차)

## 무엇을 했나 (현상 1개)

**앵커 현상**: *뜨거운 기체가 플라스마가 된다* — playground 기본 세계에서 Na 증기를 가열하면 충돌 이온화(R-ION: A+M→A⁺+e⁻+M·문턱=IE 에너지 가드)로 **자유전자 개체**가 태어나고, 3체 재결합(R-REC3)과 경쟁하며 이온화 분율이 오른다: **⟨x⟩ T0.5 0.57 → T3.0 0.81**, 급랭하면 재결합이 이겨 **x 0.83 → 0.25** (재결합열 방출). 전하 회계 Σq(원자)=n_e **정확**. 개체 추가형(⑳⑫⑲) 첫 관문.

## 구현 (playground 기준)

- **카탈로그 행 재사용**: ⑳ 의 R-ION·R-REC3 는 이미 행 형식 — playground catalog 에 추가만 ("새 현상 = 행"·KERNEL §3.1). specIon 은 ⑤ 것 공유: 양이온형(알칼리 등)은 이온화, 음이온(Cl⁻)은 전자 탈착, 중성 음이온형은 전자 부착 — 전부 같은 두 행에서 창발.
- **자유전자 개체 지원**: 엔진이 이미 보유(electrons·pairForces·경계·장부) — playground 는 tick 강성 스캔·항온조에 전자 포함 + `chargeOK`(Σq=n_e) 검증 추가. m_e 0.5 (⑳ 노브 준용).
- **전자 = 순수 연화 쿨롱 개체**: `eps_e 0`(r⁻¹² 벽 제거) + `soft_e 0.45`(전자 낀 쌍 전용 softening — 엔진에 세계 속성으로 추가·부재 = 기존 s = 참값). 점전자가 soft 0.1 특이점으로 낙하하며 벽에 catapult 하는 적분 폭탄(실측 잔차 1e32)을 원천 봉쇄 — ⑳ 장면이 유계 힘을 쓴 이유의 반응-세계 판.
- **뷰어**: 자유전자(청록 점+꼬리)·원자 수 옆 `+Ne⁻`·☄ ⑳ 프리셋. 기존 hotgas 라벨을 ⑤ 로 정정(진짜 ⑳ 이 생겼으므로).

## 뷰어 확인 방법 (눈 확인)

`playground.html` → **☄ ⑳ 플라스마** 프리셋: Na 증기가 가열되며 Na⁺(주황 굵은 링) 사이로 자유전자(청록 점·속도 꼬리)가 날아다닌다 — 원자 수 옆 `+Ne⁻` 가 전자 수. 항온조 목표를 낮추면 전자가 사라지고(재결합) 중성 Na 로 복귀. Na₂⁺/Na₂²⁺ 분자 이온 라벨(주황)도 보인다. 헤드리스 스크린샷 확인: 전자 22개·x≈0.9 플라스마 상태.

## 쉽게 풀어 쓴 설명

기체를 아주 뜨겁게 하면 원자끼리 세게 부딪히다가 전자가 튕겨 나간다 — 이온과 자유전자의 수프, 플라스마다(번개·네온사인·별). 이번 step 에서 놀이터에 "튕겨 나간 전자"가 실제 개체로 태어난다. 규칙은 단 두 줄: 세게 부딪히면 전자가 나가고(비용은 이온화 에너지 — 느린 충돌은 못 낸다), 이온이 느린 전자를 다시 붙잡는다(셋이 모였을 때만 — 남는 에너지를 셋째가 받아줘야 하므로). 가열하면 튕김이 이기고 식히면 붙잡음이 이긴다 — 이온화 곡선은 이 경쟁의 결과일 뿐 어디에도 적혀 있지 않다. 어려웠던 점: 점전하 전자가 이온에 빨려들며 컴퓨터 계산이 폭발하는 것 — 전자 주변 힘을 유한하게 다듬어(깊이가 유한한 우물) 해결했다.
