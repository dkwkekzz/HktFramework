# step-0026 — S0-㉓ 핵종·동위원소 (핵 게이트 개방)

> 앵커: 동위원소 진동수 이동 ω_D/ω_H ≈ √(μ_H/μ_D) · 게이트: **G-핵 개방 — 게임플레이가 핵분열 요구**(CONTRACT §6-② · DESIGN §9.3) · design/23-26-nuclear.md ㉓ · KERNEL §5 핵 동결 해제 1안

## 게이트 개방 근거

핵 트랙(㉓~㉖)은 게이트 **G-핵** 뒤에 있고, 개방 조건은 둘: ① 상위 단계가 자생 에너지원(별) 요구 ② **게임플레이가 핵 사건(폭발·낙진) 요구**. 사용자가 "핵분열이 가능해야 한다"고 요구 → **조건 ② 발동**. 우선순위(DESIGN §9.3)는 **㉓ 최소분 → ㉔ 붕괴 → ㉕ 분열**. 이 step 은 그 첫 조각(㉓)이다. 가상 핵종을 쓴다(실수치 정합 불요·임계 조건은 밸런스 자유도·CONTRACT §5).

## 무엇을 했나

**`nuclear.js` 신설** (엔진 diff 0 — 자체 완결 모듈·핵심 엔진 ①–⑳ 불변). 핵 내부 구조는 여전히 동결 — 핵종은 **상태표**(질량·수명·붕괴 채널·단면·바닥 특권 데이터)로 다룬다.

**보존 다발 확장 `c = (Z, e) → (Z, N, e)`** (KERNEL §5 핵 동결 해제 1안 — c 에 N 추가). 원자에 `.N`(중성자 수)·`.nuc`(핵종 라벨)을 얹되 **화학은 미접촉** — 엔진 화학은 `a.sp`·`world.mass` 만 보므로 N 추가가 화학을 안 건드린다(전 장면 회귀로 확인).

**질량 Σ 회계 `m = Z·MP + N·MN − BE·C2`** — m(Z) 테이블 폐기, **질량 결손(BE)이 장부의 실물**이 된다(㉕ 분열 방출 Δm·c² 의 근원). 가상 핵종표: H1(Z1,N0,m1) · D2(Z1,N1,m2·중수소) · O16(Z8,N8,m4·화학 O 정합) · N1(자유 중성자 c=(0,1,0)).

**앵커 — 동위원소 진동수 이동 (author 0)**: O–H vs O–D 결합의 신축 진동 주파수를 측정. 스프링 `k` 동일·환산질량 `μ` 만 다르므로 `ω = √(k/μ)` → `ω_D/ω_H = √(μ_OH/μ_OD)`. D 의 질량 2 는 **N=1(중성자 하나)의 귀결**이므로, 진동수 이동이 곧 N 이 물리적으로 실재함의 증명이다.

## 발견 (한계 정직)

1. **⑦ ħω 는 고정 노브 → 앵커는 결합 스프링 진동에서 측정** — design/23 은 "⑦ ω 가 질량에서 유도"라 했으나 modes.js 의 ħω(HBW=2.0)는 고정 상수다. 실제 질량 의존 진동수는 **결합 스프링**(kbond)의 고전 진동 ω=√(k/μ)이다. 그래서 앵커를 결합 스프링 진동 측정으로 잡았다(질량 유도·author 0 동일 성립). design/23 을 이 발견으로 정정.
2. **질량 결손은 회계용·화학 질량은 테이블 유지** — 화학 회귀(전 장면)를 지키려 화학은 `world.mass` 테이블을 계속 쓰고, 핵 사건의 에너지만 질량 결손 회계에서 가져온다. 이중 장부가 아니라 해상도 분리(화학 vs 핵).
3. **가상 핵종·핵 내부 동결** — 껍질 모형·공명 단면 없음. 핵종 상태표 + 채널 행의 유효 모델(design 경계). 실세계 정합 주장 없음.
4. **㉓ 은 기반·분열 아님** — 다음 ㉔(붕괴)·㉕(분열·k_eff)이 "핵분열 가능"을 실현한다. 자유 중성자 N1·질량 결손 회계는 여기서 예약됐다.

## 쉽게 풀어 쓴 설명

원자의 "정체"는 지금까지 (양성자 수 Z, 전자 수 e) 둘이었다. 핵분열을 다루려면 **중성자**가 필요하다 — 그래서 정체에 (중성자 수 N)을 하나 더 붙였다: (Z, N, e).

같은 원소라도 중성자 수가 다르면 "동위원소"다 — 수소(H)와 중수소(D)는 둘 다 양성자 1개지만 D 는 중성자가 하나 더 있어 두 배 무겁다. 이번 step 은 이 무게 차이가 실재함을 **진동으로** 증명했다: 용수철에 매단 추가 무거우면 천천히 흔들리듯, 무거운 D 는 산소와 이룬 결합에서 H 보다 느리게 진동한다. 그 비율(0.7746)이 이론값 √(질량비)과 정확히 일치했다 — 우리가 넣은 건 "D 는 중성자 하나 더 있어 무겁다"는 것뿐인데 진동수 이동이 저절로 나온 것(author 0).

또 무게를 "양성자·중성자 개수 − 결합 에너지"로 계산하게 바꿨다. 이 **결합 에너지(질량 결손)** 가 다음 단계에서 핵분열의 에너지가 나오는 곳이다("E=mc²의 m").

**뷰어 확인**: `stages/S0-atom/index.html` 하단 **㉓ 핵종·동위원소** 섹션에 두 진자가 나란히 흔들린다 — 위 H–O(빠름)·아래 D–O(느림). 눈으로 D 가 확연히 천천히 흔들리는 게 보이고, 아래 ω_D/ω_H=0.7746≈√(μ 비) 수치. (헤드리스: `node -e "console.log(JSON.stringify(require('./nuclear.js').isotopeShift({})))"`.)
