# step-0031 — 반응 체감 게이트: 융합·알칼리+물·위력 스케일·수치 안전판 (사용자 게이트 3차)

## 왜 이 step 인가

사용자 피드백: "반응이 너무 없다 — 핵반응 에너지가 약하고, Na+물 폭발 같은 격렬 반응이 없다. 다른 반응도 안 일어나는 것 같다." 진단 결과 셋 다 실재하는 문제였다:

1. **이온 반응열이 눌려 있었다**: step-0029 의 EA 클램프 0.6(⑤ 가상 앵커 규모 정합)이 전자 이전 발열을 ~0.1 규모로 만들어 열운동에 묻혔다.
2. **분열 Q=30 이 약했다**: 파편 속도가 열속도 수준(v≈1.4)이라 "폭발"로 안 보였다.
3. **융합이 없었다** (사용자가 명시 언급).

## 무엇을 바꿨나 (전부 playground 층 · 엔진 diff 0)

- **EA_CAP 0.6 → 2.5**: 알칼리(IE 0.3~0.5) + 음이온형(EA_eff 2.5) 전자 이전이 ~2 규모 발열 → `collisionalTransfer` 가 그만큼을 상대 KE 로 분출 → **Na+물이 실제로 격렬**해진다 (T 2~7배 급등·verify). ⑤ 규모 정합보다 반응 체감을 우선한 게임 노브 — 격차 갱신.
- **분열 Q 30 → 150** + nu_xfer 3→6 + 점화 ×1.8→×2.5: 파편 v≈3·중성자 v≈6.7 — 상자를 가로지르는 폭발이 보인다. 연쇄가 U 6개를 **전량 소진**(완전 폭주)한다.
- **핵융합 신설 (㉖ 예고편·가상 무차원)**: `FUSION = H+H → He+n + Q=40`, 게이트 = 상대 KE ≥ 장벽 4.5(쿨롱 장벽의 게이트 근사 — Gamow 터널링은 ㉖ 몫)·맨(비결합) H 만. 실 D-T 처럼 **중성자가 KE 대부분**(질량 역비 분배·v≈8) — 고속 중성자가 근처 U 분열을 촉발하는 커플링이 창발한다. 회계는 분열과 동형: H 소환 시 Q/2 를 E_nuclear 에 저장(수소=융합 연료) → 융합이 실측 ΔE 만큼 인출 → 총량 불변·Σc 는 pgConv.
- **수치 안전판 2개 (발견 → 즉시 처치)**:
  - **적응 서브스텝**: Q=150 파편이 r⁻¹² 척력 벽을 한 tick 에 관통 → 잔차 1e37 폭발 실측. `tick()` 이 최고 속도 기준으로 dt 를 쪼갠다(이동 ≤ 0.006/서브스텝·상한 48·hazard 는 world.dt 를 읽어 통계 동등). 결과: 분열 연쇄 상대 잔차 ≤ 6e-4.
  - **도구 속도 상한 VCAP=12**: 점화 연타로 속도가 기하 누적(×2.5 씩)되면 서브스텝 상한으로도 못 막는다(브라우저 실측 T~1e25). 관찰자 도구(heatPulse)만 |v| ≤ 12 로 포화 — 핵반응 방출 속도(8~10)는 그대로. 회계는 실측 증분이라 여전히 정확.
- **잔차 판정 상대화**: 허용 잔차 = max(0.1, 0.2~0.3%·주입 E) — 고 KE 서브스텝 드리프트는 에너지 규모에 비례한다(문서화된 적분 오차·전이 자체는 checkedApply/실측 보상으로 정확).

## 쉽게 풀어 쓴 설명

"반응이 심심하다"는 불만의 원인은 에너지 눈금이었다. 현실감을 위해 눌러 놓은 반응열 때문에 나트륨이 물을 만나도 미지근했고, 핵분열도 열운동에 묻혔다. 이번에 반응열 눈금을 올리자: 나트륨+물은 전자가 넘어가는 순간 온도가 몇 배로 튀고, 우라늄 분열 파편은 화면을 가로지르며, 수소를 아주 뜨겁게 만들면 진짜 별처럼 융합(H+H→헬륨+중성자)이 일어난다 — 융합이 뱉은 고속 중성자가 옆의 우라늄을 쪼개는 연쇄도 저절로 생긴다. 대신 두 가지 안전장치를 달았다: 빠른 입자가 있으면 시뮬레이션 걸음을 잘게 쪼개 계산이 터지지 않게 했고(서브스텝), 가열 도구는 일정 속도 이상으로는 못 데우게 했다(속도 상한). 에너지 장부는 이 모든 난리 속에서도 0 으로 닫힌다.

## 발견

- **위력은 스케일 분리의 문제다**: 반응이 "일어나는가"와 "보이는가"는 다르다 — 반응열 ≫ 열운동(kT)이어야 사건이 서사가 된다. Q/kT 비율이 게임 체감의 실제 노브.
- **고 KE + r⁻¹² 벽 = 적분 폭탄의 일반형**: 겹침 소환(0029)과 같은 뿌리. 해법도 일반형 — 속도 기준 적응 서브스텝. 상위 단계(S1+ 폭발 왕복)에서도 같은 안전판이 필요할 것.
- **도구는 물리보다 위험하다**: 물리 전이는 에너지 출처 원칙이 폭주를 막지만, 관찰자 도구(가열)는 외부 주입이라 무한 누적 가능 — 도구 쪽에 포화를 두는 것이 옳은 자리.
