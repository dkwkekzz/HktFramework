# step-0014 — S0-⑭ 형상 (결합각·VSEPR)

> 현실 앵커: **CH₄ 정사면체 · H₂O 굽음 · BeH₂ 직선** — 셋이 **하나의 각도 반발**에서 동시에 창발.
> 전제: ⑥(공유결합)·⑬(3D). 설계: [design/14-geometry.md](../stages/S0-atom/design/14-geometry.md) · **목표각 author 금지**.

## 한 일 (현상 1개 = 형상의 창발)

분자 형상을 author 하지 않는다. 같은 원자의 **전자쌍 방향(도메인)들 사이 공통 반발 하나**로 굽음·직선·
정사면체가 전부 나온다 (VSEPR 의 동역학 구현). 분자별 목표각은 없다 — 상수 2개(`k_ang`·`λ_lp`)와
도메인 수(③ 유도)만이 입력이다.

- **`geometry.js` 신설** (self-contained·엔진 ①–⑬ diff 0·⑬ 의 computeForces 합성 패턴 재사용):
  - **도메인** = 결합 도메인(이웃 방향) + 고립쌍 도메인(수 = (외각 전자 − 결합)/2 · **③ fillZ 유도·author 0**).
  - **공통 각도 반발** `V_ang(원자) = k_ang · Σ_{a<b} w_a·w_b / (1 − cosθ_ab + c0)`, `w = 1`(bond) | `λ_lp`(lone).
  - **결합 도메인의 힘** = −∂V_ang/∂r 를 이웃 원자에 접선 방향, 반작용을 중심에(`F_center = −ΣF_nb`).
    V_ang 이 각도(회전·병진 불변)에만 의존 → 이 정확 그래디언트는 **P·L 정확 보존**(뇌터). U_bond 통 귀속.
  - **고립쌍 방향**은 질량 없는 보조 변수 — 매 force 평가마다 V_ang 최소로 재이완(경사하강). 최소에서
    ∂V/∂lone≈0 → **포락선 정리**로 V_ang*(bond) 이 원자 위치의 보존 퍼텐셜 → 별도 에너지 라우팅 없이
    장부가 닫힌다 (design 의 "n_relax + 잉여 K_tr" 를 준정적 최소화로 대체 — 더 정직·간결).
- **`scenes.js`**: 미리 결합된 독립 분자를 무작위(피보나치+지터) 배치 → 각도 반발이 형상으로 이완. 3장면
  `s14-methane`(C4+4H)·`s14-water`(O2+2H)·`s14-linear`(Be2+2H). 외각 전자는 `valenceElectrons(Z)`=③ fillZ 유도.
  결합 고정(catalog 없음 — 형상만). **형상 이완**(과감쇠 하강)은 maxwellInit 과 동형인 초기 조건 준비.
- **`index.html`**: 3D 뷰어(⑬)에 **고립쌍 유령 화살표**(청록 파선) 추가. s14 드롭다운.

## 쉽게 풀어 쓴 설명 (비전문가용)

**"분자가 왜 그 모양인가"를 한 규칙으로 설명한다.** 물은 굽었고(104°), 메탄은 정사면체(109.5°), BeH₂ 는
일직선(180°)이다. 학교에서는 이걸 VSEPR("전자쌍끼리 밀어낸다")로 배운다. ⑭는 그 밀어냄을 **실제로**
굴린다 — 분자마다 "이 각도가 되어라"라고 정해주지 않는다. 대신 **모든 분자에 똑같은 규칙 하나**만 준다:
*중심 원자에 붙은 전자쌍 방향들이 서로 밀어낸다.*

그 하나의 규칙에서 세 모양이 저절로 갈린다:
- **메탄(CH₄)**: 탄소에 4개의 결합. 4방향이 똑같이 밀어내면 → 가장 멀어지는 배치 = **정사면체(109.5°)**.
- **물(H₂O)**: 산소에 2개의 결합 + **2개의 고립쌍**(결합 안 한 전자쌍). 고립쌍은 결합보다 **더 넓게**
  퍼진다(λ_lp>1). 그래서 고립쌍이 결합을 밀어붙여 각을 109.5°보다 **좁게(104°)** 만든다 → **굽음**.
- **BeH₂**: 베릴륨에 2개의 결합만(고립쌍 0). 2방향이 최대로 멀어지면 → **일직선(180°)**.

고립쌍의 개수는 손으로 안 넣는다 — 원자의 전자 수(③에서 계산)에서 **자동으로** 나온다(산소=2, 탄소=0,
베릴륨=0). 그리고 검증: 고립쌍 배율(λ_lp)을 1로 되돌리면 물의 각이 104°→109.5°로 **열린다** → 굽음의
원인이 정확히 고립쌍임을 보여준다.

**정직한 한계**: 진짜 CO₂(직선)는 이중결합(C=O)이 필요한데 우리 모델은 아직 단일결합만 있다(⑩의 격차).
그래서 직선 앵커는 이중결합이 필요 없는 **BeH₂**(실제로도 직선)로 확인했다. CO₂ 는 이중결합이 들어올 때.

## 뷰어에서 보기 (눈 확인)

`index.html` → 장면 (마우스 드래그로 3D 회전):
- **s14-methane**: 회색 C 중심에 흰 H 4개가 **정사면체**로 벌어짐. 고립쌍 없음.
- **s14-water**: 빨간 O + 흰 H 2개가 **굽은** 배치. O 에 **청록 파선 = 고립쌍 2개**(각을 압박하는 도메인).
- **s14-linear**: 청보라 Be + 흰 H 2개가 **일직선**.

## 발견·한계 (STATE §3 등록)

- **고립쌍 준정적 최소화가 더 정직**: design 의 "고립쌍 n_relax 이완 + 잉여 K_tr 라우팅"은 단일 원자에
  KE 를 넣어 P 를 깨뜨린다. 대신 **매 force 평가마다 고립쌍을 최소로 재이완**하면 포락선 정리로 V_ang 이
  보존 퍼텐셜이 되어 라우팅 없이 장부가 닫힌다. 다만 고립쌍이 있는 분자(물)는 준정적 근사의 잔차로 L 이
  기계 정밀도가 아니라 ~1e-4 로 미세 드리프트(고립쌍 없는 CH₄·BeH₂ 는 L 기계 정밀도 7e-14).
- **직선은 소프트 최소 — 이완으로 측정**: `1/(1−cosθ)` 는 180° 에서 기울기가 0 에 수렴(소프트 최소)이라
  유한 온도 열평균은 180° 미만으로 편향(경계 효과). 그래서 형상은 **과감쇠 이완의 최소 배치**로 측정한다
  (열평균 아님) — BeH₂ 175°. 열을 올리면 각 분포 폭이 커진다(굽힘 모드 열 여기).
- **CO₂ 는 이중결합 대기**: 직선 앵커를 BeH₂ 로 대체. C=O 이중결합(⑩ order=1 격차)이 들어오면 CO₂ 직선
  (C 2도메인 0고립)도 같은 규칙으로 나온다.
- **λ_lp=1 대조는 109.5° (120° 아님)**: design 은 물 대조를 120°(3도메인)로 적었으나, 물은 4도메인
  (2결합+2고립)이라 λ_lp=1 이면 정사면체 109.5° 로 열린다. 측정 109.9° 가 정답 — design 노트 정정.
