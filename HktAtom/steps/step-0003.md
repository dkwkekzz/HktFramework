# step-0003 — S0-③ 준위·예산 (주기율표 뼈대)

> 앵커: 주기율표(실원소 순수 함수) + 가상 원소 확정 · 전제: 없음(순수 함수 — ①②와 독립) · 설계 권위: [../stages/S0-atom/design/03-levels-budget.md](../stages/S0-atom/design/03-levels-budget.md)
> 상태: **닫힘** · 코드: `stages/S0-atom/levels.js` + verify/뷰어

## 무엇을 했나

전자 구조의 전부를 **순수 함수**로 만들었다(`levels.js`) — 시뮬 없이 단위 테스트로 닫는다. 원 안에 "전자 준위"가 처음 채워진다.

- **순수 함수 사슬**: `fillZ(Z)`(Aufbau+파울리) → `zeff`(간이 Slater 차폐) → `eps`(−R·(Zeff/n*)²) → `ionizationE`·`affinity` → `unpaired`(훈트) → **`budget(Z)` = 연속 결합차수 예산 B**(바닥 홀전자 + s→p 승위).
- **`fromZ(Z)`**: 실원소 종 명세(levels·occ0·B·IE·EA) 유도. **`VIRTUAL`**: 가상 원소 4종(V1/V0/V2/V4) 직접 author. 인터페이스 동일 → 엔진은 실/가상 구별 안 함.
- **`boltzmann(levels,T)`**: gᵢe^{−(εᵢ−ε_min)/T} 정규화 — ④ 볼츠만 검증의 기준 곡선.
- **주기율표는 표로 박지 않는다**: 같은 족의 닮음(외각 수)·원자가가 순수 함수에서 *나온다*. `if(isCarbon)` 분기 0.

## 두 가지 발견 (design/ 갱신함)

1. **승위 조건 확장 → 교과서 원자가 일렬 창발**: 초안은 승위 대상을 "occ 에 이미 있는 p"로 좁혔는데, 그러면 Be·Mg 가 B=0(2p 가 비어 승위 안 됨). **"빈 p 부껍질도 승위 대상"으로 고치니** Be=2·Mg=2 포함 `1,2,3,4,3,2,1,0` 이 일렬로 나온다. crude Slater 가 s/p 를 구분 못 해 승위 비용 cost≈0 → 이득>0 이면 항상 최대 홀전자 승위(정직: 실제 s→p 비용은 0 아님).
2. **족 내림(Li>Na>K)은 창발 안 함 — OPEN GAP 로 등록**: 측정 = **Na>Li>K**(Na 최대). 간이 Slater 가 3s 침투/차폐를 과소평가한 결과. **손튜닝으로 위조하지 않고** 격차로 남긴다(KERNEL: "앵커가 안 나오면 그것이 발견이다"). 주기 내 단조 증가·희유기체 피크·알칼리 골 3경향은 견고히 창발.

## 뷰어 눈 확인 (`index.html` — "보기: 시뮬 ⇄ 준위③")

- **상단 차트**: Z=1~20 이온화 E 막대 — 주기 **지그재그**가 뚜렷. **희유기체(He·Ne·Ar) 주황 피크 · 알칼리(Li·Na·K) 파랑 골**. 각 주기(Li→Ne, Na→Ar)에서 오르막 후 다음 알칼리에서 급락.
- **하단 카드**: 가상 원소 4종 — 각 카드에 종 색·`B` 값·유사 실원소·준위선(바닥 g 파랑 굵게 + 들뜬 e1). V1 준위 간격이 V2 보다 크다(스펙트럼 구분).

## 쉽게 풀어 쓴 설명

①에서 빈 판, ②에서 밀당하는 힘을 넣었다면, ③은 **원자 안에 전자의 "층(준위)"을 채워 넣는 규칙**을 만들었다. 딱 하나의 규칙 — "전자는 낮은 층부터 채운다(Aufbau) + 한 칸에 둘까지(파울리)" — 과 "안쪽 전자가 바깥 전자한테서 핵의 끌어당김을 가려준다(차폐)" 만 넣었다.

그랬더니 **주기율표가 저절로 나왔다.** 아무도 "탄소는 결합손 4개"라고 적어 넣지 않았는데, 함수를 돌리니 H=1, 탄소=4, 질소=3, 산소=2, … 네온=0 (교과서 원자가 1,2,3,4,3,2,1,0)이 일렬로 튀어나온다. 이온화 에너지(전자 하나 떼는 힘)를 원자번호 순으로 그리면 **그 유명한 주기 지그재그** — 비활성 기체에서 가장 높고 알칼리 금속에서 뚝 떨어지는 톱니 모양 — 이 그대로 그려진다(캡처 참고).

정직한 실패도 하나 기록했다: "같은 세로줄에서 아래로 갈수록 이온화가 쉬워진다(Li>Na>K)"는 이 간단한 차폐 모델로는 안 나온다(Na가 제일 커버린다). **속이지 않고 "미해결 격차"로 남겼다** — 나중에 더 정밀한 보정이 필요한 단계가 오면 그때 고친다.

한 마디로: **"낮은 층부터 채운다 + 안쪽이 가려준다" 두 규칙만으로 주기율표의 뼈대(원자가·주기 경향)가 창발했다.**
