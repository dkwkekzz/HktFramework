## 한 일 (요약)

가상 원소로 세운 구조 창발(⑥ 결합·⑧ 응집·⑨ 평형)에 **실원소 파라미터를 합류**시켜, **2H:1O 수프에서 H₂O 가 최다 분자종으로 창발**함을 보였다 (`if (isWater)` 분기 0 — 측정된 조성일 뿐).

핵심 장치는 **쌍별 결합 우물 깊이 D** — step-0006 이 남긴 gap(등방 우물 = 종 무관 D → H₂O 우세 안 함)의 해결:

- **`engine.js`** (최소·backward-compat): `pairD(world, sp1, sp2)` + 각 결합의 `bd.D`. 소비처(`U_bond`·해리 아레니우스)는 `bd.D != null ? bd.D : world.Dbond` — **스칼라 fallback 이라 ①–⑨ 회귀 0**.
- **`scenes.js`**: 실원소 종 `H·O·He·Ne` (B·IE 는 ③ `levels` 순수 함수 유도값 — author 아님 · σ·mass 는 무차원 비율 노브). **`Dpair` = 실 결합 에너지 비율 `H–H:O–H:O–O = 436:463:146 kJ/mol`** 앵커 (D_OH=2.0 기준 → D_HH=1.88·D_OO=0.63). O–H 최강·O–O 최약 → O 가 H 를 2개 잡아 H₂O.
- **냉각 스케줄 `annealSoup`**: 고T 평형 탐색 → 6단 냉각. 항온조가 뺀 열은 **`E_escape` 로 회계 → 장부 닫힘**(④ 복사 냉각과 동형). 어닐링이 활성화 장벽을 넘게 해 준안정 중간체(H₂·OH)를 열역학 산물(H₂O)로 이완시킨다.

## 발견 (설계를 실물 코드가 이렇게 고쳤다)

1. **H–H(436) ≈ O–H(463) 근접 → H₂ 는 실제 경쟁자**. 실 결합 에너지 비율을 그대로 쓰니 H–H 가 O–H 의 94% — H₂ 가 강하게 형성돼 H 를 가둔다. 그래서 H₂O 우세는 **어닐링(열역학 최소 도달)** 이 필요하고, 크래시 냉각은 H₂ 에 kinetic 하게 갇힌다. 이것은 결함이 아니라 **실 화학의 준안정성**(2H₂+O₂ 혼합이 점화 없이는 안 터짐)의 재현이다. 그래서 우세는 pooled(R=6) 로 확인: H₂O 46 vs H₂ 26.
2. **단일 결합만(bond.order=1) → O=O 이중결합 부재**. 실 O₂(498, 이중)를 못 표현해 우리 "O₂"(단일 O–O·D 0.63)가 비현실적으로 약하다. 그래서 설계의 `s10-h2-o2-metastable`(준안정 H₂+O₂) 장면 대신 **크래시 vs 어닐 대조**로 활성화 장벽을 실증한다 — 더 견고하고 정직. 이중/삼중 결합(π)은 후속. → STATE §3 격차.
3. **냉각을 닫힌 장부로**: 항온조(속도 재조정)가 뺀/넣은 열을 E_escape 통에 회계 → 전이·냉각을 관통해 총 E 보존(3.8e-4 ≤ EPS_E). 손 튜닝 아님 — 냉각 저수지에 열을 넘기는 정직한 회계.

## 쉽게 풀어 쓴 설명 (비전문가용)

**물은 왜 H₂O(수소 2 + 산소 1)일까?** 산소 원자는 손이 2개(원자가 B=2), 수소는 손이 1개(B=1)다. 손을 다 맞잡으면 산소 1개가 수소 2개를 잡아 H–O–H, 즉 물이 된다. 우리는 "물을 만들어라"라고 코딩하지 않았다. 대신 **어떤 원자끼리의 결합이 얼마나 튼튼한지**만 실제 화학 값(수소–수소 436, 산소–수소 463, 산소–산소 146)으로 넣었다. 산소–수소가 가장 튼튼하니, 충분히 뒤섞고 식히면 원자들이 스스로 가장 튼튼한 짝(물)으로 정착한다.

**함정**: 수소–수소(436)도 산소–수소(463)만큼 튼튼하다(겨우 6% 차이). 그래서 급하게 식히면 수소끼리 먼저 붙어 H₂(수소 기체)로 갇혀버린다 — 실제로도 수소와 산소를 섞어두면 불꽃 없이는 안 터지고 그대로 있는다(준안정). 물이 이기려면 **뜨겁게 데워 마구 섞이게 한 뒤 천천히 식혀야**(어닐링/풀림) 한다. 뜨거우면 잘못 붙은 짝이 다시 떨어져 재조합하고, 서서히 식으면 가장 안정한 물로 내려앉는다. 대장장이가 쇠를 달궜다 천천히 식혀 결정을 고르게 하는 것과 같다.

**결과**: 천천히 식힌 수프(어닐링)는 물(H₂O 46개)이 가장 많고, 급랭한 수프는 수소기체(H₂)가 더 많다 — 어닐링이 활성화 장벽을 넘겨 진짜 안정한 물질로 데려간다는 증거다.
