## 왜 이 step 인가

step-0029 관찰자 샌드박스에 대한 사용자 후속 요구 4개: ① 2D 유지한 채 3D 도 ② 온도 조절·열역학 시뮬 확인 ③ 폭발·분열 같은 역동적 현상 ④ 공간을 복셀로 나눠 온도 상태가 보이게. 전부 **새 물리 author 0** 으로 해결 — 기존 조각의 재사용·합성이다: 3D=⑬ z 해동(엔진이 이미 지원), 연소=⑱ R-ABSTRACT 행 합류, 핵분열=㉕ 동형의 인월드 판, 복셀 장=측정 함수 추가.

## 무엇을 만들었나 (playground.js/html · 엔진 diff 0)

- **핵분열 (㉕ 동형·가상·무차원)**: 중성자 = 커널 개체(q=0·B=0·작은 σ — 물질을 얇게 통과·수명 τ=80 지나면 소멸=escaped/E_escape 회계). 핵연료 `U` 소환 시 저장 핵에너지 Q=30 을 E_nuclear 통에 **함께 주입**. 분열 행 {match·hazard·apply} 는 카탈로그 행과 동형이되 **tick 후단 자체 실행기**(`runFission`)로 돈다 — 원자 소멸·생성이 엔진 접촉 페어 인덱스를 흔들지 않게 (runBonding 과 같은 지위). apply: U+n 제거 → Ba+Kr+2n 을 빈자리 탐색으로 배치, COM 운동량 상속+방출쌍 반대 방향(P 정확), KE 0.7Q(파편)+0.3Q(중성자쌍), `E_nuclear −= 실측 ΔE`(총량 불변 — Δm·c² 회계의 축약). Σc 는 **전환 장부 pgConv** 가 기록(검사 = pgIn + pgConv). ν=2 → **연쇄**: 중성자 1발이 여러 U 를 연달아 쪼갬 = 폭발적 역동.

## 뷰어 확인 방법

① 물 키트 + 항온조 ON(목표 T 낮게) → T 스파크라인이 목표로 이완·열지도가 파랗게 식는다. ② E 로 가열 → 커서 근방 셀만 빨개진다(복셀 장). ③ ☢ 핵연료 키트 → F 로 중성자 발사 → 섬광 링·☢ 피드·파편(Ba 초록·Kr 청록)·주변 셀이 빨갛게 — 연쇄면 분열 카운터가 연달아 오른다. ④ 3D 로 전환 버튼 → 드래그 회전·동일 실험 반복. ⑤ 잔차가 내내 초록(≈0)인지.

## 쉽게 풀어 쓴 설명

이번엔 실험실에 네 가지가 늘었다. (1) 상자를 3차원으로 바꿔 돌려볼 수 있다. (2) 온도 조절기(항온조)가 생겨 세계를 원하는 온도로 데우거나 식히고, 온도·압력 그래프로 확인한다. (3) 우라늄을 놓고 중성자를 쏘면 원자가 두 조각(바륨·크립톤)과 중성자 2개로 쪼개지며 큰 에너지를 뿜는다 — 새 중성자가 다른 우라늄을 또 쪼개면 연쇄 반응, 즉 폭발이 된다. 에너지는 공짜가 아니다: 우라늄을 소환할 때 미리 "핵에너지 통"에 넣어 둔 것을 분열이 꺼내 쓰는 것이고, 장부는 여전히 0 으로 닫힌다. (4) 화면을 바둑판(복셀)으로 나눠 각 칸의 온도를 색으로 칠한다 — 뜨거운 곳은 빨갛고 차가운 곳은 파랗다. 가열·폭발이 이제 눈에 보인다.

## 발견

- **분열은 카탈로그 행 형식이되 실행 시점이 다르다**: 원자를 만들고 없애는 전이는 엔진의 접촉 페어 루프(인덱스 기반) 안에서 실행하면 무효 인덱스를 만든다. 행 형식(match·hazard·apply)은 유지하고 실행만 tick 후단으로 — "형식 동형·실행 분리"가 개체 수를 바꾸는 전이의 일반 패턴 (S1+ 승격·강등 이벤트도 같은 자리).
- **저장 에너지 통 패턴**: 소환 시 Q 를 미리 통에 넣고 전이가 실측 ΔE 만큼 꺼내는 구조는, 회계를 정확히 닫으면서 "잠재 에너지를 품은 개체"를 표현하는 최소 배관이다 — ㉓ 질량 결손 장부의 축약판.
- **열지도 = 측정의 시각화**: 복셀 장은 물리에 아무 영향이 없다(측정 전용). 그런데도 가열·연쇄·냉각의 서사가 즉시 읽힌다 — "보이지 않는 창발은 닫을 수 없다"의 역방향 교훈: 보이면 실험이 된다.

## 한계 (격차 등록 → STATE §3)

- **핵분열 = 인월드 축약**: 단면 밴드(fast/thermal)·감속·지연 중성자·k_eff 스캔은 ㉕ reactorSim 몫 — 여기선 단일 단면·즉발만. 파편은 실원소 Ba/Kr 로 표기(가상 핵종 아님)·붕괴(㉔) 미연결(낙진 없음).
- **중성자 수명 소멸 = 처분 회계**: τ 후 escaped/E_escape 로 처리 — 물리(β 붕괴)가 아니라 게임 처분. 문서화된 관찰 도구.
- **항온조 중성자 제외**: 빠른 중성자를 열욕이 감속시키지 않게 제외 — 감속재 물리는 ㉕ 몫.
- **3D 조준 = 상자 중심 카메라면**: 마우스 역투영이 중심 평면에 고정 — 임의 깊이 조준 아님.
- **복셀 장 = 온도만**: 밀도·압력·조성 장은 후속. 3D 슬랩 렌더는 겹침 많으면 탁함.
