# step-0001 — S0-① 무대·장부 (입자가 있고 움직인다)

> 앵커: 입자가 있고 움직인다 · 전제: 없음 · 설계 권위: [../stages/S0-atom/design/01-stage-ledger.md](../stages/S0-atom/design/01-stage-ledger.md)
> 상태: **닫힘** · 코드: `stages/S0-atom/{engine,scenes,measure,verify}.js` + `index.html`

## 무엇을 했나

S0 원자 단계의 **뼈대**를 세웠다 — 이후 모든 세부 단계(②~㉖)가 이 위에 서고, *바뀌지 않고 채워지기만* 한다.

- **자료형 (engine.js)**: `Vec3`(처음부터 3성분 — 2D 전용 경로 없음) · `atom{id,sp,r,p,F,disp,occ:null,mu:null}` · `world{t,dt,box,frozenZ,atoms,electrons,photons,bonds,escaped,queue,ledger,computeForces}`. electrons/photons/bonds 는 빈 배열 — 구조는 지금부터 존재.
- **통 분리 장부 (10통, 0 이어도 전부 존재)**: `K_tr · U_elec · U_int · U_bond · U_vib · U_rot · U_pol · E_photon · E_nuclear · E_escape` + `P_escape`. 장부 항등식 `E_total = Σ(전 통)` 이 시간 상수. ①은 힘 0 이라 `K_tr` 만 채워지고 정확 보존.
- **tick 파이프라인 (자리를 전부 판다)**: `사건 큐 소진 → 힘(computeForces) → velocity Verlet → 경계 → 접촉 전이 샘플 → 장부·측정`. ①은 힘 0(`zeroForces`)·전이 0(빈 큐·no-op 접촉). 사건 큐는 이진 힙 + `ver` lazy 무효화 자료구조만.
- **경계 3종**: periodic(최소 이미지 랩) · reflect(위치 반전 + p 성분 뒤집기) · open(탈출 원자의 E→`E_escape`, p→`P_escape`, 원자는 `escaped[]` 로 이동해 Σc 회계 유지).
- **z 동결**: 장면 속성(`frozenZ`) — 엔진에 2D 분기 없음. 매 tick `|z|,|p_z| ≤ 1e-12` assert 로 수치 오염 즉시 검출.
- **측정 (measure.js)**: T(자유도는 frozenZ 반영) · MSD(누적 참 변위) · 총 운동량(활성+P_escape) · 조성 시그니처 · 장부 통 표.
- **장면 (scenes.js)**: `s01-ideal-gas`(주기·z동결·맥스웰 초기 p·무게중심 표류 제거) · `s01-open-box`(열린 경계).
- **검증 하네스 (verify.js)**: `runScene`·`stat(R,fn)`·`assertExact`·`assertWindow` + 불변식 스위트 — **이후 모든 단계가 재사용**.

## 뷰어 눈 확인 (`index.html` — 브라우저로 열기)

- 64개 원자가 원으로 그려지고 **격자에서 흩어져 움직인다**(속도에 따라 색이 밝아짐). t·T·N 실시간 표시.
- **장부 패널**: 10개 통 표 — `K_tr` 만 값, 나머지 9통은 정확히 `0.000000`. 맨 아래 `Σ total` 과 **잔차 `|Σ−Σ₀|` = `0.00e+0`(초록)** — 장부가 시간 내내 닫혀 있음을 눈으로 확인.
- 장면을 `s01-open-box` 로 바꾸면 원자가 상자 밖으로 날아가 사라지고(활성 N 감소) 좌하단에 "탈출 n" 표시 — 그래도 잔차는 0(E→E_escape 회계).
- 배속 슬라이더는 tick 수만 바꾼다(물리 불변) — T·잔차 변화 없음.

## 쉽게 풀어 쓴 설명

이번 조각은 "게임의 첫 화면"에 해당한다. 아직 아무 힘도, 아무 반응도 없다. 그냥 **알갱이 64개가 상자 안을 등속으로 날아다닌다.** 왜 이걸 먼저 하냐면, 앞으로 모든 물리(힘·결합·반응·핵)를 **얹을 판**을 먼저 완벽하게 깔아야 하기 때문이다.

그 판의 핵심은 두 가지다.

1. **장부(회계 장부)**: 에너지를 종류별로 10개의 "통"에 나눠 담는다 — 지금은 운동에너지(`K_tr`) 통만 차 있고 나머지(전기·결합·진동·복사·핵…)는 텅 비어 0이다. 중요한 건 **모든 통의 합이 시간이 지나도 절대 안 변하는 것**(에너지 보존). 화면의 "잔차 0.00e+0"이 그 증거다. 앞으로 힘·반응을 더할 때마다, 에너지가 한 통에서 다른 통으로 *옮겨갈 뿐* 새로 생기거나 사라지지 않는지를 이 장부가 감시한다.
2. **속임수 금지 장치(검증)**: `node verify.js` 를 돌리면 16개 검사가 자동으로 돈다. "시간 간격(dt)을 절반으로 줄여도 결과가 같은가?"(그래야 진짜 물리지 프로그램 버그가 아니다), "상자 벽에 부딪혀 튕겨도 에너지가 보존되나?", "벽이 열려 있어 알갱이가 밖으로 나가면 그 에너지를 제대로 따로 기록하나?" 같은 것들. 전부 통과했다.

한 마디로: **아직 아무 일도 안 일어나지만, 앞으로 일어날 모든 일을 정확히 셈할 수 있는 저울과 자를 먼저 만들었다.**
