# step-0020 — S0-⑳ 이온화 기체 (플라스마)

> 앵커: 뜨거운 기체의 이온화 곡선 x(T) · 전제 ⑤(자유전자·이온화 회계)⑨(상태 수)⑬(3D) · design/20 · **측정 중심 + 전이 2행**

## 무엇을 했나

`ionized.js` **신설** (self-contained · 엔진 ①–⑲ **diff 0**). 이온화 기체를 **두 접촉 전이의 평형**으로 굴린다 — 곡선은 어디에도 author 하지 않는다.

- **R-ION (충돌 이온화)** `A + M → A⁺ + e⁻ + M`: 이온화 비용 ΔE(=IE 저장 에너지 상승 + 쿨롱 점프)를 **A–M 상대 KE 에서만** 회수한다 (에너지 출처 원칙 · ⑤ `transferElectron` 동형). 전자는 A 근방에 **정지(p=0)** 로 태어나 P 정확 보존. 느린 충돌은 KE 부족 → 되돌림 = **아레니우스 문턱이 창발** (hazard 에 `e^{−IE/T}` 없음).
- **R-REC3 (3체 재결합)** `A⁺ + e⁻ + M → A + M*`: 접촉쌍 (A⁺, M) 이 곧 제3체. 이온이 이웃의 **속박 전자**를 포획(운동량 `A.p += e.p` 로 정확 보존), 방출된 재결합열은 A–M 상대 KE 로 (가열).
- **힘**: ⑲ 와 같은 이유로 **유계** — 고전 점전자는 엔진 `(σ/d)¹²` 하드코어에 catapult 되므로, `forcesPlasma` 가 부드러운 쿨롱 `kc·q/(d+s)` + 소프트코어 반발로 전 상호작용을 유계로 제공. 엔진 `pairForces` 는 안 건드림.
- IE 는 ③ `levels.VIRTUAL` 바닥 준위에서 유도(author 0): V1 IE=1.0 · V0 IE=2.0. 질량 동일 — IE 만 다른 통제 대조군.

`node verify.js` = **142 PASS** (①–⑲ 136 회귀 + ⑳ 6):
- `x(V1) T=[0.15,0.4,0.8,1.4] → [0.268, 0.611, 0.729, 0.825]` **단조↑ · S자** (급증 구간 Δ0.343 > 2× 포화 Δ0.096)
- **IE 서열**: `x(V0,IE=2) [0.000, 0.213, 0.561, 0.806] < x(V1,IE=1)` 전 T (급증 온도 ∝ IE)
- **저온 억제**: x(V0, T=0.15) = 0.000 (IE ≫ T · 상대 KE 가드 = 문턱)
- **사하 밀도 의존**: T=1.2 에서 `x(n)=0.805 → x(n/2)=0.946` (저밀도일수록 이온화 유리 — 재결합이 다체 ∝ n·n_e)
- **Σc·전하 보존**: 원자 수 불변 · `Σq_이온 − n_전자 = 0` 정확
- **장부·P 보존**: max|ΔE|/E = 3.3e-5 < 5e-3 · max|ΔP| = 9.9e-14 ≤ 1e-9 (전자 포함 총 P)

## 발견 (한계 정직)

1. **속박 게이트가 S자의 심장** — 초기 구현은 이온 근방 전자를 무조건 포획했다. 그러면 뜨거운 전자도 똑같이 재결합해 재결합률이 T 와 무관 → x(T) 가 중간값(~0.55)에 **눌러앉아 S자가 안 나왔다**. 물리적으로 재결합은 그 이온에 **국소적으로 속박**(½μ|v_e−v_A|² + U_coul < 0)인 전자만 잡는다. 이 가드를 넣자 고온에서 재결합이 떨어지며 곡선이 제대로 올랐다. author 0 — 에너지 출처 원칙의 역방향 적용일 뿐.
2. **P 측정은 전자 포함 총합이어야** — `measure.momentum` 은 원자만 센다. 이온화가 운동량을 전자 자유도로 옮기므로 원자만 보면 P 위반으로 오검출된다 (max|ΔP| 3.2). `ionized.momentumTotal`(원자+전자+P_escape)로 봐야 참 보존(9.9e-14). 사건별 감사는 엔진 `checkedApply`(`_auditP=true`)가 이미 원자+전자로 본다.
3. **캐논ical 측정 필수 (⑨ 계약 연장)** — 이온화는 흡열이라 미시정준(닫힌 계)에선 이온화가 진행될수록 원자가 식어 T 가 끌려 내려간다 → T 스캔 무효. 곡선·밀도 측정은 `thermostat`(⑩ `thermoReservoir` 동형·뺀 열 E_escape 회계)로 T 를 고정해 얻는다. 뷰어도 매 step 항온조 적용.
4. **집단 플라스마는 예약 (design 경계)** — 디바이 차폐 정량·플라스마 진동수·자기장·2온도 완화·재결합 선스펙트럼은 assert 없음. 전하 상관(−⟨qᵢqⱼ⟩ 접촉)은 **기록만** (0.053). ㉑ 이후·㉖ 융합 무대.
5. **전자 질량은 노브** (⑤ 동형·dt 강성 회피 m_e=0.5) · **재결합 선스펙트럼 미구현** — design 검증 ③(준위 선 구조)은 이 단계 2준위-없는 이온화 모델(연속 자유전자만)이라 대상 밖, ㉒/다준위 몫.

## 쉽게 풀어 쓴 설명

기체를 아주 뜨겁게 데우면 원자에서 전자가 튀어나와 **플라스마**(이온 + 자유전자 수프)가 된다. 이것을 새 규칙으로 박지 않았다. 규칙은 딱 둘이다: ① 원자끼리 세게 부딪치면 전자 하나가 튀어나온다(이온화) — 단, **부딪치는 에너지가 이온화 비용보다 커야** 한다(느리면 못 뗀다). ② 이온이 가까이 온 느린 전자를 다시 붙잡는다(재결합) — 단, 그 전자가 **너무 빠르면 못 잡고 스쳐 지나간다**.

이 둘이 밀당하면 온도별로 "얼마나 이온화됐나"(x)가 저절로 정해진다. 온도를 올리면 ①이 쉬워지고 ②는 어려워져서 x 가 확 오르는 **S자 곡선**이 나온다 — 이 곡선을 손으로 그려 넣지 않았는데 나왔다. 또 전자를 떼기 어려운 원자(IE 큰 V0)는 같은 온도에서 덜 이온화된다(급증 온도가 더 높다). 밀도를 절반으로 낮추면 재결합이 "이온+전자+제3자" 셋이 만나야 하는 다체 과정이라 더 드물어져서 이온화가 더 잘 된다(사하).

**뷰어 확인**: `index.html` → `s20-saha-scan` 선택. 원자가 **빨간 글로우 = 이온**, 파란 점 = 자유전자. 뜨거운 설정(T=1.4)에서 빨강·파랑이 32개 중 ~22개까지 나타난다. `s20-recomb-glow` 는 고온 플라스마를 급랭 — 이온·전자가 25→12로 줄며 재결합이 눈에 보인다. (이 환경에선 브라우저 확장이 연결 안 돼 화면 캡처 대신 렌더가 읽는 상태값 + 추가한 draw 경로로 확인.)
