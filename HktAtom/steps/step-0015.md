## 한 일 (현상 1개 = 부분 전하와 분자 극성의 창발)

부분 전하는 author 하지 않는다. 분자(연결 성분)마다 **전기음성도 균등화**(QEq)로 전하가 구조에 맞춰
재분배된다. 극성은 **전하 × 형상(⑭)**에서 창발한다 — 같은 규칙 하나로 O₂ 무극성·BeH₂ 무극성 분자
(극성 결합 상쇄)·H₂O 극성이 갈린다.

- **`polarity.js` 신설**(self-contained·엔진 ①–⑭ **diff 0**·⑭ computeForces 합성 패턴):
  - **QEq 에너지** `E(q) = Σᵢ(χᵢqᵢ + ½ηᵢqᵢ²) + ½ΣᵢⱼJᵢⱼqᵢqⱼ − ΣᵢE_ext·rᵢqᵢ`, s.t. `Σq = Q_분자`.
    분자마다 (n+1)×(n+1) 선형계(라그랑주 승수)를 가우스 소거로 직접 해.
  - `χ = (IE+EA)/2`(Mulliken 전기음성도) — **③ levels 유도(author 0)**. `Jᵢⱼ = k_c/(dᵢⱼ+s)`(분자 내
    실거리 → 구조 의존). J-항은 pairForces 의 분자내 쿨롱과 **동일** → U_elec 에 이미 있음(중복 0);
    새 에너지는 자기항 Σ(χq+½ηq²) 뿐 → **U_pol 통**에 회계.
  - **힘**: q 는 준정적(매 force 균등화 → 포락선 정리로 보존). pairForces 쿨롱이 부분 전하로 −∇(분자
    내·간 쿨롱) 를 이미 준다 → 추가 힘 0. 외부장은 `F_i = q_i·E_ext`(중성 분자 알짜힘 0·토크만 → 배향).
- **`scenes.js`**: `s15-o2`(O–O 동핵)·`s15-beh2`(Be+2H 직선)·`s15-h2o`(O+2H 굽음)·`s15-field`(외부장 속
  H₂O·무작위 배향 시작). ⑭ buildShape 재사용 + `polar` 모드(QEq 합성)·`randOrient`(균일 무작위 회전).
- **`index.html`**: 부분 전하 링(빨강 +·파랑 −·크기 ∝|q|) + 분자 쌍극자 화살표(노랑).

## 쉽게 풀어 쓴 설명 (비전문가용)

**"물은 왜 극성인가"를 규칙 하나로 설명한다.** 물 분자는 한쪽이 (−) 한쪽이 (+)인 **극성** 분자다. 그래서
물이 다른 물질을 잘 녹이고, 전자레인지에서 데워진다. ⑮는 이 부분 전하를 author 하지 않는다 — 대신
**전기음성도 균등화**라는 규칙 하나만 준다: *분자 안에서 전자를 당기는 힘(전기음성도)이 균등해질 때까지
전자가 재분배된다.*

전기음성도는 ③(원자 전자 구조)에서 계산된다(손으로 안 넣음): 산소 > 수소 > 베릴륨. 이 서열 하나에서:
- **O₂** (산소-산소): 둘 다 전기음성도가 같으니 전자를 똑같이 나눠 가짐 → **전하 0·무극성**.
- **H₂O** (물): 산소가 수소보다 전자를 세게 당김 → 산소 (−)·수소 (+). 게다가 분자가 **굽어(⑭)** 있어서
  두 (+)가 한쪽으로 몰림 → 분자 전체가 **극성**.
- **BeH₂**: 수소가 베릴륨보다 세게 당김 → 결합은 극성(H가 −). 그런데 **일직선**이라 양쪽 극성이 정확히
  **상쇄** → 결합은 극성이지만 **분자는 무극성**. (실제 CO₂ 가 이런 경우 — 우리 모델은 이중결합이 없어서
  BeH₂ 로 확인. ⑭와 같은 이유.)

핵심: **극성은 전하와 형상의 곱**이다. 같은 극성 결합이라도 형상(굽음/직선)에 따라 분자가 극성이 되거나
안 된다. 그리고 외부 전기장을 걸면 극성 분자(물)가 장 방향으로 **정렬**한다(⟨cosθ⟩ 0→0.7) — 유전체의 원리.

## 발견·한계 (STATE §3 등록)

- **하드니스는 온사이트 쿨롱이 지배**: 교과서 η=(IE−EA)/2 는 ③ 간이 친화도(EA>IE 과대평가·step-0003
  gap)로 **음수** → QEq 비볼록(전하 발산). 대신 **η_i = k_c/s(온사이트 쿨롱 자기반발·②) + IE(③)**
  사용 — 물리적으로 옳은 양수 하드니스(전하 blob 자기에너지)·손 튜닝 0. 전하 부호·앵커는 χ 서열이
  정하며 그건 ③에서 정확(χ_O>χ_H>χ_Be).
- **CO₂ 직선 상쇄는 BeH₂ 로**: CO₂(C=O 이중결합)는 ⑩ order=1 격차라 우리 단일결합 C 는 굽음 → 직선
  상쇄 앵커는 실제로도 직선인 **BeH₂**(H가 Be보다 전기음성 → 극성 결합·상쇄)로 확인. ⑭와 동일 정합.
- **분자간 전하 이동 없음**: QEq 는 성분(분자) 내 재분배만(Σq=Q 고정). 분자간 전하 이동(이온화)은 ⑤ 몫.
  유전율 정량 없음(배향 질서 정성). 수소 결합은 ⑯(여기선 전하만 준비).
