# step-0012 — S0-⑫ 복사장 (photon 입자) · Part II 시작

> 현실 앵커: **열린 경계 → 냉각 vs 닫힌 공동 → 복사 평형**, 그리고 **유도 방출 → 방향성 빔**.
> 전제: ④(전이 엔진·광자 빈). 설계: [design/12-radiation.md](../stages/S0-atom/design/12-radiation.md) · KERNEL §3.1(이산 전이 카탈로그·hazard 채널별).

## 한 일 (현상 1개 = 복사장의 입자화)

④는 방출된 복사를 **스칼라 빈**(`nPhotons` 개수 + `E_photon` 통)으로 근사했다. 공간·방향 정보가 없어
"광자가 어디서 어디로 가는가"를 못 물었다. ⑫는 그 빈을 **photon 입자**로 교체한다 — 방출·흡수·유도
방출이 실제 광자 궤적에서 일어난다. 이것이 Part II(⑫~㉖ — MaterialModel 충실도 축적)의 첫 조각.

- **photon 입자** (engine.js): `{id, isPhoton, E, r, dir(단위벡터), t0}`. 직진 전파 속도 `c_ph`(노브,
  기본 15 ≈ 10·v_th — **실 c 비율 아님**, "원자보다 충분히 빠르다"는 위계만·무차원 닮음). 질량 0·
  **운동량 회계 생략**(|p|=E/c_ph 는 원자 p 대비 미소·복사압은 범위 밖 — P 검사에서 광자 제외, 한계 정직).
- **전이 행 개정·신설** (KERNEL "새 현상 = 카탈로그 행"):
  - `R-EMI` 개정 — 자발 방출 = **photon 생성**(등방 무작위 dir), 빈 증가 대신 입자 push.
  - `R-ABS` 개정 — 광자–원자 접촉(`photonRc`) + 공명 게이트 `|E_ph − dE| < Γ`(`gammaLine`) → 바닥 원자 들뜸·광자 소멸.
  - `R-STIM` 신설 — **유도 방출**: 들뜬 원자 곁을 공명 광자가 지나면 확률적으로 **같은 dir** 새 광자
    복제(2광자 결맞음의 고전 근사) + 원자 완화. `nu_stim` 노브(0=자발만).
- **경계 (`photonBC`, 원자 경계와 독립)**: open → 탈출(E→E_escape) · reflect → 반사(dir 성분 뒤집기) ·
  periodic → 랩. 원자는 주기 상자에 머물되 광자만 열린/닫힌 경계를 갖는 실용 구현.
- **장부**: `E_photon` 통은 그대로 running 회계 — 광자 생성 `+E`·흡수/탈출 `−E`. bond 없는 field 장면에선
  `E_photon == Σphoton.E` **정확**(입자가 통을 표상). (bond 복사 안정화(⑥/⑩/⑪)도 여전히 `E_photon`
  통에 스칼라로 쌓으므로 **빈 완전 제거 대신 field/bin 두 모드 공존** — additive·회귀 0. design 의 "빈 배열
  제거"는 이 정합으로 대체·아래 격차 참조.)
- **측정** (measure.js): `photonStats`(개수·총E·축 정렬 이방성 alignedFrac) · `photonSpectrum`(에너지 빈 집계).

## 검증 — `node verify.js` = **88 PASS** (①–⑪ 81 회귀 + ⑫ 7)

⑫ 7종 (verify 출력 그대로):

1. **복사 냉각(입자)**: `T 2.56→1.34 · E_escape 33.0` — open 경계로 광자 탈출 → 원자 냉각. (dt=DT_STIFF)
2. **냉각 E 보존(탈출 포함)**: `max|ΔE|/E 2.76e-4 ≤ EPS_E` — 매 tick 총 E(E_escape 포함) 보존.
3. **공동 정상 상태(입자)**: `광자 수 13,19,9,9,12 (min 9>0)` — reflect 경계에 갇혀 재흡수 → 정상 광자 가스.
4. **공동 E 보존**: `rel 8.18e-5 ≤ EPS_E`.
5. **스펙트럼 단색(2준위 한계)**: `점유 빈 1개 [0,0,12,0,…]` — 2준위 → 모든 광자 E=dE·단색(연속 스펙트럼은 다준위 몫).
6. **장부 Σphoton.E 정합**: `max|Σphoton.E − E_photon통| 0.0 < 1e-9` — 입자가 통을 정확히 표상 (1200 tick).
7. **유도 방출 증폭**: `축 정렬 광자 유도 63.0 vs 자발 대조 20.75 → 3.04×` — 씨앗 방향 결맞음 복제(4런 평균).

(①–⑪ 81 은 회귀 0 — bin 경로 보존이라 ④ s04 3장면 포함 전부 불변. checkedApply 사건 회계는 field
방출·흡수·유도 방출 전이도 상시 강제 — 여기 오면 통과.)

**커널 체크 5항**: ① 모듈 독립(S0 폴더만·의존 0) ② 형태 동형(방출·흡수·유도 방출 전부 전이 카탈로그 행·
전역 조율자 0) ③ 닫힌 장부(E_photon==Σphoton.E·냉각/공동 rel ≤ EPS_E·checkedApply 사건 회계) ④ 창발=측정

방출 dE 는 ③ 유도).

## 쉽게 풀어 쓴 설명 (비전문가용)

**"빛도 알갱이다"를 실제로 굴린다.** 전에는 방출된 빛을 "빛 저금통에 몇 개"라는 숫자로만 셌다(④). 방향도
위치도 없었다. 이번엔 빛을 **작은 알갱이(광자)**로 만들어 진짜로 날려 보낸다.

세 장면이 세 현상을 보여준다:

1. **냉각 (s12-open-cooling)** — 상자가 "열려" 있으면 원자가 뱉은 빛 알갱이가 사방으로 날아가 상자를
   빠져나간다. 빛이 에너지를 가지고 나가므로 원자들은 **식는다**(온도 하강). 촛불이 식는 원리.
2. **공동 평형 (s12-cavity)** — 상자가 "거울 벽"이면 빛이 나가지 못하고 튕겨 다니다 다시 원자에 흡수된다.
   방출↔흡수가 균형을 이뤄 빛 알갱이 수가 **일정하게 유지**된다(물질과 빛의 평형). 태양 속·용광로 속 빛.
3. **레이저 빔 (s12-stim)** — 대부분 원자를 미리 들뜬 상태로 만들고(밀도 반전), 씨앗 빛을 **한 방향(+x)**
   으로 쏜다. 씨앗 광자가 들뜬 원자 곁을 지날 때 **똑같은 방향** 광자를 하나 더 낳는다(유도 방출). 이게
   눈덩이처럼 불어나 **한 축으로 정렬된 빔**이 된다. 이게 레이저의 원리다. 유도 방출을 끄면(대조군) 원자들이
   제멋대로(등방) 빛을 뱉어 빔이 안 생긴다 → 방향성은 author 한 게 아니라 규칙에서 **창발**한 것.

한계도 정직히: 우리 원자는 **2준위**뿐이라 모든 광자의 색(에너지)이 똑같다 → 스펙트럼이 **단색**(한 줄).
실제 뜨거운 물체의 연속 스펙트럼(플랑크 곡선·고에너지 꼬리)은 여러 준위나 진동-복사 결합이 있어야 나오며,
그건 다준위·㉒(MaterialModel) 몫으로 남긴다.

## 뷰어에서 보기 (눈 확인)

`index.html` 열기 → 장면 드롭다운:
- **s12-stim**: 노란 광자 점들의 **꼬리가 가로(±x)로 정렬** — HUD 좌상단 "광자 N · 축정렬 ~80%". 유도 방출 빔.
- **s12-cavity**: 들뜬 원자(노란 후광) 다수 + 광자 점들이 상자 안에 갇혀 떠다님(축정렬 ~40% = 등방). 정상 상태.
- **s12-open-cooling**: 광자가 등방으로 방출돼 경계 밖으로 사라짐 → T(우측 패널)가 시간에 따라 하강(냉각).

광자 = 노란 점 + 진행 반대쪽 꼬리. E_photon 통값 = 화면 광자 수(×dE=1).

## 발견·한계 (STATE §3 등록)

- **빔은 결맞음의 창발**: `R-STIM` 은 "방향을 복사하라"만 말한다 — 빔(정렬)은 씨앗 방향이 반복 복제되며
  *나온다*. 유도 방출 N배 vs 자발 대조 1배가 이를 수치로 증명.
- **2준위 → 단색 스펙트럼** (한계): 연속 스펙트럼·플랑크 꼬리는 이 모델의 알려진 경계(고전 광자 가스·자외
  파탄). 다준위/진동-복사 결합 도입 시 — 후속(㉒ 또는 별도).
- **빈 완전 제거 대신 field/bin 공존**: `E_photon` 통은 bond 복사 안정화(⑥/⑩/⑪)의 에너지 sink 로도
  쓰여 wholesale 제거가 ⑥/⑩/⑪ 회귀를 건드린다. 그래서 `radiationMode='field'` 를 additive 로 두고 bin
  경로를 보존(⑩ pairD fallback 과 동형·회귀 0). design/12 의 "빈 배열 제거"는 이 정합으로 갱신.
- **복사압·산란·편광 없음**: 광자 운동량 회계 생략(설계 결정) — 복사압은 범위 밖.
