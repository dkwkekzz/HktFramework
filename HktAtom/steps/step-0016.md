# step-0016 — S0-⑯ 수소 결합 (방향성 약결합)

> 현실 앵커: **물 네트워크** — 분자간 O–H···O 방향성 약결합.
> 전제: ⑧⑭⑮. 설계: [design/16-hydrogen-bond.md](../stages/S0-atom/design/16-hydrogen-bond.md).

## 한 일 (현상 1개 = 물의 수소 결합 네트워크)

design/16 의 **2단 접근**을 그대로 밟았다 — 먼저 창발 가설을 측정하고, 부족하면 정직한 보정 행을 author.

**1차 (측정만·새 물리 0)**: ⑮ 부분 전하(H⁺·O⁻) + ⑭ 형상(굽음)만으로 물 분자 사이 H-결합이
창발하는가? **`hbond.js`** 의 `detect`(검출 라벨·힘 아님: `d(H···A)<r_hb` ∧ `θ(D–H···A)` 고각)로 측정.
→ **발견**: 방향성(θ~140°)·거리(H···O~2.0)는 창발하나 **에너지가 E_hb/D_OH ≈ 2.5e-3** 로 목표
(0.03~0.3)의 **~1/10**. 점전하 근사가 실제 H-결합의 일부만 준다(design 예측 적중).

**2차 (정직 보정 행 R-HB)**: 부족 판정 → 방향 가중 단거리 인력을 **노브로 명시 author**(숨기지 않음·
DESIGN §3.2 의 C6 과 같은 지위):
```
V_hb = −D_hb · w(d) · (û_DH · û_HA)₊ⁿ      (공여체 선형성 — û_DH·û_HA=1 이 직선 D–H···A)
```
- 힘 = −∇V_hb 를 D·H·A 3체에 (`F_H = −F_D − F_A` → **P·L 정확 보존**·뇌터). U_bond 하위 항목(U_hb)로 회계.
- `D_hb=1.0` 은 **E_hb/D_OH ∈ (0.03,0.3)·분자당 배위 ~3.5 로 튜닝**(앵커 재현). 수용체 고립쌍 정합은
  검출 게이트로(힘엔 미포함 — 준정적 단순화).
- 컴포넌트(분자) 라벨로 **분자간 쌍만** H-결합(성분 내는 공유). `forcesHB` = 극성 힘(⑮) 뒤 R-HB 합성.
- 장면: `s16-water-cluster`(저T 밀집 물)·`s16-mixed`(물+Ne 무극성 대조). `index.html` H-결합 = 청록 점선.

## 쉽게 풀어 쓴 설명 (비전문가용)

**"물은 왜 서로 달라붙는가"를 만든다.** 물이 표면장력을 갖고, 0°C에 얼고, 100°C에 끓는 건 물 분자들이
서로 **수소 결합**으로 손을 잡기 때문이다. 한 물 분자의 (+)수소가 옆 물 분자의 (−)산소에 끌린다 —
공유결합보다 훨씬 약하지만(약 1/20), 분산력보다는 강한 "약결합".

이 step 은 정직하게 두 단계로 갔다:
1. **먼저 물어봤다**: ⑮에서 만든 부분 전하(수소 +, 산소 −)만으로 수소 결합이 저절로 생기나? → **방향과
   거리는 맞게 생겼다**(수소가 산소를 향해 일직선으로, 적당한 거리에서). 하지만 **너무 약했다** — 실제의
   1/10 세기. (점전하 모델의 알려진 한계 — 전자구름의 세부를 점 하나로 뭉갰으니.)
2. **부족하니 정직하게 보탰다**: "방향성 약결합 힘"(R-HB)을 **숨기지 않고 노브로 명시**해서 더했다. 세기는
   실측 위계(공유의 3~30%)에 맞췄다. 이건 손 튜닝이 아니라 design 이 미리 예약해 둔 정직한 보정 — "점전하
   로 안 나오는 물리는 억지로 짜내지 말고 명시적으로 author 하라"는 원칙.

그 결과 **물 네트워크가 창발한다**: 저온에서 각 물 분자가 평균 **3~4개**의 수소 결합을 맺어(실제 물과
같은 배위수) 그물을 이룬다. 가열하면 그물이 풀려 결합 수가 준다(얼음이 녹고 물이 끓는 원리). 그리고
**무극성 Ne**를 섞으면 Ne는 수소 결합을 하나도 안 맺는다(선택성 — 기름이 물과 안 섞이는 이유의 씨앗).

## 발견·한계 (STATE §3 등록)

- **점전하만은 H-결합 부족 → R-HB 명시 author** (step-0016): 1차 측정에서 방향성·거리는 창발하나
  에너지 E_hb/D_OH≈2.5e-3 로 목표의 ~1/10. design 이 예약한 대로 방향 가중 R-HB 를 노브로 명시(C6 과
  같은 지위). D_hb 는 E_hb/D_OH∈(0.03,0.3)·배위 ~3.5 로 튜닝. 숨기지 않음 — 근거 기록.
- **수용체 고립쌍 정합은 검출만·힘 미포함**: R-HB 힘은 공여체 선형성(û_DH·û_HA)만·수용체 고립쌍 방향
  가중 g(lp)는 준정적 단순화로 힘에서 뺌(검출 게이트로는 활용 가능). 물 배위 3~4 는 이대로 창발.
- **얼음 결정·밀도 역전(4°C)은 S1**: ⑯은 물 네트워크의 *정성*(배위·방향·온도 응답)까지. 정사면체 얼음
  격자·밀도 이상은 S1 상전이 몫(㉒ MaterialModel 에 방향성 항으로 공급). 양성자 이동은 ⑰.
