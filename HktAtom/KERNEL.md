# KERNEL — 커널 척추 (모든 작업 전 필독)

> 이 문서는 HktAtom 의 **존재론적 척추**다 — *모든 단계에서 반복되는 단 하나의 원리(커널)가 무엇이고, 단계들이 어떻게 독립 모듈로 서로를 잇는가.* 그리고 그 위에서 *어떻게 일하는가*.
> 큰 목표는 [CLAUDE.md](CLAUDE.md), 현재 위치는 [STATE.md](STATE.md).
>
> 핵심 한 줄: **보존 다발을 가진 개체들이 국소로 주고받고, 안정해진 묶음은 다음 단계의 개체로 승격된다.** 각 단계(원자·분자·물질·존재)는 이 원리를 *자체 구현한 완전 독립 모듈*이며, 단계 사이는 오직 **데이터(입력↔출력)** 로만 잇는다.

---

## 1. 단계(stage) — 이 프로젝트의 기본 단위

**단계 = 규모 한 칸 = 커널 인스턴스 하나.** "원자 단계"·"분자 단계"처럼, 하나의 단계는 하나의 커널이 굴러가는 하나의 세계다.

### 단계 5원칙 (전 단계 불변)

1. **모듈 — 자체 완전**: 단계는 `stages/S*/` 폴더 하나로 산다. **어떤 것에도 의존하지 않는다** — 다른 단계의 코드 0 · 공용 라이브러리 0 · 외부 패키지 0 · 빌드 도구 0. 그 폴더만 있으면 브라우저/node 로 완전히 돌아간다.
2. **입력이 분명**: 입력 = `input.json` 하나 (명세된 스키마 — 개체 종 카탈로그 + 상호작용 파라미터 테이블). **입력은 반드시 하위 단계의 출력이다** — 유일한 예외는 S0(사다리의 바닥)로, 실물리를 직접 author 한다.
3. **출력이 분명**: 출력 = `output.json` 하나 (이 단계에서 창발한 *안정 구조 카탈로그* + 그 구조들의 *유효 상호작용 테이블*). 이것이 다음 단계의 `input.json` 이 된다. 출력 산출이 곧 **승격 ⇧** 이다.
4. **출력은 시각화된다**: 단계는 자신의 뷰어(`index.html`)를 품는다. 각 현상과 최종 출력을 *눈으로* 확인할 수 있어야 한다 — 보이지 않는 창발은 닫을 수 없다.
5. **세부 단계 = 현상 1개**: 단계는 세부 단계들로 오른다. 한 세부 단계는 실세계의 현상 하나(현실 앵커)를 구현·재현한다.

> 단계 사이에 코드 화살표는 없다 — 오직 `S(n).output.json → S(n+1).input.json` 데이터 화살표뿐. 이 절연이 각 단계를 아무 때나·아무 세션에서나·독립적으로 만들고 고칠 수 있게 한다.

## 2. 개체 — 단계 안의 자료형

단계 안의 시뮬 단위는 단 하나의 자료형 **entity** 다. `Atom`·`Molecule` 클래스는 없다.

| 기호 | 양 | 무엇을 정하나 |
|---|---|---|
| **c** | 보존 다발 (성분 벡터) | 개체의 *정체*. S0 에선 (Z, e). 승격되면 c′ = Σc (구성원의 합 — 보존이 승격을 자동 정의) |
| **r, p** | 위치·운동량 | **국소성 구조의 압축 인코딩** (§2.1 관계론) — 누가 이웃이고 관계가 얼마나 강한지를 정한다 |
| **u** | 내부 상태 | 개체 안에 접힌 자유도. **스칼라가 아니어도 된다** — 단계가 필요로 하는 구조를 갖는다 (S0: 전자 준위 점유 벡터 — 내부 에너지는 그 측정값). 승격 시 구성원들의 미시 운동·결합·내부 에너지가 여기로 접힌다 = **온도의 탄생** |

### 2.1 공간의 지위 — 관계론 (공간은 그릇이 아니라 관계들의 요약이다)

이 커널의 공식 존재론은 **관계론**(라이프니츠)이다: 공간은 개체들이 담기는 *그릇(절대 무대)* 이 아니라, **개체 사이 상호작용 관계들의 요약**이다. 커널은 공간이 근본이라고 주장하지 않는다.

- 커널이 실제로 요구하는 것은 공간이 아니라 **국소성 구조** 둘뿐이다: ① 누가 누구와 상호작용 가능한가(이웃 관계) ② 그 관계의 강도(가까움).
- **r ∈ R³ 는 그 구조의 가장 압축된 구현이다.** 실세계의 상호작용 관계가 3차원 유클리드 공간에 등거리로 박히고 강도가 그 거리로 감쇠한다는 *경험적 사실*을, V₀ 처럼 바닥 특권으로 author 한다. 그 대가로 병진 대칭 → 운동량 보존 P(뇌터 정리)를 공짜로 얻는다 — 장부의 P 는 이 선택의 보증이다.
- **시각화의 3D 는 상태의 투영(해석)이지 상태의 본질이 아니다.** 시뮬의 실체는 정보(상태) + 갱신 규칙뿐이며, 뷰어가 그것을 공간으로 그린다.
- 단계마다 r 의 굵기가 다르다(S0 원자의 r 과 S2 물질 조각의 r 은 다른 해상도) — 공간이 절대 무대가 아니라 **규모별 국소성 인덱스**라는 관계론의 방증이다.
- **공간 자체의 창발은 이 트랙의 증명 대상이 아니다.** "개체 + 관계 그래프만으로 저차원 국소성이 창발하는가"는 훗날의 평행 가설 트랙으로 예약한다 — 기존 단계를 부수지 않고 열 수 있다(단계 모듈성의 덕).

## 3. 커널 — 모든 단계가 공유하는 것은 코드가 아니라 *형태*다

각 단계는 아래 연산자 세 벌을 **자체 구현**한다. "하나의 커널"의 뜻: 코드 1벌이 아니라 **형태(원리) 1벌** — 단계별 차이는 코드 분기가 아니라 *입력 데이터*에만 있다.

### 3.1 상호작용 I — 두 채널: 연속 힘 + 이산 전이

```
연속: F(i→j) = −∇ V(cᵢ, cⱼ, |rᵢ−rⱼ|)          // V 는 input.json 의 파라미터 테이블이 정한다
이산: 전이 T = { 조건(국소), 상태 변화, ΔE, hazard(속도 법칙), 에너지 분배, 역쌍 }
```

- **반대칭·이동만**: 힘은 반대칭, 전이는 통 사이 이동만 — 보존(§4)을 *강제*한다.
- **모든 이산 현상은 전이 한 형식이다 — 단, 속도 법칙(hazard)은 채널별이다**: 형식은 하나로 통일하되 모든 물리를 한 수식(아레니우스)에 넣지 않는다. hazard ∈ {아레니우스(열활성) · 충돌 단면(직접 충돌) · 복사 수명 · 터널링(Gamow) · 확산 제한 · 삼체 · 측정 유도}. 새 현상은 코드가 아니라 *전이 카탈로그의 행*이다 ([stages/S0-atom/DESIGN.md](stages/S0-atom/DESIGN.md) §3.3).
- **에너지 출처 원칙**: 확률은 전이 *여부*만 정한다 — **에너지는 항상 실제 자유도에서 가져온다** (에너지 분배 필드가 명세). 충돌 들뜸은 상대 운동에너지가 부족하면 불가다. T_국소는 에너지를 생성하는 파라미터가 아니라 *주변 자유도에서 그 에너지를 발견할 확률의 요약*이다.
- **세부 균형의 계층**: 단일 개체의 내부 전이(준위)는 k정/k역 = (g후/g전)·exp(−ΔE/T) 로 충분하다. **다입자 반응**의 평형(병진 상태 수·부피·농도·조합 수)은 비율 공식이 아니라 **미시상태 샘플링**으로 얻는다 — 사건이 실제 운동량·내부 상태에서 샘플되고 역과정이 같은 미시 규칙이면 가역성이 평형을 만든다(S0 방식). ΔG 기반 coarse 전이는 S1+ 의 방식이다(계층 분리). 이 계약 아래 볼츠만·화학 평형·엔트로피의 앙상블 증가 경향이 **창발**한다.
- **두 시계 실행 구조** (시공간 규모 차이의 처리): 빠른 연속(매 tick 적분) · 접촉 이산(접촉쌍 확률 샘플) · 느린 사건 큐(희귀 전이는 지수 대기시간으로 예약 — tick 폴링 금지).
- **국소**: 힘·전이는 컷오프 반경 안 이웃만 본다. 전역 조율자 0.

### 3.2 측정 M — 창발은 author 하지 않는다

- **구조** = 결합 그래프의 연결 성분. "물 분자"·"얼음"은 코드의 종류가 아니라 *측정 결과*다.
- **안정성** = 구조의 수명 τ ≫ 상호작용 시간. 안정한 구조만 출력(승격) 후보.
- **카탈로그** = 측정이 발견한 안정 구조들의 목록 (조성별) — 출력의 뼈대.

### 3.3 승격 ⇧ = 출력 산출 (단계의 완성)

안정 구조 S (구성원 {entityᵢ}) 를 다음 단계의 개체 명세로 접는다:

| 출력 항목 | 결정 방법 | 성격 |
|---|---|---|
| **c′** = Σᵢ cᵢ · **u′** = 내부 에너지 합 | 합산 | **정확** — 장부가 닫힌다 |
| **물질 모델 (MaterialModel)** — 상태 변수·자유에너지/상태방정식·수송 계수·반응 네트워크·상전이·표면/파괴 규칙·**재해석 조건**·유효 범위·**오차 한계** | **굴려서 측정** (쌍 퍼텐셜 테이블은 그 첫 조각일 뿐 — 방향성·밀도 의존·협동 효과를 잃는다) | **오차 제한된 근사** — 손 튜닝 금지 · 무엇을 보존하고 무엇을 버리는지가 계약 |

**강등 ⇩(재해석)** 은 역방향: 상위 개체를 u′ 와 일관된 미시 배치로 통계 복원한다. c·E·P 는 정확히, 미시 배치는 분포로만 — 이 비대칭이 곧 *엔트로피*다 (비가역 ≠ 비보존). 승격의 검증은 "모든 통계 동일"이 아니라 **관측량 계약**이다: 보존할 관측량 목록을 선언하고 관측량마다 |O_상위 − O_하위| < ε_O 를 통과시킨다.

> **커널 가설 (이 트랙의 증명 대상)**: "상위 단계의 상호작용을 하위 단계의 측정만으로 결정해도, 상위 시뮬이 미시를 그대로 굴린 것과 *통계적으로 닮는다*." 참이면 사다리가 닫히고 거시까지 오른다. 거짓이면 무엇이 부족한지 측정이 명령한다 — 손 튜닝으로 때우지 않는다.

## 4. 무엇이 보존되는가 — 닫힌 장부 (승격을 관통한다)

| 보존량 | 정의 | 비고 |
|---|---|---|
| **성분 Σc** | 전 개체 합 (S0: 총 Z·총 e) | 교환은 이동만. 승격/강등에서도 합산이라 정확 보존 |
| **운동량 P** | Σp | 반대칭 힘이 보장 |
| **에너지 E** | Σ(운동 p²/2m + 퍼텐셜 + u) | 통 사이 이동만. 승격 시 미시 에너지 → u′ 로 이동하여 닫힘 |

> *비가역 ≠ 비보존*: 승격은 정보(미시 배치)를 잃지만 장부는 잃지 않는다.

## 5. 단계 지도 — 입력·출력·세부 단계 (이 절이 로드맵 SSOT)

> 각 세부 단계 = 실세계 현상 1개(**현실 앵커**)의 구현. 앵커는 author 하지 않는다 — 검증의 목표 수치일 뿐. 앵커가 안 나오면 그것이 발견이다. 세부 단계의 실제 번호·쪼개기의 권위는 STATE §2.

### S0 — 원자 단계 (바닥: 실물리 author 의 유일한 특권) — 상세 설계: [stages/S0-atom/DESIGN.md](stages/S0-atom/DESIGN.md)

- **입력**: 없음 (장면 명세 — Z 조성·개수·에너지 예산 — 만 받는다). V₀ 는 실물리에서 직접 author.
- **V₀ 의 재료 (결정 — 바닥 author 의 전부)**: ① **껍질 채움 규칙** — Z → 전자 껍질(용량 2·8·8·18)을 채워 *외각 전자 수 = 결합 슬롯* 을 얻는 순수 함수 (파울리의 근사). **주기율표는 표로 박지 않는다** — 같은 족 = 같은 외각 수가 이 함수에서 *나와서* 닮는다 ② **쿨롱** — 전하 q = Z − e ③ **단거리 척력** — 겹침 방지 ④ **슬롯 공유/이전 문턱** — 공유·이온결합의 근원. (한계 정직: 목표는 주기율표의 *뼈대* — 전이금속 d-오비탈 등 세부는 필요 시 정련.)
- **핵은 동결 (결정)**: c = (Z, e) — N(중성자)·핵력은 범위 밖. 핵력은 *전하로 표현되지 않는* 별도의 단거리 채널이다(쿨롱은 오히려 양성자끼리 밀어 핵을 찢는 쪽). 화학→거시 사다리에는 핵 내부가 필요 없다. 필요해지면: ① c 에 N 추가 + 유카와형 인력 + N/Z 안정성 문턱, 또는 ② 바닥을 핵자 단계로 한 칸 내림. 지금은 안 한다.
- **출력**: 분자 카탈로그 (조성·결합 E·안정성) + 분자 간 유효 퍼텐셜 테이블.

| 세부 단계 | 현상 (현실 앵커) | 닫는 기준 |
|---|---|---|
| ① 무대 | 원자들이 존재하고 움직인다 | Σc 정확 불변 · P·E 잔차 ≤ 1e-9 · 뷰어에서 보인다 |
| ② 힘 | 충돌·산란 | 충돌해도 장부 닫힘 |
| ③ 껍질 | **주기율표 뼈대** | 족 주기성: Li·Na·K 외각=1 · He·Ne·Ar 슬롯=0 · 원자가 H=1·O=2·C=4 |
| ④ 이온결합 | **소금 (NaCl)** | Na+Cl 수프 → 이온쌍/격자 창발 · 결합 E < 0 |
| ⑤ 공유결합 | **H₂ · H₂O · CH₄** | 연결 성분 측정 · 원자가 포화 (H₃ 덩어리 0) |
| ⑥ 온도·발열 | 반응열 | 반응 전후 E 닫힘 · 발열 후 운동에너지 분포 상승 |
| ⑦ 수프 관문 | **화학량론** | 여러 Z 혼합 수프 → 조성비가 실세계 닮음 (2H:1O → H₂O 우세) |
| ⑧ 출력 산출 ⇧ | 반데르발스 | 쌍 굴림 → V′ 테이블에 인력 꼬리가 *나옴* (손 튜닝 0) · output.json 완성 |

### S1 — 분자 단계

- **입력**: S0 의 output.json. **출력**: 상 카탈로그 (온도별 상·밀도) + 물질 조각 유효 파라미터.

| 세부 단계 | 현상 | 닫는 기준 |
|---|---|---|
| ① 무대 | 분자들이 입자로 존재 | 입력 로드 · 장부 닫힘 · 보인다 |
| ② 응집 | **액적 (물방울)** | 인력 꼬리 → 뭉침 창발 |
| ③ 상전이 | **어는점·끓는점** | 확산 계수·배위수의 온도 응답이 불연속 (상 라벨 author 0) |
| ④ 규모 정합 | 미시=거시 | 같은 계를 S0 미시로 굴린 것과 통계 닮음 (보존량은 정확 동일) — 커널 가설의 첫 실증 |
| ⑤ 출력 산출 ⇧ | 응집력·표면장력 | 측정 테이블 + output.json |

### S2 — 물질 단계

- **입력**: S1 의 output.json. **출력**: 거시 구조 카탈로그 (자기 유지 구조의 명세).

| 세부 단계 | 현상 | 닫는 기준 |
|---|---|---|
| ① 무대 | 물질 조각들의 세계 | 장부 · 보인다 |
| ② 중력·에너지 흐름 | 가라앉음·층 분리 | 밀도 성층 측정 |
| ③ 순환 | **대류 세포** | 에너지 흐름 속 순환 구조 창발 |
| ④ 자기 유지 | **거시 존재의 씨앗** | 에너지를 흡수·소산하며 형태를 유지하는 구조 — 수명 ≫ τ · 항상성 지표 |
| ⑤ 출력 산출 ⇧ | — | output.json |

### S3 — 존재 단계 (열림)

- **입력**: S2 의 output.json. 존재들의 상호작용 — 생태·사회의 씨앗. S2 가 닫힐 때 구체화한다.

> **S1-④ 규모 정합이 관문이다**: 통과 = "현실처럼 창발하는" 기계의 실증. 이후 단계는 같은 파이프라인(굴림→측정→출력)의 반복이다 — 이것이 "규칙은 모두 같은 원리"의 뜻.
>
> **최종 제품은 승격·해동 시스템이다 (MMORPG 연결)**: 오픈월드의 대부분은 거시 상태로 살고, 사건(절단·연소·용해·충격)이 날 때만 국소적으로 하위 해상도로 내려갔다가 안정되면 재승격된다 — CLAUDE.md "세계와 엔진의 관계". 사슬: 원자 → 물질 → 지형·유체 → 생명 → 생태 → 문명·경제 → 플레이어 → 서버 권위. **승격 계약의 권위는 [CONTRACT.md](CONTRACT.md)** — MaterialModel 스키마·관측량 계약·재해석 조건·런타임 소비 계약이 거기 산다.

## 6. 매 세부 단계가 통과할 커널 체크 5항

1. **모듈 독립** — 단계 폴더가 자체 완전한가? (타 단계 코드·외부 의존 0)
2. **형태 동형** — 커널 서명 ⟨I 국소 교환 · M 측정 · ⇧ 출력⟩ 을 지켰는가? (전역 조율자 0 · 단계 특수 연산자 0)
3. **닫힌 장부** — Σc·P·E 가 보존되는가? *승격/강등을 포함해서.*
4. **창발 = 측정** — 분자·상·존재를 author 하지 않고 측정했는가? (`if (isWater)` 분기 0)
5. **입력 = 하위 출력** — 상호작용 파라미터가 하위 단계의 측정 산출물인가? (손 튜닝 0 — S0 만 예외)

하나라도 "아니오"면 그 세부 단계는 척추에서 벗어난 것 — 재설계한다.

## 7. 검증 4기둥 (매 세부 단계 통과해야 닫을 수 있다)

단계 폴더 안의 자체 검증(`verify.js` 등)이 수치로 증명한다. 문서의 모든 수치는 그 출력 그대로.

1. **자체 완전 실행** — 단계 폴더만으로 돌아간다 (의존 0 · 빌드 0).
2. **닫힌 장부** — Σc 정확 불변 · P·E 잔차 ≤ 임계. 승격/강등 세부 단계는 전이 전후 장부 비교 필수.
3. **현상 재현** — 이 세부 단계의 현실 앵커가 ① 수치 assert (반복 런의 통계 — 평균·허용 오차) ② **뷰어의 눈 확인** 둘 다로 확인된다.
4. **입출력 계약** — input/output.json 이 스키마를 지키고, 출력 테이블은 측정 산출물이다. (S1-④ 이후) 규모 정합: 상위 굴림이 하위 굴림과 통계적으로 닮음.

> **결정론은 요구하지 않는다** (결정): 재현성 검증(같은 시드→같은 해시·골든 회귀)은 폐기했다. 검증은 *분포*로 한다 — 현상 assert 는 반복 런의 통계 지표에 허용 오차를 둔다. `Math.random` 사용 가능. 보존(기둥 2)은 통계가 아니라 회계이므로 여전히 정확하게 닫는다.
