# KERNEL — 커널 척추 (모든 step 작업 전 필독)

> 이 문서는 HktAtom 의 **존재론적 척추**다 — *모든 규모에서 반복되는 단 하나의 원리(커널)가 무엇이고, 규모의 사다리가 어떻게 그 위에서 닫히는가.* 그리고 그 위에서 *어떻게 일하는가*(작업 구조·검증).
> 큰 목표는 [CLAUDE.md](CLAUDE.md), 현재 위치는 [STATE.md](STATE.md). **step 루프 1단계(읽기)에서 이 문서를 숙지한 뒤 한 조각을 정한다.**
>
> 핵심 한 줄: **보존 다발을 가진 개체들이 국소로 주고받고, 안정해진 묶음은 다음 규모의 개체로 승격된다.** 규모별 분기 코드 0 — 규모별 차이는 *측정된 파라미터 테이블*에만 산다.

---

## 0. 왜 이 트랙이 따로 있나 — 두 이웃의 교훈

- **HGO atom 의 교훈**: 자료형을 하나로 통일해도(보존 다발), 법칙을 손으로 쌓으면(~26개) author 가 법칙 층으로 옮겨갈 뿐이다.
- **HGO flux 의 교훈**: 법칙까지 하나로 통일해도, *한 격자*에서 모든 척도를 그대로 굴리면 원자→분자까지는 창발해도 **거시 존재까지는 연산량이 막는다**. 셀 10⁶개로 분자 몇 개를 얻는 방식으로는 물질·존재에 도달하지 못한다.

HktAtom 은 세 번째 통일을 시도한다: **규모 전이의 통일.** 미시를 영원히 굴리는 대신, 각 규모 ℓ 을 *그 규모의 개체*로 굴리고, 규모 사이를 **승격(⇧, coarse-grain)** 과 **강등(⇩, refine)** 으로 잇는다. 승격은 임시 최적화가 아니라 **커널의 정식 연산자**다 — 실세계도 그렇게 한다(화학은 쿼크를 다시 풀지 않고, 유체역학은 분자를 다시 풀지 않는다). "같은 원리의 재귀 적용"이 곧 이 프로젝트의 커널 가설이다.

---

## 1. 개체란 무엇인가 — 규모 무관 자료형 (척추 변수)

모든 규모의 시뮬 단위는 단 하나의 자료형 **entity** 다. `Atom`·`Molecule`·`Matter`·`Being` 클래스는 없다 — 전부 이 다발의 값/배치다.

| 기호 | 양 | 무엇을 정하나 |
|---|---|---|
| **c** | 보존 다발 (성분 벡터) | 개체의 *정체*. L0 에선 (Z, e) — 양성자·전자 수. 승격되면 **c′ = Σc** (구성원의 합 — 보존이 승격을 자동 정의) |
| **r, p** | 위치·운동량 | 공간 상호작용의 전제. 국소성의 근거 |
| **u** | 내부 에너지 | **승격이 만드는 양**: 구성원들의 (질량중심 기준) 미시 운동·결합 에너지가 승격 시 u 로 들어간다 = **온도의 탄생**. L0 원자에선 들뜸 에너지 |
| **ℓ** | 규모 태그 | 어느 칸의 개체인가 (L0 원자, L1 분자, L2 물질, …). *분기 조건이 아니라* 파라미터 테이블의 색인 |

> **금지**: `if (ℓ === 1) { 분자 전용 로직 }` 류의 규모 분기. 커널 코드는 1벌이고 모든 ℓ 에서 동일하게 돈다. ℓ 은 오직 "어느 파라미터 테이블을 읽는가"만 정한다.

## 2. 커널 — 한 벌의 연산자 K = ⟨상호작용, 측정, 승격/강등⟩

### 2.1 상호작용 I — 국소 교환 (모든 규모 동일)

개체 i, j (이웃, 거리 컷오프 내) 사이:

```
힘   F(i→j) = −∇ V_ℓ(cᵢ, cⱼ, |rᵢ−rⱼ|)      // 유효 퍼텐셜 — ℓ 의 파라미터 테이블이 정함
교환 X(i→j) : 문턱을 넘으면 c·u 의 일부가 이동/재배치 (결합·해리·전달)
```

- **반대칭** `F(i→j) = −F(j→i)`, 교환은 이동만 — 이것이 보존(§3)을 *강제*한다 (author 한 회계가 아님).
- **문턱**: 결합은 퍼텐셜 우물 깊이 > 상대 운동에너지일 때, 해리는 그 반대. 비선형 문턱이 이산 구조(분자·상·존재)를 만든다.
- **V_ℓ 의 출처**: L0 은 실세계 원자 원리(쿨롱 인력/척력 + 파울리 근사 + 원자가 = 외각 전자)에서 직접. **L1 이상은 손으로 쓰지 않는다** — 하위 규모 시뮬의 측정 산출물(§2.3)만 허용.

### 2.2 측정 M — 창발은 author 하지 않는다 (모든 규모 동일)

- **구조** = 결합 그래프의 연결 성분. "물 분자"·"얼음"·"생명체"는 코드의 종류가 아니라 *측정 결과*다.
- **안정성** = 구조의 수명 τ ≫ 상호작용 시간. 안정한 구조만 승격 후보가 된다.
- **구조 사전** = 측정이 발견한 안정 구조들의 카탈로그 (조성 c′ 별). 렌더·승격이 이것을 읽는다.

### 2.3 승격 ⇧ / 강등 ⇩ — 규모 전이 (이 트랙의 심장)

안정 구조 S (구성원 {entityᵢ}, 규모 ℓ) 를 규모 ℓ+1 의 개체 하나로 접는다:

| 상위 속성 | 결정 방법 | 성격 |
|---|---|---|
| **c′** = Σᵢ cᵢ | 합산 | **정확** (보존이라서) |
| **r′, p′** = 질량중심·총운동량 | 합산 | **정확** |
| **u′** = E_내부 (질량중심 기준 운동 + 결합 + 하위 u) | 합산 | **정확** — 장부가 닫힌다 |
| **V_{ℓ+1}(c′ᵢ, c′ⱼ, d)** | **하위 시뮬 측정**: 구조 두 개를 거리 d 에 놓고 굴려 평균 힘을 잰다 → 테이블 | **닫힘 근사** — 유일하게 근사가 들어가는 곳. 손 튜닝 금지 |

**강등 ⇩** 은 역방향: 상위 개체를 (시드 결정론으로) u′ 와 일관된 미시 배치로 푼다. c·E·P 는 정확히 복원, 미시 배치는 통계적으로만 복원 — 이 비대칭이 곧 *엔트로피*다 (비가역 ≠ 비보존).

> **커널 가설 (이 트랙의 증명 대상)**: "V_{ℓ+1} 을 하위 측정만으로 결정해도, 상위 규모 시뮬이 미시를 그대로 굴린 것과 *통계적으로 닮는다*." 참이면 사다리가 닫히고 거시까지 오를 수 있다. 거짓이면 무엇이 부족한지(다발 성분 추가? 퍼텐셜의 각도 의존?) 를 **측정이 명령**한다 — 손 튜닝으로 때우지 않는다.

## 3. 무엇이 보존되는가 — 닫힌 장부 (승격을 관통한다)

| 보존량 | 정의 | 비고 |
|---|---|---|
| **성분 Σc** | 전 개체 합 (L0: 총 Z·총 e) | 교환은 이동만. **승격/강등에서 비트 단위 보존** (합산이라서) |
| **운동량 P** | Σp | 반대칭 힘이 보장. 승격은 합산이라 정확 |
| **에너지 E** | Σ(운동 p²/2m + 퍼텐셜 + u) | 상호작용은 통 사이 이동만. **승격 시 미시 에너지 → u′ 로 이동**하여 닫힘 |

> **결정적 정합**: 승격은 정보를 잃지만(미시 배치) 장부는 잃지 않는다. *비가역 ≠ 비보존* — HGO 두 트랙과 같은 결정이며, HktAtom 에선 이것이 규모 전이에까지 확장된다.

## 4. 규모의 사다리 — 각 칸은 같은 커널의 인스턴스

| 칸 | 개체 | c 의 내용 | V 의 출처 | 창발 목표 (측정) |
|---|---|---|---|---|
| **L0 원자** | 원자 | (Z, e) — 실세계 원리 | 실물리에서 직접 author (유일한 예외 — 사다리의 바닥) | **분자**: H₂·H₂O 형 연결 성분, 결합 에너지·원자가 포화 |
| **L1 분자** | 분자 (⇧L0) | Σ(Z, e) — 조성 | L0 시뮬 측정 (쌍극자·반데르발스가 *나와야* 함) | **물질·상**: 고체/액체/기체 — 확산 계수·배위수로 측정, 온도 = u 통계 |
| **L2 물질** | 물질 조각 (⇧L1) | 조성 합 | L1 시뮬 측정 (응집·표면장력이 *나와야* 함) | **거시 존재**: 에너지를 흡수·소산하며 자기를 유지하는 구조 — 수명·항상성으로 측정 |
| **L3+** | (열림) | 합산 | 하위 측정 | 존재들의 상호작용 — 생태·사회의 씨앗 |

- **바닥의 특권은 한 번뿐**: L0 의 V 만 실물리에서 author 한다. 그 위의 모든 칸은 측정 산출물이다. "실세계의 원자의 원리를 이용해서 분자로 창발한다. 분자 이후 거시도 마찬가지" — 큰 목표의 이 문장이 곧 이 표다.
- **혼합 규모 공존 (사다리의 완성형)**: 한 세계 안에 L0 영역(관심 지점)과 L2 영역(원경)이 동시에 산다. 경계에서 ⇧/⇩ 왕복 — 장부는 닫힌 채. 이것이 "거시까지 계산 가능"의 실체다.

## 5. 매 step 이 통과할 커널 체크 (검증 5기둥에 더해)

1. **단일 커널** — 새 현상을 규모 분기/새 클래스가 아니라 커널 파라미터·측정에 실었는가? (`if (ℓ===…)` 분기 0)
2. **닫힌 장부** — Σc·P·E 가 보존되는가? *승격/강등을 포함해서.*
3. **국소성** — 전이가 그 개체 + 이웃만으로 판정되는가? (전역 조율자 0)
4. **창발 = 측정** — 분자·상·존재를 author 하지 않고 측정했는가? (`if (isWater)` 분기 0)
5. **측정된 유효성** — 상위 규모 파라미터가 하위 시뮬 측정 산출물인가? (손 튜닝 0 — L0 만 예외)

하나라도 "아니오"면 그 step 은 척추에서 벗어난 것 — 재설계한다.

## 6. 작업 구조 — 공용 하네스 1벌, step 은 두 항만 더한다

HGO 의 검증된 구조를 그대로 계승한다:

- **3축**: [CLAUDE.md](CLAUDE.md)(큰 목표, 거의 불변) · `steps/step-NNNN.md`(한 step = 한 조각) · [STATE.md](STATE.md)(현재 위치의 SSOT, step 마다 §1~4 덮어쓰기 + §5 INDEX 1줄 append).
- **부트스트랩 (Arc A)**: 공용 하네스를 *한 번* 만든다 — `engine/kernel.js`(자료형·이웃·해시) · `engine/interact.js`(상호작용 I — 커널 1벌) · `engine/measure.js`(측정 M) · `engine/promote.js`(⇧/⇩) · `engine/params/`(규모별 파라미터 테이블 — L1+ 는 측정 산출물 JSON) · `engine/scenes.js`(장면 레지스트리) · `engine/verify.js`(헤드리스 검증) · `viewer.html`(단일 뷰어). 이후 step 은 하네스를 건드리지 않는다.
- **한 step 이 더하는 것 = 둘뿐**: ① 장면 1항 (`engine/scenes.js` — init·knobs·watch·assert) ② 측정 1개 *또는* 파라미터 테이블 1항 (승격 측정 step 의 산출물). **step 마다 html·panel·verify 복사 0개.**
- **크기 예산**: STATE ≤ 20KB · step 문서 ≤ 14KB · KERNEL(이 문서) 거의 불변.
- **결정론**: `Math.random` 금지 — 시드 의사난수만. 같은 시드 → 같은 세계 → 같은 해시.

## 7. 로드맵 — 큰 호(arc)의 서사 (이 절이 arc SSOT)

> 방향이지 계약이 아니다 — 매 step 의 권위는 STATE §2. 각 arc 는 커널 가설(§2.3)을 쪼갠 증명 대상이다.

| arc | 목표 | 검증 신호 | 상태 |
|---|---|---|---|
| **A — 커널 기질** | entity 자료형 + 결정론 엔진 + 닫힌 장부 + 공용 하네스 (규모 태그 ℓ 포함하되 아직 L0 만) | Σc·P·E 보존 · 결정론 해시 · 회귀 앵커 | ⚪ 다음 |
| **B — L0 화학** | 실세계 원리 V₀ (쿨롱+척력+원자가) → **분자 창발** | H₂ 형·H₂O 형 연결 성분 측정 · 결합 에너지 < 0 · 원자가 포화 (덩어리 아님) | ⚪ |
| **C — 첫 승격 ⇧₀** | 분자 → L1 개체. **측정 파이프라인** (두 구조를 놓고 굴려 V₁ 테이블 산출) + **규모 정합 검증** 부트스트랩 | 같은 계를 (a) L0 그대로 (b) ⇧ 후 L1 로 굴림 → 보존량 동일 + 통계 지표(온도·밀도) 닮음 | ⚪ **심장** |
| **D — L1 물질** | 측정된 V₁ 로 다수 분자를 굴려 **상(고/액/기) 창발** | 확산 계수·배위수의 온도 응답 (상전이 문턱) — author 한 상 라벨 0 | ⚪ |
| **E — 둘째 승격 + L2 거시** | 물질 ⇧ → 방울·덩어리·흐름. **자기 유지 구조(거시 존재)** 측정 | 에너지 흐름 속 구조의 수명 ≫ τ · 항상성 지표 | ⚪ |
| **F — 혼합 규모 공존** | 한 세계에 L0 ↔ L2 동시. 경계 ⇧/⇩ 왕복 | 왕복 후 장부 잔차 0 · 경계 넘는 개체의 연속성 | ⚪ |

그 너머: 거시 존재들의 상호작용(생태), 렌더 트랙(스냅샷 읽기 전용 — HGO render 계약 계승), MMO 공유 세계. 멀다 — 지금은 Arc A 의 첫 칸.

> **arc C 가 관문이다**: 커널 가설의 첫 실증. C 가 "닮지 않음"으로 판명되면 그것이 곧 발견 — 무엇을 다발에 더해야 하는지 측정이 말해준다. C 를 통과하면 D~F 는 같은 파이프라인의 반복이다 (이것이 "규칙은 모두 같은 원리"의 뜻).

## 8. 검증 5기둥 (매 step 통과해야 닫을 수 있다)

`node engine/verify.js step-NNNN` 가 수치로 증명한다. 문서의 모든 수치는 이 출력 그대로.

1. **회귀 0** — 새 항(노브)을 끄면 직전 step 과 비트 단위 동일. 골든 해시 앵커.
2. **닫힌 장부** — Σc·P·E 보존 잔차 ≤ 임계. **승격/강등 step 은 전이 전후 장부 비교 필수.**
3. **결정론** — 같은 시드 2회 → 상태 해시 일치. `Math.random` 금지.
4. **창발 = 측정** — 장면 assert 가 "이 지표가 이 값" (라벨 author 금지의 수치판).
5. **규모 정합** (arc C 부터) — 미시 굴림 vs 승격 굴림: 보존량 정확히 동일 + 통계 지표 허용 오차 내 닮음. *HktAtom 고유 기둥.*

## 9. 빠른 참조
