# ⑬ z 해동 — 상세 설계 (3D 전환)

> 앵커: 3D · 전제: ① (장면 플래그) · DESIGN §1(차원 결정)·§9.2-⑬ · **구조 변경 0**

## 목적

`frozenZ` 해제만으로 3D 가 켜짐을 증명한다 — 차원이 코드가 아니라 장면의 속성이라는 ①의 설계 결정에 대한 청구서. ⑭ 형상(정사면체)의 전제.

## 더하는 것

- **엔진 변경 0 (선언·규율)**: 이 단계의 커밋은 `scenes.js`(z 초기화·frozenZ:false)·`measure.js`(자유도 회계)·`index.html`(3D 투영) 만 건드린다. engine.js·catalog.js diff 0 을 step 문서에 명기 — 위반 발견 = ①로 회귀하는 재설계 사건.
- 뷰어 3D 투영: 단순 원근 투영 + 마우스 회전 (외부 라이브러리 0 — 자체 행렬 유틸). z 깊이 = 반지름·명도 스케일.
- 자유도 회계 일반화: T·C_v·비리얼의 자유도 인자가 frozenZ 를 읽어 2/3 을 전환 (①⑦에 심어둔 회계의 마무리).

## 장면

- 기존 전 장면: frozenZ 유지 그대로 (회귀 세트 — 건드리지 않는다).
- `s13-gas-3d`: 3D 이상 기체 · `s13-collide-3d`: 3D 산란 · `s13-bond-3d`: V4V1₄ 형성 (3D 위상).

## 검증

1. **평면 회귀**: 닫힌 전 장면 (z 동결) 전부 그대로 통과 — z 오염 assert (①) 포함.
2. **등분배**: ⟨p_z²⟩ = ⟨p_x²⟩ = ⟨p_y²⟩ (R런, 3·se).
3. 3D 스케일: MSD ~ 2·dim·D·t 전환 · 충돌률의 차원 의존 변화 관찰 기록 · 겹침 0 유지.
4. **⑦ 재검 (등록된 회귀)**: C_v 계단이 3D 값 (병진 3/2 → +회전 → +진동) 으로 — V1₂ 선형 분자 회전 자유도 2 (3/2→5/2→7/2).
5. **눈**: 3D 회전 카메라로 기체·분자 확인 (투영은 해석 — KERNEL §2.1).
