# ⑮ 극성 — 상세 설계 (부분 전하)

> 앵커: 물은 극성 (O₂/CO₂/H₂O 3단) · 전제: ⑥⑩ (⑭ 권장) · DESIGN §3.2·§9.2-⑮

## 목적

**전기음성도 균등화**로 부분 전하가 결합 구조·장에 따라 갱신되게 한다. 결합 쌍극자와 분자 쌍극자를 구분 측정 — CO₂ (결합 쌍극자 ≠0, 분자 합 0) 가 시금석.

## 더하는 것

### 부분 전하 (atom.dq) — 전기음성도 균등화 (QEq 간이)

- 분자(연결 성분) 단위 에너지 최소화: `min Σᵢ (χᵢ·qᵢ + ½ηᵢ·qᵢ²) + ½Σᵢⱼ Jᵢⱼ·qᵢqⱼ` s.t. `Σq = Q_분자`.
- `χ = (IE+EA)/2` · `η = (IE−EA)/2` — **③ 측정값에서 유도 (author 0)**. `Jᵢⱼ = k_c/(dᵢⱼ+s)` (분자 내 실거리 — 구조 의존이 여기서 들어온다). 외부 장 항 `−E_ext·rᵢ·qᵢ` 포함 (장 의존 갱신).
- 해법: 성분 크기 ≤ 수십 → 선형계 직접 해 (가우스 소거 — 자체 유틸). 갱신 시점: 결합 변화 즉시 + 주기 간격 (노브) — 매 tick 아님 (비용·안정성).
- q_유효 = (Z − Σocc) + dq — 쿨롱 힘·⑧ E_local·측정에 일관 반영. dq 재분배의 에너지 차 → U_elec 회계 (사건 단위).

### 쌍극자 측정 분리 (measure.js)

- 결합 쌍극자 `μ_b = Σ 결합별 (dq 차)·d` · 분자 쌍극자 `μ_mol = Σᵢ qᵢ·(rᵢ−r_com)` — 둘 다 히스토그램.

## 장면 (실원소)

- `s15-o2` / `s15-co2` / `s15-h2o`: 3단 기준 각각.
- `s15-field`: 균일 외부장 속 H₂O — dq·배향의 장 응답 (갱신의 장 의존 확인).

## 검증

1. **3단 기준** (DESIGN §9.2-⑮): O₂ → dq ≈ 0 (동핵 대칭) · CO₂ → |μ_b| > 0 이고 |μ_mol| ≈ 0 (직선 상쇄 — ⑭ 형상과의 결합 검증) · H₂O → |μ_mol| > 0 (굽음 + χ_O > χ_H).
2. χ·η 가 ③ 유도값 (Mulliken) 그대로 — 원소별 손 튜닝 0 assert.
3. `s15-field`: 장 방향 분자 배향 질서 파라미터 상승 + dq 미세 변화 (유전 응답 정성).
4. 장부: dq 갱신 사건 회계 ≤1e-9 · 총 전하 보존 (분자별 Σq = Q).
5. **눈**: 부분 전하 배지 (크기·색 = dq) · 분자 쌍극자 화살표 (⑧ 유도 쌍극자와 구분 표시).

## 경계

수소 결합은 ⑯ (여기선 전하만 준비). 분자간 전하 이동 없음 (성분 내 재분배만 — 이온화는 ⑤ 행의 몫). 유전율 정량 없음.
