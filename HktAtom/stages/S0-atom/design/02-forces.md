# ② 힘·충돌 — 상세 설계

> 앵커: 산란 · 전제: ① · DESIGN §1(힘 계산)·§3.2

## 목적

연속층의 실제 내용: 쿨롱 + 단거리 척력의 전 쌍 계산. 충돌·산란이 일어나도 장부가 닫히는 것을 증명하고, **Verlet 표류 허용치를 수치로 고정**한다(이후 모든 단계의 E 잔차 기준).

## 더하는 것

### 퍼텐셜과 힘 (V_cont 의 앞 두 항 — DESIGN §3.2)

```
V(d) = k_c·qᵢqⱼ/(d+s) + ε_rep·(σᵢⱼ/d)¹²
F(i←j) = [ k_c·qᵢqⱼ/(d+s)² + 12·ε_rep·σᵢⱼ¹²/d¹³ ] · d̂     // 반대칭 — P 보존은 구조가 보장
```

- `σᵢⱼ = (σᵢ+σⱼ)/2` · `ε_rep,ij = √(εᵢεⱼ)` (Lorentz–Berthelot — 노브).
- softening `s ≈ 0.1σ₀` (노브): 재결합·이온쌍의 d→0 발산 방지. 척력이 먼저 막지만 전자(⑤, σ≈0) 대비.
- q: ①~④ 기간 중성 원자 q=0 → 척력만 실효. 쿨롱 경로는 테스트 전하 장면으로 지금 검증해 둔다(⑤에서 실전).
- **전 쌍 O(N²) + 최소 이미지** — 컷오프 없음 (장거리 쿨롱 왜곡 방지, DESIGN §1). N 예산 ≈ 수백. 병목이 실측되면 G-성능에서 근사.

### Verlet 표류 허용치의 고정

- 대표 장면(고밀도 산란)을 dt 스캔 → `|ΔE|/E ≤ C·dt²` 의 C 를 측정, 기본 dt 에서의 허용치를 `EPS_E` 상수로 고정. **이후 전 단계의 E 잔차 assert 가 이 값을 쓴다.**
- dt 기본값 결정 규칙: 최고 강성(척력 벽) 기준 — 최근접 통과 시 에너지 오차가 EPS_E 안. ⑤의 가벼운 전자 도입 시 재검 항목으로 명시.

## 장면

- `s02-scatter-2`: 2체 산란 — 충돌 파라미터 b 스캔, 편향각 θ(b) 곡선 (정성: 러더퍼드 닮음 — 테스트 전하 ±1 쌍).
- `s02-gas-collide`: N체 중성 기체 고밀도 — 산란 반복, 겹침·장부 감시.
- `s02-charge-pair`: +1/−1 쌍 궤도·산란 — 쿨롱 인력 경로 검증.

## 측정

- 최근접 거리 분포 `min d/σᵢⱼ` · 편향각 θ(b) · 압력 (비리얼 `P·V = N·T + ⟨Σ d·F⟩/dim` — 자유도는 frozenZ 반영).

## 검증

1. **장부 유지**: |ΔE|/E ≤ EPS_E (Verlet 표류만) · |ΔP| ≤ 1e-9 (충돌 중에도).
2. **겹침 0**: 전 tick `min d/σᵢⱼ > 0.7` (순간 침투 여유 포함 — 노브, 위반 0 assert).
3. **θ(b) 단조성**: b 증가 → 편향각 감소 (정성 앵커).
4. **dt 반감**: θ(b)·압력 통계 동일. 순서 셔플 무관(힘 합산은 순서 무관이 자명하지만 스위트에 포함).
5. **눈**: 산란 장면에서 궤적 잔상(트레일) 확인.

## 시각화

궤적 트레일(짧은 잔상) · 전하 배지(± 색) · 패널에 압력·최근접 거리 추가.

## 경계

결합 스프링(⑥)·분극(⑧)·각도 반발(⑭) 없음. 전하는 테스트 장면 외 전부 0. 이웃 리스트·컷오프 없음.
