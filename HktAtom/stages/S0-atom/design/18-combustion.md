# ⑱ 라디칼·연소 — 상세 설계

> 앵커: 불 (점화·전선 전파) · 전제: ⑥⑩ · DESIGN §9.2-⑱ · **원리 0 · 행 여럿**

## 목적

새 원리 없이 카탈로그 행 추가만으로 연쇄 반응 (라디칼 분지) 이 점화·화염 전파를 만드는 것을 증명한다 — "새 현상 = 행" (KERNEL §3.1) 의 극대 시험. ⑩의 H₂+O₂ 준안정이 여기서 불이 된다.

## 더하는 것

### 라디칼 = 측정 라벨 (author 0)

- 라디칼 = 예산 잔여 `Σb_ij < B` 인 결합 참여자 — 새 자료형 없음, 검출기만 (measure.js).

### 카탈로그 행 (H₂/O₂ 계 — 전부 기존 hazard 재사용)

| id | 반응 | hazard | 성격 |
|---|---|---|---|
| `R-INIT` | H₂ + M → 2H· + M | arrhenius (고Eₐ) | 개시 — ⑥ R-DISS 의 파라미터 특례 (별도 행 아님을 우선 검토) |
| `R-PROP-1` | H· + O₂ → OH· + O· | collision + 문턱 | **분지** (라디칼 1→2) |
| `R-PROP-2` | O· + H₂ → OH· + H· | collision + 문턱 | 분지 |
| `R-PROP-3` | OH· + H₂ → H₂O + H· | collision | 전파 + **발열** (ΔE → 생성물 K_tr·내부 모드 — 에너지분배 명세) |
| `R-TERM` | 라디칼 + 라디칼 + M → 안정 | threebody | 종결 (⑥ 안정화 경로 그대로) |

- **설계 규율**: 각 행은 ⑥의 결합 형성/해리 메커니즘 위의 *파라미터 행* — 엔진 코드 변경 0 이 이 단계의 닫는 조건에 포함된다. 반응 엔탈피는 결합 에너지 회계에서 자동 (author 0): ΔE = Σ끊은 D − Σ만든 D.

## 장면

- `s18-rate-scan`: 개별 전파 행의 k(T) 측정 (단일 반응 격리 상자 — 유사 1차 조건).
- `s18-ignition`: H₂+O₂ 혼합 균일 상자, T 스캔 — 점화 문턱.
- `s18-flame-front`: 가늘고 긴 상자 (z 동결 가능 — 2D 전선), 한쪽 국소 가열 → 전선 전파.

## 측정

행별 반응률 → `ln k vs 1/T` 회귀 · 라디칼 농도 궤적 (지수 증식 구간) · 점화 지연 시간 τ_ign(T) · 전선 위치(t) → 전파 속도 · 화염 후방 T.

## 검증

1. **아레니우스 직선**: 전파 행별 `ln k ~ 1/T` 선형 (R², 기울기 ≈ 문턱 E — 측정 정합).
2. **점화 문턱**: T < T_ign 에서 반응 ≈ 0 (⑩ 준안정 회귀 유지) · T > T_ign 에서 폭주 (라디칼 지수 증식 → 분지율 > 종결률 교차가 문턱을 만든다 — 교차 조건 측정으로 확인).
3. **전선 전파**: 전선 속도 정상값 도달 (R런) · 미연소 영역은 준안정 유지 — 전파가 열·라디칼 확산으로만.
4. 장부: 연소 전후 총 E 불변 · K_tr+내부 모드 상승 = 결합 E 감소분 (발열 회계) · Σc 불변.
5. **눈**: 화염 전선 — 발열 글로우 + 라디칼 하이라이트가 전선을 이룬다 (이 트랙 최고의 눈 검증).

## 경계

실제 H₂/O₂ 의 전체 반응 기구 (HO₂·H₂O₂ 경로) 축약 — 분지 골격만 (한계 정직). 대류·부력 없음 (S1+ — 여기 화염은 확산 화염). 폭굉/충격파 없음.

## 구현 정합 (step-0018 — 설계와의 정직한 차이)

1. **추상 한 규칙이 전파·분지를 통합**: 설계의 R-PROP-1/2/3 를 **추상(abstraction) 1행 R-ABSTRACT** 로 합쳤다 — R·(라디칼) + X–Y → R–X + Y· (⑰ 결합 갈아타기의 일반화). ΔE = D(X–Y)·order − D(R–X) 는 ⑩ 쌍별 D 회계(author 0). **분지(라디칼 1→2)는 예산에서 창발** — 공격 라디칼 잔여 ≥2(원자 O)면 R–X 후에도 라디칼 + 떨어진 Y 도 라디칼 → 2개(잔여 1이면 전파 1→1). 개시(H₂ 해리)·종결(라디칼 재결합)은 ⑥ 엔진(R-DISS·R-CPLX+안정화)이 그대로 → 엔진 diff 0(카탈로그 [R-ABSTRACT]+COVALENT).
2. **라디칼 = 측정 라벨(author 0)**: 예산 잔여(bondCount<B)인 원자. `if(isRadical)` 분기 0. 발열 ΔE 는 **K_tr 로 방출**(복사 아님) → 이웃 가열 → 아레니우스 속도 상승 → 연쇄.
3. **O=O 이중결합 대체 (⑩ 단일결합 gap)**: 우리 위상은 단일결합만이라 O₂ 를 단일 O-O(D 0.63·각 O 잔여1=거짓 라디칼)로 두면 무너진다. O₂ 는 실제 이중결합이므로 **order=2·D=이중결합 세기(실 498/463·2.15)** 로 둔다 → O₂ 준안정(고 Ea)·O 라디칼 아님·분지 H·+O₂→OH·+O· 흡열(문턱). 손 튜닝 아님(실 O₂ 결합 에너지).
4. **점화는 열폭발(균일)·느린 층류 전선 아님**: 닫힌 단열 상자는 유한 열확산·열배출(복사·전도)이 없어 스파크가 연쇄를 만들면 상자가 **빠르게 전역 점화**(열폭발)한다. 그래서 s18-flame-front 는 *느린 층류 전선*이 아니라 **스파크의 반응이 연료 속으로 공간 확산**(점화 스윕)을 보인다. 느린 전선·확산 화염은 유한 열배출(S1·설계 "대류·부력 S1+" 와 동류)이 필요. 초기 배치는 겹침 0(분자 간 gap ≥ σ) 필수 — 겹치면 척력이 스퓨리어스 열로 폭주.
5. **H₂O 전환·전선 전파는 정성(한계)**: 전환율 ~40%(2.5/7)·전선 1개 seed 소화(3/4). 크루드 모델의 정직한 한계 — 완전 연소·정량 화염 속도·아레니우스 직선(k(T))·점화 지연 τ_ign 은 S1(열배출·규모)·별도 정련. 사건 감사는 끔(⑥ 복사 안정화 P 미보존 이월)·보존은 원자 수(Σc 정확)·총 E 표류(<5e-2·발열 강성) 로 검증.
