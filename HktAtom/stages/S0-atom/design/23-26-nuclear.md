# ㉓~㉖ 핵 — 상세 설계 (확장팩 · 게이트 G-핵)

> 전제: 상위 단계가 자생 에너지원을 요구할 때만 착수 (DESIGN §9.3 — 엔진의 완결 조건이 아니다). 합본 설계 — 착수 시 단계별로 분리 정련한다.

## 공통 결정

- `c = (Z, e)` → `(Z, N, e)` 확장 (KERNEL §5 S0 핵 동결의 해제 — 1안 채택: c 에 N 추가). 질량 `m = Σ(m_p·Z + m_n·N) − 결합 결손` — m(Z) 테이블 폐기, Σ 회계로 (DESIGN §2).
- 핵 채널도 **같은 전이 형식** — 행 추가일 뿐. `E_nuclear` 통 실사용 시작. 중성미자·감마 탈출 = E_escape.
- 핵력은 author 하지 않는다 — 핵 *내부* 구조는 여전히 동결: 핵종은 상태표 (질량·수명·붕괴 채널 — 바닥 특권 데이터) 로 다룬다. 핵자 동역학이 필요해지면 바닥을 한 칸 내리는 별도 결정 (KERNEL 2안).

## ㉓ 핵종·동위원소 — 앵커: D₂O 진동 분리

- 더하는 것: 종에 N 축 (H/D, 주요 동위원소 데이터 행) · 질량 Σ 회계 전환.
- 검증: **D₂O vs H₂O 진동 주파수 비 ≈ √(μ_H/μ_D)** (⑦ ω 가 질량에서 유도되므로 자동 — author 0 의 증명) · 전 장면 회귀 (N 추가가 화학을 안 건드림) · Σc 3성분 회계.

## ㉔ 붕괴 채널 — 앵커: 지수 감쇠·계열 붕괴

- 행: `R-DECAY-α` (He 핵 방출 — Z−2·N−2) · `R-DECAY-β∓` (N↔Z 전환, 중성미자 E → E_escape) · `R-EC` · `R-γ` (핵 들뜸 완화) · `R-n`. 전부 lifetime 채널 (수명 = 핵종 데이터) — 사건 큐의 최장 시간 규모 시험.
- Q값 회계: 질량 결손 → 방출 입자 KE + γ + E_escape (에너지분배 필드).
- 검증: N(t) 지수 감쇠 (수명 데이터 재현) · 계열 붕괴 (모→딸 축적 곡선) · 장부 (Q값 닫힘) · 눈: 붕괴 섬광·딸핵 색 전환.

## ㉕ 분열 — 앵커: k_eff = 1 경계

- 행: `R-FISSION` (중성자 유도 — 무거운 가상 핵종 F: 흡수 → 분열 파편 2 + 중성자 ν개 + Q) · 파편·중성자는 기존 입자 형식.
- 측정: 중성자 증식률 k_eff (세대별 중성자 수 비) — 밀도·기하 스캔.
- 검증: k_eff < 1 소멸 / ≈ 1 정상 / > 1 폭주의 3영역 존재 · 경계의 밀도 의존 (기하 누설 — 열린 경계) · 장부.

## ㉖ 융합 — 앵커: D–D/D–T (a) · pp 는 별 = S2 연계 (b)

- 행: `R-FUSION` — hazard = **터널링 (Gamow)**: `P ∝ exp(−b_G/√E_rel)` (b_G 는 전하·질량 유도 — hazard 스키마의 마지막 채널 실사용). 전제: ⑳ 이온화 기체 (고온 나핵 충돌).
- 검증: 융합률의 T 의존이 Gamow 창 모양 (급증 곡선) · D–T > D–D 율 (장벽·Q 차이 순서) · Q 회계 (생성물 KE 분배 — 운동량 보존 2체 명세) · 눈: 고온 플라즈마 속 융합 섬광.
- b (pp 연쇄·항성) 는 S2 자기 유지 구조와의 연계 시점에 별도 설계.

## 경계

핵 내부 구조·껍질 모형·공명 단면 정밀도 없음 — 상태표 + 채널 행의 유효 모델 (한계 정직). 임계 사고류 실세계 정합 주장 없음 (무차원 닮음). 착수 전까지 이 문서는 예약 설계로만 존재한다.
