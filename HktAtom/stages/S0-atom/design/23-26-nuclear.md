# ㉓~㉖ 핵 — 상세 설계 (확장팩 · 게이트 G-핵)

> 게이트 G-핵의 개방 조건 둘 ([../../../CONTRACT.md](../../../CONTRACT.md) §6 · DESIGN §9.3 동기): ① 상위 단계가 자생 에너지원(별)을 요구할 때 ② **게임플레이가 핵 사건(폭발·낙진)을 요구할 때** — ② 로 열리면 우선순위는 **㉓ 최소분(c 3성분·질량 회계) → ㉔ 붕괴 → ㉕ 분열**, 융합(㉖)은 별 단계와 함께. 합본 설계 — 착수 시 단계별로 분리 정련한다. **가상 핵종을 쓴다** (실수치 정합 불요 — 임계 조건은 밸런스 자유도, CONTRACT §5).

## 공통 결정

- `c = (Z, e)` → `(Z, N, e)` 확장 (KERNEL §5 S0 핵 동결의 해제 — 1안 채택: c 에 N 추가). 질량은 Σ 회계로 전환: `m = Z·m_p + N·m_n − E_결합핵/c²` — **질량 결손이 장부의 실물**이 된다 (c² 는 무차원 환산 상수 노브). m(Z) 테이블 폐기 (DESIGN §2).
- 핵 채널도 **같은 전이 형식** — 행 추가일 뿐. `E_nuclear` 통 실사용 시작. 중성미자·탈출 γ = E_escape.
- 핵력은 author 하지 않는다 — 핵 *내부* 구조는 여전히 동결: 핵종은 상태표 (질량·수명·붕괴 채널·단면 — 바닥 특권 데이터) 로 다룬다. 핵자 동역학이 필요해지면 바닥을 한 칸 내리는 별도 결정 (KERNEL 2안).
- **㉕의 산출은 S0 안에서 끝나지 않는다 (CONTRACT §5)**: 폭발 왕복의 실행자는 서버(거시)와 **중간 해상도**(몬테카를로 중성자 수송 — CONTRACT §3 해상도 사다리)다. S0 ㉔㉕ 의 책임은 그 중간 모델이 소비할 **파라미터를 측정으로 발효**하는 것 — 손 튜닝 0 은 여기서도 계약이다.

## ㉓ 핵종·동위원소 — 앵커: D₂O 진동 분리

- 더하는 것: 종에 N 축 (H/D, 주요 가상 핵종 데이터 행) · 질량 Σ 회계 전환 (위).
- 검증: **D₂O vs H₂O 진동 주파수 비 ≈ √(μ_H/μ_D)** (⑦ ω 가 질량에서 유도되므로 자동 — author 0 의 증명) · 전 장면 회귀 (N 추가가 화학을 안 건드림) · Σc 3성분 회계.

## ㉔ 붕괴 채널 — 앵커: 지수 감쇠·계열 붕괴 (낙진 감쇠의 근원)

- 행: `R-DECAY-α` (He 핵 방출 — Z−2·N−2) · `R-DECAY-β∓` (N↔Z 전환, 중성미자 E → E_escape) · `R-EC` · `R-γ` (핵 들뜸 완화) · `R-n` (중성자 방출). 전부 lifetime 채널 (수명 = 핵종 데이터) — 사건 큐의 최장 시간 규모 시험.
- Q값 회계: 질량 결손 → 방출 입자 KE + γ + E_escape (에너지분배 필드).
- **런타임 소비 (CONTRACT §5-6)**: 핵종별 {반감기, 채널 분기비, Q} 테이블이 곧 서버 이력 변수의 붕괴 사건 큐 파라미터 — **낙진 지대의 시간 감쇠가 이 테이블에서 창발**한다 (서버는 원자 없이 큐만 굴린다).
- 검증: N(t) 지수 감쇠 (수명 데이터 재현) · 계열 붕괴 (모→딸 축적 곡선) · **붕괴열** (붕괴만 켠 계의 발열 곡선 — 감쇠 곡선의 에너지판) · 장부 (Q값 닫힘) · 눈: 붕괴 섬광·딸핵 색 전환.

## ㉕ 분열 — 앵커: k_eff = 1 경계 (CONTRACT §5 스트레스 테스트의 파라미터 공급원)

### 중성자 입자 (electron 입자 형식 재사용 — 새 자료형 0)

- `neutron = { r, p }`, m_n ≈ m_p. 전하 0 → 쿨롱·전자 채널과 무상호작용, **원자핵과만 접촉 단면**. 자유 중성자는 c=(0,1,0) 으로 Σc 회계에 포함, β⁻ 붕괴 행(㉔ 재사용) 보유.
- 단면의 에너지 의존: σ(E_rel) 를 **2~3 에너지 밴드 계단 테이블**(fast/thermal, 포획은 저에너지 강화 — 1/v 근사)로 — 연속 공명 구조는 범위 밖 (정직 간이화, 핵종 데이터의 일부).

### 카탈로그 행 3종

| id | hazard | 내용 |
|---|---|---|
| `R-N-SCAT` | 충돌단면 | 탄성 산란 — **감속(열중성자화)은 운동학에서 창발** (가벼운 핵일수록 에너지 전달 큼 — author 0) |
| `R-N-CAP` | 충돌단면 (저E 강화) | 포획: 핵종 (Z,N)→(Z,N+1) + γ |
| `R-FISSION` | 충돌단면 | 무거운 가상 핵종 F 흡수 → 파편 2 + 중성자 ν개 (평균 ν 노브 ~2.5, 정수 샘플) + Q |

- 에너지분배: Q → 파편 KE (대부분) + 중성자 KE + γ(E_photon) — 2체 파편 운동량 보존 + 등방 중성자 방출 수식 명세. 파편 질량 분배는 노브 분포 (대칭±편차 — 비대칭 2봉 정밀도는 범위 밖, 정직 명기).
- **파편 = 중성자 과잉 핵종 → ㉔ 붕괴 큐에 자동 진입** (author 0): 지연 중성자(파편의 R-n)·붕괴열·낙진 감쇠가 전부 여기서 창발한다. 지연 중성자는 k_eff≈1 제어 가능성의 근원 — 별도 author 없이 파편 데이터의 귀결.

### k_eff 측정 (두 방법 교차)

- **세대비**: 중성자에 세대 태그 → `k_eff = N(g+1)/N(g)` (초기 과도 제외 창 평균). **시간 지수**: 총 중성자 수 지수 피팅 α. 둘의 정합이 측정 신뢰도.

### 산출 ⇧ — 중간 해상도(중성자 수송)의 파라미터 (CONTRACT §5-3)

```
NuclideTable { 핵종별: σ_scat·σ_cap·σ_fis (에너지 밴드별) · ν · 파편 분포 · Q
               · 지연 중성자 분율(파편 붕괴 데이터에서 유도) · validRange · errorBounds }
```

- 전부 S0 장면에서 **측정으로 발효** (CONTRACT §3 ⇧ 의무 — validRange·errorBounds 없이는 발효 불가). 중간 해상도 모델은 같은 계약 형식·같은 사건 큐 구조라 엔진이 재사용된다.

### 장면

- `s25-moderated`: F + 가벼운 감속재 혼합 — 열중성자 스펙트럼 형성.
- `s25-density-scan` / `s25-leakage`: 밀도·기하(열린 경계 크기) 스캔 — 임계 곡선.
- `s25-chain-burst`: 초임계 순간 조립 — 미니 폭발: 에너지 방출 궤적·장부 (CONTRACT §5-4 "위력은 회계"의 축소판).

### 검증

1. **감속 창발**: 산란만으로 중성자 스펙트럼이 열 분포로 이완 (무감속 대조군은 fast 유지).
2. **3영역**: k_eff <1 소멸 / ≈1 정상 / >1 지수 증가 — 밀도·크기 스캔에서 경계 존재, 누설(작은 계)이 임계 밀도를 올림.
3. **지연 중성자**: 파편 붕괴 on/off 대조 — on 에서 임계 근방 응답이 느려짐 (제어 가능성 관찰 기록).
4. 장부: Δm·c² 회계 — 분열 전후 Σm 감소분 = 방출 E (사건 단위 ≤1e-9) · Σc(Z,N,e) 불변 · 붕괴열 연속.
5. **미니 왕복 (커널 가설의 핵 버전)**: NuclideTable 로 굴린 간이 수송(입자 수송만, 화학 없음) vs S0 전해상도 연쇄 — 관측량 (총 방출 E·세대 곡선·k_eff) ε 내 일치. CONTRACT §5 의 전체 왕복(파괴 반경·오염 감쇠)은 서버+중간 해상도 몫 — S0 는 파라미터 오차 한계까지 책임.
6. **눈**: 중성자 트레일 + 분열 섬광 캐스케이드 + 세대 곡선 패널.

## ㉖ 융합 — 앵커: D–D/D–T (a) · pp 는 별 = S2 연계 (b)

- 행: `R-FUSION` — hazard = **터널링 (Gamow)**: `P ∝ exp(−b_G/√E_rel)` (b_G 는 전하·질량 유도 — hazard 스키마의 마지막 채널 실사용). 전제: ⑳ 이온화 기체 (고온 나핵 충돌). 생성 중성자는 ㉕의 중성자 인프라 재사용 (D+D→³He+n 분기).
- 검증: 융합률의 T 의존이 Gamow 창 모양 (급증 곡선) · D–T > D–D 율 (장벽·Q 차이 순서) · Q 회계 (생성물 KE 분배 — 운동량 보존 2체 명세) · 눈: 고온 플라즈마 속 융합 섬광.
- b (pp 연쇄·항성) 는 S2 자기 유지 구조와의 연계 시점에 별도 설계.

## 경계

핵 내부 구조·껍질 모형·공명 단면 정밀도 없음 — 상태표 + 채널 행의 유효 모델 (한계 정직). 임계 사고류 실세계 정합 주장 없음 (무차원 닮음 — **밸런스는 물리가 아니라 세계 배치가 조절**, CONTRACT §5). 폭발의 파괴·기화 전파와 낙진 지대 운용은 MaterialModel(㉒)·서버 몫 — S0 는 파라미터와 판정만. 착수 전까지 이 문서는 예약 설계로만 존재한다.
