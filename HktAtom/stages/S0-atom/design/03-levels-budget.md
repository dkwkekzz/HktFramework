# ③ 준위·예산 — 상세 설계 (levels.js)

> 앵커: 주기율표 (실원소 순수 함수) + 가상 원소 확정 · 전제: 없음 (순수 함수 — ①② 와 독립) · DESIGN §3.1

## 목적

전자 구조의 전부를 **순수 함수**로: Z → 부껍질 점유 → 준위 에너지 → 이온화 E·전자친화도 → **연속 결합차수 예산 B**. 실원소로 즉시 단위검증(주기 경향)하고, Part I 을 관통할 **가상 원소 3~4종을 확정**한다.

## 더하는 것

### 종(species) 인터페이스 — 실원소·가상 원소 공용

```js
species = { id, m, sigma, eps_rep, levels:[{name, g, eps}], occ0, B, alpha /*⑧*/, color }
```

- **실원소**: `fromZ(Z)` 가 아래 순수 함수들로 유도. **가상 원소**: levels·B 를 직접 author (바닥 특권) — 인터페이스는 동일하므로 엔진은 구별하지 않는다.

### 순수 함수 명세

```
aufbau  = ['1s','2s','2p','3s','3p','4s','3d','4p', …]  · g = {s:2, p:6, d:10}
fillZ(Z) → occ                       // Aufbau + 파울리 (예외 Cr·Cu 등은 무시 — 한계 정직)
zeff(Z, shell, occ)                  // 단순화 Slater: 동일 그룹 0.35(1s 는 0.30) · (n−1) 0.85 · 안쪽 1.0
eps(shell, Zeff) = −R·(Zeff/n_eff)²  // n_eff = {1:1, 2:2, 3:3, 4:3.7} (Slater n*) · R 은 노브
ionizationE(occ)  = −eps(HOMO)
affinity(occ)     = 빈/부분 부껍질에 전자 1 추가 시 ΔE (zeff 재계산 — 간이)
unpaired(occ)     // 훈트: 부껍질 내 단일 점유 우선 배치 후 홀전자 수
budget(occ) → B   // 연속 예산 (아래)
```

### 결합차수 예산 B 알고리즘 (연속량 — DESIGN §3.1)

1. 기본값 = `unpaired(occ)` (바닥 홀전자 수).
2. **승위 후보**: 같은 n 안에서 s→p (예: C 2s²2p² → 2s¹2p³). 승위 비용 `ΔE_promo = eps(p)−eps(s)`, 이득 = 추가 홀전자 수 × 대표 결합 에너지 `D_typ` (노브). `ΔE_promo < 이득` 이면 승위 채택 — C 가 4가가 되는 경로.
3. 닫힌 껍질이면 B=0. 반환은 연속값 (부분 결합·공명 배분은 ⑥의 에너지 최소화 몫 — B 는 총량 상한).

### 가상 원소 4종 (제안 — 구현이 앵커 assert 로 확정)

| id | 구조 (author) | B | m | 실원소 유사 |
|---|---|---|---|---|
| `V1` | 준위 2개 (바닥 g2·occ1 + 들뜬 준위 1개) | 1 | 1 | H |
| `V0` | 닫힌 껍질 (들뜬 준위 1개 — 스펙트럼용) | 0 | 4 | He/Ne |
| `V2` | 홀전자 2 + 고립쌍 2 (⑭의 고립쌍 반발용) | 2 | 16 | O |
| `V4` | 승위로 4 홀전자 (승위 전 2) | 4 | 12 | C |

준위 간격·질량은 노브 — 목표는 구조 창발이지 실수치가 아니다. V1 이 V2 보다 준위 간격이 크도록(스펙트럼 구분) 배치.

## 검증 (순수 함수 단위 테스트 — 시뮬 불필요)

1. **실원소 예산 assert**: H=1 · C≈4 (승위 채택 확인) · N≈3 · O≈2 · Ne/Ar=0 · Na=1 · Cl=1. **step-0003: 승위 조건을 "빈 p 부껍질도 대상"으로 확장** → Be=2·Mg=2 도 창발(교과서 원자가 1,2,3,4,3,2,1,0 일렬). crude Slater 가 s/p 준위를 구분 못 해 승위 비용 cost≈0 → 이득>0 이면 항상 채택 = 최대 홀전자 승위. 이것이 표준 원자가를 재현하는 근원(정직: 실제 s→p 비용은 0 아님 — eps 가 s/p 구분하면 D_TYP 가 실효).
2. **이온화 E 주기 경향** (Z=1~20 스캔, 순위 관계만): 주기 내 단조 증가 · 희유기체 국소 피크 · 알칼리 국소 골. **~~족 내 감소(Li>Na>K)~~ — step-0003 발견: 간이 Slater 는 이 앵커를 창발시키지 못한다**(측정 = Na>Li>K, Na 최대). 3s 침투/차폐를 crude Slater 가 과소평가한 결과. 위조(차폐 손튜닝)하지 않고 **OPEN GAP 으로 등록** — 침투 보정이 필요한 상위 단계가 나오면 정련한다(⑮ χ 유도 전 재검). 나머지 3경향은 견고히 창발.
3. **점유 검증 훅**: `gᵢe^{−εᵢ/T}` 계산기 (④의 볼츠만 assert 가 사용할 기준 곡선) 단위 테스트.
4. **가상 원소 확정**: 4종의 B·준위가 위 표와 일치 assert (이후 회귀 고정).
5. **눈**: 뷰어 패널에 주기 경향 차트 (Z vs 이온화 E — 순수 함수 플롯) + 가상 원소 카드(준위 다이어그램).

## 경계

d-오비탈 세부(전이금속 예외)·상대론 효과 없음 — 목표는 뼈대 (DESIGN §10). 전기음성도 χ·경도 η 는 ⑮에서 이 함수들(IE·EA)로부터 유도한다 — 여기선 IE·EA 까지만.
