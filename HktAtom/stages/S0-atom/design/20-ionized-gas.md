# ⑳ 이온화 기체 — 상세 설계

> 앵커: 뜨거운 기체의 이온화 곡선 · 전제: ⑤⑫ · DESIGN §9.2-⑳ · **측정만**

## 목적

새 물리 0 — ⑤의 이온화⇌재결합과 ⑫의 복사장이 이미 만드는 고온 상태를 **체계적으로 측정**해 이온화 곡선을 얻는다. 집단 플라즈마 효과는 예약 (관찰·기록만).

## 구현 갱신 (step-0020) — 자체 모듈 `ionized.js` (measure/scenes 만으로 안 됨)

초안은 "measure.js·scenes.js 만" 이었다 (⑤ 이온화⇌재결합을 재사용 가정). 그러나 ⑤의 R-XFER 는
**원자↔원자 전자 이전**(이온결합·마델룽)이지 **자유전자를 낳는 기체 이온화**가 아니다. 그래서 ⑯–⑲ 와
같은 self-contained 패턴으로 `ionized.js` 를 신설했다 (엔진 diff 0): **R-ION**(A+M→A⁺+e⁻+M) +
**R-REC3**(A⁺+e⁻+M→A+M*·**속박 전자만** 포획) + 유계 힘 `forcesPlasma`(⑲ 동형) + 측정
(`ionization`·`thermostat`·`momentumTotal`). 발견: ① R-REC3 무조건 포획 → x(T) 중간값 눌러앉음
→ 국소 속박 게이트가 S자를 만든다. ② 이온화 흡열 → 캐논ical(항온조) 측정 필수(⑨ 연장). ③ P 측정 전자 포함.
검증 ③(재결합 **선**스펙트럼)은 자유전자 연속만 있는 이 모델 밖 → 다준위/㉒ 몫(assert 없음).

## 더하는 것 (원안 — ionized.js 로 실현)

- 이온화 분율 `x(T) = n_ion/(n_ion+n_neutral)` 온도 스캔 (닫힌 계 평형 후).
- 밀도 의존: 같은 T 에서 밀도 2배 스캔 — Saha 정성 (저밀도일수록 이온화 유리 — 재결합이 다체이므로).
- 재결합 방출 스펙트럼 (⑫ 광자 집계 — 연속 + 선 구분).
- (기록만) 전하 밀도 요동의 공간 상관 — 차폐 길이 유사 지표 · 진동 모드 존재 여부 (플라즈마 진동은 앵커 아님).

## 장면

- `s20-saha-scan`: V1 (또는 H) 기체, T 그리드 × 밀도 2점 — 각 점 평형 측정.
- `s20-recomb-glow`: 고온 → 급랭 — 재결합 방출 관찰.

## 검증

1. **이온화 곡선**: x(T) 단조 증가 + 급증 구간 존재 (S자) · IE 큰 종일수록 급증 온도 높음 (V1 vs V0 비교 — 순서 앵커).
2. **밀도 의존**: 저밀도에서 같은 T 의 x 증가 (Saha 정성 — 병진 상태 수 창발, ⑨ 계약의 연장).
3. 재결합 스펙트럼에 준위 선 구조 (④ 스펙트럼과 정합).
4. 닫힌 계 장부 유지 (고온에서도 EPS_E — 전자 dt 재검 (⑤) 포함).
5. **눈**: 온도 올릴수록 자유전자·이온 증가 + 재결합 발광.

## 경계

집단 플라즈마 (디바이 차폐 정량·플라즈마 진동수·자기장) 예약 — 측정 기록만 남기고 assert 없음. 충격파·자기유체 없음. 이 단계는 ㉖ 융합의 무대 준비이기도 하다 (G-핵 게이트 시).
