# ⑭ 형상 — 상세 설계 (결합각)

> 앵커: H₂O 굽음 · CO₂ 직선 · CH₄ 정사면체 · 전제: ⑥⑬ · DESIGN §3.2(각도 척력)·§9.2-⑭ · **목표각 author 금지**

## 목적

같은 원자의 전자쌍 방향들 사이 **공통 반발 하나**로 분자 형상이 창발함을 증명한다 (VSEPR 의 동역학 구현). 분자별 목표각은 author 하지 않는다 — 굽음·직선·정사면체가 전부 한 규칙에서 나와야 한다.

## 더하는 것

### 전자쌍 방향 자료 (atom 확장)

```js
atom.pairs = [ { dir:Vec3(단위), kind:'bond'|'lone', bondRef } ]
```

- **bond 쌍**: dir = 실제 결합 방향 (이웃 위치에서 매 tick 갱신 — 자유 변수 아님). 다중 결합 (b>1.5) 은 방향 1개 (결합 도메인).
- **lone 쌍**: 고립쌍 수 = (외각 전자 − 결합 사용)/2 (③ occ 에서 유도 — author 0). dir 은 **과감쇠 최소화 변수**: 매 tick 각도 에너지의 국소 하강 n_relax 회 (관성 없는 가상 자유도 — 에너지 회계는 아래).

### 공통 각도 반발 (수식형 — 상수 2개만 author)

```
V_ang(원자) = k_ang · Σ_{a<b} w_a·w_b / (1 − cosθ_ab + c0)
w = 1 (bond) | λ_lp (lone, λ_lp > 1 — 고립쌍 배율, 전 원소 공통 노브)
```

- 힘: bond 쌍의 각도 에너지 → 이웃 원자에 접선 방향 힘 (같은 분자 내 반대칭 짝 — P·L 보존). lone 쌍은 힘 없음 (방향만 이완 — 질량 없는 근사, 정직 명기).
- 에너지 회계: V_ang 은 U_bond 통에 귀속 (결합 구조의 에너지). lone 이완의 에너지 변화도 같은 통 — 이완은 하강만 하므로 잉여는 K_tr 로 (사건 회계).

## 장면 (실원소 — ⑩ 파라미터)

- `s14-water`: H₂O 다수 (독립 분자들) — 각 분포.
- `s14-co2`: CO₂ (C=O 이중 결합 2, C 고립쌍 0) — 직선.
- `s14-methane`: CH₄ — 정사면체 (3D 필수 — ⑬ 전제의 이유).
- `s14-virtual`: V2V1₂ (고립쌍 2) 굽음 — 가상 원소로도 같은 규칙 확인.

## 측정

결합각 분포 (분자 종별 히스토그램 — 피크·폭) · 고립쌍 포함 전체 도메인 배치 (사면체성 지표: 방향 벡터 간 각 표준편차).

## 검증

1. **3단 앵커 (하나의 k_ang·λ_lp 로 동시에)**: H₂O 피크 ∈ (95°, 115°) (109.5° 미만 — 고립쌍 압박 확인, λ_lp>1 의 효과) · CO₂ 피크 ∈ (170°, 180°) · CH₄ 피크 ∈ (104°, 115°) + 6개 각 동등성. **분자별 파라미터 분기 0** assert (코드 검사 + 파라미터 표 단일).
2. λ_lp = 1 대조런: H₂O 각이 120°(평면 3도메인 균등) 쪽으로 이동 — 고립쌍 배율의 근원 검증.
3. 장부: V_ang 포함 총합 유지 · L(각운동량) 보존 스팟 체크 (각도 힘의 반대칭 짝 검증).
4. 온도 의존: 가열 시 각 분포 폭 증가 (굽힘 모드의 열적 여기 — 정성).
5. **눈**: 물 굽음·메탄 사면체 3D 뷰 · 고립쌍 방향 유령 화살표 표시.

## 경계

이중 결합의 회전 장벽·시스/트랜스 이성질 없음 (도메인 1개 근사). 초과 원자가(PCl₅ 류) 없음 — 예산 모델 경계 (DESIGN §10). 부분 전하와의 상호작용은 ⑮.
