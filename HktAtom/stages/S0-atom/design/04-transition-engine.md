# ④ 전이 엔진 — 상세 설계 (catalog.js 실행기)

> 앵커: 볼츠만 점유 + 스펙트럼 · 전제: ①②③ · DESIGN §3.3·§4

## 목적

이산층의 뼈대 완성: **전이 카탈로그 한 형식 + 채널별 hazard + 에너지분배 회계 강제**. 첫 행 4종(들뜸·완화·방출·흡수)으로 볼츠만 점유·냉각·공동 평형 3장면을 닫는다. 이후 모든 단계는 이 실행기에 **행을 추가**할 뿐이다.

## 더하는 것

### 카탈로그 행 스키마 (catalog.js — DESIGN §3.3 의 코드 형태)

```js
row = {
  id, name,
  kind: 'contact' | 'lifetime',       // 두 시계 중 어느 쪽에 물리나
  match(world, i, j?) → ctx|null,     // 참여자 패턴 (종·occ 조건) — 국소만 본다
  guard(ctx) → bool,                  // 에너지 문턱·선택조건 (허용 그래프: 복사 채널은 부껍질 문자 차 s↔p 등 Δl=±1 단순화)
  dE(ctx),                            // 상태 에너지 차 (levels.js 로 계산)
  hazard: { model:'collision'|'lifetime'|'arrhenius'|'tunneling'|'diffusion'|'threebody', params },
  apply(world, ctx),                  // Δocc·Δbond·입자 생성/소멸 — 통 사이 이동만
  budget: { from:['K_tr',…], to:['U_int',…] },  // 에너지분배 — 실행기가 회계를 강제
  reverse: id | null,                 // 역쌍 (없으면 이유 명기)
}
```

### 실행기 (engine.js — 두 시계, DESIGN §4.2)

- **접촉 채널** (`contact`): 매 tick 접촉쌍(반경 r_c 내) 나열 → 행별 k 계산 → `p = 1 − e^{−k·dt}` 샘플. r_c 는 노브 (σᵢⱼ 배수).
- **수명 채널** (`lifetime`): 해당 상태가 *생길 때* `t + Exp(τ)` 로 큐 예약. 참여자 상태 변경 시 버전 스탬프로 무효화 (①의 큐 뼈대 실사용). tick 폴링 금지.
- **에너지 출처 강제** (공통 코드 — DESIGN §4.1): 흡열 전이는 `budget.from` 자유도의 실제 에너지 ≥ ΔE 일 때만. 충돌 들뜸은 질량중심계 상대 운동에너지에서 차감 — 차감 후 상대 속도를 COM 불변으로 재조정하는 수식을 실행기 공통 유틸로 (P 보존이 사건 단위로 닫힌다).
- **사건 단위 장부 훅**: 모든 apply 전후 전하·질량·P·E 차 ≤ 1e-9 assert (개발 모드 상시).

### 첫 행 4종

| id | kind | hazard | 내용 · 에너지분배 |
|---|---|---|---|
| `R-COL` | contact | collision (접촉 시계) | 충돌 내부 교환(들뜸⇌완화): K_tr(상대) ↔ U_int |
| `R-EMI` | lifetime | lifetime (τ_rad) | 자발 방출: U_int → E_photon |
| `R-ABS` | contact* | 국소 광자 빈 밀도 ∝ 율 | 흡수: E_photon → U_int |

**설계 이탈 (step-0004): 초안의 R-EXC/R-REL 2행 분리 → `R-COL` 1행 통합.** 분리안(들뜸 hazard ∝ g1·완화 ∝ g0)은 접촉 빈도의 속도 편향 때문에 볼츠만 비율이 계·온도에 따라 0.6~2.3× 로 흔들렸다. **Larsen–Borgnakke 재분배**(충돌 총에너지에서 후보 준위를 g 가중·에너지 가용성으로 뽑고, 상대 KE 를 E_c−ε_k 로 재조정 — COM 불변)로 통합하니 세부 균형이 정확해져 비율이 ~1.0(±10~15%)으로 수렴한다. 들뜸·완화는 이 한 규칙의 두 결과. 잔여 ~10% 편향은 접촉 상관(단순 2준위·2D LB)의 한계 — 정확 평형 보정은 ⑨ 통계 관문 몫(OPEN GAP).

### 광자 빈 (⑫ 전의 임시 복사장 — 마이그레이션 예정)

- `E_photon` 통을 **스펙트럼 빈 배열** `bins[E_k] = 개수` 로 (해상도 ΔE_bin 노브). 방출이 빈을 채우고, 닫힌 상자에선 R-ABS 가 빈에서 재흡수 (공간 균일 근사 — 정직한 한계). 열린 상자는 방출 즉시 E_escape 행선 옵션.
- ⑫ 가 빈을 광자 입자로 교체 — 그때 ④의 3장면 회귀 재현이 마이그레이션 검증이다. **유도 방출은 ⑫로 미룬다** (빈 근사에선 방향 정보가 없다).

## 장면 (볼츠만 검증 3장면 — DESIGN §9.1-④)

- `s04-thermal-bath`: 고밀도·복사 껌(τ_rad→∞) — 충돌 지배 평형.
- `s04-radiative-cooling`: 저밀도·열린 복사 — 방출 우세 냉각.
- `s04-cavity`: 닫힌 상자 + 빈 재흡수 — 공동 평형.

## 측정

점유 분포 n(준위) vs `gᵢe^{−εᵢ/T}` (③의 기준 곡선, KL 거리 또는 χ²) · 스펙트럼 (빈 히스토그램 — 위치=ΔE·세기=점유×율) · T(t) 궤적.

## 검증

1. `s04-thermal-bath`: 점유 → 볼츠만 — **창발 확인** (author 0). **step-0004: n1/n0 이 (g1/g0)e^{−ΔE/T} 의 ~0.9~1.15× (계·온도 3배 범위, 단조 응답)**. LB 규칙 자체는 고립 무작위쌍에서 ~0.95×, 접촉 상관이 ~1.1× 로 만든다. 정밀 KL<ε 는 ⑨ 통계 관문(DSMC-정합 충돌 처리)으로 이월 — 위조 안 함.
2. `s04-radiative-cooling`: T 단조 하강 + E_escape(또는 빈 합) 증가가 K_tr+U_int 감소와 정확히 일치.
3. `s04-cavity`: 빈 분포·점유 정상 상태 도달 (후반 창에서 드리프트 ≤ se).
4. **에너지 부족 전이 불가**: T ≪ ΔE 장면에서 들뜸률 → 볼츠만 꼬리 수준 (지수 억제 확인) · 개별 사건 회계 위반 0.
5. 미시 가역: R-EXC/R-REL 만 켠 계의 평형 점유가 (g후/g전)e^{−ΔE/T} (DESIGN §4.1 단일 개체 규칙).
6. 수치 불변식: dt 반감 → 점유·전이율 통계 동일 · 순서 셔플 · 사건 확률 프레임률 무관.
7. **눈**: 들뜸 글로우 + 방출 플래시(ΔE→색) + 스펙트럼 패널.

## 시각화

들뜸 원자 글로우 · 방출 순간 플래시 색 = ΔE 매핑 · 패널: 점유 vs 볼츠만 겹침 차트 · 스펙트럼 히스토그램.

## 경계

이온화(⑤)·결합(⑥) 행 없음. 광자는 빈 근사 (입자·유도 방출·방향성은 ⑫). 아레니우스 hazard 는 스키마에 있으나 첫 사용은 ⑥ 해리.
