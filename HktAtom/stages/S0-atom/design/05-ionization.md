# ⑤ 이온화·재결합·전자 이전 — 상세 설계

> 앵커: 이온 격자 · 전제: ④ · DESIGN §3.3(채널)·§9.1-⑤

## 목적

자유전자(연속상태 E≥0)를 입자로 도입하고, 오르막(흡열) 전이·미시 가역·**다입자 격자 안정화**를 증명한다. 쿨롱 힘(②)이 처음 실전 가동된다.

## 더하는 것

### electron 입자

- `electron = { id, r, p }`, 질량 `m_e` 노브 (기본 0.01·m₀ — 실제 1/1836 은 dt 강성 문제. 정직한 근사로 명기). σ≈0 → 쿨롱 softening s 가 발산을 막는다 (②).
- **dt 재검 의무**: 가장 빠른 전자 기준으로 EPS_E(②) 유지 확인 — 필요 시 전자 포함 장면의 dt 를 낮춘다 (장면 파라미터).
- 원자 전하 `q = Z − Σocc` — occ 변화가 곧 전하 변화 (별도 전하 변수 없음, Σc=(Z,e) 회계와 일치).

### 카탈로그 행 5종

| id | kind | hazard | 내용 · 에너지분배 |
|---|---|---|---|
| `R-ION-COL` | contact | collision (문턱 = IE) | 원자–원자 충돌 이온화: K_tr → U_int(+전자 KE) — 전자 생성 |
| `R-ION-E` | contact | collision | 전자 충돌 이온화 (전자 KE 가 출처) |
| `R-REC-RAD` | contact | collision + 방출 | 방사 재결합: 전자 포획, 잉여 E → E_photon (안정화 필수 — 2체 직접 포획 금지의 첫 사례) |
| `R-REC-3B` | threebody | 삼체 (제3체가 접촉 반경 내) | 삼체 재결합: 잉여 E → 제3체 K_tr |
| `R-XFER` | contact | collision | 전자 이전: A + B → A⁺ + B⁻, ΔE = IE_A − EA_B − 쿨롱 이득(접촉 거리) — guard 가 계산, 역행 동일 형식 |

- 이온화 문턱 `IE = −ε_HOMO`(③) — **오르막 전이 허용**: guard 는 에너지 출처 존재만 검사, 볼츠만 억제는 hazard·에너지 분포가 만든다 (author 0).
- 생성 전자의 초기 r·p: 모원자 표면 무작위 방향 + 잉여 에너지 분배 수식 명세 (P 보존 사건 단위).

## 장면

- `s05-hot-gas`: V1 기체 고T → 이온화 분율 상승.
- `s05-recombine`: 이온화 상태에서 냉각 → 재결합 (방사/삼체 두 경로 비율 측정).
- `s05-ion-pair`: V1(저IE 역)–V2(고EA 역) 2체 — 고립 쌍에선 이전이 오르막인 것 확인.
- `s05-lattice`: 같은 조성 N≈32~64 수프 저T → 이온쌍/격자 응집.

## 측정

이온화 분율 x(T) · 전하별 개수 · 격자 결합 에너지 (클러스터 U_elec 합 vs 분리 상태) · 연결 성분(쿨롱 근접 기준).

## 검증

1. **오르막 전이 + 미시 가역**: 닫힌 계에서 이온화⇌재결합이 정상 분율에 도달, x(T) 단조 증가 (Saha 정성 — 곡선 모양 앵커는 ⑳).
2. **다입자 격자 안정화**: 고립 이온쌍 생성은 ΔE>0 (오르막) 이지만, 격자 장면의 총 에너지는 중성 기체보다 낮음 — **마델룽 이득의 창발** (author 0). 격자 vs 고립쌍 에너지 비교 assert.
3. 재결합의 안정화 필수: R-REC-RAD·R-REC-3B 둘 다 끄면 재결합률 ≈ 0 (2체 직접 포획이 없음을 확인).
4. 장부: 사건 단위 ≤1e-9 · Σc(총 Z·총 e) 정수 불변 (전자가 원자↔자유를 오가도).
5. **눈**: `s05-lattice` 에서 +/− 교대 배열 형성.

## 시각화

전하 배지(색 링 +빨강/−파랑) · 자유전자 = 작은 점 · 격자 장면 카메라.

## 경계

공유 결합(⑥) 없음 — 이 단계의 응집은 순수 쿨롱. 금속 전자 풀(⑲)·집단 플라즈마(예약) 아님. Saha 곡선 정량 앵커는 ⑳.
