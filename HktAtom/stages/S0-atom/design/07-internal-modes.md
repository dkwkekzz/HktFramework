# ⑦ 내부 모드 — 상세 설계 (진동·회전)

> 앵커: 열용량 계단 · 전제: ⑥ · DESIGN §9.1-⑦

## 목적

결합에 접힌 자유도 U_vib·U_rot 를 도입해 **자유도의 순차 활성화(열용량 계단)** 를 재현한다 — 승격 시 "온도의 탄생"(KERNEL §2 u) 의 첫 축소판.

## 더하는 것

### 모드 표현 (bond.mode)

```js
mode = { nVib:0, EvibQuantum: ħω,  // ω = √(k_b/μ_red), μ_red = mᵢmⱼ/(mᵢ+mⱼ)
         nRot:0, ErotQuantum: B_rot }   // B_rot ≪ ħω (간격 위계가 계단의 근원)
```

- **왜 양자화인가 (설계 결정)**: 열용량 계단은 "간격 ≫ T 면 동결, ≪ T 면 활성"에서 온다 — 고전 연속 모드는 계단을 만들 수 없다. 진동은 등간격 사다리(조화 근사), 회전은 준등간격 근사 (강체 회전자의 2J+1 축퇴는 g 로 반영 — 간이).
- U_vib = Σ nVib·ħω, U_rot = Σ nRot·B_rot — 각 통 실사용 시작.
- ħω·B_rot 는 결합 파라미터에서 유도 (author 는 D·k_b·d1 뿐 — ω 는 측정값과 일치해야: 아래 검증 5).

### 카탈로그 행 4종 (전부 contact·collision — R-EXC/REL 과 같은 형식, 다른 준위 사다리)

`R-VIB-EXC`/`R-VIB-REL` (K_tr↔U_vib) · `R-ROT-EXC`/`R-ROT-REL` (K_tr↔U_rot). 충돌 시 병진↔내부 E 교환 — 문턱·단면 노브. 진동-복사 결합(적외 방출)은 노브로 예비 (기본 off — ⑫ 이후 검토).

### 해리와의 연결 (⑥ 개정)

- R-DISS 의 Eₐ 를 `D·b − nVib·ħω` 로 갱신 — **진동 사다리를 오른 결합이 먼저 끊어진다** (해리의 미시 경로가 정직해짐). ⑥ 장면 회귀 재확인 의무.

## 장면

- `s07-cv-scan`: V1₂ 기체 등적 가열 스캔 (T₁→T₂ 계단식, 각 T 에서 평형 후 E 측정).
- `s07-freeze-out`: 저T 에서 모드 점유 0 확인.

## 측정

- `C_v(T) = dE_total/dT` (T 스캔 유한 차분) · 모드별 점유 분포 vs 볼츠만 (진동 사다리 점유 = e^{−nħω/T} 기하 분포).

### z 동결 자유도 회계 (정직 — ⑬ 전이므로 2D)

| 구간 | 활성 자유도 (V1₂, z 동결) | C_v/N분자 |
|---|---|---|
| T ≪ B_rot | 병진 2 | 1 |
| B_rot ≪ T ≪ ħω | +회전 1 (평면 회전) | 3/2 |
| T ≫ ħω | +진동 2 (운동+퍼텐셜) | 5/2 |

⑬ z 해동 후 3D 값(3/2 → 5/2 → 7/2)으로 **재검하는 회귀 항목을 지금 등록**한다.

## 검증

1. **계단**: C_v(T) 가 위 표의 3구간 평탄값을 순차 통과 (R런, 전이 구간 제외 창 비교).
2. 진동 점유의 기하 분포 assert (단일 개체 세부 균형 — DESIGN §4.1).
3. 장부: U_vib·U_rot 통 정합 · 사건 단위 ≤1e-9.
4. ⑥ 회귀: 해리 Eₐ 갱신 후에도 s06 장면 전부 통과 (해리 온도 이동은 허용 — assert 창 재고정, step 문서에 기록).
5. **ω 정합**: 스프링을 고전 진동시킨 주기 vs ħω 간격 — 같은 결합 상수에서 유도되는지 (내부 일관성).
6. **눈**: 진동 = 결합선 떨림 시각화 · 회전 = 분자 자세 회전 · C_v 곡선 패널.

## 구현 노트 (step-0007)

**계단은 순수 양자 효과 — 고전 점입자 MD 로는 불가**(등분배로 모든 자유도 상시 활성). 그래서 이핵 분자를 **강체 회전자 + 양자화 모드**로 다루는 `modes.js`(self-contained — 핵심 엔진 ①–⑥ 불건드림·회귀 0)로 구현: 병진 COM 2D + 진동 등간격 사다리 Eₙ=n·ħω + 회전 2D 강체 회전자 E_J=B·J²(축퇴 g_J). 모드↔병진 교환은 ④의 LB 재분배. `node verify.js`: C_v **1.00 → 1.71 → 2.80** (목표 1·3/2·5/2 · 순차 언프리즈). 중·고온이 ~10~20% 높은 건 내부 모드 LB 의 편향(④와 같은 계열 — ⑨ 통계 관문 이월). **⑥ 고전 결합과의 결합**(형성된 bond 를 강체 양자 회전자로 rigidify)은 인터페이스로 남김 — ⑦은 계단 앵커를 modes.js 로 닫는다.

## 경계

비조화성(모스 퍼텐셜)·진동-회전 결합·적외 스펙트럼 정량 없음. 다원자 분자의 모드 수 세기(3N−5/6)는 결합별 근사로 대신 — 한계 정직. **⑥ 고전 bond↔⑦ 양자 rigidify 통합은 후속**(modes.js 는 강체 이핵 기체로 계단만 증명).
