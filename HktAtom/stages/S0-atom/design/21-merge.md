# ㉑ 동적 병합 — 상세 설계 (게이트 G-성능)

> 앵커: 성능 — 관측량 계약 |ΔO|<ε_O · 전제: ⑥⑧ + **병목 실측** · DESIGN §4.4 · 계약 형식: [CONTRACT.md](../../../CONTRACT.md) §1~3

## 목적

안정 클러스터를 초개체로 접어 연산량을 줄이되, **병합 = coarse-graining (정보 손실)** 임을 정직하게 인정하고 "모든 통계 동일" 대신 **관측량 계약**으로 검증한다. ⑪ 승격 배관과 같은 원리의 *단계 내부* 적용 — CONTRACT §3 해상도 사다리(거시↔중간↔원자)의 단계 내부 리허설이며, 관측량 계약·깨어남(재해석) 조건의 형식은 CONTRACT §1~3 과 동형이다.

## 착수 조건 (게이트)

- Part I 장면 또는 MVP 확장 장면에서 **병목 실측** (프로파일 수치가 step 문서에 있어야 착수) — 그 전에 이 단계를 당기지 않는다. 전 쌍 O(N²) 한계가 먼저 오면 이웃 해시가 선행 (별도 소단계 — 근사 아님·통계 불변 검증).

## 더하는 것

### 초개체 (superEntity — entity 와 같은 인터페이스, KERNEL entity 의 재귀)

```js
super = { c:Σc, m:Σm, r:COM, p:Σp, L:각운동량, R_eff:형상 반경,
          u:{ U_int_total, T_int },            // 내부 열역학 유지 (가열·복사 응답)
          surface:[ 활성 부위 (미포화 예산·라디칼·이온 노출) ],  // 표면 반응 유지
          members:압축 스냅샷 }                  // 재해동용 통계 요약 (전체 미시 아님 — 정직)
```

### 병합/해동 규칙

- **병합 조건**: 연결 성분이 τ_stable 이상 유지 ∧ 내부 T 정의 가능 (내부 KE 분포 정상성) ∧ 외란 없음 (최근 큰 충돌·전이 없음).
- **깨어남 조건** (DESIGN §4.4): 강한 충돌 (E > 문턱) · T_int 상승 · 응력 (외력 적분) · 전하 유입 · 표면 반응 발생 · 외부장 급변 — 조건별 문턱 노브 표.
- 해동 = ⑪ rethaw 재사용 (u·surface 와 일관된 미시 배치 통계 복원 — c·E·P 정확).
- 초개체끼리/초개체–원자 상호작용: V′ 유사 유효 퍼텐셜 (R_eff 강체 근사 + ⑪ PMF 테이블) — 표면 부위는 접촉 시 국소 해동으로 정식 처리 (근사로 반응시키지 않는다).

### 관측량 계약 (선언 목록 — ε_O 는 측정하며 확정, STATE 격차)

| 관측량 O | 측정 장면 | 비고 |
|---|---|---|
| 열용량 곡선 | 가열 응답 | 내부 열역학 유지 검증 |
| 평균 반응률 (표면) | 반응성 기체 접촉 | surface 부위·국소 해동 검증 |
| 확산 계수·충돌률 | 혼합 기체 | 유효 퍼텐셜 검증 |
| 압력 (비리얼) | 등적 스캔 | EOS 보존 |
| 응집/해체 온도 창 | T 스캔 | 상전이 조짐 보존 |

## 검증

1. **계약 일괄**: 각 관측량 병합 on/off 비교 |ΔO| < ε_O (R런) — 목록·수치를 verify 가 표로 출력.
2. **회계 정확**: 병합/해동 사건 전후 Σc·P·E ≤ 1e-9 (coarse-graining 은 정보만 잃는다 — 비가역 ≠ 비보존).
3. 왕복 반복 안정: 병합↔해동 N회 반복 후 관측량 드리프트 없음 (누적 오차 감시).
4. 깨어남 정합: 각 깨어남 조건 장면 (충돌·가열·반응 기체) 에서 해동이 실제 발생하고 이후 물리가 전해상도와 계약 내 일치.
5. **성능**: 병합 장면의 tick 비용 절감 실측 (목표 배수는 병목 실측이 정한다 — step 문서 기록).
6. **눈**: 초개체 = 반투명 외곽 + 내부 T 색 · 해동 순간 전개 애니메이션.

## 경계

결정 방향·결함·조성 구배·잔류 응력은 **복구 불가 손실**로 명기 (DESIGN §4.4) — 이들이 필요한 장면은 병합 금지 조건에 추가. 초개체의 회전 동역학은 강체 근사 (변형 없음).
