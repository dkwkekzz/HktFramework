# ⑨ 통계 관문 — 상세 설계

> 앵커: 평형은 창발한다 · 전제: ④⑥ · DESIGN §4.1(계약)·§9.1-⑨

## 목적

Part I 물리의 통계역학 계약을 일괄 검증하는 **관문**: 엔트로피의 앙상블 증가 경향·K_eq 의 상태 수 의존·T_국소 근사의 한계 확인·수치 불변식 전 장면 일괄. 새 물리 0 — 측정과 검증만 더한다.

## 더하는 것 (measure.js·verify.js 만)

### coarse-grained 엔트로피

- 위상 공간 히스토그램: 공간 셀 (L/n_cell)³ × 속도 빈 → `S = −Σ pᵢ ln pᵢ`. 셀 크기 노브 — **2배 스캔에도 경향이 유지**되는지 함께 확인 (coarse-graining 의존성 정직).
- **앙상블 검증** (DESIGN §4.1 — 단조 증가 아님): R런 평균 S(t) 가 증가 경향 + 개별 런 요동 허용. 초기 저엔트로피 배치(한쪽 구석 몰아넣기)에서 출발.

### K_eq 측정

- 대상 반응: `V1 + V1 ⇌ V1₂` (⑥ 행 그대로). `K_c = [V1₂]/[V1]²` 시간 평균 (평형 후 창).
- **상태 수 의존 검증 2종**: ⓐ 부피 2배 (N 고정) → 해리도 증가 (병진 상태 수 — 르샤틀리에 창발) ⓑ 온도 스캔 → van't Hoff: `ln K vs 1/T` 기울기 ≈ 결합 에너지 D (⑥ 의 author 값과 측정 일치 — 허용 오차 창).

### T_국소 점검 (STATE §3 열린 격차의 확인 지점)

- 평형 장면: T_국소(이웃 k 평균) 분포가 전역 T 를 중심으로 — 편차 통계 기록.
- 비평형 장면: 좌우 온도차 초기화 → T_국소 프로파일이 확산으로 이완 — 아레니우스 hazard 가 국소 T 를 따라가는지 (구배 속 반응률의 공간 프로파일). 부족이 발견되면 STATE 격차 갱신 + 정련 step 등록 (이 관문의 존재 이유).

## 장면

- `s09-entropy-corner`: 구석 몰아넣기 → 자유 팽창.
- `s09-keq-volume` / `s09-keq-temp`: K_eq 2종 스캔.
- `s09-gradient`: 온도 구배 이완.

## 검증

1. 앙상블 S(t) 증가 경향 (R=16, 후반 창 평균 > 초반 창 평균, 3·se) + 요동 존재 (개별 런 비단조 허용 확인).
2. K_eq 부피·온도 의존 2종 (위 명세) — **비율 공식 author 0, 미시상태 샘플링만으로** (커널 체크 4).
3. van't Hoff 기울기 = D ± 허용 오차 (자유에너지 경쟁의 창발 증거).
4. **수치 불변식 일괄**: 닫힌 전 장면 (s01~s08) 에 dt 반감·순서 셔플·배속 스위트 일괄 실행 — 이후 상시 회귀 세트로 고정.
5. T_국소 평형 정합 + 비평형 프로파일 기록 (assert 는 평형 정합만 — 비평형은 관찰·기록).
6. **눈**: 엔트로피 궤적 패널 (R런 밴드) · 자유 팽창 애니메이션.

## 경계

새 행 0 · 새 힘 0. ΔG 기반 coarse 전이 도입 아님 (S1+ 방식 — 계층 분리). 실원소 없음 (⑩).

## 구현 정련 (step-0009 — 실물 코드가 이 설계를 이렇게 고쳤다)

1. **van't Hoff 는 캐논ical(고정 T) → 항온조 필요**. 설계는 "T0 스캔 → ln K vs 1/T" 를 명세했으나, ⑥ 복사 안정화가 우물 D 를 광자로 방출해 계를 방출 냉각 → **평형 T 가 협대역(0.43~0.51)으로 자체 수렴**(T0 무관). 그래서 T0 스캔으로 1/T 범위를 못 만든다. van't Hoff 는 본래 정준 앙상블 관계이므로 **측정 전용 항온조**(K tick 마다 속도 재조정)로 T 고정 → 기울기 2.72(=D 2.0 + 2D 병진 엔트로피 보정)로 창발. 항온조는 측정 도구(닫힌 장부 회귀는 불변). 미시정준 van't Hoff 는 닫힌 3체 안정화(D→제3체 KE) 필요 — engine formBond 개정 사건이라 보류.
2. **측정은 measure.js·검증은 verify.js·장면은 scenes.js 초기 조건**. 새 물리 0 유지. 엔트로피는 위상공간(공간 셀×속도 빈), K_c 는 연결 성분 크기별 카운트, T_국소는 이웃 k체(k=6) 평균.
3. **T_국소 assert 는 평형 정합만**(rel 0.005). 비평형 구배(s09-gradient)는 관찰·기록 — 구배 속 반응률 공간 프로파일 정량화는 향후 반응-확산 정련.
4. **엔트로피는 단조 아님·앙상블 증가**(DESIGN §4.1): 개별 12런 중 7런 비단조(요동) — R런 평균 증가로 통과.
