# ⑰ 산·염기 — 상세 설계 (양성자 릴레이)

> 앵커: 물 자동 이온화 (2H₂O ⇌ H₃O⁺ + OH⁻) · 전제: ⑯ · DESIGN §9.2-⑰

## 목적

H⁺ (전자 없는 코어) 가 수소 결합 링크 위를 이동하는 **양성자 릴레이**로 자동 이온화 평형을 재현한다. 희귀 사건 큐 (④의 lifetime 채널) 가 큰 흡열 ΔE 사건을 다루는 첫 실전.

## 더하는 것

### 카탈로그 행 2종

| id | kind | hazard | 내용 |
|---|---|---|---|
| `R-PROT-XFER` | lifetime | arrhenius (Eₐ = ΔE_이전 + 장벽 노브) — H-결합 링크 성립 시 큐 예약 | D–H···A → D⁻···H–A : H 원자가 결합을 갈아탄다 (occ·dq·예산 재계산 동반) |
| `R-PROT-RELAY` | contact | 확산제한 (H-결합 네트워크 위) | H₃O⁺/OH⁻ 의 잉여/결손 양성자가 이웃 물로 연쇄 이전 (Grotthuss — 같은 R-PROT-XFER 의 저장벽 특례: 이온 관여 시 Eₐ 급감) |

- ΔE 계산: 이전 전후 전체 국소 에너지 (결합·부분 전하·분극) 차 — guard 가 미시 회계로 산출 (산성도 author 0).
- **자동 이온화는 별도 행이 아니다**: 중성 물끼리의 R-PROT-XFER 가 곧 2H₂O → H₃O⁺ + OH⁻ — 크게 흡열이라 hazard 가 희귀 사건으로 만든다 (르샤틀리에·볼츠만 꼬리의 몫). 역방향 (재결합) 은 같은 행의 역쌍 — 발열이라 빠름.

### 희귀 사건 큐 실전 수칙

- H-결합 성립/해체 (⑯ 검출기) 가 큐 예약/무효화 트리거 — tick 폴링 금지 (KERNEL §3.1 두 시계).
- 통계 확보: K_w 유사값이 극소 → 장시간 런 + R런 + 이온쌍 수명 가중 측정 명세 (사건 수 최소 확보 기준을 assert 전제 조건으로).

## 장면

- `s17-autoionize`: 순수 H₂O 상자 (⑯ 네트워크 조건) 장시간 — 평형 이온 농도.
- `s17-relay`: H₃O⁺ 1개 주입 — 릴레이 확산 추적.
- `s17-acid-mix`: 산성 종 (χ 높은 가상 산 HX — V 계열 재활용) 소량 — 이온 농도 이동.

## 측정

[H₃O⁺]·[OH⁻] 시간 평균 · K_w 유사 = [H₃O⁺][OH⁻] · 양성자 유효 확산 계수 D_H (전하 위치 추적) vs 분자 자기 확산 D_mol · 이온쌍 재결합 시간.

## 검증

1. **평형**: 이온쌍 생성⇌재결합이 정상 농도 도달 · K_w 유사 ≪ 1 (중성 우세) · 온도 상승 → K_w 증가 (흡열 — 르샤틀리에 창발).
2. **릴레이 시그니처**: D_H > D_mol (Grotthuss — 전하가 분자보다 빨리 이동, R런 유의차).
3. `s17-acid-mix`: [H₃O⁺] 증가·[OH⁻] 감소 — 곱 K_w 유지 (공통 이온 효과 창발).
4. 장부·보존: 사건 단위 ≤1e-9 · 총 H·전하 보존 · H₃O⁺ 의 O 예산 위반 없음 (배위 결합 — 연속 예산의 검증 사례).
5. **눈**: 이온 하이라이트 (H₃O⁺ 주황 / OH⁻ 청록) · 릴레이 경로 트레일.

## 경계

pH 정량·완충 용액·강산/약산 스펙트럼 없음 (가상 산 1종 정성). 터널링 보정 (H 의 양자성) 은 hazard 스키마에 예약만 — 채택 시 DESIGN 개정.

## 구현 정합 (step-0017 — 설계와의 정직한 차이)

구현이 설계와 어긋난 지점을 여기 남긴다 (KERNEL/README 규율).

1. **R-PROT 한 행·접촉 채널로 통합**: 설계의 R-PROT-XFER(lifetime 큐)·R-PROT-RELAY(contact) 2행을 **접촉 채널 1행 R-PROT** 으로 합쳤다. 자동이온화·릴레이·재결합이 모두 "H 가 D→A 로 결합을 갈아탄다"의 한 형식이고, **장벽 비대칭(자동이온화 흡열=희귀·재결합 발열=빠름·릴레이 열중립=빠름)은 별도 hazard author 가 아니라 에너지 가드(collisionalTransfer)에서 저절로 나온다** — "이온 관여 시 Eₐ 급감(Grotthuss)"도 author 0. 지수 대기시간 큐는 같은 포아송 통계의 최적화일 뿐(접촉 시계 p=1−e^{−k·dt} 와 동형)이라 후속 최적화로 남긴다.
2. **정체(형식 전하)는 측정**: 이온(H₃O⁺·OH⁻)은 라벨이 아니라 O 형식전하 = (H 결합 수 − 중성 nv). 전이 전후 형식전하 합 불변 → **전하 보존 정확**(Σformal=0 · verify). O 배위 ≤ 3 캡(H₄O²⁺ 금지) = 연속 예산의 배위 결합 검증.
3. **용매화 노브 protSolv (⑯ R-HB D_hb 동형·명시 author)**: 우리 모델은 명시 점전하만이고 유전 차폐가 없어 이온쌍 자기에너지를 과대평가(측정 ΔE_autoion≈+9·냉수에선 완전 동결). 실제 물 유전 용매화 대체로 **순 전하 성분당 −protSolv·Q² 안정화**를 노브로 더한다 — 방향(흡열)·온도 응답·산 이온화는 창발하고 *크기*만 노브가 정한다(숨김 0). 위상만의 함수라 힘 0(에너지 오프셋)·전이 ΔE 에 포함되어 KE 로 정산(장부 닫힘).
4. **자동이온화는 주입·재결합으로 실증**: 냉수(T~0.02·⑯ 네트워크 유지 온도)에선 자동이온화가 흡열이라 *자발* 생성이 관측 불가(⑨ van't Hoff·⑯ 점전하 격차와 동류). 그래서 이온쌍을 주입해 **재결합(중성 우세·K_w≪1)** 과 **온도 응답(고T 잔여 이온↑=흡열)** 으로 평형 방향을 실증한다(⑨의 준비된 상태 접근과 동형). 릴레이·산 이온화는 주입 이온으로 직접 관측.
5. **사건 단위 보존 ~1e-7 (설계 "≤1e-9" 완화)**: ⑯ 각도 힘의 고립쌍 준정적 최소화(warm-start 12회)가 force 를 ~1e-7 비이상적으로 만들어(STATE §3 "L 잔차") 사건 1e-9 불가. 대신 **전하(정확)·H 수(정확)·예산(≤3)** 으로 보존을 검증하고, 런 표류는 이온 쿨롱 강성+누적 비이상성으로 < 2e-3(문서화).
