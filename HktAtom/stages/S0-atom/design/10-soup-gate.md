# ⑩ 수프 관문 — 상세 설계 (실원소 합류)

> 앵커: 화학량론 (2H:1O → H₂O) · 전제: ⑥⑧⑨ · DESIGN §9.1-⑩

## 목적

가상 원소로 증명한 구조 창발에 **실원소 파라미터를 합류**시켜 실세계 화학량론이 닮게 나오는지 확인한다. "물리 구조 창발"과 "실수치 정합"의 분리(디버깅 원칙)가 여기서 다시 만난다.

## 더하는 것

### 실원소 종 세트 (species — ③ fromZ 유도 + 앵커 노브)

- 1차: `H, O` (+검증용 `He, Ne`) · 2차(⑭~⑱ 대비): `C, N, Na, Cl`.
- levels·B·IE·EA 는 ③ 순수 함수 유도값 그대로 (author 아님). σ·ε_rep·α 는 앵커 재현이 조정하는 노브 — 조정 근거를 step 문서에 기록 (무차원 닮음: 절대값이 아니라 **원소 간 비율**을 실세계 비율에 맞춘다. 예: α_O/α_H, σ_O/σ_H).
- D(결합 우물 스케일)·k_b 도 쌍별 노브 승격: `D_HH : D_OH : D_OO` 비율을 실 결합 에너지 비율(436:463:146 kJ/mol → 정규화)에 앵커.

### 새 행 0 — 파라미터 세트만 추가 (커널 "새 현상 = 행"의 대우: 새 원소 = 데이터)

## 장면

- `s10-water-soup`: H 2N + O N 원자 수프, 고T 시작 → 냉각 스케줄 (⑨ 검증된 평형 동역학 신뢰) → 조성 정착.
- `s10-h2-o2-metastable`: H₂ + O₂ 분자 혼합 저T — 장시간 조성 불변 (점화는 ⑱).
- `s10-periodic-anchor`: ③ 단위 테스트 + 이온화 E 실원소 순위 재확인 (He>H, Ne 피크, Na 골).

## 측정

조성 히스토그램 (H₂O·OH·H₂·O₂·H₂O₂ …) · 미반응 원자 비율 · 반응 진행 궤적.

## 검증

1. **화학량론**: `s10-water-soup` 냉각 후 H₂O 가 최다 분자종 (R=12) · O 예산 2 포화 (H₃O 공유 과결합 0 — 이온 H₃O⁺ 는 ⑰ 몫이라 이 장면에선 전하 중성 유지 확인).
2. **준안정**: `s10-h2-o2-metastable` 에서 반응률 ≈ 0 (활성화 장벽 — 아레니우스 억제의 실전 증거). 고T 재가열 시 반응 진행 (대조).
3. 주기율 앵커 재확인 (③ assert 실원소 전체 재실행).
4. **가상 원소 회귀**: Part I 전 장면 (V 계열) 그대로 통과 — 실원소 합류가 기존 물리를 건드리지 않음 (파라미터 분리 증명).
5. **눈**: CPK 팔레트 (H 흰색·O 빨강) 전환 · 물 분자 우세 화면.

## 시각화

실원소 CPK 색 (가상 원소 팔레트와 토글) · 조성 히스토그램에 실분자종 라벨 (라벨은 측정 조성의 표기일 뿐 — 코드 분기 0).

## 경계

굽은 형상(⑭)·극성(⑮)·수소결합(⑯) 없음 — 이 단계의 "물"은 위상(조성 H₂O)만 맞는 분자다. 연소(⑱)·산염기(⑰) 없음. 실수치 절대값 정합 주장 없음 (무차원 닮음 — 비율만).

## 구현 정련 (step-0010 — 실물 코드가 이 설계를 이렇게 고쳤다)

1. **쌍별 D 는 engine `bd.D`(스칼라 fallback)** — `pairD(sp,sp)`가 형성 시 `bd.D` 설정, `U_bond`·해리 아레니우스가 `bd.D ?? world.Dbond` 사용 → ①–⑨ 회귀 0. `world.Dpair['H-O']` 등 정렬 키.
2. **H₂O 우세는 어닐링이 필요·pooled 로 확인**. 실 비율 H–H(436)≈O–H(463)이라 H₂ 가 실 경쟁자(준안정) → 단발 냉각은 시드에 흔들림. `annealSoup`(고T→6단 냉각) 후 R=6 pooled 로 H₂O 최다(46 vs H₂ 26). 항온조가 뺀 열은 **E_escape 회계 → 장부 닫힘**.
3. **`s10-h2-o2-metastable` 폐기 → 크래시 vs 어닐 대조**. 단일 결합만이라 O=O(이중)를 못 만들어 우리 O₂ 가 비현실적으로 약함(준안정 안 됨). 대신 크래시(H₂ 갇힘) vs 어닐(H₂O)로 활성화 장벽을 실증 — 더 견고. 이중결합은 결합차수 확장 후속.
4. **노브**: D_OH=2.0 기준·σ_O/σ_H=1.2·mass 는 dt 강성 회피로 1:4 압축(조성 무관). k_b·d0 는 균일(형상은 ⑭).
