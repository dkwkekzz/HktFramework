# ⑥ 결합·복합체·해리 — 상세 설계

> 앵커: 분자 (가상 원소) · 전제: ④⑤ · DESIGN §3.1(예산)·§3.3(안정화 경로)·§9.1-⑥

## 목적

결합의 이산 상태 기계: **접근 → 임시 복합체 → 안정화(광자|제3체) → 안정 결합** 경로와 **연속 예산 분배**. 조성 시그니처(분자)가 측정에서 창발하고, 예산 포화가 과결합을 막는 것을 증명한다. "결합은 힘에서 완전 창발하지 않는다"(DESIGN §3.2 정직)의 구현.

## 더하는 것

### 자료구조

```js
bond    = { i, j, order /*연속 b_ij*/, rest:d0(b), k:k_b(b), mode:null /*⑦*/ }
complex = { i, j, t_form }   // 임시 복합체 — bond 승격 전 상태, 큐에 자연 해체 예약
```

### 결합 파라미터의 예산 의존 (수식형 — 상수는 노브)

```
E_bond(b)  = −D·b            // 우물 깊이 — 선형 (공명·부분 결합이 자연히 연속)
d0(b)      = d1 − δ·(b−1)    // 차수 높을수록 짧게
k_b(b)     = k1·b            // 차수 높을수록 단단하게
```

### 예산 분배 — 국소 에너지 최소화 (DESIGN §3.1)

- 결합 이벤트 발생 시 해당 **연결 성분 내부**에서만 재분배 (전역 조율 0): `min Σ E_bond(b_ij)` s.t. `Σ_j b_ij ≤ B_i`, `b_ij ≥ 0`. 작은 성분이므로 반복 물주기(수렴까지 라운드 로빈)로 충분 — 알고리즘 명세를 catalog 가 아닌 engine 유틸로.
- 분배 변경의 ΔE 는 U_bond 통 안 이동 + 잉여/부족은 K_tr 과 교환 (사건 단위 회계).

### 카탈로그 행 5종

| id | kind | hazard | 내용 |
|---|---|---|---|
| `R-CPLX` | contact | collision (예산 여유 guard: Σb < B 양쪽) | 접근 → 임시 복합체 (상대 KE 가 우물보다 작을 때 포획) |
| `R-CPLX-DECAY` | lifetime | lifetime (τ_cplx 노브) | 복합체 자연 해체 — 안정화 못 받으면 되돌아감 |
| `R-STAB-RAD` | lifetime | lifetime | 복합체 → 결합 + 광자 (우물 깊이 → E_photon 빈) |
| `R-STAB-3B` | contact | threebody | 복합체 + M → 결합 + M (우물 깊이 → M 의 K_tr) |
| `R-DISS` | contact | arrhenius (Eₐ = D·b + 스프링 상태, T_국소) | 해리 — 역쌍은 형성 경로 전체 |

- **2체 직접 결합 금지**가 구조로 강제된다: R-CPLX 만으로는 bond 가 생기지 않는다.
- T_국소 = 이웃 k개(노브, 기본 8)의 KE 평균 — 아레니우스 hazard 의 첫 실사용 (한계는 ⑨가 확인).

## 장면

- `s06-v1-dimer`: V1 기체 → V1₂ 형성 (H₂ 유사).
- `s06-mixed`: V1+V2 혼합 → V1₂V2 (물 위상 유사) 시그니처.
- `s06-quad`: V4+V1 혼합 → V4V1₄ (메탄 위상 유사 — 위상까지, 형상은 ⑭).
- `s06-no-stab`: 안정화 행 2종 off 비교런.
- `s06-dissoc`: 형성 후 가열 → 해리 곡선.

## 측정

연결 성분 조성 히스토그램 (**복합체와 안정 분자 구분** — 수명 τ 문턱, DESIGN §5) · 성분별 수명 분포 · 원자별 Σb_ij vs B · 결합 에너지 분포.

## 검증

1. **조성 시그니처 창발**: 각 장면의 우세 조성이 예산 화학량론과 일치 (V1₂ · V1₂V2 · V4V1₄) — `if(isWater)` 류 분기 0 (커널 체크 4). **step-0006 발견: 동핵 이량체 V1₂(H₂)는 깨끗이 우세 창발(우세 H12), 원자가 포화(H₃=0)도 완벽.** 그러나 **이핵 분자(H₂O·CH₄)는 우세 안 함** — 결합 우물 D 가 등방(종 무관)이라 H–H 가 H–O 와 경쟁하고 O–O 도 생긴다. 물/메탄이 우세하려면 **결합 종류별 선호(전기음성도) = ⑮** 가 필요(설계 경계와 정합: ⑥=등방 스프링·⑮=부분 전하). ⑥은 결합 *메커니즘*(형성·안정화·포화·해리)을 닫고, 이핵 시그니처는 ⑮로 이월.
2. **예산 포화**: 전 시점 `Σb_ij ≤ B_i + 1e-9` · V1₃ 이상 과결합 성분 0 · V0 는 결합 0.
3. **안정화 필수**: `s06-no-stab` 에서 안정 결합률이 기준 대비 급감 (복합체만 명멸).
4. 형성⇌해리 평형: `s06-dissoc` 온도 스캔에서 해리도 단조 증가, 미시 가역 (K_eq 정량은 ⑨).
5. 장부: 결합 생성·해리·재분배 전 사건 ≤1e-9 · U_bond 통 정합.
6. **눈**: 결합선(굵기=order) · 복합체는 점선.

## 시각화

결합선 실선(굵기=b) · 복합체 점선 · 조성 히스토그램 패널 (분자 vs 복합체 색 구분).

## 경계

진동·회전 모드(⑦)·형상 각도(⑭)·부분 전하(⑮) 없음 — 결합은 아직 등방 스프링. 이온 결합은 ⑤의 쿨롱 + 이 단계의 R-XFER 조합으로 이미 가능 (별도 행 없음 — 확인만).
