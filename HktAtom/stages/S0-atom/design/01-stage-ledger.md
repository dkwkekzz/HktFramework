# ① 무대·장부 — 상세 설계

> 앵커: 입자가 있고 움직인다 · 전제: 없음 · DESIGN §1·§2·§4.2·§4.3

## 목적

존재(entity)·운동(Verlet)·회계(통 분리 장부)·검증 하네스(R런 통계 + 수치 불변식)의 뼈대. 이후 모든 세부 단계가 이 위에 선다 — **여기서 만든 구조는 바뀌지 않고 채워지기만 한다.**

## 더하는 것

### 통 분리 장부 — 0 이어도 처음부터 전 통 존재 (DESIGN §2)

| 통 | 정의 | 채워지는 단계 |
|---|---|---|
| `K_tr` | Σ p²/2m (병진) | ① |
| `U_elec` | 쌍 퍼텐셜(쿨롱+척력) 합 | ② |
| `U_int` | Σ_atom (Σocc·ε − 바닥 에너지) — 들뜸 에너지 | ④ |
| `U_bond` | 결합 우물 + 스프링 변형 에너지 | ⑥ |
| `U_vib` · `U_rot` | 내부 모드 | ⑦ |
| `U_pol` | −½Σα·E² 분극 에너지 | ⑧ |
| `E_photon` | 방출된 복사 (④ 스펙트럼 빈 → ⑫ 광자 입자) | ④ |
| `E_nuclear` | 예약 | ㉓~ |
| `E_escape` | 열린 경계로 나간 에너지 (⑫ 탈출 광자 포함) | ① 구조·⑫ 실사용 |

- **장부 항등식**: `E_total = Σ(전 통)` 이 시간에 대해 상수 (허용 오차 = Verlet 표류, ②가 수치 고정 — ①은 힘 0 이라 정확).
- 열린 경계: 탈출 입자의 E → `E_escape`, p 는 별도 `P_escape` 벡터에 회계 (P 보존 검사는 `P + P_escape` 로).

### tick 파이프라인 (DESIGN §4.3 — ①에서 자리만 다 판다)

`사건 큐 소진(④) → 힘(②) → velocity Verlet → 접촉 전이 샘플(④) → 장부 갱신·측정`

- velocity Verlet: `p += F·dt/2 ; r += (p/m)·dt ; F 재계산 ; p += F·dt/2`. ①은 F=0 (자유 비행 + 경계).
- **z 동결**: `frozenZ` 장면은 초기 z=0·p_z=0 으로 만들고, 매 tick `|z|·|p_z| ≤ 1e-12` assert (힘의 z 성분이 수치 오염을 만들면 즉시 검출). 동결은 장면의 속성 — 엔진에 2D 분기 없음.
- 사건 큐 뼈대: 이진 힙, 원소 `{t_fire, rowId, 참여자 id 목록, ver}` — 참여자 상태 변경 시 버전 증가로 lazy 무효화. ①에선 비어 있고 자료구조·소진 루프만 존재.

### 검증 하네스 (verify.js — node 와 브라우저 겸용)

- `runScene(name, {dt, ticks, ...}) → 관측량` 러너.
- `stat(R, fn) → {mean, sd, se}` R런 통계 + `assertWindow(x, target, tol)` / `assertExact`.
- 수치 불변식 스위트 — **모든 이후 단계가 재사용**: ⓐ dt 반감(장면을 dt·dt/2 로 돌려 선언 관측량 비교) ⓑ 접촉쌍 순서 셔플 ⓒ 배속(뷰어 배속이 물리에 영향 0 — tick 수만 다름).

## 장면 (scenes.js)

- `s01-ideal-gas`: 주기 상자, z 동결, 가상 원소 1종(질량만 의미) N≈64~128, 맥스웰 초기 p (T₀ 지정), F=0.
- `s01-open-box`: 열린 경계 — 탈출 회계 확인용.

## 측정 (measure.js)

- T 전역 = ⟨p²/2m⟩ / (자유도/2) — **자유도는 frozenZ 를 반영**(동결 시 입자당 2).
- MSD(t) 기울기 (자유 비행에선 탄도적 — dt 불변식의 관측량으로 사용), 장부 통 표 + 총합 잔차.

## 검증

1. **회계**: 전 통 합 보존 (F=0 → 정확, ≤1e-12) · |ΔP|≤1e-9 (open 장면은 P+P_escape) · Σc 정수 불변 (원자 수·종별 수).
2. **dt 반감**: T·MSD 곡선 통계 동일 (R=12, 3·se 창).
3. **경계 3종**: periodic 랩·reflect 반전·open 탈출 회계 각각 assert.
4. **눈**: 뷰어에서 입자 운동·장부 패널 잔차 0 확인.

## 시각화 (index.html)

canvas 2D (z 동결이라 xy 투영 그대로) — 원자 = 원(종별 팔레트, 반지름 σ), 패널: 장면 선택·배속·t·T·**장부 통 표 + 총합 잔차**·입자 수. 이후 단계는 이 패널에 열을 추가한다.

## 경계

힘 0 · 전이 0 · occ 없음. electrons/photons/bonds 는 빈 배열로 구조만. 이웃 해시 없음(전 쌍은 ②부터, 최적화는 G-성능).
