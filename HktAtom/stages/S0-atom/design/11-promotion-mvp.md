# ⑪ 승격 배관 ⇧ — 상세 설계 (MVP 완결)

> 앵커: 상자 시나리오 한 장부 + coarse↔재해동 왕복 · 전제: Part I 전부 · DESIGN §6(⑪ 임시 스키마)·§9.1-⑪ · ⇧/⇩ 의무: [CONTRACT.md](../../../CONTRACT.md) §3

## 목적

**Part I 의 관문**: ⓐ 밀폐 상자에서 `형성→응집→가열→상변화 조짐→반응→냉각` 이 하나의 장부로 이어지는 MVP 시나리오 ⓑ **승격·재해동 배관의 첫 왕복** (임시 스키마 — 목적은 배관 증명, 물질 충실도 아님). 이것이 프로젝트의 진짜 핵심 산출물(승격·해동 시스템)의 첫 실물이다.

## 더하는 것

### 임시 출력 스키마 (output.json v0 — CONTRACT §2 의 부분집합)

```json
{ "schema": "s0-output-v0", "version": "0.x",
  "species": [ { "id", "composition": {"V1":2}, "m", "E_bind",
                 "u_curve": [[T,u]], "cv_curve": [[T,cv]] } ],
  "pairPotential": { "V1_2|V1_2": [[r, V]] },
  "observables": [ { "name": "조성|T|P(비리얼)|배위수", "epsilon": 0, "protocol": "" } ],
  "validRange": { "T": [lo,hi], "rho": [lo,hi] },
  "provenance": { "stage": "S0", "scenes": [], "runs": R, "date": "" } }
```

- CONTRACT §2 가 ⑪ 에 요구하는 최소: species + 쌍 퍼텐셜 + **observables ≥ 1** — 왕복 검증(아래)의 관측량 목록이 곧 이 필드다. 본 스키마 정렬은 ㉒ 몫.

### V′ 측정법 — 평균 힘 퍼텐셜 (PMF)

- 종 쌍 (분자 2개) 의 질량중심 거리 r 을 구속하고 각도·내부 상태를 열 앙상블로 굴려 평균 힘 → 적분 = V′(r) 테이블. r 그리드·T 명세. **손 튜닝 0** — 테이블은 측정 산출물 (커널 체크 5).
- 정직: 이 테이블은 방향성·밀도 의존·협동 효과를 잃는다 (DESIGN §6) — validRange 에 측정 조건을 기록하고, 실 S1 입력은 ㉒ MaterialModel.

### coarse → 재해동 왕복 (강등 ⇩ 의 첫 구현 — KERNEL §3.3)

```
coarse(world) → { 종별 개수, V, E_total, T, P }          // 미시 배치는 버린다 (비가역 ≠ 비보존)
rethaw(coarse) → world′:
  위치 = 겹침 회피 무작위 (거부 샘플링) · p = 맥스웰(T) 샘플 · 내부 상태 = 볼츠만(T) 샘플
  → E 정확 보정: 샘플 후 잔차를 p 스케일링으로 회계상 정확히 맞춤 (P=0 유지 수식 명세)
```

### MVP 장면 대본 (`s11-mvp-box` — 밀폐 상자, 하나의 런)

| 막 | 조작 (열욕 스케줄만 — 물리 조작 0) | 기대 관측 |
|---|---|---|
| 1 형성 | 고T 원자 수프 → 1차 냉각 | 분자 조성 정착 (⑥⑩) |
| 2 응집 | 2차 냉각 | 클러스터 성장 (⑧) |
| 3 가열·조짐 | 재가열 | 배위수·최대성분 곡선 꺾임 (상변화 *조짐* — 상 본 무대는 S1) |
| 4 반응 | 고T 유지 | 조성 재분포 (해리·재결합) |
| 5 냉각 | 최종 냉각 | 재응집 — 장부 잔차 연속 0 |

- "열욕"은 경계 열욕(벽 접촉 재샘플) — 에너지 출입을 E_escape 통 대칭 회계 (닫힌 장부 유지의 명세).

## 검증

1. **한 장부**: 5막 전체에서 총합 잔차 ≤ EPS_E 누적 한도 · 사건 단위 ≤1e-9 · Σc 불변.
2. **왕복**: 막 2 종료 상태를 coarse→rethaw → 이후 같은 스케줄 재개 → 관측량 비교 (조성·T·P·배위수, R런 3·se 창) · E·Σc·P 는 회계상 정확.
3. output.json 스키마 유효성 (검증기 포함) · pairPotential 에 인력 꼬리 존재 (KERNEL §5 S0-⑧ 앵커: 반데르발스 꼬리가 *나옴*).
4. u_curve·cv_curve 가 ⑦ 측정과 일치 (내부 일관성).
5. **눈**: 5막 타임라인 UI (막 전환 마커 + 장부·조성·배위수 곡선 동시 표시).

## 시각화

시나리오 타임라인 바 · 막별 자동 카메라/차트 프리셋 · output.json 다운로드 버튼 (뷰어에서 승격 실행).

## 경계

MaterialModel(EOS·수송·반응망)은 ㉒ — 여기선 배관만. 실원소 정합 심화 없음. S1 소비 테스트는 S1-① 몫 (스키마 검증기까지가 S0 책임).

## 구현 정련 (step-0011 — 실물 코드가 이 설계를 이렇게 고쳤다)

1. **coarse E = 물질 에너지** (E_photon·E_escape·E_nuclear 제외). 전 통 합을 쓰면 떠난 복사·열을 되돌리려다 왕복이 폭발. 물질에 든 에너지만 승격 대상(S1 개체 u′).
2. **rethaw = 격자 배치 → pushApart(위치 겹침 제거·힘 무관) → 감쇠 완화 → 맥스웰(T) → E 정확 보정(KE 스케일·P=0)**. 밀도 고정이라 무작위 배치는 겹침 폭발 → pushApart+완화가 필수. E 는 보정으로 정확, T 는 재표본이라 ~1.3배 이동(관측량 계약: 조성 ε=0·T 창).
3. **s11-mvp-box 는 polForces 로 결합(⑥⑩)+분산(⑧) 통합**. 5막 열욕은 thermoReservoir(E_escape 회계)로 한 장부 유지. 왕복 검증은 즉시 비교(coarse→rethaw 정확)로 — "재개 후 비교"는 T 이동 때문에 창으로.
4. **PMF 는 단원자 중성쌍 근사**(분자 내부 자유도 미포함) — 인력 꼬리 존재 확인엔 충분. u_curve·cv_curve 는 스키마 옵션(미채움·⑦ 별도 검증). output.json v0 검증기 = `validateOutput`(필드·observables≥1·인력 꼬리).
