# ⑧ 분극·응집 — 상세 설계

> 앵커: 중성 입자가 뭉친다 · 전제: ② (⑥ 권장) · DESIGN §3.2(분극·C6 정직)·§9.1-⑧

## 목적

"없는 물리는 측정에서 생기지 않는다"의 구현: 중성 입자 인력의 **근원**(분극 자유도 + 정직 author 된 C6 잔여항)을 동역학에 넣고, 저온 응집이 창발하며 근원을 끄면 소멸함을 증명한다.

## 더하는 것

### 유도 쌍극자 (atom.mu 실사용)

```
E_local(i) = Σ_j [ 전하 기여 qⱼ·d̂/(d+s)² + 쌍극자 기여(표준 쌍극자 장) ]
μᵢ = αᵢ · E_local(i)          // α 는 종 파라미터 (③ species.alpha — 바닥 특권 author)
U_pol = −½ Σ αᵢ·|E_local(i)|²  // 통 실사용
```

- 자기일관: μ 가 서로의 E_local 에 들어가므로 반복 수렴 — 반복 횟수 n_scf 노브 (기본 2, 수렴 잔차 측정 후 고정).
- 힘: 전하–쌍극자·쌍극자–쌍극자 상호작용의 해석 그라디언트 (반대칭 — P 보존). U_pol 의 시간 변화는 장부에서 K_tr 과 정합해야 (보존력 검증).

### C6 잔여항 — 정직 author, 근원은 α 에 묶는다 (설계 결정)

- **정직한 문제**: 고전 유도-유도만으로는 무극성 중성 기체(E_local≈0)에서 인력이 0 이다 — 런던 분산은 양자 요동. 그래서 DESIGN 은 C6 잔여항 author 를 허용한다.
- **묶음**: `C6ᵢⱼ = (3/2)·(IEᵢ·IEⱼ/(IEᵢ+IEⱼ))·αᵢ·αⱼ` (런던 공식 — IE 는 ③ 측정값). 계수만 author 하고 **크기는 α·IE 에서 유도** → "α=0 이면 응집 소멸" 검증이 C6 까지 관통한다.
- `V_disp = −C6ᵢⱼ/(d⁶+a⁶)` (단거리 완충 a 노브 — 척력과의 이중 계상 방지).

## 장면

- `s08-noble-condense`: V0 (중성·닫힌 껍질) 기체 냉각 스캔 → 응집 (Ne 응축 유사).
- `s08-alpha-zero`: 같은 장면, α=0 (→C6=0) 비교런.
- `s08-ion-induced`: 이온 1개 + 중성 기체 — 전하–유도 쌍극자 인력 (분극 경로 단독 검증).

## 측정

클러스터 크기 분포·최대 성분 비율 vs T · 평균 배위수 · U_pol / V_disp 에너지 기여 분해 · 응집 온도 T_c (최대 성분 비율 50% 교차 — 조짐 지표, 상전이 본 무대는 S1).

## 검증

1. **응집 창발**: 냉각 스캔에서 T_c 존재 (고T 기체 ↔ 저T 응집 — R런 통계).
2. **근원 검증**: `s08-alpha-zero` 에서 응집 소멸 (최대 성분 비율이 고T 수준 유지).
3. `s08-ion-induced`: 이온 주변 중성 밀도 상승 (분극 경로가 C6 없이 단독으로 인력을 만든다).
4. 장부: U_pol 통 닫힘 — μ 갱신 시점 에너지 회계 명세 (SCF 수렴 잔차를 장부 허용 오차에 산입, 수치 고정).
5. dt 반감 + n_scf 증가 → 통계 동일 (근사 차수가 물리를 바꾸지 않는 창 확인).
6. **눈**: 유도 쌍극자 화살표 · 응집 덩어리 형성.

## 시각화

μ 화살표(길이=|μ|) · 클러스터 색 구분 · T 스캔 중 최대 성분 비율 곡선 패널.

## 경계

부분 전하(⑮)·수소 결합(⑯)·상 라벨 없음 — "응집"은 측정된 클러스터일 뿐 고체/액체 구분은 S1. 영구 쌍극자는 ⑮ 이후 (여기선 유도만).

## 구현 정련 (step-0008 — 실물 코드가 이 설계를 이렇게 고쳤다)

1. **자기일관 SCF(n_scf) → 쌍별 비상호 근사** (힘·에너지). 이유: (a) 무극성 중성쌍은 E=0 이라 정적 상호분극이 어차피 0, (b) 유한장(이온) 근방은 1차 유도가 지배, (c) 고전 유도-유도 상관을 SCF 로 흉내내면 그것이 대신하려던 런던 분산(=C6 잔여항)과 **이중 계상**된다. 그래서 상호분극이 대신하려던 인력은 C6 채널이 전담하고, 힘·에너지엔 쌍별 근사(U_ind=−½Σαkc²q²/(d+s)⁴)를 쓴다. μ 화살표(시각화)만 국소장으로 계산(진단). → 장부가 EPS_E 로 정확히 닫힘(SCF 잔차 항 불필요).
2. **s08-ion-induced 는 분산(C6) off**. "분극 경로가 C6 없이 단독으로 인력"을 고립 검증하려면 중성-중성 인력을 꺼야 계의 유일한 인력이 이온→중성뿐이 된다 (ionizeE=0 → C6=0, α 는 유지 → 전하유도는 산다). 전하 on/off 차이 = 순수 분극 경로.
3. **1차 지표 = 평균 배위수 + 응집에너지 U_pol/N** (최대 성분 비율은 보조). 이유: **미시정준(닫힌계)** 이라 응축 잠열이 계를 T_c 근방으로 자체 가열 → 액적+증기 공존에 머문다(열 배출 sink 없음 = 정직한 물리). 이때 "단일 액적 50% 교차"는 시드에 흔들리지만 배위수·U_pol/N 은 견고하다. T_c 곡선은 뷰어 패널로 조짐만 본다(상전이 본 무대는 S1).
4. **노브 고정**: α_Ng=1.6? → **1.3**(우물 깊이 vs dt 강성 절충)·IE_Ng=1.85·a_buf=0.9·dt=0.0015(EPS_E 닫힘)·이온 전하 +2·이온 질량 120(~고정). C6=(3/2)(IE²/2IE)α²≈2.4.
