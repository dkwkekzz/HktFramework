# ⑫ 복사장 — 상세 설계

> 앵커: 열린→냉각 vs 닫힌→복사 평형 · 전제: ④ · DESIGN §9.2-⑫

## 목적

④의 광자 빈 근사를 **photon 입자**로 교체 — 공간·방향 정보를 가진 복사장. 흡수·유도 방출이 실제 광자 궤적에서 일어나고, 열린/닫힌 경계의 냉각/평형 차이가 재현된다.

## 더하는 것

### photon 입자 (DESIGN §2)

- `photon = { E, r, dir(단위벡터), t0 }` — 직진 전파 속도 `c_ph` (노브, 기본 ≈ 10·v_th_max). **정직**: 실제 c 비율 아님 — 원자보다 충분히 빠르다는 위계만 유지 (무차원 닮음).
- 광자는 질량 0·운동량 회계는 생략 (설계 결정 — |p_ph|=E/c_ph 는 원자 p 대비 미소, 복사압은 범위 밖. P 검사에서 광자 제외를 명기 — 한계 정직).

### 행 개정 + 신설

| id | 변경 | 내용 |
|---|---|---|
| `R-EMI` | 개정 | 방출 = photon 생성 (등방 무작위 dir) — 빈 대신 입자 |
| `R-ABS` | 개정 | 광자–원자 접촉 판정 + `|E_ph − ΔE| < Γ` (선폭 노브) → 흡수 단면 σ_abs |
| `R-STIM` | 신설 (contact) | **유도 방출**: 들뜬 원자 곁을 공명 광자가 통과 → 확률적 복제 방출, **dir 동일** (2광자 결맞음의 고전 근사) |

- 마이그레이션(step-0012 정합): ④의 빈 경로는 **제거하지 않고 `radiationMode='field'` 를 additive 로 추가**한다 —
  `E_photon` 통이 bond 복사 안정화(⑥/⑩/⑪)의 에너지 sink 로도 쓰여 wholesale 제거가 회귀를 건드리기 때문(⑩ pairD
  fallback 과 동형·회귀 0). field 모드에선 `E_photon` 통 = Σ photon.E **정확**(bond 없는 장면). 경계는 `photonBC`
  (원자 경계와 독립): open → 탈출 광자 E → E_escape · periodic → 랩 · reflect → 반사.

## 장면

- `s12-open-cooling` / `s12-cavity`: ④의 3장면 회귀 재현 (빈→입자 교체 검증 — 같은 assert 통과).
- `s12-stim`: 밀도 반전 인위 초기화 (들뜸 상태 다수) + 씨앗 광자 한 방향 주입 → 방향성 증폭.

## 측정

빈별 광자 수 스펙트럼 (입자를 빈으로 집계 — 측정 층에서만) · 광자 플럭스 (경계 통과율) · 방향 분포 이방성.

## 검증

1. **회귀**: ④ 3장면 assert 전부 통과 (열욕 볼츠만·열린 냉각·닫힌 공동 평형) — 냉각률이 광자 플럭스 회계와 일치.
2. 닫힌 공동: 광자 수 정상 상태(항상 >0). **스펙트럼 단색**(step-0012 발견) — 2준위 종이라 모든 광자 E=dE →
   한 빈 집중. 연속 스펙트럼·고에너지 꼬리(플랑크)는 다준위/진동-복사 결합 필요 → ㉒ 몫으로 이월(한계 정직).
3. **유도 방출**: `s12-stim` 에서 씨앗 방향 광자 수가 등방 대비 유의 증폭 (R런) · 자발만으론 이방성 없음 (대조).
4. 장부: E_photon = Σphoton.E 정합 · 사건 단위 ≤1e-9.
5. **눈**: 광자 = 이동 점 (색=E) · 유도 방출 장면의 빔 형성.

## 경계

복사압·산란(톰슨/컴프턴)·편광 없음. 플랑크 분포 정량 앵커 없음 (고전 근사 — 자외 파탄은 이 모델의 알려진 경계, 문서화만). 진동-복사(적외)는 노브 검토 항목 유지.
