# S0-atom DESIGN — 원자 단계 상세 설계도

> 이 문서는 **S0 원자 단계의 설계 권위**다. 단계 5원칙·커널 형태·검증 4기둥의 권위는 [../../KERNEL.md](../../KERNEL.md), 현재 위치는 [../../STATE.md](../../STATE.md). 구현이 설계와 어긋나는 발견을 내면 이 문서를 고치고 step 문서에 이유를 남긴다.
>
> **단계 정체 한 줄**: 실세계 원자 원리를 author 한 유일한 바닥 — 원자 수프를 굴려 **분자가 창발**하고, 분자 카탈로그 + 유효 상호작용 테이블을 `output.json` 으로 내보낸다(= S1 의 입력). 상(고/액/기)·증발·응축·결정화는 **S0 이 아니라 S1 의 몫**이다(단계 경계) — S0 은 그 재료(분자·V′·내부 모드)를 만든다.
>
> **공통 시뮬레이션 원리 한 줄 (§4 가 권위)**: 세계는 **연속층**(위치·운동량 — 힘과 적분)과 **이산층**(내부 상태 = 준위 점유의 *전이*) 두 층으로 굴러간다. 들뜸·이온화·재결합·결합·해리·붕괴·융합은 *전부* 같은 형식의 전이이고, 전이 속도는 통계역학 계약(아레니우스 + 축퇴도 포함 세부 균형)을 지킨다 — 볼츠만 분포·화학 평형·엔트로피 경향은 author 하지 않아도 **창발**한다.

## 1. 세계 결정

| 결정 | 값 | 이유 |
|---|---|---|
| **차원** | **2D 시작 → 3D 승급점 명시** | Part I(전이 엔진·장부·준위·기초 화학·스펙트럼)은 2D 로 충분. **형상·수소결합·응집 화학(⑬~) 진입 전에 3D 승급(⑫)을 평가** — 그 현상들은 본질이 3D 라 2D 로 다 만들고 옮기면 재작성 위험 |
| **경계** | 주기(토러스) + **열린/반사 경계 옵션** | 장부 검증은 닫힌 계로, 복사 냉각·증발류 장면은 열린 경계로 — 탈출 에너지는 E_escape 통에 회계 |
| **단위** | 무차원 자연 단위, k_B=1 | 목표는 닮음(경향·비율·곡선 모양)이지 실단위 재현이 아니다 |
| **두 시계** | 연속: dt Verlet · 이산: 사건 큐 | §4 — 연속 힘은 적분, 화학 반응·자발 방출·붕괴는 확률 사건/예약 사건 |
| **이웃/힘 계산** | **처음엔 작은 상자 전 쌍 계산** → 병목 측정 후 근사(해시·컷오프) | 장거리 쿨롱을 컷오프로 처음부터 자르면 이온 거동·에너지가 왜곡 — 검증이 먼저, 최적화는 G-성능 |

## 2. 자료형 — 내부 상태는 *부껍질 점유*다

```js
atom     = { Z, N /*예약*/, r:[x,y], p:[px,py], occ:{ '1s':2, '2s':2, '2p':2, … } }
electron = { r, p }                       // 자유전자 (E≥0 연속상태 — ⑤ 재결합·⑲ 이온화 기체부터)
photon   = { E, r, dir, t0 }              // 광자 입자 (⑪ 복사장부터 — 그 전엔 통(E_photon)만)
bond     = { i, j, nShared, rest:d0, mode:{vib, rot} }   // 공유 점유 + 내부 모드(⑦부터)
world    = { atoms, electrons, photons, bonds, events(큐), ledger }
```

- **occ 는 부껍질(1s·2s·2p·3s·3p·4s·3d…) 단위다** — 단순 (Z,n) 준위로는 탄소의 4가·질소/산소의 홀전자·전이금속을 표현할 수 없다(§3.1). e(전자 수) = Σocc 는 파생량. 이온·들뜸·라디칼(홀전자)·원자가가 전부 *한 점유 배치*다. 내부 에너지는 Σocc·ε 로 **측정**되는 파생량.
- **에너지 장부는 통 단위로 처음부터 분리한다** (초기값 0 이어도 자료구조엔 존재):

```
E_total = K_tr(병진) + U_int(쌍 퍼텐셜) + U_elec(Σocc·ε) + U_bond + U_vib + U_rot
        + E_photon + E_nuclear(예약) + E_escape(열린 경계 탈출분 — 복사·중성미자)
```

- **질량** m(Z): 주 동위원소 테이블 (fallback 2Z). N 도입(㉑) 시 Σ 회계로 대체.

## 3. V₀ — 바닥 물리의 전부 (준위 구조 + 연속 힘 + 전이 카탈로그)

### 3.1 준위 구조 (재료① — 부껍질·축퇴도·채움 규칙)

```
부껍질 순서: 1s 2s 2p 3s 3p 4s 3d …          // Aufbau
용량(축퇴도 g): s=2 · p=6 · d=10               // 파울리 배타 = 점유 ≤ g
ε(부껍질) = −R·(Z_eff/n_eff)²                  // 차폐(Slater 근사) — 부껍질별 유효 핵전하
채움: 낮은 ε 부터 + 훈트 단순화(같은 부껍질 안에선 홀전자 우선)
자유전자 연속상태: E ≥ 0                        // 이온화·재결합·금속 전도·이온화 기체의 공통 무대
결합 슬롯 = 홀전자 수                           // H=1 · N=3 · O=2 · F=1 · Ne=0
radius(Z) = 0.5 + 0.3 × 점유 껍질 수
```

- **탄소의 4가는 승위 전이로 창발한다**: C 바닥(2s²2p²)은 홀전자 2 — 2s→2p 승위(작은 ΔE 의 전이 카탈로그 행)로 홀전자 4 가 되고, 승위 비용은 추가 결합 2개의 에너지가 회수한다. 4가를 박지 않는다.
- 이온화 에너지 = −ε_최외각(주기 경향 창발) · **전자친화도** = 빈 부껍질에 전자를 넣을 때의 ΔE (전자 획득·재결합의 재료).
- 점유 분포 검증은 **축퇴도를 포함**한다: pᵢ ∝ gᵢ·exp(−εᵢ/T).

### 3.2 연속 힘 (재료② — 연속층의 전부)

```
q = Z − Σocc − (소속 자유전자)
V_cont(i,j,d) = k_c·qᵢqⱼ/(d+s) + ε_rep·(σᵢⱼ/d)¹² + ½k_b(d−d₀)² [결합 시]
각도 척력: 같은 원자의 전자쌍 방향(결합쌍+고립쌍)끼리 공통 반발 (고립쌍 배율 > 1) — ⑬부터
```

- 힘 = −∇V, 반대칭 자동. 중성-중성 장거리 인력(분산력)은 author 하지 않는다 — 출력 측정(⑩)과 부분 전하(⑭)가 만든다.
- **형상은 "분자별 목표 각도" author 금지**: `H2O.targetAngle=104.5°` 류 금지 — 공통 반발 에너지항 하나에서 결과 각도를 *측정*한다. (반발 규칙 자체는 author — 정확히 말해 "각도의 무작성"이지 "규칙의 무작성"이 아니다.)

### 3.3 전이 카탈로그 (재료③ — 이산층의 전부: **모든 현상이 이 한 형식**)

```
transition = { from(상태 조건), to(상태 변화), ΔE, Eₐ, ν, 선택조건(허용 그래프), 안정화경로, 역쌍 }
```

- **허용 전이 그래프**: 에너지가 맞다고 다 전이하지 않는다 — 각 행에 선택 조건(최소한: 어떤 부껍질쌍 사이가 허용인지)을 둔다. 완전한 양자 선택 규칙은 목표가 아니다(닮음 수준).
- **충돌 완화와 자발 방출은 별개 채널이다**: A\*+B→A+B′(K 로 — 고밀도 우세) vs A\*→A+γ(광자로 — 희박 우세). 밀도에 따라 우세가 갈리는 것이 창발 검증 대상.
- **결합 형성엔 안정화 경로가 필수다**(§6 참조): 2체 직접 결합은 방출 에너지가 갈 곳이 없다 — `접근 → 임시 복합체 → (광자 방출 | 제3체 전달) → 안정 결합`.

| 전이 | 상태 변화 | 비고 | 로드맵 |
|---|---|---|---|
| 들뜸/완화 (충돌) | occ 재배치, K↔U_elec | 승위(C 4가) 포함 | ④ |
| 방출/흡수/유도 방출 | occ↔광자 | 세 채널이어야 복사 세부 균형 | ④⑪ |
| 이온화/전자 획득 | occ↔자유전자(E≥0) | 열적 오르막 허용 (세부 균형) | ⑤ |
| **재결합** | A⁺+e⁻→A+γ (또는 제3체) | 이온화의 역쌍 — 이온화 평형의 반쪽 | ⑤ |
| 전자 이전 (산화환원) | donor occ→acceptor occ | 격자 안정화 포함 검증(§5 비고) | ⑤ |
| 결합 형성/해리 | occ→공유 점유 / 역 | 복합체+안정화 경로 경유 | ⑥ |
| 양성자 이전 | H⁺ 릴레이 (결합 재배열 연쇄) | 물 자동 이온화 포함 | ⑯ |
| 핵 채널 (예약) | α·β±·EC·γ·n 방출 / 분열 / 융합 | 채널별 행 — Q값·운동량 분배·중성미자는 E_escape | ㉒~㉔ |

## 4. 공통 시뮬레이션 원리 — 두 층 실행 + 통계역학 계약

### 4.1 통계역학 계약 (모든 전이가 서명한다)

```
속도       k = ν · exp(−Eₐ / T_국소)                         // 아레니우스
세부 균형   k_정 / k_역 = (g_후 / g_전) · exp(−ΔE / T_국소)    // 축퇴도 포함 — 볼츠만·평형의 근원
오르막 허용  ΔE > 0 전이도 열적 확률로 발생한다                  // "내리막만" 구현 금지
```

여기서 창발하는 것(author 0): 축퇴도 포함 볼츠만 점유(gᵢe^{−εᵢ/T}) · 화학 평형과 K_eq(T) — **평형은 ΔE 가 아니라 자유에너지(에너지 vs 상태 수 = 엔트로피)의 경쟁**이며, 상태 수는 축퇴도·내부 모드(⑦)·부피가 표현한다 · 르샤틀리에 · 아레니우스 반응 속도.

> **볼츠만 검증의 전제 (수정된 이해)**: 자발 방출만 있는 계는 볼츠만이 아니라 바닥 상태로 붕괴한다. 볼츠만 점유는 **충돌 열욕(에너지를 교환하는 충분한 입자 집단)** 또는 **닫힌 복사장(흡수+방출+유도 방출)** 이 있어야 나온다 — ④ 의 닫는 기준이 세 장면으로 갈리는 이유(§9).

### 4.2 두 시계 — 시공간 규모 차이의 실행 구조

| 시계 | 대상 | 방법 |
|---|---|---|
| 빠른 연속 | r, p (힘·운동·결합 진동) | 매 tick Verlet |
| 접촉 이산 | 접촉 조건 전이 (충돌 들뜸·이전·복합체 형성) | 접촉쌍마다 p = 1−exp(−k·dt) 샘플 |
| 느린 사건 큐 | 무접촉·희귀 전이 (자발 방출 수명·붕괴 반감기) | 지수 대기시간 τ = −ln(rand)/k 예약 — tick 폴링 금지 |

- **수치 안정 불변식 (①부터 검증)**: dt 반감 → 통계 동일 · 사건 확률이 프레임률 무관 · 큐/적분 처리 순서가 결과 분포를 바꾸지 않음 · 배속은 시간 단위만 바꾼다.

### 4.3 tick 파이프라인과 닫힌 장부

```
tick: ① 사건 큐 소진 → ② 힘(전 쌍 → 이후 근사) → ③ Verlet → ④ 접촉 전이 샘플 → ⑤ 장부·측정
```

- 전이는 §2 의 통 사이 이동만 — 카탈로그 형식이 장부 닫힘을 강제. **확률 사건 전후 전하·질량·운동량·에너지 차이 ≤ 허용 오차**를 사건 단위로 검사(디버그 모드).
- Σc(총 Z·총 전자[결합+자유]) 정수 비트 불변 · P 잔차 ≤1e-9 · E: Verlet 표류만 허용. 열린 경계는 E_escape 포함해 닫는다.
- 결정론은 요구하지 않는다(트랙 확정 결정 — 같은 seed 재현 검증은 채택하지 않음). 검증은 R회 런의 통계다.

### 4.4 동적 병합 — 수면 승격 (예약: 게이트 G-성능, 로드맵 ⑳)

안정 군집을 강체로 접되, **열역학을 잃지 않는다**:

- **유지하는 내부 상태**: 총질량·질량중심 p·각운동량 + **내부 에너지(U_vib·U_rot 총량)·온도·응력 스칼라·표면 반응 가능 부위 목록**. 내부 격자 진동은 온도로 뭉뚱그리되 열용량은 보존.
- **깨어남 조건**: 경계 충돌 E > 문턱 · 국소 T 상승 · 응력 임계 초과 · 전하 유입 · 표면 반응 요구 · 강한 외부장. 병합은 근사가 아니라 *지연*이다.
- **검증**: 장부 정확 + **병합 on/off 통계 동일성** + 표면 반응률 보존.

## 5. 측정 M

- **구조**: 결합 그래프 연결 성분 → 조성 시그니처 · 수명 τ ≥ τ_stable → 카탈로그. **일시적 복합체와 안정 분자를 수명으로 구분**한다(H₃ 복합체는 존재하되 축적되지 않음 — §9 ⑥).
- **통계**: T(전역·국소) · 점유 분포(gᵢe^{−εᵢ/T} 대조) · **coarse-grained 엔트로피**(조성·점유·공간 분포의 거친 묶음 — 앙상블 평균으로 판정) · K_eq(T) · 스펙트럼(선 위치 = ΔE, 세기 = 점유×전이율).
- **분자**: 쌍극자(부분 전하 합)와 **결합 쌍극자의 구분**(⑭ — CO₂: 결합≠0·분자≈0) · 결합각 분포 · 진동 주파수(동위원소 앵커 ㉑).
- **전자 이전·이온화의 검증 단위는 다입자다**: "고립 Na+Cl 쌍의 즉시 이온화"가 아니라 *충분히 가까운 집합에서 이온(격자) 상태가 중성 상태보다 안정*한가 — 이온화 비용·획득 이득·쿨롱 안정화·격자 에너지의 합이 판정.

## 6. 출력 산출 ⇧ — output.json (S1 의 입력)

- **유효 퍼텐셜 V′(A,B,d)**: 쌍 스윕 × 방위 × M회 평균 힘 → 테이블. 인력 꼬리(분산력 대응)가 *나오는지* + **저온 뭉침 경향의 간이 확인**(상·증발·응축의 본 측정은 S1 몫).
- **내부 상태 요약**: 구조별 u′(전자·진동·회전 평균 에너지) + **열용량 곡선**(⑦의 모드 활성화가 만든 온도 의존 — S1 의 상전이 재료).
- 스키마 초안 (⑩이 확정): species(sig·composition·mass·bindingE·radius·u·heatCapCurve·dipole·meanLifetime·abundance) + potentials(table) + provenance.

## 10. 한계 정직 (알고 감수)

- **유효 근사**: 파동함수·중첩 없음 — 부껍질·허용 그래프·Gamow 는 전부 축약 모델. 목표는 닮음.
- **T_국소 근사**: 비평형 국소계에서 온도 정의가 흔들린다 — ⑧ 이 평형 근방 충분성을 확인, 부족하면 정련.
- **무차원 단위**: 실단위 환산 없음 — 정성 경향(비율·순서·곡선 모양)의 닮음으로 검증.
- **비결정론**: 같은 seed 재현은 검증하지 않는다(트랙 확정 결정) — 재현성은 앙상블 통계로 대신한다.
- **원소 셋 유한**: {H, He, C, N, O, Ne, Na, Al, Cl, Ar, K} 시작 — 추가는 데이터로.
