# S0-atom DESIGN — 원자 단계 상세 설계도

> 이 문서는 **S0 원자 단계의 설계 권위**다. 단계 5원칙·커널 형태·검증 4기둥의 권위는 [../../KERNEL.md](../../KERNEL.md), 현재 위치는 [../../STATE.md](../../STATE.md). 구현이 설계와 어긋나는 발견을 내면 이 문서를 고치고 step 문서에 이유를 남긴다.
>
> **단계 정체 한 줄 (정직한 분류)**: S0 은 *순수한 원자 물리 시뮬레이션*이 아니라 **반응 가능한 하이브리드 입자·상태 시뮬레이션**(유효 원자 모델)이다 — 연속 힘 + 이산 상태 기계의 결합이며, author 는 0이 아니라 *바닥에 국한*된다. 역할은 셋: 상위 세계가 돌릴 **물질 모델(MaterialModel) 생성** · 상위 모델 **검증** · 국소 사건 **판정** (KERNEL·CLAUDE "세계와 엔진의 관계"). 상(고/액/기)의 본 무대는 S1 — S0 은 재료와 판정을 공급한다.
>
> **공통 시뮬레이션 원리 한 줄 (§4 가 권위)**: 세계는 **연속층**(위치·운동량)과 **이산층**(내부 상태의 *전이*) 두 층으로 굴러간다. 모든 이산 현상은 같은 *형식*의 전이지만 속도 법칙(hazard)은 채널별이고, **확률은 전이 여부만 정하며 에너지는 항상 실제 자유도에서 가져온다.**

## 1. 세계 결정

| 결정 | 값 | 이유 |
|---|---|---|
| **차원** | **자료구조는 3D 고정 · 차원은 장면이 정한다** | r·p·힘·이웃 해시·각도 반발 전부 3성분(Vec3). 초기 검증 장면만 **z 동결**(z=0 평면) — 2D 와 3D 는 충돌 단면·확산·결합 위상·상태 밀도가 다르므로 엔진을 2D 로 만들지 않는다. 3D 전환 = 장면의 z 해동(⑬), 코드 구조 변경 0 |
| **원소** | **가상 원소 3~4종으로 시작** | "물리 구조가 창발하는가"와 "실제 화학 수치와 일치하는가"를 분리한다(디버깅 원칙). 실원소 셋 {H,C,N,O,Na,Cl,…} 정합은 ⑩ 수프 관문에서 합류. 단, ③ 준위 함수(levels.js)는 순수 함수라 실원소로 즉시 단위검증 |
| **경계** | 주기(토러스) + 열린/반사 옵션 | 탈출 에너지는 E_escape 통에 회계 |
| **단위** | 무차원, k_B=1 | 목표는 닮음(경향·비율·곡선 모양) |
| **두 시계** | 연속: dt Verlet · 이산: 사건 큐 | §4 |
| **힘 계산** | 처음엔 작은 상자 **전 쌍 계산** → 병목 측정 후 근사 | 장거리 쿨롱 컷오프 왜곡 방지 — 검증 먼저, 최적화는 G-성능 |

## 2. 자료형

```js
atom     = { Z, N /*예약*/, r:Vec3, p:Vec3, occ:{'1s':2,…}, mu:Vec3 /*유도 쌍극자 — ⑧부터*/ }
electron = { r, p }                       // 자유전자 (E≥0 연속상태)
photon   = { E, r, dir, t0 }              // ⑫ 복사장부터 — 그 전엔 통(E_photon)만
bond     = { i, j, order /*연속 결합차수*/, rest:d0, mode:{vib, rot} }
world    = { atoms, electrons, photons, bonds, events(큐), ledger }
```

- **occ 는 부껍질(1s·2s·2p·3s·3p·4s·3d…) 단위** — 축퇴도 g(s=2·p=6·d=10)·파울리·훈트 단순화. 내부 에너지는 Σocc·ε 측정값.
- **에너지 장부 통 (처음부터 분리 — 0 이어도 구조 존재)**: `K_tr + U_int + U_elec + U_bond + U_vib + U_rot + U_pol(분극) + E_photon + E_nuclear(예약) + E_escape`.
- **질량** m(Z) 테이블 (N 도입 시 Σ 회계로 대체).

## 3. V₀ — 바닥 물리의 전부

### 3.1 준위 구조 (재료① — 부껍질·연속상태·결합차수 예산)

```
부껍질: 1s 2s 2p 3s 3p 4s 3d … (Aufbau) · ε(부껍질) = −R·(Z_eff/n_eff)² (차폐)
자유전자 연속상태 E ≥ 0 — 이온화·재결합·금속·이온화 기체의 공통 무대
결합차수 예산 B(원자) — 연속량: 전자 상태 → 사용 가능한 결합차수 총량 → 이웃과 에너지 최소화로 분배
  (예: C≈4 · N≈3~4 · O≈2 · H=1 · 비활성=0)
```

- **정수 슬롯이 아니라 연속 예산이다**: 홀전자 수·2s→2p 승위는 유효 원자가 모델의 *산출 근거*지 물리의 전부가 아니다(실제 분자는 전체 전자 상태가 함께 재구성된다 — 정직). 연속 예산은 공명·부분 결합·다중 결합·배위 결합을 자연스럽게 다룬다. 이온화 E = −ε_최외각 · 전자친화도 = 빈 부껍질 ΔE. 점유 검증은 gᵢe^{−εᵢ/T}.

### 3.2 연속 힘 (재료② — 분극 포함)

```
V_cont = k_c·qᵢqⱼ/(d+s)  +  ε_rep·(σᵢⱼ/d)¹²  +  ½k_b(d−d₀)²[결합]  +  V_pol
분극:  μᵢ = αᵢ·E_국소  (유도 쌍극자 — α 는 원소별 분극률, 바닥 특권 author)
각도 척력: 같은 원자의 전자쌍 방향끼리 공통 반발 (고립쌍 배율>1) — ⑭부터. 분자별 목표각 author 금지
```

- **없는 물리는 측정에서 생기지 않는다 (원칙)**: 중성 입자 사이 인력(분산력)은 동역학에 근원이 있어야 V′ 에 나타난다. 근원 = **분극 자유도**(유도-유도 상관 — 런던 분산의 고전 근사) + 부분 전하(⑮) + 결합. 고전 근사가 부족하면 **C6/r⁶ 잔여항을 정직하게 author** 하는 노브로 보충한다(숨기지 않는다 — Ne 응축·탄화수소 액화의 필요조건).
- **결합은 힘에서 완전 창발하지 않는다 (정직)**: 결합 사건은 이산 상태 기계(카탈로그)가 만들고, 스프링은 그 결과다 — 이것이 "하이브리드"의 뜻이며 ReaxFF 급 반응 힘장보다 단순한 대신 정체를 명시한다.
- **법칙 스택 (step-0033 — 무대 독립 합성)**: 연속 힘 법칙은 장면이 `computeForces` 를 배선해 켜는 것이 아니라 **엔진 스택에 등록**되고(`E.registerLaw({name, rank, active, force})`), 각 법칙은 자신의 물리 입력(종 파라미터 테이블 — 예: `alpha`(⑧)·`Dhb`(⑯))이 세계에 실려 있을 때만 기여한다. `E.stackForces` = `pairForces`(기반·F 초기화·U_elec/U_bond) + rank 오름차순 법칙 기여(F 에 더하기만·반대칭 → P 보존은 각 법칙 몫). **파라미터 부재 = 기여 0 이 그 세계의 물리적 참값** — 중력 `g=0` 과 같은 지위라 기존 장면은 회귀 0 (verify 33 동등성 ≤ 1e-12). 기존 합성 함수(`polForces`·`forcesHB`·`forcesWithAngles`)는 하위 호환으로 유지. 승격 완료: ⑮ qeq(`qeqParams`·stage 'pre' — 전하 갱신이라 기반보다 앞·step-0035: 정수층 qBase=Z−ne + 연속 재분배층·단원자 건너뜀으로 ⑤ 에너지학 보존)·⑧ pol(`alpha`)·⑭ angle(`valence`·step-0034 — 동적 세계용 고립쌍 동기화 + 위상별 기준선 정규화 + 이완-후-평가, geometry.js 주석 참조)·⑯ hb(`Dhb`). ⑰ 용매화·⑲⑳⑫ 는 미승격 (STATE §3).

### 3.3 전이 카탈로그 (재료③ — 형식은 하나, 속도 법칙은 채널별)

```
transition = { 조건, 상태변화(Δocc·Δbond), ΔE, hazard(속도 법칙), 에너지분배, 선택조건(허용 그래프), 안정화경로, 역쌍 }
hazard ∈ { 아레니우스 | 충돌단면 | 복사수명 | 터널링(Gamow) | 확산제한 | 삼체 | 측정유도 }
```

- **에너지분배 필드가 장부 닫힘을 강제한다**: ΔE 가 어느 통에서 나와 어디로 가는지 명세. 충돌 들뜸은 상대 운동에너지 부족 시 *불가*.
- **결합 형성엔 안정화 경로 필수**: `접근 → 임시 복합체 → (광자 방출 | 제3체 전달) → 안정 결합` — 2체 직접 결합은 에너지가 갈 곳이 없다.
- 채널: 들뜸/완화(충돌단면) · 방출/흡수/유도 방출(복사수명) · 이온화⇌재결합·전자 이전(충돌단면+열) · 결합/해리(삼체·복사 안정화) · 양성자 릴레이 · 핵 채널(예약 — 붕괴 α/β±/EC/γ/n·분열·융합[Gamow]).

## 4. 공통 시뮬레이션 원리

### 4.1 통계역학 계약

- **에너지 출처 원칙**: 확률은 전이 *여부*만 정한다 — 에너지는 항상 실제 자유도에서. T_국소 = 주변 자유도에서 그 에너지를 발견할 확률의 요약(에너지 생성자 아님).
- **세부 균형의 계층**: 단일 개체 내부 전이(준위)는 (g후/g전)e^{−ΔE/T} 비율로. **다입자 반응**(병진 상태 수·부피·농도·조합 수가 개입)은 비율 공식이 아니라 **미시상태 샘플링** — 사건이 실제 운동량·내부 상태에서 샘플되고 역과정이 같은 미시 규칙이면 가역성이 평형을 만든다. ΔG 기반 coarse 전이는 S1+ 방식(계층 분리).
- 창발(author 0): 볼츠만 점유·화학 평형(자유에너지 경쟁)·르샤틀리에·아레니우스 속도·coarse-grained 엔트로피의 앙상블 증가 경향.

### 4.2 두 시계 + 수치 불변식

빠른 연속(Verlet) · 접촉 이산(p=1−e^{−k·dt}) · 느린 사건 큐(지수 대기시간 예약). **①부터 검증**: dt 반감 → 통계 동일 · 사건 확률 프레임률 무관 · 처리 순서 무관 · 배속은 시간 단위만.

### 4.3 tick 과 닫힌 장부

`사건 큐 소진 → 힘(전 쌍) → Verlet → 접촉 전이 샘플 → 장부·측정`. 확률 사건 전후 전하·질량·운동량·에너지 차 ≤ 허용 오차(사건 단위 검사). Σc 정수 비트 불변 · P ≤1e-9 · E 는 Verlet 표류만. 결정론(같은 seed 재현)은 요구하지 않는다 — 앙상블 통계로 검증.

### 4.4 동적 병합 — 오차 제한 근사 (게이트 G-성능, ㉑)

- **병합은 지연이 아니라 coarse-graining 이다 (정직)**: 결정 방향·결함·조성 구배·잔류 응력은 복구 불가한 정보 손실. 그래서 검증은 "모든 통계 동일"이 아니라 **관측량 계약**: 보존할 관측량 목록(열용량·평균 반응률·열전도율·표면 반응률·상전이 온도 범위…)을 선언하고 관측량마다 |O_병합 − O_전해상도| < ε_O.
- 유지 상태: 질량·질량중심 p·각운동량·내부 에너지·온도·응력·표면 반응 부위. 깨어남: 충돌 E·T 상승·응력·전하 유입·표면 반응·외부장.

## 5. 측정 M

구조(연결 성분·수명 — 복합체와 안정 분자 구분) · T(전역·국소) · 점유 vs gᵢe^{−εᵢ/T} · coarse-grained 엔트로피(앙상블) · K_eq(T) · 스펙트럼(위치=ΔE·세기=점유×율) · 쌍극자(결합/분자 구분) · 결합각 분포 · 진동 주파수. 이온화 검증은 다입자(격자 안정화 포함).

## 6. 출력 산출 ⇧ — 2단계 (임시 스키마 → MaterialModel)

- **⑪ 임시 승격 스키마 (MVP 배관)**: species(조성·질량·결합E·u′·열용량 곡선) + 쌍 퍼텐셜 테이블 + **coarse-grain → 재해동 왕복 검증**. 목적은 배관 증명이지 물질 충실도가 아니다.
- **㉒ MaterialModel (실제 S1 입력)** — 쌍 테이블은 방향성·밀도 의존·협동 효과(물!)를 잃으므로, 형상·극성·수소결합·분산력(⑬~⑯) 이후에 산출한다:

```
MaterialModel { stateVariables · freeEnergyModel/EOS · transportCoefficients · reactionNetwork
                · phaseTransitions · surfaceRules · fractureRules · refinementConditions(재해석 조건)
                · validRange · errorBounds }
```

이것이 **원자 시뮬과 MMORPG 런타임을 잇는 핵심 산출물**이다 — 서버는 이 모델을 돌리고, refinementConditions 가 "언제 원자 해상도로 내려올지"를 정한다.

## 10. 한계 정직

- **유효 모델**: 파동함수 없음 — 부껍질·예산·hazard 전부 축약. CO·공명·방향족·초과 원자가는 예산 모델의 *경계*에 있다(필요 시 정련).
- **없는 물리는 측정에서 안 생긴다**: 인력의 근원(분극·부분전하·결합)은 동역학에 먼저 있어야 한다. C6 잔여항은 정직한 author.
- **T_국소 근사** (⑨가 확인) · **무차원 단위** · **비결정론**(seed 재현 검증 없음 — 앙상블 통계).
- **가상 원소 우선**: 실세계 수치 정합은 ⑩에서 — 그 전 앵커는 구조 창발이다.
