# S0-atom DESIGN — 원자 단계 상세 설계도

> 이 문서는 **S0 원자 단계의 설계 권위**다. 단계 5원칙·커널 형태·검증 4기둥의 권위는 [../../KERNEL.md](../../KERNEL.md), 현재 위치는 [../../STATE.md](../../STATE.md). 이 폴더(`stages/S0-atom/`)의 모든 구현은 이 설계도를 따른다 — 구현 중 설계와 어긋나는 발견이 나오면 이 문서를 고치고 step 문서에 이유를 남긴다.
>
> **단계 정체 한 줄**: 실세계 원자 원리(껍질·쿨롱·척력·슬롯)를 author 한 유일한 바닥 — 원자 수프를 굴려 **분자가 창발**하고, 그 분자들의 카탈로그 + 유효 상호작용 테이블을 `output.json` 으로 내보낸다(= S1 의 입력).

---

## 1. 세계 결정

| 결정 | 값 | 이유 |
|---|---|---|
| **차원** | **2D** | 결합·화학량론·상분리는 2D 에서도 창발하고, 시각화(원칙④)가 직관적이며 계산이 싸다. 3D 는 격차로 (필요가 증명되면) |
| **경계** | 주기(토러스) | 벽 인공물 없이 닫힌 계 — 장부 검증이 깨끗 |
| **단위** | 무차원 자연 단위 | 길이 1 ≈ 원자 반경 스케일 · 에너지 1 ≈ 결합 에너지 스케일. 실단위 환산은 하지 않는다(닮음이 목표, 재현이 아니라) |
| **시간 적분** | velocity Verlet, dt=0.01(노브) | 에너지 표류가 작은 표준 적분 — 기둥2(닫힌 장부)의 실무 조건 |
| **이웃 탐색** | 균일 격자 해시, 컷오프 r_cut=4 | 국소성(체크 2항)의 구현. O(N) |

## 2. 자료형 — entity 와 결합 간선

```js
atom = { Z, e, r:[x,y], p:[px,py] }        // c=(Z,e). u 는 S0 내에선 0 고정(들뜸·광자 범위 밖 — §10)
bond = { i, j, kind:'cov', rest:d0 }       // 공유 전자쌍의 배치 상태 (동역학 상태 — 창발 아님)
world = { atoms:[], bonds:[], T(측정), ledger }
```

- **결합(bond)은 상태, 분자는 측정**: 결합 간선은 교환 연산 X 가 만드는 *전자 배치 상태*다(커널 서명 안). "H₂O"라는 분자는 코드 어디에도 없다 — 결합 그래프의 연결 성분을 §5 측정이 읽어낼 뿐.
- **질량** m(Z): 주 동위원소 질량수 테이블 `{1:1, 2:4, 6:12, 7:14, 8:16, 10:20, 11:23, 17:35, 18:40, 19:39}` (그 외 fallback 2Z). 핵 동결(KERNEL §5)의 회계적 결과 — N 은 질량으로만 존재한다.

## 3. V₀ — 바닥 물리의 전부 (재료 4종의 수식)

### 3.1 재료① 껍질 함수 (순수 함수 — 주기율표의 근원)

```
shells = [2, 8, 8, 18]                       // 껍질 용량 (파울리 근사)
fill(Z−보정e) → outer(외각 전자 수), cap(그 껍질 용량)
slots(원자)  = min(outer, cap − outer)       // 결합 슬롯 = 원자가
chi(원자)    = outer / cap                   // 전기음성도 근사 (χ)
radius(Z)   = 0.5 + 0.3 × 껍질 수           // 척력 코어 반경 = 시각화 반경 (공용)
```

한 식이 주기율표 뼈대를 전부 낸다 — H: slots=1 · C: 4 · N: 3 · O: 2 · Na: 1(χ=0.125) · Cl: 1(χ=0.875) · He/Ne/Ar: 0. **주기성 assert(세부 단계③)는 이 함수의 출력으로 검증한다.**

### 3.2 재료② 쿨롱 + 재료③ 단거리 척력 (연속 힘 — 모든 쌍, 컷오프 내)

```
q = Z − e                                   // 이온 전하
V_pair(i,j,d) = k_c·qᵢqⱼ/(d+s)  +  ε·(σᵢⱼ/d)¹²      // σᵢⱼ = radiusᵢ+radiusⱼ
```

- k_c=1(노브) · s=0.1 연화(특이점 방지) · ε=1(노브). 힘은 −∇V, 반대칭 자동.
- 중성 원자끼리는 쿨롱 0 — 인력은 결합(3.4)이 담당. 이온이 생기면(3.3) 쿨롱 인력이 *공짜로* 이온결합·격자를 만든다.

### 3.3 재료④-a 전자 이전 (이온화 — 교환 X, 문턱)

접촉(d < σᵢⱼ×1.2) 시:

```
Δχ = χ_acceptor − χ_donor
if Δχ > θ_ion(=0.4 노브) && donor.outer ≤ 3 && acceptor.slots > 0 :  e 1개 이동 (donor.e−−, acceptor.e++)
```

Na+Cl → Na⁺+Cl⁻ 가 나오고 H+O(Δχ=0.25)는 안 나온다. 이전 후 두 원자의 χ·slots 는 재계산(e 가 바뀌었으니) — 이온은 *결과*지 종류가 아니다. 역방향(중성화)은 반대 이온의 고에너지 충돌 시 허용(노브) — 처음엔 꺼둔다(§10).

### 3.4 재료④-b 공유 결합 (교환 X, 문턱)

```
형성: d < σᵢⱼ×1.3 && 양쪽 slots_free ≥ 1 && E_approach < D(우물 깊이, =1 노브)
     → bond 추가, 양쪽 slots_free−−, 방출 D 는 두 원자 운동에너지로 (발열 — §4 회계)
결합력: V_bond = ½ k_b (d − d₀)² − D        // d₀ = σᵢⱼ, k_b=4 노브 (스프링 + 우물)
해리:  결합 신장 에너지 ½k_b(d−d₀)² > D → 간선 제거, D 를 운동에너지에서 회수 (흡열)
```

- **원자가 포화가 공짜로 나온다**: slots_free=0 이면 더 못 붙는다 → H₃ 덩어리 0, H₂O 에서 멈춤 (앵커⑤).
- 결합 세기의 χ 의존(극성 공유) 등 정련은 세부 단계⑤~⑦이 측정으로 필요를 증명할 때만.

## 4. 동역학 — tick 파이프라인과 에너지 회계

```
tick: ① 이웃 해시 재구축 → ② 힘 (쿨롱+척력+결합 스프링) → ③ Verlet 적분
      → ④ 교환 판정 (전자 이전 → 결합 형성 → 해리; 국소·쌍 단위)
      → ⑤ 장부 갱신 · 측정 샘플링
```

**닫힌 장부 (기둥2의 정의)**:

```
Σc: 총 Z(불변 정수) · 총 e(이전은 이동만 — 정수 비트 불변)
P:  Σp — 힘 반대칭 + 교환은 운동량 안 건드림 → 잔차 ≤ 1e-9
E:  K + U_pair + U_bond  (U_bond = Σ_bonds [½k_b(d−d₀)² − D])
    결합 형성/해리 = U_bond ↔ K 이동 (방출 D 는 두 원자에 운동량 보존 배분)
    Verlet 표류만 허용 잔차 (T tick 에 |ΔE|/E ≤ 1e-3, dt 로 조임)
```

## 5. 측정 M — 분자는 여기서 태어난다

- **연결 성분**: bonds + 이온쌍(반대 전하 & d < r_pair, 노브)으로 그래프 → 성분별 **조성 시그니처** `"H2O1"`(원소별 개수 정렬 문자열).
- **수명**: 시그니처×성분 동일성 추적 — τ ≥ τ_stable(=500 tick 노브)이면 *안정 구조* → 카탈로그 등록 (조성·결합 E 합·평균 반경·개수).
- **온도**: T = ⟨p²/2m⟩ (평균 운동에너지). **조성비**: 시그니처별 카운트 히스토그램 (앵커⑦의 지표).

## 6. 출력 산출 ⇧ — output.json (S1 의 입력)

### 6.1 유효 퍼텐셜 측정 프로토콜 (손 튜닝 0 의 실체)

```
카탈로그의 구조쌍 (A,B) 에 대해:
  d 를 d_min..d_max 로 스윕 → 각 d 에서 A·B 를 질량중심 거리 d 로 놓고 (무작위 방위 × M회)
  짧게 굴려 질량중심 간 평균 힘 ⟨F(d)⟩ 측정 → 적분해 V′(d) 테이블
```

반데르발스형 인력 꼬리(유도 쌍극자 — 부분 전하 배치에서 자동)가 *나오는지*가 세부 단계⑧의 앵커다.

### 6.2 스키마 초안 (⑧이 확정)

| # | 현상 (앵커) | 이 step 이 더하는 코드 | 닫는 기준 (R=5 런 통계 + 눈) |
|---|---|---|---|
| ① 무대 | 원자들이 존재하고 움직인다 | engine.js 뼈대(entity·Verlet·해시·장부) + scenes/verify/index.html 뼈대 | Σc 비트 불변 · P 잔차 ≤1e-9 · E 표류 ≤1e-3 · 뷰어에서 떠다님이 보인다 |

## 10. 한계 정직 (알고 미룬 것)

- **2체 결합의 에너지 처리**: 실세계 2체 결합은 제3체/광자가 에너지를 가져가야 안정화된다. 여기선 방출 D 를 두 원자 운동에너지로 직접 배분(운동량 보존) — 결합 직후 재해리 가능성이 실제보다 높다. τ_stable 측정이 걸러낸다. 광자·복사는 S0 범위 밖.
- **u=0 고정**: 전자 들뜸·스펙트럼(빛)은 범위 밖 — 시각화는 물리량(Z·결합·전하)의 직역이지 발광 모사가 아니다.
- **중성화(전자 반환) 꺼둠**: 이온 → 중성 되돌림은 초기 버전에서 비활성 — 필요가 측정되면 노브를 연다.
- **2D**: 3D 입체 화학(CH₄ 정사면체 등)은 표현 불가 — 조성·화학량론 수준의 닮음이 목표. 3D 는 S0 v2 격차.
- **껍질 근사**: d-오비탈·전이금속 없음 — 원소 셋은 {H, He, C, N, O, Ne, Na, Cl, Ar, K} 로 시작.
