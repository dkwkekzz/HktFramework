# S0-atom DESIGN — 원자 단계 상세 설계도

> 이 문서는 **S0 원자 단계의 설계 권위**다. 단계 5원칙·커널 형태·검증 4기둥의 권위는 [../../KERNEL.md](../../KERNEL.md), 현재 위치는 [../../STATE.md](../../STATE.md). 구현이 설계와 어긋나는 발견을 내면 이 문서를 고치고 step 문서에 이유를 남긴다.
>
> **단계 정체 한 줄**: 실세계 원자 원리를 author 한 유일한 바닥 — 원자 수프를 굴려 **분자가 창발**하고, 분자 카탈로그 + 유효 상호작용 테이블을 `output.json` 으로 내보낸다(= S1 의 입력).
>
> **공통 시뮬레이션 원리 한 줄 (§4 가 권위)**: 세계는 **연속층**(위치·운동량 — 힘과 적분)과 **이산층**(내부 상태 — 준위 점유의 *전이*) 두 층으로 굴러간다. 들뜸·이온화·결합·해리·붕괴·융합은 *전부* 같은 형식의 전이 `{ΔE, 장벽 Eₐ, 시도 빈도 ν}` 이고, 전이 속도는 통계역학 계약(아레니우스 + 세부 균형)을 지킨다 — 그래서 볼츠만 분포·화학 평형·엔트로피 증가는 author 하지 않아도 **창발**한다.

## 1. 세계 결정

| 결정 | 값 | 이유 |
|---|---|---|
| **차원** | **2D** | 결합·화학량론·평형은 2D 에서도 창발, 시각화 직관·계산 저렴. 3D 는 로드맵 ㉑ |
| **경계** | 주기(토러스) | 벽 인공물 없는 닫힌 계 — 장부 검증이 깨끗 |
| **단위** | 무차원 자연 단위 | 길이 1 ≈ 원자 반경 · 에너지 1 ≈ 화학 결합 스케일 · k_B=1 (T 는 에너지 단위) |
| **두 시계** | 연속: dt=0.01 Verlet · 이산: 사건 큐 | §4 실행 구조 — 빠른 운동과 느린/희귀 전이(방출 수명·붕괴)를 한 루프에 우겨넣지 않는다 |
| **이웃 탐색** | 균일 격자 해시, r_cut=4 | 국소성의 구현. O(N) |

## 2. 자료형 — 내부 상태는 스칼라가 아니라 *준위 점유*다

```js
atom  = { Z, r:[x,y], p:[px,py], occ:[n₁,n₂,…] }   // occ = 준위별 전자 점유 벡터 (내부 상태의 전부)
bond  = { i, j, nShared, rest:d0 }                  // 공유 준위의 점유 상태 (전이가 만든다)
world = { atoms:[], bonds:[], photons:E_γ(통), events:큐, ledger }
```

- **e(전자 수) = Σocc** — 파생량. **이온**(Σocc≠Z)·**들뜸**(바닥 채움과 다른 occ)·**원자가**(외각 준위의 빈자리)가 전부 *한 벡터의 배치*다. 스칼라 u 는 폐기 — 내부 에너지는 `Σ occ·ε` 로 **측정**되는 파생량이지 저장 변수가 아니다 (승격 시 u′ 로 접히는 것은 이 측정값).
- **결합 = 공유 준위의 점유**: bond 는 두 원자 사이에 생긴 낮은 에너지 준위(결합 오비탈 근사)를 전자가 점유한 상태다. "분자"는 여전히 측정(연결 성분)이다.
- **광자 = 에너지 통**: 방출된 ΔE 의 회계 계정(+파장 히스토그램). 개별 광자 입자는 흡수(⑩)가 요구할 때만.
- **질량** m(Z): 주 동위원소 테이블 `{1:1, 2:4, 6:12, 7:14, 8:16, 10:20, 11:23, 17:35, 18:40, 19:39}` (fallback 2Z). 핵 동결의 회계적 결과.

## 3. V₀ — 바닥 물리의 전부 (준위 구조 + 연속 힘 + 전이 카탈로그)

### 3.1 준위 구조 (재료① — 정적: 모든 이산 현상의 무대)

```
shells = [2, 8, 8, 18]                       // 껍질 용량 (파울리 근사) — occ 의 칸
ε(Z, n) = −R·(Z_eff/n)²                      // 준위 에너지 (수소형 + 차폐: Z_eff = Z − 내부 전자 수)
바닥 상태 = 아래 준위부터 채운 occ            // 초기화 기본값
slots(원자) = min(outer, cap−outer)           // 외각 점유 outer 에서 파생 — 원자가
radius(Z)  = 0.5 + 0.3 × 점유 껍질 수        // 척력 코어 = 시각 반경
```

준위 *에너지 값*이 생기면서 화학 성향이 수치로 창발한다: **이온화 에너지 = −ε_outer** (같은 주기에서 Z↑ → 깊어짐), **전기음성도 = 외각 준위의 깊이** (Cl 의 빈자리가 Na 의 전자보다 깊다 → 이전이 에너지 내리막). 옛 설계의 ad-hoc `χ = outer/cap` 문턱은 폐기 — 성향은 ΔE 가 정한다(§3.3).

### 3.2 연속 힘 (재료②③ — 연속층의 전부)

```
q = Z − Σocc
V_cont(i,j,d) = k_c·qᵢqⱼ/(d+s) + ε_rep·(σᵢⱼ/d)¹² + ½k_b(d−d₀)² [결합 시]
```

k_c=1 · s=0.1 연화 · ε_rep=1 · σᵢⱼ=radiusᵢ+radiusⱼ · k_b=4 (전부 노브). 힘 = −∇V, 반대칭 자동. 중성-중성 인력은 author 하지 않는다 — 결합(전이)과 부분 전하(⑫)가 만든다.

### 3.3 전이 카탈로그 (재료④ — 이산층의 전부: **모든 현상이 이 한 형식**)

모든 이산 사건은 같은 자료형이다:

```
transition = { 조건(국소), Δocc(상태 변화), ΔE(에너지 차), Eₐ(장벽), ν(시도 빈도), 짝(역방향) }
```

| 전이 | 상태 변화 | ΔE | Eₐ | 에너지 통 | 로드맵 |
|---|---|---|---|---|---|
| **들뜸 / 완화** | occ: 낮은 준위 → 높은 준위 / 역 | ε_hi − ε_lo | ΔE (충돌 흡열) / 0 | K ↔ occ·ε | ④ |
| **방출 / 흡수** | 완화하며 광자로 / 광자 먹고 들뜸 | 〃 | 0 (수명 1/ν_rad 사건) | occ·ε ↔ 광자 통 | ④/⑩ |
| **전자 이전** (이온화·산화환원) | donor 외각 e → acceptor 외각 빈자리 | ε_acc − ε_don | 접촉 장벽 (노브) | occ·ε 재배치 (+쿨롱 U 변화) | ⑤ |
| **결합 형성 / 해리** | 원자 외각 e ×2 → 공유 준위 / 역 | ε_bond − (εᵢ+εⱼ), ε_bond = min−D | 형성 낮음 / 해리 = D+신장 | occ·ε ↔ K (발열/흡열) | ⑥ |
| **양성자 이전** (산·염기) | H⁺ 가 결합을 갈아탐 | 준위차 | 장벽 | 〃 | ⑬ |
| **핵 붕괴** (예약) | (Z,N) → (Z′,N′) | Δm·c² | 핵 장벽 (N/Z 로부터) | 핵 통 → K·광자 | ⑲ |
| **핵융합** (예약) | 두 핵 병합 | Δm·c² | 쿨롱 장벽 | 〃 | ⑳ |

새 현상 추가 = **코드가 아니라 카탈로그에 행 추가**. 이것이 "모든 현상을 동일한 방식으로 처리"의 실체다.

## 4. 공통 시뮬레이션 원리 — 두 층 실행 구조 + 통계역학 계약

### 4.1 통계역학 계약 (모든 전이가 서명한다)

```
전이 속도    k = ν · exp(−Eₐ / T_국소)                  // 아레니우스 — T_국소 = 충돌쌍/이웃의 운동 온도
세부 균형    k_정 / k_역 = exp(−ΔE / T_국소)             // 역방향 장벽 = Eₐ + ΔE
```

이 두 줄이 통계역학 *계층*의 전부다 — 나머지는 전부 창발한다:

- **볼츠만 분포**: 준위 점유가 평형에서 exp(−ε/T) 를 따른다 (author 0 — 세부 균형의 정리).
- **화학 평형·질량 작용·르샤틀리에**: 해리 평형 상수 K(T) 가 나온다. 온도를 올리면 평형이 이동한다.
- **엔트로피 증가**: 닫힌 계에서 깁스 엔트로피(§5)가 단조 증가 경향 → 평형에서 멈춤.
- **활성화 에너지·아레니우스 반응 속도**: Eₐ 가 전이의 기본 필드라서 "점화가 필요한 연소"는 별도 기능이 아니라 카탈로그 데이터다.

> **검증 계약**: 매 전이 step 은 ① 정·역 쌍을 *함께* 구현하고 ② 세부 균형 비율을 단위검증하고 ③ 평형 분포가 볼츠만과 닮는지 통계 assert 한다. 이것이 "온도·엔트로피·평형을 연결하는 계층"의 검증 실체다.

### 4.2 두 시계 — 시공간 규모 차이의 실행 구조

원자 운동(빠름) · 화학(중간) · 방출 수명/핵 붕괴(느림~10⁶× 이상)를 한 루프에 우겨넣지 않는다:

| 시계 | 대상 | 방법 |
|---|---|---|
| **빠른 연속** | r, p (힘·운동) | 매 tick Verlet 적분 (dt) |
| **접촉 이산** | 접촉 조건 전이 (이전·결합·해리·충돌 들뜸) | 접촉쌍마다 확률 p = 1−exp(−k·dt) 로 샘플 |
| **느린 사건 큐** | 무접촉·희귀 전이 (자발 방출, 붕괴) | 발생 시각을 지수분포 τ = −ln(rand)/k 로 뽑아 **큐에 예약** — tick 마다 검사하지 않는다 |

- **척도 분리 노브**: 장면이 `dt`·`timeScale`(관찰 배속)을 정한다 — 화학을 보는 장면과 붕괴를 보는 장면은 같은 엔진의 다른 배속이다. 배속 변경 시 k·dt 불변식(속도의 물리 불변)을 verify 가 확인한다.
- 이 구조는 커널 형태의 일부다 (상위 단계도 동일: S1 의 상전이 관찰은 빠른 진동 위의 느린 사건) — KERNEL §3.1.

### 4.3 tick 파이프라인과 닫힌 장부

```
tick: ① 사건 큐 소진 (예약 시각 도달분) → ② 이웃 해시 → ③ 연속 힘 → ④ Verlet
      → ⑤ 접촉 전이 샘플링 (카탈로그 순회) → ⑥ 장부·측정
E = K + U_cont + Σ occ·ε + E_광자 (+핵 통, 예약)
```

- 전이는 통 사이 이동만 (Δocc·ε ↔ K ↔ 광자) — **모든 전이가 장부를 스스로 닫는다** (카탈로그 형식이 강제).
- Σc: 총 Z·총 e(=ΣΣocc) 정수 비트 불변. P: 힘 반대칭 + 전이 무접촉 → 잔차 ≤1e-9. E: Verlet 표류만 허용 (|ΔE|/E ≤ 1e-3/T tick).

## 5. 측정 M — 통계 지표까지

- **구조**: 결합+이온쌍 그래프 연결 성분 → 조성 시그니처("H2O1") · 수명 τ ≥ τ_stable → 카탈로그.
- **온도**: T = ⟨p²/2m⟩ (전역·국소). **점유 분포**: 준위별 occ 히스토그램 (볼츠만 대조용).
- **엔트로피**: S = −Σ pᵢ ln pᵢ (조성 분포 + 점유 분포의 깁스/섀넌 근사) — 증가 경향·평형 정지 assert 용.
- **평형 상수**: 시그니처 농도비 K_eq(T) (해리 평형·질량 작용 대조). **스펙트럼**: 광자 통의 ΔE 히스토그램 (원소 지문).

## 6. 출력 산출 ⇧ — output.json (S1 의 입력)

- **유효 퍼텐셜**: 카탈로그 구조쌍 (A,B) 를 거리 d 스윕 × 무작위 방위 × M회 → 질량중심 평균 힘 → V′(d) 테이블. 반데르발스형 인력 꼬리가 *나오는지*가 앵커 (부분 전하 ⑫ 를 당길 수 있음 — 의존이 명령).
- **내부 상태 요약**: 구조별 u′ = 평균 내부 에너지(진동+점유) + 열용량 근사 (S1 의 온도 응답 재료).
- 스키마 초안 (⑨가 확정):

```json
{ "stage": "S0-atom", "version": 1,
  "species": [ { "sig": "H2O1", "composition": {"1":2,"8":1}, "mass": 18, "bindingE": -2.1,
                 "radius": 1.4, "u": 0.3, "heatCap": 0.1, "meanLifetime": 9999, "abundance": 0.31 } ],
  "potentials": [ { "a": "H2O1", "b": "H2O1", "table": [[d, V], ...] } ],
  "provenance": { "scenes": ["soup-HO"], "runs": 5, "ticks": 20000 } }
```

### 9.1 Part I — 필수 경로 (공통 원리를 세우고 S1 을 연다)

| ② 힘 | 충돌·산란 | §3.2 연속 힘 | 산란 · 장부 유지 · 겹침 0 |
| ③ 준위 | **주기율표 뼈대 + 이온화 에너지 경향** | §3.1 occ·ε(Z,n)·바닥 채움 | slots assert (H1·C4·N3·O2·Na1·Cl1·He0·Ne0) · −ε_outer 가 주기 경향 재현 · Li·Na·K 동족 |
| ④ 전이 엔진 | **원소별 불꽃색 + 볼츠만 분포** | §3.3 카탈로그 실행기 + §4 사건 큐 + 첫 전이쌍(들뜸↔완화·방출) + 광자 통 | 고온 수프: 점유 분포 = 볼츠만 닮음 · 스펙트럼이 원소별로 갈라짐 · 세부 균형 단위검증 · **공통 원리의 부트스트랩** |
| ⑤ 전자 이전 | 소금 | 카탈로그 행 1 (이전 — ΔE 는 준위차에서) | Na:Cl 수프 → ⁺/⁻ → 이온쌍/격자 · ΔE<0 방향으로만 우세 · H:O 는 이전 안 함 |
| ⑥ 결합·해리 | H₂·H₂O·CH₄ + **해리 평형** | 카탈로그 행 2 (형성↔해리 쌍) + 공유 준위 + 연결 성분 측정 | "H2"·"H2O1" 창발 · H₃ 0 (포화) · K_eq(T): 고온일수록 해리 (르샤틀리에) |
| ⑦ 통계 관문 | **평형은 창발한다** | 엔트로피·평형 상수 측정 + 통계 assert 일괄 | 닫힌 계 S 단조 증가→정지 · 점유·조성 평형이 볼츠만/질량 작용과 닮음 · 배속 불변식 |
| ⑧ 수프 관문 | 화학량론 | 혼합 장면 + 조성 히스토그램 assert | 2H:1O → H₂O 최빈 · 조성비 실세계 경향 닮음 (허용 오차 확정) |
| ⑨ 출력 ⇧ | 반데르발스 꼬리 | §6 프로토콜 + output.json | V′(d) 인력 꼬리 *측정* · u′·열용량 포함 스키마 확정 · S1 입력 완료 |

> 에너지 준위(③)와 전이 엔진(④)이 **결합보다 먼저**다 — 결합·이온화가 전이 카탈로그의 *항목*이 되려면 무대가 먼저 서야 한다. ④ 가 공통 원리의 심장이며, 이후 모든 현상 step 은 원칙적으로 "카탈로그 행 추가 + 측정 + 앵커"다.

## 10. 한계 정직 (로드맵에도 없는 것 — 알고 감수)

- **진짜 양자역학 아님**: 준위·점유·전이는 유효 근사 — 파동함수·중첩·터널링 없음. 목표는 닮음이지 재현이 아니다 (터널링 필요 시 — ⑲ 저온 융합 등 — Eₐ 확률 보정으로 근사).
- **T_국소의 근사**: 아레니우스의 T 는 충돌쌍/이웃 운동 온도 — 비평형 국소계에서 온도가 잘 정의되지 않는 순간이 있다. 평형 근방 검증(⑦)으로 충분함을 확인하고, 부족이 측정되면 정련.
- **무차원 단위**: 실단위 환산 없음 — 앵커는 정성 경향(비율·순서·곡선 모양)의 닮음으로 검증.
- **원소 셋 유한**: 시작 {H, He, C, N, O, Ne, Na, Cl, Ar, K} — 추가는 데이터로 (코드 불변이 원칙의 증명).
