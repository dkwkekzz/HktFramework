## 발견 (한계 정직)

1. **유한 N T 요동 → 정확 T0 재척도** — 20 분자 맥스웰 씨앗은 T 가 ±27% 요동(측정 0.63 vs 0.5)했다. 무대 씨앗은 결정적이어야 하므로 COM 제거 후 정확 T0 로 재척도(dof = 3N−3). S0-①은 큰 N/창으로 넘겼지만 S1 은 분자 수가 작아(20) 재척도가 정직.
2. **①은 힘 0 — 유효 퍼텐셜은 로드만** — `input.pairPotential`(반데르발스 인력 꼬리)은 world 에 실려 있으나 ①에선 안 쓴다. ②(응집)이 이 테이블을 힘으로 켜서 액적을 창발시킬 몫 (S0 arc ①무대→②힘 과 동형).
3. **분자는 점입자 (내부 자유도 정적)** — u.T_int 는 저장만·내부 진동/회전 동역학은 없다. S1 은 분자를 강체 점으로 다룬다(⑦ 내부 모드의 S1 판·상전이 잠열은 후속). 무대엔 충분.
4. **input.json 정본·뷰어 인라인 스냅샷** — file:// 는 JSON fetch 불가라 index.html 이 같은 JSON 을 `<script type="application/json">` 로 인라인. input.json 이 정본, 인라인은 뷰잉 편의. node(verify)는 input.json 직접 require.

## 쉽게 풀어 쓴 설명

지금까지(S0)는 **원자**를 시뮬레이션했다. 원자들이 부딪치고 결합해 물 분자(H₂O) 같은 **안정한 묶음**이 생겼고, S0 는 그 묶음 목록을 `output.json` 으로 내보냈다. 이번 단계(S1)는 그 파일을 **입력으로 받아**, 이제 분자 하나하나를 **점 하나(개체)로** 다룬다 — 원자 20×여러 개가 아니라 "물 분자 7개, 수소 분자 5개, …" 20개의 개체로.

핵심은 **규칙을 새로 만들지 않았다**는 것이다. 개체의 자료형은 원자 때와 똑같은 `{정체, 위치, 운동량, 내부상태}` 이고, 달라진 건 코드가 아니라 *입력 데이터*뿐이다. 분자의 "정체"는 그것을 이루는 원자 개수(O 몇 개·H 몇 개), "내부상태"는 원자들이 결합하며 접힌 에너지와 **온도**다 — 원자들의 자잘한 흔들림이 분자 하나의 온도로 접힌 것("온도의 탄생").

이번 무대에선 분자끼리 아직 힘을 주고받지 않는다(자유 비행). 대신 **장부가 정확히 닫히는지**(원자 총수·운동량·에너지 보존), **입력을 제대로 소비했는지**(Σc = S0 가 넘긴 원자 수와 일치)를 확인했다. 다음(②)에 S0 가 측정해 넘긴 분자 간 인력을 켜면 물방울처럼 **뭉치는 현상**이 나올 것이다.

**뷰어 확인**: `stages/S1-molecule/index.html` 을 브라우저로 연다. 20개의 공이 상자 안을 자유 비행 — 빨간색이 진할수록 O 비율이 높고(물 분자), 흰색은 H 분자, 크기는 질량. 드래그로 3D 회전. 패널에 장부 total 이 불변으로 유지되고 Σc={O:16,H:32}·분자종 목록이 뜬다. (이 환경에선 브라우저 확장 미연결 → node 로 뷰어가 읽는 상태[N=20·T·total 불변·위치 상자 내]를 확인.)
