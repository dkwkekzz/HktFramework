# step-0123 — 보상 발행 (abortPublish · svc.exchange.aborted)

> 직전: [step-0122](step-0122.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md)
> 코드는 단일 소스 `src/`(제자리 수정) · 직전 동결 스냅샷 `baseline/` · reg 는 src vs baseline 비트 대조.

## 검증 질문

0122 의 abort(보상 롤백)는 거래소 내부 회계(`aborted`)로만 굴러 외부에서 안 보인다 — audit·시세 피드가 phantom 매물 롤백을 관측 못 한다. 0111 cancelled·0115 expired 발행과 같은 매핑으로, 보상 성립을 `svc.exchange.aborted` 로 1회 발행해 무수정 소비자가 관측할 수 있는가가 질문. 채우는 계약: SPINE 계층3 거래소 *수명주기 발행*의 4번째 — sold(0108)·cancelled(0111)·expired(0115)·**aborted**(이 step)로 매물의 모든 종결 경로가 버스로 관측된다(0016 발행자 무수정 소비자 패턴).

## 1. 6계층 지도 ([SPINE.md](SPINE.md) §6)

| 계층 | 이번 step |
|------|-----------|
| 게임 서비스 | **거래소 ExchangeService** — abort 성립 시 `svc.exchange.aborted{id,seller,item,price}` 1회 발행(delete 전 listing 캡처) |
| 이벤트 버스 | `svc.exchange.aborted` 토픽 추가 — audit 가 구독(`abortPublish` ON 일 때만 subs 추가) |

## 2. 메커니즘 — 보상 발행 (abortPublish; OFF → baseline 비트 동일)

- **발행 지점**: 0122 의 abort 블록에서 `listings.delete` *전* listing `l` 캡처 → `abortPublish && bus` 면 `svc.exchange.aborted{id, seller:l.seller, item:l.item, price:l.price}` 발행, `abortPublished++`.
- **구독**: `topo-build` 가 `audit && exchange && abortPublish` 면 `['svc.exchange.aborted','audit']` subs 추가.
- **OFF 플래그**: `abortPublish` 기본 false. OFF·bus 부재면 발행 0·subs 미추가 → 0122 비트 동일. reg 시나리오엔 거래소 OFF → 무영향.
- **직교성**: 발행은 *관측*만 더한다 — 보상 자체(2-서비스 일치·conserved)는 발행 ON/OFF 무관(open==escrow 불변).

- **보상이 관측 가능**: ON 이면 abort 가 `svc.exchange.aborted` 로 1회 발행돼 audit 가 관측(`abortPublished 1`·audit 1). OFF 면 발행 0·미관측.

2. **결정론 코어** — 발행은 결정론 메시지. 월드 상태 무관.

4. **은닉·단일 연결** — 발행은 버스 pub/sub(0016). audit 가 발행자 무수정으로 구독. 클라 비가시.

## 9. 의외의 발견 / 정직한 한계

- **수명주기 발행 4종 대칭**: 0107 거래소의 매물은 4가지로 닫힌다 — 체결(sold)·취소(cancelled)·만료(expired)·보상(aborted). 각각 발행 토픽이 1:1 로 대응(0108/0111/0115/0123). aborted 만 *실패 경로*(나머지는 성공 종결) — 무효 매물의 회계 정직성을 외부에 드러낸다.
- **한계 — aborted 시세 피드 미반영**: MarketFeed(0112)는 sold/cancelled/expired 를 구독하나 aborted 는 *미구독*(여기선 audit 만 구독). aborted 는 *애초에 escrow 진입 실패*라 시세(거래량/깊이)에 영향 없음 — 그래서 시세 피드엔 불필요(취소/만료와 달리 실물이 없었다). audit(관측·정직성)만 구독이 옳다. 시세 피드 반영이 필요해지면 후속.
- **한계 — list leg 한정**: 발행도 0122 와 같이 list leg abort 만. buy leg 역보상(후속)이 생기면 그 발행 형태는 별도(체결 롤백 ≠ 매물 회수).
