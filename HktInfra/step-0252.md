## 한 일 (delta)

- 박스 `src/cache.js` — `cacheWriteThrough{on}` 토글 추가(0226 cacheLruTouch 동형). 계층: 데이터(캐시). OFF 플래그 `writeThrough`(미설정→소스 무변경=0226 비트 동일).
- 메커니즘: writeThrough ON 이면 `_set` 이 캐시(store) 외 backing source(SSOT 더미·DB)에도 동시 기록(`source.set`·writeThroughs++). → 무효화(0212) 후 read-through(0206)가 *최신* 값을 재적재(OFF 면 소스 미갱신 → stale 재적재).
- verify.js 새 모드 `cachewt`(CacheStore 직접 구성·onMsg 구동).

## 검증 (수치 = `node run.js` / `node run.js spine` 출력)

- reg: ALL OK(cacheWriteThrough 미수신·writeThrough=false → 비트 동일).
- `cachewt`(가설): 5/5 — WT ON: set k=v2→invalidate→get = **v2**(소스 정합)·writeThroughs 1. WT OFF(대조군): 같은 시퀀스 → get = **v1**(stale·소스 미갱신).
- spine: ALL OK(누적 회귀 + cachewt 편입).
