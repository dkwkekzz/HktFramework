# step-0092 — 파티 ack 타임아웃 포기(partyAckGiveup·N-of-M 종결)

> 직전: [step-0091](step-0091.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md)
> 코드는 단일 소스 `src/`(제자리 수정) · 직전 동결 스냅샷 `baseline/` · reg 는 src vs baseline 비트 대조.

## 검증 질문

0088 의 파티 ack 집계는 `delivered==routed`(모든 up 멤버 ack)면 `acked` 로 종결한다. 하지만 *일부 멤버 전달이 영영 실패*(수신측 사망·손실)하면 `delivered < routed` 에서 `acked` 가 영영 false 로 *매달린다* — 파티 전송에 종결 상태가 없다(0088 §9). 0078 의 전달 재시도 상한(`deliverMaxRetries`→포기·`undeliverable`)은 *개별 전달* 차원이지 파티 차원이 아니었다. 파티 N-of-M 부분 전달을 *명시적으로 종결*할 수 있는가? SPINE 계층3·5 전달 신뢰의 파티 종결.

## 2. 메커니즘 — 멤버 전달 포기의 파티 귀속 (플래그 OFF → baseline 비트 동일 = 회귀 0)

**관찰**: 0078 의 give-up 분기(onTick, `tries >= deliverMaxRetries` → `undeliverable++`)는 inflight 엔트리를 버린다 — 그 엔트리에 이미 `party` 가 실려 있으나(0088), 파티 원장은 그 포기를 모른다.

**구현** (`src/svc-whisper.js`): `partyAckGiveup` ON 일 때
- `_partyOpen` 원장에 `failed: 0` 추가(0088 의 `delivered` 옆).
- give-up 분기에서 `_partyFail(e.party)` 호출 — 그 파티 `failed++` + `partyGiveups++`. 비-파티·OFF 면 no-op.
- `partyIncomplete(partyId)` = `done && delivered + failed === routed && failed > 0` — 모든 routed 멤버가 ack(delivered) 또는 포기(failed)로 귀결 + 실패 1↑ → *부분 전달 종결*. 0078 포기의 파티 N-of-M 판.

`partyAckGiveup OFF` 면 포기를 파티에 귀속 안 함·`failed` 불변(0) = 0091 비트 동일. `undeliverable` 자체(0078)는 양쪽 불변.

## 4. 척추 체크 5항

① **신성한 tick** — give-up 귀속은 라우터 onTick 제어 평면, 존 tick 밖 순수 반응형. ② **결정론 코어** — 세계 쓰기 무변경(minted ON==OFF). ③ **권위 단일 소유** — failed 는 파티 원장 회계(전달 권위 무관). ④ **은닉·단일 연결** — 파티 원장은 라우터 내부. ⑤ **headless·원격 검증** — `node run.js`·`spine` 수치 증명, UE 0.

## 9. 의외의 발견 / 정직한 한계

- **발견**: 파티 전송은 이제 *세 종결 상태*를 갖는다 — `done`(라우팅 결정·0083)·`acked`(전원 실수신·0088)·`incomplete`(일부 영구 실패·0092). 분산 1:N 전송의 생애가 "결정→확인→(부분)실패 종결"로 완결됐다. mbox(수신함 보유)는 ack 하고 ranking(수신함 없음)은 포기되는 비대칭이 *멤버별 수신 능력 차이*를 그대로 종결에 반영한다 — 0088 §9 가 지적한 "Mailbox 없는 up 멤버" 문제의 종결 측 답.
- **한계**: incomplete 는 *종결 상태*일 뿐 *복구*가 아니다 — 실패 멤버에 대한 재라우팅·대체 전달(예: 0061 spawnReplace 의 전달 판)은 미적용. 또한 incomplete 를 *발행*(svc.party.incomplete→audit)해 운영 평면이 보게 하는 것은 후속(0082/0087 발행의 파티 판). 멤버별 Mailbox 토폴로지(0088 §9)가 서면 acked 의 의미가 완전해진다.
