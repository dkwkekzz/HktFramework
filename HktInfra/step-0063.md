## 검증 질문

0060 §9 는 프레즌스 발행의 반응자로 *모니터링 대시보드 · 대체 spawn · 알림*을 예고했다. 0061(활성화)+0062(reconstruct)가 *대체 spawn*(행동)을 완성했다면, 이 step 은 *모니터링 대시보드*(관측)를 더한다 — `svc.presence` 를 구독해 소비자별 *건강 상태 기계*(현재 down/up/permanent + 전이 회계)를 유지하는 구조적 읽기 모델(SPINE 계층 5 세션/프레즌스의 "누가 지금 어디에/어떤 상태인가" 관측 면). audit(0016)이 토픽별 *수*만 세는 범용 sink 라면, presmon 은 프레즌스 특화 *상태 기계*다. 닫는 조건: ⒜ `presenceMonitor=0` 이면 0062 비트 동일(박스·구독 0·reg 0) ⒝ 치유 시 ranking 상태 'up'·down 1·up 1 / 영구 분실 시 'permanent'·down 1·perm 1 ⒞ events==발행(무손실 관측) ⒟ OFF 면 presmon 없음 ⒠ 발행자·기존 소비자 무수정·비-침습.

## 2. 메커니즘 — 프레즌스 상태 기계 읽기 모델 (presenceMonitor OFF → baseline 비트 동일 = 회귀 0)

새 박스 `svc-presence-monitor.js`(PresenceMonitor) — 존 tick 밖 *순수 관찰형*(onTick 없음·`net.send` 0 = 비-침습 구조적). `svc.presence` 의 `{kind, consumer}` 를 소비해 소비자별 `state`(현재 상태) + `downCount`/`upCount`/`permCount`(전이 회계) + `events`(누적)를 유지. 마지막 전이가 현재 상태(down→up→permanent 순서대로 덮어씀).

토폴로지는 `presenceMonitor && presencePublish` 일 때만 `presmon` 액터 + `['svc.presence','presmon']` 구독 행을 더한다 — *발행자(orch)·기존 소비자(audit·ranking2) 무수정으로*(0016 decouple). `presenceMonitor=0` 이면 액터·구독 미추가 → NET 비트 동일. 닿는 박스: `svc-presence-monitor.js`(새 박스)·`net-core.js`(require 1줄)·`topo-build.js`(액터·구독·makeActor)·`topology.js`(결과 노출). 순수 관측·원장 권위 불변.

## 9. 의외의 발견 / 정직한 한계

- **같은 신호, 두 종류 반응자 — 행동 vs 관측**: 0061 의 ranking2(대체 spawn)는 svc.presence 의 'permanent' 에 *행동*(자기 활성화)했고, 0063 의 presmon 은 같은 토픽의 모든 kind 에 *관측*(상태 기계)한다. 0060 이 건강 판정을 *발행 신호*로 외재화한 덕에, *행동 반응자*와 *관측 반응자*가 서로를·발행자를 모른 채 같은 신호에 공존한다(0016 decouple 의 제어 평면 판). 새 반응자(알림·자동 스케일러)도 발행자 무수정으로 계속 얹힌다.
- **audit vs presmon — 추상 수준의 분화**: 둘 다 svc.presence 를 듣지만, audit 은 *범용 sink*(토픽별 수·디버그 다이제스트)이고 presmon 은 *도메인 특화 읽기 모델*(소비자별 상태 기계). 같은 이벤트 스트림 위에 *다른 투영*이 공존한다 — CQRS 의 "한 이벤트 로그, 여러 읽기 모델" 원리. 미래엔 presmon 이 "누가 어디에" 쿼리(세션/프레즌스 SSOT)의 읽기 면이 된다.
- **마지막-전이=현재-상태의 한계**: presmon 의 state 는 *마지막 전이*로 덮어쓴다(down→up→permanent). 동시·역순 도착(버스 재정렬)이면 상태가 흔들릴 수 있다 — 현재 svc.presence 는 단일 발행자(orch)·순서 보존 경로라 안전하나, 다중 발행자/분산 버스에선 전이에 논리 시각(epoch)을 실어 LWW(last-writer-wins by epoch)로 정렬해야 한다(후속·비동기 결정론 §3 격차와 연결).
