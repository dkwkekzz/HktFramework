# step-0044 concepts — Multi-Consumer Min-Watermark (Pruning a Shared Replay Buffer Safely)

> 정식 기록: [step-0044.md](step-0044.md) · 현재 위치: [STATE.md](STATE.md)

## 개념 한눈표

| 개념 | 한 줄 정의 | 이 step 에서의 위치 |
|------|-----------|---------------------|
| 공유 replay 버퍼 | 한 producer(가방)가 *여러 소비자*에게 보낸 결과를 보관해 failover 시 재발행하는 버퍼(outBuffer) | 가지치기의 대상 |
| 소비자 frontier | 한 소비자가 *확인(중계/소비)한* 최대 outSeq | 각 소비자가 ack 로 통보 |
| min-워터마크 | *모든 기대 소비자 frontier 의 최소* — 버퍼를 이 선까지만 가지친다 | 가장 뒤처진 소비자 보존 |
| 소비자 dedup(멱등 재소비) | 같은 결과가 재발행×live 로 2회 와도 outSeq frontier 로 1회만 적용 | 랭킹(±카운트)의 멱등화 |
| 비대칭 복구 | 소비자들이 *서로 다른 시각*에 재구독/복구 | min-워터마크 필요성의 원천 |

## 1. 문제 — 단일 워터마크는 "한" 소비자만 본다

0041 은 결과 버퍼(outBuffer)를 *자기-크기조정*했다: 결과 소비자(게이트웨이)가 중계한 outSeq 를 ack 하면, 가방이 그 워터마크 이하를 가지친다. 정상 구간엔 버퍼가 0 으로 drain, gap 구간엔 자동 성장 — K 추정 없이 무손실. 

그러나 `svc.item.out` 은 게이트웨이만의 것이 아니다 — **RankingService**(0019, 발신하는 둘째 소비자)도 같은 스트림을 먹는다. 0041 의 워터마크는 *게이트웨이 하나*에만 키잉됐다. 두 소비자가 **lockstep**(같은 시각 복구)일 땐 문제없지만(0041 rankDesync 0), 한 소비자가 **늦게** 복구하면 — 게이트웨이의 ack 가 버퍼를 가지친 *뒤*에 랭킹이 돌아오면 — 랭킹의 정확 복구를 못 받친다. 0041 §9 ① 이 이 한계를 명시했다.

## 2. 해법 — 최소(min)까지만 가지치기 + 소비자 멱등

상수 한 줄의 일반화다: **단일 워터마크 → 모든 소비자 frontier 의 최소(min)**.

- **각 소비자가 1급 ack 발신자**: 게이트웨이뿐 아니라 랭킹도 `svc.item.out.ack{outSeq, consumer}` 로 자기 frontier 를 통보한다. 가방은 `consumerWm`(소비자→frontier) 맵을 들고, 가지치기 선을 `min(모든 기대 소비자 frontier)` 로 잡는다. 미-ack 소비자는 -1 로 쳐 min 을 멈춘다 → *아무도 굶지 않을 때까지* 보존.
- **소비자 dedup**: 보존된 버퍼를 늦은 소비자에게 재발행(resendOut)하면, 그 결과가 live 배달과 *겹칠* 수 있다. 게이트웨이→클라 belief 는 Set 이라 멱등(0036)이지만, 랭킹은 ±카운트라 멱등이 아니다 → `outFrontier`(소비 확인 outSeq)로 *재배달을 폐기*해 이중 적용을 막는다. 이로써 랭킹도 게이트웨이처럼 *멱등한* 버퍼 소비자가 된다.

두 메커니즘은 **함께라야** 정확하다: 보존만 있고 dedup 이 없으면 재발행×live 가 이중 적용되고(over), dedup 만 있고 보존이 없으면 더 뒤처진 소비자가 굶는다(starve). 그래서 한 조각으로 묶었다.

## 3. 어떻게 검증했나 — 비대칭 복구의 대조

`rankRenegAt`(16)이 랭킹 재구독을 게이트웨이(14)보다 늦춘다(비대칭). 그러면:
- **single**(busMinWm OFF=0043 동작): 게이트웨이 ack 가 [14,16] 버퍼를 가지친 뒤 늦은 랭킹이 재발행을 받아 — dedup 0 이라 — 이중 적용(투영 over 6 ≠ 원장). `rankProjectionFaithful`=**F**.
- **min**(busMinWm ON): 랭킹 frontier 가 min 을 눌러 버퍼 보존(peak 24→36) + dedup 으로 멱등 → 투영==원장. `rankProjectionFaithful`=**T**.

전 시드에서 F/T 가 갈리고 원장은 자기-정합을 유지한다. `busMinWm=0` 이면 0043 비트 동일(reg) — 새 경로는 전부 플래그 뒤에 잠든다.

## 한 줄 요약

여러 소비자가 공유하는 결과 replay 버퍼를, *모든 소비자 frontier 의 최소(min)*까지만 가지치고(가장 뒤처진 소비자 보존) 소비자 outSeq dedup(재배달 멱등)을 더해 — 늦게 복구하는 둘째 소비자(ranking)도 *정확히* 따라잡게(투영==원장) 한 조각. 0041 단일 워터마크(§9 ①)의 다중 소비자 일반화.
