step-0010 — 프로세스 경계 현실화: 인메모리 큐 → 실 프로세스/IPC

0001~0009 는 전 서버를 *단일 Node 프로세스 내 액터*로 두고 인메모리 큐로 통신시켜 netcode 프로토콜·토폴로지를 헤드리스로 증명했다. 이 step 은 그 host 태그 경계를 실 프로세스 경계(child_process IPC = 직렬화 메시지)로 갈아끼운다 — 각 서버 박스가 별 OS 프로세스이고 공유 메모리 0, 통신은 직렬화 IPC 메시지뿐. broker 가 lockstep 배리어로 전역 발신 순서를 보존해 멀티프로세스 실행이 인프로세스와 비트 동일(E2E 동치)이다. 아래 그림은 각 박스=프로세스, 선=프로세스 경계를 넘는 IPC(굵기=메시지 수)다 — ✝사망 존·▲승격 추종자. 검증은 node verify.js 한 줄(원격에서 전 프로세스 기동→ALL OK). 상세: step-0010.md.
