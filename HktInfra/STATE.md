## 2. NEXT — step-0003 가설 (후보, 권위는 이 절)

**전송 모델(지연·손실·재정렬) 도입 + 타이밍 비결정 아래 존 결정론·복제 사슬 정렬 재증명 — "타이밍은 비결정이어도 존 상태는 결정론"을 격리 증명한다.**

step-0001~0002 는 *무손실·즉시* 행복 전송 위에서만 섰다(0001 §8.1·0002 §8.1, 누적 백로그). 가장 load-bearing 한 다음 한 조각: `Net` 에 지연·손실·재정렬 모델을 더하고 — ① 존 onTick 의 intent 적용이 *결정론적 입력 순서화*(도착 tick 이 흔들려도 시드·로그 동일이면 같은 해시)를 지키는지 ② 0002 의 추종자 사슬 정렬(0002 §7①)이 1-tick 지연 아래 desync 0 을 유지·회복하는지를 본다. "타이밍은 토폴로지의 함수, 내용만 시드의 함수"(0001 §7①)가 깨지는 첫 지점이자 복제·뷰 강건성의 토대.

**검증할 것**: ① **회귀 0** — 전송 모델 항 off(지연=0·손실=0) 시 step-0002 골든 비트 동일(reg 기준선: 42→0x053b46c7/0xf6bf5bb3 · 7→0xa3d9fc76/0xb9bd47b9 · 1234→0xb95e74f5/0x12a3ba6a · 99→0x61382ec8/0x05b378fb · 2026→0x6d49a41a/0x14eb17b1) ② **결정론 전파** — 타이밍 비결정 아래서도 시드·로그 동일이면 존 최종 상태·해시 동일(타이밍 ↔ 상태 결정론 분리) ③ **수렴** — 권위·추종자 desync 0 유지·회복 ④ **가설** — 지연/손실 계수를 켜면 메시지 수량 동일성은 깨지되 상태 해시는 불변임을 수치로.

> 대안 한 조각(전송 모델 대신): **AOI(범위 좁힘)** — 뷰가 전체 상태(0001·0002)인 걸 클라 근방만으로(씨앗 `HktGridRelevancyComponent`). 전송 모델이 더 토대적이라 우선 후보로 둔다.

**병행 백로그(블로킹 아님)**: ⬜ 추종자 승격(failover, 0002 §8.3) · ⬜ N-추종자 팬아웃(0002 §8.5) · ⬜ 다중 클라/엔티티 intent 인터리빙(0001 §8.6·0002 §8.4) · ⬜ 존 배정 로직(zone1 고정 해소) · ⬜ 복제 탭을 게이트웨이→버스로 이전(0002 §8.2) · ⬜ 서버간 인증/버스(0001 §8.3) · ⬜ 재접속·티켓 만료(0001 §8.5) · ⬜ 시각 관찰 셸.

**빌드 인프라**: 한 step = `net-core.js` + `verify.js` (+선택 셸). 공통 하니스(`Net`·VM 스텁·시드 PRNG·FNV 해시) `engine/` 추출은 아직 보류 — 2 step·코어 중복 경미(0002 §9). 3번째 코어(0003)가 같은 중복을 또 낳으면 그때 추출 판단. step-0003 출발 템플릿은 `step-0002/net-core.js`.

## 4. DURABLE CONSTRAINTS — 모든 step이 지킬 정전(canonical) 사실

> 여러 step이 반복 참조하는 불변. 새 step은 이걸 어기면 척추에서 벗어난 것 — 재설계.

- **회귀 0**: 새로 더한 항을 끄면(플래그=0) 직전 step과 **비트 단위 동일**(verify `reg`, maxDiff=0).
- **신성한 tick**: 존 시뮬 tick 안에 시뮬 외 작업(동기 I/O·인증·트랜잭션·팬아웃) 금지 — 전부 비동기 서비스/버스 경유.
- **결정론 코어**: 세계 상태의 쓰기 경로는 intent→HktCore 하나. 같은 시드·로그 → 같은 해시. **`Math.random` 금지, 시드 의사난수만.**
- **권위 단일 소유**: 모든 상태 조각의 쓰기 권위는 정확히 한 곳(매 tick 소유자=1). 이동은 release+acquire **쌍 거래**/트랜잭션.
- **은닉·단일 연결**: 클라는 게이트웨이만 안다. 서버간은 버스/명시 인터페이스만 — 타 서버 내부·DB 직접 접근 금지.
- **수렴(desync 0)**: 클라 예측 뷰는 권위 재현으로 수렴. 겹친 뷰의 참여자는 조정 후 일치.
- **복제 = 재현, 상태 전송 아님**: `(seed+params+intent 로그)` 가 기본. 전체 스냅샷은 late-join·복구의 최후 수단.
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **HktGameplay 원칙 상속**: HktCore 순수성(UObject 0) · 서버 권위(클라 읽기전용) · ISP 3-Layer · `SetPropertyDirty` 경유. 인프라는 *확장*하되 *깨지 않는다*.
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가. 새 코어는 직전 코어를 잇고 박스/계약 하나만 더한다.
