## 2. NEXT — step-0002 가설

**존 결정론 복제 — 같은 intent 로그를 두 존 인스턴스(권위·추종자)에 공급하면, 상태 바이트를 한 번도 전송하지 않고 두 인스턴스가 매 tick 같은 해시에 도달한다 — "복제 = 상태 전송이 아니라 입력 재현"의 격리 증명.**

step-0001 의 det 는 *같은 프로세스의 자기 재현*이었다(0001 §8.2). MMO 월드 계층의 토대 전제 — `(seed+params+intent 로그)` 만 흘리면 수신자가 권위와 같은 상태를 재구성한다(저대역 복제) — 를 골격 위에서 격리 증명한다: 게이트웨이(또는 중계 박스)가 존으로 가는 intent 스트림을 추종자(follower) 존 인스턴스에 *그대로 복사*하고, 두 인스턴스의 해시 사슬이 전 구간 일치함을 본다.

**검증할 것**: ① **전파** — 권위·추종자 매 tick 해시 사슬 일치(전 시드) ② **회귀 0** — 복제 플래그 off 시 step-0001 골든 해시와 비트 동일(reg 기준선: 42→0x053b46c7/0xf6bf5bb3 · 7→0xa3d9fc76/0xb9bd47b9 · 1234→0xb95e74f5/0x12a3ba6a · 99→0x61382ec8/0x05b378fb · 2026→0x6d49a41a/0x14eb17b1) ③ 은닉·권위 보존 유지(추종자는 권위 0 — 읽기 전용 재현) ④ 가설 — 상태 전송 0 바이트 계측으로 동일 상태 도달.

**병행 백로그(블로킹 아님)**: ⬜ 전송 모델(지연·손실·순서) — 0001 §8.1, 타이밍 비결정 아래의 결정론 재검증 포함 · ⬜ 다중 클라 intent 인터리빙(0001 §8.6) · ⬜ 존 배정 로직(zone1 고정 해소) · ⬜ 서버간 인증/버스(0001 §8.3) · ⬜ 재접속·티켓 만료(0001 §8.5) · ⬜ 메시지 직렬화 포맷 · ⬜ 시각 관찰 셸.

**빌드 인프라**: 한 step = `net-core.js` + `verify.js` (+선택 셸). 공통 하니스(액터/메시지큐 `Net`·VM 스텁·시드 PRNG·FNV 해시)는 초기 몇 step 뒤 `engine/` 한 곳으로 모은다(0002 가 0001 코어를 잇는 첫 사례 — 복제 시점 판단). step-0002 출발 템플릿은 `step-0001/net-core.js`.

## 4. DURABLE CONSTRAINTS — 모든 step이 지킬 정전(canonical) 사실

> 여러 step이 반복 참조하는 불변. 새 step은 이걸 어기면 척추에서 벗어난 것 — 재설계.

- **회귀 0**: 새로 더한 항을 끄면(플래그=0) 직전 step과 **비트 단위 동일**(verify `reg`, maxDiff=0).
- **신성한 tick**: 존 시뮬 tick 안에 시뮬 외 작업(동기 I/O·인증·트랜잭션·팬아웃) 금지 — 전부 비동기 서비스/버스 경유.
- **결정론 코어**: 세계 상태의 쓰기 경로는 intent→HktCore 하나. 같은 시드·로그 → 같은 해시. **`Math.random` 금지, 시드 의사난수만.**
- **권위 단일 소유**: 모든 상태 조각의 쓰기 권위는 정확히 한 곳(매 tick 소유자=1). 이동은 release+acquire **쌍 거래**/트랜잭션.
- **은닉·단일 연결**: 클라는 게이트웨이만 안다. 서버간은 버스/명시 인터페이스만 — 타 서버 내부·DB 직접 접근 금지.
- **수렴(desync 0)**: 클라 예측 뷰는 권위 재현으로 수렴. 겹친 뷰의 참여자는 조정 후 일치.
- **복제 = 재현, 상태 전송 아님**: `(seed+params+intent 로그)` 가 기본. 전체 스냅샷은 late-join·복구의 최후 수단.
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **HktGameplay 원칙 상속**: HktCore 순수성(UObject 0) · 서버 권위(클라 읽기전용) · ISP 3-Layer · `SetPropertyDirty` 경유. 인프라는 *확장*하되 *깨지 않는다*.
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가. 새 코어는 직전 코어를 잇고 박스/계약 하나만 더한다.
