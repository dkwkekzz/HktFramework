## 2. NEXT — step-0012 가설 (후보, 권위는 이 절)

**버스 분산 + 실 네트워크 열화 내성 — broker 단일점을 pub/sub 버스로 분산하고, 실 소켓 층에 지연·분단·재연결을 주입해 내성 검증. step-0011 은 와이어를 *실 TCP 소켓*(길이-프리픽스 프레임·spawn IPC 0)으로 현실화했다 — 그러나 ⒜ broker 가 여전히 *단일 코디네이터*이고 ⒝ 소켓이 localhost·TCP *신뢰 전송*이라 실 네트워크 *분단·재연결* 내성은 미검증. 다음은 그 broker 단일점을 *버스*(pub/sub, NATS/Redpanda 또는 자작 소켓 버스)로 풀고, 소켓 층에 실 네트워크 열화를 주입해 권위 보존·desync 0 을 증명하는 것([TOOLS.md](TOOLS.md) §2·§5). 와이어가 이제 실 소켓이라 분단·재연결이 *자연한 다음 현실 문제*.**

step-0011 이 와이어를 현실화했다(실 TCP 소켓·길이-프리픽스 프레이밍·spawn IPC 0·E2E 비트 동일·`node verify.js` 한 줄 원격 기동). 게임-층 전송 모델(0004)과 소켓 와이어는 *두 층*으로 깨끗이 분리됐다(§7-4). 다음 자연한 한 조각은 그 *소켓 층*에 실 네트워크 열화(분단·재연결)를 더하고, broker 단일점을 *버스*로 분산하는 것 — 인터페이스 무변경(액터·계약 그대로) + 원격 검증 루프 보존.

**검증할 것(후보)**: ① **회귀 0** — 단일 broker·무열화면 0011 비트 동일. ② **버스 분산** — broker 단일점을 pub/sub 버스로(서버간 N×N 직접 결합 제거·발행자 무수정으로 소비자 추가). ③ **네트워크 열화 내성** — 소켓 층 실 지연·**분단**·**재연결** 아래 권위 보존·desync 0(failover/복원 장치가 소켓 끊김에도 작동). ④ **원격 한 줄 기동·은닉·재현** 유지.

> 후속 한 조각: **진짜 프로세스 kill 아래 failover**(0011 §8.3·0010 §8.3·0009 §8.3: `child.kill()`·소켓 끊김 감지·재배선·재-provisioning·거짓 사망/split-brain 펜싱) · **비동기 실행 아래 결정론**(0011 §8.1·0010 §8.1: lockstep 배리어 해제·논리 클럭/인과 순서) · **C++ 시뮬 코어 headless 교체**(§3 🔴) · **가방 서비스 분리**(서비스 계층 첫 박스 — 이제 실 소켓 별 프로세스 서비스로) · **존 N개·동적 경계**(0006 §8.2) · **존↔존 ghost 증분화·복원**(0007 §8.3).

**병행 백로그(블로킹 아님)**: ⬜ 버스 분산(broker 단일점 해소, 0011 §8.2) · ⬜ 실 네트워크 열화 내성(소켓 층 분단·재연결, 0011 §8.2) · ⬜ 진짜 프로세스 kill failover·거짓 사망·split-brain 펜싱·추종자 재-provisioning(0009 §8.3·8.4·0011 §8.3) · ⬜ 비동기 실행 아래 결정론(논리 클럭, 0011 §8.1) · ⬜ 다중 클라 결정론 복제·예측(0001~0004 무거운 모델은 C++ 승격에서 부활) · ⬜ 존 N개·동적 경계(0006 §8.2) · ⬜ 존↔존 ghost 증분화·복원(0007 §8.3·0008 §8.6) · ⬜ cross-zone 지연 완화(0007 §8.2) · ⬜ 제어 평면 손실 복원(0008 §8.2·0009 §8.2) · ⬜ 가변 지연 재정렬 아래 seq 복원(0008 §8.4) · ⬜ 서버간 인증(0001 §8.3) · ⬜ 재접속·티켓 만료(0001 §8.5) · ⬜ 가방 서비스 분리(존 tick 밖) · ✅ 시각화·검증 testbed 단일화(0010 후: `run.js`+`report.html`+`live.js` 구현, 손그림 html 8장 폐기 — 데이터층은 `engine/panel-kit.js` 재사용, 설계 [TESTBED.md](TESTBED.md)) · 🟡 레코더 per-tick 엔티티 위치·AOI 시각화·verify `scenario` 브리지·`inject`(0011 이 net-core 에 reg-safe `onTick(t,state)` 훅 *심음* — run.js 레코더의 위치 소비·verify `scenario`·`inject` 는 후속).

## 4. DURABLE CONSTRAINTS — 모든 step이 지킬 정전(canonical) 사실

> 여러 step이 반복 참조하는 불변. 새 step은 이걸 어기면 척추에서 벗어난 것 — 재설계.

- **회귀 0**: 새로 더한 항을 끄면(플래그=0) 직전 step과 **비트 단위 동일**(verify `reg`, maxDiff=0).
- **신성한 tick**: 존 시뮬 tick 안에 시뮬 외 작업(동기 I/O·인증·트랜잭션·팬아웃) 금지 — 전부 비동기 서비스/버스 경유.
- **결정론 코어**: 세계 상태의 쓰기 경로는 intent→결정론 시뮬 코어 하나. 같은 시드·로그 → 같은 해시. **`Math.random` 금지, 시드 의사난수만.**
- **권위 단일 소유**: 모든 상태 조각의 쓰기 권위는 정확히 한 곳(매 tick 소유자=1). 이동은 release+acquire **쌍 거래**/트랜잭션.
- **은닉·단일 연결**: 클라는 게이트웨이만 안다. 서버간은 버스/명시 인터페이스만 — 타 서버 내부·DB 직접 접근 금지.
- **수렴(desync 0)**: 클라 예측 뷰는 권위 재현으로 수렴. 겹친 뷰의 참여자는 조정 후 일치.
- **복제 = 재현, 상태 전송 아님**: `(seed+params+intent 로그)` 가 기본. 전체 스냅샷은 late-join·복구의 최후 수단.
- **Sim = 인터페이스 우선, C++ 최후 교체**: 존 시뮬은 *동결된 Sim 인터페이스* 뒤에 산다 — 오늘은 더미 구현(헤드리스), 인프라 전체를 원격 E2E 로 세운 뒤 인터페이스 무변경으로 얇은 C++ 호스트로 *교체만*. C++ 선-구축으로 원격 검증 루프를 끊지 않는다 ([TOOLS.md](TOOLS.md) §4·§6). 더미는 throwaway 가 아니라 인터페이스의 *첫 구현*.
- **headless·원격 검증(게임 시뮬 포함, 협상 불가)**: 모든 서버 동작 검증은 *결정론 시뮬 코어까지* Unreal Engine·GUI 없이 headless 로, 원격(이 환경/CI)에서 가능해야 한다. 더미=Node 라 자명히 충족 — C++ 승격 경로도 시뮬 *검증*에 UE 모듈을 링크하지 않는다. **'UObject 0' 으로는 부족**: 결정론 시뮬 코어가 UE 모듈(`Core`·`CoreUObject`·`GameplayTags`·`Json` 등)에 링크되면 headless 빌드 불가(§3 격차) → UE-모듈-free 코어 분리 또는 얇은 헤드리스 shim 으로 충족. 'UE 없이, 원격에서 빌드·통신·검증되는가'가 모든 박스(시뮬 포함)의 통과 조건 ([TOOLS.md](TOOLS.md) §1·§4).
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **코어 netcode 불변**: 결정론 시뮬 코어 순수성(UObject 0 — headless 빌드 가능) · 서버 권위(클라 읽기전용) · ISP 3-Layer · 시뮬 상태 직접쓰기 금지(intent 경유). 인프라는 *확장*하되 *깨지 않는다*.
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가. 새 코어는 직전 코어를 잇고 박스/계약 하나만 더한다.
- **도구 = tick 판정 + 원격-검증** ([TOOLS.md](TOOLS.md)): tick 동기는 C++(결정론 시뮬 코어), 그 외는 원격에서 빌드·헤드리스 검증되는 도구(Go·Node·컨테이너). 시뮬만 무거운 빌드로 격리(시뮬 코어 "UObject 0" 순수성 = 얇은 헤드리스 호스트로 CI 빌드 가능 = 빌드 자산).
- **데이터 3분할** ([TOOLS.md](TOOLS.md) §3): ① 월드 영속 = intent 로그(event sourcing) + 스냅샷 ② 트랜잭션 진실 원천(가방·계정) = PostgreSQL→분산 SQL ③ Redis = 휘발/캐시(진실 원천 아님). 월드 상태를 DB 행으로 저장하지 않는다.
