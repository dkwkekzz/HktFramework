# step-0111 — 거래소 취소 발행 (cancelPublish · svc.exchange.cancelled)

> 직전: [step-0110](step-0110.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md)
> 코드는 단일 소스 `src/`(제자리 수정) · 직전 동결 스냅샷 `baseline/` · reg 는 src vs baseline 비트 대조.

## 검증 질문

거래소가 체결(0108 svc.exchange.sold)만 발행하던 것을 *취소*(exchCancel 성공·매물 escrow→판매자 회수)까지 외부 관측 가능하게 한다 — SPINE 계층3 거래소 박스의 *수명주기 발행* 계약(0016 발행자 무수정 소비자)을 sold 한쪽에서 양쪽(sold+cancelled)으로 넓힌다. 닫는 조건: cancelPublish ON 이면 cancelPublished==cancelled·audit 가 svc.exchange.cancelled 를 그만큼 관측, OFF 면 발행 0 = 0110 비트 동일(reg). 발행은 비-침습(원장/세계 권위 불변).

## 2. 메커니즘 — 취소 성립 시 svc.exchange.cancelled 1회 발행 (플래그 OFF → baseline 비트 동일 = 회귀 0)

- **발행 지점**: `ExchangeService.onMsg` 의 exchCancel 성공 분기 — `this.listings.delete` + `cancelled++` + `returned` 반환 회계 직후, `cancelPublish && bus` 면 `net.send(addr, bus, {pub, topic:'svc.exchange.cancelled', ev:{id,seller,item,price}})` + `cancelPublished++`. 매물 객체 `l`(item·price)은 delete 전 캡처돼 ev 에 실린다.
- **OFF 게이트**: `cancelPublish` 기본 false → 발행 분기 휴면 = 0110 비트 동일(reg). bus 부재여도 no-op.
- **토폴로지**: topo-build 에 `cancelPublish` 옵션을 거래소 spec 으로 전달 + `audit && exchange && cancelPublish` 면 `['svc.exchange.cancelled','audit']` 구독 1행 추가. OFF 면 토폴로지도 0110 비트 동일.
- **비-침습**: 발행은 관측 사본일 뿐 — escrow 원장(open/sold/cancelled·returned)·세계 가방(minted) 권위 불변. 존 tick 밖 순수 반응형(0107 거래소 골격 유지).

- **excancel(가설)**: OPS 에 cancel 1개(s2·id3). 전 시드 동일:

- **spine**: 0001~0111 누적 회귀 사슬 ALL OK (월드해시 `0x7a122947`(seed42)… 보존·E2E 14프로세스 비트동일).

## 4. 척추 체크 5항

1. **신성한 tick**: 발행은 거래소 박스(존 tick 밖) 내부 반응 — 존 시뮬 tick 무관. ✅
2. **결정론 코어**: 세계 상태 쓰기 경로 불변(intent→sim). 발행은 관측 사본·minted ON==OFF. ✅
3. **권위 단일 소유**: escrow 원장 권위 불변(취소=release 쌍 거래·conserved). 발행이 권위를 바꾸지 않음. ✅
4. **은닉·단일 연결**: 거래소→버스 토픽 pub, audit 가 구독(발행자 무수정). 거래소는 소비자 주소/존재 모름. ✅
5. **headless·원격 검증**: Node `node run.js`·`spine` 수치 증명·UE 0. ✅

## 9. 의외의 발견 / 정직한 한계

- **발견**: 0108(sold)·0111(cancelled) 이 같은 발행 골격을 정확히 대칭으로 채운다 — 거래소 수명주기의 *두 종결 경로*(체결 / 회수)가 각자 무수정 소비자 토픽을 갖는다. 거래량/시세 피드는 sold 만으로 부족(매물 깊이=open 은 list−sold−cancelled)이라 cancelled 발행이 delisting 신호로 필요함이 드러남 — 다음 시세 피드 소비자(0114~)의 선결 입력.
- **한계**: 만료(TTL)로 인한 자동 회수는 아직 없다(취소는 판매자 명시 요청만) — 매물이 영영 escrow 에 묶일 수 있다(만료 후속). 발행은 *체결/취소* 사실만 — 가격 변동/입찰은 미모델. 거래소↔가방 2-서비스 원자 거래(0107 §9)도 후속.
