# ② 월드 — 결정론 시뮬만 사는 신성한 tick

> 인덱스: [README.md](README.md) · 구조 권위: [../../SPINE.md](../../SPINE.md) §2 · 마커: [../../STATE.md](../../STATE.md) §5
>
> **계층 한 줄**: 시뮬 tick 안에는 *시뮬만* 둔다. I/O·트랜잭션·팬아웃을 tick 밖으로 빼면 시뮬 헤드룸이 곧 동접이 된다. *결정론* 덕에 상태를 통째로 안 보내고 입력 로그만으로 같은 세계를 재현한다 — 이게 복제·복원·failover 의 토대.

---

## 존(리전) 서버 🟡 자라는 중 *(현재 전 박스 중 가장 성숙)*

- **무슨 서버인가**: 세계의 한 구역을 *결정론 시뮬 전용*으로 돌리는 서버. 공간 분할·관심 영역(AOI)·권위 핸드오프·failover 를 맡는다(`src/zone.js`).
- **이론 기반**: *결정론 상태 머신 복제(state-machine replication)* — 같은 시드·같은 입력열을 먹으면 누구든 같은 세계로 수렴한다. 그래서 상태를 통째로 안 보내고 *입력만* 보낸다. 비유 — 같은 악보(입력열)를 받은 두 연주자는 같은 연주(상태)에 도달한다. 여기에 *관심 영역(AOI)* 과 *권위 단일 소유(쌍 거래)* 가 얹힌다.
- **왜 필요했나 → 어떻게 구현했나** (각 마디가 앞 마디의 한계를 푼다):
  - *최초 구조*: 시뮬이 다른 일과 한 프로세스 → tick 에 잡일이 끼어 동접이 거기서 막힌다. 먼저 **심장**부터: `step-0001` 존 VM(결정론 시뮬 박스).
  - 심장이 하나면 죽으면 끝이다 → **복제**가 필요: `step-0002~0004` 추종자 존이 상태를 0바이트로 두고 *입력열만 미러*해 같은 해시로 수렴(+ `ISimCore` 인터페이스 동결 = C++ 교체 이음새 + 현실 전송 지연·손실·재정렬 아래 desync 597→0).
  - 한 존이 온 세계를 다 보면 대역이 터진다 → **관심만**: `step-0005` AOI(반경 R 안만 뷰로 내려보냄, 대역 51~68% 절감).
  - 한 존이 세계 전부를 맡을 수 없다 → **공간 분할 + 권위 이주**: `step-0006` 존 2개 경계 ghost 상호 구독 + 권위 release+acquire *쌍 거래*(소유자 항상 정확히 1·공백/이중쓰기 0). `step-0007` 증분 AOI(enter/exit/update 만·정지 대역 0).
  - 전송이 끊기면 뷰가 깨진다 → **반응적 복원**: `step-0008` ack/재전송·NAK/keyframe(손실 0~30%에도 desync 0).
  - 권위 존이 죽으면 그 구역이 멈춘다 → **failover**: `step-0009` 추종자(shadow) 가 lease 감지로 승격(사망→소유자 1). `step-0010` 존을 별 프로세스로. `step-0013` 죽은 추종자 재충원(divergence 0).
- **지금 어디 / 남은 것**: 존 하나가 *분할되고·관심영역만 보내고·권위를 매끄럽게 넘기고·죽어도 되살아나는* 데까지 섰다. 단 비트-결정론 복제(0002~0004)는 C++ 시뮬 승격에서 부활 예정(STATE §3 🔴 "C++ 시뮬 코어 headless 빌드"). 존 *N개·동적 경계*(지금은 2존 정적)는 후속.

## 인스턴스(던전/매치) 서버 ⬜ 미착수

- **무슨 서버인가**: 던전·매치처럼 수요 따라 떴다 사라지는 *일회성* 시뮬 서버.
- **이론 기반**: *수명주기 분리*(elastic spawn/despawn) — 오픈월드 존과 달리 필요할 때만 존재. 비유 — 상설 매장(존) vs 팝업 스토어(인스턴스).
- **왜 필요했나 → 어떻게 구현했나**: 던전·매치를 오픈월드 존과 같은 수명으로 묶으면 탄력이 없다 → 수요 따라 spawn/despawn 하는 박스가 필요. *아직 토폴로지에만 존재* — `src/` 에 박스 파일 없음.
- **지금 어디 / 남은 것**: 미착수. 다음 씨앗 = 일회성 시뮬을 오케스트레이터가 spawn/despawn 하는 최소 계약.
