# 목적 그래프 구축: 세계를 표현하는 근거가 된다

> 이 문서는 [Design-ObjectiveTree.md](Design-ObjectiveTree.md) 의 방법론을 **상흔계 아벨리온**이라는 구체 세계에 적용해 실제 목적 그래프를 구축한 정본이다. 두 문서가 겹치는 부분은 **이 문서를 우선**한다. 실물 데이터는 [data/objective-graph.json](../data/objective-graph.json), 관찰·편집기는 [objective-tree.html](../objective-tree.html).

## 0. 세계 시드

**세계 이름 — 상흔계 아벨리온**

아벨리온은 본래 하나의 태양 아래 유지되던 세계였다.
고대 이벨 문명은 태양이 약해지자 세 개의 별핵을 결합해 새로운 인공 태양을 만들려 했다. 그러나 의식은 실패했고, 별핵과 의식에 참여한 인간들의 정신이 융합되면서 인공 신격 생명체 아르카론이 탄생했다.
아르카론은 자신을 유지하기 위해 지상의 생명력과 별빛을 흡수하기 시작했다. 그 결과 세계에는 다음 현상이 나타났다.

```text
아르카론의 별빛 흡수
├─ 일부 지역에 영원한 겨울이 발생한다.
├─ 일부 지역에 과잉 별빛이 쏟아진다.
├─ 검은 태양병이 생명체 사이에 확산된다.
├─ 기후와 생태계가 불안정해진다.
└─ 고대 문명의 에너지 시설이 다시 작동하기 시작한다.
```

플레이어는 기억과 소속을 잃은 상태로 세계에 나타난다.
처음에는 단순히 살아남는 것만이 목적이지만, 생존 문제를 해결할수록 세계의 구조와 아르카론의 탄생에 접근하게 된다.

## 1. 그래프 표기 규칙

```text
[G] Goal        목적
[S] State       세계 또는 주체의 상태
[E] Entity      생명체, 인물, 신, 개체
[R] Resource    재료, 에너지, 정보
[L] Location    장소, 지형, 시설
[K] Knowledge   지식, 기록, 제작법
[T] Technique   스킬, 기술, 마법, 의식
[F] Faction     세력, 문명, 집단
[H] History     과거 사건
[X] Threat      생존을 방해하는 위협
```

관계 표기:

```text
A → B         A를 달성하거나 이용하면 B로 이어진다.
A ─필요→ B     A를 달성하기 위해 B가 필요하다.
A ─제공→ B     A가 B를 제공한다.
A ─방해→ B     A가 B의 달성을 방해한다.
A ↔ B         서로 영향을 주고받는다.
A ─충돌→ B     서로의 목적이 동시에 달성되기 어렵다.
A ─변화→ B     A의 결과로 B라는 세계 상태가 발생한다.
```

## 2. 최상위 목적 그래프

```text
[G0] 생존해야 한다.
├─ [G1] 생명을 유지하는 기본 조건을 확보한다.
├─ [G2] 생존을 직접적으로 방해하는 위협을 제거한다.
├─ [G3] 더 강한 존재로 성장한다.
├─ [G4] 생존할 수 있는 영역을 확장한다.
├─ [G5] 지속 가능한 생산 기반을 구축한다.
├─ [G6] 다른 존재와 협력하거나 지배 관계를 만든다.
├─ [G7] 미래의 위협을 예측하고 대비한다.
├─ [G8] 세계의 원리를 이해한다.
└─ [G9] 죽음으로부터 존재를 보존한다.
```

이 목적들은 서로 독립된 콘텐츠가 아니다.

```text
[G1 기본 생존] → 살아남을 시간을 확보 → [G3 성장] 활동 가능
[G3 성장]      → 더 위험한 지역 진입 → [G4 영역 확장] 가능
[G4 영역 확장]  → 새 자원·문명 발견   → [G5 생산 기반]·[G6 협력] 확장
[G5 생산 기반]  → 장기 자원 확보       → [G7 미래 대비] 가능
[G8 세계 이해]  → 불가능했던 해결법 개방 → [G9 죽음 극복]·아르카론 해결
```

## 3. G1: 생명을 유지하는 기본 조건을 확보한다

### 3.1. 식량을 확보한다 `[G1.1]`

```text
[G1.1] 지속적으로 식량을 확보한다.
├─ [G1.1.1] 즉시 먹을 수 있는 식량을 구한다.
│  (야생 열매 채집 / 작은 생명체 사냥 / 버려진 저장고 탐색 / 다른 생존자와 교환)
├─ [G1.1.2] 식량의 안전성을 확인한다.
│  (독성 판별 / 부패 확인 / 검은 태양병 오염 확인 / 안전한 조리법)
├─ [G1.1.3] 식량 생산을 지속 가능하게 만든다.
│  (작물 재배 / 동물 사육 / 균사 농장 / 물고기 서식지 관리 / 교역)
└─ [G1.1.4] 새로운 환경에서 먹을 수 있는 자원을 발견한다.
   (설원 식량 / 심해 식량 / 독성 지대 정화 / 별빛 생명체 전환)
```

도출 세계 요소: `[E]유리열매나무` `[E]재등쥐` `[E]온혈버섯` `[F]씨앗보존회` `[L]굶주린 평원`

교차 연결:

```text
유리열매나무 → G1.1 식량 / G1.2 식수 / G4.2 해안 탐험 / G5.2 담수 생산
재등쥐       → G1.1 식량 / G1.4 호흡 / G2.3 질병 확산 / G8.2 검은 태양병 연구
```

### 3.2. 물을 확보한다 `[G1.2]`

```text
[G1.2] 안전한 물을 지속적으로 확보한다.
├─ [G1.2.1] 지표수를 찾는다.
├─ [G1.2.2] 오염된 물을 정화한다.
├─ [G1.2.3] 지하수를 개발한다.
├─ [G1.2.4] 공기와 생명체에서 물을 추출한다.
├─ [G1.2.5] 수원을 보호한다.
└─ [G1.2.6] 물의 흐름을 복구한다.
   ├─ [G1.2.6.1] 강이 마른 원인을 조사한다.
   ├─ [G1.2.6.2] 붉은 뿌리의 성질을 파악한다.
   ├─ [G1.2.6.3] 해결 방법을 선택한다.
   └─ [G1.2.6.4] 강 복구 이후의 변화를 관리한다.
```

붉은 뿌리 `[E] 대수근 카르마`: 고대 이벨 문명이 사막화를 막기 위해 만든 인공 식물. 제어탑 파괴 후 물을 무제한 흡수. 단순 제거 시 저장된 물이 방출되어 대홍수 발생. 제공 자원: 수분핵·재생섬유·수맥 감지 조직.

목적 충돌: 플레이어·농민(강 복구) ↔ 물독점단(부족 유지) ↔ 카르마(영역 확대) ↔ 하류 늪 생명체(낮은 수위 유지).

### 3.3. 체온을 유지한다 `[G1.3]`

```text
[G1.3] 적정 체온을 유지한다.
└─ [G1.3.1] 영원한 겨울에서 생존한다.
   [R]속털 / [R]빙수목 방수 수지 / [R]온혈버섯 열낭 / [K]북방 유목민 다층 봉제법
   / [T]저맥동 호흡 / [L]지열 동굴 / [E]잿불도마뱀
```

`[H] 별빛 절단 사건`: 아르카론이 북방 별빛 통로를 흡수 → 열 유입 감소 → 대지 결빙 → 빙수목·설원 짐승 적응 → 북방 문명이 유목화.

### 3.4. 호흡 가능한 환경을 확보한다 `[G1.4]`

재의 숲 재 여과 / 독성 늪 정화 / 심해 산소 / 하늘 신전 희박 공기 / 별빛 균열 진공.
요소: `[R]재등쥐 여과털` `[R]바람산호 산소주머니` `[T]회귀 호흡` `[T]무호흡 순환` `[E]폐낭벌레` `[E]청록균사` `[F]숨결 수도원`.

`[T] 회귀 호흡`: 광부 하르반이 독성 갱도 생존을 위해 발견(호흡을 늦추고 혈류를 심장·뇌에 집중). 전승: 광부 생존법→폐광촌 구전→숨결 수도원 수행법→전쟁용 생존술. 수도원은 전쟁 사용을 막기 위해 전승 제한.

### 3.5. 안전한 휴식 공간을 확보한다 `[G1.5]`

거점 종류와 대가: 야영지(빠름/방어 낮음) · 동굴(기후 강함/지하 생명체 충돌) · 이동 거점(설·사막 이동/유지비 큼) · 지열 도시(에너지 안정/지열핵 폭주) · 공중 거점(지상 위협 회피/별빛 폭풍 노출) · 생체 거점(생명체 공생/생명체 목적에 종속).

## 4. G2: 생존을 방해하는 위협을 제거한다

### 4.1. 적대 생명체 `[G2.1]`

`[X] 회색등 늑대 무리`가 마을 공격 — 직접 원인: 가축을 먹이로 인식 / 중간: 초식동물 감소 / 근본: 붉은 뿌리가 물을 흡수해 숲이 고사.
해결: 사냥 / 가축 방어 시설 / 숲 복구 / 초식동물 이주 / 다른 먹이원 제공 / 우두머리와 정신 계약 / 마을 이동.
교차: 붉은 뿌리 해결→강 복구→숲 회복→초식동물 증가→늑대 공격 감소. 늑대 전멸→초식동물 과증가→어린 숲 파괴→농작물 피해.

### 4.2. 적대 세력 `[G2.2]`

`[F] 청동 수문회`(물독점단): 표면 목적=수원 관리·분쟁 방지 / 실제=물 통제로 권력 유지. 강 복구 시 권력 약화. 처리: 제거 / 공공 수자원 개혁 / 수익 공유 / 새 수원 개발 / 플레이어 장악.

### 4.3. 질병과 변이 `[G2.3]`

`[X] 검은 태양병`: 아르카론이 생명력 흡수를 위해 만든 별빛 기생 구조. 전파=감염자의 검은 결정·오염된 별빛·재등쥐 매개·오염 식수. 진행=피로→체온 상승→검은 결정 형성→기억 유출→아르카론 정신 연결→생명력 흡수. 이용: 초기(별빛 감지)·중기(신성 저항)·후기(자아 상실 위험).

```text
[G2.3.1] 검은 태양병을 치료한다.
[R]감염체 항체 / [R]백야초 냉각 수액 / [R]은빛 거머리 혈액 / [R]고요한 샘 무진동수
/ [K]약사 리에나 연구 기록 / [T]별빛 분리술 / [R]백야혈청
```

백야혈청 갈등: 치료단(치료) ↔ 전쟁 세력(병기 저항제) ↔ 아르카론 신앙(파괴) ↔ 상인 연합(독점) / 플레이어(공개·독점·개량·파기 선택).

### 4.4. 자연재해·환경재난 `[G2.4]`

`[X] 별빛 폭풍`: 아르카론이 흡수 못 한 과잉 별빛 방출. 효과=급격한 변이·광물 성질 변화·마법 장치 폭주·새 별빛 생명체 탄생. 기회=성광결정 생성·숨겨진 별길 개방·고대 시설 일시 작동.

### 4.5. 위협 근원 제거 `[G2.5]`

```text
[G2.5] 아르카론의 영향을 제거한다.
├─ [G2.5.1] 아르카론의 정체를 알아낸다.
│  [L]무너진 이벨 천문대→[R]불탄 성도 / [L]최초 의식장→[R]별핵 결합기 파편
│  [E]추방된 기록관 세리아→[K]금지된 이벨 연대기 / [E]죽지 못한 사제 오르반→[K]최초 결합 의식 진실
│  [S]아르카론이 신이 아니라 인공 생명체임을 밝힌다.
├─ [G2.5.2] 아르카론의 약점을 발견한다.
│  (감염 조직 분석 / 적일 분화구 신혈 / 심연유리-신혈 반응 / 일식 중 재생 감소
│   / 별빛 통로=재생 공급원 / 심장 내부 인간 제어 각인)
└─ [G2.5.3] 아르카론의 영향을 제거한다.
   (파괴 / 별빛 차단 휴면 / 인공 태양 복구 / 차원 추방 / 대체 에너지 공급 / 의식 분리 / 지배)
```

제거 이후 변화:

```text
파괴 ─변화→ 검은 태양병 약화 · 영원한 겨울 일부 해소 · 과잉 별빛 폭풍 · 신앙 세력 붕괴·내전
            · 시체 자원 쟁탈전 · 세계 바깥 존재의 아벨리온 발견
복구 ─변화→ 안정적 인공 태양 · 아르카론 자아 일부 유지 · 에너지 공급권 전쟁 · 태양 관리 신문명
지배 ─변화→ 플레이어 세력 압도적 성장 · 전 세력 연합 저항 · 플레이어 정신 오염
            · 새 최상위 목적: 아르카론과 융합된 자아를 보존한다.
```

## 5. G3: 더 강한 존재로 성장한다

- **G3.1 신체 성장**: 훈련(안정/한계 낮음) · 약물(빠름/중독·변이) · 생체 이식(환경 강함/정체성 변화) · 별빛 변이(강력/아르카론 연결 위험) · 기계 보강(유지 필요/고대 기술 세력 연결).
- **G3.2 장비 제작** → `[G3.2.1] 무광의 쐐기(신살 무기)`: `[R]심연유리` `[R]뇌철 결정` `[R]불멸 힘줄` `[K]최초 신살 대장장이 설계` `[T]그림자 각인(세 번째 일식 중)` `[L]침묵의 용광로(신성 에너지 없는 지하)`.
- **G3.3 스킬 계보**: 회귀 호흡→무호흡 순환 / 별읽기→차원 항로 / 혈육공명→집단 의식 / 물질기억→세계 역사 복원 / 그림자 각인→신격 연결 절단.
- **G3.4 약물**: `[R]거인혈` — 고대 거인 골수 생성. 급격 성장/부작용(무한 에너지 요구·성장 정지 불가·거인 기억 유입). 충돌: 플레이어(강화) ↔ 거인 부활교단(거인 부활용 수집).

재료별 세계 연결: 심연유리·뇌철 결정·불멸 힘줄은 각각 5~6개 목적의 교차점(§12 참조).

## 6. G4: 생존할 수 있는 영역을 확장한다

- **G4.1 환경 파악**: 정보 자체가 자원 — 안전 경로·계절 위험 지도·생명체 이동 기록·수맥 정보·별빛 폭풍 예측표·비밀 통로(판매·독점·공유 가능).
- **G4.2 이동 수단**: 육상 탈것 / 수상 / 심해 잠수 / 비행 생명체 / 별배 / 차원문. `[E]구름고래` 계약: 새끼 구조·먹이 번식지 복구·사냥단 저지·공중 폐허 제거(탈것이 아니라 고래의 생존 목적 해결).
- **G4.3 환경 적응**: 각 환경은 새 재료·기술을 주지만 기존 방식을 무효화(심해=불 불가·압력·부력 / 하늘 신전=희박 공기·불안정 중력·별빛 노출).
- **G4.4 거점 연결**: 도로 건설 ─변화→ 교역 증가·상인 성장·산적 증가·야생 이동로 단절·새 마을·토지 분쟁.

## 7. G5: 지속 가능한 생산 기반을 구축한다

- **G5.1 생산 자동화**: 농장(물·토양·씨앗·노동→식량·섬유·약초 / 토양 고갈·해충·물 사용) · 광산(노동·지지대·운송→광석·수정·화석 / 지반 붕괴·오염·지하 생명체 충돌).
- **G5.2 에너지**: 연소·수력·지열·번개·생체·별빛·신격 — 강력할수록 위험(지열핵 폭주·검은 태양병·신 의식 연결).
- **G5.3 자원 순환**: `[E]장례균사` — 사체 분해·질병 조직 격리·기억 잔류물 보존. 과성장 시 산 자를 죽은 것으로 오인. 용도: 농업·시체 처리·질병 연구·죽은 자 기억 복원.

## 8. G6: 다른 존재와 협력하거나 지배 관계를 만든다

- **G6.1 동료**: 각 인물은 기능 슬롯이 아니라 독자 목적. `[E]세리아` — 목적=이벨이 아르카론을 만들었다는 진실 증명 / 두려움=이벨 후손 박해 / 협력 조건=무조건 공개 말고 검증 / 배신=정치 무기화 시 자료 파괴 후 이탈.
- **G6.2 생명체 계약**: 구름고래(공중 이동)·잿불도마뱀(열)·회색등 늑대(추적)·바람산호(심해 산소)·기억나방(과거 기억)·길잡이 균사(지하 통로).
- **G6.3 세력 형성**: 생존자 무리→역할 집단→정착촌→도시→지역 세력→문명→세계 연합. 세력이 커질수록 개인 목적과 충돌(탐험 ↔ 지도자 이탈 방지).
- **G6.4 기존 세력 관계**:

```text
[F] 씨앗보존회 (작물 다양성 보존) ─충돌→ 청동 수문회 (농업용수 개방)
[F] 청동 수문회 (수원 통제 권력)
[F] 숨결 수도원 (위험 기술 오용 방지) ─충돌→ 일식 사제단 (감염=신성 변화 vs 질병)
[F] 일식 사제단 (아르카론 신격·질서 유지)
[F] 유리잠수단 (심연유리 채굴·심해 항로 독점) ─충돌→ 심해 생명체 (서식지 파괴)
[F] 거인 부활교단 (죽은 거인 부활) ─필요→ 무명 대장간 (거인 신체 복구 기술)
[F] 무명 대장간 (신살 기술 재사용 감시)
```

## 9. G7: 미래의 위협을 예측하고 대비한다

- **G7.1 예측**: 기억나방 이동(별빛 폭풍) · 빙수목 수액 점도(한파) · 재등쥐 지상 이동(지진·가스) · 구름고래 항로 이탈(대기 이상).
- **G7.2 대체 수단**: 종자·유전정보 보존 / 대체 수원 / 이동 거점 / 다중 에너지 / 지식 분산 / 다른 세계 이동 연구.
- **G7.3 범용 대응**: 성질 분석 도구 / 에너지 차단 도구 / 격리 시설 / 개조 가능 장비 / 재료 실험 공방 / 기록망.

## 10. G8: 세계의 원리를 이해한다

- **G8.1 물질**: 이 세계는 기억·의식도 물질에 흔적을 남긴다 — 심연유리(별빛)·기억골(생명체 기억)·장례균사(사체 기억)·별핵 금속(집단 의식·명령).
- **G8.2 생명**: 질병 치료·생체 장비·신종 창조·멸종 복원·신체 개조·아르카론 생체 수정으로 이어진다.
- **G8.3 신격**: 아르카론 탄생 원리 = 세 별핵 + 이벨 집단 의식 + 태양 복구라는 단일 목적 + 제어 실패. 이해한 플레이어의 선택: 아르카론 수정 / 새 신 창조 / 자기 신격화 / 신격 기술 파괴 / 신격 에너지 공유 체계.

## 11. G9: 죽음으로부터 존재를 보존한다

- **G9.1 죽음 지연**: 회귀 호흡·재생 약물·인공 장기·생명력 저장·응급 복구.
- **G9.2 신체 복구**: 조직 보존·장례균사 기억 추출·불멸 힘줄 연결·별빛 세포 활성·의식 재정착. 문제: 복구된 존재는 동일한가 / 기억 일부 소실 시 같은 존재인가 / 복수 신체의 원본은.
- **G9.3 기억·의식 보존**: 기억골·장례균사망·별핵 장치·생명체 공유·후계 계승.
- **G9.4 존재 방식 확장**: 다중 신체·거점 분산·집단 의식·아르카론 융합·생태계 분산. 생존의 의미 변화: 신체 보존→기억 유지→목적·영향 지속→세계 구조의 일부로 존재.

## 12. 주요 세계 요소의 교차 목적 그래프

- `[R] 심연유리` — 생성=별배 추락+별핵 에너지+심해 압력+규산질 모래+심해 분비물. 연결: 별빛 재생 차단·검은 태양병 억제·별빛 저장·야간 은신·차원 관측 렌즈·신성 방어·심해 서식지. 과채굴 ─변화→ 유리벌레 감소·그림자 산호 붕괴·심해 포식자 해안 이동·마을 공격·유리잠수단-해안 세력 전쟁.
- `[R] 뇌철 결정` — 철광맥+반복 낙뢰+폭풍 절벽 자기장. 연결: 신살 무기·전력 저장·통신·폭풍 예측·기계 구동·비룡 항법. 과채굴→비룡이 둥지 상실→마을 공격→절벽 생태 붕괴.
- `[X/R] 검은 태양병` — 위협(생명력 흡수·기억 유출·자아 상실) + 자원(별빛 감지·신성 저항·아르카론 통신). 완전 제거 시 일부 능력·연구 경로도 소멸.
- `[E] 대수근 카르마(붉은 뿌리)` — 위협(강·지하수 고갈) + 자원(수분핵·재생섬유·수맥 조직). 연결: 가뭄·농업·재생 장비·이동식 물 저장·홍수 통제·생체 도시.
- `[E] 구름고래` — 제공: 공중 이동·기상 정보·부유 지방·저주파 통신. 연결: 하늘 신전 접근·별빛 폭풍 예측·공중 교역·이동 거점·하늘 생태 복구.

## 13. 목적 그래프에서 발생하는 대표 사건 (변화 사슬)

```text
사건 1. 강의 귀환
제어탑 복구 → 강 흐름 → 농업 회복 → 식량 가격 하락 → 수문회 권력 약화
→ 수문회 제어탑 파괴 시도 → 늪 서식지 감소 → 늪 포식자 농경지 이동 → 새 방어·생태 목적

사건 2. 늑대의 멸종
대량 사냥 → 가축 피해 감소 → 초식동물 급증 → 어린 숲 소멸 → 토양 침식
→ 강 토사 퇴적 → 수로 막힘 → 늑대 복원·대체 포식자 도입 목적

사건 3. 심연유리 호황
신성 방어구 수요 → 유리 가격 상승 → 채굴량 증가 → 그림자 산호 붕괴
→ 심해 포식자 해안 상륙 → 해안 도시 공격 → 채굴 금지 요구 → 상인 연합과 전쟁

사건 4. 백야혈청 공개
제작법 공개 → 감염 사망률 감소 → 백야초 수요 급증 → 군락 고갈
→ 냉각 수액 먹던 설원 곤충 감소 → 곤충 먹는 새 남하 → 농작물 해충 증가 → 인공 백야초 재배 목적

사건 5. 아르카론의 죽음
심장핵 파괴 → 검은 태양병 연결 단절 → 감염자 기억 회복 → 북방 별빛 회복
→ 영원한 겨울 해빙 → 빙하 아래 고대 생명체 각성 → 남부 대홍수 → 과잉 별빛 방출
→ 새 별빛 종족 탄생 → 세계 외부 관측자의 아벨리온 발견
```

아르카론은 최종 보스가 아니라 세계 상태를 유지하던 거대한 구성 요소다. 제거는 새로운 시대의 시작이다.

초기:  살아남는다 (배고픔 / 물 부족 / 밤의 늑대 / 검은 빛에 아픔)

## 15. 그래프 확장 규칙

새 목적 노드 추가 시 함께 생성: ① 목적 주체 ② 현재 상태 ③ 목표 상태 ④ 발생 원인 ⑤ 해결 방법 최소 3개 ⑥ 필요 기능 ⑦ 필요 재료·정보 ⑧ 재료 제공자 ⑨ 제공자의 독립 목적 ⑩ 제공자 환경 ⑪ 현재 상태의 역사 ⑫ 교차 연결 ⑬ 완료 결과 ⑭ 실패 결과 ⑮ 장기 세계 변화.

새 세계 요소 추가 시 확인: 누구의 어떤 목적으로 존재하는가 / 어떤 목적을 가능하게·방해하는가 / 자신은 무엇을 유지하려 하는가 / 사라지면 어떤 목적이 불가능해지는가 / 증가하면 어떤 문제가 생기는가 / 최소 두 개 이상 목적에 연결되는가.

## 16. 전체 그래프 핵심 요약

```text
[G0] 생존한다.
├─ [G1] 기본 조건   : 식량·물·체온·호흡·거점
├─ [G2] 위협 제거   : 적대 생명체·적대 세력·질병·자연재해·아르카론
├─ [G3] 성장        : 신체·장비·스킬·약물·변이
├─ [G4] 영역 확장   : 탐험·이동·환경 적응·거점 연결
├─ [G5] 생산 기반   : 농업·사육·채굴·에너지·자원 순환
├─ [G6] 관계        : 동료·생명체 계약·세력·문명
├─ [G7] 미래 대비   : 재난 예측·대체 자원·이동 거점·범용 대응
├─ [G8] 세계 이해   : 물질·생명·기억·의식·신격
└─ [G9] 죽음 극복   : 죽음 지연·신체 복구·기억 보존·존재 방식 확장
```

모든 가지는 다시 서로 연결된다:

```text
식량 부족   → 생태계 조사 → 붉은 뿌리 발견 → 고대 문명 연구 → 아르카론 탄생 원인
늑대 공격   → 숲 붕괴 → 물 부족 → 수문회 정치 갈등 → 지역 문명 재편
질병 치료   → 별빛 생명 구조 연구 → 신격 생성 원리 → 죽음 극복 기술
심연유리 채굴 → 신살 무기 → 심해 생태 붕괴 → 새 해안 생존 문제
```

**최종 핵심** — 목적 그래프는 플레이어가 수행할 콘텐츠 목록이 아니다. 생존이라는 하나의 목적을 실제 행동 단위까지 분해하는 과정에서 필요한 물질·생명체·지형·기술·인물·세력·문명·역사가 도출된다. 하나의 목적은 여러 해결 방법을, 하나의 세계 요소는 여러 목적을 갖는다. 서로 다른 존재의 목적이 협력·충돌하며 사건이 발생하고, 성공과 실패가 세계를 새 상태로 바꾼다. 이 세계는 미리 정해진 퀘스트의 집합이 아니라, 수많은 존재가 각자의 생존 목적을 추구하며 끊임없이 새 문제와 해결 방법을 만들어내는 거대한 목적 그래프다.
