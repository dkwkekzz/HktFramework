## 2026-07 — 설계 확정 (문서 2편 신설, 데이터 반영 전)

**배경** — 채집물·퀘스트 NPC·몬스터 "배치"를 벗어나 세계 규칙·상태 위에서 주체들이 스스로 살게 하는 구조의 설계. 요구 원문: 종마다 목적 트리(노드는 경험·가치관·특성에 따라 조건부 발동 → 성장·개성), 상대의 내부 상태가 아니라 현상에 반응하는 상호작용, 인간류의 넨(헌터×헌터 구조 참고) 능력 체계, 헌터×헌터 수준의 깊이·다양성을 측정 가능한 기준으로.

**신설 층 4 + 공정** ([Design-Life.md](../design/Design-Life.md)):

1. **종(種) 층위** — 세력·군집·개체 위에 없던 생명 분류 층. 종 = 공통 기반(결핍 삼축·에너지 원장 임계 표) + 환경(서식 L + 압력 술어) × 특성(압력 근거 필수) × 가치관(Motive §5 욕망 5축 재사용 — 사전 신설 0).
2. **종족 목적 트리** — 기존 G 노드 형식에 세 필드 확장: 활성 조건(경험·가치관·특성 술어 — 무조건 발동 금지, 불변 L4) · 반응 트리거(믿음 변수만 참조 — 불변 L3) · 갈등 접점(복수화 3 의 필드화). 트리는 종에 하나, 개체는 활성 프로파일로 (복수화 7 유지).
3. **개체 프로파일** — { 특성 편차·가치관 가중·경험 기록 } → 활성 프로파일(켜진 노드 부분집합). 성장 = 프로파일 궤적(잃는 성장 포함). 다양성은 난수가 아니라 좌표·이력 차이(불변 L5). 능력도 같은 프로파일에서 생성 — 목적과 능력이 한 프로파일의 양면 발현.
4. **현상 층** — 방출(상태·행동의 관측 가능 투영 = 파생축 확장) → 관측(종 감각 채널 × 현상 채널·강도) → 믿음(쌍축 + 인식 4단계: 미발견→추정→확인/반증) → 반응. 내부 직독 금지(불변 L3). 플레이어 신호층(E1)은 이 층의 수신 채널 특수화로 소급 배치.
5. **저작 공정 W·S·A·I·V** — W 규칙 추가(WorldLaws §9 + 현상 방출 선언 3.5단계) · S 종족 추가 7단계(환경→공통 기반→특성→가치관→트리→현상 어휘→§19 배선, ObjectiveTree §19 는 S-7 로 포함 — 양쪽 문서에 동일 문장) · A 능력 추가 · I 개체 생성(승격 판정 기계화) · V 검증(설계 V-L1~3 / 데이터 V-L4~7 명세). 전 공정 게이트 보유.

**능력 체계** ([Design-Ability.md](../design/Design-Ability.md)) — 작업명 넨(가칭), 정식 후보 '숨(息)'(T_회귀호흡·F_숨결수도원 앵커 — 명칭 확정은 데이터 반영 첫 커밋에서). 헌터×헌터 구조 원리 4개만 차용(생명 에너지 원천·계통 적성·제약과 서약·개성 발현), 고유 설정 차용 0. 계통 6종은 개입 대상에서 유도(증폭·방사·변성·구성·감응·간섭) — 기존 T 계보가 4자리 선점(회귀호흡=증폭·별읽기/혈육공명/물질기억=감응·그림자각인=간섭). **제약과 서약의 수량화**: 출력 계수 = 희소성(클럭 duty 산정 — T_그림자각인 "세 번째 일식 중" 이 최상급 기존 사례) × 서약 크기, 위반=사건(D3 규율).
