## 2026-07 D3 실패=사건 — 실험 행동 결과 분기 + 무효과 실패 0 감사 (구현)

발화된 실험 행동은 잘못된 때·맥락에서도 **무효과가 아니라 사건**이 된다(§11·정합 4). **엔진 무변경** — 결과 분기를 데이터(시도 마커 + 상호배타 분기 법칙)로 구현. 기존 검증 9종 + 신규 1종 초록.

### 정합 4 재확인 — 두 종류의 '실패'

- **전제 미충족 = 불발**(발화 불가 + "필요: …" 안내)은 유능감 장치로 **유지**(D3 대상 아님).
- **§11 실패 = 사건**은 **발화된** 실험 행동의 결과 분기 — 잘못된 조합·사용도 효과를 가진다(무효과 금지). 결정론 유지(§19): RNG 아니라 숨은 맥락(별빛)의 법칙 교차.

### 결과 분기 패턴 (엔진 무변경으로 XOR 분기 구현)

엔진의 action.then 은 무조건 적용이라 그 자체로는 분기 못 한다. 그래서:

1. 실험 행동의 then 은 **시도 마커만 세운다**(`E_플레이어.실험.재생낭`=1, axis=실험). 결과는 안 준다.
2. 다음 틱, 마커를 읽는 **상호배타 분기 법칙**이 숨은 맥락으로 결과를 가른다:
   - **`LAW_재생낭_정상`** (별빛폭풍 없음) → 상처−1·온기+1 (의도한 회복). 마커 소거.
   - **`LAW_재생낭_빗나감`** (별빛폭풍 중) → 성광결정 부산물+1·온기+1, **회복 없음**. 마커 소거. §11 '새로운 재료가 생성된다' — 성광결정 detail '별빛 폭풍 중에만 생성'과 정합(실패가 lore 를 실현).
3. 두 법칙은 `X_별빛폭풍.활성`(false/true)로 정적 상호배타(검증9 규율) — 동시 발화 불가.

실측: 정상 상처 2→1·성광 0 / 빗나감 상처 2(회복 안 됨)·성광결정 +1. 둘 다 효과 있음(무효과 0). `ACT_조합_생체재생낭` 은 `experiment:true`·`ACT_속털_두르기`(단순 실험)도 태깅.

### 검증 — 무효과 실패 0 감사 (validate-experiment.mjs)

`data/validate-experiment.mjs` 신설: E1 무효과 금지(실험 행동 then 비어있지 않음) · E2 분기 실재(마커 읽는 분기 ≥2, 각 분기 마커 소거 외 실효) · E3 상호배타(공유 ==-가드) · E4 분기 실측(각 맥락에서 서로 다른 실효). rules 88→90·vars 170→172(성광결정 보유·실험 마커).

### ② 조합 verb 배선 (§6 조합·§8 3용도·§7 방향성)

- **`ACT_조합_생체재생낭`** (신설 조합 verb) — 카르마 유래 두 생체 재료(수분핵+재생섬유)를 합쳐 휴대용 재생낭. 생체 계열 방향(재생·저장) 그대로 + **예상 밖 확장**: 거점 없이도 상처를 아물리고(요양은 거점 필요) 덤으로 체온까지 지킨다. 격리 실측 상처 2→1·온기 1→2.

- 세 배선 전부 플레이어 행동의 산물 — 자율 세계는 채집을 안 해 미발화 → 5 대표 사건·M 시리즈·프로브 무영향(9종 검증 초록 확인).

### 고친 것 — 위협 재발화 사이클 (숲 회복 상한 + 늑대 증식 재압박, §20 D0)

늑대 위협을 `압력 축적→발화→해소→재축적` 구조로. 먹이 축(고갈0·희소1·보통2·풍부3)이 **1↔2 를 오가는 유계 진동자**가 되도록 세 법칙을 배선:

- **`RULE_숲_회복` 상한**: `강흐름≥2 ∧ 먹이<2` → +1 (every 4). 예전엔 상한 없이 풍부(3)까지 밀어 위협을 영구 봉쇄. 이제 보통(2)까지만(강 복구 시 가속).
- **`LAW_숲_자생`** 신설: `먹이<2` → +1 (every 2). 강이 안 돌아와도 어린 숲이 스스로 보통(2)까지 더디게 재생 — 이게 없으면 강 미복구 세계에서 먹이가 1에 얼어붙어 위협이 사이클이 아니라 **영구 그라인드**(해소 국면 소멸)가 된다.
- **`LAW_늑대_방목압`** 신설: `늑대≥20 ∧ 먹이≥2` → −1 (every 20). 회복한 무리의 사냥 압력이 먹이를 보통→희소로 되돌려 `X_늑대공격` 재점화. **먹이≤0(기근)까지는 안 내려** `EV_늑대멸종`(늑대≤5) 사슬은 절대 건드리지 않음.

결과: 먹이 대부분 보통(2, 위협 OFF) + 20틱마다 짧은 습격(먹이 1, 위협 ON). 1000틱 무입력에서 최소 늑대 37·`EV_늑대멸종` 미발동·엔진오류 0. **덤: 진단이 지적한 '세계가 대신 완주하는 플레이어 목적 2개' 중 `G2.1`(적대 생명체 공격 막기)이 자동 해결됨** — 위협이 살아있으니 목적이 열린 채 유지된다(예전엔 위협 소멸로 자동 완료).

## 2026-07 설계 확정 (구현 전) — 목적 트리 ↔ 플레이어 직관 연결

문서만 변경(엔진·데이터 무변경). 확정 설계 원문(§1~§18)을 [Design-Intuition.md](../design/Design-Intuition.md) 로 반영하고, 기존 설계와의 충돌 6건을 층 분리로 해소(§19 정합 1~6), 적용 로드맵 D0~D4 예약(§20).

핵심: 목적 트리는 설명 구조가 아니라 **단순한 충동의 행동이 계속 흥미로운 결과와 다음 목적을 만들도록 세계를 구성하는 내부 구조**다. 각 목적 노드는 §14 변환 8항(내부 목적→욕망 대상→작은 방해→눈에 띄는 수단→간단한 행동→즉시 보상→예상 밖의 결과→다음 목적)으로 플레이어 경험에 번역한다.

### 충돌 해소 요지 (§19)

- 결정론 유지 — 예측 불가능성은 RNG 가 아니라 정보 비대칭(숨은 상태·법칙 교차)에서.
- 욕망 신호도 상태의 렌더(원경 실루엣·잠긴 문 채널) — MMO 불변 6 유지, 동기 불변 10 '예고'의 확장.
- 동기 불변 8 은 저널에만 적용 명확화 — 세계 오브젝트 가시화(신호)는 경험 전 허용, 저널 노출은 경험 후 유지.
- 전제 미충족 UX 유지 + '실패=사건'은 발화된 실험 행동의 결과 분기(데이터)로 — 엔진 무변경.
- 저널은 지시가 아니라 경험의 정리로 재정위 — 해결 정답 대신 상황·복수 가능성.
- Design-Motive 와 접합(대체 아님) — Motive=왜 움직이는가, Intuition=무엇으로 보이는가.
