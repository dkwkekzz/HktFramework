## G2.5.3 아르카론 처리 6방식 보스전 (§6.2 — 목적당 행동 다중성·완료방식 분기)

- **말단 목적 1개 = 행동 7개**: 파괴·별빛차단휴면·인공태양복구·차원추방·대체에너지공급·의식분리·지배. 각 전제가 다르고(무광의쐐기·심연유리 공급·정체 규명·세 번째 일식 조합), 효과에 `G2.5.3.완료방식`(ref)=자기 id 기록. 완료=완료방식 != null(상태 술어 — 어떤 방식이든).
- **방식별 세계 변화 = 완료방식/코어 상태로 분기**:
  - 파괴·차원추방·의식분리 → `E_아르카론.심장핵`=false → **기존 사건 5 사슬** 자동 연결(생존=false→해빙→고대생명체 각성·별빛종족 탄생·외부관측).
  - 휴면·복구·계약·지배 → `E_아르카론.잠식`=false 로 **P1 유지 법칙(U01~03) 게이트 해제**(생존 유지·잠식 정지). U01~03 의 when 에 `잠식==true` 가드 추가로 구현(초기 잠식=true 라 기존 사건 5 베이스라인 불변).
  - `LAW_M_지배오염`(every 6, 완료방식==지배 전제) → 검은태양병 강도 상승 — **완료방식 전제 후속 법칙**의 실증(§6.2 "분기는 목적이 아니라 법칙으로").
- **일식 약점**: `E_아르카론.재생`(level 정지/감소/보통) 을 CLOCK_일식 이 구동(일식 중=감소). 파괴 방식은 재생<=감소 전제 — "일식 중에만 심장핵 파괴 가능"을 데이터로.
- 신규 노드 상태화(§10 보강 반영): `R_무광의쐐기.존재`·`E_아르카론.{잠식,재생,휴면,지배됨,공생}`·`G2.5.3.{진행,완료방식}`.
- 실증: `--force R_무광의쐐기.존재=true --at 3:ACT_아르카론_파괴@E_플레이어` → 사건 5 9/9. 지배(강도 1→3 오염)·휴면(겨울 잠복)·공생·의식분리(완료 판정) 엔진 확인. detail 커버리지 91→99(E_아르카론.약점 보류 해소, G2.5.3·R_무광의쐐기·S_일식 노드 완료).

## 사건 4 '백야혈청 공개' (P4 전파·생태 연쇄)

- 사슬 C4-1~6: 혈청 공개 → 백야초 남획 → 설원곤충 감소 → 조류 남하 → **굶주린 평원 해충** → 재배 목적 발견.
- `LAW_U03`(P1 유지 — 아르카론 생존이 검은 태양병 강도 하한 유지) + 균형 법칙 3(백야초재생·곤충회복·해충감소) + 조류 귀환 법칙. `LAW_해충_생산압력`이 해충을 `L_굶주린평원.생산`으로 전달 → **사건 1 평원과 교차**(§6). 목적·행동 2(`G_인공백야초재배`).
- 실증: `--force R_백야혈청.공개=3` 무입력 시 6/6 자동 재생.

- 클라이맥스: 심장핵 파괴 → 생존=false → 유지 법칙 **해제**(겨울 해빙·별빛 방출) → **새 존재 등장**(고대생명체 각성·별빛종족 탄생 — 숨김 노드 flag 전환, 런타임 생성 없음: 카탈로그 #18) → 외부 관측(새 시대). 비가역 법칙은 `monotonic:true`.
