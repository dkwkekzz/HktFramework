# 진행 기록 — ④ MMORPG 웹 프로토타입 (세계 표현)

> 설계: [../Design-MMO.md](../Design-MMO.md). 최신 항목을 위에 쌓는다.

## 3단계 — 개입 완료

Design-MMO §9 로드맵 3단계. 완료 기준 충족: **'강의 귀환' 사슬을 플레이어 손으로 시동하고, 그 결과 수문회의 반격이 무대에 오르는 것을 목격한다** (Playwright 실증 — 정책 off → 지열 도시 기록고에서 해독 → 재의 숲 카르마 수확 → 제어탑에서 "재생섬유 3 필요 (보유 1)" 미충족 안내 목격 → 수확 보충 → 복구 발화(완료방식 `ACT_제어탑_복구` 기록, 사슬 5/6) → 정책 on → 수문회 `ACT_수문회_제어탑파괴` pending 무대(현장 배너·습격대 행군) → 제어탑 파괴 → 사슬 6/6. 콘솔 에러 0).

### 상태층 (world-state.json)

- **`ACT_관개기록_해독`** — 보존회 전수(습득 획득). **`ACT_카르마_수확`** — 수분핵·재생섬유 획득 + 서식 -1(P5 제공 규율). 둘 다 WorldLaws §4 대표 완역에 설계돼 있던 행동의 실장 — 플레이어가 재료·지식을 **얻을** 경로가 없어 완주 불가였던 공백의 해소.

### 표현 사전 (world-visual.json) — `actions` 섹션 신설

- 플레이어 행동 18종 전부에 `{ site, spot, glyph, prompt }` — 같은 spot 문자열 = 같은 상호작용 오브젝트(예: "대수근 카르마"에 수확·길들임·제거 3행동). NPC 행동 12종에는 `site` 만(무대 연출 앵커; 수도원 2종은 지역 앵커 없음 — 연대기로만).
- **검증 V7 추가**: 플레이어 행동은 site/spot/glyph/prompt 필수(없으면 발화 UI 에 나타날 수 없음), site 참조 무결, 고아 항목 금지.

### 클라이언트 (game/world.html)

- **행동 바** — 씬의 spot 오브젝트(고정 시드 배치) 근접 시 행동 목록. 상태 4단: 발화 가능(비용·소요 틱 표시) / **전제 미충족(when 잎·cost 부족을 사람 문장으로 나열 — 퀘스트 안내)** / 진행 중(busy) / 완료(once 발화됨). 발화는 `ctx.inputs` 요청 하나 — 임의 쓰기 없음(불변 2·6).
- **NPC 무대 연출** — 엔진 `ctx.pending`(duration 진행 중)을 읽어, 무대 지역 씬에 습격대 행군 + "⚔ N틱 뒤 결판" 배너, 대륙 지도에 ⚔ 점멸. §5 경합 창의 '목격'까지 — counter(대항 행동)는 4단계 예약.
- **씬 개인 HUD** — 플레이어 hud 축(습득·보유·감염·계약) 상시 표시. 행동 불발(skipped)은 사유와 함께 토스트.
- **NPC 정책 토글** — `simulate --no-policy` 대응 디버그. 완주 실증에 사용.

## main 병합 (PR #598 흡수)

병렬 트랙(단계 6·보스전·혈청 3세력·수도원)이 main 에 병합되어 흡수. 해소 요지:

- **엔진 fs 분리 방식 통일** — 양쪽이 같은 문제를 따로 풀었다(이쪽 `process.getBuiltinModule` 지연 로드 vs main 의 `load-world.mjs` 모듈 분리). **main 방식 채택**: `state-engine.mjs` 는 fs 코드가 아예 없는 순수 모듈이 되고 `loadWorld` 는 `load-world.mjs` 로. 이 트랙의 `{target}` 치환 확장(subst/evalPred/fireAction·target 누락 가드)은 그대로 유지 — 1단계 기록의 "getBuiltinModule 지연 로드" 서술은 이 병합으로 대체됨.
- **world-state.json** — main 의 행동 15종(보스전 7·혈청 6·수도원 2) 뒤에 `ACT_이동` 을 이어 붙임. `E_플레이어.위치` 는 자동 병합. vars 87 · rules 62 · actions 31 · objectives 12 · subjects 8.
- **표현 사전 보강** — main 신규분 전수: 변수 13(보스전 축·`T_회귀호흡.공개` 등 — 아르카론 상태 5종은 별빛균열 actor, 무광의쐐기는 용광로 marker, NPC 목적·전승은 gauge), 법칙 연대기 2, 행동 연대기 15, 목적 연대기 5. 클라 글리프 추가(🌑🔆💤⛓🤝·🗡). `validate-visual` import 를 `load-world.mjs` 로 전환. V1~V4·V6 통과 유지.

## 2단계 — 지역 씬 + 아바타 완료

Design-MMO §9 로드맵 2단계. 완료 기준 충족: **대륙 어디든 걸어서 순회하며 지역 연대기를 현장에서 목격한다** (Playwright 실증 — 지열 도시 입장 → 키보드로 걸어 북동 출구 → `ACT_이동` 발화 → duration 2틱 후 착지 → 재의 숲 씬 전환 → 사건 2 발화를 현장 토스트로 목격, 콘솔 에러 0).

### 상태층 (world-state.json)

- **`E_플레이어.위치`** (ref, init `L_지열도시`) — §3.3 "아바타의 지역 단위 위치는 세계 변수다". basis 명시.
- **`ACT_이동`** — 지역 간 이동 행동. 목적지는 **`{target}` 파라미터**(발화 요청에 실림), when `{actor}.위치 != {target}`, then `위치 = {target}`, duration 2. 목적 노드에 속하지 않는 수단 행동(예외를 basis 에 기록). 인접 제약은 표현층 출구 UI 가 담당(인접 데이터는 world-map — 판정 아닌 접근 경로 제공).

### 엔진 형식 확장 (state-engine.mjs — 틱 의미론 ①~⑦ 무변경)

- `subst`/`evalPred`/`fireAction` 에 **`{target}` 치환** 추가 — `{actor}` 와 동일 메커니즘. 효과의 문자열 value 에도 치환 적용(ref 대입).
- `{target}` 을 쓰는 행동은 target 없이 발화 불가(리터럴 대입 방지 — skipped 로 보고).
- `simulate-state.mjs` `--at` 문법 확장: `--at 1:ACT_이동@E_플레이어>L_재의숲`. 기존 검증·시뮬 전부 통과 유지.
- 주의: 입력 경로는 엔진 busy 를 검사하지 않는다(정책 주체만 점유 검사) — 클라가 pendingMove 로 중복 요청을 막는다. 서버화(4단계) 시 서버측 검증 항목.

### 클라이언트 (game/world.html)

- **지역 씬**: 헤더 '지역 입장'(아바타의 현재 위치로만 입장) ↔ '대륙 지도' 토글. 지형별 소품 팔레트(고정 시드 절차 배치), 군집 글리프 배회(밀도=변수값, 보간은 표현 전용), 이름 있는 액터(라벨·클릭 가능), marker 표지판, 전역 상태의 씬 반영(겨울=북방 지역 한랭 톤·일식·홍수·과잉별빛).
- **이동**: WASD/화살표(표현 로컬 픽셀) → 출구 게이트(인접 지역 방향에 배치) 접촉 → `ACT_이동` 발화 요청 → duration 동안 입력 잠금+'이동 중' 배너 → **위치 '상태'가 실제로 바뀐 틱에만 씬 전환**(표현은 상태를 따른다). 도착 시 떠나온 지역 방향 가장자리로 입장.
- **현장 목격**: 현재 지역의 발화가 토스트로 뜬다(지역 연대기의 현장판). 씬 개체 클릭 → 그 축의 상태 카드(§3.2 — 앰비언트 클릭은 종 노드가 열린다).
- 대륙 지도의 아바타 글리프는 `E_플레이어.위치` 사전 항목(actor/@ref)으로 자동 표시 — 이동 중에도 상태가 바뀌기 전엔 출발 지역에 있다(상태 정직성).
- 버그 수정: `mix()` 가 자기 출력(rgb 문자열)을 재입력받으면 NaN — hex·rgb 겸용 파서로 수정.



## 1단계 — 살아있는 지도 (관찰자 모드) 완료

Design-MMO §9 로드맵 1단계. 엔진(`state-engine.mjs`) 틱 로직 무변경 — Node 전용 IO(`loadWorld`)만 정적 `node:` import 에서 `process.getBuiltinModule` 지연 로드로 바꿔 브라우저가 같은 모듈을 임포트할 수 있게 했다(기존 validate/simulate 동작 불변 확인).

### 산출물

| 파일 | 내용 |
|---|---|
| `data/world-map.json` | 대륙 배치 — 지역 16(그래프 L 전부, basis 필수) + feature `RIVER`(제어탑→평원→하구, `S_강흐름.단계`가 폭·색) |
| `data/world-visual.json` | 표현 사전 — 변수 73 전수(표현 66 + 비표현 7 사유 명시), 채널 8종(overlay/tone/density/actor/marker/gauge/hud/none), 연대기 번역문 84(법칙 60·행동 15·목적 7×4상·시계 2), fx 34(EV 단계 법칙 32 전부+수문회 행동 2) |

### 실행·실증

```text
저장소 루트에서: python3 -m http.server 8000
→ http://localhost:8000/HktAdvProtoA/game/world.html
검증: node data/validate-visual.mjs (기존 validate-graph/state 와 함께 전부 통과)
```

- 무입력 실행만으로 씨앗보존회(NPC 정책)가 제어탑을 복구해 사건 1 이 자율 재생되고, 수문회 반격까지 지도에서 목격된다.
- 디버그 방아쇠(=`simulate --force` 대응): 사건1 `L_제어탑.가동=true` · 사건2 `E_회색등늑대.개체수=3` · 사건3 `G3.2.1.진행=2` · 사건4 `R_백야혈청.공개=3` · 사건5 `E_아르카론.심장핵=false`.
- 눈 검증(Playwright·Chromium): 방아쇠 5종 연속 발화 시 지도가 변한다 — 해빙(빙원 톤), 별빛 통로 빛기둥, 별빛 종족 등장(✨), 남하 조류 이동(🐦), 채굴 금지 표지(⛔), 대홍수·외부 관측 오버레이. 사건 게이지 6/6·6/6·9/9·6/6 도달, 콘솔 에러 0.
- 단독 방아쇠 실증: 초기화 후 사건 2 만 발화 → 6/6 자동 재생 (강의 귀환은 NPC 자율로 병행 6/6 — 두 사슬이 같은 `S_강흐름` 위에서 상호작용).
- 표현층 불변 준수: 클라이언트에 세계 쓰기 경로 없음(입력 0 — 방아쇠는 명시적 디버그). 매 프레임은 스냅샷 읽기+보간·연출만(불변 6·7). 지역 씬 절차 배치용 고정 시드 해시 포함(2단계 대비).

### 구현 결정 (설계 문서 외 세부)

- **연대기 스로틀**: `every` 법칙의 반복 발화는 상태는 매번 바꾸되 서사는 같은 id 당 12틱에 1회만 기록 — 유지·회복 법칙의 문장 도배 방지. once 법칙·행동·목적·시계는 매번 기록.
- **행동의 2상 서사**: duration>0 행동은 발화 시 `[착수] …하려 한다`, 효과 착지 시 완성 문장 — 엔진의 pending 의미론을 그대로 표현.
- **지역 연대기**: 발화의 지역 귀속은 fx 의 region, 없으면 효과 대상 변수의 사전 region 으로 추론. 인스펙터에 그 지역 발화만 필터해 표시.
- **인스펙터 = 설명 가능한 세계**: 변수 카드에 현재값(레벨 라벨)·basis·읽는/쓰는 법칙 목록(when/then/formula 정적 색인). 파생축 표기.
- **지도 표현 규칙**: 지역 채도 = tone 변수들의 건강 비율 평균(토양침식은 반전), 군집 점 밀도 = count/level 환산, 액터/표지는 글리프 사전, 전역 오버레이(겨울/별빛/일식/폭풍/홍수/통로/관측)는 overlay 변수의 함수.
