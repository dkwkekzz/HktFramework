> [STATE.md](STATE.md) 는 **현재 핵심 상태와 TODO** 만 담고, 완료된 작업의 상세(권역별 변경 내역·실증 방법·설계 요약)는 이 문서에 누적한다. 최신 항목을 위에 쌓는다.

## 세계 상태·법칙 구현 — 대표 사건 5종 전수 완성

각 권역은 `그래프 보강(별도 커밋) → world-state 확장 → 검증 → 무입력 시뮬 실증` 순으로 진행했다. 그래프 보강은 항상 별도 커밋(§10/§8 규칙).

### 사건 4 '백야혈청 공개' (P4 전파·생태 연쇄)

- 그래프 보강 — 세계 요소 3(`E_백야초`·`E_설원곤충`·`E_남하조류`) + 목적 `G_인공백야초재배` + 관계 8 (180→184 노드·172→180 관계).
- world-state — 사건 4 사슬 C4-1~6(혈청 공개 → 백야초 남획 → 설원곤충 감소 → 조류 남하 → **굶주린 평원 해충** → 재배 목적 발견) + `LAW_U03`(P1 유지 — 아르카론 생존이 검은 태양병 강도 하한 유지) + 균형 법칙 3(백야초재생·곤충회복·해충감소) + 조류 귀환 법칙. `LAW_해충_생산압력`이 해충을 `L_굶주린평원.생산`으로 전달 → **사건 1 의 평원과 교차**(§6).
- 실증 — `--force R_백야혈청.공개=3` 무입력 시 사건 4 가 6/6 자동 재생.

### 사건 5 '아르카론의 죽음' (P1 유지 법칙 해제·새 존재 등장 #18)

- 그래프 보강 — 세계 요소 5(`S_별빛통로북방`·`E_고대생명체`·`S_남부대홍수`·`E_별빛종족`·`S_외부관측`) + 관계 8 (175→180 노드·164→172 관계).
- world-state — **P1 유지 법칙** LAW-U01·U02(아르카론 생존이 영원한겨울·과잉별빛을 지탱) + 사건 5 사슬 C5-1~9. 클라이맥스: 심장핵 파괴 → 생존=false → 유지 법칙 **해제**(겨울 해빙·별빛 방출) → **새 존재 등장**(고대생명체 각성·별빛종족 탄생 — 숨김 노드의 flag 전환, 런타임 생성 없음: 변형 카탈로그 #18) → 외부 관측(새 시대). 비가역 법칙은 `monotonic:true` 로 §6 회복 짝 요구에서 면제.
- 검증 보강 — 법칙검증5 개선(회복원에 행동·목적의 복원 set 포함, `monotonic` 규칙 면제). `every:N` 규칙의 검증9 상호배타 판정에 `단계==k`·`생존==bool` 가드 활용.
- 실증 — `--no-policy --force E_아르카론.심장핵=false` 무입력 시 사건 5 가 9/9 자동 재생. G2.5.3 6방식 보스전(§6.2)은 TODO 로 분리(사건 5 는 심장핵 파괴 방아쇠만 요구).

### 사건 3 '심연유리 호황' (P5 경제·개체 이동·세력 전쟁)

- 그래프 보강 — NPC 목적 `G_유리잠수단_채굴지속`·`G_해안세력_채굴금지` + 관계 7 (173→175 노드·157→164 관계). 충돌 구조(채굴 vs 금지) 명시.
- world-state — 사건 3 사슬 C3-1~6 + **P5 경제**(`R_심연유리.수요` 파생=무광의 쐐기 진행 중 · 채굴 행동이 공급 소모) + **생태 cascade** LAW-E01~03(산호·유리벌레 서식 붕괴) + **개체 이동**(`E_심해포식자.위치` ref 를 심해→침몰해안으로 set — 변형 카탈로그 #5) + **세력 전쟁**(C3-6 이 `F_유리잠수단.관계.F_상인연합`을 적대로) + 두 NPC 목적·행동 4 + 균형 법칙 2.
- 실증 — `--force G3.2.1.진행=2` 무입력 시 사건 3 자동 재생: 잠수단 채굴 → 공급 하락 → 산호 붕괴 → 포식자 상륙 → 해안 공격 → 채굴금지 목적 발견·전쟁 → 상인연합 해안 방어로 안전 회복·관계 완화.

- world-state — 사건 2 사슬 C2-1~6(단계 counter + `every` 누적 A1/A2/A3) + 균형 법칙 4종 + `G_늑대복원` 목적·행동 2. `S_토양침식.활성`은 **파생축**(식생≤0)으로 두어 set 충돌·회복 교착을 원천 차단.

## 설계 요약 (참조)

### Design-WorldState.md (형식)

- **다섯 층 모델**: ① vars(노드 귀속·`basis` 필수) ② initial(스냅샷) ③ rules(자율) ④ actions(주체 선택, 전제·비용·duration) ⑤ objectives(discover/complete/fail).
- **축 문법 3종**: 단축 `노드.축` / 쌍축 `노드.축.노드` / 파생축(함수, 쓰기 금지). 값 4종 flag/level/count/ref. 결정론(정수 틱).
- **변형 전수 카탈로그 18종**(§4) — 모든 변형이 환원돼야 하는 표현. 런타임 노드 생성 금지(새 존재 등장 = 숨김 노드 상태 전환).
- **틱 의미론**(§5.3): 읽기/쓰기 분리, set 충돌 = 검증기 거부, once 발화 기록 = 내장 상태. 주기 조건 = 시계 법칙(§5.4).
- **완료 판정 = 상태 술어**: 어떤 행동이든 목표 상태면 완료. `완료방식`(ref)의 후속 분기는 법칙이 담당.
- **NPC 구동**(§8): subjects + policy 우선순위 목록.
