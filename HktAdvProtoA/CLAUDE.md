# CLAUDE.md

HktAdvProtoA — 목적 트리 기반 오픈월드 어드벤처 프로토타입.

## 목표

이전에 경험하지 못했던 끝없는 성장과 상호작용을 통해 다채롭고 도파민을 뿜어내는 모험을 경험을 제공하는 세계를 구축한다.

## 지켜야 할 사항

이 프로젝트의 세계 설계는 [Design-ObjectiveTree.md](Design-ObjectiveTree.md) 의 목적 트리 원칙을 절대 기준으로 따른다. 세부 규칙은 해당 문서를 참조하되, 다음 핵심 원칙은 모든 작업에서 항상 지킨다.

1. **먼저 목적, 그다음 세계.** 지형·생명체·아이템·스킬·문명·세력·사건을 먼저 만들고 목적을 끼워 맞추지 않는다. 목적을 분해한 결과로 세계 요소를 도출한다.
2. **최상위 목적은 생존이다.** 모든 하위 목적(탐험, 성장, 전투, 제작, 거래, 연구, 건설, 세력 형성 등)은 생존에서 파생된 하위 목적으로 정의한다.
3. **목적은 상태 변화다, 행동이 아니다.** "늑대를 처치한다"가 아니라 "야영지를 습격하는 늑대 무리를 저지하여 밤의 생존 가능성을 높인다"처럼 만들고자 하는 세계 상태로 기술한다.
4. **모든 세계 요소는 존재 근거를 가진다.** 재료·생명체·지형·스킬·세력·역사 각각에 생성 원인, 제공자, 관련 목적을 기록한다. 근거 없는 요소는 세계에 추가하지 않는다.
5. **양방향 추적 가능성.** 목적을 아래로 분해하면 세계가 도출되고, 세계 요소를 위로 역추적하면 어떤 목적을 위해 존재하는지 설명할 수 있어야 한다.
6. **하나의 요소는 여러 목적과 연결된다.** 재료·장소·생명체는 퀘스트 전용 소품이 되어서는 안 되며 여러 목적의 교차점이어야 한다.
7. **하나의 목적은 여러 해결 방법을 가진다.** 플레이어가 정해진 순서로 콘텐츠를 소비하지 않고 자신만의 해결 방법을 선택할 수 있게 한다.
8. **플레이어 외 주체도 자신의 목적을 가진다.** 생명체·세력·문명·현상은 각자의 생존/유지 목적에 따라 행동하며, 서로 다른 목적 트리의 충돌과 결합이 세계의 사건을 만든다.
9. **목적 완료·실패는 세계 상태 전환이다.** 콘텐츠 종료가 아니라 세계가 다른 상태로 바뀌는 사건으로 취급하고, 파생 목적을 남긴다.
10. **검증 규칙 준수.** 새 목적 트리나 세계 요소를 추가할 때는 Design-ObjectiveTree.md 16절의 검증 15개 항목으로 자체 점검한다.

작업 진행 상황은 항상 [STATE.md](STATE.md) 에 기록하고, 새 작업을 시작하기 전에 먼저 읽는다.
