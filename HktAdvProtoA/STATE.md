# STATE.md

## 구현 현황

**상흔계 아벨리온** 목적 그래프 구축 완료 (타입 노드 + 타입 관계 모델).

- `Design-ObjectiveGraph.md` — 상흔계 아벨리온의 목적 그래프 정본 (세계 시드·표기 규칙·G0~G9 전개·교차 그래프·대표 사건). [Design-ObjectiveTree.md](Design-ObjectiveTree.md)(방법론)와 겹치는 부분은 이 문서가 우선.
- `data/objective-graph.json` — **유일한 원본 데이터** (**163 노드 · 133 관계**). 목적 추가·수정은 여기 한 곳에서만 한다(HTML 편집기 또는 JSON 직접 편집).
  - 노드 타입: `G`목적 `S`상태 `E`생명체·인물·신 `R`재료·에너지·정보 `L`장소·지형·시설 `K`지식·기록·제작법 `T`스킬·기술·의식 `F`세력·문명 `H`과거 사건 `X`위협 `EV`사건.
  - 관계 타입: `필요` `제공` `방해` `충돌` `변화` `상호` `파생`.
  - 목적 분해 트리 G0→G1~G9 전체 + 명명된 세계 요소(아르카론·카르마·심연유리·뇌철 결정·검은 태양병·회귀 호흡·세리아·구름고래 등) + 대표 사건 5종(변화 사슬).
  - `meta.world` 에 세계 시드, `meta.nodeTypes`/`relationTypes`/`relationHelp` 로 스키마 자기 기술.
- `data/validate-graph.mjs` — 검증 전용 (데이터 없음). JSON 을 읽어 id 중복·parent/link 참조·순환·타입만 확인. `node data/validate-graph.mjs`.
- `objective-tree.html` — 타입 모델 대응 관찰·편집기 (의존성 없는 단일 파일).
  - 트리 뷰: 목적 분해 트리 + 세계 요소를 타입별 그룹으로. 타입 태그·검색·접기/펼치기.
  - 그래프 뷰: 목적 tidy-tree + 세계 요소 타입별 컬럼, 타입 관계를 색상 점선으로. `선택 노드 관계만 표시` 토글, 이동/확대.
  - 편집: 이름·타입 변경·상위 목적(분해) 재지정·세부 항목(라벨↔값, 문자열/리스트) 추가·삭제·타입 관계(방향·종류·설명) 추가·삭제·노드 추가/복제/삭제.
  - localStorage 자동 저장 + JSON 내보내기/가져오기 + 원본 복원. `세계 시드` 버튼으로 아벨리온 배경 표시.
  - 로컬 서버 권장: `python3 -m http.server` 후 `objective-tree.html` (file:// 은 `가져오기`로 JSON 직접 로드).

**세계 상태 데이터화** 설계 v2 완료 (구현은 다음 단계).

- `Design-WorldState.md` — 목적 그래프(1번)를 근거로 세계 상태를 데이터로 표현하는 설계. v2 는 163노드·133관계 전수 조사로 보강.
  - **다섯 층 모델**: ① vars(상태 변수 — 노드 귀속·`basis` 필수) ② initial(스냅샷) ③ rules(법칙 — 자율 발화) ④ actions(행동 — 주체 선택 발화, 전제·비용·duration) ⑤ objectives(목적 생애주기 — discover/complete/fail 술어).
  - **축 문법 3종**: 단축 `노드.축` / 쌍축 `노드.축.노드`(계약·감염·보유·습득·관계) / 파생축(함수, 쓰기 금지). 값 4종: `flag`/`level`/`count`/`ref`. 결정론(정수 틱).
  - **변형 전수 카탈로그 18종**(§4) — 세계의 모든 변형이 환원돼야 하는 표현 목록. 런타임 노드 생성 금지(새 존재 등장 = 숨김 노드의 상태 전환).
  - **틱 의미론**(§5.3): 읽기/쓰기 분리(스냅샷 기준 일괄 평가), set 충돌 = 검증기 거부, once 발화 기록 = 내장 상태. 주기 조건(일식·폭풍)은 시계 법칙(§5.4).
  - **완료 판정 = 상태 술어**: 어떤 행동으로 도달했든 목표 상태면 완료. `완료방식`(ref)으로 방식별 후속 분기는 법칙이 담당.
  - **NPC 구동**(§8): subjects + policy(우선순위 목록) — 발견된 목적을 기계적으로 수행. 플레이어 없이도 세계가 변하는 실행 주체.
  - **그래프 보강 요구**(§10): E_플레이어·L_제어탑·S_강흐름·R_식량·R_무광의쐐기·S_일식·G_수문회_제어탑파괴 — 상태화에 필요하지만 그래프에 없는 노드. world-state 작성 전 선행 커밋.

**세계 법칙** 설계 완료.

- `Design-WorldLaws.md` — 법칙의 **내용** 설계 (WorldState 가 형식, 이 문서가 내용).
  - 법칙 패턴 7종: 유지/압력/생태/전파/경제/반응/시계. 형식 보강: rules 에 `every: N`(주기 재발화) 추가.
  - 자율 법칙 42개 전수 번역 — 변화 15(초기값 2·유지 5쌍·파생 2·사슬 개시 6), 방해 16(압력 8·행동 효과 2·생태 5·중복 1), 충돌 9(반응 법칙 LAW-R01~09 — 상대 NPC 목적 발견), 상호 2.
  - 사건 사슬 5종 완역(C1~C5) — "once 방아쇠 → every 전파 → 목적 발견으로 종결" 패턴 확립.
  - 필요 53·제공 36 → 행동 번역 규칙 + '강의 귀환' 권역 행동 5개 완역 (전체 카탈로그는 데이터 단계).
  - NPC 정책 12주체 (세력 10 + 늑대·카르마) — **그래프에 NPC 목적 노드가 전무하다는 구조적 공백 발견** (트리 §2 미구현).
  - 균형 법칙 LAW-B01~04 — 모든 압력에 회복 짝 (단조 붕괴 금지, 사건 사슬 양방향화).
  - 그래프 보강 추가 발견: 세계 요소 11 + NPC 목적 17 + 축 4 (WorldState §10 에 누적).
