## 4. DURABLE CONSTRAINTS — 반복 참조 수치 (원칙의 권위는 CLAUDE.md)

- 창세 `W:SRC` = 10⁹ · 에너지 전부 정수 · 서버 틱 10Hz · 비콘 5Hz(양자화) · 지역 체크섬 3초.

- 필드 이질화(A7-2): 셀 풍요도 배수 [1..4] 시드 유도 · 노드 재충전 = `NODE_REGEN_AMOUNT × 풍요도`(셀→노드) · 셀 잔고 자체는 균질(강한 확산 grad/4).
- 생명 간 이체(A7-3): `INTENT.GIVE {targetId,amount}` = `player→player` 자유 에너지 증여 · 사거리 `GIVE_RANGE`=120 · 클램프(증여자 고갈/수령자 만충).
- 타입 채집·합성(A8-1): 재료 7종(`MATERIALS` = `{affinity,abundance}`·시드 유도 노드 `mat`) · `INTENT.MINE {nodeId}` = `노드→창고 G:p#mat` 25/회 · `INTENT.FORGE {mat}` = `창고 100 + 생체 50 → 아이템`(잔고=두 이체 합·민팅 없음) · 종류=원장 밖 라벨(보존 무관), 양=원장 안(보존).
- 가치 단일화(A9-1): 아이템 위력 = f(잔고)뿐 — 재료는 배율에 개입 안 함(옛 `div` 제거). `affinity`=채널(발산/획득), `abundance`=worldgen 분포 가중(나무·돌 6 … 금·불 1) → 재료 다양성=희소성. "총량이 가치를 결정한다".
- 엔트로픽 누수(A9-2): 이완 커널 `shared/entropy.js` — `relaxGradient`(두 풀·필드 확산 일반형)·`entropicLeak(잔고,num,den)=floor(잔고×num/den)`. 소유 아이템은 `DECAY_INTERVAL_TICKS`=50 마다 2%(1/50) `item→SINK` 누수(양자 바닥 1)→0 이면 소멸. `WEAPON_WEAR` 제거. 소산분은 태양 순환 복귀(보존).
- 이동 50px 당 에너지 1 (`플레이어→소실`) · 전투 기본 데미지 = 결정론 롤 30±10(위임 가능·25% 표본 감사) → 50% 흡수(`피격자→공격자`) + 50% 소각(`피격자→소실`) · 노드 재충전 5초 주기(`SOURCE→셀→노드`) · 구조 = 조직별 풀 `S:<id>#<organ>`(organ∈{atk,meta}, 발산=공격·대사=채집·유지비=총 구조) · 대사 못 채우면 구조 이화(`구조→플레이어`)로 연명 → 아사 = 자유 0 && 총 구조 0(전투사는 구조 불가침) → 드랍 + `세계→플레이어` 리스폰 인출.
- 틱 플러시 순서 LEAVE→OPS→ENTER · 서버 처리 순서 리스폰→인텐트 FIFO→재충전→플러시.
