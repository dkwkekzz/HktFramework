# step-0007 — 공간 개념 3D 전환 (컬럼형)

> 위치·거리·사거리·속도 예산을 전부 3D(x,y 수평 + z 높이)로. 이후 3D 렌더의 토대.

## 1. 한 일 (어느 파일에 무슨 메커니즘)

- **`shared/`**:
  - `constants.js`: `WORLD_HEIGHT=1000` · `SPAWN_POS.z` · `dist3(ax,ay,az,bx,by,bz)`. `regionKey`/`fieldCellOf` **불변** — 파티션은 (x,y) 컬럼, z 는 컬럼 내 자유(수직은 분할 안 함).
  - `worldgen.js`: 노드·몬스터 `z` 배치(시드 유도).
  - `protocol.js`: BEACON/WELCOME/TELEPORT/POS/ENTER 에 z (JSON). 바이너리 tx 는 무관(위치 미포함).
- **`server/`**:
  - `game.js`: `dist3` 로 교체(채집·공격·픽업 사거리, 비콘 속도 예산). 플레이어·아이템 z, 비콘 z 클램프(`WORLD_HEIGHT`), 스폰·리스폰·TELEPORT·드랍·POS·ENTER·스냅샷에 z. **원장·region·필드 코드 불변**(컬럼).
  - `monster.js`: 3D 내비(`dist3`, 3D `#moveToward`, 비콘 z).
- **`client/`**: `state.js` 미러 z(노드·몬스터 z 는 시드 유도), `sim.js` 수직 이동 `R`/`F` + 비콘 z, `bots.js` 3D 내비. `render.js` 는 top-down 2D 투영 유지(고도 표시만 추가) — 3D 렌더는 후속.

## 2. 검증 (`npm test` + 봇 시뮬 2026-07-06 출력)

- **pass 28 / fail 0**. 기존 26종 3D 좌표로 회귀 무손실 + 2종:
  - `3D 공간 — 사거리가 z 를 포함한다`: 같은 (x,y) 라도 z 를 `GATHER_RANGE+40` 띄우면 채집 `out-of-range`, z 를 노드 높이에 맞추면 채집 성공 — 거리가 3D 임을 증명.
  - `3D 속도 예산 — 수직 순간이동 비콘도 기각`: 0.1초 수직 500px 비콘 TELEPORT 정정, z 불변.
- 봇 8기 + 몬스터 6기 3D 라이브(~17초): `세계 총 10⁹ · 체크섬 OK` 반복, 서버 에러 0.

## 3. 불변식 판정 + 한계

- **보존·검증·미러**: 좌표는 여전히 권위 아님(비콘=예산·사거리 검증용), 파티션·체크섬은 (x,y) 컬럼 유지 → 미러 정합·보존 불변. 테스트·라이브 총합 10⁹ 불변.
- **정직한 한계**: ① 파티션·필드 셀은 컬럼(2D) — 완전 볼류메트릭(수직 분할)은 미도입(검증된 relevancy·대역폭 모델 보존 선택; 수직이 주 이동축인 세계라면 재검토). ② 렌더는 top-down 2D 투영(사거리 원은 3D 구의 근사) — 3D 렌더는 예정. ③ 필드 확산은 여전히 (x,y) 2D 격자 — z 방향 확산 없음(필드는 컬럼 자원).
