# step-0018 — A7-3 생명 간 이체 (플레이어 간 에너지 증여 = MMO 관계)

## 1. 한 일

병렬 솔로에 머물던 플레이어 상호작용(전투·노드 경합뿐)에 **자발적 에너지 증여**를
더했다 — 협력·교환·부양이 이체 문법으로 표현되어 "다중접속 관계"가 생긴다.

- `shared/protocol.js`: `INTENT.GIVE { targetId, amount }`.
- `shared/constants.js`: `CAUSE.GIVE` · `GIVE_RANGE=120`(근접해야 증여).
- `server/game.js`: GIVE 인텐트 처리 — 대상이 살아있는 다른 플레이어·사거리 안 검증 후
  `player→player` 이체(`#tx`, 클램프). Got<Want 는 게임플레이(증여자 고갈/수령자 만충).
  사거리 안이면 양쪽 시야가 겹쳐 미러 정합(from=증여자·to=수령자 둘 다 relevant).
- `tools/bots.js`: 여유 있고 근처에 나보다 궁한 동료가 있으면 60 을 나누는 협력 행동
  (인기 노드에 모일 때 부유→빈곤 흐름) + 증여 누적 카운터 전시.

## 2. 검증

`npm test` **38/38** 통과 (37→38, A7-3 추가). 전 불변식 회귀 무손실.

- `[A7-3] 증여 giver→taker 120·자기증여/사거리밖 기각·부양 50 · 총합 1000000000 불변`
  — giver→taker 증여로 자유 이체(증여자↓·수령자↑), 양쪽 클라 미러 정합, 자기 증여 기각,
  사거리 밖 기각, 굶주린(자유 0) 동료를 증여로 되살림(부양). 전 과정 보존.
- 라이브 `node tools/bots.js 8` (~28s): 세계 총 에너지 1,000,000,000 불변 · 체크섬 OK ·
  에러/RESYNC 0 · **증여 누적 38회(협력)** — 라이브에서 플레이어 간 에너지가 실제로 흐름.

## 3. 불변식 판정 + 한계

- **보존 ✅**: 증여는 `player→player` 이체(클램프) — 총합 10⁹ 불변(테스트·라이브 38회).
- **이체 문법 ✅**: MMO 관계 = `{giver→receiver}` 단일 이체. 새 예외 없음.
- **미러 정합 ✅**: from/to 양쪽이 소유자 relevant + 사거리 안이라 시야 겹침 → 양쪽 클라 재생 일치.
- **한계**: 단방향 증여만 — 원자적 양방향 교환(escrow)·공유(파티/길드) 풀·기생 강제는 미도입
  (교환은 두 번의 GIVE 로 근사 가능하나 원자성 없음). 증여는 자유 에너지만(구조·아이템 증여 별도).
  봇 협력은 근접 시에만 발동(분산되면 뜸함) — 사회적 군집·거래소는 관찰/후속 소관.
