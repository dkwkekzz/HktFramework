# step-0013 — A6-4 스킬 = 발산 패턴

## 1. 한 일

스킬을 **비용 있는 증폭 이체 패턴**으로 구현한다: `player→SINK`(시전 비용 = 대사 스파이크) + 구조·쿨다운 게이팅된 증폭 데미지 버스트. 스킬마다 흡수(`피격자→공격자`) vs 소각(`피격자→SINK`) 비율이 달라 *형태가 차별*된다.

- `shared/constants.js` — `SKILLS` 테이블: `smash`(강타 — 큰 소각 버스트, leech 20%) · `drain`(흡정 — 큰 흡수, leech 90%). 각각 cost·base·structDiv·leechPct·cooldownMs.
- `shared/growth.js` — `skillDamage(skill, struct) = base + floor(struct/structDiv)` (구조가 위력↑, 여전히 피격자 클램프).
- `shared/protocol.js` — `INTENT.SKILL = 'skill'` (`{ skillId, targetId }`).
- `server/game.js` — SKILL 핸들러: 스킬 존재·**스킬별 쿨다운**·타깃·사거리·시전비 검증 → 시전비 `player→SINK` + `피격자→공격자`(leechPct) + `피격자→SINK`(잔여) + 잔고 0 시 `#kill`. 플레이어당 `skillCd` 맵 추가.

기존 데미지 tx 타입(atk-cost/leech/burn) 재사용 — 미러는 결과 tx 만 재생, 스킬 로직 재계산 없음.

## 2. 검증

`npm test` **33/33** 통과(신규 1종, 기존 32종 회귀 무손실). 신규 `A6-4 스킬`:

- **형태 차별** — 흡정: 데미지 15 중 흡수 13(공격자 순증가 = 13−시전비 8) · 강타: 데미지 35 중 소각 28(SINK 증가 = 시전비 20 + 소각 28). `drain.leechPct(90) > smash.leechPct(20)`.
- **구조 스케일** — `skillDamage(smash, 600) > skillDamage(smash, 0)`.
- **쿨다운 강제** — 흡정 즉시 재시전은 `cooldown` 기각.
- 매 단계 총합 불변.

실측 출력: `[A6-4] 흡정 흡수 13/15(cost 8) · 강타 소각 28/35(cost 20) · 쿨다운 강제 · 총합 1000000000 불변`.

## 3. 불변식 판정 + 한계

- **보존(#1)**: ✅ 시전비·흡수·소각 전부 `#tx` — 데미지는 피격자 인출, 총합 불변.
- **미러(#4)**: ✅ 스킬은 서버 판정, 결과 tx(atk-cost/leech/burn)만 방송·재생. 새 cause 없음(바이너리 인코딩 유지).
- **검증(#2~3)**: 쿨다운·사거리·시전비를 서버가 강제(스킬별 쿨다운) — 클라 위임 아님.
- **한계**: (a) 스킬 2종·고정 파라미터 — 밸런스 아닌 "형태 차별" 증명 목적. (b) 스킬은 A2 위임 감사 대상 아님(서버 canonical 계산만) — 위임 스킬 판정은 미도입. (c) 자원(연출·쿨다운 UI)은 범위 밖 — 서버/프로토콜/원장 층만.
