# step-0004 — A3 영속화: 원장 잔고 저장·복원

> "상태 = 원장뿐" 최종 시험. 영속은 원장 잔고 직렬화/복원이 전부여야 한다.

## 1. 한 일 (어느 파일에 무슨 메커니즘)

- `shared/ledger.js`:
  - `serialize()` → 전 풀을 `[id, balance, max, region]` 배열로. 순수 로직(저장 계층 무관, C++ 이식 대상).
  - `load(records)` → 풀·지역 합계를 통째로 재구축(`createPool` 이 O(1) 로 지역 합계 복원).
- `server/game.js`:
  - 생성자를 `#genesis()`(창세) / `#restore(snap)`(복원)로 분리. `new GameServer({ snapshot })` 면 창세를 건너뛰고 잔고 복원.
  - `snapshot()` → `{ v, tickCount, txSeq, nextItemNo, pools, items[], mobs[] }`. 노드·몬스터 **배치·max·cell 은 담지 않는다**(시드 유도) — 잔고만 원장에서.
  - `#restore` 는 `ledger.load` 후 배치를 `generateWorld(WORLD_SEED)` 로 재유도하고, 몬스터 dead/respawnAt·아이템 소유 메타만 스냅샷에서 얹는다.

## 2. 검증 (`npm test` 2026-07-06 출력)

- **pass 21 / fail 0**. 기존 19종 회귀 무손실 + 2종:
  - `직렬화→복원 라운드트립`(ledger) — 40풀 + 2000회 이체 폭풍 후 JSON 경유 복원, 전 풀 잔고·지역 합계·총합 완전 일치.
  - `A3 영속화`(game) — 채집·응축·몬스터 처치로 분포를 흐트린 뒤 `snapshot()`→JSON→`new GameServer({snapshot})`: 복원 후 **세계 총합 10⁹ 불변 + 전 지역 체크섬 원본 일치 + 전 풀 잔고 일치**, 몬스터 dead·아이템 메타 복원. 복원 서버를 60틱 더 굴려도 총합 불변.

## 3. 불변식 판정 + 한계

- **보존**: 복원은 기록된 분포를 그대로 재생(창조·소멸 없음) → 총합 정확히 10⁹. 라운드트립·복원 후 재틱 모두 확인.
- **"상태 = 원장뿐" 성립**: 배치·max 는 시드 유도, 잔고만 저장해도 세계가 되살아난다 — SPINE §1 A3 완료 판정(재시작 후 체크섬 일치 + 총합 불변) 충족.
- **정직한 한계**: ① 스냅샷은 메모리 객체 반환까지 — `server/index.js` 의 디스크 저장·부팅 로드 배선은 미도입(수송 계층 관심사, 이 트랙 범위 밖의 사소 작업). ② 플레이어 풀은 스냅샷에 남지만 재시작 후 재접속 시 `nextPlayerNo` 가 1부터라 고아 풀과 id 충돌 여지 — 접속 정체성 복원은 이 주장(잔고 영속) 밖, 별도 처리 필요.
