# step-0017 — A7-2 필드 이질화 (지역별 풍요도 = 영토 가치)

## 0. 직관 (한눈에)

**예전엔 온 세상 땅이 똑같아** 어디서 캐든 자원이 같은 속도로 다시 찼다. 이제 땅마다
비옥도가 다르다(1~4배). 비옥한 땅의 자원은 4배 빨리 다시 차고, 척박한 땅은 느리다.
그래서 "좋은 땅"이 생긴다 = **영토 가치**. 지구에 옥토와 사막이 있듯, 세계에 부유/빈곤
지역이 갈린다("지구 같은 다채로운 복합계").

## 1. 한 일

균질하던 필드를 시드 유도 풍요도로 이질화해 **부유/빈곤 지역**을 갈랐다 — 부유 지역
노드가 빨리 재충전되어 영토 가치가 공간에 분포한다("지구 같은 복합계").

- `shared/constants.js`: `FIELD_RICH_MIN=1`·`FIELD_RICH_MAX=4`(풍요도 배수 범위).
- `shared/worldgen.js`: `generateFieldRichness(seed)` — 셀별 풍요도 배수를 시드 파생 독립
  스트림으로 유도(노드/몹 유도 불변). 배치처럼 동기화하지 않는 시드 유도.
- `server/game.js`: 창세에 풍요도 맵 생성(비영속·복원 시 재유도), 각 노드가 자기 셀 풍요도를
  물려받음(`n.richness`). **노드 재충전량 = `NODE_REGEN_AMOUNT × 풍요도`**(셀→노드, 클램프).
  셀 자체는 균질 저수지로 유지 — 강한 확산(grad/4)이 셀 잔고 구배를 씻으므로 이질성은
  노드 재충전 속도에 실었다(확산에 무너지지 않는 영토 가치).

## 2. 검증

`npm test` **37/37** 통과 (36→37, A7-2 추가). 전 불변식 회귀 무손실 — A6-0 태양 순환 포함.

- `[A7-2] 풍요도 1~4 · 1주기 노드 회복 부유 160 > 빈곤 40 · 총합 1000000000 불변`
  — 풍요도는 시드 결정론·이질적(범위 [1..4]). 부유 셀 노드는 한 재충전 주기에 `40×4=160`,
  빈곤 셀 노드는 `40×1=40` 회복 → 4배 영토 가치. 셀→노드 이체라 민팅 없음·보존.
- `[A6-0] 재순환 주기 50틱 · SINK 최고 5000→0 · SOURCE 정상상태` — 이질화 후에도 SOURCE 정상상태 유지.
- 라이브 `node tools/bots.js 8` (~20s): 세계 총 에너지 1,000,000,000 불변 · 체크섬 OK ·
  에러/RESYNC 0 (노드 재충전 tx 미러 정합).

## 3. 불변식 판정 + 한계

- **보존 ✅**: 노드 재충전은 `셀→노드` 이체(클램프) — 배수만 커질 뿐 민팅 없음·총합 10⁹ 불변.
- **이체 문법 ✅**: 이질화 = 재충전 이체량 스케일. 신규 이체 종류 없음.
- **미러 정합 ✅**: 셀→노드 재충전은 기존 방송 경로 그대로 — 클라가 스케일된 tx 를 재생.
  풍요도 자체는 시드 유도(비동기화)라 클라가 서버와 동일하게 유도.
- **한계**: 셀 잔고 자체의 공간 구배는 지속되지 않는다(확산이 균질화) — 정직한 반례로,
  영토 가치는 셀이 아니라 **노드 재충전 속도**에 실었다. 노드 위치·풍요도는 시드 고정이라
  동적 지역 변화(고갈로 인한 이주·영토 쟁탈)는 미도입(플레이어 밀도·경합 관찰 소관).
  풍요도는 재충전 속도만 가르며 노드 용량(max)은 아직 균질.
