# step-0009 — A6-0 태양 순환 (SINK→SOURCE 재순환)

## 1. 한 일

세계를 **닫힌 열역학 루프**로 만든다: 소산 에너지(`W:SINK`)를 주기적으로 `W:SRC`(태양 원점)로 되돌린다. 서버는 유일한 에너지 원점이되 *생성기가 아니라 순환의 원점* — 에너지는 `SOURCE→생명→SINK→SOURCE` 로 영원히 돈다.

- `shared/constants.js` — `RECYCLE_INTERVAL_TICKS = 50`(5초 주기) + `CAUSE.RECYCLE = 'recycle'` 추가. 월드 소스/싱크 주석을 "닫힌 루프의 두 끝"으로 재서술.
- `server/game.js` `tick()` — 필드 확산 직후·재충전 직전에 재순환 블록 추가: `tickCount % RECYCLE_INTERVAL_TICKS === 0` 이면 `ledger.transfer(SINK, SOURCE, SINK잔고, RECYCLE)`. 재충전보다 먼저 실행해 SOURCE 를 채운 뒤 세계로 흘려보낸다.
- 재순환은 `region=null` 저수지 간 이체 → 방송·체크섬과 무관(무음 `transfer`, `#tx` 아님). 필드 주입(`SOURCE→셀`)과 동일한 서버 내부 순환 패턴.

이 순환이 없으면 이동·전투·(향후 A6-1 대사)가 세계를 SINK 로 단조 소산시켜 영속이 깨진다. A6 아크(생명=소산 구조)의 토대.

## 2. 검증

`npm test` **29/29** 통과(신규 1종 추가). 신규 테스트 `A6-0 태양 순환`:

- **(1) 기본** — SINK 에 12345 소산 모사 후 경계 tick 직전까지 유지되다가, `tickCount === 50` tick 에서 전량 SOURCE 로 복귀(`SINK=0`, `SOURCE=src0`).
- **(2) 반복** — 4주기 반복: 매 주기 5000 소산 → 재순환 → `SINK 최고 5000→0`, `SOURCE 정상상태`(src0 복귀), 매 주기 총합 불변.

실측 출력: `[A6-0] 재순환 주기 50틱 · SINK 최고 5000→0 · SOURCE 정상상태 · 총합 1000000000 불변`.

## 3. 불변식 판정 + 한계

- **보존(#1)**: ✅ 재순환도 `ledger.transfer` 한 경로 — 총합 `1000000000` 불변. 매 주기 assert.
- **중재·검증·미러(#2~4)**: 영향 없음 — 재순환은 무지역 저수지 간 무음 이체라 방송·체크섬 대상 아님. 기존 28종 전건 회귀 통과.
- **한계**: (a) 재순환은 주기 full-drain(SINK 전량) — 연속 방사가 아니라 톱니형. 창발 관찰에는 충분하나 물리적 "연속 flux" 모델은 아니다. (b) 현재 소산원은 이동·전투뿐 — 지속 대사 압력은 A6-1 에서 도입. (c) 클라 미러는 SOURCE/SINK 를 무한 우물로 물질화하므로 재순환을 재생하지 않는다(무해 — region=null, 체크섬 무관).
