# step-0014 — A6-5 아이템 = 결정체 장착

## 1. 한 일

아이템(응축 에너지)의 **현재 잔고**가 유효 스탯을 증폭한다 — 실재하는 에너지를 *읽을* 뿐 민팅하지 않는다. 두 방향의 증폭:

- **무기 → 발산(공격) 증폭**: `damage += weaponBonus(무기 잔고)`. 마모(`item→SINK`)로 잔고가 줄면 증폭도 준다. 데미지는 여전히 피격자 풀로 클램프.
- **결정 → 획득(채집) 증폭**: 결정 소지 시 채집량 `= GATHER_AMOUNT + gatherBonus(결정 잔고)`. 노드가 제공(민팅 아님), `Got<Want` 클램프 유지.

- `shared/constants.js` — `WEAPON_BONUS`(플랫 30) 제거 → `WEAPON_ATK_DIVISOR = 8` · `CRYSTAL_GATHER_DIVISOR = 10`.
- `shared/growth.js` — `weaponBonus(bal)` · `gatherBonus(bal)` 순수 함수.
- `server/game.js` — 전투: 무기 증폭 = 마모 전 잔고의 함수. 채집: 소지 결정 잔고로 증폭.

동기화되는 것은 결과 tx(gather/leech/burn/wear)의 금액뿐 — 미러 재계산 없음.

## 2. 검증

`npm test` **34/34** 통과(신규 1종, 기존 33종 회귀 무손실). 신규 `A6-5 아이템`:

- **순수 함수** — `weaponBonus`·`gatherBonus` 잔고에 단조 증가.
- **발산 증폭** — 무기(250) 소지 공격 데미지 = `canonical + weaponBonus(250)=+31`(마모 전 잔고).
- **획득 증폭** — 결정(100) 소지 채집 = `GATHER_AMOUNT + gatherBonus(100)=+10`.
- **해제 제거** — 무기 드랍 후 공격 = 증폭 없는 `canonical` (dealt2 < dealt).
- 매 단계 총합 불변(민팅 없음 — 데미지·채집 전부 클램프).

실측 출력: `[A6-5] 무기 발산 +31(드랍 시 0) · 결정 획득 +10 · 민팅 없음(클램프)·총합 1000000000 불변`.

## 3. 불변식 판정 + 한계

- **보존(#1)**: ✅ 증폭은 이체 *금액의 상한*만 높인다 — 공격은 피격자 인출, 채집은 노드 인출로 여전히 클램프. 새 에너지 없음.
- **미러(#4)**: ✅ 결과 tx 만 방송·재생. 새 cause 없음.
- **중재(#2)**: 채집 증폭도 FIFO·`Got<Want` 클램프 그대로 — 동시 채집 중재 불변.
- **한계**: (a) 무기·결정 2종 고정 계수 — 밸런스 아닌 "아이템 에너지 = 증폭기" 증명. (b) 명시적 장착 슬롯 없음 — 소지=적용(무기 1·결정 1 우선). 다중 장착·슬롯 UI는 자원/프레젠테이션 범위. (c) 결정은 채집 증폭에 소모되지 않는다(읽기만) — 용해(USE)로만 소진.

## 4. A6 아크 종결

A6-0 태양 순환 → A6-1 대사 → A6-2 구조 예치 → A6-3 스탯 → A6-4 스킬 → A6-5 아이템. **생명 = 소산 구조** 의 성장 루프가 전부 이체 문법으로 닫혔다 — 보존을 깨지 않는 영구 성장. 잔여 관찰 후보 A6-6(창발적 빌드 다양성)은 새 메커니즘이 아닌 측정 step.
