# step-0010 — A6-1 대사 (metabolism)

## 1. 한 일

생명(player·bot·몬스터봇)에 **지속 대사**를 부여한다: 매 주기 upkeep 를 `player→SINK` 로 지불하고, 채집·전투로 못 채우면 잔고 0 → 아사. "지속 소모·세계를 갈구·유지 못하면 죽음" — 소산 구조의 압력 엔진.

- `shared/constants.js` — `UPKEEP_INTERVAL_TICKS = 10`(1초) · `UPKEEP_AMOUNT = 5`(플랫) · `CAUSE.UPKEEP = 'upkeep'`.
- `server/game.js` `tick()` — 인텐트 처리 직후(2b) 매 upkeep 주기에 살아있는 각 플레이어가 `#tx(p.id, SINK, UPKEEP_AMOUNT, UPKEEP)`. 이체 후 잔고 0 이면 `#kill`(기존 사망 경로 — 전리품 드랍·리스폰 타이머). upkeep tx 는 **비공간**(`at` 없음)이라 `#txRelevant` 상 소유자에게만 방송 — 무지역 player 풀이라 체크섬 무관, 타인 미러 무영향.
- `client/render.js` — tx 피드 라벨 `upkeep→대사`, `recycle→순환` 추가(읽기 전용 뷰어).

소산분은 A6-0 태양 순환이 SOURCE 로 되돌린다 → 대사가 세계를 마르게 하지 않고 순환한다. 구조 기반 upkeep 스케일링은 A6-3 소관(현재 플랫).

## 2. 검증

`npm test` **30/30** 통과(신규 1종, 기존 29종 회귀 무손실). 신규 `A6-1 대사`:

- **대사 지불** — 스폰(300) 후 upkeep 주기 경계 전에는 소모 0, 경계 tick 에서 정확히 `UPKEEP_AMOUNT`(5) 만큼 `player→SINK`.
- **아사** — 잔고를 upkeep 1회분(5)으로 만든 뒤 진행 → 다음 주기에 잔고 0·`dead`. 사망 시 잔고 0(전량 SINK).
- **리스폰** — `RESPAWN_DELAY_MS` 경과 후 `SOURCE→player` 인출로 부활(`SPAWN_GRANT`).
- 매 단계 총합 `1000000000` 불변.

실측 출력: `[A6-1] upkeep 5/10틱 · 유지 실패=아사(잔고0)·리스폰 SOURCE 인출·총합 1000000000 불변`.

## 3. 불변식 판정 + 한계

- **보존(#1)**: ✅ 대사·아사 전부 `#tx` 한 경로 — 총합 불변. 에너지는 SINK 로 갔다가 태양 순환으로 복귀.
- **중재·검증(#2~3)**: 영향 없음 — 대사는 인텐트 경쟁·비콘 검증과 무관한 서버 주기 이체.
- **미러(#4)**: ✅ upkeep 는 소유자 전용 방송(비공간·무지역 풀) — 타인 미러/지역 체크섬 불변. 소유자 미러는 자기 upkeep tx 를 재생해 정합. 기존 미러 정합 테스트 2종 회귀 통과.
- **한계**: (a) upkeep 플랫(5/주기) — 구조·스탯 스케일링 없음(A6-3). (b) 자가소모(`STRUCT→player` 연명)는 구조 풀 도입(A6-2) 후에나 가능 — 지금은 잔고 0 즉시 아사. (c) 몬스터봇도 대사하므로 사냥감 없으면 굶어 죽는다(포식자 아사 — 의도된 압력, 별도 튜닝 없음).
