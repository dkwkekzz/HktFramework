# step-0001 — A1 필드 확산: 셀 격자 확산 프리미티브 (첫 조각)

> A1 의 첫 조각. `shared/` 결정론 코어에 확산 프리미티브만 세운다 — 서버 재충전 교체는 다음 조각.

## 1. 한 일 (어느 파일에 무슨 메커니즘)

- `shared/field.js` (신규) — 필드 = 원장 안의 셀 격자 풀(id `F:cx_cy`). 확산은 인접 셀 간 이체.
  - `createField(ledger, {grid, max, seed})` — 격자 풀 생성.
  - `diffuseTick(ledger)` — 각 인접 간선(오른쪽·아래 이웃)을 정확히 한 번 순회, 높은 셀 → 낮은 셀로 `flow = floor(기울기 * NUM/DEN)` 를 **`ledger.transfer()` 로만** 이체. 보존은 검증 코드가 아니라 이체 클램프가 강제. 이동 총량 반환.
  - `fieldCellId` / `fieldCellOf` 좌표 헬퍼.
- `shared/constants.js` — `FIELD_CELL_SIZE=250`(→ `FIELD_GRID` 8×8) · `FIELD_CELL_MAX` · `FIELD_DIFFUSE_NUM/DEN = 1/4`(≤1/2 → 오버슛·진동 없이 평형 수렴) · `POOL.CELL='F:'` · `CAUSE.DIFFUSE`.
- 경계 불변 유지: 확산은 순수 `shared/` 로직 — `server/`·`client/` 미변경. 별도 동기화 채널 없이 tx 스트림에 편입될 형태.

## 2. 검증 (`npm test` 2026-07-06 실행 출력)

- **pass 16 / fail 0** (duration 253ms). 기존 13종 회귀 무손실 + `field.test.js` 3종 신규:
  - 확산 1틱이 전 풀 총합 보존 — 임의 초기 분포(8×8, 시드 20260706) 200틱 매 틱 총합 == 창세.
  - 평형 단조 수렴 — 단일 셀 스파이크(100k)가 이웃으로 번지고, spread(max-min)가 300틱 비증가 후 초기 대비 크게 감소(no-op 아님 증명).
  - 방향 불변 — 항상 높은 셀 → 낮은 셀, 역류 없이 총합 보존.

## 3. 불변식 판정 + 한계

- **보존**: 확산의 모든 흐름이 `transfer()` 를 통과 → 자료구조가 강제. 테스트로 확인, 이상 없음.
- **이체 문법 확장**: 필드 재충전이 `{from,to,amount,cause=diffuse}` 이체 조합으로 표현됨 — A1 주장(필드도 이체로 돈다)의 코어가 성립.
- **정직한 한계**: ① 아직 프리미티브만 — `server/game.js` 재충전은 여전히 `세계→노드` 직접 이체다. 노드가 셀에서 뽑고, 세계가 셀에 주입하는 배관은 미연결(다음 조각). ② "고갈→회복 루프가 tx 로그만으로 재생 가능"(A1 완료 판정)은 서버 연결 후에야 검증 가능 — 현재는 확산 자체의 보존·수렴만 닫힘.
