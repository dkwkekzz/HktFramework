# step-0002 — A1 필드 확산: 서버 배관 연결 (노드 재충전을 필드로)

> A1 마무리. 확산 프리미티브(step-0001)를 `server/game.js` 재충전에 물려 `세계→노드` 직접 주입을 제거한다.

## 1. 한 일 (어느 파일에 무슨 메커니즘)

- `server/game.js`:
  - 창세에 `createField(ledger)` 로 8×8 셀 격자를 만들고 `SOURCE→셀` 로 셀당 `FIELD_CELL_SEED` 적립(보존 — SOURCE 인출). 셀은 SOURCE/SINK 급 `region=null` 서버 내부 저수지 → 방송·체크섬 대상 아님. 노드마다 겹치는 셀 id(`n.cell`) 를 `fieldCellOf` 로 계산해 보관.
  - 틱 §3 교체: **매 틱 `diffuseTick(ledger)`**(이웃 셀 간 zero-sum 이체, `ledger.transfer` 직결이라 pendingOps·방송에 안 남음). 재충전 주기엔 `SOURCE→셀` top-up(씨앗값까지, 필드 지속) + **`셀→노드` `#tx`**(고갈→회복). `세계→노드` 경로 삭제.
- `client/state.js` `#applyTx`: `F:` 셀 풀을 무한 저수지로 물질화(SOURCE/SINK 처럼) — `셀→노드` 재충전 tx 재생 시 노드가 전액 수령. `region=null` 이라 체크섬 무관·셀 잔고 오차 무해.
- `shared/constants.js`: `FIELD_CELL_SEED=3000` · `FIELD_INJECT_AMOUNT=40`.

## 2. 검증 (`npm test` + 봇 시뮬 2026-07-06 출력)

- **pass 18 / fail 0**. 신규 2종 + 기존 16종 회귀 무손실:
  - `A1 필드 확산` — 노드·셀 동반 고갈 후 120틱, 노드 회복 + 총합 == 10⁹ 불변. 방송된 재충전 tx 전부 `from` 이 `F:` 셀(SOURCE→노드 직접 주입 0건) 확인.
  - `A1 미러 정합` — 시야 진입 전 고갈 → `셀→노드` 재충전을 클라 미러가 재생, 노드 잔고 서버 일치 · resync 0 · 체크섬 OK.
- 봇 8기 시뮬(`node tools/bots.js 8`, 12초): `[원장] 세계 총 에너지 1,000,000,000 · 체크섬 OK` 반복, 채집·전투 정상 — 필드 배관이 라이브 스택에서 보존·정합 유지.

## 3. 불변식 판정 + 한계

- **보존**: 확산·주입·재충전 전부 `transfer` 경유 → 자료구조 강제. 테스트·봇 시뮬 총합 10⁹ 불변.
- **이체 문법 확장**: 재충전이 `{SOURCE→셀→노드}` + `{셀↔셀 diffuse}` 이체 조합으로 표현 — A1 주장(필드도 이체로 돈다) 성립. **고갈→회복 루프 tx 재생 가능**(미러 테스트) + 확산 중 총합 불변 → SPINE §1 A1 완료 판정 충족.
- **정직한 한계**: ① 필드가 씨앗값까지 top-up 되어 과공급 — 확산이 아직 *희소성 병목*은 아니다(밸런스 튜닝은 SPINE §0 범위 밖). 확산의 실제 수송·수렴은 `field.test.js` 단위 3종이 담보, 여기선 재충전이 필드를 *경유*함을 증명. ② 셀은 서버 내부(비방송)라 클라가 필드 상태를 못 본다 — "동기화에 공짜 편입"의 완전형(셀 자체 미러)은 미도입(대역폭 보존 위해 유보).
