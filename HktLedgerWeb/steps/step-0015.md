# step-0015 — A6-6 항상성 (구조 이화로 연명·구조 고갈 시 아사)

## 1. 한 일

성장을 되돌릴 수 없는 래칫에서 **가역적 비상 연료**로 바꿨다 — 자유 에너지로 대사를
못 채우면 곧바로 죽지 않고 구조(잠긴 질서)를 태워 연명한다.

- `server/game.js` 대사 블록(틱 2b): upkeep 지불 전에 자유 부족분을 계산해
  `deficit = upkeep − balance(player)` 만큼 **구조→플레이어** 이화 이체(`CAUSE.CATABOLISM`)
  후 대사(`player→SINK`)를 지불한다. 사망 조건을 `자유 0` 에서 **`자유 0 && 구조 0`** 으로
  바꿔, 태울 몸이 남는 한 아사하지 않는다. 이화는 `to===player` 라 소유자에게만 방송
  (upkeep 과 동형·비공간·체크섬 무관). 구조가 줄면 스탯도 준다 —
  `attackBonus·upkeepFor = f(구조)` 이므로 굶주릴수록 약해지는 곡선이 공짜로 따라온다.
- `shared/constants.js`: `CAUSE.CATABOLISM` 추가 (원인 태그 1개, 새 매직넘버 없음 — upkeep 재사용).
- `test/game.test.js`: A6-2 의 "사망해도 구조 지속" 검증을 아사→**전투사**로 전환
  (아사는 이제 구조를 태우므로, 영구 성장 불가침은 전투 사망으로 증명). A6-6 신규 테스트 추가.

## 2. 검증

`npm test` **35/35** 통과 (34→35, A6-6 추가). 전 불변식 회귀 무손실.

- `[A6-6] 자유0 → 구조 250→220 이화로 연명 · 구조 고갈 시 아사 · 총합 1000000000 불변`
  — 자유 0 상태로 5 대사 주기 생존(구조 250→220 이화), 스탯 단조 감소, 미러 구조 잔고 정합
  (이화 tx 재생), 계속 굶기면 구조 0 → 그때 아사(자유 0 && 구조 0).
- `[A6-2] 성장 player→STRUCT 120 · 사망/리스폰 지속(영구)·이탈 환원 SINK · 총합 1000000000 불변`
  — 전투사로도 구조 120 불가침 유지.
- 라이브 `node tools/bots.js 8` (~22s): 세계 총 에너지 1,000,000,000 불변 · 체크섬 OK ·
  에러/RESYNC 0 · 구조 총 27→1671 성장(bias 분산 → 빌드 분화 81~252).

## 3. 불변식 판정 + 한계

- **보존 ✅**: 이화는 `구조→플레이어` 이체(클램프 통과) — 총합 10⁹ 불변(테스트·라이브 확인).
- **이체 문법 ✅**: 항상성 = `{구조→플레이어}` + 기존 `{플레이어→SINK}` 조합. 신규 예외 없음.
- **미러 정합 ✅**: 이화 tx 는 `to===player` 라 소유자 방송 → 클라 구조 잔고 재생 일치.
- **한계**: 봇은 대체로 배불러(자유 여유) 이화가 라이브에서 드물게만 발동 — 굶주림
  압력을 상시 노출하려면 봇 성장 bias 를 자유 임계 이하로 미는 행동이 필요(측정 step 소관).
  전투 사망은 구조 불가침, 아사는 구조 소진으로 갈렸다(의도) — 두 죽음의 리스폰 강도 차이
  (전투사=구조 유지 강함 / 아사=구조 0 약함)는 밸런스 튜닝 대상이 아니라 관찰 대상.
