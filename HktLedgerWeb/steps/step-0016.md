# step-0016 — A7-1 구조 분화 (조직별 예치 = 빌드 트리)

## 0. 직관 (한눈에)

**예전엔 "성장 = 숫자 하나 키우기"** 라 누구나 같은 방향으로만 세졌다. 이제 몸에 장기가
둘이다 — 발산 장기(🗡, 키우면 공격↑)와 대사 장기(🌿, 키우면 채집↑). 철수는 발산에
몰빵해 전사가 되고, 영희는 대사에 몰빵해 채집가가 된다. 같은 양을 키우면 밥값(유지비)은
똑같지만 잘하는 게 갈린다 = **진짜 RPG 빌드**. 봇들도 성향대로 🗡/🌿 로 분화한다.

## 1. 한 일

성장을 1차원 스칼라에서 **조직(organ)별 빌드**로 분화시켰다 — 예치가 "어느 장기를
키울지" 선택이 되어 봇 빌드 분화가 *행동*이 아니라 *구조*로 실재화한다.

- `shared/constants.js`: `ORGANS = ['atk','meta']`(조직 목록·추가 지점) + `GROWTH_META_DIVISOR=40`.
  조직 풀 id = `S:<playerId>#<organ>` — `POOL.STRUCT` 접두 유지라 클라 자동 물질화 그대로.
- `shared/growth.js`: 스탯 함수를 조직별로 — `attackBonus(atk 조직)`·`skillDamage(skill, atk 조직)`,
  신규 `gatherStructBonus(meta 조직)`(채집 증폭), `upkeepFor(총 구조)`(총량의 함수 유지).
- `server/game.js`: `#structId(id, organ)`·`#structTotal(id)`. addPlayer 가 조직마다 풀 생성,
  removePlayer 가 조직마다 SINK 환원. GROW 는 `msg.organ` 선택(기본 첫 조직). 공격·스킬은
  `atk` 조직, 채집 want 에 `meta` 조직 증폭 합산. 대사는 총 구조 기준, A6-6 이화는 조직을
  정해진 순서로 소진.
- `tools/bots.js`: `struct()` 조직 합산, 편향 큰 개체는 `atk`(발산)·작은 개체는 `meta`(대사)
  특화 예치 → 라이브 빌드 분화(🗡/🌿 전시).

## 2. 검증

`npm test` **36/36** 통과 (35→36, A7-1 추가). 전 불변식 회귀 무손실.

- `[A7-1] 발산빌드 공격+3·채집 25 | 대사빌드 공격+0·채집 32(+7) · 같은 유지비 6 · 총합 1000000000 불변`
  — 같은 300 을 서로 다른 조직에 예치 → 발산 빌드는 in-game 데미지 `canonical+attackBonus(300)`,
  대사 빌드는 채집 `기본+gatherStructBonus(300)=+7`. 총량 같으니 유지비 동일(6). 미러 조직 잔고 정합.
- `[A6-3] 구조 800 → 공격 +8·대사 5→9` · `[A6-6] 자유0 → 구조 250→220 이화로 연명` — 조직 전환 후에도 유지.
- 라이브 `node tools/bots.js 8` (~22s): 세계 총 에너지 1,000,000,000 불변 · 체크섬 OK ·
  에러/RESYNC 0 · 빌드 분화 발산 4/8(🗡) · 대사 4/8(🌿) · 구조 총 1694(106~329).

## 3. 불변식 판정 + 한계

- **보존 ✅**: 조직 예치·이화·환원 전부 이체(클램프) — 총합 10⁹ 불변(테스트·라이브).
- **이체 문법 ✅**: 분화 = 예치 대상 풀만 바뀔 뿐 `{player→S:id#organ}` 이체. 신규 예외 없음.
- **미러 정합 ✅**: 조직 GROW tx 는 `from===player` 라 소유자 방송 → 클라 조직 잔고 재생 일치.
- **한계**: 조직 2종(발산·대사)만 — 용량/회복 등 조직은 미도입(풀 max·클라 동기화 얽힘, 별도).
  이화 소진 순서는 `ORGANS` 배열 고정(발산→대사) — 어느 장기부터 태울지 전략적 선택은 미제공.
  봇 조직 선택은 정적(bias 임계) — 상황 적응형 재분배는 관찰/후속 소관.
