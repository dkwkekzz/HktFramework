# step-0011 — A6-2 구조 예치 (성장)

## 1. 한 일

**성장을 이체로** 구현한다: 자유 에너지를 플레이어당 구조 풀 `S:<id>`(잠긴 질서)로 예치한다. 성장은 "무에서 능력 창조" 가 아니라 **자유 에너지의 질서화** — 순수 재분배라 총합 불변. 구조는 **사망해도 지속**(영구 성장), 접속 종료 시에만 SINK 로 환원.

- `shared/constants.js` — `POOL.STRUCT = 'S:'` · `STRUCT_MAX = 10000` · `GROW_AMOUNT = 50` · `CAUSE.GROW`.
- `shared/protocol.js` — `INTENT.GROW = 'grow'`. + A6-1 누락 교정: `CAUSE_LIST` 에 `UPKEEP` 추가(upkeep tx 가 JSON 폴백되던 것을 16B 바이너리로 복원 — A4 대역폭 유지).
- `server/game.js` — `#structId(id)` 헬퍼 · `addPlayer` 에서 구조 풀 생성 · `INTENT.GROW` = `#tx(p, S:p, want, GROW)`(자유 잔고·구조 포화로 클램프, 0 이면 기각) · `removePlayer` 에서 구조 `S→SINK` 환원 후 제거. 사망(`#kill`)은 구조를 건드리지 않는다 → 영구 성장.
- `client/state.js` — `#applyTx` 무지역 액터 물질화에 `POOL.STRUCT` 추가(빈 채, 무한 수용) → 소유자 미러가 GROW tx 를 정확히 재생. 구조는 region=null 이라 체크섬 무관.
- `client/render.js` — tx 라벨 `grow→성장`, 풀 라벨 `S:→구조`.

## 2. 검증

`npm test` **31/31** 통과(신규 1종, 기존 30종 회귀 무손실 — 바이너리 라운드트립 포함). 신규 `A6-2 구조 예치`:

- **질서화** — GROW 120: 자유 `300→180`, 구조 `0→120`, 총합 불변(창조 아님).
- **미러 정합** — 소유자 클라가 GROW tx 를 재생해 자유 잔고 일치(구조 풀 물질화 검증).
- **영구 성장** — 자유만 고갈시켜 아사시켜도 구조 `120` 유지, 리스폰 후에도 `120` 유지.
- **이탈 환원** — `removePlayer` 시 구조 `S→SINK`·풀 제거, 총합 불변.

실측 출력: `[A6-2] 성장 player→STRUCT 120 · 사망/리스폰 지속(영구)·이탈 환원 SINK · 총합 1000000000 불변`.

## 3. 불변식 판정 + 한계

- **보존(#1)**: ✅ 예치·환원 전부 `#tx` 한 경로 — 총합 불변. 구조 에너지는 원장에 잠겨 있을 뿐 소멸/창조 없음.
- **미러(#4)**: ✅ GROW 는 소유자 전용 방송(무지역 풀). 미러가 구조 풀을 물질화해 재생 — 자유 잔고 정합, 지역 체크섬 불변. STRUCT 는 A4 바이너리 PT 에 없어 GROW tx 는 JSON 폴백(정상).
- **중재·검증(#2~3)**: 영향 없음.
- **한계**: (a) **구조의 이득이 아직 없다** — 성장의 *저장*만 증명. 스탯·최대 용량 등 "왜 성장하는가" 는 A6-3(스탯=구조의 함수). (b) 구조는 현재 회수 불가(자가소모·용해 없음) — 자유가 마르면 구조를 두고도 아사한다. 구조를 연명에 쓰는 자가소모는 전투 사망 판정과 얽혀 별도 조각으로 미룸. (c) 사망 시 지속을 택함(영구 성장 의도) — 소산적 "사망 시 전량 환원" 이 아니라 접속 종료에서만 환원.
