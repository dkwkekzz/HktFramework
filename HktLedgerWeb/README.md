## 실행

**원클릭 시뮬레이션** — 설치→테스트→서버→봇 8기→관전 브라우저까지 한 번에:

```
run.bat            # Windows
./run.sh [봇수]    # macOS / Linux (관전: http://localhost:8080/?name=관전자)
```

봇(`tools/bots.js`)은 특권이 없다 — 브라우저 클라이언트와 동일한 프로토콜·동일한
미러 원장으로 채집(⛏)/사냥(⚔)/응축/무기제작을 스스로 수행하며, 서버는 봇의
비콘·인텐트를 똑같이 검증한다. 5초마다 콘솔에 각 봇 에너지와 세계 총합을 출력한다.

개별 실행:

```bash
npm install
npm start          # 서버만 — http://localhost:8080 (탭 여러 개 = 멀티플레이)
node tools/bots.js 8
npm test           # 보존·중재·검증·미러 + 필드/감사/영속/바이너리/3D/태양순환/대사/성장/스탯 테스트 32종
```

조작: `WASD` 수평 이동 · `R`/`F` 상승·하강 · `E` 채집/줍기 · `Space` 공격 · `C` 결정 응축 · `B` 무기 제작 · `V` 결정 사용 · `X` 버리기

공간은 3D(x,y 수평 + z 높이)로 처리된다 — 위치·거리·사거리·속도 예산이 전부 3D. region 체크섬 격자와 필드 셀은 (x,y) 컬럼(z 는 컬럼 내 자유). 렌더는 Canvas 원근 3D(드래그 회전·휠 줌, z 높이를 높이 스틱으로 전시).

## 구조 — 서버/클라 경계가 곧 설계의 경계

```
shared/    서버·클라 공용 결정론 코어 (외부 API 의존 0 — 순수 결정론 로직)
 ├─ ledger.js      에너지 원장 — 유일한 상태. 이체 클램프 = 보존 강제 지점 · serialize/load(A3)
 ├─ constants.js   시뮬 상수 단일 출처 (에너지 정수) · dist3 3D 거리
 ├─ worldgen.js    시드 → 월드 3D 배치 유도 (배치는 동기화하지 않는다)
 ├─ field.js       필드 셀 격자 확산 — 이웃 셀 간 zero-sum 이체 (A1)
 ├─ audit.js       판정 규칙 결정론 롤 — 위임·감사 공통 근거 (A2)
 └─ protocol.js    메시지 정의 + 틱 플러시 순서 + tx 16B 바이너리 인코딩 (A4)

server/    원장 권위 — 회계사. 시뮬레이션 없음
 ├─ game.js        ① 클램프 ② FIFO 중재 ③ 원장 커밋 ④ relevancy 방송 · 필드 재충전·감사·스냅샷
 ├─ monster.js     몬스터 = 무특권 서버 봇 (동일 프로토콜 비콘·인텐트) (A5)
 └─ index.js       수송(WebSocket)·정적 서빙·10Hz 틱 루프

client/    세부 시뮬레이터 — 이동 적분·예측·연출은 전부 여기
 ├─ state.js       미러 원장: 서버 확정 tx 재생 + 시야(ENTER/LEAVE) 경계
 ├─ sim.js         로컬 3D 이동 (프레임레이트) + 5Hz 양자화 비콘
 ├─ net.js         수송 + 수신 대역폭 계측
 └─ render.js      Canvas 원근 3D 카메라 (orbit·깊이정렬·원장 읽기 전용)
```

## 동기화되는 것의 전부

| 채널 | 내용 | 빈도 |
|---|---|---|
| tx 스트림 | `{from, to, amount, cause}` 이체 + 사실 이벤트 (인과 순서) | 발생 시 |
| 지역 체크섬 | 지역별 잔고 합계 int + 세계 총합 | 3초 |
| 좌표 비콘 | 양자화 위치 (권위 아님 — 예산·사거리 검증용) | 5Hz |
| ENTER/LEAVE | 관심영역 출입 시 풀 스냅샷 | 시야 변화 시 |

실측: 클라 1인 300~400 B/s(JSON). **tx 스트림은 16B 바이너리 인코딩(A4)** — 레코드 107.5→16.0 B/tx(85%↓), 이벤트·문자열 iid 는 JSON 폴백. 인코딩은 `protocol.js` 한 곳.

## 네 시스템이 전부 이체 문법이다

- **이동** — 서버는 이동을 시뮬레이션하지 않는다. 클라 비콘 간 거리를 `MAX_SPEED` 예산으로 검증(스피드핵 기각→TELEPORT 정정)하고, 50px당 에너지 1을 `플레이어→소실` 이체로 청구한다.
- **채집(모험으로 에너지 획득)** — `노드→플레이어` 이체. 요청량이 아니라 잔고로 클램프(`Got<Want` = 고갈). 재충전은 `세계→노드` 주입이 아니라 **필드에서 흐른다**(A1): `SOURCE→셀` 보충 + 매 틱 `셀↔셀 확산` + `셀→노드` 인출 → 고갈·회복 루프.
- **전투** — 데미지 = 피격자 풀 인출. 50%는 `피격자→공격자`(흡수), 50%는 `피격자→소실`. 시전 비용·무기 내구 소모도 이체. 잔고 0 = 사망 → 소지품 드랍, `세계→플레이어` 리스폰 인출.
- **아이템** — 아이템 = 응축된 에너지 풀. 결정 응축/용해, 무기 제작(내구도 = 잔고, 공격마다 마모), 드랍/픽업(소유권 선점 = FIFO 중재).

## 검증된 불변식 (`npm test`)

1. **보존**: 창세(`W:SRC` = 10⁹) 이후 어떤 게임플레이 시퀀스에서도 전 풀 합계 불변 — 화면 우상단에 상시 전시.
2. **중재**: 동시 채집·픽업은 도착 순서로 클램프·선점, 패자는 명시적 기각.
3. **검증**: 속도 예산 초과 비콘 기각, 사거리 밖 인텐트 기각.
4. **미러 정합**: 서버 메시지 재생만으로 재구축한 클라 원장이 지역 체크섬과 일치. 불일치 시 해당 지역만 스냅샷 복구(RESYNC).

## 증명 완료 — 설계 주장 arc (SPINE §1, step 기록은 `steps/`)

| arc | 주장 | 방법 (step) |
|---|---|---|
| **A1 필드 확산** | 필드 재충전도 이웃 셀 간 zero-sum 이체로 돈다 | `SOURCE→셀→노드` + 매 틱 `셀↔셀 diffuse` (0001·0002) |
| **A2 판정 감사** | 클라 위임 판정 조작을 샘플링 재시뮬로 탐지 | 결정론 데미지 롤 + 25% 표본 감사 (0003) |
| **A3 영속화** | 영속 = 원장 잔고 저장·복원이 전부 | `serialize/load` + `snapshot/restore` (0004) |
| **A4 바이너리 tx** | tx 16B 인코딩으로 대역폭 절감 | tx 레코드 107.5→16.0 B/tx (0005) |
| **A5 몬스터 권위 이관** | 몬스터도 특권 없는 클라이언트로 | `MonsterController` 무특권 서버 봇 (0006) |
| **3D 공간·렌더** | 공간 개념을 3D 로 | `dist3`·z 배치·비콘 z (0007) · Canvas 원근 3D (0008) |
| **A6-0 태양 순환** | 소산(SINK)이 SOURCE 로 재순환해 세계가 영속 (닫힌 열역학 루프) | `SINK→SOURCE` 주기 재순환 (0009) |
| **A6-1 대사** | 생명은 지속 소모하고 못 채우면 아사한다 | 매 주기 upkeep `player→SINK` (0010) |
| **A6-2 구조 예치** | 성장 = 자유 에너지의 질서화(창조 아님), 영구 지속 | `player→STRUCT` 예치 (0011) |
| **A6-3 스탯 = 흐름 계수** | 스탯은 저장 숫자가 아니라 구조의 함수(공격·대사) | `attackBonus`·`upkeepFor(struct)` (0012) |

전 arc 회귀 무손실 — `npm test` **32종** 통과. 불변식 4종은 매 step 유지. **A6(생명=소산 구조) 아크 진행 중** — SPINE §1 A6.
