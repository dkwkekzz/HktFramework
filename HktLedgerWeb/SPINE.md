## 0. ⛔ 범위 경계 (SCOPE — 반복 오해 금지)

**이것은 각을 보는 프로토타입이다 — 목적은 설계 검증이지 게임 완성이 아니다.**

- **하는 일**: 원장 동기화 모델의 핵심 주장들(§1)을 실행 가능한 코드 + 자동 테스트로 증명하고, 실측 수치(대역폭·탐지율)를 남긴다.
- **안 하는 일(⛔)**: **리소스 관련 일체 — 맵·캐릭터·비주얼 에셋·렌더 고도화(WebGL·볼류메트릭 파티션 등)는 이 트랙 범위 밖.** 콘텐츠 볼륨·밸런스 튜닝도 제외 — 주장 증명에 필요한 최소만. 기존 Canvas 렌더는 원장을 눈으로 확인하는 읽기 전용 최소 뷰어일 뿐 작업 대상이 아니며, STATE §2 후보에 리소스/렌더 방향을 다시 올리지 않는다. **HktGameplay/HktInfra 참조·연동 금지**(완전 독립 트랙). UE5 빌드 무관.
- **`shared/` 순수성(외부 의존 0)은 결정론 코어의 불가침 조건이다** — 편의를 위해 어기는 순간 결정론·재현성이 깨져 이 트랙의 존재 이유가 사라진다.

## 1. 증명하려는 주장 — 완성 판정의 전부

설계의 주장을 웹에서 하나씩 닫는다. 진행 마커의 권위는 [STATE.md](STATE.md) §3.

**이미 증명됨** (`npm test` 13종 + 실측 — step-0000 baseline):

- **보존**: 임의 게임플레이 시퀀스(이동·채집·전투·아이템·접속 종료) 후 전 풀 합계 불변.
- **중재**: 동시 채집·픽업은 FIFO 클램프·선점, 패자 명시 기각(`Got<Want`).
- **검증**: 속도 예산 초과 비콘 기각(TELEPORT 정정)·사거리 밖 인텐트 기각 — 서버가 물리를 몰라도 치트를 안다.
- **미러 정합**: 서버 메시지 재생만으로 재구축한 클라 원장 == 지역 체크섬(불일치 시 RESYNC).
- **대역폭**: 클라 1인 수신 300~400 B/s (JSON 인코딩 상태).

**남은 주장** → 아래 arc 로 닫는다:

| arc | 주장 | 왜 증명해야 하는가 | 완료 판정 |
|---|---|---|---|
| **A1 필드 확산** | 필드(노드 재충전)도 이웃 셀 간 zero-sum 정수 이체로 돈다 — 별도 동기화 채널 없이 원장에 공짜 편입 | 지금 재충전은 `세계→노드` 마법 주입 — 이체 문법의 확장 한계 검증(설계 §7 단계 4) | 고갈→회복 루프가 tx 로그만으로 재생 가능 + 확산 중 총합 불변 테스트 |
| **A2 판정 감사** | 클라 위임 판정의 조작을 샘플링 재시뮬로 탐지할 수 있다 | 설계 §5 잔여 리스크("회피했는데 맞았다")의 유일한 보강 장치(설계 §7 단계 5) | 개조 봇(판정 조작)을 감사가 탐지 — 탐지율 실측 수치 |
| **A3 영속화** | 영속은 원장 잔고 저장·복원이 전부다 | "상태 = 원장뿐" 주장의 최종 시험 — 이것이 성립해야 서버 슬리밍이 완성 | 재시작 후 지역 체크섬 일치 + 세계 총합 불변 |
| **A4 바이너리 tx** | tx 16B 바이너리 인코딩으로 대역폭 추가 절감 | 설계 §4 대역폭 추정의 실측 검증 — 인코딩은 `protocol.js` 한 곳 | 봇 8기 시뮬 실측 B/s 절감 수치 |
| **A5 몬스터 권위 이관** | 몬스터도 특권 없는 클라이언트(서버 봇)로 돌 수 있다 | 지금 몬스터는 서버 정적 배치 — "서버는 시뮬레이션하지 않는다"의 마지막 예외 제거 | 몬스터 AI 가 봇과 동일 프로토콜로 구동 + 불변식 유지 |

arc 순서는 고정이 아니다 — 다음 조각의 권위는 STATE §2. **A1~A5 는 전부 닫혔다**(진행 마커 STATE §3).

### A6 — 생명 = 소산 구조 (성장의 보존적 구현)

세계는 **닫힌 열역학 루프**다: 서버(SOURCE)는 유일한 에너지 원점(태양)이되 생성기가 아니라 순환의 원점 — 에너지는 `SOURCE→생명→SINK→SOURCE` 로 영원히 돈다(총합 10⁹ 불변). 생명(player·bot)은 그 흐름을 소모·갈구하며 내부 질서를 유지하는 소산 구조다. **성장 = "무에서 능력 창조" 가 아니라 자유 에너지를 잠긴 질서(구조 풀)로 재분배** — 스탯·스킬·아이템은 실재 에너지 풀의 잔고를 읽는 흐름 계수이지 민팅한 숫자가 아니다. 이체로 못 풀리는 지점은 정직하게 반례로 STATE 에 기록한다(규칙 5).

| step | 주장 | 완료 판정 |
|---|---|---|
| **A6-0 태양 순환** | 소산(SINK)이 SOURCE 로 재순환해 세계가 영속 | 재순환 주기마다 SINK→SOURCE·SINK 유계·총합 불변 (step-0009 ✅) |
| **A6-1 대사** | 생명은 지속 소모하고 못 채우면 죽는다 | upkeep `player→SINK`·잔고 0 아사·리스폰·보존 (step-0010 ✅) |
| **A6-2 구조 예치** | 성장 = 자유 에너지의 질서화(창조 아님) | `player→STRUCT` 예치·사망 지속(영구 성장)·이탈 환원·총합 불변 (step-0011 ✅) |
| **A6-3 스탯 = 흐름 계수** | 스탯은 저장 숫자가 아니라 구조의 함수 | 공격·대사=f(구조)·미러 정합·데미지 클램프 내 (step-0012 ✅) |
| **A6-4 스킬 = 발산 패턴** | 스킬 = 비용 있는 증폭 이체 | 보존·구조/쿨다운 게이팅·서버 강제 |
| **A6-5 아이템 = 결정체 장착** | 아이템은 증폭하되 만들지 않는다 | 장착이 에너지 안 만듦(잔고 보존)·해제 환원 |
