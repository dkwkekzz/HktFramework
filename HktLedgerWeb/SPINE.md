## 0. ⛔ 범위 경계 (SCOPE — 반복 오해 금지)

**이것은 각을 보는 프로토타입이다 — 목적은 설계 검증이지 게임 완성이 아니다.**

- **하는 일**: 원장 동기화 모델의 핵심 주장들(§1)을 실행 가능한 코드 + 자동 테스트로 증명하고, 실측 수치(대역폭·탐지율)를 남긴다.
- **안 하는 일(⛔)**: 렌더 품질·콘텐츠 볼륨·밸런스 튜닝 — 주장 증명에 필요한 최소만. **HktGameplay/HktInfra 참조·연동 금지**(완전 독립 트랙 — 접점은 엔진 이식 시점의 §3 지도뿐). UE5 빌드 무관.
- **`shared/` 순수성(외부 의존 0)이 곧 C++ 이식 가능성이다** — 편의를 위해 어기는 순간 이 트랙의 존재 이유가 사라진다.

> **미래 세션 주의**: 남은 작업에 "엔진 연동"·"UE 이식 착수"를 넣지 마라 — 이식은 이 트랙이 §1 주장을 전부 닫은 *뒤* HktGameplay 소관으로 시작한다. 이 트랙의 일은 웹에서 증명을 쌓는 것까지다.

## 1. 증명하려는 주장 — 완성 판정의 전부

설계의 주장을 웹에서 하나씩 닫는다. 진행 마커의 권위는 [STATE.md](STATE.md) §3.

**이미 증명됨** (`npm test` 13종 + 실측 — step-0000 baseline):

- **보존**: 임의 게임플레이 시퀀스(이동·채집·전투·아이템·접속 종료) 후 전 풀 합계 불변.
- **중재**: 동시 채집·픽업은 FIFO 클램프·선점, 패자 명시 기각(`Got<Want`).
- **검증**: 속도 예산 초과 비콘 기각(TELEPORT 정정)·사거리 밖 인텐트 기각 — 서버가 물리를 몰라도 치트를 안다.
- **미러 정합**: 서버 메시지 재생만으로 재구축한 클라 원장 == 지역 체크섬(불일치 시 RESYNC).
- **대역폭**: 클라 1인 수신 300~400 B/s (JSON 인코딩 상태).

**남은 주장** → 아래 arc 로 닫는다:

| arc | 주장 | 왜 증명해야 하는가 | 완료 판정 |
|---|---|---|---|
| **A1 필드 확산** | 필드(노드 재충전)도 이웃 셀 간 zero-sum 정수 이체로 돈다 — 별도 동기화 채널 없이 원장에 공짜 편입 | 지금 재충전은 `세계→노드` 마법 주입 — 이체 문법의 확장 한계 검증(설계 §7 단계 4) | 고갈→회복 루프가 tx 로그만으로 재생 가능 + 확산 중 총합 불변 테스트 |
| **A2 판정 감사** | 클라 위임 판정의 조작을 샘플링 재시뮬로 탐지할 수 있다 | 설계 §5 잔여 리스크("회피했는데 맞았다")의 유일한 보강 장치(설계 §7 단계 5) | 개조 봇(판정 조작)을 감사가 탐지 — 탐지율 실측 수치 |
| **A3 영속화** | 영속은 원장 잔고 저장·복원이 전부다 | "상태 = 원장뿐" 주장의 최종 시험 — 이것이 성립해야 서버 슬리밍이 완성 | 재시작 후 지역 체크섬 일치 + 세계 총합 불변 |
| **A4 바이너리 tx** | tx 16B 바이너리 인코딩으로 대역폭 추가 절감 | 설계 §4 대역폭 추정의 실측 검증 — 인코딩은 `protocol.js` 한 곳 | 봇 8기 시뮬 실측 B/s 절감 수치 |
| **A5 몬스터 권위 이관** | 몬스터도 특권 없는 클라이언트(서버 봇)로 돌 수 있다 | 지금 몬스터는 서버 정적 배치 — "서버는 시뮬레이션하지 않는다"의 마지막 예외 제거 | 몬스터 AI 가 봇과 동일 프로토콜로 구동 + 불변식 유지 |

arc 순서는 고정이 아니다 — 다음 조각의 권위는 STATE §2.

## 2. 구조 불변 — 경계가 곧 설계

파일 지도는 [README.md](README.md) §구조. 요지: `shared/`(결정론 코어) / `server/`(회계) / `client/`(세부 시뮬) 경계는 arc 가 진행돼도 불변 — 새 기능이 경계를 흐리면 재설계.

## 3. 종착점 — 엔진 이식 지도 (이 트랙이 끝난 뒤의 이야기)

- **가져갈 것**: `shared/` 전체(원장·상수·프로토콜 규약 — 순수 로직이라 C++ 이식 대상), `server/game.js` 의 처리 순서(리스폰→인텐트 FIFO→재충전→플러시), 틱 플러시 순서 규약(LEAVE→OPS→ENTER).
- **버릴 것**: JSON 인코딩(→A4 에서 16B 바이너리로 대체), Canvas 렌더, 몬스터 정적 배치(→A5).
- **이식 로드맵·기존 자산 재사용 맵**: 설계 §7(단계 0~5 — 권장 시작점 단계 0 원장 코어)·§6 표 참조 — 여기 중복하지 않는다.
