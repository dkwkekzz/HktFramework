# [08·2.3a] SPH 커널·밀도 추정 (SPH Kernels & Density Estimation)

## 0. 한 문장 요약

> **SPH 커널 `W` 는 "입자 하나를 점이 아니라 주변에 부드럽게 퍼진 작은 덩어리로 본다"는 약속**이다. 어떤 양이든 *이웃 덩어리들의 겹침을 가중합* 한 것이고, 미분은 커널의 미분으로 옮겨 진다. 문제는 한 커널이 모든 항을 잘 처리하지 못한다는 것 — 밀도엔 매끈한 커널(poly6), 압력엔 중심에서 *세게 미는* 커널(spiky), 점성엔 *항상 평탄화하는* 커널(viscosity)이 필요하다. 커널을 잘못 고르면 입자가 한 점으로 뭉치거나 음의 점성으로 폭발한다.

아래는 이 한 문장을 한 걸음씩 푸는 과정이다.

---

## 1. 커널 보간 — 왜 합이 "장(field)"이 되는가

연속체에서 어떤 양 `A(x)` 의 값은, 디랙 델타로 쓰면 `A(x) = ∫ A(x') δ(x - x') dx'` 다. SPH 는 *뾰족한 델타를 폭 `h` 의 매끈한 봉우리 `W` 로 바꾼다*(smoothing):

```
A(x) ≈ ∫ A(x') W(x - x', h) dx'        // 연속 (델타를 매끈한 W 로 흐림)
     ≈ Σ_j  m_j (A_j / ρ_j) W(x - x_j, h)   // 적분을 입자 합으로 이산화
              └ "입자 j 가 차지하는 부피" m_j/ρ_j ┘
```

`m_j/ρ_j` 가 입자 하나의 부피라, 합은 "각 이웃이 점 `x` 에 기여하는 양 × 그 점에서의 커널 무게"의 누적이다. **밀도** 는 `A=ρ` 를 넣으면 특히 깔끔해진다:

```
ρ_i = Σ_j m_j W(x_i - x_j, h)
```

밀도란 곧 *근처에 입자가 얼마나 빽빽이 겹쳐 있는가* 다. 가까우면 `W` 가 크고, `h` 밖이면 0. **그래서 SPH 에서 밀도는 측정하는 게 아니라 커널 합으로 정의된다** — 이게 모든 것의 출발점이다.

**미분이 공짜인 이유.** `A` 는 입자 위치 `x_j` 에 안 걸리고 커널 `W(x-x_j)` 에만 `x` 가 걸린다. 그래서

```
∇A(x) ≈ Σ_j m_j (A_j/ρ_j) ∇W(x - x_j, h)
∇²A(x) ≈ Σ_j m_j (A_j/ρ_j) ∇²W(x - x_j, h)
```

미분이 **커널의 미분 `∇W`, `∇²W`** 로 옮겨 진다. 격자도 차분도 없이 `∇p`(압력 힘)·`∇²u`(점성)를 입자만으로 얻는 비결이 이것이다 — 그리고 *커널의 미분이 어떻게 생겼느냐* 가 그대로 물리의 품질을 결정한다.

---

## 2. 좋은 커널의 조건

`W(r, h)` 가 갖춰야 할 성질:

- **정규화(normalization)**: `∫ W dV = 1`. 안 그러면 밀도 추정에 일정한 배율 오차가 박힌다.
- **콤팩트 지지(compact support)**: `r > h` 면 `W = 0`. 이웃 탐색이 `O(n)` 으로 끝나는 근거([11](../11-spatial-structures.md)).
- **양수·단조 감소**: 가까울수록 큰 무게.
- **매끈함**: `r=0`(중심)과 `r=h`(경계)에서 충분히 미분 가능해야 힘이 튀지 않는다.
- **델타 수렴**: `h → 0` 이면 델타로 돌아가 정확도 회복.

문제는 **한 커널이 이 모든 걸 모든 항에 대해 동시에 잘하지 못한다**는 것이다. 특히 *값* 이 좋은 커널과 *미분* 이 좋은 커널이 다르다. 그래서 Müller(2003)는 항마다 다른 커널을 쓴다.

---

## 3. 세 커널 — 왜 항마다 다른가

| 항 | 커널 | 왜 이 커널인가 |
|---|---|---|
| 밀도·일반 보간 | **poly6** | 매끈하고 종 모양, `r=0` 근처에서 평탄 → 안정적인 값 추정 |
| 압력 그래디언트 | **spiky** | 중심에서 `∇W` 가 폭발(가팔라짐) → 가까운 입자를 *세게* 밀어냄 |
| 점성 라플라시안 | **viscosity** | `∇²W ≥ 0` (지지 안에서 양수) → 항상 *평탄화* 만, 에너지 주입 없음 |

**poly6 — 밀도용.** 종 모양으로 매끈해 밀도/일반 양의 보간이 안정적이다. 그런데 **치명적 결함**이 있다: poly6 의 *그래디언트* 는 중심(`r→0`)에서 **0 으로 죽는다**. 즉 두 입자가 아주 가까워질수록 밀어내는 힘이 *약해진다*.

> **그림(왜 poly6 로 압력을 쓰면 군집하는가)**: 입자 둘이 점점 가까워지면 밀도가 치솟아 압력이 커진다. 그런데 미는 힘 `∝ ∇W` 가 중심에서 0 으로 죽으면 — 압력은 큰데 밀어내질 못한다. 입자들이 서로를 통과해 한 점으로 **응어리(clumping)** 진다. 밀도는 폭발하고 시뮬은 터진다. 이것이 단일 poly6 의 함정이다.

**spiky — 압력 그래디언트용.** spiky 커널의 그래디언트는 반대로 **중심에서 가장 가팔라(폭발)** 진다 — 가까울수록 *더 세게* 민다.

```
spiky ∇W ∝ -(h - r)²  (방향: 멀어지는 쪽)   // r→0 에서 크기 최대
```

가까운 입자를 강하게 밀어내므로 군집이 생기지 않는다. Müller 의 핵심 통찰: **밀도는 poly6 로 매끈히 재고, 미는 힘은 spiky 로 강하게** — 값과 미분에 서로 다른 커널을 쓰는 것이 정석이다.

**viscosity — 점성 라플라시안용.** 점성은 속도를 *이웃 평균으로 끌어당기는 확산* 이어야 한다([01a §4](01a-navier-stokes-terms.md)). 그러려면 `∇²W` 가 지지 영역 안에서 **항상 양수** 여야 한다. poly6 의 라플라시안은 부호가 바뀌어 — 어떤 거리에선 `∇²W < 0` → **음의 점성(에너지 주입)** → 입자가 가만있다 *스스로 진동·폭발* 한다. Müller 의 viscosity 커널은 `∇²W ≥ 0` 을 보장하도록 설계돼 항상 에너지를 *빼기만* 한다.

```
W_viscosity 의 라플라시안 ∇²W ∝ (h - r) ≥ 0   (지지 안에서 항상 양수)
```

> **요약 직관**: 값이 필요한 곳(밀도) → poly6, *멀어지는 힘* 이 필요한 곳(압력) → 중심에서 센 spiky, *항상 빼는 확산* 이 필요한 곳(점성) → 부호가 안 바뀌는 viscosity. 세 커널을 섞는 건 트릭이 아니라 각 항의 물리가 요구하는 조건을 맞추는 것이다.

## 4. 압력 힘이 대칭형인 이유 (보너스)

운동량 압력 힘은 단순 `-∇p/ρ` 가 아니라 **대칭형** 으로 쓴다:

```
f_i^pressure = -Σ_j m_j (p_i/ρ_i² + p_j/ρ_j²) ∇W_ij
                          └ i, j 가 대칭으로 들어감 ┘
```

`p_i/ρ_i² + p_j/ρ_j²` 는 입자 `i↔j` 교환에 대칭이다. 그래서 `i` 가 `j` 를 미는 힘과 `j` 가 `i` 를 미는 힘이 **크기 같고 방향 반대**(뉴턴 3법칙) → **운동량이 정확히 보존**된다. 비대칭형(`p_i/ρ_i²` 만)을 쓰면 쌍힘이 안 맞아 운동량이 새고 표류한다. SPH 공식이 그 모양인 데는 보존 법칙의 이유가 있다.

## 5. 함정 (전체 체크리스트는 [08-fluids §5](../08-fluids.md#5-함정--결정론-체크리스트))

- **단일 커널 오용**: 밀도·압력·점성에 같은 커널 → 군집(압력에 poly6) 또는 음의 점성 폭발(점성에 poly6). 항마다 poly6/spiky/viscosity.
- **정규화 누락**: `∫W dV ≠ 1` 이면 밀도에 배율 오차 → 압력·전체가 어긋난다.
- **`h` 와 입자 간격 불일치**: 지지 반경 `h` 가 입자 간격에 비해 너무 작으면 이웃이 부족해 밀도 추정이 들쭉날쭉. 보통 이웃 30~40개가 잡히도록 `h` 를 잡는다.
- **합산 순서 비결정성(→ [12])**: 이웃 합 `Σ_j` 는 정렬된 결정적 순서로. GPU atomic 은 비결정적.
