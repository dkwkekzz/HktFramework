# [08·2.4] Position-Based Fluids (PBF)

> SPH 의 밀도 비압축을 **위치 기반 구속**(position-based constraint)으로 다시 쓴 것. [05]·[07] 의 PBD/XPBD 와 같은 계열이라, 강체·천·유체를 하나의 통합 솔버로 돌릴 수 있다. 큰 고정 timestep 에 강해 게임 실시간에 인기.

Macklin & Müller(2013). SPH 의 밀도 비압축을 **위치 기반 구속**으로 다시 쓴 것 — [05]·[07] 의 PBD/XPBD 와 정확히 같은 계열이라, 강체·천·유체를 **하나의 통합 PBD 솔버**(NVIDIA FleX)에서 같은 반복 루프로 돌릴 수 있게 한 점이 결정적이다.

발상의 전환: SPH 처럼 *힘 → 가속 → 적분* 하는 대신, **위치를 직접 보정** 한다. 각 입자에 밀도 구속을 건다 — "밀도가 목표 `ρ0` 와 같아야 한다":

```
C_i(p_1...p_n) = ρ_i/ρ0 - 1 = 0
```

이 구속을 만족시키도록 위치를 옮기는 것이 한 스텝의 전부다. SPH 의 밀도 추정(커널 합, [03a](03a-sph-kernels.md))을 그대로 쓰되, *압력 힘* 대신 *위치 보정* 으로 비압축을 강제한다.

```
PBF 한 스텝:
  1. 예측 위치       p* = x + Δt·v + Δt²·f
  2. 이웃 탐색       (공간 해시 → [11])
  3. solver 반복 (보통 3~5회):
       각 입자 밀도 구속 C_i 계산
       라그랑주 승수 λ_i = -C_i / (Σ|∇C|² + ε)   // ε: CFM/완화항
       위치 보정 Δp_i = (1/ρ0) Σ_j (λ_i+λ_j+s_corr) ∇W_ij
       p* ← p* + Δp_i
  4. 속도 갱신       v = (p* - x)/Δt
  5. vorticity confinement + XSPH viscosity 로 후처리
  6. commit          x ← p*
```

- **`λ_i` = 라그랑주 승수**: [01a §3](01a-navier-stokes-terms.md) 의 그 라그랑주 승수다 — "구속을 딱 맞출 만큼의 보정량". PBD 의 표준 형식(`λ = -C / (Σ|∇C|² + ε)`)을 밀도 구속에 적용한 것.
- **`s_corr`**: **인공 표면장력/응집(tensile instability) 보정** — 이웃이 적은 표면 입자가 음압으로 응어리지는 현상을 막아 표면을 매끈히 유지한다.
- **속도를 위치차로 정의**(`v = (p*-x)/Δt`): 힘을 적분하지 않고 *보정된 위치* 에서 속도를 역산하는 게 PBD 의 핵심. 그래서 무조건 안정하다.

**왜 게임에서 인기인가.**

- **반복 횟수로 비압축↔비용 직관 조절**: solver 반복을 늘리면 더 비압축, 줄이면 더 싸다. 한 노브로 품질-성능을 직접 잡는다.
- **CFL 에 덜 민감 → 큰 고정 timestep**([03])에서 잘 버틴다. SPH 의 압축성-스텝 트레이드오프([03-lagrangian-sph](03-lagrangian-sph.md))에서 자유롭다.
- **통합 솔버**: 밀도 구속이 PBD/XPBD 와 같은 형식이라, 강체([05])·천/소프트바디([07])·유체를 **한 반복 루프** 에 섞을 수 있다(FleX). 유체가 천을 적시고 강체를 띄우는 상호작용이 같은 솔버 안에서 일관되게 풀린다.
- **XPBD 정식화**를 쓰면 강성(stiffness)이 timestep 에 독립적이 되어 [07] 의 천/소프트바디와 강성 단위를 통일할 수 있다.

> **SPH 와의 관계**: PBF 는 "IISPH 의 위치 기반 사촌"으로 봐도 좋다. 둘 다 비압축을 반복으로 푼다 — IISPH 는 압력을 암시적 선형계로([03-lagrangian-sph](03-lagrangian-sph.md)), PBF 는 위치를 구속 반복으로. PBF 는 후자라 PBD 생태계에 자연스럽게 합류한다.

**관련 함정** (전체 체크리스트는 [08-fluids §5](../08-fluids.md#5-함정--결정론-체크리스트)):
- **반복 횟수 비결정성(→ [12])**: 수렴 조기 종료는 비결정성의 원천. 결정론이 필요하면 반복 횟수를 *고정* 한다(PBF 는 본래 고정 횟수라 유리).
- **부동소수점 합산 순서(→ [12])**: `Σ_j ∇W_ij` 누적을 정렬된 결정적 순서로. GPU atomic add 는 비결정적.
- **`s_corr` 미적용 시 군집**: 표면 입자가 응어리지고 표면이 우둘투둘해진다 — 인공 응집 보정 필수.
- **`ε`(CFM) 과소/과대**: 너무 작으면 `λ` 가 폭발(0 나눗셈 근처), 너무 크면 비압축이 무뎌진다.
