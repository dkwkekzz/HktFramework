# [08·2.5] Height-field — 수면 한 장 (Height-Field Water)

> 3D 전체를 풀지 않고 수면 높이 `h(x, y)` 한 층만 본다. 차원이 하나 줄어 압도적으로 싸다 — 호수·강·바다의 게임용 표준. shallow water(국소 출렁임) + Tessendorf FFT(넓은 바다).

3D 전체를 풀지 않고 수면 높이 `h(x, y)` 한 층만 본다. 차원이 하나 줄어(3D→2D) 압도적으로 싸다. 게임에서 *보이는 물* 의 대부분 — 바다·강·호수 — 은 진짜 유체 시뮬이 아니라 이 높이장 근사다.

## Shallow Water Equations (SWE)

수심이 파장보다 얕다는 가정. 수직 속도를 무시하고 깊이 평균한 2D 방정식 — 호수·강·로컬 물웅덩이의 출렁임/잔물결(ripple), 노 젓기 상호작용에 쓴다. 가장 단순한 게임용 근사는 2D **파동 방정식**(wave equation) 격자다.

```
2D 파동 방정식 (격자, 명시적):
  h^{n+1}_ij = 2h^n_ij - h^{n-1}_ij
             + c²(Δt/Δx)² (h_{i+1,j}+h_{i-1,j}+h_{i,j+1}+h_{i,j-1} - 4h_ij)
  ※ 안정 조건: c·Δt/Δx ≤ 1 (CFL)
```

각 격자점의 다음 높이는 (이전 두 프레임의 관성) + (이웃 평균과의 차이만큼 복원). 괄호 안 `(이웃 4합 − 4×자기)` 는 [01a §4](01a-navier-stokes-terms.md) 에서 본 **라플라시안** — "이웃 평균에서 벗어난 만큼 되당김"이 파동을 만든다. `c` 는 파속, CFL `c·Δt/Δx ≤ 1` 을 넘기면 폭발한다(한 스텝에 파동이 셀을 건너뛰면 안 됨). 명시적이라 구현이 단순하고 GPU stencil 로 바로 올라간다.

## Tessendorf FFT ocean

넓은 바다는 시뮬이 아니라 **통계적 스펙트럼 합성** 으로 만든다. Phillips 스펙트럼으로 주파수 영역의 높이장을 깔고 **역 FFT** 로 공간 영역 변위/법선을 얻는다.

발상: 실제 바다 표면은 수많은 파장·방향의 사인파가 겹친 것이고, 그 진폭 분포(어떤 파장이 얼마나 센가)는 바람·중력으로 정해지는 *통계 스펙트럼*(Phillips)으로 잘 모델링된다. 주파수 영역에 스펙트럼을 깔고 역 FFT 한 번이면 *타일링되는 무한 바다* 한 장이 나온다 — 게임/영화 표준(예: *Assassin's Creed* 의 바다, UE Water). **실제 유동 시뮬은 아니고 *그럴듯한 파면* 재현** 이라는 점이 핵심 — 물끼리 부딪치거나 흐르지 않는다.

> **선택 직관**: 상호작용(노/배가 만드는 잔물결)이 필요한 국소 수면 → SWE/파동 격자. 시각적으로 넓고 그럴듯하기만 하면 되는 외해 → Tessendorf FFT. 둘을 합쳐 *먼 바다는 FFT, 배 주변은 SWE* 로 섞기도 한다.

## 게임에서의 위치

게임플레이에 닿는 물 거동(부력)은 이 높이장에서 **수면 높이를 샘플** 해 아르키메데스 근사로 푸는 게 가장 싸고 안정적이다(→ [10-specialized-systems](../10-specialized-systems.md) 부력/공력). 높이장은 메시로 직접 뽑으므로([08-fluids §3](../08-fluids.md#3-한눈-요약--이산화-패밀리-비교) 표면 추출) marching cubes 같은 비싼 등치면 추출도 필요 없다.

---

**관련 함정** (전체 체크리스트는 [08-fluids §5](../08-fluids.md#5-함정--결정론-체크리스트)):
- **CFL 위반**: 명시적 파동 stencil 은 `c·Δt/Δx ≤ 1` 을 넘기면 폭발한다 — `Δt` 또는 `c` 를 묶어라.
- **FFT 는 유동이 아님**: Tessendorf 는 통계적 파면 재현일 뿐 — 흐름·충돌·질량 보존이 없다. 상호작용·부력 정확도가 필요하면 SWE/샘플 근사로.
- **결정론**: 게임 부력에 쓰는 높이장 샘플은 게임플레이에 닿으므로, 필요하면 결정적 경로로(→ [12]). 순수 시각 FFT 는 결정론에서 빼는 게 싸다.
