# [08·2.1a] Navier–Stokes 각 항의 직관 (Navier–Stokes, term by term)

## 0. 한 문장 요약

> **NS 운동량 방정식은 그냥 `F = ma` 를 "공간에 퍼진 속도장"에 다시 쓴 것**이다 — 가속도 `∂u/∂t` 에 네 가지 힘/효과가 더해진다. 이류는 "물질을 따라가면" 사라지는 *겉보기* 항이고, 점성은 속도를 이웃과 평균 내는 확산이며, 압력은 비압축이라는 *구속*을 매 순간 지키기 위해 즉시 풀려 나오는 *반작용*이다.

아래는 이 한 문장을 항 하나씩 그림으로 푸는 과정이다. 미분 연산자(`∇`, `∇·`, `∇²`)의 기하학적 의미는 [00-foundations](../00-foundations.md) 의 벡터·미적분 절을 전제한다.

---

## 1. 좌변 `∂u/∂t` 와 "물질 미분" — 카메라를 어디에 두는가

`F = ma` 의 가속도 `a` 가 NS 좌변에 해당한다. 그런데 속도장 `u(x, t)` 에는 *두 가지* 시간 변화가 있다.

- **국소(Eulerian) 변화** `∂u/∂t`: 공간의 **고정된 한 점**에 카메라를 박고 보는 변화. 강가 다리에 서서 다리 밑 한 지점의 물살이 빨라지는지 보는 것.
- **물질(Lagrangian) 변화** `Du/Dt`: 유체 **알갱이 하나를 따라가며** 보는 변화. 보트를 타고 물살에 떠내려가며 내 속도가 어떻게 변하는지 보는 것.

둘의 관계가 **물질 미분(material derivative)**:

```
Du/Dt = ∂u/∂t + (u·∇)u
 (따라가며 본 가속)   └ 국소 변화 ┘   └ 이류 ┘
```

뉴턴 법칙은 "알갱이를 따라가는" 관점(`Du/Dt`)에서 깔끔하다. 그걸 고정 격자 관점(`∂u/∂t`)으로 옮기면 `(u·∇)u` 라는 **추가 항이 튀어나온다** — 이것이 이류다. NS 운동량 방정식을 `Du/Dt = -(1/ρ)∇p + ν∇²u + f` 로 쓰면 정확히 `질량×가속 = 힘들의 합` 의 모양이다.

> **핵심**: 이류는 "새로운 물리력"이 아니라 *고정 카메라로 보기 때문에 생기는 겉보기 항*이다. 그래서 Lagrangian(입자) 솔버에서는 — 입자가 알갱이를 따라가므로 — **이류가 공짜로 사라진다**([03-lagrangian-sph](03-lagrangian-sph.md)). Eulerian 격자에서는 이걸 매 스텝 손으로 처리해야 한다([02-eulerian-grid](02-eulerian-grid.md)).

---

## 2. 이류 `-(u·∇)u` — 왜 유일한 비선형 항인가

`(u·∇)u` 는 "속도장이 자기 자신을 자기 자신을 따라 실어 나른다"는 뜻이다. 1D 로 줄이면 정체가 또렷하다:

```
1D:  (u·∇)u = u · ∂u/∂x
       └ 나르는 속도 ┘ └ 날라지는 양의 기울기 ┘
```

날라지는 양(`u`)과 그것을 나르는 속도(`u`)가 **같은 것**이다. 그래서 `u·∂u/∂x` 는 `u` 에 대해 **2차(곱)** — 비선형(non-linear)이다. NS 의 나머지 항은 전부 `u` 또는 `p` 에 **선형**이다(`∇²u`, `∇p` 는 1차). 난류·소용돌이·충격 같은 유체의 *모든 흥미로운 카오스* 가 바로 이 한 비선형 항에서 나온다.

> **그림**: 빠른 물줄기가 느린 물 속으로 파고들면, 빠른 부분이 앞쪽 느린 부분을 밀어 *프로파일이 점점 가팔라진다* → 결국 말려 깨진다(파도가 부서지는 이유). 선형 항은 이런 "자기 강화"를 못 만든다.

수치적으로 이 항이 제일 까다롭다. 단순 차분은 폭발하고(CFL), Stam 의 **semi-Lagrangian**은 "시간을 거꾸로 추적"해 무조건 안정을 얻지만 대가로 디테일이 뭉개진다(수치 점성) — 상세는 [02-eulerian-grid](02-eulerian-grid.md).

## 3. 압력 `-(1/ρ)∇p` 와 비압축 `∇·u=0` — 라그랑주 승수의 정체

이 둘은 한 묶음으로 이해해야 한다. **압력 단독으로는 방정식이 없기 때문**이다.

**먼저 `∇·u=0` 이 무슨 뜻인가.** 발산(divergence) `∇·u` 는 한 점에서 "흘러 나가는 양 − 흘러 들어오는 양"이다.

```
∇·u = ∂u/∂x + ∂v/∂y + ∂w/∂z
```

- `∇·u > 0`: 그 점이 *원천(source)* — 사방으로 퍼져 나감 → 거기 있던 유체가 늘어남 → **팽창**.
- `∇·u < 0`: 그 점이 *흡입(sink)* → **압축**.
- `∇·u = 0`: 들어온 만큼 나간다 → **부피 불변 = 비압축**.

작은 상자를 상상하라. 비압축이면 어떤 상자든 들어온 물의 양 = 나간 물의 양이어야 한다(물은 거의 안 눌린다). 이 "매 점, 매 순간 지켜야 하는 부피 보존"이 `∇·u=0` 이다.

**그럼 압력은?** `∇·u=0` 은 미래를 예측하는 발전 방정식이 아니라, *매 순간 만족해야 하는 구속*이다. 역학에서 구속을 강제하는 힘이 **라그랑주 승수(Lagrange multiplier)** — 압력이 바로 그것이다.

> **비유**: 책상 위 구슬은 "책상을 뚫지 않는다"는 구속을 받는다. 책상이 구슬을 떠받치는 **수직항력**은 미리 정해진 값이 아니라 *구슬이 뚫지 않을 만큼 딱 필요한 만큼* 즉시 생긴다. 압력도 똑같다 — 유체가 *압축되지 않을 만큼 딱 필요한 만큼* 매 스텝 솟아나는 반작용이다. 그래서 압력에는 `∂p/∂t = …` 같은 자기 방정식이 없다.

**계산 절차(연산자 분리의 핵심).** 그래서 솔버는 이렇게 한다:

```
1. 압력 빼고 다른 항(이류·점성·외력)만 적용 → 임시 속도 u*  (보통 ∇·u* ≠ 0, 발산이 생김)
2. u* 의 발산을 정확히 상쇄하는 압력을 푼다:
      ∇²p = (ρ/Δt) ∇·u*        ← 포아송(Poisson) 방정식
3. 그 압력의 그래디언트로 발산을 깎아낸다:
      u = u* - (Δt/ρ) ∇p       ⟹  이제 ∇·u = 0
```

이 3단계가 Eulerian 의 **pressure projection** 이다. 수학적으로는 "임의의 벡터장을 *발산 없는 부분* 과 *그래디언트 부분* 으로 쪼갠다(Helmholtz–Hodge 분해)"는 것 — projection 이라는 이름이 여기서 온다. 압력항이 하는 일은 결국 속도장에서 "압축을 일으키는 성분"만 깔끔히 제거하는 사영이다.

> **왜 한 갈래로 갈리는가**: Lagrangian 은 이 포아송을 직접 풀지 않고, *밀도가 목표값을 벗어난 만큼* 압력을 EOS 로 계산하거나(SPH) 위치를 보정한다(PBF). 같은 구속(`ρ`=일정 ↔ `∇·u=0`)을 푸는 다른 길이다 → [03](03-lagrangian-sph.md) · [04](04-position-based-fluids.md).

## 4. 점성 `ν∇²u` — 왜 라플라시안이 "확산"인가

라플라시안 `∇²u` 는 "한 점의 값이 *이웃 평균* 에서 얼마나 벗어났는가"를 잰다.

```
1D 근사:  ∂²u/∂x² ≈ (u_{i+1} + u_{i-1} - 2u_i) / Δx²
                      └ 이웃 둘의 평균 − 자기 자신 ┘ (×2/Δx²)
```

- `u_i` 가 이웃 평균보다 *작으면* `∇²u > 0` → 시간이 지나며 끌어올려짐.
- `u_i` 가 이웃 평균보다 *크면* `∇²u < 0` → 끌어내려짐.

즉 `∂u/∂t = ν∇²u` 는 **모든 점을 이웃 평균 쪽으로 당기는** 방정식 — 열이 뜨거운 데서 찬 데로 퍼지는 그 확산(diffusion) 방정식과 글자 그대로 같다. 점성은 *속도의 들쭉날쭉함을 매끄럽게 뭉개는* 작용이다. 운동 에너지를 열로 소산시키므로 유체가 점점 잠잠해진다.

> **그림**: 빠른 층과 느린 층이 나란히 흐르면, 점성은 둘 사이 경계를 흐릿하게 섞어 속도차를 줄인다(꿀이 물보다 점성이 크다 = `ν` 가 크다 = 더 빨리 평준화).

게임 유체는 `ν` 가 작아 점성항을 **생략하거나 약하게**만 둔다. 더 큰 문제는 *원치 않는* 점성이다 — semi-Lagrangian·PIC 의 보간이 사실상 강한 인공 확산처럼 작동해 디테일을 죽인다(**수치 점성**, [02](02-eulerian-grid.md)). 명시적으로 풀면 `Δt` 제약이 빡세서 보통 **암시적 확산**(implicit, 선형계 풀이)으로 처리한다.

---

## 5. 외력 `f` — 가장 단순한 항

중력·부력·사용자 입력 힘, 그리고 잃어버린 소용돌이를 되박는 **vorticity confinement** 까지. 발전 방정식에 그냥 더하면 된다(`u ← u + Δt·f`). 수치적으로 가장 얌전한 항이라 더 풀 것이 없다.

---

## 6. 종합 — 한 스텝을 항별로 쪼개 보면

Eulerian 의 한 스텝은 결국 **항을 하나씩 순서대로 적용**하는 것이다(연산자 분리, operator splitting):

```
u ← u + Δt·f               // 5절: 외력
u ← advect(u, Δt)          // 2절: 이류 (semi-Lagrangian)
u ← diffuse(u, ν, Δt)      // 4절: 점성 (선택, 암시적)
u ← project(u)             // 3절: 압력으로 ∇·u=0 강제
```

각 항의 직관을 알면 이 순서가 자연스럽다 — 먼저 힘으로 밀고, 흐름을 따라 나르고, 점성으로 다듬고, 마지막에 압력으로 "부피 보존"을 못 박는다. 구체적 알고리즘은 [02-eulerian-grid](02-eulerian-grid.md).

## 7. 함정 (전체 체크리스트는 [08-fluids §5](../08-fluids.md#5-함정--결정론-체크리스트))

- **이류를 선형처럼 다룸**: `(u·∇)u` 의 비선형성이 폭발/충격의 근원. 단순 전진 차분은 CFL 을 넘기면 터진다.
- **압력을 상태로 저장**: 압력에는 발전 방정식이 없다 — 매 스텝 `∇·u=0` 에서 새로 푼다. 이전 압력은 솔버의 *초기 추정* 으로만 쓴다.
- **점성과 수치 점성 혼동**: 의도한 `ν∇²u` 와 보간이 만드는 인공 소산은 다른 것. 연기가 흐릿하면 후자를 의심(→ FLIP/APIC, [02](02-eulerian-grid.md)).
