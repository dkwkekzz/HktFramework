# [07·2.2a] XPBD compliance — 강성을 솔버에서 떼어내기 (XPBD, from the ground up)

## 0. 한 문장 요약

> **순수 PBD 는 "구속을 *무한히* 빳빳한 막대로 보고 100% 만족시킨다"** — 그래서 강성을 끌 수 없고 반복 수에 끌려다닌다. XPBD 는 구속에 **유연도 `α`(=용수철의 1/k)** 를 부여해 "딱 이만큼만 버티는 용수철"로 바꾸고, 그 용수철이 한 스텝 동안 누적한 힘을 **라그랑주 승수 `λ`** 로 기억한다. `α` 가 물리적 강성을 쥐고, 반복은 수렴만 담당한다.

아래는 이 문장을 한 걸음씩 풀어가는 과정이다.

---

## 1. 순수 PBD 가 숨기고 있던 가정 — "무한 강성"

[02-pbd-xpbd](02-pbd-xpbd.md) 의 거리 구속 투영을 다시 보자:

```
Δp_i = -(w_i/(w_i+w_j)) * C * n
```

이 한 줄은 **"구속 위반 `C` 를 이번 투영에서 통째로 0으로 만든다"** 는 뜻이다. 매 반복마다 `C` 를 완전히 지운다 — 즉 구속을 *절대 안 늘어나는 강체 막대*로 본다. 강성 `k` 라는 개념 자체가 식에 없다.

문제는 여기서 나온다:

- 반복을 **여러 번** 돌리면(Gauss–Seidel) 다른 구속이 깬 것을 또 지우고, 다시 지우고… 그 결과 천이 점점 더 빳빳해진다.
- 반복 수 `N` 을 바꾸면 **같은 천이 다른 강성**을 갖는다. timestep 을 줄여도 마찬가지.

> 직관: 순수 PBD 의 "강성"은 물성이 아니라 **솔버를 몇 번 돌렸나**의 부산물이다. 물리 상수가 아니라 설정 값에 매달려 있다 — 결정론·튜닝 양쪽에 독.

우리가 원하는 것: "이 천의 강성은 `k=500 N/m` 다"를 **반복 수와 무관하게** 박는 것. 그러려면 구속이 *무한히* 빳빳한 막대가 아니라 **유한한 용수철**이어야 한다.

---

## 2. 유연도 `α = 1/k` — 용수철의 말랑함

강성 `k` 의 용수철을 거꾸로 본다. **유연도(compliance) `α := 1/k`** 를 정의한다.

```
k  = ∞ (무한 강성, 강체 막대)  ⟺  α = 0   (전혀 안 늘어남)
k  작음 (말랑한 용수철)        ⟺  α 큼    (잘 늘어남)
```

`α` 는 "단위 힘당 얼마나 늘어나는가"라는 **물리량(단위 있음, 길이/힘)** 이다. 반복 수·timestep 같은 솔버 설정과 무관한, 천 고유의 성질이다. 이걸 솔버에 직접 집어넣으면 강성이 설정에서 분리된다.

탄성 에너지로 보면 구속 `C` 에 묶인 용수철의 퍼텐셜은

```
U(x) = (1/2) * (1/α) * C²  = (1/2) k C²
```

`α → 0` 이면 `U → ∞` (조금만 위반해도 무한 에너지) ⟹ 강체 막대. `α > 0` 이면 유한한 복원력. **순수 PBD = 이 에너지의 `α→0` 극한**이라는 것이 곧 드러난다(§5).

---

## 3. 라그랑주 승수 `λ` — 용수철이 낸 힘을 기억하기

구속을 다루는 정석은 라그랑주 승수다([05-constraint-solving](../05-constraint-solving.md) 와 같은 언어). `λ` 는 **그 구속이 가한 힘의 크기**(impulse 차원)다. 구속력은 구속 방향 `∇C` 를 따라

```
f_constraint = ∇Cᵀ λ
```

순수 PBD 가 `λ` 를 *매 투영마다 버린다*면(위치만 옮기고 힘은 안 기억), XPBD 는 한 스텝 동안 **`λ` 를 누적**한다. 왜 기억해야 하는가?

> 유한 강성 용수철은 "지금까지 얼마나 당겼는지"를 알아야 다음에 얼마나 더 당길지 정한다. `λ` 가 그 누적 기억이다. 무한 강성(PBD)은 매번 "무조건 0으로" 라 기억이 필요 없다 — 그래서 PBD 엔 `λ` 가 없었다.

XPBD 는 backward Euler 로 이산화한 운동방정식에 이 유연한 구속을 결합해, 한 스텝에서 풀어야 할 두 식을 세운다(Macklin 2016):

```
M (x - x̃) = ∇Cᵀ λ                 # 운동방정식: 예측위치 x̃ 에서 구속력만큼 이동
C(x) + α̃ λ = 0                     # 유연한 구속: α̃ 가 0이면 C=0(강체), 클수록 C 허용
```

둘째 식이 핵심이다. `α̃ = 0` 이면 `C(x)=0`(순수 PBD), `α̃ > 0` 이면 `C = -α̃ λ` 즉 **힘에 비례해 구속을 살짝 위반하도록 허용**한다 — 용수철이 늘어나는 바로 그것.

---

## 4. 왜 `α̃ = α/Δt²` 인가 — Δt² 의 출처

여기가 가장 헷갈리는 지점이다. compliance 가 솔버에 들어갈 때 왜 그냥 `α` 가 아니라 `α/Δt²` 인가?

운동방정식 `M(x - x̃) = ∇Cᵀ λ` 의 `λ` 는 **impulse**(힘 × Δt 의 적분)지, 힘 자체가 아니다. backward Euler 에서 가속도는 `(x - x̃)/Δt²` 차원으로 들어오므로, `M(x-x̃)` 한 변에 `Δt²` 이 묻어 있다. 두 식을 한 변수 `λ` 로 정리하면 그 `Δt²` 이 구속 식 쪽으로 넘어가 **유연도에 `1/Δt²` 가 붙는다**:

```
α̃ = α / Δt²        # "timestep 정규화된 compliance"
```

차원으로 확인하면 깔끔하다. 둘째 식 `C + α̃ λ = 0` 에서 `C` 는 길이, `λ` 는 impulse(=힘·시간) 이므로 `α̃` 는 길이/impulse. 한편 물리 유연도 `α` 는 길이/힘. 힘 = impulse/시간 이 아니라 가속도 이산화 때문에 시간이 *제곱*으로 들어와 `α̃ = α/Δt²` 가 된다.

> 직관: `α̃ = α/Δt²` 은 "한 timestep 안에서 이 용수철이 얼마나 양보하는가"로 환산한 값이다. Δt 가 작으면(스텝이 촘촘) `α̃` 이 커져 한 스텝당 양보가 늘고, 누적 `λ` 와 합쳐져 **결국 같은 물리 강성 `k=1/α`** 로 수렴한다. 이 정규화 덕분에 **timestep 을 바꿔도 강성이 안 변한다** — PBD 가 못 하던 바로 그것.

이제 한 구속의 갱신을 풀면(거리 구속, `w=1/m`):

```
α̃ = α / Δt²
Δλ = (-C - α̃ * λ) / (w_i + w_j + α̃)     # 분모에 α̃ 가 더해진 것에 주목
λ  += Δλ                                  # 한 스텝 내 누적
Δp_i = +w_i * Δλ * n
Δp_j = -w_j * Δλ * n
```

PBD 갱신과 딱 두 군데가 다르다: **분모에 `+α̃`**(용수철이 양보하는 만큼 보정을 줄임), **분자에 `-α̃·λ`**(지금까지 누적한 힘을 되먹임). 이 두 항이 강성을 `α` 가 쥐도록 만든다.

---

## 5. 극한 확인 — `α→0` 이면 정확히 순수 PBD

`α = 0 ⟹ α̃ = 0` 을 위 갱신에 넣으면:

```
Δλ = -C / (w_i + w_j)
Δp_i = -(w_i/(w_i+w_j)) * C * n
```

[02-pbd-xpbd](02-pbd-xpbd.md) 의 순수 PBD 거리 구속 투영과 **글자 그대로 같다**. 즉 XPBD 는 PBD 를 *버리는* 게 아니라 **`α=0` 특수 케이스로 품는** 일반화다. `α` 슬라이더를 0에서 올리면 강체 막대 → 점점 말랑한 용수철로 연속적으로 변한다.

반대로 `α̃` 가 매우 크면(아주 말랑) 분모 `w+α̃ ≈ α̃` 라 `Δλ ≈ -C/α̃` 로 보정이 작아져 거의 안 당긴다 — 흐물거리는 천.

---

## 6. 그래서 무엇이 달라졌나 — 반복 vs 강성의 분리

| | 순수 PBD | XPBD |
|---|---|---|
| 강성을 쥐는 것 | 반복 수 `N`·Δt (부작용) | **compliance `α`**(물리 상수) |
| 반복 수의 역할 | 강성 + 수렴 (뒤섞임) | **수렴(품질)만** |
| timestep 바꾸면 | 강성이 변함 | `α̃=α/Δt²` 정규화로 **불변** |
| `λ` | 없음(매번 버림) | 한 스텝 누적(용수철 힘 기억) |
| 강체 구속 | 기본 | `α=0` 극한 |

> 핵심: XPBD 의 단 두 항(`분모 +α̃`, `분자 -α̃λ`)이 **강성을 솔버 설정에서 떼어내** 물리 상수 `α` 에 묶었다. 품질이 부족하면 반복이 아니라 **substepping** 을 늘린다(작은 Δt 가 `α̃` 정규화와 맞물려 수렴·안정 둘 다 좋아짐, Macklin 2019). 이 분리가 강체 조인트([06](../06-joints-articulation.md))와 천·soft 구속을 **하나의 XPBD 솔버 프레임**([05](../05-constraint-solving.md))으로 통합하는 토대다.

## 7. 함정 (전체 체크리스트는 [07-deformable-bodies §5](../07-deformable-bodies.md#5-함정--결정론-체크리스트))

- **`λ` 리셋 시점**: `λ` 는 **substep 시작마다 0으로** 초기화하고 그 substep 의 반복 동안만 누적한다. 스텝 경계를 넘겨 누적하면 강성이 어긋난다.
- **`α̃` 의 Δt² 누락**: `α̃ = α/Δt` 로 잘못 쓰면 timestep 독립성이 깨진다 — 반드시 `Δt²`.
- **`α=0` 와 부동소수점**: 강체 구속을 `α=0` 으로 둘 때 분모 `w+α̃` 가 순수 `w` 라 안전하지만, 매우 작은 `α̃` 와 큰 `w` 가 섞이면 조건수 주의([05](../05-constraint-solving.md)).
- **결정론**: `α` 는 결정론 상수 — CVar 로 흔들지 말고 헤더 상수로 고정(프로젝트 규약). 반복·substep 수도 고정([12](../12-determinism-networking.md)).
