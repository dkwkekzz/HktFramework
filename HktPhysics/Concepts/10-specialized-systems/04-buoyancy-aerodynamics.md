# [10·2.4] 부력 · 공력 (Buoyancy & Aerodynamics)

> 물·공기 같은 매질이 물체에 가하는 힘을 전체 유체 시뮬([08]) 없이 *해석적 근사*로 처리하는 게임 실무 — 부력(아르키메데스), 항력, 양력, 바람장.
> **상위 노드**: [10-specialized-systems.md](../10-specialized-systems.md) · **상위 지도**: [README.md](../README.md) · **의존**: [02-dynamics](../02-dynamics.md) (힘·토크) · [08-fluids](../08-fluids.md) (height-field 물 표면)

---

물·공기가 물체에 가하는 힘. 전체 유체 시뮬([08](../08-fluids.md)) 을 돌리는 건 비싸므로, 게임에서는 *해석적 근사*로 배가 출렁이고 낙하산이 펴지고 날개가 뜨는 효과를 만든다.

## 부력 (Buoyancy, Archimedes)

잠긴 부피(submerged volume)가 밀어낸 유체 무게만큼 위로 뜨는 힘이다(아르키메데스 원리).

```
Fbuoyancy = ρfluid * g * Vsubmerged   (위 방향)
# ρfluid: 유체 밀도, g: 중력가속도, Vsubmerged: 잠긴 부피
```

실무에선 물체를 voxel/샘플 포인트로 근사해 *물 표면 아래에 있는 점들*만 합산한다. 물 표면 높이는 보통 [08](../08-fluids.md) 의 height-field(shallow water/Gerstner 파도)에서 샘플링한다 — 파도 위에서 배가 출렁이는 효과의 출처.

**핵심 — 부력 중심**: 힘을 무게중심이 아닌 *부력 중심(center of buoyancy)* 에 가해야 한다. 배가 기울면 잠긴 부피의 모양이 바뀌어 부력 중심이 무게중심에서 어긋나고, 그 어긋남이 **복원 토크(restoring torque)** 를 만들어 배가 다시 자세를 잡는다. 부력을 무게중심에 그냥 걸면 이 복원 토크가 사라져 배가 뒤집힌다.

## 항력 (Drag)

속도 제곱에 비례해 운동을 거스르는 힘. 물속 감속, 낙하산, 종단속도(terminal velocity)의 원천이다.

```
Fdrag = -½ * ρ * |v|² * Cd * A * v̂
# ρ: 매질 밀도, Cd: 항력계수, A: 단면적, v̂: 속도 방향 단위벡터
```

`-v̂` 방향(운동 반대)이라 항상 감속시킨다. 부력에 항력 댐핑을 더하지 않으면 배가 무한히 출렁인다.

## 양력 (Lift, 간단 익형)

받음각(angle of attack)에 따라 진행 방향에 *수직*으로 생기는 힘. 비행기 날개·글라이더·돛에 쓰며, 받음각 곡선 `Cl(α)` 로 근사한다.

```
Flift = ½ * ρ * |v|² * Cl(α) * A   (진행방향에 수직)
# Cl(α): 받음각에 따른 양력계수 곡선
```

받음각이 커지면 양력이 늘다가 어느 각(stall angle)을 넘으면 급감한다(실속) — `Cl(α)` 곡선이 그 모양을 담는다.

## 바람 (Wind)

전역/국소 바람장(wind field)을 물체 속도에 더해 *상대 속도*로 항력·양력을 계산한다.

```
v_relative = v_object - v_wind     # 이 상대 속도로 drag/lift 계산
```

천([07](../07-deformable-bodies.md))·나뭇잎·파티클([09](../09-particles.md))에도 동일하게 주입해 일관된 바람 효과를 낸다.

## 실무

- **부력** : 전용 엔진 기능보다 게임별 구현이 일반적 — 물체를 샘플 포인트로 근사해 height-field 물 표면 아래 점에 부력·항력을 가한다(예: UE의 Water 플러그인 + 커스텀 부력 컴포넌트).
- **항력/양력** : 강체에 외력으로 직접 더하는 커스텀 컴포넌트가 표준. 비행 게임은 익형별 `Cl/Cd` 룩업 테이블을 둔다.
