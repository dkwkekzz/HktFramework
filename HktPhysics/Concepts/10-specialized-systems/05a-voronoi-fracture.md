# [10·2.5a] Voronoi 분할 — 가장 가까운 점이 파편을 만든다 (Voronoi Fracture)

## 0. 한 문장 요약

> **공간 안에 점(seed)들을 뿌리고, 각 점이 "자기에게 가장 가까운 영역"을 차지하게 하면 — 그 영역들의 경계가 곧 깨진 파편의 면이 된다.** 두 이웃 점의 셀 경계는 둘을 잇는 선분의 *수직 이등분면*이라, 자동으로 평평한 절단면(부서진 콘크리트 단면 같은)이 만들어진다. 점을 어디에 얼마나 뿌리느냐가 파편의 크기·모양·분포를 결정한다.

---

## 1. 왜 "가장 가까운 점"이 자연스러운 파편인가

물체가 깨질 때 생기는 조각은 대략 *핵(nucleation site)* 들에서 균열이 퍼져 만난 면들로 갈린다. 이걸 기하학으로 흉내 내는 가장 단순하고 자연스러운 모델이 **"각 점이 자기 영역(자기에게 가장 가까운 공간)을 차지한다"** 는 규칙이다.

점 `pᵢ` 의 영역(Voronoi 셀)은:

```
Cell(pᵢ) = { x | 모든 j 에 대해 |x − pᵢ| ≤ |x − pⱼ| }
        = "다른 어떤 점보다 pᵢ 에 더 가까운 모든 점 x"
```

이 정의만으로 공간이 빈틈없이, 겹침 없이 셀들로 채워진다. 각 셀이 하나의 파편이 된다.

## 2. 셀 경계 = 수직 이등분면 — 왜 평평한 절단면이 나오나

두 이웃 점 `pᵢ`, `pⱼ` 의 셀 경계는 "두 점에서 거리가 같은 점들의 집합"이다. 그것은 정확히 두 점을 잇는 선분의 **수직 이등분면(perpendicular bisector plane)** 이다.

```
경계면: { x | |x − pᵢ| = |x − pⱼ| }   ⟹  평면 (수직 이등분면)
```

평면이라는 점이 중요하다 — 셀(파편)은 이런 평면들로 둘러싸인 **볼록 다면체(convex polyhedron)** 가 된다. 부서진 콘크리트·돌의 단면이 평평한 다각형들로 보이는 것과 같은 모양이다. 구현은 보통 각 점을 둘러싼 이웃들의 수직 이등분 평면들로 셀을 *반평면 교차(half-space intersection)* 해 잘라낸다(또는 원본 메시를 이 평면들로 차례로 자른다).

## 3. 점 분포가 파편 패턴을 결정한다

파편의 "느낌"은 전적으로 *seed 점을 어떻게 뿌리느냐*로 정해진다.

- **균일 랜덤(uniform random)**: 고르게 비슷한 크기의 파편 — 일반적인 산산조각.
- **충격점 집중(clustered around impact)**: 맞은 자리 근처에 점을 많이 뿌리면 그곳만 잘게, 멀수록 큰 덩어리 — 총알 구멍·충격 중심의 사실적 패턴.
- **결(grain) 방향 편향**: 점을 한 축으로 늘려 뿌리면 나무결처럼 길쭉한 파편.

게임에서는 보통 이 분포를 아티스트가 제어(점 밀도·패턴·시드 고정)해 *결정적이고 의도된* 파편을 굽는다.

## 4. 클러스터링으로 다단계 파괴를 굽는다

한 번에 잘게 쪼개진 파편만 두면 항상 가루로 부서진다. 더 자연스럽게 — *큰 충격엔 큰 덩어리로, 더 큰 충격엔 그 덩어리가 다시 잘게* — 하려면 계층(hierarchy)을 둔다.

- 가장 잘게 나눈 Voronoi 셀(leaf 파편)들을 **클러스터(cluster)** 로 묶어 큰 덩어리를 만든다.
- 약한 충격: 클러스터 단위로만 분리(큰 조각으로 떨어짐).
- 강한 충격: 클러스터 내부 결합까지 끊어 leaf 파편으로 흩어짐.

이 다단계 구조를 미리 구워두면 런타임엔 "어느 레벨까지 끊을지"만 결정하면 된다([05-destruction-fracture](05-destruction-fracture.md) 의 연결 그래프·island 와 직접 연결된다 — 클러스터 = 묶인 노드 그룹).

## 함정 (전체 체크리스트는 [10-specialized-systems §5](../10-specialized-systems.md#5-함정--결정론-체크리스트))

- **시드 비결정성**: seed 점을 비고정 난수로 뿌리면 빌드/클라마다 파편이 달라진다 → 시드 고정(베이크 결정성).
- **점 과다**: 셀 수가 너무 많으면 베이크·런타임 모두 비용 폭발 → 다단계 클러스터링으로 leaf 수 통제.
- **얇은/퇴화 셀**: 점이 너무 가까우면 얇은(degenerate) 파편이 생겨 충돌·렌더가 불안정 → 최소 간격(Poisson-disk 등) 보장.
