## 0. 한 문장 요약

> **타이어 힘은 "지면을 미끄러진 양(슬립)"의 함수다.** 정지 마찰처럼 "안 미끄러지면 힘이 없다"가 아니라, *고무가 살짝 미끄러지면서(슬립)* 비로소 추진·제동·코너링 힘이 생기고, 그 관계는 처음엔 선형으로 가파르게 오르다 피크를 찍고 다시 완만히 내려가는 비선형 곡선(Pacejka)이다. 종방향·횡방향 힘은 같은 고무가 낼 수 있는 *하나의 마찰 예산*을 나눠 쓴다(friction circle).

아래는 이 문장을 한 걸음씩 푼다.

---

## 1. 왜 슬립이 힘을 만드는가

직관적으로 "바퀴가 구르면 안 미끄러진다"고 생각하기 쉽지만, 실제 타이어는 접지면(contact patch)의 고무가 변형되며 **항상 조금씩 미끄러진다**. 이 미세한 미끄러짐의 양 — 슬립(slip) — 이 클수록 고무가 노면을 더 강하게 긁어 더 큰 힘을 낸다. 슬립이 0이면 힘도 0, 슬립이 커지면 힘이 커지다가, 너무 커지면(고무가 다 미끄러져 버리면) 오히려 힘이 줄어든다(미끄러지는 타이어가 접지력을 잃는 것).

슬립은 두 방향으로 나뉜다 — 진행 방향(종방향)과 옆 방향(횡방향).

## 2. Slip ratio — 종방향 슬립 (가속/제동)

바퀴 원주 속도(`ωwheel * Rwheel`)와 차량 실제 진행 속도(`vlong`)의 불일치다.

```
slipRatio = (ωwheel * Rwheel - vlong) / |vlong|
```

- 가속 시 바퀴가 노면보다 빨리 돌면(`ωR > vlong`) → 양의 슬립 → 추진력.
- 제동 시 바퀴가 노면보다 느리게 돌면(`ωR < vlong`) → 음의 슬립 → 제동력.
- 슬립 = 0 이면 완전 구름(추진/제동력 없음).

이 값이 종방향 타이어 힘 `Flong` 을 결정한다.

## 3. Slip angle — 횡방향 슬립 (코너링)

바퀴가 *향하는* 방향과 실제 *진행하는* 방향 사이의 각도다.

```
slipAngle = atan2(vlat, |vlong|)     # vlat: 횡속도, vlong: 종속도
```

코너에서 바퀴를 꺾으면 차가 즉시 그 방향으로 가지 않고 약간 옆으로 미끄러지며 간다 — 그 어긋난 각이 slip angle 이고, 이것이 코너링 힘(조향력) `Flat` 을 만든다. slip angle 이 클수록 코너링 힘이 커지다가 한계를 넘으면 줄어든다(언더/오버스티어로 미끄러짐).

## 4. Pacejka magic formula — 슬립→힘 곡선의 모양

슬립과 힘의 관계는 단순 비례가 아니라 **처음 선형 상승 → 피크 → 완만한 하강**의 비선형 곡선이다. 이 모양을 단 4개 계수로 근사하는 산업 표준이 파제카 매직 포뮬러(Pacejka magic formula)다.

```
F(slip) = D * sin( C * atan( B*slip - E*(B*slip - atan(B*slip)) ) )
# B: stiffness(초기 기울기 — 얼마나 빨리 힘이 붙나)
# C: shape(곡선 모양 — 피크 후 얼마나 떨어지나)
# D: peak(최대 힘 — 그립 한계)
# E: curvature(피크 근처 휘어짐)
```

"magic" 이라 불리는 이유: 물리 유도가 아니라 *실측 곡선에 가장 잘 맞는 함수 형태*를 경험적으로 찾은 것이기 때문이다. 게임에서는 같은 형태를 종방향(slip ratio 입력)과 횡방향(slip angle 입력)에 각각 적용해 `Flong`, `Flat` 을 얻고, 계수를 튜닝해 "운전 느낌"을 만든다. 더 가벼운 게임은 이 곡선을 1D 룩업 테이블이나 구간 선형으로 대체하기도 한다.

## 5. Friction circle / ellipse — 하나의 그립 예산

타이어가 낼 수 있는 *총* 마찰력에는 한계가 있다(`μFz`, μ는 마찰계수, Fz 는 수직 하중). 종방향(가속/제동)과 횡방향(조향)이 *그 한계를 나눠 쓴다*. 둘의 합성 벡터 길이가 한계 원 안에 있어야 한다.

```
(Flong / μFz)^2 + (Flat / μFz)^2 ≤ 1      # 마찰원 안쪽이어야 함
```

이것이 운전 직관의 핵심을 설명한다:
- **풀 가속 중에는 조향력이 줄어** 차가 똑바로만 나가려 한다(언더스티어).
- **풀 브레이크 중에 핸들을 꺾으면** 종방향 예산이 다 차서 횡방향이 부족 → 미끄러진다(그래서 ABS·트레일 브레이킹 같은 테크닉이 의미를 가진다).
- 한계 원을 타원으로 두면 종/횡 그립이 다른 차의 특성도 표현한다.

friction circle 합성을 안 하면 가속과 조향을 동시에 풀로 줘도 그립이 비현실적으로 커지는 버그가 난다.

## 6. 저속 발산 처리 — 가장 흔한 실패

slip ratio/angle 정의에 모두 분모로 `|vlong|`(또는 `|v|`)가 들어간다. 차가 거의 멈추면(`|v| → 0`) 분모가 0에 가까워져 슬립이 폭발하고 타이어 힘이 발산한다 — 정지한 차가 갑자기 튀어나가거나 진동하는 원인.

대응:
- **저속 클램프**: `|v|` 에 하한을 둬 분모가 너무 작아지지 않게 한다.
- **정지 마찰 별도 처리**: 일정 속도 이하에서는 슬립 기반 모델 대신 정적 마찰(static friction)·속도 댐핑으로 부드럽게 멈추게 전환한다.

- **저속 발산**: `slipRatio`/`slipAngle` 분모(|v|)가 0 근방에서 힘 폭주 → 저속 클램프 + 정지 마찰 별도 처리 필수.
- **friction circle 미적용**: 가속+조향 동시에 그립이 비현실적으로 커진다 → 종/횡 합성으로 한계 원 안에 묶는다.
