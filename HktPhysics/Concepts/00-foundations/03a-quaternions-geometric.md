## 1. 왜 또 사원수인가 — 이 문서의 자리

형제 노드 [03-rotations](03-rotations.md)는 회전 표현의 **카탈로그**다. 행렬, 오일러각, 축각, 사원수를 나열하고 "사원수를 써라"라는 결론에 도달한다. 하지만 그 문서는 사원수를 *도구*로 제시할 뿐, **왜 4개의 실수가 3차원 회전을 정확히 표현하는가**, **왜 하필 반각인가**, **왜 `q v q⁻¹` 라는 기묘한 샌드위치 곱인가**라는 근본 질문에는 깊이 답하지 않는다.

이 문서는 그 "왜"를 채운다. 결론을 외우는 대신, 복소수가 2D 회전을 표현하는 친숙한 사실에서 출발해 한 차원씩 끌어올려 사원수에 도달한다. 이걸 한 번 제대로 통과하면 사원수는 더 이상 마법이 아니라 **2D 회전의 자연스러운 3D 일반화**로 보인다.

표기 규약은 허브를 따른다. 각도는 모두 **라디안**. 사원수는 `q = (w, x, y, z) = w + x i + y j + z k`, 스칼라부 `w = Re(q)`, 벡터부 `v = Im(q) = (x, y, z)`. 단위 사원수만 회전을 나타낸다 (`|q| = 1`).

## 2. 출발점 — 복소수는 2D 회전이다

먼저 한 차원 아래에서 직관을 굳힌다. 복소수 `z = a + b i` 는 평면의 점 `(a, b)` 이고, 핵심 사실은 `i² = -1` 이다. 단위 복소수 `u = cos θ + i sin θ` 를 어떤 점 `p = x + i y` 에 곱하면:

```
u · p = (cos θ + i sin θ)(x + i y)
      = (x cos θ - y sin θ) + i (x sin θ + y cos θ)
```

이건 정확히 2D 회전행렬 `[[cosθ, -sinθ], [sinθ, cosθ]]` 를 `(x, y)` 에 적용한 결과다. 즉 **단위 복소수를 곱하는 것 = 원점 둘레로 θ 만큼 회전**.

여기서 두 가지 구조를 기억하자. 이게 사원수로 그대로 승격된다.

- **단위원 위의 점이 회전이다.** `|u| = 1` 인 복소수들은 단위원 `S¹` 을 이룬다. 각 점이 하나의 회전. 회전의 합성은 복소수 곱이고, 곱은 각도의 덧셈(`θ₁ + θ₂`)에 대응한다.
- **곱 한 번으로 회전한다.** 2D에서는 `p → u p` 한 번이면 충분하다. 나중에 보겠지만 3D에서는 이게 *두 번*(샌드위치)이 된다 — 그 차이가 반각의 근원이다.

오일러 공식 `e^(iθ) = cosθ + i sinθ` 가 여기에 깔끔한 언어를 준다. 회전의 합성이 지수의 덧셈이 되고, 보간은 지수의 선형 보간 `e^(i(1-t)θ₀) · e^(i t θ₁)` 으로 자연스럽게 나온다. 이 지수형은 5절 SLERP에서 그대로 사원수판으로 부활한다.

## 3. 한 차원 올리기 — 해밀턴의 곤경과 i, j, k

3D 회전도 똑같이 "단위 어떤 수를 한 번 곱하면" 되지 않을까? 해밀턴(Hamilton)이 1843년에 매달린 문제가 이거였다. 복소수를 3차원으로 늘리려면 `a + b i + c j` 같은 삼원수(triplet)가 필요한데, **두 삼원수의 곱이 닫히지 않는다**. `i j` 가 무엇이 되어야 하는지 일관되게 정의할 수가 없었다.

해밀턴의 돌파구는 차원을 **3이 아니라 4로** 올리는 것이었다. 허수 단위 셋 `i, j, k` 를 두고:

```
i² = j² = k² = i j k = -1
```

이 한 줄에서 모든 곱셈 규칙이 따라 나온다. 양변에 적절히 곱해 정리하면:

```
i j =  k     j k =  i     k i =  j        (순환, 오른손)
j i = -k     k j = -i     i k = -j        (반순환, 부호 반전)
```

핵심은 **비가환(non-commutative)**: `i j = -j i`. 회전이 비가환(순서를 바꾸면 결과가 다름)이라는 물리적 사실이 대수 구조에 그대로 박혀 있다. 이게 사원수가 회전에 "맞는" 첫 번째 신호다.

이 곱셈 규칙을 일반 사원수 `q = (w, v)`, `p = (s, u)` (스칼라+벡터 분해)에 적용하면 그 유명한 **해밀턴 곱**이 나온다:

```
q ⊗ p = (w s - v·u,  w u + s v + v×u)
         └ 스칼라부 ┘  └─── 벡터부 ───┘
```

내적 `v·u` 와 외적 `v×u` 가 동시에 튀어나온다는 점을 음미하자. 외적(비가환, 순서 의존)이 비가환성을, 내적(가환)이 스칼라부를 만든다. 사원수 곱은 본질적으로 "내적과 외적을 한 연산에 묶은 것"이다.

## 4. S³, 반각, 그리고 sandwich product

### 4.1 단위 사원수는 S³ 위의 점

`|q|² = w² + x² + y² + z² = 1` 인 사원수들은 4차원 공간의 **단위 초구(unit 3-sphere) S³** 를 이룬다. 2D에서 단위 복소수가 `S¹`(원)을 이뤘듯이, 3D 회전은 `S³` 위의 점으로 표현된다. 차원이 하나 더 많다는 게 곧 double cover(7절)로 이어진다.

회전축을 단위벡터 `n̂`, 회전각을 `θ` 라 하면, 그 회전을 나타내는 단위 사원수는:

```
q = ( cos(θ/2),  sin(θ/2) · n̂ )
  =   cos(θ/2) + sin(θ/2)(nx i + ny j + nz k)
```

여기 **반각 `θ/2`** 가 나타난다. 왜 절반인가? 4.3에서 샌드위치 곱으로 정확히 유도한다. 지금은 형태만 새겨두자: 스칼라부가 `cos(θ/2)`, 벡터부가 `sin(θ/2)·n̂` 으로 **축과 각이 분리되어** 들어 있다. 축각 표현([03](03-rotations.md))이 사원수 안에 그대로 인코딩된 셈이다.

### 4.2 회전은 켤레 샌드위치 `q v q⁻¹`

3D 점 `v = (vx, vy, vz)` 를 **순허수 사원수** `v = (0, v)` (스칼라부 0)로 본다. 이 점을 `q` 로 회전시키는 공식은 곱 한 번이 아니라 **양쪽에서 끼우는 것**이다:

```
v' = q ⊗ v ⊗ q⁻¹
```

단위 사원수에서는 `q⁻¹ = q* = (w, -v)` (켤레, conjugate)이므로 역원 계산이 공짜다. 결과 `v'` 는 다시 순허수 사원수가 되고, 그 벡터부가 회전된 점이다.

왜 한 번이 아니라 두 번(샌드위치)인가? 직관적으로: `q ⊗ v` 한 번은 점을 4D 공간에서 비틀어 스칼라부를 0이 아니게 만들어 버린다(더 이상 순수 3D 점이 아니게 됨). 오른쪽에서 `q⁻¹` 을 한 번 더 곱하면 그 비틀림이 정확히 상쇄되어 다시 순허수(3D 점)로 돌아오고, **남는 것은 순수한 회전뿐**이다. 두 번 작용하기 때문에 각 작용이 `θ/2` 씩만 기여하면 합쳐서 `θ` 가 된다 — 이것이 반각의 정체다.

### 4.3 반각의 유도 (sandwich를 펼쳐서)

말로만 하지 말고 직접 펼쳐 보자. 축을 `n̂`, 점 `v` 를 축에 **수직인** 성분만 가진다고 하자(축에 평행한 성분은 회전 불변이라 따로). `q = (cos(θ/2), sin(θ/2) n̂)`, `c = cos(θ/2)`, `s = sin(θ/2)` 로 두고 `v' = q v q⁻¹` 을 해밀턴 곱으로 전개하면, `n̂·v = 0`, `n̂×(n̂×v) = -v` (수직이므로) 같은 항등식을 쓸 때:

```
v' = (c² - s²) v + 2 c s (n̂ × v)
   = cos θ · v + sin θ · (n̂ × v)
```

마지막 줄에서 배각 공식 `c² - s² = cos θ`, `2 c s = sin θ` 를 썼다. 그런데 `cos θ · v + sin θ · (n̂×v)` 는 정확히 **로드리게스 회전 공식(Rodrigues)** 에서 축에 수직인 성분이 `θ` 만큼 도는 식이다. 즉:

> 사원수에 `θ/2` 를 넣었더니, 샌드위치가 두 번 작용하면서 배각 공식이 발동해 **결과는 정확히 `θ` 회전**. 반각은 "두 번 작용 × 배각 공식"의 산물이다.

이 유도가 사원수 전체를 떠받친다. 한 번쯤 손으로 끝까지 전개해 보면 평생 안 잊는다.

## 5. SLERP — 구면 위 최단 호의 등속 보간

### 5.1 왜 NLERP/선형보간으로는 부족한가

자세 `q₀` 에서 `q₁` 로 부드럽게 보간하고 싶다. 두 단위 사원수를 그냥 선형보간하면 `(1-t)q₀ + t q₁` 은 **S³ 를 벗어나** 구 내부를 가로지른다(현, chord). 다시 정규화하면 구로 끌어올릴 수 있고(이게 NLERP — [06](06-identities-approximations.md) 참조), 경로 자체는 맞지만 **각속도가 일정하지 않다** — 중간에서 빨라졌다 양 끝에서 느려진다.

SLERP(Spherical Linear intERPolation)는 **S³ 위의 측지선(great-circle arc, 큰 원의 호)을 따라 등각속도로** 보간한다. 두 자세를 잇는 최단 회전을, 일정한 각속도로 지나간다.

### 5.2 기하 유도

두 단위 사원수가 이루는 각을 `Ω` 라 하면 `cos Ω = q₀ · q₁` (4D 내적). 우리가 원하는 것은 `q₀` 에서 `q₁` 까지의 호 위에서, `t ∈ [0,1]` 에 따라 호의 길이를 **선형으로** 지나가는 점이다.

2D에서 단위원 위의 두 점을 등각속도로 잇는 것과 똑같은 문제다. 평면 삼각형을 그려 사인 법칙으로 풀면(또는 `q₀, q₁` 으로 생성되는 2차원 평면 안에서 직교 분해하면) 가중치가 떨어진다:

```
                sin((1-t) Ω)        sin(t Ω)
slerp(q₀,q₁;t) = ──────────── q₀ + ────────── q₁
                   sin Ω             sin Ω
```

검산: `t=0` 이면 첫 항 계수 `sinΩ/sinΩ=1`, 둘째 `0` → `q₀`. `t=1` 이면 `q₁`. `Ω → 0` 이면 `sin((1-t)Ω)/sinΩ → (1-t)`, `sin(tΩ)/sinΩ → t` 로 **선형보간으로 수렴** — 그래서 작은 각에서는 NLERP로 대체해도 무방하다(다음 절).

지수형으로 보면 더 우아하다. `q(t) = q₀ (q₀⁻¹ q₁)^t`. 상대 회전 `q₀⁻¹ q₁` 을 축각으로 분해해 `t` 거듭제곱(= 각도에 `t` 곱하기)한 뒤 `q₀` 에 합성. 복소수 보간 `e^(i(1-t)θ₀)e^(itθ₁)` 의 사원수판이다(2절 끝과 연결).

### 5.3 알고리즘 (double-cover 처리 포함)

```
function slerp(q0, q1, t):
    d = dot(q0, q1)                 # cos Ω, 4D 내적

    # --- double cover: 가까운 쪽 반구로 ---
    if d < 0:
        q1 = -q1                    # q1 과 -q1 은 같은 회전(7절)
        d  = -d

    # --- 거의 평행하면 선형보간 폴백 (0/sinΩ 방지) ---
    if d > 0.9995:
        result = q0 + t*(q1 - q0)   # NLERP
        return normalize(result)

    Omega = acos(clamp(d, -1, 1))   # acos 클램프 필수 ([06])
    sinO  = sin(Omega)
    w0 = sin((1 - t)*Omega) / sinO
    w1 = sin(t*Omega)       / sinO
    return w0*q0 + w1*q1            # 이미 단위; 안전상 normalize 가능
```

세 줄짜리 가드가 핵심이다. `d < 0` 분기(double cover), `d > 0.9995` 분기(0 나눗셈 회피 + NLERP 전환), `acos` 의 `clamp` ([06](06-identities-approximations.md)). 이 셋을 빼면 SLERP는 실전에서 NaN과 "먼 길로 도는 회전"을 낸다.

## 6. 이중 덮개 (double cover) — `q` 와 `-q` 는 같은 회전

`S³` 는 회전군 `SO(3)` 을 **2:1 로 덮는다**. 즉 모든 회전에 대해 그것을 나타내는 단위 사원수가 정확히 **둘** 있다: `q` 와 `-q`. 샌드위치 공식이 이를 증명한다:

```
(-q) v (-q)⁻¹ = (-q) v (-q⁻¹) = q v q⁻¹     # 부호가 양쪽에서 상쇄
```

`q` 와 `-q` 가 같은 점 변환을 주므로, **회전으로서는 구별 불가능**하다. 반각이 이 현상의 근원이다: 각을 `θ → θ + 2π` (한 바퀴, 같은 회전) 돌리면 사원수의 인자는 `θ/2 → θ/2 + π` 가 되어 `cos/sin` 의 부호가 뒤집힌다 → `q → -q`. 회전은 `2π` 주기지만 사원수는 `4π` 주기인 것이다.

이게 실무에서 **반드시** 처리해야 하는 곳:

| 상황 | 안 하면 생기는 일 | 처리 |
|---|---|---|
| 보간(SLERP/NLERP) | `q₀·q₁ < 0` 이면 긴 쪽(>180°)으로 돈다 | 내적 음수면 한쪽 부호 반전 |
| 두 자세 비교/거리 | `q` 와 `-q` 를 다르다고 판정 | `min(|q₀-q₁|, |q₀+q₁|)` 또는 `|dot|` |
| 자세 평균/누적 | 부호 튐으로 평균이 망가짐 | 기준 사원수와 같은 반구로 정렬 |
| 네트워크 직렬화 | 같은 자세가 다른 비트 → 결정론 영향 | `w ≥ 0` 정규 형태로 강제 |

허브의 함정 체크리스트(§5, "double-cover 부호")와 [03](03-rotations.md)이 같은 문제를 가리킨다. 한 줄 규칙: **보간·비교 전에 `if dot(q0,q1) < 0: q1 = -q1`**.

## 7. 🎨 인터랙티브 직관 — 무엇을 드래그하며 볼까

이 노드에는 드래그 시각화(viz)가 따라붙는다(허브 인덱스의 🎨 표시). 다음을 눈으로 확인하는 용도다:

- **반각**: 슬라이더로 `θ` 를 키우면 사원수 벡터부 길이가 `sin(θ/2)` 로 자라는 것 — `θ=180°` 에서 스칼라부 `cos90°=0`.
- **double cover**: `q` 와 `-q` 가 **같은** 오브젝트 자세를 만든다는 것 (두 사원수, 한 결과).
- **SLERP vs NLERP**: 두 자세 사이를 보간할 때 SLERP는 등속, NLERP는 중간이 빠른 것을 각속도 곡선으로 비교.
- **긴 쪽 회전**: 부호 처리를 끄면 보간이 180° 넘게 "먼 길로" 도는 것.

수식을 외우는 것보다 이 네 가지를 손으로 만지는 게 직관에 압도적으로 빠르다.

## 8. 실무 (엔진에서의 사원수 기하)

- **저장은 항상 단위 사원수.** 적분으로 누적 오차가 끼므로 매 스텝(또는 주기적) 정규화([03](03-rotations.md), 허브 §5). 정규화는 `q / |q|` 한 번, rsqrt로 저렴([06](06-identities-approximations.md)).
- **샌드위치 대신 행렬 변환.** 벡터 하나만 돌릴 땐 `q v q⁻¹` (약 ~28 mul)가 괜찮지만, **같은 자세로 여러 벡터**를 돌릴 땐 사원수→3x3 행렬로 한 번 변환해 두고 행렬곱(메시 전체)이 더 싸다. 엔진들이 자세는 사원수로 저장하되 렌더/충돌엔 행렬을 넘기는 이유(허브 §4).
- **double cover는 보간·비교·직렬화에서 항상 의식.** §6 표. 결정론이 필요하면 `w ≥ 0` 정규형으로 직렬화([12](../12-determinism-networking.md)).
- **SLERP는 가드 3종 세트와 함께.** 부호 반전, 평행 폴백(NLERP), `acos` 클램프. 키프레임 애니메이션처럼 호출이 잦으면 NLERP가 충분히 좋고 더 싸다 — SLERP의 등속성이 정말 필요한지 따져라([06](06-identities-approximations.md)).
- **`θ/2` 의 라디안성을 잊지 말 것.** 사원수 생성 시 들어가는 각은 라디안의 절반. 도(degree)로 받은 입력은 `deg→rad` 변환 후 `0.5` 를 곱한다. 부호·단위 버그의 단골.
- **각속도 적분과의 연결.** 각속도 `ω` 로부터 자세를 전진시키는 `q̇ = ½ (0, ω) ⊗ q` 는 [03-time-integration](../03-time-integration.md)의 주제. 여기서의 반각이 그 `½` 와 같은 뿌리(`d/dt cos(θ/2)`)임을 알아두면 두 노드가 한 그림으로 묶인다.
