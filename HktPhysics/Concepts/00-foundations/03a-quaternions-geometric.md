## 0. 한 문장 요약

> **사원수 = "단위원(복소수)으로 2D를 돌리던 트릭"을 4차원 단위 초구(S³)로 끌어올린 것**이고, 3D 회전은 그 초구 위의 점을 벡터 양옆에 끼워 곱하는(sandwich) 연산으로 나타난다. 양옆에서 두 번 작용하기 때문에 각이 절반(θ/2)으로 들어가고, 그 때문에 `q`와 `-q`가 같은 회전을 가리킨다(이중 덮개).

아래는 이 한 문장을 한 걸음씩 기하학으로 풀어가는 과정이다.

## 1. 출발점 — 복소수는 2D 회전 그 자체다

사원수를 이해하는 가장 견고한 출발점은 **2D 회전 = 복소수 곱셈**이라는 사실이다. 이걸 몸으로 받아들이면 사원수는 그 자연스러운 확장일 뿐이다.

복소수 `z = a + b i` 를 평면의 점 `(a, b)` 로 본다. 단위 복소수는

```
z = cos(φ) + i sin(φ) = e^(i φ)      // 단위원 위의 점, 각 φ
```

이고, **어떤 점 `p = x + i y` 에 `e^(iφ)` 를 곱하면 정확히 φ 만큼 회전**한다.

```
e^(iφ) · (x + i y) = (x cosφ − y sinφ) + i (x sinφ + y cosφ)
```

괄호 안을 보면 그대로 2D 회전 행렬 `[[cos −sin],[sin cos]]` 다. 핵심 관찰 세 가지:

1. **회전 = 곱셈**: 회전을 "행렬·벡터"가 아니라 "수·수"의 곱으로 한다.
2. **합성 = 곱의 곱**: φ 회전 후 ψ 회전 = `e^(iψ) e^(iφ) = e^(i(φ+ψ))`. 지수가 더해진다.
3. **크기 보존**: `|e^(iφ)| = 1` 이라 길이를 바꾸지 않는다(isometry). 회전은 *단위* 원 위의 점이 담당한다.

> 즉 2D에서 "회전을 담는 그릇"은 **단위원(1차원 구 S¹)** 이고, 그릇에서 점을 꺼내 한 번 곱하면 회전이 끝난다. 사원수는 이 그림을 한 차원 위로 올린 것이다.

## 2. 3D로 올리려는 시도 — 그리고 해밀턴의 도약

자연스러운 질문: "그럼 3D 회전은 *세 개*의 수로 똑같이 곱셈 한 번에 안 되나?"

답은 **안 된다**. 곱셈이 잘 정의되고(결합·역원), 길이를 보존하며, 회전을 닫힌 연산으로 만드는 "곱셈 가능한 수 체계"는 차원이 1, 2, 4, 8 에서만 존재한다(Hurwitz 정리). 3차원에는 그런 곱셈이 없다. 해밀턴(W. R. Hamilton)이 1843년에 10년을 헤매다 깨달은 것이 바로 이것 — **3차원을 포기하고 4차원으로 넘어가야 한다**.

그가 다리 위에서 칼로 새겼다는 관계식:

```
i² = j² = k² = i j k = −1
```

여기서 곱셈표가 따라 나온다 — 그리고 **비가환(non-commutative)** 이다(회전이 비가환이니 당연하다):

```
i j = k,   j k = i,   k i = j
j i = −k,  k j = −i,  i k = −j      // 순서를 바꾸면 부호가 뒤집힌다
```

사원수를 **스칼라부 + 벡터부**로 쓰면 이 곱셈표가 우리가 이미 아는 내적·외적으로 정리된다:

```
q = w + x i + y j + z k = (w, v),   v = (x, y, z)

q1 q2 = ( w1 w2 − v1·v2 ,  w1 v2 + w2 v1 + v1 × v2 )
           └ 내적이 스칼라부 ┘   └─ 외적이 벡터부 ─┘
```

> **기하학적 메시지**: 사원수 곱셈 안에는 우리가 [01-vectors](01-vectors.md) 에서 본 **내적(cos, 정렬)과 외적(sin, 벌어짐·법선)이 한 연산으로 합쳐져** 있다. 비가환성은 외적 `v1×v2 = −v2×v1` 에서 온다 — 회전의 순서 의존성이 여기 박혀 있다.

순수(pure) 사원수 = 스칼라부 0 인 것 `(0, v)`. 우리는 3D 벡터 `v` 를 이 순수 사원수로 "끼워 넣어" 다룬다.

## 3. 단위 사원수 = 4차원 단위 초구 S³ 위의 점

```
|q| = sqrt(w² + x² + y² + z²)
```

`|q| = 1` 인 사원수들의 모임은 4차원 공간의 **단위 초구(unit 3-sphere, S³)** 다. 2D에서 회전을 담던 그릇이 단위원 `S¹` 이었듯, 3D 회전을 담는 그릇은 **`S³`** 이다.

- `S¹`(원): 점 하나를 각 1개로 — 2D 회전(1 DOF).
- `S³`(초구): 점 하나를 각 3개로 — 3D 회전(3 DOF). (`w²+x²+y²+z²=1` 제약이 4개 성분 중 1개를 묶어 자유도 3.)

> 시각화의 핵심 직관: 모든 단위 사원수는 **반지름 1짜리 4D 공 표면 위에 산다**. 적분으로 오차가 쌓여 이 표면을 벗어나면(`|q|≠1`) 다시 `q/|q|` 로 표면에 투영(정규화)하면 된다 — 이것이 행렬 재직교화보다 압도적으로 싼 이유([03-rotations](03-rotations.md)).

## 4. 회전 공식 — 왜 "양옆에서 끼워(sandwich)" 곱하는가

벡터 `p` 를 순수 사원수 `(0, p)` 로 보고, 회전은 다음 **켤레(conjugation) / 샌드위치** 로 정의된다:

```
p' = q (0, p) q⁻¹           // 단위면 q⁻¹ = q* = (w, −v)
```

왜 한쪽 곱(`q p`)이 아니라 양쪽에서 끼우는가? 두 가지 기하학적 이유:

**(1) 순수성을 지키려면.** 한쪽으로만 곱하면 결과의 스칼라부가 일반적으로 0이 아니게 되어 "3D 벡터"의 자격을 잃는다. 샌드위치 `q p q⁻¹` 는 결과가 **항상 순수 사원수(스칼라부 0)로 닫힌다** — 즉 3D 벡터를 3D 벡터로 보낸다. 그리고 `|q p q⁻¹| = |p|` 라 길이를 보존한다(회전의 필수 조건).

**(2) 회전 = 두 반사의 합성이기 때문.** 기하학의 정리: *평면 위 임의의 회전은 두 거울 반사의 합성이고, 두 거울면 사이 각이 θ/2 면 합성 회전각은 θ 다.* 샌드위치 구조의 "왼쪽 `q`"와 "오른쪽 `q⁻¹`"가 바로 이 **두 번의 작용**에 대응한다. 각각이 θ/2 씩 기여해 합이 θ.

이 (2)가 다음 절의 **반각**을 설명한다.

## 5. 반각(half-angle)의 정체 — `q = (cos(θ/2), sin(θ/2) u)`

축 `u`(단위)·각 `θ` 회전의 사원수가 **왜 θ가 아니라 θ/2** 인지를 직접 계산으로 확인하자. 벡터 `p` 를 축에 대해 분해한다:

```
p = p∥ + p⊥        // p∥ = (p·u)u : 축에 평행,  p⊥ : 축에 수직
```

`q = (cos(θ/2), sin(θ/2) u)` 로 샌드위치를 전개하면(곱셈표 사용):

```
평행 성분:  q p∥ q⁻¹ = p∥                                   // 축 방향은 안 돈다 (불변)
수직 성분:  q p⊥ q⁻¹ = cos(θ) p⊥ + sin(θ) (u × p⊥)          // 평면 안에서 θ 회전
```

수직 성분 결과가 정확히 **로드리게스 회전**(평면 내 각 θ 회전: `cosθ` 만큼 제자리 + `sinθ` 만큼 90° 옆)이다. 여기서 핵심:

> `q` 안에는 `θ/2` 가 들어 있는데, **샌드위치가 그것을 두 번 작용**시켜(왼쪽·오른쪽) 결과의 회전각이 정확히 `θ` 가 된다. 반각은 버그가 아니라 *양옆 곱셈 구조의 필연적 산물*이다.

복소수와의 대조가 선명하다:

```
2D (한쪽 곱):    z = e^(i θ)       ← 각 θ 가 통째로
3D (양쪽 곱):    q = e^( (θ/2) u ) ← 각 θ/2,  양옆에서 두 번
```

(맨 오른쪽은 다음 §8 의 지수 사상 표기. `u` 를 순수 사원수로 본 사원수 지수다.)

**실무 최적화 형태** (샌드위치를 전개하면 곱 2회 대신 외적 2회로 더 싸다):

```
t  = 2 (qv × p)
p' = p + qw · t + qv × t          // qv = 벡터부, qw = 스칼라부
```

## 6. 이중 덮개(double cover) — `q` 와 `−q` 는 같은 회전

반각의 직접적 귀결. 회전각을 `θ → θ + 2π`(같은 회전, 한 바퀴 더) 로 바꿔 보자. 사원수에는 `θ/2` 가 들어가므로:

```
θ/2 → θ/2 + π
cos(θ/2+π) = −cos(θ/2),   sin(θ/2+π) = −sin(θ/2)
⟹  q → −q
```

즉 **물리적으로 똑같은 회전**(360° 차이)이 사원수로는 부호가 반대인 `q` 와 `−q` 두 점으로 나타난다. 기하학적으로:

> `S³`(초구)가 회전군 `SO(3)` 를 **2겹으로(2-to-1) 덮는다**. 초구 위의 정반대 두 점 `q`, `−q` 가 같은 3D 회전 하나로 내려온다. 그래서 `S³ → SO(3)` 를 "이중 덮개(double cover)" 라 부른다.

이건 단순한 수학 트리비아가 아니라 **유명한 물리 현상**과 같은 구조다 — 컵을 손바닥에 얹고 팔을 꼬며 360° 돌리면 팔이 꼬인 채로 남지만, **720° 돌리면 원래대로 풀린다**(벨트 트릭 / Dirac's plate trick). 즉 방향(orientation)의 "진짜 한 바퀴"는 720°이고, 360°는 절반일 뿐이다. 사원수의 `q`/`−q` 가 바로 이 절반/온전한 한 바퀴를 구분한다.

**실무 함의 — 부호 정렬**: 두 자세를 보간·비교할 때 `q1·q2 < 0` 이면 한쪽 부호를 뒤집어야(`q2 ← −q2`) "가까운 쪽(짧은 호)"으로 돈다. 안 하면 먼 길로 720°에 가깝게 도는 보간이 나온다([03-rotations](03-rotations.md) 함정).

## 7. SLERP — 초구 위의 측지선(great arc)

두 자세 `q1, q2` 사이를 매끄럽게 잇는다는 건 기하학적으로 **`S³` 위에서 둘을 잇는 최단 호(great-circle arc, 측지선)를 일정한 속도로 따라가는 것**이다. 4D 내적이 둘 사이 각을 준다:

```
cos(Ω) = q1 · q2            // 4D 내적 (w,x,y,z 네 성분)
```

이 호를 등속으로 매개변수화한 것이 **SLERP(Spherical Linear Interpolation)**:

```
slerp(q1, q2, t) = ( sin((1−t)Ω) / sinΩ ) q1 + ( sin(tΩ) / sinΩ ) q2,   t∈[0,1]
```

- **등각속도**: `t` 가 일정하게 늘면 회전각도 일정하게 는다(호를 균등 분할). 카메라/애니메이션이 부드러운 이유.
- **`Ω → 0`(거의 같은 회전)**: `sinΩ → 0` 이라 0/0 위험 → **NLERP**(선형 보간 후 정규화)로 폴백:
  ```
  nlerp(q1, q2, t) = normalize( (1−t) q1 + t q2 )
  ```
  NLERP 는 호의 *현(chord)* 을 따라 직선으로 간 뒤 초구로 투영하는 셈 — **경로(great arc)는 같지만 속도가 불균등**하다(중간이 약간 빠름). 작은 각에선 차이가 무시할 만해 실무 표준 폴백이다.
- **부호 정렬 선행**: §6 대로 `q1·q2 < 0` 이면 `q2 ← −q2` 후 보간(짧은 호 선택).

> 시각화에서 SLERP 슬라이더를 움직이면, 초구를 평면에 투영한 원호 위를 점이 **균등 간격**으로 미끄러지는 걸 볼 수 있다. NLERP 고스트를 켜면 같은 끝점인데 중간 속도가 어긋나는 것을 비교할 수 있다.

## 8. 지수·로그 사상 — 축각과 사원수를 잇는 다리 (보너스)

복소수 `e^(iφ)` 의 사원수 판이 존재한다. 순수 사원수 `θ/2 · u`(축 `u`, 크기 θ/2)의 지수가 단위 사원수다:

```
exp( (0, (θ/2) u) ) = ( cos(θ/2),  sin(θ/2) u ) = q
log( q )            = (0, (θ/2) u)               // 역사상: 축각/2 로 복귀
```

기하학적으로 `log q` 는 초구 위의 점 `q` 를 **단위원소(identity, `(1,0,0,0)`) 에서의 접평면(tangent space)** 으로 펴 놓은 것 — 그 접평면이 바로 "축×각/2", 즉 회전 벡터의 세계다. 이 사상이 각속도 `ω` 로 자세를 적분하는 다리가 된다:

```
q_new = exp( (0, (Δt/2) ω) ) · q            // 정식 자세 적분 (작은 각이면 §6의 dq 근사)
```

(정식 유도·다양한 적분기는 [03-time-integration](../03-time-integration.md), 작은 회전 근사 `dq ≈ (1, 0.5 ω Δt)` 는 [06-identities-approximations](06-identities-approximations.md).)

## 9. 왜 결국 사원수인가 — 행렬·오일러각과의 기하 대조

| 관점 | 회전 행렬(3×3) | 오일러각 | 사원수(S³) |
|---|---|---|---|
| 사는 공간 | 9차원 중 직교 다양체 | 3차원 토러스(주기) | 4차원 단위 초구 |
| 자유도/성분 | 3 DOF를 9 성분으로 (중복 6) | 3/3 (최소지만 특이) | 3 DOF를 4 성분으로 (중복 1) |
| 직교성/단위성 회복 | 재직교화 — 비쌈(그람-슈미트) | — | **정규화 1회 — 매우 쌈** |
| 특이점 | 없음 | **짐벌락**(축 정렬 시 1 DOF 상실) | 없음(초구는 매끄러움) |
| 보간 | 어려움 | 비선형·불량 | **SLERP**(측지선) 자연스러움 |
| 중복의 성격 | 6개 잉여 성분 | 주기·순서 의존 | `q`/`−q` 이중 덮개 1개뿐 |

> 핵심: 사원수는 **"최소에 가까운 표현(4성분)" + "특이점 없는 매끄러운 곡면(S³)" + "값싼 정규화" + "측지선 보간"** 을 동시에 갖춘 유일한 후보다. 오일러각의 짐벌락(다양체 위상 자체의 문제)도, 행렬의 비싼 재직교화도 피한다. 단 하나 치러야 할 값이 `q`/`−q` 부호 정렬뿐이다.

## 10. 함정 (전체 체크리스트는 [00-foundations §5](../00-foundations.md#5-공통-함정--결정론-체크리스트))

- **double-cover 부호**: 보간·비교 전 `q1·q2 < 0` ⟹ `q2 ← −q2`. 안 하면 720°에 가깝게 도는 "먼 길" 보간.
- **반각 혼동**: 축각→사원수 변환에서 `θ` 를 그대로 넣으면 회전이 2배가 된다. 항상 `θ/2`.
- **정규화 누락**: 적분 후 `|q|≠1` → 매 스텝/주기적 `q/|q|` 로 S³ 재투영.
- **`acos` 클램프**: `Ω = acos(q1·q2)` 에서 내적이 반올림으로 `>1` 이면 NaN → `clamp(·,−1,1)`([06](06-identities-approximations.md)).
- **SLERP 0/0**: `Ω≈0` 이면 NLERP 폴백.
