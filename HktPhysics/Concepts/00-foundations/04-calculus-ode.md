# [00.4] 미적분·ODE (Calculus & Ordinary Differential Equations)

> 물리 시뮬레이션은 본질적으로 상미분방정식(ODE)의 수치적 풀이다 — 도함수, 상태공간 표현, 안정성, 테일러 전개라는 네 개념으로 그 프레임을 세운다.
> **상위 허브**: [00-foundations.md](../00-foundations.md) · **상위 지도**: [README.md](../README.md)

---

## 1. 왜 미적분이 물리 엔진의 언어인가

뉴턴 역학은 "지금의 힘이 지금의 가속도를 정하고, 가속도가 시간에 따라 속도를, 속도가 위치를 정한다"라고 말한다. 이 문장에 들어 있는 "에 따라"가 전부 **도함수**다. 가속도는 속도의 시간 도함수, 속도는 위치의 시간 도함수. 그러니 물리법칙은 태생적으로 **미분방정식**의 형태를 띤다.

그런데 컴퓨터는 미분방정식을 해석적으로 풀어 주지 않는다. 대신 시간을 잘게 쪼개(`dt`) 한 스텝씩 상태를 전진시킨다. 이 한 줄이 게임 물리 엔진 전체의 골격이다:

> **물리 시뮬레이션 = ODE의 수치해(numerical solution).** 매 틱마다 "현재 상태와 그 도함수"로부터 "다음 상태"를 추정한다.

이 문서는 그 프레임을 세우는 **개념**만 다룬다. *어떤 적분기*(오일러, semi-implicit, RK4, Verlet)를 쓸지, 그 안정성·심플렉틱성·에너지 보존의 구체적 비교는 [03-time-integration](../03-time-integration.md)의 영역이다. 여기서는 적분기가 발 디딜 땅 — 도함수, 상태공간, 안정성의 의미, 테일러 전개 — 만 깔고 적분기 상세는 [03] 노드로 미룬다.

표기는 허브를 따른다. 시간 미분은 점 표기 `ẋ = dx/dt`, 시간 간격은 `dt`(또는 `h`). 각도는 라디안.

---

## 2. 도함수 — 순간 변화율

도함수의 정의는 극한이다:

```
ẋ(t) = lim   ( x(t + h) - x(t) ) / h
       h→0
```

직관적으로 "아주 짧은 시간 `h` 동안의 변화량 ÷ `h`", 즉 **순간 변화율**이자 그래프의 접선 기울기다. 물리에서 이 한 정의가 전부를 굴린다:

```
v = ẋ        속도 = 위치의 변화율
a = v̇ = ẍ    가속도 = 속도의 변화율 = 위치의 2차 도함수
```

회전도 똑같다. 각속도 `ω` 가 자세의 변화율이고, 자세를 사원수로 표현하면 그 도함수가 `q̇ = ½ (0, ω) ⊗ q` 다([03a](03a-quaternions-geometric.md), [03-time-integration](../03-time-integration.md)). 선형이든 각이든 "변화율"이라는 도함수의 정의 하나로 묶인다.

**수치 미분의 함정.** 위 극한 정의를 그대로 코드로 옮겨 `(x(t+h) - x(t))/h` 를 작은 `h` 로 계산하면 — 분자가 **두 가까운 값의 차(상쇄, cancellation)** 라 정밀도가 폭락하고, `h` 를 줄일수록 오히려 부동소수점 오차가 커진다([05-numerical-floating-point](05-numerical-floating-point.md)). 그래서 물리 엔진은 도함수를 **수치 미분으로 구하지 않는다.** 도함수는 물리법칙(`a = F/m`)이 *닫힌 형태로* 줘 버린다. 컴퓨터가 하는 일은 미분이 아니라 그 반대, **적분**이다.

---

## 3. 적분 — 변화율을 모아 상태를 전진

도함수가 "쪼개기"라면 적분은 "모으기"다. 가속도(변화율)를 알 때 속도를, 속도를 알 때 위치를 복원한다:

```
v(t) = v(0) + ∫₀ᵗ a(τ) dτ
x(t) = x(0) + ∫₀ᵗ v(τ) dτ
```

해석적으로 풀 수 있는 건 교과서 문제뿐이다. 게임은 힘이 매 순간 바뀌고(충돌, 사용자 입력, 제약), 닫힌 적분이 존재하지 않는다. 그래서 적분을 **이산 합산**으로 근사한다. 가장 단순한 형태(전진 오일러):

```
v_{n+1} = v_n + a_n · dt
x_{n+1} = x_n + v_n · dt
```

연속 적분 `∫ a dτ` 를 "`a` 가 한 스텝 동안 일정하다고 보고 `a·dt`"로 근사한 것이다. 이게 바로 가장 단순한 ODE 적분기다 — 그리고 이 근사를 *어떻게 더 잘하느냐*가 [03-time-integration](../03-time-integration.md) 전체의 주제다(여기선 더 들어가지 않는다).

## 4. 상태공간(state space) — 물리계를 1계 ODE로

### 4.1 2계를 1계로 접기

뉴턴 방정식 `ẍ = F(x, ẋ, t)/m` 은 위치의 **2차** 도함수를 포함하는 2계 ODE다. 수치 적분기는 대개 **1계** ODE `ẏ = f(y, t)` 형태를 전제로 설계된다. 둘을 잇는 표준 기법이 **상태공간 표현**: 위치와 속도를 한 벡터로 묶어 **상태(state)** `y` 를 정의한다.

```
y = (x, v)               # 상태 = 위치와 속도를 쌓은 벡터
ẏ = ( ẋ, v̇ ) = ( v, F(x,v,t)/m )
```

오른쪽을 보면 `ẏ` 가 오직 `y`(와 `t`)만으로 결정된다 — 깔끔한 1계 형태 `ẏ = f(y, t)` 다. 2계 문제를, 차원을 2배로 늘린 1계 문제로 **접었다**. 이게 상태공간의 핵심 아이디어다.

### 4.2 왜 이 표현이 강력한가

- **모든 적분기가 통일된다.** 오일러, RK4, semi-implicit 등은 전부 "`ẏ = f(y,t)` 를 받아 `y_{n+1}` 을 내는" 블랙박스로 쓸 수 있다. 위치/속도/자세/각속도를 한 상태 벡터에 다 욱여넣으면 적분기 코드 하나가 전부를 굴린다.
- **다물체로 자연 확장.** N개 강체면 상태는 `y = (x₁,v₁, x₂,v₂, …, q₁,ω₁, …)`. 차원만 커질 뿐 형태는 같다.
- **위상공간(phase space) 직관.** 상태 `(x, v)` 를 한 점으로 보면, 시간에 따라 그 점이 위상공간을 그리는 궤적(trajectory)이 곧 운동이다. 에너지 보존계의 궤적은 닫힌 곡선(예: 진자는 타원), 감쇠계는 안으로 말리는 나선 — 적분기가 이 궤적을 얼마나 충실히 따라가는가가 안정성의 본질이다(5절).

### 4.3 의사코드 — 상태공간 한 스텝

```
# 상태: state = { x, v }   (위치/속도, 벡터)
# 도함수 함수: f(state, t) -> dstate
function derivative(state, t):
    a = force(state.x, state.v, t) / mass     # 물리법칙이 도함수를 준다
    return { dx: state.v, dv: a }             # ẋ = v, v̇ = a

# 한 스텝 전진 (여기선 전진 오일러; 적분기 교체 지점은 [03])
function step(state, t, dt):
    d = derivative(state, t)
    state.x += d.dx * dt
    state.v += d.dv * dt
    return state
```

`derivative` 와 `step` 이 분리된 게 포인트다. `step` 의 내부(전진 오일러)를 RK4나 semi-implicit로 갈아끼우는 것이 [03-time-integration](../03-time-integration.md)에서 하는 일이고, `derivative`(물리법칙)는 그대로 둔다.

## 5. 안정성(stability) — 적분이 폭주하지 않으려면

### 5.1 안정성이란 무엇인가

수치 적분은 매 스텝 오차를 낸다. 문제는 그 오차가 스텝을 거듭하며 **줄어드느냐(안정), 커지느냐(불안정)**다. 불안정하면 속도·위치가 지수적으로 발산해 오브젝트가 화면 밖으로 날아가거나 `Inf/NaN` 이 된다 — 물리 엔진에서 흔한 "폭발(blow-up)".

### 5.2 모델 문제와 안정성 조건

안정성을 정량화하는 표준 도구는 **시험 방정식(test equation)** `ẏ = λ y` (`λ` 는 보통 음의 실수, 감쇠를 모델). 해석해는 `y(t) = y₀ e^(λt)` 로, `λ<0` 이면 0으로 수렴해야 한다. 전진 오일러를 적용하면:

```
y_{n+1} = y_n + dt·λ·y_n = (1 + λ dt) y_n
       ⇒ y_n = (1 + λ dt)ⁿ y₀
```

이 수열이 발산하지 않으려면 **증폭계수**의 크기가 1 이하여야 한다:

```
|1 + λ dt| ≤ 1        ⇒   dt ≤ -2/λ     (λ < 0)
```

즉 **`dt` 가 너무 크면 안정 조건을 깨고 발산**한다. 전진 오일러는 이렇게 `dt` 에 상한이 있는 **조건부 안정(conditionally stable)** 적분기다. 강성(stiff)이 큰 계(`|λ|` 가 큰 강한 스프링·강한 감쇠)일수록 허용 `dt` 가 잔인하게 작아진다 — 이것이 게임에서 단단한 스프링이 작은 `dt` 에서도 터지는 이유다.

### 5.3 게임에 주는 교훈

- **고정 `dt`.** 가변 `dt` 는 안정성 경계를 들쭉날쭉하게 만들어 같은 장면이 프레임률에 따라 터지기도/안 터지기도 한다. 그래서 물리는 보통 **고정 타임스텝 + 누적자(accumulator)** 로 돌린다([03-time-integration](../03-time-integration.md)).
- **음함수(implicit) 적분의 동기.** `dt` 상한이 거슬리면 안정 영역이 훨씬 넓은(무조건 안정, A-stable) 음함수 적분으로 간다 — 대신 매 스텝 방정식을 풀어야 해 비싸다. 이 트레이드오프의 본론도 [03].
- **에너지 관점.** 전진 오일러는 위상공간 궤적이 바깥으로 말려 **에너지를 인공적으로 주입**(발산)하고, 후진 오일러는 안으로 말려 **에너지를 잃는다**(과감쇠). 둘 다 진실이 아니다 — 그래서 게임은 에너지를 평균적으로 보존하는 **심플렉틱(semi-implicit/Verlet)** 적분기를 선호한다([03]에서 상술).

## 6. 테일러 전개 — 모든 적분기의 출처

적분기들이 어디서 나왔는지 한 줄로 답하면 **테일러 전개**다. 한 점 `t` 근방에서 함수를 다항식으로 펼친다:

```
x(t + dt) = x(t) + ẋ(t) dt + ½ ẍ(t) dt² + (1/6) x⃛(t) dt³ + …
```

이 급수를 **어디서 자르느냐**가 적분기의 차수(order)와 정확도를 정한다:

| 자르는 지점 | 결과 | 국소 오차(local error) |
|---|---|---|
| `x + ẋ dt` | 전진 오일러 (1차) | `O(dt²)` |
| `x + ẋ dt + ½ ẍ dt²` | 2차 방법(미드포인트류) | `O(dt³)` |
| 4차항까지 유효 | RK4 (4차) | `O(dt⁵)` |

핵심 직관 셋:

- **국소 오차 vs 누적 오차.** 위 표는 한 스텝(국소) 오차다. 한 단위 시간을 `1/dt` 스텝으로 쪼개므로, 전역 오차는 보통 차수가 하나 낮다(오일러: 국소 `O(dt²)` → 전역 `O(dt)`).
- **차수가 높을수록 `dt` 절반의 보상이 크다.** RK4는 `dt` 를 절반으로 줄이면 오차가 약 1/32(`2⁵`)로 준다. 오일러는 1/2뿐. 정확도 효율이 압도적이라 부드러운 궤적(탄도, 궤도)엔 RK4가 유리하다.
- **차수가 높다고 게임에 항상 좋은 건 아니다.** RK4는 도함수를 스텝당 4번 평가(비용 4배)하고, **심플렉틱하지 않아** 장시간 에너지 보존이 semi-implicit 오일러보다 못할 수 있다. 충돌·제약처럼 `f` 가 불연속인 게임 물리에선 고차의 매끄러움 가정이 깨져 이득이 반감된다. 그래서 많은 게임 엔진이 *저차이지만 심플렉틱한* semi-implicit Euler/Verlet을 택한다 — 이 비교의 본론이 [03-time-integration](../03-time-integration.md)이다.

테일러 전개를 알면 적분기 표를 외울 필요가 없다. "급수를 어디서 자르고, 잘린 항을 어떻게 근사로 채우는가"라는 한 관점에서 전부 파생된다.

## 7. 실무 (개념이 코드에 닿는 곳)

- **도함수는 물리법칙이 준다, 수치 미분 금지.** `a = F/m` 처럼 닫힌 형태로 구하라. `(x(t+h)-x(t))/h` 식 수치 미분은 상쇄로 정밀도가 무너진다([05](05-numerical-floating-point.md)).
- **상태공간으로 통일하라.** 위치·속도·자세·각속도를 한 상태로 묶어 `ẏ = f(y,t)` 형태로 두면 적분기를 한 곳에서 교체할 수 있다(§4.3). 자세 부분은 사원수 도함수 `q̇ = ½ ω ⊗ q`([03a](03a-quaternions-geometric.md)).
- **고정 타임스텝 + 누적자.** 안정성(§5)을 프레임률과 분리하려면 가변 `dt` 를 피하고 고정 `dt` 로 적분, 남는 시간은 누적해 다음 프레임으로 이월([03-time-integration](../03-time-integration.md)).
- **강성계는 `dt` 상한을 의식.** 단단한 스프링/강한 감쇠는 명시적(explicit) 적분의 `dt ≤ -2/λ` 를 쉽게 위반해 폭발한다. 서브스텝을 늘리거나 음함수/소프트 제약으로 옮긴다([05-constraint-solving](../05-constraint-solving.md)).
- **차수 선택은 비용·연속성·심플렉틱성의 절충.** 매끈한 궤도엔 RK4, 충돌·제약 많은 일반 강체엔 semi-implicit Euler/Verlet. 정확도 표(§6)만 보고 RK4를 고르지 말 것 — 상세 근거는 [03].
- **단위 일관성.** `dt` 는 초, 각은 라디안, 토크/관성 단위 정합. 단위 불일치는 안정성 분석을 통째로 무의미하게 만든다(허브 §1).
