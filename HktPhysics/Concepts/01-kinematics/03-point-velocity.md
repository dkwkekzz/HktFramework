# [01.3] 강체 한 점의 속도 (Velocity of a Point on a Rigid Body)

> 강체 위 임의의 점은 자기만의 속도를 갖는다 — 질량중심의 병진 `v_cm` 에 회전 기여 `ω × r` 가 더해진 `v_P = v_cm + ω × r`. 가속도까지 가면 구심항·오일러항이 따라붙는다. 그리고 두 점/두 바디의 *상대 속도* 가 바로 충돌(contact)·조인트(joint) 자코비안의 토대다 — 이 문서는 그 다리를 놓는다.
> **상위 허브**: [01-kinematics.md](../01-kinematics.md) · **상위 지도**: [README.md](../README.md)

---

## 1. 왜 "한 점의 속도"가 필요한가

지금까지 선형 운동([01-kinematics/01](01-linear-motion.md))은 질량중심 `x` 하나의 운동을, 각운동([01-kinematics/02](02-angular-motion.md))은 회전 `ω` 를 따로 다뤘다. 그런데 실제 물리에서 중요한 건 *특정 점* 의 속도다:

- **충돌 접촉점(contact point)** 이 얼마나 빨리 파고드는가 → 충격량(impulse) 계산.
- **조인트 부착점(anchor)** 두 개가 얼마나 벌어지는가 → 구속 위반 속도.
- **바퀴/발/손** 끝점이 지면 대비 얼마나 미끄러지는가 → 마찰·캐릭터 컨트롤.

이 점들은 cm 이 아니다. 강체가 회전하면 cm 에서 멀리 떨어진 점일수록 회전 때문에 더 빠르게 움직인다(돌리는 막대 끝이 손잡이보다 빠른 것). 그래서 "병진 + 회전" 을 합친 *한 점의 속도* 공식이 필요하다. 그리고 이 공식의 상대 버전이 곧 충돌·구속 솔버가 푸는 양이므로, 이 문서는 운동학([01])과 충돌·구속([04](../04-collision-detection.md)·[05](../05-constraint-solving.md))을 잇는 다리다.

---

## 2. 정의 — 강체 속도장(velocity field)

강체는 "모든 점 사이 거리가 불변" 인 물체다. 이 강체 조건 때문에 강체의 속도장은 단 두 양 `(v_cm, ω)` 로 완전히 결정된다 — 점마다 따로 속도를 저장할 필요가 없다.

- `v_cm ∈ R³` : 질량중심의 병진 속도(m/s). 강체 전체가 공유하는 "평행이동" 성분.
- `ω ∈ R³` : 각속도(rad/s). 강체 전체가 공유하는 "회전" 성분.
- `r ∈ R³` : cm 에서 관심 점 `P` 로 향하는 위치 벡터(월드 프레임에서 본, m).

이 세 양으로 강체 위 *어느* 점 `P` 의 속도든 즉시 계산된다. 강체의 12자유도 상태 `(x, q, v, ω)` 중 운동 부분 `(v, ω)` 6개가 무한히 많은 점의 속도를 결정하는 것 — 이게 강체 가정의 힘이다.

---

## 3. 수식 — v = v_cm + ω × r 와 가속도

### 3.1 기본 공식

```
v_P = v_cm + ω × r
```

- `v_cm` : 병진 — 모든 점이 똑같이 받는 평행이동 속도.
- `ω × r` : 회전 기여 — `r` 에 수직이고, 크기 `|ω||r|sinφ`(φ는 ω와 r 사이 각). cm 에서 멀수록(`|r|↑`), 회전축에서 멀수록 빠르다.

직관: `v_cm` 은 강체 전체를 한 덩어리로 미는 성분, `ω × r` 은 그 위에서 cm 을 중심으로 도는 성분. 둘을 벡터로 더하면 점 `P` 의 실제 속도다. `ω × r` 의 외적은 "`r` 을 회전축 둘레로 쓸고 지나가는 접선 방향" 을 가리킨다.

> **유도 한 줄**: `P` 의 월드 위치는 `x_P = x_cm + r`. 시간 미분하면 `v_P = v_cm + ṙ`. 강체라 `r` 의 길이는 불변, 회전만 하므로 `ṙ = ω × r`(회전하는 벡터의 미분, [01-kinematics/04](04-rotation-derivative.md)의 `Ṙ=[ω]×R` 과 같은 뿌리). 따라서 `v_P = v_cm + ω × r`.

### 3.2 가속도 — 구심항과 오일러항

한 번 더 미분하면 점 `P` 의 가속도가 나온다. 곱 미분 때문에 항이 늘어난다:

```
a_P = a_cm + α × r + ω × (ω × r)
            └ 오일러항 ┘ └ 구심(원심)항 ┘
```

- `a_cm` : cm 병진 가속도.
- `α × r` (**오일러항, Euler term**) : 각가속도 `α = ω̇` 때문에 생기는 접선 가속도. 회전이 빨라지거나 느려질 때.
- `ω × (ω × r)` (**구심항, centripetal term**) : 등속 회전이라도(`α=0`) 점이 원을 그리려면 안쪽으로 당겨지는 가속도. 크기 `ω²·r_⊥`, 방향은 회전축 쪽. 이게 원운동의 "원심력" 의 운동학적 뿌리다.

> **유도**: `v_P = v_cm + ω × r` 를 미분. `d/dt(ω × r) = ω̇ × r + ω × ṙ = α × r + ω × (ω × r)`(`ṙ = ω × r` 대입). 구심항이 `ω×(ω×r)` 의 이중 외적으로 나오는 게 핵심.

### 3.3 상대 속도 — 충돌/구속의 핵심 양

두 바디 A·B 가 한 점(또는 각자의 부착점)에서 만난다고 하자. 그 접촉/부착점에서 본 *상대 속도* 가 솔버가 푸는 양이다:

```
v_A^P = v_cmA + ω_A × r_A          # A 의 부착점 속도
v_B^P = v_cmB + ω_B × r_B          # B 의 부착점 속도
v_rel = v_A^P − v_B^P = (v_cmA + ω_A × r_A) − (v_cmB + ω_B × r_B)
```

- **충돌**: `v_rel` 을 접촉 법선 `n` 에 사영한 `v_n = n · v_rel` 이 양수면 파고드는 중(접근). 충격량으로 이걸 0(또는 반발) 으로 만든다([04](../04-collision-detection.md)).
- **마찰**: `v_rel` 의 접선 성분이 미끄럼 속도 → 마찰 충격량.
- **조인트**: 두 부착점 속도 차가 0이 되도록 구속(예: ball joint 는 `v_rel = 0`)([06](../06-joints-articulation.md)).

이 `v_rel` 을 상태 `(v_cmA, ω_A, v_cmB, ω_B)` 에 대한 선형 사상으로 쓰면 그 계수 행렬이 **자코비안 `J`** 다 — 다음 절.

## 4. 알고리즘 — 자코비안의 토대로

### 4.1 v_rel 을 자코비안 형태로

`v_rel` 을 두 바디의 속도 상태 벡터 `u = [v_cmA, ω_A, v_cmB, ω_B]ᵀ`(12×1)의 선형 함수로 정리하면:

```
v_rel = J · u
J = [ I,  −[r_A]× ,  −I,  [r_B]× ]          # (3×12), 점 상대속도 자코비안
                                            # [r]× : r 의 skew-symmetric 행렬
```

여기서 `ω × r = [ω]× r = −[r]× ω` 를 썼다 — 외적을 행렬곱으로 바꾼 것([01-kinematics/02](02-angular-motion.md)·[04](04-rotation-derivative.md)의 skew-symmetric). 한 점 속도 공식 `v=v_cm+ω×r` 이 그대로 자코비안 행 블록의 구조를 결정한다:

- 병진 부분 → `±I` (3×3 단위행렬).
- 회전 부분 → `∓[r]×` (위치 벡터의 skew-symmetric).

**즉 `v=v_cm+ω×r` 을 이해하면 contact/joint 자코비안의 형태를 외울 필요 없이 즉석에서 쓸 수 있다.** 솔버가 푸는 구속식 `J·u + b = 0`(또는 ≥0) 의 `J` 가 바로 이것이다(상세 [05](../05-constraint-solving.md)).

### 4.2 의사코드 — 접촉 법선 속도

```
# 입력: 바디 A,B 상태, 접촉점 worldP, 법선 n
r_A = worldP − x_cmA               # cm→접촉점 (월드)
r_B = worldP − x_cmB
v_A = v_cmA + cross(omega_A, r_A)  # A 부착점 속도
v_B = v_cmB + cross(omega_B, r_B)  # B 부착점 속도
v_rel = v_A − v_B
v_n   = dot(n, v_rel)              # 법선 방향 접근 속도 (>0 이면 파고듦)
v_t   = v_rel − v_n * n            # 접선(미끄럼) 속도 → 마찰
```

이 짧은 코드가 충돌 해결·마찰·조인트 위반 측정의 공통 출발점이다. `r_A`, `r_B` 를 cm 기준으로 잡는 것에 주의 — 바디 transform 원점이 cm 과 다르면 변환이 필요하다([01-kinematics/05](05-frames-transforms.md)).

## 5. 실무 (엔진은 무엇을 쓰는가)

- **솔버는 `(v_cm, ω)` 만 든다.** UE5/Chaos·PhysX·Box2D·Bullet·Jolt 모두 강체의 운동을 `(v, ω)` 로 저장하고, 접촉/조인트 시점에 `v=v_cm+ω×r` 로 부착점 속도를 *그때그때* 계산한다 — 점마다 속도를 저장하지 않는다(강체 속도장).
- **`r` 은 cm 기준, skew-symmetric 으로 외적.** 자코비안 빌드에서 `ω × r` 을 `−[r]× ω` 행렬곱으로 다루는 게 표준. `[r]×` 캐싱이 솔버 반복(iteration) 비용을 줄인다.
- **2D 단순화(Box2D).** 2D 에서는 `ω` 가 스칼라라 `ω × r` 이 `ω·(−r_y, r_x)` 의 90° 회전으로 떨어진다 — 외적이 스칼라×벡터로 단순해져 자코비안도 가벼워진다([01-kinematics/02](02-angular-motion.md)).
- **구심항은 보통 명시적으로 안 더한다.** 게임 솔버는 속도 레벨에서 한 스텝씩 풀기 때문에 `a_P` 의 구심/오일러항을 직접 적분하지 않고, 회전 자세 적분([04](04-rotation-derivative.md))이 그 효과를 자연히 만들어낸다. 구심항은 회전체의 안정성·자이로스코프 효과([02](../02-dynamics.md))를 분석할 때 등장한다.

### 함정 한 줄 요약
- **`r` 을 cm 이 아닌 다른 원점에서 재면** `ω × r` 이 틀려 부착점 속도가 어긋난다. 항상 cm→점.
- **외적 순서/부호**: `ω × r` 이지 `r × ω` 가 아니다(부호 반전). skew-symmetric 변환 시 `[r]× ω = −[ω]× r` 부호 주의.
- **상대 속도 방향 규약**: `v_rel = v_A − v_B` 의 A/B 순서와 법선 `n` 방향 규약을 솔버 전체에서 일관되게(반대로 잡으면 반발 부호가 뒤집힘).
