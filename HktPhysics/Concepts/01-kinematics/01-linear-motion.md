# [01.1] 선형 운동 (Linear Motion)

> 강체의 병진(translation)을 위치 `x`·속도 `v`·가속도 `a` 로 기술하고, 그 미분 관계와 등가속 해석해(SUVAT), 그리고 시뮬레이션에서 쓰는 유한차분(적분 한 스텝)의 골격을 세운다 — 회전을 빼고 *가장 단순한* 운동부터 완벽히 잡는다.
> **상위 허브**: [01-kinematics.md](../01-kinematics.md) · **상위 지도**: [README.md](../README.md)

---

## 1. 왜 선형 운동부터인가

운동학의 모든 어휘는 선형 운동에서 출발한다. 위치를 시간으로 미분하면 속도, 속도를 미분하면 가속도 — 이 두 단계의 미분 사슬이 운동의 *언어* 전체다. 회전([01-kinematics/02](02-angular-motion.md))은 이 언어를 곡선 매니폴드 위로 옮긴 것이고, 한 점 속도([01-kinematics/03](03-point-velocity.md))는 병진과 회전을 합친 것이다. 그래서 선형 운동을 먼저, *완전히* 이해하면 나머지는 "그 위에 비가환성이 얹힌" 변주로 읽힌다.

선형 운동에는 회전 운동학을 괴롭히는 두 골칫거리가 없다:

- **벡터는 가환(commute)하고 그냥 더해진다.** `Δx_1 + Δx_2 = Δx_2 + Δx_1`. 변위는 순서를 바꿔도 같다. 회전은 이게 깨진다(비가환).
- **위치 공간은 평평한 유클리드 공간(R³)** 이다. 곡률이 없으니 "한 스텝 직선으로 전진" 이 곧 정확한 적분 형태에 가깝다. 회전은 곡면(SO(3)) 위라 직선 전진이 곡면을 벗어난다(재정규화 필요).

이 단순함 덕분에 선형 운동은 적분 오차를 *맨눈으로* 분석하기 좋은 실험실이 된다. 등가속 해석해가 닫힌 형태로 존재하므로, 적분기가 그 해를 얼마나 따라가는지 정확히 잴 수 있다.

## 2. 정의 — 위치·속도·가속도

병진 상태는 시간 함수 세 개로 기술한다. 모두 월드 프레임의 3-벡터다(프레임 변환은 [01-kinematics/05](05-frames-transforms.md)).

- **위치(position)** `x(t) ∈ R³` — 기준 원점에서 본 질량중심(center of mass, cm)의 위치. 단위 m.
- **속도(velocity)** `v(t) ∈ R³` — 위치의 시간 도함수. 단위 m/s.
- **가속도(acceleration)** `a(t) ∈ R³` — 속도의 시간 도함수. 단위 m/s².

미분 관계는 두 단계의 사슬이다:

```
v = dx/dt = ẋ
a = dv/dt = v̇ = ẍ
```

여기서 윗점(`ẋ`)은 시간 미분이다. 이 두 식이 운동학의 *전부* 다 — 나머지는 이 관계를 적분하거나(상태 전진), 특정 가속도 모델(`a = F/m`, [02](../02-dynamics.md))을 끼워넣거나, 회전판으로 옮긴 것이다.

> **표기**: 강체의 위치는 관례상 *질량중심* 의 위치를 가리킨다. 강체 위의 다른 한 점 `P` 의 속도는 `v_P = v_cm + ω × r` 로 회전 기여가 붙는다([01-kinematics/03](03-point-velocity.md)). 이 문서에서 `x`, `v`, `a` 는 별말 없으면 cm 의 양이다.

## 3. 수식 — 적분 관계와 SUVAT(등가속 해석해)

### 3.1 적분으로 되돌리기

미분이 `x → v → a` 라면, 적분은 그 역방향이다:

```
v(t) = v_0 + ∫_0^t a(τ) dτ
x(t) = x_0 + ∫_0^t v(τ) dτ
```

일반적으로 `a(t)` 는 시간/상태에 따라 변하므로(`a = F(x,v,t)/m`) 이 적분은 닫힌 형태로 안 풀린다 — 그래서 수치 적분기([03](../03-time-integration.md))가 필요하다. 하지만 **가속도가 상수** 인 특수한 경우엔 닫힌 해가 있고, 이게 적분기 정확도를 재는 기준선이 된다.

### 3.2 등가속 해석해 (SUVAT)

`a = const` 이면 위 적분이 정확히 풀린다. 고전역학의 SUVAT 공식이다(S=변위, U=초기속도, V=종속도, A=가속도, T=시간):

```
v(t)  = v_0 + a·t                      ... (1) 속도
x(t)  = x_0 + v_0·t + ½·a·t²           ... (2) 위치  ← ½at² 항이 핵심
v²    = v_0² + 2·a·(x − x_0)           ... (3) 시간 소거 (1D 스칼라형)
x(t)  = x_0 + ½·(v_0 + v(t))·t         ... (4) 평균속도형 (사다리꼴)
```

식 (2)의 `½·a·t²` 항이 이 문서에서 가장 중요한 디테일이다. 이건 "스텝 동안 속도가 `v_0` 에서 `v_0 + a·t` 로 *변하는* 효과"를 정확히 적분한 결과다. 식 (4)는 같은 것을 평균속도 `(v_0 + v_t)/2` 로 본 형태로, 사다리꼴 적분의 기하학적 의미를 준다.

> **단위 점검**: `a·t²` = (m/s²)·s² = m ✓. `v_0·t` = (m/s)·s = m ✓. 모든 항이 길이 차원으로 맞아야 한다 — 디버깅 시 차원 분석이 부호/계수 실수를 빠르게 잡는다.

## 4. 알고리즘 — 유한차분과 적분 한 스텝

시뮬레이션은 연속 시간을 고정 timestep `dt` 로 잘라 한 스텝씩 전진한다([03](../03-time-integration.md)·결정론은 [12](../12-determinism-networking.md)). 미분 `v = ẋ` 를 유한차분으로 근사하는 방식이 곧 적분기의 정체다.

### 4.1 유한차분 — 미분의 이산 근사

```
forward (전진)  : v_n ≈ (x_{n+1} − x_n) / dt
backward (후진) : v_n ≈ (x_n − x_{n-1}) / dt
central (중심)  : v_n ≈ (x_{n+1} − x_{n-1}) / (2·dt)   ← 2차 정확도
```

중심차분이 가장 정확(O(dt²))하지만 미래/과거 값을 동시에 요구한다. 적분기 설계는 이 차분식을 "다음 상태를 푸는" 방향으로 재배열하는 일이다. 운동학적 바디의 속도 역산([01-kinematics/08](08-kinematic-bodies.md))도 본질적으로 `v = (x_target − x_now)/dt` 라는 전진차분이다.

### 4.2 Explicit (Forward) Euler — 가장 단순, 그래서 함정

```
# 입력: x_n, v_n, a_n, dt
v_{n+1} = v_n + a_n · dt          # (1) 속도 갱신
x_{n+1} = x_n + v_n · dt          # (2) 위치 갱신 — 옛 속도 v_n 사용!
```

여기에 이 문서의 **핵심 함정** 이 있다. 위치 갱신 (2)는 `x += v·dt` 로, "한 스텝 내내 속도가 `v_n` 으로 *일정* "하다고 가정한다. 하지만 실제론 스텝 동안 속도가 `a·dt` 만큼 변한다 — 그 변화분이 위치에 남기는 기여 `½·a·dt²` 가 통째로 빠진다.

등가속 해석해 식 (2)와 비교하면:

```
정확해   : x_{n+1} = x_n + v_n·dt + ½·a·dt²
exp.Euler: x_{n+1} = x_n + v_n·dt              ← ½·a·dt² 누락
오차/스텝 : Δ = ½·a·dt²                          (한 스텝당 위치 국소오차, O(dt²))
```

즉 explicit Euler 는 매 스텝 `½·a·dt²` 만큼 위치를 *덜* 전진시킨다(중력처럼 `a` 방향이 일정하면 오차가 같은 방향으로 누적). `dt` 를 절반으로 줄이면 스텝당 오차는 1/4 로 줄지만 스텝 수는 2배라, 누적(전역) 오차는 O(dt) — explicit Euler 가 1차 정확도인 이유다.

### 4.3 ½at² 를 살리는 길

함정을 피하는 표준적 방법 세 가지(상세는 [03](../03-time-integration.md)):

| 방식 | 위치 갱신 | ½at² 처리 | 비고 |
|---|---|---|---|
| **Symplectic(semi-implicit) Euler** | `x += v_{n+1}·dt` | *새* 속도를 써서 `½at²` 의 절반을 자연히 회수 | 게임 기본. 에너지 거동 안정, 비용 동일 |
| **Velocity Verlet** | `x += v·dt + ½·a·dt²` | 명시적으로 항을 더함 | 2차 정확도, 가속도 1회 저장 |
| **해석적(등가속 구간)** | 식 (2) 직접 | 정확 | `a=const` 보장될 때만(예: 탄도) |

가장 흔한 처방은 **symplectic Euler** 다. 속도를 먼저 갱신하고 *그 갱신된 속도* 로 위치를 밀면(`x += v_{n+1}·dt`), 전개해보면 `x += v_n·dt + a·dt²` 가 되어 누락분의 절반을 공짜로 회수한다. 비용은 explicit Euler 와 똑같은데 안정성·에너지 거동이 훨씬 낫다 — 그래서 게임 물리의 사실상 기본값이다.

## 5. 실무 (엔진은 무엇을 쓰는가)

- **적분기 기본값은 거의 항상 symplectic/semi-implicit Euler.** UE5/Chaos·PhysX·Box2D·Bullet·Jolt 모두 강체 속도를 먼저 갱신하고 그 속도로 위치를 전진시키는 형태가 기본이다(허브 [01-kinematics.md](../01-kinematics.md) §4). 순수 explicit Euler 는 ½at² 누락과 에너지 발산 때문에 프로덕션에서 회피된다.
- **고정 timestep 위에서만.** 가변 dt 는 적분 결과를 프레임레이트에 종속시켜 비결정적으로 만든다. 운동학 적분은 고정 dt 로 돌리고, 화면 부드러움은 render interpolation([01-kinematics/07](07-interpolation.md))으로 분리한다. 결정론 제약은 [12](../12-determinism-networking.md).
- **`x` 는 질량중심 위치.** 엔진의 바디 transform 원점이 cm 과 다르면(메시 피벗 ≠ cm) 내부적으로 cm 기준으로 적분하고 표시 transform 으로 변환한다 — 부착점/렌더 피벗과 cm 의 분리는 [01-kinematics/05](05-frames-transforms.md).
- **차원/단위 라디안 무관.** 선형 운동은 길이·시간 단위만 쓴다(라디안은 회전 쪽). 그래도 중력 상수·스케일(cm vs m)을 엔진 단위와 맞추는 건 부동소수점 정밀도([00](../00-foundations.md))에 직결된다.

### 함정 한 줄 요약
- **explicit Euler 의 ½·a·t² 누락**: `x += v·dt` 만 쓰면 등가속 해석해 대비 스텝당 `½·a·dt²` 위치 오차가 같은 방향으로 누적된다 → symplectic Euler 로 새 속도를 쓰거나 Verlet 으로 항을 명시(상세 [03](../03-time-integration.md)). (허브 §5와 동일)
- **가변 dt**: 적분이 프레임레이트 종속 → 비결정적. 고정 dt 강제.
- **forward 차분의 위상 지연**: `v = (x_{n+1}−x_n)/dt` 는 반 스텝 늦은 속도. 중심차분이 정확하지만 미래값 의존.
