# [01.4a] 회전 미분 근본 유도 (Quaternion Derivative — First Principles)

> `q̇ = ½ ω̂ ⊗ q` 의 그 **½ 은 어디서 오는가**, `[ω]×` 는 왜 skew-symmetric 인가, 그리고 이 둘이 사실 같은 사실의 두 얼굴(so(3) 리 대수)임을 끝까지 판다. [04](04-rotation-derivative.md)가 "공식과 사용법"이라면 이 문서는 "그 공식의 증명서"다.
> **상위 허브**: [../01-kinematics.md](../01-kinematics.md) · **상위 지도**: [../README.md](../README.md)

---

## 1. 왜 이 유도가 필요한가

[04](04-rotation-derivative.md)에서 회전 적분의 두 핵심식을 *받아 썼다*:

```
Ṙ = [ω]× R          (회전행렬 형태)
q̇ = ½ ω̂ ⊗ q         (사원수 형태,  ω̂ = (0, ωx, ωy, ωz) 순허수 사원수)
```

복습용으로 이 둘을 외워 두면 적분기는 짤 수 있다. 하지만 두 가지 질문이 남는다:

1. **왜 ½ 인가?** 선형 운동 `ẋ = v` 에는 계수가 없는데, 회전에는 왜 정확히 ½ 이 붙는가. 1 도 2 도 아닌 ½ 이어야 하는 이유는?
2. **왜 `[ω]×` 는 반대칭(skew-symmetric)인가?** 하필 이 행렬 꼴이 나오는 게 우연인가, 필연인가?

이 두 질문의 답은 **같은 뿌리** — 회전이 이루는 군(group) `SO(3)` 과 그 접공간인 리 대수(Lie algebra) `so(3)` — 에 있다. 답을 알면 적분기·각속도 합성·exp/log 사상([00](../00-foundations.md))이 전부 한 그림으로 묶인다. 이게 "나중의 나"를 위해 한 번은 끝까지 파둘 가치가 있는 이유다.

표기 약속(허브와 동일):
- 사원수 곱은 `⊗`(해밀턴 곱). 단위 사원수만 자세를 표현한다(`|q| = 1`).
- `ω` 는 각속도 벡터(rad/s, 우손계). `ω̂ = (0, ω)` 는 그 순허수(pure) 사원수 매립.
- `[a]×` 는 벡터 `a` 의 외적 행렬: `[a]× b = a × b`.
- 별도 명시 없으면 `ω` 는 **world frame(공간 고정)** 표현.

## 2. 1부: 회전행렬 미분과 `[ω]×` 의 skew-symmetric 유도

먼저 행렬 쪽을 푼다. 여기서 반대칭성이 *공짜로* 떨어진다.

### 2.1 직교 제약을 미분한다

회전행렬은 정의상 직교(orthonormal)이고 행렬식 +1 이다:

```
R(t) Rᵀ(t) = I          (모든 t 에 대해 항상 성립)
```

이 **항등식을 시간으로 미분**한다(곱미분):

```
Ṙ Rᵀ + R Ṙᵀ = 0
Ṙ Rᵀ + (Ṙ Rᵀ)ᵀ = 0           (∵ R Ṙᵀ = (Ṙ Rᵀ)ᵀ)
```

`S := Ṙ Rᵀ` 라 두면:

```
S + Sᵀ = 0     ⟺     Sᵀ = −S
```

즉 `S = Ṙ Rᵀ` 는 **반드시 반대칭 행렬**이다. 이건 가정이 아니라 "회전은 길이를 보존한다(`RᵀR=I`)"는 사실의 직접적 결과다. 길이 보존을 미분하면 반대칭이 튀어나온다 — 이게 skew-symmetric 의 근원이다.

### 2.2 반대칭 3×3 = 외적 = 각속도

3×3 반대칭 행렬은 자유도가 3 뿐이다(대각은 0, 위·아래 삼각이 부호만 다름):

```
        [  0   −c    b ]
  S  =  [  c    0   −a ]
        [ −b    a    0 ]
```

이 행렬을 임의 벡터에 곱하면 정확히 `(a,b,c) × v` 가 된다. 그래서 `S = [ω]×`, `ω = (a,b,c)` 로 **정의**한다. 이렇게 도입된 `ω` 가 바로 각속도다(이 정의가 물리적 각속도와 일치함은 [03](03-point-velocity.md)의 `v_P = ω × r` 에서 확인된다). 따라서:

```
Ṙ Rᵀ = [ω]×        ⟹        Ṙ = [ω]× R
```

**핵심**: `[ω]×` 가 반대칭인 건 디자인 선택이 아니라 `RᵀR=I` 의 미분이 강제하는 결과다. 각속도 3개 성분은 "반대칭 행렬의 3 자유도"와 정확히 일치한다 — 이게 3D 회전이 3 자유도인 이유와도 맞물린다.

### 2.3 body frame 버전 (왼쪽 vs 오른쪽)

위는 `Ṙ Rᵀ`(왼쪽 곱) — world frame 각속도 `ω_world`. 같은 미분을 `Rᵀ Ṙ`(오른쪽 곱)로 묶으면 body frame 각속도 `ω_body` 가 나오고, 둘은 `ω_world = R ω_body` 로 연결된다:

```
Ṙ = [ω_world]× R = R [ω_body]×
```

적분기를 짤 때 "어느 프레임의 ω 인가"를 섞으면 조용히 틀린다([04](04-rotation-derivative.md)·[05](05-frames-transforms.md)). 부호·프레임은 항상 명시.

## 3. 2부: 사원수 미분과 ½ 의 정체

이제 본론. ½ 은 두 방법으로 유도할 수 있고, 둘 다 보면 ½ 의 정체가 또렷해진다.

### 3.1 방법 A — 극한에서: "무한소 회전 사원수"

시각 `t` 의 자세가 `q(t)`, 짧은 시간 `Δt` 뒤 자세가 `q(t+Δt)` 라 하자. 그 사이의 **증분 회전**(world frame 기준 왼쪽 곱)을 `Δq` 라 하면:

```
q(t+Δt) = Δq ⊗ q(t)
```

`Δt` 동안 회전한 각은 `Δθ = ω Δt`(축 `n = ω/|ω|`, 각 `|ω|Δt`). 축–각을 사원수로 올리는 표준식([00](../00-foundations.md)):

```
Δq = ( cos(Δθ/2),  sin(Δθ/2) · n )
```

**바로 여기에 ½ 의 씨앗이 있다.** 축–각 → 사원수 변환은 각을 *절반* 으로 나눠 넣는다(`θ/2`). 이건 사원수가 회전을 `q v q⁻¹` 로 **양쪽에서 두 번** 작용시키기 때문이다 — 한 번이 아니라 두 번 작용하므로, 같은 물리 회전을 내려면 각 사원수는 절반 각만 담아야 한다. 이 "양쪽 샌드위치 → 절반 각" 구조가 ½ 의 물리적 근원이다.

이제 `Δt → 0` 극한을 취한다. 작은 각이므로 1차 테일러:

```
cos(Δθ/2) ≈ 1
sin(Δθ/2) ≈ Δθ/2 = (|ω|Δt)/2
```

대입:

```
Δq ≈ ( 1,  (Δt/2) · |ω| n )
   = ( 1,  (Δt/2) · ω )
   = 1 + ½ (0, ω) Δt
   = 1 + ½ ω̂ Δt              (ω̂ = (0, ω) 순허수 사원수)
```

이걸 증분식에 넣고 도함수 정의로 정리:

```
q(t+Δt) − q(t) = (Δq − 1) ⊗ q(t) = ½ ω̂ Δt ⊗ q(t)

q̇ = lim_{Δt→0} [q(t+Δt) − q(t)] / Δt = ½ ω̂ ⊗ q
```

**ω̂ ⊗ q** — world frame 각속도이므로 **왼쪽 곱**. body frame 각속도라면 `q̇ = ½ q ⊗ ω̂_body`(오른쪽 곱). 행렬판의 왼/오른쪽 구분과 정확히 대응한다.

### 3.2 방법 B — 노름 보존에서: "½ 은 노름을 묶는 계수"

`|q|=1` 을 항상 유지해야 한다. `|q|² = q ⊗ q* = 1`(여기 `q*` 는 켤레)를 미분:

```
q̇ ⊗ q* + q ⊗ q̇* = 0
```

`q̇ = Ω ⊗ q`(미지의 사원수 `Ω` 가 왼쪽에 곱해진다고 가정) 형태를 넣어보자. 그러면 `q̇* = q* ⊗ Ω*`:

```
Ω ⊗ q ⊗ q* + q ⊗ q* ⊗ Ω* = 0
Ω ⊗ 1 + 1 ⊗ Ω* = 0          (∵ q ⊗ q* = 1)
Ω + Ω* = 0
```

`Ω + Ω* = 0` 은 **Ω 가 순허수(실수부 0)** 여야 함을 뜻한다 — 즉 `Ω = (0, w)` 꼴. 노름 보존이 "곱해지는 각속도 사원수는 허수여야 한다"를 강제한다(2.1 의 skew-symmetric 과 정확히 같은 논리의 사원수 버전이다!). 남은 건 `w` 와 `ω` 의 관계인데, 이는 회전행렬 미분과 일치시키면 `w = ½ ω` 로 고정된다. 결국:

```
q̇ = ½ ω̂ ⊗ q
```

방법 B 가 주는 통찰: **½ 은 "노름을 1 로 묶는 정규화 계수"** 이기도 하다. `q ⊗ q* = 1` 에서 `q` 가 좌우에 한 번씩, 두 번 나타나므로 미분에서 인자 2 가 생기고, 그걸 상쇄하는 게 ½ 이다. 방법 A 의 "샌드위치 → 절반 각"과 방법 B 의 "노름의 두 번 등장"은 **같은 2 의 두 표현**이다.

### 3.3 검산: 사원수식 ↔ 행렬식이 같은가

두 식이 정말 같은 회전을 적분하는지 확인. `R(q)` 를 `q` 로 표현하고 양변을 미분하면(사원수 → 회전행렬 야코비), `q̇ = ½ ω̂ ⊗ q` 를 넣었을 때 정확히 `Ṙ = [ω]× R` 이 떨어진다. 즉:

```
q̇ = ½ ω̂ ⊗ q     ⟺     Ṙ = [ω]× R
```

두 식은 **동일 사실의 두 좌표 표현**이다. 하나에 ½ 이 있고 하나에 없는 건 모순이 아니라, 사원수가 회전을 "반각으로" 담는 데서 오는 표현 차이다(반각 → 미분에서 ½).

## 4. 3부: 통합 — so(3) 리 대수와 지수 사상

위 두 유도를 한 그림으로 묶는 언어가 리 군/리 대수다. 이게 "왜 둘이 같은가"의 최종 답이다.

### 4.1 군과 접공간

- **SO(3)**: 3D 회전들이 이루는 군(곱 = 합성, 항등원 = 항등회전, 역원 = 역회전). 곡면(매끄러운 다양체)이다.
- **so(3)**: SO(3) 의 항등원에서의 **접공간(tangent space)** = "무한소 회전들의 공간". 이게 바로 **반대칭 3×3 행렬들의 집합**이다. 2.1 에서 `S=ṘRᵀ` 가 반대칭으로 나온 건, `Ṙ` 가 접벡터이고 접공간이 so(3) 이기 때문이다.
- **단위 사원수 군 SU(2) / S³**: SO(3) 를 **이중덮개(double cover)** 한다 — `q` 와 `−q` 가 같은 회전. 이 "이중"이 보간 부호 함정([07](07-interpolation.md))과 반각의 뿌리다.

### 4.2 지수 사상: 대수 → 군

각속도(접벡터) `ω` 를 유한 회전(군 원소)으로 올리는 다리가 **지수 사상**:

```
행렬:   R = exp([ω]× t) = I + sinθ·[n]× + (1−cosθ)·[n]×²      (로드리게스, θ=|ω|t, n=ω/|ω|)
사원수: q = exp(½ ω̂ t) = ( cos(θ/2), sin(θ/2)·n )
```

**여기서 ½ 이 마지막으로 정체를 드러낸다.** 미분식 `q̇ = ½ ω̂ ⊗ q` 를 (ω 상수 가정에서) 적분한 닫힌 해가 `q = exp(½ ω̂ t) ⊗ q₀` 다. 행렬 쪽은 `exp([ω]× t)` — 지수의 인자에 ½ 이 없다. 그 차이가 사원수 닫힌해의 각이 `θ/2` 로 나오는 이유이고, 곧 3.1 의 "반각 사원수"와 같은 말이다. 정리하면:

```
미분식의 ½  ⟺  지수의 ½  ⟺  사원수가 반각을 담음  ⟺  S³ 가 SO(3) 를 2:1 로 덮음
```

네 문장이 전부 같은 사실이다. ½ 은 우연한 계수가 아니라 **"사원수가 회전을 두 번 작용(반각으로)한다 = 이중덮개"** 라는 구조 상수다.

### 4.3 한 줄 정리

```
RᵀR = I  를 미분 → [ω]× 는 skew-symmetric (so(3))      ─┐
                                                         ├─ 같은 사실
|q| = 1  를 미분 → 곱해지는 각속도는 순허수, 계수 ½  ─┘

½ 의 근원 = SU(2)/S³ → SO(3) 이중덮개 = 반각 = 양쪽 샌드위치 q v q⁻¹
```

## 5. 알고리즘 / 의사코드

근본 유도를 코드로 옮기면 [04](04-rotation-derivative.md)의 적분 스텝과 같아진다. 여기서는 "½ 과 정규화가 코드 어디에 박히는가"만 강조.

```text
# 1) 1차(naive) 적분 — q̇ = ½ ω̂ ⊗ q 를 그대로 오일러 전진
function integrate_quat_firstorder(q, omega_world, dt):
    omega_hat = quat(0, omega_world.x, omega_world.y, omega_world.z)   # 순허수
    qdot      = 0.5 * (omega_hat ⊗ q)                                  # ← 그 ½
    q_next    = q + qdot * dt
    return normalize(q_next)        # ← |q|=1 드리프트 보정(노름 보존 유도의 실무판). 필수.

# 2) 지수 사상(exact, ω 일정 가정에서 닫힌해) — 큰 dt·큰 ω 에 정확
function integrate_quat_exp(q, omega_world, dt):
    theta = norm(omega_world) * dt
    if theta < EPS:                 # 0/0 폴백: sin(θ/2)/θ → 1/2 의 극한
        dq = quat(1, 0.5*dt*omega_world.x, 0.5*dt*omega_world.y, 0.5*dt*omega_world.z)
        dq = normalize(dq)
    else:
        axis = omega_world / norm(omega_world)
        s    = sin(theta * 0.5)     # ← 반각. 여기에 ½ 이 산다
        dq   = quat(cos(theta*0.5), axis.x*s, axis.y*s, axis.z*s)
    return normalize(dq ⊗ q)        # world frame → 왼쪽 곱
```

두 함수의 차이: 1번은 ½ 이 *미분 계수* 로, 2번은 ½ 이 *반각 sin/cos 인자* 로 나타난다 — 4.2 의 "미분의 ½ ⟺ 지수의 ½" 가 코드에 그대로 보인다. 적분기 선택·정규화 정책의 실무 논의는 [03-time-integration.md](../03-time-integration.md)와 [04](04-rotation-derivative.md)에 위임.

## 6. 실무 트레이드오프

- **유도를 외우지 말고 둘 중 하나만 기억하라**: "RᵀR=I 미분 → skew" 와 "축–각의 반각이 ½ 의 출처". 이 두 닻만 있으면 부호·프레임·계수를 매번 재유도할 수 있다.
- **부호/프레임 일관성이 ½ 보다 자주 버그를 낸다**: `½ ω̂ ⊗ q`(world, 왼쪽) vs `½ q ⊗ ω̂`(body, 오른쪽)을 섞으면 회전이 거꾸로/엉뚱하게 돈다. 코드 주석에 프레임을 박아라([05](05-frames-transforms.md)).
- **정규화는 노름 보존 유도의 실무 그림자**: 3.2 가 "이론상 노름은 보존된다"고 말하지만, 1차 적분은 부동소수점·1차 절단오차로 노름이 드리프트한다 → 매 스텝 `normalize`([04](04-rotation-derivative.md)·허브 §5). 지수 사상 적분은 구조상 노름이 보존되지만 그래도 안전상 정규화한다.
- **결정론**: 지수 사상의 `sin/cos`, slerp 의 `acos` 는 플랫폼별 결과가 갈려 lockstep 결정론을 깬다(허브 §5, [12](../12-determinism-networking.md)). 이중덮개(±q)도 보간 전 부호 정규화로 다뤄야 한다([07](07-interpolation.md)).
- **엔진 현실**: UE5/Chaos·PhysX·Bullet·Jolt 모두 자세는 사원수, 적분은 `q̇=½ωq`(또는 exponential map) — 허브 §4 표와 일치. 즉 이 ½ 은 모든 주요 엔진의 회전 적분 한복판에 박혀 있다.
