# [01·2.4a] 회전 미분의 근본 유도 — 왜 ½ 인가, 왜 반대칭인가 (Rotation Derivatives, from the ground up)

> `q̇ = ½ ω q` 의 **½ 은 어디서 오는가**, `Ṙ = [ω]×R` 의 **[ω]× 가 왜 반대칭(skew-symmetric)이어야 하는가**를 근본부터 유도한다. 두 식이 결국 같은 회전을 두 언어로 적은 것임을 보인다.
> **상위 노드**: [04-rotation-derivative.md](04-rotation-derivative.md) · [01-kinematics.md](../01-kinematics.md) · **상위 지도**: [README.md](../README.md) · **의존**: [00-foundations.md](../00-foundations.md) (사원수 반각·곱셈표)

---

## 0. 한 문장 요약

> 자세의 시간 변화는 "현재 자세에 **무한소 회전을 합성**" 하는 것이다. 무한소 회전을 사원수로 쓰면 반각 때문에 각속도가 `½` 로 들어가고(`q̇ = ½ ω̂ ⊗ q`), 행렬로 쓰면 "길이를 보존하는 무한소 변환" 이라는 조건이 곧 **반대칭 행렬** `[ω]×` 다(`Ṙ = [ω]× R`). 둘은 같은 사실의 두 표기다.

---

## 1. 공통 출발점 — 자세 미분은 "무한소 회전의 합성"

자세 `A(t)`(행렬이든 사원수든)를 작은 시간 `dt` 뒤로 보내는 것은, 현재 자세에 **그 사이에 일어난 작은 추가 회전 `δ`** 를 합성하는 것이다:

```
A(t+dt) = δ(dt) ⊗ A(t)      (world frame: 작은 회전을 왼쪽에서 합성)
```

여기서 `δ(dt)` 는 축 `n̂`, 각 `θ = |ω| dt` 인 *아주 작은* 회전이다. 미분의 정의에 넣으면:

```
Ȧ = lim_{dt→0} ( A(t+dt) − A(t) ) / dt = lim ( δ(dt) − I ) / dt · A(t)
```

즉 **자세 미분의 모든 내용은 "`δ(dt)` 가 `I`(항등) 에서 얼마나, 어느 방향으로 벗어나는가"** 에 들어 있다. 이 한 줄을 사원수와 행렬 두 언어로 풀면 각각 `½` 과 반대칭이 떨어진다.

---

## 2. 사원수에서 — 왜 ½ 인가

작은 회전 `δ` 를 사원수로 쓴다. 축 `n̂`, 각 `θ = |ω| dt` 인 사원수는 반각으로:

```
Δq = ( cos(θ/2), n̂ sin(θ/2) )
```

`dt → 0` 이면 `θ = |ω|dt → 0` 이므로 작은 각 근사:

```
cos(θ/2) ≈ 1
sin(θ/2) ≈ θ/2 = |ω| dt / 2
⟹  Δq ≈ ( 1,  ½ ω dt )           // 벡터부 = ½ ω dt
```

여기서 `½` 이 **반각(θ/2) 에서 직접 떨어진다**. 이를 §1 의 합성에 넣으면:

```
q(t+dt) = Δq ⊗ q(t) ≈ (1, ½ ω dt) ⊗ q(t)
        = q(t) + ½ (0, ω) ⊗ q(t) · dt          // (1,0) 이 항등, 나머지가 증분
⟹  q̇ = lim ( q(t+dt) − q(t) ) / dt = ½ ω̂ ⊗ q
```

> **핵심 직관**: 사원수는 회전을 **반각으로 인코딩**한다(`q = (cos(θ/2), n̂ sin(θ/2))`, 그 이유는 [00-foundations.md](../00-foundations.md) 의 사원수 심화 — 양옆 sandwich 곱이 각을 두 번 작용시키기 때문). 미분은 이 반각을 그대로 물려받아 각속도를 절반으로 들여보낸다. `½` 은 버그가 아니라 반각 구조의 필연적 산물이다.

body frame 으로 보면 작은 회전이 *오른쪽* 에서 합성되어(`q(t+dt) = q(t) ⊗ Δq_body`) 곱 순서만 뒤집힌다:

```
q̇ = ½ q ⊗ ω̂_body
```

---

## 3. 행렬에서 — 왜 [ω]× 가 반대칭인가

자세를 회전행렬 `R(t)` 로 쓰면, 회전행렬은 항상 직교 제약 `RᵀR = I` 를 만족한다(길이·각도 보존). 이 제약 자체를 시간 미분한다:

```
d/dt (RᵀR) = Ṙᵀ R + Rᵀ Ṙ = 0
⟹ Rᵀ Ṙ = −(Rᵀ Ṙ)ᵀ
```

마지막 줄이 정확히 "**`Rᵀ Ṙ` 는 자신의 음의 전치와 같다**" = **반대칭(skew-symmetric) 행렬** 의 정의다. 즉 *직교성을 유지하라* 는 제약 하나가 자세 미분을 반대칭 행렬로 강제한다.

반대칭 3×3 행렬은 자유 성분이 3개뿐이고, 그 3개를 벡터 `ω` 로 모으면 cross-product 연산자가 된다:

```
Rᵀ Ṙ = [ω_body]×        (body frame 각속도)
⟹ Ṙ = R [ω_body]×       또는 world frame 으로  Ṙ = [ω]× R,   ω = R ω_body

         ⎡  0   −ωz   ωy ⎤
[ω]× =   ⎢  ωz    0  −ωx ⎥      ([ω]× a = ω × a)
         ⎣ −ωy   ωx    0 ⎦
```

> **핵심 직관**: "길이를 안 바꾸는 무한소 선형변환" 은 반드시 반대칭이다. §1 의 `(δ − I)/dt` 가 행렬 언어로는 `[ω]×` — 회전군 `SO(3)` 의 접공간(리 대수 `so(3)`)이 바로 반대칭 행렬들의 공간이고, 그 원소가 각속도 벡터와 1:1 대응한다.

---

## 4. 둘은 같은 사실이다 — 두 언어의 대조

| 관점 | 사원수 `q` | 회전행렬 `R` |
|---|---|---|
| 무한소 회전 | `Δq ≈ (1, ½ ω dt)` | `δR ≈ I + [ω]× dt` |
| 미분식 | `q̇ = ½ ω̂ ⊗ q` | `Ṙ = [ω]× R` |
| 각속도가 들어가는 방식 | 반각 → 계수 `½` | 직교 제약 → 반대칭 `[ω]×` |
| 사는 접공간(리 대수) | 순허수 사원수 `(0, ½ω)` | 반대칭 행렬 `so(3)` |
| 정확 한 스텝 | `q_{n+1} = exp(½ω̂ dt) ⊗ q_n` | `R_{n+1} = exp([ω]× dt) R_n` |

두 `exp` 모두 같은 무한소 생성자(각속도)를 유한 회전으로 지수화한 것 — 사원수 지수는 `(cos(|ω|dt/2), …)`, 행렬 지수는 로드리게스 공식이다([00-foundations.md](../00-foundations.md)). 같은 회전을 사원수는 반각(`½`)으로, 행렬은 반대칭으로 적었을 뿐 내용은 하나다.

> 그래서 실무가 사원수를 택하는 이유가 선명하다: 같은 정보를 4성분 + 값싼 정규화로 담고(행렬은 9성분 + 비싼 재직교화), 반각 미분식이 컴팩트하다. 적분기·정규화 정책의 실제 선택은 [03-time-integration.md](../03-time-integration.md).

**관련 함정** (전체 체크리스트는 [01-kinematics §5](../01-kinematics.md#5-함정--결정론-체크리스트)):
- **반각 혼동**: 무한소 회전 사원수에 `θ` 를 그대로 넣으면 회전이 2배. 항상 `θ/2`, 미분 계수는 `½`.
- **곱 순서(world vs body)**: world 좌측 곱 `ω̂ ⊗ q` / `[ω]× R`, body 우측 곱 `q ⊗ ω̂` / `R [ω_body]×`. `ω = R ω_body` 로 환산.
- **정규화/재직교화**: 1차 적분은 단위성/직교성을 깬다 → 사원수 `q/|q|`, 행렬 Gram–Schmidt.
