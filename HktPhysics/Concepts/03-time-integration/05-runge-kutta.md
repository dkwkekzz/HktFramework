# [03·2.5] Runge–Kutta (RK2 · RK4) — 정확하지만 게임엔 과한 도구

> 한 스텝 안에서 도함수를 여러 곳에서 평가해 평균내는 고차 explicit 적분기. 매끄러운 힘장엔 압도적, 접촉 강체 메인 루프엔 부적합.
> **상위 노드**: [03-time-integration.md](../03-time-integration.md) · **상위 지도**: [README.md](../README.md) · **의존**: [02-taxonomy](02-taxonomy.md)

---

Runge–Kutta 는 한 스텝 안에서 도함수 `f` 를 *여러 곳에서 평가*해 가중평균내는 고차 explicit 적분기다. 평가를 더 살수록 정확도가 올라간다.

## RK2 (midpoint) — 2차

```
k1 = f(y_n, t_n)
k2 = f(y_n + ½·dt·k1,  t_n + ½·dt)      ← 중간점에서 기울기 재평가
y_{n+1} = y_n + dt·k2
```

현재 기울기로 중간점까지 가보고, *그 중간점의 기울기*로 한 스텝 전체를 민다. 한 번의 보정으로 1차 → 2차 정확도.

## RK4 — 4차

국소 O(dt⁵), 전역 O(dt⁴). 함수평가 4회/스텝.

```
k1 = f(y_n,            t_n)
k2 = f(y_n + ½dt·k1,   t_n + ½dt)
k3 = f(y_n + ½dt·k2,   t_n + ½dt)
k4 = f(y_n + dt·k3,    t_n + dt)
y_{n+1} = y_n + (dt/6)·(k1 + 2k2 + 2k3 + k4)
```

네 곳(시작·중간 2회·끝)의 기울기를 심슨 가중치(1:2:2:1)로 평균낸다. **부드러운(smooth) 힘에서 압도적 정확도**를 주어 궤도역학·과학 시뮬에서 표준이다.

## 게임에서 잘 안 쓰는 이유

1. **비싸다** — 스텝당 힘 평가 4회. 강체에선 충돌/구속이 끼어 평가 비용이 크다.
2. **symplectic 이 아니다** — RK4 는 고차 정확도지만 보존계에서 *천천히 에너지가 새는*(보통 감쇠) 비-사교 적분기다(보존되는 shadow Hamiltonian 이 없다 → [03a-symplectic-energy](03a-symplectic-energy.md)). 장시간 게임 루프에선 정확도보다 *장기 안정성*이 중요하므로 손해.
3. **불연속에 취약** — RK 의 중간 평가는 "이 스텝 안에서 힘이 매끄럽다"를 가정한다. 충돌·접촉처럼 힘이 불연속이면 중간점 평가가 오히려 오차를 키운다(충돌 검출은 스텝 경계에서만 일어나므로 스텝 내부의 중간 기울기는 가짜다).
4. **결정론·솔버 통합 부담** — 속도 기반 impulse 솔버([05-constraint-solving.md](../05-constraint-solving.md))와 끼워 맞추기 까다롭다.

> 정리: RK4 는 "충돌 없는 매끄러운 힘장(예: 우주선 궤도, 일부 카메라/스프링 보간)"에선 합리적이지만, **접촉 강체 메인 루프엔 부적합**하다. 게임이 정확도 높은 RK4 대신 1차 symplectic Euler 를 쓰는 역설은 "장기 안정성 > 단기 정확도"라는 게임 특유의 요구에서 나온다.
