# [02·2.7] 에너지 — 보존 vs 소산 (Energy: Conservation vs Dissipation)

> 운동방정식과 별개로, 에너지는 시뮬레이션의 정확성·안정성을 *검증*하는 강력한 잣대다. 운동·위치 에너지, 일–에너지 정리, 그리고 총에너지의 증감이 적분기 품질을 진단하는 디버깅 신호가 되는 이유.
> **상위 노드**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md) · **의존**: [01-newton-laws](01-newton-laws.md), [04-inertia-tensor](04-inertia-tensor.md)

---

운동방정식([06-newton-euler](06-newton-euler.md))이 "어떻게 움직이는가"를 풀어준다면, 에너지는 "그 풀이가 믿을 만한가"를 검증한다. 직접 운동을 만들진 않지만 시뮬레이션 품질의 잣대로 쓰인다.

```
운동에너지 (kinetic):   KE = ½·m·|v|²  +  ½·ωᵀ·I·ω     (병진 + 회전)
위치에너지 (potential):  PE_grav = m·g·h,   PE_spring = ½·k·x²
일–에너지 정리:          W = ∫ F·dx = ΔKE
역학적 에너지 보존:       마찰·항력 등 소산력이 없으면 KE + PE = const
```

운동에너지의 회전항 `½·ωᵀ·I·ω` 에 관성텐서가 들어간다 — 주축에서는 `½(I1ω1² + I2ω2² + I3ω3²)` 로 단순해진다([04-inertia-tensor](04-inertia-tensor.md)).

## 보존력 vs 소산력

- **보존(conservative)력**: 중력·이상 스프링. 경로 무관, 위치에너지로 표현 가능. 일을 가해도 위치에너지로 저장됐다 돌아온다.
- **소산(dissipative)력**: 마찰·항력·비탄성 충돌. 에너지를 열로 빼앗아 시스템을 감쇠시킨다 — 되돌릴 수 없다([01-newton-laws](01-newton-laws.md)의 drag/friction).

## 에너지는 적분기의 청진기다

게임에서 에너지는 *디버깅 신호*로 매우 유용하다. 외력·마찰이 없는 폐쇄계인데 총에너지가:

- **늘면** → 적분기가 에너지를 주입하고 있다 (explicit Euler 의 발산). 시뮬레이션이 점점 격렬해지다 터진다.
- **빠르게 줄면** → 과도한 수치 감쇠 (과한 implicit/PBD). 물체가 끈적하게 죽는다.

따라서 총에너지의 드리프트를 모니터링하면 적분기 선택의 적부를 정량적으로 판단할 수 있다 — 적분기 선택과 직결된다([03-time-integration](../03-time-integration.md)). 심플렉틱 적분기가 장기 에너지 드리프트가 작다는 사실([08-lagrangian §심플렉틱](08-lagrangian.md), [03])이 이 잣대로 드러난다.
