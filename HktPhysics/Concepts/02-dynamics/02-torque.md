# [02·2.2] 토크와 외적의 물리 (Torque, τ = r × F)

> 힘이 *회전을 만드는 능력*. 작용점 위치 `r`(무게중심 기준)과 힘 `F` 의 외적이 토크다. 외적이 왜 회전을 기술하는가, 그리고 오프센터 힘이 왜 회전과 병진을 동시에 일으키는가.
> **상위 노드**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md) · **의존**: [00-foundations.md](../00-foundations.md) (외적), [01-newton-laws](01-newton-laws.md)

---

선형 운동이 "힘 → 가속도"라면, 회전 운동은 "토크 → 각가속도"다. 그 둘을 잇는 다리가 외적이다.

## 토크 (torque)

힘이 회전을 만드는 능력. 작용점의 위치벡터(무게중심 기준) `r` 과 힘 `F` 의 외적:

```
τ = r × F
```

외적의 기하학([00-foundations/01-vectors](../00-foundations/01-vectors.md))을 그대로 물리로 읽으면:

- **크기** `|τ| = |r||F| sin θ` — 힘이 `r` 에 수직일 때 최대, 평행하면 0. 문을 경첩 쪽에서 밀면(평행) 안 열리고, 손잡이를 직각으로 밀면(수직) 가장 잘 열린다. `sin θ` 가 바로 "지렛대 팔(lever arm)"의 효율이다.
- **방향** — `r` 과 `F` 가 만드는 평면의 법선(오른손 법칙). 이 방향이 곧 *회전축*이다. 토크 벡터가 가리키는 축 둘레로 물체가 돌려는 경향을 갖는다.

즉 토크는 단순한 스칼라 "돌리는 힘"이 아니라 **축까지 담은 벡터**다. 3D에서 회전이 축을 갖는 양인 이상, 그것을 만드는 원인도 벡터여야 한다.

## 토크 = 각운동량의 변화율

선형 운동량의 변화율이 힘이듯(`F = dp/dt`), 각운동량의 변화율이 토크다:

```
τ = dL / dt
```

이 대응이 선형↔회전의 평행 구조 전체를 떠받친다 (→ [03-momentum-impulse](03-momentum-impulse.md), [06-newton-euler](06-newton-euler.md)).

| 선형 | 회전 |
|---|---|
| 힘 `F` | 토크 `τ = r × F` |
| 질량 `m` | 관성텐서 `I` |
| 운동량 `p = m·v` | 각운동량 `L = I·ω` |
| `F = dp/dt` | `τ = dL/dt` |
| 충격량 `J = Δp` | 각충격량 `r × J = ΔL` |

## 오프센터 힘 — 병진과 회전의 동시 발생

강체에 걸린 힘 하나는 두 가지를 동시에 한다:

- 무게중심을 **병진** 가속시킨다 — *어디에* 걸리든 합력은 그대로 `F = m·a_cm` ([06-newton-euler](06-newton-euler.md)).
- 무게중심에서 벗어난 작용점(`r ≠ 0`)이면 **회전** 토크 `τ = r × F` 를 만든다.

그래서 충격량이 접촉점(CoM 밖)에 걸리면 속도뿐 아니라 각속도도 바뀐다:

```
Δv = J · invMass          (병진)
Δω = invI · (r × J)        (회전; r = CoM → 접촉점)
```

이 한 쌍이 충돌 응답에서 "맞은 위치에 따라 물체가 스핀을 먹는" 현상의 전부다 (→ [05-constraint-solving](../05-constraint-solving.md)).

## 2D에서의 토크

2D 물리에서 외적은 스칼라로 축약된다([00-foundations/01-vectors](../00-foundations/01-vectors.md)):

```
τ = cross2(r, F) = rx·Fy − ry·Fx     // z 성분만 남은 부호 있는 스칼라
```

회전축이 항상 화면 수직(z)이라 토크도 각속도도 단일 스칼라로 충분하다. Box2D 의 회전 동역학이 단순한 근본 이유다([02-dynamics §4](../02-dynamics.md#4-실무-엔진은-무엇을-쓰는가)).
