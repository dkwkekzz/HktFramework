# [02.2] 토크와 외적의 물리 (Torque & the Cross Product)

> 힘이 무게중심을 비껴 걸리면 물체는 돌기 시작한다. 그 "회전을 일으키는 힘"이 토크 `τ = r × F` 다. 외적이 왜 등장하는지(지렛대 팔·면적), 토크가 각운동량의 시간 변화율 `τ = dL/dt` 라는 회전판 뉴턴 2법칙, 그리고 가장 중요한 함정 — `r` 은 반드시 **무게중심(CoM) 기준** 위치여야 한다 — 을 정리한다.
> **상위 허브**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md)

---

## 1. 왜 필요한가 — 힘만으로는 회전을 설명 못 한다

[02.1]에서 `a = invMass·F` 로 **병진(translation)** 을 풀었다. 하지만 같은 힘이라도 **어디에** 걸리느냐에 따라 결과가 다르다:

- 문을 경첩 근처에서 밀면 잘 안 열린다. 손잡이(경첩에서 먼 곳)에서 밀면 쉽게 열린다.
- 같은 힘인데 결과가 다른 이유는, 회전 효과가 **힘의 크기 × 회전축으로부터의 거리** 에 비례하기 때문이다.

힘이 무게중심(center of mass, CoM)을 정확히 통과하면 **순수 병진**만 생긴다. CoM을 비껴가면(off-center) 병진 + **회전**이 함께 생긴다. 이 회전 성분을 만드는 양이 토크다. 동역학이 6자유도(병진 3 + 회전 3)를 모두 다루려면 토크가 반드시 필요하다.

---

## 2. 정의 — 토크는 외적이다

물체의 CoM을 기준으로, 힘이 걸리는 점의 위치 벡터를 `r`, 힘을 `F`라 하면 토크는:

```
τ = r × F
```

`×`는 벡터 외적(cross product, [00-foundations] 참조). 외적의 세 성질이 토크의 물리를 그대로 인코딩한다:

1. **크기** — `|τ| = |r|·|F|·sin θ` (`θ`는 `r`과 `F` 사이 각). `|r|·sin θ` 가 바로 **지렛대 팔(lever arm, moment arm)** — 회전축에서 힘의 작용선까지의 수직 거리다. 힘이 `r`과 평행이면(θ=0) 토크는 0 — 막대를 길이 방향으로 당기면 돌지 않는다.
2. **방향** — `τ`는 `r`과 `F` 둘 다에 수직, 즉 **회전축 방향**(오른손 법칙). 토크 벡터가 가리키는 축을 중심으로 물체가 돈다.
3. **부호/회전 방향** — 오른손 법칙이 회전의 방향(시계/반시계)을 정한다. 좌표계 손잡이(handedness)와 일관되게 유지해야 한다.

### 지렛대 직관

```
        F
        ↑
        |
  o─────●  ← 힘 작용점
  |     |
  | r   |  지렛대 팔 = |r|·sinθ  (여기선 θ=90° → 팔 = |r|)
  |     |
 CoM
```

`r`을 늘리면(작용점을 CoM에서 멀리) 같은 힘으로 더 큰 토크. 이것이 렌치 손잡이가 긴 이유, 문 손잡이가 경첩 반대편에 있는 이유다.

---

## 3. 수식 — 회전판 뉴턴 제2법칙

병진에서 `F = dp/dt` 였듯, 회전에는 그 정확한 짝이 있다:

```
τ = dL/dt              (L = 각운동량 = I·ω, [02.3]/[02.4])
```

각운동량 `L = I·ω` 를 전개하면(관성텐서 `I`가 회전으로 변할 수 있으므로):

```
τ = I·α + ω × (I·ω)
        └────┬────┘
        자이로스코픽 항 (gyroscopic / Euler term)
```

- `I·α` 는 친숙한 `F = m·a` 의 회전 짝 — 토크가 각가속도를 만든다.
- `ω × (I·ω)` 는 회전 특유의 항으로, 빠르게 자전하는 물체에서 세차(precession)를 일으킨다. 이 전체 식이 **Newton–Euler 방정식**의 회전부이며 [02.6]에서 본격적으로 다룬다. 대부분 엔진은 빠른 자전이 드물어 이 항을 옵션/off로 둔다([02.6]).

각가속도를 직접 구할 때는 역관성텐서를 쓴다:

```
α = invI · ( τ − ω × (I·ω) )      (자이로 항 포함 시)
α = invI · τ                       (자이로 항 무시 시, 흔한 근사)
```

`invI = I⁻¹` 는 [02.1]의 `invMass` 와 같은 동기 — 곱셈으로 솔버를 가속하고, 정적 물체는 `invI = 0` 으로 회전 불가를 표현한다.

---

## 4. 알고리즘 — 오프센터 힘을 힘 + 토크로 분해

엔진에서 "한 점 `p`에 힘 `F`를 가한다"는 연산은 병진과 회전 **둘 다**에 기여한다. CoM 위치를 `x_com` 이라 하면:

```
applyForceAtPoint(body, F, p):
    body.forceAccum  += F                       # 병진: 점 위치 무관, 힘 그대로
    r = p − body.x_com                           # CoM 기준 상대 위치  ★핵심★
    body.torqueAccum += cross(r, F)              # 회전: τ = r × F
```

**중요한 비대칭**: 힘은 작용점과 무관하게 병진에 똑같이 기여하지만(`forceAccum += F`), 토크는 **CoM 기준 `r`** 에 의존한다. 그래서 같은 힘이라도 작용점에 따라 회전 결과가 달라진다.

CoM을 정확히 지나는 힘(`r ∥ F` 또는 `r = 0`)을 가하면 `cross(r, F) = 0` — 순수 병진. 중력이 보통 그렇다(CoM에 작용한다고 모델링하므로 토크 0).

한 스텝의 회전부 전체 흐름:

```
# 1) 토크 누적 (applyForceAtPoint, 충격량의 회전부 등에서)
body.torqueAccum = Σ cross(r_i, F_i)

# 2) world 관성텐서 갱신 (회전했으므로!)  — [02.4]
I_world    = R · I_body · Rᵀ
invI_world = R · invI_body · Rᵀ

# 3) 각가속도
α = invI_world · ( torqueAccum − ω × (I_world·ω) )   # 자이로 항 옵션

# 4) [03] 적분기로 ω, q 갱신
```

> 2단계를 빼먹으면(body 텐서를 world 에서 그대로 쓰면) 회전 중인 물체의 토크 응답이 틀어진다 — [02.4]의 핵심 함정이다.

## 5. 실무 트레이드오프 — `r` 은 반드시 CoM 기준

> **이 문서에서 가장 중요한 함정.**

`τ = r × F` 의 `r` 은 **무게중심에서 작용점까지의 벡터**여야 한다. 다른 기준점을 쓰면 회전이 물리적으로 틀린다.

### 왜 CoM인가

자유 강체는 외력 하에서 **CoM을 중심으로 회전**한다(병진은 CoM의 운동, 회전은 CoM 둘레의 운동으로 깔끔히 분리됨 — 이 분리가 Newton–Euler 정식화의 토대). 토크를 CoM이 아닌 점 기준으로 재면, 병진과 회전이 섞여 운동방정식이 더는 단순한 `I·α = τ` 형태가 아니게 된다.

### 흔한 실수: 모델 피벗을 CoM으로 착각

| 기준점 | `r = p − ?` | 결과 |
|---|---|---|
| **CoM** (정답) | `p − x_com` | 물리적으로 정확한 회전 |
| 모델 원점/피벗 | `p − x_pivot` | 피벗≠CoM이면 회전 어긋남 |
| 월드 원점 | `p − 0` | 완전히 틀림 |

아티스트가 만든 메시의 **피벗(pivot)** 은 보통 발밑이나 모델 중심 같은 편의 위치이지, 질량 분포의 무게중심이 아니다. 비대칭 물체(예: 한쪽이 무거운 망치)는 피벗과 CoM이 크게 다르다. CoM은 콜라이더 모양에서 자동 산출하는 게 표준이다([02.5]).

```
# 틀린 코드 — 모델 피벗 기준
r = p − body.transform.position      # ✗ position 이 CoM 이 아닐 수 있음

# 옳은 코드 — CoM 기준
r = p − body.worldCenterOfMass       # ✓
```

### 단위·부호 점검

- 토크 단위: `N·m`(힘×거리). 외적 결과 벡터의 각 성분이 해당 축 둘레 토크.
- 외적은 **반대칭** — `r × F = −(F × r)`. 인자 순서를 바꾸면 부호가 뒤집혀 회전 방향이 반대가 된다. `cross(r, F)` 순서를 엔진 전체에서 일관되게.
- 좌표계 손잡이(왼손/오른손)와 외적 정의가 일관해야 회전 방향이 맞다([00]/[01]).
