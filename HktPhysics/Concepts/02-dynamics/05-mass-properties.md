# [02·2.5] 무게중심과 합성 강체의 질량 속성 (Mass & Center of Mass)

> 강체 동역학이 모두 **무게중심(center of mass)** 을 원점으로 삼는 이유, CoM 의 정의, 그리고 여러 부품을 한 강체로 합칠 때의 질량 속성(질량·CoM·관성) 계산 절차.
> **상위 노드**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md) · **의존**: [04-inertia-tensor](04-inertia-tensor.md) (평행축 정리)

---

강체 동역학은 모두 **무게중심(center of mass, CoM)** 을 원점으로 삼는다. 이유는 두 가지 — Newton 식이 깨끗하게 `F = m·a_cm` 가 되고, 회전이 CoM 둘레로 깔끔히 분리되기 때문이다([06-newton-euler](06-newton-euler.md)). CoM 이 아닌 점을 기준 삼으면 병진과 회전이 교차항으로 얽혀 운동방정식이 지저분해진다.

## 무게중심의 정의

```
무게중심:  r_cm = (Σ mᵢ·rᵢ) / (Σ mᵢ)          (이산)
           r_cm = (∫ r·ρ dV) / (∫ ρ dV)         (연속)
```

질량으로 가중한 위치의 평균이다. 이 정의의 직접적 귀결 하나가 평행축 정리를 떠받친다: **CoM 기준 위치의 질량가중합은 0** (`Σ mᵢ(rᵢ − r_cm) = 0`). 이 "0이 되는 교차항"이 평행축 정리가 CoM 출발일 때만 성립하는 근거다(→ [04a 심화 §4](04a-inertia-tensor-geometric.md)).

## 합성 강체의 질량 속성 계산

합성체(여러 모양/부품)의 질량 속성 계산 절차 — 엔진이 콜라이더 묶음에서 강체를 만들 때 그대로 한다:

```
1. 각 부품의 질량 mᵢ, 무게중심 cᵢ, 본체 관성 Iᵢ(cᵢ 기준) 계산
2. 전체 질량 M = Σ mᵢ,  전체 무게중심 C = (Σ mᵢ·cᵢ)/M
3. 각 Iᵢ 를 평행축 정리로 C 기준으로 이동 → 모두 합산 → I_composite
4. (선택) I_composite 를 대각화하여 주축·주관성으로 저장, invI 캐시
```

핵심은 3단계 — 각 부품의 관성은 *자기 CoM 기준*으로 계산돼 있으므로, 전체 CoM `C` 로 평행축 이동([04-inertia-tensor](04-inertia-tensor.md))시킨 뒤에야 더할 수 있다. 서로 다른 기준의 텐서를 그냥 더하면 틀린다.

## 메시에서 자동 산출 — Mirtich 알고리즘

볼록 메시의 정확한 질량 속성은 부피 적분을 삼각형/사면체로 분해해 푼다(**Mirtich 1996** 알고리즘이 표준). 엔진들이 콜라이더에서 자동으로 질량/CoM/관성을 산출할 때 이 계열을 쓴다 — 수동 입력은 오버라이드용이다([02-dynamics §4](../02-dynamics.md#4-실무-엔진은-무엇을-쓰는가)).

**관련 함정** (전체 체크리스트는 [02-dynamics §5](../02-dynamics.md#5-함정--결정론-체크리스트)):
- **CoM 이 원점이 아닌 좌표에서 토크 계산**: `τ = r × F` 의 `r` 은 반드시 무게중심 기준 위치여야 한다. 모델 피벗을 CoM 으로 착각하면 회전이 어긋난다([02-torque](02-torque.md)).
- **자동 산출 질량 속성의 함정**: 콜라이더에서 산출한 관성이 물리적으로 무효(삼각부등식 위반)면 적분이 폭발한다. 비정상적으로 얇은/큰 모양은 클램프하거나 검증할 것.
