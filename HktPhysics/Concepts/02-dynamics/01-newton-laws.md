# [02·2.1] 뉴턴의 운동 법칙과 힘 (Newton's Laws & Forces)

> 모든 강체 동역학의 출발점 — 질점(point mass)의 세 법칙, `a = F/m`, 그리고 엔진이 역질량(invMass)을 저장하는 이유. 한 프레임에 누적되는 외력(중력·스프링·항력)의 카탈로그.
> **상위 노드**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md) · **의존**: [00-foundations.md](../00-foundations.md)

---

모든 강체 동역학은 **질점(point mass)** 의 뉴턴 법칙에서 출발한다. 강체는 결국 무수한 질점의 묶음이고, 6DOF 운동방정식([06-newton-euler](06-newton-euler.md))은 이 세 법칙을 강체로 확장한 것일 뿐이다.

## 세 법칙

```
제1법칙 (관성): 합력이 0 이면 속도는 불변 (정지 또는 등속).   ΣF = 0  ⇒  v = const
제2법칙 (가속): 합력 = 질량 × 가속도.                          ΣF = m·a = dp/dt
제3법칙 (반작용): 작용에는 크기 같고 방향 반대인 반작용.        F_AB = −F_BA
```

게임 엔진에서 실제로 코드가 푸는 형태는 제2법칙을 가속도에 대해 정리한 것이다:

```
a = F / m            (= ΣF · invMass)
```

## 왜 역질량(inverse mass)을 저장하는가

엔진은 거의 항상 `m` 대신 **역질량(inverse mass) invMass = 1/m** 을 저장한다. 이유는 두 가지다.

- 적분 루프에서 매번 나눗셈 대신 곱셈(`a = F * invMass`)을 쓴다. 나눗셈은 곱셈보다 훨씬 비싸고, 솔버는 이 연산을 매 반복마다 수만 번 한다.
- **고정체(static/immovable)** 를 `invMass = 0` 으로 깔끔히 표현한다 — 무한 질량이면 어떤 힘에도 가속도가 0. 충돌 솔버에서 "벽은 안 밀린다"가 분기(if) 없이 자동으로 성립한다.

## 제3법칙 = 솔버의 불변량

제3법칙은 충돌 솔버의 근본 불변량이다. 두 물체에 충격량을 줄 때 한쪽에 `+J`, 다른 쪽에 `−J` 를 줘야 **운동량 보존**과 결정론이 동시에 보장된다 (→ [03-momentum-impulse](03-momentum-impulse.md), [05-constraint-solving](../05-constraint-solving.md)).

## 힘의 종류 — 한 프레임에 누적되는 외력

한 프레임에서 강체의 `F_accum` 에 더해지는 대표적 힘들:

```
중력 (gravity):     F_g = m·g            (g ≈ (0,0,−9.81), 질량 비례 → 모두 같은 가속도)
스프링 (Hooke):     F_s = −k·x − c·v      (k=강성, c=감쇠계수; 음부호=복원/저항)
선형 항력 (drag):   F_d = −b·v            (저속, Stokes)
2차 항력 (drag):    F_d = −½·ρ·Cd·A·|v|·v  (고속, 공기/물; |v|·v 로 방향 보존)
부력 (buoyancy):    F_b = ρ_fluid·V·(−g)  (잠긴 부피 V; → [10] 부력/공력)
쿨롱 마찰 (friction): |F_f| ≤ μ·|N|        (정지마찰 μ_s, 운동마찰 μ_k; → [05] 접촉 모델)
```

- **중력**은 질량에 비례하므로 가속도(`g`)는 질량과 무관하다 — 엔진은 보통 힘이 아니라 가속도로 직접 적용한다(`v += g·dt`). 무거운 공과 가벼운 공이 같은 속도로 떨어지는 이유가 여기에 코드로 박혀 있다.
- **스프링/항력**은 속도에 의존(`v` 항)하므로 explicit 적분에서 큰 `k`/`b` 는 발산한다 — 강성 스프링은 implicit 적분([03-time-integration](../03-time-integration.md)) 또는 구속([05-constraint-solving](../05-constraint-solving.md))으로 옮기는 게 정석.
- **마찰**은 부등식 구속이라 단순 외력이 아니라 솔버 내부에서 다룬다([05] Coulomb cone).

- **강성 스프링/항력을 외력으로**: 큰 `k`/`b` 를 explicit 외력으로 적분하면 발산. implicit([03]) 또는 구속([05])으로 옮긴다.
