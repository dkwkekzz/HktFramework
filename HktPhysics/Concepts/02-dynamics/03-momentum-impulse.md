# [02·2.3] 운동량과 충격량 (Momentum & Impulse)

> 운동량 `p = m·v`(선형)과 `L = I·ω`(각). 힘을 시간으로 적분한 **충격량**이 곧 운동량 변화 — 이것이 현대 엔진의 충격량 기반(impulse-based) 솔버의 심장이다. 충돌을 "힘"이 아니라 "순간 속도 점프"로 보는 관점.
> **상위 노드**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md) · **의존**: [01-newton-laws](01-newton-laws.md), [02-torque](02-torque.md)

---

## 선형 운동량 (linear momentum)

```
p = m·v
```

제2법칙의 본래 형태는 `F = dp/dt` 다. 질량이 일정하면 `F = m·a` 로 환원되지만, 운동량 형태가 더 근본적이다 — 충돌은 "순간적인 큰 힘"이라 가속도로 다루기 곤란하기 때문이다. 벽에 부딪히는 0.001초 동안의 힘을 직접 적분하려 들면 dt 가 터무니없이 작아야 한다.

## 충격량 (impulse) — 충격량–운동량 정리

힘을 시간으로 적분한 양이 충격량이며, 이는 운동량의 변화와 같다(**충격량–운동량 정리**):

```
J = ∫ F dt = Δp = m·Δv
  ⇒  Δv = J / m = J · invMass
```

이것이 게임 물리에서 **충격량 기반(impulse-based) 솔버**([05-constraint-solving](../05-constraint-solving.md))의 심장이다. 충돌은 dt 동안의 힘 적분으로 보지 않고, "순간적으로 속도를 `J·invMass` 만큼 바꾸는 사건"으로 처리한다.

이 관점이 표준이 된 이유:
- 침투를 막는 페널티 힘(penalty force, 침투 깊이에 비례하는 스프링)보다 **안정적**이다 — 페널티는 강성 스프링이라 발산하기 쉽다([01-newton-laws](01-newton-laws.md)).
- **restitution(반발)·friction(마찰)** 을 속도 레벨에서 직접 다룰 수 있다.

## 각운동량과 각충격량

회전 쪽 대응물:

```
각운동량:   L = I·ω                  (선형 p = m·v 의 회전판)
각충격량:   r × J = ΔL = I·Δω
  ⇒  Δω = invI · (r × J)
```

여기서 `I` 가 스칼라가 아니라 **3×3 관성텐서**라는 점이 회전을 어렵게 만든다 — `L` 과 `ω` 가 일반적으로 평행하지 않다([04-inertia-tensor](04-inertia-tensor.md)). 접촉점이 무게중심 밖일 때 충격량 `J` 가 회전을 일으키는 식이 `Δω = invI·(r×J)` 다([02-torque](02-torque.md)).

## 운동량 보존과 결정론

닫힌계(외력 없음)에서 총운동량은 보존된다. 충돌 솔버가 한쪽에 `+J`, 다른 쪽에 `−J` 를 주는 제3법칙 쌍([01-newton-laws](01-newton-laws.md))이 이 보존을 코드 차원에서 강제한다. 보존은 정확성의 검증 잣대일 뿐 아니라, 누적 순서가 같으면 **결정론**의 토대가 된다([12-determinism-networking](../12-determinism-networking.md)).
