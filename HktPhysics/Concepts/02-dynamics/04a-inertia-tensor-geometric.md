# [02.4a] 관성텐서 기하학적 심화 (Inertia Tensor — Geometric Deep Dive)

> 질량이 스칼라인데 왜 관성은 3×3 텐서여야 하는가 — `L = I·ω` 에서 `L`이 `ω`와 평행하지 않다는 한 가지 사실에서 주축(principal axes)·고유분해·평행축 정리·world 변환 `R·I·Rᵀ`까지 전부가 따라 나온다. 본 문서는 [02-dynamics/04](04-inertia-tensor.md)의 공식들을 "왜 그 모양인가"의 기하로 다시 푼다.
> **상위 허브**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md)

---

## 1. 왜 관성은 텐서인가 — 질량의 비대칭

선형 운동에서 질량 `m`은 스칼라다. 어느 방향으로 밀든 같은 `m`이 저항한다 — `p = m·v`, `F = m·a`. 방향과 무관하게 단 하나의 수가 "밀기 어려움"을 다 설명한다.

회전은 다르다. 같은 토크를 줘도 **어느 축으로 돌리느냐**에 따라 물체가 도는 정도가 달라진다. 긴 막대를 길이축으로 굴리는 건 쉽지만, 그 막대를 가운데에서 빙빙(길이축에 수직으로) 돌리는 건 훨씬 힘들다. 즉 "돌리기 어려움"은 단일 수가 아니라 **방향의 함수**다. 방향마다 다른 값을 주면서 선형성(`I·(aω₁+bω₂) = a·I·ω₁ + b·I·ω₂`)을 만족하는 객체 — 그것이 바로 2계 텐서, 구체적으로 3×3 대칭 행렬이다.

관성텐서의 성분 정의(부피 적분, 밀도 ρ)는 [04](04-inertia-tensor.md)에 있다. 부호 규약까지 명시하면:

```
I = ∫ ρ · ( |r|²·E − r·rᵀ ) dV       (E = 3×3 단위행렬, r = CoM 기준 위치)

       [ ∫ρ(y²+z²)   −∫ρ·xy     −∫ρ·xz   ]
   =   [ −∫ρ·xy      ∫ρ(z²+x²)  −∫ρ·yz   ]
       [ −∫ρ·xz      −∫ρ·yz     ∫ρ(x²+y²)]
```

대각 성분 `Ixx, Iyy, Izz`는 **관성모멘트**(moment of inertia, 항상 ≥ 0), 비대각 성분은 **곱 관성**(product of inertia). 위 정의에서 곱 관성은 `−∫ρ·xy` 처럼 **음의 부호**를 달고 들어간다 — 이 부호 관례가 자료마다 갈리는 함정의 근원이다(§7). 본 시리즈는 일관되게 위 `|r|²E − r·rᵀ` 형태(곱 관성에 마이너스)를 채택한다.

## 2. 핵심 직관 — `L`은 `ω`와 평행하지 않다 (`L ∦ ω`)

선형에서 `p = m·v`는 항상 `v`와 같은 방향이다 (`m`이 스칼라니까). 회전의 각운동량은 그렇지 않다:

```
L = I · ω
```

`I`가 텐서이므로 `L`은 일반적으로 `ω`와 **다른 방향**을 가리킨다. 물체가 어떤 축 `ω`를 중심으로 돌고 있어도, 그 회전이 만들어내는 각운동량 `L`이 그 축과 어긋나 있을 수 있다는 뜻이다.

**왜 어긋나는가 (기하):** 각운동량은 모든 질량 조각의 `r × (ω × r)`의 합이다. CoM에서 멀고 회전축에서 비대칭하게 분포한 질량은 `ω`와 다른 방향으로 "쏠린" 기여를 만든다. 질량 분포가 회전축에 대해 대칭이면 그 쏠림이 상쇄되어 `L ∥ ω`가 되지만, 비대칭이면 남는다.

**이것이 세차(precession)의 씨앗이다.** `L`은 외부 토크가 없으면 (공간에 대해) 보존되는데, `ω`가 `L`과 어긋나 있으면 물체는 `L`을 고정한 채 `ω`가 빙빙 도는 운동을 한다 — 던진 스마트폰이 한 축으로 안 돌고 비틀거리는 현상(테니스 라켓 정리), 자이로의 세차. 자유 회전체의 운동방정식과 자이로 항 `ω×(I·ω)`은 [06](06-newton-euler.md)에서 다룬다.

**언제 `L ∥ ω` 인가:** `ω`가 `I`의 **고유벡터**일 때다. 즉 `I·ω = λ·ω`. 이 특별한 축들이 주축(§3)이고, 그 축으로 돌릴 때만 회전이 "깨끗"하다.

## 3. 고유분해 — 주축 (Principal Axes)

`I`는 실수 대칭 행렬이다. 스펙트럼 정리(spectral theorem)에 의해 항상 **직교하는 고유벡터 3개**로 대각화된다:

```
I = R_p · diag(I₁, I₂, I₃) · R_pᵀ
```

- `I₁, I₂, I₃` (≥ 0): 주관성모멘트(principal moments). `I`의 고유값.
- `R_p`: 고유벡터를 열로 갖는 직교행렬. 본체 좌표에서 주축 방향을 가리키는 회전.

**기하적 의미:** 어떤 비대칭 강체든, 그것을 바라보는 좌표축을 잘 돌리면(`R_p`) 곱 관성이 전부 0이 되는 좌표가 존재한다. 그 좌표축이 주축이다. 주축으로 돌릴 때만:

```
L = I·ω = diag(I₁,I₂,I₃)·ω   ⟹   주축 i 로 돌면 L_i = I_i·ω_i  (L ∥ ω)
```

세 주축 회전 모두에서만 `L ∥ ω`가 보장된다. 이래서 엔진들은 관성을 **(대각벡터 `(I₁,I₂,I₃)` + 주축 회전 사원수 `R_p`)**로 저장한다 — 풀 3×3 대신. Jolt의 `mInvInertiaDiagonal` + `mInertiaRotation`, PhysX의 principal inertia + body pose가 정확히 이것이다([04](04-inertia-tensor.md), 허브 §4). 메모리(9 → 3+4)도 절약되고, `invI` 계산도 대각의 역수라 거의 공짜다.

**관성 타원체(inertia ellipsoid):** `ωᵀ I ω = const`는 타원체를 그린다. 그 주축(긴/짧은 반지름 방향)이 정확히 위 고유벡터, 반지름 길이는 `1/√I_i`. "돌리기 어려운 정도"의 방향 의존성을 한 도형으로 본 것.

## 4. 평행축 정리 (Parallel Axis Theorem) — 유도

CoM을 지나는 축에 대한 관성 `I_cm`을 알 때, CoM에서 벡터 `d`만큼 평행 이동한 점을 기준으로 한 관성 `I_d`는:

```
I_d = I_cm + m·( |d|²·E − d·dᵀ )
```

**유도.** 임의 점 위치를 CoM 기준 `r`로 쓰면, 새 기준점에서 본 위치는 `r' = r + d` (모든 질량 조각에 공통인 평행이동 `d`). 정의에 넣으면:

```
I_d = ∫ρ( |r+d|²E − (r+d)(r+d)ᵀ ) dV
    = ∫ρ( |r|²E − r·rᵀ )dV                       … (A) = I_cm
    + ∫ρ( |d|²E − d·dᵀ )dV                        … (B) = m(|d|²E − d·dᵀ)
    + ∫ρ( 2(r·d)E − r·dᵀ − d·rᵀ )dV               … (C) 교차항
```

(B)에서 `d`는 상수라 적분 밖으로 빠지고 `∫ρ dV = m`. 핵심은 (C)가 **0이 된다는 것**: 교차항은 모두 `∫ρ·r dV`에 선형으로 의존하는데, `r`이 CoM 기준이므로 정의상 `∫ρ·r dV = m·r_cm = 0`. 그래서 교차항이 통째로 사라지고 (A)+(B)만 남는다.

```
⟹  I_d = I_cm + m(|d|²E − d·dᵀ)
```

**왜 CoM 기준이 필수인가:** (C)가 사라지는 유일한 이유가 "`r`이 CoM 기준"이라는 점이다. 그래서 평행축 정리는 항상 **CoM을 경유**해야 한다. 부품 A의 축에서 부품 B의 축으로 바로 못 옮긴다 — A축 → A의 CoM → 공통 CoM → B축처럼 CoM을 거점으로 두 번 적용한다. 합성 강체(여러 부품 → 하나의 `I`) 산출이 이 정리의 주 용도다([05](05-mass-properties.md)).

**부호 점검:** `m(|d|²E − d·dᵀ)`는 항상 관성을 **늘린다**(질량을 축에서 멀리 떼면 돌리기 더 어렵다). 따라서 평행축 정리는 한 방향 — CoM 축이 모든 평행축 중 관성 최소. 빼는 방향(역평행축, `I_cm = I_d − m(...)`)으로도 쓸 수 있지만 결과가 음수/무효가 나오면 입력이 틀린 것이다(§7).

## 5. world 변환 — `I_world = R·I_body·Rᵀ` 유도

관성텐서는 본체(body)에 고정된 양이다. 물체가 회전하면 world 좌표에서 본 텐서도 같이 돌아야 한다. body→world 회전을 `R`이라 하면:

```
I_world = R · I_body · Rᵀ
```

**유도 (합동변환, congruence).** 각운동량 관계 `L = I·ω`는 좌표계와 무관한 물리다. world 좌표에서 성립해야 한다:

```
L_world = I_world · ω_world
```

벡터는 좌표 변환에서 `L_world = R·L_body`, `ω_world = R·ω_body`로 회전한다(`R`은 회전행렬). body 좌표에서는 `L_body = I_body·ω_body`. 대입:

```
L_world = R·L_body = R·(I_body·ω_body) = R·I_body·(Rᵀ·ω_world)
        = (R·I_body·Rᵀ)·ω_world
```

`L_world = I_world·ω_world`와 비교하면:

```
⟹  I_world = R · I_body · Rᵀ
```

`R`이 회전행렬(`Rᵀ = R⁻¹`)이라 이 변환은 **합동변환(congruence)이자 동시에 닮음변환(similarity)**이다. 그래서 고유값(주관성모멘트)은 변환에서 보존되고 — 물리적으로 당연하다, 같은 물체를 다른 좌표로 봤을 뿐이니 — 고유벡터(주축)만 `R`로 함께 돌아간다.

**왜 `R·I·Rᵀ`이지 `Rᵀ·I·R`이 아닌가:** `R`이 body→world일 때 위 유도가 `R·I_body·Rᵀ`을 준다. body→world의 반대 규약(`R`이 world→body)을 쓰면 자리가 바뀐다 — 엔진 코드에서 `R`의 방향 규약을 먼저 확인할 것. 부호/순서 함정은 §7과 허브 §5에 정리.

**역텐서:** 솔버는 `invI`를 쓴다. `(R·I·Rᵀ)⁻¹ = R·I⁻¹·Rᵀ` (`R⁻¹=Rᵀ`이므로). 그래서 body의 `invI_body`만 들고 있다가 매 프레임 `invI_world = R·invI_body·Rᵀ`로 회전시킨다. body 관성을 대각으로 저장하면(§3) `invI_body = diag(1/I₁,1/I₂,1/I₃)`라 이 변환이 더 싸다. **이걸 빼먹고 body 텐서를 world에서 그대로 쓰는 게 가장 흔한 버그**다(허브 §5).

**알고리즘 (매 스텝):**

```
회전 적분 후 R(또는 사원수 q) 갱신
invI_world = R · invI_body · Rᵀ        # 대각이면 R·diag·Rᵀ
α_world    = invI_world · ( τ − ω×(I_world·ω) )   # 자이로 항은 [06]
```

## 6. 2D 붕괴 — 텐서가 스칼라가 되는 이유

2D는 회전축이 화면에 수직한 **z축 하나뿐**이다. `ω = (0, 0, ω_z)`로 z성분만 산다. 이때 `L = I·ω`에서 실제로 작동하는 건 `Izz` 성분 하나:

```
L_z = Izz · ω_z       (Izz = ∫ρ(x²+y²) dA = ∫ρ·|r|² dA)
```

`Ixx, Iyy`나 곱 관성은 2D 운동에 관여하지 않는다(평면 밖 회전이 없으니까). 그래서 3×3 텐서가 **단일 스칼라 `I = Izz`**로 붕괴한다. 결과:

- 관성이 1 float. `invI = 1/I`도 스칼라. world 변환 `R·I·Rᵀ`이 불필요(스칼라는 회전 불변) — 2D는 `I_world = I_body`.
- 자이로 항 `ω×(I·ω)`이 사라진다: `ω`와 `I·ω` 둘 다 z축이라 외적이 0. 세차 없음.
- 각충격량도 스칼라: `Δω = (r×J)_z / I` (외적의 z성분은 스칼라 `r_x·J_y − r_y·J_x`).

이것이 Box2D가 교과서적으로 단순한 이유다(허브 §4). 평행축 정리도 스칼라로 붕괴: `I_d = I_cm + m·|d|²` (`|d|²E − d·dᵀ`의 z성분이 `|d|²`).

```
2D 평행축:   I_d = I_cm + m·(dx² + dy²)
```

3D 텐서 논의의 거의 전부가 2D에선 1 float로 줄어든다. 반대로 말하면, 3D의 모든 까다로움(`L∦ω`, 주축, world 변환, 세차)은 **회전축이 여럿이라서** 생긴다.

## 7. 부호·삼각부등식 — 유효성 점검

**부호 규약.** §1에서 곱 관성을 `−∫ρ·xy`로(마이너스) 정의했다. 일부 자료·코드는 `Ixy = +∫ρ·xy`로 정의하고 텐서를 `|r|²E − r·rᵀ` 대신 다른 부호 조합으로 조립한다. 둘 다 자기 일관적이면 같은 물리를 주지만, **평행축 정리·`R·I·Rᵀ`·고유분해가 같은 규약을 써야** 한다. 외부 공식을 복붙할 때 부호가 섞이면 주축이 틀어지고 세차가 가짜로 생긴다(허브 §5). 검증법: 대칭 형상(구·정육면체)을 넣어 곱 관성이 0, 대각이 알려진 값(`⅖mr²` 등, [04](04-inertia-tensor.md))과 맞는지 본다.

**삼각부등식(유효 관성 조건).** 물리적으로 실현 가능한 강체의 주관성모멘트는 항상 다음을 만족한다:

```
I₁ ≤ I₂ + I₃,   I₂ ≤ I₃ + I₁,   I₃ ≤ I₁ + I₂      (등호는 평면 형상)
```

**왜:** `I₁ = ∫ρ(y²+z²)`, `I₂ = ∫ρ(z²+x²)`, `I₃ = ∫ρ(x²+y²)`. 더하면 `I₂+I₃ = ∫ρ(x²+y²+2z²) ≥ ∫ρ(x²+y²) = ... `를 정리하면 `I₂+I₃ − I₁ = 2∫ρ·z² ≥ 0`. 음이 아닌 적분이라 부등식이 강제된다. 등호는 `∫ρ·z²=0`, 즉 모든 질량이 한 평면(z=0)에 있는 평면 형상.

**함정:** 콜라이더에서 자동 산출하거나 손으로 입력한 관성이 이 부등식을 **위반**하면 물리적으로 존재할 수 없는 강체이고, 적분이 폭발하거나 세차가 미쳐 돈다(허브 §5, [05](05-mass-properties.md)). 비정상적으로 얇거나(거의 평면) 퇴화한 메시, 잘못된 부호 조합이 흔한 원인. 엔진은 산출 후 주관성모멘트를 뽑아 삼각부등식과 비음수(`I_i ≥ 0`)를 검사하고, 위반 시 클램프하거나 거부해야 한다.

```
검증:  대각화 → (I₁,I₂,I₃) 추출
       assert I_i ≥ 0  for all i
       assert I₁ ≤ I₂+I₃  및 순환 3개
       위반 시 클램프(예: 얇은 축에 ε 두께 부여) 또는 입력 거부
```

## 8. 실무

- **저장 형식:** 풀 3×3을 상시 들고 다니는 엔진은 드물다. 대각벡터 + 주축 회전(사원수)이 표준 — Jolt `mInvInertiaDiagonal`+`mInertiaRotation`, PhysX principal inertia + pose, Bullet `m_invInertiaLocal`(대각) + 매 스텝 world 갱신(허브 §4).
- **매 프레임 비용:** `invI_world = R·invI_body·Rᵀ`을 회전마다 갱신. 대각 저장이면 `R·diag·Rᵀ`로 싸다. **이 갱신 누락이 1순위 버그**(허브 §5).
- **2D 엔진:** 텐서 전체가 1 float로 붕괴. world 변환·자이로 항 불필요(§6). Box2D 단순함의 근원.
- **유효성:** 자동 산출 후 삼각부등식·비음수 검증을 넣어라(§7). 퇴화 메시는 폭발의 원천.
- **부호 일관성:** 외부 공식 이식 시 곱 관성 부호 규약을 먼저 통일(§7). 대칭 형상으로 단위 테스트.
