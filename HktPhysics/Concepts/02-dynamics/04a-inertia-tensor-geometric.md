# [02·2.4a] 관성텐서 — 기하학적 심화 (Inertia Tensor, from the ground up)

## 0. 한 문장 요약

> **관성텐서 = "질량이 회전축에서 얼마나 멀리 퍼져 있나(r²)"를 *모든 방향에 대해 한꺼번에* 담은 양**이다. 회전 저항이 축 방향마다 다르기 때문에 하나의 숫자(스칼라)로는 부족하고, 입력 방향(`ω`)을 받아 출력 방향(`L`)을 내놓는 선형사상 — 즉 3×3 행렬(텐서) — 이 필요하다. 그래서 `L = I·ω` 의 두 벡터는 일반적으로 평행하지 않으며, 평행해지는 특별한 세 방향이 *주축*이다.

아래는 이 한 문장을 한 걸음씩 기하학으로 풀어가는 과정이다.

---

## 1. 출발점 — 회전 관성은 r²·m 의 합이다

질점 하나가 축에서 수직거리 `d` 만큼 떨어져 그 축 둘레로 돈다고 하자. 그 점의 회전 관성은 `m·d²` 다. 직관: 멀리 있는 질량일수록 같은 각속도라도 더 빠른 선속도(`v = ω·d`)를 갖고, 운동에너지(`½mv²`)와 각운동량 기여가 `d²` 로 불어난다. **회전 관성의 본질은 "질량 × (축으로부터의 거리)²"의 합**이다.

강체는 무수한 질점의 묶음이니 적분으로:

```
한 축(예: x축) 둘레 관성:
  Ixx = Σ mᵢ (yᵢ² + zᵢ²) = ∫ (y² + z²) ρ dV
```

`(y²+z²)` 가 바로 x축으로부터의 수직거리 제곱이다([04-inertia-tensor](04-inertia-tensor.md)의 정의식이 여기서 나온다). 막대를 긴 축으로 돌리면 모든 질량이 축 가까이 있어(`d` 작음) 관성이 작고, 직교 축으로 돌리면 질량이 멀리 퍼져(`d` 큼) 관성이 크다.

> 첫 번째 핵심: **회전 관성은 축의 선택에 의존한다.** 같은 물체라도 어느 축으로 도느냐에 따라 값이 다르다. 그러니 "회전 질량"은 하나의 숫자가 될 수 없다.

---

## 2. 왜 *텐서*인가 — `L`과 `ω`가 어긋나기 때문

질점의 각운동량은 `L = r × p = r × (m v) = m·(r × (ω × r))` 다. 벡터 삼중곱(BAC-CAB)을 전개하면:

```
r × (ω × r) = (r·r) ω − (r·ω) r
            = |r|² ω − (r·ω) r
```

여기서 결정적 관찰: 두 번째 항 `−(r·ω) r` 때문에 **`L` 은 `ω` 와 같은 방향이 아니다**. `ω` 성분에 더해, `r` 방향으로 끌어당겨진 성분이 섞인다. 질량분포가 비대칭이면 이 끌림이 상쇄되지 않아 `L` 이 `ω` 에서 기울어진다.

이걸 모든 질점에 대해 더하면, "`ω` 를 넣으면 `L` 을 내놓는" 선형사상이 된다:

```
L = I·ω,    I = ∫ ρ ( |r|² E₃ − r⊗r ) dV
```

`|r|²E₃ − r⊗r` 가 정확히 [04-inertia-tensor](04-inertia-tensor.md)의 대각(`y²+z²` …)·비대각(`−xy` …) 성분을 만든다. `r⊗r` 의 비대각 항이 바로 §1의 "방향 섞임"을 코드화한 곱 관성(products of inertia)이다.

> 두 번째 핵심: **관성텐서는 "입력 방향 `ω` → 출력 방향 `L`"의 선형사상**이다. 방향마다 회전 저항이 다르고 심지어 방향을 틀어버리기 때문에, 단일 스칼라가 아니라 3×3 행렬(텐서)이 필요하다. `L ∥ ω` 가 *아닌 것*이 자이로스코프·세차운동의 근원이다([06-newton-euler](06-newton-euler.md)의 `ω×(I·ω)` 항).

---

## 3. 주축 (principal axes) — `L ∥ ω` 가 되는 특별한 세 방향

`L` 이 일반적으로 `ω` 와 어긋난다면, 자연스러운 질문: "어긋나지 *않는* 방향이 있는가?" 즉 `I·ω = λ·ω` 가 성립하는 `ω` 가 있는가? 이건 정확히 **고유값 문제**다. `I` 는 대칭(`Ixy=Iyx`)이므로 선형대수의 스펙트럼 정리가 보장한다:

- **항상** 서로 직교하는 세 고유벡터가 존재한다 — 이것이 **주축(principal axes)**.
- 그 고유값 `I1, I2, I3` 가 **주관성모멘트(principal moments)**, 모두 실수이고 (물리적 물체면) 양수.

주축 방향으로 회전시키면 `L = Iₖ·ω` 로 **`L` 과 `ω` 가 정확히 평행**하다 — 흔들림 없이 그 축을 유지하며 도는 "자연스러운 자전축"이다. 팽이를 아무 방향으로나 던지면 비틀거리지만, 주축으로 던지면 안정적으로 도는 이유.

주축 좌표계에서 텐서는 대각이 된다:

```
R_p ᵀ · I · R_p = diag(I1, I2, I3)     // R_p = 주축을 열로 갖는 회전
```

> 세 번째 핵심: **대칭 텐서의 고유분해 = 흔들리지 않는 세 회전축 찾기.** 곱 관성이 0이 되는 좌표계가 곧 주축계다. 대칭 도형(구·박스)은 명백한 대칭축이 곧 주축이라 처음부터 대각이다. 그래서 엔진은 `I` 를 `(대각벡터, 본체회전)` 으로 저장한다([04-inertia-tensor](04-inertia-tensor.md), [02-dynamics §4](../02-dynamics.md#4-실무-엔진은-무엇을-쓰는가)).

## 4. 평행축 정리 — 왜 항상 *더하기*인가

무게중심(CoM)을 지나는 축 둘레 관성 `I_cm` 에서, 그와 평행하면서 거리 `d` 만큼 떨어진 축 둘레 관성을 구한다. 새 축 기준 위치 `r' = r − d`(여기서 `d` 는 CoM→새기준 벡터, `r` 은 CoM 기준 질점 위치)로 전개하면:

```
I_P = ∫ ρ |r'|² … dV = ∫ ρ |r − d|² … dV
    = ∫ ρ |r|² …  −  2d·∫ ρ r …  +  ∫ ρ |d|² … dV
       └ I_cm ┘      └ = 0 ┘        └ m·d² (텐서형) ┘
```

가운데 항 `∫ ρ r dV` 는 **CoM 기준 위치의 가중합 = 0** (무게중심의 정의 그 자체, [05-mass-properties](05-mass-properties.md))이라 깔끔히 사라진다. 남는 것:

```
스칼라형:  I_P = I_cm + m·d²
텐서형:    I_P = I_cm + m·( (d·d) E₃ − d⊗d )
```

> 네 번째 핵심: **평행축 정리가 항상 *더하기*인 이유 = `m·d² ≥ 0`.** 어떤 축이든 CoM 을 지나는 평행축이 그 둘레 관성이 *최소*다 — 질량을 축에서 멀리 옮기면(`d↑`) 관성은 늘기만 한다. 교차항이 0으로 사라지는 것은 CoM 의 정의가 보장하므로, 이 정리는 *반드시 CoM 관성에서 출발*해야 성립한다. (CoM 이 아닌 두 임의 축 사이엔 단순 더하기가 성립하지 않는다.)

이것이 합성 강체에서 부품 관성을 전체 CoM 으로 모아 더하는 절차의 정당성이다([05-mass-properties](05-mass-properties.md)).

## 5. world 변환 `R·I·Rᵀ` — 텐서는 기저에 묶인 양

관성텐서는 질량분포라는 *물리적 사실*이라 본체에 고정돼 있다(body frame 상수). 그런데 같은 물리량이라도 **어느 좌표계의 성분으로 적느냐**에 따라 숫자 배열이 달라진다. 회전 `R`(body→world)로 물체가 돌면, world 좌표에서 본 텐서 성분도 따라 돌아야 한다.

유도는 `L = I·ω` 가 *어느 좌표계에서든* 같은 물리를 기술해야 한다는 요구에서 나온다. world 의 각속도를 body 로 끌어와(`R ᵀ ω_world`) body 텐서를 곱하고(`I_body`) 다시 world 로 돌려보내면(`R …`):

```
L_world = R · I_body · (Rᵀ · ω_world)
        = (R · I_body · Rᵀ) · ω_world
  ⇒  I_world = R · I_body · Rᵀ        // 합동변환 (congruence)
```

양옆에 `R` 과 `Rᵀ` 가 끼는 이 **합동변환(congruence transform)** 이 "텐서를 회전시키는" 표준 방식이다. 벡터(`v' = R v`)는 한 번 곱하지만, 텐서는 두 *발(index)* 이 모두 기저에 묶여 있어 양쪽에서 변환을 받는다 — 사원수 회전이 벡터를 양옆에서 끼우는 것([00-foundations/03a §4](../00-foundations/03a-quaternions-geometric.md))과 같은 "양옆 작용" 구조의 사촌이다.

> 다섯 번째 핵심: **`R·I·Rᵀ` 는 "같은 물체를 돌린 좌표계에서 다시 본 것"** 일 뿐, 물체의 관성이 변하는 게 아니다. 그래서 매 프레임 자세 `R` 이 바뀌면 world 텐서도 매 프레임 다시 계산해야 한다([04-inertia-tensor](04-inertia-tensor.md)). `I_body` 가 대각이면 `R·diag(I1,I2,I3)·Rᵀ` 로 싸게 전개된다 — 엔진이 대각+회전 저장을 선호하는 이유.

## 6. 왜 결국 텐서인가 — 스칼라(2D)·텐서(3D) 대조

| 관점 | 2D 회전 관성 | 3D 관성텐서 |
|---|---|---|
| 자유도 | 1 (화면 수직축 하나) | 3 (직교 세 축) |
| 표현 | 스칼라 `I` (단일 float) | 3×3 대칭 텐서 (또는 대각벡터+회전) |
| `L` vs `ω` | 항상 평행 (`L = Iω`) | **일반적으로 어긋남** (주축에서만 평행) |
| 비선형 항 | 없음 | `ω×(I·ω)` 자이로 항 발생 |
| 좌표 변환 | 불변 (방향 하나뿐) | `R·I·Rᵀ` 매 프레임 |

> 핵심: 2D는 회전축이 화면 수직 하나뿐이라 "방향마다 다른 관성"이 사라져 스칼라로 붕괴한다(Box2D 가 단순한 이유, [02-dynamics §4](../02-dynamics.md#4-실무-엔진은-무엇을-쓰는가)). 3D에서 회전축이 임의 방향을 가질 수 있는 순간, 관성은 "방향→방향" 사상이 되어야 하고 그래서 텐서다. 모든 까다로움(`L≠ω`, 세차, 자이로 항, world 변환)이 이 한 가지 사실에서 파생된다.

## 7. 함정 (전체 체크리스트는 [02-dynamics §5](../02-dynamics.md#5-함정--결정론-체크리스트))

- **body 텐서를 world 에서 그대로 사용**: §5 — 회전 중이면 매 프레임 `R·I_body·Rᵀ` 필수. 빼먹으면 토크 응답이 자세에 따라 틀어진다.
- **곱 관성 부호 규약 혼동**: §2 의 `−r⊗r` 관례. 평행축·world 변환과 자기 일관성 검증, 삼각부등식(`I1+I2 ≥ I3`) 체크.
- **CoM 이 아닌 축에서 평행축 정리 시작**: §4 의 교차항 소거는 CoM 출발일 때만 성립. 임의 두 축 사이엔 단순 더하기 불가.
- **주축 가정 오류**: 비대칭 합성체는 body 축이 주축이 아닐 수 있다 — 대각화 없이 `invI` 를 성분 역수로 처리하면 틀린다.
