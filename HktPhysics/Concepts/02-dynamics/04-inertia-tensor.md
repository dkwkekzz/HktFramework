# [02.4] 관성텐서 (Inertia Tensor)

> 질량이 "병진에 대한 저항"이라면, 관성텐서는 "회전에 대한 저항"이다 — 단, 방향마다 다르므로 스칼라가 아니라 **3×3 행렬**이다. 부피 적분으로 정의하고, 주축(principal axes)·평행축 정리(parallel axis)·world 변환 `I_world = R·I_body·Rᵀ` 를 거쳐, 형상별 공식 표를 정리한다. 가장 흔한 함정 — body 텐서를 world 에서 그대로 쓰면 안 된다 — 을 짚는다.
> **상위 허브**: [02-dynamics.md](../02-dynamics.md) · **상위 지도**: [README.md](../README.md)
>
> *기하학적 심화(왜 텐서인가·`L∦ω`·고유분해·합동변환 유도)는 형제 문서 [02.4a](04a-inertia-tensor-geometric.md)로 미룬다. 이 문서는 정의·공식·실무에 집중한다.*

---

## 1. 왜 필요한가 — 회전 저항은 방향마다 다르다

`a = invMass·F` 에서 질량 `m`은 하나의 스칼라다 — 어느 방향으로 밀든 같은 저항. 그런데 회전은 다르다. 연필을 떠올려보자:

- 길이 방향(심 축)으로 돌리기는 쉽다 — 질량이 축 가까이 모여 있어 저항이 작다.
- 그 수직 방향으로 (헬리콥터 날개처럼) 돌리기는 어렵다 — 질량이 축에서 멀어 저항이 크다.

즉 **같은 물체라도 회전축 방향에 따라 회전 저항이 다르다.** 이 방향 의존성을 하나의 스칼라로는 담을 수 없다. 그래서 `α = invI·τ` 의 `I`는 3×3 행렬 — **관성텐서** 다. 이것이 동역학에서 회전이 병진보다 까다로운 유일한 근원이다([허브 §3]).

---

## 2. 정의 — 부피 적분

질량 분포 `ρ(x,y,z)` 를 가진 강체의 관성텐서는 CoM을 원점으로 한 다음 부피 적분으로 정의된다:

```
       ⎡  Ixx  Ixy  Ixz ⎤
  I =  ⎢  Iyx  Iyy  Iyz ⎥          (대칭: Ixy = Iyx 등)
       ⎣  Izx  Izy  Izz ⎦
```

대각 성분 — **관성 모멘트(moments of inertia)**, 각 축 둘레 회전 저항:

```
Ixx = ∫ (y² + z²) ρ dV       (x축에서 떨어진 거리²)
Iyy = ∫ (x² + z²) ρ dV
Izz = ∫ (x² + y²) ρ dV
```

비대각 성분 — **관성곱(products of inertia)**, 질량 분포의 비대칭(축 정렬 안 됨):

```
Ixy = − ∫ x·y ρ dV           (부호 관례 주의! — §6)
Ixz = − ∫ x·z ρ dV
Iyz = − ∫ y·z ρ dV
```

직관: 각 성분은 "질량이 그 축에서 얼마나 멀리, 어떻게 퍼져 있나"를 잰다. 멀수록(거리²) 회전 저항이 크다. 관성곱은 "이 축으로 돌리면 저 축으로 비틀림이 새는가"를 나타낸다 — `L∦ω` 의 원천이며 [02.4a]에서 깊이 다룬다.

---

## 3. 주축과 대각화

관성텐서는 대칭 행렬이라 **항상 직교 고유분해**가 된다(스펙트럼 정리). 즉 적절한 좌표축을 고르면 비대각 성분이 0이 되는 축들이 존재한다 — 이를 **주축(principal axes)** 이라 하고, 그때의 대각 성분을 **주관성 모멘트(principal moments)** 라 한다:

```
            ⎡ I1  0   0 ⎤
I_principal = ⎢ 0  I2   0 ⎥          (관성곱 = 0)
            ⎣ 0   0  I3 ⎦
```

주축은 물체의 대칭축과 일치하는 경우가 많다(구·박스·실린더 등). 실무 의미:

- **저장 효율** — 풀 3×3(6개 독립값) 대신 **대각벡터 `(I1, I2, I3)` + 주축 회전(사원수)** 만 저장. `invI = (1/I1, 1/I2, 1/I3)` 도 즉시.
- **유효성 조건** — 물리적으로 타당한 텐서는 **삼각부등식**을 만족해야 한다: `I1 ≤ I2 + I3`(및 순환). 위반하면 음의 질량 같은 비물리 상태 — 적분이 폭발한다([02.5]).

대부분의 엔진(Bullet/PhysX/Jolt/Chaos)이 정확히 이 "대각 + 회전" 표현을 쓴다([허브 §4]). 고유분해의 기하학적 의미·유도는 [02.4a §주축].

---

## 4. 평행축 정리 (Parallel Axis Theorem)

관성텐서는 **CoM 기준**으로 정의된다. 하지만 합성 강체(여러 부품)의 텐서를 구하려면, 각 부품의 CoM-텐서를 전체 CoM으로 **옮겨 합산**해야 한다. 이를 가능케 하는 것이 평행축 정리.

부품의 CoM이 전체 CoM에서 `d = (dx, dy, dz)` 떨어져 있고 부품 질량이 `m`이면:

```
I_shifted = I_com + m · ( |d|²·E − d·dᵀ )       (E: 3×3 단위행렬)
```

성분으로 풀면(예: 대각·비대각 각각):

```
Ixx' = Ixx + m·(dy² + dz²)
Iyy' = Iyy + m·(dx² + dz²)
Izz' = Izz + m·(dx² + dy²)
Ixy' = Ixy − m·dx·dy            (관례에 따라 부호 — §6)
...
```

직관: 회전축을 CoM에서 멀리 옮기면(`d` 큼) 같은 질량이 더 큰 저항을 만든다(거리² 항). **합성 강체 절차**는 이렇게 된다:

```
1. 각 부품의 m, CoM, I_part(부품 CoM 기준) 산출 (콜라이더 모양에서)
2. 전체 CoM = Σ(m_i · com_i) / Σ m_i
3. 각 I_part 를 d_i = com_i − 전체CoM 만큼 평행축 이동
4. I_total = Σ I_shifted_i
```

상세 절차·Mirtich 부피 적분은 [02.5]에서, 평행축 정리의 유도는 [02.4a §평행축].

## 5. world 변환 — `I_world = R·I_body·Rᵀ`

> **핵심 연산.** 물체가 회전하면 그 관성텐서도 함께 회전한다.

`I_body`(또는 `I_local`)는 물체 고정 프레임에서 정의된 **상수** 텐서 — 물체와 함께 돈다. 하지만 동역학 방정식(`α = invI·τ`, `L = I·ω`)은 **월드 프레임**에서 계산된다. 그래서 매 프레임, 물체의 현재 회전 `R`(회전행렬, 사원수에서 변환)으로 텐서를 월드로 옮긴다:

```
I_world    = R · I_body · Rᵀ
invI_world = R · invI_body · Rᵀ        (역행렬도 같은 합동변환)
```

이것은 **합동변환(congruence transformation)** 으로, 텐서(2차 양)를 좌표 회전하는 정식 방법이다(벡터의 `v_world = R·v_body` 와 다름에 주의 — 텐서는 양쪽에서 변환). 기하학적 유도는 [02.4a §합동변환].

대각 표현을 쓰는 엔진은 더 싸게 처리한다 — body 주축 회전 `R_principal` 과 물체 자세 `R_body` 를 합쳐 한 번에:

```
R_total = R_body · R_principal
invI_world = R_total · diag(1/I1, 1/I2, 1/I3) · R_totalᵀ
```

Bullet은 매 스텝 `R·invI_local·Rᵀ` 로 `m_invInertiaTensorWorld` 를 갱신하고, Jolt/PhysX/Chaos는 대각벡터+주축 회전으로 같은 일을 더 싸게 한다([허브 §4]).

## 6. 실무 트레이드오프 — body 텐서를 world 에서 그대로 쓰는 함정

> **이 문서에서 가장 중요한 함정 — 가장 흔한 강체 회전 버그.**

`I_body`는 물체 프레임의 **상수**다. 회전 중인 물체의 토크 응답을 계산할 때 `I_body`를 월드 프레임 텐서로 **그대로 쓰면**, 물체가 돌수록 토크 응답이 점점 틀어진다.

```
# 틀린 코드 — body 텐서를 world 에서 직접 사용
α = invI_body · τ_world          # ✗ 물체가 회전하면 축이 안 맞음

# 옳은 코드 — 매 프레임 world 로 변환
invI_world = R · invI_body · Rᵀ
α = invI_world · ( τ_world − ω × (I_world·ω) )   # ✓
```

증상: 비대칭 물체(연필·문짝)가 회전 중일 때 엉뚱한 축으로 도는 것처럼 보이거나, 토크에 대한 반응이 자세에 따라 달라진다. 구(sphere)처럼 등방(isotropic) 텐서(`I = k·E`)는 회전해도 불변이라 이 버그가 안 드러나 — 그래서 구로 테스트하면 놓치기 쉽다. **비대칭 박스로 테스트하라.**

### 부호·단위 점검 (자기 일관성 검증)

| 항목 | 점검 |
|---|---|
| **관성곱 부호** | `Ixy = −∫xy` 인지 `+∫xy` 인지 자료마다 관례가 다르다. 엔진 전체에서 한 관례로 통일하고, 평행축·world 변환과 자기 일관되게. |
| **삼각부등식** | `I1 ≤ I2 + I3`(순환) 만족 여부. 위반 시 비물리 → 클램프 또는 거부([02.5]). |
| **대칭성** | `I`는 항상 대칭이어야(`Ixy = Iyx`). 산출 후 비대칭이면 버그. |
| **단위** | `kg·m²`. world 변환은 합동변환이라 단위 보존. |
| **2D 붕괴** | 2D는 회전축이 하나(화면 수직)뿐 → 텐서가 단일 스칼라로 붕괴(Box2D). world 변환 불필요 — 회전해도 스칼라 `I` 불변. |

> 한 문장: **body 텐서는 상수, world 텐서는 매 프레임 `R·I·Rᵀ` 로 다시 만든다.** 빼먹으면 회전 중 토크 응답이 조용히 틀어진다.
