# HktPhysics — 게임 물리 엔진 (라우터)

> 이 문서는 **목표와 참조 위치만** 보관하는 얇은 라우터다. 이론 지도의 권위는 [Concepts/README.md](Concepts/README.md) 이다. 세부 이론은 각 분기 문서를 참조할 것.

## 큰 목표

게임 물리 엔진에 필요한 **모든 이론을 깊이 있게 정리**하고, 그 위에서 **실제 구현까지 완성**한다. 한 번에 도달하지 않는다 — 이론 지도(Concepts)를 먼저 트리/DAG 로 깔고, 거기서 구현 트랙으로 내려간다.

## 작업 원칙

- **본문은 한국어**, 수식·용어 원어 병기.
- 각 문서는 **실무(실제 엔진이 무엇을 쓰는가)** 를 반드시 포함한다 — PhysX / Havok / Box2D / Bullet / Jolt / Chaos(UE) 등.
- 이론 문서끼리는 상대 링크로 **DAG 의존 관계**를 명시한다.
- 결정론(determinism)에 영향을 주는 선택은 항상 표기한다 — 추후 네트워킹/멀티플레이 전제.
