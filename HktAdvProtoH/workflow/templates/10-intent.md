# 10-intent — INTENT-<도메인>-<번호>

## 추적

| 필드 | 값 |
|---|---|
| Intent ID | INTENT-… |
| Source Goal | GOAL-… |
| Source Possibility | POSS-… |

## Intent 서술

> 세계에서 **무엇이 참이어야 하는가**만 서술한다. 클래스/함수/구현 언급 금지.
> 형식: "…한 조건의 Actor 는 / …행동을 통해 / …결과를 만들 수 있다."

```text
광맥을 알고 있으며,
적절한 채굴 도구를 보유하고 있고,
광맥에 접근 가능한 Actor 는

Mine 행동을 통해

광맥의 자원을 감소시키고
자신의 Stone 보유량을 증가시킬 수 있다.
```

## 의미 단위 목록

> Intent 문장에 등장하는 모든 의미 단위를 나열한다. 다음 단계(World Model)가 이 목록을 State/Rule 로 매핑한다.
> 하나라도 빠지면 Semantic Closure 실패의 씨앗이 된다.

| 의미 단위 | 종류 (조건/행동/결과) |
|---|---|
| 광맥을 알고 있다 | 조건 |
| 채굴 도구를 보유하고 있다 | 조건 |
| 광맥에 접근 가능하다 | 조건 |
| Mine 행동 | 행동 |
| 광맥 자원 감소 | 결과 |
| Stone 보유량 증가 | 결과 |
