# proposals/ — GameView Capability Proposal 수신함

Cycle 트랙이 GameView 에 시각 capability 를 요청하는 **유일한 채널**.

- 파일명: `GVP-NNN-<slug>.md` (NNN 은 3자리 일련번호)
- 템플릿: [../../templates/capability-proposal.md](../../templates/capability-proposal.md)
- 상태 흐름: `PROPOSED → APPROVED(인간 승인) → DONE` 또는 `REJECTED`
- Cycle 트랙은 파일 생성(PROPOSED)까지만. 승인은 인간, 구현·DONE 처리는 GameView 트랙.
- Proposal 을 내기 전에 반드시 기존 ✅ 어휘 조합(사다리 ①②)으로 해결 가능한지 먼저 검토한다.
