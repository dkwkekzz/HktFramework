# 배포 · 모바일

저장소를 받지 않고 브라우저만으로 지금의 세계에 들어가기 위한 환경. 특히 휴대폰처럼
clone · Node 설치 · 빌드를 할 수 없는 기기에서.

## 어떻게 서는가

`render.yaml`(저장소 루트)의 `hkt-adv-proto-h` 서비스 하나가 전부다.

```text
buildCommand   npm ci --include=dev && npm run build      dist/ 를 만든다
startCommand   npm run world                              dist/ 를 서빙하며 세계를 같은 포트에 얹는다
```

Render 대시보드에서 **New → Blueprint → 이 저장소 → Apply**. 이후로는 push 할 때마다
저절로 다시 선다.

프로세스 하나 · 포트 하나인 이유는 `server/main.ts` 가 정적 빌드와 세계의 WebSocket 을
같은 HTTP 서버에 함께 얹기 때문이다 (C003). 그래서 플레이어는 주소 하나만 알면 되고,
클라이언트는 `location.host` 로 붙으므로 주소가 코드에 박히지 않는다. `https` 로 열리면
`wss` 로 붙는 것도 이미 되어 있다 (`app/main.ts`).

`--include=dev` 가 필요한 이유: Render 는 `NODE_ENV=production` 이라 이것이 없으면
빌드의 `tsc`·`vite` 와 실행의 `tsx` 가 통째로 빠진다.

### 무료 티어의 성질

- 한동안 아무도 없으면 서비스가 잠든다. 다음 사람이 열면 다시 서는 데 수십 초가 걸린다.
- **다시 서면 세계는 처음부터 시작한다.** 세계 상태는 메모리에만 있고 저장되지 않는다
  (지금까지도 그랬다). 이어서 하던 것을 다음 날 그대로 잇는 용도가 아니다.

## 로컬에서 같은 것을 재현

```bash
cd HktAdvProtoH
npm ci && npm run build && npm run world       # http://localhost:5180
```

같은 네트워크의 휴대폰에서 보려면 `PORT=5180` 인 채로 위를 띄우고 폰 브라우저에서
`http://<이 기계의 LAN 주소>:5180` 을 연다.

개발 중에는 지금까지대로 `npm run dev` (`run.sh`) 를 쓴다 — 세계가 dev 서버 프로세스
안에서 돈다.

## 손가락 조작

키보드·마우스가 없는 기기에서 지금 가능한 행동 전부에 닿을 수 있어야 한다는 것이 기준이다.
**세계에 새로 요청하는 것은 없다** — 버튼은 그 행동에 이미 배정된 키 코드를 내놓고,
조립 루트는 그것을 키보드에서 온 것과 구분하지 않는다 (`app/main.ts`). 손가락과 키가
갈라질 길 자체가 없다.

```text
왼쪽 절반 끌기    손가락을 댄 자리에 스틱이 생기고 그 쪽으로 계속 간다
오른쪽 절반 끌기  시점이 돈다 (세계로 나가지 않는다 — C008)
오른쪽 절반 탭    지목 — 지금까지의 이동·상호작용 그대로
오른쪽 아래 버튼  지금 걸 수 있는 행동. 되는지 안 되는지는 세계의 판정을 그대로 비춘다
오른쪽 위 버튼    명령 표면 · 충돌체 관찰 · 속성 관찰 (관찰자 쪽에서 끝난다)
```

조작 자리는 **손가락을 쓰는 기기에서만** 나타난다. 기기 이름(UA)을 묻지 않고
`(pointer: coarse)` 인지, 혹은 손가락이 한 번이라도 닿았는지로 정한다 —
데스크톱 화면에는 나타나지 않고 기존 조작은 하나도 바뀌지 않는다.

관련 코드: `view/input/touch.ts` (손짓) · `view/hud/touch-pad.ts` (자리) ·
`index.html` (좁은 화면 배치).

## 확인한 것

Chromium 을 휴대폰 화면(390×844, 터치)으로 띄워 실제로 확인했다.

```text
스틱을 밀면        interactionId "move" 요청이 나간다 — 키보드가 보내던 것과 같은 모양
버튼을 누르면      그 행동의 요청이 나간다 (예: attack)
명령 표면          손가락으로 열고, 닫는 자리(✕)로 닫힌다
                   — Escape 는 자판이 있는 기기에만 있으므로 닫는 자리를 냈다
HUD                가로 넘침 없음 · 겹침 없음 · 페이지 오류 없음
데스크톱 회귀      조작 자리 숨김 · WASD · 우클릭 시점 · 좌클릭 지목 · F 스킬 ·
                   / 로 열고 Escape 로 닫기 모두 그대로
```
