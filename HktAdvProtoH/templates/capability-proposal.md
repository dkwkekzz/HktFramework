# GameView Capability Proposal 템플릿

`gameview/proposals/GVP-NNN-<slug>.md` 로 작성한다 (Design-GameView §21·§23).

```text
GAME VIEW CAPABILITY PROPOSAL

ID
    GVP-NNN

STATUS
    PROPOSED            # PROPOSED → APPROVED / REJECTED → DONE

REQUIRED BY
    <CYCLE-ID>

VISUAL REQUIREMENT
    무엇을 표현해야 하는가 (World 용어가 아니라 시각 요구로 —
    예: "곡선 부채꼴 영역" O, "시야 범위" 참고용, "늑대 시야" X)

CURRENT CAPABILITY
    현재 ✅ 어휘 중 검토한 것

PROBLEM
    왜 기존 어휘 조합(사다리 ①②)으로 부족한가

PROPOSED CAPABILITY
    종류: Visual Component(③) / Generic Primitive·Capability(④) / Renderer Plugin(⑤)
    이름: 반드시 범용 이름 (World-specific 이름 금지)

GENERIC INTERFACE
    파라미터 초안 (세계 의미 없는 일반 파라미터만)

RESOLUTION (GameView 트랙 기입)
    구현 결과 / VOCABULARY 반영 항목 / DONE 날짜
```
