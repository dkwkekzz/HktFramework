# INTENT PACKAGE

```text
Cycle:
    CYCLE-XXX
```

Intent가 여러 개면 아래 블록을 반복한다.

```text
Intent ID:
    INTENT-<CAPABILITY>-NNN

Source Goal:
    GOAL-...

Source Possibility:
    POSSIBILITY-...

Intent:
    <세계에서 무엇이 참이어야 하는가를 서술.
     구현 구조(클래스/메서드/서비스) 언급 금지.>

    예:
    광맥을 알고 있으며,
    적절한 채굴 도구를 가지고 있고,
    광맥에 접근 가능한 Actor는

    Mine을 통해

    광맥의 Resource를 감소시키고
    자신의 Inventory에 Resource를 획득할 수 있다.
```
