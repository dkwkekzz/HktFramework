## 이전 → 지금

곁말은 늘 칸 **아래**로 폈다. 표면이 세로로 구르는 자리라 위로 펴면 첫 줄이 잘리기
때문이다. 그래서 마지막 줄에서는 아래가 없어 그대로 잘렸다 (V-011 REPORT ②).

    같은 칸 (표면 바닥에 붙은 마지막 줄)      이전            지금
    곁말이 펴지는 쪽                          늘 아래          위로 접힌다
    표면 밖으로 새어 나간 픽셀                 아래로 46·61     0

좌우도 같다 — 곁말은 칸 가운데에 서므로 끝 열에서는 표면 밖으로 나갔다. 지금은
남은 쪽으로 맞춰 선다.

## 검증

실제 Client 를 띄워(900×420 — 표면 높이 302px 로 좁혀 마지막 줄이 바닥에 닿게 했다)
소지품 표면을 열고 물건 칸에 손을 얹었다.

```text
칸        item.pickaxe
칸 자리    y 243..301 / 표면높이 302     ← 표면 바닥에 붙은 마지막 줄이다
펴진 쪽    above                        ← 반대 방향으로 접혔다
맞춘 쪽    center
새어 나감  0 / 0 / 0 / 0                ← 위·아래·왼·오른 어느 쪽으로도 잘리지 않는다
```

페이지 오류 0.

**직접 보지 못한 것** — 좌우로 접히는 경우(`start` · `end`)는 이 화면에서 재현하지
못했다. 지금 팩의 곁말이 112px 라 이 폭에서는 끝 열에서도 넘치지 않는다. 더 좁은
화면(360px)에서 걸리는 것은 기반 트랙이 따로 확인했고, 이 세션에서는 보지 못했다.

## REPORT

세계 관찰의 결손은 없다. 곁말에 실리는 것은 전부 이미 실려 오는 값이다.
