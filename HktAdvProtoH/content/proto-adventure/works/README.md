# works/ — Cycle 이 아닌 작업의 할일

Cycle(8 Stage)로 돌지 않는 작업의 레인 홈이다. 지금 쓰는 것은 VIEW 레인이다
(guides/view-work.md). 살아 있는 파일은 하나다:

```text
BACKLOG.md        살아 있는 문서 — 남은 할일 + 관찰 결손 REPORT.
                  Master 의 frontier/ 에 대응하는 자리다 — 다른 세션이 이것만 보고 잇는다.
                  닫힌 항목은 지운다 — 완료의 기록은 커밋이다
V-NNN-<name>.md   과거 형식의 닫힌 기록 (V-001~V-021) — 수정하지 않는다 (History).
                  새 파일을 만들지 않는다
```

```text
여기가 소유    남은 화면 할일 · 발견한 세계 관찰의 결손(REPORT — Frontier 재료)
여기가 아님    세계·Master 의 상태 (world/ · master/ 소유) · Cycle 기록 (cycles/ 소유) ·
              완료 경위 (git 소유)
```

레인 목록과 판정은 `guides/works.md`, 형식은 guides/view-work.md 가 소유한다.
