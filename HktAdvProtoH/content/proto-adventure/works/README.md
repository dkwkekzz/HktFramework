# works/ — Cycle 이 아닌 작업의 기록

Cycle(8 Stage)로 돌지 않는 작업의 완료 기록이다 — 한 작업 = 한 파일.
지금 쓰는 것은 VIEW 레인(`V-NNN-<name>.md` — guides/view-work.md)이다.

```text
여기가 소유    그 작업의 목표 · 바뀐 표면 · 검증 · REPORT (발견한 결손 보고)
여기가 아님    세계·Master 의 상태 (world/ · master/ 소유) · Cycle 기록 (cycles/ 소유)
```

레인 목록과 판정은 `guides/works.md`, 형식은 각 레인의 Guide 가 소유한다.
보관소다 — 한번 닫힌 파일은 수정하지 않고, 평소 읽지 않는다 (History).
