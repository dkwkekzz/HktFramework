# works/ — Cycle 이 아닌 작업의 할일과 기록

Cycle(8 Stage)로 돌지 않는 작업의 레인 홈이다. 지금 쓰는 것은 VIEW 레인이다
(guides/view-work.md). 파일이 두 종류다:

```text
BACKLOG.md        살아 있는 문서 — 남은 할일만. 닫힌 항목은 지운다.
                  Master 의 frontier/ 에 대응하는 자리다 — 다른 세션이 이것만 보고 잇는다
V-NNN-<name>.md   닫힌 작업의 기록 — 한 작업 = 한 파일. 수정하지 않는다 (History)
```

```text
여기가 소유    남은 화면 할일 · 닫힌 작업의 목표·바뀐 표면·검증·REPORT
여기가 아님    세계·Master 의 상태 (world/ · master/ 소유) · Cycle 기록 (cycles/ 소유)
```

레인 목록과 판정은 `guides/works.md`, 형식은 각 레인의 Guide 가 소유한다.
보관소다 — 한번 닫힌 파일은 수정하지 않고, 평소 읽지 않는다 (History).
