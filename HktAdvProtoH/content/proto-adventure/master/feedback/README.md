# feedback/ — Cycle Feedback 기록

닫힌 Cycle 하나가 Master 에 반영된 경위를 **한 Cycle = 한 파일**(`<CycleId>.md`)로 담는다.
Cycle 마다 자기 파일이므로 병렬 갈래의 Feedback 이 서로 충돌하지 않는다.

```text
여기가 소유    Overlay 를 왜 그렇게 바꿨는가 · 닫힌 Frontier 후보의 결과와 배운 것 ·
              Constraint Evaluation 판정 경위 · 제출한 Candidate · 보고된 Master Gap
여기가 아님    현재 상태 (overlay.md · frontier/ · graph/ 소유) ·
              Master 층 자체의 결정 경위 — 닫힌 Q · Constraint 승인 (HISTORY.md 소유)
```

형식은 [../SCHEMA.md](../SCHEMA.md), 절차는 `guides/master-feedback.md` 소유다.
살아 있는 문서가 아니라 보관소다 — 한번 쓰이면 수정하지 않고, 평소 읽지 않는다 (History).
