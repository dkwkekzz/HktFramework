# HktZeta

**수열(값의 궤적)로 세계를 표현하는 오픈월드 MMORPG 프로토타입.**

세계를 객체들의 집합으로 만들지 않는다 — 하나의 산술 함수(오라클 **Ω**)가 모든 존재의 다음 결정을 내리는
공통 원천이 되고, 세계는 그 값들이 쌓인 **궤적**이다. 제타 함수 ζ(s)=Σ 1/nˢ 가 소수의 분포를 품듯,
Ω 은 정수 n 의 **소인수 구조**에서 결정을 길어 올린다.

> 단순한 결정 → 결정의 결합 → 생명체의 성장. 이 세 겹만으로 오픈월드를 짓는다.

## 실행

```bash
npm test                    # 결정론·순수성·불변식·창발 자동 회귀 (14/14, ≈1.3s)
npm run demo                # 궤적을 ASCII 밀도 지도로 굳혀 눈으로 확인
node tools/demo.mjs 7 400 8 # seed=7, 400틱, 초기 8존재 (인자 조절 가능)
```

`npm run demo` 는 방사형·유기적 밀도 지도를 그리고 결정론 재현(같은 seed 두 번 → 같은 지문)을 확인해 준다.
의존성 없음(순수 Node). 클라우드 환경에서 그대로 재현된다.

## 어떻게 도는가 (한 눈에)

```
존재 = 주소 a(정수, "유전자")
  ↓  n = 1 + (mix(a, t) mod P)          ← (주소, 시각)을 결정 색인으로 접는다
n 을 소인수분해                          ← 이것이 곧 결정 절차
  ↓
결정 = { turn=μ(n), act=Ω(n)%4, mag=ω(n) }   ← 단순한 결정
  ↓  시간축으로 누적(적분)
궤적 = 이동·성장·분열의 역사             ← 결정의 결합 → 창발하는 세계
```
