# CLAUDE.md — HktZeta 작업 규칙 (간략·불변)

> 수열(값의 궤적)로 세계를 표현하는 오픈월드 MMORPG 트랙. UE 빌드·타 플러그인과 무관한 독립 웹 트랙.
> 이 문서는 **목표·불변 원칙·작업 방식**만 정한다 — 아주 간략하며 왠만하면 변하지 않는다.
> 설계·존재론·로드맵의 권위는 [SPINE.md](SPINE.md), 현재 위치는 [STATE.md](STATE.md), 상세는 `steps/`.

## 한 줄

> **세계를 객체들의 집합으로 만들지 않고, 하나의 산술 함수(오라클 Ω)가 만들어내는 값의 궤적으로 만든다.**
> 제타 함수 ζ(s)=Σ 1/nˢ 가 소수의 분포를 품듯, Ω 은 정수 n 의 소인수 구조에서 결정을 길어 올린다.
> 모든 존재는 이 공통 원천에서 *다음 결정*을 읽는다. 세계는 그 값들이 쌓인 궤적이다.

## 목표

**단순한 결정 → 결정의 결합 → 생명체의 성장**, 이 세 겹만으로 오픈월드 MMORPG 를 만든다.
아주 단순한 산술 규칙에서 출발해, 결합과 성장이 *창발*하도록 한 겹씩 쌓는다. 한 번에 도달하지 않는다.

## 불변 원칙

> **① 세계는 저장되지 않고 계산된다.** 존재는 객체가 아니라 *주소*(정수)다. 상태는 최소한만 들고,
> 나머지는 (주소, 시각)을 오라클에 넣어 언제든 다시 읽는다. 시뮬레이터가 아니라 함수를 읽는다.

> **② 결정은 단순하고, 복잡함은 창발이다.** 원천은 μ(n)·Ω(n)·ω(n) 같은 *작은 산술 지표*뿐이다.
> 행동·궤적·생태의 복잡함은 이 단순한 결정들을 시간축으로 *결합(적분)*한 결과여야 한다 —
> 복잡함을 손으로 author 하지 말고 굴려서 얻는다.

> **③ 결정론은 검증의 뿌리다.** 같은 seed → 완전히 같은 궤적. 모든 명제는 `npm test`(자동 회귀)로
> 상시 재현되고, `npm run demo`(눈으로 보는 궤적 지도)로 비전문가도 한눈에 납득할 수 있어야 한다.
> 검증법(재현 가능한 측정)을 못 세우는 명제는 아직 시작하지 않는다.

> **④ 렌더는 세계를 읽기만 한다.** 시각화는 궤적의 *읽기 전용 소비자*다 — 세계 규칙을 렌더 안에서
> 재유도하지 않는다. 지금은 ASCII 지도로 대충 그려도, 이후 같은 궤적 계약으로 리치 렌더로 교체 가능하게 둔다.

## 작업 방식 — step 단위

- **step** = 한 조각의 전진. 분명한 명제와 *측정 가능한* 검증을 가진다. `steps/step-NNNN-<slug>.md` 하나.
- 매 step: 읽기(STATE·SPINE) → 구현(core 최소 변경) → 검증(`npm test` + 필요시 데모) → STATE 갱신 → 닫기.
- **STATE.md 는 현재 참인 것 + NEXT 만 든다.** 완료 로그를 쌓지 않는다(이력은 git·step 문서가 든다).
- **번호는 은퇴만, 재사용 금지.** 삭제된 step 번호는 비워 둔다.

## 실행 · 검증

```
npm test        # 결정론·불변식 자동 회귀 (상시 재현, 의존성 없음)
npm run demo    # 궤적을 ASCII 밀도 지도로 굳혀 눈으로 확인 (node tools/demo.mjs [seed] [ticks] [count])
npm install     # 3D 렌더용 three.js 1회 설치 (코어 테스트에는 불필요)
npm run shot    # 헤드리스 Chromium 으로 field/terrain/worm 3D 3장 캡처 → tools/shots/
npm run serve   # 브라우저로 직접 관찰 http://localhost:8123/render/?view=field|terrain|worm
```
