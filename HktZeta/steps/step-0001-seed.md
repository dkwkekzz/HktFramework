# step-0001 — 씨앗: 하나의 함수가 세계를 굴린다

## 명제

> 단 하나의 산술 함수(오라클 Ω)가 모든 존재의 다음 결정을 내리고, 그 결정들을 시간축으로 결합(적분)한
> 것이 세계의 궤적이 된다. 세계는 저장되지 않고 *계산*되며, 같은 seed 는 같은 궤적으로 재현된다.

## 구현

- **수론 원천** `core/arith.mjs`: `factorize` 위에 μ(n)·ω(n)·Ω(n)·λ(n)·lpf. 핫 패스용 `analyze(n)`
  이 한 번의 인수분해로 지표를 함께 뽑고 메모이즈한다. `mix(a,t)` 는 (주소,시각)→결정 색인 pairing.
- **오라클** `core/oracle.mjs`: `decide(a,t)` = `n=1+(mix(a,t) mod ORACLE_PERIOD)` 의 소인수 구조에서
  `{turn=μ(n), act=Ω(n)%4, mag=max(1,ω(n))}` 를 뽑는 순수 함수. `stepMotion` 이 결정을 이동으로 번역.
- **궤적** `core/world.mjs`: `seedWorld/step/run`. 존재 = `{addr,x,y,heading,energy}`. FEED→에너지,
  에너지→주소 전진(성장), SPLIT→자식 파생(번식). `hashState` 로 궤적 지문을 접는다.
- **눈 검증** `tools/demo.mjs`: 궤적을 ASCII 밀도 지도로 굳힌다 — 방사형·유기적 창발이 한눈에 보인다.

## 검증 (4기둥, `npm test` 14/14 통과 ≈1.3s)

- **결정론**: `run(42,300)` 두 번 → 같은 `hashState`. 다른 seed → 다른 지문.
- **순수성**: `decide(a,t)` 재호출 동일. `step(s0)` 후 `s0` 지문 불변.
- **불변식**: 200틱에 걸쳐 `turn∈{−1,0,1}` · `act∈[0,4)` · `mag≥1`.
- **창발**: `run(7,500)` 이 이동·복수 위치·개체수 변화를 낸다. `npm run demo` 로 방사형 지도 확인.

## 발견 · 한계 (다음 step 의 씨앗)

- **수리**: 채널을 `lpf(n)%4` 로 뽑으니 MOVE(0)가 영영 안 나왔다 — 소수 mod 4 는 0 을 못 밟는다.
  `Ω(n)%4`(모든 잔여류를 밟음)로 교체해 해결. → *지표 선택이 곧 게임 밸런스*라는 첫 교훈.
- **성능**: 무계 주소 + 결정마다 3회 인수분해로 500틱이 타임아웃. `analyze` 단일 인수분해 + `ORACLE_PERIOD`
  유계 창(√n≤1024) + 메모이즈로 해결. 큰 주소의 BigInt 승격은 P1(성능 seam)으로 남긴다.
- **한계(정직)**: 개체수는 `MAX_BEINGS=512` 하드 상한으로 *잘라낸다* — 아직 항상성이 아니다.
  성장⇄사멸 균형은 P2 로 분리(STATE NEXT 참조). "죽음"의 산술 정의가 다음 명제다.
