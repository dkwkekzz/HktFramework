## 1. 본 문서의 위치

05의 시드 구조는 비트 페이로드에 `wounded_traveler`, `journal_fragment` 같은 spawner를 명시했지만 **그들이 무슨 말을 하는가**는 비워뒀다. 07이 좌표를 못 박았지만 그 좌표에 가서 실제로 마주칠 텍스트는 없었다. 본 문서가 그 빈 칸을 채운다.

본 문서의 텍스트는 P1 첫 1시간 플레이를 **실제로 가능**하게 만든다. 다음을 포함한다.

- SEED 01 부상 NPC·폐허 생존자 대화
- SEED 02 들불 진압 협력자 대화 (선택, 결정적 스폰 아님)
- SEED 03 일지 단편 7개 전문 + 작성자 K의 대화
- SEED 04 정상 명판 표기 양식

---

## 2. 텍스트 작성 원칙

본 문서의 모든 텍스트는 다음 원칙을 따른다.

- **줄임표(...)는 의도적 분위기 장치** — 의식이 흐려진 NPC, 미완성된 일지, 위급 상황의 침묵을 표현
- **일인칭은 일지 작성자만** — NPC 대화는 직접 발화로
- **고유명사는 일지의 K·T·M 외에 없음** — 명명권 시스템이 작동하기 전에는 작성자조차 무명. 플레이어가 부여한 이름이 명판에 새겨진다
- **시그널 단계 정합** — S2 청각 단서로 노출되는 NPC는 처음에 짧은 신음·외침만, 가까이 가야 대화 라인
- **모든 분기 텍스트가 짧음** — 길어지면 플레이어가 양보다 빨리 스킵. 한 호흡으로 읽히는 길이

## 3. SEED 01 — 상류 폐허 NPC 대화

### 3.1 부상 NPC (wounded_traveler) — 강가 진입점 A

**상황: 의식 없이 강가 갈대밭에 쓰러져 있음**

가까이 가면 (S2 → S1 전환):
```
"...읔... 흐읍..."
[얕은 숨소리. 의식 없음]
```

**상황: 회복 액션 직후 짧게 깨어남**

```
"...누구... 물... 좀..."
[물 한 모금]
"...상류에서... 짐승이... 모두를..."
[다시 의식 잃음]
```

**상황: 두 번째 회복 시도 또는 시간 경과 후**

```
"...아직 살아있는 건가... 동료들이 있었어요. 폐허에 숨어 있어요. 강을 따라 올라가면... 산기슭 가까운 곳에... 작은 폐허가... 만약 갈 수 있다면..."

[기침]

"혼자 가지 마요. 그 짐승은... 사람도 잡아먹어요. 한쪽 눈이 흰색이었어요. 달빛 아래서 봤어요..."
```

**상황: 따라오기 동행 선택 시 (선택적 기능, 본 시드의 핵심은 아님)**

```
"...몸이 무거워요. 천천히만 가요. 강에서 멀어지면 안 돼요. 그 짐승은 풀숲을 좋아해요..."
```

**상황: 무시 + 10분 이상 경과 시 (사망 직전)**

```
"...누구든... 와줘요... 동료들이... 폐허에..."
[숨이 끊김]
```

**사망 후**: 시신이 표류물에 합류 (SEED 01-C의 까마귀 떼 진입점 강화).

### 3.2 폐허 생존자 (cowering_survivor) — 폐허 내부, SEED 01 Quake 단계

**상황: 폐허 잔해 사이에서 떨고 있음**

가까이 가면:
```
"...누구야! 짐승이야?! ...아... 사람이구나..."
[안도하는 한숨]
```

**상황: 첫 대화**

```
"짐승이 떠난 줄 알았는데... 며칠을 여기 숨어 있었어요. 동료들은... 다 끝났어요. K와 T는 마지막까지 일지를 썼어요. 강에 흘려보냈죠. 누군가 읽어주기를 바라며..."

[잠시 침묵]

"당신이 그 일지를 읽었나요? 그렇다면... 우리를 기억해주세요."
```

**상황: 구조 액션 후**

```
"고마워요. 강 하류에... 다른 마을이 있다고 들었어요. 거기까지만 데려다줘요. 부탁할게요."
```

**상황: 그 짐승에 대해 묻는 분기**

```
"한쪽 눈이 흰색이었어요. 다른 늑대들보다 컸어요. 너무 조용했어요. 발자국 소리가 풀잎을 가르는 것 같았어요..."

"...K가 그것에게 이름을 지어주고 싶다고 했어요. 짐승이 이름조차 없는 게 두려웠대요. 알 수 없는 것보다, 이름 있는 것이 덜 무섭다고요."
```

### 3.3 부상 NPC 후속 — SEED 07 행상인과 결합 (P2에서 활용)

부상 NPC가 살아남아 강 하류 마을로 갔다는 사실은 P2의 행상인 시드와 결합 가능. 행상인이 본 NPC를 안다는 단서 — "강가에서 누군가 구해줬다고 들었어요. 당신이 그 사람인가요?"

상세는 09.x (P2 콘텐츠 텍스트)에서.

## 4. SEED 03 — 일지 단편 7개 전문

각 단편은 강 회랑 따라 결정적 분포 (07 §4.4). 단편 N이 단편 N+1보다 하류에 위치. 플레이어는 강을 거슬러 오르며 누적 발견.

### 단편 1 (강 회랑의 가장 하류, 시작 풀숲 인접)

```
다섯째 날.

강을 따라 일지를 흘려보낸다. 누군가 읽기를 바라며.

산에서 본 그것은... 늑대가 아니었다.
더 컸고, 더 조용했다.
우리는 다섯이었다. 이제 셋.

내일이면 둘이 될지도 모른다.
```

### 단편 2

```
캠프를 차렸던 곳은 산기슭의 옛 채집민 거주지였다.
사람들의 흔적이 남아 있었지만 모두 도망친 것 같았다.

부서진 도구. 뒤집힌 가구.
누군가가 황급히 떠난 자리.

우리도 그렇게 될까?
```

### 단편 3

```
밤이 됐다.

그것이 또 우리 캠프 주변을 돈다.
발자국 소리가 풀숲을 가른다.
풀잎을 가른다.

한쪽 눈이 흰색이었다. 달빛에 비쳤을 때.
M이 봤다고 했다. M의 말이 사실이라면.
```

### 단편 4

```
M이 다쳤다.
어제 그것을 피하다가 절벽에서 떨어졌다.
다리가 부러졌다.

그가 도망치지 못한다면 우리는 그를 두고 가야 할까.
아니, 그럴 수 없다.

강가에서 누군가를 봤다고 했다. 풀숲을 지나가는 사람.
그 사람이라면... 우리를 도와줄지도 모른다.

당신이 이 일지를 읽고 있다면, 부탁한다.
```

### 단편 5

```
M을 강에 띄워 보냈다.

의식이 없어서. 우리가 데리고 갈 수 없어서.
누군가 강 하류에서 발견해주기를.

만약 그가 살아남는다면, 우리를 기억해 달라고 전해 달라.

우리에게는 시간이 없다.
그 짐승이 다시 가까이 왔다.
```

### 단편 6

```
둘 남았다. K와 T.

폐허 안에 숨었다.
짐승이 폐허 주변을 돈다.

이 일지가 마지막 두 페이지다.
만약 우리가 살아남지 못한다면 누군가 이 짐승의 이름을 지어주기를.

우리는 이름조차 알지 못했다.
알 수 없는 것이 가장 무서웠다.

이름이 있다면, 덜 무서울지도 모른다.
```

### 단편 7 (SEED 01 폐허 내부, 무너진 책상 위)

```
마지막 페이지다.

짐승이 폐허 안으로 들어왔다.
도망갈 곳이 없다.

우리는 마지막까지 함께 있을 것이다.
누군가 이 폐허에 닿거든, 우리를 기억해 달라.

그리고 그 짐승을... 막아주기를.
이름을 지어주기를.

— K, T
```

### 단편 분포의 미적 정합

7개 단편이 강 상류로 갈수록 절박해진다. 단편 1·2는 관찰자의 시선, 3·4는 위협의 인식, 5는 동료의 상실, 6은 마지막 두 명, 7은 마지막 순간. 플레이어가 강을 거슬러 오를수록 텍스트의 톤이 무거워지며, 폐허 도달 시점에서 최대 절박.

**SEED 03 결말 분기 — 작성자 K의 생존 여부**

본 시드의 결말은 다음 두 분기 중 하나로 결정 (시드 결합에 따라):
- **K 사망 분기**: 폐허에서 K·T의 시신 발견. 단편 7이 마지막 메시지. 명명권은 폐허에 새겨짐.
- **K 생존 분기**: K가 폐허에서 살아남아 SEED 01의 cowering_survivor와 동일 인물. T는 사망. K의 직접 발화로 단편의 내용이 마무리.

본 게임의 첫 1시간에서는 **K 생존 분기 권장** — 시드 결합이 풍부해지고, 플레이어가 직접 명명권 부여 의식을 K와 함께 수행 가능.

## 5. SEED 03 — 일지 작성자 K의 대화 (K 생존 분기)

K는 SEED 01의 cowering_survivor와 동일 인물.

**상황: 폐허에서 첫 만남, 모든 단편을 읽은 플레이어**

```
"...누구... 아, 일지를 읽었군요."
[K가 천천히 일어남]
"단편 7개 모두 읽었나요? 그렇다면... 알고 있겠네요. T는 살아남지 못했어요. 저만 남았어요."

[잠시 침묵]

"그 짐승은... 아직 폐허 근처에 있어요. 매일 밤 돌아와요. 만약 당신이 그것을 막을 수 있다면..."
```

**상황: 짐승 처치 후 K에게 돌아감**

```
"...해냈군요."
[K가 처음으로 미소짓는다]

"이제 그것에게 이름을 지어주세요. 우리가 마지막까지 바랐던 것. 알 수 없는 것이 아니라, 이름 있는 것이 되도록."

[명명 액션 노출]
```

**상황: 명명 액션 완료 후**

```
"...[플레이어가 지은 이름]. 좋은 이름이에요. T가 들었으면 좋아했을 거예요."

[K가 깊은 한숨을 쉰다]

"이제 마을로 돌아가야겠어요. M이 살아남았는지 확인해야죠. 강 하류에... 누군가 그를 구했다는 소문을 들었어요."
```

(M이 SEED 01의 wounded_traveler — 플레이어가 진입점 A에서 구한 인물. K·M·T의 인과 사슬이 완성)

## 6. SEED 02 — 들불 진압 협력자 (선택)

본 NPC는 결정적 스폰이 아닌 **확률적**. 들불 발생 영역 근처에 다른 행인이 있을 때만 출현. 첫 1시간에서는 만나지 않을 가능성이 높음.

**상황: 들불 영역에서 멀리 외침이 들림 (S3 청각)**

```
"누구든! 도와줘요! 불이 번지고 있어요!"
```

**상황: 가까이 가면 (S1)**

```
"강물을 길어와요! 양동이 있어요? 빨리! 풀숲이 다 타버려요!"
```

**상황: 진압 협력 중 단편 대화**

```
"이 가뭄에... 번개 한 번이면 끝이에요. 누가 시작한지도 모르는 불이..."
"산에서 동물들이 내려와요. 강 쪽으로요. 거기 다른 사람들도 있을 거예요."
```

**상황: 진압 성공 후**

```
"고마워요. 혼자였으면 다 타버렸을 거예요. 이 빚은 갚을게요."
```

→ 감사 토큰 1개 발급 + NPC 기억 갱신 (재회 시 인식)

**상황: 진압 실패 (영역 폐허화)**

```
"...너무 늦었어요. 다 끝났어요."
[NPC가 어두운 표정으로 떠남]
```

→ NPC 떠남, 명판에 "이 자리에서 들불을 막으려 했으나 실패" 자동 기록

## 7. SEED 04 — 정상 명판 표기 양식

SEED 04의 명판은 정상에 새겨지는 영구 표지. 본 게임 가장 가시적인 명명권의 사용처.

### 7.1 첫 등정자의 명판

```
─────────────────────
[플레이어가 지은 정상 이름]

이 자리를 처음 본 자:
[플레이어 캐릭터 이름]

[게임 내 일시]
─────────────────────
```

명판의 텍스트는 위 양식 고정. 플레이어가 정상 이름과 자신의 이름만 채운다.

### 7.2 N번째 등정자 칭호

명판 자체는 첫 등정자만 새기지만, 후속 등정자도 정상에서 자기 자국을 남길 수 있음.

**상황: N번째 등정자 (N≥2)**

```
[명판 옆 작은 돌무지]

이 자리를 본 자: [플레이어 이름]
[N]번째 등정자.
[일시]
```

돌무지는 영구. 등정자가 누적될수록 정상의 돌무지가 늘어남 — 영구 변형 지형의 가시화.

### 7.3 명판 보기 액션 (다른 플레이어)

정상에 도달한 다른 플레이어가 명판을 읽을 때:

```
"이 자리는 '[정상 이름]'.
처음 본 자는 [첫 등정자 이름]. [일시].
당신은 [N]번째 등정자입니다."
```

→ 본 게임의 멀티플레이성 + 영속성의 동시 시연.

## 8. 본 문서가 미룬 항목

후속 문서·세션에서.

- **P2 시드의 NPC 대화** — 행상인(SEED 07), 은둔자(SEED 08) — 08 작성 후 별도 문서
- **NPC 대화의 음성 톤·표정·바디 랭귀지** — 본 문서는 텍스트만
- **다중 분기 대화 트리** — 본 문서는 선형 라인 중심, 분기 노드는 일부만 표기
- **다국어 번역** — 본 문서는 한국어 원문, 영문 등 번역 양식 별도 필요
- **부상 NPC의 사망 분기 대화의 시각 연출** — "숨이 끊김" 외의 묘사
- **K·T·M의 풀네임 또는 별명** — 현재 이니셜만, 일지의 미스터리 분위기 유지를 위해 의도적

2. **09.x — P2 콘텐츠 텍스트** (08 작성 후) — SEED 07 행상인, SEED 08 은둔자의 대화.
