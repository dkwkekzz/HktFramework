## 1. 본 문서의 역할

03에서 L5 Beat 그릇을 정의했고, 04에서 그 그릇에 들어갈 누적 feature(도감·시혜·변종·명명권·흔적 등)를 갖추었다. 본 문서는 그 그릇과 feature를 **풀숲 첫 1시간에서 실제로 마주칠 5개의 시드 스토리**로 묶어낸다.

시드 스토리는 "이야기"가 아니라 **"씨앗"** 이다. 어떤 입력(L1 지형, L2 환경, 플레이어 행동)을 만나면 어떻게 자라날지의 분기를 모두 포함한다. 작성자가 결말을 정하지 않는다 — 결말은 플레이어의 경로가 결정한다.

본 문서의 5개 시드는 다음을 시연하기 위해 선정되었다.

| 시드 | 시연하는 feature | Phase |
|---|---|---|
| 1. 상류 폐허 | 시혜 토큰 / 다중 진입점 / Tremor→Quake 사슬 | P1 |
| 2. 들불 사슬 | 환경 인과 / 영구 변형 지형 / 변종 시드 | P1 (P3 영속성 절반) |
| 3. 흘러내려오는 일지 | 단서 누적 / 도감 텍스트 / 추리 | P1 |
| 4. 정상의 조망 | 발견 보상 / 명명권 / 지도 단편 일괄 갱신 | P1 (P2 명명권 절반) |
| 5. 이름 없는 변종 | 변종 시스템 / 흔적 추적 / 유니크 드롭 | P2 (P1 진입점 일부) |

다섯 시드는 서로 **결합한다.** §8의 상호작용 표 참조.

## 2. 시드 스토리 공통 양식

모든 시드는 같은 양식으로 기술. 작성자는 이 양식의 각 칸을 채우면 된다. (06에서 본 양식을 추상화한 가이드로 분리 예정.)

```
ID:                    영문 스네이크 케이스, 영구 식별자
시그니처:              한 줄로 "이 시드가 시연하는 것"
배경:                  세계 안에서 일어난 사실, 플레이어 모름
진입점 (Multiple):     1~N개, 각 진입점은 위치·감각 단서·필요 행동
비트 분해:             Whisper/Tremor/Quake 각 단계
인과 사슬:             parents · children · Resolved 후 children 자동 생성
페이로드:              spawner / interactable / env modifier
가시 흔적:             플레이어가 볼 수 있는 시각·청각 단서
누적 feature 연결:     이 시드가 어떤 누적 시스템을 갱신하는가
우회 시나리오:         진입점 중 일부만 만남 / 모두 우회 시 거동
다른 시드와의 연결:    상호 결합 가능성
```

## 3. SEED 01 — 상류 폐허 (RUIN_UPSTREAM_01)

### 시그니처
첫 1시간의 중심 비트. 부상 NPC·표류 시신·산 정상 조망 세 진입점이 모두 상류의 같은 폐허로 수렴한다. 시혜 토큰 발급, Tremor→Quake 사슬, 다중 진입점이 한 시드에 압축되어 있다.

### 배경
강 상류, 산기슭에 가까운 곳에 작은 폐허가 있다. 한때는 채집민의 임시 거주지였다. 며칠 전, 산에서 내려온 짐승 한 마리에게 습격당했다. 일부 생존자가 강을 따라 하류로 도피했고, 일부 시신이 강에 떠내려왔다. 폐허의 윤곽은 산 정상에서 멀리 보인다. 짐승은 아직 폐허 근처에 머무른다.

**플레이어는 위 사실을 모른다.** 흔적과 만남을 통해 점진적으로 재구성한다.

### 진입점 (3개)

**진입점 A — 강가의 부상 NPC**
- 위치: 강 회랑의 시작 풀숲 쪽, 강가 갈대밭
- 감각: 풀숲을 지날 때 약한 신음 소리 (Whisper 청각 단서)
- 필요 행동: 의식 없는 NPC를 발견 → "회복" 액션
- 회복 후: NPC가 짧게 깨어남. "상류에서... 짐승이..." 토막 정보. 다시 의식 잃음 또는 따라옴 (플레이어 의지)

**진입점 B — 산 정상 조망**
- 위치: 산 정상의 조망 액션 (SEED 04와 공유)
- 감각: 정상에 도달했을 때, 강 상류 쪽으로 무너진 건물 윤곽이 시야에 들어옴
- 필요 행동: 조망 액션 수행 → 지도 단편에 폐허 위치 표시

**진입점 C — 풀숲 깊은 곳의 까마귀 떼**
- 위치: 강 하류의 풀숲 깊은 곳, 강가
- 감각: 까마귀의 군집 울음 (Whisper 청각)
- 필요 행동: 접근 → 표류한 시신을 발견. "조사" 액션으로 상류 출신임을 단서로 인지

### 비트 분해

| 단계 | tier | 내용 |
|---|---|---|
| 0 | Whisper × 3 | 신음 / 멀리 보이는 윤곽 / 까마귀 울음 (각 진입점) |
| 1 | Tremor | 어느 한 진입점이라도 만나면 활성화 — 상류 방향성 단서 누적, 강 상류에 안개 가중치 추가 (시야 차단으로 미지감) |
| 2 | Quake | 폐허에 도달, 짐승과 만남 (전투 또는 도주), 폐허 내부 조사 완료 |

### 인과 사슬

```
parents: []  (시작 비트)

children (Quake 결과별):
  - heal_token_traveler        — 진입점 A에서 회복했을 때 1회 발급
  - rescue_token_survivors     — 폐허 내부에서 추가 생존자 구조 시 2회 발급
  - codex_entry_ruin           — 폐허 도감 항목 영구 등록
  - codex_entry_predator       — 짐승 도감 항목 등록 (NAMELESS_VARIANT_01과 공유)
  - permanent_naming_predator  — 짐승 처치자가 변종에게 이름 부여 (NAMELESS_VARIANT_01의 영구 명명권 트리거)
  - upstream_journal_fragment  — 폐허에서 일지 단편 1개 발견 (DRIFTING_JOURNAL_01의 단편 풀에 합류)
```

### 페이로드

- **spawner**
  - `wounded_traveler` — 강가 부상 NPC, Authored
  - `drifted_corpse` × 2 — 강 하류 표류 시신
  - `carrion_crows` — 시신 주변 까마귀 떼
  - `predator_beast` — 폐허 내부에 머무는 짐승 (SEED 05의 변종 함수 호출)
  - `cowering_survivor` × 1 — 폐허 내부 살아남은 생존자 (조건부)
- **interactable**
  - `heal_action` (NPC 회복)
  - `corpse_investigate` (시신 조사 → 상류 단서 텍스트)
  - `ruin_entrance` (폐허 입구, 진입 후 내부 region 로드)
  - `rescue_action` (생존자 구조)
- **env modifier**
  - 강 상류 영역에 안개 가중치 +30% (시야 차단으로 미지감 강화)
  - Tremor 활성화 동안만 적용, Quake로 Resolved되면 해제

### 가시 흔적

- **하류 → 상류 점진적 누적**: 표류물(부서진 가구 조각, 옷가지)이 강을 따라 점점이. 상류로 갈수록 빈도 증가.
- **폐허 주변**: 까마귀 밀도 ↑, 풀밭에 끌린 자국 (짐승이 시신을 끌고 다닌 흔적)
- **폐허 내부**: 핏자국, 부서진 도구, 뒤집힌 가구

### 누적 feature 연결

- **감사 토큰**: 부상자 회복 1개 + 생존자 구조 2개 (도구별 발급)
- **도감**: 폐허(장소), 변종 짐승(종), 새로 만난 NPC(인물) 세 항목 영구 등록
- **명명권**: 짐승 처치 시 SEED 05의 변종 명명권이 본 시드에서 트리거 가능 (시드 결합)
- **지도 단편**: 진입점 B를 통해 폐허 위치 단편 갱신
- **지식 단서**: 폐허에서 발견한 일지 단편이 SEED 03 풀에 합류

### 우회 시나리오

| 우회 패턴 | 거동 |
|---|---|
| 진입점 A만 만남 + 부상자 무시 | Tremor 활성화 안 됨. 부상자는 일정 시간(~10분 게임시간) 후 사망. 시신이 표류물로 합류 → 진입점 C로 재진입 가능 |
| 진입점 B만 만남 + 폐허 미방문 | 지도 단편만 표시. Tremor 활성화는 됨 (시각 단서가 Tremor 트리거에 포함됨). 다른 플레이어/세션에서 재방문 가능 |
| 진입점 C만 만남 + 시신 조사만 | 단서만 누적. 상류 추적 안 하면 비트는 결국 만료. 단, 짐승은 폐허에 계속 머무름 |
| 모든 진입점 우회 | 비트 미발생. 폐허는 그대로 남음. 다른 세션 또는 일정 시간 후 다른 진입점으로 재시도 가능 |

**핵심 원칙**: 어떤 우회 시나리오에서도 게임이 망가지지 않는다. 우회 = 손해가 아닌, **이 시드의 자식 비트(감사 토큰, 명명권, 도감 항목)를 못 받음**. 후속 시드들은 자기들의 진입점으로 따로 작동.

### 다른 시드와의 연결

- **SEED 05 (NAMELESS_VARIANT_01)**: 폐허의 짐승이 바로 그 변종이다. 본 시드의 Quake가 SEED 05의 만남 진입점 중 하나로 동작 — "발자국을 추적하기 전에 우연히 마주친다"는 경로.
- **SEED 03 (DRIFTING_JOURNAL_01)**: 폐허 내부의 일지 단편이 일지 풀의 마지막 조각이 됨.
- **SEED 04 (PEAK_VISTA_01)**: 진입점 B는 SEED 04를 거치지 않으면 사용 불가. 산 정상에 먼저 오르는 경로의 자연스러운 보상.

## 4. SEED 02 — 들불 사슬 (WILDFIRE_CASCADE_01)

### 시그니처
환경 인과의 순수 시연. L2의 가뭄 상태와 산 정상의 번개(확률적)가 모든 비트를 자동 트리거. 플레이어는 "사건의 관찰자"이자 "선택적 개입자". Quake 이후 영구 변형 지형이 발생하고, 그 자리에 새로운 변종(불에 적응한 종)이 시드된다.

### 배경
풀숲 바이옴의 단일 계절이 늦여름이라 가정한다(03 §5에서 미해결로 남은 항목, 본 시드가 늦여름을 권장하는 근거 중 하나). 가뭄이 일정 시간 지속되면 풀숲의 마른 잎이 발화 가능 상태로 진입. 산 정상에서 번개가 칠 때(확률적, 결정적 시드 함수) 점화. 들불이 풀숲 일정 영역을 덮으며 번지고, 동물 군집이 강가로 도주한다. 산기슭까지 번지면 동굴 입구가 일시적으로 봉쇄된다. 들불이 잦아든 후, 그을린 풀숲 자리에 불에 적응한 변종 식물·곤충이 시드된다.

### 진입점 (3개)

**진입점 A — 연기 냄새**
- 위치: 점화 지점에서 반경 200m 내 풀숲
- 감각: 마른 잎이 타는 냄새 (Whisper 후각/시각 — 약한 회색 안개)
- 필요 행동: 냄새 방향으로 이동 → 점화 지점 발견

**진입점 B — 산 정상 화재 연기**
- 위치: SEED 04와 공유 (산 정상)
- 감각: 정상에서 보이는 회색 연기 줄기
- 필요 행동: 조망 액션 → 화재 위치 지도 단편 갱신

**진입점 C — 동물 도주 무리**
- 위치: 도주 경로 어디서나 (점화 지점 → 강가 방향)
- 감각: 풀숲에서 일제히 한 방향으로 달리는 토끼·여우·작은 사슴 떼
- 필요 행동: 무리를 관찰하면 방향 추적 가능. 또는 무리에 합류해 강가로 가면 강가 모임 비트로 전환

### 비트 분해

| 단계 | tier | 내용 |
|---|---|---|
| -1 | (L2 상태) | 가뭄 지속 N시간 (자동 누적) |
| 0 | (L2 이벤트) | 산 정상에 번개 (확률적, 결정적 시드) |
| 1 | Whisper × 3 | 연기 냄새 / 산 정상 연기 / 동물 도주 |
| 2 | Tremor | 들불 확산 — 영역 표시 + hazard 활성화 |
| 3 | Quake | 영역 폐허화 또는 진압 |
| 4 | (자동 children) | 폐허화 영역에 변종 식물·곤충 시드 활성화 |

### 인과 사슬

```
parents: [L2.가뭄_지속, L2.번개_발생]

children (Quake 결과별):
  - permanent_terrain_patch_burnt   — 영역 L1 patch (그을린 풀숲)
  - fire_variant_flora_spawn        — 변종 식물 시드 (P2 콘텐츠)
  - codex_entry_wildfire            — 사건 도감 등록 (일자, 영역, 진압 여부)
  - gratitude_for_animal_guidance   — 동물 무리를 안전 영역으로 인도 시 (인접 NPC 목격 조건)
  - signpost_wildfire_site          — 사건 발생지에 자동 명판 (Quake 후)
```

### 페이로드

- **spawner**
  - `fleeing_animals` — 도주 동물 떼 (방향 결정적)
  - `carrion_crows` — 폐허화 후 몰려옴
  - `firewall_hazard` — 들불 자체 (환경 hazard, 접촉 시 체력 감소)
- **interactable**
  - `water_bucket_action` — 강에서 물 길어 진압 (반복 필요)
  - `firebreak_action` — 풀숲을 베어 방화선 구축 (도구 필요)
- **env modifier**
  - 시야 감소: 영역 전체 -50% (연기)
  - 체력 감소: 화재 영역 내 지속 -1/초
  - 산기슭 통행 제한: 들불이 산기슭 도달 시 동굴 입구 일시 봉쇄

### 가시 흔적

- **점화 전**: 마른 잎의 누런빛 (Whisper 시각, L2의 가시화)
- **확산 중**: 연기 기둥이 멀리서 보임 (권장 경로 시그널의 일종 — 자연스럽게 사건 위치 어필)
- **확산 후**: 그을린 풀숲이 영구 남음. 이후 변종 식물 시드가 자라면서 외형이 변함

### 누적 feature 연결

- **영구 변형 지형**: Quake 후 L1 patch. 다른 플레이어/세션에서도 영구 가시.

- **감사 토큰**: 동물 무리 인도 또는 진압 협력 NPC가 있을 때 발급
- **명판**: Quake 후 사건 발생지에 자동 명판 (위치, 일시, 진압자 이름)

### 우회 시나리오

| 우회 패턴 | 거동 |

| 모든 진입점 무시 | 자연 진압(시간 경과 + 강의 비, L2 확률) 또는 폐허화 완료. Quake는 발생. 영구 변형도 진행. |

## 5. SEED 03 — 흘러내려오는 일지 (DRIFTING_JOURNAL_01)

### 시그니처
단서 누적 → 추리 → 위치 노출의 시연. Whisper 누적이 Tremor를 트리거하는 정통적 구조. 도감의 텍스트 항목이 단편적으로 채워지는 경험을 만든다.

### 배경
누군가가 강 상류 어딘가에서 일지 단편을 강에 흘려보내고 있다. 단편은 7개. 강을 따라 표류하며, 하류로 갈수록 빈도가 낮아진다. 작성자의 정체와 의도는 단편의 누적 내용으로 점진적 노출.

작성자의 후보 정체(시드 결합에 따라 달라짐):
- (a) SEED 01의 폐허 생존자 — 가장 일반적
- (b) SEED 05의 변종에 쫓기는 다른 모험가
- (c) 폐허 사건과 무관한 제3의 인물 — 더 깊은 미스터리 (P2 확장에서 추가)

### 진입점 (1개, 누적형)

**단편 1번 발견** — 강가 표류물 사이에서 발견. 짧은 텍스트. 도감에 단편1 등록.

(이후 단편들은 자동 진입점이 아니라 누적 보상. 플레이어가 강가에 자주 노출되면 자연스럽게 누적.)

### 비트 분해

| 단계 | tier | 내용 |
|---|---|---|
| 0 | Whisper × N | 단편 1~6 발견 (N개 누적) |
| 1 | Tremor | 단편 N≥4 누적 시 활성화 — 작성자 위치의 대략적 지표가 도감에 표기 |
| 2 | Quake | 단편 7 발견 + 작성자 위치 도달 |

단편 N의 임계치는 결정적 (시드 함수). 본 시드는 N=4를 권장하지만 데이터 튜닝 가능.

### 인과 사슬


### 페이로드

- **spawner**
  - `journal_fragment` × 7 — 강가 결정적 위치에 배치 (시드 함수로 위치 결정)
  - `journal_author` — 단편 7과 같은 위치에 작성자 (조건부, 시드 결합에 따라 생존/사망)

  - `journal_read_action` — 단편 읽기 → 도감에 텍스트 추가
  - `author_dialogue` — 작성자와 대화 (생존 시)

### 가시 흔적

- 강가 표류물 사이에 약간 다른 색의 병 — 일부러 눈에 띄게.

- **명명권**: 무명 작성자에 도달한 첫 플레이어가 명명
- **감사 토큰**: 생존 작성자와의 만남에서 발급 (작성자가 도움받았다고 느낄 때)

## 7. SEED 05 — 이름 없는 변종 (NAMELESS_VARIANT_01)

### 시그니처
변종 시스템의 시연. 흔적 추적 → 위치 발견 → 처치 → 명명권 + 유니크 드롭의 정통적 사슬. P2의 핵심 feature가 P1 첫 1시간에도 한 번은 등장하도록 본 시드를 P1/P2 경계에 배치.

### 배경
풀숲의 어떤 종(권장: 늑대)이 결정적 변이를 거쳐 변종으로 출현. 변종은 같은 종보다 강하고, 외형(예: 한쪽 눈이 흰색)·행동(예: 단독 사냥)이 다르다. 자기 영역을 가지며, 영역 안에 발자국·사냥 흔적이 남는다. 같은 좌표·같은 환경 시드라면 어느 세션에서든 같은 변종이 출현 — 명명권이 의미를 갖는 결정성 보장의 시연.

본 시드의 변종은 SEED 01의 폐허 짐승과 **동일 개체**다. 두 시드의 결합으로 폐허 시드를 만나지 않은 플레이어도 본 변종을 만날 수 있다.

### 진입점 (3개)

**진입점 A — 발자국**
- 위치: 깊은 풀숲의 결정적 위치
- 감각: 풀숲 바닥에 큰 발자국 — 일반 늑대보다 크고 다른 형태
- 필요 행동: 조사 액션 → 도감에 흔적 등록, Whisper 누적

**진입점 B — 사냥 흔적**
- 위치: 변종 영역 내부, 풀숲 또는 풀밭 경계
- 감각: 뜯긴 짐승 시신 (토끼·여우 등 작은 종)
- 필요 행동: 조사 → 변종의 식성·체격 정보

**진입점 C — 폐허에서 직접 만남**
- 위치: SEED 01의 폐허 내부
- 발생: SEED 01의 Quake에서 자동 합류

### 비트 분해

| 단계 | tier | 내용 |
|---|---|---|
| 0 | Whisper × N | 발자국·사냥 흔적 N개 누적 |
| 1 | Tremor | 흔적 N≥3 시 변종 영역의 대략적 지표가 지도에 표기 |
| 2 | Quake | 변종 발견 → 처치 또는 도주 |
| 3 | (Quake children) | 처치 시 명명권·유니크 드롭. 도주 시 다른 영역에 재출현 (Tremor 재활성화) |

### 인과 사슬

```
parents: []  또는  [RUIN_UPSTREAM_01]  (시드 결합 시)

children (Quake 결과별):
  - permanent_naming_variant         — 변종 명명권 (영구)
  - unique_drop_variant              — 유니크 아이템 1개
  - codex_entry_variant              — 변종 도감 항목 (외형·행동·드롭)
  - tool_evolution_trigger_combat    — 도구 진화 트리거 (P2 도구 시스템)
  - migration_to_new_region          — 도주 시 다른 영역에 재시드 (Tremor 재활성화)
```

### 페이로드

- **spawner**
  - `predator_beast_variant` — 변종 함수로 결정된 외형·행동·체력·드롭의 개체
  - `prey_carcass` × N — 사냥 흔적용 시신
- **interactable**
  - `track_investigate` — 발자국 조사 (도감 갱신)
  - `carcass_investigate` — 시신 조사 (식성 정보)
  - `engrave_variant_name` — 처치 후 명명 액션 (1회만)

### 가시 흔적

- **풀숲 깊은 곳**: 발자국 - 시각 단서. 같은 좌표라면 어느 플레이어든 같은 발자국을 본다.
- **영역 경계**: 찢긴 풀, 부서진 가지 (영역 표시)
- **사냥 흔적**: 시신 — 까마귀와 결합 가능 (SEED 01의 까마귀 떼와 시각적 통합)

### 누적 feature 연결

- **변종 시스템**: 결정적 변이 함수의 첫 사용. 같은 좌표·같은 시드 → 같은 변종.
- **명명권**: 변종 이름이 서버에 영구 기록. 다른 플레이어가 도감에서 보면 명명자 이름과 함께 등록.
- **유니크 드롭**: 본 변종 처치 시 1회 드롭. 동일 변종 재출현 시 드롭 없음.
- **도구 진화**: 변종 처치가 진화 트리거 (P2 시스템)
- **도감**: 변종 외형·행동·드롭 항목 영구 등록

### 우회 시나리오

| 우회 패턴 | 거동 |
|---|---|
| 흔적 무시 | 변종은 자기 영역에 머무름. 다른 플레이어 추적 가능. |
| 추적 + 도주 (변종이 도망) | 다른 영역에 재시드. Tremor 재활성화. 명명권은 다음 처치자에게. |
| SEED 01 Quake에서 우연 만남 | 흔적 추적 없이 변종 만남. 흔적 도감 항목은 미등록 — 회수 가능 |
| 모든 우회 | 변종은 그대로. 다른 세션에서 재시도 가능. |

### 다른 시드와의 연결

- **SEED 01**: 가장 강한 결합. 폐허 짐승 = 본 변종. 처치자가 양 시드의 Quake를 동시 완수.
- **SEED 02**: 들불로 영역 폐허화 시 변종 이주. 다른 영역에 새 흔적 시드 자동 발생.
- **SEED 03**: 일지 단편에 변종 흔적 언급 가능 — 본 시드의 사전 단서 역할.

## 8. 시드 스토리 간 상호작용

### 8.1 결합 매트릭스

각 행 시드가 각 열 시드에 어떻게 영향을 주는가.

| ↓이 ┃ →에게 | SEED 01 폐허 | SEED 02 들불 | SEED 03 일지 | SEED 04 정상 | SEED 05 변종 |
|---|---|---|---|---|---|
| **SEED 01** | — | (영향 없음) | 폐허 단편이 일지 풀에 합류 | (영향 없음) | **폐허 짐승 = 변종** |
| **SEED 02** | 폐허 단서 일부 소실 (시간 압박) | — | (영향 없음) | (영향 없음) | 변종 이주 트리거 |
| **SEED 03** | (영향 없음) | (영향 없음) | — | 정상 단서 제공 | 변종 사전 언급 |
| **SEED 04** | 진입점 B 활성화 | 진입점 B 활성화 | (영향 없음) | — | (영향 없음) |
| **SEED 05** | 변종 명명권이 양 시드 공유 | (영향 없음) | (영향 없음) | (영향 없음) | — |

### 8.2 결합이 만드는 경험

- **정상부터 가는 플레이어**: SEED 04 먼저 → SEED 01 진입점 B 및 SEED 02 진입점 B 동시 활성화 → 빠른 다중 비트 진입 (정보 과부하 주의, AI 동적 드롭이 페이스 조절)
- **강가부터 가는 플레이어**: SEED 03 단편 수집 → SEED 01 진입점 A or C → 단편 7에서 작성자 발견 + 폐허 도달 (자연스러운 사슬)
- **들불을 먼저 만나는 플레이어**: SEED 02 진입 → 동물 도주 따라가다가 강가 도착 → SEED 01 진입점 A 또는 C 자연 접근
- **모든 진입점 우회**: 1시간 권장 시간 내 어느 시드도 활성화 안 함. 가능. 단, 다음 세션에서 시드는 그대로 — 풀숲은 정지된 게 아니라 **누락된 채로 지속**.

### 8.3 우선순위 충돌

03 §3.3의 충돌 처리 규칙이 본 시드들에 어떻게 적용되는지.

- **SEED 01 진입점 A의 부상 NPC** vs **SEED 02의 들불 도주 동물**: 같은 시공간에 둘 다 위치 가능. 들불이 부상 NPC 위치까지 번지면 NPC 사망 — 시간 압박.
- **SEED 05의 변종**이 SEED 02의 들불로 영역 잃음: 변종이 다른 영역으로 이주. 본 위치의 흔적 시드는 폐허화로 소실. 새 영역에 흔적 재생성.
- **SEED 04의 명판**이 다른 비트로 손상될 수 있나? 정상은 영구 변형 금지 영역(높이 한계). 본 게임 어떤 비트도 정상 명판을 덮지 못함.

## 9. 본 문서가 미룬 항목

후속 문서·세션에서.

- **시드 스토리 추가 작성** — 본 5개는 첫 1시간 + Phase 1~2 절반. P2 후반·P3·P4용 시드 추가 필요 → 08 후보
- **시드 작성 양식 가이드** — 본 문서의 양식을 작성자용 템플릿으로 분리 → 06 후보
- **권장 경로 시그널 배치 규칙** — 본 5개 시드의 진입점들이 절차 생성 지형에서 어떻게 배치되는가 → 07 후보
- **NPC 대화 트리의 실제 텍스트** — 부상 NPC, 폐허 생존자, 일지 작성자의 대화 라인
- **일지 단편의 실제 텍스트** — 7개 단편 각각의 문장
- **변종 변이 함수의 변이 차원** — 외형의 어떤 축이 어떻게 변하는가
- **명판의 표기 양식** — 명명자·일시·사건이 어떻게 새겨지는가
- **AI 동적 드롭이 본 시드들의 보상 페이스를 어떻게 조절하는가**

## 10. 다음 단계 권장

본 5개 시드는 Phase 1의 **첫 1시간 본격 콘텐츠**를 시연한다. 검증 지점은 다음과 같다.

**검증 1: 첫 1시간 플레이어가 5개 시드 중 몇 개를 만나는가?**
- 권장 경로(강가→정상): SEED 01, 03, 04 만남 가능, 05는 SEED 01의 Quake에서 자동 결합
- 산부터 경로(정상→하산): SEED 04 먼저, SEED 01·02 진입점 B 활성화
- 어떤 경로든 **3개 이상 시드 만남**이 목표

**검증 2: 우회한 플레이어가 다음 회차에서 새로 만나는가?**
- 시드는 결정적 위치에 있으므로 우회 후 재시도 시 그대로 존재
- Phase 2 변종 시드 갱신이 추가되면 재방문 동기 추가

**다음 작업 권장 순서:**

1. **06 — 시드 스토리 작성 양식 가이드**
   본 문서의 양식을 추상화. 카테고리·기재 항목·결합 규칙을 작성자용 템플릿으로 분리. 본 5개 외 추가 시드 작성자가 이를 참조.

2. **07 — 권장 경로 시그널 배치 규칙**
   본 5개 시드의 진입점이 절차 생성 지형에서 어떻게 결정적으로 배치되는지의 규칙. 03 §4.2의 자연스러운 배치를 본 시드들에 구체화.

3. **08 — Phase 2 확장 시드 스토리**
   본 문서의 5개 외에 P2의 핵심 feature(시드 갱신, 도구 진화 1단계, 흔적 시스템 본격 활용, 사회적 자본 초기) 시연용 시드 추가.

**우선 권장: 07.** 06은 본 양식이 5개 시드에 일관되게 적용되었음을 확인했으므로 추출 위험이 낮다. 07은 본 시드들이 실제 지형 위에 결정적으로 배치되어야 작동하므로 가장 시급. 07이 작성되면 본 시드들이 풀숲의 실제 위치에 못 박힌다.
