## 사고의 흐름

```
[방향성 문서: 게임 비전 + 4 Pillars]
        ↓
   [주제 제시: "강과 산이 있는 풀숲" Terrain Story]
        ↓
   [문서 1] 이 문서가 무엇인지 정의
        - 분기 질문: 바이옴 템플릿(A) vs 첫 바이옴(B) vs 둘 다
        - 결정: A+B 둘 다
        - 공통 사고 프레임 5단계 제시
        ↓
   [문서 2] 시스템 골격 설계 (1차)
        - 기능 분해 (풀숲/강/산의 어포던스)
        - HktStory 3-Tier (Whisper/Tremor/Quake)
        - 3종 Spawner (Environmental/Emergent/Narrative)
        - 가치 충돌 해소 규칙
        - 6-레이어 모델 (L1~L6)
        - 끝에 4개 결정 필요 항목 제기
        ↓
   [문서 3] 확정 사양 반영 및 재설계
        - 결정: 1시간 스케일 / 단일 계절 / Hybrid 생성 / 권장+우회
        - 5개 서브-바이옴 도입 (스케일 확장의 귀결)
        - L5 Beat 공통 인터페이스 설계
        - 첫 1시간 시퀀스 (다중 진입점 구조)
        ↓
   [문서 4] Feature 확장 및 단계별 로드맵
        - 03이 암시만 하고 정의 안 한 영역 진단
        - 광범위 feature 브레인스토밍 (도구/도감/시혜/변종/명명권/AI 드롭/영속성)
        - 4 Pillar × L1~L6 매핑
        - 신규 가치 충돌 5개 해소
        - Phase 1(MVP) → Phase 4(다음 바이옴) 로드맵
        ↓
   [문서 5] 풀숲 L6 시드 스토리 (5개)
        - SEED 01 상류 폐허 — 시혜 토큰 / 다중 진입점 / Tremor→Quake
        - SEED 02 들불 사슬 — 환경 인과 / 영구 변형 / 변종 시드
        - SEED 03 흘러내려오는 일지 — 단서 누적 / 도감 텍스트 / 추리
        - SEED 04 정상의 조망 — 발견 보상 / 명명권 / 지도 단편 일괄
        - SEED 05 이름 없는 변종 — 변종 시스템 / 흔적 추적 / 유니크 드롭
        - 시드 결합 매트릭스 (다섯 시드가 어떻게 서로 영향을 주는가)
        ↓
   [문서 7] 시그널 배치 규칙 (06을 건너뜀 — 배치가 양식보다 시급)
        - 시그널 4단계 어휘 S1~S4 (즉시/단거리/중거리/지평선)
        - 시작 지점의 결정적 정의 + S1 시그널 4개 자동 배치
        - 5개 시드 진입점 13개의 배치 방식 분류 (F/R/E/B)
        - 시드 간 위치 상호 의존성 그래프
        - 우회 경로 보장 명제 + 강 횡단 강제
        - 5개 서브-바이옴별 시드 분포 요약
        ↓
   [문서 6] 시드 작성 양식 가이드 (07 다음, 사례 추출 순서)
        - 11칸 필수 양식 + 진입점 5칸 양식
        - 시그널 S1~S4 / 배치 F/R/E/B 선택 가이드
        - 인과 사슬 children 양식 + 누적 feature 매핑
        - 자주 빠지는 항목 체크리스트
        - 05 5개 시드의 양식 적용 사례
        ↓
   [문서 9] 콘텐츠 텍스트 (P1)
        - SEED 01 부상 NPC·폐허 생존자 K 대화
        - SEED 03 일지 단편 7개 전문 + 작성자 K 분기
        - SEED 02 들불 진압 협력자 / SEED 04 정상 명판 양식
        ↓
   [문서 8] L6 시드 스토리 (P2)
        - SEED 06 화재 적응 변종 식물 (시드 갱신 + 식물 변종)
        - SEED 07 행상인의 레시피 (사회적 자본·NPC 기억·레시피북)
        - SEED 08 흔적의 정원 — 은둔자 (흔적 시스템 본격·도구 진화)
        - P1+P2 8개 통합 결합 매트릭스
        - P2 6개 feature 모두 시연 검증
        ↓
   [다음 문서 후보]
        - 09.x: P2 콘텐츠 텍스트 (행상인·은둔자 대화)
        - P3 시드 (영구 변형 본격, 서버 히스토리 가시화)
        - 두 번째 바이옴 시리즈 (A안 템플릿 검증)
```
