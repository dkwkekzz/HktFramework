## 1. 본 문서의 위치

05의 5개 시드가 P1을 시연했고, 04의 Phase 2 단계는 다음 feature가 P2의 콘텐츠 완성도를 정의한다고 명시했다.

| P2 핵심 feature | 시연 필요 |
|---|---|
| 변종 시스템 (시드 갱신 포함) | SEED 05는 단일 변종. **시간 경과 후 새 변종이 시드되는 시연** 필요 |
| 명명권 (변종/지역/사건) | SEED 04·05에서 첫 사용. **N-th 발견자 보상**과 결합된 시연 필요 |
| 흔적·단서 시스템 | SEED 03·05에서 일부 사용. **추리의 본격 시연** 필요 |
| 도구 진화 1단계 | 04에서 정의만 됨. **실제 트리거 시드** 필요 |
| 레시피북 | 04에서 정의만 됨. **조합 발견형 시드** 필요 |
| 사회적 자본 / NPC 기억 | 04에서 정의만 됨. **재회 NPC 시드** 필요 |

본 문서의 3개 시드가 위 6개 feature를 모두 시연하면 P2 콘텐츠 MVP 완성.

## 2. P2 시드 배치 전략

P1의 5개 시드가 풀숲 첫 1시간의 척추라면, P2의 3개 시드는 **시간 경과·반복 플레이 진입 시** 자연스럽게 노출되는 시드들. 따라서 본 3개 시드는 다음 조건을 만족하도록 설계.

- **P1 시드의 결과가 본 P2 시드의 진입 조건**이 됨 (SEED 02 들불 → SEED 06 변종 식물)
- **재방문 또는 시간 경과**가 시드 활성화의 키 (SEED 07 행상인의 일시 캠프)
- **P1 시드와 결합되어 더 깊은 인과 사슬을 만듦** (SEED 08 은둔자가 SEED 07과 관계)

## 3. SEED 06 — 화재 적응 변종 식물 (FIRE_VARIANT_FLORA_01)

### 시그니처
SEED 02의 영구 변형 영역에 시드되는 변종 식물. **시드 갱신 + 변종 식물**의 시연. P3의 영구 변형 결과가 P2의 새 콘텐츠가 되는 흐름의 정통 사례.

### 배경
들불이 진화한 후 그을린 풀숲 영역에 새 식물이 자란다. 일반 식물과 다른 외형(검붉은 잎, 회색 줄기)과 다른 효능(독성 또는 약효, 결정적 변이). 들불 영역마다 다른 변종 — region 시드 + 들불 위치 시드의 함수. 영역 N개 = 변종 N종.

플레이어는 변종 식물을 수확하고, 다른 채집물과 조합해 **새 레시피를 발견**한다. 변종 식물의 효능은 처음에는 미지 — 수확해서 분석하거나 다른 재료와 섞어봐야 알 수 있음.

### 진입점 (1개)

**진입점 A — 그을린 풀숲의 검붉은 잎**
- 위치 region: SEED 02의 영구 변형 영역 (들불 폐허화 위치)
- 감각 단서: 시각 (검붉은 잎이 회색 풀숲과 대비)
- 필요 행동: 수확 또는 조사
- 시그널 단계: S1 (영역 안에서 시각)
- 배치 방식: B (SEED 02 영역에 묶임)

### 비트 분해

| 단계 | tier | 내용 |
|---|---|---|
| 0 | (전제) | SEED 02 Quake로 영역 폐허화 완료 |
| 1 | Whisper | 검붉은 잎 시각 발견 |
| 2 | Quake | 수확 액션 또는 분석 |
| 3 | (자동 children) | 레시피 발견 가능성 |

본 시드는 Tremor 생략 — SEED 04와 비슷한 가벼운 시드.

### 인과 사슬

```
parents: [WILDFIRE_CASCADE_01.permanent_terrain_patch_burnt]

children (Quake 결과별):
  - codex_entry_fire_flora        — 변종 식물 도감 등록
  - recipe_discovery_fire_flora   — 다른 채집물과 조합 시 레시피 잠금 해제
  - permanent_naming_fire_flora   — 식물 명명권 (변종 식물 단위)
  - tool_evolution_trigger_harvest — 변종 식물 수확 N회 시 낫 진화
```

### 페이로드

- **spawner**: `fire_variant_flora` × N (들불 영역마다 결정적 분포)
- **interactable**: `harvest_action` (수확), `analyze_action` (효능 분석)
- **env modifier**: 없음

### 가시 흔적

- 그을린 풀숲의 회색 줄기들 사이에 검붉은 잎 — 시각 대비로 발견 용이
- 수확 후 변종 식물의 줄기가 영역에 남음 (다음 방문 시 재출현 — 시드 갱신)

### 누적 feature 연결

- **발견·미지: 변종** — 식물 변종의 첫 등장. SEED 05는 동물 변종, 본 시드는 식물 변종.
- **발견·미지: 시드 갱신** — 들불 영역마다 다른 변종. 한 region에 들불이 N번 발생하면 N종 변종.
- **발견·미지: 명명권** — 식물 단위 명명권.
- **지식·도감: 도감 + 레시피북** — 식물 도감 + 효능 레시피 잠금 해제.
- **행동·도구: 도구 진화** — 수확 N회로 낫 진화 트리거.

### 우회 시나리오

| 우회 패턴 | 거동 |
|---|---|
| SEED 02 미진행 | 본 시드 미시드. P1에서는 만남 불가. |
| 영역 방문 안 함 | 변종 그대로 존재. 다른 플레이어 발견 가능. |
| 발견 + 수확 안함 | 도감 등록만, 레시피 미잠금. 재방문 시 회수 가능. |
| 수확 + 분석 안함 | 효능 미지. 도구 진화 트리거는 누적. |

### 다른 시드와의 연결

- **SEED 02 (완전 의존)**: parents.
- **SEED 03**: 일지 단편에 변종 식물 사전 언급 가능 — "산기슭 그을린 풀숲에 이상한 잎이 있었다..."
- **SEED 07 (행상인)**: 변종 식물이 레시피 재료. 행상인이 본 식물을 알아보고 추가 레시피 제공.

## 4. SEED 07 — 행상인의 레시피 (TRAVELING_MERCHANT_01)

### 시그니처
**사회적 자본 초기 + 레시피북 + NPC 기억**의 시연. 행상인이 풀숲을 떠돌며 일시적 캠프를 차린다. 플레이어의 감사 토큰·도감 진척에 따라 다른 레시피를 판매. 재회 시 NPC가 플레이어를 인식.

### 배경
풀숲을 떠도는 행상인 한 명. 강 회랑·산기슭·깊은 풀숲을 순회하며 시간대에 따라 다른 위치에 일시 캠프. 채집물·도구 부품을 판매·교환. 플레이어의 행적에 따라 다른 레시피를 제공:
- **기본 레시피**: 모든 플레이어에게 판매
- **감사 토큰 N개 보유 시**: 특수 레시피 1 (사회적 자본의 첫 시각화)
- **도감 일정 비율 달성 시**: 특수 레시피 2 (지식의 보상)
- **SEED 06 변종 식물 도감 등록 시**: 변종 식물 활용 레시피
- **재회 시**: 플레이어 인식 + 이전 대화 기억 + 신규 레시피 제공

### 진입점 (3개, 시간대 함수)

**진입점 A — 강 회랑 일시 캠프 (저녁 시간대)**
- 위치 region: 강 회랑
- 감각 단서: 시각 (멀리서 모닥불 연기 S3) + 청각 (음악 또는 짐승 소리)
- 필요 행동: 캠프에 접근 → 대화
- 시그널 단계: S3 (연기) → S2 (캠프 자체)
- 배치 방식: E (저녁 시간대 + 강 회랑 함수)

**진입점 B — 산기슭 일시 캠프 (낮 시간대)**
- 위치 region: 산기슭 전이대
- 감각 단서: 시각 (능선 위 작은 천막)
- 필요 행동: 접근 → 대화
- 시그널 단계: S3 → S2
- 배치 방식: E (낮 시간대 + 산기슭 함수)

**진입점 C — 깊은 풀숲 일시 캠프 (밤 시간대)**
- 위치 region: 깊은 풀숲
- 감각 단서: 청각 (모닥불 타닥거림 S2) + 시각 (풀숲 사이 작은 불빛)
- 필요 행동: 접근 → 대화
- 시그널 단계: S2
- 배치 방식: E (밤 시간대 + 깊은 풀숲 함수)

세 시간대를 순환하며 행상인 캠프가 이동. 같은 행상인, 다른 위치.

### 비트 분해

| 단계 | tier | 내용 |
|---|---|---|
| 0 | Whisper × N | 모닥불 연기 / 음악 / 작은 불빛 (시간대 따라 다른 진입점) |
| 1 | (Tremor 생략) | — |
| 2 | Quake | 행상인과 대화 + 거래 또는 떠남 |

### 인과 사슬

```
parents: []

children (Quake 결과별):
  - recipe_unlock_basic              — 기본 레시피 1개 (모든 플레이어)
  - recipe_unlock_gratitude          — 감사 토큰 N개 보유 시 특수 레시피 (예: 부상자 회복 보조약)
  - recipe_unlock_codex              — 도감 일정 비율 달성 시 특수 레시피
  - recipe_unlock_fire_flora         — SEED 06 변종 식물 도감 등록 시 변종 활용 레시피
  - npc_memory_merchant              — 행상인이 플레이어 인식 (재회 시 다른 대화)
  - permanent_naming_merchant_routes — N번째 만남 시 행상인의 순회 경로 명명 가능
```

### 페이로드

- **spawner**: `traveling_merchant`, `campfire`, `pack_animals`(×2~3)
- **interactable**: `trade_action`, `dialogue_action`
- **env modifier**: 캠프 반경 30m에 약한 안전 효과 (적대적 spawner 약화)

### 가시 흔적

- **시간대별 캠프**: 같은 시간대에 같은 location에 캠프 결정적 출현
- **순회 경로**: 충분한 만남 후 플레이어가 행상인의 순회 패턴 파악 가능 → 도감에 "행상인의 순회 경로" 항목

### 누적 feature 연결

- **사회·시혜: 사회적 자본** — 감사 토큰 N개 보유에 따른 분기 노출.
- **사회·시혜: NPC 기억** — 재회 시 인식. 첫 만남, 두 번째 만남, 충분한 만남 후 다른 대화.
- **지식·도감: 레시피북** — 4종의 잠금 해제 조건 (기본/감사/도감/변종).
- **지식·도감: 도감** — 행상인 NPC 항목 + 판매 아이템 항목.
- **발견·미지: 명명권** — 행상인의 순회 경로 명명.

### 우회 시나리오

| 우회 패턴 | 거동 |
|---|---|
| 캠프 미발견 (모든 시간대) | 행상인은 계속 순회. 재시도 가능. |
| 발견 + 거래 안함 | 행상인은 일정 시간 후 다음 location으로. 다른 시간대에 재출현. |
| 한 시간대만 만남 | 부분 거래. 다른 시간대 미체험. |
| 감사 토큰 없음 | 기본 레시피만. 특수 레시피 미잠금. |
| 도감 미달성 | 도감 보상 레시피 미잠금. |
| 모든 우회 | 행상인 미만남. P3에서 행상인 시드 갱신 가능 (다른 행상인 출현). |

### 다른 시드와의 연결

- **SEED 01의 감사 토큰**이 본 시드의 진척 입력. P1 진입점 A 부상자 회복 시 받은 토큰이 P2에서 의미를 가짐.
- **SEED 06**: 변종 식물이 본 시드의 레시피 재료.
- **SEED 08 은둔자**: 행상인과 은둔자가 서로 안다는 단서 (대화 분기로 표시).
- **부상 NPC M의 행방**: 행상인이 강 하류 마을에서 부상자를 구해줬다는 소문을 들음 → SEED 01·03의 인과 사슬 마무리.

## 5. SEED 08 — 흔적의 정원 (TRAIL_GARDEN_01)

### 시그니처
**흔적 시스템의 본격 시연**. 추리 사슬 + 도구 진화 트리거. 깊은 풀숲의 어떤 영역에 한 NPC가 의도적으로 단서를 남겼다. 단서를 모으면 거주지 위치 노출.

### 배경
깊은 풀숲의 한적한 영역에 한 NPC(은둔자)가 자기 거주지로 가는 길에 단서를 남겼다. 조각된 나무 표지, 풀숲에 묶인 끈, 돌 무지. 단서들은 의도적 — 누군가가 찾아오기를 바라며. 단서 5개를 모두 모으면 거주지 위치 노출.

은둔자는 한때 강 하류 마을 사람. 어떤 사건으로 마을을 떠나 깊은 풀숲에 칩거. 행상인이 그의 옛 친구. 플레이어가 행상인을 통해 은둔자의 존재를 알 수도 있고, 풀숲에서 우연히 단서를 발견할 수도 있음 (다중 진입 경로).

### 진입점 (1개, 누적형)

**진입점 A — 깊은 풀숲의 조각된 나무 표지**
- 위치 region: 깊은 풀숲
- 감각 단서: 시각 (나무에 새겨진 작은 기호)
- 필요 행동: 조사 액션
- 시그널 단계: S1 (가까이 갔을 때 발견)
- 배치 방식: R (깊은 풀숲 region 시드 함수)

단서 2~5번은 단서 1번에서부터 자연 경로를 따라 결정적 배치.

### 비트 분해

| 단계 | tier | 내용 |
|---|---|---|
| 0 | Whisper × 5 | 단서 1~5 누적 (조각된 표지 / 묶인 끈 / 돌 무지 / 흙길의 화살표 / 거주지 직전 표시) |
| 1 | Tremor | 단서 5개 누적 시 거주지 위치 도감 표기 |
| 2 | Quake | 거주지 도달 + 은둔자와 대화 |

### 인과 사슬

```
parents: []  또는  [TRAVELING_MERCHANT_01.npc_memory_merchant] (행상인과 충분한 대화 시 은둔자 사전 노출)

children (Quake 결과별):
  - codex_entry_hidden_dweller       — 은둔자 도감 등록
```

- **지식·도감: 도감 + 지식 단서** — 은둔자 항목 + 5개 단서 텍스트 누적.
- **발견·미지: 명명권** — 무명 은둔자에 대한 명명.
- **사회·시혜: 감사 토큰** — 발견 자체에 대한 보상.
