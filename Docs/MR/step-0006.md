> 상태: **명세(SPEC)** — 방향과 메커니즘을 확정하고 예비 검증(PoC)까지 수행했다. 본 검증·수치 표·회귀 증명은 구현 시 채운다.

## 0. 왜 이 step인가 — "처음에만 변하고 멈추는" 세계

step-0001~0005는 모두 **상수 source**(고정 위치·고정 rate의 외부 수도꼭지)를 깔고 돌았다. 그런데 상수 구동을 소산계에 넣으면 끌개는 **고정점**이다 — 도달하면 끝이다. 표준 시나리오를 8000 tick 돌리면(시드 42):

| 측정 | 초기(~t1000) | 정착 후(t3000~8000) |
|---|---|---|
| 생멸(births/deaths) | 활발 | **얼어붙음** (births=16, deaths=15 고정) |
| 사회 수 | 진동 | 1로 수렴 (경쟁 소멸) |
| field churn(구조 변화) | 27/tick | 6으로 단조 감소 |
| totalRho | — | **정확히 717.64 불변** |

더 부어도(source ×5), 임계를 낮춰도(thE↓) churn·발화만 폭증할 뿐(28431 발화/2k) 생멸은 0 — **"더 뜨거운 고정점"**일 뿐 살아있는 세계가 아니다. 자원을 고갈-재생하는 동적 장으로 바꿔도 consume/regrow 12조합 전부 **진폭 Δ=0**, 또 다른 고정점에 안착했다. 원인은 둘이 겹친다:

1. **상수 경계 + 전부 소산 법칙 → 고정점.** 모든 법칙(확산·이완·복사·소산)이 평형으로 미는 음의 되먹임이다.
2. **항상성이 과해 구조가 자기-불안정화를 못 한다.** `alive` 판정이 문자 그대로 `mass ≈ massEMA`(변하지 않을 것)를 요구하고, 응집이 덩어리를 강하게 붙잡아 굶어도 안 죽는다 → 개체수 붕괴 없음 → 회복 사이클 없음. step-0005 §5(2)의 *"사회가 스스로 너무 커져 터지는 내생적 재앙은 아직 안 봤다"* 가 정확히 이것이다.

에너지 흐름 문서([04-energy-flow](step-0001/04-energy-flow.md))는 *"source를 계속 공급하는 한 세계는 절대 정지하지 않고, 구조는 생기고 무너지길 반복한다"* 고 적었지만 — **그 주장은 발화(열적 떨림)에만 성립하고 구조(생멸)에는 거짓**임이 드러났다. step-0006은 이 간극을 메운다.

## 1. source의 재정의 — 발산은 *사건*이다, 상수가 아니다

유저의 통찰: 실세계에서 source에 해당하는 것은 **에너지 발산**이다. 태양은 영원한 수도꼭지가 아니라 **유한한 연료를 태우며 빛을 내는, 그 자체로 죽어가는 소산 구조**다. 발산이란 *축적된 기울기(질서·물질)를 가진 구조가 그것을 풀어내는 사건*이지, 무에서 솟는 상수 흐름이 아니다.

이 프레임은 이미 한 층 위에서 답을 갖고 있다 — [06-recursion](step-0001/06-recursion.md) line 47, step-0003의 발견:

> **"거시의 태양은 미시의 대사다."** 거시 층에는 외부 source가 따로 없다. 거시의 에너지 소득은 미시 사회들의 **대사(metabolism) = 발산**이다(승급/promotion).

즉 **모든 층의 source는 한 층 아래 구조의 발산이다.** 사회의 태양은 구성원(생명)의 대사고, 생명의 태양은 그 아래 무언가의 발산이다. 유일하게 *비물리적인* 조각은 **맨 아래의 상수 수도꼭지** 하나뿐이다. 그것만이 발산하는 구조가 아니라 영구기관이고, 그래서 그것이 먹인 세계가 그것과 함께 평형에 눌러앉는다.

**그렇다고 외부 source를 없애지는 않는다.** 닫힌 유한계는 열적 죽음(2법칙)으로 끝난다 — 태양은 생물권의 *바깥*에 있다. 외부 source는 물리적으로 필요한 "태양"으로 남긴다. 바뀌는 것은: **그 태양이 먹인 물질이 그냥 앉아있지 않고, 쌓여서 스스로 점화하는 2차 발산체(별)가 된다**는 것이다. 발산을 *사건화*하는 것 — step-0005가 발화를 사건화했듯이.

## 2. 메커니즘 — 점화(`ignite`): `threshold`의 거울

새 법칙이 아니다. 기존 임계 법칙([03-4] `threshold`)의 **정확한 거울 연산자** 하나다.

| | `threshold` (기존, E에 작용) | **`ignite` (신규, rho에 작용)** |
|---|---|---|
| 방아쇠 | `E[i] > thE` (에너지 과잉) | `rho[i] > thIgn` (물질 과잉) |
| 작용 | E를 방출(`E*=0.3`), 이웃 E + 국소 T로 분배, **rho를 흩음** | rho를 태움(`rho -= fuel`), **E로 변환**, 이웃 E + 국소 T로 분배 |
| 의미 | 에너지가 너무 모이면 → 폭발하며 **물질을 흩는다** | 물질이 너무 모이면 → 점화해 **에너지를 낸다 = 별** |
| 방향 | E → (T, 흩어진 rho) | rho → (E, T) |

둘은 (E, rho) 쌍에 대한 쌍대(dual)다. 하나는 에너지 과잉이 물질을 흩고, 하나는 물질 과잉이 에너지를 낳는다. **`ignite`가 곧 "에너지 발산"의 미시 구현**이다 — 물질(쌓인 질서)이 에너지로 풀린다.

```js
// [03-5] 점화: rho 과잉 → E 발산 (별의 탄생). threshold 의 거울.
function ignite(sim, thIgn, burnFrac, massToE, spread) {
  const { N, M, rho, E, T } = sim; let conv = 0;
  for (let i = 0; i < M; i++) {
    if (rho[i] <= thIgn) continue;
    const fuel = rho[i] * burnFrac;            // 태울 물질
    rho[i] -= fuel;
    const released = fuel * massToE;           // 물질 → 에너지 (massToE = 이득 계수, E=mc² 의 역할)
    conv += released;
    const x = i % N, y = (i / N) | 0, ns = [];
    const p = (nx, ny) => ns.push(((ny + N) % N) * N + ((nx + N) % N));
    p(x+1,y); p(x-1,y); p(x,y+1); p(x,y-1);
    E[i] += released * (1 - spread);           // 국소 + 이웃으로 발산
    for (const n of ns) E[n] += released * spread / ns.length;
    T[i] += released * 0.1;                    // 발산에 따르는 열
  }
  if (conv) sim.injectedTick += conv;          // rho→E 변환분은 E 장부의 주입 (닫힌 장부)
}
```

**닫힌 장부 / 보존.** `massToE`는 보존 계수가 아니라 **이득(gain)**이다 — 물질이 *저장된 에너지 저수지*이고 점화가 그것을 푼다(E=mc²). 이는 프레임의 기존 패턴 그대로다: 승급의 `cE=3.0`(대사→E₂ 소득), 하향 채널의 `wDown`(거시 발화→미시 T)이 모두 *각 층 장부를 닫는 이득 결합*이었다. `ignite`도 동일 — `injectedTick`에 기록해 E 장부를 닫는다. (rho는 더 이상 전역 보존량이 아니다 — 태워 없어진다. 필요하면 `burnedTotal` 장부를 따로 둬 회계한다.)

**회귀 조건.** `thIgn = ∞`(점화 off)이면 `ignite`는 아무 일도 안 하므로 **step-0005와 비트 단위 동일**해야 한다 (`reg`/`regc`로 증명). step-0005의 모든 수치가 그대로 재현되어야 통과.

**tick 순서.** [07] 고정 순서에서 `threshold`(E 임계) 바로 뒤에 `ignite`(rho 임계)를 둔다 — 둘 다 "임계 = 사건" 단계.

## 3. 검증 질문

> ① **별의 탄생**: rho가 자기 응집으로 점화 임계를 넘어 *스스로* 발산체가 되는가 (외부 손 없이)?
> ② **별의 죽음**: 연료(rho)가 고갈되면 발산이 멈추고 그 자리가 암흑이 되는가 (발산체는 죽는가)?
> ③ **영구 비평형(핵심)**: 점화→소진→암흑→재축적 사이클이 **고정점 대신 한계순환**을 만들어, 0절의 freeze(후반 생멸=0)가 풀리는가?
> ④ **보존**: rho→E 변환에서 E 장부 잔차가 ~1e-6를 유지하는가 (`massToE` 이득이 누수가 아님)?

여기에 step-0005가 남긴 화살표도 자연히 닿는다 — ②(별의 죽음 = 그것이 먹이던 사회의 **기근·암흑**)는 *내생적 재앙*이다. step-0005는 재앙에 외부 flare가 필요했지만(§5(2)), 점화-소진 사이클은 **재앙을 내생화**한다.

## 4. 예비 검증 (PoC) — freeze가 풀린다

step-0005 코어에 위 `ignite`를 `external` 훅으로 끼우고(표준 source 유지) 10000 tick. 후반(t6000~10000) 생멸이 0이 아니면 freeze 해소 (시드 42):

| 설정 | 후반 births | 후반 deaths | 판정 |
|---|---|---|---|
| 점화 OFF (= step-0005) | 0 | **0** | 얼어붙음 |
| thIgn=1.2, massToE=2 | 0 | 0 | (임계 높아 점화 안 함) |
| thIgn=0.8, massToE=3 | 0 | 0 | (경계) |
| **thIgn=0.6, massToE=4** | **11** | **11** | **영구 생멸 부활** |

점화가 켜진 사이클의 시계열(thIgn=0.55, t7000~10000):

```
tick   사망누계   living   최대rho
 7000     31        1       0.49
 8000     36        0       0.47
 9000     42        1       0.44
10000     49        1       0.45
```

**사망 누계가 31→49로 끝없이 오른다**(상수 source 기준은 15에서 영구 고정). 최대 rho는 **thIgn(0.55) 바로 아래 0.41~0.49를 riding** — 밀도가 임계까지 쌓이고→점화로 무너지고→다시 쌓이는 **이완 진동자/자기조직 임계(SOC)**의 서명이다. 자원 모델이 못 만든(Δ진폭=0) 한계순환을, 점화가 **임계+리셋**(integrate-and-fire) 구조로 만들어낸다. → ③의 강한 예비 증거.

(재현: step-0005 코어 + 위 `ignite` 훅. 본 검증은 코어에 정식 편입 후 `verify.js`로.)

## 7. 정직한 위험과 열린 질문

1. **부트스트랩.** 응집(attract)은 E를 태워야 rho를 모은다(대사 비용). 외부 source가 초기 응집을 씨 뿌려야 점화가 시작된다 → 외부 태양을 남기는 또 하나의 이유. *질문: 외부 source rate가 점화의 창과 어떻게 맞물리는가(이중 창)?*
2. **점화의 창이 실재하는가.** thIgn이 낮으면 모든 물질이 한 번에 타 사회가 못 서고(폭주), 높으면 점화 안 함(freeze 복귀). step-0002의 "생명의 창"이 source 강도에 있었듯, 점화 강도에도 양끝 0의 봉우리가 있어야 한다 — 없으면 이 메커니즘은 기각.
3. **한계순환인가 SOC인가.** PoC는 임계를 riding하는 SOC처럼 보인다. 깔끔한 주기적 한계순환인지, 사태(avalanche) 크기 분포가 멱법칙인 SOC인지 `cycle`로 특성화 — 어느 쪽이든 freeze는 풀리지만 *세계의 질감*이 다르다.
4. **보존 회계.** rho→E로 rho가 전역 보존량이 아니게 된다. `burnedTotal` 장부 + 외부 source의 rho 보충(태양이 물질도 공급?) 여부를 결정해야 한다. 안 그러면 물질이 단조 감소해 장기 고갈(다른 종류의 열적 죽음).
5. **항상성과의 충돌.** 점화가 사회를 주기적으로 무너뜨리면, step-0001~0005가 어렵게 세운 항상성(자기유지)을 *얼마나* 깨야 하는가? 너무 깨면 사회가 못 서고, 안 깨면 freeze. **"무너지되 재생하는"** 균형이 step-0006의 핵심 튜닝이다 (step-0005의 점화 임계 wDown≈15가 "견디다 무너지는" 경계를 이미 보여줬다 — 그 거울).

## 8. 재귀와의 관계 / 로드맵 변경

**발산은 모든 층의 같은 연산이다.** `ignite`(미시 물질→에너지)는 승급(`cE`, 미시 대사→거시 E)·하향 채널(`wDown`, 거시 발화→미시 T)과 같은 "이득 결합, 층별 장부 닫힘" 패턴이다 — 재귀 가설을 깨지 않는다. *"거시의 태양은 미시의 대사"* 가 *"미시의 태양은 그 아래의 점화"* 로 한 층 더 내려가, **발산이 층을 관통하는 단일 원리**임이 드러난다.

**로드맵 변경 제안.** step-0005 §7은 다음을 **3층(메타-사회)** 로 지정했었다(사회 간 인과는 위를 경유). 그러나 0절이 보였듯 — **얼어붙는 단일 세계 위에 3층을 쌓으면 얼어붙은 탑**이 된다. 영구 비평형(끊임없이 변하는 세계)이 *더 근본적인* 선결 조건이다. 따라서:

- **step-0006 = 내생적 발산(점화)** — 이 문서. 세계가 멈추지 않게 한다.
- **step-0007 = 3층 메타-사회** (구 step-0006) — 두 사회를 한 메타-셀로 덮어 공유 재앙(전쟁·붕괴). 점화로 *살아있는* 두 사회가 준비된 뒤 검증한다.

> 이 순서 변경은 제안이다 — 유저가 3층을 먼저 보고 싶다면 번호를 맞바꾼다.
