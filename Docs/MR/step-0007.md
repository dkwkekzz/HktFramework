# step-0007 — 사슬: source→별→생명→거름→새 별, 세계가 스스로 굴러간다

> [step-0006으로](step-0006.md) · 실행물: [step-0007.html](step-0007.html) · 코어: `step-0007/sim-core.js`(step-0006에서 **법칙 0 추가, 계수 2개 확장**: `ejectRadius`, `igniteRadius`) · 헤드리스: `step-0007/verify.js`
> 주제는 유저가 지정했다 — *"source로부터 생명에게 에너지를 전달하는 과정이 생생하게 보여지도록"*, 그리고 *"나의 궁극적인 가장 중요한 목표는 세계가 스스로 굴러가게 하는 것이다."*

step-0006이 답한 것: 발산을 *사건화*(점화) 하면 freeze 가 풀린다. 그러나 그 별은 **한 자리에 못박혔다** — ejecta·빛이 4-이웃에만 분배되어 사슬이 *공간적으로* 안 돈다. 본 step의 검증 §5.6 도 같은 한계: "별이 생명을 *끌어가* 태운다." step-0007은 ignite 의 **분배 반경**(`ejectRadius`)을 노브로 확장한다 — 새 법칙이 아니라 *계수 확장* (CLAUDE.md 규약, [step-0001](step-0001.md) 6요소 불변). 그리고 ejR=6 에서, **외부 트리거 없이 source 한 점만으로 별이 옮겨다니며 생명을 만들고 죽이는 자가-재생산 사슬이 10000+ tick 굴러간다.**

## 검증 질문 (본 thesis: 세계가 스스로 굴러간다)

> ① **사슬의 이동**: 별의 위치 분산이 ≥5셀 — 별이 한 자리에 못박히지 않고 옮겨다닌다?
> ② **사슬의 자기지속**: 외부 트리거 0, source 한 점만으로 후반(t6000~10000) 별/tick > 0 이 유지되는가?
> ③ **사슬에 깃든 생명**: 별이 옮겨다니는 사이에 *살아있는 생명*이 무더기로 켜졌다 꺼지길 반복(후반 생멸 ≥1000)?
> ④ **회귀**: `ejectRadius=0`(기본) 일 때 step-0006 과 비트 단위 동일, 점화 off/on 양쪽?

모든 수치는 시드 [42, 7, 1234, 99, 2026], `step-0007/verify.js <mode> <seed> [ejR]` 로 재현된다.

## 0. 왜 — step-0006 의 별은 못박혀 있었다

step-0006의 `ignite` 는 ejected rho 와 빛을 항상 **4-이웃**(상하좌우 1셀) 에만 분배했다. 그래서 별이 점화하면 그 *주변에* rho 가 쌓이고, 그 자리가 곧 다시 점화 — 별은 자기 둘레 한두 셀 안에서 진동할 뿐 자리를 옮기지 못한다. step-0006 §5.6 의 진단은 이것의 다른 얼굴이었다: 사회의 자리에서 *떨어진* 별이 사회의 rho 를 끌어가 태웠다(공간적으로 가까웠으나 사슬은 굴러가지 않았다).

표준 사슬 시나리오(단일 source at (16,32), ejR=2 vs ejR=6 vs ejR=8, 시드 5개 평균, 10000 tick):

| ejR (분배 반경) | 별 위치 std | 점유한 격자 셀 수 | 후반 살아있는 사회 | 후반 생멸 |
|---|---|---|---|---|
| 0 (step-0006 4-이웃) | 1.9 셀 | 37 | **0.65** | ~1930 |
| 2 (디스크 r2) | 2.4 셀 | 49 | 0.62 | ~2030 |
| 4 | 3.4 셀 | 101 | 0.40 | ~2900 |
| **6 (사슬 sweet spot)** | **5.1 셀** | **~330** | **8.5** | **~4250** |
| 8 (과한 흩어짐) | 9~10 셀 | ~1500 | 3.5 | ~4400 |

ejR=0 (step-0006 그대로, 별 못박힘) 와 ejR=6 사이의 **살아있는 사회 수 ~13배 차이**(0.65 → 8.5) 가 본 thesis 의 정답이다 — 별이 옮겨다녀야 *그 사이에서* 생명이 산다. (시드 42 기준; §2 의 5 시드 평균 living 은 7.9~10.2.)

## 1. 메커니즘 — `ignite` 의 분배 셀이 r 디스크로 확장된다

새 법칙이 아니다. 기존 `ignite` 법칙(step-0006 [03-5])의 *분배 셀 집합*이 4-이웃에서 r 디스크로 일반화된 것이다.

```js
// step-0007: ignite() 변경 부분만
const ejR = P.ejectRadius | 0, lgR = (P.igniteRadius | 0) || ejR;
let nsR, nsE;
if (ejR <= 0) {
  // step-0006 4-이웃 push 순서 그대로 — 회귀 0
  const ns = []; push(x+1,y); push(x-1,y); push(x,y+1); push(x,y-1);
  nsR = ns; nsE = ns;
} else {
  nsR = cellsInRadius(sim, x, y, ejR).filter(c => c !== i);
  nsE = (lgR === ejR) ? nsR : cellsInRadius(sim, x, y, lgR).filter(c => c !== i);
}
```

`ejectRadius=0`(기본) 일 때 step-0006 의 4-이웃 분배·순서가 **그대로** 보존된다(회귀 0). 별빛 분배 셀 집합은 기본적으로 ejected rho 와 동일하지만 `igniteRadius>0` 으로 분리 가능 — 본 step 의 시나리오는 통일(lgR=ejR=6) 을 사용한다.

**왜 r 디스크가 사슬을 만드는가.** ejR>0 일 때 별 한 번의 점화로 rho 가 둘레 r 셀까지 *흩뿌려진다*. 그 자리에 빛도 닿는다(`igniteSpread=0.92` × `massToE=5` 이득). 빛 닿는 곳에서 `attract` 의 `eff = E/(E+0.15)` 가 1 에 가까워져 흩어진 rho 가 **그 자리에서 재응결** — 다음 별이 *다른 위치*에서 켜진다. step-0006 [03-2] 의 응집 법칙이 *빛의 발자국*을 따라가는 것이 사슬의 기관이다.

## 5. 정직한 한계

0. **이 step의 범위는 사슬의 *공간 이동* 하나.** "별빛이 생명을 *영양*으로 키운다" 라는 §5.6 의 원래 §7 ② 검증은 본 step 도 *엄격하게는* 통과하지 못한다 — 별이 옮겨다니며 *그 자리의* 생명을 빛으로 일시 키운 뒤 자기 점화로 그 생명을 태워 다음 자리로 옮겨가는 동역학이라, 한 *고정* 사회를 *지속적으로* 키우지 않는다. 본 step의 답: **생명이 한 자리에 머물러야 한다는 가정 자체를 버린다** — 사슬에서는 생명도 옮겨다니며 별이 된다.
1. **사슬의 정상상태는 source 가 보충하는 rho 에 의존.** §3 의 totalRho 정상상태(~787) 는 srcRho=0.020·r=2 (0.26/tick) 가 별의 burnedTick (~0.27/tick) 을 보충하기 때문. srcRho=0 이면 사슬이 ~3000 tick 만에 totalRho 가 임계 미만으로 떨어져 죽는다(probe 시드 42 확인). 즉 *한 층 안에서* 사슬은 외부 입력이 *작지만 0 은 아니어야* 한다 — step-0006 §5.1 "빛=물질 소모" 의 정직한 잔재. 진짜 *0 입력* 무한은 재귀(step-0010) 가 답.
2. **ejR 디스크 분배는 step-0006 4-이웃의 *상위 호환*.** ejR=0 일 때 정확히 같은 셀·같은 순서로 push — 비트 동일. ejR>0 일 때 `cellsInRadius` 의 셀 순서(y-내림차→x-내림차)가 다르고 분배 셀 수가 다르므로 결과는 당연히 갈라진다.
3. **사회는 *행위자*가 아니라 *덧없는 응결*.** 사슬에서 살아있다고 검출된 ~9 개의 agent 는 평균 수명이 짧다(점화로 자주 소진). 종래의 "오래 사는 생명체" 가 아니라 *별의 발자국에서 잠시 모이는 물질의 무더기*다. 본 step 의 thesis 가 *세계가 굴러가는가* 였으므로 이는 의도된 성질, 그러나 "생명의 깊이"(긴 항상성 + 의미있는 행동) 는 별도 과제.
4. **분배 *반경* 의 창은 좁다.** ejR=2/4 (좁음): 별 못박힘, 사회 ~0.5. ejR=6 (sweet spot): 사회 8~10. ejR=8 (넓음): 너무 흩어져 응결 안 되고 사회 ~3.5. 위치는 burnFrac·igniteSpread·srcRho 에 함께 의존하며 결정론적 상수가 아니다.
5. **잔차 ↑.** 디스크 분배에서 부동소수점 누적 오차가 step-0006 의 4-이웃(고정 분모 4) 대비 ~5배 커진다(1.6e-6 → 9e-6). 여전히 *장부 닫힘*(1e-3 한참 아래) 이지만 정직히 기록.

## 6. 의외의 발견 — 사슬이 step-0009 (물질 정상상태) 도 일부 푼다

원래 step-0009 의 검증 질문(§7) 은 *"외부 물질 공급(rhoRate) 이 사체 물질 재응축과 균형을 이뤄 정상상태 totalRho 가 존재하는가? 또는 재귀(step-0010) 가 필요한가?"* 였다. 사슬에서 **totalRho 가 ~787 의 좁은 범위에서 정상상태** 를 잡는다(§3) — srcRho 의 보충 = burnedTick 의 소모 가 자동으로 균형이 맞는다. 사슬 자체가 자기조절 음의 되먹임 ─ rho 가 늘면 점화 자주 → burnedTick 증가, rho 가 줄면 점화 드뭄 → burnedTick 감소. step-0009 의 일부 답이 본 step 에서 떨어졌다(같은 코어, 다른 시각).

## 7. 화면에서 직접 확인하는 법

[step-0007.html](step-0007.html) 을 연다. 페이지가 열리면 바로 **⛓ 사슬** 시나리오가 켜진다 (ejR=6, source 한 점, 외부 트리거 0):

- **별의 광배**: 점화한 셀에서 r=6 의 부드러운 노란 광배가 *디스크* 로 퍼진다 — 별의 발산이 어디까지 닿는지 한눈에 보인다. 광배 안쪽의 흰 핵이 별 자체.
- **사슬 trail**: 최근 200 tick 의 점화 자리가 *주황 점*으로 fade-out 한다 — 별이 어디를 지나갔는지의 흔적. 시간이 흐르면 디스크 둘레를 별이 돌아다닌 *궤적*이 보인다.
- **대사 halo**: 살아있는 노란 원(생명) 주위에 강도 ∝ metab 의 주황 글로우 — *별빛을 받아 대사를 돌리는* 그 순간이 빛난다. 별빛이 닿지 않는 생명은 halo 가 거의 없다. **에너지 전달이 시각적으로 살아있다.**
- **계기판**: "별의 위치 분산" 이 5셀 이상으로 유지되면 사슬이 도는 중. "사슬 점유 격자" 가 ~300 셀에 도달하면 한 시뮬레이션에서 별이 점유한 영역이 8% 에 이른다.

**핵심 비교**: 우측의 **분배 ejR** 슬라이더를 천천히 0 (=step-0006 4-이웃) 으로 내리면 별이 한 자리에 못박히고 노란 원(생명) 무더기가 거의 사라진다 — 같은 source, 같은 시드, **분배 반경 하나만** 의 차이. *별이 옮겨다닐 때* 비로소 사슬이 살아있다.

**직접 씨 뿌리기 — ★ `씨앗 ρ` 도구**: 도구 카드의 노란 **씨앗 ρ +** 를 골라 빈 곳을 클릭하면 *별의 요람*(rho 펌프)이 놓여 그 자리에 물질이 쌓이고 새 별 사슬이 시작된다. 반면 **source +(E)** 는 *빛만* 주입한다 — 별은 **rho 가 임계(thIgn)를 넘을 때** 켜지므로 E 만으로는 (초기 잔여 rho 를 잠깐 태운 뒤) 별이 사그라든다. 헤드리스 확인: 같은 자리에 source 를 놓아도 E 만이면 3000 tick 별 ~1450(초기 rho 소진 후 멈춤), E+rho 면 ~60,000(사슬 지속) — **40배.** 별의 연료는 빛이 아니라 *물질*이다.

다른 시나리오(stars/disaster/war2/basic/...) 는 step-0006 동작 그대로 (ejR=0 → 회귀 0).

## 8. 다음 — 사슬의 깊이와 재귀

step-0007 이 *공간적* 사슬 (외부 트리거 0, 별의 자가 이동) 을 검증했고 부수적으로 *물질 정상상태* 까지 닿았다. 남은 호:

- **step-0008 — 사슬의 두 사회 (충돌).** 두 source 가 멀리 떨어져 각자 사슬을 만들면 두 사슬은 어떻게 만나는가? 만난 자리에서 *공유 별*이 켜지는가, 서로 *밀어내는가*? — 사회 간 인과의 사슬판.
- **step-0009 — 사슬의 *내용* 분화.** 별이 내리는 것은 지금 하나(빛 E + rho ejecta). 그러나 5 대 재앙(역병·기근·전쟁·천재·붕괴) 처럼 발산의 *내용*이 갈라져야 사회 동역학이 풍부해진다. burstToT vs igniteHeat 의 거시 한 층 위에서.
- **step-0010 — 재귀: 두 사슬 위의 메타-사슬.** step-0005 가 지정한 메타-사회. 미시 사슬의 발산이 거시 셀의 source 가 되어, *거시 사슬*이 한 층 위에서 굴러간다. step-0006 §5.1 의 "빛=물질 소모" 가 진정으로 *재귀로* 풀리는 자리.
- **이후 — 사회의 *깊이*.** 본 step 의 사회는 덧없는 응결(§5.3). 별의 자리에 *오래 머무는* 사회 — 별과 사회의 분리 — 는 다른 노브(예: 사회 자리에서 점화를 막는 sink 채널) 가 필요할 수 있다. step-0006 §7 의 후보 (a)/(c) 가 이 호에서 다시 부활.
