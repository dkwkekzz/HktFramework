# 05. 경계·항상성 (Emergent Agent)

> [step-0001 인덱스로](../step-0001.md) · 관련: [04-energy-flow](04-energy-flow.md), [03-law](03-law.md), [06-recursion](06-recursion.md)

## 이것이 무엇인가

[03 법칙] + [04 에너지 흐름]이 만들어낸, **스스로를 유지하는 양의 패턴**. 주변과 구별되는 경계를 갖고, 시간이 지나도 흩어지지 않으며, 그러기 위해 끊임없이 기울기를 처리한다. 이것이 곧 "생명"이고 "개체(entity)"다 — 단, **우리가 만든 게 아니라 떠오른 것**이다. 시스템의 안정 끌개(attractor)일 뿐이다.

idea.md의 *"항상성과 욕구"* 가 여기 자연 귀결된다: 자기를 유지하려는 경향 = 항상성, 그 유지를 위해 자원을 필요로 함 = 욕구.

## 목적과 어떻게 연결되며, 왜 존재해야 하는가

이 요소가 **"entity를 설계하지 않는다"의 결정적 증거**다. 생명·몬스터·NPC를 코드로 정의하지 않았는데도 화면에 "그것들"이 나타나면, 우리의 접근이 옳았다는 뜻이다.

또한 욕구가 *공짜로* 따라온다. 인간을 모방해 "배고픔=80"을 넣지 않아도, 자기 유지 패턴은 본질적으로 "E가 떨어지면 흩어진다 → 그래서 E를 향한다"는 행동을 보인다. 배고픔·번식·회피·공격이 전부 "항상성을 깨는 것에 대한 반응"으로 emergent하게 나온다. 톰과 제리의 쫓고 쫓김(idea.md)도 결국 두 자기유지 구조 사이의 기울기 다툼이다.

## 세계에서 어떻게 작동하고 다른 요소와 어떻게 상호작용하는가

- **[04 기울기]의 자식이다.** 기울기를 처리하는 구조만 유지된다. source가 끊기면 굶어 흩어진다(죽음). 그래서 생명은 본질적으로 *자원을 향해 움직이고 경쟁*한다.
- **[03 법칙]의 산물이자, 새 법칙의 *소스가 아니다*.** 패턴이 특별한 규칙을 갖는 게 아니라, *같은* 4법칙이 그 패턴 위에서 돌 뿐. → 직관 전이가 깨지지 않는다.
- **서로 상호작용한다.** 두 패턴이 같은 기울기를 두고 만나면 경쟁(포식·기생·공생)이 emergent하게 발생. 이 상호작용의 안정된 집합이 곧 [06 재귀]의 입력(= 생태계·사회).
- **측정 가능해야 한다.** "자기 유지"는 관찰자가 *판정*하는 게 아니라 *측정*되어야 한다(아래 지표). 그래야 우리가 "정말 떠올랐다"고 말할 수 있다.

## 프로토타입으로 만들 구조 설계

핵심은 **검출(detection)**: 우리가 entity를 만들지 않으므로, *떠오른 것을 찾아내는* 코드가 필요하다.

- **경계 검출:** `ρ`가 임계 이상인 셀들을 연결요소(connected components)로 묶는다(flood fill). 각 덩어리 = 후보 구조.
- **항상성 판정(시간 추적):** 후보에 ID를 부여하고 tick마다 추적. 다음을 만족하면 "살아 있는 agent"로 승격:
  - 수명: `L`tick 이상 존속
  - 안정성: 질량(Σρ)이 일정 범위에서 유지(폭발·소멸 아님)
  - 대사: 내부로 E 순유입 > 0 (기울기를 *먹고* 있음)
- **agent 레코드:** `{id, cells, centroid, mass, E_intake, age}`. 이 레코드 목록이 [06]의 입력이 된다.
- **검증 지표(시간 그래프):** 살아있는 agent 수, 평균 수명, 평균 대사율. → "생명의 창"([04])에서 이 수치들이 0보다 크고 안정적이면 1차 검증 성공.

```js
function detectAgents(field, thRho){
  const {N,rho,idx,neighbors}=field, seen=new Uint8Array(N*N), agents=[];
  for(let y=0;y<N;y++) for(let x=0;x<N;x++){
    const i=idx(x,y);
    if(seen[i]||rho[i]<thRho) continue;
    const cells=[], stack=[[x,y]]; seen[i]=1;
    while(stack.length){
      const [cx,cy]=stack.pop(), ci=idx(cx,cy); cells.push(ci);
      for(const [nx,ny] of neighbors(cx,cy)){
        const ni=idx(nx,ny);
        if(!seen[ni]&&rho[ni]>=thRho){ seen[ni]=1; stack.push([nx,ny]); }
      }
    }
    agents.push({cells, mass: cells.reduce((s,c)=>s+rho[c],0)});
  }
  return agents; // 이후 ID 매칭으로 시간 추적 → 항상성 판정
}
```

## 검증 현황과 수정 이력

- **[step-0002](../step-0002.md)** — "만들지 않고 검출"이 구현·통과됐다. flood fill + centroid 최근접 ID 추적 + 3조건(수명 ≥ 60 tick · 질량 안정 ±50% · 대사 > 0)의 논리곱으로 "살아있는 agent"를 코드가 판정한다. *"욕구가 공짜로 따라온다"* 실증: source를 끊으면 굶어 흩어진다 — 배고픔 변수 없이. 한계도 기록됨: 뭉친 이후가 정적이다(이동·경쟁 없음) → step-0003 과제로.
- **[step-0003](../step-0003.md)** — 이 문서의 예언 *"생명은 본질적으로 자원을 향해 움직이고 경쟁한다"* 가 실증됐다(메커니즘은 [03]의 wE 계수). 목동 실험: 걷는 source를 같은 개체가 115셀 추적(wE≥1, wE=0이면 전멸). 경쟁 실험: 두 자기유지 구조가 같은 기울기를 두고 만나면 승자가 패자의 질량을 흡수(포식의 원형). **측정 장치 추가:** centroid 이동 속도·누적 이동거리·궤적, 누적 탄생/사망, 경합사망(사망 반경 10셀 내 타 생존 agent = 경쟁의 흔적). 그리고 agent 레코드가 설계대로 [06]의 입력이 됐다 — mass→ρ₂, 대사→E₂로 승급.
