# 06. 재귀 (Recursion)

> [step-0001 인덱스로](../step-0001.md) · 관련: [05-homeostasis](05-homeostasis.md), [01-field](01-field.md), [03-law](03-law.md)

## 이것이 무엇인가

[01]~[05]의 구조 전체가 **한 단계 위에서 그대로 반복**되는 성질. [05]에서 떠오른 agent들을 *점*으로 보면, 그 점들이 사는 새로운 [01 장]이 생기고, 그 위에서 같은 [03 법칙]이 돌아 더 큰 자기유지 구조 — 무리·사회·문명 — 가 떠오른다. idea.md의 *"무한 회귀: 원 안에 원 안에 원"*.

## 목적과 어떻게 연결되며, 왜 존재해야 하는가

이것이 **성공의 그림("불 다루는 직관 = 혁명 일으키는 직관")을 성립시키는 유일한 메커니즘**이다. 두 직관이 통하는 이유는 단 하나 — 두 스케일이 *같은 법칙*으로 돌기 때문이다. 불 끄기(국소 E 기울기 관리)와 혁명 일으키기(사회 E 기울기 관리)가 구조적으로 동일하면, 한쪽에서 익힌 감각이 다른 쪽에 그대로 옮겨진다.

재귀가 **방대함과 모험심**도 만든다(idea.md의 헌터×헌터 암흑대륙, 원자와 우주의 관계). 스케일을 올릴 때마다 새 콘텐츠를 그릴 필요 없이 *같은 규칙의 새 층*이 열리므로, 세계는 사실상 끝이 없다. 안으로 들어가도(원자), 밖으로 나가도(우주) 같은 원리가 반복된다.

## 세계에서 어떻게 작동하고 다른 요소와 어떻게 상호작용하는가

- **[05]의 출력이 [06]의 입력.** agent 레코드 목록 → 상위 장의 "양". 한 agent의 `mass`는 상위 세계에서의 `ρ`, `E_intake`는 상위 `E`, 무리 짓는 성향은 상위 `A`가 된다.
- **같은 [03 법칙] 재적용.** 응집(무리), 확산(소문·문화 전파), 소산(자원 고갈·쇠퇴), 임계(전쟁·혁명·붕괴 같은 불연속 사건). → 사회 현상이 *새 규칙 없이* 나온다.
- **양방향이다.** 상위 구조의 상태가 하위에 되먹임된다(사회의 붕괴 = 구성원들의 기울기 환경 급변). 위아래 층이 결합되어야 진짜 "살아 있는" 세계.
- **idea.md의 "5대 재앙"** 은 상위 스케일에서 임계 법칙이 터지는 사건으로 자연 해석된다 — 미리 스크립트하지 않아도 떠오르는 거대 사건.

## 프로토타입으로 만들 구조 설계

프로토타입에서는 **2층까지만** 검증한다(미시 셀 → agent 무리). 무한 재귀는 구조가 옳음을 보인 뒤 일반화한다.

- **승급(promotion):** [05]의 agent 레코드 목록을 새 입자 집합으로 변환. 위치 = centroid, 양 = (mass→ρ, intake→E, 군집성향→A).
- **상위 장:** 미시 격자보다 거친 좌표(연속 위치 + 공간 해시)나, agent를 노드로 한 그래프. 같은 `diffuse/attract/dissipate/threshold` 함수를 *agent 단위*로 재호출.
- **동일 코드 재사용이 핵심 설계 원칙:** 법칙 함수가 "격자"가 아니라 "이웃을 가진 점들의 집합"에 대해 동작하도록 추상화하면, 미시·거시가 *문자 그대로 같은 함수*를 쓴다. → 재귀가 코드 차원에서 보장됨.
- **검증:** 미시에서 검증된 "생명의 창"이 거시에서도 재현되는가? agent 무리가 자기유지(= 사회)하는가? 미시의 source 차단이 거시 구조 붕괴로 전파되는가(층간 결합)?

```js
// 같은 법칙을 점 집합에 재적용하기 위한 추상화
function step(points, neighborsOf, params){
  diffuse(points, neighborsOf, params.alpha);
  attract(points, neighborsOf, params.g);
  dissipate(points, params.delta);
  threshold(points, params.theta);
}
// 미시: points = 격자 셀, neighborsOf = 4-이웃
// 거시: points = agent들,  neighborsOf = 반경 내 다른 agent
// → 동일 step() 호출 = "원 안의 원"
```

## 검증 현황과 수정 이력

- **[step-0002](../step-0002.md)** — 미착수 (의도적 연기).
- **[step-0003](../step-0003.md)** — **2층 검증 통과.** 구현은 위 설계와 한 가지가 다르다: 연속 위치 점 집합 대신 *거시도 그냥 격자 장*(`createSim(16)`)으로 했다 — "동일 코드 재사용"이 점 집합 추상화 없이도 문자 그대로 성립하기 때문(미시와 같은 `step()` 호출). 승급은 mass→ρ₂(완화 주입), 대사→E₂(소득) — *거시의 태양은 미시의 대사다.* 검증 3종 모두 통과: ① 거시 생명의 창 재현 — 양끝 0, 그리고 **미시보다 좁다**(source 0.35에서 미시 생명 3.4개, 사회 0개 — "사회는 생명보다 까다롭다", 설계에 없던 발견). ② 층간 결합 — 미시 source 차단 시 ~900 tick 만에 두 층 연쇄 붕괴(시드 5개 일관). ③ 거시 보존 성립(잔차 ~1e-7, 승급 소득은 거시 장부의 주입으로 기록). **미검증 잔여:** 하향 결합(상위 → 하위, wBack 구현만 됨), 사회 *간* 상호작용(전쟁의 원형), 3층 이상 일반화 — step-0004 후보.
- **[step-0004](../step-0004.md)** — **하향 결합 ② 부분 검증, 사회 간 상호작용 ③ 부정.** wBack>0의 A-채널은 *조향만* 내려보내 사회가 구성원을 모으고(응집도 2.07→0.42셀) 안정시키지만(생멸 회전 25%↓), 거시 발화를 미시 재앙으로 내리지는 못한다(에너지를 못 옮김). 사회 *간* 상호작용은 **거리로는 일어나지 않음**을 대조군으로 증명 — 두 사회로 남을 만큼 멀면 공유 자원이 없어 무관하고, 가까우면 한 사회로 병합. 두 미검증 항목(하향 *재앙*, 사회 *간*)이 같은 부재(하향 에너지 채널)로 수렴 → step-0005가 채널 하나로 검증한다. **여전히 미검증:** 3층 이상 일반화.
- **[step-0005](../step-0005.md)** — **하향 에너지 채널로 ② 재앙 전파 검증(✓), ③ 사회 간은 수직 한계로 재진단.** 승급의 대칭(거시 발화 → 미시 열)을 같은 신호-결합 원칙으로 넣어(각 층 장부 독립적으로 닫힘) 거시 발화 사건이 그 아래 미시 사회를 절멸시키고 재생시킨다 — 재귀의 *하향* 인과가 처음으로 작동. 그러나 채널은 **수직(기둥)**이라 발화한 거시 셀 바로 아래로만 내리고, 8 거시셀 떨어진 이웃 사회엔 무영향(전 시드, 압축을 올려도 동일). **결론:** 사회 간 인과는 peer-to-peer가 아니라 **공유 상위층을 경유**해야 한다 — 두 사회를 한 메타-셀로 덮는 3층에서 그 메타-셀의 발화가 둘 모두에게 내린다(공유 재앙). 재귀 가설이 스스로 3층의 필요를 지정. **미검증:** 3층(메타-사회) 구현 = step-0006.
- **[step-0006](../step-0006.md)** — **발산이 층을 관통하는 단일 원리임이 드러났다.** step-0003의 *"거시의 태양은 미시의 대사"* 를 한 층 더 내려 — **"미시의 태양은 그 아래의 점화(`ignite`)"** 다. 점화는 승급(`cE`)·하향 채널(`wDown`)과 같은 "이득 결합, 층별 장부 닫힘" 패턴(rho→E, `massToE` 이득)이라 재귀 가설을 깨지 않는다. 그리고 재귀가 **"무한한 세계"의 답**을 내놓는다: 한 층에서 빛은 물질을 소모하므로(열역학) 영원한 빛은 불가능하지만, 각 층이 *한 층 아래의 발산*으로 살고 맨 아래만 외부 공급을 받으면 — **유한한 바닥을 무한한 깊이가 가린다.** 무한은 보존이 아니라 재귀의 깊이다. **다음:** "태양"은 한 step이 아니라 호(arc)로 점진 분할된다(물질 방출·순환 → 정상상태 → **3층 메타-사회** = 재귀로 무한; [step-0006.md §7](../step-0006.md)). 3층에선 *점화로 살아있는*(얼지 않는) 두 사회를 한 메타-셀로 덮어 공유 재앙(전쟁·붕괴)을 검증하고 메타층 발산이 사회들의 태양이 된다.
- **[step-0010](../step-0010.md)** — **사슬이 척도를 가리지 않음이 비트로 증명됐다 — *메타-사슬*.** step-0007~0009 가 미시에서 사슬·분화를 키우는 동안 멈춰 있던 거시가, 미시 사슬의 승급을 source 로 받아 **한 층 위에서 사슬을 굴린다**(거시별/t 6.4 — 점화는 *사건 집합*이고 "굴러간다"는 그 활성 영역의 코히어런트 표류: `roll` 무게중심 연속변위 1.5 ≪ 무작위 3.6). 거시 점화는 **새 코드 0줄** — 미시와 *같은* `ignite()` 에 거시 params 를 준 것뿐(`regm`: promoteComp off 면 step-0009 코어와 비트 동일). 재귀(요소 06)가 "또 하나의 장"이라는 가설의 가장 강한 증거: 같은 법칙이 층을 가로질러 같은 패턴을 만든다. 그리고 step-0009 의 기질 φ 가 **승급을 타고 올라온다**(미시별 φ 0.93→거시별 φ 0.80) — step-0009 의 "비례 동승 트레이서"를 *층간 채널*에 재사용(`promoteComp`, φ≤1→거시 rhoB≤rho 보존). 올라온 기질이 거시 발산의 종류(빛/열)를 가른다(미시 φ=1+거시 heatB=0.5 → 거시 E −12%; `reg0`: 거시 igniteHeatB=null 이면 비트 동일 — 층간 트레이서도 순수 측정). *의외의 발견:* 미시에서 16셀로도 안 섞이던 두 기질이 거시에선 **혼혈로 융합**(빛+열 두 사슬 → 거시별 φ=0.36) — 거시는 미시의 공간 분해능을 잃는 *평균자*. **2.5D 층 시각화 도입**(등축투영, 코어는 2D 유지 — CLAUDE.md 로드맵). **여전히 미검증:** 거시 *생명*(거시 living=0 — 거시 사슬은 굴러가되 항상성 사회는 아직), 닫힌 고리(상향 승급 × 하향 wDown), 3층 — step-0011 후보.
