# 02. 양 (Quantity)

> [step-0001 인덱스로](../step-0001.md) · 관련: [01-field](01-field.md), [03-law](03-law.md), [04-energy-flow](04-energy-flow.md)

## 이것이 무엇인가

장의 각 점에 저장되는 **상태 데이터**. 스칼라(방향 없는 크기)나 벡터(방향 있는 양)로, 그 점이 "지금 어떤 상태인가"를 숫자로 표현한다. idea.md의 *"상태만 데이터화한다"* 가 바로 이것이다.

최소 4종으로 시작한다:

| 기호 | 이름 | 종류 | 의미 |
|------|------|------|------|
| `E` | 에너지 | 스칼라 | 일을 할 수 있는 능력. 흐름의 연료. |
| `T` | 열 | 스칼라 | 무질서·온도. E가 소산되면 쌓이는 "찌꺼기". |
| `ρ` (rho) | 밀도 | 스칼라 | 물질이 얼마나 뭉쳐 있나. 지형·몸의 재료. |
| `A` | 끌림 | 스칼라 | 그 점의 물질이 이웃을 당기는 정도(중력 같은 응집 성향). |

## 목적과 어떻게 연결되며, 왜 존재해야 하는가

세계의 *다양성*은 entity의 종류 수가 아니라 **양의 분포**에서 나와야 한다. 같은 4개의 숫자라도 분포가 다르면 한 곳은 사막, 한 곳은 숲, 한 곳은 도시가 된다 — 우리가 "사막/숲/도시" 객체를 만들지 않고도. 이것이 "entity를 설계하지 않는다"를 *내용물 차원*에서 실현하는 방법이다.

또한 양은 **최소 표현**이어야 한다. 속성이 많을수록 설계가 인간 모방으로 회귀한다(체력·배고픔·분노… 다 인간을 베낀 것). 그래서 idea.md는 *"가장 간단한 건 만류인력"* 이라 짚는다. 우리는 인간적 속성 대신 물리적으로 환원 가능한 원초 양(에너지·열·밀도·끌림)에서 출발해, 더 복잡한 것은 *떠오르게* 한다. (배고픔 = 국소 E 고갈, 분노 = 임계 초과… 는 [05]에서 emergent하게 다룸.)

## 세계에서 어떻게 작동하고 다른 요소와 어떻게 상호작용하는가

- **[01 장] 위에 산다.** 각 양은 장과 같은 크기의 배열. 양 = 장의 "내용물".
- **[03 법칙]의 입력이자 출력.** 법칙은 양을 읽어 다음 양을 쓴다. 양 없이는 법칙이 계산할 대상이 없다.
- **[04 에너지 흐름]의 실체가 `E`다.** source는 E를 주입, sink는 E를 빼간다. E의 공간적 불균형이 곧 기울기.
- **상호 변환된다(보존).** E가 일을 하면 T로 바뀌고(소산), ρ가 뭉치면 위치에너지가 E로 환원되는 식. 변환 규칙이 [03]의 핵심.
- **합성되어 "의미"가 된다.** 높은 ρ + 낮은 T = 단단한 지형. 높은 E + 임계 T = 발화. 양 자체엔 의미가 없고, *조합*이 현상으로 읽힌다([05]가 이를 패턴으로 포착).

## 프로토타입으로 만들 구조 설계

- **저장:** [01]의 SoA 배열을 그대로 사용(`E`, `T`, `rho`, `A`). 더블 버퍼링 — 한 tick은 `cur`을 읽어 `next`에 쓰고 swap. (제자리 갱신 시 이웃 의존 순서 버그 방지.)
- **초기화:** 약한 난수 노이즈로 `ρ`, `A` 시드. `E`, `T`는 0에서 시작하고 source가 채우게 둔다. → "균일한 무(無)에서 구조가 떠오르는가"를 보는 실험.
- **정규화/단위:** 모든 양을 `0.0~1.0`으로 정규화해 색 매핑과 임계 비교를 단순화. 보존 검사를 위해 총량 `ΣE + ΣT`(에너지+열)를 매 tick 로깅.
- **렌더 합성(채널 매핑 예시):**
  - R ← `E` (에너지: 붉게 타오름)
  - G ← `rho` (밀도: 물질·지형)
  - B ← `T` (열: 식어 흩어진 무질서)
  - `A`는 디버그 토글로 별도 시각화.

```js
function makeBuffers(N){
  const z = () => new Float32Array(N*N);
  return { cur:{E:z(),T:z(),rho:z(),A:z()},
           next:{E:z(),T:z(),rho:z(),A:z()} };
}
function cellColor(c, i){
  return [ c.E[i]*255, c.rho[i]*255, c.T[i]*255 ]; // R,G,B
}
```

## 검증 현황과 수정 이력

- **[step-0002](../step-0002.md)** — E·T·ρ·A 4종으로 1차 검증 전부 통과. "최소 표현" 원칙이 버텼다 — 배고픔·체력 같은 속성을 추가하지 않고도 욕구가 떠올랐다. **수정 1건:** 더블 버퍼(`cur`/`next`)를 플럭스 누적 방식으로 대체 — 스냅샷 기준 변화량을 모아 일괄 적용하므로 동기 갱신이 보장되고 보존이 산수로 성립한다. 결과는 더블 버퍼와 동등(설계 의도인 "이웃 순서 버그 방지"는 그대로 달성).
- **[step-0003](../step-0003.md)** — 새 양 없이 *행동*까지 나왔다(행동은 [03] 응집 되먹임의 계수였다). 거시 층의 양은 승급으로 채워진다: 살아있는 agent의 mass→ρ₂, 대사→E₂, 그리고 A₂는 거시 응집 되먹임이 스스로 만든다 — *"양은 층마다 다시 태어난다."* 4종이 두 층 모두에서 충분했다.
