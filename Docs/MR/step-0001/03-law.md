# 03. 법칙 (Law)

> [step-0001 인덱스로](../step-0001.md) · 관련: [02-quantity](02-quantity.md), [04-energy-flow](04-energy-flow.md), [05-homeostasis](05-homeostasis.md)

## 이것이 무엇인가

[02 양]을 시간에 따라 바꾸는 **국소 연산자**. "한 점의 다음 값 = 그 점과 이웃들의 현재 값의 함수"라는 형식의 규칙. 법칙은 세계의 동사(動詞)다 — 명사(entity)를 만들지 않고, *변화의 방식만* 정한다.

두 가지 불가침 성질을 둔다:

- **국소성:** 멀리 떨어진 점을 직접 참조하지 않는다. 영향은 항상 이웃을 통해 전파된다.
- **보존 + 소산(열역학):** 양은 무에서 생기거나 사라지지 않고 *옮겨지거나 형태를 바꿀* 뿐이며, 그 과정에서 일부는 항상 `T`(열)로 빠져 되돌릴 수 없다.

## 목적과 어떻게 연결되며, 왜 존재해야 하는가

법칙이 곧 **"인간을 모방하지 않는다"의 실현 수단**이다. 시나리오·스크립트(=인간이 정한 줄거리)를 흉내 내는 대신, 몇 개의 국소 규칙만 깔면 줄거리는 *계산의 결과로* 나온다.

그리고 **소수의 법칙이 모든 스케일에 적용**되어야 한다 — 이것이 성공의 그림("불 다루는 직관 = 혁명 일으키는 직관")의 엔진이다. 법칙이 적고 보편적일수록, 플레이어가 한 영역에서 익힌 감각이 다른 영역에 그대로 옮겨진다. 법칙이 많고 특수하면(이 몬스터엔 이 규칙, 저 NPC엔 저 규칙) 직관은 전이되지 못하고 세계는 암기 대상이 된다.

idea.md의 영감을 4개 법칙으로 압축한다: 만류인력 → **응집**, 파동·확산 → **확산**, 열역학 → **소산/보존**, 양자역학적 도약 → **임계/상전이**.

## 세계에서 어떻게 작동하고 다른 요소와 어떻게 상호작용하는가

4개 법칙(매 tick 순서대로 적용):

1. **확산 (Diffusion / Wave)** — `T`와 `E` 일부가 이웃으로 퍼진다. `∂q = α·(이웃 평균 − 자기값)`. 균질화·전파를 담당. → 파동의 법칙.
2. **응집 (Attraction)** — `ρ`가 끌림 `A`가 높은 이웃 쪽으로 흐른다. 높은 ρ는 더 높은 A를 유발(되먹임)하여 덩어리가 자란다. → 만류인력. 지형·몸의 재료가 여기서 뭉친다.
3. **소산·보존 (Dissipation)** — `E`는 일을 하면 줄고 그만큼 `T`가 는다. `T`는 sink로 빠진다. 총량은 보존되되 *쓸 수 있는* E는 단조 감소. → 왜 모든 것이 식고, 유지하려면 [04]의 공급이 필요한지의 이유.
4. **임계·상전이 (Threshold)** — 어떤 양이 임계를 넘으면 *불연속* 사건이 터진다(발화: E↑T↑ρ↓ / 응결: T↓ρ↑ / 탄생: 국소 조합 충족 시 자기유지 시드 생성). → 연속 장에서 사건이 튀어나오는 지점 = **도파민의 출처**.

상호작용: 법칙들은 [02 양]을 공유 자원으로 두고 경쟁·협력한다. 확산은 펼치려 하고 응집은 모으려 한다 — 이 *긴장*이 평형을 단순하게 만들지 않는다. [04 에너지 흐름]이 E를 계속 부어 1·2의 줄다리기를 살아 있게 유지하면, 4의 임계가 간헐적으로 터지며 구조가 생멸한다. 그 안정 패턴이 [05]다.

## 프로토타입으로 만들 구조 설계

- **구조:** 각 법칙 = 순수 함수 `law(cur) -> next 기여분`. tick 루프가 정해진 순서로 호출(순서는 [07]에서 고정). 함수를 켜고 끄는 토글로 *각 법칙의 기여를 분리 관찰*.
- **파라미터(슬라이더로 실시간 조절):** `α`(확산율), `g`(응집 강도), `δ`(소산율), `θ_*`(각 임계). → "어떤 조합에서 구조가 떠오르는가"의 탐색이 핵심 실험.
- **검증 훅:** 소산·보존 법칙은 매 tick `ΣE+ΣT` 변화를 출력해 *수치적으로* 보존 확인(source/sink 유입출 제외하면 0이어야 함).

```js
// 확산: 이웃 평균으로 끌어당김
function diffuse(f, q, alpha, out){
  for(let y=0;y<f.N;y++) for(let x=0;x<f.N;x++){
    const i=f.idx(x,y);
    let sum=0; const ns=f.neighbors(x,y);
    for(const [nx,ny] of ns) sum += q[f.idx(nx,ny)];
    out[i] = q[i] + alpha*(sum/ns.length - q[i]);
  }
}
// 소산: E가 일하며 T로 전환 (보존)
function dissipate(E,T,delta){
  for(let i=0;i<E.length;i++){ const d=delta*E[i]; E[i]-=d; T[i]+=d; }
}
// 임계: 발화 이벤트
function threshold(E,T,rho,thE){
  for(let i=0;i<E.length;i++) if(E[i]>thE){ T[i]+=E[i]*0.5; E[i]*=0.3; rho[i]*=0.8; }
}
```

## 검증 현황과 수정 이력

가장 손이 많이 간 요소다. 단, 모든 수정은 **새 법칙 추가가 아니라 기존 4법칙의 계수·되먹임 보정**이었다 — "소수의 법칙" 원칙은 깨지지 않았다.

- **[step-0002](../step-0002.md)** — 4법칙을 전부 플럭스(이웃 간 교환) 형태로 구현해 불가침 성질 검증: 개방계 3000 tick 보존 잔차 ~1e-6, 임계 발화가 매 tick 2~14회 터지며 비정지성 성립. **수정 3건:** (1) *A 평활화* — 끌림에 사거리를 줘 셀 단위 점 붕괴(체커보드 불안정) 제거. (2) *응집의 대사 비용* — ρ를 옮기려면 E를 태워야 함(E→T, 보존). [04]의 "보상과 대가가 같은 법칙에서"의 수치 실현이자, "굶으면 흩어진다"([05])의 성립 조건. (3) *열 교반 kT* — T가 높을수록 ρ가 빨리 흩어짐. 구조가 영구 고착되는 것을 막는 소산의 되먹임 경로.
- **[step-0003](../step-0003.md)** — **수정 1건:** 응집 되먹임 목표를 `A ← ρ`에서 `A ← ρ + wE·E`로. 이 한 항에서 이동(목동 추적)·경쟁(승자독식)·생멸 회전이 떠올랐다 — *행동조차 법칙의 계수다.* wE=0이면 step-0002와 비트 단위 동일(회귀 검증). 그리고 이 문서의 핵심 주장 *"소수의 법칙이 모든 스케일에 적용"* 이 실증됐다: 같은 4법칙이 거시 16×16 장에서 문자 그대로 같은 함수로 재호출되어 사회를 만든다(거시 발화 = 재앙의 원형).
