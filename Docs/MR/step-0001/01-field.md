# 01. 장 (Field)

> [step-0001 인덱스로](../step-0001.md) · 관련: [02-quantity](02-quantity.md), [03-law](03-law.md), [06-recursion](06-recursion.md)

## 이것이 무엇인가

공간 그 자체다. 격자(또는 연속체)의 각 점이 값을 담을 수 있는 **그릇**. 장은 비어 있을 때조차 존재하며, 물질·지형·날씨·생명·사회는 전부 "이 장 위에 떠 있는 값의 패턴"일 뿐 별도의 객체가 아니다.

비유: 종이는 그림이 아니지만 모든 그림은 종이 위에서만 가능하다. 장은 그 종이다.

## 목적과 어떻게 연결되며, 왜 존재해야 하는가

핵심 제약 **"entity를 설계하지 않는다"** 가 장에서 강제된다. 만약 생명·돌·구름을 각각 객체로 만들면 우리는 결국 그것들을 일일이 설계하게 된다. 대신 "모든 것은 장 위의 값 패턴"이라고 못 박으면, 우리가 설계할 수 있는 대상은 *장과 그 위의 규칙*뿐이고 — 개별 존재는 설계 대상에서 원천적으로 빠진다. 즉 장은 "직접 만들지 않기"를 물리적으로 보장하는 토대다.

또한 장은 **국소성(locality)** 을 제공한다. 점들이 이웃과만 상호작용하게 만들면, 멀리 떨어진 두 곳은 *중간을 거쳐서만* 영향을 주고받는다. 이 국소성이 나중에 파동·확산·전파 같은 현상과, "스케일을 넘는 직관 전이"의 기하학적 바탕이 된다.

## 세계에서 어떻게 작동하고 다른 요소와 어떻게 상호작용하는가

- **[02 양]을 담는다.** 장의 각 점은 양(에너지·열·밀도·끌림)의 현재값을 보관한다. 장은 정적인 좌표계이고, 양은 그 위에서 변하는 내용물이다.
- **[03 법칙]의 무대가 된다.** 법칙은 "한 점의 다음 값 = 그 점과 이웃 점들의 현재 값의 함수"로 작동한다. 이 "이웃"의 정의를 제공하는 게 장의 위상(topology, 격자의 연결 구조)이다.
- **[04 에너지 흐름]의 좌표를 준다.** source와 sink가 장의 *어느 위치*에 있느냐가 기울기의 방향을 정한다.
- **[06 재귀]에서 다시 등장한다.** 떠오른 entity들을 점으로 본 상위 세계 역시 또 하나의 장이다. 장은 스케일마다 한 겹씩 존재한다("원 안의 원").

## 프로토타입으로 만들 구조 설계

통합 프로토타입([07-prototype](07-prototype.md))에서 장이 기여하는 부분.

- **자료구조:** `N×N` 2D 격자. 메모리는 SoA(Structure of Arrays)로 — 필드별 `Float32Array(N*N)` 하나씩. (`E[]`, `T[]`, `rho[]`, `A[]`)
  - 시작 크기 `N = 64` (빠른 피드백). 검증되면 128 이상으로.
  - 인덱싱 `idx(x,y) = y*N + x`.
- **위상:** 4-이웃(von Neumann)을 기본으로. 경계 처리 2모드 토글 가능하게: `wrap`(토러스, 무한 세계 느낌) / `clamp`(닫힌 세계, 경계가 곧 sink).
- **불변식:** 장 자체는 tick 동안 바뀌지 않는다(크기·위상 고정). 바뀌는 건 항상 *양*뿐. → 디버깅 시 "구조 변화 = 버그" 판정 기준.
- **렌더:** `<canvas>` 픽셀 = 격자 셀 1:1 매핑. 한 픽셀의 색은 그 셀의 양들을 합성해 표현([02] 참조).

```js
const N = 64;
const field = {
  N,
  E:   new Float32Array(N*N),
  T:   new Float32Array(N*N),
  rho: new Float32Array(N*N),
  A:   new Float32Array(N*N),
  idx: (x,y) => y*N + x,
  // 4-이웃 (경계 모드는 wrap 예시)
  neighbors: (x,y) => [
    [(x+1)%N, y], [(x-1+N)%N, y],
    [x, (y+1)%N], [x, (y-1+N)%N],
  ],
};
```

## 검증 현황과 수정 이력

- **[step-0002](../step-0002.md)** — 설계 그대로 구현·통과. 64×64 SoA `Float32Array`, 4-이웃, wrap/clamp 토글 전부 동작. 장의 불변식(tick 동안 크기·위상 불변)도 유지됐다. **수정 없음.**
- **[step-0003](../step-0003.md)** — 이 문서의 예고 *"장은 스케일마다 한 겹씩 존재한다"* 가 실증됐다. 거시 장(16×16)이 `createSim(16)` 한 줄로 추가되고, 미시와 *같은 법칙*이 그 위에서 돌아 사회가 떠올랐다(거시 생명의 창 재현). 장 자체의 구조 변경은 없음 — 한 겹 더 쌓였을 뿐이다.
