step-0001 · 무엇을 만들려는가

field + 법칙 + 에너지 흐름을 설계하면 — 물질·생명·사회가 그 위에서 떠오른다.
세계는 만드는 게 아니라 떠오르게 한다. entity를 설계하지 말고, 칸·숫자·규칙·기울기를 깔면 나머지는 저절로 나온다.
인간을 모방하지 않는다정해진 시나리오·스크립트 대신, 원리·법칙을 깔고 세계가 스스로 전개되게 한다.
entity를 설계하지 않는다생명·날씨·생태계를 직접 만들지 않고, 그것들이 떠오를 토대만 설계한다.

세계를 이루는 6요소 — 한눈에

E 에너지(연료) ρ 밀도(물질) T 열(식은 찌꺼기) A 끌림(당기는 힘)
6개는 동등하지 않다 — 4 생성자 + 2 결과. 앞의 4개는 빼면 세계가 무너지는 최소 생성자이고, 뒤의 2개는 그 4개에서 저절로 따라 나오는 결과다(만드는 게 아니라 검출·관찰하는 대상). 더 많은 다양성이 필요하면 새 요소가 아니라 양·법칙 안에 필드·규칙을 더한다. 그래서 적지도 많지도 않은 6개.

생성자 4빼면 무너짐

  • 장 — 값이 사는 공간 (어디)
  • 양 — 칸에 담긴 숫자 (무엇)
  • 법칙 — 숫자를 바꾸는 규칙 (어떻게)
  • 에너지 흐름 — 평형(죽음)을 막는 엔진 (왜 굴러가나)

결과 2저절로 나옴

  • 항상성 — 떠오른 자기유지 패턴 = 생명
  • 재귀 — 같은 4개가 한 층 위에도 통함
모눈종이 / 픽셀 화면. "점"이란 곧 한 칸.
1장 Field생성자
무엇인가

값을 담는 공간 그 자체. 격자의 각 칸이 그릇이고, 모든 것은 이 위의 패턴일 뿐 별도 객체가 아니다.

왜 존재하는가

"entity를 안 만든다"가 여기서 강제된다. 설계할 수 있는 건 장과 규칙뿐 — 개별 존재는 원천적으로 설계 대상에서 빠진다.

어떻게 작동/상호작용

양을 담고, 법칙에 "이웃"의 정의를 주며, 재귀에서 한 겹 위 세계로 다시 등장한다.

프로토타입 구조

N×N 격자, 필드별 Float32Array(SoA), 4-이웃, 경계 wrap/clamp 토글. 장 자체는 tick 동안 불변 — 바뀌는 건 양뿐.

const N = 64;
const field = {
  N, E:new Float32Array(N*N), T:new Float32Array(N*N),
  rho:new Float32Array(N*N), A:new Float32Array(N*N),
  idx:(x,y)=>y*N+x,
  neighbors:(x,y)=>[[(x+1)%N,y],[(x-1+N)%N,y],[x,(y+1)%N],[x,(y-1+N)%N]],
};
칸마다 꽂힌 4개의 계기판. 칸의 색 = 숫자들의 합성.
2양 Quantity생성자
무엇인가

각 점에 저장되는 상태 숫자. 에너지 E, 열 T, 밀도 ρ, 끌림 A 4종으로 시작.

왜 존재하는가

세계의 다양성은 entity 종류 수가 아니라 양의 분포에서 나온다. 같은 4숫자라도 분포가 다르면 사막·숲·도시가 된다. 인간적 속성(체력·분노) 대신 물리적 원초 양에서 출발.

어떻게 작동/상호작용

장 위에 살고, 법칙의 입력이자 출력이며, 보존되며 서로 변환된다(E가 일하면 T로). 조합이 "의미"가 된다 — 높은 ρ+낮은 T=단단한 지형.

프로토타입 구조

더블 버퍼(cur→next), 0~1 정규화. 렌더: R←E, G←ρ, B←T. 보존 검사로 ΣE+ΣT 매 tick 로깅.

function cellColor(c,i){ return [c.E[i]*255, c.rho[i]*255, c.T[i]*255]; }
잉크가 물에 퍼지듯, 커피가 식듯. 이웃만 보고 갱신.
3법칙 Law생성자
무엇인가

양을 시간에 따라 바꾸는 국소 연산자 = 세계의 동사. 명사(entity)를 만들지 않고 변화의 방식만 정한다. 불가침 성질: 국소성 + 보존·소산(열역학).

왜 존재하는가

"인간 모방 안 함"의 실현 수단. 소수의 보편 법칙일수록, 한 영역에서 익힌 직관이 다른 영역에 그대로 전이된다(불 다루기 = 혁명 일으키기).

어떻게 작동/상호작용

4법칙을 매 tick 적용 — 확산(펼침)·응집(모음)·소산(식음)·임계(불연속 사건=도파민). 확산과 응집의 긴장을 에너지 흐름이 살아 있게 유지한다.

프로토타입 구조

각 법칙 = 순수 함수 + 토글. 파라미터 α,g,δ,θ 슬라이더로 "구조가 떠오르는 조합" 탐색.

function dissipate(E,T,delta){            // E가 일하며 T로 (보존)
  for(let i=0;ithE){ T[i]+=E[i]*.5; E[i]*=.3; rho[i]*=.8; }
}
방 한쪽 히터, 반대쪽 열린 창문. 기울기 = 세계의 엔진.
4에너지 흐름 Gradient생성자
무엇인가

E를 주입하는 source와 빼가는 sink, 그 사이의 공간적 기울기. 세계를 평형(=죽음)에서 떼어놓는다.

왜 존재하는가

세계가 스스로 굴러가게 하는 유일한 원동력. 기울기가 있으면 그것을 해소하는 구조(소산 구조)가 저절로 생긴다. 콘텐츠 없이 끝없는 사건 — 보상과 대가가 같은 법칙에서 나온다.

어떻게 작동/상호작용

양 E로 구현. 확산이 지우려는 기울기를 source가 다시 만들어 법칙을 살아 있게 한다. 플레이어 행위 = source/sink를 옮기고 만드는 것(불 지피기, 댐 쌓기).

프로토타입 구조 · 핵심 실험

클릭으로 source(+)/sink(−) 배치, ∇E 흐름 화살표. source 강도를 0→max로 올리며 "생명의 창"을 찾는다 — 0이면 죽음, 적당하면 구조 출현, 과하면 폭주.

촛불, 강물 속 소용돌이. 흐름이 통과해도 모양은 유지.
5경계·항상성 Agent결과
무엇인가

법칙+흐름이 만든 자기유지 패턴. 경계를 갖고 흩어지지 않으려 끊임없이 기울기를 처리한다. 이게 곧 "생명" — 우리가 만든 게 아니라 떠오른 끌개(attractor).

왜 존재하는가

"entity를 안 만든다"의 결정적 증거. 욕구도 공짜로 따라온다 — E가 떨어지면 흩어지므로 본질적으로 E를 향해 움직이고 경쟁한다(배고픔·번식·회피가 emergent).

어떻게 작동/상호작용

기울기의 자식(source 끊기면 죽음). 특별한 규칙 없이 같은 4법칙이 패턴 위에서 돌 뿐 → 직관 전이가 유지된다. 둘이 만나면 경쟁(포식·공생).

프로토타입 구조 — 검출이 핵심

만들지 않으므로 찾아내는 코드가 필요: ρ 임계 이상 셀을 연결요소로 묶고(flood fill), ID로 시간 추적해 수명·안정성·대사(E 순유입)를 만족하면 "살아있는 agent"로 승격.

6재귀 Recursion결과
무엇인가

1~5 구조 전체가 한 단계 위에서 그대로 반복. agent들을 점으로 보면 새 장이 생기고 같은 법칙으로 무리·사회·문명이 떠오른다.

왜 존재하는가

"불 다루기 = 혁명 일으키기"를 성립시키는 유일한 메커니즘 — 두 스케일이 같은 법칙으로 돌기 때문. 새 콘텐츠 없이 새 층이 열려 세계가 사실상 무한해진다.

어떻게 작동/상호작용

agent의 mass→상위 ρ, intake→상위 E. 같은 법칙 재적용으로 무리·전파·쇠퇴·혁명이 나온다. 위아래가 양방향으로 결합(사회 붕괴 ↔ 구성원 환경 급변).

프로토타입 구조

2층까지만 검증. 법칙 함수가 "이웃을 가진 점들의 집합"에 동작하게 추상화하면 미시·거시가 문자 그대로 같은 함수를 쓴다.

function step(points, neighborsOf, p){
  diffuse(points,neighborsOf,p.alpha); attract(points,neighborsOf,p.g);
  dissipate(points,p.delta);           threshold(points,p.theta);
}
// 미시: points=격자셀, neighborsOf=4-이웃
// 거시: points=agent들, neighborsOf=반경 내 agent  ← 같은 step() = 원 안의 원

어떻게 결합하여 세계를 이루는가

장이 양을 담고 → 법칙이 양을 국소적으로 바꾸는데 → 에너지 흐름이 평형을 막아서 → 법칙이 양을 구조로 조직하고(= 떠오른 항상성, 곧 욕구) → 같은 규칙이 군집에도 적용되어(재귀) 사회·문명으로 자라난다.

통합 프로토타입 — tick 루프

6요소를 한 HTML+JS 화면에서 검증한다. 법칙 적용 순서는 결과를 바꾸므로 고정하고, 각 단계는 토글 가능.

순서단계요소
1source 주입 / sink 배출에너지 흐름
2확산 (T, E 약하게)법칙
3응집 (ρ ← A)법칙
4소산 (E→T→sink)법칙
5임계 (발화·응결·탄생)법칙
6버퍼 교체양
7agent 검출 + 시간추적항상성

9렌더 + 지표 갱신—

1차 검증 기준

  1. 보존 — source/sink 유입출을 빼면 ΣE+ΣT 변화 ≈ 0.
  2. 생명의 창 — source 강도 중간 구간에서만 안정 agent 수 > 0.
  3. 비정지성 — 그 구간에서 구조가 생멸을 반복하며 화면이 멈추지 않음.
  4. 재귀(2층) — 거시에서도 agent 무리가 자기유지하고, 미시 source 차단이 거시 붕괴로 전파됨.

현실 물리와의 관계

진짜 맞닿는 부분

확산 = 열방정식 ∂u/∂t = α∇²u. 보존·소산 = 열역학 1·2법칙. 특히 에너지 흐름 → 생명은 비평형 열역학의 소산 구조(Prigogine) — 베나르 대류·태풍·생명이 모두 "기울기를 먹고 모양을 유지하는" 같은 부류다. 가장 깊고 정확한 연결.

은유 수준

응집은 만류인력의 캐리커처(뉴턴 법칙 그대로는 아님). 임계/상전이는 실제 현상이지만 "양자역학"이라는 이름은 비유.

일부러 다르게 한 부분

모든 스케일에 같은 법칙(재귀)은 현실 물리엔 일반적으로 없다(양자·고전·상대론 영역이 다름). 이는 "불 다루기 = 혁명 일으키기"의 직관 전이를 위한 의도된 선택. AI 함수화도 물리가 아니라 구현 트릭.

현실 물리를 복제하는 게 아니라, 사람들이 이미 가진 물리 직관이 그대로 통하도록 빌려 쓴 양식화된 게임 물리.

부록 · AI 함수화 (요소가 아닌 구현 트릭)
