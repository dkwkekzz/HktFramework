## 1. 의도

> 오픈월드 MMORPG에서 무한한 미지의 세계를 경험하는 것.
> 이전에 경험하지 못했던 끝없는 성장과 상호작용을 통해 다채롭고 도파민을 뿜어내는 모험을 제공하는 세계를 구축한다.

플레이어에게 정해진 콘텐츠를 순서대로 소비시키는 것이 아니다. 플레이어가 스스로 목적을 세우고,
그 목적을 달성하기 위해 세계를 이해하고 탐험하며, 필요한 재료·지식·능력·관계·환경을 획득하게
만든다. 하나의 목적은 세부 목적으로, 세부 목적은 **재료를 제공하는 무대(기회)** 까지 분할된다.

이 문서가 답하는 세 가지:

1. 목적 트리를 채우면 어떤 모양이 되는가 (§3)
2. **말단 단위**는 무엇으로 구성되는가 (§4)
3. 이것을 게임에서 **시각적으로** 어떻게 표현하는가 (§6)

## 2. 핵심 원리

### 2.1 목적 노드 = 상태 차이

모든 목적 노드는 행동의 나열이 아니라 **상태 차이**로 표현한다:

```
현재 상태 → 원하는 상태 → 두 상태의 차이 → 차이를 유지시키는 장애물
→ 장애물을 해소하는 데 필요한 조건 → 각 조건을 만드는 하위 목적
```

분해의 요체는 할 일을 나열하는 것이 아니라 **목적 달성을 막고 있는 상태(장애물)를 찾아내는 것**이다.

```
현재 상태:   거대 신이 존재하며 지속적으로 재앙을 발생시킨다.
원하는 상태: 거대 신이 더 이상 나의 생존을 위협하지 않는다.
상태 차이:   신이 살아 있고, 공격 방법을 모르고, 접근할 수 없고, 죽인 뒤의 결과도 모른다.
필요 조건:   정체 이해 · 약점 발견 · 공격 수단 · 접근 · 생존 준비 · 후속 재앙 방지
```

이 문법은 HktFeature 0018의 동기 정의("**줄이려는 상태 차이**")를 뿌리에서 말단까지 **재귀
적용**한 것이다 — 뿌리만 동기인 것이 아니라, 모든 노드가 같은 문법의 작은 동기다.

### 2.2 완료 판정은 상태를 묻고, 경로를 묻지 않는다

노드의 완료 조건(`done_when`)은 **세계 상태에 대한 술어**다. 퀘스트 플래그가 아니다.

```
나쁨: 거대_신_제거_퀘스트_완료 == true
좋음: 신의 영향력 ≤ 임계값 ∧ 재앙 발생 불가 ∧ 육체 재구성 불가 ∧ 숭배자의 힘 공급 차단
```

따라서 같은 목적에 여러 정답이 공존한다 — 직접 죽인다 · 봉인한다 · 추방한다 · 힘의 근원을
차단한다 · 숭배자를 없애 굶주리게 한다 · 다른 거대 존재와 충돌시킨다 · 권능을 흡수한다.
**시스템이 제시하지 않은 방법이라도 술어를 충족하면 성공이다** — 플레이어의 발명이 공식 경로가 된다.

### 2.3 분해 정지 조건 — 말단은 품목이 아니라 속성을 요구한다

어떤 목적이 "**단일 상태 변화**를 만드는 행동 단위"로 환원되면 분해를 멈춘다. 말단의 문법:

```
[대상]에 [행동]을 수행하여 [조건]을 만족시키고 [상태 변화]를 발생시킨다.
```

이때 말단의 요구는 **품목명이 아니라 속성**으로 쓴다:

```
나쁨: 신성 광석 10개를 수집한다.
좋음: 신성 에너지를 견딜 수 있는 재료를 확보한다.
      → 신성 광석 채굴 / 거대 생물 껍질 / 금속을 신성 에너지에 노출해 변형 /
        타 플레이어에게 구매 / 균류 배양 / 고대 장비 분해 … 전부 정답
```

속성 요구가 곧 다중 해법(§5 원칙 3)의 근거이고, 그 판정 기반이 물질 속성 시스템(0013)이다.

### 2.4 트리가 아니라 DAG

한 무대는 여러 목적의 재료를 동시에 공급하고(권속의 심장 = 약점 조사의 표본이자 약물의 촉매),
한 세부 목적이 여러 상위에 봉사한다(약물 제작 → 위협 제거와 성장 양쪽). 목적 계층은 **DAG**다 —
개발용 Goal 그래프([goal-system-design.md](goal-system-design.md))가 DAG인 것과 같은 이유이며,
이 겹침이 "한 행동이 여러 진행을 동시에 미는" 도파민의 원천이다.

### 2.5 트리는 세계의 진실이 아니라 플레이어의 믿음이다 — 가설·실험 루프

목적 그래프의 노드는 **플레이어가 세계를 이해한 만큼만** 존재한다. 각 노드·재료·약점은
**발견 상태**를 가진다: `미발견 → 추정(가설) → 확인 / 반증`.

- 약점은 주어지지 않는다 — **관찰 → 가설 → 실험 → 검증**으로 발견한다:
  ```
  가설: 거대 신은 특정 진동에 취약하다
  ├─ 신의 조직을 확보한다          ├─ 여러 진동 주파수 발생 수단을 만든다
  ├─ 조직에 진동을 가해 반응을 측정한다   ├─ 유효 주파수를 기록한다
  └─ 실제 개체에게 재현되는지 검증한다
  ```
- 잘못된 가설은 반증되어 그래프에서 **붕괴**한다 — 지식도 소모·갱신되는 자원이다.
- **상향 발견**: 미지의 무대에서 용도 불명의 재료를 먼저 얻고, 나중에 분해 중 그 재료 요구와
  만나는 순간 가지가 통째로 역결합하며 밝혀진다 — "그 비늘이 여기 쓰이는 거였구나".

플레이어마다 다른 가설 경로로 다른 약점(독성·저온·신앙 차단·무광 환경·언어의 역순 발화…)에
도달할 수 있다 — 약점은 정답 하나가 아니라 물질·생명·에너지 시스템의 결합에서 **발견**된다.

### 2.6 무한성의 근거

- 뿌리 목적은 유한하고 안정적이다 — 세계관의 척추 (§3.1).
- 중간 목적은 세계 상태로부터 계산·생성된다 — "거대 신"은 하드코딩 보스가 아니라 "현재 세계의
  최상위 위협" 슬롯이다 (§5 원칙 2).
- 말단·무대는 절차 생성 + 속성 조합으로 무한하다 (유니크 아이템 철학, 방향성 문서 §6.3·§9.2).
- **결과가 새 목적을 생성한다** — 세계 수준(신이 죽자 신성 에너지 유출·억압받던 종의 폭증·숭배
  문명 붕괴)과 **개인 수준**(강화 약물의 부작용 통제 · 변형된 신체에 맞는 장비 · 변형된 몸을
  거부하는 세력 상대) 모두에서. 목적 달성은 콘텐츠의 종료가 아니라 다음 세계 상태의 시작이다.

## 3. 목적 트리 초안

### 3.1 뿌리 — 생존의 일곱 얼굴

생존은 "체력이 0이 되지 않는 상태"가 아니다. 즉각적 죽음의 회피부터 존재 방식의 확장까지를
포함하며, 욕구 시스템의 동기와 정렬된다:

```
0. 생존해야 한다
├─ 0.1 생존을 방해하는 위협을 제거하거나 통제한다        [동기: 안전]
├─ 0.2 생존 능력을 성장시킨다                            [동기: 성장(허기의 확장)]
├─ 0.3 생존에 필요한 자원을 안정적으로 확보한다           [동기: 허기·질서]
├─ 0.4 환경에 적응한다                                   [동기: 안전(환경)]
├─ 0.5 실패해도 회복할 수 있는 기반을 만든다              [동기: 질서]
├─ 0.6 다른 존재와의 관계로 생존 가능성을 높인다          [동기: 사회/소유 — 협동·시혜 기둥]
└─ 0.7 기존 육체와 존재 방식의 한계를 극복한다            [동기: 성장의 극한]
```

### 3.2 폭 — 위협 제거 가지의 전개

위협은 몬스터만이 아니다: 생명체·문명·종교·날씨·독성 물질·생태계 붕괴·에너지 폭주·질병·
공간 이상·**잘못된 플레이어의 행동**까지, 세계 상태로 표현되는 모든 것이 위협 슬롯을 채운다.

```
0.1 위협을 제거하거나 통제한다
├─ 0.1.1 세계적 재앙을 발생시키는 존재를 제거한다 (예: 만악의 거대 신)
├─ 0.1.2 지역의 직접적 위협을 제거한다 (마수 둥지 → 위치 파악 → 파괴)
├─ 0.1.3 질병·저주·오염의 확산을 막는다
├─ 0.1.4 적대 세력을 약화시킨다 (예: 수송로 차단 → 신에게 가는 희생물 감소)
├─ 0.1.5 제거할 수 없는 위협을 회피하거나 봉인한다
└─ 0.1.6 위협이 발생하는 근본 원인을 변화시킨다
```

### 3.3 깊이 — 거대 신 가지의 수직 절단

```
0.1.1 거대 신을 제거한다 (done_when: 신이 더 이상 생존을 위협하지 않는다 — §2.2 술어)
├─ 0.1.1.1 정체와 행동 원리를 파악한다
│    흔적 추적 · 출현지 조사 · 목격자 증언 · 영향받은 물질 채취 · 고대 기록 해독 ·
│    연관 생물 분석 · 행동 주기/경로 추론 · 힘의 원천 추론 · 가설 실험 검증
├─ 0.1.1.2 약점을 발견한다                           ← §2.5 가설·실험 루프의 집
│    신체 구조 · 구성 물질 분석 · 에너지 순환 · 회피하는 환경 · 저항한 생명체 조사 ·
│    손상/회복 관찰 · 유사 하위 생명체 실험 · 공격 수단 시험 · 재현성 확인
├─ 0.1.1.3 피해를 줄 수단을 확보한다                  ← 속성 기반 제작의 집 (§4.2)
│    공격 원리 결정 → 구조 설계 → 필요 속성 정의(진동 전달률·에너지 손실·내구성·
│    반응 표면·절연) → 속성을 충족하는 재료 탐색(수정질 광물/거대 생물의 뼈/
│    금속-균류 복합체/고대 인공 결정/타 플레이어의 합성 물질…) → 채취 → 정제·가공 →
│    결합 → 안정화 → 시험 → 실패 분석·개선 → 운반
├─ 0.1.1.4 거처에 접근한다 (열쇠=권리 · 경로=정보 · 탈것=생명체)
├─ 0.1.1.5 충돌에서 살아남을 준비를 한다 (0.2 가지와 분해 공유)
├─ 0.1.1.6 결전을 수행할 세력을 규합한다 (관계 재료 — 협동 기둥 결합점)
├─ 0.1.1.7 제거를 실행한다
├─ 0.1.1.8 남긴 결과를 처리한다 (유출된 신성 에너지, 신의 육체=희귀 재료)
└─ 0.1.1.9 부활·재생을 막는다 (숭배 구조·힘의 공급 감시)
```

성장(0.2)·자원(0.3) 가지도 같은 문법으로 전개된다 — 장비는 "방어력 +N"이 아니라 기능으로
정의되고(체온 방출·독기 여과·감각 은폐·충격의 에너지 전환·자가 증식 수복…), 약물의 결과는
공격력 증가가 아니라 신체의 변화(무산소 활동·생명력→열 전환·조직 흡수 재생·이성 유지 곤란…)이며
그 부작용이 **새 목적을 낳는다**(§2.6). 자원은 고정 채집 포인트가 아니라 발생 원리(생명체의
생산·계절·물질 반응·재앙의 흔적·문명의 축적·타 플레이어의 실패로 인한 유출)를 **이해해야**
안정적으로 확보된다.

### 3.4 구조적 관찰

- **모든 가지가 재료 요구(§4.1)로 수렴한다.** 상위가 아무리 서사적이어도 말단은 "어떤 속성을
  가진 무엇을 어디서 얻는다/만든다/알아낸다"다 — 서사와 월드 콘텐츠의 접합면.
- **가지끼리 재료·무대·분해를 공유한다** (§2.4 DAG).
- 깊이는 뿌리에서 말단까지 대체로 **4~6 단**. 말단 하나 = 마이크로 루프(30초~5분), 세부 목적
  하나 = 미들(30분~2시간), 상위 가지 = 매크로(주~월) — 3단 루프(방향성 문서 §6.1)와 대응.

## 4. 말단 단위의 해부

### 4.1 재료의 종류 — 말단이 요구하는 것

"재료를 제공한다"는 상자에서 아이템을 주는 것이 아니라, 세계가 목적 달성에 이용할 수 있는
**가능성**을 제공한다는 뜻이다. 재료는 열 갈래다:

| 종류 | 예 | 성격 |
|---|---|---|
| **물질** | 광석, 혈액, 뼈, 조직, 식물, 결정 | 보유형 |
| **에너지** | 열, 전기, 마력, 생명력, 신성력 | 보유형 — HktFeature 세계의 **결제 통화** |
| **정보** | 기록, 지도, 관찰 결과, 행동 패턴 | 보유형 (관측 데이터) |
| **지식** | 제작법, 언어, 생태 이해, 약점 가설 | 보유형 (재현 가능한 이해 — 검증 필요) |
| **능력** | 감지, 채집, 가공, 전투, 이동 | 보유형 (몸에 붙음) |
| **생명체** | 운반 생물, 공생체, 소환체, 희생체 | 보유형 (살아있는 도구) |
| **관계** | 동료, 세력의 신뢰, 거래 권한 | 상태형 (세계에 존재하는 관계) |
| **접근권** | 폐허의 문, 특정 지역, 의식 장소 | 상태형 |
| **환경 상태** | 폭풍, 월식, 고온·저온, 특정 계절 | 상태형 — 소유 불가, **맞이해야** 한다 |
| **시간과 기회** | 출현 주기, 번식기, 세력 간 전쟁 | 상태형 — 소유 불가, **포착해야** 한다 |

- **보유형/상태형 축**이 게임플레이를 가른다: 보유형은 획득·저장·거래되고, 상태형은 기다리고
  맞추고 유지해야 한다. 상태형 재료("월식 아래에서만") 가 일정·타이밍·계획 플레이를 만든다.
- **정보와 지식의 구분**: 정보는 관측된 사실, 지식은 재현 가능한 이해다. 정보는 모으면 되지만
  지식은 검증(§2.5)을 거쳐야 `확인` 상태가 된다 — 가설 시스템과 맞물리는 지점.
- 물질·에너지 재료의 실체는 HktFeature의 속성 있는 물질(0013)과 에너지 원장(0001~0003)이다.

### 4.2 좋은 말단의 네 조건

1. **하나의 명확한 상태 변화를 만든다** — 미발견→발견, 미보유→보유, 성질 미상→성질 확인,
   작동 불가→작동 가능.
2. **실제 선택을 제공한다** — 어디를 조사할지, 어떤 도구로, 어느 위험까지, 다량·저순도 vs
   소량·고순도, 누구와 거래할지, 어떤 부작용을 감수할지. 선택이 없으면 시스템 연산이지 목적이 아니다.
3. **결과를 감각으로 확인할 수 있다** — 형태·색·소리·진동·생명체의 반응·환경의 변화·측정
   도구의 출력 (§6.4). `done_when` 은 기계 판정 가능해야 하고(HktFeature 불변 원칙 ①의 목적
   시스템 버전), 그 판정이 플레이어의 감각에도 보여야 한다.
4. **여러 해결 방법을 허용한다** — 속성 요구(§2.3)가 이것을 보장한다.

### 4.3 행동 유형 — 네 가족, 열일곱 동사

말단의 `verb` 는 다음 중 하나다. **각 동사는 독립 미니게임이 아니라 세계의 공통 상호작용
법칙(속성·자극·전이 0013, 에너지 지불 0018)의 조합으로 구현한다** — 동사가 늘어도 법칙은 늘지 않는다.

| 가족 | 동사 | 기능 |
|---|---|---|
| **인식** | 탐색 · 관찰 · 비교 · 실험 · 검증 | 위치/흔적 발견, 성질·행동 이해, 차이 확인, 조건-반응 확인, 목적 조건 충족 확인 |
| **수급** | 채취 · 포획 · 운반 · 보존 | 일부 분리, 생포, 이동, 상태 유지 |
| **변환** | 분해 · 정제 · 변환 · 결합 · 조율 | 구성 요소 분리, 불순물 제거, 상태 변화, 새 구조 조립, 에너지·진동·온도 값 맞춤 |
| **세력** | 전투 · 보호 · 협상 | 상대의 행동 가능성 감소, 상태 유지 방어, 타자의 행동·관계 변경 |

인식 가족이 다섯 동사로 독립해 있는 것이 이 설계의 특징이다 — 아는 것 자체가 재료(정보·지식)
이므로, 앎의 획득도 채집과 동급의 플레이다.

### 4.4 목적 노드의 스키마

말단만이 아니라 **모든 노드**가 같은 구조를 가진다 (말단 = 하위 목적이 없는 노드):

```yaml
GoalNode:
  desired: 거대 신의 조직에 남은 신성 잔향을 보유한 상태     # 원하는 상태
  current: 잔향 없음 · 조직의 위치만 추정                    # 현재 상태 (플레이어 기준)
  done_when: 인벤토리에 신성 잔향 속성체 ≥ 1                 # 세계 상태 술어 — 기계 판정 (필수)
  demand:                                                    # 필요 재료 — 속성으로 기술 (§2.3)
    - {kind: 물질, property: 신성 잔향 보존율 ≥ X}
    - {kind: 환경 상태, property: 조직 소멸 전 시간 내}
  obstacles: [강한 신성 방사, 조직을 지키는 생명체, 시간 경과 시 소멸, 경쟁 세력]
  verb: 채취                    # 말단이면 단일 동사 (§4.3) — 분해 정지의 증명
  serves: [0.1.1.1.4, 0.2.3.2]  # 봉사하는 상위 목적들 — DAG 다중 부모
  alternatives: [숭배자의 유물 강탈, 하위 생명체 포획 후 추출]   # 대체 경로 (원칙 3)
  epistemic: 추정               # 미발견 / 추정 / 확인 / 반증 (§2.5)
  evidence: 봉인 용기 내 잔향 측정치                        # 완료 증거 — 감각 확인 (§4.2-3)
  aftermath: [주변 생태 변화, 적대 세력의 추적 시작]          # 후속 결과 → 새 목적의 씨앗 (§2.6)
  stages: [S-0045]              # 이 요구에 응답하는 기회들 — 발견된 것만
```

### 4.5 기회(무대)의 스키마 — 세계의 응답

무대는 목적 노드가 아니라 세계가 재료 요구에 응답하는 **기회**다:

```yaml
Stage:
  source: 거대 신이 지나간 자리의 조직 조각            # 기회의 원천 (실존하는 세계 요소)
  supplies:                                            # 공급 테이블 — 속성 기준
    - {property: 신성 잔향, rule: 시간 경과 시 소멸, purity: 채취 방식에 따라}
  obstacles: [신성 방사(오염), 수호 생명체, 경쟁 세력, 접촉 시 플레이어 변이]
  interactions: [흔적 추적, 오염 측정, 절단, 누출 방지, 봉인, 운반]   # §4.3 동사의 조합
  choices:                                             # 위험-보상 트레이드 (§4.2-2)
    - 다량 신속 채취 (오염 감수) ↔ 소량 정밀 채취
    - 전체 운반 ↔ 현장 정제 ↔ 생명체에 이식해 운반 ↔ 타 세력에 위탁
  outcomes: [고순도 잔향, 오염된 잔향, 신의 새 특성 발견, 신체 변형, 생태 변화, 추적당함]
  discovered: false                                    # 미발견 무대는 그래프에 "?" 로만
```

무대의 다섯 성질:

1. **공급 규칙이 곧 게임플레이다.** "시간 경과 시 소멸"은 긴박함을, "채취 방식에 따른 순도"는
   숙련을, "경쟁 세력"은 사회적 긴장을 만든다. 재료를 그냥 주는 무대는 무대가 아니라 상점이다.
2. **위험이 가격이다.** obstacles 가 위험-보상 그래디언트(방향성 문서 §5.3)를 실어 나른다.
3. **고갈·이동한다.** 같은 목적도 다음에는 다른 무대에서 풀린다 — 공략의 화석화 방지.
4. **발견되기 전에는 "?" 다.** 무대의 존재 자체가 정보 재료로 유통된다.
5. **세계는 재료를 생성하지 않는다 — 재해석한다.** 플레이어가 내열성 재료를 원할 때 세계는
   아이템을 스폰하는 것이 아니라, **이미 존재하는** 요소들(화산 생물의 껍질, 용암 광물, 불의
   문명의 장비, 고온에 변형된 나무, 열을 먹는 균류)을 목적 관점에서 재해석해 기회로 노출한다.
   현재 세계 상태에서 실존 가능한 기회만 발견될 수 있다.

## 5. 생성 규칙 — 트리는 누가 채우는가

- **원칙 1 — 목적은 플레이어가 정한다.** 시스템은 수행할 목적을 명령하지 않는다. 세계 상태를
  보여주고 플레이어가 원하는 상태를 선택하게 한다. 뿌리(§3.1)는 설계자가 고정하는 문법이지
  강제되는 퀘스트가 아니다.
- **원칙 2 — 하위 목적은 세계 상태로부터 계산한다.** 같은 목적도 세계가 다르면 분해가 다르다:
  신이 육체를 가지면 → 파괴 수단, 신앙으로 존재하면 → 숭배 구조 붕괴, 공간 현상이면 → 유지
  조건 변경. 이것은 사실상 세계 상태 위의 **플래너**다 — 세계 상태가 술어로 읽히는(legible)
  것이 전제이며, 원장·속성·tx 로 이루어진 HktFeature 세계가 이미 그 조건을 충족한다.
- **원칙 3 — 모든 하위 목적에 대체 경로가 존재한다.** 재료 하나가 없어서 영원히 막히면 안 된다:
  찾는다·만든다·훔친다·거래한다·대체한다·생물에게 생산시킨다·다른 원리로 달성한다.
  속성 기반 요구(§2.3)가 이것의 구조적 보장이다.
- **원칙 4 — 플레이어가 새로운 경로를 발명할 수 있다.** `done_when` 이 세계 상태 술어(§2.2)인
  한, 시스템이 모르는 방법도 자동으로 성공이 된다.
- **원칙 5 — 결과가 새로운 목적을 생성한다.** 모든 성공은 `aftermath` 로 세계에 변화를 남기고,
  그 변화가 다음 상태 차이(=목적)를 만든다 (§2.6).

**생성의 제약** — AI 가 생성하는 어떤 가지도: (a) 말단이 §4.1 재료 종류로 환원되고,
(b) `done_when` 이 세계 상태 술어로 기계 판정 가능하며, (c) 응답하는 기회가 현재 세계에 최소
1개 실존해야 한다(§4.5-5). 통과 못 하면 세계에 넣지 않는다 — 수행 불가능한 목적 방지.

## 6. 시각 표현

원칙: **트리를 통째로 보여주지 않는다.** 전체가 보이는 순간 세계는 체크리스트가 되고 미지가
죽는다. 층마다 다른 시각 언어로, **플레이어가 이해한 만큼만**(§2.5) 보여준다.

### 6.1 세 개의 시야 — 같은 그래프, 세 카메라

| 층 | 시각 장치 | 화면 위치 | 답하는 질문 |
|---|---|---|---|
| 말단 (지금) | **나침반/표식** — 활성 말단 하나만 | HUD 상시 | "지금 뭘 하지?" |
| 세부 목적 (오늘) | **방사형 목적 그래프** — 중앙에 현재 핵심 목적, 바깥으로 필요 조건 → 재료·행동, 연결선 = 인과·의존 | 열어보는 창 | "이걸 왜 하지?" |
| 전체 (인생) | **별자리 지도** — 발견 노드는 별, 완료는 밝게 점등, 미발견 가지는 성운 | 전체 화면 | "나는 어디까지 왔지?" |

방사형 그래프와 별자리 지도는 **같은 DAG의 두 카메라**다 — 하나는 현재 목적 중심의 자기(ego)
시점, 하나는 축적된 이해 전체의 시점. 별자리 은유의 이유: 미발견이 "빈 칸"이 아니라 "성운"으로
읽혀 결핍이 아닌 기대가 되고, DAG 교차 간선이 별자리 연결선으로 자연스러우며, 별이 무한히
늘어나는 것이 세계관과 일치한다.

### 6.2 앎의 상태를 그린다 — 그래프는 이해의 지도

발견 상태(§2.5)가 렌더 문법을 정한다:

```
확인된 목적:      선명하게
추정(가설):       흐리고 불안정하게 — 떨리는 선
가능성 분기:      여러 갈래의 유령 가지
미발견:          안개·성운·빈 공간
반증된 가설:      붕괴·변형되는 연출 — 지식이 죽는 순간도 보여준다
```

위치 정보도 같은 원리다 — 정확한 마커 대신 **정보 정확도에 따라 좁아지는 탐색 영역**:

```
낮음:   "북쪽의 황폐한 지역에서 흔적이 발견되었다"      (넓은 방향 부채꼴)
중간:   "붉은 강과 검은 숲 사이에서 강한 반응"          (영역 하이라이트)
높음:   "특정 동굴 내부에서 목표 물질의 반응 측정"       (좁은 원)
직접:   세계에 실제 대상이 시각적으로 나타남              (마커 소멸 — 실물이 마커)
```

플레이어는 마커를 따라가는 것이 아니라 **정보의 정확도를 올려가며** 접근한다 — 인식 가족
동사(§4.3)가 이 정확도를 올리는 행위다.

### 6.3 도파민의 시각화 — 상향 파문, 숫자 없는 진행

말단 완료 순간, 그 노드에서 뿌리 방향으로 **빛의 파문이 계보를 타고 올라가며** 경유하는 조상
노드의 **충족된 조건을 점등**한다 (HUD 에는 짧게, 별자리 지도에는 성대하게).

- 진행도를 하나의 숫자로 요약하지 않는다 — "연구 진행도 72%" 가 아니라 **조건들의 상태 서술**:
  ```
  이동 경로 확인됨 · 에너지원 가설 둘 경합 중 · 재생 방식 미상 ·
  저온 반응 확인(약점 여부 불확실) · 재료 확보(안정화 방법 없음)
  ```
  파문이 채우는 것은 퍼센트 바가 아니라 이 조건 노드들이다.
- 마이크로 행동(잔향 채취)이 매크로 서사(신을 죽인다)에 닿아 있음을 매번 몸으로 보여준다.
- DAG 이므로 한 완료가 **여러 갈래로 동시 파문**할 수 있다 — 권속의 심장 하나가 약점 조사와
  약물 촉매 두 가지를 동시에 울릴 때가 설계상 최고의 순간.
- 상향 발견(§2.5) 시에는 역연출: 새 가지가 한꺼번에 점등되며 이미 가진 재료들이 제자리로
  날아가 결합한다. 반증 시에는 가지의 붕괴 — 상실도 연출이다.

### 6.4 세계 안의 표식 — 속성은 행동으로 보인다

재료의 성질은 숫자 툴팁이 아니라 **물질의 행동**으로 보여준다. 플레이어는 관찰로 성질을
추론한다 (인식 동사 '관찰'·'비교'의 실체):

| 속성 | 감각 표현 |
|---|---|
| 높은 열전도 | 열이 빠르게 퍼지는 발광 |
| 불안정성 | 표면의 떨림·균열·불규칙한 소리 |
| 신성 에너지 | 주변 물질의 부유, 빛의 왜곡 |
| 독성 | 주변 식생의 변색, 생명체의 회피 |
| 공명 | 특정 소리에 반응하는 진동 |
| 높은 순도 | 일정하고 안정적인 패턴 |
| 혼합물 | 여러 패턴의 충돌·불규칙 변화 |

- **재료 공명 발광**: 활성 말단이 요구하는 **속성**을 가진 대상이 시야에 들면 은은히 빛난다
  (공명 — HktFeature 0015 와 같은 시각 문법). 목적이 세계를 다르게 보이게 만드는 직접 체험.
- **무대의 문턱**: 기회 영역 진입 시 짧은 명패와 환경 연출 변화. 미발견 무대는 §6.2 의 탐색
  영역 문법을 따른다.
- **위험의 정직한 표시**: obstacles 는 환경 연출(독안개의 색, 뼈 무더기, 식생의 회피)로 사전
  고지한다 — 위험-보상 판단을 플레이어의 읽기 능력에 맡기는 것 자체가 콘텐츠다.
- **타인의 파문**: 같은 무대의 다른 플레이어의 완료 파문이 희미하게 보인다 — 사회적 존재감의
  배경 복사. 시혜 연출(각인)과 같은 문법.

### 6.5 제작의 가시화 — 과정에 개입한다

제작은 슬롯+버튼이 아니라 **재료가 실제로 변하는 과정**이다: 절단→분쇄→가열→가압→침투→공생→
조율 속에서 결정이 성장하고 불순물이 분리되고 불안정부가 폭주한다. 플레이어는 그 변화를 **보고
개입한다** — 온도를 낮추고, 압력을 올리고, 불순물을 걷어내고, 폭주를 의도적으로 허용한다.
완성품의 형태와 기능이 이 과정에서 실제로 결정된다 — 변환 가족 동사(§4.3)의 시각적 실체이며,
같은 목적의 플레이어들이 서로 다른 결과물을 만드는 이유다.

### 6.6 렌더 규율

시각 표현이 무엇이 되든 파이프라인은 `세계 속성 → ViewModel → 렌더(속성 그대로)`
(HktFeature 불변 원칙 ③)를 지킨다. 목적 그래프·발견 상태·파문 이벤트·속성의 감각 표현은 전부
세계 속성/권위 tx 에서 파생한 Scene 서술자로 노출하고, 렌더러는 그것을 그릴 뿐이다 — 별자리
지도를 지금은 대충 그리다가 나중에 통째로 갈아끼울 수 있어야 한다.
