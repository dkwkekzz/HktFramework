# 목적 계층 설계 — 목적에서 무대까지 (Objective Hierarchy)

> **종류:** 게임 디자인 설계
> **의존 문서:** [히키토의_대모험_방향성.md](히키토의_대모험_방향성.md) (비전·4 기둥)
> **관련 구현 트랙:** [HktFeature feature-0018 욕구 시스템](../HktFeature/features/feature-0018-motive-strategy.md) (동기→전략→절차 런타임 기반)
> **상태:** v0.1 초안 / 2026-07-20

---

## 1. 의도

> 오픈월드 MMORPG에서 무한한 미지의 세계를 경험하는 것.
> 이전에 경험하지 못했던 끝없는 성장과 상호작용을 통해 다채롭고 도파민을 뿜어내는 모험을 제공하는 세계를 구축한다.

이를 위해 플레이어에게 **하나의 목적으로부터 세부 목적으로 분할하고, 그 목적에 필요한 재료를
제공하는 무대**를 만든다. 즉 목적을 "재료를 제공하는 단위(=무대)"까지 분할하는 것이 이 문서의 주제다.

이 문서가 답하는 세 가지:

1. 목적 트리를 어느 정도까지 채우면 어떤 모양이 되는가 (§3)
2. **말단 단위**는 무엇으로 구성되는가 (§4)
3. 이것을 게임에서 **시각적으로** 어떻게 표현하는가 (§6)

## 2. 핵심 원리 — 목적은 "재료 요구"에서 끝난다

### 2.1 분해 사슬

```
목적 (왜 사는가)
 └─ 세부 목적 (무엇을 이루면 되는가)          ← 재귀적으로 반복
     └─ 재료 요구 (그러려면 무엇이 필요한가)   ← 분해의 말단
         └─ 무대 (세계가 그 재료를 공급하는 장소·상황)
```

- **분해 정지 조건**: 어떤 목적이 "**단일 획득 행위**(채집·사냥·제작·탐사·교환·대화 중 하나)로
  충족되는 재료 요구"로 환원되면 분해를 멈춘다. 그것이 말단이다.
- **무대는 목적 트리의 노드가 아니라 세계의 응답이다.** 말단 노드는 "달빛 약초 3개가 필요하다"까지만
  말하고, "달빛 약초는 밤의 습지에서 자란다"는 세계(무대)가 답한다. 이 분리가 중요하다 —
  같은 재료를 공급하는 무대가 여럿일 수 있고(선택·모험의 여지), 무대가 미발견 상태일 수 있다(미지).

### 2.2 트리가 아니라 DAG

한 무대는 여러 목적의 재료를 동시에 공급한다(화산 지대의 흑요석은 "신살 무기 제작"과 "거점 화로
건설" 양쪽의 재료다). 또한 한 세부 목적이 여러 상위 목적에 봉사할 수 있다("강화 약물 제작"은
0.1 위협 제거와 0.2 성장 모두에 기여). 따라서 목적 계층은 트리가 아니라 **DAG**다 —
개발용 Goal 그래프([goal-system-design.md](goal-system-design.md))가 DAG인 것과 같은 이유이며,
이 겹침이야말로 "하나의 행동이 여러 진행 바를 동시에 채우는" 도파민의 원천이다.

### 2.3 양방향 성장 — 하향 분해와 상향 발견

트리는 정적 퀘스트 목록이 아니다. 두 방향으로 자란다:

- **하향 분해 (목적 → 재료)**: 플레이어가 목적을 잡으면 시스템(AI)이 세부 목적과 재료 요구를
  생성·공개한다. 전통적 퀘스트 방향.
- **상향 발견 (재료 → 목적)**: 미지의 무대에서 **용도 불명의 재료**를 먼저 발견한다 —
  "이 검은 비늘은 어디에 쓰는 거지?" 나중에 어떤 목적을 분해하다가 그 재료 요구와 만나는 순간,
  이미 가진 재료가 트리에 **역방향으로 결합**하며 가지 하나가 통째로 밝혀진다.
  탐험(모험심 기둥)이 목적 시스템과 만나는 지점이며, "무의미해 보였던 발견이 의미를 얻는" 보상이
  수집 행위 자체를 도박적 기대로 만든다.

### 2.4 무한성의 근거

"무한한 미지"는 트리의 **말단이 고갈되지 않는 것**으로 구현한다:

- 상위 목적(생존·성장)은 유한하고 안정적이다 — 세계관의 척추.
- 중간 목적은 세계 상태에 따라 AI가 생성·변이한다(거대 신이 죽으면 그 공백을 새 위협이 채운다 —
  비가역 사건, 방향성 문서 §4.4).
- 말단 재료·무대는 절차 생성으로 무한하다(모듈러 조합, 유니크 아이템 철학 — 방향성 문서 §6.3, §9.2).
- 같은 목적이라도 **분해 경로가 매번 다를 수 있다**(약점이 다르면 필요한 재료가 다르다) —
  공략의 고정화를 막고 서버·시즌마다 다른 모험을 만든다.

## 3. 목적 트리 초안

뿌리는 넷. HktFeature 욕구 시스템의 동기(안전·허기·질서 + 예정된 소유/사회)와 정렬한다 —
목적은 결국 "줄이려는 상태 차이"(동기)에서 출발하기 때문이다.

```
0. 생존해야 한다                                        [뿌리 동기: 안전·허기]
├─ 0.1 나의 생존을 방해하는 것들을 제거한다
│   ├─ 0.1.1 만악을 창조하는 거대 신을 제거한다
│   │   ├─ 0.1.1.1 거대 신의 약점을 파악한다
│   │   │   ├─ 0.1.1.1.1 고대 서고에서 신화 기록을 찾는다        → 재료: 기록(정보)
│   │   │   ├─ 0.1.1.1.2 생존한 목격자를 찾아 증언을 듣는다      → 재료: 증언(정보)
│   │   │   └─ 0.1.1.1.3 신의 권속을 잡아 몸의 일부를 조사한다   → 재료: 권속의 심장(물질+정보)
│   │   ├─ 0.1.1.2 거대 신을 제거할 수 있는 아이템을 제작한다
│   │   │   ├─ 0.1.1.2.1 제작 비법(레시피)을 획득한다            → 재료: 레시피(정보)
│   │   │   ├─ 0.1.1.2.2 핵심 재료를 수급한다                    → 재료: 흑요석·신성 결정 등(물질)
│   │   │   ├─ 0.1.1.2.3 제작이 가능한 시설·장인을 확보한다      → 재료: 화산 대장간 접근권(권리) + 장인(인적)
│   │   │   └─ 0.1.1.2.4 제작을 실행한다                        → 행위: 제작
│   │   ├─ 0.1.1.3 거대 신의 거처에 도달한다
│   │   │   ├─ 0.1.1.3.1 관문을 여는 열쇠를 획득한다             → 재료: 열쇠(권리)
│   │   │   └─ 0.1.1.3.2 도달 수단(탈것·경로)을 확보한다         → 재료: 경로 지식(정보) + 탈것(물질)
│   │   └─ 0.1.1.4 결전을 수행할 세력을 규합한다                 → 재료: 협력자(인적)   [협동 기둥 결합점]
│   ├─ 0.1.2 지역을 위협하는 마수 무리를 소탕한다
│   │   ├─ 0.1.2.1 무리의 둥지를 찾아낸다                        → 재료: 위치(정보)
│   │   └─ 0.1.2.2 둥지를 파괴한다                              → 행위: 사냥
│   └─ 0.1.3 환경 위협(독기·혹한·저주)을 중화한다
│       ├─ 0.1.3.1 내성 장비를 제작한다                          → (0.2.1 과 분해 공유)
│       └─ 0.1.3.2 중화 약물을 제작한다                          → (0.2.3 과 분해 공유)
├─ 0.2 나의 생존률을 높이기 위해 성장한다
│   ├─ 0.2.1 생존력을 상승시켜주는 아이템(장비)을 제작한다
│   │   ├─ 0.2.1.1 장비 재료를 수급한다                          → 재료: 가죽·광석·목재(물질)
│   │   └─ 0.2.1.2 제작 시설을 이용한다                          → 재료: 제작대 접근권(권리)
│   ├─ 0.2.2 생존력을 상승시켜주는 스킬을 획득한다
│   │   ├─ 0.2.2.1 스승·비전서를 찾는다                          → 재료: 스승(인적) 또는 비전서(정보)
│   │   └─ 0.2.2.2 스킬의 매개물과 공명한다                      → 재료: 공명 매개물(물질)  [HktFeature 0015]
│   ├─ 0.2.3 절대적으로 강하게 만들어주는 약물을 제작한다
│   │   ├─ 0.2.3.1 희귀 약초를 채집한다                          → 재료: 달빛 약초(물질)
│   │   ├─ 0.2.3.2 촉매를 수급한다                              → 재료: 권속의 심장(물질) ← 0.1.1.1.3 과 무대 공유
│   │   └─ 0.2.3.3 연금 시설을 확보한다                          → 재료: 연금로 접근권(권리)
│   └─ 0.2.4 몸 자체를 성장시킨다(섭취·수련)                     → 행위: 섭취   [HktFeature 0006·0007]
├─ 0.3 생존의 기반(거점·비축)을 구축한다                          [뿌리 동기: 질서]
│   ├─ 0.3.1 안전한 거점을 확보한다
│   │   ├─ 0.3.1.1 입지를 탐사해 고른다                          → 재료: 입지 정보(정보)
│   │   └─ 0.3.1.2 건축 재료를 수급해 짓는다                     → 재료: 목재·석재(물질)
│   ├─ 0.3.2 식량·물자를 비축한다                                → 재료: 보존 식량(물질) + 저장 시설(권리)
│   └─ 0.3.3 생산 시설(화로·제작대·연금로)을 세운다               → 재료: 시설 부품(물질) — 0.2.x 의 "접근권"을 스스로 생산
└─ 0.4 함께 생존할 관계를 만든다                                  [뿌리 동기: 소유/사회 — 협동 기둥]
    ├─ 0.4.1 동료를 규합한다                                     → 재료: 협력자(인적)
    ├─ 0.4.2 베풂으로 명성·존경을 쌓는다                          → 재료: 존경(권리 — 돈으로 못 삼)  [시혜 시스템]
    └─ 0.4.3 교역로를 개척한다                                    → 재료: 교역 상대(인적) + 경로(정보)
```

트리에서 읽히는 구조적 사실:

- **모든 가지가 결국 6~7종의 재료 요구로 수렴한다** (§4.1). 상위 목적이 아무리 서사적이어도
  ("만악의 신을 죽인다") 말단은 언제나 "어디서 무엇을 얻는다"다. 이것이 서사와 월드 콘텐츠를
  잇는 접합면이다.
- **가지끼리 재료·무대를 공유한다** (권속의 심장, 화산 대장간, 접근권류) — §2.2 의 DAG 성질.
- **0.3 은 0.2 의 "접근권" 재료를 스스로 생산하는 가지다** — 소비자였던 플레이어가 공급자(무대의
  건설자)가 되는 전환이며, 거점 후원·시혜 시스템(방향성 문서 §7.2)이 붙는 자리다.
- 깊이는 뿌리에서 말단까지 대체로 **4~5 단**이다. 이보다 얕으면 심부름이고, 깊으면 목적을 잊는다.
  이 깊이가 마이크로/미들/매크로 3단 루프(방향성 문서 §6.1)와 자연 대응한다:
  말단 하나 = 마이크로(30초~5분), 세부 목적 하나 = 미들(30분~2시간), 상위 가지 = 매크로(주~월).

## 4. 말단 단위의 해부

### 4.1 재료의 종류 — 말단이 요구하는 것

| 종류 | 정의 | 예 | 주 획득 행위 |
|---|---|---|---|
| **물질** | 인벤토리에 담기는 에너지의 결정체 | 광석, 약초, 권속의 심장 | 채집·사냥·제작 |
| **정보** | 알면 세계가 달라 보이는 지식 | 약점, 레시피, 위치, 증언 | 탐사·대화·조사 |
| **능력** | 몸에 붙는 재현 가능한 힘 | 스킬, 내성, 공명 | 수련·공명·섭취 |
| **인적** | 함께해야 하는 타자 | 장인, 스승, 협력자, 교역 상대 | 대화·시혜·규합 |
| **권리** | 접근·이용을 허락하는 자격 | 열쇠, 시설 접근권, 명성·존경 | 교환·기여·발견 |

물질만이 재료가 아니라는 점이 요체다. 정보·인적·권리 재료가 있어야 "약점을 파악한다" 같은
서사적 목적도 동일한 말단 문법으로 환원되고, 협동·시혜(0.4)도 별도 시스템이 아니라 같은
트리의 가지가 된다.

### 4.2 말단 노드의 스키마

```yaml
leaf:
  id: L-0231
  demand:                 # 무엇이 필요한가
    material: 달빛 약초    #   재료 (종류: 물질)
    quantity: 3
  verb: 채집              # 단일 획득 행위 (분해 정지 조건의 증명)
  serves: [0.2.3.1]       # 어느 세부 목적(들)에 봉사하는가 — DAG 다중 부모 허용
  done_when: 인벤토리에 달빛 약초 ≥ 3   # 기계 판정 가능한 완료 조건 (필수)
  stages: [S-0045, S-0102]  # 이 재료를 공급하는 무대들 — 발견된 것만 노출
```

`done_when` 은 반드시 세계 상태로 기계 판정이 가능해야 한다 — HktFeature 불변 원칙 ①
(직관적 검증 가능)의 목적 시스템 버전이다. 판정할 수 없는 목적은 아직 목적이 아니다.

### 4.3 무대의 스키마 — 세계의 응답

```yaml
stage:
  id: S-0045
  place: 밤의 습지 (월드 좌표·영역)
  supplies:               # 공급 테이블 — 한 무대가 여러 재료를 공급
    - {material: 달빛 약초, rule: 밤에만 개화, respawn: 3일, depletion: 과채집 시 군락 이동}
    - {material: 습지 목격자의 증언, rule: 은둔 NPC 신뢰 획득 시}
  hazards: [독안개(내성 요구), 야행 포식자]    # 위험 = 비용. 위험-보상 그래디언트의 담지자
  discovered: false        # 미발견 무대는 트리에서 "?" 로만 존재
```

무대의 네 가지 성질:

1. **공급 규칙이 곧 게임플레이다.** "밤에만 개화" 는 플레이어의 시간 계획을, "과채집 시 군락 이동"은
   생태 반응(방향성 문서 §4.1)을, "신뢰 획득 시"는 관계 플레이를 만든다. 재료를 그냥 주는 무대는
   무대가 아니라 상점이다.
2. **위험이 가격이다.** 무대의 hazards 가 위험-보상 그래디언트(방향성 문서 §5.3)를 실어 나른다 —
   좋은 재료일수록 무대가 깊고 험하다.
3. **고갈·이동한다.** 무대는 소진되고 재생하고 옮겨간다 — 같은 목적도 다음에는 다른 무대에서 풀게
   되어 공략이 화석화되지 않는다.
4. **발견되기 전에는 "?" 다.** 무대의 존재는 정보 재료(위치)로 유통된다 — 정보가 재료인 이유.

### 4.4 절차와의 관계 (런타임 결선)

HktFeature 욕구 시스템(0018)의 사슬 `동기 → 전략 → 절차` 와 이 문서의 사슬은 이렇게 겹친다:

| 이 문서 | HktFeature 0018 | 예 |
|---|---|---|
| 뿌리 목적 | 동기 (줄이려는 상태 차이) | 생존 = 안전·허기 결핍 |
| 세부 목적 | (이 문서가 추가하는 층) | "약물을 제작한다" |
| 말단 (재료 요구 + 행위) | 전략 (수단) | 채집·사냥·제조 |
| 무대에서의 실행 | 절차 (단계 실행) | 이동→접근→수확 |

즉 **이 설계는 0018 위에 "세부 목적" 층을 얹는 것**이다. 봇과 플레이어가 같은 사슬을 쓰므로
(0018 의 결선 구조), NPC 도 같은 목적 트리로 움직일 수 있다 — 세계의 모든 생명이 각자의
트리를 굴리는 것이 "살아있는 세계"의 실체다.

## 5. 생성 규칙 — 트리는 누가 채우는가

- **뿌리(0.x)는 설계자가 고정한다.** 동기와 정렬된 4개 안팎. 거의 변하지 않는 세계관의 척추.
- **중간 목적은 AI가 세계 상태로부터 생성한다.** "거대 신" 은 하드코딩된 보스가 아니라
  "현재 세계의 최상위 위협" 슬롯이다. 죽으면 생태·세력 시뮬레이션이 다음 위협을 밀어 올리고,
  AI가 그 분해(약점·재료·무대)를 새로 생성한다. 서버마다·시즌마다 다른 신, 다른 공략.
- **말단·무대는 절차 생성 + AI 변이.** 재료 명세(종류·희귀도·태그)와 무대 템플릿(지형·공급 규칙·
  위험)의 조합 폭발. 유니크 아이템 철학과 동일 기조.
- **생성의 제약**: 새로 생성되는 어떤 가지도 (a) 말단이 §4.1 의 재료 종류로 환원되고,
  (b) `done_when` 이 기계 판정 가능하며, (c) 공급 무대가 최소 1개 실존해야 한다.
  — 이 세 검사를 통과 못 하는 생성물은 세계에 넣지 않는다(수행 불가능한 목적 방지).

## 6. 시각 표현

원칙: **트리를 통째로 보여주지 않는다.** 전체 트리가 보이는 순간 세계는 체크리스트가 되고
미지(모험심 기둥)가 죽는다. 층마다 다른 시각 언어로, 발견된 만큼만 보여준다.

### 6.1 세 개의 시야

| 층 | 시각 장치 | 화면 위치 | 답하는 질문 |
|---|---|---|---|
| 말단 (지금) | **나침반/표식** — 활성 말단 하나만. "달빛 약초 2/3" | HUD 상시 | "지금 뭘 하지?" |
| 세부 목적 (오늘) | **여정 기록(저널)** — 활성 가지의 계보 브레드크럼: `생존 › 성장 › 약물 제작 › 약초 3개` | 열어보는 창 | "이걸 왜 하지?" |
| 전체 (인생) | **별자리 지도** — 발견된 노드는 별, 미발견 가지는 흐린 성운·"?" 로. 완료 별은 밝게 점등 | 전체 화면 지도 | "나는 어디까지 왔지?" |

별자리 은유를 고르는 이유: (a) 미발견을 "빈 칸"이 아니라 "성운"으로 그려 결핍이 아닌 기대로
읽히게 하고, (b) DAG 의 교차 간선이 별자리 연결선으로 자연스럽게 표현되며, (c) 절차 생성으로
별이 무한히 늘어나는 것이 세계관("끝없는 미지")과 시각적으로 일치한다.

### 6.2 도파민의 시각화 — 상향 파문

말단 하나를 완료하는 순간, 그 노드에서 뿌리 방향으로 **빛의 파문이 계보를 타고 올라가며**
경유하는 조상 노드의 진행 바를 차례로 채운다 (HUD 에는 짧게, 별자리 지도에는 성대하게).

- 마이크로 행동(약초 하나)이 매크로 서사(신을 죽인다)에 닿아 있음을 **매번 몸으로 보여주는** 장치.
- DAG 이므로 한 번의 완료가 **여러 갈래로 동시에 파문**할 수 있다 — "권속의 심장" 하나가
  0.1.1.1(약점 조사)과 0.2.3(약물 촉매) 두 가지를 동시에 울릴 때가 설계상 최고의 순간이다.
- 상향 발견(§2.3) 시에는 역연출: 새 가지가 별자리에 **한꺼번에 점등**되며 이미 가진 재료들이
  제자리로 날아가 결합한다 — "그 비늘이 여기 쓰이는 거였구나".

### 6.3 세계 안의 표식 — UI 밖으로

- **재료 공명 발광**: 활성 말단이 요구하는 재료가 시야에 들어오면 은은히 빛난다(공명 —
  HktFeature 0015 와 같은 시각 문법). 목적이 세계를 "다르게 보이게" 만드는 직접 체험.
- **무대의 문턱**: 무대 영역 진입 시 짧은 명패("밤의 습지 — 무언가 자라는 곳")와 환경 연출 변화.
  미발견 무대는 지도에 없다가, 정보 재료를 얻으면 지도에 "?" 로 먼저 찍힌다.
- **위험의 정직한 표시**: hazards 는 환경 연출(독안개의 색, 뼈 무더기)로 사전 고지한다 —
  위험-보상 판단을 플레이어의 읽기 능력에 맡기는 것 자체가 콘텐츠다.
- **타인의 파문**: 같은 무대에 있는 다른 플레이어의 완료 파문이 희미하게 보인다 — "저 사람도
  뭔가를 이뤘다". 시혜 연출(누가 지어준 시설의 각인)과 같은 문법으로, 사회적 존재감의 배경 복사.

### 6.4 렌더 규율

시각 표현이 무엇이 되든, 파이프라인은 `세계 속성 → ViewModel → 렌더(속성 그대로)`
(HktFeature 불변 원칙 ③)를 지킨다. 목적 트리·진행도·파문 이벤트는 전부 세계 속성/권위 tx 에서
파생한 Scene 서술자로 노출하고, 렌더러는 그것을 그릴 뿐이다 — 별자리 지도를 지금은 대충
그리다가 나중에 통째로 갈아끼울 수 있어야 한다.
