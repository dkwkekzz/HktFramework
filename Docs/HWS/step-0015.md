# step-0015 — R-주형 자기복제(heredity): 저장(R)의 *씨앗 끝*에서 유전·변이·선택을 창발시킨다 — 척추 다섯째 축(시간축)의 첫 토대

> [step-0014로](step-0014.md) · 실행물: [step-0015.html](step-0015.html)(3D 표준 셸) · 시뮬 로직: `engine/hws-laws.js` 의 **`replicate` 법칙 1개**(LAW_ORDER ⑤d — 결정화 뒤, sim-core.js 복사 없음) · 헤드리스: `step-0015/verify.js` · 엔진 재현: `node engine/validate/verify-sim-engine.js`

step-0014 가 활성도 계량(결정1·2)을 닫아 **척추 네 결정이 *별*을 대표로 모두 한 바퀴 돌았다**(1 척추변수 ✅·2 측정분류 ✅·3 이산문턱 ✅별·4 삼중항 ✅). 그러나 네 결정은 개체를 *공간*에서 빚을 뿐 — 세계를 *지속*시키되(임계 자기조직, 0012 의 끝없는 churn) *복잡성을 축적*하진 못한다(소산구조 ≠ 진화: Bénard·불꽃·눈송이는 화려하나 진화 안 함). 사람급 복잡 *적응*계로 가려면 **다윈 동역학(유전·변이·선택)** 이 필요하고, 빠진 토대는 **유전**이었다 — 분열(0004)은 스칼라 m 만 복제해 *가변·선택되는 정보 담체(genotype)*가 없었다. step-0015 는 그 토대를 놓는다: **저장(R)의 *씨앗 끝* — 자기복제하는 R-배치(genotype, 이산 태그 G)가 제 사본의 결정화를 *촉매*하면**, 복제오류=변이·기질경쟁=선택으로 **다윈 동역학이 substrate 위에서 돈다**(SPINE §다섯째 축, R-주형 하이퍼사이클).

이것은 **law-pipeline 의 다섯째 step** 이다 — 더한 시뮬 로직은 `engine/hws-laws.js` 의 `replicate` 법칙 1개(LAW_ORDER ⑤d) + 노브 8개(`kTemplate` 마스터 + geneRate·geneThresh·geneMu·geneTypes·geneFit0·geneFitStep·geneClear) + 유전형 필드 G(Uint8 이산 태그)의 *가법* 해시. 회귀는 동결 *해시*로 잠근다 — 이 step 은 회귀 앵커를 *가법 확장*해 별+생명+자기제한+FSM+계량 스택(step-0014)을 골든 잠금에 넣었다(`golden-sim.json` 의 `flux@` 키 신규 = step-0015 회귀 앵커, `gene@` 키 신규 = step-0016 회귀 앵커). `kTemplate=0` → step-0014 비트 불변.

결과: **① 유전이 창발한다** — 변이율 mu=0 이면 자식 R 이 부모 태그를 *완벽 복사*(fidelity **1.00**, 한 점 씨앗 → 순수 클론 4096칸). *이산* 태그라 정보가 번지지 않는다(연속 필드 불가 — Schrödinger 비주기 결정). **② 변이가 창발한다** — mu=0.02 면 복제오류로 변종 4종 출현, 변이율 **0.021 ≈ mu**. **③ 선택이 창발한다** — 고적합 tag4(fit 0.95) vs 저적합 tag1(fit 0.50) 경쟁에서 고적합이 **1.53배** 더 점유(차등 번식=선택, 기질 경쟁). **④ 적응이 창발한다** — 저적합만 파종+변이 → 고적합 변종이 선택돼 평균 적합도가 **0.50→0.63(+0.13)** 상승(다윈 동역학: 변이+선택이 함께 돌면 *적응*이 생긴다). **⑤ 회귀 0·닫힌 장부·결정론·churn 유지** — kTemplate=0 시 step-0014 비트 동일(flux@), 잔차 **4.55e-13**, 해시 일치(G 가법), 공멸 없이 지평선 생존(후반 출생/사망 4552/4554≈균형). **유전형은 도는 R 순환에 *올라탄다*** — 복제는 활성도 A 와 달리 *실제 변환*(E→R 을 굳힘)이되, 별·생명 churn 을 깨지 않고 substrate(~2200칸)를 잠근다(임계 자기조직 보존).

## 2. 메커니즘 — R-주형 복제: E→R 쌍 거래 + 이산 태그 복사, 복제오류=변이·기질경쟁=선택

법칙 순서의 ⑤d(결정화 ⑤ 직후)에 복제를 둔다 — 직전 결정화가 만든 R 주형을 읽어 자기복제한다(저장 형성 군집). 각 셀은 R(담체)과 유전형 태그 `G[i]`(Uint8, 0=무유전, 1..geneTypes)를 갖는다. kTemplate≠0 일 때:

```js
// ⑤d replicate — R-주형 자기복제(genotype 태그 복사 + 복제오류 + 기질경쟁)
for (i) { if (G[i]≠0 && R[i] < geneClear) G[i] = 0;  Gb[i] = G[i]; }   // 풍화로 기질 사라지면 태그 소거 + tick 시작 주형 스냅샷
for (각 주형 i: Gb[i]≠0 && R[i] ≥ geneThresh) {
  fit = geneFit0 + geneFitStep·(Gb[i]−1);                              // 유전형→표현형(복제 propensity)
  for (4이웃 j: G[j]==0 && E[j] ≥ geneRate) {                          // 빈칸 + 기질 있음(자원 문턱=선택)
    if (tumbleHash(j) 발화 < fit) {                                    // propensity=fit 로 발화(고적합이 빨리)
      E[j] -= geneRate; R[j] += geneRate;                             // E→R 쌍 거래(닫힌 장부)
      tag = Gb[i]; if (복제오류 < mu) tag = ±1 이웃 태그(변이);          // 복사 + 복제오류=변이
      G[j] = tag;
    }
  }
}
```

다섯 설계 결정이 이 복제를 *척추 정합*하게 만든다:

1. **유전 = 저장의 씨앗 끝(SPINE §다섯째 축)** — 유전은 별도 필드가 아니라 *저장(R)의 능력*이다. 수동적 광물(무유전 R)은 저장만 하지만, *자기복제하는 R-배치*(genotype 태그를 가진 R)는 제 사본의 결정화를 촉매한다(바위→자기복제 결정→genotype 연속체, Cairns-Smith 점토 유전자: 유전은 *전생물적*, 광물에서 난다). genotype = 복제된 R-패턴.
2. **유전은 *이산* 정보** — G 는 Uint8 이산 태그다. 연속 필드(E·R·A)는 확산·EMA 로 번져 정보를 못 지키지만(Schrödinger "비주기 결정"), 이산 태그는 복사돼도 흐려지지 않는다 — fidelity 1.00(mu=0)이 이를 증명한다. *이것이 유전이 이산을 요구하는 이유*다.
3. **다양성은 병렬 필드 아닌 속성에(단일 척추)** — genotype 다양성(태그 1..geneTypes)은 *R 의 속성*에 실린다. 필드는 여전히 E 하나(+상 R) — G 는 둘째 구동 필드가 아니라 R 의 이산 라벨이다(별 state 가 별의 라벨이듯).
4. **다윈 엔진을 author 하지 않는다(측정/창발)** — "유전·변이·선택"을 코드에 박지 않는다. 복제(태그 복사)·복제오류(±1 변이)·기질경쟁(빈칸+E 문턱)이라는 *국소 법칙*만 깔면, 유전·변이·선택은 그 위에서 *창발*한다. genotype→phenotype 맵(fit=태그의 함수)은 authored type 분기가 아니다 — E 동역학은 태그로 안 갈리고(필드는 E), 복제 *속도*만 태그의 함수다(활성도는 여전히 측정으로 환원).
5. **국소·닫힌 장부·순환** — 주형은 제 4이웃만 본다(전역 조율자 0). 복제는 E→R 쌍 거래뿐(G 태그는 거래 0 — 정보지 에너지 아님)이라 장부가 닫힌다. 풍화(⑤ kWeather)가 R 을 깎아 R<geneClear 면 태그 소거 — 빠른 복제(개체 척도) + 느린 풍화(세계 척도)로 유전 정보가 *순환*한다(정보는 저장 극단에만; 소산 극단 불꽃은 흐름이 패턴을 지운다).

### 한 tick = 한 세대 (scan-order 폭주 방지)

tick 시작에 G 를 Gb 로 스냅샷하고 *Gb 에서 주형을 읽어* G 에 쓴다 — 그래서 갓 태어난 자식은 같은 tick 에 다시 복제하지 않는다(한 tick=한 세대). 빈칸(G==0) 경쟁은 *scan 순서 먼저 온 주형*이 차지(live G 확인) — 국소 자원경쟁이 결정론적으로 풀린다.

## 6. 의외의 발견

1. **클론이 격자 전체를 채워도 fidelity 가 정확히 1.00 이다.** 통제 아레나에서 한 점 씨앗이 4096칸 전부로 번지는데도(13→4096) mu=0 이면 *모든* 칸이 부모 태그다 — 4083번 복제하며 단 한 번도 정보가 흐려지지 않았다. 연속 필드(E·R·A)는 4083번 확산·EMA 거치면 완전히 뭉개질 텐데, 이산 태그는 *복사 연산*이라 세대를 무한히 건너도 비트 보존된다. "유전은 이산을 요구한다"가 수치로 — 같은 substrate 위 연속/이산의 정보 운명이 갈린다.
2. **변이는 4종을 다 깨우는데 변이율은 정확히 mu 다.** mu=0.02 한 점 씨앗(tag2)에서 시작했는데 변종 4종이 모두 출현했다 — ±1 변이가 태그 공간(1↔2↔3↔4, wrap)을 랜덤워크로 탐사한다. 그런데 누적 변이율(geneMut/geneReps)은 0.021 로 mu 에 수렴한다 — 변이는 *국소 사건*이지만 통계는 노브 그대로다(큰 수의 법칙). 다양성의 *공급률*이 노브로 제어된다.
3. **유전형이 R 을 절반 넘게 잠가도 별·생명은 안 죽는다.** 전체 스택에서 복제가 substrate 를 ~2200칸(절반)이나 genotype R 로 잠그는데(저장체 R 총량이 step-0014 보다 크게 늘어남), churn 은 비트 단위로 보존된다(carrying capacity ~56 동일·공멸 없음). 유전형은 R 순환을 *멈추지 않고 올라탄다* — 별이 채운 E 가 굳어 R 이 되고, 그 R 에 태그가 박히고, 풍화가 R 과 태그를 함께 지우고, 다시 새 R 이 태그를 받는다. 유전 정보가 에너지 순환의 *승객*이지 *기관차*가 아니다(단일 척추의 자연스런 귀결).

## 7. 정직한 한계

1. **적합도 맵이 authored·단봉이다 — 열린 진화(OEE) 아님.** fit(tag)=geneFit0+geneFitStep·(tag−1)는 *매끄러운 단봉* 맵 — 선택은 늘 최고 태그(geneTypes)로 climb 하고 거기서 멈춘다(적응이 *포화*). genotype→phenotype 가 풍부한(다봉·문맥의존·공진화) 적합도 지형이 아니라서, *지속적* 복잡성 축적(OEE)은 아직 없다. 이 step 은 다윈 동역학의 *부품*(유전·변이·선택·적응)이 substrate 위에서 도는 걸 보였지, 열린 진화를 보인 게 아니다(인공생명 미해결 난제 — Tierra/Avida 도 정체). 각은 있으나 도달 보장 아님.
2. **genotype 이 phenotype 을 *복제 속도*로만 발현한다.** 태그는 복제 propensity(fit)에만 쓰인다 — 형태·대사·이동 등 풍부한 phenotype 으로 발현되지 않는다(유전형→표현형 맵이 1차원·스칼라). 진짜 적응 방산엔 다차원 phenotype 발현이 필요(백로그).
3. **유전이 *R 위*지 *생명 m 위*가 아니다.** SPINE "유전이 개체보다 먼저"를 따라 유전을 R(저장 극단)에 먼저 깔았다 — 생명(m, 활성도 가운데)은 아직 genotype 을 안 가진다(분열은 여전히 스칼라 m 복제). 유전을 생명에 결합(genotype↔대사 엔진 묶기 = "단단한" 자기복제)하는 단계는 후속(주요 전이 사다리: 복제분자→…→개체).
4. **자기복제의 *기원*(abiogenesis)은 author 했다.** 최초 복제자(genotype 씨앗)는 `spawnGene` 으로 *심었다* — 무유전 R 에서 자기복제 R 이 *저절로* 발생하는 경로(예: 어떤 R-배치가 우연히 자기촉매가 됨)는 보이지 않았다. "유전의 *복제·선택*"은 닫혔고 "유전의 *기원*"은 백로그.
5. **scan-order 이방성·통제 아레나 의존.** 빈칸 경쟁이 scan 순서로 풀려 성장에 약한 +x/+y 편향(등방성 stencil 백로그). 또 heredity/select 수치는 *통제 아레나*(확산·풍화 off)에서 잰 것 — 전체 스택에선 확산·생명 grazing 이 클론 경계를 흐트려 더 복잡하다(통제는 격리 측정).
6. **통제 아레나 수치는 *성장기* 일회성 — 포화하면 언다.** 통제 아레나는 풍화·확산이 없어 클론이 격자(4096칸)를 다 채우면 빈칸이 없어 복제가 *멈춘다*(meanFit·ratio 가 ~tick 60 에 얼어 이후 불변). 그래서 select 의 "적응 +0.13"·"선택 ratio 1.53"은 *성장기 경쟁*의 결과지 *지속* 다윈 적응이 아니다(한계 1 의 포화와 같은 결). *지속* 회전(풍화로 R<geneClear 면 태그 소거 → 재복제)은 **전체 스택 `sustain`** 이 보인다 — geneCells 가 4096 이 아닌 ~2200 에 정상상태(턴오버 중)이고 in-stack 평균 적합도도 오른다. 통제 아레나는 *깨끗한 격리 측정*, 지속성의 권위는 sustain.
6. **G 의 3D 셰이더 렌더는 미구현 — 2D 오버레이·통계만.** 유전형 클론 색은 *2D drawHook* 에만 그린다(3D 하이트필드는 E·R·A 채널만). 기본 3D 뷰에선 우측 "유전형/평균 적합도" 통계로 읽고, 클론 색은 2D 토글에서 본다. 헤드리스 `verify heredity·select` 가 본 thesis 의 권위.
