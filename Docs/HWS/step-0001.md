# step-0001 — 닫힌 장부를 가진 최소 세계

> 자원·생명·플레이어를 만들기 전에, 그것들이 *떠오를 수 있는* 세계부터 증명한다.
> 근본은 넷이다: **터**(자리) · **흐름량**(보존되는 무언가) · **법칙**(국소 변화) · **구동**(평형을 막는 엔진).

[CLAUDE.md](CLAUDE.md) 의 목표 — "스스로 굴러가 자원을 만들고 생명이 탄생하는 세계" — 를 거꾸로 분해하면:

```
생명  ← 자원을 먹어 자신을 유지하는 패턴
자원  ← 흐름이 고여 머무는 패턴
흐름  ← 평형이 아닌 세계  ←  구동(source→sink)
세계  ← 터 + 보존되는 양 + 국소 법칙
```

따라서 첫 step 은 사슬의 맨 아래 — **보존되며 흐르는 세계** — 를 만들고, 그것이 (1) 장부가 닫혀 있고 (2) 재현 가능하며 (3) 멈추지 않음을 수치로 증명하는 것이다.

## 2. 설계

### 표준 시나리오 (이후 step 의 수치 비교 기준 — 고정)

- 64×64 wrap. 초기 E = 1.0 + 0.5·(rng(seed)−0.5), 난수는 초기화에만.
- source(16,16, r3=29셀, 셀당 +0.05/tick) + sink(48,48, r4=49셀, 셀 E 의 10%/tick 제거).
- kD = 0.20 (확산) · kT = 0.001 (소산). 기준 길이 10000 tick. 시드 [42, 7, 1234, 99, 2026].

### 법칙 적용 순서 (불변 — 순서가 결과를 바꾼다)

```
tick = ① 확산 → ② 소산 → ③ 주입(source) → ④ 배출(sink)
```

### 닫힌 장부

모든 E 변화는 쌍 거래(이웃 셀 또는 장부)다. 항등식과 잔차:

```
sumE(t) + dissipated + sunk − injected = sumE(0)
잔차 = |위반량| / max(1, E₀ + injected)   — 허용: < 1e-6
```

### 파일

- [step-0001/sim-core.js](step-0001/sim-core.js) — 브라우저/Node 겸용 코어
- [step-0001/verify.js](step-0001/verify.js) — `node verify.js <conserve|det|neq|all> [seed]`
- [step-0001.html](step-0001.html) — 단일 파일 시연 (인라인 코어 = sim-core.js 동일)
- 첫 step 이므로 회귀(`reg`) 모드 없음 — step-0002 부터 이 코어가 회귀 기준.

## 4. 의외의 발견

**구동이 시드를 지운다.** 정상상태 sumE 가 전 시드에서 1362.151~1362.152 — 소수 셋째 자리까지 수렴하고, varE 는 표시 자리에서 동일(0.1055)하다. 초기 노이즈(시드)의 흔적이 10000 tick 안에 완전히 씻겨나가고, 세계의 장기 모습은 **법칙+구동의 기하만으로 결정**된다.

게임 설계에의 함의: 이 세계에서 "어떤 시드냐"는 장기적으로 무의미하다. 세계의 정체성은 법칙이 정하고, **놀라움(모험)은 시드가 아니라 비선형·이력(history)이 생긴 뒤에야 가능**하다 — 선형 세계는 과거를 기억하지 못한다. step-0002 의 비선형 도입이 이 성질을 깨는지가 관전 포인트.

## 5. 정직한 한계

- **고임이 없다.** 정상상태 E 분포는 source 봉우리의 단조 기울기뿐 — source 아닌 곳의 국소 봉우리(자원의 원형)는 떠오르지 않는다. 원인: 확산+소산은 모든 응축을 깎는 선형 소거 연산이고, 그에 맞서는 항이 법칙에 없다. → 자원이 떠오르려면 비선형 최소 1개(응집 또는 임계)가 필요하다는 것이 step-0002 의 가설.
- sink 가 일을 거의 안 한다(제거의 ~6%) — source 에서 먼 곳은 E 가 닿기 전에 소산으로 식는다. 현 step 에서는 무해하나, 구동의 기하(거리)가 닿음/못 닿음을 가른다는 신호로 기록해 둔다.
- varE 임계(>1e-3)·drift 임계(<1e-3)는 이 시나리오에 맞춘 경험값이다 — 시나리오가 바뀌면 재정의해야 한다.

**가설: 비선형 1개를 넣으면 고임(자원의 원형)이 떠오른다.** → step-0002 에서 응집 1항으로 통과. 아래는 당시 예고 원문.

- 법칙에 항 하나를 추가한다 — 후보: **응집**(E 가 높은 이웃으로 흐름이 쏠림) 또는 **임계**(농도 임계 초과 시 확산 둔화). 새 법칙이 아니라 기존 확산의 계수 확장 형태를 우선 검토.
- 검증할 것: ① source 아닌 곳에 국소 봉우리가 생기고 지속되는가 ② 그것을 제거(수확)하면 재생되는가 ③ 닫힌 장부·결정론 유지 ④ **회귀 0** — 새 계수 = 0 에서 step-0001 과 비트 동일.
- §4 의 질문: 비선형이 생기면 세계가 시드를 기억하기 시작하는가(고임의 위치가 시드마다 달라지는가).
