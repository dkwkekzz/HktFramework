## 0. 문제 — "변위 플롯"은 세계가 아니다

현재 브라우저 3D(`engine/hws-3d.js`)는 `h = HS·log(1+E)` — **E라는 한 스칼라를 높이로 직역**한 것뿐이다. 울퉁불퉁한 표면 + 호박색 R 융기 + 발광 점. 이건 *값의 지도*(과학 시각화)지 *세계*(게임)가 아니다.

같은 데이터인데 세계로 안 읽히는 이유는 단 하나 — **번역 함수가 1개(값→높이)뿐**이기 때문이다. 세계는 한 값이 *여러 정체성*으로 갈라져야 읽힌다: 여기는 물, 저기는 바위, 저건 살아 숨쉬는 것, 저 위는 빛. **해석 레이어 = 그 갈라짐을 만드는 번역 함수들의 모음.**

게임이 그려야 하는 것: **생명 · 나무 · 돌 · 지형 · 바람 · 빛.** 이 문서는 이것들을 *author 하지 않고*(에셋 제작 금지, [CLAUDE.md](CLAUDE.md) 큰 목표 "얕은 철학으로 모방된 세계" 거부) 코어 스냅샷에서 *연역*해 그리는 규약이다.

## 1. 제1원칙 — 렌더러는 존재론과 똑같이 분류한다

척추([SPINE.md](SPINE.md))는 개체를 *이름(별/바위/생명)이 아니라* **활성도 연속축 + 국소 비가역 문턱**으로 가른다. **해석 레이어는 그 분류를 그대로 렌더에 쓴다.** 세계 원형(돌/나무/생명/빛)은 자의적 배정이 아니라 *척추 좌표에서 연역*된다 — 그래서 "낯설지만 임의가 아닌"([VISION-UE](VISION-UE.md) 톤 4) 미지가 유지된다.

분류 다이얼은 **활성도 `A`**(step-0014, = 척추 변수 E의 throughput `|dE/dt|` EMA)다. A는 "무엇이 있나(재고 E·R)"가 아니라 **"흐름이 사나"**를 잰다 — 정확히 세계가 *살아있는 정도*다.

**확정 — 셰이더 렌즈만(author 0)**: 세계 원형은 *원초적 형태*(융기·결정질·발광체)로 셰이더가 필드를 읽어 그린다. 알아볼 수 있는 메시(나무·돌 에셋) scatter 는 채택하지 않는다(§4). UE는 절대 필드를 만지지 않는다 — 화면은 전부 스냅샷의 함수(서버 권위, [VISION-UE](VISION-UE.md) 결정론 불변).

> **브라우저 1차 구현(검증된 프로토)**: `engine/hws-3d.js` 에 이 해석 함수의 첫 구현이 들어갔다 — **2분할 뷰**("세계 해석(2분할)" 토글, 기본 ON). 왼쪽 = 기존 *에너지 변위* 렌즈(원본 하이트필드), 오른쪽 = *세계 해석* 렌즈(같은 E/R/G/A 텍스처를 §2 표대로 물·돌·나무[유전]·빛으로 번역). 활성도 `A` 를 RGBA32F 의 alpha 채널로 실어 분류 다이얼로 쓴다. 두 뷰는 카메라·오버레이·픽킹을 공유한다(GL 리소스 1벌). step-0009~ 전 3D 셸에서 자동 표시 — 셸 수정 0. UE 셰이더로 승격하기 전 매핑을 *브라우저에서 먼저 검증*하는 자리. **✅ 현 상태(물질 표현 구현, 2026-06)**: 종전 두 뷰가 높이 `h=E+R` 을 공유해 거의 똑같이 보이던 것을 닫았다 — 세계 해석 뷰는 이제 *에너지가 아니라 물질*을 그린다. `VS_WORLD/FS_WORLD` 가 활성도 `A` 로 **높이 = 물질(`hOf(R + 저활성E)`)** — 흐르는 에너지(고활성 E·A)*만* 빼서 빛으로(별 연소·확산이 솟지 않고 발광). 물질 *분포는 안 건드린다*(형태 author 금지, §4). 차이는 *재질·빛*으로: 상(고체/액체/공허 3분기)·조성 G·밀도 R·광택(액체)·발광(에너지). **척추 정합**: 1차 시도의 "물 평탄화"는 §4 가 금지한 형태 author 라 되돌렸다 — *완전히 다른 실루엣*은 렌더러가 아니라 *시뮬*(형태 사다리)이 빚는다(두 뷰가 정착 물질에서 같은 실루엣인 건 §5 진단, 버그 아님). 설계·근거 §5b(아래).

## 2. 해석 함수 — 좌표 → 세계 원형 (핵심 매핑표)

각 셀/에이전트의 좌표 5개를 읽어 세계 원형을 고른다. **입력**: 활성도 `A` · 물질 `E`/`R` · 유전 `G` · FSM 상태 · 이동성(에이전트 여부).

| 시뮬 좌표 (척추 읽기) | 세계 원형 | 셰이더 렌즈 기법 | 근거 step |
|---|---|---|---|
| 낮은 `A` + 높은 `R` + 태그 없음 (수동 광물) | **돌 · 암반** | R 융기 높이 → 거칠고 어두운 암석 셰이더, 무광 | 0008 |
| 낮은 `A` + 높은 `R` + 유전 `G` + 고착 | **나무 · 산호 · 결정** | G 색조 + 누적 성장 높이, 결정질·반투과 셰이더 | 0015 |
| 높은 `A` + FSM `burning` | **빛 · 불 · 별** | emissive 폭발 + 포인트라이트 + 상승 Niagara | 0011·0013 |
| 중간 `A` + 에이전트 `m` (이동성) | **생명** (발광 군집·균사·플랑크톤) | flowmap 따라 표류하는 발광 점군, G로 색 분기 | 0003·0005·0015 |
| 얕은 `E` (저활성 재고) | **물 · 웅덩이** | 굴절·투과·반사 하이트필드(깊이=E) | 0001 |
| `∇E` (확산 플럭스) | **바람 · 해류** | Niagara 벡터필드 / flowmap UV advection | 파생 |
| `∇²E` (라플라시안) | **안개 · 응결**(모이고 흩어짐) | 볼류메트릭 안개 밀도 | 0001 |
| `A` 전역 (보존된 흐름) | **빛**(정직한 세계) | 화면 총광량 일정 — emissive 합 보존 | 0014 |
| kin E-공유 도메인 + 경계 막 (`couple`) | **개체 · 세포**(공유 내부 + 막) | 도메인 내부 E plateau(균질) + 경계 단차 = *형태* — 렌즈가 바닥 E 하이트필드에서 받는다(코드 0). 첫 *형태* 행 | 0017·0018 |

> **핵심 통찰 — "나무"의 정체**: 이 세계에 나무 에셋은 없다. 그런데 나무가 *무엇이냐* 따지면 — 에너지를 저장하고(목재=R), 씨앗으로 자기복제하며(유전 G), 천천히 자라고(낮지만 0 아닌 A), 동물처럼 떠돌지 않는(고착) 것이다. 그건 정확히 **step-0015가 만든 "R 위의 자기복제 유전형"**(SPINE "바위 → 자기복제 결정 → 산호·균사" 연속체)이다. **돌과 나무를 가르는 건 메시가 아니라 유전(G)의 유무**다. 빛·생명·지형도 같은 식으로 좌표에서 연역된다. "세계를 그린다" = *하나의 스냅샷을 활성도 축으로 여러 번 다르게 읽는 것.*

## 3. 원형별 셰이더 렌즈 (구현 규약)

모든 렌즈는 같은 입력(§6 텍스처)을 다르게 읽는다. **새 매질이 필요하면 새 에셋이 아니라 같은 장을 읽는 식(도함수·필터)을 추가**한다([VISION-UE](VISION-UE.md) 제1원칙).

- **지형·물** — `h = E + kRelief·R`. 얕은 E = 물(굴절·투과·프레넬 반사, 깊이로 흡광), 두꺼운 R = 솟은 지면. 자동 명암 포화점은 2D/3D와 공유([DESIGN-3D](engine/DESIGN-3D.md)).
- **돌·암반** — R 높음 + A≈0 + G 없음. 무광 거친 노멀, 색은 어둡게. "흐름 끊긴 자리"(step-0014: A_store≈A_bg)라 빛을 거의 안 낸다.
- **나무·결정(유전)** — R + G 태그. G를 색조(hue)에 매핑해 혈통/종을 구분, 결정질 반투과 + 약한 내부 발광(낮은 A=생장). 누적 R로 높이 성장. 같은 G 끼리 색이 같아 "숲/군락"으로 읽힌다.
- **빛·별** — FSM 상태로 **이산 분기**(lerp 금지, step-0013 "딱 뒤집힘"): `kindling`(어두운 응결핵) → `burning`(고강도 emissive + 포인트라이트 + 위로 솟는 Niagara mist) → `ash`(식어 저장체 색으로 가라앉음). A 최고 극단이라 화면에서 *홀로 타오른다*(A_burn/A_store=26.1이 그대로 명암 대비).
- **생명** — 에이전트 m, 표면 위 발광 인스턴스(크기 ∝ √m, 2D 규칙 동일). `∇E` flowmap 따라 표류(주화성), 대사(상승 입자)·죽음(하강·확산 입자). G로 색 분기 → 종/세력.
- **바람·해류** — `∇E`를 flowmap UV / Niagara 벡터필드로. 코어 불변 → 결정론·보존 안전([VISION-UE](VISION-UE.md) "(A) 파생 바람").
- **빛(보존이 미학)** — 전역 emissive 총합이 A 보존으로 일정. 빛은 사라지지 않고 *돌* 뿐 — "정직한 세계"([VISION-UE](VISION-UE.md) 톤 2)를 처음으로 화면에 실현하는 렌즈.

## 4. 왜 셰이더 렌즈인가 — 형태를 author 하지 않는다 (메시도, 원형별 렌더 규칙도)

| | 셰이더 렌즈 (채택) | 인스턴스 메시 scatter (기각) |
|---|---|---|
| author | 0 — 같은 필드를 다르게 읽음 | 나무/돌 메시 제작 필요 |
| 일관성 | 자기일관적 세계(데코 아님) | 필드가 안 만든 형태를 얹음 = 디오라마 |
| 톤 | 원초적·외계적 유지 | 지구 메시(소나무 등)가 외계감을 깸 |
| 결정론 | 스냅샷의 함수 → 자동 보존 | 동일 |

메시 scatter 로 가는 순간 "스스로 굴러가는 세계"가 "값으로 칠한 디오라마"로 떨어진다 — 이 프로젝트가 명시적으로 거부한 "얕은 철학으로 모방된 세계"([CLAUDE.md](CLAUDE.md) 큰 목표). 원초적 렌즈는 *지금 데이터로 진짜 세계*가 된다. (메시는 트레일러/데모 한정 백로그.)

> **경계가 한 칸 더 안쪽에 있다 — 메시뿐 아니라 "원형별 렌더 규칙"으로 *형태(실루엣)*를 지어내는 것도 author 다.**
> "물은 평평한 시트, 바위는 각진 결정으로 솟게" 같은 *형태(어디가 휘고 가지치는가)의 규칙*을 렌더러가 박으면, 메시를 안 쓸 뿐 인과는 똑같이 뒤집힌다 — 필드에 없는 *실루엣 곡률*을 손으로 만든 것. 그 형태는 여전히 **시뮬**의 일이다(형태 사다리, §5).
> **단 *어느 양이 높이(부피)가 되는가*는 렌더러의 정직한 읽기이고 — 답은 *에너지가 아니라 물질*이다(§5b 설계 확정).** 현실에서 에너지(장)는 형태가 없어 *빛·열·흐름*으로 보이고, 물질(응축상)만 부피·경계·높이를 갖는다 — 뜨거운 가스는 산이 안 되고 *빛난다*. 그래서 **높이 = 물질 = `R`(고체 저장체) + 저활성 `E`(고인 액체, A≈0)** 이고, *흐르는 에너지*(고활성 E·A)는 높이에서 빠져 **빛**으로 간다. 종전 `h=E+R`(에너지까지 높이)은 에너지를 물질로 *오역*한 것 — *값의 지도*지 세계가 아니었다(에너지 변위 뷰가 정확히 그것). 렌즈가 읽는 것: *어느 상(고체R/액체E/빛)인가 · 색 · 밀도 · 조성(G) · 구조(막)* = **물질의 정체**. *실루엣의 곡률·가지(형태)* 만 시뮬 몫. 물질이 *어디 있나*(R·E 분포)는 시뮬이 정하므로 이 읽기도 author 가 아니다.

## 5. 정직한 격차 — 형태는 *flux 의 하류*이고, 시뮬의 일이다

§2 표로 *무엇인지*(돌/나무/생명)와 *재질·빛*은 지금 셰이더로 읽어낼 수 있다. 하지만 **형태(form)** 는 못 만든다 — 그리고 **만들어선 안 된다.**

**제1원칙 — 형태는 에너지 흐름의 *하류(downstream)* 다.** 현실에서 형태는 흐름 위에 칠한 장식이 아니라, *flux 가 만들고 유지하는 기하 그 자체*다. 다섯 겹으로 빚어진다:

| 원리 | 형태는 = | 우리 sim 의 현재 |
|---|---|---|
| **비평형 소산구조**(Prigogine) | 에너지가 흐르는 *통로*(베나르 셀·태풍의 눈) | ✅ 비평형 throughput 있음(별→E→소산) |
| **대칭 깨짐·불안정**(Turing) | 균일의 불안정(빠른 억제 vs 느린 활성 → 점·줄·격자) | 🟡 재료 있음 — *비확산 R 자기촉매(활성) + 확산 E(기질)* = Gray-Scott 절반(step-0015). **둘째 전역 필드 금지**(단일 척추) — 기존 E↔R 두 timescale 을 조여 창발 |
| **상분리·표면장력** | 안 섞이는 상의 *경계(막·표면)* = 윤곽 | 🟡 **막 창발(step-0018)** — kin E 공유(`couple`)로 개체 액적 내부 균질·경계에 *막*(단차) 창발(막 지수 1.98→3.46, 바닥 E 필드에 실림). *단* 곡률·표면장력 동역학(둥글어짐·합쳐짐)·불투과 막은 아직(R2·선택투과 백로그) |
| **주형 성장 = 형태발생** | 유전형이 *어디에 굳힐지* 지시 → 누적 성장 | 🟡 genotype `G`(0015) 있으나 *복제 속도*만 — 공간 배치 미지시 |
| **수송 기하**(왜 나무가 가지치나) | 흐름을 부피에 분배/수집하는 최적 가지구조 | ⬜ 미도입 |

다섯의 공통점: **형태는 flux 의 *결과*지 입력이 아니다.** 그래서 렌더러가 author 할 수 없다 — 만들어 넣는 순간 인과가 뒤집힌다(§4).

**"두 뷰가 *물질 형태*에서 같은 것"은 버그가 아니라 *진단*이다** — 시뮬이 아직 물질(R)에 형태(곡률·가지·막)를 안 빚었다는 정직한 신호. **단 *에너지 vs 물질* 자체는 두 뷰가 갈려야 한다(§4·§5b 설계 확정)** — 에너지 변위 뷰는 `h=f(E)`(에너지가 곧 지형, *값의 지도*), 세계 해석 뷰는 `h=f(물질=R+저활성E)`(흐르는 에너지는 지형을 안 부풀리고 *빛*). 종전엔 둘이 `h=E+R` 을 공유해 똑같아 보였다 — 높이가 에너지를 물질로 오역한 탓. *어느 양을 높이로 드는가*(물질)에서 두 뷰가 갈리고, 남은 *물질 내부의 형태*만 형태 사다리가 채운다(아래).

> **첫 형태가 필드에 실렸다(step-0018, 형태 사다리 R1 ✅)** — 막/flux 결합(`couple`)이 kin 끼리 *E 자체*를 재분배해 개체 도메인+막을 **바닥 E 하이트필드에 새겼다**. 이제 생명은 0-D 점이 아니라 *내부 E 공유·경계 막*을 가진 flux 결합 도메인이고, 같은 해석 렌즈가 그 형태를 **코드 수정 0** 으로 받아 그린다 — 이 §5 명제("형태가 생기면 렌즈가 공짜로 받는다")의 첫 실현이자 *렌즈가 옳다는 증거*. 남은 형태(줄기·가지·곡률 표면·둥근 세포)는 사다리 R2~R4 가 잇는다(아래).

**형태는 시뮬 step 이 위 1~5 를 한 조각씩 획득해야 *창발*한다**(렌더러의 일이 아니다, [SPINE.md](SPINE.md) §다섯째 축 = 개체는 author 가 아니라 *차등 응집이 빚은 표면장력 액적 = flux 결합 도메인*으로 *측정*). 이후 step 이 형태를 빚으면 — 필드 자체에 구조가 생기면 — **같은 해석 함수가 그 형태를 공짜로 받아 그린다**(§6 입력 계약 불변, 코드 수정 0). 그게 렌즈가 옳다는 증거다. 그때까지 해석 레이어는 *색·재질·빛*만 정직하게 비춘다.

> **형태 사다리**(STATE 권위로 한 조각씩, [SPINE.md](SPINE.md) §다섯째 축). *단일 척추 불변 — 어느 조각도 둘째 전역 필드를 더하지 않는다; 다양성은 E 의 상(R)·속성(G)에 싣는다*:
> **R1 ✅ 개체(다세포='계') = 차등 응집 → flux 결합 도메인·막**(step-0017 공간 토대[표면장력 액적=kin 연결 성분 *측정*] + step-0018 막/flux 결합[kin E 국소 공유 → 내부 균질·경계 막 창발, 바닥 E 필드에 실림, 막 지수 1.98→3.46]). 형태가 처음 필드에 실린 조각 — 렌즈가 코드 0 으로 받는다. · **R2 곡률 기반 표면장력**(응집/막을 경계 곡률로 편향 → 액적 둥글어짐·합쳐짐[coalescence]; 노브=0→회귀0·측정 원형도→1) · **R3 `G` → 방향성 결정화**(genotype 이 결정/복제 *방향*을 국소 편향 → 등방 blob 대신 가지·결정축[R 하이트필드 *형태*]; R 속성이라 단일 척추, 노브 `kAniso`=0→회귀0·측정 이방성 지수>1) · **R4 E↔R 튜링 불안정**(*둘째 필드 없이* — 비확산 R 자기촉매=활성 + 확산 E=기질의 두 timescale → 균일 깨 반점/줄무늬) · **표현 분열 통일**(E·R·A·m·G 같은 원시형 → 형태가 살 *내부*; 대형 리팩터). 각 조각은 가설 4기둥 + 척추 체크 4항을 통과해 닫고, *측정 가설*(형태를 재는 수: 막 지수·곡률·이방성 지수·도메인 수·경계 길이)로 4번째 기둥을 채운다. **형태가 생기는 순간 이 §2·§5 를 갱신**(원형별 *형태* 행 추가)한다 — R1 이 그 첫 갱신(이 §2 표 "개체 도메인·막" 행 + §5 "상분리·표면장력" 🔴→🟡).

## 5b. ✅ 닫힘 — *에너지*가 아니라 *물질*을 그린다 (높이=물질 분해 · 구현 2026-06)

§5 는 *형태*(시뮬의 일)를 다뤘다. 이건 더 근본적인 격차였다 — **무엇을 높이(부피)로 드는가**다. 렌더러 트랙이되 "재질"이 핵심이 아니다. **`VS_WORLD/FS_WORLD` 강화로 닫혔다**(아래 설계대로 — 높이=물질·빛=에너지).

**사용자 지적(2026-06)**: "에너지 높낮이만으로 물질을 표현할 수 없다 — 에너지와 다양한 속성으로 물질을 그려야 한다. 현실 원리를 참조하라." **진단**: 종전 `h=E+R`(`engine/hws-3d.js:611,661`)이 *흐르는 에너지 E*까지 지형 높이로 부풀려 **에너지를 물질로 오역**한다(좌·우 두 뷰가 이 높이를 공유해 똑같아 보인 근본 원인). 종전 "재질이 안 갈린다"는 진단은 *증상*이고, 병의 *뿌리*는 높이가 에너지였던 것.

**현실 원리 — 에너지와 물질은 존재론적으로 다른 층, 다르게 보인다**:

| | 에너지 (energy) | 물질 (matter) |
|---|---|---|
| 본성 | *장(field)* — 공간에 퍼짐 | *질량/응축상* — 공간을 점유 |
| 형태 | **없다** | **있다**(부피·경계·표면) |
| 보이는 법 | 빛·열·흐름(발광·색온도·이류) | 지형·표면·덩어리(높이·법선·경계) |
| 뜨거운 곳은 | *더 밝다*(안 솟음) | — |
| 무거운 곳은 | — | *솟는다*(안 밝아짐) |

**설계 확정 — 활성도 `A` 를 물질/에너지 분류 다이얼로 써서 높이를 분해한다**(새 필드 0 · 시뮬/결정론/verify 무관 · 기존 E/R/A/G 를 *다르게 읽음*):

| 척추 양 | `A` | 물질/에너지 | 세계 원형 | 높이 기여 |
|---|---|---|---|---|
| 고활성 `E` + `A` | 큼 | **에너지** | 빛·불·흐름·열 | **0**(빛으로) |
| 저활성 `E`(고임) | ≈0 | **액체 물질** | 물·웅덩이 | 깊이=E(평평·투과) |
| `R`(결정화 저장체) | ≈0 | **고체 물질** | 바위·나무·퇴적 | 높이=R(솟음·불투명) |

세계 해석 뷰 높이: **`h = hOf(R + 저활성E)`** — 물질만(흐르는 에너지=고활성 E·A 는 빠져 빛으로, 높이 0). `A` 가 *세계가 살아있는 정도*를 재는 본래 용도(§1)가 여기서 실현된다. **척추 주의(2026-06)**: "깊이=E(평평)" 의 *평평*은 액체의 *재질*(투과·광택·낮은 기복)로 읽되, 높이는 물질 분포(R·저활성E)를 *그대로* 따른다 — 액체 높이를 손으로 평탄화(`kFilm` 포화 막 등)하면 §4 가 금지한 *형태 author*("물은 평평한 시트", E 분포 재성형, 척추 체크 2 위반)다. 1차 구현이 그 평탄화를 넣었다가 되돌렸다. 두 뷰의 *실루엣* 차이는 *흐르는 에너지 제거*(별·확산이 안 솟음)에서만 정직하게 나오고, 더 큰 형태 차이는 *시뮬*(형태 사다리)이 빚어야 렌즈가 받는다(§5).

**물질을 다속성으로 분화(에너지 + 다양한 속성) — 정체는 양이 아니라 속성의 함수**:

| 속성 | 필드 | 표현 |
|---|---|---|
| **상(phase)** | R / 저활성E / 빈칸 | 고체(솟음·불투명) / 액체(평평·투과) / 기체·공허(없음) — 결정화·증발 문턱 *이산* 분기(lerp 금지) |
| **조성(composition)** | `G` 태그 | 종/물질 색·결정성(돌 vs 나무 vs 산호) — 돌/나무를 가르는 건 *유전의 유무*(§2) |
| **밀도(density)** | `R` 크기 | 불투명도·견고함·높이 |
| **구조(structure)** | `couple` 막/도메인 | 경계 가진 응집체(개체, step-0018 막이 첫 조각) |

**현실 원리 — 상전이가 물질↔에너지를 잇는다(닫힌 장부, 이미 시뮬에)**: 결정화(E→R, 0008) 빛→고체 / 연소 FSM(R→E, 0013) 고체→빛 폭발 / 풍화·증발(R→E) 고체→빛·안개. 뷰는 *현재 셀의 상만 읽어*(R 우세=고체 / 저활성E=액체 / 고활성E=빛) 그리면 된다 — 변환은 시뮬이 장부 보존으로 이미 함.

**정직한 효과(왜 이게 옳은가)**:
- **초기 step(0001~0007, R 없음)**: 물질이 거의 없어 → 지형 평평 + 흐르는 빛 + 고인 물만. *올바르다* — 아직 응축 안 된 에너지 세계.
- **R 누적(0008~)**: 고체 물질이 *솟아오른다* — 에너지에서 물질이 *창발*하는 과정이 화면에 그대로. 결정화 문턱이 빛→고체 전이를 만든다.
- **두 뷰가 *높이부터* 갈린다**: 좌=에너지 변위(E가 지형), 우=물질 세계(R/물이 지형, 에너지는 빛). 사용자가 가리킨 "에너지와 세계해석은 시각화가 다르다"가 실현된다.
- **§5 형태 사다리와 상보**: 시뮬이 R 에 형태(곡률·가지·막, R1~R4)를 빚으면 이 물질-높이가 그걸 *코드 0* 으로 받는다. 형태(시뮬)와 물질-읽기(렌더러)는 직교하되 같은 R 위에서 만난다.

**구현(렌더러 트랙 — *시뮬·결정론·verify 무관*, 순수 프레젠테이션 · `engine/hws-3d.js` 2026-06)**:
1. ✅ **높이 = 물질(분포 재성형 0)**: `matH = hOf(R + 저활성E)` — 흐르는 에너지(고활성 E·A, `actFrac`)*만큼만* 에너지뷰(`h=E+R`)와 갈린다(별 연소·확산 전선이 솟지 않고 `vGlow` 로 빛난다). 고인 물(저활성 E)은 *물질*이라 분포 그대로 높이에 실린다 — 차이는 *재질*로 읽는다. 법선도 물질 높이(`hAtXY`).
2. ✅ **물질 속성마다 다른 *읽기 함수*(높이 아닌 색·재질·빛 — §3 허용)**: 상(3분기 `solid/liquid/void`·lerp 0 — 고체 무광·액체 투과·광택·공허 암흑) · 조성 `G`→색조(`geneCol` 돌vs나무) · 밀도 `R`→밝기·불투명(`store·(0.5+0.5·dens)`) · 깊이→색(얕음 청록·깊음 남색, 액체) · 광택 `spec=vWet·pow(d,28)`(액체 전용). 흐르는 에너지→`vGlow` 발광.
3. **검증 = 눈으로**(헤드리스 verify 아님 — 화면이 권위): step-0018.html 을 띄워 ① 흐르는 에너지(별·확산)가 솟지 않고 빛나는지 ② 물·돌·나무가 재질로 갈리는지 ③ R 누적에 따라 고체 물질이 솟는지. *흐르는 에너지가 있는 자리*에서 두 뷰 높이가 갈리고, *정착 물질*에선 같은 실루엣(=§5 진단, 시뮬에 형태 없음 — 버그 아님).
4. ✅ 닫음 → §8 로드맵 3행. **척추 정합(중요)**: 1차 시도서 "물 평탄화(포화 막 `kFilm·(1-e^-E)`)"로 두 뷰를 더 다르게 보이려 했으나, 이는 §4 가 금지한 *형태 author*("물은 평평한 시트" — E *분포*를 손으로 재성형, 척추 체크 2 위반)라 *되돌렸다*. **렌더러는 실루엣을 못/안 만든다** — "완전히 다른 형태"는 *시뮬*(형태 사다리 R2~R4)이 빚어야 같은 렌즈가 코드 0 으로 받는다(§5). **남은 한계(백로그)**: ⬜ 구조(막) 별도 렌즈 미구현(액체 E 에 묻어 옴) · ⬜ 액체 투과/굴절은 광택 근사(진짜 굴절=§8 6행) · 오버레이 링/빔은 에너지뷰 높이 기준(공유 버퍼).

> **종전 "재질 렌즈"(물 투과·돌 무광·나무 결정) 프레이밍은 이 *물질 표현*의 *하위*(조성·밀도 속성)로 흡수된다** — 핵심은 재질이 아니라 *높이=물질·빛=에너지* 분해다. 이 트랙은 형태 사다리(R1~R4, 시뮬 step)와 직교하되, 둘 다 "에너지를 세계로" 번역하는 같은 명제의 두 절반이다.
