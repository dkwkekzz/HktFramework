# step-0016 — 생명 유전(inherit): genotype 을 *생명의 대사 엔진*에 묶는다 — 척추 다섯째 축의 둘째 칸(R 위 유전 → *생명* 위 유전)

> [step-0015로](step-0015.md) · 실행물: [step-0016.html](step-0016.html)(3D 표준 셸) · 시뮬 로직: `engine/hws-laws.js` 의 **`inherit` 법칙 1개**(LAW_ORDER ⑧b — 번식 뒤, sim-core.js 복사 없음) · 헤드리스: `step-0016/verify.js` · 엔진 재현: `node engine/validate/verify-sim-engine.js`

step-0015 가 **유전의 토대**를 깔았다 — 저장(R)의 *씨앗 끝*에서 자기복제하는 R-배치(genotype, 이산 태그 G)가 유전·변이·선택을 창발시켰다. 그러나 그 유전은 *R 위*에만 있었다(SPINE "유전이 개체보다 먼저"). 생명(m, 활성도 *가운데*)은 아직 genotype 없이 스칼라 m 만 복제했다 — *느슨한* 분열이지 *단단한* 자기복제가 아니었다. step-0016 은 그 다음 칸을 놓는다: **그 genotype 을 생명의 대사 엔진(m)에 단단히 묶는다.** 생명 = *자기복제 광물(genotype)을 제 소산 엔진(대사)에 묶어 활성도 가운데 선 것*(SPINE 결정2; 주요 전이 사다리 복제분자→…→**개체**의 다음 칸). 별의 *느슨한* 혈통(metallicity)과 달리 생명은 *단단한* 자기복제 — 유무가 아니라 **결합의 단단함**으로 갈린다(이름이 아니라 역할, 척추 그대로).

이것은 **law-pipeline 의 여섯째 step** 이다 — 더한 시뮬 로직은 `engine/hws-laws.js` 의 `inherit` 법칙 1개(LAW_ORDER ⑧b) + 노브 3개(`kInherit` 마스터 + `inheritMu`·`inheritCost`, 적합도 맵·태그 종류는 step-0015 와 *공유* — genotype 개념 통일) + 생명 유전형 속성 `a.g`(이산 태그)의 *가법* 해시. 회귀는 동결 *해시*로 잠근다 — `golden-sim.json` 의 `life@` 키 신규 = step-0017 회귀 앵커. `kInherit=0` → step-0015 비트 불변(`gene@`).

생명 유전은 **세 결합**으로 genotype 을 생명에 묶는다(모두 국소 — 전역 조율자 0): **① 부트스트랩(획득)** — 유전형 없는 생명이 제가 선 칸의 R-genotype(`G[center]`)을 *읽어* 제 유전형으로 삼는다(생명은 광물 유전자에서 부트스트랩, Cairns-Smith). **② 상속** — 분열 자식이 *인접 부모*(자식은 늘 부모의 4이웃에 태어난다)의 태그를 물려받는다(±변이=복제오류). **③ 표현형→대사** — `fit(태그)=geneFit0+geneFitStep·(태그−1)` 가 낮으면 차등 대사세(`inheritCost·(1−fit)·m`, m→metabolized 쌍 거래) → 고적합이 *생명 개체군에서* 선택된다.

결과: **① 상속이 생명 계통에 흐른다** — mu=0 이면 분열 자식이 인접 부모 태그를 *완벽 물려받음*(fidelity **1.00**, 순수 클론 계통 ~351개체). **② 변이가 창발한다** — mu=0.02 면 변종 태그 3종 출현, 변이율 **0.0196 ≈ mu**. **③ 선택이 *생명 위에서* 창발한다** — 고적합 tag4(fit 0.95) vs 저적합 tag1(fit 0.50) 경쟁에서 고적합이 **3.27배** 더 점유(차등 생존, 표현형세). **④ 적응이 *생명 위에서* 창발한다** — 저적합만 파종+변이 → 생명 평균 적합도가 **0.50→0.81(+0.31)** 상승. **⑤ 회귀 0·닫힌 장부·결정론·churn 유지** — kInherit=0 시 step-0015 비트 동일(gene@), 잔차 **4.48e-13**, 해시 일치(a.g 가법), 공멸 없이 지평선 생존(carrying capacity ~63). **전체 스택에선 *모든* 생명이 R-genotype 에서 부트스트랩**(geneCells = pop) — 별→결정화로 빚은 R-genotype 위에 선 생명이 유전형을 *읽어* 단단히 묶는다. 표현형세는 활성도 A 의 *읽기 전용*과 달리 **실제 대사 변환**이되, 약한 결합(inheritCost 0.02)이라 임계 자기조직을 깨지 않는다.

> ① **회귀 0**: kInherit=0 이면 step-0015 와 비트 동일? (`reg` — 복제 스택 해시 == golden `gene@`)
> ② **보존·결정론**: 표현형세(m→metabolized 쌍 거래)가 도는 내내 닫힌 장부·결정론(a.g 가 해시에)? (`conserve`·`det`)

## 2. 메커니즘 — genotype↔대사 결합: 부트스트랩·상속·표현형세, 모두 국소·닫힌 장부

법칙 순서의 ⑧b(번식 ⑧ 직후)에 둔다 — 자식이 있어야 인접 부모에서 상속한다. 각 생명은 유전형 태그 `a.g`(0=무유전, 1..geneTypes)를 갖는다. kInherit≠0 일 때:

```js
// ⑧b inherit — 생명 유전(부트스트랩 + 상속 + 표현형→대사)
occ = {각 유전형 생명의 center → a.g}                      // 부모 매개(자식이 인접 부모를 찾는다)
for (각 생명 a):
  if (a.g 없음):
    if (a 갓 태어남):                                       // 상속 — 인접 부모(occ)의 태그
      for (4이웃 j): if (occ[j]) { a.g = occ[j]; break; }
      if (복제오류 < mu) a.g = ±1 이웃 태그(변이)
    if (a.g 아직 없음) a.g = G[a.center]                    // 부트스트랩 — 제가 선 R-genotype
  if (a.g):                                                 // 표현형 → 대사(선택)
    fit = geneFit0 + geneFitStep·(a.g−1)
    tax = inheritCost·(1−fit)·a.m                           // 저적합일수록 더 냄
    a.m -= tax; metabolized += tax                          // m→metabolized 쌍 거래(닫힌 장부)
```

다섯 설계 결정이 이 결합을 *척추 정합*하게 만든다:

1. **유전을 생명에 묶는다(SPINE §다섯째 축, 단단한 자기복제)** — step-0015 는 유전을 R(저장 극단)에 깔았다. 이 step 은 그 genotype 을 생명의 *대사 엔진(m)* 에 묶는다 — 생명 = 자기복제 광물(genotype)을 소산 엔진(대사)에 묶어 *가운데* 선 것. 별(소산 극단)의 *느슨한* 혈통과 생명의 *단단한* 자기복제는 *결합의 단단함*으로 갈린다(이름이 아님).
2. **유전은 *이산* 정보, 같은 genotype 을 공유** — a.g 는 Uint8 이산 태그다. step-0015 의 R-genotype 과 *같은* 태그·적합도 맵(geneTypes·geneFit0·geneFitStep)을 쓴다 — 새 유전 시스템이 아니라 같은 genotype 의 *담체 이동*(R→생명). 표현 분열을 한 칸 좁힌다(E·R·A·m·G 중 G 가 R 과 생명을 잇는다).
3. **다양성은 병렬 필드 아닌 속성에(단일 척추)** — genotype 다양성(태그 1..geneTypes)은 *생명의 속성* a.g 에 실린다. 필드는 여전히 E(+상 R) — a.g 는 둘째 구동 필드가 아니라 생명의 이산 라벨이다(별 state·R 의 G 가 그렇듯).
4. **다윈 엔진을 author 하지 않는다(창발)** — "상속·변이·선택"을 코드에 박지 않는다. 인접 부모 복사(상속)·복제오류(±1 변이)·차등 대사세(표현형) 라는 *국소 법칙*만 깔면, 상속·변이·선택은 그 위에서 *창발*한다. genotype→phenotype 맵(fit=태그의 함수)은 authored type 분기가 아니다 — E 동역학·활성도는 태그로 안 갈리고(필드는 E), 대사 *세율*만 태그의 함수다(활성도는 여전히 측정으로 환원).
5. **국소·닫힌 장부·순환** — 부트스트랩=내 칸 G, 상속=인접 부모 occ, 표현형=내 m(전역 조율자 0). 표현형세는 m→metabolized 쌍 거래(crowd·baseCost 와 같은 소산 경계)라 장부가 닫힌다. genotype 은 죽음에서 휘발(사망 시 m→E, 태그 소멸)하고 새 생명이 다시 부트스트랩 — 유전 정보가 *순환*한다.

### reproduce(⑧, 동결)를 안 건드린다 — 부모 위치가 매개(stigmergic)

번식(⑧)은 자식을 배열 끝에 append 하고 태그를 안 박는다(동결 유지). inherit(⑧b)가 그 직후에 돌며, 자식은 *늘 부모의 4이웃*에 태어나므로 점유 맵(occ)에서 인접 부모를 찾아 태그를 물려받는다 — reproduce 를 수정하지 않고 상속을 구현한다. occ 는 *bornTick 이 아니라 이미 태그를 가진* 개체로 만든다(씨앗을 tick T 에 심고 같은 tick 에 번식해도 부모가 빠지지 않게).

- **(1) 상속(충실 물림)** — mu=0 이면 한 점 씨앗(tag 2 클러스터)이 분열 자식에 제 태그를 *완벽 물려준다*: fidelity **1.00**(전 시드, 모든 유전형 생명이 부모 태그). 자식은 늘 부모의 4이웃에 태어나므로 인접 부모를 찾아 *이산* 태그를 복사한다 — 유전이 *생명 계통*에 흐른다(step-0015 의 R 위만이 아니라).
- **(2) 변이** — mu=0.02 면 복제오류로 변종 태그 3종 출현, 변이율 **0.0196 ≈ mu**(0.02). 상속(충실 물림)과 변이(복제오류)는 다윈 동역학의 두 토대 — 이제 *생명* 위에서.

- **(3) 선택** — 고적합 tag4(fit 0.95)와 저적합 tag1(fit 0.50)을 *교차 파종*(준균일 혼합)해 cell 별로 경쟁시키면, 고적합이 차등 대사세를 *덜 내* 더 빨리 번식해 **3.27배** 더 많은 칸을 점유한다(차등 생존=선택, *생명 개체군에서*). 코드에 "선택"을 박지 않았다 — 표현형세 차 + 유한 기질이 *선택을 창발*시킨다.
- **(3b) 적응** — 저적합(tag1)만 흩뿌리고 변이를 켜면(mu=0.1), 고적합 변종이 선택돼 생명 평균 적합도가 **0.50→0.81(+0.31)** 오른다. 지속 churn(carrying capacity 가 그리드를 안 채워 연속 회전)이 변종 침입을 허용한다 — 변이+선택이 함께 돌면 *적응*이 *생명 위에서* 창발한다.

## 척추 체크 4항 (SPINE.md)

1. **단일 척추 ✅** — a.g 는 병렬 *구동* 필드가 아니라 생명의 *이산 속성*(태그). 필드는 여전히 E(+상 R). 다양성(genotype)은 속성에 — 둘째 척추 아님. step-0015 의 R-genotype 과 *같은* 태그를 공유(표현 분열 한 칸 좁힘).
2. **활성도 환원 ✅** — genotype→phenotype 맵(fit=태그의 함수)은 *대사 세율*만 바꾼다(authored type 으로 E 동역학·활성도를 분기하지 않음). 생명은 여전히 활성도 축 가운데 — 표현형세는 소산(대사) 강도의 변조.
3. **국소 문턱 ✅** — 부트스트랩(내 칸 G)·상속(인접 부모)·표현형(내 m) 다 셀별·개체별 국소량. 전역 조율자 0.
4. **순환 장부 ✅** — 표현형세는 m→metabolized 쌍 거래(닫힌 장부 불변, 잔차 4.48e-13). genotype 은 죽음에서 휘발(m→E, 태그 소멸)하고 새 생명이 부트스트랩 — 빠른 상속 + 사망 휘발로 유전 정보가 순환(비가역 ≠ 비보존).

## 5. 화면에서 직접 확인하는 법

[step-0016.html](step-0016.html) 을 연다 — 3D 표준 셸. 클릭 동작 기본 = "유전 생명 놓기":

## 6. 의외의 발견

1. **전체 스택에서 *모든* 생명이 유전형을 갖는다(geneCells == pop, 전 시드).** 통제 아레나에선 a.g 를 직접 심었지만, 전체 스택에선 생명이 *빠짐없이* R-genotype 에서 부트스트랩한다 — 별→결정화로 빚은 R 위에 생명이 살기 때문이다(생명은 채식지=R 핵 근처에 모인다). 무유전 생명이 거의 안 남는다. 유전과 생명이 *같은 자리*(R-rich 채식지)에 사는 substrate 의 자연스런 귀결 — "유전이 개체보다 먼저"(R 위 유전)가 깔려 있으니 생명이 깨어나면 그 위에서 곧장 유전형을 입는다(Cairns-Smith 점토 유전자의 게임화).
2. **선택비가 R(step-0015 1.53)보다 생명(3.27)에서 두 배 강하다.** 같은 적합도 맵인데 생명에서 선택이 더 날카롭다 — *지속 churn*(생사 회전) 때문이다. R-주형 복제는 빈칸을 채우면 *멈춰* 성장기 일회 경쟁이지만(step-0015 한계 6), 생명은 carrying capacity 아래서 *연속 회전*해 적합 유전형이 부적합을 *지속 치환*한다(경쟁 배제가 끝까지 간다). *죽음이 있어 선택이 더 강하다* — 생명(소산 가운데)이 R(저장 극단)보다 다윈 동역학에 더 알맞은 무대다.
3. **표현형세는 *실제 변환*인데도 churn 을 안 깬다(약한 결합 0.02).** 활성도 A(읽기 전용, step-0014)와 달리 표현형세는 m 을 *실제로* 깎는다(소산). 그런데도 별·생명 churn 이 보존된다 — 약한 결합(2%/tick)이라 도는 순환에 *얹힌* 미세 편향일 뿐이다. 결합을 키우면(0.05) 한계 개체군이 공멸한다(§한계 4) — 유전 정보가 에너지 순환의 *승객*이라는 step-0015 의 발견이 생명에서도 성립(기관차 아님). *선택은 churn 을 조향하지 구동하지 않는다.*

## 7. 정직한 한계

1. **적합도 맵이 authored·단봉이다 — 열린 진화(OEE) 아님(step-0015 와 동일).** fit(tag) 는 매끄러운 단봉 맵 — 선택은 늘 최고 태그로 climb 하고 거기서 멈춘다(적응이 *포화*). 이 step 은 다윈 동역학을 *생명*으로 옮겼을 뿐, 열린 진화를 만든 게 아니다(인공생명 미해결 — Tierra/Avida 정체). 각은 있으나 도달 보장 아님.
2. **phenotype 이 *대사 세율* 한 축으로만 발현한다.** 태그는 차등 대사세에만 쓰인다 — 흡수율·이동·형태·분열 문턱 등 풍부한 phenotype 으로 발현되지 않는다(유전형→표현형 맵이 1차원·스칼라). 진짜 적응 방산엔 다차원 phenotype 발현이 필요(백로그).
3. **생명은 아직 0-D 점 — 개체(다세포='계')가 아니다.** genotype 을 생명에 묶었으나 생명은 여전히 한 셀 스칼라 m(형태·경계·내부 없는 0-D 점). "유전이 개체보다 먼저" 의 *유전* 칸을 닫았으니 다음은 *개체*(차등 응집→표면장력 액적→flux 결합 도메인) — kin selection 이 안정화할 클론 유전 정체성이 이제 있다(주요 전이 사다리 다음 칸).
4. **전체 스택 결합이 약해야(0.02) churn 이 보존된다 — 선택이 그만큼 미약하다.** inheritCost 0.05 면 한계 시드(42)가 ~34000 tick 에 공멸했다(표현형세가 carrying capacity 를 넘어 음성 피드백을 보탬). 그래서 전체 스택 기본은 0.02(약함) — 생명 평균 적합도가 시드별로 0.50~0.84 로 *완만히* 갈린다(통제 아레나의 0.25 강결합 선택과 대비). *통제는 격리 측정, 전체 스택은 통합 동역학* — 둘의 결합 강도가 다르다(step-0015 가 통제에서 mu 를 달리 준 것과 같은 정신).
5. **상속이 *인접 부모* 휴리스틱(scan 순서)·통제 아레나 의존.** 자식은 늘 부모의 4이웃에 태어나 인접 부모를 찾지만, 4이웃에 다른 유전형 생명이 있으면 scan 순서(N,S,W,E)로 *먼저 온* 태그를 무는 약한 이방성·경계 혼합이 있다(통제는 두 유전형을 교차 파종해 cell 별 경쟁으로 이를 평균화). 또 heredity/select 수치는 *통제 아레나*에서 강결합(0.25)으로 잰 격리 측정 — 전체 스택은 약결합·부트스트랩이라 더 완만하다.
6. **부트스트랩이 sticky — 일단 입은 유전형을 안 바꾼다.** 생명이 한 번 유전형을 획득하면(상속·부트스트랩) *평생 유지*한다(다른 R-genotype 위로 옮겨도 안 바뀜) — 단단한 carrier 의 단순화다. 환경(기질) 변화에 유전형이 재획득되는 동역학(수평 전이·재부트스트랩)은 백로그.
7. **3D 생명 유전형 렌더는 2D drawHook 한정(헤드리스 미검증).** 생명을 유전형 색 점으로 칠하는 것은 2D 오버레이에만 입혔다 — 3D 하이트필드의 생명 마커 색은 미구현(R-genotype 색은 step-0015 에서 3D 입혔으나 GLSL 육안 검증 필요). 헤드리스 `verify heredity·select` 가 본 thesis 의 권위.
