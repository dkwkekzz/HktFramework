# PRIMER — 이 세계를 직관으로 이해하기 (별·둑·봉우리·에너지)

> 형식 이론([SPINE.md](SPINE.md))을 *쉽게 풀어쓴 입문서*. 엄밀한 존재론은 SPINE, 별의 정식 정의·수치는 [step-0011.md](step-0011.md).
> 한 줄 요약: **세계엔 에너지(E) 하나가 흐르고, 모든 개체(별·둑·생명)는 그 에너지가 *얼마나 활발히 흐르느냐*로만 갈린다.**

---

## 1. 세계엔 숫자 하나뿐 — 흐름량 E

격자 모든 칸에 **E(흐름량)** 라는 숫자가 있다. 자원·에너지의 양이라고 보면 된다. 별도 바위도 생명도 *따로 코딩된 종류가 아니다* — 전부 이 E 하나가 만드는 패턴이다. 다른 점은 단 하나, **그 자리에서 에너지가 얼마나 활발히 흐르는가(활성도)**:

```
   활성도 낮음 ◄─────────────────────────────► 활성도 높음
   (저장·평형)            (가운데)              (소산·방출)
      둑 R                 생명                    별
   광물·바위            먹고 흘림              불·확산
   "주차된 에너지"     "흐름 통과 패턴"       "쏟아내는 에너지"
```

같은 에너지가 **굳어 멈추면 둑(저장)**, **활활 흐르면 별(소산)**, 그 가운데서 흐름을 통과시켜 자기를 유지하면 **생명**이다.

---

## 2. 봉우리란? — E의 지형, 그리고 먹이터

E를 칸마다 높이로 그리면 지형이 나온다. **봉우리 = 주변보다 E가 높이 쌓인 곳**(언덕 꼭대기):

```
E  ▁▁▂▃▅▇█▇▅▃▂▁▁▁▁▂▃▄▃▂▁▁
          ↑           ↑
        봉우리      작은 봉우리
```

- **봉우리 자체**는 "E가 높은 지점".
- **운동을 일으키는 건 "차이"(기울기)** — 옆 칸과의 E 차이. 생명은 더 높은 E 쪽으로 기어오른다. 그래서 차이가 생명을 *밀고*, 그 차이가 모여드는 꼭대기가 봉우리다.

생명은 E를 먹고 산다 → **봉우리 = 먹이터**. 생명은 봉우리에 모여 먹고 번식한다.

> 주의: 3D 화면 높이는 `E + 기복·R`이라, *먹이 봉우리(E)*와 *지형 언덕(R=둑)* 둘 다 높이로 솟아 비슷해 보인다. 하지만 둘은 정반대다(§4).

---

## 3. 별이 하는 일 — 떠도는 먹이터를 만든다

옛날(step-0010까지)엔 외부 **source**가 한자리에 E를 부어 *영원히 고정된 봉우리*를 만들었다. 생명이 다 거기로 모여 멈춰버렸다(동결). step-0011의 **별**은 이 고정 봉우리를 *떠도는* 봉우리로 바꾼다. 별의 한살이:

1. **점화** — 굳은 저장체 R이 어딘가 충분히 쌓이면, 그 자리에서 별이 켜진다(가스가 뭉쳐 별이 되듯).
2. **주입** — 별은 매 tick 주변에 E를 부어 넣는다. *이게 봉우리(먹이터)를 세우는 행위*다.
3. **서행** — 별은 천천히 한 칸씩 기어간다 → 봉우리도 같이 이동 → 생명이 쫓아다니며 **끝없이 나고 죽는다(churn)**.
4. **소진** — 연료가 다하면 꺼진다(비가역). 다른 곳에서 새 별이 켜진다 → 봉우리가 **명멸하며 떠돈다**.

결과(verify 수치): 외부 고정 source 대비 churn **634배**, 무게중심 떠돎 **20배**. 고정된 수렴점이 사라졌다.

---

## 4. 둑 vs 별 — 같은 축의 양 끝

`둑 쌓기`는 클릭한 자리에 **R(저장체)** 을 칠한다 — *흐르는 E(먹이)가 아니라 굳은 저장*이다.

| | **둑 (R, 저장체)** | **별 (star)** |
|---|---|---|
| 극단 | 평형(저장) | 소산(방출) |
| 활성도 | ≈ 0 (가만히 쌓임) | 높음 (E를 쏟아냄) |
| 하는 일 | 지형을 만든다(기복) | **먹이 봉우리(E)를 만든다** |
| 생명에게 | 못 먹음 (고체) | 먹임 (별이 뿜은 E) |
| 운동 | 부동 | 서행·필멸 |
| 비유 | 장작 산·광물 | 모닥불 |

**둘 다 에너지지만**, 하나는 가만히 주차된 것, 하나는 활활 내보내는 것. 둑은 높이 솟아도(3D 지형 `E+기복·R`) *먹이가 아니다* — 생명을 놔도 안 모인다.

---

## 5. 둑은 별의 요람 — R → 별 → E → R 순환

둑과 별은 무관하지 않다. **둑(R)이 점화 문턱을 넘으면 그 자리에서 별이 켜진다.** 빈 세계에 둑을 쌓고 가만 두면:

```
둑 쌓고  +100tick:  별#=2  ← 별이 둑 위에 켜졌다
        +500tick:  별#=9  sumE 4099→6267 ← 별들이 세계를 먹이기 시작
```

그리고 R은 거의 안 줄어든다 — 소비되는 게 아니라 *별이 설 자리를 알리는 신호(요람)*다. 완전한 고리:

```
둑(R) 쌓임 → 별 점화 → 별이 E 주입 → E 퍼져 다른 곳에 다시 R로 굳음 → 새 둑 → 새 별 …
```

**둑은 별의 차가운 요람, 별은 둑이 깨어난 뜨거운 모습.** 둑을 쌓는 건 곧 "여기에 다음 별을 심는다".

## 6. 에너지는 사라지지 않는다 — 보존과 과증식

생명 1개를 풍요로운 세계에 놓으면 봉우리가 싹 사라지며 폭발적으로 증식한다. **에너지가 사라진 게 아니다** — 장부 잔차가 계속 PASS(~1e-12). 봉우리가 *옮겨간* 것이다:

```
t=0    pop=  1   필드E=9818 ← 밝은 봉우리들
t=200  pop=395   필드E=1344 ← 봉우리 사라짐(수백 마리가 먹어치움)
```

먹힌 E는 세 갈래로 갔다:
1. **생명의 몸(M)** — 일부는 생물량(노란 원들)이 됐다.
2. **대사로 태워짐** — *대부분*. 수백 마리를 먹여 살리는 유지비로 "체열"처럼 흩어졌다(장부엔 기록, 보존).
3. **저장체 R에 잠김** — 세계 에너지의 *절대다수*는 R(굳은 저장)에 안전하게 잠겨 있다. 생명은 흐르는 E만 먹지 R(고체)은 못 먹는다.

> **세계가 에너지 바닥난 게 아니다** — 오히려 R에 가득하다. 다만 *먹을 수 있는 형태(필드 E)*만 폭발한 생명이 순식간에 훑었을 뿐.

이게 step-0011의 **과증식(overshoot)**이다: 외부 source 세계는 고정 공급이 상한(K≈11)을 만들지만, 내생 별 세계는 그런 음성 피드백이 없어 1마리가 뷔페를 만나 폭발 → 필드를 비운다.

### 그리고 왜 결국 *텅* 비는가 — 엔진이 멈추면 열죽음

과증식으로 끝나지 않는다. 한참 두면 생명도 별도 저장체도 *전부* 사라져 죽은 세계가 된다. 왜?

세계엔 **들어오는 길 하나 + 나가는 길 둘**뿐이다. 그리고 나가는 길은 *일방통행*이다 — 대사·증발로 흩어진 에너지는 장부엔 기록되지만(보존) 다시 못 쓴다(체열처럼).

```
        ┌──────────── 별 주입 (유일한 입력) ────────────┐
        │                                               ▼
   [ 별 ] ──연료(외부 질량)──►  E (흐르는 먹이) ──► 생명이 먹음
                                  │                      │
                              증발(일방) ◄──┘          대사(일방)  ← 못 돌아옴
```

세계의 일생(실측, 시드 42):

```
tick   생명 별#   활성E(E+M+R)   별 주입(누적)   대사로 태움(누적)
4000     5  10      42332          68715              0       ← 별이 채운 풍요
8000   214  10      12554         138158          95659       ← 생명이 맹렬히 태움
12000  217  10       6624         207335         167733       ← 저수지 거의 고갈
────────────────────────── 붕괴 ──────────────────────────
13000    0   0       2837         214500(정지)    175198(정지) ← 별·생명 동시 전멸
16000    0   0       1220         214500          175198       ← 잔불도 증발로 사라짐
```

붕괴의 3단계:

1. **생명이 과식 → 제 식량원(별)을 죽인다.** 생명이 흐르는 E를 *굳기 전에* 먹어치우면 E가 R로 못 쌓인다. 그런데 R이 **별의 점화 신호(요람)**였다 → R이 안 쌓이니 새 별이 못 켜진다.
2. **별이 꺼지면 입력이 끊긴다.** 기존 별들이 연료를 다 태우면(~290 tick) 꺼지는데, R 고갈로 새 별이 안 켜져 → **주입이 멈춘다**(표: 주입이 214500에서 정지). 유일한 동력이 사라진다.
3. **입력은 끊겼는데 새는 건 계속.** 별이 채워둔 거대한 저수지를 생명이 *주입보다 빠르게* 태우고(대사 167733 > 별이 보탠 양) 있었다. 입력까지 끊기자 남은 E·생명·저장이 전부 대사·증발로 빨려나간다 → 마지막 잔불(E+M+R 2837→1220)도 식어 사라진다.

> **한 줄: 세계는 "별이라는 엔진"이 돌아야만 사는 *열린 계*다. 생명이 과식으로 그 엔진을 꺼뜨리자, 열역학 2법칙(대사·증발의 일방통행)이 나머지를 전부 흩어버렸다.** 에너지가 *사라진* 게 아니라 못 쓰는 형태로 옮겨가 세계가 식은 것. SPINE의 "구동 없는 세계는 *반드시 죽는다*"의 실연이다(구동 off 11000 tick → sumE 0.068, [04-drive.md](step-0001/04-drive.md)).

*동결을 풀었더니 이번엔 과식으로 엔진을 꺼뜨려 죽더라* — 다음 step의 숙제는 **자기제한**: 생명이 과식하지 않게 묶으면(밀도 의존 음성 피드백) 식량원(별)을 안 죽이고 churn이 *끝없이* 이어진다. 동결(너무 적음)도 공멸(너무 많음)도 아닌 *임계 자기조직*.

## 7. 현실 비유

| 이 세계 | 현실 (느슨한 비유) |
|---|---|
| 흐름량 E | 에너지 일반 (열·빛·자원) |
| 봉우리 (E 높은 곳) | 먹이가 풍부한 자리 |
| 둑 / R (저장체) | **광물·암석·연료·씨앗** — 굳어 멈춘 에너지. 별이 태어나는 *짙은 가스·먼지 구름*에 가장 가깝다 |
| 별 | 항성 — 짙은 구름이 붕괴해 점화, 빛을 쏟다 연료 소진하고 꺼짐 |
| 생명 | 흐름을 통과시켜 자기를 유지하는 소산구조 |
| R→별→E→R 순환 | 가스구름 → 별 → 빛 → 식어 먼지 → 새 구름 (우주의 물질 재활용, *형태만* 닮은 비유) |

핵심: **"광물"은 따로 코딩된 종류가 아니라, E가 얼어붙은 저활성 phase에 붙이는 *역할 이름*이다.** 흐르면 불, 굳으면 광물 — 같은 에너지의 두 얼굴.

## 8. 화면에서 직접 해보기 ([step-0011.html](step-0011.html))

- **둑 → 별**: `둑 쌓기`로 한 곳을 두텁게 칠하고 재생 → 잠시 뒤 그 위에 별(밝은 백황색 코어)이 점화한다. 저장이 소산으로 깨어나는 순간.
- **떠도는 봉우리**: `별 씨앗 ×6` → `생명 ×5` → 생명이 떠도는 별을 쫓아 폭발적으로 churn, 무게중심(자홍 십자)이 떠돈다.
- **보존 확인**: 통계 패널에서 `sumE`가 떨어지는 만큼 `M`(생명 몸)이 오르고 **장부 잔차는 계속 PASS** — 에너지가 *이동*했지 사라지지 않았다는 증거.
- **과증식 관찰**: 한참 두면 생명이 과식해 봉우리를 비우고 → 별이 꺼지고 → 공멸. `분열 mDiv`나 `baseCost`를 올리면 폭발이 느려져 더 오래 churn을 볼 수 있다.
