## 4. DURABLE CONSTRAINTS — 모든 step이 지킬 정전(canonical) 사실

> 여러 step이 반복 참조하는 불변. 새 step은 이걸 어기면 척추에서 벗어난 것 — 재설계.

- **회귀 0**: 새로 더한 항을 끄면(계수=0) 직전 step과 **비트 단위 동일**(verify `reg`, maxDiff=0).
- **닫힌 장부**: E+R+T 보존 잔차 ≤ ~1e-13(미시 1e-6 / 거시 1e-7).
- **결정론**: 같은 시드 2회 → 전 셀 비트 비교 + 상태 해시 일치. **시드 결정론 — `Math.random` 금지.**
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **greedy 이동 = 국소 최대 함정** *(step-0010 해소)*: greedy는 옅은 골짜기 너머 더 큰 고임을 못 찾음(step-0005~0009 반복) — **탐사(run-and-tumble)가 해소**(escape): 구배가 없으면 무작위 보행만 남고(필드 E의 운동을 생물량이 물려받음) 굶주린 생명이 골짜기를 건넌다.
- **동결을 푸는 건 운동이 아니라 *비균일성/불연속*** — 매끄러운 균일 표류는 갈릴레이 불변으로 정적 세계와 동일(step-0007).
- **"능력 추가"는 정적 끌개로 수렴 → 구조를 바꿔야 한다** — 이동·비용·탐사(0005·0006·0010)를 다 줘도 정적 source에선 동결. **step-0011이 구조를 바꿔(구동 내생화) 동결을 풂** — 영구 전역 봉우리 제거 = 수렴점 소멸(churn 634배).
- **구동 내생화는 동결을 풀되 *공멸*을 부른다(step-0011) → 자기제한이 닫는다(step-0012)** — 외부 source의 *고정성*이 실은 carrying capacity(K)의 숨은 원천이었다(내생 구동엔 없어 공멸). step-0012가 생명에 *밀도 의존 자기제한*을 줘 K 를 생명 자신의 혼잡에서 창발시킨다 — **끝없는 churn = 동결도 공멸도 아닌 임계 자기조직** 완성.
- **carrying capacity 는 개체수가 아니라 *공간 분포*의 문제(step-0012)** — 자기제한을 *국소*(crowdR<채식지)로 주면 개체수는 줄어도 살아남은 생명이 채식지를 덮어 *공멸 지연뿐*. *채식지 척도*(crowdR=starR)로 흩뜨려야 채식지에 E 가 남아 결정화→연료(R) 재충전→지속. "몇 마리"가 아니라 "어떤 척도로 흩어졌나"가 지속을 가른다.
- **절제가 풍요보다 오래 산다(step-0012)** — 생명에 추가 *비용*(혼잡세)을 물려 더 죽게 만든 것이 개체군을 *영원히 살게* 했다. 솎이지 않은 풍요(0011)는 공멸, 솎인 절제(0012)는 지속. 끝없는 churn 의 maxR 은 *총 R 불변*이 아니라 *점화 가능 peak 의 정상상태*(흩어진 R 배경은 풍화돼도 활성 채식지가 peak 재충전).
- **별 연료 = 외부 질량(주입 경계)** — 별의 에너지는 닫힌 장부 밖(제 질량), 태워 E로 주입하면 `injected`로 추적(외부 source와 같은 경계). 내생화는 에너지 *원천*이 아니라 *언제·어디서*(R 누적)를 세계 상태로 결정하는 것. R은 별의 점화 신호(siting)지 소비 대상이 아니다.
- **law-pipeline 표준(0011~)** — 새 step = `engine/hws-laws.js` 법칙 1개 + 노브 + `LAW_ORDER` 한 자리(노브=0 → early-return = 회귀 0). 회귀 앵커 = 동결 *해시*(`verify-sim-engine.js` + `golden-sim.json`: std@/endo@/cwd@), 동결 파일 아님. 장부/해시 확장은 미존재 시 no-op 가법만(상태 라벨도 `state!==undefined` 일 때만 해시에 먹임 → FSM off 면 과거 해시 불변). (0001~0010 복사 코어 동결.)
- **이산 FSM = 라벨이지 타입(step-0013, SPINE 결정3)** — 상태(living/burning/ash)는 *활성도 배수의 함수*지 자유 태그가 아니다(labelViol=0: 라벨==배수 인덱스). 켜지는 국소 법칙은 *스칼라 배수 + 게이트*뿐, 별도 에너지 경로 분기 금지(결정2 정합 a). burning/ash 는 *측정 throughput(dE/dt)* 으로 환원(b). 이산성은 *문턱·timescale 분리*에서 창발 — 점화 빠른 snap·소진 느린 연료, 두 문턱 벌려(burnOn>burnOff, 폭>0) anti-chatter(c). 새 FSM 을 더할 땐 verify 가 (a)(b)(c) 를 수치로 통과해야 닫는다.
- **불은 연료가 다해야 꺼진다(step-0013)** — 스스로 선택된 burning 별은 전율 주입으로 제 핫코어를 달궈 조기 quench(burnOff) 문턱 밑으로 잘 안 떨어진다(ash 99% 연료 소진·1% 핫코어). FitzHugh–Nagumo: 빠른 변수(점화)는 snap, *느린 변수(연료)가 사이클을 끈다*. burnOff 는 히스테리시스 폭(anti-chatter)엔 필수지만 소진 경로론 미미.
- **별 문턱이 두 층(step-0013)** — *siting*(R 누적 핵에서 별이 *선다*, ignThresh — R 공간)과 *flashover*(선 별이 *전율 연소로 뒤집힌다*, burnOn — E 잔열)는 다른 문턱. 활성도 축 위 "존재"와 "활성"이 갈린다. living(kindling)은 siting 됐으나 flashover 전 — 정지해 핫코어를 쌓아야 도달(떠돌면 흩어져 못 참).
- **존재론↔동역학 독립(step-0013)** — 이산 FSM(존재론 조각)을 더해도 step-0012 의 끝없는 churn(동역학)이 보존된다(40k 전 시드 생존·후반 출생≈사망). 두 축은 직교 — 존재론 조각이 동역학을 깨지 않음을 확인.
- **활성도 = 척추 변수 E 의 flux, 분류는 측정으로(step-0014, SPINE 결정1·2)** — 활성도 A = E 의 통과 throughput(net dE/dt) EMA. 재고(E)와 흐름(A)은 다른 양 — *분류 신호는 흐름(A)*. 저장↔소산은 authored enum 아니라 *A 의 두 극단*으로 읽힌다(A_burn/A_store=26.1). 새 *측정* 필드를 더할 땐 verify 가 두 극단 분리를 수치로 보여야 닫는다(결정2). A 는 *연속축*(이분 enum 아님) — 생명·확산은 가운데.
- **측정은 부작용 0 — A 는 읽기 전용 계기(step-0014)** — 활성도 A 는 E/R/agent 동역학에 *되먹이지 않는다*(둘째 척추 금지 — 필드는 E 하나). 그래서 kFlux on/off 가 동역학을 비트 단위로 안 바꾼다(sustain 동일). 측정으로 분류를 *관찰*함과 그 분류를 법칙이 *소비*함은 다른 단계 — 0014 는 관찰만.
- **저장체의 "활성도≈0"은 R 아닌 *흐름 끊긴 자리*의 성질(step-0014)** — A_store(정착 R)≈A_quiet(정착 세계 전체)≈A_bg — 흐름이 가라앉으면 R 유무와 무관히 저활성, *소산(별)만* 활성도 축 높은 끝에 홀로. 활성도 축은 "무엇이 있나" 아닌 "흐름이 사나"를 잰다. 별 연소 셀의 100%가 R-rich(같은 substance)인데도 A 26배 — *흐름이 정체성보다 분류*(SPINE: 같은 자리가 저장·소산 동시에, 활성도가 순간 역할 읽음).
- **유전 = 저장(R)의 씨앗 끝, 이산 정보(step-0015, SPINE §다섯째 축)** — 유전은 별도 필드가 아니라 *R 의 능력*: 자기복제하는 R-배치(genotype=이산 태그 G)가 제 사본 결정화를 *촉매*한다(복제=E→R 쌍 거래+태그 복사). 유전은 *이산*을 요구한다 — 연속 필드(E·R·A)는 확산·EMA 로 번져 정보를 못 지키나(fidelity<1), 이산 태그는 복사 연산이라 세대 무한히 건너도 비트 보존(mu=0 → fidelity 1.00). 다양성(genotype)은 *병렬 필드 아닌 속성*(태그)에 — 단일 척추(필드는 E, G 는 R 의 라벨). 새 *유전* 속성을 더할 땐 verify 가 충실 복제(fidelity)·변이율(≈mu)·선택(차등 번식)을 수치로 보여야 닫는다.
- **다윈 동역학은 author 가 아니라 창발(step-0015)** — "유전·변이·선택"을 코드에 박지 않는다. 복제(태그 복사)·복제오류(±1 변이)·기질경쟁(빈칸+E 문턱)이라는 *국소 법칙*만 깔면 그 위에서 창발한다. genotype→phenotype 맵(fit=태그 함수)은 authored type 분기 아님 — E 동역학은 태그로 안 갈리고(활성도 환원 유지), 복제 *속도*만 태그의 함수. 변이+선택 함께 돌면 *적응*(평균 적합도 상승)이 창발(끌개 항상성을 넘는 첫 *방향 있는 축적*). **단 적합도 단봉·authored → OEE 아님**(다봉·공진화 지형+풍부한 phenotype 필요).
- **유전 정보는 에너지 순환의 *승객*이지 *기관차* 아님(step-0015·0016)** — 복제·표현형세는 활성도 A 의 *읽기 전용*과 달리 **실제 변환**(E→R 굳힘·m 깎음)이지만, 유전형은 이미 도는 순환에 *올라탈* 뿐이다. R 위(0015): 유전형이 substrate 절반 잠가도 churn 비트 보존. 생명 위(0016): 표현형세는 실제 대사 변환인데도 *약한 결합*(inheritCost 0.02)이라 churn 보존(0.05 는 한계 개체군을 공멸로 민다 — 선택이 carrying capacity 음성 피드백을 보탬). *선택은 churn 을 조향하지 구동하지 않는다.* 존재론 조각(유전)이 동역학을 안 깬다(0013·0014 와 같은 직교성).
- **유전↔생명 결합 = genotype 을 대사 엔진에 묶음, 단단한 자기복제(step-0016, SPINE §다섯째 축)** — step-0015 의 R-genotype 을 생명(m, 활성도 가운데)에 *세 결합*으로 묶는다: 부트스트랩(생명이 제가 선 R-genotype 을 읽음 — Cairns-Smith)·상속(분열 자식이 인접 부모 태그를 ±변이로 물려받음 — reproduce 동결, 부모 위치가 매개)·표현형→대사(fit 낮을수록 차등 대사세, m→metabolized 쌍 거래). 같은 태그·적합도 맵 공유(새 유전 시스템 아님 — genotype 담체 이동 R→생명, 표현 분열 한 칸 좁힘). 다양성은 *병렬 필드 아닌 속성*(a.g) — 단일 척추. 새 *생명 유전* 속성을 더할 땐 verify 가 상속(fidelity)·변이율(≈mu)·선택(차등 생존 ratio)·적응(평균 적합도↑)을 수치로 보여야 닫는다.
- **죽음이 있어 선택이 더 강하다 — 생명(소산 가운데)이 R(저장 극단)보다 다윈 무대로 알맞다(step-0016)** — 같은 적합도 맵인데 선택비가 R(1.53)보다 생명(3.27)에서 *두 배 날카롭다*. - **전체 스택에선 모든 생명이 R-genotype 에서 부트스트랩(step-0016, geneCells=pop)** — 통제 아레나는 a.g 를 author 하나, 전체 스택은 생명이 *빠짐없이* 제가 선 R-genotype 을 읽어 유전형을 입는다 — 별→결정화로 빚은 R 위에 생명이 살기 때문(채식지=R 핵). 유전과 생명이 *같은 자리*(R-rich)에 사는 substrate 의 귀결 — "유전이 개체보다 먼저"(R 위 유전)가 깔려 있어 생명이 깨면 곧장 유전형을 입는다(Cairns-Smith 게임화).
- **개체='계'는 author 가 아니라 차등 응집이 빚은 표면장력 액적으로 *측정*(step-0017, SPINE 주요 전이 사다리 유전→개체)** — 다세포 개체를 `Organism{cells}` 컨테이너로 *만들면* 활성도 환원(척추 체크 2) 위반이다. 대신 차등 응집(kin↑/타↓, Steinberg DAH = Schelling 분리: 같은 유전형 a.g 선호 + 빈칸 이주)이라는 *국소 위치 법칙*만 깔면 cell sorting → 같은 태그 블롭(표면장력 액적 = flux 결합 도메인)이 *창발*하고, 개체는 그 *4-인접 kin 연결 성분*(`measureOrganisms`)으로 *측정*해 읽는다. "표면장력"·"막"을 코드에 안 박는다 — 이종 경계 최소화가 kin 선호에서 창발(개체 먼저·막은 액적 표면으로 뒤). - **차등 응집은 위치만 — 장부 거래 0, 개체는 동역학의 승객(step-0017)** — 응집은 m·E·R 을 안 건드리고 *위치만* 재배치한다(move/tumble 과 같은 거래 0 경계 → 잔차 3.98e-13 불변·해시 새 항 0). 실제 위치 재배치(A 읽기전용과 다름)이되 장부 거래가 0이라 임계 자기조직(끝없는 churn)을 안 깬다(공멸 없음·carrying capacity ~69). 개체(존재론 조각)가 동역학을 안 깬다(0013·0014·0015·0016 과 같은 직교성). *개체는 churn 에 올라탈 뿐 구동하지 않는다* — 응집해도 생존 이득 0이라 진화적으로 *중립*(개체↔대사 결합 전까지, §3 새 🔴).
- **DAH(세포)=Schelling(사회)이 한 알고리즘·개체는 능동 정렬의 산물(step-0017)** — 차등접착(세포생물학)과 사회 분리(경제학)는 *같은 국소 법칙*(같은 종 선호 + 빈칸 이주)의 두 발현 — `adhere` 한 함수가 둘 다(이름이 아니라 역할, 척추 그대로). 또 개체는 밀도의 우연(percolation 잔클러스터, 통제 최대 11세포)이 아니라 *능동 정렬*(응집 최대 21세포, 2.6배)의 산물이라야 의미 있다 — 측정된 개체가 percolation 배경을 *넘어서야* 한다. 개체 크기는 substrate 의 *밀도·이동성*에 달림(통제 조밀·정적 평균 4.5 vs 전체 스택 희소·이동성 1.5) — 큰 다세포는 정착 생활사를 요구할 수 있다.
- **막은 author 가 아니라 측정 — kin E 공유가 빚은 창발 경계(step-0018, 형태 사다리 R1)** — "막"·"표면장력"·"장벽"을 코드에 박으면 author. 막 = 같은 유전형 kin 4-인접 생명끼리 *필드 E 를 국소 공유·재분배*(`couple`, 쌍 거래)하면 내부가 균질해지고 경계에 단차로 *창발*하는 것 — `measureMembrane`(경계/내부 ΔE = 막 지수)으로 *측정*해 읽는다(개체 먼저·막 뒤, 0017 의 연장). 결정적 정합: `couple` 은 *국소 4-인접 kin 쌍*만 보고 전역 `measureOrganisms`(연결 성분)를 *동역학에 안 쓴다* — "측정은 부작용 0" 정전 사실을 지키며 도메인은 국소 공유에서 창발. 새 *막* 형태를 더할 땐 verify 가 막 지수(경계/내부 대비 > 통제)를 수치로 보여야 닫는다.

- **소산구조 ≠ 진화하는 복잡계 — 유전이 빠진 토대(이번 논의)** — 비평형 throughput + 임계 자기조직(0012)은 세계를 *지속*시키나 복잡성을 *축적*하진 않는다(임계 끌개에 맴돔 — Bénard·불꽃·눈송이는 화려하나 진화 안 함). 사람급 복잡 적응계엔 다윈 동역학(유전·변이·선택)이 필요하고, 유전 = *이산* 정보의 자기복제(연속 필드는 정보 못 지킴 — 0008 R·0013 FSM 이산성이 재료). 경로 = R-주형 자기복제(하이퍼사이클·단일 척추 유지). **유전이 개체보다 먼저**(다세포 협동은 클론 kin selection 안정화). **정직: OEE 미해결** — 각은 있으나(원리·재료) 도달 보장 아님(Tierra/Avida 정체). 사다리(복제분자→염색체→다세포→사회→인지)에서 우리는 *유전 토대 앞*. - **유전 = 저장의 *씨앗 끝*(자기복제)이지 저장 전부가 아니다(이번 논의)** — 저장(R)은 유전의 *필요조건이지 충분조건 아님*: 유전 = 저장 + 자기복제(주형). *수동적 광물(바위)은 유전 없음*(저장만), *자기복제 결정*만 가짐 — 바위→자기복제 결정→genotype 의 연속체(저장 극단 *안*에서 창발, Cairns-Smith 점토 유전자: 유전은 *전생물적*, 광물에서 난다). DNA 도 *제 사본을 베끼는 비주기 결정*=한 종류 광물. **유전은 생명 전용 아님 — 저장 극단(R)의 능력**, 별(남긴 R=원소로 *느슨한* 혈통, metallicity)·생명(자기 주형 *단단한* 복제)이 *결합 단단함*으로 갈림(유무 아님). 소산(별 불꽃, A 최고)은 흐름이 패턴을 지워 정보 못 새김 — 기억은 저장 극단에만.
- **개체는 author 가 아니라 측정 — 차등 응집→표면장력 액적(step-0017 실현, ↑ 위 정전 사실)** — 다세포 개체("계")를 `Organism{cells}` 컨테이너로 *만들면* 활성도 환원(척추 체크 2) 위반. 개체 = 차등 응집(kin↑/타↓, Steinberg)이 빚은 표면장력 액적 = *flux 결합 도메인*으로 *측정*해 읽는다(step-0017 이 *공간 토대*를 놓음 — kin 접촉 0.51→0.95). 막은 액적의 표면으로 창발(개체 먼저·막 뒤 — 아직 측정 선일 뿐, flux 결합·막 백로그). 형태는 형태발생(위치정보·대칭깨짐·경계불안정)으로 — *외계* 형태지 사람 모방 아님(VISION).
- **형태(form)는 flux 의 하류 — 렌더러가 아니라 *시뮬*이 빚는다(이번 논의, [INTERPRET.md](INTERPRET.md) §5)** — 시각화 렌즈가 필드에서 읽어도 되는 건 *색·재질·빛·흐름*(E/R/A/G/∇E 의 함수)뿐, *지오메트리(형태)는 아니다*. "물=평면, 바위=결정" 같은 *형태 규칙*을 렌더러가 박는 것은 메시 scatter 와 같은 author(인과 역전). 높이는 `h=E+R` 하나라 *두 시각화 뷰가 같은 실루엣인 건 정상* — "비출 형태가 아직 없다"는 진단이다. 형태는 현실의 다섯 원리(소산구조·튜링 불안정·상분리/표면장력·주형성장 형태발생·수송기하)대로 *flux 의 결과*로 창발해야 하며, 이는 **이후 step 의 일**(개체=차등응집→표면장력 액적·G 의 공간 phenotype·E↔R 두 timescale 튜링[*둘째 전역 필드 금지, 단일 척추*]·표현분열 통일, [SPINE.md](SPINE.md) §다섯째 축). 시뮬이 형태를 얻으면 같은 렌즈가 코드 수정 0 으로 그려낸다.
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가. 새 코어는 직전 코어를 잇고 항을 하나만 더한다.
