## 2. NEXT — step-0010 가설

**확률적 탐사(run-and-tumble)를 얻은 생명은 움직이는 풍경 위에서 산다 — 풍경의 내생 churn이 생명의 끝나지 않는 churn으로 전사된다(G2 완전 해소 후보).**

step-0009가 풍경을 살아 움직이게 했지만 greedy 정주 생명은 *살되 따라가지 못해* churn이 멎는다(국소 최대 함정으로 옅은 골짜기를 못 건넘). step-0010은 생명에게 *탐사*를 준다: 갇혔을 때(이동 불가 + 흡수 부족) 결정론적 의사난수 방향 한 칸 — 옅은 골짜기를 건너 다음 고임을 찾는 능력.

**검증할 것**: ① 기복 세계 생존(pop>0 지속 — 0009 §8.1 역전) ② 탐사가 국소 최대 탈출 ③ **회귀 0**(탐사 계수=0 이면 step-0009 비트 동일) ④ 닫힌 장부·결정론(탐사 방향도 시드 결정론) ⑤ **내생 churn(G2)**: 정적 source·기복 세계에서 출생≈사망>0 이 *맥동 없이* 지속.

**병행 백로그(블로킹 아님)**: ⬜ 저장체가 촉매(R 위에서 baseCost↓/응집 창↑) · ⬜ 이산 FSM(연속 결정화→딱 뒤집히는 living/solid/ash) · ⬜ 등방성 stencil(네모→둥글게) · ⬜ 구동 내생화(별을 외부 주입→세계 안 개체).

**빌드 인프라**: 한 step = `sim-core.js`+`verify.js`+작은 `panel.js`+~12줄 셸 HTML. 공통 CSS/엔진은 `engine/hws-ui.css`·`engine/hws-ui.js` 한 곳. **3D 셸 표준(0009~)**: `engine/hws-3d.js`(WebGL2, 의존성 0), 셸 한 줄 `HWS3D.bind(HWS.mount(core, HWS3D.attach(panel)))`. step-0010 출발 템플릿은 `step-0009/panel.js`. 엔진 재현 검증 `node engine/validate/verify-engine.js`. 스펙 [engine/PANEL.md](engine/PANEL.md) · 설계 [engine/DESIGN-3D.md](engine/DESIGN-3D.md).

**게임화 cross-cutting(step 진행과 별개로 누적, 상세 step 문서):**
- **G1 timescale** 🔧노브 — 폭발이 빠름(씨앗1→정점 ~33tick). 게임은 world-tick을 렌더와 분리 + rate 상수 재튜닝. 다운스트림.
- **G2 동결** 🟡 — 정착 후 얼어붙음. step-0007 떠도는 자원(맥동적)+**step-0009 풍경 차원 내생 해소**. 남은 과제=생명 차원 전사 → step-0010.
- **G3 한 점 수렴** 🟡 — greedy가 source로 뭉침. step-0006 strip 완화·step-0007 traverse·**step-0009 다중 끌개**(고임 15~20개). 생명 분산 분포는 step-0010 탐사 선행.

> **원리·아키텍처는 적절**(보존 장부·결정론·서버 권위·점진적 법칙·자원/생명 창발) — 게임 substrate로 타당. 부적절한 건 *절대 timescale(G1, 노브)* 과 *미완 동역학(G2·G3, 다음 step들이 메움)*.
>
> **상시 렌즈 — 척추** ([SPINE.md](SPINE.md) 필독): 개체는 *이름(별/저장체/생명)이 아니라* 활성도 연속축 + 국소 비가역 문턱으로 갈리고, 빠른 비가역 전이 + 느린 재구성으로 세계 척도에서 순환한다. 매 step은 가설 4기둥 + 척추 체크 4항(단일 척추 / 활성도 환원 / 국소 문턱 / 순환 장부)으로 판정.

## 4. DURABLE CONSTRAINTS — 모든 step이 지킬 정전(canonical) 사실

> 여러 step이 반복 참조하는 불변. 새 step은 이걸 어기면 척추에서 벗어난 것 — 재설계.

- **회귀 0**: 새로 더한 항을 끄면(계수=0) 직전 step과 **비트 단위 동일**(verify `reg`, maxDiff=0).
- **닫힌 장부**: E+R+T 보존 잔차 ≤ ~1e-13(미시 1e-6 / 거시 1e-7).
- **결정론**: 같은 시드 2회 → 전 셀 비트 비교 + 상태 해시 일치. **시드 결정론 — `Math.random` 금지.**
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **greedy 이동 = 국소 최대 함정**: 확률적 탐사가 없으면 가까운 봉우리에 갇혀 옅은 골짜기 너머 더 큰 고임을 못 찾음(step-0005~0009 반복, → step-0010이 해소 대상).
- **동결을 푸는 건 운동이 아니라 *비균일성/불연속*** — 매끄러운 균일 표류는 갈릴레이 불변으로 정적 세계와 동일(step-0007).
- **"능력 추가(이동·비용)"는 정적 끌개로 수렴** — 흩어진 끝없는 churn은 *무대 자체가 움직여야* 한다(step-0005·0006 실패 → 0007·0009 방향).
- **생명은 형성기(FORM) 강고임에서 굳은 저장체를 씨앗으로 bootstrap** — 생명이 깨어나면 자유 E를 소비해 저장체가 새로 안 굳음(step-0008).
- **비가역 ≠ 비보존**: 상전이(E→R)해도 닫힌 장부는 그대로 닫힘 — "되돌릴 수 없음"은 상태의 성질이지 에너지의 성질이 아님(step-0008).
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가. 새 코어는 직전 코어를 잇고 항을 하나만 더한다.
