# step-0008 — 흐름량이 문턱을 넘어 *굳으면* 저장체(평형 상)가 된다: 첫 평형 개체 + 첫 비가역 문턱

> [step-0007로](step-0007.md) · 실행물: [step-0008.html](step-0008.html) · 코어: `step-0008/sim-core.js`(step-0007 코어에서 **법칙 1개 확장**(`결정화·풍화`)) · 헤드리스: `step-0008/verify.js`
> **척추([SPINE.md](SPINE.md)) 첫 적용** — STATE 가 지정한 가장 큰 격차(저장체 부재)를 닫는다.

step-0007 까지 세계의 모든 개체(고임·생명)는 **소산** 쪽이었다 — 구동(흐름)이 끊기면 증발·확산·아사로 사라진다. 척추 결정2가 요구하는 반대 극단, **저장체(평형 개체: 흐름 0에서도 존재하는 농축 저장소)** 가 없었다. step-0008 은 그것을 더한다. 메커니즘은 단 하나: **결정화·풍화**. 각 셀의 흐름량 E 가 국소 문턱 `crystThresh` 를 넘으면 초과분의 `kCryst` 가 매 tick *굳어* 저장소 `R[i]`(저장체)로 옮겨간다(E→R). R 은 확산도 증발도 하지 않는다 — **흐름이 끊겨도 그 자리에 남는다**(저장체의 정의). 결정화는 *빠르고 문턱 위에서만*, 풍화(R→E, `kWeather`)는 *느리고 무조건* — 이 비대칭이 래칫을 만든다: 개체 척도는 (사실상)비가역이고, 세계 척도는 풍화로 느리게 순환한다(탄 나무는 못 되돌려도 탄소는 지질학적 시간에 돌아온다).

결과: **① 결정화로 저장체 R 이 강한 고임 핵에 떠오르고**(전 시드 R 평균 1872, 굳은 셀 438~482개), **② 구동을 끊어도 저장체는 남는다**(보존율 0.56 vs 순수 소산 0.14 — 평형 vs 소산), **③ 결정화는 문턱을 넘는 셀에서만 켜진다**(문턱을 들판 최대 위로 올리면 R=0), **④ 회귀 0·닫힌 장부·결정론 유지**(kCryst=0 시 step-0007 비트 동일, 잔차 2.51e-13, 비트 동일).

## 검증 질문 (본 thesis: 흐름량이 문턱을 넘어 굳으면 흐름 0에서도 존재하는 저장체가 된다)

> ① **저장체 출현**: 결정화로 저장체 R 이 강한 고임 핵에 떠오르는가? (`store`·`thresh`)
> ② **흐름 0에서 존재(평형 vs 소산)**: 구동을 끊으면 저장체 R 은 *남고*, 흐르는 고임 E 는 *붕괴*하는가? (`store`)
> ③ **비가역 문턱(질적 경계)**: 결정화가 `E>crystThresh` 인 셀에서만 켜지는가? (`thresh`)
> ④ **회귀·보존·결정론**: kCryst=0 이면 step-0007 과 비트 동일? 켜도 닫힌 장부(R 포함)·결정론 유지? (`reg`·`conserve`·`det`)

모든 수치는 시드 [42, 7, 1234, 99, 2026], `node step-0008/verify.js <mode> [seed]` 로 재현된다. 결정화 시나리오 상수 = **kCryst=0.01, crystThresh=3.0, kWeather=0.0003**. 저장체/문턱 가설(`store`·`thresh`)은 *생명 없는 정적 필드*로 검증한다 — 결정화는 필드 항이고(step-0002 가 고임을 생명 없이 보였듯), greedy 생명은 source 를 먹어 흐르는 E 를 항상 낮게 만들어 필드 현상을 가리기 때문(§6).

## 2. 메커니즘 — 흐름량의 상전이(결정화·풍화), 새 양(量) 아님

흐름량 문서(02-quantity)의 원칙: "다양성은 새 요소가 아니라 *양 안에* 흡수한다." 저장체는 새 양이 아니라 **같은 흐름량 E 의 다른 상(phase)** 이다 — 흐르는 상(확산·증발하는 E)과 굳은 상(정지한 R). 법칙 순서 ⑤(구동 직후·생명 직전)에 한 패스를 더한다:

```js
// ⑤ 결정화·풍화 — kCryst=0 이면 통째로 건너뜀(회귀 0, R 불변)
if (p.kCryst !== 0) {
  for (각 셀 i) {
    if (E[i] > crystThresh) {              // 문턱(척추 결정3): 넘은 셀만 굳는다(국소 판정)
      var dep = (E[i] - crystThresh) * kCryst;   // 초과분의 일부가 빠르게
      E[i] -= dep; R[i] += dep;            // E → R (결정화)
    }
    if (R[i] !== 0) {
      var rel = R[i] * kWeather;           // 굳은 R 이 느리게·무조건
      R[i] -= rel; E[i] += rel;            // R → E (풍화)
    }
  }
}
```

세 설계 결정이 이 항을 *건전하게* 만든다:

1. **문턱 게이팅(척추 결정3)** — 결정화는 `E>crystThresh` 에서만 켜진다. 문턱 *이전*엔 그냥 흐르는 재료(E), *넘으면* 질적으로 다른 상(굳은 R). 강한 고임 핵(E up to ≈4)만 굳고, 배경(E≈0.5)은 영원히 안 굳는다 — "문턱 이전엔 재료, 넘으면 새로운 개체"의 최소 구현.
2. **비대칭 = 래칫(척추 비가역 vs 순환)** — 결정화율 kCryst(0.01)는 풍화율 kWeather(0.0003)의 ~33배. 높은 문턱 진입(빠름) + 느린 무조건 방출(반감기 ~2300 tick)이 *래칫*을 만든다: 저장체는 고임이 머문 자리에 쌓이고, 고임/source 가 떠난 뒤에도 오래 남아 천천히 E 를 되돌려준다. **개체 척도는 비가역, 세계 척도는 느린 순환** — 둘은 다른 timescale 이라 모순이 아니다.
3. **E↔R 쌍 거래 = 닫힌 장부(척추 결정4)** — 결정화도 풍화도 E 와 R 사이 내부 이전이라 sumE+R 이 보존된다. R 을 장부 항으로 더하면(생물량 M 과 같은 급) 책이 닫힌다. **상(狀)은 바뀌어도 에너지는 보존 — 비가역 ≠ 비보존.**

저장체는 아직 *비활성 저장*이다 — 확산을 막거나(무대) 생존 문턱을 낮추지(촉매) 않는다. 그건 다음 rung(한 step=한 항, §9).

## 4. ①② 저장체 — `store`, 통과 (흐름 0에서 존재 = 평형 vs 소산)

저장체의 *정의*는 "흐름이 끊겨도 존재한다"이다. 두 세계를 같은 FORM 으로 키운 뒤 구동을 끊고(drive off) 2000 tick 보존율을 대조한다(생명 없는 정적 필드):

| 시드 | R0(형성된 저장체) | 저장체 보존율 | 순수 소산 보존율 | 차(margin) |
|---|---|---|---|---|
| 42 | 1334.3 | 0.554 | 0.135 | 0.418 |
| 7 | 2130.9 | 0.558 | 0.135 | 0.423 |
| 1234 | 2111.1 | 0.558 | 0.135 | 0.423 |
| 99 | 2129.7 | 0.558 | 0.135 | 0.423 |
| 2026 | 1656.4 | 0.555 | 0.135 | 0.420 |
| **평균** | 1872.5 | **0.556** | **0.135** | **0.421** |

- **① 저장체가 떠올랐다** — 결정화로 강한 고임 핵에 R 평균 1872 가 굳었다.
- **② 흐름 끊겨도 남는다** — 구동 off 후 2000 tick: 저장체는 **55.6%** 가 남는데(풍화로 천천히), 순수 소산(결정화 끈 세계의 흐르는 고임)은 **13.5%** 로 붕괴(증발 (0.999)^2000≈0.135). 저장체가 소산보다 **~4배** 오래 산다. 결정화 끈 세계를 기준선으로 쓰면 풍화 되먹임 교란이 빠져 *평형 vs 소산* 대비가 깨끗하다.

이것이 척추 결정2의 두 극단을 한 세계에 처음으로 공존시킨다: 소산(흐르는 고임)은 흐름이 있어야 살고, 평형(굳은 저장체)은 흐름이 끊겨도 산다.

## 5. ③ 비가역 문턱 — `thresh`, 통과 (질적 경계)

결정화가 *모든* 셀이 아니라 *문턱을 넘는* 셀에서만 켜지는가. 같은 세계를 두 문턱으로(생명 없는 정적 필드, FORM 8000):

| 시드 | 정상 문턱(cTh=3.0) R | 굳은 셀 | 문턱 과대(cTh=100) R |
|---|---|---|---|
| 42 | 1334.3 | 482 | 0 |
| 7 | 2130.9 | 438 | 0 |
| 1234 | 2111.1 | 463 | 0 |
| 99 | 2129.7 | 447 | 0 |
| 2026 | 1656.4 | 460 | 0 |
| **평균** | 1872.5 | 458 | **0** |

- **문턱이 상전이를 게이트한다** — cTh 를 들판 최대(E≈4) 위로 올리면(cTh=100) *아무 셀도 안 넘어* R 이 **정확히 0**. 정상 문턱이면 강한 고임 핵 ~458 셀이 넘어 굳는다. "문턱 이전엔 흐르는 재료(E), 넘으면 굳은 상(R)" 이 수치로 성립한다(척추 결정3, 국소 판정 — 전역 조율자 0).

## 척추 체크 4항 (SPINE.md — 이 step 부터 가설 4기둥과 함께)

1. **단일 척추 ✅** — R 은 *병렬 전역 필드*가 아니라 같은 흐름량 E 의 *굳은 상*. 장부가 `sumE+M+R` 로 한 양(量)을 추적(§3). 다양성(저장체 vs 에너지)은 셀당 스칼라 상태일 뿐.
2. **활성도 환원 ✅** — 저장체는 활성도(throughput)≈0 극단(흐름 0에서 존재, §4). authored type 분기 아님 — 셀당 스칼라 R 의 크기로 *측정*된다.
3. **국소 문턱 ✅** — 결정화 판정이 `E[i]>crystThresh` 로컬 필드값만으로(§5). 전역 조율자 0.
4. **순환 장부 ✅** — E↔R 쌍 거래, R 장부 항(§3). 빠른 비가역 결정화 + 느린 풍화로 세계척도 순환. 상 바뀌어도 보존(비가역 ≠ 비보존).

## 6. 화면에서 직접 확인하는 법

[step-0008.html](step-0008.html) 을 연다. **떠도는 자원을 끄고(정적)** 관찰하면 저장체가 또렷하다:

- **저장체가 쌓인다**: source 상류 강한 고임 핵에 <span style="color:#c89b6a">■</span>(호박색) 저장체가 굳는다. "저장체 R" 계기판이 0 이 아니다.
- **구동 끄기**: 흐르는 고임은 빠르게 식어 사라지는데 **저장체는 남아** 천천히 풍화한다(누적 풍화가 계속 는다). 평형(저장체) vs 소산(고임)의 차이가 눈에 보인다.
- **문턱 슬라이더(cTh)**: 4 위로 올리면 결정화가 *꺼진다*(아무것도 안 굳음). 내리면 더 옅은 곳까지 굳어 저장체가 번진다 — 상전이의 문턱을 손으로 옮긴다.
- **결정화 체크 끄기(kCryst→0)**: 저장체가 더는 안 생기고 step-0007 과 비트 동일한 세계.
- **떠도는 자원 켜기**: source 가 지나간 자리에 *저장체 궤적*이 얇게 남는다 — 세계가 자기 역사를 지층으로 기록한다(§7).

## 7. 의외의 발견 — 생명이 자원을 가려서 저장체는 생명 *이전*에 굳는다, 그리고 저장체 궤적

설계하지 않았는데 떠오른 것 둘:

1. **저장체는 생명 *이전*의 풍요에서 굳는다(생명이 자원을 가린다).** 처음엔 결정화를 전체 스택(생명 포함)으로 검증하려 했으나 — greedy 생명이 source 에 주차해 흐르는 E 를 어디서나 0.45 로 *먹어치워*(step-0004~0006 의 한 점 수렴), 생명이 있는 동안엔 E 가 문턱(3.0)을 거의 안 넘어 저장체가 새로 안 굳는다. 저장체는 대부분 *생명 없는 형성기(FORM)* 의 강한 고임에서 굳는다. 의도는 검증 시나리오 선택이었는데, 결과는 게임적 서사: **"생명 이전의 풍부한 원시 고임에서 광물이 결정화했고, 생명이 깨어나자 자유 에너지를 소비했다."** 저장체(평형)와 소산(생명)이 *시간적으로* 분리된다 — bootstrap(저장체가 씨앗을 제공)의 자연스러운 모습.
2. **떠도는 자원이 저장체 *궤적*을 남긴다.** 떠도는 source(step-0007) 위에서 결정화를 켜면, source 가 지나간 자리마다 얇은 저장체가 굳어(전 시드 ~490 셀에 총 R≈38) **세계의 이동 역사가 지층으로 기록**된다. 떠도는 자원의 "어디에 있었나"가 굳은 저장체에 화석처럼 남는다 — VISION-UE 의 "지속 고임=암석" 직관이 코어 동역학으로 실현된 첫 형태.

## 8. 정직한 한계

1. **저장체는 아직 *비활성 저장*이다 — 무대도 촉매도 아니다(본 step 의 범위).** R 은 확산을 막지도(흐름을 휘지 못함=무대 아님), 생존 문턱을 낮추지도(촉매 아님) 않는다. 별→저장체→생명 사슬의 "저장체가 생명의 무대·촉매"는 미실현 — 다음 rung(§9). 이번 step 은 "저장체가 *존재*한다"까지다.
2. **문턱이 *연속(graded)* 이지 이산 상태 전이가 아니다.** 결정화는 셀이 "저장체 상태"로 *딱 뒤집히는* FSM(살아있는 나무→탄 나무→재)이 아니라, 초과분이 *점진적으로* R 로 새는 연속 이전이다. 척추 결정3 의 완전한 이산·비가역 상태기계(개체별 living/burning/ash 라벨)는 더 강한 형태 — 후속. 본 step 의 "비가역"은 *비대칭 래칫*(높은 진입 문턱 + 느린 무조건 방출)으로만 구현됐고, 풍화로 천천히 *되돌아오므로* 엄밀히는 준-가역이다.
3. **저장체/문턱 가설은 생명 없는 필드로만 검증했다(§6).** 생명 포함 전체 스택에선 결정화가 장부·결정론·회귀만 검증되고, "흐름 0에서 존재"의 깨끗한 대비는 생명이 자원을 가려 측정 불가. 생명·저장체의 *직접* 되먹임(생명이 풍화된 저장체를 먹는가)은 공유 E 로 간접 결합만 — 측정 안 함.
4. **결정화 상수(kCryst·crystThresh·kWeather)는 시나리오 튜닝 경험값.** crystThresh=3.0 은 강한 고임 핵(E≈4)만 굳히도록 고른 값 — source.rate·kA 가 바뀌면 재튜닝 필요. 결정론에 영향을 주는 시뮬레이션 상수가 아니라 상전이 문턱 노브.
5. **R 격자에 묶인 모양(step-0002 §6.5 이월).** 저장체도 4이웃 격자 위 E 의 함수라 강한 고임의 네모(마름모) 모양을 물려받는다 — 등방성 stencil 백로그.
6. **풍화가 모든 R 에 무조건 균일.** 깊이/나이 의존 풍화(겉만 풍화, 오래된 저장체는 더 단단)는 없음 — 단일 kWeather. 저장체 *나이*의 이력은 미기록.

## 9. 다음 (step-0009 예고)

> 가설: **저장체가 흐름을 휘면(무대), 응집 고임이 그 둘레에 *재편*되어 자원 풍경이 내생적으로 바뀐다.**

step-0008 이 저장체를 *존재*시켰다. step-0009 은 사슬의 다음 고리 — **저장체가 무대가 된다**: R 이 깔린 셀의 확산을 낮추면(굳은 땅은 흐름을 통과시키지 않음) 흐름이 저장체를 *피해* 휘고, 고임이 저장체 둘레에 재편된다. 이는 동시에 STATE G2/G3(동결·한 점 수렴)의 *내생적* 해법 후보 — 외부 sawtooth(step-0007) 없이도 저장체 퇴적이 풍경을 스스로 바꾼다(고임이 자기 자리를 메우면 흐름이 옆으로 밀림).

- 검증할 것: ① 저장체가 국소 확산을 변조하는가(흐름이 저장체를 피하는가) ② 고임이 저장체 둘레에 재편되는가 ③ **회귀 0** — 변조 계수=0 이면 step-0008 과 비트 동일 ④ 닫힌 장부·결정론 유지(확산 변조는 가중치만 바꿀 뿐 총량 보존).
- 병행 백로그(블로킹 아님): **저장체가 촉매**(R 위에서 baseCost 낮춤/응집 창 넓힘 — "생명의 무대이자 촉매") · **이산 상태기계**(연속 결정화→딱 뒤집히는 living/solid/ash FSM, §8.2) · **등방성 stencil**(네모 저장체 둥글게) · **구동 내생화**(별을 외부 주입에서 세계 안 개체로 — 척추 종착점).

각 step 의 "다음" 절이 다음 한 조각을 제안하지만, **현재 위치와 다음 가설의 권위는 [STATE.md](STATE.md)** 다.
