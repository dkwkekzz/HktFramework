# 요소 3 — 법칙 (Law)

> 흐름량을 이웃끼리만 주고받게 하는 국소 연산자. 전역 스크립트 금지.

## 정의

법칙은 (1) **국소적**이고 — 셀은 4이웃하고만 상호작용 — (2) **보존적**이거나(이동) **장부 기록형**(소산)이다. step-0001 의 법칙은 둘:

| 법칙 | 식 | 성격 |
|---|---|---|
| **확산** | `E'[i] = E[i] + kD·(ΣE[이웃4] − 4E[i])`, kD=0.20 | 보존 이동 — 기울기를 깎는다 |
| **소산** | `d = kT·E[i]; E[i] −= d; dissipated += d`, kT=0.001 | 장부 기록 — 세계를 식힌다 |

## 적용 순서 고정 (불변)

```
tick = ① 확산 → ② 소산 → ③ 주입(source) → ④ 배출(sink)
```

순서가 결과를 바꾸므로, 이후 모든 step 은 이 순서의 *사이에 끼워 넣는 것이 아니라* 계수·항 확장으로 법칙을 키운다. 순서 변경은 회귀 단절 = 새 아크.

## 왜 이렇게인가

- **국소성**: "플레이어가 한 번 배운 직관이 어디서나 통하는" 세계의 전제. 전역 규칙이 하나라도 생기면 장소마다 물리가 달라진다.
- **확산만으로는 아무것도 만들어지지 않는다**: 확산+소산은 모든 구조를 *지우는* 방향이다(엔트로피). 이것이 의도다 — 구조는 법칙이 만드는 게 아니라 구동([04-drive.md](04-drive.md))과의 긴장에서 떠오른다.
- **안정 조건**: 4이웃 확산은 kD ≤ 0.25 에서 수치 안정. 표준 0.20.
