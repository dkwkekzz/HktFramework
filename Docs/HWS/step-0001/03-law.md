# 요소 3 — 법칙 (Law)

> 흐름량을 이웃끼리만 주고받게 하는 국소 연산자. 전역 스크립트 금지.

## 정의

법칙은 (1) **국소적**이고 — 셀은 4이웃하고만 상호작용 — (2) **보존적**이거나(이동) **장부 기록형**(증발)이다. step-0001 의 법칙은 둘:

| 법칙 | 식 | 성격 |
|---|---|---|
| **확산** | `E'[i] = E[i] + kD·(ΣE[이웃4] − 4E[i])`, kD=0.20 | 보존 이동 — 기울기를 깎는다 |
| **증발** | `d = kEvap·E[i]; E[i] −= d; evaporated += d`, kEvap=0.001 | 장부 기록 — 세계를 식힌다 |
| **응집** (step-0002) | 확산 플럭스에 업힐 보정 `+kA·agg(min(eᵢ,eₙ))·(eᵢ−eₙ)`, kA=0(기본) | 보존 이동 — *창 안에서* 기울기를 키운다 |

**응집은 새 법칙이 아니라 확산 계수의 농도 의존 확장이다**(CLAUDE.md 설계 원칙). 농도 창 `agg(m)=1−((m−mc)/w)²`(|m−mc|<w 에서만 >0) 안의 셀만 이웃의 더 높은 쪽으로 거꾸로 흐른다. 커널 인자 `min(eᵢ,eₙ)`·`agg` 가 (i,n) 대칭이고 `(eᵢ−eₙ)` 가 antisymmetric → 플럭스 보존(닫힌 장부). kA=0 이면 응집 블록을 통째로 건너뛰어 **step-0001 식과 비트 동일**(회귀 0의 출발점). 자세히는 [step-0002.md §2](../step-0002.md).

## 적용 순서 고정 (불변)

```
tick = ① 확산 → ② 증발 → ③ 주입(source) → ④ 배출(sink)
```

순서가 결과를 바꾸므로, 이후 모든 step 은 이 순서의 *사이에 끼워 넣는 것이 아니라* 계수·항 확장으로 법칙을 키운다. 순서 변경은 회귀 단절 = 새 아크.

## 왜 이렇게인가

- **국소성**: "플레이어가 한 번 배운 직관이 어디서나 통하는" 세계의 전제. 전역 규칙이 하나라도 생기면 장소마다 물리가 달라진다.
- **확산만으로는 아무것도 만들어지지 않는다**: 확산+증발은 모든 구조를 *지우는* 방향이다(엔트로피). 이것이 의도다 — 구조는 법칙이 만드는 게 아니라 구동([04-drive.md](04-drive.md))과의 긴장에서 떠오른다.
- **안정 조건**: 4이웃 확산은 kD ≤ 0.25 에서 수치 안정. 표준 0.20.
