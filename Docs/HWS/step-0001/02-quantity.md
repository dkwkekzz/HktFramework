# 요소 2 — 흐름량 (Quantity)

> 만들어지지도 사라지지도 않고 *옮겨만 다니는* 무언가. 자원의 조상.

## 정의

- **E**: 각 셀에 저장되는 스칼라 흐름량 (Float64). 세계 안의 모든 가치는 결국 E 의 패턴이다.
- **장부 T**: 세계 밖과의 거래 기록 — `injected`(주입), `evaporated`(증발), `sunk`(배출). step-0003 에서 **생물량 M**(=Σ 에이전트.m, 생명이 보유한 흐름량)과 **metabolized**(대사 소산)가 더해진다.

## 닫힌 장부 (이 프로젝트의 회계 원칙)

E 는 세계 안에서 보존된다. 세계 밖과의 출입은 반드시 장부에 기록되어, 언제나 다음 항등식이 성립해야 한다:

```
sumE(t) + evaporated + sunk − injected = sumE(0)                          (step-0001~0002)
sumE(t) + M + evaporated + sunk + metabolized − injected = sumE(0)        (step-0003~, 생명 포함)
```

상대 잔차 = |위반량| / max(1, E₀ + injected). 허용 기준: 미시 ~1e-6. 항이 늘어도 원칙은 같다 — 흐름량은 터(E)·생명(M)·장부 버킷 사이를 *옮겨만 다닌다*. 생명의 흡수(E→M)·대사(M→metabolized)·사망(M→E)·출생(E→M)이 모두 쌍 거래다(step-0003).

- **왜 장부인가**: "자원을 지킨다"는 게임은 자원이 *어디서 와서 어디로 갔는지* 가 항상 추적 가능해야 성립한다. 보존이 깨지면 가치도, 희소성도, 지킬 이유도 없다.
- **닫힌 *장부* ≠ 닫힌 *계***: 장부가 닫혔다는 건 *회계가 맞아떨어진다*는 뜻이지 세계가 고립됐다는 뜻이 아니다. 세계는 source 로 들어오고 증발·sink 로 나가는 **열린 계**다(보존은 세계+바깥 전체로 성립). 왜 보존 위반이 아니고 순환 생태계로 이어지는지는 [concept-open-world.md](concept-open-world.md).
- **왜 하나의 양인가**: 다양성(자원의 종류)은 새 요소가 아니라 *양 안에* 필드를 더해 흡수한다. step-0001 은 한 종으로 시작한다.

## 구현 (step-0001 기준)

- 초기화: `E[i] = initE + noise·(rng(seed)−0.5)` — 난수는 초기 노이즈에만 사용.
- 모든 E 변경 연산은 같은 양만큼 장부 또는 이웃 셀에 반영한다(쌍 거래).
