# step-0017 — 개체(organism): 차등 응집으로 *표면장력 액적*을 빚어 다세포 '계'를 *측정*한다 — 주요 전이 사다리의 다음 칸(유전 → 개체)

> [step-0016로](step-0016.md) · 실행물: [step-0017.html](step-0017.html)(3D 표준 셸) · 시뮬 로직: `engine/hws-laws.js` 의 **`adhere` 법칙 1개**(LAW_ORDER ⑥a — move 뒤·crowd 앞, sim-core.js 복사 없음) · 헤드리스: `step-0017/verify.js` · 엔진 재현: `node engine/validate/verify-sim-engine.js`

step-0016 이 genotype(a.g)을 생명의 대사 엔진에 묶어 "유전이 개체보다 먼저"의 *유전* 칸을 닫았다 — 그러나 생명은 아직 *0-D 점*(형태·경계·내부 없는 한 셀 스칼라 m)이었다. SPINE 의 주요 전이 사다리(복제분자→염색체→단세포→**다세포(개체)**→사회→인지)에서 우리는 *유전 칸을 닫고 개체 칸 앞*에 섰다. step-0017 은 그 다음 칸을 놓는다: **개체(다세포='계')를 세운다 — 단, 만들지(author) 않는다.** 개체 = `Organism{cells}` 컨테이너로 *만들면* 활성도 환원(척추 체크 2) 위반이다. 대신 **차등 응집**(kin↑/타↓, Steinberg 차등접착 가설)으로 같은 유전형(kin=같은 a.g) 생명끼리 모이고 다른 태그는 밀어내, cell sorting → 같은 태그 블롭(**표면장력 액적**)이 경계를 최소화하며 *창발*한다. 개체는 그 **4-인접 kin 연결 성분**(flux 결합 도메인)으로 *측정*해 읽는다. "유전이 개체보다 먼저"(SPINE) — a.g 가 정의돼야(step-0016) kin 이 정의돼 다세포가 묶인다.

이것은 **law-pipeline 의 일곱째 step** 이다 — 더한 시뮬 로직은 `engine/hws-laws.js` 의 `adhere` 법칙 1개(LAW_ORDER ⑥a) + 노브 3개(`kAdhesion` 마스터 + `adhesionLambda`·`adhesionGain`) + 측정 헬퍼 `measureOrganisms`(커널, 4-인접 kin 연결 성분 = author 아닌 *측정*). 회귀는 동결 *해시*로 잠근다 — `golden-sim.json` 의 `org@` 키 신규 = step-0018 회귀 앵커. `kAdhesion=0` → step-0016 비트 불변(`life@`).

차등 응집은 **위치만** 바꾸는 단일 법칙이다(장부 거래 0 — move/tumble 과 같은 경계): 각 생명이 빈 4이웃 후보(+머무름) 중 *응집 점수* = (같은 태그 이웃 수 kin) − `adhesionLambda`·(다른 태그 이웃 수 타) 가 최대인 칸으로 옮긴다(후보 칸의 8이웃 점유를 셈). kin 많은 자리로 끌리고 타 자리를 피한다 — 강접착 세포가 안으로 모여 표면장력 액적(DAH). 머무름보다 `adhesionGain` 이상 *엄격히* 나아야 옮김(jitter 방지). 이것은 정확히 **Schelling 분리 동역학**의 게임화다(차등접착 = 이웃 선호 + 빈칸 이주).

결과: **① cell sorting 이 창발한다** — 두 유전형 생명을 *무작위 혼합*(kin 접촉 비율 **0.51**)으로 통제 아레나에 파종하면, 차등 응집이 같은 태그끼리 모아 kin 접촉이 **0.95** 로 오른다(응집 off 통제는 **0.51** 동결 — 같은 초기 배치). 이종 경계가 최소화돼 표면장력 액적이 생긴다. **② 개체가 *측정*된다** — 정렬이 빚은 4-인접 kin 연결 성분의 평균 크기 **4.5세포**·최대 **21세포**(응집 off 통제는 평균 **1.7**·최대 **11** — 무작위 percolation 잔클러스터). 다세포 도메인이 *차등 응집에서 창발*하고, 개체는 만든 게 아니라 *측정*된다(척추 체크 2 — 활성도 환원). **③ 회귀 0·닫힌 장부·결정론·churn 유지** — kAdhesion=0 시 step-0016 비트 동일(life@), 잔차 **3.98e-13**(위치만 — 거래 0), 해시 일치(x,y 가법), 공멸 없이 지평선 생존(carrying capacity ~69). **전체 스택에선 *부트스트랩한* 생명이 kin 액적으로 묶인다**(평균 개체 1.5·최대 7세포 — 희소·이동성 개체군이라 통제 아레나보다 작다, §정직한 한계 4). 차등 응집은 활성도 A 의 읽기 전용과 달리 **실제 위치 재배치**지만, 장부 거래가 0이라 임계 자기조직을 깨지 않는다.

## 2. 메커니즘 — 차등 응집(kin↑/타↓), 위치만·국소·닫힌 장부

법칙 순서의 ⑥a(이동 ⑥ 직후·혼잡 ⑥b 직전)에 둔다 — 먹이를 쫓은 뒤 같은 자리에서 kin 으로 정렬하고, crowd 가 그 정렬된 자리의 밀도를 잰다. 각 생명은 유전형 태그 `a.g`(0=무유전, 1..geneTypes, step-0016)를 갖는다. kAdhesion≠0 일 때:

```js
// ⑥a adhere — 차등 응집(kin↑/타↓ → 표면장력 액적, Steinberg DAH / Schelling 분리)
occ = {각 생명의 center → a.g}                              // 점유 그리드(태그). -1=빈칸
for (각 생명 a):
  myTag = a.g
  best = score(a.x, a.y, myTag) + adhesionGain             // 머무름 기준 + 문턱(엄격한 개선만 옮김)
  for (빈 4이웃 후보 j):                                     // 점유 칸엔 못 들어간다
    sc = score(j.x, j.y, myTag)                            // = (kin 이웃 수) − adhesionLambda·(타 이웃 수), 후보 8이웃 점유 셈
    if (sc > best) { best = sc; pick = j }
  if (pick): occ[a.center]=빈칸; a 를 pick 으로; occ[pick]=myTag   // 위치만(장부 거래 0)
```

다섯 설계 결정이 이 응집을 *척추 정합*하게 만든다:

1. **개체를 author 하지 않는다(SPINE 척추 체크 2 — 활성도 환원)** — `Organism{cells}` 컨테이너를 *만들면* 개체가 authored type 이 돼 활성도 환원을 깬다. 대신 차등 응집(국소 위치 바이어스)만 깔면, 개체(다세포='계')는 그 위에서 *표면장력 액적*으로 창발하고 *측정*된다. "만들지 않고 측정한다"가 이 step 의 핵심 정합이다.
2. **kin 은 step-0016 의 a.g — 새 정체성 없음(유전이 개체보다 먼저)** — 응집 판정은 같은 유전형(a.g)을 *kin* 으로 본다. 다세포 협동은 클론 유전 정체성(kin selection)이 안정화한다(Maynard Smith) — genotype 없이는 "kin"이 정의 안 돼 개체가 안 묶인다. step-0016 이 a.g 를 생명에 실었기에 이제 묶일 수 있다(사다리 순서 그대로).
3. **다양성은 병렬 필드 아닌 측정에(단일 척추)** — 개체(연결 성분)는 *측정*이지 둘째 구동 필드가 아니다. 필드는 여전히 E(+상 R) — `measureOrganisms` 는 위치(center)·태그(g)만 *읽고* E/R/agent 동역학에 되먹이지 않는다(둘째 척추 금지).
4. **표면장력을 author 하지 않는다(창발)** — "표면장력"·"막"을 코드에 박지 않는다. kin 선호 + 타 반발 + 빈칸 이주라는 *국소 법칙*만 깔면, 이종 경계 최소화(=표면장력)와 sorting 은 그 위에서 *창발*한다(Steinberg DAH: 강접착 세포가 안으로 모여 액적). 막은 액적의 *표면*으로 창발한다 — 개체가 먼저·막은 뒤.
5. **국소·닫힌 장부·위치만** — 응집은 제 4이웃·후보 8이웃만 본다(전역 조율자 0). 위치만 바꿀 뿐 m·E·R 을 안 건드린다 — move/tumble 과 같은 *거래 0* 경계라 장부가 닫힌다(잔차 불변). 순차 그리디(occ 제자리 갱신)라 같은 scan 안에서 먼저 옮긴 생명을 뒤가 본다(결정론, Math.random 금지).

### reproduce(⑧, 동결)·inherit(⑧b, step-0016)를 안 건드린다

차등 응집은 *위치 법칙*이다 — 번식·상속·대사 어느 것도 수정하지 않는다. 생명은 step-0016 대로 부트스트랩·상속·표현형세를 겪고(kin 정체성 획득), 그 위에서 응집이 *공간 배치*만 정렬한다. 두 축(시간축 유전 ⑧b, 공간축 응집 ⑥a)이 직교한다.

## 6. 의외의 발견

1. **차등 응집이 Schelling 분리와 정확히 같다 — DAH 와 사회 분리가 한 알고리즘.** Steinberg 의 차등접착 가설(세포생물학, 1960s)과 Schelling 의 분리 모델(경제학, 1971)은 *같은 국소 법칙*(같은 종 선호 + 빈칸 이주)의 두 발현이다. 우리 `adhere` 한 함수가 둘 다다 — kin 접촉 0.51→0.95 의 sorting 이 *세포 정렬*이자 *사회 분리*. 척추가 "이름이 아니라 역할"이라 한 것의 또 한 예: 같은 메커니즘이 생물·사회 두 척도에서 같은 패턴을 빚는다.
2. **개체가 percolation 문턱이 아니라 *능동 정렬*로 생긴다.** 응집 off 통제도 무작위 잔클러스터(최대 11세포)가 있다 — 44% 밀도의 우연한 percolation. 그러나 그건 *수동적*이고 작다. 차등 응집은 *능동적*으로 같은 태그를 끌어모아 21세포 액적을 빚는다(2.6배). 개체는 밀도의 우연이 아니라 *정렬의 산물* — "측정된 개체"가 의미 있으려면 응집이 percolation 배경을 *넘어서야* 하고, 넘어선다.
3. **개체가 통제 아레나에선 크고 전체 스택에선 작다(같은 응집, 다른 substrate).** 통제 아레나는 *조밀·정적*(44% 밀도·이동 off)이라 큰 액적(평균 4.5·최대 21). 전체 스택은 *희소·이동성*(carrying capacity ~69 가 그리드에 흩어지고 떠도는 별을 쫓음)이라 작은 액적(평균 1.5·최대 7). 같은 차등 응집 법칙인데 개체 크기가 substrate 의 *밀도·이동성*에 달렸다 — 개체성은 응집의 *강도*만이 아니라 *공간 기회*(붙어 살 밀도)의 함수다. step-0016 의 선택비가 R(1.53)보다 생명(3.27)에서 날카로웠듯, 개체도 *어디 사는가*가 *얼마나 묶이는가*를 가른다.

## 7. 정직한 한계

1. **개체가 *공간 군집*일 뿐 — 기능적 분업·표현형 분화 없다.** 측정된 개체(kin 연결 성분)는 같은 유전형 생명이 붙어 산 *덩어리*다 — 그러나 그 안의 세포가 *역할을 나누지*(생식세포 vs 체세포, 분업) 않는다. 진짜 다세포성은 *분화*(같은 genotype, 다른 phenotype)와 *개체 수준 선택*(액적이 단위로 번식·사멸)을 요구한다. 이 step 은 개체의 *공간적 토대*(응집 도메인)만 놓았다 — 기능적 개체는 백로그(분화·생식세포 격리).
2. **막(膜)·공통 경계가 아직 *측정 선*일 뿐 — 물리적 표면 없다.** "막은 액적의 표면으로 창발"이라 했으나, 현재 개체 경계는 `measureOrganisms` 가 그은 *연결 성분 윤곽*(측정)이다 — 내부 E 를 공유하는 *물리적 공통 경계*(flux 결합)나 외부와의 물질 교환 장벽(막)은 아직 없다. 액적이 *flux 결합 도메인*(내부 E 공유)이 되려면 개체 내 셀이 E 를 공유·재분배하는 법칙이 필요(백로그 — 개체 내부 flux 결합).
3. **차등 응집이 *대사*에 안 묶인다 — 응집은 공짜다.** 차등 응집은 위치만 바꾸고 비용이 0이다(거래 0). 실제 세포 접착은 *에너지*를 쓰고(접착 분자 합성), kin 협동은 *대사 이득*(공유 자원·분업)을 준다. 현재 개체는 응집해도 *생존 이득이 없다* — kin selection 의 *선택압*(개체 단위 적합도)이 없어 개체성이 *중립*이다. 개체가 진화적으로 의미 있으려면 응집↔대사 결합(액적 내부 자원 공유 → 생존 이득)이 필요(백로그 — step-0016 의 표현형→대사 결합을 *개체*로).
4. **전체 스택 개체가 작다 — 희소·이동성 개체군의 한계.** carrying capacity ~69 가 64×64 그리드에 흩어지고 떠도는 별을 쫓느라, 전체 스택 개체는 평균 1.5·최대 7세포로 작다(통제 아레나 4.5·21 과 대비). 큰 다세포 개체는 *조밀·정착* substrate 를 요구한다 — 떠도는 채식지(별)를 쫓는 유목 생명은 큰 액적을 못 이룬다. 정착(저장체 위 정주) 생활사가 다세포성의 전제일 수 있다(백로그 — 정착 생활사).
5. **응집이 *4-인접* 휴리스틱·scan 순서 의존.** 후보는 4이웃, 접촉 셈은 8이웃, 이동은 순차 그리디(scan N,S,W,E·배열 순서)라 약한 이방성이 있다(격자축 정렬 액적). 등방성 응집(거리 가중·동시 갱신)은 백로그(0002 의 facet 이방성과 같은 부류). 또 sort/organism 수치는 *통제 아레나*(조밀·정적)에서 잰 격리 측정 — 전체 스택은 희소·이동성이라 더 작다(§한계 4).
6. **표면장력이 *정렬 지표*지 물리적 장력 아님.** kin 접촉 0.95 는 이종 경계가 최소화됐다는 *측정*이지, 액적이 실제 *표면장력*(곡률 비례 압력·합쳐짐 dynamics)을 갖는 건 아니다. 액적이 둥글어지고 합쳐지는(coalescence) 진짜 표면장력 동역학은 경계 곡률 법칙을 요구(백로그 — 곡률 기반 표면장력).
7. **3D 개체 렌더는 2D drawHook 한정(헤드리스 미검증).** 개체를 kin 연결 선으로 잇는 것은 2D 오버레이에만 입혔다 — 3D 하이트필드의 개체 경계·액적은 미구현. 헤드리스 `verify sort·organism` 이 본 thesis 의 권위.
