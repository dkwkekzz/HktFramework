# step-0007 — 자원을 떠돌게 하니, 생명이 끝없이 추적하며 churn 한다 (정착 동결이 *재점화*로 풀린다)

> [step-0006으로](step-0006.md) · 실행물: [step-0007.html](step-0007.html) · 코어: `step-0007/sim-core.js`(step-0006 코어에서 **요소 1개 확장**(`떠도는 자원`) — source 를 `srcPeriod` tick 마다 `srcJump` 칸씩 +x 로 *재배치*: `cellX = round(x0 + srcJump·floor(tick/srcPeriod))`, 토러스 wrap) · 헤드리스: `step-0007/verify.js`
> step-0006 §9 가 지정한 과제 — *"가설: 세계가 스스로 자원을 옮기면(떠도는 자원), 개체군이 끝없이 그것을 따라 흘러 정착 동결이 풀린다 — 정적 평형이 끝나지 않는 추적으로 바뀐다."*

step-0006 이 *생존 문턱*을 보였지만, 정적 자원 풍경 위 개체군이 결국 한 고임으로 모여 *얼어붙었다*(정착 후 출생=사망=0). step-0005(이동)·step-0006(비용) 두 번의 *능력 추가*가 모두 "정적 끌개로 수렴"함을 보여, 흩어진 끝나지 않는 동역학은 *무대 자체가 움직여야* 한다고 가리켰다(step-0006 §7). step-0007 은 그 무대를 움직인다 — source 를 한자리(16,16)에 묶지 않고 **주기적으로 +x 로 재배치**(`srcJump=6`칸 / `srcPeriod=150`tick)해 고임이 세계를 떠돌게 한다. 새 장이나 새 흐름이 아니라 *주입이 일어나는 자리*를 옮기는 것뿐이다(주입 총량 rate·셀수는 불변 → 장부 닫힘). 결과: **① 정착 동결이 풀린다 — 떠도는 자원 위에선 정착 후에도 출생·사망이 멈추지 않고**(정착 후 4000 tick 출생≈50·사망≈50 지속 · 전 시드 — 대조: 정적 source(`srcJump=0`)와 *≈연속 표류*(`srcJump=1`)는 둘 다 0/0 으로 *얼어붙는다*), **② 떠도는 자원을 따라가야 산다**(이동 on 이면 추적거리 0.03~0.23 으로 곁을 따라 생존 · 이동 off 면 옛 자리에 뒤처져 *멸종*), **③ 무게중심이 자원의 궤적을 추적하고**(source 가 6000 tick 동안 240칸=세계 3.75바퀴 가로지르는 동안 무게중심이 추적거리 0.53 유계로 곁을 따라감), **④ `srcJump=0` 이면 step-0006 과 비트 동일하며**(회귀 maxDiff=0 — 정적·동결 그대로), **⑤ 흡수·출생·사멸·이동·기초대사·재배치가 모두 닫힌 장부에 남는다**(잔차 2.51e-13).

step-0006 §9 의 가설 — *"세계가 스스로 자원을 옮기면 정착 동결이 풀리는가"* — 의 답은 **예, 그러나 churn 은 맥동적(pulsed)이다**. 자원이 떠돌자 개체군은 한자리에 영구히 얼어붙기를 *멈추고*, 떠도는 고임을 끝없이 추적하며(③) 매 재배치마다 뒤처진 개체를 아사로 솎고 따라잡은 개체를 분열로 채워(①) 인구학적 turnover 가 *영원히 0 으로 가지 않는다* — step-0004 이래의 정착 동결(G2)이 처음으로 풀렸다. **그러나 가장 중요한·의외의 발견은 따로 있다: *매끄러운* 균일 표류(`srcJump=1`≈연속)는 동결을 *전혀* 풀지 못한다(출생=사망=0).** 함께 움직이는 좌표계에서 보면 균일 표류는 step-0006 정적 상태와 *완전히 같기* 때문이다(갈릴레이 불변) — 개체군이 강체처럼 미끄러져 따라갈 뿐이다. 동결을 푸는 것은 *운동 자체*가 아니라 *운동의 비균일성(이산 재배치)*이다. 그리고 그 churn 마저 매 점프 직후 ~30 tick 에 몰렸다가 다음 점프 전 ~50 tick 은 *재정착해 잠깐 얼어붙는다*(§6.1) — 동결은 *완전히 풀린* 게 아니라 *주기적으로 재점화*된다. 끊임없는 *매끄러운* churn 은 *연속적으로 변하는 풍경*(확률적 탐사·여러 떠도는 고임)이 있어야 한다(§6·§9). 이것이 본 step 의 가장 정직한 결과다.

## 검증 질문 (본 thesis: 떠도는 자원이 정착 동결을 churn 으로 푼다)

> ① **동결 해소(churn)**: 떠도는 자원 위에선 정착 후에도 출생>0 *그리고* 사망>0 으로 turnover 가 *안 멈추는가*(정적 source·≈연속 표류는 둘 다 0/0 으로 얼어붙는가)?
> ② **따라가야 산다**: 떠도는 source 를 이동 on 이면 *추적해 살고*, 이동 off 면 옛 자리에 뒤처져 *굶어 죽는가*(멸종)?
> ③ **추적**: 개체군 무게중심이 떠도는 source 의 궤적을 *유계로 따라가는가*(source 가 세계를 가로지르는 동안)?
> ④ **회귀·보존**: `srcJump=0` 이면 step-0006 과 비트 동일? 떠도는 자원에서도 닫힌 장부·결정론 유지?

모든 수치는 시드 [42, 7, 1234, 99, 2026], `node step-0007/verify.js <mode> [seed]` 로 재현된다. 표준 시나리오 = step-0006(64×64 wrap · source(16,16,r3,0.05) · sink(48,48,r4,0.10) · kD=0.20 · kEvap=0.001 · 응집 kA=0.45·mc=1.1·w=0.7 · 생명 kL=0.05·mMaint=0.03·mDeath=0.05·mSeed=0.50·lifeR=1 · 번식 mDiv=1.20·divR=1 · 이동 moveR=1·moveThresh=0.02 · 기초대사비 baseCost=0.08). 떠도는 자원 시나리오 상수 = **srcJump=6, srcPeriod=150**.

## 2. 메커니즘 — source 위치에 주기적 재배치 하나 (새 장 아님, 새 흐름 아님)

떠도는 자원은 step-0006 의 구동(③④) 단계 *안*에서 source 위치만 바꾼다 — 주입·증발·생명의 순서·연산은 step-0006 그대로다:

```js
// ③④ 구동 — srcJump=0 이면 이 블록을 건너뛰어 srcCells 불변 → step-0006 비트 동일(회귀).
if (p.srcJump !== 0 && p.srcPeriod > 0) {
  var nj  = Math.floor((sim.tick - sim.srcBaseTick) / p.srcPeriod);   // 지금까지 점프 횟수
  var ncx = (((sim.srcBase.x + p.srcJump * nj) % W) + W) % W;         // 새 source x (토러스 wrap)
  if (ncx !== p.source.x) { p.source.x = ncx; sim.srcCells = discCells(W,H,ncx,p.source.y,p.source.r); }
}
// 그 뒤: 주입(srcCells 에 rate)·배출(sink). step-0006 그대로 — 주입 총량 rate·셀수 불변(장부 보존).
```

세 설계 결정이 이 한 항을 *건전하고 동결을 푸는* 항으로 만든다:

1. **재배치는 주입 *위치*만 바꾸고 *총량*은 안 바꾼다 (`injected += rate·srcCells.length`, 셀수 불변)** — source disc 의 셀 수는 위치와 무관하게 일정(wrap)하므로, 어디로 옮겨도 매 tick 주입량은 같다. 따라서 닫힌 장부 `sumE+M+evap+sunk+metab−injected=E0` 에 *새 항이 없다* — 자원 이동은 "어디에 붓는가"만 바꿀 뿐 "얼마나 붓는가"는 그대로다(§3). 옛 자리는 주입이 끊겨 마르고(증발+흡수), 새 자리에 신선한 고임이 차오른다.
2. **이산 점프가 *비평형 transient* 를 만든다 (`srcJump≈2·source.r`)** — 한 번에 6칸(≈source 지름) 옮기면 새 고임이 옛 고임과 거의 겹치지 않아 *미수확(ungrazed)* 영역이다. 매 재배치마다: (a) 옛 자리에 *뒤처진* 개체는 흡수가 baseCost 아래로 떨어져 **굶어 죽고**(사망 전선), (b) 따라잡은 개체는 신선한 고임에서 m 을 키워 mDiv 를 넘겨 **분열**한다(출생 전선). 이 transient 가 step-0006 의 정착 평형을 *주기적으로 깨* 동결을 푼다. **반대로 `srcJump=1`(≈연속 균일 표류)은 transient 가 없다** — 개체군이 매끄럽게 미끄러져 따라가며 함께 움직이는 좌표계에서 step-0006 정적 상태와 동일(갈릴레이) → 출생=사망=0(§7①).
3. **`srcJump=0` 이 회귀 스위치 (`if (p.srcJump !== 0 …)`)** — `srcJump` 가 0 이면 재배치 블록이 통째로 건너뛰어져 `srcCells` 가 생성 시 그대로(원위치 disc)다 → step-0006 와 같은 주입을 같은 자리에 같은 순서로 수행한다(§3 reg, maxDiff=0). 떠도는 자원은 정적 세계 위에 얹는 *무대 운동*이고, 끄면 정적 세계(step-0006)가 그대로 남는다.

**떠도는 자원이 생명의 순서·연산을 *바꾸지 않는다***: 구동 단계에서 source 위치만 바뀌고 ⑤이동·⑥흡수/유지/사망·⑦번식 블록은 step-0006 그대로다. 그래서 회귀 체인이 유지된다 — `srcJump=0` 이면 step-0006, baseCost 까지 끄면 step-0005, 이동까지 끄면 step-0004, 번식까지 끄면 step-0003, 에이전트가 없으면 step-0002 와 비트 동일.

## 3. ④ 회귀·보존·결정론 — `reg`·`conserve`·`det`, 통과

### ④ 회귀 0 (`reg`) — 가장 먼저 증명할 것

`srcJump=0` 이면 step-0007 코어는 step-0006 코어와 **비트 단위 동일**해야 한다. 두 경우 모두 검증한다 — (A) 에이전트 0(구동 on/off, 10000 tick), (B) 에이전트 있음(강고임 1에 씨앗, 번식·이동·baseCost on, `srcJump=0`, +4000 tick):

```
seed 42/7/1234/99/2026   maxDiff = 0  (E 전 셀 비트 + 기본 장부 + 에이전트 상태 해시 일치)  OK
```

재배치 블록을 `srcJump !== 0` 조건으로 감쌌기 때문에, `srcJump=0` 경로는 `srcCells` 를 한 번도 건드리지 않아 step-0006 와 같은 연산을 같은 순서로 수행한다 — **떠도는 자원은 정적 세계 위에 얹는 *무대 운동*이고, 끄면 정적 세계(step-0006)가 그대로 남는다**.

떠도는 자원 on(강고임 1에 씨앗). 8000 tick 형성 + 씨앗 → 성장·추격·아사·분열이 섞인 8000 tick(총 16000). 장부는 step-0006 식 `sumE+M+evap+sunk+metab−injected=E0` 그대로 — **재배치는 주입 위치만 옮길 뿐 새 항이 없다**:

|---|---|---|---|---|---|---|---|
| 42 | 2.511e-13 | 307.99 | 9.395 | 10 | 367 | 358 | 9714.19 |
| 7 | 2.516e-13 | 303.45 | 9.786 | 10 | 353 | 344 | 9700.20 |
| 1234 | 2.517e-13 | 307.53 | 9.768 | 10 | 362 | 353 | 9705.97 |
| 99 | 2.523e-13 | 308.49 | 9.661 | 10 | 356 | 347 | 9689.54 |

- **장부가 닫혀 있다** — 잔차 2.51e-13(step-0006 2.52e-13 동급). 재배치는 source disc 셀 수를 안 바꾸므로 주입 총량이 불변이고, 흡수(E→m)·대사(m→소산)·사망(m→E)·출생(터→m) 네 흐름만 장부 항을 바꾼다 — 식이 닫힌다. **누적 출생(362)>사망(353)** — 떠도는 자원을 좇으며 transient 마다 솎이고 채워지지만 개체군은 유지된다(turnover 가 0 으로 안 가라앉음).
- **세계가 step-0006 보다 *더* 되살아난다** — sumE 평균 268(step-0006)→306(step-0007). source 가 한자리를 계속 파먹지 않고 옮겨다녀, 옛 자리가 회복하며 세계의 물이 *더 많이* 남는다(§7②). 대사 소산도 10193→9703 으로 줄었다(개체가 떠돌며 흡수가 분산됨).
- **결정론(`det`)도 비트 동일** — 같은 시드·같은 씨앗으로 2회 실행 시 E + 에이전트 상태 해시 일치(예: seed 42 `d7be4ee5`, 2회 일치). 재배치는 tick 의 결정론적 함수라 개체군 전체가 재현된다.

| **평균** | **50.4** | **50.6** | **7.8** | **0** | **0** | **11** | **0** | **0** | **11** |

- **떠도는 자원이 동결을 푼다** — `srcJump=6` 이면 정착 후에도 출생≈50·사망≈50/4000tick 으로 turnover 가 *멈추지 않는다*(개체수는 7~8 로 유지 — 솎인 만큼 채워짐). step-0006(`srcJump=0`)은 같은 구간에서 출생=사망=0 으로 *얼어붙는다*(정적 자원 풍경 → 정적 평형). step-0004 이래 매 step 미해소이던 **G2(정착 동결)가 처음으로 풀렸다**.
- **그러나 ≈연속 표류는 동결을 *못* 푼다(갈릴레이 — §7①)** — `srcJump=1`(1칸/20tick ≈ 연속 균일 표류)도 출생=사망=0 이다. 매끄러운 표류는 함께 움직이는 좌표계에서 step-0006 정적과 동일해, 개체군이 강체처럼 미끄러져 따라갈 뿐 transient 가 안 생긴다. **동결을 푸는 건 *운동*이 아니라 *운동의 비균일성(이산 점프)*** — `srcJump` 한 노브의 양 끝(1 vs 6)이 동결과 churn 을 가른다.
- **off·cont 의 0/0 은 *멸종*이 아니라 *살아있는 동결*이다** — verify 는 off·cont 의 개체수(둘 다 11 유지)를 *함께* 단언한다. 개체가 멸종해도 출생=사망=0 이 되므로(개체가 없으니), 살아있음을 함께 확인해야 "동결" 주장이 우연히 멸종으로 통과하지 않는다(step-0006 의 "평균 아닌 최소까지 검증"과 같은 엄밀성).

### ② 떠도는 자원을 따라가야 산다 (`chase`)

형성 8000 + 강고임 씨앗 후, source 가 여러 번 재배치되는 3000 tick. 이동 on 과 off 를 비교:

| 시드 | 이동 on 생존 | 이동 on 추적거리 | 이동 off 생존 |
|---|---|---|---|
| 42 | 생존 | 0.034 | **멸종** |
| 7 | 생존 | 0.226 | **멸종** |
| 1234 | 생존 | 0.063 | **멸종** |
| 99 | 생존 | 0.060 | **멸종** |
| 2026 | 생존 | 0.217 | **멸종** |

- **추적이 생존 조건이 된다** — 이동 on 이면 개체군이 떠도는 고임을 *바짝 좇아*(추적거리 0.03~0.23) 흡수 ≥ baseCost 인 자리에 머물러 산다. 이동 off 면 씨앗 자리에 *못 박혀* source 가 떠난 뒤 흡수가 baseCost 아래로 떨어져 *전멸*한다(abiogenesis 없음 → 영구 멸종). step-0006 의 "떠나야 산다"(②)가 step-0007 에선 **"끝없이 따라가야 산다"** 로 강화됐다 — 표적이 멈추지 않으므로 추적도 멈출 수 없다.

### ③ 무게중심이 자원의 궤적을 추적한다 (`track`)

개체군을 키운 뒤 6000 tick. source 는 6칸/150tick 으로 +x 를 돌아 **240칸**(=세계 64칸의 3.75바퀴)을 가로지른다. 무게중심-source 추적거리를 잰다:

|---|---|---|---|---|
| 42 | 240 | 0.543 | 8 | 10 |
| 7 | 240 | 0.529 | 7 | 12 |
| 1234 | 240 | 0.524 | 8 | 11 |
| 99 | 240 | 0.537 | 8 | 10 |
| 2026 | 240 | 0.539 | 8 | 10 |

- **개체군이 자원의 궤적을 유계로 추적한다** — source 가 세계를 3.75바퀴 가로지르는 동안 무게중심이 추적거리 0.53(셀)로 *바짝 곁을 따라간다*(발산하지 않음). step-0006 에선 무게중심이 source 한 점에 *고정*(거리≈0.04, 평생 제자리)됐지만, step-0007 에선 무게중심이 *source 와 함께 세계를 traverse* 한다 — 공간적으로 한 점에 영구 정착하기를 *멈췄다*. **개체군 공간 확산 spread 도 1.76(step-0006)→1.96(step-0007)** 으로 커졌다(추격 꼬리로 더 펼쳐짐 — 한 점 수렴 완화).

## 5. 화면에서 직접 확인하는 법

[step-0007.html](step-0007.html) 을 연다. 응집 on + 생명 on + 번식 on + 이동 on + 기초대사비 on + 떠도는 자원 on(srcJump=6, 주기 150) 으로 시작한다:

- **속도를 낮춘다**: 씨앗을 키운 뒤 속도를 1~5 로 낮추면 source 가 점프할 때마다 개체군이 *따라 기어가는* 모습과 뒤처진 점이 *쪼그라들다 사라지는*(아사) 모습이 보인다.
- **동결 해소(①)**: **강한 고임에 씨앗**으로 개체군을 키워라. **떠도는 자원 on** 이면 노란 점들이 떠도는 고임을 *끝없이 좇으며* 누적 출생·사망이 *계속 오른다*. **떠도는 자원 끄기**(srcJump=0)면 step-0006 처럼 한자리에 모여 *멈춘다*(출생·사망 정지).
- **연속 vs 이산(핵심)**: **점프 srcJump 를 1 로** 내리면(≈연속 표류) 개체군이 매끄럽게 미끄러져 따라가지만 **출생·사망이 다시 멈춘다**(갈릴레이 동결). **6 으로 올리면** 매 점프가 churn 을 *재점화*한다 — 운동이 아니라 *비균일성*이 동결을 푼다.
- **따라가야 산다(②)**: 키운 개체군에서 **이동 끄기**. source 가 떠나면 노란 점들이 옛 자리에서 *다 굶어 죽는다*(멸종). 이동을 다시 켜면 추적해 산다.
- **추적(③)**: 자홍 십자(무게중심)가 초록 원(source)을 *바짝 따라다니며* 세계를 가로지른다 — step-0006 의 고정된 십자와 대조.
- **회귀(④)**: **srcJump=0**(슬라이더 0 또는 떠도는 자원 해제). source 가 멈추고 개체군은 step-0006 처럼 한 고임에 정착·동결한다. 장부 잔차는 항상 PASS(<1e-6).

## 6. 정직한 한계

1. **churn 이 맥동적(pulsed)이지 *연속*이 아니다 — 동결은 *완전히* 풀린 게 아니라 *주기적으로 재점화*된다(본 step 의 핵심 정직).** 매 재배치(150tick 주기) 직후 ~30 tick 에 사망·출생이 *몰리고*(seed 42 측정: 점프 후 20–29tick 구간에 사망 56·출생 29 집중), 다음 점프 전 ~50 tick(110–149tick)은 출생=사망=0 으로 개체군이 *재정착해 잠깐 얼어붙는다*. 즉 개체군은 각 주기의 ~1/3 동안 churn 하고 ~2/3 동안 정지 평형으로 되돌아간다 — step-0006 동결을 *깨는 펄스*가 주기적으로 올 뿐, *끊임없는 매끄러운 churn* 은 아니다. 연속 churn 은 *연속적으로 변하는 풍경*(확률적 탐사 run-and-tumble·여러 떠도는 고임·응집 난류)이 있어야 한다 → step-0008.
2. **떠도는 방식이 결정론적 sawtooth(+x 등속 점프) — 시나리오에 튜닝된 경험값.** srcJump=6·srcPeriod=150 은 본 표준 시나리오에서 "개체군이 추적 가능하면서도(멸종 안 함) 매 점프가 transient 를 만든다(동결 안 됨)"는 창을 주도록 고른 값이다(6칸≈2·source.r 라 새 고임이 대체로 미수확 영역). source rate·kL·확산이 바뀌면 추적 가능 속도와 손익분기가 달라져 재튜닝이 필요하다 — 결정론에 영향을 주는 시뮬레이션 상수가 아니라 *무대 운동 노브*다. 확률적 떠돎(random walk)·여러 source 는 미구현(백로그).
3. **점프가 너무 크면 멸종 — 추적 가능 속도에 상한이 있다.** srcJump≥10(점프 한 번에 이동 보폭 한계 + 옛 고임 회복 전 거리 초과)이면 개체군이 따라잡지 못해 *전멸*한다(전 시드, abiogenesis 없음). 떠도는 자원은 "따라갈 수 있을 만큼만" 떠돌아야 개체군을 살린다 — 너무 빠른 무대는 동결 대신 멸종을 낳는다.
4. **이동은 여전히 결정론적 greedy — 국소 최대 함정(step-0005 §6.2·step-0006 §6.4 이월).** 떠도는 고임은 항상 가까이(점프 6칸) 있어 greedy 로 충분하지만, 옅은 골짜기 건너 *원거리 재배치*(큰 점프·여러 source)는 못 따라간다 — 확률적 탐사는 미검증(백로그). 추적은 *국소적으로 연속한* 자원 궤적에서만 성립한다.
5. **죽음은 여전히 한 종류(기아사)뿐(step-0006 이월).** 떠도는 자원은 *공간적* 아사(뒤처짐→흡수<baseCost)를 더할 뿐, 포식·노화·질병 같은 다른 사망 경로는 없다. 모든 사망은 m<mDeath(기아사)다.
6. **자원의 떠돎이 *외부에서 부과된* 운동이다 — 세계가 *스스로* 자원을 옮기는 내생 동역학은 아직 아니다.** 재배치는 결정론적 sawtooth 로 *각본대로* 움직인다 — 응집(step-0002)이 만든 고임이 *스스로* 생겼다 사라지며 떠도는 내생적 자원장은 아니다(step-0002 고임은 persist 0.92 로 안정·정적). "무대가 스스로 굴러가는" 떠도는 자원장(생성-소멸하는 다중 고임)은 본 step 의 sawtooth 보다 한 단계 더 내생적이어야 한다 → step-0008 백로그.

## 7. 의외의 발견 — 운동이 아니라 *비균일성*이 동결을 풀었고, 떠도는 자원이 세계를 더 되살렸다

설계하지 않았는데 떠오른 것 둘:

1. **매끄러운 균일 표류는 동결을 *전혀* 못 푼다 — 갈릴레이 불변성(본 step 의 가장 깊은 발견).** 직관은 "자원이 *움직이면* 개체군이 따라 흐르며 churn 하겠지"였다. 그러나 *매끄러운* 균일 표류(srcJump=1≈연속)는 출생=사망=0 으로 step-0006 과 똑같이 얼어붙었다 — **함께 움직이는 좌표계에서 보면 균일 표류는 정적 세계와 *완전히 동일*하기 때문이다(갈릴레이 불변)**. 개체군은 강체처럼 미끄러져 따라갈 뿐 어떤 비평형도 겪지 않는다. 동결을 푼 것은 *운동 자체*가 아니라 *운동의 비균일성* — 이산 점프(srcJump=6)가 매 재배치마다 *불연속*을 만들어 평형을 깬다. step-0005("이동을 더하면 흩어지겠지"→수렴)·step-0006("비용을 더하면 흩어지겠지"→집중)에 이어 **세 번째로 "동역학을 흩뜨리려는 단순 직관이 뒤집혔다"** — 이번엔 그 뒤집힘이 *해법*을 가리켰다: 끝나지 않는 동역학엔 *매끄러운 변화*가 아니라 *비균일·불연속한 변화*가 필요하다.
2. **떠도는 자원이 세계의 물을 *더* 되살린다(step-0006 풍요 역설의 공간적 강화).** step-0006 이 "생존 비용이 잉여를 솎아 sumE 9.8→268 로 되살렸다"면, step-0007 은 source 가 한자리를 영구히 파먹지 않고 *옮겨다녀* 옛 자리가 회복할 시간을 줘 sumE 268→306 으로 *더* 되살렸다. 직관은 "자원이 떠돌면 개체군이 더 힘들어진다"였으나, 닫힌 장부 아래 "떠도는 source 가 세계를 골고루 적시고 한 점 strip 을 막는다"가 저절로 성립한다 — 무대가 움직이니 세계가 덜 닳는다.

## 9. 다음 (step-0008 예고)

**가설: 자원 풍경이 *연속적으로* 변하면(확률적 탐사, 또는 생성-소멸하는 여러 떠도는 고임), 맥동 churn 이 *끊임없는 매끄러운* churn 으로 바뀐다 — 동결이 주기적으로 재점화되는 게 아니라 영영 돌아오지 않는다.**

- step-0007 이 *떠도는 자원*으로 정착 동결을 풀었지만, churn 이 *맥동적*이었다(매 점프가 재점화, 점프 사이 ~2/3 구간은 재정착해 잠깐 동결 — §6.1). 또 갈릴레이 발견(§7①)이 가리키듯, 끝나지 않는 *매끄러운* 동역학엔 *연속적으로 변하는 풍경*이 필요하다. step-0008 은 두 길 중 하나를 더한다: **(A) 확률적 탐사(run-and-tumble)** — 시드된 난수로 개체가 greedy 국소 최대를 벗어나 골짜기를 건너 탐사하면, 정적·맥동 평형이 끊임없는 탐색으로 바뀌는가(결정론 유지가 전제). **(B) 내생적 떠도는 자원장** — 응집 고임이 *스스로* 생겼다 사라지며 떠돌면(외부 sawtooth 가 아니라 세계가 스스로 옮김), 개체군이 *연속적으로* 변하는 풍경을 좇으며 영영 정착하지 못하는가.
- 검증할 것: ① 정착 후 *모든* 구간(점프 사이 포함)에서 출생·사망>0(맥동 없는 연속 churn — §6.1 해소) ② 확률적 탐사가 국소 최대를 벗어나 더 큰 고임을 찾는가(step-0005 §6.2 함정 해소) ③ **회귀 0** — 탐사 확률=0 또는 자원장 변화=0 이면 step-0007 과 비트 동일 ④ 닫힌 장부·결정론 유지(시드된 난수라도 재현 가능).

### 병행 백로그 (step-0008 블로킹 아님)

- **종간 경쟁·포식 — 자원을 두고 다투는 여러 생명.** step-0004 §6.2 이월. 서로 다른 전략(흡수율·분열 임계·이동 문턱·기초대사비·추적 속도)의 생명이 한 떠도는 자원을 공유하면 경쟁 배제·공존·포식-피식 진동이 떠오르는가.
- **등방성 stencil — 네모 고임·축 치우친 이동·표류를 둥글게.** step-0005 §6.4. 기본 off=회귀 0 유지.
