## Description

HktGameplay/Content 내 스프라이트 atlas 텍스처가 G-0113 success_criteria 를 만족하는지 일괄 점검하는 Editor Automation 또는 Commandlet. 검증 항목: CompressionSettings ∈ {TC_EditorIcon, TC_BC7}, MipGenSettings=TMGS_NoMipmaps, Filter=TF_Bilinear (자산-단위 TF_Nearest 오버라이드는 허용·기록), LODGroup=TEXTUREGROUP_Pixels2D. 위반 자산 목록을 로그/JSON 으로 출력. CI 통합 여부는 별도 결정.
