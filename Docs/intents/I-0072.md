## Intent

캐릭터가 어떻게 움직이느냐가 "이 캐릭터가 어떤 존재인가"를 말해준다. 클래스 체인지(I-0067) 전후의 이동·전투·대기 모션이 달라야 성장이 피부로 느껴진다.

애니메이션 시스템은 현재 클래스·장착 무기·속성 상태·행동 컨텍스트를 입력으로 받아 재생할 모션을 결정한다. 상호작용(I-0069) 유형에 따라 다른 반응 모션이 트리거되며, 특수 상태(부상·흥분·피로)는 기본 모션에 레이어로 덧씌워진다.

애니메이션 로직은 `HktPresentation` 레이어 내 AnimGraph / AnimInstance 에 구현된다(루트 CLAUDE.md 원칙 1). 시뮬레이션 상태를 읽기 전용으로 참조하며, 애니메이션 실행 결과가 WorldState 에 영향을 주어서는 안 된다.
