## Intent

캐릭터의 2D 표현은 HUD·인벤토리·대화창 등 UI 맥락에서 캐릭터의 현재 상태를 한눈에 전달한다. 클래스 체인지(I-0067)나 장비 변화가 있을 때 2D 아이콘·초상화·스프라이트가 함께 갱신되어야 플레이어가 성장을 시각적으로 인지한다.

2D 렌더링은 `HktPresentation` 레이어에 속한다(루트 CLAUDE.md 원칙 1). 시뮬레이션 상태를 읽기 전용으로 수신해 그릴 뿐이며, 역방향으로 상태를 쓰지 않는다. 렌더 데이터는 `FHktWorldView` 에서 파생되고, 원본 `FHktWorldState` 에 직접 접근하지 않는다.

Voxel 기반 세계와 병존하는 2D 표현이므로, 해상도와 아트 스타일의 일관성을 유지하는 것이 구현 제약으로 남는다.
