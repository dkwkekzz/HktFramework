## Intent

Workspace 에 엔터티, 지형 등의 재료를 넣어두기만 하면 ai agent가 알아서 인게임에 필요한 데이터로 적절하게 변환해주는 시스템을 만든다.

대략 구성은 아래와 같다.
Root
├── Paper2D
│   ├── Paper2D_Entity_Character....
│   │   ├── Animations
│   │   │   ├── animation 만들기 위한 재료
│   │   │   └── ...
│   │   └── atlas or static_image
│   └── ...
├── HISM
│   ├── HISM_Entity_Natural_.... 
│   └── ...
└── ...
- Paper2D_Entity_Character 는 GameplayTag를 의미함. 없으면 알아서 ini에 등록해서 에디터에서 인식 못하는 일 없도록 해야 함.
- 각 Tag에 대해 DataAsset을 만드는 것이 목적. Paper2D, HISM 각자 만드는 방식이 다를텐데 적절하게 대응할 것.
- 각 Tag안의 내용물을 이용해서 적절한 방식으로 대응할 것.
- 버전 관리를 위해서 meta파일을 관리해도 좋을듯.

## 진행 현황 (2026-05-16)

`HktWorkspaceGenerator` 모듈로 Paper2D / HISM 두 카테고리 빌더 완성.

### 디렉터리 컨벤션

`{Saved}/Workspace/{Paper2D|HISM}/{Tag폴더}/...` — Paper2D · HISM 동일 규약.

- Tag 폴더 직속 서브폴더 ≥ 1 → **Character** (각 서브폴더 = anim, 폴더명이 곧 AnimTag)
- 서브폴더 0 + 직속 이미지 1장 → **StaticVisual**
- anim 폴더 내부:
  - `atlas_{Dir}.png` → 방향별 Atlas (이미 패킹)
  - `{Dir}/frame_*.png` → 방향별 FrameSequence (빌더가 atlas 로 인라인 패킹)
  - 단일방향 `frame_*.png` → 1-row strip atlas 자동 묶음
  - `Cast.mp4` → 영상 (8방향 추출 — 현재 TODO)
- `anim_meta.json` / `entity_meta.json` 사이드카로 `cellW/cellH/frameDurationMs/pixelToWorld/looping/mirrorWestFromEast` override
- 호환 분기: 직속 `Animations/` 단일 폴더는 anim 컨테이너로 자동 인식 (구버전 트리)
- 폴더명 → GameplayTag 정규화: `_` 또는 `.` 혼용 허용 — 모두 점 표기로 통일

### 빌더 동작 (카테고리별 산출)

| 카테고리 | Mode          | 산출 자산                                                                |
|----------|---------------|--------------------------------------------------------------------------|
| Paper2D  | Character     | `UHktPaperAnimationDataAsset` + `UHktPaperActorVisualDataAsset` + Atlas/Sprite/Flipbook |
| Paper2D  | StaticVisual  | `UHktPaperActorVisualDataAsset` + Texture/Sprite                         |
| HISM     | Character     | `UHktSpriteCharacterTemplate` (Crowd/Niagara 소비) — legacy SpriteGenerator 워크스페이스로 atlas bridging 후 `BuildSpriteAnim` 호출 |
| HISM     | StaticVisual  | `UHktHISMSpriteVisualAsset` (정적 단일 quad)                             |

### 진입점

- 콘솔: `HktWorkspace.Scan`, `HktWorkspace.BuildAll`, `HktWorkspace.BuildTag`, `HktWorkspace.Panel`
- MCP 도구: `list_workspace_tags`, `workspace_scan_and_build_all`, `workspace_build_tag`
- Skill: `/workspace-build`
- Slate 패널: Window > Developer Tools > HKT Workspace
- Settings: Project Settings > HktGameplay > HktWorkspace

### Tag 자동 등록

미등록 폴더명을 발견하면 `FHktWorkspaceTagRegistrar` 가 native + ini 양쪽에 동적 등록 — 에디터 재시작 없이 즉시 사용 가능.

### Manifest 기반 증분 빌드

Tag 폴더당 `.workspace.meta.json` — 입력 파일 SHA1 해시(파일 크기 + 수정시각) + 산출 자산 경로 보존. 해시가 동일하면 재빌드 skip. `bForce=true` 로 강제 재빌드 가능. **source 타입과 무관하게** `entity_meta.json` (Tag 폴더 직속) 과 `anim_meta.json` (각 anim 폴더) 사이드카는 항상 해시에 포함 — 사이드카만 수정해도 재빌드가 트리거됨.

### 사이드카 → DataAsset → 런타임 데이터 흐름

빌드시 JSON 의 값이 DataAsset 에 박히고, 런타임은 DataAsset 만 권위로 사용한다.

1. **사이드카 로드** (`HktPaperWorkspaceBuilder::NormalizeAnim` / `BuildEntry`)
   - `entity_meta.json` (Tag 폴더) → `FrameDurationMs` / `PixelToWorld` / `bLooping` / `bMirrorWestFromEast` 의 캐릭터 기본값
   - `anim_meta.json` (anim 폴더) → anim 단위 override. 두 스키마 지원:
     - (A) `{"directions":[{"dir":"E","cellW":..,"frameDurationMs":..,"looping":..}, ...]}` — directions 원소 안의 `frameDurationMs` / `looping` 도 anim 단위 override 로 채택 (첫 유효값)
     - (B) flat `{"cellW":..,"cellH":..,"frameDurationMs":..,"looping":..}` — root level 값 적용
2. **DataAsset 기입** (`HktPaperAssetBuilder::BuildAnim`) — 해결된 `FrameDurationMs`/`bLooping`/`bMirrorWestFromEast` 가 `UHktPaperAnimationDataAsset::Animations[AnimTag].Meta` 에 저장. `UPaperFlipbook::FramesPerSecond` 도 같이 박지만 권위는 DataAsset.
3. **런타임 적용** (`AHktSpritePaperActor::RebindFlipbookIfNeeded`) — 바운드된 flipbook 의 intrinsic FPS 와 `Meta.FrameDurationMs` 비율을 `CurrentMetaTimeScale` 에 캐시하고, `SetPlaybackPosition(ElapsedSec * Scale)` 로 재생. DataAsset 의 `FrameDurationMs` 만 수정해도 PIE 에서 즉시 반영 (flipbook 자산 재빌드 불필요).

### 알려진 제한 / TODO

- **Video 모드 미지원** (Paper2D · HISM 공통) — 워크스페이스 일원화 이후 ffmpeg 추출 경로 재배선 필요
- HISM Character 산출 자산이 deprecated `UHktSpriteCharacterTemplate` — 신규 `UHktHISMSpriteVisualAsset` + `UHktHISMSpriteAnimationDataAsset` 분리형으로의 마이그레이션은 후속 과제
- HISM 런타임은 `UHktSpriteCharacterTemplate::Animations[].FrameDurationMs` 를 소비하는 측의 권위 보장 필요 — Paper2D 와 달리 현재 미검증

### 최근 변경 (2026-05-16)

- 사이드카 통합 명명: `character_meta.json` → `entity_meta.json` 전면 교체 (호환 분기 없음, 완전 폐기). 모든 entity (Character / Item / Natural 등) 공용.
- 매니페스트 해시에 `entity_meta.json` + `anim_meta.json` 무조건 포함 — FrameSequence 모드에서 사이드카만 수정해도 재빌드 트리거되도록 수정 (이전엔 Atlas 모드만 anim_meta 해시).
- `anim_meta.json` 스키마 (A) directions 원소 안의 `frameDurationMs` / `looping` 도 anim 단위 override 로 채택 — Paper2D / HISM 빌더 양쪽 적용. Run/Walk 등 directions-형식 사이드카가 무시되던 버그 수정.
- 런타임 `AHktSpritePaperActor` 가 `Meta.FrameDurationMs` 를 단일 권위로 사용하도록 변경 — DataAsset 편집만으로 재생속도 즉시 변경 가능.
- HISM 빌더가 `entity_meta.json` 의 `frameDurationMs` / `looping` / `mirrorWestFromEast` 를 캐릭터 디폴트로, anim 사이드카를 anim 단위 override 로 합성해 `BuildSpriteAnim` 의 새 override 인자(`FrameDurationMs` / `Looping` / `MirrorWestFromEast` tri-state)로 전달 — DataAsset `Animations[].FrameDurationMs` 등에 사이드카 값이 반영됨.
