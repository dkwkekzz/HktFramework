## Intent

주체를 선택하고 대상으로 오른쪽으로 선택하여 액션을 부여할 수 있다.
이는 기본적인 논리적 개념의 방식이며, 인게임에서 어떻게 풀어갈지는 이후 결정되어야 한다.

대상을 오른쪽을 누르면 `Story.Event.Target.Default` 단일 진입점으로 들어간다.
Dispatch할 Story 의 Precondition (사거리/쿨다운) 을 측정하고 만족하면 수행,
아니면 대상의 위치로 이동한다.

## Dispatch할 Story 예시

### 기본공격

collision test → 타격된 부위에 이펙트 생성, 대상과 상호작용.
대상은 기본 hit 이벤트를 구독하고 있고, 상호작용이 발생하면 데미지 차감 및 적절한 연출이 발생.
( 나무 베기도 동일한 로직 — 나무 entity 가 hit 이벤트를 구독하고 데미지 누적으로 쓰러진다 )

### 파이어볼 (기존과 동일)

casting → fireball entity 생성 → fireball 이 생성되는 연출 → 발사 → collision test → explosion effect → explosion collision test → damage

## 구현 매핑

- 진입점: `HktStoryTargetDefault.cpp` — `CheckTrait Target Hittable` 게이트로 NPC/자연 entity 통합 → UseSkill 디스패치.
- `EHktArchetype::Natural` (ClassTag `Entity.Natural`) — Hittable 포함. Birch/Oak 가 자동 매칭되어 BasicAttack 의 히트테스트에 잡힌다.
- 나무 사망 흐름: Spawn 시 Health 초기화 + `<Tree>Lifecycle` 부착 → BasicAttack 누적 → `State.Dead` → Lifecycle 이 Branch drop / Lineage++ / SaplingSeed 디스패치 / DestroyEntity.
- 폐기: `DefaultActionEventTag`, `Event.Natural.TreeFelled/OakFelled`, `Story_TargetAction.json`, `*_FelledListener.json`.
