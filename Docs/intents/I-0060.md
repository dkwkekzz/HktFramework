## Intent

VM 은 동일한 입력(WorldState · Intent · Tick)에 대해 항상 동일한 출력을 만들어야 한다. 이 결정론은 멀티플레이어의 전제이자 검증의 전제이다. 결정론이 깨지는 순간 server-authoritative 구조도, script 의 사후 재현도, LLM 산출물의 검증도 모두 의미를 잃는다.

이를 위해 VM 은 UE 런타임에 의존하지 않는 순수 C++ 로 유지되며(루트 CLAUDE.md 의 HktCore 순수성 원칙), WorldState 쓰기는 반드시 dirty 추적 프록시를 경유해 같은 순서·같은 결과로 커밋된다. 부동소수점·해시·난수까지 결정성 영역 안에 들어와야 한다.

서버는 권위적으로 시뮬레이션을 돌리고, 클라이언트는 읽기 전용 view 만 받는다. 같은 script · 같은 시드 · 같은 입력이면 어느 머신에서 돌려도 같은 세계가 만들어진다 — 이것이 이 의도가 약속하는 최소 보장이다.
