## Intent

상위 의도(I-0001)는 "스스로 성장하는 세계 · 무한한 성장 · 모험 · 플레이어 공존"을 동시에 요구한다. 이 네 축을 코드로 미리 다 적어 둘 수는 없다. 의도가 살아 있으려면 의도 자체와 같은 추상 수준에서 동작하는 실행 매체가 필요하다.

이 의도는 그 매체를 정의한다. 게임 규칙은 엔진 C++ 가 아니라 데이터로 기술된 script 로 표현되고, 결정론적 VM 이 그 script 를 해석해 시뮬레이션을 진행한다. 그 결과 의도(자연어/도식) → script(데이터) → VM 실행(시뮬레이션) 의 경로가 무너지지 않는 한, 의도가 변하면 게임도 변한다.

이 의도는 단일 모듈이 아니라 일곱 개의 하위 의도가 함께 성립할 때만 의미를 갖는다.

네 축의 본체:
- VM 의 결정론(I-0060)
- script 의 데이터화(I-0061)
- LLM 의 자기 작성(I-0062)
- 작성된 script 의 검증(I-0063)

세 축을 잇는 조건:
- 셋이 공유할 단일 계약 — script 의미론 / 원시 연산 카탈로그(I-0064)
- LLM 산출물에 대한 런타임 안전 경계(I-0065)
- 수정 루프를 사람의 인내심 안에서 닫는 관측·디버깅(I-0066)

본체 넷만으로는 닫히지 않는다. 계약 없이는 셋이 서로 다른 언어를 말하고, 안전 경계 없이는 LLM 의 한 번의 실수가 시뮬레이션을 멈추며, 관측 없이는 "검증 실패" 가 수정으로 이어지지 않는다.
