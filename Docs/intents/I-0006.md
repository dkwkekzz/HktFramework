## Intent

인게임에서도 지속적으로 성장·확장될 수 있는 콘텐츠 시스템을 위해, 게임에서 진행되는 모든 로직은 Script 에 의해 이루어진다. 대규모 전투·심리스 월드를 견디는 *순수 C++ SOA 결정론적 VM* (UObject 0) 을 구현하여 Story Script 를 시뮬레이션한다.

결정론은 서버 권위·미드조인 복원·리플레이 동일성의 전제다. VM 은 WorldState 를 직접 쓰지 않으며, 모든 쓰기는 `FHktVMWorldStateProxy::SetPropertyDirty` 를 경유해 dirty 추적 후 커밋한다.
