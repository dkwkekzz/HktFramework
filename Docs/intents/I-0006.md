## Intent

상위 의도(I-0001)는 "스스로 성장하는 세계 · 무한한 성장 · 모험 · 플레이어 공존"을 동시에 요구한다. 이 네 축을 코드로 미리 다 적어 둘 수는 없다. 의도가 살아 있으려면 의도 자체와 같은 추상 수준에서 동작하는 실행 매체가 필요하다.

이 의도는 그 매체를 정의한다. 게임 규칙은 엔진 C++ 가 아니라 데이터로 기술된 script 로 표현되고, 결정론적 VM 이 그 script 를 해석해 시뮬레이션을 진행한다. 그 결과 의도(자연어/도식) → script(데이터) → VM 실행(시뮬레이션) 의 경로가 무너지지 않는 한, 의도가 변하면 게임도 변한다.

이 의도는 단일 모듈이 아니라 네 개의 하위 의도가 함께 성립할 때만 의미를 갖는다. VM 의 결정론(I-0060), script 의 데이터화(I-0061), LLM 의 자기 작성(I-0062), 그리고 작성된 script 의 검증(I-0063) — 이 넷이 닫힌 루프를 이룰 때 비로소 "의도와 같은 수준의 구현"이 가능해진다.
