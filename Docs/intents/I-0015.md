## Intent

I-0014 의 placement → spawner 흐름은 GameplayTag 매칭 기반이라 런타임 silent skip 으로 오류가 묻히기 쉽다. 베이크/로드 시점에 정적 검증을 추가해 미스매치를 빌드 단계에서 차단한다.

## 범위

다음 두 가지를 단일 검증 패스로 통합한다.

### 1. PlacementStoryTag bake 시점 매칭 (I-0014 후속)

`UHktTerrainBakedAsset::GeneratorConfig.PlacementStoryTag` 가 다음 조건을 만족해야 한다.

- 빈 태그 (v3 자산 폴백 의도) → 통과
- 비어있지 않으면 → 동명 storyTag 의 Placement Story 가 `Content/Stories/**` 에 존재해야 함
- 없으면 베이크 실패 또는 strong warning

검증 지점: `UHktTerrainBakeLibrary::BakeRegion` 또는 별도 `UHktTerrainBakedAsset::PostLoad` 시점.

### 2. Placement → spawner-story 태그 그래프 (I-0014 미구현 / 콘텐츠 공백)

Placement Story 내부 `DispatchEvent eventTag` (또는 `tags` 로 매핑된 alias) 가 가리키는 storyTag 가 실제로 등록된 spawner-story 와 매칭되는지 정적 분석.

검증 지점: `FHktStoryJsonLoader::LoadAllFromContentDirectory` 완료 후 1회 그래프 빌드 → 미스매치 entry 목록 출력. Editor 빌드는 fatal, Runtime 빌드는 warning.

부수: biome 매직 넘버(`IfEqConst biome 203`) 의 의미 정합성도 같은 패스에서 lint 가능 — `EHktBiomeType` enum 미스매치 검출.

## 비범위

- 동작 검증(시뮬레이션 실행) 은 본 의도에 포함되지 않음.
- Region 메모리 정합성 검증도 별도 (I-0014 에서 Region 동기화는 이미 NetSerialize 경로로 보장됨).

## 후속 작업 (Backlog)

- 누적 검증 리포트를 .uasset 메타로 캡처 → CI 게이트.
