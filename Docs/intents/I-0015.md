## Intent

In-Game Core 는 콘텐츠 디자이너가 작성한 Story·GameplayTag·baked asset 매핑에 의존해서 게임을 구동한다. 이 결합은 손으로 작성한 식별자 매칭에 의존하므로, 한쪽이 바뀌면 다른 쪽이 조용히 어긋나도 시스템은 계속 동작하는 것처럼 보인다.

**디자이너의 의도는 silent 로 손실되어선 안 된다.** 콘텐츠가 의도한 상호작용이 실제로 발생할지를 디자이너가 *추측* 으로 확인해야 하는 상태가 되어선 안 된다. 매핑이 끊겼다면 끊겼다고, 의도된 분기가 도달 불가라면 도달 불가라고 *기계가* 알려야 한다.

본 의도는 In-Game Core 가 콘텐츠를 *받는 쪽* 으로서 갖는 책임이다 — 결합이 코드 변경·콘텐츠 증가 어느 쪽으로도 silent 손상되지 않게 한다.

## 적용 영역

- **Placement → Spawner Story** (I-0014): biomeId / DispatchEvent / PlacementStoryTag 매칭
- **Entity Lifecycle Story** (I-0011), **Behavior Story** (I-0012): storyTag dispatch 그래프
- **baked asset 호환성** (I-0013, I-0014): BakeVersion 과 런타임 알고리즘의 동치성

본 의도는 위 영역들의 *공통 조건* 이며, 개별 적용은 각 의도의 구현 책임으로 흩어진다.
