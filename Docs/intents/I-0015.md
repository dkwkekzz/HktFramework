## Intent

자연 배치는 콘텐츠 디자이너가 작성한 Placement / Spawner Story 와 시스템 (biome id, storyTag 등록부, baked asset 의 `PlacementStoryTag`) 사이의 결합으로 동작한다. 이 결합은 손으로 작성한 GameplayTag·정수 매칭에 의존하므로, 한쪽이 바뀌면 다른 쪽이 조용히 어긋난다.

**디자이너의 의도는 silent 로 손실되어선 안 된다.** Placement → Spawner → Entity 그래프 어딘가가 끊겼다면 끊겼다고 알려져야 하고, 콘텐츠가 의도한 자연이 실제로 발생할지를 디자이너가 *추측* 으로 확인하는 상태가 되어선 안 된다.

본 의도는 I-0014 의 메커니즘이 동작한다는 *전제* 가 시스템에 의해 보증되어야 한다는 것이다.

## 현재 격차

I-0014 의 매칭은 런타임 silent skip 로 폴백한다 (`Placement_*.json` 미존재 / `DispatchEvent` 타겟 부재 / biome 매직 넘버 불일치). 빌드·로드 시점의 machine-verified 보장이 없으므로 디자이너 의도와 시스템 거동의 어긋남을 인지할 수단이 부족하다.
