## Intent

게임 규칙은 컴파일된 코드가 아니라 JSON 데이터로 존재해야 한다. 데이터일 때만 LLM 이 쓸 수 있고(I-0062), 외부에서 검증할 수 있고(I-0063), 빌드 없이 실험할 수 있다.

VM 은 이 JSON 을 인게임에서 로드해 즉시 실행 가능한 형태로 해석한다. "재시작 후 적용" 이 아니라 "지금 이 세션에서 적용" 이 가능해야 한다. 그래야 의도 → script → 실행의 피드백 루프가 사람의 인내심 안에서 닫힌다.

JSON 은 사람도 읽을 수 있어야 하고, 기계도 정확하게 파싱할 수 있어야 한다. 스키마는 의도의 단위(엔티티, 속성, 규칙, 트리거)와 1:1 로 대응되며, 의도의 변경이 script 의 국소 수정으로 반영되는 구조를 지향한다. 한 줄을 바꾸기 위해 전체를 재작성해야 한다면 이 의도는 실패한 것이다.
