## Intent

I-0004 의 결정론적 시뮬레이션은 서버 권위·미드조인 복원·리플레이 동일성의 전제다 (Absolute Principle 3·4). 그러나 결정론을 "동일 결과의 반복" 으로 좁게 구현하면, 시뮬레이션이 표현해야 할 *세계의 풍부함* 이 동질성으로 무너진다 — 모든 청크의 자연이 같은 패턴이거나, 같은 상황의 AI 가 항상 같은 분기를 택하거나, 같은 트리거의 Story 가 늘 같은 전개로 흘러간다.

**결정론과 다양성은 양자택일이 아니다.** 동일 입력 → 동일 결과를 유지하되, 입력의 자연스러운 차이 (좌표, 시드, lineage id, 누적 region 메모리 등) 가 결과의 차이로 *증폭* 되어야 한다. 결정론은 다양성을 죽이는 제약이 아니라, 그 다양성을 *재현 가능* 하게 만드는 보증이다.

본 의도는 I-0004 의 결정론 시스템이 다양성을 *표현할 수단* 을 갖춰야 함을 말한다 — 어떤 분기든 (자연 배치, AI, 전투, Story) 결정론을 깨지 않고 풍부해질 수 있어야 한다.

## 적용 영역

- **자연 배치** (I-0014): 동일 voxel 재방문 → 동일 출현, voxel 간 / lineage 간 → 서로 다른 출현 (시드 = voxel 좌표 한 곳)
- **AI 행동·전투 분기** (I-0011, I-0012 후속): 동일 상황 → 재현 가능, 누적 상태 → 분기 다양화
- **Story 분기**: 동일 트리거 → 동일 전개 가능, 컨텍스트 차이 → 자연스러운 분기 차이
