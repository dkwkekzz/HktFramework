## Intent

2D 스프라이트가 시뮬레이션 상태에 맞춰 자연스럽게 애니메이션 되도록 한다. 시뮬레이션은 *상태* 만 제공하고, 어떤 프레임을 언제 보일지는 렌더 측의 책임이다.

표현 수단(PaperActor / HISM CrowdHost / Niagara) 이 *복수* 더라도 anim 의사결정은 *단일 출처* (`HktSpriteAnimProcessor` 순수 함수 네임스페이스) 에서만 이뤄진다. 렌더러는 산출물 `FHktSpriteAnimViewModel` 의 set 만 소비하며 자체 의사결정 로직을 가지지 않는다 — 이것이 본 의도의 *불변* 조건이다.
