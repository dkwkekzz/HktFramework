## Intent

WorldView (Movement / Combat / Animation / Sprite 뷰) 를 매 프레임 `FHktSpriteAnimViewModel` (AnimTag / PlayRate / Facing / Clock) 로 변환하는 *단일 의사결정 출처*. `AbsorbViews → TickViewModel → ExpireActionLayers` 3 단 순수 함수 — 모든 표현 수단 (Paper2D / HISM Crowd / Niagara Crowd) 의 공통 진입점이며, 렌더러는 VM 의 set 만 소비한다.

태그별 anchor (`TagStartLocalSec` + phase-shared group table) 로 동시 활성 layer 의 elapsed 계산이 분리되고, Locomotion 그룹 안에서는 Idle ↔ Walk ↔ Run ↔ Fall 전환 시 발 위상이 보존된다. Action layer 는 `ExpireActionLayers` 가 자체 시작 시각으로 만료를 판정해 Montage/UpperBody 와의 동시 활성에도 정확하게 종료한다.
