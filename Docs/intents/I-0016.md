## Intent

사용자 액션은 *영속 상태* 로 표현되고, 캐릭터의 Brain 이 그 상태를 매 프레임 해석해 이동/공격을 결정한다.

## 구현 요약

3 단으로 분리된다 — **입력 → 상태 → 결정**.

- **입력**: 우클릭이 `Story_TargetAction` 으로 들어가 *결정만* (Hittable / Move) 한 뒤 Subject 의 `ActionIntent*` 프로퍼티에 *기록* 하고 종료. 디스패치하지 않는다.
- **상태**: 6개 Cold 프로퍼티 (`ActionIntentType / Target / X / Y / Z / Slot`) 가 Subject 에 영속. 마지막 쓰기가 곧 현재 의도.
- **결정**: 각 캐릭터의 Lifecycle Story (`Story_PlayerLifecycle` / `Story_NPCLifecycle`) 가 매 프레임 yield 하며 ActionIntent 를 읽고 사거리·쿨다운에 따라 `MoveToward` 또는 `DispatchEventTo(UseSkill, Target)` 를 선택. 종료(대상 사망·위치 도달) 시 자체 클리어.

세부 데이터/플로우/격차는 [Design-I0016-ActionIntentBrain.md](../Design-I0016-ActionIntentBrain.md).
