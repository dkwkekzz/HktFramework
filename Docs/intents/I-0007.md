## Intent

"스스로 성장하는 세계" 라는 최상위 의도를 기술적으로 실현한다 — LLM 과 이미지 생성 모델을 UE5 에디터에 연결해, 텍스트 컨셉 하나로 지형·스토리·캐릭터·아이템·VFX 까지 완전한 게임 콘텐츠를 자동 생성한다.

이 자동화의 *왜* 는 단순한 노동 절감이 아니다. **디자이너가 표현해야 할 의도의 단위는 의도 그 자체** — "이 World 의 자연이 무엇으로 이루어지는가", "이 캐릭터의 성격은 어떠한가", "이 아이템의 역할은 무엇인가" — 이지, `(biomeId, storyTag)` · `(propertyId, fixed32 값)` 같은 시스템 결합의 저수준 식별자가 아니다. 콘텐츠 자동화 파이프라인은 디자이너의 의도-수준 표현을 받아 저수준 결합을 *결과로* 산출하는 역할을 진다.

World 가 늘어나거나 Feature 가 추가될 때마다 저수준 매핑을 손으로 적어야 한다면, In-Game Core 의 "유연성" 은 콘텐츠 제작 비용의 선형 증가로 상쇄된다. 본 의도는 그 상쇄가 발생하지 않게 한다 — 콘텐츠는 의도로 적고, 결합은 파이프라인이 만든다.
