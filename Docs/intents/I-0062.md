## Intent

사람이 의도(자연어 · 의도 문서 · 예시)만 제시하면, LLM 이 그 의도에 부합하는 script(I-0061) 를 스스로 작성한다. 사람은 의도 수준에 머무르고, 코드/데이터 수준의 번역은 LLM 이 담당한다.

이 의도가 성립하려면 두 가지가 필요하다. 첫째, LLM 에게 줄 수 있는 명확한 계약 — script 스키마, VM 이 보장하는 의미론, 사용 가능한 원시 연산. 둘째, LLM 의 산출물을 그대로 신뢰하지 않는 안전장치 — 검증(I-0063) 과 결정론적 재현(I-0060) 으로 LLM 이 "맞는 것 같다"고 한 결과를 사실로 확인할 수 있어야 한다.

LLM 은 매번 옳지 않다. 그러나 의도 → script 작성 → 검증 → 수정의 루프가 충분히 빠르면, 사람이 직접 작성하는 것보다 더 많은 의도를 더 빠르게 형상화할 수 있다. 이 의도가 노리는 것은 그 루프이다.
