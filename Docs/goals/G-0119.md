## Intent

컨셉 텍스트 1회 입력에서 어셋 산출까지의 8-step 파이프라인을 영속·재현 가능하게 오케스트레이션한다.

```
concept_design → feature_design → [parallel Worker per feature]
                                       ├── story_generation
                                       ├── asset_discovery
                                       └── char/item/vfx/texture-gen
concept_design → map_generation  (parallel with feature_design)
```

핵심 설계:

- **Pipeline feature**: `concept_design.feature_outlines` 에서 도출 → `feature_design` 에서 상세화
- **Manual feature**: 개별 탭에서 ad-hoc feature 자동 등록 (`manual-{type}-{timestamp}`)
- **Per-feature work.json**: `.hkt_steps/{project_id}/features/{feature_id}/work.json` — Worker 간 충돌 방지
- **Manifest 추적**: `FeatureStatus` 가 stories/assets 완료 수 추적
- **스텝 간 데이터**: `.hkt_steps/{project_id}/{step_type}/output.json` 파일 매개

각 스킬은 자율 실행 가능한 단일 step 이며, `full-pipeline` 만 메타 오케스트레이터로 Worker 를 병렬 스폰한다. Step 실패 시 `step_fail` 도구가 manifest 에 에러 기록.

이 목표는 G-0118 통신 인프라를 사용하고, 각 step 의 어셋 빌드 결과는 G-0120 (Generator) / G-0121 (Map) / G-0122 (Story) 가 산출.
