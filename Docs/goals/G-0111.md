## Intent

UI 는 HktPresentation 모듈에 의존 없이 (G-0004) GameplayTag 만으로 동작.

```
GameplayTag (Widget.LoginHud)
  → UHktAssetSubsystem::LoadAssetAsync
  → UHktTagDataAsset (IHktUIViewFactory 구현)
  → CreateView() / CreateStrategy()
  → UHktUIElement (CanvasSlot + Strategy)
```

월드 좌표 → 화면 좌표 변환은 **전략 패턴** 으로 분리 — 뷰포트 고정 (`UHktViewportAnchorStrategy`) 와 월드 투영 (`UHktWorldViewAnchorStrategy`) 두 종.

엔터티별 HUD 는 `IHktPlayerInteractionInterface::OnWorldViewUpdated` 델리게이트로 동기화 — `FHktWorldState` 직접 읽기는 허용 (UI 는 Presentation 미경유로 같은 WorldState 를 본다).
