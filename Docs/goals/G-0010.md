## Intent

멀티플레이어 게임의 시뮬레이션을 결정론적으로 실행하여 GGPO 롤백 동기화 / 리플레이 / 서버 권위 모델을 모두 동일 코어에서 지원한다. 클라/서버 동일 코어, 결정성, 30Hz 틱이 핵심.

이 pillar 는 HktCore (VM) + HktRule (인터페이스) + HktRuntime (네트워킹) + HktStory (바이트코드) 4 모듈 위에 성립하며, 횡단 제약 G-0001 ~ G-0005 을 모두 따른다.

## Success Criteria

- description: 1000 tick 동일 입력에 서버/클라 FHktWorldState 해시 100% 일치
  measurable: true
  measure: "HktAutomationTests `HktCore.Determinism.*` 통과"
- description: HktCore 모듈 UE 런타임 헤더 include 0 (G-0001 위반 0)
  measurable: true
  measure: G-0001 success_criteria 측정 결과 재사용
- description: GGPO 30Hz 롤백 윈도우 내 입력이 정상 적용
  measurable: false
  measure: 수동 — 멀티플레이어 세션에서 입력 지연 / 롤백 발생 시 시각 jitter 관찰
