## Intent

LLM 에이전트와 UE5 에디터/런타임 사이의 통신 인프라. 에이전트는 JSON-RPC(stdio) 로 Python MCP 서버에 도구를 호출하고, 서버는 두 채널 — Remote Control API(에디터) / WebSocket(런타임) — 으로 UE5 측에 위임한다. 외부 Monolith MCP 프록시가 살아 있으면 도구가 동적으로 병합되며, 죽어 있어도 무시한다 (선택 의존).

C++ 측 브릿지는 두 모듈로 분리: `HktMcpBridge` 는 런타임 최소 표면 (WebSocket 서버 + RPC 처리), `HktMcpBridgeEditor` 는 에디터 전용 어셋 레지스트리 / 생성 상태 (`EHktGenerationStatus`) 노출. 데이터 구조 (`FMcpRpcRequest/Response`, `FHktAssetInfo`, `FHktActorInfo`) 는 UE5 ↔ Python JSON 페이로드 계약.

이 목표는 G-0030 의 통신 계층 — 상위 파이프라인 (G-0101) 및 어셋 Generator (G-0102) 가 의존한다.
