## Intent

UE Automation 테스트를 헤드리스 (`-unattended -nullrhi`) 로 실행하고, 실패 결과를 LLM 에이전트가 직접 소비할 수 있는 구조화 JSON 으로 stdout 에 내보낸다. UE 의 거대한 텍스트 로그 스트림을 파싱하지 않아도 되도록 — `failures[].errors` / `full_test_path` / `duration_ms` 만 추출 — 에이전트의 토큰·시간 비용을 압축한다.

본 시스템은 G-0050 의 핵심 경계 인터페이스. 인프라 기준:

- 환경 설정은 CLI 인자 > 환경변수 > `.hkt-test.env` 파일 우선순위로 해소
- 종료 코드 3 분기 (`0` 통과 / `1` 실패 / `2` 실행오류) 로 분류 정확도 보장
- `index.json` 파싱은 UE5 Automation 리포트 포맷 (`tests[].state`, `entries[].event`) 에 직접 결합
- Windows cp949 기본 코덱 회피 — stdout/stderr 는 UTF-8 강제 디코드 (`errors=replace`)

상위 G-0050 의 자동 수정 사이클(`/test-fix`)은 본 시스템의 출력 계약에 의존한다.
