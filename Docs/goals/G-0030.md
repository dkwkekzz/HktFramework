## Intent

게임 컨셉 텍스트 1회 입력으로 지형 / 스토리 / 캐릭터 / 아이템 / VFX / 텍스처 / 스프라이트 / Paper2D 어셋을 자동 생성. 기획자·아티스트 인력 부담 감소, 빠른 프로토타이핑 가능.

8-step pipeline 을 MCP 서버 경유로 UE5 에디터에서 실행 (`HktGameplayGenerator/CLAUDE.md` §Generator Pipeline):

```
concept_design → feature_design → [parallel Worker Agents per feature]
                                       ├── story_generation
                                       ├── asset_discovery
                                       └── char/item/vfx/texture-gen
concept_design → map_generation  (parallel with feature_design)
```

스텝 간 데이터는 `.hkt_steps/{project_id}/{step_type}/output.json` 파일을 통해 전달되고, feature 단위 작업은 `features/{feature_id}/work.json` 으로 충돌을 방지한다.

런타임 통신 흐름: LLM 클라이언트 → JSON-RPC(stdio) → Python MCP 서버(`hkt_mcp.server`) → Remote Control API / WebSocket → UE5 에디터. 별도 Monolith MCP 프록시(`monolith_client.py`) 의 도구는 동적 병합되며, 연결 실패 시 무시한다.

생성 어셋의 출력 경로는 Convention Path 규칙(`HktGameplayGenerator/CLAUDE.md` §Tag 시스템) 으로 결정되며, 런타임 로딩은 GameplayTag → DataAsset 비동기 로드(`UHktAssetSubsystem::LoadAssetAsync`) 로 분리한다 (G-0020 의존).
