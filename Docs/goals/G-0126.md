## Intent

`FHktCoreDataCollector` / `FHktCoreEventLog` 데이터를 사용자에게 시각화. 6 종 Slate 위젯으로 VM 레지스터 / 엔터티 프로퍼티 / 런타임 / 이벤트 로그 / Presentation ViewModel 5 축을 커버.

- 데이터는 ActiveTimer 로 폴링 — 패널이 자체 갱신 (델리게이트 의존 0). Version 카운터 변화 시에만 row 재생성.
- 패널은 시뮬레이션 상태에 쓰지 않음 — `FHktCoreDataCollector::GetEntries` / `FHktCoreEventLog::GetSnapshot` 만 호출 (G-0004 ISP 단방향 보존).
- `SHktInsightTable` 은 공통 Key|Value 출력 위젯 — 다른 패널에서 재사용.
