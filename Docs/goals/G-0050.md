## Intent

Automation 테스트를 헤드리스 환경에서 실행하고, 실패 결과를 LLM 이 직접 분석/수정/재실행할 수 있도록 구조화한다. 구조화 JSON 출력 (`failures[].errors`) 은 UE 로그 전체 파싱을 우회 — 에이전트의 토큰·시간 비용을 압축한다.

핵심 자동화 대상

1. VM 명령 검증 (`HktOpcodeTests`)
2. Story 무결성·시나리오·JSON 파서 검증
3. Story V2 cpp/JSON 동등성 검증

## Success Criteria

- description: "`python run_automation_tests.py --filter HktCore` 가 구조화 JSON 출력 산출"
  measurable: true
  measure: "종료 코드 ∈ {0, 1, 2}, stdout 이 valid JSON (스키마 README §출력 JSON)"
- description: /test-fix 슬래시 커맨드로 실패 → 분석 → 수정 → 재실행 사이클이 1회 이상 동작
  measurable: false
  measure: "수동 — Tools/.hkt-test.env 설정 후 `/test-fix HktCore.Story 5` 실행"
- description: Story V2 cpp/JSON 동등성 자동 검증
  measurable: true
  measure: "HktAutomationTests `HktCore.Story.V2.*.Equivalent` 카테고리 전 항목 pass"
