## Intent

Voxel 캐릭터의 메시 합성 / 보크셀화 / 베이킹은 컨텐츠 제작 도구 — 런타임에는 결과물 (`UStaticMesh` / `UHktVoxelSkinLayerAsset`) 만 소비. 도구 코드가 Runtime / Shipping 빌드에 누설되면 모듈 의존이 폭발하고 패키지 크기 증가.

`HktVoxelSkin.Build.cs` 가 `Target.bBuildEditor` 분기로 `UnrealEd` 의존을 Editor 한정 등록. 모듈 자체는 Runtime 모듈로 빌드되지만 Editor-only 경로는 `WITH_EDITOR` 가드로 컴파일에서 제거.
