## Intent

HISM (G-1002) 의 대안 경로. atlas 별 1 `UNiagaraComponent` (NS_HktSpriteAtlasCrowd 인스턴스) 가 인스턴스 attribute 를 NDI Array 로 받는다. 빌보드 / 모션벡터 / UV 처리는 머티리얼이 아닌 **Niagara Mesh Renderer** 가 담당하여 머티리얼 복잡도를 줄인다.

HISM 경로와 **외부 API 시그니처 1:1 일치** — `RegisterEntity` / `UnregisterEntity` / `SetCharacter` / `UpdateEntity` / `ClearAll`. CrowdHost (G-0108) 가 CVar `hkt.Sprite.Renderer == 1` 일 때 본 경로로 디스패치.

`UHktSpriteCharacterTemplate` 은 G-1002 와 **공유** — `TemplateCache: TMap<FGameplayTag, UHktSpriteCharacterTemplate*>` 가 비동기 로드 결과를 보관.

자산 부재 시 기본 경로 `/HktGameplay/Niagara/NS_HktSpriteAtlasCrowd` 를 시도 — 별도 설정 없이 동작 가능.
