## Intent

엔터티 / 위젯 / VFX 등 시각 리소스를 코드 하드코드가 아닌 `GameplayTag` 로만 지칭한다. 변환 경로는 단일.

```
GameplayTag → UHktAssetSubsystem::ResolveTagPath → FSoftObjectPath
            → FStreamableManager 비동기 로드 → UHktTagDataAsset
```

핵심 보증.

1. **동기 로드 금지** — 메인 스레드 블로킹으로 인한 hitching 차단. 런타임 경로는 `LoadAssetAsync` / `LoadAssetByPathAsync` 만.
2. **Tag miss 폴백** — 매핑 없을 시 `OnTagMiss` 콜백으로 Generator 가 자동 생성 → 경로 등록 → 재시도.
3. **렌더 카테고리 사전 캐싱** — `RebuildTagMap` 시 CDO 의 `GetRenderCategory()` 결과를 미리 캐시 (에셋 본체 미로드).
