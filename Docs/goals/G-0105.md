## Intent

서버 시뮬레이션에서 산출된 `FHktWorldView` 가 1 프레임 안에 ViewModel 까지 반영되어야 시각 jitter / 입력 체감 지연이 없다.

세 가지 분기로 처리한다.

1. **InitialSync** — 첫 수신 시 `View.ForEachEntity()` 로 전체 엔티티 일괄 등록
2. **Diff** — 이후 프레임은 `ForEachRemoved` → `ForEachSpawned` → `ForEachDelta` 순으로 증분 적용
3. **SyncRenderers** — 변경 적용 직후 같은 프레임에 모든 Renderer 호출

`THktVisualField` 의 generation counter 로 별도 reset 없이 dirty 가 자동 만료되어 다음 프레임 비용을 0 에 수렴.
