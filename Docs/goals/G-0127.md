## Intent

HktInsights Slate 패널 5 종을 UE5 에디터에서 도킹 가능한 nomad 탭으로 노출. 개발자가 Play-In-Editor 세션 중 어느 위치에든 도킹/플로팅 시켜 실시간 모니터링.

- 등록 탭 (TabName | DisplayName)
  - `HktVMStateTab` | HKT VM State
  - `HktRuntimeInsightsTab` | HKT Runtime
  - `HktWorldStateTab` | HKT World State
  - `HktGameplayLogTab` | HKT Gameplay Log
  - `HktViewModelStateTab` | HKT ViewModel State
- 메뉴 통합 — `Window` 메뉴 + `Tools > Instrumentation` 양쪽에 같은 5 항목 추가.
- 모듈은 Editor 빌드 한정 — Runtime/Shipping 누설 금지.
