## Intent

VFX 는 **클라이언트 전용** — 서버 시뮬레이션은 의도(Intent / 이벤트) 만 산출, Niagara 스폰은 클라가 담당 (G-0003 준수).

자산 결합은 두 단계.

1. **Programmer-authored Intent** — `FHktVFXIntent` 가 의미를 표현 (목적 / 강도 / 컨텍스트)
2. **Resolve 단계** — `UHktVFXAssetBank` 가 Intent → Niagara System / Texture 매핑 보관 (HktVFXEditor 가 생성)

Voxel 파괴는 분리된 dispatcher 사용 — `UHktVoxelVFXDispatcher::SpawnFragment` 가 팔레트 색상 + 1x1x1 큐브 메시 + 발사 방향으로 Niagara 스폰. 타격 피드백은 `UHktVoxelHitFeedback` 별도 경로.
