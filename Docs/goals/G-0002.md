## Intent

HktCore VM 은 서버와 클라이언트가 동일 입력으로 동일 출력을 산출해야 한다 — GGPO 30Hz 롤백 동기화 / 리플레이 / 서버 권위 모델 모두 이 보존조건 위에 성립한다.

부동소수점 연산은 `FHktFixed32` 고정소수점으로 대체. 비결정 자료구조 (TSet 순회 / 포인터 주소 기반 정렬 등) 사용 금지.
