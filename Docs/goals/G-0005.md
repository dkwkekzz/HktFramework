## Intent

VM 인터프리터가 `FHktWorldState` 를 직접 수정하면 dirty 추적이 무너지고, 프레임 파이프라인의 Apply Dirty 단계가 무력화된다. 모든 쓰기는 `FHktVMWorldStateProxy` 를 경유하여 dirty 컬럼을 누적한 뒤 일괄 커밋해야 한다.

vM 외부 (예: 서버 룰) 가 WorldState 를 직접 수정하면 클라 동기화가 깨진다 — 동일하게 Proxy 경유.

## Success Criteria

- description: HktVMInterpreter / HktVMRuntime 코드에서 FHktWorldState 직접 Set 호출 0 (SetPropertyDirty 외)
  measurable: true
  measure: grep -rE '(WorldState\.(Set|Push)|WorldState->(Set|Push))' HktGameplay/Source/HktCore/Private/VM/ → SetPropertyDirty 외 0
- description: FHktVMWorldStateProxy 가 dirty 컬럼을 추적하고 Apply Dirty 단계에서 일괄 커밋
  measurable: false
  measure: 코드 리뷰 — HktSimulationTick.cpp 의 ProcessBatch → Apply Dirty 흐름 확인
