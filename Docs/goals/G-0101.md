## Intent

VM 은 SaveStore / LoadStoreEntity / DispatchEvent 등 32-bit 고정 폭 바이트코드를 결정론적으로 실행한다. 컴파일 경로 (`FHktStoryBuilder` + `FHktVRegAllocator`) 는 동일 입력 시퀀스에 대해 byte-identical 한 `FHktVMProgram` 을 산출해야 하며 — 이것이 깨지면 클라/서버 결과가 1 비트라도 다르고 GGPO 동기화가 즉시 무너진다.

## Success Criteria

- description: 동일 Builder 호출 시퀀스가 동일 바이트코드 산출 (자동 회귀 가드)
  measurable: true
  measure: "HktAutomationTests `HktCore.VRegIR.ByteIdentical.Determinism` / `BasicEncoding` / `LabelResolution` / `MixedEncoding` 통과"
- description: VM 실행 경로에 부동소수점 / `FMath::*` 호출 0
  measurable: true
  measure: "grep -rE '\\b(float|double|FMath::)' HktGameplay/Source/HktCore/Private/VM/ → FHktFixed32 / 명시적 캐스팅 외 0"

  measurable: true
