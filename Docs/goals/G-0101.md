## Intent

UE Automation 프레임워크 위에서 VM/Story 를 in-process 실행하기 위한 자기완결 미니 런타임. `FHktAutomationTestHarness` 가 `FHktWorldState`, `FHktVMWorldStateProxy`, `FHktVMInterpreter`, `FHktVMRuntime`, `FHktVMContext` 를 한 묶음으로 보유하여 PIE 부팅 없이 VM 명령을 실행한다 — UE 라이프사이클·GC 와 분리된 결정론적 검증 환경.

핵심 기능 축

- **Setup/Teardown** — 매 테스트마다 깨끗한 WorldState 보장
- **Entity 빌더** — `CreateEntity` / `CreateEntityWithProperties(TMap<PropId, int32>)`
- **VM 실행 모드** — `ExecuteProgram`(완료까지) / `ExecuteTick`(단일) / `ExecuteUntilWait` + `ResumeUntilDone`(Wait 분리 — 외부 이벤트 주입 결합)
- **이벤트 주입** — `InjectCollisionEvent` / `InjectMoveEndEvent` / `InjectGroundedEvent` / `InjectAnimEndEvent` / `AdvanceTimerFrames`(결정론적 정수 진행)
- **검증 헬퍼** — `GetRegister` / `GetProperty` / `HasTag` / `GetEntityCount`

Story Spec 사이드카 (`*.spec.json`) 자동 발견은 `IMPLEMENT_COMPLEX_AUTOMATION_TEST(FHktStorySpecAutomationTest, "HktCore.Story.Spec", ...)` 로 펼쳐 시나리오 단위 테스트를 등록한다 (Session Frontend 경로: `HktCore.Story.Spec.<TagNormalized>.<ScenarioName>`).

콘솔 명령 (모듈 진입점) — `hkt.automation.{run,opcodes,stories,scenarios,jsonparser,report}` 로 에디터 내 실행도 지원.
