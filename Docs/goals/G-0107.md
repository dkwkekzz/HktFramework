## Intent

엔터티 수가 늘어나도 프레임 비용이 변경 엔터티 수에만 비례해야 한다.

- `SpawnedThisFrame` → `UHktAssetSubsystem::LoadAssetAsync` 후 AActor 비동기 스폰 (블로킹 0)
- `RemovedThisFrame` → ActorMap 에서 제거 + Destroy
- `DirtyThisFrame` → `THktVisualField::IsDirty(CurrentFrame)` 가드를 통과한 필드만 Apply

ViewModel ↔ Actor 매핑은 `TMap<FHktEntityId, TWeakObjectPtr<AActor>>` 로 관리하여 GC 간 안전.

`EHktRenderCategory::Actor` 분류 (Entity.Character.\* / Entity.NPC.\* / Entity.Building.\*) 만 본 Goal 범위 — Projectile (MassEntity) / UI 는 별 Goal.

## Success Criteria

- description: 매 프레임 전체 엔터티 순회 없음 — DirtyThisFrame 만 처리
  measurable: true

  measurable: true

  measurable: true
