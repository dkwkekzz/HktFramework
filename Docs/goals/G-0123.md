## Intent

MCP 자동 파이프라인(G-0119) 과 병렬로, 사용자가 직접 컨셉/Intent 를 입력해 Generator 를 호출하는 인터랙티브 경로. UE5 에디터 콘솔 `HktGen.Prompt` 로 패널을 연다.

`FHktClaudeProcess` 가 `claude --print --output-format stream-json` 을 subprocess 로 실행:

- SKILL.md → `--system-prompt` 인수
- Intent JSON → user prompt
- Refine 시 이전 결과 + 사용자 피드백 포함하여 재실행

산출 어셋은 동일 ConventionPath 규칙(G-0120) 을 따르며, `UHktGeneratorRouter` 핸들러를 거쳐 등록된다.

이 경로는 자동 파이프라인이 제공하지 않는 1회성/탐색적 생성 (단일 VFX 시도, 단일 캐릭터 메시 변형 등) 을 빠르게 시도하기 위한 것 — 8-step pipeline 의 manifest/StepStore 에는 기록되지 않는다.
