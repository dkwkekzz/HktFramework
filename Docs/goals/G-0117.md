## Intent

Voxel 메싱 파이프라인 (G-0109) 은 GPU 직접 업로드 + Greedy 병합으로 성능이 좋지만 셰이더·머티리얼·LOD 인프라가 무겁다. **Sprite-only 배포 / 모바일 / 디버그 / iso 카메라** 환경에서는 청크당 1 인스턴스 빌보드가 더 적합 — Voxel 의존 없이 단독 동작.

핵심 구조.

1. **TerrainSubsystem 단일 출처 경유** — `UHktTerrainSubsystem::AcquireChunk` 로 청크 voxel 버퍼 획득. baked-first → Generator 폴백 (G-0006). `FHktTerrainGenerator` 직접 인스턴스화 0.
2. **HktVoxelCore 의존 0** — `FHktVoxelRenderCache` / Greedy meshing 우회. `FHktTerrainVoxel[32768]` 직접 스캔.
3. **단일 HISM, 청크당 1 인스턴스** — top-most non-empty voxel 만 추출 (`FHktSpriteTerrainSurfaceCell`). Diff 기반 Add/Update/Remove 로 카메라 이동 시 점진 갱신.
4. **공유 ChunkLoader** — `IHktTerrainChunkLoader` (Legacy / Proximity) 를 Voxel 경로와 동일하게 사용.
5. **머티리얼 측 빌보드** — `M_HktSpriteTerrainBillboard` (Z-up quad, 지면 평면). HktSpriteCore 의 캐릭터 빌보드 (`M_HktSpriteYBillboard`, Y-axis) 와 별개.
6. **ComponentZBias 로 Crowd 와 정렬** — Terrain = 0 (베이스라인), Crowd = +1cm. 머티리얼 WPO 가 cm 단위로 카메라 쪽 밀어내며 depth-buffer 반영.

## 미구현 영역 (예정)

본 Goal 은 다음 미구현분을 추적 — 완료 시 success_criteria 추가/measurable 승격.

- **`UHktSpriteTerrainStyleSet`** — `HktVoxelTerrainStyleSet.h` 주석에 "PR-D 신설 예정" 으로 언급. 현재 `AHktSpriteTerrainActor` 가 `AtlasTexture` / `PaletteLUT` / `AtlasSizePx` / `CellSizePx` 를 UPROPERTY 로 직접 노출 — StyleSet DataAsset 으로 통합 필요.
- **`AHktVoxelSpriteTerrainActor` deprecation 완료** — `HktVoxelTerrain/Public/HktVoxelSpriteTerrainActor.h` 에 deprecated 마킹. 1 릴리스 유예 후 제거. 외부 콘텐츠 referencer 마이그레이션.
- **블록 동적 변경 시 표면 재추출** — InstanceMap diff 는 청크 단위. 청크 내부 voxel 변화 (파괴 등) 가 표면 셀에 영향 시 재스캔 트리거가 명시 안 됨 — 현재는 `MaxScansPerSecond` 시간 트리거에만 의존.
