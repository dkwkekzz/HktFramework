## Intent

세 렌더 경로 (Paper / HISM / Niagara) 가 동일 캐릭터에 동일 시각 결과를 산출하려면 애니 의사결정이 한 곳에 모여야 한다. 결정 함수가 두 벌이면 시간이 가며 분기되고 캐릭터별 검수가 두 배가 된다.

핵심 분리.

1. **Processor 는 캐릭터 데이터 미의존** — 입력은 `FHktSpriteAnimFragment` (POD) 만, 출력은 `(AnimTag, PlayRate)`. CharacterTemplate (Sprite/Paper) 헤더 미참조. 두 경로가 동일 결정 함수 호출.
2. **태그 계층 우선순위 고정** — `Anim.Montage.* > Anim.UpperBody.* > Anim.FullBody.* > Locomotion 합성`. `UHktAnimInstance` 와 동일 규약.
3. **권위는 서버 VM** — `AnimStartTick` 은 서버 VM 이 `PropertyId::AnimStartTick` 으로 권위 기록. 클라 Fragment 미저장. Crowd Host 가 `LastAuthoritativeAnimStartTick` 로 변화 감지 → `AnimStartLocalMs` 캡처 (G-0003).
4. **카메라 yaw 합성은 클라** — Facing 은 매 프레임 `(atan2(LastMoveDirXY), CameraYaw)` 로 재산출. 카메라 회전에 자연스러움.
