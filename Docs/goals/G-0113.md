## Intent

스프라이트 외곽선·픽셀 무결성을 깨뜨리는 두 부류의 엔진 기본값을 일관된 정책으로 고정한다 — (1) 카메라 이동 시 픽셀이 뭉개지는 PostProcess/Anti-Aliasing 동작, (2) 알파 외곽선에 찌꺼기를 만드는 텍스처 압축·밉맵 동작.

본 프로젝트의 기준 톤은 **일러스트/카툰** (Filter=Bilinear) 이며, atlas 단위 픽셀 무결성 + 일정한 톤을 보증한다. 정책은 (a) 콘텐츠 측 수입 자산, (b) `HktSpriteGenerator` 자동 생성 자산 양쪽에 동일하게 적용 — 두 진입점 정책 분기 0.

1. **Anti-Aliasing 정책** — TSR 누적 블렌딩 잔상 제거. `r.AntiAliasingMethod=0` (또는 동등 대안) 을 `Config/DefaultEngine.ini [SystemSettings]` 에 고정.
2. **PostProcess Volume Manual 고정** — 기본 PPV 가 `AutoExposureMethod=AEM_Manual` + `AutoExposureBias=0` + ColorGrading `Saturation=1.0, Gain=1.0`. SystemSettings 단독은 톤매퍼 차단 불완전 — PPV 와 병행.
3. **Tonemapper Linear Passthrough** — `r.TonemapperFilm=0`. HDR 디스플레이 / 포스트 LUT 사용 포기 (트레이드오프 명시).
4. **텍스처 압축 정책** — 스프라이트 atlas 는 `UserInterface2D(RGBA)` 또는 `BC7`. Default(DXT1/5) 0.
5. **밉맵 정책** — atlas 는 `MipGenSettings=NoMipmaps`.
6. **필터·텍스처 그룹** — 기본 `Filter=TF_Bilinear` + `TextureGroup=TEXTUREGROUP_Pixels2D`. 픽셀아트 자산은 자산 단위 `TF_Nearest` 오버라이드 허용.
7. **Generator ↔ 콘텐츠 정책 동등성** — `HktSpriteGeneratorFunctionLibrary` 가 atlas 자동 생성 시 동일 정책 적용. 현재 `TF_Nearest` 박혀있어 정책 (Bilinear 기본) 과 어긋남 — 봉사 작업으로 정합화 필요.

## 미구현 영역 (예정)

본 Goal 은 다음 미구현분을 추적 — 완료 시 success_criteria 의 measurable 승격.

- **콘텐츠 측 atlas 텍스처 메타 일괄 검증 스크립트** — 현재 자산-단위 검증은 수동. Editor Automation 또는 Commandlet 으로 일괄 점검 자동화 필요.
- **HktSpriteGenerator Filter 정합화** — `HktSpriteGeneratorFunctionLibrary.cpp:177` 의 `TF_Nearest` 를 `TF_Bilinear` 로 전환 (또는 정책 단위 분기 인자 추가).
- **PPV 기본 자산 표준화** — 기본 게임모드/레벨에 박힐 표준 PPV 자산 위치/네이밍이 미정. 정의 후 자산 리뷰 가능.
