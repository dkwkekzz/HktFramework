## Intent

게임플레이 행위는 모두 **JSON Story 정의** 로 작성하며, 로더 파이프라인이 `FHktStoryValidator` → `FHktStoryJsonParser` → `FHktStoryRegistry` 순으로 실행하여 GameplayTag 키 단일 레지스트리에 `FHktVMProgram` 을 등록한다.

JSON 파서는 내부 컴파일 인프라로 `FHktStoryBuilder` (Fluent C++) 를 그대로 호출하므로, JSON 경로 산출물이 Builder 의 결정론 보장 (G-0101 byte-identical 회귀) 을 그대로 상속한다.

`HktStory/Private/Definitions/`, `HktStory/Private/Snippets/` 의 C++ 정의 cpp 는 **폐기 예정** — JSON 마이그레이션이 끝나면 모두 삭제 대상이며 본 Goal 의 정착 형태에는 포함되지 않는다.
