## Intent

Voxel 표면을 단순 큐브 페이스 합으로 그리면 쿼드 수가 폭증해 GPU 가 한계. Binary Greedy Meshing 으로 동일 타입의 인접 면을 비트마스크 단위로 병합하여 쿼드 수를 최소화한다.

렌더 경로는 표준 StaticMesh 우회.

- `HktVoxelMesher` 가 32^3 단위로 메싱 → `FHktVoxelChunkProxy` 가 RHI 버퍼 직접 업로드
- 전용 `FHktVoxelVertexFactory` 가 압축 정점 포맷 해석
- LOD 단계는 다운샘플 좌표계 (`HktVoxelLOD`)

`HktVoxelCore` LoadingPhase 는 **PostConfigInit** 고정 — 렌더 서브시스템 선행 초기화 필요. 변경 금지.

`HktVoxelTerrain` 은 자체 `FHktTerrainGenerator` 인스턴스화 금지 — `UHktTerrainSubsystem::AcquireChunk` 경유 (G-0006 준수).
