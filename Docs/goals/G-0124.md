## Intent

스프라이트 캐릭터 어셋의 자동 생성 파이프라인. 다른 Generator (G-0120) 가 단일 Intent → 단일 어셋의 짧은 변환인 반면, 스프라이트는 **다단계 + 다입력 (Video / Atlas / TextureBundle)** 으로 — 별도 표면이 필요하다. Router 디스패치 대상이 아니라 MCP 도구 / 에디터 패널에서 직접 호출된다.

### 3-stage 파이프라인 (Docs/SpritePipeline-3Stage.md)

| Stage | 입력 | 처리 | 산출 | 패널 |
|---|---|---|---|---|
| 0. Anim Capture | UE5 AnimSequence | `FHktAnimCaptureScene` 으로 결정론적 프레임 렌더 | 비디오/프레임 시퀀스 | `SHktAnimCapturePanel` |
| 1. Video Extract | 비디오 파일 | 프레임 분리 | 프레임 PNG 시퀀스 | `SHktSpriteVideoExtractPanel` |
| 2. Atlas Pack | 프레임 시퀀스 | 패킹 + UV 메타 | Atlas Texture + Atlas JSON | `SHktSpriteAtlasPackPanel` |
| 3. Sprite Build | Atlas + 메타 | DataAsset 조립 | `DA_SpriteCharacter_*` + 빌보드 머티리얼 | `SHktSpriteBuilderPanel` |

각 Stage 는 독립 입력으로 시작 가능 — 외부에서 미리 만든 Atlas 도 Stage 3 입력으로 받음 (Stage 0~2 우회).

### Paper2D 경로

`HktPaper2DGenerator` 는 동일 입력 (frames 또는 atlas) 에서 Paper2D `UPaperFlipbook` 을 산출. 런타임 페어는 Paper2D 렌더러 (`Docs/Design-HktSpritePaper2DRenderer.md`) — Niagara Crowd 경로와 평행 옵션.

### MCP / 패널 / 통합 창

`SHktSpriteToolsWindow` 가 위 6개 패널 + Paper2D 패널을 단일 도킹 창에 모음. `sprite_tools.py` MCP 도구는 LLM 에이전트가 동일 파이프라인을 자동 호출. 디폴트 값은 `UHktSpriteGeneratorSettings` (Project Settings).
