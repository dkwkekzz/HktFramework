## Intent

서버 권위 시뮬레이션 결과 (`FHktWorldView`) 를 UE5 시각 표현으로 변환한다. 핵심 가치는 다음 세 가지.

1. **시뮬레이션 미의존** — Presentation 은 `OnWorldViewUpdated(FHktWorldView)` 델리게이트만 수신. WorldState 직접 쓰기 0 (G-0003 / G-0004).
2. **대량 엔터티 처리 성능** — SOA 뷰모델 + Generation Counter dirty 추적 (`THktVisualField`) 으로 프레임당 변경 엔터티만 처리. 적합 카테고리에 HISM / Niagara Crowd / Mass Entity 디스패치.
3. **데이터 드리븐 자산 연결** — `GameplayTag → UHktAssetSubsystem::LoadAssetAsync → TagDataAsset → 시각 표현` 단일 경로. Tag miss 시 Generator 콜백으로 자동 생성 후 등록.

Voxel/Sprite/Landscape 3개 렌더 경로 모두 `UHktTerrainSubsystem` 단일 출처 (G-0006). HktUI 는 HktPresentation 미의존 — `IHktPlayerInteractionInterface` 만 사용.
