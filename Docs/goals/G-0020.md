## Intent

서버 권위 시뮬레이션 결과 (`FHktWorldView`) 를 UE5 시각 표현으로 변환한다. 핵심 가치는

1. 시뮬레이션 미의존 — Presentation 은 WorldView 만 읽음 (G-0003)
2. 대량 엔터티 처리 성능 — SOA + HISM/Crowd 렌더러
3. 데이터 드리븐 — GameplayTag → DataAsset → 시각 표현 자동 연결

Voxel/Sprite/Landscape 3개 렌더 경로 모두 `UHktTerrainSubsystem` 단일 출처 (G-0006).

## Success Criteria

- description: 200 엔터티 가시 상태에서 평균 프레임타임 ≤ 16.6ms
  measurable: true
  measure: UE5 stat unit, 5 분 평균 — 자동화 미구현, 수동 측정
- description: WorldView 갱신 → 시각화 반영 ≤ 1 프레임
  measurable: true
  measure: HktPresentationSubsystem::OnWorldViewUpdated 핸들러 latency 측정
- description: 시각 리소스 (Mesh / Anim / VFX / UI 위젯) 이 GameplayTag 만으로 비동기 로드되어 연결됨
  measurable: false
  measure: 코드 리뷰 — `UHktAssetSubsystem::LoadAssetAsync` 사용 확인
