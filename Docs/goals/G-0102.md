## Intent

GGPO 롤백은 클라이언트가 N+1, N+2, … 로 예측 실행한 프레임을 권위 Batch 도착 시점에 정확히 되돌릴 수 있어야 한다. 이를 위해 한 프레임의 모든 변경 — 엔티티 생성 / 제거, Property / Tag / OwnerUid 변동 — 을 `FHktSimulationDiff` 에 Old/New 양방향 쌍으로 누적하고, `UndoDiff` 로 역순 적용한다.

누락 없는 가역성이 깨지면 롤백 후 상태 해시가 달라져 결정론이 무너진다.
