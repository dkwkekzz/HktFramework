## Intent

`concept_design.terrain_spec` 또는 `map-gen` 스텝의 출력 HktMap JSON 을 UE5 Landscape + 스포너 볼륨 + 리전 + Story 참조 + Props 배치로 빌드한다.

HktMap 은 UMap 이 아닌 JSON 기반 맵 정의 — 런타임 동적 로드/언로드 가능. 파일 위치는 `.hkt_maps/` (`HKT_MAPS_DIR` 환경변수). 핵심 구성 요소:

- **Landscape**: `FHktTerrainRecipeBuilder` 가 노이즈 레시피로부터 heightmap 절차적 생성
- **Spawner**: 엔터티 스폰 볼륨 정의
- **Region**: 영역 경계 + 게임플레이 메타데이터
- **Story refs**: 리전/스폰 이벤트와 Story Tag 연결 (G-0104 산출 참조)
- **Props**: 정적 메시 배치

지형 데이터의 단일 출처는 `UHktTerrainSubsystem` (G-0006 제약) — Generator 산출도 동일 경로를 거쳐야 Voxel/Sprite/Landscape 3 렌더 경로가 일관된다.

이 목표는 G-0101 의 `map_generation` 스텝과 G-0100 의 MCP 도구 채널에 의존.
