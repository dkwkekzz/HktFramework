## Intent

서버와 클라이언트가 동일 `IHktDeterminismSimulator` 와 동일 고정 틱 (`hkt.Sim.FramesPerSecond` 기본 30Hz) 으로 시뮬레이션하므로 — 동일 초기 상태 + 동일 입력 → 동일 결과가 성립한다. 클라는 입력 지연을 가리기 위해 로컬 예측 (AdvanceLocalFrame) 후 권위 Batch 수신 시 `DiffHistory` 를 역순으로 `UndoDiff` → 빨리감기 → 권위 `AdvanceFrame` 의 3 단계를 일관되게 처리한다.

이 흐름이 결정론을 전제로 하므로 G-0010 의 가장 가시적 검증 지점이다.
