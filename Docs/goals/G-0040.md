## Intent

런타임 시뮬레이션 상태를 UE5 에디터에서 실시간 관찰. VM 레지스터 / 엔터티 프로퍼티 / 런타임 인사이트 / 이벤트 로그 / ViewModel 상태 5 축을 nomad 도킹 탭으로 통합하여 결정론적 시뮬레이션의 디버깅·튜닝을 지원한다.

전 코드는 `ENABLE_HKT_INSIGHTS` 매크로 가드 — Shipping 빌드에서 no-op (HktCore Build.cs 가 비-Shipping 에서 자동 정의). 데이터 주입은 `HKT_INSIGHT_COLLECT(Category, Key, Value)` 매크로 경유.

구성 요소

- Slate 패널 6 종
  - `SHktVMStatePanel` — 3-pane VM 인스펙터 (엔터티 → VM → 레지스터 상세)
  - `SHktWorldStatePanel` — Hot/Cold tier 분리 엔터티 프로퍼티 뷰어
  - `SHktRuntimeInsightsPanel` — Server / Client / ProxySimulator 탭형
  - `SHktGameplayLogPanel` — GameplayTag 계층 필터 트리 + 시간순 이벤트 로그
  - `SHktViewModelStatePanel` — Presentation ViewModel 상태 뷰어
  - `SHktInsightTable` — 재사용 가능한 Key|Value 테이블 위젯
- 에디터 nomad 도킹 탭 5 종 (`HktInsightsEditorModule`)
  - HKT VM State / HKT Runtime / HKT World State / HKT Gameplay Log / HKT ViewModel State
  - Window 메뉴 + Tools > Instrumentation 양쪽에 등록
- 콘솔 명령 3 종
  - `hkt.insights.clear` — 수집 데이터 클리어
  - `hkt.insights.categories` — 등록된 카테고리 목록 출력
  - `hkt.insights.dump <Category>` — 특정 카테고리 데이터 덤프
