## Intent

런타임 시뮬레이션 상태를 에디터에서 실시간 관찰. VM 레지스터 / 엔터티 프로퍼티 / 이벤트 로그 / 런타임 인사이트 4 축을 도킹 탭으로 통합.

전 코드는 `ENABLE_HKT_INSIGHTS` 매크로 가드 — Shipping 빌드에서 no-op (HktCore Build.cs 가 비-Shipping 에서 자동 정의).

## Success Criteria

- description: 5 종 Slate 패널 (VMState / WorldState / RuntimeInsights / GameplayLog / InsightTable) 이 모두 동작
  measurable: false
  measure: 수동 — UE5 에디터 Window 메뉴에서 4 종 도킹 탭 열기 확인
- description: ENABLE_HKT_INSIGHTS=0 에서 모든 코드 경로 컴파일 타임 제거
  measurable: true
  measure: Shipping 빌드 산출물에 HktInsights 심볼 0
- description: "hkt.insights.{clear,categories,dump} 콘솔 명령 동작"
  measurable: false
  measure: 수동
