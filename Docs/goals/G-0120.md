## Intent

Tag 단위 어셋 생성 요청을 적절한 Generator Handler 로 디스패치하고, 생성된 어셋의 출력 경로를 ConventionPath 규칙으로 결정한다.

라우팅 진입점:

| Tag prefix | Handler | 산출 |
|---|---|---|
| `VFX.*` | VFX Generator | UNiagaraSystem |
| `Entity.Character.*` | Mesh + Anim Generator | StaticMesh + Anim |
| `Entity.Item.*` | Item Generator | Mesh + 아이콘 |
| `Anim.{Layer}.{Type}.{Name}` | Anim Generator | Anim 어셋 |

Handler 인터페이스 (`IHktGeneratorHandler::CanHandle / HandleTagMiss`) 는 런타임 어셋 누락(`UHktAssetSubsystem` Tag-miss) 또는 에디터 명령에서 트리거된다. 어셋 생성 후 `UHktTagDataAsset` 파생 클래스를 함께 등록하여 다음 런타임 로딩이 발견 가능하게 한다.

ConventionPath 는 Generator 출력 경로 결정에만 사용 — 런타임 로딩은 GameplayTag → DataAsset 비동기 로드 (G-0020) 로 분리된다. 이 분리가 깨지면 결정성/캐싱이 무너진다.

Texture / Sprite / Paper2D 는 Router 등록 핸들러가 아닌 독립 Subsystem / FunctionLibrary 로, MCP 도구 또는 에디터 패널에서 직접 호출된다.
