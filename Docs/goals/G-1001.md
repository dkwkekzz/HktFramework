## Intent

Paper2D 는 인스턴싱이 없어 엔터티 한 명 = 액터 한 개 = `UPaperFlipbookComponent` 한 개 — 군중 규모에선 부적합하지만 단일 캐릭터 검수 / 디버그 / 저밀도 신에서 가장 편한 경로.

표준 `FHktActorProcessor` + `IHktPresentableActor` 파이프라인을 그대로 사용한다 — 별도 호스트/렌더러 없음.

매 프레임 Tick 흐름.

1. 위치 보간 (`RenderLocation` → `InterpLocation`)
2. `HktSpriteAnimProcessor::ResolveRenderOutputs` (G-1000) → `(AnimTag, PlayRate)`
3. `ResolveStoredFacing` → `KeyDir + bFlipX` (W/SW/NW 미러)
4. `(AnimTag, KeyDir)` 변경 시 `Template->Flipbooks.Find({...})` → `SetFlipbook`
5. ElapsedSec = `(NowLocalSec - AnimStartLocalSec) * PlayRate` → `SetPlaybackPosition`
6. `RelativeScale3D.X = bFlipX ? -1 : +1`
7. RootScene yaw = CameraYaw (빌보드)

미러 dir(W/SW/NW) 은 Template 키를 만들지 않는다 — 액터가 X-스케일 -1 로 처리하여 atlas 절약.

비주얼 자산은 `UHktPaperActorVisualDataAsset::IdentifierTag` (예: `PaperSprite.Character.Knight`) 한 번 로드로 Template 의 모든 Flipbook 이 함께 끌려옴 — 매 프레임 동기 룩업 가능.
