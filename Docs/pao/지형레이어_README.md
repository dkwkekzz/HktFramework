# 지형(地形) 레이어 프로토타입 — 실세계화 심화

> 동반 코드: `terrain_layer_prototype.py` (numpy + matplotlib, 한 파일)
> 산출물: `terrain_evolution.gif` · `terrain_final.png` · `landslide_powerlaw.png`

물질(불) 레이어에 이어, **같은 3축 + 같은 3법칙**을 지형에 박아 실제 지형형성학
(침식·퇴적·산사태) 수준으로 깊이 판 프로토타입이다. 코드 어디에도 "강을 여기 그려라",
"산맥을 저기 세워라"는 명령이 없다. 칸마다 숫자 3개와 그 숫자를 읽는 법칙 4개뿐인데
**덴드라이트 강줄기·협곡·능선·퇴적분지가 스스로 떠오른다.**

```bash
python3 terrain_layer_prototype.py            # 시뮬 + 그림 3장
python3 terrain_layer_prototype.py --ticks 60 # 더 오래 침식
python3 terrain_layer_prototype.py --no-render # 시뮬만(빠름)
```

---

## 1. 같은 3축이 지형에서 무엇이 되는가

| 축 | 코드 | 지형에서의 의미 | 설계 문서의 축 |
|---|---|---|---|
| **잠재 P** | `w.P` | 고도(중력 위치에너지) + 물 — gradient가 곧 흐름·긴장 | 고도·지각응력·지하수 |
| **친화 A** | `w.A` | 침식성 — 같은 물이 와도 A 높은 곳만 깊게 깎인다 | 침식/퇴적 성향 |
| **질서 O** | `w.O` | 퇴적·토양 — 깎여 흐른 흙이 쌓여 *남는* 지층 | 지층·지형 → **다음 잠재** |

핵심은 물질 레이어와 **문법이 같다**는 것이다. `P/A/O`라는 세 글자, 그리고 그것을 읽는
네 법칙은 자기가 "불"을 돌리는지 "지형"을 돌리는지 모른다. 그래서 한 번 짠 법칙이
레이어를 갈아타며 그대로 돈다(설계 문서의 "Processor 15개가 아니라 3개").

## 2. 같은 법칙이 지형에서 무엇이 되는가

| 법칙형 | 함수 | 지형에서의 모양 | 떠오르는 것 |
|---|---|---|---|
| **촉매** | `law_catalysis` | 물방울이 경사를 따라 흐르며 물길을 파고, 판 물길이 다음 물을 더 모은다 (반응이 반응을 낳음) | **덴드라이트 강줄기** |
| **임계** | `law_threshold` | 경사가 안식각을 넘으면 산사태 — 경사가 아니라 *절벽* | **능선·협곡 + 자기조직화 임계성** |
| **보존** | `law_conservation` | 깎인 흙은 반드시 어딘가 쌓인다 (공짜 없음) + 풍화 되먹임 | **퇴적분지** |
| **되먹임** | `law_uplift` | 느린 융기가 잠재를 다시 채운다 (끝없음의 엔진) | **정상상태 지형** |

`terrain_final.png`의 네 칸이 정확히 이 네 법칙이 손댄 결과다. 왼쪽 위 고도, 오른쪽 위
강줄기(촉매), 왼쪽 아래 퇴적 O(보존), 오른쪽 아래 경사(임계로 안식각까지 깎인 사면).

## 3. 자기조직화 임계성 = 멱법칙 (설계 문서 "criticality"의 숫자 증명)

`landslide_powerlaw.png`는 산사태 크기 분포다. 임계 법칙의 가장 순수한 이산형
(Bak–Tang–Wiesenfeld 모래더미 — "쌓이다 4 넘으면 무너져 이웃에 1씩")으로 측정했다.
결과는 **4 자릿수에 걸친 직선 = 멱법칙**, 꼬리 지수 **τ ≈ 1.15**.

> 한 칸짜리 사태부터 2만 칸 대붕괴까지, *어떤 규모든* 일어난다. 작은 사건은 흔하고 큰
> 사건은 드물되 **상한이 없다.** 이게 설계 문서가 말한 "예측불가능성의 수학적 정체"이며,
> 지형이 스스로 안식각 근처(임계점)로 수렴한다는 뜻이다 — 우리가 임계점을 손으로 찾은 게
> 아니라 세계가 거기로 *조직화*된다.

## 4. 실세계화에서 직접 부딪힌 함정 두 개 (예산으로 잡아야 할 비용)

설계 문서는 "criticality 탐색"과 "수치 비용"을 *없앨 수 없으니 예산으로 잡으라*고 했다.
이번에 실물로 두 번 터졌고, 둘 다 코드에 박아 해결했다.

1. **물방울 침식 폭주** — 침식·퇴적을 한 칸에 몰아넣으면 스파이크가 자라 값이 10^22까지
   발산한다. → 4 격자 코너에 쌍선형 분배 + per-step 상한(`MAXDELTA`)으로 잡음.
2. **산사태 발산** — 4이웃 확산의 완화계수가 CFL 한계(0.25)를 넘으면(처음 0.5로 둠)
   가파른 지형에서 값이 ±로 진동하며 폭발한다(총합은 보존되지만 max가 터짐). → 0.2로 낮춤.

> 교훈: 매끄러운 지형에선 0.5도 멀쩡히 돌아 *안정해 보였다.* 능선을 세우자(=실세계에
> 가까워지자) 비로소 터졌다. 풍요로움을 키우면 안정성 마진이 같이 줄어든다 — 곱셈의 양날.

## 5. UE5 / Mass 번역

| 프로토타입 | UE5/Mass |
|---|---|
| `w.P / w.A / w.O` (거친 grid) | `FMassFragment` (Potential/Affinity/Order) |
| `law_catalysis / threshold / conservation / uplift` | `UProcessor` 4개 |
| `tick()`의 호출 순서 | `ExecutionOrder` 고정 |
| `law_catalysis`가 이웃 칸에 *쓰기*만 함 | spatial query 폭발 회피 (entity는 자기 칸 sampling) |

## 6. 다음 단계 — 단 하나의 위쪽 화살표 (Step 4)

설계 문서의 **통일 테스트**: *레이어 N의 질서가 N+1의 잠재가 되는가.*

이 레이어는 그 다리를 이미 들고 있다 — `w.O`(퇴적·토양)다. 다음 한 걸음은:

> **지형의 질서 O(비옥한 퇴적분지·강가) → 날씨 레이어의 잠재 P(지형성 강우가 모이는 자리).**

즉 산맥의 질서가 바람을 막아 비를 쏟게 하고(지형성 강우), 그 비가 다시 지형을 깎는다.
이 화살표 **하나**만 코드로 연결하면 물질→지형→날씨로 수직 사슬이 한 칸 더 길어지고,
"트렌치코트 입은 5마리"가 아니라 *하나의 세계*라는 가설이 한 단계 더 증명된다.

> 원칙(설계 문서 5장): 5개 레이어를 얕게 ❌ / 1개를 깊게 + 위쪽 화살표 1개 ✅.
> 지형은 이제 깊다. 남은 건 화살표 하나.
