# 히키토의 대모험 — 통합 시뮬레이션 설계 핵심

> 세계는 *만드는* 게 아니라 *떠오르게* 한다.
> entity를 설계하지 말고 — **field + 법칙 + 에너지 흐름**을 설계하면, 물질·지형·날씨·생명·사회가 그 위에서 emergent하게 나온다.

---

## 0. 목적 — 무엇을 만들려는가

**끝없는 모험과 강한 도파민을 주는 세계**를, 콘텐츠를 끝없이 그려서가 아니라 **세계가 스스로 굴러가게** 해서 만든다.

이를 위한 두 가지 태도:

- **인간의 모습을 모방하지 않는다.** 정해진 시나리오·스크립트를 흉내 내는 대신, 원칙·원리·법칙을 깔고 그 위에서 세계가 자연스럽게 전개되게 한다.
- **entity를 설계하지 않는다.** 생명·날씨·생태계 같은 결과물을 직접 만들지 않고, 그것들이 *떠오를* 토대(field + 법칙 + 에너지 흐름)를 설계한다.

> 성공의 그림: 플레이어가 한 번 배운 직관(예: 불을 다루는 법)이 전혀 다른 영역(예: 혁명을 일으키는 법)에 그대로 통하는 세계.

---

## 1. 개념 정의 — 세계를 이루는 기본 부품

### 1-1. field (장) — 일차 시민

먼저 직관 하나부터 바꿔야 한다. **atom 하나는 아무것도 보여주지 않는다.**
온도 속성도 단독으로는 의미가 없다 — 기울기(gradient)가 있어야 비로소 열이 흐른다. 세계는 atom으로 만들어지는 게 아니라 atom들 사이의 **차이와 관계**로 만들어진다.

그래서 설계의 일차 시민은 atom이 아니라 **field**다.

- **field** = 공간의 모든 점(격자 칸)에 값이 하나씩 박힌, 한 장의 투명한 지도. (예: 방 안 모든 지점의 온도)
- **gradient** = field의 공간 미분 = 드라마의 원천. (값의 차이가 곧 흐름·긴장)

### 1-2. 세 개의 속성 축 = 세 장의 field

세계의 *모든 것*을 단 3개의 단어로만 기술하기로 못 박는다. 그 3개의 단어를 공간에 깐 것이 3장의 field다.

| 축 (field) | 역할 | 담는 것 |
|---|---|---|
| **잠재 (Potential)** | 풀려나려는 저장 에너지. gradient가 곧 긴장. | 긴장을 *쌓는다* |
| **친화 (Affinity)** | 접촉 시 결합·변환하려는 정도. 끌거나 민다(+/−). | 방출의 *엔진* + 재귀의 엔진 |
| **질서 (Order)** | 엔트로피에 저항하며 *남는 것*. | 잔여가 *쌓이는* 곳 (number-go-up) |

> **축을 늘리고 싶은 충동을 참아라.** 깊이는 차원 추가가 아니라 *상호작용*에서 나온다. 3축이면 충분하다. (DNA 염기 4개, RGB 3채널이 거대한 공간을 만들듯이.)

### 1-3. atom·entity·법칙

- **atom** = field를 국소적으로 읽고 쓰는 단말. 속성 운반체.
- **entity** = atom들의 조합. 자기 발밑의 field 값을 *읽고*, 필요하면 *되쓴다*.
- **법칙** = field의 *차이*를 읽고 상태를 바꾸는 규칙.

법칙이 따르는 세 가지 모양(이게 축 자체보다 중요하다):

- **임계 (threshold)** — 변화는 경사가 아니라 *절벽*이어야 한다. 양이 질로 점프해야 예측 오차가 생긴다(물→얼음).
- **촉매 (catalysis)** — 반응이 반응을 낳아야 재귀가 산다. 끝없음의 엔진.
- **보존 (conservation)** — 공짜는 없다. 잠재를 모으려면 어딘가를 비워야 한다. 축적에 무게를 준다.

### 1-4. "조합이 보여주는 것"의 정체

조합이 보여주는 것은 *사물*이 아니라 **되어감(과정)**이다. 불은 물체가 아니라 빠른 산화가 눈에 드러난 것이고, 생명체는 원자 배열이 아니라 엔트로피에 저항하며 스스로를 유지하는 패턴이다. → 이게 **emergence(창발)**이며, 우리가 직접 그리지 않고 *떠오르게* 하려는 바로 그것이다.

## 2. 문제 정의 — 위 개념을 쓰면 무엇이 어려워지는가

개념은 깔끔하지만, 실제로 굴리면 세 가지 근본 문제가 튀어나온다.

### 문제 A — 끝없음과 도파민은 서로를 죽인다 ★ (가장 근본)

- **도파민의 정체:** atom의 속성이 아니라 *예측과 결과 사이의 간격*(reward prediction error)에서 나온다. → **가독성(학습 가능한 보상)**을 원한다.
- **끝없음의 정체:** 루프의 *출력이 입력으로 되돌아옴*. → **카오스(조합 폭발)**를 원한다.

둘은 정면충돌한다. 순수 카오스 = 노이즈 = 도파민 안 나옴. 순수 진행 = 천장에 닿아 끝남.

### 문제 B — 5개 레이어를 어떻게 "하나의 세계"로 묶나

같은 3축을 물질·지형·날씨·생명·사회에 다 박아도, 잘못하면 *같은 옷 입은 5개의 독립 시뮬레이션*(통일의 코스프레)이 된다.

### 문제 C — 창발은 좁은 임계점에서만 재밌고, 연산이 무겁다

- scale-invariant 시스템은 본질적으로 **임계점(self-organized criticality) 근처에서만** 재밌다. 그 점은 좁고 해석으로 못 찾는다. 한 칸 넘으면 다 얼어 죽고, 한 칸 모자라면 전부 죽처럼 뭉개진다.
- MMO 스케일에서 gradient는 neighbor-coupled → spatial query 폭발.

## 3. 해결 — 각 문제를 어떻게 푸나

### 해결 A — "체스" 구조 (문제 A에 대응)

규칙은 몇 개로 고정(완전 가독), 그런데 국면은 무한.
→ **법칙은 적고 고정, 상태공간은 거대.**

이걸 굴리는 엔진이 **도파민 루프**다:

```
긴장(잠재 충전) → 방출(점화/수확) → 잔여(질서 축적) → 새 긴장 …
```

- **끝없음** = 마지막 잔여가 다른 곳에 *새 긴장*을 만들어, 루프 출력이 입력으로 되돌아옴(반응 생성물이 다시 반응물이 되는 화학처럼).
- **"미친" 도파민** = **캐스케이드.** 높은 잠재 + 낮은 점화 임계 + 전파성 = 연쇄반응(산불·핵분열·콤보). 불씨 하나가 미리 깔아둔 판을 화면 가득 연쇄로 터뜨린다.
- **시혜자/steer 판타지와 도파민 폭탄은 같은 메커니즘이다.** 세계 곳곳에 긴장을 심어두고(성장·세팅) → 한 방으로 점화(수확·방출). 플레이어 = 세계에 질서/에너지를 주입하고 그 반응을 지켜보는 자.

### 해결 B — 같은 3축을 모든 스케일에 + "질서→잠재" 사슬 (문제 B에 대응)

같은 3축을 모든 레이어에 박는다:

| 레이어 | 잠재 | 친화 | 질서 | 임계(터지는 순간) |
|---|---|---|---|---|
| **물질** | 결합/열에너지 | 반응성·극성 | 결정구조 | 상전이·점화 |
| **지형** | 고도·지각응력·지하수 | 침식/퇴적 성향 | 지층·지형 | 산사태·단층파열 |
| **날씨** | 온습도·전하 | 기단 혼합 | 조직된 저기압 | 폭풍·번개 |
| **생명** | 바이오매스·비옥도 | 포식·공생·번식 | 생태계 구조 | 개체군 붐/붕괴 |
| **사회** | 부·미충족 욕구·불만 | 동맹/적대·교역 | 정주지·제도 | 전쟁·혁명·시장붕괴 |

→ 플레이어가 *불을 다루며 배운 임계·캐스케이드 직관*이 그대로 *혁명을 일으키는 데* 전이된다(= 가독성의 극한, 0번 목적 달성).

**🔑 통일의 단 하나의 테스트:**
> **레이어 N에서 생긴 *질서*가 레이어 N+1의 *잠재*가 되는가.**
> 지형의 질서(산맥) → 날씨의 잠재(지형성 강우) → 생명의 잠재(숲 자랄 자리) → 사회의 잠재(도시 설 자리).
> 이 사슬이 살아있으면 *하나의 세계*, 끊기면 *트렌치코트 입은 5마리.*

**"같은 3축"의 정확한 의미** (오해 방지):
- 개념 차원: **3장** (잠재·친화·질서 — 세계를 보는 단 3개의 렌즈).
- 구현 차원: 레이어마다 3장씩(총 ~15장). 단 전부 *같은 타입* + *같은 법칙* 적용 + *수직으로 연결.*
- OOP 비유: 전역 singleton 한 개가 아니라, **공유 class를 레이어별로 instance화해서 서로 wire한 것.** 통일은 "literally 한 숫자"가 아니라 *공유 문법 + 공유 법칙 + 연결*에서 온다.

### 해결 C — semantic 통일 + criticality는 비용으로 인정 (문제 C에 대응)

레이어를 묶는 방식은 두 갈래인데, 우리는 **(b) semantic 통일**로 간다.

- **(a) substrate 통일** — 상위 레이어가 하위 atom으로 *실제로 만들어짐*(생명체=물질 atom의 패턴). 가장 우아하지만 연산이 잔혹하고 steer 불가능. → **프로젝트를 죽이는 꿈.**
- **(b) semantic 통일 ✅** — 각 레이어는 자기 entity를 갖되, **공유 field를 읽고 쓴다.** 생명체는 물질 atom으로 *만들어진* 게 아니라 국소 물질 field를 *읽고 되쓴다.* 결합은 느슨하고, 추적·steer 가능하며, 그래도 하나로 느껴진다.
  - 대가: **레이어 간 read/write 계약**을 명시적으로 설계해야 한다(누가 어느 field를 쓰고 읽는지). = 위 "질서→잠재" 사슬을 코드로 박는 일.

남은 두 비용은 *없앨 수 없으니 예산으로 잡는다*:
- **criticality 탐색** — 재밌는 임계점은 해석으로 못 찾는다. 돌려보며 찾는 실제 엔지니어링 비용으로 일정에 미리 박아둔다.
- **gradient 연산** — field를 거친 그리드에 저장하고 entity가 *sampling*하게 한다(매 entity가 매 이웃을 쿼리하지 않음). field를 일차 시민으로 둔 게 여기서 보상받는다.

## 4. 전반적 설계 — 아키텍처 매핑

### 4-1. 개념 ↔ HktCore/HktMass

| 개념 | 구현 | 비고 |
|---|---|---|
| field (잠재/친화/질서) | **거친 그리드**에 저장 | 일차 시민. entity가 sampling |
| atom | Mass **Fragment** | 의미 없는 순수 데이터 |
| entity | Fragment들의 조합 | field를 read/write |
| 법칙 (임계·촉매·보존) | **Processor** | field의 *차이*를 읽고 상태 변경 |
| emergence | 다수 entity × 다수 Processor / tick | 관측되는 결과 |

### 4-2. 축 = 인터페이스 (핵심 설계 원리)

- **3축 = 공유 인터페이스** (공유 Fragment 타입): 모든 레이어가 `GetPotential / GetAffinity / GetOrder`를 구현.
- **3법칙 = 그 인터페이스에 대해 짠 Processor.**
- 결과: Processor는 자기가 다루는 게 용암인지 몹 떼인지 경제인지 *모른다.* "잠재 읽고 → 임계 넘으면 터뜨리고 → 질서에 쌓는다"만 안다.
  - → 법칙을 한 번 짜면 5개 레이어 전부에서 돈다(**Processor 15개가 아니라 3개**).
  - → 한 레이어의 질서를 다음 레이어의 잠재에 *그냥 꽂을 수 있다*(같은 타입 = 공통 화폐). 수직 결합이 거의 공짜.

## 5. 어디서부터, 어떻게 시작할까 ★

> 대원칙: **5개 레이어를 얕게 ❌ / 1개 레이어를 깊게 + 위쪽 화살표 1개 ✅.**
> 수평으로 넓히기 전에 *수직으로 한 번 뚫어라.* 이게 되면 전체 가설이 증명된 것이다.

**Step 0 — 종이 위에서 계약 한 장.**
5개 레이어 사이의 화살표만 그린다: *무엇이 무엇의 잠재가 되는가.* 코드보다 먼저.

**Step 1 — field 기반부터.**
3개 scalar field(잠재·친화·질서)를 거친 그리드에 올린다. **아직 entity 없음.** 맵 3장이 시간에 따라 흐르는 것만.

**Step 2 — 3개 법칙형 Processor를, 물질 레이어 하나에만.**
임계 / 촉매 / 보존. 다른 레이어는 손대지 않는다.
*(물질을 먼저 잡는 이유: 가장 구체적이고, 플레이어가 핵심 직관(임계·캐스케이드)을 배우는 곳이며, 손맛 검증이 가장 쉽다.)*

**Step 3 — 루프가 손맛 날 때까지 튜닝 (= criticality 찾기).**
긴장→방출→캐스케이드가 *느껴지는* 점을 찾는다. 해석으로 못 찾는다 — 돌려보며 찾는다. **실제 엔지니어링 비용으로 미리 잡아둘 것.**

**Step 4 — 단 하나의 위쪽 화살표.**
물질의 *질서* → 다음 레이어(지형)의 *잠재.* 수직 결합 **1개**를 증명한다.
→ 여기까지 되면 통일 가설이 증명된 것. 이후엔 *이 패턴을 레이어마다 복제*할 뿐이다.
