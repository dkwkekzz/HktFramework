# 08 — Phase 6~8: 제한적 AI · 빌드 최적화 · 도메인 확장

전제: Phase 1~5 완료. 원본 §22·§28·§32(Phase 6~8)·§33 의 수정판.
이 문서는 앞 문서들보다 의도적으로 얇다 — 세부는 해당 Phase 착수 시점에 그때까지의 실측을
반영해 구체화하고, 여기서는 **경계와 도입 기준**만 고정한다.

## Phase 6 — 제한적 AI 사용

AI 가 하는 것 / 안 하는 것의 경계는 원본 §22·§32 그대로:

| AI 가 한다 | AI 가 하지 않는다 |
|---|---|
| 부품 분할 보조(어노테이션 초안) | 정점 배열 |
| 템플릿·단면·tip 가설 선택 (Phase 5 의 전수 루프 대체) | UV Atlas |
| 흑백 장식 마스크 생성 | 완성 BaseColor/Normal/Roughness |
| 최적화 정체 원인 진단·시각 크리틱 | 검증기 통과 판정 |

- **장식 마스크**: 원본 §22 의 요청/검증/정제 파이프라인 그대로. 생성 주체는 외부 이미지
  API 또는 로컬 모델 — 어느 쪽이든 **결과 마스크는 검증·정제 후 Float32 배열로 프로젝트에
  저장**(06§4.4 규약)하므로 생성기의 비결정성이 산출물 결정성을 오염하지 않는다.
  실패 시 정제 단계(배경 제거→threshold→최대 연결 요소→윤곽 단순화)는 자체 코드.
- **분할 보조**: AI 는 어노테이션 UI 의 **초안**만 채운다 — 사용자가 확인/수정하는 5.1 흐름
  유지(`manuallyConfirmed` 의미 유지).
- **서버 도입 기준 (D-12 의 유예 해제 조건)**: 다음 중 하나가 실제로 필요해질 때만 —
  ① API 키를 브라우저에 둘 수 없는 외부 AI 호출, ② 로컬 모델(ONNX) 실행, ③ 프로젝트
  공유 저장소. 도입 시 원본 §29 API·§30 이벤트 형태를 그대로 승격하고, 코어(core~eval)는
  이미 DOM 무의존이므로 서버에서 재사용된다.

## Phase 7 — 빌드 최적화

원본 §28 계승:

- gltf-transform 파이프라인(Node 스크립트, `tools/`): prune → weld(위치+속성 기준 재용접)
  → meshopt 인코딩 → KTX2(BasisU, ORM 은 UASTC, BaseColor 는 ETC1S) → validator.
- LOD: 파라메트릭 생성기의 이점 활용 — **폴리곤 감소가 아니라 세그먼트 수를 줄여 재생성**
  (LOD0: 기본, LOD1: 세그먼트 ½, LOD2: ¼ + fuller 오프). UV·의미값이 LOD 간 같은 규칙으로
  생성되므로 텍스처 공유가 자연 성립. 이것이 데시메이션 대비 이 설계의 구조적 이득이다.
- 충돌 메시: 캡슐(칼날·손잡이) + 박스(가드) 근사 — 파라미터에서 해석적으로.
- 선택: 레이캐스트 AO(부품 간 차폐 — D-7 잔여), seamVisibility 실측(중립 조명 렌더 비교).

## Phase 8 — 도메인 확장

- 재사용 경계(원본 §32): core / uv(validate·atlas 프레임) / material / bake / eval /
  export / app 골격은 도메인 공통. 도메인별 신규 = 생성 문법(mesh/), 의미값 정의,
  Atlas 레이아웃, 기능 평가.
- 이 시점에 packages 분리(D-12 유예 해제): `core+bake+uv` 를 공용 패키지로, 검 생성기를
  첫 도메인 패키지로.
- 생물은 원본 §33 원칙(종별 템플릿 + cage deformation + UV 보존) 유지 — 단 본 트랙이 아니라
  별도 트랙 후보. 리포에 이미 인접 트랙(HktCreature: 스켈레톤 로드 + 절차 살)이 있으므로
  착수 전에 통합/분리를 결정한다.

## 남은 미결정 (착수 시 결정)

- KTX2 인코딩을 브라우저(wasm)에서 할지 Node 도구로만 할지.
- 장식 마스크 생성 모델 선택(외부 API vs 로컬 ONNX).
- seamVisibility 의 정량 정의(렌더 비교 방법).
- Phase 8 첫 확장 도메인(창이 최소 diff — 칼날 생성기 재사용률 최대).
