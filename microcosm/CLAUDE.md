# microcosm

**궁극 목표** — 하나의 규칙(입자 + 장: `dx/dt = f(x) + ΣW·g + I − γx`)에서 오픈월드 MMORPG 의 모든 아트(나무·캐릭터(스켈레톤)·바다·지형)의 **형태와 움직임을 *창발*시켜 생성**한다. 손으로 그리는 아트 리소스 비용을 없애는 것이 핵심이다. (세계 전체의 완전한 시뮬레이션은 목표가 아님 — *아트 생성*에 집중.)
