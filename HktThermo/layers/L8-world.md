# L8 — 세계·생태 (World / Ecosystem = 오픈월드 MMORPG) 구현 명세

> 역할: **모든 레이어가 겹쳐 하나의 복잡계**가 되는 층 = 오픈월드 MMORPG. 전역 에너지 예산(태양 입력·
> 복사 출력)이 정상상태 churn 을 돌리고, 관측/비관측 LOD 를 스케줄한다. 구현 실체는 `HktGameplay`(UE).
> **모드**: 런타임 전역.

## 1. 자료구조

```
World  = { totalEnergy, SINK, sunInflux I, regions[], observers[] }
Region = { mode(observed|folded), macroState | entities, seed }
```
- 세계 총량은 불변(창세 고정). SINK = 소산 누적 풀(태양이 되돌릴 재고).

## 2. 구현 연산

**`sunInflux(region) → ΔE`** — 태양 유입(경계조건·구동원).
- **입력**: 지역 + 유입율 `I`. **과정**: `region.pool += I·Δt`. **출력**: 유입량. **불변**: 스택을 관통하는 유일한 외부 구동 — 끊기면 전 레이어 평형사(정상상태의 열린 조건).

**`reclaimSink(rate) → ΔE`** — 소산 회수(느린 순환).
- **입력**: SINK + 재방출율. **과정**: `SINK` 를 아주 느리게 가용 풀로 되돌림. **출력**: 회수량. **불변**: 빠른 비가역(소산)을 느린 순환으로 닫음 → 세계가 안 죽음(척도 분리).

**`lodSchedule(regions, observers) → mode[]`** — 관측 기반 레이어 스케줄(핵심).
- **입력**: 지역들 + 관측자 위치. **과정**: 관측 지역 → 낮은 레이어 전개(개체·미시), 비관측 → 높은 레이어로 접기(통계·사건 수). **출력**: 지역별 시뮬 모드. **불변**: LEAVE(접기)↔ENTER(펴기)서 총량·시드 정합(재구체화 결정론·EXAMPLE-unobserved §5).

**`steadyStateAudit() → residual`** — 전역 보존 감사.
- **입력**: 전 지역·SINK. **과정**: `유입 총합 vs 복사 출력 총합` 대조. **출력**: 잔차. **불변**: 정상상태서 입력 = 출력(장기), Σ world 불변.

## 3. 인터페이스

- **상향**: 최상위 — 소비자는 플레이어(욕망 실현·큰 목표). 서사·생태는 이 층의 창발.
- **하향 `constrainDown() → {지역 유입, LOD 모드}`** — L3(플럭스 소스)·L5(먹이 유입)·L7(relevancy 방송)에 경계조건 공급.

## 4. 오프라인/런타임 분할

- **런타임(주)**: `sunInflux`·`reclaimSink`·`lodSchedule` 이 전역 루프에서. 서버는 공유 세계를 복제(결정론+국소 → 복제 공짜).
- **오프라인**: 바이옴·생태 초기 분포·유입율 `I` 를 worldgen 시드에서 굽는다.

## 5. 검증·불변식

- **정상상태**: 장기 유입 = 복사 출력(에너지 예산 닫힘). **척도 분리**: 소산(빠름)↔태양 회수(느림)로 churn 지속(열적 죽음 회피). **LOD 정합**: 관측 재개 시 세계 어긋남 0(시드 결정론). **직관 검증**: 안 보는 지역이 접혀 굴러가다 들어가면 총량 정합 개체군으로 펼쳐짐(EXAMPLE-unobserved).

> **종착**: 컨텐츠 = 새 타입이 아니라 *에너지 분포의 새 배치*. 병렬 확장 = 바이옴·문명을 같은 스택 위에.
