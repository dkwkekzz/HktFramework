# L3 — 흐름·장 (Flux / Field / Transport) 구현 명세

> 역할: **제2법칙의 엔진.** 구배가 있으면 흐름이 생긴다 — 열전도·확산·대류. 런타임에 "얼마가 어디로
> 흐르나"를 정하는 층. 구현 실체는 `HGO/flux`·`microcosm` 장방정식·`HktLedgerWeb` `field.flow()`.
> **모드**: 런타임 이체.

## 1. 자료구조

```
Field = { grid: Cell[][][], k(전도율), Dc(확산계수) }   // 온도장·밀도장·속도장
Cell  = { value }                                        // 예: 온도·농도·에너지
```

## 2. 구현 연산

**`flow(hi, lo) → amt`** — 구배 비례 이체(전 스택 흐름의 원시함수).
- **입력**: 이웃 두 셀 값 `hi > lo`, 차이 `Δ = hi−lo`. **과정**: `amt = floor(|Δ|/4)`, 높은 셀→낮은 셀로 `amt` 이체. **출력**: 이체량. **불변**: 합계 불변(이체 클램프) · 방향은 *늘* 내리막(엔트로피 화살표) · `Math.random` 없음(mean-field 기댓값·정수·결정론).

**`conduct(field, K) → field'`** — 열전도/확산(Fourier·Fick).
- **입력**: 필드 + 전도율 `k`. **과정**: 모든 이웃 쌍에 `flow` 를 `k` 스케일로 합산(한 스텝). **출력**: 다음 필드. **불변**: Σvalue 불변 · K=0 → 정지(회귀 0) · 평형(Δ=0)서 흐름 0.

**`advect(field, velocity) → field'`** — 대류(값을 속도장 따라 수송).
- **입력**: 필드 + 속도장. **과정**: 각 셀 값을 속도 방향 이웃으로 이류. **출력**: 다음 필드. **불변**: 총량 보존(경계 랩/클램프).

**`dissipate(amt) → SINK`** — 소산(폐열 배출).
- **입력**: 흐름 중 마찰/저항 손실 `amt`. **과정**: 가용 풀→전역 SINK 이체. **출력**: SINK 증분. **불변**: 사라지지 않고 SINK 로(L8 태양이 회수).

## 3. 인터페이스

- **상향 `measureUp(field) → {열유속 q=−k∇T, 물질유속 J=−Dc∇c, 엔트로피 생산율}`** — L4(구조가 볼 지속 플럭스)가 읽음.
- **하향 `constrainDown({온도 경계, 소스/싱크}) → 셀 경계값`** — L8 태양 유입·L2 상전이 소스가 필드 경계로.

## 4. 오프라인/런타임 분할

- **런타임(주)**: `flow`·`conduct`·`advect` 가 매 이체 사건에 돈다 — 파이어볼 공기저항 `floor(700/4)=175`, 명중 주입 등(EXAMPLE-fireball §3 L3 카드).
- **오프라인**: 전도율 `k`·확산계수 `Dc` 는 L2 물성에서 유도해 구움.

## 5. 검증·불변식

- **닫힌 장부**: 모든 `flow` 는 합계 불변(자료구조 강제). **엔트로피 화살표**: 흐름은 늘 구배 내리막 — 평형서 정지. **직관 검증**: 뜨거운 셀 하나가 이웃으로 번져 평탄해지는 장면을 눈으로(엔트로피 증가). **결정론**: mean-field `floor(|Δ|/4)` — 시드 무관 재현.
