# L4 — 구조·형태 (Dissipative Structure / Morphology) 구현 명세

> 역할: **형태가 창발하는 층.** 먼평형에서 지속되는 에너지 플럭스가 국소 질서(대류 셀·결정·지형·나무)를
> 만든다(Prigogine). 손으로 그린 아트를 없애는 `microcosm` 의 목표. **모드**: 오프라인 유도.

## 1. 자료구조

```
Structure = { mesh, params, stability }        // 자기조직 안정 패턴 = 형태
FieldEq   = { f(x), W(이웃 커널), I(주입), γ(감쇠) }   // microcosm: dx/dt=f(x)+ΣW·g+I−γx
```

## 2. 구현 연산

**`growStructure(fluxBC, seed, steps) → Structure`** — 소산 구조 성장(핵심).
- **입력**: 지속 플럭스 경계조건(L3 이 공급) + 시드 + 반복수. **과정**: 장방정식 `dx/dt = f(x)+ΣW·g+I−γx` 를 적분 → 반응확산/자기조직으로 안정 패턴 수렴. **출력**: 형태(mesh) + 안정성 지표. **불변**: 같은 (시드,BC) → 같은 형태(결정론) · 국소 커널 W 만(전역 조율자 0) · 질서 형성분 = 수출 엔트로피로 상쇄(2법칙).

**`measureStructure(pattern) → {M, 형태 파라미터}`** — 형태 측정.
- **입력**: 수렴한 패턴. **과정**: 결합수·가지수·표면적 등 집계. **출력**: `M`(결합수) + 형태 파라미터. **불변**: L1/L2 bake 입력이 됨(예: 슬라임 형태 → `M=100`).

**`bakeAsset(Structure) → MeshAsset`** — 에셋 굽기(오프라인).
- **입력**: 형태. **과정**: mesh/텍스처로 직렬화. **출력**: 런타임 로드 asset(나무·지형·크리처). **불변**: 형태는 굽혀 고정 — 런타임에 재성장 안 함.

## 3. 인터페이스

- **상향 `measureUp(Structure) → {형태 mesh, M, 안정성}`** — L1/L2(bake 입력)·L5(생명이 얹힐 몸)가 읽음.
- **하향 `constrainDown({플럭스 세기, 자원}) → 성장 파라미터`** — L3 플럭스·L8 자원 분포가 형태를 *구속*(타입 지시 아님).

## 4. 오프라인/런타임 분할

- **오프라인(주)**: `growStructure`·`bakeAsset` 이 개발 파이프라인에서 돈다 — 지형·나무·크리처 메시를 굽는다. `microcosm` = "세계 시뮬 아닌 **아트 생성**".
- **런타임**: 형태는 이미 구워짐(런타임 성장 ≈ 0). 죽을 때 형태 붕괴는 L5 문턱이 트리거(구조 해체 이벤트).

## 5. 검증·불변식

- **결정론**: 같은 (시드,BC) → 같은 형태(재현). **국소성**: 커널 W 만 봄 — 전역 형태 지정 0. **직관 검증**: 균일 초기장에서 무늬(반응확산 점박이·대류 셀)가 스스로 떠오르는 장면을 눈으로 — author 없이 형태 창발.
