# L1 — 결합·분자 (Bond / Molecule) 구현 명세

> 역할: 원자 사이 **화학 퍼텐셜 에너지**를 만들고, **분자 = 결합한 원자의 연결 성분**을 *측정*한다.
> 구현 실체는 `HGO/atom` Phase C(결합 기하 章 닫힘). **모드**: 오프라인 유도.

## 1. 자료구조

```
Bond     = { i, j, e_shared, wellDepth D, r_eq, order }   // 원자 배열 위의 간선
Molecule = { atomIds: int[], composition: {Z→count}, bondCount M }   // 측정 산물(저장 아님)
```
- 결합은 원자 배열 위 *간선*으로 산다. 분자는 별도 객체가 아니라 *간선 그래프의 연결 성분*.

## 2. 구현 연산

**`formBond(a, b, K) → Bond?`** — 결합 형성(발열).
- **입력**: 두 원자의 외각 `e`(원자가·빈자리) + 거리 `r`. **과정**: 이온(전하 끌림) vs 공유(외각 채움) 판정 → 간선 추가 + **결합에너지 방출**(음에너지 우물, ΔE→운동/광자). **출력**: Bond{wellDepth D, r_eq} 또는 없음. **불변**: 형성 시 방출 E = 우물 깊이(장부 닫힘), K=0 → 결합 0.

**`breakBond(bond, K)` — 해리(흡열).**
- **입력**: 결합 + 두 원자 상대 KE. **과정**: `상대KE > D` 면 간선 제거 + **D 만큼 흡수**(운동E → 결합E). **출력**: 두 자유 원자. **불변**: 형성의 정확한 역연산(닫힌 장부).

**`measureMolecules(bonds, atoms) → Molecule[]`** — 분자 측정(핵심).
- **입력**: 간선 그래프 + 원자 배열. **과정**: union-find 로 연결 성분 라벨링 → 각 성분의 조성·결합수 집계. **출력**: 분자 목록. **불변**: author 분기 0 — "물 분자"는 `{Z:1×2, Z:8×1}` 성분일 뿐 타입 아님.

**`bondGeometry(bond, K) → force`** — 기하(길이·각도·차수).
- **입력**: 결합 원자 위치. **과정**: Morse 길이 `r_eq`·VSEPR 각도·차수별 우물 깊이. **출력**: 복원력. **불변**: K=0 → 기하력 0(회귀 0).

## 3. 인터페이스

- **상향 `measureUp(bonds) → {분자 목록, 조성, 결합수 M, E_body}`** — L2·L4 가 읽음. `M`(결합수)이 L2 붕괴 문턱 `C=M·D` 의 입력.
- **하향 `constrainDown({온도}) → 해리율`** — L2 온도가 높으면 `breakBond` 빈발(열해리 경계조건).

## 4. 오프라인/런타임 분할

- **오프라인(유도)**: `bakeMorphologyStats(molecule)` — 슬라임 젤 분자망을 측정 → **결합수 `M=100`**, **몸 에너지 `E_body=200`**, 기하(길이·각도). L0 의 `D` 와 함께 L2 로 넘김.
- **런타임**: 개별 결합을 틱 하지 않는다. 결합수·몸값은 상수로 접혀 L5 대사·L7 가치 계산에 쓰임.

## 5. 검증·불변식

- **닫힌 장부**: 형성 발열 = 해리 흡열 = 우물 깊이 D(누수 0). **측정 일관**: 같은 간선 그래프 → 같은 연결 성분(결정론 union-find). **직관 검증**: 두 원자가 붙었다 떨어지는 장면에서 E 보존을 눈으로 재현(HGO scene).
