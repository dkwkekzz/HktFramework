# L0 — 원자 (Atom) 구현 명세

> 역할: 에너지가 *양자화되어 담기는 최소 그릇.* 구현 실체는 `HGO/atom`(step-0112, JS 결정론 샌드박스).
> **모드**: 오프라인 유도(상수 굽기) + 관측 시 구체화. 런타임 사건엔 원자가 직접 등장하지 않는다.

## 1. 자료구조

```
Atom = { Z, N, e, x, rx,ry,rz, px,py,pz }   // 이름 아닌 이 양들이 원자를 규정
World = { atoms: Atom[], bath: {px,py,E,…}, ledger: {Q,B,L,E}, tick, seed }
Bond  = { i, j, e_shared, wellDepth }        // (L1 소유지만 L0 배열 위에 삶)
```
- `Z` 원소 · `N` 동위원소 · `e` 전하(Z−e)·원자가(외각 e) · `x` 들뜸 준위 · `r,p` 공간·운동량.
- `bath` = 반동·방출 입자의 보존 잔여를 받는 싱크(운동량·에너지 장부 닫힘용).

## 2. 구현 연산

**`stepWorld(world, laws, K) → world'`** — 엔진(고정). 법칙이 늘어도 불변.
- **입력**: 현재 world · 법칙 목록 laws · 노브 K(계수 벡터).
- **과정**: ① 각 법칙이 원자별 힘/전이 누적(`apply`) ② velocity-Verlet 적분 `a=F/m`(적응 서브스텝) ③ 토러스 랩 ④ tick++.
- **출력**: 다음 world'.
- **불변**: K=0 → 직전과 비트 동일(회귀 0) · 장부 잔차 ≤1e-6 · 같은 seed 2회 비트 동일.

**`coulomb(a, b, K) → force`** — 전하 상호작용.
- **입력**: 두 원자의 `Z−e`, 거리 `r`. **과정**: `F = K·q_a·q_b / r²` (min-image). **출력**: 힘 벡터(a,b 대칭). **불변**: 뉴턴 3법칙(Σforce=0), K=0 → 0.

**`emit(a, K) → photon?`** — 자발 방출.
- **입력**: 들뜬 준위 `a.x`. **과정**: x 하강 → 광자 `λ=hc/ΔE` + 원자 반동 `−p_photon→bath`. **출력**: photon{λ, p} 또는 없음. **불변**: E·p 장부 닫힘(반동은 bath 적재).

**`formBond/unbond(a, b, K)`** — (L1 이 정의, L0 배열 위 실행). 결합=외각 e 공유/전하 끌림 간선. unbond: 상대 KE > `wellDepth`.

**`fuse(a, b, K) / decay(a, K)` — 핵 변환(비가역).**
- **입력**: 충돌 두 원자(fuse)·불안정 N(decay). **과정**: Z·N 재배치 + 질량결손 `Δm·c²` → 운동/광자 방출. **출력**: 변환된 원자 + 방출 E. **불변**: 비가역이라도 `Q·B·L·E` 닫힘(*비가역 ≠ 비보존*).

**`materialize(seed, E_budget) → Atom[]`** — [관측] 미시 구체화.
- **입력**: 서버 시드 + 에너지 예산. **과정**: 시드 PRNG 로 원자 다발 결정론 생성(고-x·고-p 등). **출력**: 원자 배열. **불변**: `Σ E(atoms) ≤ E_budget` · 같은 시드 → 모든 클라 동일.

## 3. 인터페이스

- **상향 `measureUp(World) → {원소Z, 전하Z−e, 원자가, 광자λ, KE=Σp²/2m}`** — L1·L2·렌더가 읽음. 특히 `KE 합` = L2 온도의 재료.
- **하향 `constrainDown({힘장, 온도경계}) → 원자 힘/속도 스케일`** — L1 결합력·L3 열 경계가 원자에 주는 경계조건. 타입 지시 0.

## 4. 오프라인/런타임 분할

- **오프라인(유도 랩)**: `bakeConstants(material)` — 물질 조성에 `stepWorld` 를 돌려 **결합 우물 깊이 D**(unbond 문턱)·**스펙트럼 색 λ** 를 측정해 굽는다. (예: 슬라임 젤 → `D=4 E/결합`.)
- **런타임**: 원자를 틱 하지 않는다. 관측 조각만 `materialize` 로 펼침(연출). 나머지는 L2 통계로 접힘.

## 5. 검증·불변식 (HGO 검증 4기둥)

1. **회귀 0** — 새 법칙 K=0 → 직전 step 비트 동일(maxDiff=0). 2. **닫힌 장부** — Q·B·L·E 잔차 ≤1e-6. 3. **결정론** — 시드 2회 비트+해시 일치(`Math.random` 금지). 4. **가설** — 더한 조각이 의도 현상을 수치로.
