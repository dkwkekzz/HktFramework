# L2 — 상·물질 (Phase / Bulk Matter) 구현 명세

> 역할: **열이 처음으로 창발하는 층.** 분자 앙상블의 통계가 온도·압력·상(相)이 된다. 구현 실체는
> `HGO/flux`(cell 위 물질)·`HWR`·`HWS`. **모드**: 오프라인 유도(문턱 굽기) + 런타임 스칼라 상태변수.

## 1. 자료구조

```
Cell/Ensemble = { T, P, ρ, phase, heatLoad }   // 개별 원자 아닌 통계 스칼라 몇 개
Bakedconst    = { C=M·D, η, T_melt, T_boil }    // 오프라인 유도 상수
```
- 런타임에 L2 가 드는 건 **스칼라 몇 개**(개별 원자 대신). `heatLoad` 가 대표 상태변수.

## 2. 구현 연산

**`coarseGrain(atoms_in_cell) → {T, P, ρ}`** — 조립(핵심: 원자 → 통계).
- **입력**: 셀 내 원자 앙상블. **과정**: `T = Σ(p²/2m)/N` (⟨KE⟩), `P = Σ 운동량플럭스/면적`, `ρ = N/V`. **출력**: 거시 스칼라 3종. **불변**: N개 자유도 → 3 스칼라(비가역 정보 압축이지만 E 보존).

**`bakeThreshold(D, M) → C`** — 붕괴 문턱 유도(오프라인).
- **입력**: L0 우물 깊이 `D` + L1 결합수 `M`. **과정**: 몸 전체를 흩으려면 결합당 평균 주입 E > D → `C = M·D`. **출력**: 응집 문턱 `C=400`. **불변**: 원자 ~10²³ → 숫자 하나.

**`phaseTransition(T, baked) → {phase, ΔE_latent}`** — 상전이.
- **입력**: 온도 `T` + 융해/기화 문턱. **과정**: `T ≥ T_melt` → 상 변화 + **잠열 이체**(구조E ↔ 열E). **출력**: 새 상 + 잠열량. **불변**: 잠열 = 결합E 총합(장부 닫힘), 문턱 미달 → 상 불변(회귀 0).

**`updateHeatLoad(cell, ΔE) → heatLoad'`** — [런타임] 열 부하 누적.
- **입력**: 현재 `heatLoad` + 주입/방출 ΔE(L3 이 전달). **과정**: `heatLoad += ΔE`. **출력**: 갱신 스칼라. **불변**: 개별 원자 대신 스칼라 하나로 열을 든다.

## 3. 인터페이스

- **상향 `measureUp(cell) → {T, P, ρ, phase, C}`** — L3(흐름이 볼 온도장)·L5(생명이 볼 붕괴 문턱 C)가 읽음.
- **하향 `constrainDown({주입 ΔE}) → heatLoad 갱신`** — L3 흐름이 준 열유속을 heatLoad 로 받음.

## 4. 오프라인/런타임 분할

- **오프라인(유도)**: `bakeThreshold` → `C=400`, 열 결합 효율 `η=3/4`, 상전이 문턱. L0·L1 상수를 받아 L2 상수로 합성.
- **런타임**: `updateHeatLoad` 로 스칼라 하나만 굴린다. 관측 시 L0 로 펼쳐 미시 확인, 비관측 시 지역 통계(T·ρ)로 접힘(EXAMPLE-unobserved §3).

## 5. 검증·불변식

- **닫힌 장부**: 잠열 = 결합E, 조립 전후 Σ E 불변. **직관 검증**: 얼음→물→수증기에서 T-곡선의 잠열 평탄부를 눈으로. **결정론**: 같은 앙상블 → 같은 T·P.

> **정밀 주의**: L2 아래로는 "열"이 없다 — L0 는 개별 `p²/2m` 만 안다. 온도는 L2 통계에서 처음 정의된다.
