# RUNTIME — 런타임·권위·LOD 아키텍처 (세계를 어떻게 계산·저장·복제·검증하나)

> 이 문서의 역할: [SPINE.md](SPINE.md)(무엇이 레이어인가)·[layers/](layers/README.md)(각 레이어를 어떻게
> 구현하나)를 **하나의 MMORPG 실행 시스템**으로 세운다. *세계를 실제로 어떻게 계산·저장·복제·검증하는가*
> 와 그 위의 **권위·LOD 아키텍처**를 정의한다. SPINE 이 존재론이라면 RUNTIME 은 실행 계약이다.
>
> 핵심 한 줄: **서버는 시뮬레이션하지 않는다 — 총량(에너지 장부)을 회계하고, 시드·예산을 발급하고,
> 사건을 중재·방송할 뿐이다.** 미시 세계는 `f(seed, ledger)` 의 순수 함수라, *저장하지 않고 재생성*하며
> *관측되는 조각만* 클라가 결정론으로 구체화한다. 안 보이는 세계는 개체 틱 없이 거시로 접혀 굴러간다.

---

## 1. 권위 모델 (Authority) — 무엇을 누가 드나

| 소유 | 서버 (권위) | 클라이언트 (구체화) |
|---|---|---|
| **확정 사실·총량** | L7 이체 장부 `Σ pools`(전 풀 합계 불변) | — |
| **인과 제약** | 사거리·속도 예산·쿨다운 | (검증 참고용 비콘) |
| **중요 자산** | 이름 있는 보스·플레이어 소유물·퀘스트 개체(개별 추적) | — |
| **시드·예산** | 지역 seed + 에너지 예산 발급 | 이를 받아 전개 |
| **관측 미시** | — | L0~L4 원자·물질·형태 결정론 구체화 |
| **궤적·연출** | — | 비행·파티클·발광(좌표 **비권위**) |

- **불변 A — 서버 = 회계사**: 서버는 ① 이체 클램프 ② FIFO 중재 ③ 원장 커밋 ④ relevancy 방송만. 이동
  적분·연출·세부 판정은 전부 클라(HktLedgerWeb 규칙 4).
- **불변 B — 좌표는 권위가 아니다**: 위치는 사거리·속도 예산 검증용 비콘일 뿐. 배치는 시드 유도(worldgen).
- **불변 C — 에너지는 정수·못 만든다**: 모든 값은 정수, 예산 클램프가 상한(안티치트=보존의 따름정리).

## 2. 계산 모델 (Compute) — 세계를 어떻게 전진시키나

### 2.1 유도 그래프 + 세 붕괴
레이어 스택은 런타임 호출 그래프가 아니라 **유도 그래프**다. 세 가지가 접힌다:
- **계산 붕괴**: 관측 해상도에 맞는 레이어만 돈다(아래 LOD). 비용 O(관측 개체 + 활성 지역), 개체 총수 아님.
- **저장 붕괴**: 미시 세계 = `f(seed, ledger)` → 저장 대신 재생성(§3).
- **컨텐츠 붕괴**: L0·L1·L4 는 오프라인에서 상수·에셋으로 구워짐(§2.4).

### 2.2 LOD 티어 — 관측이 레이어 해상도를 정한다

| 티어 | 조건 | 도는 레이어 | 단위 | 비용 |
|---|---|---|---|---|
| **T0 초점** | 관측자 근접·시야 내 | L0~L6 전개(미시 조각까지) | 개체 + 원자(관측분) | 최고 |
| **T1 주변** | 시야 내 원거리 | L5~L7 개체(형태 LOD↓·미시 접힘) | 개체 | 중 |
| **T2 활성** | 관측자 없음·시뮬 유효 | L2·L3·L5 거시 통계 + 사건 수 | 지역 통계(6 숫자) | 저 O(지역) |
| **T3 휴면** | 장기 비관측 | 시드 + 총량만 — **지연 계산** | 숫자 몇 개 | ~0 |

- **T2/T3 = 지연 계산**: 개체를 틱 하지 않는다. T3 는 마지막 접근 시각만 들고 있다가, 관측자가 다가오면
  경과 Δt 를 `macroPopulationStep` 한 번(또는 안정성 위해 몇 서브스텝)으로 **따라잡는다**
  (EXAMPLE-unobserved §3). 슬라임 1만·1000틱도 ~8 정수 연산.

### 2.3 서버 틱 루프 (권위 · 틱 순서 `LEAVE→OPS→ENTER`)

```
serverTick(dt):
  # LEAVE — 관측 이탈 지역 접기
  for region in newlyUnobserved: region.macro = coarseGrain(region.entities); region.mode = T2/T3

  # OPS — 사건 중재 (이것이 서버 계산의 전부)
  for intent in fifo(intents):           # L6→L7
      t = clamp(intent, ledger, causal)  # 잔고·사거리·쿨다운
      commit(t, ledger)                  # Σ pools 불변
  for region in activeUnobserved:        # T2
      region.macro = macroPopulationStep(region.macro, dt)   # 개체 틱 아님
  reclaimSink(rate); sunInflux(regions)  # L8 순환

  # ENTER — 관측 진입 지역 펴기
  for region in newlyObserved: region.entities = materialize(region.macro, region.seed); region.mode = T0/T1
  broadcast(relevancy)                   # 사건 서술자만(프레임 아님)
```

### 2.4 오프라인 bake 파이프라인 (런타임 밖·한 번)
`HGO/atom`(L0)·Phase C(L1)·`microcosm`(L4) 가 개발 파이프라인에서 돌아 **상수·에셋**을 굽는다 —
`D`(우물 깊이)·`M`(결합수)·`C=M·D`(붕괴 문턱)·`η`·`body`·`m`(유지비)·스펙트럼 색·메시. 런타임은 이
숫자를 정수 이체에 꽂을 뿐, 원자를 절대 틱 하지 않는다.

## 3. 저장 모델 (Storage) — 저장하지 말고 재생성한다

### 3.1 저장하는 것 (작다)
```
Persisted = {
  worldSeed,                    # 세계 결정론 뿌리
  ledgerSnapshot: {pool→balance},   # 보존 총량(정수) — 진실의 핵
  transferJournal: Transfer[],  # 이체 로그(이벤트 소스) — 스냅샷 이후 diff
  importantAssets: Asset[],     # 중요 자산만 개별(정체성 있는 것)
  regionMacro: {id→6숫자},      # 비관측 지역 접힌 상태
  regionLastSeen: {id→tick},    # T3 지연 계산용
}
```

### 3.2 재생성 (크다 → 안 저장)
- **미시 세계 = `f(worldSeed ⊕ regionSeed, ledgerSnapshot)`**: 개별 원자·개체 위치·몸값을 저장하지
  않는다. 관측 시 시드 + 지역 총량에서 결정론으로 펼친다(같은 입력 → 같은 세계).
- **이벤트 소싱**: 모든 게임플레이가 이체 문법 `{from,to,amount,cause}` 이므로 **저널이 곧 이벤트 로그**.
  스냅샷 + 저널 리플레이로 어느 시점이든 복원(감사·롤백·미러의 토대).
- **익명 vs 정체성**: 익명 다수(슬라임 1만)는 총량으로 접힘 — 개별 저장 0. 중요 자산만 개별 영속.

> **결정론이 저장을 없앤다**: 저장할 필요가 없는 이유는 "다시 만들면 똑같기" 때문. `Math.random` 금지가
> 이 등식을 지킨다.

## 4. 복제 모델 (Replication) — 서버↔클라 동기화

### 4.1 relevancy(관심 관리)
서버는 관측자별 relevancy 지역을 계산해 **그 지역의 사건 서술자만** 방송한다. 프레임별 좌표가 아니라
발사체 서술자·이체 사건(시전·명중·죽음)만. 대역폭 O(사건), 개체 수 아님.

### 4.2 결정론 미러
같은 `seed` → 모든 클라(+서버 미러)가 **비트 동일**하게 구체화. 서버는 궤적을 조율할 필요가 없다 —
비행·연출은 클라가 각자 결정론으로 재생성해 자동 일치. 서버는 *사건 3건*(발사·명중·죽음)만 확정.

### 4.3 LEAVE/ENTER 재조정
- **LEAVE**(관측→비관측): concrete 개체 → `coarseGrain` 으로 총량 접기(N·B_tot·T).
- **ENTER**(비관측→관측): 총량 + 시드 → `materialize` 로 개체 펴기. 모든 클라가 같은 개체를 같은 자리에.
  총량 정합이므로 "관측하니 어긋나 있더라" 0.

### 4.4 안티치트 (권위의 따름정리)
- 클라가 위치를 속임 → 사거리·속도 예산 비콘 검증만 건드림(텔레포트 불가).
- 클라가 위력을 부풀림 → escrow 예산 클램프가 상한(에너지 못 만듦).
- 클라가 결과를 조작 → 서버 미러가 같은 시드로 재현해 불일치 탐지.

## 5. 검증 모델 (Verification) — HGO 4기둥을 세계로 일반화

매 커밋(새 시스템·새 컨텐츠)은 결정론 샌드박스에서 수치로 증명한다:

1. **닫힌 장부(제1법칙)** — `steadyStateAudit`: 어떤 사건 시퀀스에서도 `Σ world` 불변(EXAMPLE-fireball
   §5: 1250=1250, EXAMPLE-unobserved §4: IN=OUT). 강제는 이체 클램프(자료구조).
2. **결정론** — 같은 시드 2회 → 상태 해시 일치. 서버 미러 = 클라 재현 일치(`Math.random` 금지).
3. **회귀 0** — 새 시스템 노브=0 → 직전과 비트 동일(골든 해시). 새 컨텐츠는 게이트 뒤 early-return.
4. **복제 정합** — LEAVE→macroStep→ENTER 왕복 후 총량·개체 수 정합(재구체화 결정론). 저널 리플레이 =
   라이브 상태 일치.

> **골든 앵커**: 스냅샷 + 저널 + 시드 [42,7,1234,99,2026] 시나리오 해시. 접힘/펴기·거시 스텝이 총량을
> 새게 하면 즉시 골든 불일치로 잡힌다.

## 6. 컴포넌트 아키텍처 — 실제 배치

```
 ┌─ 오프라인 (한 번) ─────────────┐        ┌─ 서버 (권위·회계사) ──────────────┐
 │ HGO/atom(L0) Phase C(L1)       │        │ Ledger(L7): clamp·commit·Σ불변     │
 │ microcosm(L4)                  │  굽기  │ Arbiter: FIFO 중재                 │
 │  → D·M·C·η·body·m·색·메시 ─────┼──────► │ Region LOD: coarseGrain/macroStep  │
 └────────────────────────────────┘  상수  │ World(L8): sunInflux·reclaimSink   │
                                     ·에셋  │ Relevancy: 사건 서술자 방송         │
                                            └──────────────┬─────────────────────┘
                                              시드·예산·사건 │ ▲ 인텐트(L6)·비콘
                                                            ▼ │
                            ┌─ 클라이언트 (구체화·연출) ─────────────────────────┐
                            │ materialize(L0~L4): 시드→원자·물질·형태(관측 조각)  │
                            │ 미시 적분: 비행·대사·충돌(결정론)                    │
                            │ 렌더: 속성→ViewModel→Scene(순수 소비)               │
                            └────────────────────────────────────────────────────┘
```

**레이어↔런타임 배치**:

| 위치 | 레이어 | 무엇을 |
|---|---|---|
| 오프라인 bake | L0·L1·L4 | 상수·형태 유도(런타임 안 돎) |
| 서버 권위 | L2(문턱)·L5(거시)·L7·L8 | 장부·거시 반응·순환·LOD |
| 클라 구체화 | L0~L4(관측)·L6 | 미시 전개·개별 행동·연출 |

## 7. 실패 모드·한계 (정직)

- **closure 없는 현상**: 미시를 요약할 거시 법칙이 없으면(난류·예측 불가 창발) → (a) 룩업 (b) 현상론적
  근사 (c) 관측 창서 실제 미시. 이 후퇴점 = author 하는 곳, 작고 명시적으로 유지.
- **재구체화 정체성 손실**: 접힌 익명 개체는 펼 때 *같은 총량의 다른 표본*. 정체성이 필요하면 중요 자산으로
  승격(개별 저장). 접힘은 익명 다수에만.
- **부동소수 금지**: 정수만(결정론·미러). 분수 필요 시 정수 커널(`floor(·/4)`)로.
- **LOD 팝핑**: 티어 경계서 형태 해상도 전환이 보일 수 있음 → 히스테리시스·페이드로 완화(연출 문제, 총량 무관).
