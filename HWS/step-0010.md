# step-0010 — 확률적 탐사(run-and-tumble): 생명이 옅은 골짜기를 건넌다 — 그리고 *진짜* 장애가 드러난다

> [step-0009로](step-0009.md) · 실행물: [step-0010.html](step-0010.html)(3D 표준 셸) · 코어: `step-0010/sim-core.js`(step-0009 코어에서 **법칙 1개 확장**(`탐사`)) · 헤드리스: `step-0010/verify.js`

step-0009 는 풍경을 *살아 움직이게* 했다(퇴적 전선이 정적 source 인데도 영구히 떠돈다). 그러나 greedy 정주 생명은 그 위에서 *살되 따라가지 못해* churn 이 후반에 멎었다(0009 §8.1: 후반 6k 출생 2~7) — 국소 최대 함정으로 옅은 골짜기를 못 건너기 때문(step-0005 이래 이월). step-0010 은 사슬의 다음 고리, **생명에게 탐사를 준다**. 메커니즘은 단 하나: **탐사(run-and-tumble)** — 갇힌(국소 최대) *굶주린* 생명이 의사난수 방향으로 한 칸.

원리: 운동은 두 모드의 접합이 아니라 **한 원리의 두 얼굴**이다. 구배에 정보가 있으면 greedy 가 등반하고(**run**, step-0005~0009 그대로), 구배에 정보가 없으면(국소 최대·옅은 평지) *편향 없는 운동 = 대칭 무작위 보행*만 남는다(**tumble**) — 이는 필드 E 자신의 운동(구배 있으면 advection, 없으면 등방 확산)을 생물량 m 이 *물려받는* 것이다. greedy 는 특수 케이스, 무작위가 일반(null) 운동. "무작위"는 *구배와 무상관(탈상관)*일 뿐 비결정론이 아니다 — 방향은 `tumbleHash(x,y,tick,seed)` 의 순수 함수(`Math.random` 금지, 시드 2회 비트 동일).

결과는 두 갈래다. **① 메커니즘은 깨끗하게 작동한다** — 옅은 트랩(굶주리는 국소 최대)에 갇힌 생명이 *해자(옅은 골짜기)를 건너* 피난처로 가 생존한다(탐사 on 전 시드 생존 거리 4.7, off 는 국소 최대에 갇혀 사멸). **step-0005 이래 5 step 이월된 "greedy=국소 최대 함정"의 첫 해소.** 그러나 **② 가장 큰 그림(끝나지 않는 churn)은 탐사만으로 오지 않는다(정직한 핵심 발견)** — 정적 source 세계에서 개체군은 살지만(pop 10~11) 정착 후반의 churn 은 탐사가 있어도 멎는다(후반 6k 출생 on 1.0 / off 3.8, 둘 다 동결). **개체군이 영구 *전역* 끌개인 정적 source 로 수렴하기 때문**(G3) — 탐사의 도달거리는 *국소적*(가까운 refuge 로 골짜기 건너기)이라 전역 봉우리를 못 이긴다. 탐사가 오히려 source 로의 수렴을 가속한다. **즉 G2 의 진짜 장애는 *생명의 이동 능력*(탐사로 해결)이 아니라 *영구 전역 봉우리의 존재* — 구동 내생화가 G2 완전 해소의 조건**(step-0005·0006 의 "능력 추가가 정적 끌개로 수렴" 패턴의 churn 차원 재연, §8.1). ③ **회귀 0·닫힌 장부·결정론 유지**(pTumble=0 시 step-0009 비트 동일, 잔차 2.51e-13, 해시 일치).

## 검증 질문 (본 thesis: 탐사는 국소 함정을 풀지만, 끝없는 churn 의 장애는 전역 끌개다)

> ① **탈출(국소 최대)**: 갇힌 굶주린 생명이 옅은 골짜기를 건너 더 나은 자원으로 가는가? (`escape`)
> ② **생존 + 한계(G2)**: 탐사 생명이 움직이는 풍경 위에 *사는가*(pop>0) — 그러나 *끝없는* churn 은 오는가? (`churn`)
> ③ **회귀 0**: pTumble=0 이면 step-0009 와 비트 동일? (`reg`)
> ④ **보존·결정론**: 탐사 on 에서도 닫힌 장부(탐사는 위치만 바꿈)·결정론(의사난수도 시드 결정론) 유지? (`conserve`·`det`)

모든 수치는 시드 [42, 7, 1234, 99, 2026], `node step-0010/verify.js <mode> [seed]` 로 재현된다. 탐사 시나리오 상수 = **pTumble=1.0**(신규 — 갇힌·굶주린 매 tick 무조건 tumble = 최대 탐사). 이 step 표준 source 는 **정적**(srcJump=0) — 내생 풍경 churn 이 주인공이고 외부 sawtooth 는 끈다(0009 §8.1 표준·패널 기본과 일치). 응집·생명·번식·이동·기초대사비·결정화·기복 상수는 step-0009 그대로.

## 2. 메커니즘 — 탐사: 구배가 없으면 남는 것은 무작위 보행 (이동의 일반화, 새 양 아님)

법칙 순서 ⑥(이동)을 pTumble≠0 일 때 다음으로 일반화한다. 각 생명에 대해:

```js
// run (구배 존재) — step-0005~0009 그대로: 빈 이웃 중 E 가 floor=E[center]+moveThresh 초과 최고 셀로
if (bIdx >= 0) { /* 그 칸으로 한 칸 */ continue; }
// ── step-0010: tumble (구배 없음=국소 최대, bIdx<0) ──
// 굶주림 게이트(국소 문턱): 입(disc)의 예측 흡수 < 이번 tick 비용이면 net 손실 — 도박할 만하다
intake = kL * Σ_{입 cells} E;   hcost = m·mMaint + baseCost;
if (intake < hcost) {                               // 잘 먹는 정착 생명은 탐사 안 함
  empties = 빈 이웃(점유 제외);
  hsh = tumbleHash(x, y, tick, seed);               // 구배 무상관·시드 결정론
  if ((hsh>>>16)/65536 < pTumble)                   // 발화(rate) — 고비트
    한 칸 ← empties[(hsh & 0xffff) % empties.length] // 방향 — 저비트(균등, *내리막도 허용*)
}
```

세 설계 결정이 이 항을 *건전하게* 만든다:

1. **가법적 폴백(회귀 0 의 제약)** — 순수 연속 run-and-tumble("항상 표류 + 나쁜 소식에 재배향")은 *greedy 등반*과 **다른 운동 원시형**이라 pTumble=0 에서 step-0009 로 환원되지 않는다(회귀 0 위반). 그래서 greedy(run)를 기반에 두고, 구배가 사라진 자리(`bIdx<0`)에서만 tumble 을 더한다 — 이것이 "구배 없는 곳에 남는 무작위"라는 원칙의 *가법적* 실현이다. pTumble=0 이면 분기를 통째로 건너뛰어 step-0009 의 "갇히면 제자리"와 비트 동일.
2. **굶주림 게이트 = 안정성** — tumble 은 *굶주린*(예측 흡수 < 비용, net 손실 중인) 생명만 켠다. 잘 먹는 정착 생명은 탐사하지 않아(흡수≥비용) 안정 정착을 깨지 않는다 — 대장균이 *조건이 나빠질 때* tumble 을 늘리는 것과 같다(생물학적 정합). 게이트는 그 개체의 m·위치 + 입의 로컬 E 만 본다(국소 문턱, 전역 조율자 0).
3. **거래 0 = 보존** — tumble 은 *순수 위치 변경*이다. 무에서 생기는 것 없고, greedy 이동(step-0005)과 똑같이 아무것도 거래하지 않는다 — 장부 식 `sumE+M+R+evap+sunk+metab−injected=E0` 가 그대로 닫힌다(잔차 2.51e-13, §3).

내리막을 *허용*하는 것이 핵심이다 — 옅은 골짜기(죽은 영역)를 건너려면 일시적으로 손해 보는 칸을 밟아야 한다(greedy 는 절대 안 밟아 갇힌다). 무작위 방향은 균등하고(구배와 무상관) tumbleHash 로 결정론적이다 — "무작위"는 *생성이 비결정*이 아니라 *구배와 탈상관*을 뜻한다(척추 결정론 유지).

### 왜 *순수* run-and-tumble 이 아닌가 — 그리고 왜 그게 옳은 발견을 낳았나

설계 논의에서 두 갈래가 있었다: (A) greedy + 무작위 폴백(채택), (B) *순수* 연속 run-and-tumble(항상 표류, 구배가 tumble rate 를 편향). (B)가 개념적으로 더 깨끗하지만 두 이유로 (A)를 택했다 — ① (B)는 greedy 기준 회귀 0 를 깬다(다른 운동 원시형), ② 더 깊게는, **무작위 보행은 *국소* refuge 찾기엔 좋아도 *방향성* 드리프트 추적엔 본질적으로 약하다**(편향이 없으므로). 이 ②가 본 step 의 핵심 발견(§8.1)으로 이어졌다 — 탐사는 가까운 함정은 풀지만 전역 끌개는 못 이긴다.

- **② 산다(가설 ① 통과)** — 탐사 생명이 정적 source·기복 세계에서 pop 11 로 *생존*한다(0009 §8.1 재확인). 전반 colonization 은 활발하다(전반 6k 출생 평균 48 — 씨앗→정착 transient).
- **② 그러나 *끝없는* churn 은 안 온다(정직한 핵심 한계)** — 후반 6k 의 churn 은 탐사 유무와 무관하게 멎는다(후반 출생 on 1.0 / off 3.8 — 둘 다 동결, 0009 §8.1 의 후반 동결 그대로). **개체군이 영구 전역 끌개인 정적 source 로 수렴하기 때문**(후반 탐사가 평균 103 회나 일어나도 — 즉 *움직이긴* 하는데 source 둘레만 더듬을 뿐 떠도는 field 고임으로 못 떠난다). 탐사는 오히려 source 로의 수렴을 *가속*한다(누적 churn 비율 on/off 가 시드별 0.86~2.48 로 *신뢰성 있는 증가 없음* — §8.1).
- **장애가 옮겨갔다** — step-0009 까지 churn 의 장애는 "생명이 옅은 골짜기를 못 건넌다"(이동 능력)였고, 탐사가 그것을 풀었다(escape ✓). 그런데 풀고 보니 *끝없는 churn* 의 진짜 장애는 따로 있었다: **영구 *전역* 봉우리(외부 정적 source)의 존재**. 전역 봉우리가 있는 한 어떤 국소 탐사도 개체군이 거기로 수렴하는 것을 못 막는다. → **G2 완전 해소의 조건은 구동 내생화**(영구 전역 봉우리 제거 — 별이 세계 안에서 나고 진다, 척추 종착점) → step-0011.

## 척추 체크 4항 (SPINE.md)

1. **단일 척추 ✅** — 탐사는 *병렬 전역 필드*가 아니라 생명(m)의 운동 법칙이다. 필드는 여전히 E(+상태 R) 뿐. 무작위는 시드 의사난수(tumbleHash)지 새 난수원이 아니다.
2. **활성도 환원 ✅** — 탐사는 authored type 분기 없이 *모든* 생명에 같은 규칙으로 적용된다(굶주림은 활성도 축 위 측정된 상태 — 흡수<비용). "탐사하는 종"을 만들지 않았다.
3. **국소 문턱 ✅** — tumble 트리거는 그 개체의 m·위치 + 입(disc)의 로컬 E 만 본다(전역 조율자 0). 방향 tumbleHash 도 (x,y,tick,seed) 로컬 함수.
4. **순환 장부 ✅** — 탐사는 *위치만* 바꾼다(거래 0) — greedy 이동(step-0005)과 같이 장부 식 불변(잔차 2.51e-13). 비가역 상태 변화 없음.

## 6. 화면에서 직접 확인하는 법

[step-0010.html](step-0010.html) 을 연다 — 3D 표준 셸(좌드래그 회전·휠 줌·클릭 조작). 지형 높이가 E+R(기복 on). 떠도는 자원은 기본 off(정적 source):

- **탐사가 골짜기를 건넌다**: 강한 고임에 씨앗을 놓아 보라("씨앗 ×3" 버튼). 고임이 옅어지거나 퇴적에 밀려 떠나면 굶주린 생명(발광 점)이 *떨며 움직여* 다음 고임을 더듬는다(tumble — 누적 탐사 카운터가 는다). 탐사를 끄면(상단 "탐사" 체크 off=pTumble 0) greedy 만 남아 갇힌 생명이 제자리에서 굶어 사라진다 — step-0009 와 같은 후반 동결.
- **잘 먹는 생명은 안 떤다**: 강고임 위 정착 생명은 탐사하지 않는다(흡수≥비용) — tumble 은 *굶주릴 때만*.
- **정직한 한계를 눈으로**: 한참 두면 탐사를 켜도 생명들이 결국 source 둘레로 모여(전역 끌개) churn 이 잦아든다. 떠도는 자원을 켜 보라(외부 운동) — 그때 비로소 churn 이 끝없이 이어진다(무대가 *움직여야* 산다, step-0007). 끝없는 내생 churn 은 구동 내생화가 필요하다(§9).
- **둑 쌓기·수확**: 클릭 동작 그대로(step-0009).

## 7. 의외의 발견 — 막힌 문을 여니, 진짜 벽이 보였다

설계하지 않았는데 떠오른 것 셋:

1. **탐사가 *국소* 함정은 풀지만 *전역* 끌개는 못 이긴다 — 같은 메커니즘의 두 운명.** escape 에선 탐사가 완벽히 작동한다(전 시드 생존). 그런데 전체 세계에선 churn 을 못 살린다. 차이는 *기하*다 — escape 의 피난처는 *가까이*(거리 2) 있어 국소 무작위 보행이 닿지만, 전역 source 는 개체군 전체의 *수렴점*이라 어떤 국소 탐사도 거기로 가는 흐름을 못 막는다. **무작위 보행은 방향 편향이 없어 *가까운 것 찾기*엔 강하고 *멀리 떠나기*엔 약하다** — 이 비대칭이 (B) 순수 run-and-tumble 을 안 쓴 두 번째 이유(§2)와 정확히 맞물린다.
2. **장애가 한 칸 옮겨갔다(연쇄의 정직).** step-0005·0006 은 "이동·비용을 더하면 흩어지겠지"가 정적 끌개로 수렴해 실패했고, step-0007 은 *무대가 움직여야* 풀린다고 가리켰다. step-0010 은 같은 교훈의 마지막 조각이다 — **생명에게 줄 수 있는 *능력*(탐사)을 다 줬는데도 정적 source 에선 동결한다.** 남은 건 능력이 아니라 *무대의 구조*다(영구 전역 봉우리 제거 = 구동 내생화). 5 step 에 걸쳐 "능력 추가는 한계가 있다"가 누적되어 척추 종착점(구동 내생화)을 *불가피*하게 만들었다.
3. **굶주림 게이트가 정착을 *보호*한다.** "탐사를 주면 정착 생명이 들떠 흩어지겠지"가 또 뒤집혔다 — 굶주림 게이트(잘 먹으면 탐사 안 함) 때문에 탐사 on 이 정착 평형을 *전혀* 흔들지 않는다(pop 11 동일, 후반 churn 도 off 와 같음). 탐사는 *실패하는* 생명만 구하고 *성공한* 생명은 안 건드린다 — 의도는 "탐사를 켜자"였는데 결과는 *선택적*으로만 켜지는 자기 게이팅.

## 8. 정직한 한계

1. **끝없는 churn 은 탐사만으로 안 된다 — 정적 source 에선 개체군이 전역 끌개로 수렴(본 step 의 가장 큰 정직).** 탐사 생명은 산다(pop 11)지만 후반 churn 은 탐사 유무와 무관하게 멎는다(후반 출생 on 1.0 / off 3.8). 누적 churn 비율(on/off)도 시드별 0.86~2.48 로 *신뢰성 있는 증가가 없다*(seed 7 은 오히려 0.86). 원인: 개체군이 영구 *전역* 봉우리(외부 정적 source)로 수렴하고(G3), 국소 도달거리의 탐사는 이를 못 막는다(오히려 가속). **이는 메커니즘의 버그가 아니라 *세계 구조*의 한계** — G2 완전 해소는 구동 내생화(영구 전역 봉우리 제거)가 필요하다(→ step-0011). escape 가 증명하듯 탐사 *자체*는 의도대로 작동한다(국소 함정 해소).
2. **무작위 보행은 *방향성* 드리프트를 못 쫓는다.** 탐사는 편향이 없어(균등 무작위) 떠도는 고임이 *한 방향으로* 미끄러질 때 능동 추적하지 못한다(가까운 refuge 찾기엔 강함, §7.1). 진짜 추적은 *시간 감지형* run-and-tumble(자기 흡수의 시간 변화로 tumble rate 를 편향 — 대장균의 완전판)이나 관성·기억이 필요 — 백로그. 본 step 의 탐사는 "갇힘 탈출"까지.
3. **굶주림 게이트·pTumble 은 시나리오 노브.** 게이트(흡수<비용)와 pTumble=1.0 은 시나리오 튜닝값(결정론에 영향 주는 시뮬 상수 아님 — 탐사 방향·발화는 시드 결정론). 게이트를 흡수<비용이 아닌 다른 임계로 잡거나 pTumble 을 낮추면 탐사 빈도가 달라진다(escape 의 생존엔 여유 있음 — 거리 4.7 vs 200 tick).
4. **escape 프로브의 합성 필드는 측정 편의.** 트랩·해자·피난처를 `paintE`/`setCell` 로 손으로 칠한다(E0 보정으로 장부 유지) — 세계가 *스스로* 만든 함정이 아니라 *통제된* 함정에서 메커니즘을 격리 측정한다(step-0005 chemotaxis 프로브와 같은 성격). 전체 세계의 함정(떠도는 고임이 남긴 옅은 골짜기)은 churn 시나리오에서 간접 확인.
5. **이산 상태기계·등방성 stencil·저장체 촉매 이월** — step-0009 의 백로그 그대로(탐사는 이동만 일반화). tumble 방향이 4 이웃(von Neumann)이라 격자 이방성 잔존.

## 9. 다음 (step-0011 예고)

> 가설: **구동(별)을 외부 주입에서 *세계 안 개체*로 내생화하면, 영구 전역 봉우리가 사라져 개체군이 한 점으로 수렴할 곳을 잃는다 — 탐사 생명의 churn 이 비로소 끝나지 않는다(G2 완전 해소).**

step-0010 이 생명의 *이동 능력* 한계(국소 최대 함정)를 풀었지만, 끝없는 churn 의 진짜 장애는 *영구 전역 봉우리*(외부 정적 source)였다(§8.1) — 개체군이 거기로 수렴해 떠도는 풍경을 안 쓴다. step-0011 은 **구동을 내생화**한다: source 가 세계 밖 고정 주입이 아니라, 세계 안에서 *나고 지는* 개체(예: 강고임이 임계를 넘으면 점화해 E 를 방출하다 연료를 소진하고 꺼지는 소산현상 — 척추 결정2 의 소산 극단)가 되게 한다. 그러면 전역 봉우리가 *떠돌고 명멸*해 수렴점이 사라진다.

- 검증할 것: ① 구동 내생화 시 개체군이 한 점 수렴 안 함(G3 해소, 무게중심이 떠돔) ② **끝없는 churn**(정적 외부 source 없이 출생≈사망>0 후반에도 지속 — 본 step §8.1 의 역전, G2 완전 해소) ③ **회귀 0**(내생 구동 계수=0 이면 step-0010 과 비트 동일) ④ 닫힌 장부·결정론(점화·소진도 쌍 거래) ⑤ 척추: 별이 활성도 축의 *소산 극단*으로 환원되는가(authored "별 타입" 없이).
- 병행 백로그(블로킹 아님): **시간 감지형 탐사**(방향성 드리프트 추적, §8.2) · **저장체 촉매**(R 위 baseCost↓) · **이산 상태기계**(living/solid/ash FSM) · **등방성 stencil**.
