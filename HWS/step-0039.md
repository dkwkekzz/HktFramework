# step-0039 — 죽은 별 잔해→새 씨앗 (出沒生死 → 재구성, VOXEL.md V5+)

> 직전: [step-0038](step-0038.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md)

## 검증 질문

step-0038 은 떴다 진 별을 지평선(z=0)에서 *꺼지게* 해 활성도 축을 닫힌 궤적(born→천장→set→死)으로 만들었다. 그러나 진 별은 **흔적 없이 사라졌다** — 빈 자리엔 *처음 놓은* R 핵만 남아 다음 별이 거기서 났다(잔해 없는 죽음). SPINE 의 척도분리("개체 척도 = 빠른 비가역 死, 세계 척도 = 느린 재구성 — 재 → 풍화 → 다시 저장체")가 아직 별 일생에 미적용이었다. 이 step 은 그 끝을 닫는다: **일몰사로 z=0 무덤에서 꺼지는 별이 미연소 외부 연료의 일부를 그 자리 저장체 R 로 남겨 다음 별의 점화 씨앗이 되게** 한다. 닫는 조건 = 회귀 0(새 노브 `kAshSeed`=0 → 잔해 침착 미진입 → 0038 비트 동일 + 전 골든 해시 불변) + 잔해 가설 수치(off ΔR≈0 / on ΔR>0) + 닫힌 장부(연료=외부 질량을 R 로 들이며 E0 보정) + 결정론 + 척추 체크 4항.

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

**이 단계가 답한 질문** — 별이 죽으면 그냥 사라지고 끝일까, 아니면 그 잔해가 세계에 무언가를 남길까?

지난 단계까지의 별은 한살이가 이러했다: 땅바닥(높이 0)의 작은 돌무더기에서 불이 붙어 → 하늘 끝까지 떠오르고 → 연료가 줄면 도로 가라앉고 → 바닥에 닿으면 꺼진다. 그런데 꺼진 별은 *아무 자취도 없이* 사라졌다. 다음 별은 여전히 *맨 처음 우리가 놓아둔* 돌무더기에서만 다시 붙었다. 죽음이 세계에 아무것도 돌려주지 않은 것이다.

**무엇을 바꿨나** — 별이 바닥에서 꺼질 때, *다 못 태운 연료의 절반*을 그 자리에 **단단한 돌(저장체)** 로 가라앉게 했다. 별의 무덤에 작은 돌무더기가 새로 생기는 셈이다. 그 돌무더기는 곧 *다음 별이 붙을 새 씨앗*이 된다. 이로써 한살이가 완전히 한 바퀴 돈다: 나고 → 뜨고 → 지고 → 꺼지고 → **무덤에 씨앗을 남기고** → 그 씨앗에서 다음 별이 난다. 처음 우리가 놓아준 돌무더기에 더는 기대지 않는다 — 세계가 *제 죽은 별의 잔해로* 다음 별의 씨앗을 만든다.

이것은 단순히 보기 좋은 마무리가 아니라 척추(SPINE)가 일찍부터 요구한 **두 시간 척도의 분리**를 별의 한살이에 실현한 것이다: *죽음은 빠르고 되돌릴 수 없지만*(개체의 시간), *잔해는 느리게 다시 저장 물질로 돌아온다*(세계의 시간). 탄 나무는 못 되돌려도 그 탄소는 아주 느리게 흙으로 돌아오는 것과 같다.

**무엇을 발견했나** — 새 기능을 끄면(분율 0) 별은 예전처럼 흔적 없이 사라지고 세계의 저장 물질은 한 톨도 안 는다(증가 0). 켜면(절반) 별 한 번의 죽음마다 약 119 만큼의 저장 물질이 무덤에 쌓인다(다섯 시드 모두 똑같이). 그리고 이렇게 외부의 연료가 세계 안 물질로 바뀌어도 **에너지 장부는 완벽히 닫혀 있다**(오차가 사실상 0 — 소수점 16자리 아래). 들여온 만큼 세계의 기준선을 똑같이 올려 보정했기 때문이다.

**왜 중요한가** — "구동(별)조차 외부 주입이 아니라 세계 안에서 나고 진다"는 큰 목표가, 이제 *세대가 제 잔해로 다음 세대의 씨앗을 빚는* 닫힌 고리로 한 걸음 더 갔다. 죽음이 손실이 아니라 *재구성*이 된다.

**솔직한 한계** — "느린 풍화"를 *즉시* 침착으로 흉내 냈다(별이 꺼지는 순간 잔해가 바로 돌이 된다 — 진짜 느린 풍화 지연은 백로그). 또 격리 아레나(중력·결정화 끔)라 잔해 돌무더기가 *고이는 바다 → 결정화*의 전체 에너지 고리와 아직 직접 잇닿진 않았다 — 그 완전 폐합은 다음 칸.

## 2. 메커니즘 — `ignite` 잔해 침착 항 (노브 `kAshSeed`, LAW_ORDER 무변경)

0035~0038 과 같은 형식으로 `ignite` 법칙을 **제자리 확장**한다(새 법칙·LAW_ORDER 자리 추가 없음 — 별 일생의 한 항). 0038 의 일몰사 분기(떠올랐다[`st.rose`] 다시 지는[`dying`] 별이 z=0 닿음)에 한 줄을 얹는다:

```
if (setDeath !== 0 && st.rose && dying && st.z === 0) {        // 0038 일몰사
  if (ashSeed !== 0) { var grave = st.y*W + st.x, sd = ashSeed * st.fuel;   // ← 0039: 무덤(z=0)에 잔해 R
                       R[grave] += sd; sim.E0 += sd; sim.ashSeeded += sd; }
  if (fsm) { st.state = 2; ... } else sim.starDeaths++;        // 0038 그대로
  continue;
}
```

- **무덤 = z=0 평면 인덱스**(`st.y*W + st.x`) — siting(점화 후보 탐색, line 715)이 *2D z=0 평면만* 보는 자리와 정확히 일치 → 잔해 R 이 곧 다음 별의 점화 신호가 된다.
- **연료(F)는 외부 질량**(장부 lhs 밖 — `sumE + M + R + evap + sunk + metab − injected = E0` 에 안 듦, 0011/0038). R 로 들이면 lhs 가 늘어 장부가 깨지므로, **`sim.E0` 를 같은 만큼 올려** 보정한다(`seedSunCore`·source `harvest` 와 같은 *외부 유입* 패턴 — `sunk` 의 역). 비가역 死라도 보존(쌍 거래는 아니나 경계 유입+baseline 보정).
- **노브 `kAshSeed`=0 → `ashSeed`=0 → 침착 미진입** = 0038 비트 동일. 기본 0(DEFAULTS).
- **이중 가드**: ① `kAshSeed`=0 → 미진입(전 골든 시나리오 kAshSeed 미지정=0). ② D=1·rise off → 일몰사 자체가 미발생(`st.rose` 안 켜짐, 0038) → 잔해 침착 도달 못 함.

### 무엇을 *안* 바꿨나 (다음으로 전가)

- **느린 풍화 지연** — 잔해를 죽음 순간 *즉시* 침착(ASH_LINGER 같은 시간 지연 없이). 진짜 느린 timescale 풍화는 백로그.
- **전체 에너지 고리 폐합** — 잔해 R → (중력 바다 → 결정화) → 새 별의 *완전* self-running 폐합은 다음 칸(이번은 격리 아레나·중력/결정화 off).
- **생명·형태 z-활성화** — VOXEL.md 사다리 나머지.

### 척추 체크 4항

1. **단일 척추** ✅ — 새 필드 없음. 별의 연료(외부 질량)가 *기존* 저장체 필드 R 로 상전이할 뿐(병렬 전역 필드 0). 다양성은 R 의 분포에.
2. **활성도 환원** ✅ — authored type 분기 없음. 소산 극단(별)이 저장 극단(R)으로 *역할 전이*하는 활성도 축의 한 점(別 자료형 아님). 잔해는 활성도≈0 의 저장체.
3. **국소 문턱** ✅ — 잔해 침착은 *제 별의 로컬 상태*(st.rose·dying·st.z===0)만으로 판정. 전역 조율자 0. 무덤 위치도 제 (x,y).
4. **순환 장부** ✅ — 비가역 死라도 보존: 외부 연료 → R 유입 + E0 baseline 보정(잔차 8.6e-16). 죽음이 *순환 고리*(별→잔해→씨앗→별)의 한 거래로 명시됨.

## 4. 의외의 발견

- **잔해 ΔR 이 전 시드 정확히 동일(118.87)**. 격리 아레나에서 별의 궤적(점화→상승→하강→일몰사 타이밍)이 *시드 무관 결정론*이라(중력·생명·노이즈 0), 무덤에 남는 미연소 연료가 시드와 무관하게 같은 값으로 수렴한다. 죽음의 *타이밍*(연료 잔량)이 별 한살이의 결정론적 함수임을 잔해량이 드러낸다.
- **잔해 침착이 사망 횟수를 안 늘렸다**(off·on 모두 사망 1·200tick). 0038 의 세대 순환은 *처음 놓은* R 핵으로도 이미 돌고, 잔해는 거기에 *추가* 씨앗을 얹을 뿐 — 죽음 빈도를 안 바꾼다(직교성: 잔해는 동역학의 승객). 더 긴 런·중력 폐합에서 잔해 씨앗이 자급 세대를 늘리는지는 다음 칸.

## 5. 정직한 한계

- **즉시 침착 ≠ 느린 풍화**. SPINE 의 "느린 재구성"을 죽음 순간 즉시 R 침착으로 흉내 냈다. 진짜 timescale 분리(잔해가 ASH_LINGER 류 지연 뒤 서서히 R 로)는 백로그.
- **격리 아레나 — 전체 고리 미폐합**. 중력·결정화 off 라 잔해 R 이 *바다 → 결정화 → 새 별* 의 전체 에너지 고리와 아직 직접 잇닿지 않았다. 잔해는 z=0 무덤에 즉시 R 로 — 0037 의 바다(고인 E)와는 별도 경로. 완전 self-running 폐합은 다음 칸(STATE §2).
- **단일 별 starCap=1**. 다중 별의 무덤 잔해가 서로의 siting 을 어떻게 편향하는지(혈통 — SPINE "별=느슨한 혈통, 잔해가 다음 별 siting 편향")는 미검증.
