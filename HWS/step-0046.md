# step-0046 — 생명의 폐열: 생명이 고질을 먹고 저질 엔트로피를 배출한다(슈뢰딩거, SPINE 여섯째 축)

> 직전: [step-0045](step-0045.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md) 여섯째 축

## 검증 질문

step-0045 가 E 에 *질 축*(자유 E ↔ 열 E `Eth`)을 열었으나, 질은 아직 *측정 토대*였다 — 동역학에 안 먹였다(0045 정직한 한계 ②). 슈뢰딩거의 핵심은 *생명은 음엔트로피(자유에너지)를 먹고 엔트로피(폐열)를 환경에 배출하는 far-from-equilibrium 소산구조*라는 것. 생명은 *이미* 고질 자유 E 만 먹는다(흡수 `kL` 이 `sim.E`[자유 풀]서만 끌어옴 — `Eth` 는 못 먹음, 구조적). **그 짝 — 생명이 저질 폐열을 *배출*하는가 — 을 단일 척추·닫힌 장부 안에서 더할 수 있는가?** 닫는 조건: metabolize 제자리 확장 + 노브(kLifeHeat=0 → 회귀 0) · cost→Eth+metabolized 쌍 분배로 닫힌 장부 · 폐열 가설 수치 · 결정론 + 척추 4항.

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

**이 단계가 답한 질문**: 0045 에서 에너지에 "질"(뜨겁다/차갑다)을 줬다. 그런데 생명은 그 질과 어떻게 엮이나? 왜 생명은 끊임없이 먹어야 살까?

**무엇을 바꿨나**: 생명이 살아가며 쓰는 *대사 비용*(유지비)이 지금까진 *세계 밖으로 사라졌다*. 이제 그 일부가 *식어버린 저질 열*로 생명이 있는 자리에 *남는다*. 즉 생명은 신선한(질 높은) 에너지를 먹어 제 몸을 유지하고, 그 대가로 *식은 폐열을 환경에 내놓는다*.

**무엇을 발견했나**: 생명을 다섯 마리 놓고 돌리면, 폐열 배출을 *끄면* 식은 열이 전혀 안 생기고(전부 세계 밖으로), *켜면* 식은 열이 정확히 *생명이 앉은 자리*에 쌓인다(이 실험에서 약 0.77 만큼). 양은 한 톨도 안 사라진다 — 비용이 "세계 밖 소멸"과 "식은 열로 잔류"로 *나뉘기만* 한다.

**왜 중요한가**: 이것이 슈뢰딩거가 말한 생명의 본질이다 — *생명은 질서(낮은 엔트로피)를 먹고 무질서(열)를 배출해 제 질서를 유지한다*(소산구조). 0045 의 질 축이 비로소 *생명을 굴리는 동역학*에 연결됐다. 생명은 환경의 질을 *낮추며*(자유 E 를 먹고 폐열을 내며) 산다 — 멈추면(먹지 못하면) 식어 무너진다.

**솔직한 한계**: ① 폐열이 제자리에 고일 뿐 *퍼지지 않는다*(열 확산 없음 — 다음). ② 식은 열을 *되살리는 길이 없다*(누적 → 열사 위험 — 풍화식 재활용 짝 후속). ③ 생명이 *남이 버린 식은 열*은 아직 못 먹는다(여전히 자유 E 만).

## 2. 메커니즘 — `metabolize` 제자리 확장 + 노브 `kLifeHeat`(새 LAW_ORDER 자리 없음)

**한 조각**: `engine/hws-laws.js` `metabolize` 의 대사 손실 처리를 확장 + `DEFAULTS.kLifeHeat` 1개. 기존:

```
var cost = a.m·mMaint + baseCost ;  a.m -= cost ;  sim.metabolized += cost      // 전부 세계 밖 소멸
```

확장:

```
a.m -= cost ;
var heat = cost·kLifeHeat ;
if (heat > 0) { sim.Eth[a.center] += heat ; sim.qualInit = true ; }              // 폐열 — 저질 열로 제자리 잔류
sim.metabolized += cost − heat ;                                                  // 나머지는 종전대로 세계 밖
```

- **슈뢰딩거 소산구조**: 흡수(`kL`)는 *자유 E(고질)만* 먹는다(`sim.E` 풀 — `Eth` 못 먹음, 구조적으로 이미 그러함). 이 step 은 *배출* 짝을 더한다 — 대사 폐열을 저질 `Eth` 로. 생명 = 고질 섭취 + 저질 배출 = far-from-equilibrium 질 엔진.
- **단일 척추**: `Eth` 는 0045 의 E 질-상태(병렬 필드 아님). 생명은 새 자료형이 아니라 *그 질 축에 들고 나는* 패턴.
- **장부**: `cost` 가 `heat`(→Eth) + `(cost−heat)`(→metabolized)로 *쌍 분배* — 둘 다 lhs(0045 가 sumEth 가법) → 보존. `kLifeHeat=0` → heat 0 → `metabolized += cost`(직전 step 비트 동일).
- **회귀 0**: kLifeHeat=0 → heat 0·Eth 무변경·qualInit 미설정 → hashState Eth feed skip → 골든 비트 불변.
- **0045 와 독립**: kQual(자발 강등)=0 이라도 생명이 Eth 를 낸다(폐열은 별개 출처). 둘 다 Eth 의 출처.

### 무엇을 *안* 바꿨나 (다음으로 전가)

- **열 확산(advection)**: 폐열이 제자리에 고임(안 퍼짐).
- **열 재활용**(Eth→E): 누적 → 열사 위험(0041 풍화의 질-판).
- **생명의 Eth 섭취**: 생명이 *남의* 폐열을 못 씀(여전히 자유 E 만) — "저질도 일부 회수"는 후속.

## 4. 의외의 발견

**모든 시드가 동일 수치**(폐열 0.77 등). 아레나가 정적(noise=0·이동/번식 off·확산 off)이라 의사난수 자리가 없다 — 생명의 폐열은 *결정론적 대사 산술*이다. 또: 폐열이 *정확히* 생명 자리에만 쌓인다(ethAtLife = totalEth) — 확산이 없으니 생명은 *제 발밑을 식힌다*. 흥미롭게도 이는 후속 "생명이 제 폐열에 갇힐 수 있다"(자기 오염)는 동역학의 씨앗 — 열 확산·이동이 그걸 푼다.

## 5. 정직한 한계

- **열 확산 없음**: 폐열이 제자리 고임 → 생명이 제 발밑을 식혀 자기 오염 가능(이동/확산이 풀어야). advection 후속.
- **열 재활용 없음**: Eth 누적 → 열사(0040 R 래칫의 질-판). 풍화식 재활용 짝 후속.
- **저질 미섭취**: 생명이 남의 Eth 를 못 먹는다(여전히 자유 E 만). 부분 회수는 후속.
