# step-0013 — 별 연소 FSM: living→burning→ash, 문턱에서 *딱* 뒤집힌다 — 이산 비가역 문턱(SPINE 결정3) 완성

> [step-0012로](step-0012.md) · 실행물: [step-0013.html](step-0013.html)(3D 표준 셸) · 시뮬 로직: `engine/hws-laws.js` 의 **`combust` 법칙 1개** + `ignite` 의 ash 처리(law-pipeline — sim-core.js 복사 없음) · 헤드리스: `step-0013/verify.js` · 엔진 재현: `node engine/validate/verify-sim-engine.js`

step-0012 가 동역학의 세 실패(동결·공멸·임계)를 닫아 **끝없는 churn 을 완성**했다(G2/G3 동역학적 종결). 이제 남은 큰 축은 *존재론* — 척추 결정3(이산 비가역 문턱)이 아직 *연속 노브*였다(kCryst·kIgnite·kCrowd 모두 graded). step-0013 은 그 마지막 조각, **별의 연소를 진짜 이산 FSM 으로** 만든다. 별의 alive→dead proto-FSM(점화→소진) **가운데 burning 을 끼워** 3-상태 FSM 을 완성한다: **living**(갓 점화 kindling — 저활성·정지) →[핫코어 ≥ burnOn]→ **burning**(전율·서행) →[연료 소진 *또는* 핫코어 < burnOff]→ **ash**(주입 0·불응기·제거). 전이는 *문턱에서 딱 뒤집히고*(연속 변조 아님) *비가역*이다(되돌아가지 않음).

이것은 **law-pipeline 의 셋째 step** 이다 — 더한 시뮬 로직은 `engine/hws-laws.js` 의 `combust` 법칙 1개(⑤b ignite 앞) + 노브 4개(`kFSM`·`livingFrac`·`burnOn`·`burnOff`) + ignite 의 ash 분기(fuel→ash, 불응기 머묾) + 상태 라벨의 *가법* 해시. 회귀는 동결 *해시*로 잠근다 — 이 step 은 회귀 앵커를 *가법 확장*해 별+생명+자기제한 스택(step-0012)까지 골든 잠금에 넣었다(`golden-sim.json` 의 `cwd@` 키 신규). `kFSM=0` → step-0012 비트 불변.

결과: **① 이산 전이가 작동한다** — 별이 living→burning→ash 를 *계단*으로 밟고(LBA 3상태 모두 도달), 역전이가 한 번도 없다(back=0, 비가역). **② 활성도로 환원된다** — 상태 라벨이 *전 tick·전 별* 활성도 배수와 1:1(labelViol=0), 측정 throughput 비 living/burning = **0.550 = livingFrac**(라벨이 측정 dE/dt 로 읽힌다, 자유 태그 아님). **③ 히스테리시스로 안 떨린다** — 폭 burnOn−burnOff = **0.20 > 0**, timescale 분리(빠른 점화 snap·느린 연료 소진)에서 이산성 창발. **④ 회귀 0·닫힌 장부·결정론 유지** — kFSM=0 시 step-0012 비트 동일(cwd@), 잔차 4.48e-13, 해시 일치(상태 라벨 가법). **⑤ 동역학 보존** — 이산 FSM 이 step-0012 의 끝없는 churn 을 깨지 않는다(전 시드 40k 생존, 후반 출생/사망 1355/1360 ≈균형).

## 2. 메커니즘 — 연소(combust): living→burning→ash, 빠른 점화 snap + 느린 연료 소진(FitzHugh–Nagumo 구조)

법칙 순서에 ⑤c(연소)를 ⑤b ignite 앞에 끼운다(이번 tick 주입 전에 상태를 정해 burnMul 을 ignite 가 읽는다 — 이전 tick 잔열 기준). 별은 `state ∈ {0 living, 1 burning, 2 ash}` 속성과 활성도 배수 `burnMul ∈ {livingFrac, 1, 0}` 을 갖는다. kFSM≠0 일 때:

```js
// ⑤c combust — 핫코어 = 별 disc 평균 E(자기 throughput 의 잔열)
hot = mean(E over star.cells);
if (state===0 /*living*/ && hot >= burnOn)  { state=1; burnMul=1; }      // SNAP 점화(빠른 변수·상문턱)
if (state===1 /*burning*/ && hot <  burnOff) { state=2; burnMul=0; }      // SNAP 조기 quench(하문턱<상)
// ⑤b ignite — 주입율 = starRate·burnMul (living=×0.55, burning=×1, ash=0)
//   연료 소진(fuel<=1e-9)이면 burning→ash(느린 변수, 보통 경로) → 불응기 ASH_LINGER tick 머물다 제거.
//   burning 만 서행(채식지 떠돎), living(kindling)은 정지해 핫코어를 제자리에 쌓는다.
```

네 설계 결정이 이 FSM 을 *건전하게*(SPINE 결정2↔결정3 정합) 만든다:

1. **라벨이지 타입 아님(결정2 정합 a)** — 상태별로 *다른 에너지 경로*를 분기하지 않는다. 켜지는 국소 법칙은 단 둘 — *주입 배수*(burnMul 스칼라)와 *서행 게이트*(burning 만)뿐이다(결정4 국소 반응법칙). `verify fsm` 이 *전 tick·전 별* 라벨 == 활성도 배수 인덱스([livingFrac,1,0])임을 **labelViol=0** 으로 증명한다 — 별도 `if(type=='burning')` 분기 없음. `reg`(maxDiff=0)이 kFSM=0 단일 경로를 보장한다.
2. **활성도로 환원 가능(결정2 정합 b)** — burning/ash 판정은 *그 별의 throughput(주입 dE/dt)* 으로 읽힌다. 측정 throughput(연료 소비율) 비 **living/burning = 0.550 = livingFrac**(전 시드) — 라벨은 *측정의 편의 표기*지 진실의 출처가 아니다. 핫코어(disc 평균 E)도 그 칸의 E 만으로 읽는 국소량이다.
3. **이산성은 timescale·문턱 분리에서 창발(결정2 정합 c)** — 점화는 *빠른 변수*(핫코어 E ≥ burnOn 에서 snap), 소진은 *느린 변수*(연료 고갈) 주도. 두 문턱을 벌려(burnOn 0.6 > burnOff 0.4, **폭 0.20**) 그 사이 밴드에선 latch — living↔burning 깜빡임이 없다(anti-chatter). FitzHugh–Nagumo 흥분성 매질/이완 진동의 게임화다.
4. **순환 장부(결정4·비가역≠비보존)** — state 는 *거래 0*(별 위치·연료처럼 상태일 뿐). 주입은 step-0011 의 fuel→E 외부 질량 경계 그대로(injected 추적). 비가역(living→burning→ash, 되돌림 없음)이라도 닫힌 장부는 그대로 닫힌다 — 잔차 4.48e-13. 세계 척도 순환: ash 가 비운 자리에 R 이 다시 누적→새 별 siting(느린 재구성). 개체 척도는 비가역, 세계 척도는 순환(SPINE "비가역인데 순환").

### siting(ignThresh) ≠ flashover(burnOn) — 두 층의 문턱

별의 문턱이 이제 *두 층*이다: **siting**(R 누적 핵에서 별이 *선다* — ignThresh, step-0011)과 **flashover**(선 별이 *전율 연소로 뒤집힌다* — burnOn, step-0013). 전자는 *어디에 별이 생기나*(R 공간), 후자는 *그 별이 언제 본격 연소하나*(E 잔열). living(kindling)은 siting 됐으나 아직 flashover 전 — 저활성으로 핫코어를 달구는 잠복기다.

## 척추 체크 4항 (SPINE.md)

1. **단일 척추 ✅** — FSM 은 병렬 전역 필드가 아니라 구동(별, 활성도 축 소산 극단)의 *국소 상태 속성*(Fragment). 필드는 여전히 E(+상태 R). 핫코어는 별 disc 의 E 를 *읽는* 국소량이지 새 필드가 아니다.
2. **활성도 환원 ✅** — burning/living/ash 는 authored type 분기 없이 *활성도 배수(주입 throughput)* 로 환원된다(labelViol=0, throughput 비=livingFrac). 라벨은 연속 활성도 축 위 측정의 편의 표기.
3. **국소 문턱 ✅** — 점화·소진 판정은 *그 별의 disc 평균 E + 제 연료*만으로(전역 조율자 0). siting(R 핵)·flashover(E 잔열) 둘 다 로컬.
4. **순환 장부 ✅** — state 는 거래 0(주입은 fuel→E 외부 질량 경계 불변, 잔차 4.48e-13). 비가역(living→burning→ash)이라도 보존. 세계 척도 순환: ash 빈 자리 → R 재누적 → 새 별 siting(느린 재구성, SPINE "비가역인데 순환").

## 5. 화면에서 직접 확인하는 법

[step-0013.html](step-0013.html) 을 연다 — 3D 표준 셸. 외부 source off, 자기제한 on, 연소 FSM on:

- **이산 전이가 눈에 보인다**: "별 씨앗 ×6" + "생명 ×5" 를 놓고 보라. 갓 점화한 별은 **어둑한 주황(living kindling)** 으로 *제자리에서* 달궈지다가 핫코어가 burnOn 을 넘으면 **밝은 백황(burning)** 으로 *딱* 뒤집혀 서행하고, 연료가 다하거나 심하게 잠식되면 **잿빛(ash ember)** 으로 꺼져 잠시 머물다 사라진다. 색이 *연속 변조*가 아니라 *계단*으로 바뀜에 주목 — 별 living/burning/ash 카운터가 끝없이 돈다.
- **히스테리시스를 만져 본다**: "점화 burnOn" 을 낮추면 living 이 더 쉽게 burning 으로 뒤집히고, "소진 burnOff" 를 높이면 burning 이 더 자주 조기 ash 가 된다. 둘을 가깝게 붙이면(폭→0) 경계에서 깜빡임이 늘어남(anti-chatter 붕괴)을 본다.
- **FSM 을 끄면 step-0012**: "연소 FSM(별)" 체크를 끄거나 kFSM 을 0 으로 내리면 중간 burning 없이 *점화→full rate→소진* 으로 돌아간다(별이 모두 같은 백황, 계단 전이 사라짐).

## 6. 의외의 발견

1. **자기제한 사이트는 quench 를 거의 안 한다 — 불은 연료가 다해야 꺼진다.** 핫코어 quench(burnOff)를 조기 소진 경로로 넣었지만, *스스로 선택된* burning 별은 전율 주입으로 제 핫코어를 계속 달궈 burnOff 밑으로 잘 안 떨어진다(ash 핫코어 ~4 vs ash 연료 ~360). 즉 소진은 압도적으로 *느린 변수*(연료)가 끈다 — burnOff 는 *심하게 잠식된* 소수만 조기에 끈다. 이게 바로 FitzHugh–Nagumo 의 핵심: 빠른 변수(점화)는 snap, 느린 변수(연료/회복)가 사이클을 끈다.
2. **living 을 *정지*시킨 게 flashover 를 보장했다.** kindling 이 burning 처럼 떠돌면 저활성 주입이 흩어져 핫코어가 burnOn 까지 못 찬다(초기 튜닝에서 living→burning 거의 0). living 을 *정지*시켜 제자리에 잔열을 쌓게 하자 비로소 flashpoint 에 도달했다 — "달구려면 멈춰 있어야 한다."
3. **문턱이 두 층으로 갈라졌다(siting ≠ flashover).** step-0011 의 단일 점화 문턱(R>ignThresh)이 이제 *어디에 별이 서나*(siting, R 공간)와 *언제 본격 연소하나*(flashover, E 잔열)의 두 층이 됐다 — 별도로 설계하지 않았는데 FSM 을 끼우자 자연히 분리됐다. 활성도 축 위에서 "존재"와 "활성"이 다른 문턱임이 드러난 셈.

## 7. 정직한 한계

1. **조기 quench(burnOff)가 거의 load-bearing 하지 않다.** ash 의 ~99%가 연료 소진, ~1%만 핫코어 quench다(§6.1). burnOff 는 히스테리시스 폭(anti-chatter)을 정의하는 데는 필수지만 *소진 경로*로는 미미하다 — 더 빈번한 조기 quench(예: 생명이 밀집 채식해 핫코어를 끄는 동역학)는 다른 grazing 파라미터나 밀도 의존 흡수가 필요할 수 있다. 단일 메커니즘만 검증.
2. **생명·결정화의 문턱은 여전히 graded.** 이 step 은 *별*만 이산 FSM 으로 만들었다 — 생명(자기제한 kCrowd)·결정화(kCryst E↔R)는 아직 연속/가역이다. SPINE 결정3 을 *전 개체*로 확장하려면 생명의 living/dormant·결정의 solid/melt 같은 FSM 이 후속(백로그). "별 FSM 완성"은 결정3 의 *대표 사례*지 전수는 아니다.
3. **ASH_LINGER 는 고정 상수(노브 아님).** ash 불응기 20 tick 은 헤더 상수로 박았다 — 흥분성 매질의 refractory 기간을 튜닝 가능 노브로 노출하지 않았다(노브 폭증 억제). 불응기 길이가 별 재점화 간격(siting 밀도)에 주는 영향은 미탐사.
4. **flashover timescale(잠복기)은 짧다.** living→burning 까지 보통 수~수십 tick(핫코어가 빨리 참). 더 긴 kindling 잠복(연료를 천천히 모으는 별)은 livingFrac↓ 나 burnOn↑ 로 줄 수 있으나 flashover 도달률과 trade-off — 지속 안정대 안에서만 튜닝.
5. **종간 경쟁·등방성 stencil·저장체 촉매 이월** — step-0011/0010 백로그 그대로.
