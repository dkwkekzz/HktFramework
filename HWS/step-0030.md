# step-0030 — 6-이웃 확산: 흐름 stencil 에 z 항을 더해 상위 평면이 살아난다 (VOXEL.md V2)

> 한 줄: V1(step-0029)은 터를 **W×H×D voxel** 로 일반화했으나 법칙이 z=0 평면만 처리해 *상위 평면이 불활성*이었다(초기 noise 만 보존). step-0030 은 사다리의 **둘째 칸(V2) = 6-이웃 확산**이다: `diffuse` 의 선형 확산 stencil 을 z=0 평면에서 **W×H×D 상자 전체**로 일반화하고 **z 항**(상하 이웃)을 더한다 — 4-이웃→6-이웃. 그러면 z=0 평면의 E 가 **z 로 퍼져 상위 평면이 비로소 산다**. 새 노브 `kDz`(z 확산 계수)가 z 결합을 켠다: **kDz=0 또는 D=1 이면 z 항이 산술로 0 = 직전 step 비트 동일**(회귀 0), **kDz=kD 면 등방**(x·y·z 동일 계수). z 항의 상하 쌍 거래가 cancel 되어 **닫힌 장부 유지**.

---

## 검증 질문 (본 thesis: V1 은 *그릇*만 키웠다 — 상위 평면은 죽어 있다. 진짜 3D 세계[바다·지면]가 서려면 먼저 *에너지가 z 로 흐를* 수 있어야 한다. 그 첫 흐름 = z 확산. 단 D=1 에서 비트 동일·D>1 에서 등방·보존을 지켜야 한다. VOXEL.md V2, STATE §2 🔴 최우선)

핵심 가설 한 줄: **확산 stencil 을 6-이웃으로 일반화하되 D=1 또는 kDz=0 에서 직전 step 과 비트 동일하고, D>1·kDz=kD 에서 z 확산이 *등방*(z-이웃 ≡ x-이웃)이며 z=0 평면의 E 가 상위 평면으로 퍼지고(상위 평면이 살아남), 결정론·닫힌 장부를 유지한다.**

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

**이 단계가 답한 질문** — 지난 단계(V1)에서 세계의 그릇을 납작한 바둑판에서 *벽돌을 쌓은 상자*로 키웠다. 그런데 거기까지였다 — 에너지는 여전히 *맨 아래 층*에서만 퍼지고, 위층은 처음 모습 그대로 *얼어붙어* 있었다(불활성). 위로 바다가 고이고 아래로 지면이 쌓이는 진짜 3차원 세계가 서려면, 먼저 **에너지가 위아래 층 사이를 흐를 수 있어야** 한다. 이 단계의 질문: **에너지가 z(높이) 방향으로도 퍼지게 하되, 지난 29단계의 검증을 하나도 깨지 않을 수 있을까?**

**무엇을 바꿨나** — 에너지가 퍼지는 규칙(확산)을 *6방향*으로 넓혔다. 예전엔 한 칸의 에너지가 *동·서·남·북 네 이웃*으로만 번졌다(납작한 판이니까). 이제 *위·아래 두 이웃*을 더해 *여섯 이웃*으로 번지게 했다. 새 손잡이 하나 — *위아래 확산 세기(kDz)* — 를 더했다. 이 손잡이를 0 으로 두면 위아래로 안 번져 예전(V1)과 똑같고, 가로세로 확산 세기와 *같게* 두면 *모든 방향으로 똑같이*(등방) 번진다. 핵심 안전장치: 층이 하나(깊이 1)뿐이면 위아래 이웃이 *아예 없으므로* 새 항이 저절로 0 이 된다 — 그래서 예전 검증이 한 비트도 안 변한다.

**무엇을 발견했나** — 세 가지를 수치로 확인했다. ① **위층이 살아났다**: 맨 아래 층 한 점에 에너지를 부어 놓고 돌리면, 위아래 확산을 끄면(kDz=0) 에너지가 *위층에 한 톨도 안 올라가지만*(0%), 켜면(kDz=0.15) **87% 가 위층으로 올라가** 천장까지 닿는다. 손잡이 하나가 위층을 깨운다. ② **퍼짐이 등방이다**: 가운데 층 한 점에 에너지를 부으면, 옆으로 번진 양과 위로 번진 양이 *완전히 똑같다 — 단 하나의 비트도 안 다르다*(가로·세로·높이 세기를 같게 뒀으니 당연하지만, 코드가 그걸 정확히 지킨다는 증거). ③ **에너지 장부가 그대로 닫힌다**(오차 사실상 0 — 1000조분의 3) — 위아래로 주고받는 양이 정확히 짝을 이뤄 상쇄되기 때문이다. 그리고 ④ *지난 29단계의 모든 검증 수치(골든 해시)가 단 하나도 안 변했다*.

**왜 중요한가** — 3D 세계의 *첫 흐름*이다. 에너지가 이제 위아래로 흐를 수 있으니, 다음 단계들은 그 흐름에 *방향*을 줄 수 있다: 에너지가 *아래로* 모이게 하면 골짜기에 **바다**가 고이고(V3, 중력), 물질이 *바닥부터* 쌓이게 하면 **지면**이 선다(V4, 지지 침착). 무엇보다 차원을 키우는 큰 변화에서도 *법칙 하나(확산)에 항 하나(z)만 더하고 + 회귀 0* 이라는 이 프로젝트의 작업 방식이 그대로 통한다는 걸 다시 보였다 — 손잡이를 0 으로 두면 어제의 세계, 켜면 한 칸 더 나아간 세계.

**솔직한 한계** — ① 위아래 확산은 *방향이 없다*(등방) — 에너지가 위로도 아래로도 똑같이 번진다. *아래로 모이는* 중력은 아직 없다(V3). 그래서 *지금은* 바다가 고이지 않는다 — 에너지가 3D 상자를 고루 채울 뿐이다. ② 다른 법칙들(증발·결정화·생명·별)은 여전히 *맨 아래 층에서만* 돈다 — 이번엔 *확산 하나만* 3D 로 키웠다(한 번에 한 조각). 위층은 확산으로 에너지를 받지만 거기서 굳거나 생명이 살진 않는다(V5+). ③ 기복(퇴적이 흐름을 휘는 옛 지형 항)은 여전히 맨 아래 층 전용이다 — 3D 수직 수송은 V3 중력이 맡는다. ④ 화면(3D 뷰)도 아직 맨 아래 층 하이트필드만 그린다 — 벽돌 렌더는 렌더러 트랙(L-V1)의 일이다. ⑤ 6방향 확산은 4방향보다 *안정 한계가 빡빡하다*(가로세로·위아래 세기 합이 너무 크면 발산) — 등방으로 쓰려면 각 세기를 0.166 이하로 둔다(실험장은 0.15 로 맞췄다).

## 2. 메커니즘 — `diffuse` 의 6-이웃 일반화 (D=1·kDz=0 에서 비트 동일)

이 step 은 `engine/hws-laws.js` 의 `DEFAULTS`(노브 `kDz` 가법)와 `diffuse` 의 *선형 확산 경로*(`kRelief=0`)만 수정한다. 기복 경로(`kRelief≠0`)·다른 법칙은 무수정.

### (1) `DEFAULTS.kDz = 0` — z 확산 계수

상하 이웃(z±1)으로의 확산 세기. 0 = off = 직전 step(V1) 비트 동일. D=1 이면 z 이웃이 없어 *kDz 값과 무관하게* z 항이 산술로 0(이중 가드). kDz=kD 면 등방. 안정 조건(6-이웃 명시적 오일러): 4·kD + 2·kDz ≤ 1(등방이면 6·kD ≤ 1 → kD ≤ 0.166).

### (2) `diffuse` 선형 경로: z=0 평면 → W×H×D 상자 + z 항

기존 simple 경로는 `for y, for x` 로 *z=0 평면만*(N=W·H) 4-이웃 확산했다. 이제 바깥에 `for z (0..D)` 를 감싸고, 절대 인덱스 `i = z·W·H + y·W + x` 로 *모든 평면*을 같은 스킴(simultaneous buffer-update)으로 확산한다. 각 셀에 **z 항**을 더한다:

```
B[i] = E[i] + kD·(eN+eS+eW+eE − 4·E[i])          // 기존 x·y 4-이웃(평면별)
       + (kDz≠0 일 때) kDz·( [z+1<D] (E[i+WH]−E[i]) + [z>0] (E[i−WH]−E[i]) )   // 새 z 항(상하 이웃, 벽 클램프)
```

- **D=1 에서 비트 동일**: z=0 한 평면, 상하 이웃이 둘 다 없어 z 항 = 0. `B[i] = E[i] + kD·(…) + 0` 는 기존 식과 *비트 동일*(IEEE 754 `x+0.0 = x`). 골든 해시 전 시나리오(전부 D=1) 불변.
- **z 응집**: `kA≠0` 면 농도 창 응집에도 같은 정신으로 상하 이웃 항을 더한다(대칭 커널 `aggK(min)` → 상하 쌍 거래 cancel → 보존).
- **보존**: z 확산·z 응집 모두 셀↔셀 쌍 거래(상 셀이 −, 하 셀이 + 로 정확히 상쇄). z 벽(바닥 z=0·천장 z=D−1, flux 0)으로 장부 자동 닫힘.
- **등방**: 모든 평면이 *같은 수치 스킴*. kDz=kD 면 x·y·z 가 동일 계수 → 점 주입의 확산 프로파일이 구면 대칭(z-이웃 ≡ x-이웃, 비트 단위).

### (3) 무엇을 *안* 바꿨나 (V3+ 로 전가)

- 기복 경로(`kRelief≠0`)는 z=0 평면 전용 유지 — 3D 수직 수송은 V3 중력이 맡는다(donor-제한 하향 선호).
- 증발·결정화·구동·생명 등 다른 법칙은 N=W·H(z=0 평면) 유지 — V2 는 *확산 하나*만 3D 로(한 조각). 상위 평면은 확산으로 E 를 받되 거기서 굳거나(결정화 V4) 생명이 살진(V5+) 않는다.

## 4. 의외의 발견

- **등방이 *비트 단위로* 정확하다(상대오차 0)** — kDz=kD 일 때 점 주입의 x-이웃과 z-이웃이 단지 "근사적으로 같다"가 아니라 *단 하나의 비트도 안 다르다*. simultaneous buffer-update 스킴이 x·y·z 를 *대칭적으로* 같은 식에 넣기 때문 — 경계(z 벽·x·y 토러스)가 닿기 전까지 확산 프로파일이 완전한 구면 대칭. "모든 평면 같은 스킴"(별도 z-법칙으로 안 쪼갬)의 정합성이 *수치로* 보상된다.
- **상위 평면이 *한 점*에서 87%까지 차오른다** — z=0 평면 단일 셀 주입이 200 tick 만에 8층 상자의 상위 7층에 87% 를 채운다(천장까지 12%). z 결합 하나가 "그릇만 키운"(V1) 죽은 위층을 *완전히* 깨운다 — 불활성→활성의 전환이 노브 하나로 깔끔히 갈린다(kDz=0 이면 0%, 정확히).

## 5. 정직한 한계

1. **등방 = 방향 없음(중력 부재)** — z 확산은 위아래로 *똑같이* 번진다. *아래로 모이는* 중력(donor-제한 하향 선호)은 V3 의 몫 — 그 전엔 바다가 안 고인다(E 가 상자를 고루 채울 뿐). V2 는 "z 로 흐를 수 있음"이지 "z 로 고임"이 아니다.
2. **확산만 3D — 다른 법칙은 z=0 평면** — 증발·결정화·생명·별·기복은 여전히 z=0 평면 전용(한 조각 원칙). 상위 평면은 확산으로 E 를 받되 거기서 굳거나(결정화 V4) 생명이 살진(V5+) 않는다. 그래서 *전체 스택*에서 D>1 의 풍부한 3D 동역학은 아직 — V3~V5 가 채운다.
3. **기복 경로 2D 유지** — `kRelief≠0`(퇴적이 흐름을 휘는 옛 지형 항)은 z=0 평면 전용. D>1 + kRelief 시나리오는 상위 평면 기복 미처리(verify 아레나는 kRelief=0). 3D 수직 수송은 V3 중력으로 통일 — 기복은 그때 재검토/대체.
4. **렌더 미전환** — 3D 뷰는 아직 z=0 평면 하이트필드. voxel 렌더(R 점유 큐브 + E=밝기)는 렌더러 트랙 L-V1.
5. **성능·안정** — 확산이 N=W·H·D 전 셀을 순회 → tick 비용 ∝ D(V1 의 z=0 평면 순회보다 D배). 6-이웃 안정 한계(4·kD+2·kDz ≤ 1)가 4-이웃(kD ≤ 0.25)보다 빡빡 — 등방이면 kD ≤ 0.166. 희소 순회 최적화(수치 불변)·낮은 D·전용 아레나로 흡수. G1 timescale 다운스트림.
