# step-0032 — 지지 침착: E→R 침착을 지지 있는 칸으로 게이트 → 지면이 바닥부터 쌓인다 (VOXEL.md V4)

> 한 줄: V3(step-0031)의 중력으로 *E* 는 바닥에 고인다(바다) — 그러나 *물질 R* 은 아직 공중에 떠 굳을 수 있다(결정화가 z 평면 무관 침착). step-0032 는 사다리의 **넷째 칸(V4) = 지지 침착**이다: `crystallize` 의 E→R 침착에 **지지 게이트**를 더한다(법칙 신설 아닌 게이트 노브 1개 + 문턱 1개). 마스터 `kSupport` 를 켜면 결정화가 W×H×D 전 평면으로 일반화되되 **지지 있는 칸**(z=0 바닥 = 항상 지지, 또는 바로 아래 칸 R≥`supportThresh` — 로컬 z−1 한 칸)에서만 굳는다. 그러면 **공중에 뜬 바위(부유 R)가 안 생기고 지면이 바닥부터 쌓인다**. V3 중력이 바닥에 모은 E 가 굳어 — *R 의 중력(지면)* 을 *E 의 중력(바다, V3)* 과 짝짓는다. **kSupport=0 또는 D=1 이면 게이트 무효(z=0 평면) = 직전 step 비트 동일**(회귀 0).

## 검증 질문 (본 thesis: V3 는 *E* 를 바닥에 고였으나[바다] *R* 은 아직 어디서든 굳는다 — 진짜 지면이 서려면 침착이 *지지*를 존중해야 한다[공중에 바위가 뜰 수 없다]. 그 게이트 = 지지 침착. 단 D=1·kSupport=0 에서 비트 동일·D>1 에서 부유 R 0·바닥부터 쌓임·보존을 지켜야 한다. VOXEL.md V4, STATE §2 🔴 최우선)

핵심 가설 한 줄: **결정화에 지지 게이트를 더하되 D=1 또는 kSupport=0 에서 직전 step 과 비트 동일하고, D>1·kSupport>0 에서 침착이 지지 있는 칸에서만 일어나(부유 R=0) 지면이 바닥(z=0)부터 쌓이며, 결정론·닫힌 장부를 유지한다.**

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

**이 단계가 답한 질문** — 지난 단계(V3)에서 에너지에 중력을 줘 바닥에 고이게 했다(바다). 그런데 *물질*(굳은 바위·흙)은 아직 *어디서든* 생길 수 있었다 — 공중에 에너지가 있으면 거기서 그냥 굳어 *허공에 뜬 바위*가 된다. 진짜 땅은 그렇지 않다 — 바위는 *받쳐 주는 것 위에만* 쌓인다(바닥, 또는 이미 쌓인 바위 위). 이 단계의 질문: **물질이 굳는 규칙에 "받침이 있어야 굳는다"는 조건을 주되, 지난 31단계의 검증을 하나도 깨지 않을 수 있을까?**

**무엇을 바꿨나** — 새 법칙을 만들지 않았다. 이미 있던 *굳기 규칙*(결정화 — 에너지가 진해지면 물질로 굳음)에 **받침 검사**를 한 줄 더했다. 손잡이 하나(*지지 침착 켜기*)를 켜면: 한 칸이 굳으려 할 때, 그 칸이 **맨 아래층**이거나(바닥은 늘 받침) **바로 아래 칸에 이미 물질이 충분히 있으면**(받쳐 줌)만 굳는다. 받침이 없으면(아래가 텅 빔) 굳지 못하고 기다린다. 손잡이를 끄면 예전처럼 맨 아래층에서만 굳어(2차원) 지난 단계와 똑같다. 깊이가 하나뿐이어도 맨 아래층은 항상 바닥(받침)이라 검사를 그냥 통과 — 그래서 예전 검증이 한 비트도 안 변한다.

**무엇을 발견했나** — 천장(맨 위층)에 에너지 한 판을 부어 놓고 중력으로 떨어뜨리며 굳기를 켰다. 두 경우를 비교했다. ① **받침 검사를 끄면**(무게이트): 에너지가 *떨어지는 도중 허공에서 굳어* — **공중에 뜬 바위가 12,288칸**(세 개 층 분량) 생긴다. 받쳐 주는 것 없이 허공에 떠 있는 바위다. ② **받침 검사를 켜면**(게이트): 에너지가 *바닥까지 다 떨어진 뒤에야* 굳어 — **공중 바위가 한 칸도 없다**(0칸). 물질이 *맨 아래층(바닥)에서부터* 쌓인다(가장 낮은 물질층 = 바닥). 땅이 밑에서부터 차오른다 = **지면의 원형**. 그리고 ③ **에너지 장부가 그대로 닫힌다**(오차 1000조분의 1) — 받침 검사는 *어디서 굳을지*만 거를 뿐 양을 만들거나 없애지 않으니까. ④ *지난 31단계의 모든 검증 수치가 단 하나도 안 변했다*.

**왜 중요한가** — V3 의 *바다*(에너지가 바닥에 고임)와 V4 의 *지면*(물질이 바닥부터 쌓임)이 합쳐져, 비로소 **지면과 바다가 스스로 고이는 최소 3차원 세계**가 섰다. 둘 다 *그려 넣은 게 아니라* 같은 단일 에너지에서 중력 하나로 *창발*한다(바다 = 에너지의 중력, 지면 = 물질의 중력). 무엇보다 큰 변화에서도 "기존 규칙에 게이트 한 줄 + 손잡이 하나 + 회귀 0" 이라는 작업 방식이 또 통했다 — 손잡이를 끄면 어제의 세계, 켜면 한 칸 더 나아간 세계.

**솔직한 한계** — ① *차폐가 없다* — 아래 칸이 바위로 막혀 있으면 에너지가 옆으로 우회해야 하는데, 지금 중력은 그냥 통과한다(순수 에너지 하향). "막히면 옆으로"는 옆 확산(V2)이 일부 맡지만, 바위가 에너지를 *실제로 가로막는* 차폐는 V5+ 의 일이다. ② *이미 굳은 바위는 안 떨어진다* — 받침이 사라져도(아래가 풍화로 비어도) 위 바위는 그대로 떠 있다. *부유 R 붕괴*(받침 잃은 바위가 낙하)는 V5+. ③ *굳기 규칙 하나만 게이트* — 결정화만 지지를 본다. 다른 물질 형성(튜링 반점·덴드라이트 가지 등)은 아직 맨 아래층 전용이라 받침 검사를 안 받는다(한 번에 한 조각). ④ 화면(3D 뷰)도 아직 맨 아래층만 그린다 — 벽돌 렌더는 렌더러 트랙(L-V1). ⑤ 받침 검사는 *바로 아래 한 칸*만 본다(국소) — 비스듬한 받침(대각선 지지)·아치 같은 구조는 못 만든다(그건 의도된 단순화 — 전역 지형맵 같은 조율자를 두지 않으려는 척추 원칙).

## 2. 메커니즘 — `crystallize` 의 지지 게이트 (D=1·kSupport=0 에서 비트 동일)

이 step 은 `engine/hws-laws.js` 에 노브 `kSupport`·`supportThresh`(가법)와 `crystallize` 의 침착 분기만 수정한다. 풍화·다른 법칙은 무수정.

### (1) `kSupport = 0`(마스터)·`supportThresh = 0.5`(문턱)

`kSupport` 0 = off(z=0 평면 결정화 = step-0031 비트 동일). 1 = on(전 평면 + 지지 게이트). `supportThresh` = z>0 셀이 굳으려면 바로 아래 칸 R 이 넘어야 할 값. =0 이면 무게이트(아래 R≥0 항상 참 = 모든 칸 지지 → 부유 R 발생, 대조용).

### (2) `crystallize` 의 침착 게이트

```
N = (kSupport≠0) ? W·H·D : W·H        // 지지 켜야 3D 전 평면, 끄면 z=0 평면(step-0031)
for i in 0..N:
  if E[i] > crystThresh:
    if kSupport==0  OR  i < W·H(=z=0 바닥)  OR  R[i−W·H](=아래 칸) ≥ supportThresh:   // 지지 게이트
      dep = (E[i]−crystThresh)·kCryst;  E[i] −= dep;  R[i] += dep            // 침착(E→R 쌍 거래)
  if R[i] ≠ 0:  rel = R[i]·kWeather;  R[i] −= rel;  E[i] += rel             // 풍화(게이트 무관)
```

- **D=1 또는 kSupport=0 에서 비트 동일**: kSupport=0 → N=W·H(z=0 평면) + 게이트 무효 → 기존 결정화와 *비트 동일*(IEEE 754). 모든 D 에서. D=1 → N=W·H 어차피 z=0 평면, 게이트 켜도 `i<W·H` 항상 참(바닥) → 무조건 통과 = 동일.
- **부유 R 차단**: z>0 셀은 아래 칸 R 이 문턱 미만이면 침착 skip → 공중에 R 이 안 생긴다. z=0(바닥)은 늘 통과 → 지면이 바닥부터.
- **바닥부터 쌓임**: z=0 가 먼저 굳어 R[z=0]≥문턱 → 그제야 z=1 이 지지받아 굳음 → 한 겹씩 위로(국소 z−1 판정). 공중 바위 0.
- **보존**: 침착(E→R)·풍화(R→E) 모두 셀 안 쌍 거래. 게이트는 침착 *위치*만 거를 뿐 양을 안 바꿈 → 장부 무관(잔차 임계 동일).

### (3) 무엇을 *안* 바꿨나 (V5+ 로 전가)

- **R 차폐**(아래가 고체면 E 가 옆으로 우회) — 지금은 순수 E 하향(중력은 R 무시). 차폐는 V5+.
- **부유 R 붕괴**(받침 잃은 R 낙하) — R 은 한 번 굳으면 고정. 낙하는 별도 조각(V5+ 백로그).
- **다른 침착 법칙**(replicate·anisotropy·turing·dendrite)은 z=0 평면 유지 — V4 는 *결정화 하나*에만 게이트(한 조각). 이들의 3D 게이트도 V5+.

## 4. 의외의 발견

- **부유 R 이 *정확히 3개 평면 분량*(12288 = 3×4096)** — 무게이트 슬랩(z=7)이 중력으로 떨어지며 z=7·6·5 세 층을 지날 동안 제자리 결정화해 *세 겹의 공중 바위*를 남긴다(그 뒤 E 는 다 떨어져 더 이상 위층서 안 굳음). 게이트는 이 *전부*를 0 으로 만든다 — 받침 한 줄이 "허공의 바위"라는 비물리를 *완전히* 제거한다(부분이 아니라 0).
- **바다와 지면이 *같은 중력*에서 갈린다** — V3 의 E 중력(바다)과 V4 의 R 지지(지면)는 둘 다 "아래로"라는 *한 방향 상수*에서 나온다. E 는 흐르니 바닥에 *고이고*(액체), R 은 굳었으니 받침 위에 *쌓인다*(고체) — 같은 중력이 *활성도(흐름/저장) 축* 위 두 극단에서 바다와 지면으로 갈린다(authored type 없이, 척추 ②).

## 5. 정직한 한계

1. **R 차폐 미구현 — 중력이 R 을 안 본다** — E 중력(V3)은 아래 칸이 고체(R)여도 그냥 통과한다. "막히면 옆으로"의 *옆*은 V2 확산이 일부 맡으나, 바위가 E 를 *실제로 가로막는* 차폐(고인 물이 지면 위에 얹히는 진짜 바다 표면)는 V5+. 그래서 *지금은* 바다가 지면 *위에* 또렷이 얹히진 않는다(E 와 R 이 같은 바닥에 섞여 고임).
2. **부유 R 붕괴 없음** — R 은 한 번 굳으면 고정(받침이 풍화로 사라져도 안 떨어짐). 침착 *시점*엔 지지를 보지만 *사후* 지지 상실은 무시 — 부유 R 낙하는 별도 조각(V5+).
3. **결정화만 게이트** — replicate·anisotropy·turing·dendrite 등 다른 E→R 침착은 z=0 평면 전용 유지(한 조각). 전체 스택의 3D 형태(가지·반점이 3D 로)는 아직 — V5+ 가 하나씩 게이트.
4. **렌더 미전환** — 3D 뷰는 아직 z=0 평면 하이트필드. voxel 렌더(R 점유 큐브 + 고인 E 물 볼륨)는 렌더러 트랙 L-V1/L-V2.
5. **지지 = 바로 아래 한 칸(국소)** — 대각선 지지·아치 같은 구조는 못 만든다(z−1 한 칸만 봄). 이는 *의도된 단순화* — 전역 지형맵 조율자를 피하는 척추 원칙(국소 문턱). 성능은 결정화가 N=W·H·D 순회 ∝ D(kSupport on 시).
