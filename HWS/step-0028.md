# step-0028 — 격자 z-일반화: 시뮬 공간을 W×H×D voxel 로 (VOXEL.md V1)

> 한 줄: 지금까지 세계는 납작한 2D 필드였고 높이는 렌더러가 물질 R 에서 *발명한* 착시였다(2.5D). 지면 위 바다·절벽·동굴이 *스스로 굴러가는* 세계는 납작한 판으로 표현이 불가능하다 — 그래서 공간을 **voxel(벽돌) 3D 상자**로 일반화한다. step-0028 은 그 전환의 **첫 칸(V1) = 격자만 일반화**다: 깊이 `D` 노브, 인덱스 `(z·H+y)·W+x`(z 는 벽·x·y 는 토러스), 커널에 3D 헬퍼(`discCells3`·`ballOffsets`·`tumbleHash3`) 가법. **법칙 산술은 무수정** — 법칙들은 N=W·H 로 z=0 평면만 처리하고(z 확산은 V2·중력[바다]은 V3·지지 침착[지면]은 V4 로 전가), **D=1 이면 기존 2D 와 비트 동일**(z 이웃이 없어 z 항이 산술로 0 = 회귀 0). 이 step 은 *법칙*이 아니라 *터(Ground)의 차원*을 일반화하는 첫 step 이다.

---

## 검증 질문 (본 thesis: 2.5D[2D 필드 + 렌더 발명 z]로는 지면·바다가 스스로 고이는 세계가 표현 불가 — 시뮬 공간 자체가 3D 여야 한다. 단 27 step 의 검증 자산[회귀 사슬·골든 해시]을 한 줄도 버리지 않으려면 *깊이 D=1 에서 비트 단위로 동일*하게 일반화해야 한다. VOXEL.md V1, STATE §2 🔴 최우선)

핵심 가설 한 줄: **격자를 W×H×D 로 일반화하되 D=1 에서 기존 2D 와 비트 동일하고, D>1 에서 z=0 평면이 D=1 전체 세계와 비트 동일하며(깨끗한 일반화), 결정론·닫힌 장부를 유지한다.**

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

**이 단계가 답한 질문** — 지금까지 우리 세계는 64×64 칸의 *납작한 바둑판*이었다. 화면에서 보이던 "높이"는 시뮬의 사실이 아니라, 렌더러가 물질의 양을 보고 *그려낸 착시*였다(그래서 2.5차원이라 불렀다). 그런데 지면 위에 바다가 고이고, 절벽이 서고, 동굴이 뚫리는 — 현실처럼 *스스로 굴러가는* 세계는 납작한 판으로는 표현할 길이 없다. 이 단계의 질문: **공간을 진짜 3차원(벽돌을 쌓은 상자)으로 바꾸되, 지난 27단계 동안 쌓은 검증을 하나도 깨지 않을 수 있을까?**

**무엇을 바꿨나** — 세계의 *그릇*을 바꿨다. 예전엔 칸이 가로·세로 둘로만 매겨졌는데, 이제 *깊이*(층)를 더해 가로·세로·높이 셋으로 매긴다. 새 손잡이 하나 — *깊이 D* — 를 더했다. D 를 1 로 두면 층이 하나뿐이라 *예전 납작한 세계와 완전히 똑같다*. D 를 2 이상으로 올리면 층이 쌓인 *벽돌 상자*가 된다. 칸 번호를 매기는 규칙을 정하고(맨 아래 층이 예전 2D 와 같은 자리), 바닥·천장은 *벽*(에너지가 못 새어 나감)으로, 옆면은 예전처럼 둥글게 이어지게(토러스) 했다. 그리고 *세계의 법칙들(에너지가 퍼지고 굳고 생명이 먹는 규칙)은 한 줄도 안 고쳤다* — 이번 단계는 *그릇만* 키운다. 위층에서 에너지가 퍼지는 것(중력으로 바다가 고이는 것)은 *다음 단계들*의 몫이다.

**무엇을 발견했나** — 일반화가 *깨끗하다*는 걸 수치로 확인했다. ① 깊이를 4 로 둔 세계의 *맨 아래 층*을 떼어 보면, 깊이를 1 로 둔 납작한 세계와 *완전히 똑같다 — 단 하나의 비트도 안 다르다*(다섯 시드 전부 차이 0). 같은 씨앗에서 맨 아래 층은 같은 난수로 시작하고, 법칙들이 가로·세로만 보기 때문이다. ② 깊이를 키워도 에너지 장부가 그대로 닫힌다(오차가 사실상 0 — 1000조분의 1보다 작다). ③ 같은 씨앗으로 두 번 돌리면 결과가 비트까지 같다(결정론 유지). ④ 그리고 *지난 27단계의 모든 검증 수치(골든 해시)가 단 하나도 안 변했다* — 깊이를 안 적으면 자동으로 1 이 되어 예전과 똑같이 굴러가기 때문이다.

**왜 중요한가** — 3D 전환의 *토대*다. 이 단계가 깨끗하게 닫혔기 때문에, 다음 단계들은 안심하고 위로 쌓을 수 있다: 위층으로 에너지가 퍼지게 하고(V2), 에너지가 아래로 모이게 해 *바다*를 고이게 하고(V3, 중력), 물질이 바닥부터 쌓이게 해 *지면*을 세운다(V4). 그리고 렌더러는 따로 — 예전에 높이로 그리던 에너지 크기를 이제 *색의 밝기*로(클수록 밝게), 물질이 찬 칸을 진짜 *벽돌*로 그린다(L-V1). 무엇보다 *27단계의 검증을 한 줄도 안 버리고* 그릇을 키웠다는 게 핵심이다 — "한 번에 한 조각 + 회귀 0"이라는 이 프로젝트의 작업 방식이 차원 전환 같은 큰 변화에도 그대로 통한다는 증거다.

**솔직한 한계** — ① 이번 단계에서 *위층은 아직 죽어 있다* — 에너지가 위로 안 퍼지고(z 확산은 V2), 아래로도 안 모인다(중력은 V3). 그래서 깊이를 키워도 *지금은* 맨 아래 층만 살아 있고 위층은 처음 noise 그대로 멈춰 있다(불활성). 진짜 3D 세계(바다·지면)는 V2~V4 가 닫혀야 선다. ② 화면(3D 뷰)도 아직 *맨 아래 층의 하이트필드*만 그린다 — 벽돌(voxel) 렌더는 렌더러 트랙(L-V1)의 일이다. ③ 기존 손잡이(노브)들은 전부 2D 에서 맞춰졌다 — 깊이를 1 로 둘 때의 동일성은 비트로 지키지만, 깊이를 키운 뒤의 *동작*은 전부 새 가설이라 다음 단계들에서 수치로 다시 증명해야 한다. ④ 칸 수가 깊이에 비례해 늘어(깊이 16 이면 16배) tick 비용이 커진다 — 희소 순회 최적화(수치를 안 바꾸는) 전까지는 낮은 깊이·전용 실험장으로 흡수한다.

## 2. 메커니즘 — 격자 일반화의 세 변경점 (모두 D=1 에서 비트 동일)

이 step 은 `engine/hws-laws.js`(DEFAULTS)·`engine/hws-sim.js`(createSim)·`engine/hws-kernel.js`(헬퍼 가법) 셋을 *최소* 수정한다. 법칙 함수 본문은 한 줄도 안 고친다.

### (1) `DEFAULTS.D = 1` — 깊이 노브

터 깊이 z. 1 = off = 기존 2D 와 비트 동일. >1 이면 voxel 상자. 인덱싱 규약 `idx = (z·H+y)·W+x`(z=0 평면 == 기존 2D 메모리 레이아웃) — z=0 이면 `(0·H+y)·W+x = y·W+x` 로 기존과 같다. 해시(`hashState`)는 E/R 버퍼 전체를 먹으므로 D=1 에선 길이 W·H 로 과거와 동일 → 골든 불변.

### (2) `createSim`: `N = W·H·D` + `buf = E 복사본`

상태 배열 길이를 W·H·D 로 일반화(D=1 → W·H, 자료형·의미 무수정). 초기 noise rng 는 인덱스 순서로 채우므로 *z=0 평면(첫 W·H 셀)은 D 와 무관하게 같은 draw* 를 받는다(이것이 z=0 평면 비트 동일의 토대). **buf 를 zeros 대신 E 복사본으로 초기화** — 유일한 보존 미세점: `diffuse` 가 E/buf 를 스왑하는데 V1 에선 z=0 평면만 쓰므로, 미작성 상위 평면이 스왑 후에도 초기 noise 를 보존해야 장부가 닫힌다(zeros 면 상위 평면 E 가 유실). D=1 에선 diffuse 가 매 tick 전 셀을 덮어쓴 *뒤* 스왑하므로 buf 초기값이 무관 → 비트 동일(회귀 0 불변).

### (3) 커널 3D 헬퍼 (가법 — 동결 함수 무수정)

- `discCells3(W,H,D,cx,cy,cz,r)` — 반경 r 공 셀(x·y wrap·z 클램프). **D=1·cz=0 이면 `discCells(W,H,cx,cy,r)` 와 셀·순서 비트 동일**(dz=0 바깥 루프 1회) — 3D 헬퍼가 2D 의 진부분집합(회귀 안전).
- `ballOffsets(r)` — 반경 r 공 오프셋(dz·dy·dx 스캔 순서 고정).
- `tumbleHash3(x,y,z,t,seed)` — `tumbleHash` 의 z-확장. **z=0 이면 `imul(0,·)=0` 이라 `tumbleHash(x,y,t,seed)` 와 비트 동일** — 2D 해시 = 3D 해시의 z=0 슬라이스. 기존 법칙은 `tumbleHash` 를 그대로 써 회귀 0; 3D 에이전트/별 siting(V5+)만 이걸 쓴다.

세 헬퍼 모두 *z=0 슬라이스가 2D 등가물과 비트 동일*하게 설계해, 차원 일반화가 기존 동작의 진부분집합임을 산술로 보장한다.

## 4. 의외의 발견

- **z=0 평면이 D 와 *완전히* 무관하게 같다(maxDiff=0)** — 단지 "회귀 0"(D=1 동일)을 넘어, *D=4 에서도* 맨 아래 층이 2D 세계와 비트 동일이다. 이는 두 사실의 합작: ① 초기 noise rng 가 인덱스 순서라 z=0 평면이 첫 W·H draw 를 D 무관하게 받음 ② 법칙이 x·y wrap 만 보고 z 를 안 봄. 덕분에 V1 의 일반화가 *깨끗*(상위 평면이 z=0 동역학에 영향 0)함이 산술로 증명된다 — 흔한 "차원 추가 후 미세 드리프트"가 없다.
- **buf 초기화가 유일한 보존 미세점이었다** — diffuse 의 E/buf 스왑이 V1 에선 z=0 평면만 쓰므로, buf 를 zeros 로 두면 상위 평면 E 가 스왑에서 유실돼 장부가 깨졌다. buf=E 복사본 한 줄로 닫혔고, D=1 에선 무관(덮어쓴 뒤 스왑)이라 회귀도 안 건드린다 — *차원 확장의 보존은 동역학이 아니라 버퍼 관리에 숨어 있었다*.

## 5. 정직한 한계

1. **상위 평면 불활성** — V1 은 격자만 일반화한다. z 확산(V2)·중력(V3)·지지 침착(V4) 전까지 D>1 의 상위 평면은 초기 noise 에 멈춰 있다(살아 있는 건 z=0 평면뿐). 진짜 3D 세계(바다·지면)는 그 칸들이 닫혀야 선다.
2. **렌더 미전환** — 3D 뷰는 아직 z=0 평면 하이트필드다. voxel 렌더(R 점유 인스턴스드 큐브 + E=밝기)는 렌더러 트랙 L-V1(RENDER-STATE.md) — 시뮬과 직교 병행.
3. **노브 재튜닝 미래** — 기존 노브는 2D 튜닝. D=1 비트 동일은 지키나, D>1 *동작*은 전부 새 가설(V2~ 에서 수치 증명).
4. **성능** — 셀 수 ∝ D(깊이 16 → 16배). 단 V1 법칙은 N=W·H 로 z=0 평면만 순회해 tick 비용은 *아직* 2D 와 동급(createSim 의 배열 채움만 D배). z 확산(V2) 부터 비용이 D 에 비례 — 희소 순회 최적화(수치 불변)·낮은 D·전용 아레나로 흡수. G1 timescale(world-tick/렌더 분리)이 더 일찍 필요해질 수 있음(다운스트림).
5. **scan-order 이방성 심화 가능** — 기존 백로그(center-셀/scan-order)가 z 추가로 커질 수 있다. z 바깥 고정 순서(`(z·H+y)·W+x`)로 통제하되 V2~ 에서 계량.
