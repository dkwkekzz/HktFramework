# step-0034 — 부유 R 붕괴(collapse): 지지 잃은 공중 바위가 아래로 무너진다 (VOXEL.md V5+)

> 직전: [step-0033](step-0033.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md)

## 검증 질문

V4(step-0032 지지 침착)는 R 이 *생길 때* 지지 없는 칸에 안 굳게 막았다 — **정적**이다(처음부터 공중 바위가 안 생김). 그러나 *이미 떠 있는* R — 풍화·다른 침착 법칙(튜링·덴드라이트)이 공중에 깐 R, 또는 아래 지지가 사라진 R — 은 V4 가 손대지 않는다. **떠 있는 R 은 무너져야 하는가, 무너진다면 어디로 가는가?** 이 step 은 새 법칙 `collapse` 하나를 더한다(gravity 뒤): 각 셀이 아래가 *비지지*면 제 R 을 아래로 떨군다(R↔R 쌍 거래). 닫는 조건: ① 회귀 0(kCollapse=0 또는 D=1 → early-return → 직전 step 비트 동일·`coll@` 가법) ② 닫힌 장부(R↔R 쌍 거래 보존) ③ 결정론 ④ 가설(공중 R 슬랩이 붕괴 off 면 떠 있고, on 이면 바닥부터 쌓인다).

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

**이 단계가 답한 질문** — 지난 단계들에서 우리는 3차원 세계를 세웠다: 에너지는 아래로 가라앉아 골짜기에 고이면 *바다*가 되고(중력), 물질은 받쳐주는 바닥 위에서만 굳어 바닥부터 쌓이면 *지면*이 된다(지지 침착). 그런데 지지 침착은 "굳을 때" 공중에 안 굳게 막을 뿐, *이미 공중에 떠 있는 물질*은 그대로 두었다. 진짜 세계라면 받침이 없는 바위는 *떨어져야* 한다.

**무엇을 바꿨나** — 법칙 하나를 더했다. "내 아래 칸이 단단한 지면이 아니면(비어 있거나 무르면), 내 물질의 일부를 아래로 떨어뜨린다." 이게 전부다. 에너지를 가라앉히는 중력 법칙과 *똑같은 골격*인데, 떨어뜨리는 대상이 에너지가 아니라 물질이고, 조건이 정반대다 — 에너지는 아래가 단단하면 *막혀서* 그 위에 고이고(바다), 물질은 아래가 무르면 *떨어진다*(지면이 바닥부터 쌓임). 이 떨어뜨리는 양만큼 아래 칸이 받으므로 *총량은 한 톨도 안 변한다*.

**무엇을 발견했나** — 공중에 띄운 물질 판은, 법칙을 끄면 그 자리에 그대로 떠 있고(무게중심 높이 5층 그대로), 켜면 *바닥까지 무너져 내린다*(무게중심 높이가 5에서 0.46으로 내려감). 흥미로운 건 *어떻게* 쌓이느냐다: 한 기둥의 물질을 다 내려보내면, 바닥 한 칸이 "단단함의 기준"을 넘는 순간 그 칸이 *지면*이 되고, 남은 물질은 그 위 칸에 안착한다. 즉 물질이 바닥부터 한 층씩 차곡차곡 쌓인다(바닥 두 층이 전부를 담는다). 떨어지는 동안에도 총량은 정확히 보존됐다(오차가 사실상 0 — 1조분의 1보다 작다).

**왜 중요한가** — 이로써 "물질의 중력"이 완성된다. 받침이 있으면 쌓이고(지지 침착, 정적), 받침이 없으면 무너진다(붕괴, 동역학) — 둘이 짝지어야 비로소 지형이 *살아 움직인다*: 풍화로 아래가 깎이면 위가 무너지고, 새로 생긴 물질이 공중에 뜨면 가라앉아 자리를 잡는다. 절벽이 무너지고 더미가 안식각으로 주저앉는 세계의 첫 벽돌이다.

**솔직한 한계** — 지금 붕괴는 *수직으로만* 일어난다(바로 아래 칸으로만). 그래서 물질은 한 기둥 안에서 쌓일 뿐, 옆으로 흘러내려 *비탈(안식각)*을 만들지는 못한다 — 한 칸에 물질이 아무리 높이 쌓여도 옆으로 안 퍼진다. 진짜 모래더미처럼 옆으로 주르륵 흘러내리는 건 다음 조각(측면 사면 이완)으로 남긴다. 또 전체 스택(별·생명이 도는 세계)에선 이 붕괴가 아직 거의 안 보인다 — 거긴 D=1(2차원)이라 위아래가 없기 때문이다. 현상은 3차원 격리 아레나에서만 또렷하다.

## 2. 메커니즘 — collapse 법칙 1개 + 노브 kCollapse + 문턱 collapseThresh + LAW_ORDER 한 자리(gravity 뒤)

`engine/hws-laws.js` 에 법칙 함수 1개(`collapse`) + `DEFAULTS` 노브 1개(`kCollapse`, 기본 0) + 문턱 1개(`collapseThresh`, 0.5) + `LAW_ORDER` 한 자리(`gravity` 뒤 — 두 중력 항을 묶는다)를 더했다.

```
function collapse(sim) {
  var p = sim.p; if (p.kCollapse === 0) return;        // 노브=0 → early-return = 회귀 0
  var D = p.D || 1; if (D < 2) return;                  // z 이웃 없음(D=1) = 회귀 0 (이중 가드)
  var R = sim.R, WH = p.W * p.H, kC = p.kCollapse, cth = p.collapseThresh;
  for (var z = 1; z < D; z++) {                         // z=0 은 바닥 벽 — 받기만 하는 안착 자리
    var zb = z * WH, below = zb - WH;
    for (var k = 0; k < WH; k++) {
      var i = zb + k, r = R[i];
      if (r <= 0) continue;
      if (R[below + k] >= cth) continue;                // 아래가 고체 지면(지지) → 안착. 미만이면 비지지 → 떨어짐
      var flow = r * kC;                                // 하향 낙하(제 R 의 비율 → donor-제한, 음수 없음)
      R[i] = r - flow; R[below + k] += flow;            // R↔R 쌍 거래 — 보존
    }
  }
}
```

`gravity`(①g, E 의 중력)와 **같은 골격**이되 ① 옮기는 양이 E 가 아니라 R 이고 ② 게이트가 *역방향*이다 — gravity: 아래가 *고체*(R≥occludeThresh)면 *막힘*(E 가 위에 고임=바다). collapse: 아래가 *비지지*(R<collapseThresh)면 *떨어짐*(R 이 지지 위에 쌓임=지면). 같은 문턱 척도(고체 R 기준 통일: supportThresh=occludeThresh=collapseThresh=0.5). z 오름차순 단일 패스 → 한 tick 한 칸 낙하(침전 속도 유한). 결정화(⑤) 앞이라 이번 tick 붕괴는 직전 tick R 형상에 작용(gravity 와 같은 정신).

### 무엇을 *안* 바꿨나 (다음으로 전가)

- **측면 사면 이완(안식각)** — 붕괴는 *수직(바로 아래)* 으로만. 한 칸에 R 이 높이 쌓여도 옆으로 안 흐른다 → 모래더미 안식각·산사태는 별도 조각(백로그).
- **풍화·다른 침착과의 결합** — 붕괴 *판정*만 더했다. 풍화로 받침이 깎여 위가 무너지는 동적 연쇄, turing/덴드라이트가 공중에 깐 R 의 자동 붕괴는 동역학적으론 작동하나(이 step 으로 길이 열림) 전체 스택 발현은 직교 백로그.
- **전체 스택(D=1) 발현** — 전체 스택은 D=1 이라 붕괴 비활성(z 벽 early-return). V5+ 다른 개체 z-활성화(별 高z·생명 (x,y,z))는 다음 step 들.

**가설 해석**: 한 기둥 R(=1.0)이 문턱(0.5)을 넘어 z=0 이 고체 지면이 되고, 넘침이 그 위 z=1 에 안착한다 → *바닥부터 쌓이는 지면*. 공중에 떠 있던 판이 무너져 내려 바닥 두 층에 정확히 안착한다(중간 층 z=2~4 는 비워짐, loOn=0).

### 척추 체크 4항

1. **단일 척추** — 새 필드 없음. R 은 기존 저장상(E 의 굳은 phase). 붕괴는 *법칙의 항*이지 둘째 필드가 아니다. ✅
2. **활성도 환원** — authored type 분기 없음. R 의 낙하 *속도*만(아래가 비지지인가의 국소 판정) — 개체 종류를 안 만든다(gravity 와 같은 정신). ✅
3. **국소 문턱** — 제 z−1 아래 한 칸 R 만 본다. 전역 수면고·지형맵 같은 조율자 0. 방향 상수(아래)는 scan-order 처럼 법칙의 상수. ✅
4. **순환 장부** — R↔R 쌍 거래(나간 만큼 들어옴). 낙하는 *비가역*이라도 양은 보존(비가역 ≠ 비보존, 잔차 1e-14). ✅

## 4. 의외의 발견

**붕괴가 *저절로 바닥부터 쌓는다*(층화)** — donor-제한 비율 낙하 + 같은 지지 문턱이 맞물리면, 떨어지는 R 이 단순히 z=0 한 칸에 다 뭉치지 않고 *바닥부터 한 층씩 차오른다*: z=0 이 문턱(0.5)을 넘는 순간 "고체 지면"이 되어 그 위 R 의 낙하를 멈추고, 넘침이 z=1 에 안착한다(바닥 2층 100%·z=0 이 54%). 별도 "쌓기" 규칙을 안 짰는데 *지지 게이트의 역방향*만으로 V4 의 "지면이 바닥부터 쌓인다"가 동역학으로 재현됐다 — V4(정적 형성)와 V5+(동적 붕괴)가 *같은 문턱*을 공유해 한 지면 모델로 정합한다.

## 5. 정직한 한계

- **수직 전용 — 안식각 없음**: 붕괴가 바로 아래로만 떨어져 *옆으로 흘러내리지 않는다*. 한 칸에 R 이 아무리 높이 쌓여도 비탈(안식각)을 안 만든다 — 진짜 모래더미·산사태(측면 사면 이완)는 별도 조각(백로그).
- **전체 스택 미발현**: 전체 스택은 D=1 이라 붕괴 비활성. 현상은 3D 격리 아레나(collapse 아레나)에서만 또렷.
- **연쇄(cascade) 미검증**: 풍화가 받침을 깎아 위가 *연쇄로* 무너지는 동역학은 길이 열렸으나 이 step 에선 정적 슬랩만 검증(연쇄 시나리오는 다음).
