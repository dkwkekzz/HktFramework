# step-0035 — 별 부력 상승(star rise): 소산 극단이 떠올라 하늘서 E 를 뿜는다 = 태양 (VOXEL.md V5+)

> 직전: [step-0034](step-0034.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md)

## 검증 질문

step-0034(붕괴)는 *저장 극단*(R)이 **가라앉는** 걸 더했다. 활성도 축(SPINE 결정2)의 두 끝 중 한쪽만 연직으로 실현된 셈이다. **나머지 끝(소산 극단=별, 활성도 최고)은 어디로 가야 하는가?** 대칭이라면 *떠올라야* 한다 — 불꽃·뜨거운 기둥처럼 부력으로. 이 step 은 `ignite` 법칙을 제자리 확장해(LAW_ORDER 무변경) 점화한 별이 z=0 지면 핵에서 태어나 천장까지 떠오르고 제 z 의 3D ball 로 E 를 뿜게 한다(노브 `kStarRise`). 닫는 조건: ① 회귀 0(kStarRise=0 또는 D=1 → 부력 미진입/상승 0 → 직전 step 비트 동일·`sun@` 가법) ② 닫힌 장부(상승=위치만, 방출=fuel→E 외부 경계) ③ 결정론 ④ 가설(별이 천장까지 떠올라 E 무게중심이 高z 로).

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

**이 단계가 답한 질문** — 지난 단계(step-0034)에서 *물질*은 받침이 없으면 아래로 무너지게 했다. 그런데 세계엔 정반대 성질의 개체도 있다 — *별*. 별은 가장 격렬하게 에너지를 처리하는 "소산 극단"이다. 물질이 가라앉는다면, 그 반대편 끝인 별은 *떠올라야* 자연스럽다. 불꽃이 위로 솟고 뜨거운 공기가 떠오르듯이.

**무엇을 바꿨나** — 별 점화 규칙에 "부력"을 한 줄 더했다. 별은 여전히 바닥의 물질 핵에서 태어나지만, 켜면 매 순간 한 칸씩 *하늘로 떠오른다* — 천장에 닿을 때까지. 그리고 제가 떠 있는 높이에서 에너지를 사방(공 모양)으로 뿜는다. 별이 하늘 꼭대기에 자리 잡고 에너지를 쏟아내면, 그 에너지는 (지난 단계의 중력으로) 아래로 비처럼 내린다 — 즉 **태양**이 된다: 높은 곳의 발원지 → 쏟아짐 → 바다로 고임.

**무엇을 발견했나** — 부력을 끄면 별은 바닥(높이 0)에 머물러 에너지를 바닥에만 뿌린다(에너지의 무게중심 높이 = 0). 켜면 별이 천장(높이 7)까지 떠올라, 에너지의 절반 이상이 꼭대기 층에 모이고 무게중심 높이가 0에서 6.36으로 솟는다. 더 깊은 의미가 하나 드러났다: step-0034에서 *저장 극단(물질)은 가라앉고* 이번에 *소산 극단(별)은 떠오르니*, "개체를 가르는 활성도 축"이 이제 **위아래(연직) 방향 그 자체**가 됐다 — 낮은 활성(저장)은 아래, 높은 활성(소산)은 위. 코드에 "별은 위, 바위는 아래"라고 박은 게 아니라, 가라앉음과 떠오름이라는 두 동역학이 *저절로* 그 질서를 만든다.

**왜 중요한가** — 이로써 3차원 세계의 에너지 순환이 닫힌다: 태양이 하늘에서 에너지를 뿜고(이 단계) → 중력이 아래로 끌어내려 바다로 고이고(step-0031) → 물질이 바닥부터 지면을 쌓고(step-0032·0034) → 그 위에서 다시 별이 점화한다. 위에 태양, 아래에 바다와 땅 — 우리가 아는 세계의 연직 구조가 이름표가 아니라 *법칙에서 창발*한다.

**솔직한 한계** — 지금 부력은 별을 *수직으로만* 곧장 띄운다(매 tick 한 칸). 진짜 부력 기둥처럼 옆으로 퍼지거나 소용돌이치진 않는다. 또 별이 천장에 닿으면 거기 머물며 하늘을 떠돈다 — "지는 별"(천장서 다시 소진·낙하)은 아직 단순하다. 그리고 전체 스택(별·생명이 도는 세계)은 2차원(D=1)이라 부력이 아직 안 보인다 — 현상은 3차원 격리 아레나에서만 또렷하다. 태양빛이 실제로 비처럼 내리는 결합(부력+중력 동시)은 이 step 에선 중력을 꺼 격리 검증했고, 둘을 함께 켜는 통합 시나리오는 다음으로 남긴다.

## 2. 메커니즘 — ignite 제자리 확장: 부력 z-상승 + 3D ball 방출 + 노브 kStarRise (LAW_ORDER 무변경)

`engine/hws-laws.js` 의 `ignite` 법칙에 부력을 더했다(법칙 신설 아님 — VOXEL.md V2~ 의 "기존 법칙 제자리 확장 + 노브만" 형식) + `DEFAULTS` 노브 1개(`kStarRise`, 기본 0).

```
// ① 점화 시(별 생성): rise 면 z=0(지면 R 핵) + 3D ball 방출
if (rise) { ns.z = 0; ns.cells = K.discCells3(W, H, D, bx, by, 0, p.starR); }

// ② 매 tick(별 처리): 서행(xy, 주기마다) + 부력 상승(z, 매 tick 한 칸·천장까지)
var canMove = (st.state === undefined || st.state === 1), nx = st.x, ny = st.y, moved = false;
if (canMove && st.age % dPer === 0) { nx = (st.x+st.vx+W)%W; ny = (st.y+st.vy+H)%H; moved = true; }  // 서행
if (rise && canMove && st.z < D - 1) { st.z++; moved = true; }                                       // 부력
if (moved) {
  st.x = nx; st.y = ny;
  if (st.z !== undefined) { st.center = (st.z*H+ny)*W+nx; st.cells = K.discCells3(W,H,D,nx,ny,st.z,p.starR); }  // 3D ball
  else { st.center = ny*W+nx; st.cells = K.discCells(W,H,nx,ny,p.starR); }                                     // 2D(회귀)
}
```

**step-0034 붕괴와 대칭**: 저장 극단 R 은 아래가 비지지면 *가라앉고*(collapse), 소산 극단 별은 *떠오른다*(rise). 두 동역학이 활성도 연속축(SPINE 결정2)을 *연직 z 축*으로 창발시킨다 — authored "별=위/R=아래" 분기 없이. 별이 高z 에서 뿜은 E 를 `gravity`(V3 kGravity)가 아래로 끌어내리면 "비처럼" 내려 바다로 — 태양의 완성(이 step 은 중력 off 로 부력만 격리 검증).

### 무엇을 *안* 바꿨나 (다음으로 전가)

- **부력+중력 동시(태양빛 비)** — 이 step 은 중력 off 로 부력만 격리. 둘을 함께 켜 高z 발원 E 가 실제로 낙하·바다로 고이는 통합 시나리오는 다음.
- **지는 별(천장서 소진·낙하)** — 별이 천장 도달 후엔 거기서 서행(하늘 배회)만. 별의 *하강*(연료 소진→재→낙하)은 백로그.
- **부력의 옆퍼짐/대류** — 수직 곧장 상승만(매 tick 한 칸). 부력 기둥의 측면 퍼짐·소용돌이는 백로그.
- **전체 스택(D=1) 발현** — D=1 이라 부력 비활성. 현상은 3D 격리 아레나에서.

### 척추 체크 4항

1. **단일 척추** — 새 필드 없음. 부력은 별 *속성*(Fragment: z 좌표)·위치 갱신이다. 필드는 여전히 E 하나. ✅
2. **활성도 환원** — authored "별=위" 분기 없음. 떠오름은 *연직축 위 한 점의 동역학* — 별의 종류를 새로 만들지 않는다(붕괴와 대칭). 활성도 축이 z 로 창발. ✅
3. **국소 문턱** — 별은 제 z 만 보고 한 칸 오른다(천장 z=D−1 클램프). 전역 수면고·고도맵 같은 조율자 0. ✅
4. **순환 장부** — 상승은 위치만(거래 0). 방출은 기존 fuel→E 외부 경계(injected, step-0011 그대로). 장부 잔차 1.5e-15. ✅

## 4. 의외의 발견

**활성도 축이 *연직축*으로 창발했다(step-0034 와 합쳐서).** step-0034 단독으론 "R 이 가라앉는다"였고 step-0035 단독으론 "별이 떠오른다"지만, *둘을 합치면* SPINE 결정2 의 활성도 연속축(저장 극단 ↔ 소산 극단)이 **공간의 연직 z 축 그 자체**로 실현된다 — 낮은 활성(저장 R)은 바닥에, 높은 활성(소산 별)은 천장에. 이건 author 한 게 아니다(코드 어디에도 "별은 위/R 은 아래" 분기가 없다): *가라앉음*(donor-제한 하향)과 *떠오름*(부력 상향)이라는 두 국소 동역학이 같은 활성도 척도(고체 R 기준·소산 throughput)를 공유해 *저절로* 연직 질서를 만든다. 차이슨의 energy rate density 축(은하→별→…→생명)이 HWS 에선 글자 그대로 *높이*가 됐다.
