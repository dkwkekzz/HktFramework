# step-0043 — 3D 번식: 자식의 연직 출생(번식이 연직축으로 — 개체군이 번식으로 3D 를 오른다)

> 직전: [step-0042](step-0042.md) · 현재 위치·다음 가설의 권위: [STATE.md](STATE.md) · 척추: [SPINE.md](SPINE.md)

## 검증 질문

step-0042 가 생명의 *이동*(주화성)을 z 로 풀어, 개체가 연직 에너지 구배를 읽어 위로 올라가게 했다. 그러나 *번식*은 여전히 2D였다 — `reproduce` 가 자식을 늘 z=0 평면(`nidx = ny·W+nx`)에 두었다. 그래서 부모가 z>0 으로 올라가도 자식은 바닥으로 추락했다(개체군이 3D 로 *번식해 퍼지지* 못함). 이 step 은 `reproduce` 의 자식 배치를 **4-이웃[2D 평면]→6-이웃[3D]**으로 *제자리 확장*한다(move 의 kMoveZ z-이동과 같은 형식·새 LAW_ORDER 자리 없음) + 노브 `kDivZ` 1개: 부모 z-평면 + 위/아래(z±1) 후보 중 E 최고 칸에 자식을 둔다. **닫는 조건**: ① 회귀 0(kDivZ=0 → pz 강제 0 → 자식 z=0 평면 비트 동일·D=1 → z±1 벽 밖, 이중 가드) ② 닫힌 장부(m 반분 쌍 거래) ③ 결정론(agent.z 포함) ④ 가설(연직 E 구배서 kDivZ ON 이면 자식이 천장까지 줄지어 태어난다).

## 0. 쉽게 풀어 쓴 설명 (먼저 읽기 — 전문 기호 없이)

- **이 단계가 답한 질문**: 지난 단계에서 생명은 *걸어서* 위로 올라갈 수 있게 됐다(에너지가 높은 위쪽으로 한 칸씩 이동). 그런데 생명이 *새끼를 칠* 때는 여전히 새끼가 항상 맨 바닥에 떨어졌다. 부모가 아무리 높이 올라가 새끼를 낳아도 새끼는 바닥으로 추락하니, 개체군이 높은 곳에서 *번져 자리 잡지* 못했다. 그래서 물었다 — **새끼도 부모 근처(위/아래)에서 태어나, 에너지가 높은 위쪽으로 *번식해서* 올라갈 수 있게 하자.**
- **무엇을 바꿨나**: 새끼를 둘 자리를 고를 때, 예전에는 부모의 *같은 높이 옆칸 네 곳*만 봤다. 이제 거기에 **바로 위 칸과 바로 아래 칸 둘을 더해** 여섯 곳을 본다. 그중 에너지가 가장 높은 빈칸에 새끼를 둔다. 위쪽이 더 밝으면(에너지가 높으면) 새끼는 *위에서* 태어난다. 새 스위치(이름은 두되 끄면) 0이면 예전과 한 치도 다르지 않다 — 새끼가 다시 바닥에서만 태어난다.
- **무엇을 발견했나**: 위로 갈수록 밝아지는 세계에 바닥의 생명 아홉 마리를 두고 번식만 켰더니 — 스위치가 꺼져 있으면 새끼가 전부 바닥에 쌓여 *조금도 안 올라간다*(가장 높이 올라간 새끼의 높이 = 0). 스위치를 켜면 새끼가 한 세대씩 위로 태어나 **맨 위 천장(여덟 층 중 꼭대기)까지 줄지어 닿는다**(가장 높은 높이 = 7, 평균 높이 0 → 약 1.3, 전체의 6할이 바닥 위로). 즉 개체군이 *걷지 않고 낳기만 해도* 3차원을 타고 오른다.
- **왜 중요한가**: 지난 단계의 "걸어서 오름"과 이번의 "낳아서 오름"은 생명이 3D 세계를 채우는 *두 갈래 길*이다. 둘을 합치면 생명은 위로 가는 에너지를 향해 *이동으로도, 세대 교대로도* 퍼진다 — 한 점이 아니라 *부피*를 차지하는 군체로 가는 첫발이다.
- **솔직한 한계**: 이번엔 *번식 한 갈래*만 z 로 풀었다. 위로 태어난 새끼의 *유전 상속*·*이웃 응집*·*혼잡 판정* 같은 것은 아직 바닥 평면(2D 칸 셈)만 본다 — 이들은 생명 자료형 전체를 3차원으로 일반화한 *뒤에야* z>0 에서 작동한다(다음 백로그). 또 새끼가 위로만 줄지어 오르는 것은 이 *정적인* 사다리꼴 구배 덕인데, 실제로 에너지가 출렁이는 세계에선 오름이 더 들쭉날쭉할 것이다.

## 2. 메커니즘 — `reproduce` z-확장 + 노브 `kDivZ`(0 → 자식 z=0 평면 = 회귀 0)

`engine/hws-laws.js` 의 `reproduce`(⑧) 본문을 *제자리 확장*한다 — 새 법칙·새 LAW_ORDER 자리 없음(move 의 kMoveZ z-이동과 같은 형식·VOXEL.md §3 "기존 법칙 제자리 확장 + 노브").

- **부모 z-평면 후보**: `pz = (kDivZ && D>1) ? (par.z||0) : 0`, `zBase = pz·WH`. 자식 후보 인덱스 `nidx = zBase + ny·W+nx`. **kDivZ=0 또는 D=1 → pz 강제 0 → zBase=0 → 기존 2D 인덱스와 비트 동일**(자식이 z=0 평면).
- **연직 후보(z±1)**: `kDivZ && D>1` 일 때만 부모 같은 (x,y) 의 위(z+1)·아래(z−1) 칸도 후보에 더한다(z 벽 클램프 — `nz<0||nz>=D` skip). E 최고 칸 선택은 기존 그대로(`E[idx] > bestE`). 연직 E 구배(위가 높음)면 z+1 이 in-plane 후보를 이겨 자식이 *위로* 태어난다.
- **자식 객체**: `z: bestZ` 추가 + `cells` 는 bestZ===0 이면 `discCells`(2D), 아니면 `discCells3`(3D). 분열은 기존 그대로 **m 반분**(`par.m = half` + 자식 m=half) — 쌍 거래 보존, E·R 안 건드림.
- **해시 가법**: `if (kDivZ) sim.moveZInit = true` — agent.z 를 hashState 가 가법 해싱(move 의 kMoveZ 와 *같은 플래그* — 둘 다 agent 에 의미 있는 z 를 부여). kDivZ=0 이면 미설정 → 과거 골든 전부 불변(st.z 미해싱·a.g·a.soma 가법과 같은 패턴).

**회귀 이중 가드**: ① kDivZ=0 → pz 강제 0 → 자식 인덱스·cells·해시 모두 기존과 비트 동일 ② D=1 → z±1 이 z 벽 밖이라 연직 후보 0. golden `div3@`(kDivZ=1·D=8) 가 z-출생·agent.z 해시 본문을 동결(드리프트 가드).

### 무엇을 *안* 바꿨나 (다음으로 전가)

- **유전 상속(inherit)·응집(adhere)·혼잡(crowd)·공유(share) 등은 여전히 2D 인덱싱**(occ 배열 W·H, `ny·W+nx`). z>0 자식의 상속·다세포 협동은 agent 자료형의 z-일반화(occ/이웃 셈을 6-이웃으로) 선행 — 백로그(0042 와 같은 caveat). 이 step 의 div3 아레나는 그들(kInherit·kAdhesion·…)을 다 off 로 격리.
- 살아있는 3D 생태(흡수·대사 z-일반화 — 먹으며 오름)·형태 R1~R5 ball 화는 다음 V5+ 칸으로.

## 4. 의외의 발견

- **번식이 *이동보다 멀리* 오른다(같은 정적 구배서)**: 0042 의 z-이동은 30 tick 에 meanZ 7.00(전 개체가 천장에). 이번 z-번식은 같은 구배·tick 에서 maxZ 는 7(천장 닿음)이나 meanZ 는 1.26 에 그친다 — 두 메커니즘의 *모양*이 다르다. 이동은 *개체 전부*가 끌개(천장)로 수렴(점→점)하나, 번식은 *나무처럼 가지치며* 오른다: 선두 계통이 한 세대씩 천장까지 닿는 동안(maxZ 7), m 이 반씩 줄어 바닥 평면에도 형제들이 계속 쌓여(z=0 가 다수) 평균은 낮게 머문다. *분포 자체가 3D 군체*(바닥 넓고 위로 가는 가지)라는 점이 외려 "부피를 차지하는 개체"의 싹에 가깝다.

## 5. 정직한 한계

- **z>0 자식은 아직 "반쪽 시민"**: 유전 상속(inherit)·응집·혼잡이 2D 인덱싱이라, 위에서 태어난 자식은 유전형을 못 물려받고(상속 occ 가 z=0 평면만 봄) kin 으로 안 묶인다. 진짜 *3D 다세포 군체*는 agent 자료형 전체의 z-일반화 후. 이 step 은 *번식 한 갈래의 z-출생*만 격리 입증.
- **정적 구배 한정**: 자식의 단조 상승은 E(z)=1+z 가 *안 변하는* 덕. 동역학적 구배(확산·중력·대사가 E 를 출렁이게)에선 오름이 비단조일 것(0042 와 같은 한계).
- **mDiv 작게(0.005) 인위적**: 천장까지 닿으려면 분열 ~7세대(m 반분)가 필요해 mDiv 를 작게 뒀다. 표준 스택의 mDiv(~0.9~1.2)에선 1~2세대만 올라간다(maxZ 작음) — 이 격리 아레나는 *경로*를 보이는 것이지 표준 동역학 수치 아님.
