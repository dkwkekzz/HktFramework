- **격자 = voxel(0029~, VOXEL.md)**: 터는 W×H×D. 인덱스 `(z·H+y)·W+x`(z=0 평면 == 기존 2D)·x·y wrap·z 벽(클램프). **D=1 → 전 골든 해시 비트 불변**(z 항 산술 0). 커널 3D 헬퍼(`discCells3`·`ballOffsets`·`tumbleHash3`)는 z=0 슬라이스가 2D 등가물과 비트 동일. 차원 확장은 *터의 진화*지 새 필드 아님(단일 척추). **stencil 일반화·게이트·ignite z-확장은 기존 법칙 *제자리* 확장 + 노브만**(VOXEL.md §3 형식 권위·모든 평면을 같은 스킴에 대칭). 회귀 0 = 새 노브=0 *+* D=1 z-이웃 부재(이중 가드).
  *공통 이중 가드*: 아래 V2~V5+ 항 전부 **노브=0 또는 D=1 → 비트 동일**(z 항 산술 0 / early-return). 전문·수치는 각 step 문서·§7 INDEX.
- **z 확산 6-이웃(0030, V2)** `diffuse` z 항(`kDz`): 등방(kDz=kD)·안정 4·kD+2·kDz ≤ 1.
- **중력 z-비등방 하향(0031, V3)** `gravity`: 각 셀 E 의 `kGravity` 를 아래(z−1)로 유출(donor 쌍 거래·잔차 0·z 오름차순 단일 패스) → E 가 z=0 침전=바다. 방향 상수=법칙 상수(z−1 로컬·조율자 아님).
- **지지 침착(0032, V4)** `crystallize` 지지 게이트(`kSupport`·`supportThresh`): 지지 칸(z=0 또는 아래 R≥문턱)에서만 E→R 침착 → 부유 R 0·지면 바닥부터. 위치만 거름(장부 무관).
- **R 차폐(0033, V5)** `gravity` 차폐 게이트(`kOcclude`·`occludeThresh`, in-place): 아래 R≥문턱이면 하향 차단 → E 가 지면 위에 고임=**바다 완성**. 양 미변경·잔차 0.
- **부유 R 붕괴(0034, V5+)** 새 법칙 `collapse`(`kCollapse`·`collapseThresh`, `gravity` 뒤): 아래 R<문턱(비지지)면 제 R 비율 떨굼(R↔R 쌍 거래·보존·잔차 1e-14) → 바닥부터. `gravity` 의 *역게이트*(고체면 막힘 ↔ 비지지면 떨어짐). V4 정적 침착의 동역학 짝.
- **별 일생=활성도 z-궤적(出沒生死), `ignite` 제자리 확장(0035~0038, V5+, LAW_ORDER 무변경·위치/상태만·방출 fuel→E)**: 상승(`kStarRise`, 0035)=z=0 핵서 점화→천장까지 떠 3D ball 방출(sun@). 하강(`kStarFall`·`starFallThresh`, 0036)=연료<문턱(dying)면 z↓하며 *연소 중* 방출(fall@). **태양빛 비(0037, 법칙 무변경·`gravity` 와 *합성*)**=진 별빛이 중력으로 z=0 바다로(별빛→비→바다·바닥 5%→91%·게이트=기존 `kGravity`·rain@). **죽음(`kStarSet`, 0038)**=떠올랐다(`st.rose`) 지는(dying) 별이 z=0 닿으면 死(FSM off=제거·on=ash)→빈 starCap 에 R 핵서 다음 별(death@). **= born→천장→set→死→다음 = 닫힌 궤적·세대 순환**(소산 극단이 저장 바닥 안착=소산 정체성 상실, SPINE 결정2·3). 회귀 이중 가드: 각 노브=0 → 미진입(직전 비트 동일) / D=1·rise off → st.z 1 못 됨 → 상승·하강·죽음 다 미발생. **별 연료 F 는 ledger lhs 밖(외부 질량) → 연료 남기고 죽어도 보존**. `hashState` 는 별의 x·y·fuel·state 만(st.z·st.rose 미해싱). 전문은 step 문서.
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가.
- **척추 체크 4항**: ① 단일 척추(다양성은 병렬 필드 아닌 *속성*에 — 필드는 E 하나) ② 활성도 환원(authored type 분기 금지 — E 동역학은 태그로 안 갈림) ③ 국소 문턱(전역 조율자 0) ④ 순환 장부(비가역 상태라도 보존).
- **이산 FSM = 라벨이지 타입(0013, 결정3)**: 상태는 *활성도 배수의 함수*지 자유 태그 아님(labelViol=0). 별도 에너지 경로 분기 금지(스칼라 배수+게이트만). 이산성은 문턱·timescale 분리에서 창발 — anti-chatter 폭>0(burnOn>burnOff).
- **측정은 부작용 0 — 둘째 척추 금지(0014·0018)**: 활성도 A·막 측정은 동역학에 *되먹이지 않는다*(읽기 전용). 켜고 끔이 동역학을 비트 단위로 안 바꿈.
- **형태는 flux 의 하류 — 렌더러가 *지오메트리* author 금지([RENDER.md](RENDER.md) §6)**: 렌즈가 필드에서 읽는 건 색·재질·빛·흐름(E/R/A/G/∇E 함수) + *어느 양이 z냐*(물질 R)뿐, 형태(실루엣)는 아님. 형태는 시뮬(형태 사다리)이 빚어야 렌즈가 코드 0 으로 받는다.
- **개체는 author 아닌 측정(0017)**: 다세포를 `Organism{cells}` 컨테이너로 만들면 활성도 환원 위반. 개체 = 차등 응집이 빚은 표면장력 액적을 *4-인접 kin 연결 성분*으로 측정.
- **유전 = *이산* 정보의 자기복제(0015)**: 연속 필드(E·R·A)는 확산·EMA 로 번져 정보 못 지킴 — 이산 태그(G)만 복사 연산이라 세대 무한히 건너도 비트 보존. 유전은 저장 극단(R)의 능력이지 *생명 전용 아님*(별=느슨한 혈통·생명=단단한 복제, 결합 단단함으로 갈림).

**B. 반복 작용하는 발견(설계에 계속 작용 — 압축)**

- 동결 푸는 건 운동 아닌 *비균일성/불연속*(매끄러운 균일 표류 = 갈릴레이 불변, 0007). "능력 추가"는 정적 끌개 수렴 → *구조*를 바꿔야(0011 구동 내생화가 동결 풂).
- 구동 내생화는 동결 풀되 *공멸* 부름 → 자기제한이 닫음(0011→0012). 외부 source 의 고정성이 실은 carrying capacity 의 숨은 원천이었다.
- **carrying capacity = 개체수 아닌 *공간 분포*(0012)** — 자기제한을 *국소*(crowdR<채식지)로 주면 공멸 지연뿐. 채식지 척도(crowdR=starR)로 흩뜨려야 지속. **절제가 풍요보다 오래 산다**(혼잡세가 개체군을 영속).
- 별 연료 = 외부 질량(주입 경계); R 은 점화 *신호*(siting)지 소비 대상 아님(0011). 불은 연료 다해야 꺼진다(FN 빠른점화-느린소진, 0013).
- **흐름이 정체성보다 분류(0014)** — 저장체 활성도≈0 은 R 아닌 *흐름 끊긴 자리*의 성질(빈 배경도 같음). 별 연소 셀 100% R-rich 인데도 A 26배.
- **선택은 churn 을 조향하지 *구동*하지 않음 — 유전은 에너지 순환의 *승객*(0015·0016)**. 존재론 조각(유전·개체·막·협동·분화·정착·형태)은 동역학을 안 깬다(0013~0025 직교성 — 새 법칙=노브0 회귀0·쌍 거래 보존).
- 죽음이 있어 선택 더 날카로움 — *생명*(소산 가운데)이 *R*(저장 극단)보다 다윈 무대로 알맞음(선택비 3.27 vs 1.53, 0016). 동결 안 되는 회전이 누적 선택의 조건.
- **유전이 개체보다 먼저**(kin=a.g 정의돼야 다세포 묶임, 0017). DAH(세포)=Schelling(사회) 한 알고리즘이고 개체는 percolation 아닌 *능동 정렬*의 산물.
- **흩어진 협동은 중립 아닌 *해롭다* — kin 구조가 협동보다 먼저(0019)**. *어떻게* 공유하나(표적 구조 vs 균등화)가 b>c 를 가르고, *비평형*(기근)서만 선택압. 공공재는 *풍요*의 자식 / risk-pooling 은 *위기*에(0019·0020 두 보완 국면). 비용 회수 가능(m→m)+시너지라야 강한 침투(0020).
- **분화는 *조밀함*의 자식**(전체 스택 희소라 거의 안 켜짐 — 정착이 전제, 0021·0023). soma 는 손실 아니라 *사장 자원의 회수*(0021). 번식 격리(Weismann)는 author 분기 아닌 *창발*(soma 가 m 비워, 0022). 정착성 생활사는 *안정 자원*의 자식 — 떠도는 자원엔 운동성이 답(0023).
- **형태 사다리(R2~R5, 0024~0027 — 완료, 전문은 step 문서)**: 차등 응집=표면장력(곡률은 바닥 필드 E 에·형태는 흐름의 하류)·등방 blob↔이방성 needle(0025)·**둘째 필드 없이 Turing**(확산 E·비확산 R 의 차등 이동성, 0026)·**Mullins-Sekerka 옆가지**(기하 차폐+곡률 증폭·"덜 먹여야 가지가 산다", 0027). 새 법칙=노브0 회귀0·셀 안 쌍 거래 보존이라 churn 직교.
- **막의 능동성은 *정류*(방향 대칭 깨짐)에서(0028)** — couple(수동 균등화)은 농도 차 못 세우나(ratio≈1), permeate(정류·일방향 import)는 확산이 평형으로 되돌려도 *안>바깥* **유지**(1.00→3.12). 막은 *평형에 맞서* 일함(far-from-equilibrium 능동 경계 — 형태 넘어 *능동성* 첫 발현, throughput 대가). kin 액적 표면서만 창발(외톨이 게이트→전체 스택 benign). 단일 E 라 "선택"은 *방향*뿐 — *무엇* 선택은 다중 자원 선행.
- 소산구조 ≠ 진화하는 복잡계 — 비평형 throughput + 임계 자기조직(0012)은 *지속*시키나 복잡성을 *축적*하진 않음(임계 끌개 맴돎). 사람급 복잡 적응계엔 다윈 동역학이 필요. **OEE 미해결** — 각은 있으나 도달 보장 아님.
