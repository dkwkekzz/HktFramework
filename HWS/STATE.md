## 4. DURABLE CONSTRAINTS — 모든 step이 지킬 정전(canonical) 사실

> 여러 step 이 *반복* 참조하는 불변만. 단일 step 의 발견·한계 전문은 `step-NNNN.md`(여기 누적 금지). 새 step 이 아래를 어기면 척추에서 벗어난 것 — 재설계.

**A. 모든 step 이 지키는 규칙**

- **회귀 0**: 새 항을 끄면(계수=0) 직전 step 과 **비트 단위 동일**(verify `reg`, maxDiff=0).
- **닫힌 장부**: E+R+T 보존 잔차 ≤ ~1e-13(미시 1e-6 / 거시 1e-7). *비가역 ≠ 비보존* — 상전이(E→R)·상태 비가역(FSM·a.soma)이라도 장부는 닫힘(0008).
- **결정론**: 같은 시드 2회 → 전 셀 비트 비교 + 상태 해시 일치. **`Math.random` 금지**(탐사·할당은 시드 의사난수 — "무작위"는 *구배와 탈상관*일 뿐 생성은 결정론, 0010).
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **law-pipeline 표준(0011~)**: 새 step = `hws-laws.js` 법칙 1개 + 노브 + `LAW_ORDER` 한 자리(노브=0 → early-return). 회귀 앵커 = 동결 *해시*(`verify-sim-engine.js` + `golden-sim.json`), 동결 파일 아님. 장부/해시 확장은 *미존재 시 no-op* 가법만(상태 라벨도 정의됐을 때만 해시에). (0001~0010 복사 코어 동결.)
- **격자 = voxel(0029~, VOXEL.md)**: 터는 W×H×D. 인덱스 `(z·H+y)·W+x`(z=0 평면 == 기존 2D 레이아웃)·x·y wrap·z 벽(클램프). **D=1 → 전 골든 해시 비트 불변**(z 이웃 없어 z 항 산술 0 = 회귀 0). 커널 3D 헬퍼(`discCells3`·`ballOffsets`·`tumbleHash3`)는 각자 z=0 슬라이스가 2D 등가물과 비트 동일(차원 일반화 = 진부분집합). 차원 확장은 *터의 진화*지 새 요소/필드 아님(단일 척추). **stencil 일반화(V2~)는 기존 법칙 *제자리* 확장 + 노브만**(새 법칙/슬롯 아님 — VOXEL.md §3 가 형식 권위): 모든 평면을 *같은 수치 스킴*에 대칭으로 넣어야 등방이 *비트 단위로* 정합(별도 z-법칙으로 쪼개면 z=0 평면[기존 law]과 상위 평면이 다른 스킴 → 등방 깨짐). 회귀 0 = 새 노브=0 *+* D=1 z-이웃 부재(이중 가드). z 쌍 거래는 상하 cancel → 보존(잔차 임계 동일).
- **z 확산 = 6-이웃(0030~, VOXEL V2)**: `diffuse` 의 선형 확산이 z=0 평면 → W×H×D 상자(노브 `kDz`, 기본 0). **kDz=0 또는 D=1 → z 항 산술 0 = 직전 step 비트 동일**. kDz=kD 면 등방(점 주입의 z-이웃 ≡ x-이웃, 상대오차 0). 안정(6-이웃): 4·kD+2·kDz ≤ 1. *등방 = 방향 없음* — 다른 법칙(증발·결정화·생명·기복)은 아직 z=0 평면.
- **중력 = z-비등방 하향(0031~, VOXEL V3)**: `gravity` 법칙 — 각 셀이 제 E 의 `kGravity` 비율을 *아래(z−1)* 이웃으로 유출(donor-제한 쌍 거래). **kGravity=0 또는 D=1 → gravity early-return/루프 빔 = 산술 0 = 직전 step 비트 동일**(이중 가드). z 오름차순 단일 패스(한 tick 한 칸 침전). 잔차 *정확히 0*(단일 하향 쌍 거래 비트 보존; V2 의 대칭 쌍 cancel 3e-15 보다 깨끗). *비등방=아래만* → E 가 z=0 바닥에 완전 침전(바다 원형). R 차폐(아래 R 막음)는 V5+. 방향 상수(아래)는 scan-order 류 법칙 상수지 전역 조율자 아님(z−1 로컬).
- **지지 침착 = R 의 중력(0032~, VOXEL V4)**: `crystallize` 의 E→R 침착에 지지 게이트(노브 `kSupport` 0/1·문턱 `supportThresh`). **kSupport=0 → 결정화 z=0 평면 + 게이트 무효 = 직전 step 비트 동일(모든 D)**; D=1 추가 가드(z=0 = 항상 바닥 지지). kSupport>0 면 결정화가 W×H×D 일반화되되 *지지 있는 칸*(z=0 바닥, 또는 아래 칸 R≥문턱)에서만 굳음 → 부유 R(공중 바위) 0·지면 바닥부터. 게이트는 침착 *위치*만 거름(양 안 바꿈) → 장부 무관(잔차 1.4e-15). *R 의 중력(지면)* = *E 의 중력(바다, V3)* 의 저장-축 짝(같은 "아래"에서 흐름은 고이고 고체는 쌓임). 부유 R 붕괴·R 차폐·다른 침착 게이트는 V5+.
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가.
- **척추 체크 4항**: ① 단일 척추(다양성은 병렬 필드 아닌 *속성*에 — 필드는 E 하나) ② 활성도 환원(authored type 분기 금지 — E 동역학은 태그로 안 갈림) ③ 국소 문턱(전역 조율자 0) ④ 순환 장부(비가역 상태라도 보존).
- **이산 FSM = 라벨이지 타입(0013, 결정3)**: 상태는 *활성도 배수의 함수*지 자유 태그 아님(labelViol=0). 별도 에너지 경로 분기 금지(스칼라 배수+게이트만). 이산성은 문턱·timescale 분리에서 창발 — anti-chatter 폭>0(burnOn>burnOff).
- **측정은 부작용 0 — 둘째 척추 금지(0014·0018)**: 활성도 A·막 측정은 동역학에 *되먹이지 않는다*(읽기 전용). 켜고 끔이 동역학을 비트 단위로 안 바꿈.
- **형태는 flux 의 하류 — 렌더러가 *지오메트리* author 금지([RENDER.md](RENDER.md) §6)**: 렌즈가 필드에서 읽는 건 색·재질·빛·흐름(E/R/A/G/∇E 함수) + *어느 양이 z냐*(물질 R)뿐, 형태(실루엣)는 아님. 형태는 시뮬(형태 사다리)이 빚어야 렌즈가 코드 0 으로 받는다.
- **개체는 author 아닌 측정(0017)**: 다세포를 `Organism{cells}` 컨테이너로 만들면 활성도 환원 위반. 개체 = 차등 응집이 빚은 표면장력 액적을 *4-인접 kin 연결 성분*으로 측정.
- **유전 = *이산* 정보의 자기복제(0015)**: 연속 필드(E·R·A)는 확산·EMA 로 번져 정보 못 지킴 — 이산 태그(G)만 복사 연산이라 세대 무한히 건너도 비트 보존. 유전은 저장 극단(R)의 능력이지 *생명 전용 아님*(별=느슨한 혈통·생명=단단한 복제, 결합 단단함으로 갈림).

**B. 반복 작용하는 발견(설계에 계속 작용 — 압축)**

- 동결 푸는 건 운동 아닌 *비균일성/불연속*(매끄러운 균일 표류 = 갈릴레이 불변, 0007). "능력 추가"는 정적 끌개 수렴 → *구조*를 바꿔야(0011 구동 내생화가 동결 풂).
- 구동 내생화는 동결 풀되 *공멸* 부름 → 자기제한이 닫음(0011→0012). 외부 source 의 고정성이 실은 carrying capacity 의 숨은 원천이었다.
- **carrying capacity = 개체수 아닌 *공간 분포*(0012)** — 자기제한을 *국소*(crowdR<채식지)로 주면 공멸 지연뿐. 채식지 척도(crowdR=starR)로 흩뜨려야 지속. **절제가 풍요보다 오래 산다**(혼잡세가 개체군을 영속).
- 별 연료 = 외부 질량(주입 경계); R 은 점화 *신호*(siting)지 소비 대상 아님(0011). 불은 연료 다해야 꺼진다(FN 빠른점화-느린소진, 0013).
- **흐름이 정체성보다 분류(0014)** — 저장체 활성도≈0 은 R 아닌 *흐름 끊긴 자리*의 성질(빈 배경도 같음). 별 연소 셀 100% R-rich 인데도 A 26배.
- **선택은 churn 을 조향하지 *구동*하지 않음 — 유전은 에너지 순환의 *승객*(0015·0016)**. 존재론 조각(유전·개체·막·협동·분화·정착·형태)은 동역학을 안 깬다(0013~0025 직교성 — 새 법칙=노브0 회귀0·쌍 거래 보존).
- 죽음이 있어 선택 더 날카로움 — *생명*(소산 가운데)이 *R*(저장 극단)보다 다윈 무대로 알맞음(선택비 3.27 vs 1.53, 0016). 동결 안 되는 회전이 누적 선택의 조건.
- **유전이 개체보다 먼저**(kin=a.g 정의돼야 다세포 묶임, 0017). DAH(세포)=Schelling(사회) 한 알고리즘이고 개체는 percolation 아닌 *능동 정렬*의 산물.
- **흩어진 협동은 중립 아닌 *해롭다* — kin 구조가 협동보다 먼저(0019)**. *어떻게* 공유하나(표적 구조 vs 균등화)가 b>c 를 가르고, *비평형*(기근)서만 선택압. 공공재는 *풍요*의 자식 / risk-pooling 은 *위기*에(0019·0020 두 보완 국면). 비용 회수 가능(m→m)+시너지라야 강한 침투(0020).
- **분화는 *조밀함*의 자식**(전체 스택 희소라 거의 안 켜짐 — 정착이 전제, 0021·0023). soma 는 손실 아니라 *사장 자원의 회수*(0021). 번식 격리(Weismann)는 author 분기 아닌 *창발*(soma 가 m 비워, 0022). 정착성 생활사는 *안정 자원*의 자식 — 떠도는 자원엔 운동성이 답(0023).
- **차등 응집이 곧 표면장력(DAH)** — position 곡률은 redundant, R2 는 *바닥 필드 E* 에(형태는 흐름의 하류, 0024). 같은 침착 법칙에 *방향*만 더하면 등방 blob ↔ 이방성 needle(0025). **둘째 필드 없이도 Turing** — 확산 E·비확산 R 의 *차등 이동성*이 곧 Turing 전제(R4, 0026): 짧은 활성은 R *근방 커널*(없으면 격자 체커보드)·전체 스택 churn 은 *활성 포화*가 능동적으로 지킴(필드 법칙이라 자연 게이트 없어 큰 R 위 무한 sink → 포화가 차단). **Mullins-Sekerka 도 같은 템플릿을 *전선*에**(R5, 0027): 기하 차폐(확산 E·긴 억제 — 자라는 셀이 제 E 비우면 볼록 tip 만 바깥서 채워짐)+곡률 증폭(짧은 활성 — 볼록 tip 침착 가속)이 평탄 전선을 옆가지로(거칠기 1.67→24.56). 곡률 증폭 *없으면* 컴팩트(R4 의 "근방 커널 필수"와 같은 형태)·*저-E*라야 가지가 멎어 빈틈 남음(고-E 면 메워 컴팩트 폭주 — "덜 먹여야 가지가 산다")·전선만 자라 직교성 *자연* 보존(turing 의 포화 능동 방어와 대비).
- **막의 능동성은 *세기*가 아니라 *정류*(방향 대칭 깨짐)에서 온다(0028)** — couple(수동·양방향 균등화)은 농도 차를 못 세우나(안≈바깥, ratio≈1), permeate(정류·일방향 import)는 확산이 평형으로 되돌려도 *안>바깥*을 **유지**(농도비 1.00→3.12). 막은 *평형에 맞서* 일한다(far-from-equilibrium 능동 경계 = 죽은 돌[평형] vs 살아있는 세포[농도 차 유지]의 차이 — 형태를 넘어 *능동성* 첫 발현, 단 throughput 의 대가). R4/R5 의 *공간* 대칭 깨짐을 *흐름 축*에 적용. 막은 *kin 액적 표면*에서만 창발(외톨이 게이트 → 전체 스택 benign·직교). 단일 E 라 "선택"은 *방향*(import vs retain)일 뿐 — *무엇* 선택(화학적 선택성)은 다중 자원 선행.
- 소산구조 ≠ 진화하는 복잡계 — 비평형 throughput + 임계 자기조직(0012)은 *지속*시키나 복잡성을 *축적*하진 않음(임계 끌개 맴돎). 사람급 복잡 적응계엔 다윈 동역학이 필요. **OEE 미해결** — 각은 있으나 도달 보장 아님.
