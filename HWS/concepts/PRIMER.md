## 1. 세계엔 숫자 하나뿐 — 흐름량 E

격자 모든 칸에 **E(흐름량)** 라는 숫자가 있다. 자원·에너지의 양이라고 보면 된다. 별도 바위도 생명도 *따로 코딩된 종류가 아니다* — 전부 이 E 하나가 만드는 패턴이다. 다른 점은 단 하나, **그 자리에서 에너지가 얼마나 활발히 흐르는가(활성도)**:

```
   활성도 낮음 ◄─────────────────────────────► 활성도 높음
   (저장·평형)            (가운데)              (소산·방출)
      둑 R                 생명                    별
   광물·바위            먹고 흘림              불·확산
   "주차된 에너지"     "흐름 통과 패턴"       "쏟아내는 에너지"
```

같은 에너지가 **굳어 멈추면 둑(저장)**, **활활 흐르면 별(소산)**, 그 가운데서 흐름을 통과시켜 자기를 유지하면 **생명**이다.

---

## 2. 봉우리란? — E의 지형, 그리고 먹이터

E의 분포를 값의 높낮이로 그려 보면 봉우리와 골이 보인다. **봉우리 = 주변보다 E가 많이 쌓인 곳**(국소적으로 값이 높은 자리). *주의: 이건 E 값을 그래프로 그린 것이지 화면 높이가 아니다 — 현재 렌더는 E를 밝기로 보이고 높이는 R 만 만든다(시점 안내 참조).*

```
E  ▁▁▂▃▅▇█▇▅▃▂▁▁▁▁▂▃▄▃▂▁▁
          ↑           ↑
        봉우리      작은 봉우리
```

- **봉우리 자체**는 "E가 높은 지점".
- **운동을 일으키는 건 "차이"(기울기)** — 옆 칸과의 E 차이. 생명은 더 높은 E 쪽으로 기어오른다. 그래서 차이가 생명을 *밀고*, 그 차이가 모여드는 꼭대기가 봉우리다.

생명은 E를 먹고 산다 → **봉우리 = 먹이터**. 생명은 봉우리에 모여 먹고 번식한다.

> 주의: *먹이 봉우리(E)*와 *지형 언덕(R=둑)*은 정반대다(§4) — 하나는 흐르는 먹이, 하나는 굳은 고체. (옛 2.5D 화면은 `E + 기복·R`을 모두 높이로 그려 둘이 비슷해 보였지만, **현재 렌더는 높이를 물질 R 만 만들고 E 는 밝기로 보여** 구분이 분명하다 — VOXEL.md V-B.)

## 3. 별이 하는 일 — 떠도는 먹이터를 만든다

옛날(step-0010까지)엔 외부 **source**가 한자리에 E를 부어 *영원히 고정된 봉우리*를 만들었다. 생명이 다 거기로 모여 멈춰버렸다(동결). step-0011의 **별**은 이 고정 봉우리를 *떠도는* 봉우리로 바꾼다. 별의 한살이:

1. **점화** — 굳은 저장체 R이 어딘가 충분히 쌓이면, 그 자리에서 별이 켜진다(가스가 뭉쳐 별이 되듯).
2. **주입** — 별은 매 tick 주변에 E를 부어 넣는다. *이게 봉우리(먹이터)를 세우는 행위*다.
3. **서행** — 별은 천천히 한 칸씩 기어간다 → 봉우리도 같이 이동 → 생명이 쫓아다니며 **끝없이 나고 죽는다(churn)**.
4. **소진** — 연료가 다하면 꺼진다(비가역). 다른 곳에서 새 별이 켜진다 → 봉우리가 **명멸하며 떠돈다**.

결과(verify 수치): 외부 고정 source 대비 churn **634배**, 무게중심 떠돎 **20배**. 고정된 수렴점이 사라졌다.

## 4. 둑 vs 별 — 같은 축의 양 끝

`둑 쌓기`는 클릭한 자리에 **R(저장체)** 을 칠한다 — *흐르는 E(먹이)가 아니라 굳은 저장*이다.

| | **둑 (R, 저장체)** | **별 (star)** |
|---|---|---|
| 극단 | 평형(저장) | 소산(방출) |
| 활성도 | ≈ 0 (가만히 쌓임) | 높음 (E를 쏟아냄) |
| 하는 일 | 지형을 만든다(기복) | **먹이 봉우리(E)를 만든다** |
| 생명에게 | 못 먹음 (고체) | 먹임 (별이 뿜은 E) |
| 운동 | 부동 | 서행·필멸 |
| 비유 | 장작 산·광물 | 모닥불 |

**둘 다 에너지지만**, 하나는 가만히 주차된 것, 하나는 활활 내보내는 것. 둑은 높이 솟아도(3D 지형 `E+기복·R`) *먹이가 아니다* — 생명을 놔도 안 모인다.

---

## 5. 둑은 별의 요람 — R → 별 → E → R 순환

둑과 별은 무관하지 않다. **둑(R)이 점화 문턱을 넘으면 그 자리에서 별이 켜진다.** 빈 세계에 둑을 쌓고 가만 두면:

```
둑 쌓고  +100tick:  별#=2  ← 별이 둑 위에 켜졌다
        +500tick:  별#=9  sumE 4099→6267 ← 별들이 세계를 먹이기 시작
```

그리고 R은 거의 안 줄어든다 — 소비되는 게 아니라 *별이 설 자리를 알리는 신호(요람)*다. 완전한 고리:

```
둑(R) 쌓임 → 별 점화 → 별이 E 주입 → E 퍼져 다른 곳에 다시 R로 굳음 → 새 둑 → 새 별 …
```

**둑은 별의 차가운 요람, 별은 둑이 깨어난 뜨거운 모습.** 둑을 쌓는 건 곧 "여기에 다음 별을 심는다".

## 6. 에너지는 사라지지 않는다 — 보존과 과증식

생명 1개를 풍요로운 세계에 놓으면 봉우리가 싹 사라지며 폭발적으로 증식한다. **에너지가 사라진 게 아니다** — 장부 잔차가 계속 PASS(~1e-12). 봉우리가 *옮겨간* 것이다:

```
t=0    pop=  1   필드E=9818 ← 밝은 봉우리들
t=200  pop=395   필드E=1344 ← 봉우리 사라짐(수백 마리가 먹어치움)
```

먹힌 E는 세 갈래로 갔다:
1. **생명의 몸(M)** — 일부는 생물량(노란 원들)이 됐다.
2. **대사로 태워짐** — *대부분*. 수백 마리를 먹여 살리는 유지비로 "체열"처럼 흩어졌다(장부엔 기록, 보존).
3. **저장체 R에 잠김** — 세계 에너지의 *절대다수*는 R(굳은 저장)에 안전하게 잠겨 있다. 생명은 흐르는 E만 먹지 R(고체)은 못 먹는다.

> **세계가 에너지 바닥난 게 아니다** — 오히려 R에 가득하다. 다만 *먹을 수 있는 형태(필드 E)*만 폭발한 생명이 순식간에 훑었을 뿐.

이게 step-0011의 **과증식(overshoot)**이다: 외부 source 세계는 고정 공급이 상한(K≈11)을 만들지만, 내생 별 세계는 그런 음성 피드백이 없어 1마리가 뷔페를 만나 폭발 → 필드를 비운다.

### 그리고 왜 결국 *텅* 비는가 — 엔진이 멈추면 열죽음

과증식으로 끝나지 않는다. 한참 두면 생명도 별도 저장체도 *전부* 사라져 죽은 세계가 된다. 왜?

세계엔 **들어오는 길 하나 + 나가는 길 둘**뿐이다. 그리고 나가는 길은 *일방통행*이다 — 대사·증발로 흩어진 에너지는 장부엔 기록되지만(보존) 다시 못 쓴다(체열처럼).

```
        ┌──────────── 별 주입 (유일한 입력) ────────────┐
        │                                               ▼
   [ 별 ] ──연료(외부 질량)──►  E (흐르는 먹이) ──► 생명이 먹음
                                  │                      │
                              증발(일방) ◄──┘          대사(일방)  ← 못 돌아옴
```

세계의 일생(실측, 시드 42):

```
tick   생명 별#   활성E(E+M+R)   별 주입(누적)   대사로 태움(누적)
4000     5  10      42332          68715              0       ← 별이 채운 풍요
8000   214  10      12554         138158          95659       ← 생명이 맹렬히 태움
12000  217  10       6624         207335         167733       ← 저수지 거의 고갈
────────────────────────── 붕괴 ──────────────────────────
13000    0   0       2837         214500(정지)    175198(정지) ← 별·생명 동시 전멸
16000    0   0       1220         214500          175198       ← 잔불도 증발로 사라짐
```

붕괴의 3단계:

1. **생명이 과식 → 제 식량원(별)을 죽인다.** 생명이 흐르는 E를 *굳기 전에* 먹어치우면 E가 R로 못 쌓인다. 그런데 R이 **별의 점화 신호(요람)**였다 → R이 안 쌓이니 새 별이 못 켜진다.
2. **별이 꺼지면 입력이 끊긴다.** 기존 별들이 연료를 다 태우면(~290 tick) 꺼지는데, R 고갈로 새 별이 안 켜져 → **주입이 멈춘다**(표: 주입이 214500에서 정지). 유일한 동력이 사라진다.
3. **입력은 끊겼는데 새는 건 계속.** 별이 채워둔 거대한 저수지를 생명이 *주입보다 빠르게* 태우고(대사 167733 > 별이 보탠 양) 있었다. 입력까지 끊기자 남은 E·생명·저장이 전부 대사·증발로 빨려나간다 → 마지막 잔불(E+M+R 2837→1220)도 식어 사라진다.

> **한 줄: 세계는 "별이라는 엔진"이 돌아야만 사는 *열린 계*다. 생명이 과식으로 그 엔진을 꺼뜨리자, 열역학 2법칙(대사·증발의 일방통행)이 나머지를 전부 흩어버렸다.** 에너지가 *사라진* 게 아니라 못 쓰는 형태로 옮겨가 세계가 식은 것. SPINE의 "구동 없는 세계는 *반드시 죽는다*"의 실연이다(구동 off 11000 tick → sumE 0.068, [04-drive.md](../step-0001/04-drive.md)).

*동결을 풀었더니 이번엔 과식으로 엔진을 꺼뜨려 죽더라* — 다음 step의 숙제는 **자기제한**: 생명이 과식하지 않게 묶으면(밀도 의존 음성 피드백) 식량원(별)을 안 죽이고 churn이 *끝없이* 이어진다. 동결(너무 적음)도 공멸(너무 많음)도 아닌 *임계 자기조직*.

## 7. 광물이 *제 사본을 베끼는* 날 — 유전 (이미 sim 에 들어왔다)

> 앞 §1~6 은 별 엔진이 돌리는 *지금 돌아가는 세계*(step-0011~0012). 이 절의 유전은 한때 "다음 이야기"였으나 **이제 sim 에 실현됐다**(step-0015 둑 R 위 · step-0016 생명 위). "생명을 어떻게 더 키울까"의 답이었고, 그 위에서 step-0017 이 *개체(다세포)*를 세운다(§8).

지금 세계는 **살아있다** — 별 엔진이 돌면 생명이 끝없이 나고 죽는다(churn). 그런데 *늘 똑같이* 돈다. **더 복잡해지지 않는다.** 눈송이가 아무리 정교해도 진화하지 않고, 모닥불이 아무리 화려해도 *자식을 안 남기는* 것과 같다. "끝없이 도는 것"과 "점점 복잡해지는 것"은 다르다.

진짜 *사람 같은* 복잡한 것이 나오려면 한 가지가 더 있어야 한다 — **유전**:

```
부모를 닮은 자식  +  조금씩 다른 자식  +  잘 사는 쪽이 더 퍼짐   =   진화(점점 복잡)
   (유전)            (변이)              (선택, 이미 있음)
```

지금 생명은 자식에게 **크기(m) 하나**만 물려준다. 그건 *설계도*가 아니라 그냥 덩치다 — 닮음을 만들 *정보(genotype)*가 없다. 그래서 임계상태를 맴돌 뿐 못 자란다.

### 기억은 *가만히 있는 것*에만 새긴다 — 그래서 유전은 둑(R) 쪽에 산다

유전은 *기억*이다. 그런데 기억은 **활활 타는 불(별)엔 못 새긴다** — 흐름이 글씨를 매 순간 지워버린다(§1 활성도: 소산은 흐름이 격렬). 글씨는 **가만히 굳은 것(둑 R·광물)** 에만 남는다. 그래서 유전은 *별(소산)이 아니라 둑(저장) 쪽*에 산다.

이건 실제 생물학 그대로다 — **DNA(설계도)는 가만히 보관되는 "광물 같은 결정"**이고, **대사(살아가는 일)는 활활 타는 불**이다. 생명이란 *둑(설계도)과 불(대사)을 한 몸에 단단히 묶은 것*이다(§1 "가운데").

### 그럼 광물이 유전을 하나? — 그냥 바위는 아니다

여기서 헷갈리기 쉽다. 둑·광물이 저장이라고 *광물이 곧 유전*은 아니다:

| | 저장(가만히 있음) | **제 모양을 베낌** | 유전? |
|---|---|---|---|
| **바위·광물** | ✅ | ❌ 그냥 앉아만 있음 | **없음** |
| **씨앗·결정 주형** | ✅ | ✅ 제 무늬를 옆에 새김 | **있음** |

**유전 = 저장 + 자기복제(베끼기).** 그냥 바위는 저장만 하고 제 모양을 복제하지 않으니 유전이 없다. *씨앗처럼 제 무늬를 옆 칸에 베껴 새기는 특별한 결정*만 유전을 한다(실제로 결정은 씨앗에서 같은 격자를 베끼며 자란다 — 원시적 복제!). 그래서:

```
그냥 바위  →  제 무늬를 베끼는 결정  →  유전자(DNA)
(유전 0)        (원시 유전)            (정교한 유전)
```

벽이 아니라 **연속선**이다. DNA도 알고 보면 *제 사본을 베끼는 법을 배운 광물*일 뿐 — 이게 생명의 기원이다(광물이 먼저, 생명은 그 위에서 깨어남).

### 별도 유전하나? — 느슨하게, 남긴 재로

별은 불꽃이라 *제 몸엔* 기억을 못 새긴다. 하지만 **죽으며 남긴 재(R·원소)가 다음 별이 설 자리를 정한다**(§5 둑이 별의 요람). 실제 우주에서 1세대 별이 만든 무거운 원소가 2·3세대 별의 재료가 되듯(태양도 그 후손이다). 그러니:

- **별**: 남긴 *재(둑)* 로 — **느슨한** 유전.
- **생명**: 제 설계도를 *직접 베껴* — **단단한** 유전.

유전이 "있다/없다"가 아니라 **얼마나 단단히 묶였나**의 차이다. 별도 생명도 결국 *둑(저장)을 통해* 대물림한다 — 이름이 아니라 *역할*로 갈리는 이 세계의 규칙 그대로(§1).

> **한 줄: 유전은 생명만의 것이 아니라 "둑(저장·광물)의 능력"이다. "제 사본을 베끼는 법을 배운 광물"이 곧 유전자이고, 거기서 생명이 시작된다.** 이게 세계가 *끝없이 돌기*(§1~6)를 넘어 *점점 복잡해지기*(사람 같은 것)로 가는 문턱이었고, sim 이 그 문턱을 넘었다.
>
> **이미 된 것 / 정직**: 유전·변이·선택·적응은 sim 에서 *수치로* 확인됐다(상속 충실도 1.00·적합한 유전형이 부적합을 2배 빠르게 치환·평균 적합도 +0.31, step-0016). 다만 적합도 지형이 *단봉*(authored)이라 *정말 사람만큼* 열린 복잡성으로 갈지는 아무도 못 풀었다(열린 진화 OEE 는 미해결 난제) — 길은 보이지만 도착은 보장 못 한다.

## 8. 개체(다세포) — 같은 색끼리 뭉치면 한 '몸'이 된다

> 지금까지 "생명"은 격자 한 칸짜리 **점**이었다(0-D — 형태·안팎이 없다). §7 의 유전이 각 생명에게 **유전형 = 색**을 달아줬다(빨강·초록·파랑·보라). step-0017 은 그 위에서 점들을 묶어 *다세포 개체*를 만든다. 단 **만들지 않고 측정한다** — 이게 핵심 트릭이다.

### 자석이 아니라 "끼리끼리 이사 가기"

전역적으로 "이 다섯 개를 한 몸으로 묶어라" 하는 명령은 *없다*. 대신 **점 하나하나가 자기 주변만 보고** 한 칸씩 이사하는 국소 규칙(`adhere`) 하나만 깐다:

```
매 tick, 각 생명(점):
  내 주변 8칸을 본다
  "나와 같은 색 이웃이 더 많은" 빈 칸이 있으면 → 거기로 한 칸 이사
  (점수 = 같은 색 이웃 수 − λ·다른 색 이웃 수)
  ※ 위치(x,y)만 바꾼다 — 먹이도 몸도 안 건드림(장부 거래 0)
```

모두가 동시에 이걸 하면 — 빨강은 빨강끼리, 보라는 보라끼리 저절로 **덩어리(액적)**로 뭉친다. 물과 기름이 섞였다가 갈라지는 것, 또는 사람들이 끼리끼리 동네를 이루는 것(셸링의 분리 모델)과 *똑같은 규칙*이다. 코드에 "표면장력"이나 "막"을 박지 않았는데도, 같은 색이 안으로 모이고 다른 색을 바깥으로 밀어내며 경계가 최소화된다 = **표면장력 액적이 창발**한다.

```
응집 전(무작위 섞임)              응집 후(끼리끼리 갈림)
  ● ▲ ● ▲ ▲                       ● ● ●   ▲ ▲
  ▲ ● ▲ ● ●          ───►         ● ● ●   ▲ ▲ ▲
  ● ▲ ● ▲ ●                       ● ●     ▲ ▲
  (●빨강 ▲보라 무작위)            (같은 색 블롭 = 액적)
```

### "개체"는 물건이 아니라 *세어낸 값*이다

그럼 다세포 개체는 어디 있나? **메모리 어디에도 `Organism` 객체가 없다.** 개체 = *"같은 색이면서 서로 붙어 앉은 점들의 무리"* 를, 필요할 때마다 세어낸 **측정값**이다(`measureOrganisms`):

```
붙어 앉은 같은 색 점들을 한 그룹으로 묶는다 (섬 세기 = union-find)
  → 그룹 하나 = 개체 한 마리
  → 그룹에 든 점 개수 = 그 개체의 "세포 수"
```

보라 점 5개가 4-인접으로 붙어 있으면 → "세포 5개짜리 개체 1마리". 떨어진 점 하나는 → "단세포". 생명이 죽으면 무리는 저절로 흩어지고, 새 생명이 붙으면 커진다. **개체가 따로 태어나거나 죽지 않는다 — 점들의 배치를 읽으면 그때그때 드러날 뿐.**

| | 보통 게임 | 이 세계(step-0017) |
|---|---|---|
| 다세포 개체 | `class Organism { cells[] }` 객체를 만든다 | **자료형 없음** |
| 개체란 | 메모리에 존재하는 물건 | 붙어 앉은 점들의 **연결 성분**(측정) |
| 세포 수 | 배열 길이 | 무리에 든 점 개수 |

### 왜 이렇게 비틀었나 — "이름이 아니라 역할"

§1의 대원칙 때문이다: 모든 것은 에너지 E 하나의 패턴이어야 하고, 새 *자료형*(별·바위·생명에 이어 "개체")을 또 추가하면 안 된다. 그래서 개체를 **만드는** 대신, 점을 뭉치게 하는 *국소 규칙 하나*만 깔고 개체는 **세어 읽는다**. (화면에서 같은 색 점들을 잇는 선이 바로 이 "한 개체 = 연결 성분"이다.)

수치(verify): 무작위로 섞은 두 색을 응집시키면 같은 색 접촉 비율이 **0.51 → 0.95**(응집 끄면 0.51 동결), 개체 평균 **4.5세포**·최대 **21세포**(응집 끄면 1.7·11 — 우연히 붙은 잔덩어리의 2.6배).

> **한 줄: 다세포 = 같은 색 점들이 끼리끼리 한 칸씩 모여(국소 규칙) 만든 덩어리를, "붙어 있는 같은 색 점 무리"로 세어낸 것. 개체라는 물건은 없고, *붙어 앉은 점 무리*를 개체라 부른다 — 만들지 않고 측정한다.**
>
> **정직**: 아직은 *공간 군집*일 뿐이다. 무리 안의 세포가 역할을 나누지(생식/체세포 분업) 않고, 뭉쳐도 생존 이득이 없어 **진화적으로 중립**이다(다음 숙제 = 개체↔대사 결합으로 개체에 *이득*을 줘 한 몸으로 선택받게 하기). 막(膜)도 아직 *측정 선*일 뿐 물리적 경계는 없다.

## 9. 현실 비유

| 이 세계 | 현실 (느슨한 비유) |
|---|---|
| 흐름량 E | 에너지 일반 (열·빛·자원) |
| 봉우리 (E 높은 곳) | 먹이가 풍부한 자리 |
| 둑 / R (저장체) | **광물·암석·연료·씨앗** — 굳어 멈춘 에너지. 별이 태어나는 *짙은 가스·먼지 구름*에 가장 가깝다 |
| 별 | 항성 — 짙은 구름이 붕괴해 점화, 빛을 쏟다 연료 소진하고 꺼짐 |
| 생명 | 흐름을 통과시켜 자기를 유지하는 소산구조 |
| R→별→E→R 순환 | 가스구름 → 별 → 빛 → 식어 먼지 → 새 구름 (우주의 물질 재활용, *형태만* 닮은 비유) |

핵심: **"광물"은 따로 코딩된 종류가 아니라, E가 얼어붙은 저활성 phase에 붙이는 *역할 이름*이다.** 흐르면 불, 굳으면 광물 — 같은 에너지의 두 얼굴.

## 10. 화면에서 직접 해보기 ([step-0011.html](../step-0011.html) · 개체는 [step-0017.html](../step-0017.html))

- **둑 → 별**: `둑 쌓기`로 한 곳을 두텁게 칠하고 재생 → 잠시 뒤 그 위에 별(밝은 백황색 코어)이 점화한다. 저장이 소산으로 깨어나는 순간.
- **떠도는 봉우리**: `별 씨앗 ×6` → `생명 ×5` → 생명이 떠도는 별을 쫓아 폭발적으로 churn, 무게중심(자홍 십자)이 떠돈다.
- **보존 확인**: 통계 패널에서 `sumE`가 떨어지는 만큼 `M`(생명 몸)이 오르고 **장부 잔차는 계속 PASS** — 에너지가 *이동*했지 사라지지 않았다는 증거.
- **과증식 관찰**: 한참 두면 생명이 과식해 봉우리를 비우고 → 별이 꺼지고 → 공멸. `분열 mDiv`나 `baseCost`를 올리면 폭발이 느려져 더 오래 churn을 볼 수 있다.
- **개체(다세포) 보기** ([step-0017.html](../step-0017.html)): `혼합 군집`을 놓으면 빨강·보라 점이 무작위로 섞여 있다가 *같은 색끼리 액적으로 갈린다*. 같은 색 4-인접 점을 잇는 선이 곧 *한 개체*(연결 성분). 우측 "개체 (수/평균/최대 세포)"가 *적은 수·큰 크기*로 가고 "kin 접촉"이 0.5→0.9+로 오른다. `차등 응집` 체크를 끄면 점들이 안 묶여 0-D 점(step-0016)으로 돌아간다.
