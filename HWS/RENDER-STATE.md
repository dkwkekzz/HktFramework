## 1. NOW — 켜진 렌즈 (`engine/hws-3d.js` — `progV` voxel 세계 · `progT` 레거시 하이트필드)

**L-V1 전환 완료**: 시뮬이 voxel(W×H×D)이라 우측 뷰가 **진짜 3D voxel 세계**로 바뀌었다 — 형태(높이)는 더 이상 렌더러의 발명이 아니라 **sim 의 사실**(R 점유 = 기하). 좌측은 레거시 2.5D 하이트필드(z=0 바닥 슬라이스)로 대비 보존. **눈 검증 PASS**(사용자 브라우저 확인 — voxel 정상; 셰이더 4종 컴파일·4 렌즈 표시 확인. "시뮬 동역학이 좀 이상"은 시뮬 트랙 사안 — 렌더러는 *읽기만* 하므로 직교).

**우측 = voxel 세계 (`progV` — L-V1)**:
- ✅ **R 점유 인스턴스드 큐브**: R(또는 의미있는 E)이 있는 칸만 단위 큐브 1개로 — 빈칸=void(생략). 위치 = sim `(x,y,z)`(sim-z=월드 위, 중력 방향 z=0 바닥). CPU 가 매 프레임 점유 칸을 스캔해 인스턴스(셀+필드) 빌드 → `drawElementsInstanced`. *형태 발명 0*(VOXEL V-A).
- ✅ **E 밝기(VOXEL V-B)**: 고도 표현 폐기. 흐르는 E(고활성 A)=발광 큐브(클수록 밝게)·고인 E(저활성)=파란 물 voxel(깊이로 청록↔남빛).
- ✅ **승계 렌즈(차원만 큐브로)**: 상 3분기(고체/액체/빛·lerp 0)·조성 `G` 절차적 해시 색(나무/결정 ↔ 돌)·밀도(R)·생명 발광 점·별 FSM 이산 재질(kindling/burning/ash) — 별은 **부력 z**(step-0035)로 천장까지 떠오른 제 높이에 그려진다.
- ✅ **L-V2 물 볼륨**: 물 큐브를 *반투명*으로(불투명 먼저 → 물 블렌드, 뒤 큐브 비침). 깊이(고인 E)로 Beer-Lambert 흡광(`transmit=exp(-depth·absorb)`·얕음 청록·깊음 남)·표면 프레넬(`uEye` 시선 비스듬할수록 반사↑·하늘색)·깊이 알파(얕음 투명·깊음 짙음). 쌓인 물 voxel 이 블렌드로 누적돼 *볼륨감*. 불투명 voxel 은 `vWet=0` → 불변.
- ✅ **L-V3 `∇R` 거칠기**: 고체 큐브 면 노멀을 R 6-이웃 라플라시안(`|∇²R|` 고주파)으로 변조 — 들쭉날쭉한 R=거친 암석·매끈한 R=매끈. CPU 가 인스턴스에 `rough` 실어 보냄(8번째 float)·FS 가 서브셀 해시(`hash33(floor(vWorld·6))`)로 facet 흔듦. 높이 불변(셰이딩 노멀만·도함수 읽기)·물/빛 큐브 `rough=0` 불변.
- ✅ **L-V4 `∇E` 바람**: 빛 큐브 발광을 `∇E` 하류 방향(고E→저E)으로 `uTime` 이류 띠로 변조 — 흐르는 에너지의 *세기*에 더해 *방향*. CPU 가 셀별 ∇E 중앙차분을 월드 좌표로 인스턴스에 실어 보냄(9~11번째 float)·FS 가 `dot(vWorld,fdir)` 위상 + 시간 이동. 코어 불변(도함수 읽기)·무흐름/저활성 `flowVis=1`(발광 불변).
- ✅ **L-V5 `∇²E` 안개·응결**: *빈칸*(void)의 미량 E 가 수렴(`∇²E<0` = 국소 peak)하는 자리에 부드러운 점 스프라이트(가우시안 falloff·푸른 흰빛·알파-오버)를 깐다 — 겹쳐 쌓여 *볼류메트릭 안개*(응결). CPU 가 빈칸 6-이웃 E 라플라시안을 재 농도(`-∇²E × 미량 E`)로 별도 점군(`bufFog`)에 모음·물 뒤·점 앞에 깊이 테스트 on·쓰기 off 로 그림. 진짜 raymarch(3D 텍스처)는 정제 백로그 — 점군 근사.
- ✅ **voxel 픽킹**: voxel 뷰포트(분할 하단) 클릭·호버가 *점유 큐브에 레이캐스트*(고정 스텝 행진·인스턴스 빌드와 같은 점유 판정) → 첫 충돌 셀 `(x,y,z)`. 호버 HUD 가 z·A 까지 표시(시뮬 진단용). 레거시 하이트필드 뷰는 기존 하이트필드 레이마칭 유지(`camRay` 공유 — 타깃 y=cam.cy 로 D>1 프레이밍 정합).
- ✅ **3D 오버레이**: 도메인 박스 와이어프레임(W×H×D)·source/sink 수직 기둥+바닥 링·무게중심 기둥·호버 voxel 큐브를 voxel 월드 좌표로(`buildLines3D` — 별도 `bufLnV`). 깊이 테스트 on(공간감)·쓰기 off. 레거시 뷰의 하이트필드 마커(`buildLines`)와 뷰별 다른 버퍼(`vaoL`/`vaoLV`).

**좌측 = 에너지 변위 (`progT` — 레거시 2.5D)**: z=0 바닥 슬라이스 하이트필드(h=E+R) + 표준 오버레이(링·빔·경계·호버). "옛 착시 ↔ 새 정직한 voxel" 교육 대비.

**RETIRED (`progW` 2.5D 세계해석 — 더 이상 컴파일 안 됨)**: 물 막 흡광·프레넬·`∇R` 거칠기·`∇E` flowmap·`G` 해시 — 수식은 코드에 *참조 보존*, voxel 재구현은 L-V2+.

## 4. DURABLE — 렌더러 트랙 불변

- **형태 author 0** — 필드가 만든 것만 비춘다. *어느 양이 z·색·빛이 되는가*는 읽기(허용), *양의 분포 재성형*은 author(금지). 도함수·필터(∇R·∇E)는 읽기. **voxel(L-V1~) 에선 더 강해짐**: 위치=sim `(x,y,z)` 그대로 — 렌더러가 높이를 *발명조차 안 한다*(R 점유 = 기하, VOXEL V-A).
- **z = 물질(R) only** — 에너지(E)는 흐르든 고이든 z 를 안 만든다(응축상 R 만 공간 점유). 2.5D 에선 `hOf(R)`, **voxel 에선 sim-z 가 곧 월드 위**(중력 방향 z=0 바닥). E 는 색 밝기로만(VOXEL V-B). RENDER §2·§5.
- **voxel 렌즈(L-V1~)**: `progV` 인스턴스드 단위 큐브 — CPU 가 매 프레임 *점유 칸*(R>0.08 또는 의미있는 E)을 스캔해 인스턴스(셀+필드+거칠기+∇E, 11 float) 빌드 → `drawElementsInstanced`. 분류 문턱은 CPU 방출 == VS 색칠(불일치 0). **두 패스(L-V2)**: 불투명(고체·빛, `vaoV`) 깊이 쓰기 on 먼저 → 물(반투명, `vaoVW`) 깊이 쓰기 off·블렌드 on 나중(뒤 큐브 비침). `vWet` varying 이 프레넬·알파를 게이트(불투명은 불변). **이웃 도함수(L-V3·L-V4·L-V5)**: ∇²R(거칠기)·∇E(바람)·∇²E(안개) 같은 이웃 필요 양은 *CPU 빌드*가 6-이웃에서 계산해 인스턴스에 실어 보낸다(셰이더는 셀별 인스턴스라 이웃을 못 봄 — 텍스처 샘플 대신 사전계산·월드 좌표로 매핑). **빈칸(void)은 큐브 0** 이되 ∇²E 수렴 자리는 *별도 점군*(`bufFog` — 큐브 아닌 부드러운 스프라이트)으로 안개를 얹는다. 좌측 레거시 하이트필드(`progT`, z=0 슬라이스)는 교육 대비로 보존. 점/별은 `uVoxel` 로 높이 분기(sim-z ↔ 하이트필드). 성능: 점유 스캔 O(W·H·D)·greedy meshing 백로그.
- **소유 파일**: `engine/hws-3d.js`(+ 프레젠테이션 한정 `hws-ui.css`/`hws-ui.js`) · `RENDER.md` · `RENDER-STATE.md`. **불가침**(시뮬 소유): `hws-laws.js`·`hws-kernel.js`·`hws-sim.js`·`golden-sim.json`·`step-NNNN/*`·`STATE.md`·`SPINE.md`.
- **검증 3종**: ① `node engine/validate/verify-sim-engine.js` 골든 해시 불변(=시뮬 안 건드린 알리바이) ② `node engine/validate/smoke-dom-3d.js` 3D 스모크 ③ **눈 검증**(화면이 권위) + 척추 한 항(형태 author 0).
- **필드 있으면 읽고 없으면 no-op** — 시뮬 step 진행과 독립. 필드에 형태가 실리면 렌즈가 코드 0으로 받는다.
