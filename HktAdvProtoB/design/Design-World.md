# 세계 기반 형식 — 상태와 규칙이 세계의 전부다

이 문서는 트랙의 가장 아래층이다: 세계가 무엇으로 되어 있고(상태), 무엇이 그것을 바꾸는가(규칙). 위층 문서([Design-Life.md](Design-Life.md) 생명·종, [Design-Ability.md](Design-Ability.md) 능력)는 전부 이 형식 위에서만 정의된다 — 이 문서에 없는 형식을 위층이 발명하면 재설계 대상이다.

## 1. 세계관 스택 — 다섯 층이자 생성 순서

```text
세계관 [ ① 세계 공간 → ② 세계 규칙 → ③ 주체 → ④ 생존 경쟁 → ⑤ 성장 ]
```

| 층 | 정의 | 형식 (이 문서) |
|---|---|---|
| ① 세계 공간 | 존재들이 살아가는 무대 | 지역 그래프 + 환경 압력 (§5) |
| ② 세계 규칙 | 상태를 바꾸는 유일한 경로 | 법칙·행동의 4단 형식 (§3) |
| ③ 주체 | 규칙 위에서 목적을 수행하는 존재 — 플레이어도 그중 하나 | 주체 등록 + 구동 방식 (§3.3, 목적은 Life) |
| ④ 생존 경쟁 | 주체들의 목적이 같은 상태를 두고 겹치는 것 | 갈등 접점 (Life §7) |
| ⑤ 성장 | 경쟁의 경험이 개체를 바꾸는 것 | 개체 프로파일 궤적 (Life §5) |

이 순서는 감상이 아니라 **저작의 생성 순서**다: 공간과 압력이 먼저 있고(공정 0), 규칙이 그 위에 놓이고(공정 W), 주체(종)가 그 압력에 맞게 태어나고(공정 S), 경쟁은 저작하지 않으며(갈등 접점의 시뮬 발화), 성장은 개체의 이력이 만든다. 뒤 층을 앞 층 없이 저작하는 것 — 예컨대 압력 없는 무대에 종을 놓거나, 규칙 없는 사건을 쓰는 것 — 이 배치형 퇴행의 정확한 정의다(불변 ①).

## 2. 상태 — 세계는 등록된 속성의 값들이다

**세계 상태 = 속성 사전에 등록된 축들의 현재 값. 그 외에 세계는 없다.** 서술("이 숲은 위험하다")은 상태가 아니다 — 판정에 쓰려면 축으로 등록해야 한다.

### 2.1. 속성 사전 (등록제)

모든 축은 사용 전에 속성 사전에 등록한다. 등록 항목: 이름 · 값 종류 · 정의역 · **존재 근거(basis)**. 미등록 축 참조는 검증 오류다. 존재 근거는 "이 축은 어느 목적·압력·규칙의 판정을 위해 존재하는가"의 한 줄 — 근거를 쓸 수 없는 축은 등록하지 않는다(세계를 역추적 가능하게 유지하는 장치).

### 2.2. 값은 네 종류로 제한한다

| 종류 | 값 | 용도 | 예 |
|---|---|---|---|
| `flag` | 참/거짓 | 존재·활성·발생 여부 | `잿안개.활성` |
| `level` | 0..N 정수 + 라벨 | 단계 질의 (연속 실수 대신) | `미답림.먹이` = 0고갈/1희소/2보통/3풍부 |
| `count` | 0 이상 정수 | 개체수·수량·누적 | `무면호.개체수` |
| `ref` | 축·주체 id 또는 없음 | 소유·지배·대상 | `메아리이끼군락.점유` |

연속 실수를 금지하는 이유: 판정 임계값이 데이터 곳곳에 흩어지고, 서사적 의미("부족하다"·"무너졌다")와 값의 대응이 흐려진다. `level` 은 임계를 라벨로 사전에 고정한다.

### 2.3. 축은 세 문법뿐이다

```text
단축    <소유자>.<축>            한 존재의 상태.        무면호.개체수
쌍축    <소유자>.<축>.<대상>     두 존재 사이의 상태.    재하.믿음.PHE_모방울음
파생축  <소유자>.<축> (파생)     다른 축들의 함수 — 직접 쓰기 금지, 산식만.
                               예: 도시.연료위기 = (등불도시.연료 <= 1) ∧ (한기.단계 >= 2)
```

파생축이 해결하는 것: 파생 상태(위기·위협 활성)를 독립 변수로 두면 원인이 바뀌어도 결과가 안 바뀌는 모순이 생긴다. 파생축은 언제나 원인들의 함수다.

### 2.4. 술어 — 판정의 유일한 언어

판정(규칙 조건·목적 완료·노드 활성·현상 방출)은 전부 술어로 쓴다: `{축, 비교(== != >= <= > <), 값}` 의 조합(`그리고`/`또는`/`아니다`). 술어는 상태만 읽는다 — 행동 이력 카운트("N번 수행")는 술어가 아니다(불변 ③); 이력이 판정에 필요하면 그 이력을 축(count)으로 등록하고 그 축에 대한 술어를 쓴다.

## 3. 규칙 — 상태를 바꾸는 유일한 경로

### 3.1. 4단 형식

모든 상태 변화는 이 형식을 거친다(불변 ②). 예외 없음 — 초기화(공정 0 시드)조차 "창세 규칙"의 1회 실행으로 기록한다.

```text
규칙 = { 조건: 술어           — 언제 일어날 수 있는가
        비용: 에너지 이동      — 무엇을 지불하는가 (§4 — 0 비용은 명시 판정)
        전이: 축 값 변경 목록   — 세계가 어떻게 달라지는가
        기록: 사건 원장 항목    — 무엇이 일어났다고 남는가 (§7) }
```

두 갈래뿐이다:

- **법칙** — 아무도 원하지 않아도 조건이 참이면 저절로 일어난다 (생태·기후·부패·확산). 매 틱 평가.
- **행동** — 주체가 선택해야 일어난다 (사냥·채집·이동·협상). 조건은 전제, 비용은 대가.

판별 질문: **"이 변화는 누가 원해서 일어나는가?"** — 아무도 원하지 않아도 일어나면 법칙이다.

### 3.2. 규칙 저작의 짝 규율

- **압력 ↔ 회복 짝**: 어떤 축을 깎는 법칙을 놓으면 그 축을 회복시키는 경로(법칙 또는 행동)를 함께 놓는다. 짝 없는 압력은 세계를 단조 소진시키고, 짝 없는 회복은 긴장을 없앤다. 압력과 회복의 임계가 어긋나게 설계하면 축이 진동한다 — 살아있는 세계의 기본 파형.
- **실패도 전이다**: 행동이 조건을 만족하고 발화했다면, 의도와 다른 결과("빗나감")도 반드시 전이와 기록을 남긴다. 무효과 실패 금지 — 실패는 사건이다.
- **현상 방출 선언**: 규칙이 만드는 전이마다 "무엇으로 관측되는가"를 현상 사전(Life §6)에 등록하거나 은닉 사유를 명시한다. 관측 불가능한 변화만으로 된 세계는 주체들에게 존재하지 않는 세계다.

### 3.3. 주체와 구동

주체 = 목적을 가지고 행동을 선택하는 존재. 등록 항목: id · 종(Life §3) · 구동 방식. 구동은 두 가지뿐이고 **플레이어는 구동만 다른 주체다**:

```text
입력 구동  플레이어 — 행동 선택이 외부 입력.
자율 구동  NPC 개체·군집 — 행동 선택이 데이터: 매 틱, 활성 프로파일(Life §5) 안에서
          반응 트리거가 참인 노드 중 우선순위(결핍 압력 > 가치관 가중) 최상위 노드의
          행동 중 조건·비용을 만족하는 첫 번째를 발화. 만족하는 행동이 없으면 아무것도
          하지 않는다. 지능이 아니라 목적의 기계적 수행이다.
```

## 4. 에너지 보존 — 무상 출력은 없다

세계에 에너지 원장을 둔다: 모든 비용은 소멸이 아니라 **이동**이다(사냥한 생명의 에너지는 포식자에게, 연소한 연료의 에너지는 열로). 창세(공정 0)에 총량이 정해지고 이후 규칙은 재분배만 한다.

- 검증 채널: 총합 감사(전 원장 합 = 창세 총량, 잔차 0)가 상시 가능해야 한다.
- 이 보존이 게임플레이다: 고갈·포화·독점이 규칙 위반이 아니라 자연 결과가 되고, "얻지 못함"은 버그가 아니라 세계의 상태다.
- 능력(넨)의 출력도 이 원장에서 지불된다([Design-Ability.md](Design-Ability.md) §1) — 능력 남용이 생존 압력을 만드는 것은 별도 밸런스 장치가 아니라 보존의 귀결이다.

## 5. 공간 — 지역 그래프와 압력, 그리고 미답 경계

공간 = 지역들의 그래프. 지역 등록 항목: id · 이웃(이동 경로와 비용) · **환경 압력 목록**(그 지역이 거주자에게 가하는 술어 — 한기·안개·독기·어둠) · 부존(그 지역에 있는 요소·군락 축들).

- **압력 없는 지역은 없다.** 압력 0 인 지역은 종을 분화시키지 못하고 긴장을 만들지 못한다 — 등록 반려. 안전조차 "낮은 압력 + 높은 경합(누구나 살고 싶은 땅)"으로 설계한다.
- **미답 경계**: 공간 그래프는 닫히지 않는다 — 가장자리에 미답 지역(등록됐으나 내용 미공개, 진입 조건 있음)을 유지한다. 미답은 "콘텐츠 없음"이 아니라 "고압력·고에너지·미관측"이다: 위험과 기회의 기울기가 개척 전선을 만들고, 끝없는 방대함의 모험심(이 트랙의 헌터×헌터 감수성)은 이 경계의 존재에서 온다. 미답 지역의 내용은 공정(S·E)으로만 채워진다 — 채우는 순간 그 너머에 새 미답을 잇는다.

## 6. 시간 — 틱과 클럭

- **틱 결정론**: 세계는 고정 순서의 틱 루프로 전진한다 — ① 클럭 갱신 → ② 법칙 평가 → ③ 자율 구동 행동 선택·발화 → ④ 입력 구동 행동 반영 → ⑤ 파생축 재계산 → ⑥ 현상 방출·믿음 갱신 → ⑦ 사건 원장 확정. 같은 시드·같은 입력이면 같은 세계다(불변 ⑥). 난수는 어디에도 없다 — 예측 불가능성은 정보 비대칭(관측하지 못한 상태·클럭)에서만 나온다.
- **클럭**: 주기 상태(계절·안개·달)는 클럭으로 등록한다 — 주기·지속·구동 축(예: `잿안개.활성`). 클럭 주기들은 서로소로 잡아 교차 창(둘 이상이 동시에 참인 틱)을 희소하게 만든다 — 희소 창은 제약과 서약의 희소성 계수([Design-Ability.md](Design-Ability.md) §3)와 희귀 사건의 원천이다.

## 7. 사건 원장 — 경험·서사·검증의 공통 원천

모든 규칙 실행은 사건 원장에 한 줄을 남긴다(append-only): `{틱, 규칙 id, 행위자, 대상, 전이 요약}`. 이 원장이 세 가지를 한 번에 해결한다:

1. **경험** — 개체의 경험 기록(Life §5)은 이 원장의 부분집합(그 개체가 행위자·대상·관측자인 항목)이다. 성장의 원천.
2. **서사** — 이야기는 원장의 해석이다. 연대기·전설·소문은 전부 원장 항목의 번역이지 별도 저작물이 아니다.
3. **검증** — 창발 게이트(Process V3: "스크립트 0 으로 사건 발생")의 판정 대상이 이 원장이다.

## 핵심 문장

세계는 등록된 속성의 값들이고, 규칙만이 그것을 바꾸며, 바뀐 것은 전부 기록된다.
공간의 압력이 종을 부르고, 규칙의 짝이 세계를 진동시키고, 미답 경계가 모험을 부른다 — 콘텐츠는 이 위에서 스스로 태어난다.
