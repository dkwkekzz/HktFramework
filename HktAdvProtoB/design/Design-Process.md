# 저작 공정 — 규칙·종족·요소·능력·개체를 세계에 넣는 표준 진입점

이 문서가 트랙의 심장이다. 세계에 무언가를 넣는 방법은 아래 일곱 공정뿐이며, 각 공정은 **입력 → 절차 → 산출 → 검증 게이트**를 갖는다. 게이트 없는 공정은 없고, 게이트를 통과하지 못한 산출물은 세계에 들어가지 않는다. 이 문서만 읽은 문맥 없는 세션이 새 종 하나를 온전히 세계에 살게 할 수 있어야 한다 — 그것이 이 문서 자체의 검증이다(최종 목적 5).

형식 정의는 [Design-World.md](Design-World.md)(상태·규칙·공간·시간), [Design-Life.md](Design-Life.md)(종·트리·개체·현상·요소), [Design-Ability.md](Design-Ability.md)(넨) — 이 문서는 그 형식들을 **순서와 게이트**로 엮는다.

## 1. 최종 목적 — 품질을 수치로 잰다

"헌터×헌터 수준의 다양하고 깊은 세계관, 특색 있는 캐릭터"를 다섯 수치 게이트로 고정한다(불변 ⑥ — 검증법을 세울 수 없는 목표는 목표가 아니다).

```text
목적 1 다양성   한 종 트리에서 개체 10을 생성하면 서로 다른 활성 프로파일 ≥7 (V1).
목적 2 깊이     요소 100% 가 서로 다른 주체 ≥2 트리에 연결되고, 존재 근거 역추적 100% (V2).
목적 3 창발    대표 만남 시나리오의 무입력 시뮬에서 스크립트 노드 0 으로 사건 원장에
              갈등 접점 발화 ≥1 (V3).
목적 4 개성    능력 100% 프로파일 근거 보유 · 동일 능력 개체 쌍 0 (V4).
목적 5 재현성   문맥 없는 세션이 이 문서만으로 새 종 1종을 전 게이트 초록으로 통과.
              §8 워크드 예시 3건이 그 최초 증명이다.
```

## 2. 공정 지도

```text
공정 0  세계 시드      공간·클럭·에너지 총량·초기 압력 (세계당 1회)
공정 W  규칙 추가      법칙·행동 (현상 방출 선언 포함)
공정 S  종족 추가      환경→임계→특성→가치관→트리→현상 어휘→세계 배선 (7단계)
공정 E  요소 도출      재료·장소·기술 — 종의 필요에서만, ≥2 주체
공정 A  능력 추가      능력 보유 종의 개체 한정 (Design-Ability §6 게이트)
공정 I  개체 생성      프로파일 좌표→활성 산출→(A)→승격 판정
공정 V  검증           설계 게이트(즉시) + 데이터 게이트(시뮬)
```

의존 순서: 0 → W·S 반복 ⇄ E (종의 필요가 요소를 부르고 요소가 트리를 연다) → I → A. 어느 공정도 건너뛰어 뒤 공정을 실행할 수 없다 — 압력 없는 무대에 종을 놓는 것, 트리 요구 없는 요소를 놓는 것이 배치형 퇴행의 정의다(불변 ①).

## 3. 공정 0 — 세계 시드 (세계당 1회)

```text
입력:  세계 컨셉 한 문단
절차:  0-1 공간   지역 ≥3 을 그래프로 — 각 지역에 압력 술어 ≥1 (압력 0 지역 반려).
              가장자리에 미답 지역 ≥1 (진입 조건 명시 — 개척 전선 확보).
      0-2 클럭   주기 상태 ≥2, 주기는 서로소로 (교차 창 희소성 — 넨 제약·희귀 사건의 원천).
      0-3 원장   에너지 총량과 초기 분포. 이후 모든 규칙은 재분배만 한다.
      0-4 창세 기록  시드 전체를 "창세 규칙" 1회 실행으로 사건 원장 틱 0 에 기록.
산출:  지역 표 · 클럭 표 · 원장 창세 항목
게이트: 전 지역 압력 ≥1 · 미답 ≥1 · 클럭 서로소 · 총량 명시. 시드는 최소로 —
       여기서 콘텐츠(종·요소·사건)를 넣기 시작하면 공정 위반이다.
```

## 4. 공정 W — 규칙 추가

```text
입력:  규칙 후보 (현상 서술 — "안개가 짙으면 소리가 멀리 간다")
절차:  W-1 판별   누가 원해서 일어나는가? 아무도 원하지 않아도 일어나면 법칙, 선택이면 행동.
      W-2 축 확인  조건·전이에 필요한 축이 속성 사전에 있는가 — 없으면 등록(존재 근거 필수)부터.
      W-3 4단 작성 조건(술어) → 비용(원장 이동 — 0 도 명시 판정) → 전이 → 기록.
      W-4 짝 검사  깎는 규칙엔 회복 짝이 있는가 · 행동엔 빗나감 결과가 있는가(무효과 실패 금지).
      W-5 현상 선언 전이마다 현상 사전 등록 또는 은닉 사유 명시 (공란 금지).
산출:  규칙 명세 + 속성 사전 갱신 + 현상 사전 행
게이트: 4단 완비 · 짝 존재 · 전이 100% 현상/은닉 판정 · 참조 축 전부 등록됨
```

## 5. 공정 S — 종족 추가 (7단계)

```text
S-1 환경 선언   서식 지역 선택 + 그 지역 압력 술어 목록 확인. 이 종이 "왜 여기 사는가"가
              아니라 "이 압력이 왜 이 종을 낳았는가"를 쓴다.          산출: 서식·압력 표
S-2 임계 표    결핍 삼축 임계·대사 비용·감각 채널 (Life §2).           산출: 종 임계 표
S-3 특성 도출   압력마다 대응 특성 ≥1 — 근거 없는 특성 금지(basis 에 압력 기록).
                                                              산출: 특성 벡터 정의역
S-4 가치관     공용 5축(소유·유대·앎·힘·계승) 종 기본 가중 + 잠금.      산출: 가치관 행
S-5 트리 전개   존속 루트 + 공통 첫 분기(유지·위협·연속) 아래로 Life §4 스키마로 분해.
              노드마다: 활성 조건(≥1 술어족) + 반응 트리거 + 행동 ≥2 + 갈등 접점(트리 ≥1).
              분해 종료: 말단의 완료 술어가 실재 축으로 판정 가능해질 때.  산출: 종족 트리
S-6 현상 어휘   방출 전수(상태·행동별 — 공정 W-5 와 같은 규율) + 관측 교차표(감각 채널 ×
              세계 현상 — 이 종에게 세계가 어떻게 보이는가).           산출: 현상 사전 행들
S-7 세계 배선   상태 축 등록(개체수·서식·종 전용 축) · 주체 등록(자율 구동) · 압력↔회복 짝
              확인 · 요소 요구 목록을 공정 E 로 넘김.                 산출: 배선 명세

공정 S 게이트 (공란 = 미완성):
  □ 활성 조건 없는 노드 0 (루트·공통 첫 분기의 「상시」 명시 제외)      — 불변 ⑤
  □ 반응 트리거의 믿음 축 외 참조 0 (내부 직독 0)                    — 불변 ④
  □ 갈등 접점 ≥1, 접점 축이 타 주체 트리에 실재                      — Life §4
  □ 말단 해결 행동 ≥2 · 완료는 전부 상태 술어                        — 불변 ③
  □ 특성 100% 압력 근거                                           — S-3
  □ 방출 현상 ≥1 (관측 불가능한 종은 세계에 없는 종이다)              — S-6
한 문장 규칙: 종족 추가 커밋은 이 게이트 전부가 초록이 될 때까지 끝나지 않는다.
```

## 6. 공정 E — 요소 도출 · 공정 A — 능력 추가 · 공정 I — 개체 생성

```text
공정 E (재료·장소·기술·시설):
  입력:  종 트리의 요구 (S-7 요소 요구 목록 — "보온 재료가 필요하다")
  절차:  E-1 요구를 낸 가지 확인 (basis) → E-2 두 번째 주체 찾기 — 이 요소를 다른 어느
        트리가 쓰거나 두고 다투는가 (없으면 만들지 말고 보류) → E-3 축 등록(공급·점유 등)
        + 획득·사용 행동(공정 W) → E-4 미답 배치면 진입 조건과 연결.
  게이트: ≥2 주체 연결 · 존재 근거 역추적 가능 · 획득 행동에 세계 쪽 소모 효과(공급 하락 등)

공정 A (능력 — 능력 보유 종의 개체 한정, 공정 I 의 I-3 에서 진입):
  A-1 계통 판정   특성 벡터 → 주계통 (Ability §2. 특이 판정은 예외 심사 기록 필수).
  A-2 프로파일 추출 지배 경험(겪음 축 누적 최대 또는 결정 사건)과 가치관 상위 축 (Ability §4).
  A-3 능력 초안   f(프로파일) 로 생성 — 효과는 상태 술어로 표현 가능해야, 발동은 행동
                4단 형식으로 (Ability §1).
  A-4 제약·서약   제약 술어(지배 경험에서 재료를 얻는다) + 희소성 계수 산정(Ability §3 표)
                + 서약 페널티 법칙(위반=사건).
  A-5 세계 배선   수련법·능력의 기원·전승 전 항목 + 갈등 접점 ≥2 주체 (Ability §5).
  게이트: Ability §6 공정 A 게이트 전 항목 (비용·제약-출력 정합·근거·유일성·배선).

공정 I (개체):
  I-1 종 선택 + 프로파일 좌표 — 특성 편차·가치관 가중·초기 경험 기록. 좌표는 종 정의역
     안 (정의역 밖 편차 = 종 재설계 신호이지 개체 옵션이 아니다).
  I-2 활성 프로파일 산출 — 종 트리 전 노드의 활성 조건을 평가 (설계 단계 수기 표,
     데이터 단계 자동).
  I-3 능력 종이면 공정 A ([Design-Ability.md](Design-Ability.md) §6) 를 잇는다.
  I-4 승격 판정 — 군집 기본과 달라야 할 이유(편차·이력)가 있으면 이름 부여(승격은
     사건 원장에 기록 — 서사적 사건), 없으면 군집에 남긴다.
  게이트: 같은 종 기존 개체와 활성 프로파일 차이 ≥1 노드 또는 능력 상이 —
         구분되지 않는 개체는 개체가 아니라 군집이다.
```

## 7. 공정 V — 검증

```text
설계 게이트 (저작물이 데이터가 되기 전, 문서 위에서):
  V-설1 스키마 정합   산출물이 해당 공정의 전 필드를 공란 0 으로 채웠다.
  V-설2 참조 실재     인용한 축·규칙·지역·클럭·현상이 전부 등록되어 있다.
  V-설3 불변 무위반   불변 ①~⑥ 위반 0 (배치·직접 대입·경로 카운트·내부 직독·무조건
                    발동·난수 — 여섯 냄새 전수 점검).

데이터 게이트 (엔진·시뮬 위에서 — 검증기는 STATE.md NEXT):
  V1 다양성   한 종 프로파일 10 샘플 → 상이 활성 프로파일 ≥7                (목적 1)
  V2 깊이     요소 100% ≥2 주체 · basis 역추적 100%                       (목적 2)
  V3 창발    두 종 동일 무대 무입력 시뮬 → 스크립트 0 갈등 접점 발화 ≥1      (목적 3)
  V4 개성    능력 근거 100% · 동일 능력 쌍 0                              (목적 4)
  V5 현상 격리 반응 트리거의 내부 직독 0 (정적 검사) · 전이의 현상/은닉 100%
  V6 보존    에너지 총합 감사 잔차 0 · 같은 시드 재실행 비트 동일
```

## 8. 워크드 예시 — 시드 세계 「잿빛 경계」 전 공정 완주

목적 5(재현성)의 최초 증명. 아래 3건이 공정 0·S·E·I·A 의 전 필드를 실제로 채운다. 여기 등장하는 모든 이름은 이 트랙의 원안이다.

### 8.1. 공정 0 — 세계 시드

| 지역 | 이웃 | 압력 | 성격 |
|---|---|---|---|
| 등불도시 | 잿안개습지 | 한기(겨울 클럭) · 연료 소모(도시 유지비) · 경합(낮은 위험 = 높은 밀집) | 인간 정주지 |
| 잿안개습지 | 등불도시·미답림 | 잿안개(시야·후각 차단 클럭) · 습기(온기 압력) | 경계 — 사냥과 실종의 땅 |
| 미답림 (미답) | 잿안개습지 | 진입 조건: 잿안개 활성 중에만 길이 열림 · 고압력(미공개) | 고에너지·미관측 — 개척 전선 |

클럭: **잿안개**(주기 7, 지속 2 — 습지 시야 차단·미답림 개방) · **겨울**(주기 60, 지속 15 — 한기 전역 상승). 7 과 60 은 서로소 — "겨울의 잿안개" 교차 창은 희소하다(넨 제약 후보). 원장: 창세 총량의 6할이 미답림에 몰려 있다(위험과 기회의 기울기 — 개척 전선의 동력). 게이트: 전 지역 압력 ≥1 ✅ · 미답 1 ✅ · 서로소 ✅ · 총량 명시 ✅.

### 8.2. 공정 S — 종족 「무면호(無面狐)」: 관측한 현상을 모방 방출하는 여우

현상 층의 능력을 종 특성으로 가진 짐승 — 이 종 하나로 현상·믿음·위장 형식 전체가 검증된다.

- **S-1 환경**: 잿안개습지(주서식)·미답림 가장자리. 압력: 상위 포식자(미답림 발원 — 시각 사냥꾼) · 먹이 은닉(습지의 작은 짐승은 숨는다) · 잿안개(자신도 시야를 잃는다).
- **S-2 임계 표**: 허기 임계 2 · 온기 내성 습기까지(한기 취약 — 겨울에 도시 쪽으로 밀려남) · 대사 1 · 감각: 청각 3·후각 2·시각 1.
- **S-3 특성**: **모방 방출**(관측한 현상을 복제해 방출 — 시각 사냥꾼 압력 대응: 포식자의 울음을 흉내내 포식자를 쫓는다) · 야행(잿안개·야간 활동 — 시야 압력 회피) · 도약(습지 지형 대응). 전 특성 압력 근거 ✅.
- **S-4 가치관**: 소유 2(먹이 은닉처) · 유대 1(무리 아님, 짝) · 앎 1 · 힘 0 · 계승 1. 잠금: 없음.
- **S-5 트리** (요약 — 전 노드 활성·반응·행동 ≥2·접점 보유):

| 노드 | 활성 조건 | 반응 트리거 | 행동 ≥2 | 갈등 접점 |
|---|---|---|---|---|
| 존속한다 (루트) | 상시 | 상시 | (위임) | — |
| ├ 유지: 작은 짐승 사냥 | 상시 | 믿음.PHE_짐승기척 ≥추정 | 매복 · 몰이 | 습지 먹이 축 (상위 포식자와 경합) |
| │ └ 도시 가금 습격 | 경험: 겪음.습지기근 ≥1 · 소유 ≥2 | 믿음.PHE_가금소리 ≥추정 | 야습 · **사람 목소리 모방으로 유인** | 등불도시.가금 (인간과 충돌) |
| ├ 위협: 포식자 쫓기 | 상시 | 믿음.PHE_포식자접근 ≥추정 | **포식자 울음 모방** · 은신 도주 | — |
| │ └ 사냥꾼 홀리기 | 경험: 겪음.피습 ≥1 · 앎 ≥2 | 믿음.PHE_인간발소리 ≥확인 | **동행자 목소리 모방(분리 유도)** · 흔적 교란 | 인간의 믿음 축 자체 (감응 넨과 정면 충돌 — §8.4) |
| └ 연속: 짝·은닉처 | 유대 ≥1 | 계절 현상 | 구애 방출 · 은닉처 확장 | 은닉처 후보지 (인간 개척과 경합) |

- **S-6 현상 어휘**: 방출 — PHE_모방울음(청각, **방출원이 "모방 행동"이므로 내용이 거짓일 수 있는 유일한 현상 — 믿음 오염의 원천**) · PHE_여우기척(청각 1) · PHE_은닉처흔적(잔흔 1). 관측 — 청각 3 이 습지의 거의 모든 소리 현상을 잡는다(모방의 재료).
- **S-7 배선**: 축 무면호.개체수·서식, 자율 구동 등록, 압력(사냥당함)↔회복(번식 법칙) 짝, 요소 요구 → 공정 E: "모방 연습 매개"(→ 메아리이끼 §8.3).
- **게이트**: 활성 조건 없는 노드 0 ✅ · 내부 직독 0 ✅ (전 트리거가 믿음 축) · 접점 4 ✅ · 말단 행동 ≥2 ✅ · 특성 압력 근거 ✅ · 방출 현상 3 ✅.

**공정 I — 개체 3 (V1 축소 실증)**: 같은 트리, 다른 좌표·이력 → 전부 다른 활성 프로파일.

| 개체 | 프로파일 차이 | 켜진 노드 | 서사 |
|---|---|---|---|
| 군집 기본 (무명) | 편차 없음 | 사냥·포식자 쫓기 | 그냥 여우. 군집으로 뭉뚱그림 |
| 「등불을 배운 것」 (승격) | 겪음.습지기근 2 · 소유 +1 | + 가금 습격 | 기근이 도시행을 열었다 — 사람 목소리를 배웠다 |
| 「외눈」 (승격) | 겪음.피습 1 · 앎 +2 | + 사냥꾼 홀리기 | 사냥꾼에게 눈을 잃고, 사냥꾼을 배웠다 |

### 8.3. 공정 E — 요소 「메아리이끼」

- 요구 근거: 무면호 트리 "모방 연습"(S-7) — 소리를 머금었다 되뱉는 이끼.
- 두 번째 주체: 인간류 — 감응 계통 넨 수련의 청각 매개(수련 행동의 재료) + 도시 학자의 채집 수요.
- 축: 메아리이끼군락.공급(level)·점유(ref). 획득 행동: 채집(세계 쪽 소모 — 공급 하락, 회복 법칙 짝). 서식: 잿안개습지(안개가 소리를 가두는 곳 — 존재 근거가 지역 압력과 정합).
- 게이트: ≥2 주체(무면호·인간류) ✅ · 역추적 ✅ · 소모·회복 짝 ✅.

### 8.4. 공정 I+A — 인간류 개체 「재하」: 넨 「참소리」

인간류 종 정의는 축약 선언(존속 루트 + 공통 첫 분기 + 각성 가지 — 전면 전개는 NEXT), 개체로 공정 I·A 전 필드를 완주한다.

**공정 I — 프로파일**: 특성 — 청각 +2(안개 사냥꾼의 귀)·신체 −1. 가치관 — 앎 3·유대 2·힘 0. 경험 — **겪음.동생실종 1 (잿안개 속, 동행자 목소리를 따라갔다 — "외눈" 류의 모방에 홀린 것)** · 겪음.잿안개사냥 다수. 활성 — 미답 진입 가지(앎 3), 추적 가지 활성; 도시 정주 가지 비활성. 승격: 이름 있는 개체 ✅ (이력이 군집 기본과 다름).

**공정 A**:

```text
A-1 계통    청각 특성 최대 → 감응(感應). 인접: 간섭·구성 80%.
A-2 지배 경험 겪음.동생실종 — 모방된 목소리에 홀린 것. 가치관 상위: 앎(검증).
A-3 초안    「참소리」 — 감응: 들리는 소리 현상이 진짜 방출원의 것인지 모방인지 판별하고,
           참이면 방출원의 방향을 얻는다. 개입 대상: 자기 믿음 축 (믿음.PHE_* 를
           확인/반증으로 강제 갱신 — 무면호 모방의 정확한 대항 지점).
           비용: 생명 원장 지불 — 장시간 감청은 허기·온기 압력 (무상 출력 0).
A-4 제약·서약 제약 ① 잿안개 활성 중에만 (주기 한정 — 클럭 참 비율 2/7, 계수 ×2.5.
           지배 경험의 시간이 그대로 제약이 됐다 — 동생을 잃은 것도 안개 속이다.)
           제약 ② 자신이 실제로 들어본 적 있는 소리만 판별 가능 (대상 한정 ×2 —
           겪음 축이 판별 가능 집합을 정의한다. 성장할수록 능력이 넓어진다.)
           서약: 판별 결과를 남에게 거짓으로 전하면 능력이 침묵한다 (위반 시 침묵 ×1.5 —
           위반은 사건: 침묵의 시작은 현상을 방출하고, 재하를 아는 자들이 관측한다.)
A-5 배선    수련법 기원: 등불도시 안개 사냥꾼들의 "귀 씻기" 구전(발견 목적: 안개 실종 —
           압력이 낳았다) → 재하가 「참소리」로 맺음(발현). 전승: 구전은 공유, 맺은
           능력은 개인(제약이 이력에 잠김 — 소실 가능성: 재하 사망 시).
           갈등 접점: ① 무면호 「외눈」 — 같은 현상 층의 창과 방패 (모방 vs 판별)
           ② 등불도시 경비대 — 실종 수사에 참소리의 정치적 수요 (유대 vs 앎 의 긴장)
           → ≥2 주체 ✅.
게이트: 비용 ✅ · 제약-출력 정합 ✅ (×2.5·×2·×1.5, 산정 근거 = 클럭·겪음 집합) ·
       근거 공란 0 ✅ (전 항목 프로파일 역산) · 동일 능력 쌍 0 ✅ · 기원·전승·접점 ✅.
```

**이 예시 묶음이 증명하는 것** — 무면호의 종 특성(모방 방출)과 재하의 넨(참소리)은 서로를 모른 채 같은 현상 층 위에 저작됐지만, 갈등 접점이 자동으로 맞물린다(모방 vs 판별). 대표 만남 시나리오(V3): 잿안개 활성 틱에 「외눈」과 재하가 잿안개습지에 있으면 — 외눈이 동행자 목소리를 모방 방출 → 재하의 믿음 오염 시도 → 재하의 참소리 판별(활성: 잿안개 중 + 들어본 소리) → 반증 갱신 → 추적 행동 → 외눈의 흔적 교란 — **스크립트 0 으로 사건 원장에 추격전이 쓰인다.** 데이터 단계에서 이 시나리오가 V3 게이트의 1호 판정 대상이다.

## 핵심 문장

저작자는 압력·규칙·종·접점까지만 만든다 — 사건과 이야기는 시뮬레이션이 원장에 쓴다.

이 문서만 읽은 낯선 세션이 새 종을 세계에 살게 할 수 있는가 — 그것이 이 설계 전체의 단 하나의 검증이다.
