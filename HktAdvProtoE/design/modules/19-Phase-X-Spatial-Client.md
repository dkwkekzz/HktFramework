# 19. Phase X — 3D 공간과 웹 클라이언트

> 상위: [Design-Modules.md](../Design-Modules.md) · 선행: [18-Phase-W-World-Compiler.md](18-Phase-W-World-Compiler.md) · 후속: [20-Phase-N-Runtime.md](20-Phase-N-Runtime.md)

공간은 먼저 만들고 콘텐츠를 집어넣는 빈 무대가 아니다. **공간은 행동 가능성을 지원하기 위해 생성된다.**

---

| ID | 목적 | 대표 검증 | 선행 |
|---|---|---|---|
| X0 | 3D 지형 생성 전에 지역 간 의미와 연결 조건을 결정한다 | 밀수 요구가 있을 때 공식 도로와 분리된 은폐 경로가 생성됨 | W2, S0 |
| X1 | 의미적 지역 그래프를 실제 이동 가능한 3D 지형으로 변환한다 | 인간·거대 마물·비행 생물이 각각 요구된 경로를 실제로 통과 | X0 |

## X0 — region-topology

패키지: `packages/spatial-client/X0-region-topology`

| 항목 | 내용 |
|---|---|
| 목적 | 3D 지형 생성 전에 지역 간 의미와 연결 조건을 결정한다 |
| 포함 | Region Node, Boundary, Route, Hidden Path, Choke Point |
| 대표 검증 | 밀수 조직 요구가 있을 때 공식 도로와 분리된 은폐 경로가 생성됨 |
| 선행 | W2, S0 |

W0 의 `SpaceRequirement` 를 소비한다. 요구 예시:

```text
거대 마물   몸체 통과 폭 · 계절별 이동 경로 · 먹이-번식지 연결 · 진동 전파 지형
            · 회복용 광물 지대 · 인간에게 보이는 관찰 지점
밀수 조직   공식 경로 우회 통로 · 시야 차단 지형 · 경비 교대와 연결된 이동 거리
            · 은닉 공간 · 두 국가 관할권이 겹치는 지대
비행 종     수직 이동 공간 · 상승 기류
국가        경계 · 요새 · 도로 · 보급 거리
신          영역 중심점 · 의례 장소 · 영향 경계
```

## X1 — spatial-compiler

패키지: `packages/spatial-client/X1-spatial-compiler`

| 항목 | 내용 |
|---|---|
| 목적 | 의미적 지역 그래프를 실제 이동 가능한 3D 지형으로 변환한다 |
| 포함 | 3D Embedding, Terrain Mesh, Road, River, Landmark, Navigation |
| 대표 검증 | 인간·거대 마물·비행 생물이 각각 요구된 경로를 실제로 통과할 수 있음 |
| 선행 | X0 |

공간 생성 9계층:

```text
1. 의미적 지역 그래프
2. 지역 간 연결과 이동 비용
3. 2D·3D 좌표 임베딩
4. 광역 지형 생성
5. 도로·강·협곡·경계 생성
6. 정착지·둥지·의례 장소 배치
7. 전투·은신·관찰용 미시 공간 생성
8. 이동 가능성 검증
9. 렌더링 메시와 충돌 구조 생성
```

논리 데이터와 표현 데이터를 분리한다.

```text
논리 공간
  이동 가능성
  관할권
  위험도
  생태
  의념장
  상호작용 지점
표현 공간
  메시
  머티리얼
  식생
  조명
  이펙트
```

초기 구현에서는 복셀을 사용하지 않는다: 광역은 높이 필드 지형 메시, 동굴·절벽·건물은 별도 메시 또는 절차적 모듈, 식생은 인스턴싱, 거대 생물 경로는 일반 NPC 내비게이션과 분리된 광역 경로.

## X2 — web-client

패키지: `packages/spatial-client/X2-web-client`

| 항목 | 내용 |
|---|---|
| 목적 | 논리 세계를 브라우저에서 이동하고 관찰할 수 있게 한다 |
| 포함 | Renderer, Camera, Controls, Entity Visual, Animation |
| 대표 검증 | 브라우저에서 지역에 접속하여 이동·충돌·NPC 관찰이 가능 |
| 선행 | X1, S0 |

렌더링은 Three.js `WebGPURenderer` 를 우선 사용하고 WebGPU 미지원 시 WebGL 2 로 내려간다. 물리·충돌은 Rapier, 빌드는 Vite.
클라이언트는 이동과 애니메이션만 예측한다 (권위는 N0).

## X3 — world-ui

패키지: `packages/spatial-client/X3-world-ui`

| 항목 | 내용 |
|---|---|
| 목적 | 퀘스트 목록 대신 현상·주장·약속·개입 가능성을 보여준다 |
| 포함 | Phenomenon FX, Claim UI, Evidence UI, Commitment UI, Debug Overlay |
| 대표 검증 | 사실·소문·추측이 출처와 확신도를 달리해 표시됨 |
| 선행 | U1, U2, I2, I3, X2 |

플레이어에게 보이는 콘텐츠 그래프는 실제 세계 전체가 아니라 투영이다.

```text
C_p = Project(SituationGraph, Belief_p, Capabilities_p, Relations_p)
```

즉, 플레이어가 알지 못하는 사건은 콘텐츠 UI 에도 나타나지 않는다.

UI 표시 항목: 알고 있는 사건 · 확실한 사실 · 불확실한 주장 · 정보의 출처 · 관련 주체 · 현재 맺은 약속 · 가능한 행동 · 예상되지만 확정되지 않은 결과.

**금지 표현**

```text
동쪽 숲에서 늑대 10마리를 처치하라
```

**요구 표현**

```text
마을의 약초 운송이 3일째 중단되었다.
운송인은 거대 짐승의 흔적을 보았다고 주장한다.
경비대는 도적의 소행이라고 발표했다.
치료사는 이틀 안에 약초가 필요하다.
당신은 운송인에게 빚이 있다.
```
