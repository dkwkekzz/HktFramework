# L2 — 자리를 관찰하는 표면 (기반 층 2 · 세계 절반 ②-부속 여섯째)

상태: **확정** (Human 승인 · 실주행 반영). ② [L2-World-Region.md](L2-World-Region.md) 의 확장 계약이고 새 층이 아니다 —
②-부속 다섯(Material · Time · Life · Access · Foundation)이 **세계가 무엇을 아는가**를 세웠다면 이 문서는
**그것을 관찰자가 어떻게 묻고 어디서 읽는가**를 세운다. 세계의 규칙도 State 도 한 자리 늘리지 않는다.

재료: [design/Plan-Place-Observation-Surface.md](../../design/Plan-Place-Observation-Surface.md) — 지금 화면이 글자를 뿌리는 자리 넷의 실측 ·
진단 여섯 · 기존 지목(TG) 기반과의 겹침 판정. 이 문서는 그것을 다시 적지 않는다 — **무엇이 확정되었고 무엇이 이 축의 것이 아닌지**만 둔다.
함께 읽는다: [Design-Targeting-R0.md](../../design/Design-Targeting-R0.md) (TG — §3.2 대상 프레임 · §4.3 해제 · §5.2 입력 해석 정책) ·
[L2-World-Region.md](L2-World-Region.md) §17 검증 기준 · R14.

세운 Cycle: **C026~C028** (닫힘 — 실주행 판정까지).

> **이 문서는 뒤늦게 선다.** 이 축은 `design/` 의 제안이 승인되어 바로 Cycle 로 간 탓에 로드맵에 결과물이 없었다 —
> 그래서 스물셋 개 spec 이 「판」과 「지목」을 전제로 쓰는데 그 계약의 집이 없었다. 이 문서가 그 집이다.
> 옮긴 것은 재료 문서와 그 승인(확정 열넷) · C026~C028 이 실제로 세운 것뿐이고, 새로 지은 의미는 없다.

---

## 1. 확정한 것

확정 항목은 **O**(Observation). Concept 의 W · Region 의 R · Material 의 S · Time 의 T · Life 의 F · Access 의 K ·
Foundation 의 G 와 같은 자리의 이름공간이다.

| # | 확정 |
|---|---|
| **O1** | **정보가 서는 자리는 셋이다** — **눈**(세계 그 자체 · 색 · 모양 · 크기 · 표식 · 늘 있고 글자가 없다) · **손**(지목한 것에 대한 판 · 이름 · 조건 · 규칙 · 지금 값 · 불가 사유 · 청했을 때만) · **귀**(방금 일어난 일 한 줄 · 사라진다). 상시 HUD 는 **내 몸의 상태**만 진다 — 세계의 사실(깊이 · 안전한 이유 · 압력)은 셋으로 옮긴다 |
| **O2** | **세계에 이름표를 다는 것은 그 자리에 실물이 서 있는 것뿐이다** — 존재 · landmark · 출구 표식. 넓은 자락(방 · 조건 · 구역 · 통로)은 글자 대신 **색과 경계**로 말한다. 방 이름은 늘 떠 있는 이름표가 아니라 **들어선 순간 한 번** 지나가는 제목이다 |
| **O3** | **눈은 다름만 말한다** — 무엇이 다른지는 말하지 않는다. 그것이 궁금함의 조건이다. 색을 늘리지 않고 아이콘을 얹지 않는다 |
| **O4** | **지목은 관찰자가 쥔다.** 세계는 선택을 기억하지 않고 물어본 것에 답만 한다 — 세계 State 가 늘지 않으므로 저장의 판도 오르지 않는다. 대결의 지목이 오는 층이 그것을 가져간다 (TG 의 CurrentTarget 은 그때 선다) |
| **O5** | **지목의 수명은 대상 프레임과 같다** — 화면 중앙 상단에 지목된 대상이 서고, **새로 고를 때까지 유지**되며 그동안 판이 상시 떠 있다. 판은 자판을 잡지 않는다 (몸이 계속 움직여야 한다) |
| **O6** | **해제는 셋** — 물러남(Escape)으로 푼다 · 대상이 세계에서 사라지면 풀린다 · 방을 옮기면 풀린다. **쓰러진 존재는 풀지 않는다** (TG §4.3 과 같은 규칙) |
| **O7** | **대상은 둘이다** — **존재**이거나 **자리**다. 자리는 id 가 없으므로 대상의 어휘가 넓어진다(요청에 이미 있는 좌표가 그 자리다 · 새 봉투 자리가 아니다). 자리 지목의 단위는 **점 하나**이고, 그 점이 속한 자락·칸을 화면이 계산하지 않는다 |
| **O8** | **답의 출처 — 세계에 새로 묻지 않는다.** 땅의 사실(표면 · 지날 수 있는가 · 못 지나가는 사유 · 걸린 자락)은 관찰자가 자기 방 데이터를 **세계와 같은 규칙으로 컴파일해** 읽는다 (땅을 그리는 C005~C007 의 길 그대로). 세계만 아는 것(방 · 깊이 · 규칙을 품은 방의 State)은 **이미 봉투에 매 순간 실려 온다**. 그래서 요청도 패킷도 늘지 않고 **왕복 기다림이 없다** — 누르는 즉시 판이 찬다 |
| **O9** | **어긋나면 어긋났다고 적는다** — 내 데이터와 세계의 땅이 다르면 봉투의 땅 hash 가 그것을 말한다 (C001 부터의 장치). 그때는 답이 아니라 **어긋났다는 사실**을 판에 적는다. 지어내지 않는다 |
| **O10** | **관찰은 이 층에서 공짜다** — 대가(시간 · 기력)는 뒤 층의 것이고, 구조가 그것을 막지 않는다. 그래서 관찰은 처음부터 **한 번의 의도(지목)** 이지 화면의 토글이 아니다. 대가가 붙는 날 세계가 "물을 수 있는가" 를 판정하는 요청이 하나 서고, **사실의 출처는 그때도 바뀌지 않는다** (O8) |
| **O11** | **판은 「지금 알 수 없다」를 적을 자리를 가진다.** 무엇이 언제 가려지는가는 뒤 층이고, **가림은 세계만 아는 사실에만 뜻이 있다** — 관찰자가 가진 데이터로 유도되는 것은 애초에 가릴 수 없다 |
| **O12** | **클릭의 뜻은 정책이 정한다** — 지금 클릭은 선택이 아니라 **실행**(누른 존재의 첫 행동이 즉시 나간다)이다. 그 결정을 코드에서 빼 **정책으로 주입**하는 것이 이 축의 유일한 구조 변경이고, **그 수술은 한 번만 한다** (TG §5.2 와 같은 자리 — 대결의 지목이 올 때 다시 열지 않는다) |
| **O13** | **몸 위 이름표는 이름과 생명만** 남기고 나머지는 판으로 옮긴다. 지목된 몸만 이름표를 강조한다 |
| **O14** | **실패가 정보로 남는다** — 거절 사유와 세계의 알림은 잠깐 뜨고 사라지되(귀) 판의 **기록**으로 남아 다시 읽힌다. 새 것이 위이고 상한이 있다. 기록은 대상의 것이 아니라 **관찰자의 것**이다 (§17 "실패 원인을 추적할 수 있는가" 가 요구하는 자리) |

**한 문장** — 지금 화면은 "세계가 아는 것" 을 자리를 가리지 않고 전부 글자로 내놓는다.
필요한 것은 새 위젯이 아니라 **정보가 서는 자리의 규약**과, 그 자리를 여는 **지목 하나**다.

## 2. 이 축의 것이 아닌 것

| 무엇을 | 어디가 답하는가 |
|---|---|
| 지목의 수명이 대결로 넘어가는 것 · Tab 순환 · 적대 · 공격 의도 · Acquaintance | TG 와 대결 층 (O4 가 자리를 비워 둔다) |
| 무엇이 언제 가려지는가 (발견 상태 · 아는 것) | 3층 — 주체가 무엇을 아는가 (O11 은 적을 자리까지다) |
| 관찰이 시간 · 기력을 쓰는 것 · 거리 제한 · 실패 사유의 목록 | 3층 (O10 이 구조를 막지 않는다) |
| 표식 남기기 · 지도 그리기 · 기억 | 3층 — 지금 지으면 미지를 사 버린다 (규칙을 품은 방의 "길을 외운다" 와 정면으로 붙는다) |
| hover — 지목하기 전에 미리 알려 주는 것 | 두지 않는다 — O3 가 다시 무너진다 |
| 구체적 문구 · 색 · 수치 | `content/view` 의 결정 표 (컨텐츠와 Human 의 것) |
| 지형이 낳는 재료 · 채취 | [L2-World-Material.md](L2-World-Material.md) |

## 3. 데이터 계약 (의미 계약 — 타입과 파일 배치는 구현이 정한다)

새 layer 는 없다. 세계 계약(봉투)에 **새 자리가 나지 않는다** — O8 때문이다.

### 3.1 판에 무엇이 실리는가

```text
제목        무엇을 지목했는가 — 존재의 이름이거나 자리. 지목이 없으면 **내가 선 자리**를 진다
어디인가     방 · 깊이 · 그 자리
땅이 어떤가  표면(평지 · 비탈 · 급경사 · 젖음) · 지날 수 있는가 · 못 지난다면 사유
무엇이 걸렸나 그 자리에 걸린 자락의 코드들 (조건 · 도시 · 구역 · 통로와 그 열림/닫힘)
규칙이 있나  그 방이 규칙을 품었다면 지금 State 와 마지막으로 바뀐 때
할 수 있는 것 그 대상이 주는 행동과, 지금 못 한다면 그 사유
기록        최근 거절 사유와 세계의 알림 몇 줄 (O14)
알 수 없는 것 그 줄에 「지금 알 수 없다」 (O11)
```

**전부 세계가 이미 아는 값이다.** 화면이 지어내는 것은 하나도 없다.

### 3.2 값이 사는 자리

```text
세계 계약(봉투)   새 자리 없음 — 방 · 깊이 · 방의 State 는 이미 실려 오고, 땅은 관찰자가 같은 규칙으로 만든다 (O8)
세계 State        늘지 않는다 — 지목은 관찰자가 쥔다 (O4)
관찰자가 쥐는 것   지목한 대상 하나 · 기록 (저장되지 않는다)
컨텐츠의 표        코드 → 문구 · 줄의 차례 · 기록의 상한 · 이름표에 남길 것
```

## 4. 코드 대응 — 설 자리

```text
engine/view-kernel/hud/           늘 떠 있는 판 하나 (자판을 잡지 않는다) · 초점 · 곁말
engine/view-kernel/scene/         지목한 것을 강조하는 렌더 지시 — 무엇을 골랐는지 모른 채 그린다
engine/protocol-core/actions.ts   요청의 좌표 — 이미 있다 (O7 · 새 자리가 아니다)
engine/world-authoring/query.ts   자리를 묻는 조회 — 이미 있다 (표면 · 통행 · 사유 · 태그)
content/view/                     판의 결정 표 · 코드 → 문구 · 세계 이름표를 O2 대로 걷어내는 일
input                             클릭의 뜻을 정하는 정책의 주입 자리 (O12)
```

## 5. 실주행이 확정한 것

```text
시점의 상하를 25°~45° 에 묶는다. 좌우는 그대로 돈다 — 아래 한계는 지평선이 남으면서 시점이 몸 뒤 지형에 파묻히지 않는 각이고,
위 한계는 방을 내려다보되 몸과 표식의 그림이 납작해지지 않는 각이다. **시점은 관찰자의 것이므로 세계는 이것을 모른다**

판이 뜬 채 걷기와 시점 돌리기 · 물러남과 방 이동 · 진입 제목 한 번 · 지목의 즉답 · 기록의 규칙과 상한 — 지금 그대로 둔다
```

그리고 이 축의 실주행이 ② 에 규칙 하나를 되돌려 세웠다 — **R14 규칙 가독성의 최소 힌트는 표현이 진다**
(규칙을 품은 방은 자기 규칙의 **형**을 말하고, 잠긴 이음은 어느 갈래의 규칙이 쥐고 있는지까지 말한다.
답은 말하지 않는다). 그 확정의 집은 [L2-World-Region.md](L2-World-Region.md) R14 다 — 여기 다시 적지 않는다.

## 6. 이 축이 어디로 들어왔는가

이 문서가 없던 동안 이 축은 `design/` 의 제안에서 바로 Cycle 로 갔다. 재료 문서의 승인 기록이 그 이유를 적고 있다 —

> "로드맵의 자리 — 8층(화면)을 여는 길은 README §2 표의 **「별도 주입 없음」 규약을 고쳐야 하므로 쓰지 않는다**"

즉 규약이 화면 축의 자리를 막아 두었고, 그래서 이 축은 로드맵 밖에 남았다. 그 규약은 고쳤다 —
화면 축이 필요해지면 8층을 여는 것이 아니라 **2층의 이 문서처럼 ②-부속으로 선다** ([README.md](README.md) §2).
