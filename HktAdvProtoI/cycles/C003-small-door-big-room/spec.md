## 목표

관찰자의 몸이 숲 안쪽에서 붉은 눈의 거목으로 들어가 **작은 문**을 건너면 지금까지 어느 방보다 **네 배 넓은 방**에 서고, 그 방의 끝에 닿으면 **요청하지
않았는데 떨어져** 심장 호수에 선다. 올라갈 길은 없고 남은 것은 물길 하나이며, 그것을 건너면 숲 안쪽인데 **들어갔던 자리가 아니다**.

```text
Start → End    작은 문 하나가 밑동에 있다 → 안이 밖보다 컸고, 끝까지 갔더니 떨어졌고, 돌아갈 길이 없었다. 연결에는 종류가 있다 — 묻고 건너는 것과 묻지 않고 데려가는 것
하지 않는 것    데이터만으로 세계를 바꾸는 실측 · 세계를 표로 보는 도구                      → C004
               고대 문을 여는 규칙 · 발견 상태                                             → C008 이후 · 3층
               환상의 미로 · 붉은 황야 · 얼음 협곡의 방 자체                               → 그 방의 컨텐츠 행
               거목 내부 세계 · 심장 호수 안의 내용물(물 · 생물 · 구조)                      → 4층 이후 — 방은 이름만 있고 비어 있다
               떨어지는 동안의 시간 · 낙하 연출 · 낙하 피해                                 → 없다 — 전이는 한 순간이다
               방의 크기에 따라 시점이 물러나는 것                                          → View 의 결정 (DESIGN §3 결정 대기 「카메라 규칙」)
숨기는 것       중첩 관계(어느 방이 어느 방의 자식인가) — 관찰에 없다 (§14.2)
               추락 이음 — 관찰의 출구 목록에 없다. 묻지 않는 이음은 표식이 없다
```

기반 Cycle 로 읽으면 — 기구: 방마다 다른 크기 · 방의 부모/자식(Containment) · 요청 없이 일어나는 전이 · 한 방향 이음 · 도착만 하는 자리.
계약: 크기 · 부모 · 이음의 전이 종류가 데이터. 예제: 거목 → 내부 세계 → 심장 호수 → 숲 안쪽의 강 어귀.

## UNRESOLVED

