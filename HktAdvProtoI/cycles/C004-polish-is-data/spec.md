## 목표

숲 안쪽의 **고대 문이 열려 있다** — 붙어서 요청하면 「잠겨 있다」가 아니라 「아직 갈 수 없는 곳」이 온다. 이 변화를 만든 것은 **데이터 한 줄**이고 코드는
한 줄도 바뀌지 않았다. 그리고 세계가 자기 그래프(방 아홉 · 이음 열셋 · 중첩 둘 · 경계 셋 · 검사 오류 0)를 도구로 읊는다.

```text
Start → End    앞의 셋이 "나중에 데이터로 바꿀 수 있다" 고 말했다 → 문 하나를 여는 데 코드가 필요하지 않았고, 규칙은 방의 이름을 하나도 모른다. 약속이 측정값이 됐다
하지 않는 것    환상의 미로의 방 · 방이 품는 규칙 · 이음의 활성을 바꾸는 규칙(압력)         → C008 이후
               고대 문을 **무엇이** 여는가 (지식 · 조건)                                 → 3층
               붉은 황야 · 얼음 협곡의 방                                                → 그 방의 컨텐츠 행 — 경계로 남는다
               땅의 컴파일 · 높이 · 표면 · 경사                                          → C005 이후
               도구의 편집 기능 — 도구는 읽기 전용이다                                    → 요구가 오는 Cycle
숨기는 것       없음
```

기반 Cycle 로 읽으면 — 기구: 세계 데이터를 읽어 표와 검사로 내는 도구. 계약: 닫힌 이음 목록 · 경계 목록 · 시작 방 — 셋 다 데이터. 예제: 고대 문 한 줄 · world:observe 한 화면.

## 규칙

```text

  ① 조건  닫힌 이음 목록의 값이 「비어 있음」이 된다 (숲 안쪽의 문이 목록에서 빠진다 · 코드 diff 0)
     변형  숲 안쪽의 문이 「열림」이 된다
  ② 조건  숲 안쪽의 문이 「열림」이고, 몸이 그 표식의 「가까이」이고, 몸의 요청이 「건너기」가 된다 (저쪽 환상의 미로는 「아직 없는 곳」이다)
     변형  요청의 답이 「거절 · 아직 없는 곳」이 된다 — 「거절 · 닫힘」이 아니다
```
