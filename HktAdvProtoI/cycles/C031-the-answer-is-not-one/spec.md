## 목표

관찰자의 몸이 협곡 어귀에서 **세 걸음 걸어 들어가는 동안 문의 말이 바뀐다** — 「체열이 감지된다」가 「눈보라 속에서 약하다」가 된다. 되돌아 나오면 처음 말로
돌아온다. **답은 손에 드는 것만이 아니다** — 어디에 서 있는가도 답이다. 그래서 그 문의 답이 재료 둘과 **환경 하나**가 된다.

```text
Start → End    답은 가져가는 것이다 — 무언가를 캐서 지녀야 한다 → 답은 가져가는 것만이 아니다. 여기 서 있으면 덜 들킨다. 같은 문을 두 사람이 다른 자리에서 다르게 읽는다 — 세계가 하나의 정답으로 닫히지 않는다
하지 않는 것    완화가 문을 **열게** 하는 것 — 2층은 표시까지다                                        → 3층 · 4층 (K12)
               몸이 요구에 답하는 것(체열 억제) · 지식이 요구를 여는 것                                → 3층
               가능성을 지니는 것 · 성질의 조합과 상쇄                                                → 4층
               눈보라를 철에 매는 것 — 이 협곡의 눈보라는 그치지 않는다                                 → 그렇게 바꾸려면 협곡의 확정을 뒤집는 일이다 (Human)
               협곡 문 뒤에 무엇이 있는가                                                            → 그 방의 컨텐츠 행 (㊷ 가 지금은 "뒤에 아무것도 없다" 를 적는다)
숨기는 것       무엇이 요구를 무르게 했는가 — 판은 완화된 말만 하고 눈보라를 가리키지 않는다. 관찰자는 걸어 들고 나며 그 경계를 안다 (그것이 미지감이다)
```

기반 Cycle 로 읽으면 — 기구: 요구가 자기를 무르게 하는 자락을 밝히는 자리 · 사유가 **몸이 선 자리**를 함께 읽는 것 · 환경이 답의 한 종류로 세어지는 것.
계약: 어느 요구가 어느 자락에서 약해지고 그때 무엇을 말하는가가 전부 데이터. 예제: 빙결 심층의 문 × 협곡의 눈보라.

## UNRESOLVED

**없음** — 닫힌 Cycle.

기본형으로 둔 것 (Human 이 감사할 자리).

```text
① 돌아옴을 **자락을 걸어 나가는 것**으로 보인다 — 이 협곡의 눈보라는 그치지 않는다(M5 확정)고 협곡이 이미 못 박았으므로 "걷히면 돌아온다" 는 길이 막혔다. 들어온 자리가 자락 밖이고 거기서 문까지 세 걸음이다. 눈보라를 철에 매는 것은 협곡의 확정을 뒤집는 일이라 이 Cycle 이 정하지 않는다 (DESIGN 결정 대기)
② 몸의 김을 눈보라 속에서 옅게 하지 않았다 — 문 앞의 자락이 눈보라 자락 **안에 통째로 들어 있어** 옅은 쪽이 늘 서고 밝은 쪽이 한 번도 서지 않는다. C029 가 보인 「김이 푸르게 빛난다」가 세계에서 사라진다. 겹치지 않게 하려면 어느 한쪽의 자리를 옮겨야 하고 그것은 데이터 결정이다 (DESIGN 결정 대기)
③ 완화된 사유가 처음 사유를 **대신** 선다 (곁에 함께 서지 않는다) — 같은 것에 판이 두 번 답하지 않게. 그래서 문구 하나가 두 마디를 다 진다 (DESIGN 결정 대기)
④ 완화를 **몸이 선 자리**로 읽는다 — 기획서는 자락까지만 적고 누구의 자리인지 말하지 않는다. 감지되는 쪽이 자락 안일 때로 읽어야 "눈보라 속이면 덜 본다" 가 걸음으로 관찰된다
⑤ 완화 자락을 **그 자락 하나의 이름**으로 가리킨다 (태그가 아니라) — 같은 태그를 여러 자락이 나눠 가질 수 있기 때문이고, C029 의 흔적이 가리키는 어법과 같다
⑥ 계약 목록에 성질 어휘를 **등록**하는 데까지다 — 작성기가 요구를 구조로 적기 전에는 판정할 입력이 없다 (ENGINE 레인의 자리)
```
