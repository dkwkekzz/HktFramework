## 목표

**관찰자의 몸이 세계에 서서 HP 와 CP 를 가지고, 몸의 성질은 저장된 값이 아니라 유도된다.** 최대 HP · 최대 CP · 인지 범위가 「몸의 종류 · 때 · 자락」 세 Source 의 합으로 나오고,
그 값이 지금 세계와 한 값도 다르지 않다. 조건이 처음으로 **행위자를 가리킨다** — 빙결 심층의 문이 「체열이 숨겨지는가」를 문 앞의 몸에게 묻고, 답할 Source 가 없는 몸에게 문은 닫혀 있다(2층까지는 묻지 않고 표시만 했다).
그리고 몸은 Core 를 가진다 — 성장이 귀속될 자리가 몸의 지속 상태로 선다.

```text
Start → End    몸의 값은 닫힌 필드다. 최대 HP 도 인지 범위도 태어날 때 박힌 숫자이고 세계는 몸에게 아무것도 묻지 않는다 → 몸의 성질은 물음의 답이다. 세계가 몸에게 묻고 여러 Source 가 답하며, 문이 처음으로 몸에게 묻는다
하지 않는 것    관찰이 무대 몸의 인지 범위를 읽는 것 · 앎 · 행동 입구 · 행동의 생명주기                          → C040
               원정 · 무대의 한 명 · 교체 · 대기 몸 · Core 둘째                                                  → C041
               장착 슬롯 여섯 · Bag · Source 가 슬롯으로 들어오는 것                                              → C042
               Source 로서의 장착물 · 소지 · Aura · Ability · 조건의 효과                                         → 4 · 6층 (Source 의 자리만 — 합성 규칙은 여기)
               추위가 HP 를 깎는 것 · 결정면 접촉이 몸에 하는 일 · 체온을 쫓는 것                                  → 컨텐츠 행 (M8 — Human 이 이름을 줄 때) — 질문 Q3 이 이것을 되묻는다
               앎 요구의 판정(knowledge Lock) · 플레이어 · 세력 대상의 조건                                        → C040(앎) · 층 없음(플레이어 · 세력 — 자리만 그대로)
               Core 가 무엇을 열고 어떻게 자라는가 · Class                                                        → 6 · 7층 (자리만)
               태어난 개체(탄생지의 셈)가 몸을 얻는 것                                                            → 컨텐츠 행 (Life F10 — 3층은 미지를 놓지 않는다)
숨기는 것       성질을 이루는 Source 의 목록과 각 몫(관찰자는 최종값만 본다) · 문이 몸의 무엇을 읽었는가(판은 여전히 「체열이 감지된다」 현상만 말한다) · Core 의 값이 무엇을 여는가
```

기반 Cycle 로 읽으면 — **기구**: 몸의 성질을 묻는 자리(성질 이름 → Source 들의 답 → 최종값 · 저장 0)와 Source 의 형(누가 · 어느 성질에 · 어떤 몫 — 상한 · 더함 · 참거짓) ·
조건 평가기의 「행위자」 갈래(성질 · 있음 · 상태 물음이 실제 몸을 읽는다) · 몸에 귀속된 Core 의 자리.
**계약**: 몸의 종류마다의 기본 성질 · 때와 자락이 인지 범위에 거는 상한 · 문의 성질 요구가 읽는 몸의 성질 이름 · Core 의 값 — 전부 데이터이고 세계는 그 이름을 짓지 않는다.
**예제**: 관찰자의 몸 하나(rabbit-swordsman — 최대 HP 200 · 최대 CP 100 · 인지 범위 「제한 없음」) · 빙결 심층 문의 「체열이 숨겨진다」 물음 하나 · Core 「야수계」 하나.
