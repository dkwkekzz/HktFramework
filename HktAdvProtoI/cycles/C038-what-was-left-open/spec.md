닫힌 Cycle 이다. 목표 · 규칙 형식으로 다시 썼고 의미는 기획서와 앞 spec 이 이미 약속한 것에서만 왔다 — 새로 세운 게임 의미가 하나도 없다.

## 목표

**형이 약속한 만큼 세계가 실제로 그렇게 한다.** 세계가 아직 드러나지 않은 기회를 관찰에 싣지 않고(발견되지 않은 것은 관찰자가 알 길이 없다 — 그것이 그 갈래의 뜻이다),
조건이 문 · 자락 · 되돌아옴까지 읽고, 검사가 태어남의 셈을 양쪽으로 재고, 도구의 표가 갓 선 세계 말고 **묻는 때**의 값을 보이며,
지나간 것이 남긴 자리가 스러진 것도 방의 기억에 남는다. 화면에 새로 서는 글자는 없다 — 이 Cycle 은 **약속을 지키는 Cycle** 이다.

```text
Start → End    형과 약속은 섰는데 그것을 지키는 자리가 비어 있다 — 세계는 숨긴 것을 흘리고, 조건은 형보다 좁게 읽고, 표는 한 때만 보인다 → 형이 약속한 만큼 세계가 실제로 그렇게 한다
하지 않는 것    아직 드러나지 않은 것이 **발견되는** 절차(무엇이 그것을 드러내는가)                        → 3층 (발견 상태 다섯 · G10) — 여기서는 **거름**만 세운다
               새 조건 갈래(행위자 · 플레이어 · 세력 · 확률)의 읽기                                      → 그 층. 여기서 여는 셋은 **이미 형에 있고 세계가 값을 아는** 것뿐이다
               「몇 번 스러졌나」를 고갈과 **따로** 세는 것                                               → 두지 않는다 — 같은 잣대로 센다 (아래 기본형 ③)
               묻는 때의 값이 방 하나의 **그림**에까지 닿는 것                                           → 도구 부채 그대로 (보고의 표만 낸다)
숨기는 것       아직 드러나지 않은 기회의 존재 · 그것이 무엇인지 · 무엇이 그것을 드러내는가. 조건이 새로 읽는 값(문의 열림 · 자락의 걸림 · 되돌아옴의 마디)도 여전히 조건의 결과 코드로만 말해진다
```

기반 Cycle 로 읽으면 — **기구**: 관찰이 기회의 이름을 붙일 때의 거름 하나 · 조건이 읽는 대상 셋 · 검사 ㊸ 의 뒷면 잣대 · 보고를 묻는 때로 내는 손잡이.
**계약**: 거름은 **세계**가 한다 — 판이 그리지 않는 것으로 두면 다른 Client 가 그것을 보게 된다 (원칙 1 · 3). 무엇을 숨길지는 데이터의 갈래 한 값이다.
**예제**: 데이터에 아직 드러나지 않은 기회가 하나도 없다 — 형과 시험이 그 자리를 잰다.

## UNRESOLVED

**없음** — 닫힌 Cycle. 다섯 다 앞 spec 이 이미 정한 의미이고 새로 결정할 게임 의미가 없다.

기본형으로 둔 것 (Human 이 감사할 자리).

```text
① **거름은 세계가 한다** — 판이 그리지 않는 것으로 두면 다른 Client 가 그것을 보게 된다 (원칙 1 · 3)
② **여는 읽기 셋은 세계가 이미 값을 아는 것뿐이다** — 문의 열림 · 자락의 걸림 · 되돌아옴의 마디. 새 State 도 새 판정도 없다
③ **스러짐을 고갈과 같은 셈으로 센다** — 따로 세면 같은 사실("그 자리가 비었다")을 세계가 두 말로 하게 된다. 따로 세야 하면 데이터가 아니라 형이 늘 자리다
④ **묻는 때는 보고의 표에만 닿는다** — 방 하나의 그림에 덧씌움을 얹는 것은 도구 부채 그대로다
⑤ **아직 드러나지 않은 것의 문구를 표에서 지운다** — 세계가 그 코드를 싣지 않게 되었으므로 닿지 않는 말이다
```
