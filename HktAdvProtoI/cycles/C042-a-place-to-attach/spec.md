## 목표

**몸과 원정에 뒤 층이 붙을 자리가 선다.** 모든 몸이 장착 자리 「여섯」을 가지고(부위 이름 없음 · 전부 「빈 자리」), 그 자리는 Source 를 몸에 잇는 자리일 뿐 아무것도 실행하지 않는다 —
변형 데이터로 자리 하나에 「체열이 숨겨진다」 Source 를 걸면 빙결 심층의 문이 긴 밤에 열리고, 비우면 다시 닫힌다. 원정은 Bag 하나를 가진다 — 지금 몸의 소지품(곡괭이 · 광석 · 허물)이 원정의 Bag 으로 옮겨 가
둘째 요정도 같은 곡괭이로 캔다. 물건의 규칙은 한 줄도 바뀌지 않는다.

```text
Start → End    소지품은 몸의 것이고 몸에 무엇을 붙일 자리가 없다 → 원정이 가방을 들고 몸마다 여섯 자리가 비어 있다. 4층은 그 자리에 물건을, 6층은 능력의 출처를 넣기만 하면 된다
하지 않는 것    아이템이 무엇인가 · Bag 의 칸 수(30) · 이동 · 쌓기 · 획득 · 버리기 · 소모 · 제작                    → 4층 (§22 — 소유 구조까지)
               「장착」 행동 · 장착 가능 여부 · 장착물의 효과 · 슬롯의 부위 의미                                   → 4 · 6층 (§20 · §21 — 자리만)
               슬롯이 능력 · Skill 을 실행하는 것 · Ability Source · Ability Rule                                 → 6층 (R7 — Slot → Source 까지)
               Bag 을 읽는 조건(「포함」 물음)                                                                   → 4층 (자리만 그대로 — 판정 불가)
숨기는 것       빈 자리 여섯(관찰자에게 아직 아무것도 말하지 않는다 — 실릴 것이 없다) · Bag 이 원정의 것이라는 사실(판의 소지품 줄은 지금과 같이 보인다)
```

기반 Cycle 로 읽으면 — **기구**: 몸마다의 자리 여섯(빈 자리 또는 Source 하나)과 그 자리가 성질 물음의 Source 로 읽히는 길 · 원정에 붙은 Bag 하나와 무대 몸이 그것을 쓰는 길 · 둘을 재는 검사 하나.
**계약**: 자리의 수(여섯 — 원문이 정했다 · 헤더 상수) · 시작 Bag 의 내용 · 자리에 걸린 Source 가 어느 성질에 어떤 몫인가 — 데이터.
**예제**: 관찰자 몸의 빈 자리 여섯 · 원정의 Bag 에 든 곡괭이 하나 · 변형 데이터의 Source 한 줄(체열이 숨겨진다).

## UNRESOLVED

첫 spec 의 질문 **Q6**(소지품을 원정의 Bag 으로 옮기는가)의 답이 이 spec 에 든다. 이 spec 에서 새로 생긴 의미는 없다 — 자리의 수 여섯은 원문이 정했다.

기본형으로 둔 것 (Human 이 감사할 자리).

```text
① 자리의 수 「여섯」은 헤더 상수다 (원칙 6 — 원문 §20 이 고정했고 모든 몸이 같다). 손잡이가 아니다
② 자리는 「빈 자리」 또는 「Source 하나」다 — 쌓지 않는다. Source 의 형은 C039 의 것(성질 이름 · 몫)이고 무엇이 그것을 자리에 넣는가는 4 · 6층의 행동이다
③ 소지품은 **옮긴다** (Q6 추천) — 몸의 소지품 자리가 사라지고 원정의 Bag 이 그것이다. 물건의 이름 · 수 · 도구 판정은 그대로다
④ Bag 을 쓰는 것은 무대 몸이다 — 대기 몸은 세계에 없으므로 쓸 일이 없다. 원정 단위의 소유가 드러나는 자리는 "둘째가 같은 곡괭이로 캔다" 하나다
⑤ 「장착」 행동을 두지 않는다 — 자리에 무엇을 넣는 길은 이번 세계에 없고 변형 데이터로만 실측한다 (뒤 층의 것을 더미로 만들지 않는다)
⑥ Bag 을 읽는 조건(「포함」 물음)은 자리만 그대로 둔다 — 판정 불가. 4층이 연다
⑦ 검사 하나가 자리 여섯과 Bag 하나를 함께 센다 — 둘 다 "정확히 하나/여섯" 을 재는 같은 모양의 검사다
```
