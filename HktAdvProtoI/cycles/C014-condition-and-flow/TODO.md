`npm run dev` 로 직접 본다. 그림은 같은 폴더 `shots/`.

**"재료는 하나의 사슬이고, 어떤 것은 다른 방에서 실려 온다"** 로 옮겨 갔는가.

물길은 240 세계 초마다 30 초씩 분다. 손으로 볼 때는 어귀에서 기다리면 되고, 그림은
그 State 에서 무엇이 보이는가를 보인다 (`HKT_SOURCE_PHASE="A:phase,B:phase"` — 세계 규칙을
하나도 바꾸지 않는 배치 손잡이다).
