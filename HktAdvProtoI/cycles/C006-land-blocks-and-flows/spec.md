## 목표

**땅이 처음으로 몸에 닿는다.** 백왕령의 데이터에 물길 하나와 자리 둘과 자락 넷을 더해 컴파일하면,
관찰자가 북쪽 능선으로 걸어 올라가다 **막히고**(세계의 대답: 너무 가파르다), 방을 가로지르는 **강에 막히며**, 다리 자리 하나로만 건넌다.
강가는 젖은 색이고 도시 곁에 백색 거목이 서 있으며, 조건 자락 안에 서면 판이 **왜 여기가 안전한가**를 말한다 — 산이 막는다 · 강이 먹인다 · 거목이 물린다.

```text
Start → End    북쪽은 솟았지만 아무것도 막지 않는다. 방은 여전히 어디로든 걸어갈 수 있는 색칠된 바닥이다 → 못 넘는 산과 못 건너는 물이 생겼다. 건널 자리는 하나뿐이고 거목 아래 도시가 있다. 땅이 처음으로 몸에 닿았고 화면이 "안전한 이유" 를 말한다
하지 않는 것    도구의 그림 넷과 보고 · 데이터만으로 새 방을 채우는 실측 · 촬영                        → C007
               장식(scatter) · 무작위 · 여러 개체의 instance                                        → C007 · 폴리싱
               막힌 것을 피해 가는 길찾기 · 밀려남                                                  → 두지 않는다 (§1 "경로 탐색 · Collision mesh 는 없다 — traversable 격자까지")
               조건이 실제로 무엇을 막는 것 (조건은 **표시**다)                                      → 3층 이후 (W2 는 조건을 적으라고만 한다)
               높이 · 경사가 속도 · 체력에 하는 일                                                  → 3층 (§2)
               걷는 도중의 진행이 통행을 다시 읽는 것                                               → 결정 대기 (DESIGN §3 Tool — 막는 것은 요청 판정뿐이다)
숨기는 것       다리가 어디 있는지 · 어디가 막히는지 · 조건 자락이 어디까지인지 · 통행 임계가 몇 도인지. 봉투가 그 격자를 싣지 않으므로 **걸어 보아야 안다** — 화면의 색과 세계의 대답이 유일한 안내다
```

기반 Cycle 로 읽으면 — **기구**: 물길이 땅을 파는 자리 · 물길로부터의 거리 · 통행 격자(경사 임계 + 막는 것 + 사유 태그) · 자락과 자리를 컴파일 산출로 내보내기 ·
자리로 태그를 묻는 조회 · 자리 하나를 세워 그리는 것.
**계약**: 세계 사실(경사 임계 · 통행 임계 · 강가 젖음의 폭 · 표면 태그의 차례)이 **세계와 관찰자가 함께 읽는 한 표**에 있고, 표현(태그 → 색 · 태그 → 그림 · 코드 → 문구)은 그리는 쪽에 남는다.
**예제**: 백왕령의 강 하나 · 다리 하나 · 백색 거목 하나 · 조건 자락 셋과 도시 하나.

⑤ **조건 태그의 이름** — Concept §3.5 는 `settlement/condition` 까지 주고 안전의 이유를 산 · 강 · 거목 셋으로 갈랐다. 그 둘을 잇기 위해 조건의 접두사 아래 셋을 두었다 (C007 의 검사 ③ 이 그 접두사를 읽는다)
⑥ **사유 코드의 문구** — 코드는 세계의 것이고 문구는 그리는 쪽의 것이다 (C001 부터의 규약). 「너무 가파르다」는 기획서가 준 말이고 물과 조건 셋은 그 어법을 따랐다
⑦ **겹친 조건을 줄이지 않는다** — 기획서가 셋을 함께 말하므로(산맥이 막고 · 강이 먹이고 · 거목이 물린다) 걸린 것을 전부 낸다
⑧ **규칙 표를 방 데이터 곁으로 옮긴다** — C005 가 이 Cycle 로 미룬 결정이다. 세계가 통행 임계를 읽어야 하는 순간 표는 세계와 관찰자의 공유물이 되고, 그 자리는 경계 규칙이 이미 정해 둔 곳이다. 값은 한 글자도 바꾸지 않고 자리만 옮긴다
⑨ **통행 임계는 데이터가 아니라 상수다** — 결정론에 드는 값이라 규칙 표가 아니라 머리에 박는다 (원칙 6). 바꾸려면 코드가 바뀐다는 것이 그 뜻이다
