## 목표

**실패가 정보가 된다.** 세계가 나에게 한 말 — 거절 사유와 알림 — 이 잠깐 뜨고 사라지는 데서 그치지 않고 **판의 기록으로 남는다.**
못 지나간 이유를 나중에 다시 읽고, 무엇이 언제 있었는지 짚는다. 규칙을 품은 방이 길을 재배열하면 그것도 같은 기록에 남아,
압력이 넘친 그 순간을 지나고 나서도 **무슨 일이 있었는지 되짚을 수 있다.**

```text
Start → End    세계가 한 말은 2.2초 뒤 사라지고 뒤에 온 것이 앞의 것을 덮는다 — 실패는 겪을 뿐 남지 않는다 → 말이 남는다. 왜 못 지나갔는지 · 언제 길이 바뀌었는지를 뒤에 가서도 읽는다. 실패가 정보가 된다
하지 않는 것    기록을 펼쳐 더 보는 것 · 걸러 보는 것 · 지우는 것                                  → 두지 않는다 (기획서가 말하지 않는다)
               받아들여진 요청까지 기록하는 것                                                   → 두지 않는다 — 걸을 때마다 늘면 사유가 묻힌다
               세계가 기록을 쌓아 다른 관찰자에게 보내는 것                                       → 두지 않는다 — 기록은 **관찰자의 것**이다 (O14)
               다른 몸에게 일어난 일(타격 · 죽음)을 기록하는 것                                   → 5층 (대결)
               잠깐 뜨는 문구를 걷어내는 것                                                      → 두지 않는다 — 알리는 것과 남기는 것은 하는 일이 다르다 (O1 의 귀와 손)
               관찰이 대가를 갖거나 가려지는 것                                                  → 3층 (O10 · O11)
숨기는 것       기록은 **내가 겪은 것**뿐이다 — 다른 관찰자의 화면에 내 기록이 없고, 세계는 내가 무엇을 들었는지 모른다. 그리고 「언제 다시」는 어느 줄에도 없다 — 얼마 전 일인지만 적힌다
```

기반 Cycle 로 읽으면 — **기구**: 판에 기록이 서는 자리 하나. 그 기구는 무엇이 쌓였는지 모른다.
**계약**: 무엇을 쌓는가(거절과 알림 · 받아들여진 것은 아니다) · 몇 줄까지 · 나이를 무슨 단위로 적는가가 전부 컨텐츠의 표다.
**예제**: 못 지나가는 자리의 거절 하나 · 방에 들어섬 하나 · 미로의 재배열 하나.

## UNRESOLVED

**없음** — 닫힌 Cycle. 기획서 O1 · O4 · O14 와 §3.1, Region §17 이 이번에 필요한 게임 의미를 다 준다.
Human 이 답할 것은 `plan/DESIGN.md` §3 L2-World-Observation "결정 대기 — 관찰" 에 있다.

기본형으로 둔 것 (Human 이 감사할 자리).

```text
① **기록의 상한** — 기획서는 "상한이 있다" 까지다. 판이 화면을 삼키지 않을 만큼으로 이 Cycle 이 정하고 감사 항목으로 올린다. 표현의 결정이라 그리는 쪽 표에 둔다 (C026 의 "줄의 차례" 와 같은 자리)
② **나이를 적는 어법** — 세계 시각이 초이므로 초로 적는다. 타격이 나이를 재는 방식과 같은 자리이고 표현의 결정이다
③ **기록이 사는 시간** — 영원히 남는다. 기획서가 "사라지지 않고 남아 다시 읽힌다" 고만 하므로 시간으로 지우는 규칙을 지어내지 않는다. 미는 것은 상한뿐이다
④ **같은 사유가 이어질 때** — 줄이 하나씩 는다. 묶어 세는 것은 기획서에 없으므로 지어내지 않는다. 규칙 2 ② 가 막는 것은 **같은 한 사건**이 여러 줄이 되는 것이지 서로 다른 두 번의 거절이 두 줄이 되는 것이 아니다
⑤ **방을 옮길 때의 기록** — 남는다. 기록은 대상의 것도 방의 것도 아니라 관찰자의 것이다 (O14)
```
