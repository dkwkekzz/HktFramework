| **선례** | `Design-Creature-Behavior-R0.md` (Agent 초안 → Human 승인 → Inject) |

> **두 층을 한 문서에 둔 이유**: 병합 전 카탈로그는 자기 마지막 절에서 "획득 경로 — 어디서
> 어떻게 얻는가 → 이 문서는 '무엇이 있는가' 만 답한다" 로 그 층을 비워 두었고, 병합된 시스템
> 층이 정확히 그 빈칸이다 (§5 Harvest · §6 Extraction Consequence). 종류와, 그 종류를 세계에서
> 꺼내는 규칙은 서로를 검사할 수 있어야 한다 — 그래서 한 문서다.

### 0. 목적

이 문서는 베이라 세계에서 **자원이 왜 존재하며, 어디에서 생기고, 어떻게 획득되고, 획득이 세계에 어떤 결과를 남기는가**를 정의한다.

아이템 제작법보다 먼저 존재해야 하는 문서다.

```text
World Principle
↓
Terrain / Ecology
↓
Resource Source
↓
Resource
↓
Material
↓
Item
```

베이라에서는 세계압이 안정된 Property로 결속되었을 때 광물·식물·기관·소재·자원이 된다.

따라서 자원은 임의로 배치하는 Loot Node가 아니다.

> **Resource = 세계의 Principle이 물질·생명·환경·정보에 반복적으로 작용한 결과, Actor가 획득하고 다른 상태로 변환할 수 있게 된 세계 상태다.**

---

## 0.1 한 문장 설계

> **자원의 종류는 효과의 목록이 아니라 압력의 목록이다. 어떤 생존 압력이 그 적응을
> 강요했는가가 정해지면 그 자원이 무엇에 쓰이는지는 따라 나오고, 그 반대는 성립하지 않는다.**

이 문장이 막는 것은 `BW §34` 가 금지한 형태다 — "엄청 좋은 약초 → 위험한 곳에 배치".
아래(§14) 어느 계통도 그렇게 읽히면 그 계통은 실패다.

| 계층            | 소유                                      |
| ------------- | --------------------------------------- |

# 2. Resource와 Resource Source

둘을 분리한다.

## Resource Source

자원을 만들어 내거나 보유하고 있는 세계 존재다.

```text
광맥
식물
생체 기관
사체
대기 결정 군락
토양층
기억 모래층
유랑대지의 탈피 부위
```

## Resource

Source로부터 분리되어 Actor가 운반하거나 가공할 수 있는 상태다.

```text
열기억철 광석
혈수지
공생결절
숨결석
기억유리 원석
충격석
```

관계:

```text
Resource Source
    │
    ├─ 자연 성장
    ├─ 축적
    ├─ 분비
    ├─ 탈피
    └─ 매장
         ↓
      Harvest
         ↓
      Resource
```

# 3. Resource Source 분류

## GEOLOGICAL

세계압이 암석과 광물에 결속된다.

예:

* 균압석
* 열기억철
* 상향맥석
* 고정암
* 충격석

## BIOLOGICAL_PLANT

식물이 생존 과정에서 Property를 축적한다.

예:

* 혈수지
* 심박목
* 음형수지

## BIOLOGICAL_ORGAN

생물이 지형에 적응하며 획득한 기관이다.

```text
열 저장낭
공생결절
공명기관
압력 감지기관
```

반드시 죽여야 얻을 필요는 없다.

```text
사냥
탈피 수거
분비물 채취
절단
마취 후 추출
공생 분리
```

등 서로 다른 획득법을 허용한다.

## ENVIRONMENTAL

자연 순환 자체에서 생성된다.

```text
안정수
정상수
등토
빙하 보존 생체조직
```

## INFORMATIONAL

추상적인 상태가 물질에 결속된다.

```text
기억유리
증언사
공백석
```

# 4. Resource Formation

모든 자원은 반드시 다음 질문에 답한다.

```text
왜 여기에서만 생기는가?
↓
어떤 Principle 때문인가?

그 Principle은 무엇에 작용하는가?
↓
암석 / 생명 / 대기 / 정보 ...

어떤 Property가 남는가?
↓
IP-*

그 상태가 오랜 시간 반복되면 무엇이 만들어지는가?
↓
Resource Source
```

지형 역시 `근본 원인 → Property → 자연 순환 → 자원` 순으로 설계하도록 이미 정의되어 있다.

## 4.1 방법 — 새 절차를 만들지 않는다

세 문서가 이미 절차를 정해 두었고 이 문서는 그것을 따르기만 한다.

```text
BW §11   World Pressure → Environment → Survival Pressure → Adaptation → Property → Resource
BW §33   여섯 질문 (WorldState / Survival Pressure / 무엇이 고정했나 / 인간 가치 /
         획득 Gameplay / 여는 Capability)
BW §34   금지 — 좋은 것을 위험한 곳에 배치 · 세계압이 높으니 등급이 높다
SCHEMA   grants 는 **이미 어떤 Possibility 가 요구하는 기존 MC-*** 만 가리킨다.
         없으면 비우고 grants_note 에 사유를 적는다 — 능력을 열지 않는 자원은 정상이다
```

마지막 줄이 이 문서에서 가장 자주 쓰인다. 아래(§14) 12종 중 **grants 를 갖는 것은 넷뿐**이고
나머지는 재료·소재로 선다. 그것이 빠뜨린 것이 아니라 `BW §12` (세계압은 가능성을 늘릴 뿐
전리품을 보장하지 않는다) 와 `DC-GROWTH-NEED-FROM-POSSIBILITY` 를 지키는 형태다.

# 5. Harvest — 자원을 얻는 행위

채집은 Source에서 Item을 생성하는 단순 버튼이 아니다.

```text
Source
+
Harvest Method
+
Actor Capability
+
Tool
+
Environment
↓
Resource Result
+
Source Change
```

예:

### 열기억철 광맥

```text
정밀 절단
→ 결정 구조 보존
→ 안정된 열기억철

강한 충격
→ 빠른 채굴
→ 구조 손상

폭파
→ 대량 획득
→ 열 급방출
→ 주변 빙하 균열
```

따라서 획득 방식이 결과 자원의 상태에 영향을 줄 수 있다.

---

# 6. Extraction Consequence

모든 중요 자원에는 채집 결과가 있어야 한다.

```text
Resource Gain
≠
World Change 0
```

예를 들어 백야철빙원에서는 광맥 채굴 자체가 지역의 열 균형을 변화시킬 수 있다.

가능한 결과:

```text
Source 감소
Source 파괴
환경 Property 변화
생물 서식지 변화
새로운 위험 생성
NPC 경제 변화
다른 Actor의 접근 가능성 변화
```

# 7. Renewable / Exhaustible

Resource는 두 종류로 나눈다.

## Renewable

조건이 유지되면 다시 생성된다.

```text
혈수지
식물성 소재
생물의 탈피물
특정 수계 자원
```

재생은 타이머만으로 이루어지지 않는다.

```text
생물 살아 있음
+
먹이 존재
+
환경 조건 유지
→ 재생
```

## Exhaustible

Source 자체를 소비한다.

```text
광맥
기억유리층
고정암
고대 생물
```

과도하게 채집하면 실제 세계 구조가 변할 수 있다.

# 8. Resource State

같은 Resource라도 획득 결과가 달라져야 하는 경우가 있다.

예:

```text
열기억철
Purity
Thermal Saturation
Structural Stability
Contamination
```

이 차이가 실제 Gameplay에 영향을 주기 시작하면 Runtime에서 별도의 Resource Instance 또는 Resource Lot으로 개체화한다.

아무 차이가 없다면:

```text
열기억철 × 14
```

로 유지한다.

# 10. Resource 관찰 규칙

플레이어는 설명문만 읽어서 자원을 알아내지 않는다.

```text
Observation
↓
Resource Principle 추론
↓
Harvest Method 선택
↓
다른 Result
```

예:

```text
광맥 주변 원형 서리
↓
열이 중심으로 빠져나가고 있다
↓
충격을 주면 저장 열이 급격히 방출될 수 있다
↓
정밀 절단 도구 선택
```

이는 모든 지형 요소가 `관찰 → 원인 → 추론 → 행동`으로 연결되어야 한다는 세계 설계 원칙과 같다.

# 카탈로그 층 (§11 ~ §20) — 무엇이 있는가

여기부터(§11~§20) 병합 전 `Resource Catalog R0` 의 본문이다. 위의 시스템 층이 **어떻게
생기고 어떻게 얻는가**를 정했다면, 아래는 **무엇이 있고 그것이 왜 거기 있는가**를 종류마다
답한다. 두 층은 서로를 이렇게 검사한다.

```text
카탈로그의 한 종류      → 시스템의 §2 Source · §5 Harvest · §7 Lifecycle 에 자리가 있는가
시스템의 한 규칙        → 카탈로그에 그 규칙이 실제로 적용될 종류가 있는가
```

> 상태: **기초 기획 초안** (Agent 작성 — Human 승인·개정 대기)
> 범위: Master Graph 가 **한 번이라도 언급한** 아이템·자원 종류 전부. 각 종류의 세계 유래
> (`IP-*` 성질 · `IT-*` 종류 · `IM-*` 조합)와 그것이 여는 것까지
> 목적: "쓸 물건이 없어서" 아이템 Cycle 들이 열리지 못하는 상태를 끝낸다.
> 광물은 Q22 로 이미 정의되었고, **그때 범위 밖이었던 나머지 전부**가 이 문서다

# 14. 생명이 남긴 것 — 새로 세우는 12종

각 계통은 같은 형식이다. **압력 → 적응 → 성질 → 종류 → (여는 것)** 순으로 읽는다.

## 14.1 회귀초 — 되돌리는 식물 (BW §8 이 이미 명명했다)

| | |
|---|---|
| WorldState | `MW-HYPER-PREDATION` |
| 생존 압력 | 포식 경쟁이 극단적이어서 몸이 부서지는 것이 일상이다. 보통 속도의 회복으로는 아무도 살아남지 못한다 (BW §8) |
| 적응 | "상처를 빨리 낫게 한다" 가 **아니라** "안정되어 있던 이전 생체 상태를 유지한다" (BW §8) |
| 인간 가치 | 치명상 · 장기 손상 · 절단 · 일부 질병 — 문명권 의료의 한계를 넘는다 |

```text
IP-STATE-PRESERVING   겪은 변화와 무관하게 이전의 안정된 상태를 유지한다
IT-RETURN-HERB        그 성질을 지닌 식물 — BW §8 의 회귀초. 쓰면 없어진다
IM-STATE-RESTORING    그 성질을 몸에 작용시키는 형태
grants                MC-RESTORE-BIOLOGICAL-STATE  ← 기존 노드. MP-ADAPT-BY-RESOURCE 가 이미 요구 중
```

**실패로 읽히는 형태**: 체력을 얼마 채워 주는 물약. 회귀초는 양을 더하는 것이 아니라
**되돌리는** 것이고, 되돌릴 이전 상태가 없으면 아무 일도 하지 않는다.

## 14.2 회귀 기관 — 되돌리는 생명 (BW §6 "신체를 원래 상태로 복원하는 생명")

같은 지역, 같은 압력의 **생물판**이다. 식물은 그 자리에 남고 생물은 그 성질을 몸 안에
기른다 — 그래서 이쪽은 **몸에서 꺼내야 하는 것**이고, 그 사실이 `MG-ACQUIRE-RARE-ORGAN`
(특정 생물의 희귀한 기관을 손에 넣는다)의 **첫 실물**이 된다.

| | |
|---|---|
| WorldState | `MW-HYPER-PREDATION` |
| 생존 압력 | 위와 같다. 다만 움직이는 것은 그 자리의 식물을 기다릴 수 없다 |
| 적응 | 되돌리는 작용을 몸 안의 한 기관에 모았다 |
| 인간 가치 | 회귀초보다 강하고, 대신 그 생물을 상대해야만 얻는다 |

```text
IP-STATE-PRESERVING   (같은 성질을 공유한다 — 성질은 한 번만 세운다)
IT-REVERSION-ORGAN    그 작용을 담은 기관. 몸에서 나오므로 세계의 아이템 층을 요구한다
IM-STATE-RESTORING    (같은 조합을 공유한다) → grants: MC-RESTORE-BIOLOGICAL-STATE
```

**주의**: 같은 성질·같은 조합을 공유하는 것이 요점이다. 같은 의미의 능력을 출처별로
복제하지 않는다 (`DC-GROWTH-NO-CAPABILITY-DUPLICATION`). 회귀초와 이 기관의 차이는
능력이 아니라 **얻는 경로와 대가**다.

## 14.3 갑각 — 파고드는 것을 붙잡는 층 (BW §22 "특수 갑각")

| | |
|---|---|
| WorldState | `MW-ZONE-WILD` |
| 생존 압력 | 서로의 몸을 뚫는 것이 일상이다. 한 겹으로 막는 몸은 뚫린 한 번에 끝난다 |
| 적응 | 두께가 아니라 **겹**이다. 얇은 층을 여러 겹 두어 파고드는 것을 층마다 붙잡는다 |
| 인간 가치 | 관통에 대응하는 유일한 형태의 방어구 재료 |

```text
IP-PENETRATION-RESISTANT   파고드는 힘을 여러 겹으로 나누어 붙잡는다
IT-LAYERED-SHELL           그 갑각을 덧댄 방어구. 장착형
grants                     없음 — grants_note: 방어의 **형태**는 이미 세계에 있다
                           (방어 종류 층 · 관통 층 — 설계에 있고 코드에는 아직 없다).
                           이것은 새 능력이 아니라
                           그 형태 중 하나를 실제로 지닌 첫 재료다
```

**산격석과 무엇이 다른가**: 산격석은 **큰 한 번**을 흩어 보내고 작은 것에 약하다.
갑각은 **파고드는 것**을 붙잡고 넓게 오는 충격에는 그대로 흔들린다. 둘을 같은 자리에
쓰면 선택이 사라진다 — 서로 반대쪽에 강해야 이 둘이 다 존재할 이유가 있다.

## 14.4 독 — 삭이는 것 (BW §22)

`MG-ACQUIRE-RARE-ORGAN` 이 요구하는 "몸에서 나오는 것" 중 유일하게 **상대에게 쓰는** 것이다.

| | |
|---|---|
| WorldState | `MW-ZONE-WILD` |
| 생존 압력 | 정면으로 이길 수 없는 것들이 섞여 산다. 한 번에 끝내지 못하면 죽는 쪽이 자기다 |
| 적응 | 힘이 아니라 **시간**으로 이긴다 — 닿기만 하면 상대의 구조가 스스로 무너진다 |
| 인간 가치 | 정면 전투력이 앞서는 상대를 힘 아닌 것으로 뒤집는 수단 (`MW-ZONE-FRINGE.world_shape` 가 요구하는 바로 그 형태) |

```text
IP-CORROSIVE     닿은 것의 구조를 시간에 걸쳐 무너뜨린다
IT-VENOM-SAC     그 독을 담은 주머니. 쓰면 없어진다. **고른 대상에게 쓴다**
grants           없음 — grants_note: 독은 능력이 아니라 **이름 붙은 조건**이다.
                 그 자리는 MC-CONDITION-STACKING(PARTIAL)이 소유한다
```

**이 계통이 여는 것**: 불식광의 `pressure` 는 이미 "독과 삭임이 만연해 반응하는 것은 다
사라졌다" 라고 적혀 있다 — **불식광이 존재하는 이유가 이 독이다.** 이 계통을 세우면
기존 광물 하나의 유래가 세계 안에서 확인 가능해진다.

## 14.5 정화기관 — 중화하는 기관 (BW §17 · §18 이 ID 까지 명명했다)

BW 가 `IT-PURIFICATION-ORGAN` 이라는 이름을 직접 썼고, Master 는 그것을 **삽화라는 이유로
비주입 판정**했다 (`capabilities.yaml` 말미 · HISTORY Q14). 그 판정의 사유는 "요구가 없다"
였고, **§14.4 가 서면 그 사유가 사라진다.**

| | |
|---|---|
| WorldState | `MW-ZONE-WILD` |
| 생존 압력 | 같은 지역에 삭이는 것이 만연하다 (§14.4 의 뒷면) |
| 적응 | 삭이는 것을 몸 안에서 중화하는 기관을 길렀다 |
| 인간 가치 | 더 강한 독성 지역으로 들어갈 수 있게 된다 — BW §17 Capability Gate 의 교과서 예시 |

```text
IP-TOXIN-NEUTRALIZING    삭이는 작용을 중화한다
IT-PURIFICATION-ORGAN    그 기관 (BW §18 이 명명한 ID 를 그대로 쓴다)
IM-*                     세우지 않는다
grants                   없음 — grants_note: BW §18 은 MC-DETOXIFY 를 예로 들지만
                         그 노드는 존재하지 않는다. 새 MC 를 이 아이템 때문에 만들지
                         않는다 (BW §18 이 스스로 금지한다). 독이 세계의 상태가 되고
                         어떤 Possibility 가 "그것을 견디고 들어간다" 를 요구할 때
                         MC 가 서고, 그때 이 grants 를 잇는다
```

**이것이 `BW §18` 의 방향 그 자체다**: 요구가 먼저, 경로가 나중. 이 문서는 **경로만**
준비해 두고 요구는 만들지 않는다.

## 14.6 감응 기관 — 닿지 않고 아는 것 (BW §22 "비정상적 감각")

| | |
|---|---|
| WorldState | `MW-ZONE-WILD` |
| 생존 압력 | 보이지 않는 것에게 먼저 발견되면 진다 |
| 적응 | 시야가 아닌 것으로 안다 — 진동 · 열 · 압력의 결 |
| 인간 가치 | 살펴보지 않고도 아는 힘의 **세계 안 원천** |

```text
IP-FIELD-SENSING       닿지 않은 것의 존재와 상태를 읽는다
IT-SENSING-ORGAN       그 기관. 장착형
grants                 없음 — grants_note: "아는 힘" 은 이미 MC-OBSERVE 의 경로 하나로
                       설계에 서 있다 (통찰 층). 이것을 별도 MC 로 세울지는
                       아직 Human 앞에 열려 있는 질문이다.
                       그 답이 나오기 전에는 grants 를 잇지 않는다
```

**이 계통은 Q29 를 대신 결정하지 않는다** — 다만 Q29 가 (b)나 (c)로 답해질 때
"그 힘을 세계에서 어떻게 얻는가" 의 답이 미리 준비되어 있게 한다.

## 14.7 도약근 — 한 번에 자리를 바꾸는 것 (BW §22 "특수 이동")

| | |
|---|---|
| WorldState | `MW-ZONE-WILD` |
| 생존 압력 | 상시 포식 아래에서 걷는 속도로 자리를 옮기는 것은 죽는 것과 같다 |
| 적응 | 힘을 모아 두었다가 한 번에 푼다 — 지속 속도가 아니라 **한 번의 도약** |
| 인간 가치 | 유리한 자리를 의도적으로·빠르게 잡는 수단 |

```text
IP-EXPLOSIVE-RELEASE   모아 둔 힘을 한 번에 푼다
IT-LEAPING-TENDON      그 근·건. 장착형
grants                 MC-REPOSITION  ← 기존 노드(PARTIAL). MP-CONTROL-MOVEMENT 가 요구 중
```

**이것이 채우는 결손**: overlay 는 `MC-REPOSITION` 의 부족을 "유리한 자리를 **빠르게·
의도적으로** 잡는 전용 수단. 걸어가서 만들 수는 있다" 라고 적어 두었다. 이 계통이
정확히 그 문장을 겨냥한다.

## 14.8 환경을 두른 것 (BW §23 "Resource 역시 특정 환경 Property 를 가지기 시작한다")

| | |
|---|---|
| WorldState | `MW-ZONE-DANGER` |
| 생존 압력 | 장소 자체가 해를 입힌다. 위험이 사건이 아니라 상시 조건이다 |
| 적응 | 그 환경을 막는 것이 아니라 **몸에 들여 같이 지닌다** |
| 인간 가치 | 그 환경 아래에서 버티는 시간을 산다 |

IP-HAZARD-TOLERANT     특정 환경 작용 아래에서 자기 기능을 유지한다
IT-HAZARD-HIDE         그 성질을 지닌 가죽·껍질. 쓰면 없어지는 형태와 장착형 둘 다 가능하다
grants                 없음 — grants_note: 환경 위험이라는 개념이 아직 세계에 없다
                       (MC-READ-ENVIRONMENT · MC-USE-HAZARD 둘 다 MISSING).

## 14.9 재생 조직 — 계속 되돌아오는 것 (BW §24 "극단적 재생")

| | |
|---|---|
| WorldState | `MW-ZONE-DEEP` |
| 생존 압력 | 인간의 전투 상식이 무너지는 층. 한 번 이겼다고 끝나지 않는다 |
| 적응 | 잃은 것을 **다시 만든다** — 시간이 지나면 원래대로 돌아간다 |
| 인간 가치 | 끊기지 않고 이어지는 회복 |

```text
IP-REGENERATIVE        잃은 구조를 시간에 걸쳐 다시 만든다
IT-REGENERATIVE-TISSUE 그 조직. 쓰면 없어진다 (지속되는 조건을 남긴다)
grants                 없음 — grants_note: 이것은 능력이 아니라 이름 붙은 조건이다
                       (MC-CONDITION-STACKING). 회귀(§14.1)와 헷갈리면 안 된다
```

**회귀와 재생의 차이가 이 문서에서 가장 중요한 구분이다.**

```text
회귀   변화 자체를 되돌린다 — 되돌릴 이전 상태가 있어야 성립한다. 즉시. 한 번
재생   잃은 것을 다시 만든다 — 이전 상태를 몰라도 성립한다. 시간에 걸쳐. 계속
```

`MC-MAINTAIN-PRESSURE` 의 detail("상대가 시간이 지나면 되돌아가는 성질을 갖는다")이
이미 재생을 **적의 성질**로 적어 두었다 — 이 계통은 그것을 인간 쪽으로 가져온 것이고,
그래서 그 능력이 왜 필요한지가 같은 지역 안에서 설명된다.

## 14.10 축전 기관 — 힘을 담아 두는 것 (BW §6 "엄청난 에너지를 저장하는 기관")

이 문서에서 **가장 많은 결손을 건드리는 계통**이다.

| | |
|---|---|
| WorldState | `MW-ZONE-DEEP` |
| 생존 압력 | 한 번의 교전이 길고, 힘이 떨어진 쪽이 곧 먹이가 된다 |
| 적응 | 쓸 힘을 몸 안에 **담아 둔다** — 계속 내는 것이 아니라 모아 두었다 꺼낸다 |
| 인간 가치 | 기력이 스스로 돌아오지 않는 세계에서 그것을 **되찾는 첫 경로** |

```text
IP-ENERGY-DENSE        자기 크기에 비해 큰 힘을 담아 둔다
IT-ENERGY-ORGAN        그 기관. 쓰면 없어지는 형태(즉시 회복)와 장착형(용량 증가) 둘 다
grants                 없음 — grants_note: MC-CP-ECONOMY 는 이미 있는 노드다.
                       이 계통은 능력을 **주는** 것이 아니라 그 노드의 결손
                       ("기력이 스스로 돌아오지 않는다")을 세계 안의 경로로 채운다
```

**이 계통이 동시에 겨냥하는 세 자리**

```text
MC-CP-ECONOMY (PARTIAL)              기력 회복 경로가 "타격 성공" 하나뿐이다  → 두 번째 경로
MC-ATTACK-POWER (PARTIAL)            값을 올릴 세계 내 경로가 없다            → 장착형이 그 첫 경로
MP-OUTGROW-THE-OPPONENT.resource     "능력치를 올릴 장비·성장의 원천"         → 그 원천
```

**주의 (Human 판단 자리)**: 능력치 증분은 이 문서가 갖지 않는다 (Cycle 소유). 그리고
이것이 `MC-ATTACK-POWER` 를 채우려면 **장착 Cycle 이 먼저 서야** grants 가 몸에 닿는다.

## 14.11 기억을 뜬 것 (BW §6 · §25 "기억을 물질에 보존하는 생물")

| | |
|---|---|
| WorldState | `MW-ZONE-UNKNOWN` |
| 생존 압력 | 인식·정체가 흔들리는 층. 자기가 무엇을 겪었는지조차 남지 않는다 |
| 적응 | 겪은 것을 몸 밖의 물질에 새겨 둔다 — 자기 안에 두면 함께 바뀌기 때문이다 |
| 인간 가치 | 지금 보는 것이 실재인지 대조할 **바깥의 기준** |

```text
IP-MEMORY-BEARING   겪은 것을 물질에 새겨 두고, 그 새김은 주변이 바뀌어도 바뀌지 않는다
IT-MEMORY-CAST      그 물질. 지니는 것만으로 작용한다
grants              MC-VERIFY-REALITY  ← 기존 노드. MW-ZONE-UNKNOWN 이 demands 로 요구 중
```

**정박정과 무엇이 다른가**: 정박정은 **내가 무엇이었는지**를 붙든다(정체). 이것은
**무엇이 있었는지**를 붙든다(사실). 둘 다 UNKNOWN 층의 답이지만 지키는 대상이 다르고,
그래서 둘을 함께 지녀야 그 층이 온전히 감당된다.

## 14.12 둥지 기관 — 접힌 공간에서 나오는 것 (BW §25 "공간을 둥지로 사용하는 생명")

| | |
|---|---|
| WorldState | `MW-ZONE-UNKNOWN` |
| 생존 압력 | 공간이 그대로 있지 않다. 갇히는 것이 곧 죽는 것이다 |
| 적응 | 자기 둥지로 쓰는 공간을 **드나드는** 기관을 길렀다 |
| 인간 가치 | 변형된 공간에서 빠져나오는 유일한 수단 |

```text
IP-SPACE-FOLDING     변형된 공간의 안팎을 오간다
IT-NEST-ORGAN        그 기관. 쓰면 없어진다 (한 번의 탈출)
grants               MC-ESCAPE-ALTERED-SPACE  ← 기존 노드. MW-ZONE-UNKNOWN 이 demands 로 요구 중
```

## 14.13 노화를 늦추는 물질 — **세우지 않는다** (BW §6)

BW §6 의 여섯 예시 중 이것 하나만 세우지 않는다. 사유를 남긴다.

```text
어느 MW-* 도 "시간·노화" 를 압력으로 갖고 있지 않다. 압력이 없으면 §4.1 의 Trace 첫 칸이
비고, 그 상태에서 세우면 그것이 곧 BW §34 가 금지한 "좋은 것을 배치한" 형태가 된다.
세우려면 그 압력을 가진 지역이 먼저 서야 하고 — 그것은 이 문서가 아니라 WHY 의 몫이다.
```

# 15. 문명권이 만든 것 — 곡괭이 (세계에는 있는데 Master 에는 없다)

`content/world/semantic/item.ts` 에 `pickaxe` 가 실재하고 채굴 판정이 그것을 직접 묻는다.
그런데 Master 에는 이 종류의 노드가 **0건**이다. 그래프와 세계가 어긋난 유일한 자리다.

| | |
|---|---|
| WorldState | `MW-SAFE-FRONTIER` |
| 성질 (`IP-*`) | **없다.** 그리고 없는 것이 맞다 |
| 인간 가치 | 캘 수 있게 한다 |

```text
IT-MINING-PICK   채굴 용도를 지닌 도구. 평범한 돌과 같은 지역의 산물이다
IP-*             세우지 않는다 — "채굴" 은 세계압이 남긴 성질이 아니라 **종류가 가진 용도**다
                 (IS §3.3). 성질로 세우면 그 성질이 어느 지역에서 왔는지 답할 수 없다
grants           없음 — 용도는 grants 사슬이 아니라 카탈로그의 행동 선언에 산다
```

**이 노드가 여는 것**: 채굴 판정이 "든 것이 곡괭이인가" 에서 "이 몸에 채굴 용도가 지금
있는가" 로 바뀐다 (`DC-ITEM-CAPABILITY-COMES-FROM-GRANTS`). 그러면 곡괭이가 아닌
다른 도구가 생겨도 채굴 규칙은 한 줄도 바뀌지 않는다.

# 17. 상호작용의 축 — 무엇이 다채로움을 만드는가

종류를 세는 것과 **다채로워지는** 것은 다르다. 축은 셋이고 셋 다 이미 세계에 얼개가 있다.

| 축 | 갈래 | 세계에 이미 있는 것 |
|---|---|---|
| 역할 | 쓴다(소모) · 적용한다(장착) · 재료 · 지닌다 | IS §5.1 행동 유형 선언 |
| 대상 | 자신 · 고른 대상 · 대상 없음 | 고른 대상 관계는 지목 층이 세운다 |
| 시간 | 즉시 · 이름 붙은 조건으로 남음 · 사용에 시간이 걸리고 끊길 수 있음 | 조건 합성 얼개 · 행동 시간·중단 층 |

| 종류 | 역할 | 대상 | 시간 |
|---|---|---|---|
| 회귀초 (§14.1) | 쓴다 | 자신 | 시간이 걸린다 · 끊기면 아무 일도 없다 |
| 회귀 기관 (§14.2) | 쓴다 | 자신 · 고른 대상 | 즉시 |
| 갑각 (§14.3) | 적용한다 | — | 지속 |
| 독 (§14.4) | 쓴다 | **고른 대상** | 이름 붙은 조건 |
| 정화기관 (§14.5) | 적용한다 | — | 지속 |
| 감응 기관 (§14.6) | 적용한다 | — | 지속 |
| 도약근 (§14.7) | 적용한다 | — | 지속 (여는 것은 행동) |
| 환경 가죽 (§14.8) | 쓴다 · 적용한다 | 자신 | 이름 붙은 조건 |
| 재생 조직 (§14.9) | 쓴다 | 자신 | 이름 붙은 조건 |
| 축전 기관 (§14.10) | 쓴다 · 적용한다 | 자신 | 즉시 · 지속 |
| 기억을 뜬 것 (§14.11) | 지닌다 | — | 지속 |
| 둥지 기관 (§14.12) | 쓴다 | 대상 없음 | 즉시 |
| 곡괭이 (§15) | 적용한다 | — | 지속 (여는 것은 행동) |
| 광물 6종 (§13) | 재료 · 적용한다 | — | — |

**세 축이 모두 채워진다** — 특히 §14.4(고른 대상)와 §14.12(대상 없음)가 서면 IS §5.3 의
대상 정책 세 갈래가 실물로 다 있게 된다.

# 18. 어느 Cycle 이 무엇을 여는가

IS §6 의 네 Cycle 에 이 카탈로그를 얹으면 이렇게 나뉜다.

| Cycle | 이 문서에서 쓰이는 것 |
|---|---|
| 1. 아이템의 바닥 (쓴다·없어진다) | **§14.1 회귀초** · §14.9 재생 조직 · §14.10 축전 기관(소모형) · §14.4 독 — 넷이면 세 축이 다 실측된다 |
| 2. 장착 | §14.3 갑각 · §14.7 도약근 · §14.10 축전 기관(장착형) · §15 곡괭이 · 기존 광물 제작물 |
| 3. 제작 | 광물 6종 + §14.8 환경 가죽 — 재료가 결과물이 되는 첫 자리 |
| 4. 세계의 아이템 | **§14.2 · §14.5 · §14.6 · §14.9 · §14.10 · §14.12 — 기관 전부.** 몸에서 나오는 것은 몸 밖에 놓일 수 있어야 존재한다 |

**여기서 드러나는 사실 하나**: 기관 계통은 전부 Cycle 4 를 기다린다. 그러므로 Cycle 1 이
쓸 수 있는 것은 **식물·조직 쪽**이고, 그것이 §14.1 을 첫 물건으로 두는 이유다.

# 23. 미결 이음매 — 병합이 드러낸 것 (Human 판정 대기)

병합은 두 층을 이었을 뿐 **세계를 새로 정하지 않았다.** 이으면서 문서들이 서로 다른 말을
하는 자리가 셋 드러났다. 어느 것도 여기서 결정하지 않는다 — 판정 전까지 양쪽을 그대로 둔다.
그것이 `BW §34` 를 지키는 형태다: 이름을 맞추려고 원인을 지어내지 않는다.

## 23.1 지리 모델이 두 벌이다

| | 축 | 실물 |
|---|---|---|
| 시스템 층 · §12 | **대지형** — 왕관수계 분지 · 백야철빙원 · 무호흡해 … | 정본 없음 — 2층 세계 절반 주입 대기 (`content/roadmap/L2-World-Tool.md` §3). 그래프 노드 **0건** |
| 카탈로그 층 §13 · §14 | **층(Zone)** — SAFE · WILD · DANGER · DEEP · UNKNOWN · SPATIAL-SHEAR | `MW-ZONE-*` 로 그래프에 실재하고 세계 코드가 쓴다 |

대지형 문서는 층을 **한 번도 언급하지 않고**, 카탈로그는 대지형을 한 번도 언급하지 않는다.
가능한 판정은 셋이고 결과가 서로 다르다.

```text
대지형이 층을 대체한다      → §13 · §14 의 지역 칸이 전부 다시 서야 한다
대지형이 층 위에 얹힌다      → 대지형마다 어느 층인지 정하면 둘 다 산다
둘이 직교한다 (규모 vs 위험) → 자원마다 두 좌표를 다 가진다
```

## 23.2 같은 것으로 보이는 자원이 이름을 두세 벌 갖는다

아래는 **판정이 아니라 관찰**이다 — 성질 설명이 실제로 겹치는 것만 묶었고, 어느 문서도 이
대응을 명시한 적이 없다.

| 카탈로그 (§13 · §14) | 대지형 문서 | §12 초기 카탈로그 | 겹치는 성질 |
|---|---|---|---|
| 경계결정 `IT-BOUNDARY-BLADE` | 백왕의 치아 | — | 비정상적 구조를 절단한다 |
| 정박정 `IT-ANCHOR-STONE` | 정박암 | 고정암 | 변화 속에서 자기 기준을 유지한다 |
| §14.1 회귀초 · §14.2 회귀 기관 | 회귀밀 | 혈수지 | 이전의 안정된 생체 상태로 되돌린다 |
| §14.8 환경을 두른 것 | 백야수의 털 · 하늘물 · 천행토 | 기압막 | 환경 Property 를 몸에 두른다 |
| — | 태양심 | 열기억철 | 열을 오래 보존했다가 방출한다 |
| — | 숨결진주 | 숨결석 | 대기를 담아 둔다 |
| — | 무음막 | 무음결정 | 진동 전달을 끊는다 |
| — | 방향석 | 상향맥석 | 이동·낙하 방향을 바꾼다 |
| — | 탈피대지 | 탈피암 | 오래 견딘 외피가 남는다 |
| — | 맥동정 | 압력진주 | 세계압을 몸 안에 축적한다 |

지형 이름도 마찬가지다 — **글자가 같은 것은 무호흡해 하나뿐**이고, `울림석림`(§12 의 공명결정 ·
충격석)은 대지형 문서에 대응 지형이 없으며 `이름을 먹는 수해`(이름목 · 가면열매 · 기억수액)는
§12 에 대응 항목이 없다.

```text
판정이 필요한 것
    이름 한 벌을 정본으로 삼는가, 아니면 셋이 정말 서로 다른 것인가
    다르다면 무엇이 다른가 — 성질인가, 출처인가, 대가인가 (§20 P2 가 이 질문의 기준이다)
```

## 23.3 회복 계통이 같은 `MC-*` 를 두 조합으로 가리킨다

```text
§14.1 회귀초 · §14.2 회귀 기관
    IP-STATE-PRESERVING → IM-STATE-RESTORING      → MC-RESTORE-BIOLOGICAL-STATE

Design-Item-Lifecycle-Progression-R0 §18 (혈수지 계통)
    혈수지 → 정제 → 회복 Item → IM-BIOLOGICAL-RESTORATION → MC-RESTORE-BIOLOGICAL-STATE
```

§20 의 **P2**(같은 의미는 출처가 달라도 한 노드다)와 `DC-GROWTH-NO-CAPABILITY-DUPLICATION`
을 그대로 적용하면, `IM-BIOLOGICAL-RESTORATION` 은 새 조합이 아니라 **`IM-STATE-RESTORING`
의 다른 이름일 가능성이 높다.** 달라도 되는 것은 조합이 아니라 얻는 경로와 대가다.

**판정 전까지**: 새 `IM-*` 를 세우지 않는다. `MC-RESTORE-BIOLOGICAL-STATE` 를 여는 첫 칸은
§14.1 이 이미 채우고 있으므로 회복 Cycle 은 이 이음매가 닫히기 전에도 열 수 있다.

# 24. 병합 기록 — 무엇을 이었고 무엇을 손댔는가

## 24.1 병합한 것

```text
Design-Resource-Catalog-R0.md   그래프가 언급한 자원 종류의 세계 유래   → 이 문서의 §11 ~ §20
Design-Resource-System-R0.md    자원의 원천 · 획득 · 결과의 규칙        → 이 문서의 §0 ~ §10 · §21
                                (병합과 함께 파일은 사라진다. 원문 마지막 장
                                `네 문서의 최종 관계` 는 총괄 문서 Chain §3 으로 나갔다)
```

## 24.2 구 §번호 → 신 §번호

병합 전 §번호로 이 문서를 가리키는 참조가 밖에 있다 (예: 곡괭이를 `§5` 로 가리키던 것은
지금 §15 다).

| 구 Catalog | 신 | | 구 System | 신 |
|---|---|---|---|---|
| §0 한 문장 설계 | §0.1 | | §0 목적 | §0 |
| §1 전수 조사 | §11 | | §1 ~ §8 | 그대로 |
| §2 방법 | §4.1 | | §9 초기 Resource Catalog | §12 |
| §3 광물 6종 | §13 | | §10 ResourceDefinition | §9 |
| §4 생명 12종 (§4.x) | §14 (§14.x) | | §11 관찰 규칙 | §10 |
| §5 곡괭이 | §15 | | §12 완료 기준 | §21 |
| §6 자원이 아닌 것 | §16 | | 부록 | Chain §3 |
| §7 상호작용의 축 | §17 | | | |
| §8 Cycle | §18 | | | |
| §9 grants | §19 | | | |
| §10 설계 원칙 | §20 | | | |
| §11 다루지 않는 것 | §22 | | | |

문서 안의 자기 참조는 이 표대로 전부 갱신했다. `BW §*` · `IS §*` · `정책 §*` 처럼 **다른
문서를 가리키는 참조는 한 건도 건드리지 않았다.**

## 24.3 병합하면서 손댄 곳 — 전부

```text
1  머리          두 문서의 머리를 하나로 교체 (§번호 표 · 파일명 사유 · 미결 표시)
                 카탈로그의 원래 머리말(상태 · 범위 · 목적)은 §11 앞에 그대로 옮겼다
2  §번호         위 §24.2 대로 재부여 + 자기 참조 갱신
3  §22           '획득 경로' 항 개정 — 병합 전에는 범위 밖이었고 지금은 §5 · §6 이 답한다
4  §11 앞        카탈로그 층이 시작한다는 안내와 두 층이 서로를 검사하는 방법 (새로 씀)
5  §23 · §24     새로 씀 — 병합이 드러낸 이음매와 이 기록
6  부록          삭제 — `네 문서의 최종 관계`는 총괄 문서
                 `Design-Item-Chain-R0.md` §3 으로 **원문 그대로** 옮겼다.
                 사슬 전체는 사슬의 한 칸이 소유할 것이 아니다
7  §12 끝        이름이 대지형 문서와 일치하지 않는다는 대조 주의 한 줄 (새로 씀 · §23.2 로 보낸다)
8  §0.1 · §4.1   병합으로 멀어진 `아래` 두 곳에 `(§14)` 만 덧붙였다 — 문장은 그대로다
```

**그 외 본문 문장 · 표 · 코드블록은 두 원문 그대로다.** 자원 한 종류도 더하거나 빼지 않았고,
성질 · 조합 · grants 를 새로 잇지 않았다.
