# Design-CyclePlan — Cycle·Step 구현 설계도 (마스터)

> [Design-ModulePlan.md](Design-ModulePlan.md)(모듈 구조 원문)를 **진행 축**으로 분할한 설계도다.
> 모듈의 구조·순서·계약은 원문과 [modules/MODULES.md](../modules/MODULES.md)를 그대로 따르고,
> 이 문서는 **무엇을 어떤 순서로, 어떤 게임이 보일 때까지** 만드는가를 규정한다.
> Workflow 는 크게 둘이다 — **① 설계도 분할 → ② 구현** ([modules/WORKFLOW.md](../modules/WORKFLOW.md) §11).

---

## 1. 두 축 — 왜 Cycle 인가

진행은 2차원이다.

- **가로축 = 모듈 구조** (V→A 14계층, 원문 §18 순서). 어느 바퀴에서도 바뀌지 않는다.
- **세로축 = Cycle (콘텐츠 깊이).** 같은 구조를 여러 바퀴 돌며 깊어진다 — 그래서 Layer 가 아니라
  Cycle 이다. Cycle 1 이 전 구간을 얇게 관통하고, Cycle 2, 3… 이 같은 구조 위에서 깊이만 늘린다.

한 번에 복잡한 콘텐츠를 세우면 검증이 불가능해진다. 그래서 한 Cycle 안에서는 깊이를 늘리지
않고(WORKFLOW 원칙 ⑤ 얇은 관통), 깎은 깊이는 갚을 Cycle 과 함께
[유예 장부](../progress/deferred.md)에 적립한다.

## 2. Cycle 의 목표는 반드시 게임이다 — 게임 판정 3문

지금까지 단계 목표(M0~M9)는 모듈 검증의 언어였다 — "압력이 상승한다", "의도가 제출된다".
맞는 말이지만 **모호하다**. Cycle 부터 목표의 언어는 게임이다: Cycle 완주 게이트와
막(Act) 이정표는 아래 3문에 전부 "예"가 나오는 **최소 게임 장면**이어야 한다.

| # | 판정 질문 |
|---|---|
| ① **보이는가** | 브라우저에서 열어서, 코드·Lab 지식 없이 무슨 일이 벌어지는지 보이는가? |
| ② **스스로 도는가** | 관전만 해도 세계가 스스로 진행되는가 — 사건이 흐르는가? |
| ③ **다르게 만들 수 있는가** | 개입 또는 시드 변경이 결과를 바꾸는 것이 화면에서 보이는가? |

**Lab 은 게임이 아니다** — Lab 은 개발자 도구다(WORKFLOW §10-3 표면 감사와 같은 원칙).
게임 표면(GS, Game Surface)은 `app/packages/client/` 에 산다. 관전(신의 시점으로 지켜보기)도
3문을 통과하면 게임이다 — 조작은 Cycle 1 막 D 에서 들어온다.

## 3. Cycle 목록

| Cycle | 이름 | 목표 게임 (완주 게이트) — 한 문장 |
|---|---|---|
| **1** | 관통 | **《국경 협곡 — 관전과 첫 개입》**: 시드 하나가 협곡 하나를 낳고, 그 안에서 국경석 이동 → 신 약화 → 마물 남하가 저절로 벌어지며, 플레이어가 흔적·소문·계약으로 개입하면 결말이 달라진다 (원문 §21 최종 검증 장면의 축소 게임) |
| **2** | 북극성 깊이 | 착수 시 설계도 분할로 확정. 후보 게임: **《정보전》** — 같은 두 능력자, 아는 것만 다른데 승패가 뒤집힌다 (능력 문법 G5·G6 심화 + E3 정보 표면 + E5 제도 무대 + W1 다의미 병합) |
| **3+** | 폭·자동화 | 착수 시 확정. 후보 게임: **《낯선 협곡들》** — AI 가 늘린 종·지역이 다음 시드의 세계에 등장해 새 이야기를 만든다 (N 본격 · A 본격 · 콘텐츠 폭 확장) |

- Cycle 1 의 콘텐츠 예산은 원문 §21 범위가 상한이다 — 주체 8 · 의존 8종 · 공간 7자리 · 행동 12.
- Cycle 2+ 의 상세(막·Step·게임)는 **그 Cycle 착수 시** `design/cycles/cycle-N.md` 로 분할한다.
  지금 못박는 것은 목표 게임 후보뿐이다.
- 단계 0~3 에서 닫힌 32개 모듈(V·O·S·D·P·R + E0)은 **Cycle 1 충족으로 소급 인정** — 재작업 없음.
  단, 아직 게임 표면이 없다는 것이 Cycle 1 잔여 작업의 첫 이유다 (막 A 의 GS-1).

## 4. Cycle 1 의 막(Act) 구조 — 게임 이정표

Cycle 1 잔여 구간(E→Q→W→G→C→E5→X→N→A)을 다섯 막으로 나눈다. **막마다 게임 이정표가 있다** —
이정표도 게임 판정 3문을 통과해야 하며, Lab 확인으로 대신할 수 없다.
Step 별 구현 수준 상세는 [cycles/cycle-1.md](cycles/cycle-1.md).

| 막 | 구간 (Step) | 게임 이정표 — 이것이 보이면 막이 닫힌다 |
|---|---|---|
| **A. 사건이 보인다** | E1 · E2 · E3 · E4 · **GS-1 관전 화면** | 《고기 하나, 넷의 손》 — 2D 관전 화면에서 배고픈 주체들이 같은 고기 앞에 모이고, 거래·강탈·계약·원한이 토큰의 움직임과 자막으로 보인다. 시드를 바꾸면 다른 결말 |
| **B. 세계가 태어난다** | Q0~Q3 · W0~W6 · **GS-2 협곡 지도** | 《시드가 협곡을 낳는다》 — 다섯 주체의 요구가 병합되어 협곡 지도가 그려지는 과정을 리플레이로 보고, 완성된 협곡 안에서 막 A 의 사건 루프가 돈다. 같은 시드 = 같은 협곡 |
| **C. 큰 존재들이 움직인다** | G0~G6 · C0~C4 · E5 · **GS-3 연대기** | 《국경석이 옮겨지는 날》 — 국가가 국경석을 옮기고, 신의 영역이 약해지고, 마물이 마을로 내려오는 §21 사건 연쇄가 관전 화면에서 저절로 벌어진다. 반복 결핍이 전문화(성장)를 낳는 것이 연대기 카드로 보인다 |
| **D. 손이 들어온다** | X0~X4 | 《협곡을 걷는다》 — 플레이어가 3D 협곡을 걷고, 흔적을 발견하고, 퀘스트 없이 계약 하나로 개입한다. 개입한 세계와 안 한 세계의 결말 차이가 화면에 보인다 |
| **E. 함께, 그리고 확장** | N0~N3 · A0~A4 | 《둘이 선 협곡》 — 두 플레이어가 같은 사건에 개입하고, 재접속해도 세계가 이어지며, AI 가 만든 새 종 하나가 다음 시드의 협곡에 등장한다 |

막 E 가 닫히고 §21 최종 검증 장면이 게임으로 서면 **Cycle 1 완주**다. 그 다음이 Cycle 1 리뷰
(재미 4문 첫 실측, WORKFLOW §10)와 Cycle 2 설계도 분할이다.

## 5. Step 규격

- **Step = 모듈 1개** (MODULES.md 위상 순서 유지) 또는 **게임 표면 GS 1개**.
- GS 는 X 계층(X2 렌더·X4 아는 것 UI)의 조각을 앞당긴 것이다 — MODULES.md 에 없는 작업은
  존재하지 않으므로(WORKFLOW §2), 각 막 착수 시 GS 행을 MODULES.md 에 등록하는 작업을 먼저 낸다.
- 모든 Step 은 설계도에 **4절 블록**을 가진다 (서식: [modules/STEP-TEMPLATE.md](../modules/STEP-TEMPLATE.md)):
  ① 개념 → 구현 표 (타입 · 함수 시그니처 · 하위 작업) — 이 개념은 어떤 코드가 되는가
  ② 시뮬레이션 표 (입력 픽스처 → 기대 결과 → 확인 방법) — **기대값은 구현 전에 확정**
  ③ 예상 화면 (렌더러 + 스케치) — 그래프류는 그림 자체가 검증
  ④ 이번 Cycle 깊이 / 유예 (깎은 것 → deferred.md 적립)
- 구현은 Step 블록에서 작업 카드를 꺼내 8단계 사이클(WORKFLOW §5)로 돈다.
  구현이 설계도의 사실을 바꾸면 설계도를 고쳐 같은 커밋에 넣고, 어느 쪽을 고쳤는지 남긴다.

## 6. 기존 자산 매핑 — 이미 선 것

| 원문 단계 | 모듈 | Cycle 1 지위 |
|---|---|---|
| 단계 0 (M0) | V0~V4 · O0~O2 | 충족 — 검증 기반과 공리·존재론·상태 스키마 |
| 단계 1 (M1) | S0~S3 · D0~D4 | 충족 — 주체가 서고 의존과 압력이 계산된다 |
| 단계 2 (M2) | P0~P5 | 충족 — 결핍이 목적과 계획이 된다 |
| 단계 3 (M3) | R0~R6 · D5 | 충족 — 사건·흔적·지각·믿음·기억·의도의 고리가 닫힌다 |
| 단계 4 일부 | E0 | 충족 — 겹친 의도가 상황으로 묶인다 |

이들의 확인 장면은 전부 Lab 이었다 — 게임 판정 3문 기준으로는 아직 **게임이 0개**다.
그래서 Cycle 1 의 첫 막(A)이 사건 모듈과 함께 **관전 화면(GS-1)** 을 세운다.
