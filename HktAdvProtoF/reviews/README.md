# reviews/ — 구현 리뷰 인덱스

STATE.md 의 보고를 사람이 읽을 수 있게 풀어 쓴 리뷰의 목차다.

**리뷰는 단계 단위로 쓴다.** 단계(WORKFLOW §7, 원문 ModulePlan §18~19)는 기술 계층이 아니라
**수직 통합 목표(M0~M9)** — "세계가 새로 할 수 있게 되는 일 하나 + 대표 장면 + 완료 조건" — 의 단위이고,
모듈별 검증은 계약·증거(`app/packages/contracts/`)가 이미 담당하므로 리뷰는 그 위에서
"이 단계가 정말 목표에 다가갔는가" 를 묻는다. 발견한 이슈의 **원본 장부는 STATE.md 열린 이슈 표**다
(GitHub 이슈는 사람 알림용 미러).

**리뷰 작성 절차는 [WORKFLOW §10](../modules/WORKFLOW.md)** 에 규정돼 있다 — 원칙 셋(주장이 아니라
재현 · 직관 우선 · 과장 금지), 절차 다섯(재현 → 완료 조건 → MasterPlan 대비 → 북극성 대조 → 이슈업),
산출물 둘(단계 리뷰 문서 + 이 인덱스 갱신). **리뷰는 사용자가 요청할 때 진행한다**
(`/advproto-review`) — 단계가 닫히면 STATE.md TODO 에 "리뷰 대기" 항목만 남는다.

## 전체 지도 — 지금 어디까지 왔나 (2026-08-03 기준)

**전체 목표를 한 문장으로:** 퀘스트를 미리 써 두는 대신, "주체가 존재하려면 무엇이 필요한가(의존)" 에서
출발해 가능성 → 세계 요구 → 세계 실체화 → 관찰 → 행동 → 충돌 → 사건 → 성장으로 이어지는 루프가
스스로 콘텐츠를 만들어 내는 MMORPG. 북극성 둘(넨급 능력 문법 · 방대한 세계관)은 CLAUDE.md 에 명문화되어 있다.

**현재 위치:** 10단계 중 단계 0·1·2 구현. 모듈 23개, 코어 약 22,600줄, 테스트 1218개 (리뷰 환경 재실행 전원 통과).
**"누가, 무엇에 기대어, 무엇을 좇아, 어떤 순서로 낼 것인가" 까지 완성됐고, 세계는 여전히 한 발짝도
움직이지 않는다.** 계획은 아직 요청이 아니다 — 그것을 세계에 내보내는 것은 단계 3 의 R2 규칙 엔진이다.

```

                              ████    ████                 ▒▒▒▒   ▒▒▒▒                          (▒ = P3 관측·stale 이 씨앗만 심음)
[구현 단계]                    0·1 완료  2 완료   4(Q·W)     3(R)              3(R·E) 다음        5(G)
```

   선등록돼 있고, 착수 가능 목록이 R0 를 계산한다. **착수 전 조건: P3 Lab Chromium 확인**(단계 2

   P3 `stale` 기억·관측 선행이 씨앗을 심어 뒀다.
3. **W1 다중 주체 요구 병합 (단계 4)** — "다섯 주체의 요구 → 국경 협곡 하나". 가장 독창적이고 가장 어렵다.

## 총평 (단계 0·1·2 시점)

**설계 → 구현 정합성: 매우 높음.** 두 설계 문서의 규정이 장식이 아니라 관문으로 살아 있고,
구현된 범위 안에서 원문과 어긋나는 지점을 찾지 못했다 (이탈은 전부 기록된 의도적 이탈).
단계 2 의 특징은 "새로 정하지 않는다" — P1 방향은 O1 에서, P3 선행은 P0 걸림에서, P4 여덟
요소는 앞 계층에서, P5 순서는 P3/P4 에서 읽어 오고 각 대조를 테스트가 강제한다.

**진행률의 정직한 위치:** 10단계 중 3단계. MasterPlan 콘텐츠 루프 12칸 중 "주체·가능성" 2칸
(+ 관찰·해석의 씨앗). 북극성 기준으로는 — 능력 문법(①)은 부품(대가 전환·금기)과 기반층(가치관
요소 소비)이 늘었고, 다채로움(②)은 기반층(같은 결핍 앞 유형 5 × 문화 × 정보 × 재고의 갈림)이
섰다. 핵심(G5·G6·E3 의 작동 체계, E5 제도 무대)은 여전히 오지 않았다 — 계획된 순서 안이다.

**시정할 것:** 단계 0 의 판정 체계 구멍 2건은 상환 완료(V4-e·V0-c). 이번에 새로 남긴 것 —
R0 착수 전 P3 Chromium 확인(§3-1), P4 무게표 설계 판단은 R0~R2 사이(§3-2), 물리 벽 우회
장면은 공간 계층 착수 시 재검증(§3-3).
