# reviews/ — 구현 리뷰 인덱스

STATE.md 의 보고를 사람이 읽을 수 있게 풀어 쓴 리뷰의 목차다.

**리뷰는 단계 단위로 쓴다.** 단계(WORKFLOW §7, 원문 ModulePlan §18~19)는 기술 계층이 아니라
**수직 통합 목표(M0~M9)** 의 단위이고, 기획 준수의 검증은 계약·증거(`app/packages/contracts/`)가
이미 담당하므로 리뷰는 그 위에서 남은 리스크를 묻는다 — **"기획을 어겼는가"가 아니라 "기획대로
만들었는데 재미없는 것은 아닌가."** 발견한 이슈의 **원본 장부는 STATE.md 열린 이슈 표**다
(GitHub 이슈는 사람 알림용 미러).

**리뷰 작성 절차는 [WORKFLOW §10](../modules/WORKFLOW.md)** (v2, 2026-08-04 개정) — 원칙 넷(주장이
아니라 재현 · 직관 우선 · 과장 금지 · **약속 금지**), **재미 4문 실측**(㉮ 반사실 diff · ㉯ 이야기
가독성 · ㉰ 결정의 질 · ㉱ 다채로움 — 실제로 돌린 값만 싣고, 잴 수 없으면 사유를 적는다), **표면
감사**(모듈 값이 게임 안 무엇으로 새는가 — 없으면 X4 부채 장부), 절차 여섯, 산출물 둘(단계 리뷰
문서 + 이 인덱스 갱신) + **최소 재미 실험 1개 제안**. 리뷰는 사용자가 요청할 때 진행한다
(`/advproto-review`). 구형식(5문·드릴다운) 리뷰 문서는 이 개정으로 대체됐다 — 원문은 git 이력에 있다.

## 전체 지도 — 지금 어디까지 왔나 (2026-08-04 기준)

**전체 목표를 한 문장으로:** 퀘스트를 미리 써 두는 대신, "주체가 존재하려면 무엇이 필요한가(의존)" 에서
출발해 가능성 → 세계 요구 → 세계 실체화 → 관찰 → 행동 → 충돌 → 사건 → 성장으로 이어지는 루프가
스스로 콘텐츠를 만들어 내는 MMORPG. 북극성 둘(넨급 능력 문법 · 방대한 세계관)은 CLAUDE.md 에 명문화되어 있다.

**현재 위치:** 원본은 [STATE.md](../STATE.md) "지금 어디인가" 표다. 이 인덱스의 갱신 시점
(2026-08-04) 기준으로 단계 0~3 닫힘(**단계 3 리뷰 대기**), 단계 4 진행 중(E0 닫힘). 단계 0~2
리뷰의 재현 수치(테스트 1535·verify exit 0)는 그 리뷰 시점(단계 3 중간)의 값이다. 단계 3 에서
고리가 닫혔다 — 결핍 → 목적 → 계획 → 의도 → 사건 → 흔적 → 지각 → 믿음 → 기억·사이 → 다시 의도.
아직 서지 않은 것은 **둘이 서로를 알아보고 다투는 장면의 결말**(E1~E3)이다.

```
[MasterPlan 콘텐츠 루프]      주체 → 가능성 → 세계요구 → 실체화 → 관찰 → 해석 → 행동 → 충돌 → 사건 → 결과 → 성장
                              ████    ████                 ████   ████    ████   ▒▒▒▒(E0)  ████        (▒ = 자리만)
[구현 단계]                    0·1 완료  2 완료   4(Q·W)     3 완료           4(E1~E4) 진행 중          5(G)
```

## 다음 고비 — 아직 만들어지지 않은 것

1. **단계 3 리뷰(대기 중) + E1~E4 (단계 4)** — E3 충돌 해결이 **"퀘스트 없는 콘텐츠" 가 처음
   검증되는 자리**다. 단계 3 리뷰부터 재미 4문의 ㉯(사건 로그 이야기 발굴)가 처음 가능해진다 —
   그 리뷰가 이 프로젝트 재미 주장의 첫 실측이 된다.
2. **W1 다중 주체 요구 병합 (단계 4)** — "다섯 주체의 요구 → 국경 협곡 하나". 가장 독창적이고 가장
   어렵다 — 처음으로 "읽어 올 곳이 없는 것" 을 새로 정해야 하는 모듈.
3. **G5·G6 능력 문법 (단계 5)** — 북극성 ① 의 핵심. 정보 표면 4필드·강도 판정 계약 문안은 이미
   MODULES.md 에 편입돼 있다.
4. **표면 부채 장부 (X4)** — 이번 리뷰 개정으로 시작됐다: 단계 1·2 의 표면 부채(압력 게이지·열린
   길들 화면·이유 9줄·행보 읽기 등)가 각 리뷰 §4 에 쌓이고 있고, X4 착수 시 계약의 입력이 된다.

"방대하고 다채로운 세계관"(북극성 ②)의 위치: 다채로움은 W1 병합·C 계층, 규모는 A 계층(단계 9)이 담당한다.
최초 프로토타입 범위(원문 §21)는 의도적으로 작아서 **"방대함" 은 단계 9 이전에는 검증 자체가 계획에 없다.**

## 총평 (단계 0·1·2 + 단계 3 중간 시점)

**설계 → 구현 정합성: 매우 높음** — 구현된 범위에서 원문과 어긋나는 지점을 찾지 못했다(이탈은
전부 기록된 의도적 이탈). 그래서 리뷰의 중심을 기획 준수에서 **재미 실측**으로 옮겼다(§10 v2).
그 첫 실측의 요약: 개입 하나가 세계 전체에 닿되 캐릭터의 서열은 지우지 않고(단계 1 ㉮), 정보·재고
하나가 선택의 구조를 바꾸며(단계 2 ㉮), 압력 1위가 항상 이기지는 않는다(단계 2 ㉰). **재미의 뼈대
(선택이 결과를 바꾸고, 정답이 하나가 아니다)는 값으로 서 있다** — 다만 그것이 "이야기" 가 되는지
(㉯)는 사건 로그가 도는 단계 3 리뷰부터만 잴 수 있고, 게임 안 표면은 아직 0 이다(표면 부채 장부).
북극성 핵심(G5·G6·W1·E5)은 전부 미착수 단계에 있다 — 지금까지 지은 것은 그 핵심이 설 땅이다.
