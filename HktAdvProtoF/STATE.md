D4 의 스냅샷은 필요할 때마다 새로 조립되는 한 컷이었고 지나간 값은 아무 데도 남지 않았다 — R0 은 그것을 담는다. 새로 짓는 것은 최소다: 조립 관문은 O2 `assembleWorld`, 무엇이 달라졌는지는 O2 `worldDiff`, 시간은 V1 틱, 해시는 V1 `stateHash`. **원장은 시간이 아니라 변화를 센다** — 한 자리도 다르지 않은 세계는 칸을 늘리지 않는다(`empty-commit`). 칸마다 앞 칸의 해시를 품으므로 **지나간 칸의 값 하나를 손대면 그 뒤가 전부 어긋나고**(`broken-chain`), 손댄 원장 위에는 새 칸을 쌓지도 못한다. 근거의 사건 자리(`CommitCause.eventIds`)는 **비운 채로 연다** — 채우는 것은 R1 이고, 지금은 사람이 읽는 이름만 요구한다(`causeless-commit`). O2 관문이 막은 값이 하나라도 섞이면 커밋 전체가 물린다 — 세계는 반쪽으로 담기지 않는다. 되돌아가는 틱·같은 틱·두 번째 genesis 도 각자의 사유로 걸리고, 물린 커밋은 던지지 않고 원장을 그대로 둔다. 같은 재료면 분해했다 다시 세워도 같은 지문이다(O2 왕복 성질을 실제로 쓴다) |

구현 루트는 [app/](app/) — npm workspaces 모노레포, Node ≥22.18 네이티브 TS 타입 스트리핑으로
빌드 없이 `.ts` 를 실행한다 (런타임 의존성 0개, `typescript`·`@types/node` 는 타입 검사 전용).

모든 작업은 [modules/WORKFLOW.md](modules/WORKFLOW.md)의 8단계 사이클을 따른다:
작업 카드 없이 착수 금지, 커밋 1개 = 작업 1개, 완료 판정은 증거 파일로만.
실행 방아쇠: 작업 한 바퀴는 `/advproto-step`, 단계 리뷰는 `/advproto-review` (규정 원본은 WORKFLOW).

  빛과 흔적으로 알고, **장막벌레는 냄새로만 다섯을 맡으며**(빛도 소리도 없다 — 사냥꾼이 보는
  다섯과 벌레가 맡는 다섯은 다른 다섯이다), **상단과 국가는 보고만 받는데 그 보고가 문턱에 못
  미쳐 아무것도 모르고**, **어머니신은 의념을 읽는데 이 겨울에 의념 잔향이 하나도 나지 않아
  역시 모른다.** 그리고 감지한 자에게도 **무엇이 일어났는지는 실리지 않는다** — 지각은 통로·세기·
  자리·애매함까지이고 어느 자리가 움직였는지는 R4 가 짐작할 몫이다.
- **상태 원소**: `Percept` — **O1 12타입에 없고, 없는 것이 옳다.** O1 은 세계에 적히는 것을 세고,

  R4 `BeliefGraph` 다. Percept 는 그 사이의 **통과물**이므로 세계 원소로 세우지 않는다.
- **시각화**: diff (같은 현상을 놓고 주체별 감지 비교 — MODULES.md R3 행)

②-장르에도 걸린다: 조직·국가가 보고로만 아는 탓에 늘 늦는다는 것이 제도 무대의 전제다.
