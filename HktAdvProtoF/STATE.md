- 목적: 같은 자리에 **둘 이상**이 걸리면 상황이 서고, 그 안의 쌍마다 **서로를 알아보는가**가 갈린다.
- 입력: `SituationStake[]` · `Memory`(R5) · `WorldState`(O2)
- 출력: `Situation` · `SituationPair`(겨눔 3단계 `mutual|one-sided|blind` × 앎 4단계) · `Solitude`(사실)
- 검증 장면: 넷이 04 를 겨누는데 04 는 아무도 겨누지 않는다 — **서로 알아본 다툼은 0** 이고,
  겨누는 자들 중 04 가 아는 자와 모르는 자가 갈린다(매복).
- 상태 원소: `Situation`, `SituationPair`
- 시각화: 그래프(**주체↔주체 간선** — D5 가 긋지 않은 선)

#### [E0-c] 상황장·감사 — 이기는 자를 적으면 걸린다

- 목적: 상황들을 담고 감사가 **위반과 사실**을 가른다.
- 입력: `Situation[]` · `SituationStake[]`
- 출력: `SituationField` · `SituationAudit` · `SituationGraph`(주체↔주체)
- 검증 장면: 조건을 갖췄는데 상황장에 없는 자리는 `missing-situation` 으로 걸리고,
  혼자 걸린 자리(`Solitude`)와 아무 상황에도 끼지 않은 주체는 **위반이 아니라 사실**로 남는다.
  이기는 자를 적은 상황은 `outcome-declared` 로 걸린다 — 결과 확정은 E3 다.
- 상태 원소: `SituationField`, `Solitude`
- 시각화: 그래프 + 표

#### [E0-d] 검증 3종 + Lab 눈검증

- 목적: E0 를 시나리오 3종과 Lab 화면 7요소로 눈에 세운다.
- 입력: R6 장면(넷의 의도) + D5 장면(다툼 5)
- 출력: `e0-recognized-contest` · `e0-groundless-situation-rejected` · `e0-boundary` · `/lab/e0` ·
  `evidence/E0.json`
- 검증 장면: 위 셋 + 결정성(같은 재료 100회 → 같은 해시)
- 상태 원소: 없음 (소비만)
- 시각화: 그래프(상황 클러스터 맵) + 표

E0 가 갚는 유예: 여럿의 의도를 묶는 눈 · 다대다 겨눔 → [progress/deferred.md](progress/deferred.md).
**같은 틱·같은 자리를 다투는 사건 판정은 갚지 않는다** — 상황을 세우는 것까지가 E0 이고 결과를
확정하는 것은 E3 다 (D5 가 "이기는 자를 정하지 않는다" 로 세운 못을 E0 도 그대로 진다).

## 단계 게이트

**단계 0·1·2 게이트는 닫혔다** — 각 단계 progress 문서의 §단계 게이트 를 본다.

**단계 3 (M3 충돌하는 주체) 닫힘.** 대표 장면("두 인간이 음식 하나를 원한다")은 `/lab/d5` 에서
값으로 섰다 — 재고 10·6·4 에서는 다툼이 아니던 것이 **재고 2 에서 다툼으로 선다**. 여덟 모듈이
쌓아 올린 것은 한 문장씩이다: R0 이 세운 것은 그 장면이 적힐 **자리**(세계의 열), R1 이 세운 것은
그 자리를 바꾸는 **유일한 통로**(사건), R2 가 세운 것은 그 통로가 **밖에서 보이는 표면**(흔적),
R3 이 세운 것은 **그 표면을 누가 읽는가**, R4 가 세운 것은 **그것을 무엇으로 읽는가**,
R5 가 세운 것은 **그 읽음이 누구를 향하는가**, R6 가 세운 것은 **그 향함이 어떻게 손이 되는가**다 —
그리고 그 손이 다시 사건과 흔적을 내면서 **고리가 닫힌다**:
결핍 → 목적 → 계획 → 의도 → 사건 → 흔적 → 지각 → 믿음 → 기억·사이 → **다시 의도**.
아직 서지 않은 것은 **둘이 서로를 알아보고 다투는 장면**이다 — 상황으로 묶는 것은 E0,
결과를 확정하는 것은 E3 다. 전문은 [progress/stage-3.md](progress/stage-3.md) §단계 게이트.

**E0 착수 전 게이트: 비어 있다.**

**단계 리뷰 운용** (WORKFLOW §10): 리뷰는 **사용자가 요청할 때만** 진행한다 (`/advproto-review`).
단계를 닫는 커밋은 TODO 에 "단계 N 리뷰 대기" 한 줄을 남긴다 — 자동으로 리뷰를 쓰지 않는다.
단계 0·1·2 리뷰는 완료 ([reviews/](reviews/README.md)).
