# rule_0007 — 골격 결합 (Skeletal bonds) : 분자가 *형상*을 갖고, 고분자가 *사슬*로 자란다

> **상태: 설계만 완료(구현 전·예정).** 이 문서는 다음에 구현할 규칙의 *설계*다. 코드(`rule_0007.js`)·
> 검증(`verify_0007.js`)은 아직 없다. 구현 착수 시 이 설계를 기준으로 한다.

## 무엇을 푸는가 — "질점 융합"의 한계

현재 공유 결합은 엔진 `reconcileMerges` 가 결합한 원자들을 **하나의 질량중심 질점(point mass)으로 융합**한다.
`parts` 에 구성 원자 *기록*은 남지만 **공간적 골격(어느 원자가 어디에 붙었나)이 없다** — 그냥 뭉친 점이다. 그래서:

- **분자 형상이 없다** — 물의 굽은 각도·메탄의 사면체가 안 나온다(극성을 *기하의 함수*로 계산하나 그 기하를 시나리오가 seed 해야 함 — rule_0005 의 열린 격차).
- **고분자가 없다** — 탄소(결합가 4)는 `freeValence` 로 계속 결합해 *자라긴* 하나, 사슬이 아니라 **무정형 잡종 질점**으로 누적된다(rule_0004 수프의 C₂H₃ClMgO₄ 류).
- **분자가 회전 못 한다** — 강체 점질량이라 방향 의존 EM 을 정렬 못 함 → 분자 액체·상태(④)가 막힘(rule_0005 한계).

rule_0007 은 공유 결합의 *실현*을 바꾼다: **융합(point-mass) → 지속 링크(persistent bond).** 결합한 원자는
**distinct 원소로 남고**, 결합은 *길이를 유지하는 힘*으로 붙잡는다. 분자는 **distinct 원자들이 결합으로 묶인
골격(skeleton)** 이 된다 — 형상·회전·사슬이 *공짜로* 따라온다.

> 금속(rule_0006)이 이미 길을 보였다: 금속은 융합 안 하고 distinct 원자가 전자바다로 *격자*를 이룬다.
> rule_0007 은 그 "distinct + 묶는 힘" 을 **공유 결합**으로 일반화한다(전자바다 대신 *방향성 결합 링크*).

## 핵심 전환 — 위상(topology)을 기록하고, 융합하지 않는다

### 결합 위상
- 원자에 **안정 id** 를 준다(생성 시 1회). 결합은 id 쌍으로 기록 → 원소 추가/삭제에도 안전.
- `world.bonds = [{a, b, order}]`(id 참조) 또는 각 원자 `e.bonds`(인접 리스트). 매 틱 살아남는다.
- **결합 형성**: rule_0002/0004 의 결합 게이트(접촉+접근+부드러움+잔여 손)는 그대로. 단 `pendingMerges`(융합)
  대신 **`pendingBonds`(링크)** 를 표시 → 엔진이 위상에 기록하고 **양쪽 `freeValence` 만 차감**(융합 X).

### 엔진 변경 (원칙적 확장)
- `reconcileMerges`(융합) → **`reconcileBonds`**(위상 기록 + 원자가 차감, 원자는 distinct 유지).
  - *위상 부기*는 보편 역학이라 엔진의 몫이다 — 융합도 엔진이 소유했듯(질량 합·운동량 보존). 규칙은 *결합력*만 더한다.
- 이온(`reconcileTransfers`)·금속(rule_0006 격자)은 그대로 — 이미 융합 안 함.
- **마이그레이션**: "분자 = 융합 질점(parts)" → "분자 = 결합으로 연결된 원자들의 *연결 성분*". 조성·질량·전하는
  연결 성분을 합산해 *측정*(저장이 아니라 그래프 순회). 보존(Σm·Σq·Σmv)은 그대로 — 원자가 안 사라지니 자동.

## 골격 힘 (rule_0007 의 본체 — `apply`)

결합된 원자 쌍·결합 둘레에 작용하는 힘. 모두 중심·상대량 → **운동량 보존**.

### ① 결합 길이 힘 (Morse) — 골격을 붙잡는다
평형 결합 길이 `L = bondK·(√mᵢ+√mⱼ)`(공유 반경, 기존 척도). 차수 높을수록 짧고 깊다.
```
U(r) = D·(1 − e^(−α(r−L)))²        →  멀면 인력(결합 유지), 가까우면 반발(코어). 중심력.
  D = 결합 깊이 ∝ order·√(원자가곱)   (Z 에서 창발 — 이중결합이 더 강·짧음)
```
> **Morse 를 쓰는 이유**: 충분히 늘이면(변곡점 너머) 인력이 *약해져 끊긴다* → **가역 분해**(결합 깨짐)가
> 같은 힘에서 창발(후속 rule 전가했던 항목을 골격이 흡수). Hooke(영구 스프링)는 못 끊어 부적합.

### ② 결합각 힘 (VSEPR) — *형상*을 만든다
한 원자의 결합들(과 고립 전자쌍)이 서로 *반발* → 각을 최대화 → 형상 창발(2결합=굽음·4결합=사면체·linear 등).
- 1차 설계: 한 원자 i 의 두 이웃 j,k 사이에 **각 반발력**(전자쌍 반발 대용) — j,k 를 벌려 평형각으로.
- 부분적으로는 **이미 창발**한다: 결합 후 distinct 가 된 이웃 원자들이 rule_0003 EM(부분전하·Born)으로 서로
  반발 → 자연히 벌어짐. 단 *고립 전자쌍*(물의 104.5° 의 진짜 원인)은 아직 모델에 없음 → 명시적 VSEPR 항으로
  보완(고립쌍 수 = `valenceElectrons − 결합 사용분`, Z 에서 창발). **이게 형상 창발의 핵심.**

### ③ 결합 소산 — 진동을 식혀 형상이 정착
결합 형성은 KE 를 방출한다(원자가 결합 길이로 snap). 감쇠 없으면 골격이 영원히 진동한다. 결합을 따라
*상대운동만* 소산(metal `kSink` 와 같은 처방) → 골격이 식어 형상으로 정착. 운동량 보존, 에너지만 냉각(결합열).

## 보존되는 것 / 변하는 것

- **운동량**: 길이·각·소산 모두 중심·상대량 → `ΔΣmv=0`.
- **에너지**: KE + 결합 PE(Morse) + 소산(결합열). 닫힌 장부(기존 `bondEnergy` 개념 계승).
- **질량·전하**: 원자가 안 사라지니 자동 보존(융합 합산 불필요 — 연결 성분 순회로 *측정*).
- **개체 수**: 공유 결합이 더는 개수를 줄이지 않는다(distinct 유지) — 분자는 *그래프*로 식별.

## 창발 — 형상·고분자·회전·완전한 극성

- **분자 형상**: 결합각 힘에서 물의 굽음·메탄 사면체·CO₂ 일직선이 *창발*(seed 아님). → rule_0005 "형상 seed" 격차 해소.
- **고분자(사슬)**: 탄소가 결합가 한도로 이웃과 *링크*를 이어 -C-C-C- 가 **distinct 원자 골격 사슬**로 성장.
  무정형 질점 블롭이 아니라 *형상 있는 큰 분자*. (반복 단위·선택적 성장의 통제는 §열린 질문.)
- **분자 회전**: 유연 골격(distinct 원자들)이 *스스로 텀블링* — 강체 각운동 없이 회전 창발 → **방향 의존 EM 정렬
  가능** → 분자 액체·상태(④ 고체/액체/기체)가 비로소 분자 차원에서 창발(rule_0005 한계 해소).
- **완전한 극성**: 부분전하(rule_0005)가 *살아있는 동적 기하* 위에 놓여 극성이 frozen 아닌 진짜 기하에서 창발.

## 기존 규칙 연동 / 마이그레이션

- **rule_0002 / 0004**: 결합 *결정*(언제·어떤 종류)은 그대로. 공유 시 `pendingMerges` → **`pendingBonds`** 로만 바꿈.
- **엔진**: `reconcileMerges` → `reconcileBonds`(위상 기록·원자가 차감·융합 X). 보편 위상 부기 = 엔진 몫(원칙적 확장).
- **rule_0003 (EM)**: **직접 결합된 쌍은 EM 에서 제외**(상호작용은 결합이 담당) — 비결합(분자 간) EM(반데르발스)은
  유지. 결합 이웃의 *각 반발*은 EM 으로도 일부 창발(②).
- **rule_0005 (부분전하·극성)**: "parts(frozen)" → "결합 이웃(live)" 로 읽어 부분전하·극성을 *동적 기하*에서 계산.
  ensureCharges 도 그래프 기반으로.
- **rule_0006 (금속)**: 거의 무영향 — 금속은 이미 distinct 격자(전자바다). 골격은 *공유* 결합 전용.

## 열린 설계 질문 (구현 전 결정)

1. **각도/형상 모델**: 명시적 VSEPR 각 힘 vs EM 이웃 반발만으로? 고립 전자쌍을 어디까지 모델링?
2. **고분자 성장 통제**: 무차별 누적(수프 블롭) 방지 — 결합 게이트·포화·입체 장애로 사슬을 어떻게 통제?
3. **결합 끊김(Morse)**: 분해 임계(늘어남)·세부 균형 — 가역 분해를 어디까지 이번 규칙에 넣나(별 규칙 전가?).
4. **소산 vs 보존**: 결합 진동 소산 세기 — 너무 세면 즉시 굳고, 약하면 안 정착. dt=1 안정 범위.
5. **엔진 잠금**: `reconcileBonds` 는 엔진 변경 — "엔진 author 안 함" 원칙과의 정합(위상 부기는 보편이라 허용?).
6. **마이그레이션 회귀**: 기존 verify(H₂O 조성=parts) 들을 "연결 성분 조성" 으로 재표현 — 회귀 보존 전략.

## 검증 계획 (구현 시 단언할 것 — 개요)

- **위상**: 공유 결합 후 원자가 distinct 로 남고(개수 유지) 결합 위상에 기록·`freeValence` 차감·`Σm·Σq·Σmv` 보존.
- **길이**: 결합 쌍이 평형 길이 `L` 부근에서 진동·정착(소산), 늘이면 Morse 로 끊김(분해).
- **형상**: 물(2결합+고립쌍)이 *굽은 각*, 메탄(4결합)이 *사면체각*, CO₂ 가 *일직선* 으로 창발(seed 아님).
- **고분자**: 탄소들이 사슬 골격으로 성장(연결 성분 길이↑), 무정형 블롭 아님.
- **회전·극성**: 유연 골격이 텀블링, 극성이 동적 기하에서 창발. **분자 응결(액체)** 이 회전 정렬로 가능해짐.
- **운동량 보존·결정론·하위호환**(금속·이온 무영향).
