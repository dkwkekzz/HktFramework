# rule_0007 — 전자구름 배제 부피 (Pauli exclusion / excluded volume)

> 모든 원자에 *부피*를 준다. 전자구름이 겹치면 밀어내 — **전하 없이도 서로 부딪치고 튕긴다.**
> "산발하고 튕기는" 동적 세계의 기반: 물질이 비로소 서로를 통과하지 않는다.

## 무엇을 푸는가 — "중성은 통과한다"

지금까지 *밀어내는 힘(단단함·정상력)*은 [rule_0003](../rule_0003/rule_0003.md) 전자기력의 **Born 반발**뿐이었고, 그건 *전하 사이트*(이온 순전하·분자 부분전하)에서만 켜졌다. 그래서:

- **중성 홀원자는 서로 통과한다** — 배제 부피가 없어 충돌이 없다. 그냥 등속으로 스쳐 지나간다.
- 전하 없는 세계(뷰어 기본 세계 등)는 *아무 일도 안 일어나는 듯* 정적으로 보인다 — 힘이 안 보이니 관성 드리프트뿐.

실세계는 다르다. 중성 원자도 가까워지면 **전자구름이 겹쳐 파울리 배타 원리로 강하게 밀어낸다.** 이 단거리 반발이 물질에 *부피*를 주고, 원자를 서로 *부딪치게* 한다. rule_0007 은 그 배제 부피를 **모든 원자**에 부여한다 — 전하와 무관하게, *전자가 있으면* 충돌한다.

> Born(rule_0003)과의 분담: Born 은 *전하곱*에 묶인 단거리 반발(이온·부분전하의 단단함). rule_0007 은 *전하와 무관한* 전자구름 겹침(모든 원자의 단단함). 둘은 출처가 달라 이중계산이 아니다 — 중성 원자엔 Born 이 0 이고 rule_0007 만 작동, 하전 사이트엔 둘 다 단단함을 더한다.

## 상태 (크기는 전자 수에서 온다)

새 상태 없음 — 전자구름 반경 σ 를 *측정*한다(저장 아님). 크기는 **전자 수**에서 창발한다:

- **Z(원자번호=중성 전자 수) 있음**: 전자가 채운 *껍질 수*가 클수록 큰 구름. `σ = evSigma0 + evPerShell·shellState(Z).period`.
  전하도 읽는다: `− evChargeShrink·q` → **양이온(전자 잃음)은 작고, 음이온(전자 얻음)은 크다**(이온 반경 창발).
- **Z 없음·`r` 있음**: 시각/접촉 반경의 일부를 코어로 — `σ = evRfrac·r`(구형 원소·분자 합성체. 하위 호환).
- **둘 다 없음**: 기본 코어 `evSigma0`.

> 전자가 더 많은 껍질을 채울수록(주기 깊을수록) 원자가 크다는 것은 rule_0004 의 껍질 모형(`shellState`)에서 그대로 빌려온다 — "전자가 껍질을 채운다"는 법칙은 한 곳(rule_0004)에만 산다.

## 법칙 (`apply` — 규칙이 누적하는 힘)

힘이므로 엔진의 `a=F/m` 위에서 누적만 한다(상태 변경 0). 원소 `i`·`j≠i` 의 중심거리 `r`(토러스 최근접)·두 구름 합 `σ = σᵢ+σⱼ` 로:

```
겹칠 때만(r < σ):  F = kPauli·(σ − r)        (단방향 Hooke, 항상 밂 = −r̂ 방향)
안 겹치면(r ≥ σ):  F = 0                       (단거리 — 원거리 거동 무간섭)
```

`r < evRMin` 클램프(완전 겹침 시 방향 안정). 기본값 `kPauli 0.6`, `evSigma0 1.0`, `evPerShell 1.4`, `evChargeShrink 0.3`, `evRfrac 0.6`, `evRMin 0.3`.

## 보존되는 것 / 변하는 것

- **운동량 보존**: 중심 반발(작용-반작용) → `ΔΣp = 0`(verify 다체 가스에서 1e-6 이내).
- **에너지(탄성·보존력)**: 속도에 무관한 중심 반발 → 충돌 후 운동에너지를 *유지*한다(소산 없음). 그래서 **튕김이 사그라들지 않는다** — rule_0003 마찰의 감쇠와 대비되는, "정적"의 반대.
- **전하·전자**: 안 바꾼다. Z·q 를 *읽어* 크기만 측정.

## 창발 — 충돌·압력·기체

- **충돌(튕김)**: 마주 오는 중성 원자가 통과하지 않고 되튕긴다 — 전하 0 이라 EM 은 안 보이고 오직 배제 부피의 일.
- **전자 수 = 크기**: Z 큰 원자(껍질 많음)는 큰 구름 → *더 먼 거리에서* 부딪친다. 같은 Z 라도 음이온이 양이온보다 큰 구름.
- **다체 가스**: 여러 원자가 박스를 날아다니며 서로 튕겨 섞인다 — 압력·확산처럼 보이는 거동의 기반.
- **결합과의 공존**: 결합(rule_0002/0004)은 *사건*이라 게이트를 만족하면 엔진이 병합한다 — 배제 부피 힘과 무관하게. 부드럽게 만나면 붙고(결합), 세게 부딪치면 튕긴다(배제 부피). 코어 σ 를 결합 길이보다 작게 둬 결합 거리에 닿을 수는 있게 했다.

## 검증 (verify_0007.js)

엔진+규칙(**rule_0001 관성 + rule_0007 배제만**)으로 굴려 단언한다 — EM·결합을 빼 *배제 부피 단독* 거동만 본다. **8개 단언**:

1. **결정론** — 비트 동일.
2. **정면 충돌(중성)** — 마주 오던 중성 원자가 속도 반전·통과 안 함(좌우 안 뒤바뀜). 전하 0 → EM 안 보임 → 순수 배제 부피.
3. **운동량 보존** — 대칭 충돌의 ΣΣp ≈ 0.
4. **탄성(소산 없음)** — 충돌 후 운동에너지 유지(KE 1.44→1.44). 튕김이 지속.
5. **단거리** — 멀리 떨어진 둘은 힘 0(위치 불변).
6. **전자 수→크기** — Z 큰 원자가 더 먼 거리에서 튕긴다(최소접근 Z2=3.74 < Z18=9.30).
7. **이온 반경** — 음이온이 양이온보다 큰 구름(최소접근 양이온<음이온).
8. **다체 가스** — 30체 충돌에서 발산 없음(NaN 0)·운동량 보존.

## 상태

- ✅ 설계·구현·시나리오·검증 완료. verify_0007 **8개 단언 전부 통과**. 합성(전 규칙) 안정 확인: 중성 기본 세계가 충돌·산란, 화학 수프에서 결합·충돌 공존(발산 없음).
- 해소한 격차: **중성 물질이 서로 통과**(충돌 없음) → 모든 원자에 배제 부피 부여로 *서로 부딪침*.
- 후속(전가):
  - **rule_0008 골격 결합** — 공유 결합을 질점 융합→지속 링크로. 분자가 distinct 원자가 되면 배제 부피가 *원자별*로 작동해 분자 형상·충돌이 더 정교해진다.
  - **반발 세부**: 현재 단방향 Hooke(코어). 더 가파른 멱·지수 코어로 단단함 정밀화는 후속.
