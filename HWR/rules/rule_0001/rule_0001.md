# rule_0001 — 충격량과 질량

> 첫 규칙. 세계에 *원소*가 존재하고, 그 원소는 **관성**을 가지며, 이에 **질량**을 갖는다.
>
> **아키텍처(중요)**: 관성(위치 적분)·뉴턴 2법칙(`a=F/m`)·시간(tick)·토러스 랩은 **세계 로직 엔진([`engine.js`](../../engine.js))이 고정으로 소유**한다. 규칙은 원소에 작용하는 *힘만 누적*한다(`e.fx += …`) — 규칙이 늘어도 엔진은 불변, 힘만 누적된다. 따라서 이 규칙(rule_0001)의 몫은 **외부 충격량을 힘으로 전달하는 통로**다. "관성·질량"은 엔진이 보장하고, rule_0001 은 *같은 충격량에 질량이 다르게 반응함*(`Δv=J/m`)을 통해 질량을 거동으로 드러낸다.

## 무엇을 정의하는가

세계는 원소들로 채워진다. 각 원소는 위치 `(x, y)`, 속도 `(vx, vy)`, 그리고 **질량 `m > 0`** 을 갖는다. 이 규칙은 두 가지를 정한다.

1. **관성 (뉴턴 1법칙)** — 외부에서 힘이 작용하지 않으면 원소의 속도는 **변하지 않는다**. 즉 위치만 속도에 따라 적분된다. 정지한 것은 정지해 있고, 움직이는 것은 같은 속도로 계속 움직인다.
2. **질량 = 관성의 척도** — 외부 **충격량(impulse)** `J = (Jx, Jy)` 가 원소에 가해지면 속도가 `Δv = J / m` 만큼 변한다. *같은* 충격량이라도 질량이 클수록 속도 변화는 작다 — 무거운 것은 움직이기 더 어렵다. 질량이 비로소 *거동으로* 드러난다.

## 상태 (원소가 갖는 양)

| 양 | 의미 |
|---|---|
| `x, y` | 위치 |
| `vx, vy` | 속도 |
| `m` | 질량 (`m > 0`). 관성의 크기 — 운동량·운동에너지의 계수이자 충격량 응답의 분모. |
| `r, hue` | 시각화 표시값(반경·색). *창발 아님* — 뷰어가 질량을 보기 쉽게 한 표시일 뿐. |

세계: `{ width, height, tick, elements: [...], impulses: [...] }`. `impulses` 는 외부에서 예약된 충격량 `{tick, idx, jx, jy}` 목록(사용자 입력·시나리오 같은 *외부* 작용의 통로 — 원소 타입이 아님).

## 법칙 (`apply` — 규칙이 기여하는 힘)

규칙은 **힘만 누적**한다. 적분·관성·시간은 엔진([`engine.js`](../../engine.js))의 몫이다.

- **외부 충격량 → 힘**: 이번 `tick` 에 이 원소(`idx===i`)로 예약된 충격량 `J` 를 힘 `J/dt` 로 누적(`e.fx += jx/dt`). 엔진의 적분(`v += (F/m)·dt`)에서 `Δv = (J/dt)/m·dt = J/m` — `dt` 무관하게 정확히 `Δv = J/m`.

엔진이 보장하는 부분(규칙 밖):

- **관성 적분** — `x += vx·dt`, `y += vy·dt`. 힘이 없으면 속도 불변(등속). 토러스 랩(`mod width/height`) — 좌표 동일시일 뿐 힘이 아니므로 속도·운동량 불변, 뷰어에서 영원히 굴러간다.
- **질량 = 관성의 척도** — `a = F/m`. 같은 힘이라도 무거우면 덜 변한다.

`dt` 기본 1.

## 보존되는 것 / 변하는 것

- **보존**: 자유 운동(충격량 없음)에서 **총 운동량 `p = Σ m·v` 불변**. 충격량이 들어오면 정확히 `ΣJ` 만큼만 변한다 — **닫힌 장부** `ΔΣp = ΣJ`.
- **변하는 것**: 위치(항상). 속도(충격량이 있을 때만).
- **불변량 도출**: 운동량 `p = m·v`, 운동에너지 `KE = ½ m v²` 는 질량으로부터 정의된다.

## 창발 / author 안 함

- 코드는 *원소와 일반 법칙*만 안다 — 특정 타입(검·몬스터…) 분기 0.
- 질량은 박힌 라벨이 아니라 **거동의 원인**이다: 같은 충격량에 다르게 반응하는 것으로 검증된다.

## 검증 (verify_0001.js)

엔진(`engine.js`)+규칙을 `stepWorld` 로 굴려(뷰어와 동일) 단언한다.

1. **결정론** — 같은 입력 2회 → 비트 동일.
2. **관성** — 충격량 없으면 100틱 후에도 모든 속도 불변, 총 운동량 불변.
3. **갈릴레이** — 같은 속도·다른 질량 → 같은 변위(자유 운동은 질량 무관).
4. **질량 = 척도** — 같은 충격량 `J` → `Δv = J/m`, 두 원소의 `m·Δv` 가 동일(운동량 변화는 질량 무관·속도 변화는 역비).
5. **장부 닫힘** — 충격량 후 `ΔΣp = ΣJ` (1e-9 이내).
6. **시나리오** — `tick 5` 동일 충격량 후 가벼운 원소가 더 빠르다(`vx = J/m` 정확).
