# rule_0001 — 관성 (질량 = 관성의 척도)

> 첫 규칙. 세계에 *원소*가 존재하고, 그 원소는 **관성**을 갖는다 — 운동 상태를 유지하려 변화에 *저항*하며, 그 저항의 크기가 **질량**이다.

## 무엇을 정의하는가

각 원소는 위치 `(x, y)`, 속도 `(vx, vy)`, **질량 `m > 0`** 을 갖는다. **관성과 질량은 분리되지 않는 하나의 법칙**이다.

- **관성 = 변화에 대한 저항.** 원소는 속도를 유지하려 한다.
- **질량 = 그 저항의 크기.** 외부에서 힘/변형 `F` 가 들어오면 변화는 `a = F/m` — 질량이 클수록 같은 힘에 **덜 변한다**(저항이 크다).
- 힘이 없으면 변화 0 → **등속**. 이는 별도 법칙이 아니라 저항의 극한(들어온 힘이 0).

## 아키텍처 — 누가 무엇을

- **저항·적분·시간 = 엔진([`engine.js`](../../engine.js))**: `v += (F/m)·dt`(질량에 반비례하는 저항) · `x += v·dt`(유지되는 운동) · `tick` · 토러스 랩을 모든 원소에 *항상* 실현한다.
- **외부 힘 입구 = rule_0001**: 세계로 들어오는 외부 힘/변형(`world.impulses`)을 힘 누적기에 더한다. 그러면 엔진의 `a=F/m` 가 질량으로 저항한다(무거울수록 덜 변함). **충격량은 '입력'일 뿐** — 사용자가 밀거나(상호작용) 시나리오가 예약한 외부 작용이며, 원소 *타입*이 아니다(author 안 함).

## 상태 (원소가 갖는 양)

| 양 | 의미 |
|---|---|
| `x, y` | 위치 |
| `vx, vy` | 속도 |
| `m` | 질량(`m > 0`) — 관성의 크기. 변화 저항의 분모(`a=F/m`)이자 운동량·운동에너지의 계수. |
| `r, hue` | 시각화 표시값(반경·색). *창발 아님* — 질량을 보기 쉽게 한 표시일 뿐. |

세계: `{ width, height, tick, elements: [...], impulses: [...] }`. `impulses` 는 외부에서 예약된 힘 `{tick, idx, jx, jy}` 목록(사용자 입력·시나리오 같은 *외부* 작용의 통로 — 원소 타입이 아님).

## 법칙 (`apply` — 규칙이 기여하는 힘)

규칙은 **힘만 누적**한다. 적분·관성·저항(`a=F/m`)·시간은 엔진의 몫이다.

- 이번 `tick` 에 이 원소(`idx===i`)로 예약된 외부 힘(충격량 `J`)을 `F = J/dt` 로 힘 누적기에 더한다.
- 엔진 적분에서 `Δv = (J/dt)/m·dt = J/m` — 질량이 클수록 `Δv` 가 작다(= 저항). `dt` 무관하게 정확.
- 외부 힘이 없으면 기여 0 → 등속(엔진 적분).

`dt` 기본 1.

## 보존되는 것 / 변하는 것

- **보존**: 외부 힘이 없으면 **총 운동량 `p = Σ m·v` 불변**. 외부 힘 `J` 가 들어오면 정확히 `ΣJ` 만큼만 변한다 — **닫힌 장부** `ΔΣp = ΣJ`.
- **변하는 것**: 위치(항상). 속도(외부 힘이 있을 때만, `Δv = J/m`).
- **불변량 도출**: 운동량 `p = m·v`, 운동에너지 `KE = ½ m v²` 는 질량으로부터 정의된다.

## 창발 / author 안 함

- 코드는 *원소와 일반 법칙*만 안다 — 특정 타입(검·몬스터…) 분기 0.
- 질량은 박힌 라벨이 아니라 **저항의 크기**다: 같은 힘에 다르게 반응하는 것으로 드러난다.

## 검증 (verify_0001.js)

엔진(`engine.js`)+규칙을 `stepWorld` 로 굴려(뷰어와 동일) 단언한다.

1. **결정론** — 같은 입력 2회 → 비트 동일.
2. **관성(등속) + 운동량 보존** — 외부 힘 없으면 속도 불변, 총 운동량 불변.
3. **갈릴레이** — 같은 속도·다른 질량 → 같은 변위(외부 힘 없으면 질량 무관).
4. **질량 = 저항의 크기** — 같은 힘 `J` → `Δv = J/m`(무거울수록 덜 변함), 두 원소의 `m·Δv` 동일.
5. **장부 닫힘** — 외부 힘 후 `ΔΣp = ΣJ` (1e-9 이내).
6. **시나리오** — `tick 5` 동일 힘 후 가벼운 원소가 더 빠르다(`vx = J/m` 정확).
