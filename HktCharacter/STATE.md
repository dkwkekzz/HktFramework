## 지금 되는 것

- **① 뼈**: X Bot·Y Bot FBX 로드 → 구동 뼈 65개, 키 1.7m 정규화, 발 접지. 원본 스킨은 버림.
- **② 근육**: 해부학 아틀라스 31개(표재근)를 명시적 **부착 패치**(`origins[]`/`insertions[]`,
  뼈 로컬 오프셋 + 뼈-축 성분 `t`)로 정의 → 방추형 벨리를 뼈 사이에 부착. 이두근은 정지부가
  **관절을 넘어가** 팔꿈치 굴곡 시 실제로 짧아지고 굵어짐(부피 보존, 라이브 갱신).
  각 근육은 **프로필 스웹 방추형**(가는 힘줄 끝 → 중앙 벌크)이라 달걀이 아니라 가늘고 길다.
  + 뼈 패딩 캡슐로 정강이·손·발·머리 채움.
- **③ 피부**: 근육·뼈 캡슐의 음함수 필드를 **smooth-max(공간 분할)** 로 union(WP-09·§9.8·
  원칙③ — 가산 합이 아니라 겹침부가 표면을 공유) → MarchingCubes(64³) → 정점 용접 →
  **Laplacian fascia 스무딩**(WP-10·§9.10 — 근육 골·계단 줄무늬 완화) → 뼈에 스키닝 바인딩 →
  `SkinnedMesh` 로 rest 포즈에서 **한 번 굽기**. **체형별 피부 전달률**(§11)로 근육 분리 노출
  조절 — 근육질·마른은 또렷, 비만은 매끄럽게. 붙인 달걀이 아니라 연속 피부 위 릴리프.
- **애니메이션**: 6개 Mixamo 클립(대기·걷기·뛰기·점프·공격·삼바) 순수 월드 공간 리타깃 →
  뼈가 움직이면 근육·피부가 함께 변형. 클립별 사전 측정 접지.
- **UI**: 레이어 토글(뼈/근육/피부) · 모델 드롭다운(X/Y Bot) · **체형 드롭다운(마른/평균/근육질/비만)** ·
  애니메이션 · 속도.

  **전달률·fascia**(§11·§9.10), 애니 변형, **체형**(비만 전후 > 마른).
