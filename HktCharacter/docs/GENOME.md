# GENOME — 살 게놈 (genome-encoding-principles 이식)

> 근거 문서: [genome-encoding-principles.md](../genome-encoding-principles.md).
> 이 문서는 그 일반 원리를 **"주어진 스켈레톤에 SDF 살을 붙이는"** 도메인에 이식한
> 결과의 설계·검증 기록이다. 구현: `src/fleshdna.js`(순수 게놈·디코더), `src/mcflesh.js`
> (SDF 소비), `tools/flesh-verify.mjs`(4법칙 감사). 상위 로드맵은 [FLESH-PLAN.md](FLESH-PLAN.md).

## 0. 왜 이 도메인이 원리와 특별히 잘 맞나

원리 문서 §2 의 핵심 계율은 **"위상(topology)은 게놈의 연속 부분에 절대 넣지 마라"** 다.
이 프로젝트의 불변 원칙 — *"골격은 로드하는 것이지 만드는 것이 아니다"*(CLAUDE.md) — 은
바로 그 계율의 가장 깨끗한 실현이다:

```
L0 체제    = 로드된 스켈레톤        ← 게놈 밖 · 외부 고정 (이산)
L1 구조    = 뼈 계층               ← 게놈 밖 · 외부 고정 (이산)
────────────────────────────────────────────────────────────
L2 비례    = 뼈 scale (main.js props: 길이·골격)   ← 살 게놈은 안 건드림
L3 살/채움 = ★ 살 게놈 (부위 두께·프로파일 형태·flatten)
L4 표면    = ★ 살 게놈 (색)
```

위상이 애초에 게놈 밖이므로 **어떤 유전자 값이 와도 위상이 깨질 수 없다** → 폐쇄성이
구조적으로 보장된다. 살 게놈은 순수하게 연속 층(L2 성격의 두께 ~ L4 색)만 담는다.

## 1. 표현 = (수열, 전개 규칙)

원리 문서 §0: *정보의 대부분은 수열이 아니라 디코더에 있다.*

- **수열(genome)** — 정규화 유전자 벡터 `[0,1]^13` (직렬화하면 13바이트 hex, 예:
  `6680668080668066668066808c`). 짧다. 규칙의 *파라미터*일 뿐이다.
- **전개 규칙(decoder)** — `src/fleshdna.js` 의 `TEMPLATE`(16개 해부학 세그먼트: 뼈 이름
  정규식 → 기본 프로파일·flatten·그룹)와 `compileFlesh`. 정보의 거처는 여기다.
- `compileFlesh(genome)` 가 TEMPLATE 을 유전자로 변조 → 세그먼트별 반지름 LUT(PCHIP 33점)
  를 굽고, `mcflesh.js` 가 그 LUT 만 소비해 캡슐 SDF → MarchingCubes 로 살을 세운다.

## 2. 유전자 배치 (13개, 부위 그룹별 인접)

| # | key | 층 | 범위 | 의미 |
|---|---|---|---|---|
| 0–1 | head.thick / head.shape | L3 | thick[.6,1.6] shape[0,1] | 머리 두께 · 두상 볼록 |
| 2–4 | torso.thick / torso.shape / torso.flatten | L3 | | 몸통 두께 · 허리 잘록 · 앞뒤 납작 |
| 5–6 | arm.thick / arm.shape | L3 | | 팔 두께 · 이두 볼록 |
| 7 | hand.thick | L3 | | 손 두께 |
| 8–9 | leg.thick / leg.shape | L3 | | 다리 두께 · 종아리 볼록 |
| 10 | foot.thick | L3 | | 발 두께 |
| 11–12 | surface.hue / surface.tone | L4 | | 살색(좁은 대역) · 명도 |

- **그룹 인접 배치** → 크로스오버가 그룹 경계에서만 일어나면 부위가 통째로 상속된다(조합성).
- **폐쇄성 구현**: 모든 유전자는 `value = lo + gene·(hi−lo)` clamp 매핑으로만 해석. 조건부
  "이 값이면 안 됨" 분기 없음. `shape` 는 끝점(관절) 고정 + 중간 편차만 `×(1+s)` 로 조각 →
  인접 세그먼트 연속성 보존 + 반지름 하한 클램프 → 임의 수열이 항상 유효.
- **전역 배율 유전자 없음(설계 결정)**: 모든 부위를 곱하는 전역 "벌크" 유전자는 부위를
  얽어 조합성을 깬다(초기 감사에서 ratio 1.03 으로 확인). "전체 크기"는 부위 두께의 동조
  이동으로, 골격 크기는 뼈 scale(L2)로 표현한다 — 채널이 깨끗해진다.

## 3. 형태 = 기능 (§6)

스탯을 게놈에 *따로 적지 않는다.* `deriveStats(pheno, lengths)` 가 **표현형에서 읽어낸다**:
부피 = Σ 부위(π·평균r²·flatten·길이), 그로부터 체력 ∝ 부피, 속도 ∝ 다리길이/√질량,
위력 ∝ 팔 부피, 사거리 ∝ 팔 길이. 뷰어는 실제 뼈 길이를 재서 넘긴다(형태=기능). 결과로
**트레이드오프가 공짜로 생긴다** — 두께를 키우면 체력↑·속도↓ (§검증 ⑤).

## 4. 4법칙 감사 결과 (`node tools/flesh-verify.mjs`)

원리 문서 부록 하네스 이식. **눈이 아니라 숫자로** 판정하며 SVG 카드(`tools/flesh-audit.svg`)
로 남긴다. 결정론적 시드라 재현된다.

| 법칙 | 측정 | 합격선 | 결과 |
|---|---|---|---|
| ① 폐쇄성 | 랜덤 게놈 10,000 → 유효율 | =1.0 | **1.0000** ✅ |
| ② 지역성 | d_g(게놈 L2) vs d_p(표준화 특징 L2) Spearman ρ | >0.7 | **0.717** ✅ |
| ③ 조합성 | 경계 vs 유전자별 무작위 재조합의 부위 상속률 비 | >1.5 | **1.50** (경계 1.00 / 무작위 0.66) ✅ |
| ④ 다양성 | 표준화 특징 상관행렬 참여비(유효 차원) | ≥6.5 | **6.76** / 52차원 ✅ |
| ⑤ 형태→기능 | 두께↑ 시 체력·속도 상관 (트레이드오프) | 체력↑·속도↓ | **체력ρ 1.00 · 속도ρ −1.00** ✅ |
| ⑥ 채널 분리 | 팔 유전자 변경이 팔 세그먼트만 바꾸는가 | 타부위 0 | **팔 3 · 타부위 0** ✅ |

감사 과정에서 잡힌 설계 결함과 처방(원리 문서 §5 실패 카탈로그 그대로):
- 전역 벌크 유전자 → 조합성 붕괴 → **제거**(부위 두께 동조로 대체).
- 특징 단위 상이(반지름 vs 색)로 지역성·다양성 왜곡 → **특징 표준화** + 프로파일 3점 샘플.
- 살색 hue 순환성 → **좁은 살색 대역**으로 비순환화.
- r=0 자리표시(손가락) 자동 일치가 조합성 대조군 부풀림 → **그려지는 부위만** 집계.

## 5. 뷰어 사용 (`npm run dev`)

패널 **"살 게놈"** 섹션: 유전자 슬라이더(작은 변화→작은 형태 변화=지역성 시연),
🎲 랜덤 개체(임의 수열도 항상 유효=폐쇄성 시연), 변이(층별 변이율), DNA 코드
입출력(바이트 수열 복원), 실시간 스탯 readout(형태→기능). "SDF 살" 표시를 켜면 반영.
콘솔: `__hkt.genome`, `__hkt.dna`, `__hkt.stats`, `__hkt.setDna(hex)`, `__hkt.randomFlesh(seed)`.

> 주: 실시간 SDF 경로는 **원형 단면**만 채운다(flatten 은 애니메이션 회전 추적이 필요 →
> FLESH-PLAN Phase W/F2·bake 담당). flatten 유전자는 스탯·특징·(향후)워프가 소비한다.
> 실시간에서 눈에 보이는 유전자 효과 = 부위 두께 + 프로파일 형태 + 색.

## 6. 남은 일 (FLESH-PLAN 과 접점)

- flatten·bump 을 실시간/워프 경로 형상에 반영 (FLESH-PLAN §5.2–5.3, §5W).
- 프리셋·A→B 보간 UI (`lerpGenome` 는 이미 있음 — F4).
- LLM 파이프라인: DNA 는 의미 있는 키의 13바이트라 "어깨 넓은 드워프"→생성→뷰어 드롭 검증
  이 그대로 성립 (FLESH-PLAN §7).
