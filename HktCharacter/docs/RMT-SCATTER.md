# RMT-SCATTER.md — 제타 영점(RMT) 기반 환경 스캐터

제타 함수 영점 간격 ↔ GUE 고유값 간격의 일치(Montgomery–Odlyzko)에서 나오는
**준위 반발(level repulsion)** 을 PCG 배치 노이즈로 쓴다. 일반 난수(푸아송)는
간격 밀도 P(s)=e^{-s} — s=0 이 최빈이라 **뭉침(clumping)** 이 필연이다. GUE 는
P(s)=(32/π²)s²e^{-4s²/π} (Wigner surmise) — s→0 에서 s² 로 죽어 "완전한
무작위이면서 절대 뭉치지 않는" 배열이 된다. 푸아송 디스크 샘플링과 달리
하드 최소 거리 컷이 없어 억제가 **연속적**이고, 결정 격자와 달리 장거리
질서가 없어 유기적이다.

## 이론 → 구현 매핑

| 필요 | 이론 | 구현 (`src/rmt.js`) |
|---|---|---|
| 1D 간격열 (크기 변주) | GUE 벌크 간격 = 제타 영점 간격 통계 | β=2 에르미트 **삼중대각 앙상블**(Dumitriu–Edelman) → 암시적 QL 고유값 → 국소 창 언폴딩 → 평균 1 간격열 |
| 2D 점 배치 (지면 스캐터) | 지니브르 앙상블 고유값 = 2D 쿨롱 가스(β=2): 거시 균일 원판 + 미시 쌍 반발 | 결합 밀도 ∝ ∏\|zᵢ−zⱼ\|²e^{−nΣ\|z\|²} 를 **메트로폴리스 MCMC** 로 표본 (일반 복소 고유값 솔버 대신 로그-가스 표현) |
| 비교 기준 | 푸아송 (일반 `Math.random`) | `uniformDiskPoints` — 같은 개수, 반발 없음 |

전부 시드 결정론 (`mulberry32`) — 같은 seed 는 같은 배치.

## 배치 (`src/scatterLayout.js` — three 무의존)

- 소형(잔디 73%·바위 22%·수정 5%): 지니브르 N=220, 반경 9.2m, 캐릭터 공터 1.6m.
- 나무: **별도 저밀도 과정** N=14 — 개인 공간이 다른 객체를 한 과정에 섞으면
  반발 스케일이 하나로 뭉개진다. 과정 분리가 원칙.
- 크기: GUE 간격열을 [0.5, 1.8] 로 클램프 — 0 도 극단도 드문 "자연스러운 다양성".
- 렌더는 `src/scatter.js` (타입별 InstancedMesh, 절차 지오메트리, 빌드 1회·프레임 비용 0).

## UI

패널 "환경" 섹션 — **RMT**(기본) / **무작위**(뭉침 비교) / **끄기** / **재배치**(새 시드).

## 검증

```bash
npm run verify:rmt        # Node 수학 검증 + SVG 캡처 (브라우저 불필요)
npm run verify:rmt:shot   # headless Chromium 실제 씬 4컷 (RMT/무작위 × 기본/조감)
```

v1 실측 (2026-07-15): 간격 평균 1.0000 · P(s<0.25)=2.04% (Wigner 이론 1.7%,
푸아송이면 22.1%) · 히스토그램 L1=0.046 · 2D 최소 NN 거리 7.0× (vs 무작위) ·
근접쌍 비율 2.7% vs 12.7%. 캡처는 `verify/out/`.

## 한계·주의

- MCMC 는 로드 시 1회 ~0.3s (N=220, 260 sweep) — 재배치 클릭마다 재계산.
  N 을 키우면 O(N²·sweep) 로 는다.
- 2D 반발의 근접쌍 비율은 0 이 아니라 ~2% (NN CDF ∝ r⁴) — 하드 최소 거리가
  필요하면 푸아송 디스크를 쓰고, "부드러운 자연스러움"이 목적일 때 RMT 를 쓴다.
- `eval/` 은 legacy v1 잔재 — 이 트랙의 검증은 `verify/` 에 둔다.
