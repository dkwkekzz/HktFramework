# 게놈 인코딩 설계 원리

> 어떤 도메인이든, 유한한 수열로 무한한 대상을 생성하되 **그 수열이 진화 가능하도록** 만드는 방법.

---

## 0. 근본 정리

**표현은 수열이 아니다. 표현은 `(수열, 전개 규칙)` 쌍이다.**

세는 논증으로 끝난다. 길이 N 비트의 수열은 2^N 개뿐이므로, 거의 모든 대상은 압축 불가능하다. 유한한 수열로 담을 수 있는 것은 "가능한 모든 대상"이 아니라 **"구조가 있는 대상"** 이라는 얇은 부분집합뿐이다.

따라서:

- **정보의 대부분은 수열이 아니라 전개 규칙(디코더)에 있다.**
- 수열은 규칙의 *파라미터*다. 대상의 인코딩이 아니다.
- 좋은 게놈 설계란 **좋은 수열 설계가 아니라 좋은 디코더 설계**다.

이 사실을 놓치면 게놈이 그냥 압축된 데이터가 되고, 모든 좋은 성질을 잃는다.

```
게놈 (짧은 수열)  ──[전개 규칙]──▶  표현형 (거대한 구조)
   수십~수백 값         정보의 거처         무한한 디테일
```

## 1. 설계 4법칙

디코더를 평가하는 기준. 넷 다 **정량 측정 가능하다** — 눈으로 보고 판단하지 마라.

### 폐쇄성 (Closure)
> 임의의 랜덤 수열을 넣어도 항상 유효한 대상이 나와야 한다.

검증도, 재시도도, 필터링도 없이. 규칙이 구조적 정합성을 보증하므로 파라미터가 무엇이든 결과는 유효하다.

**측정:** 랜덤 게놈 10,000개 → 유효율. 100% 미만이면 디코더에 버그가 있거나 범위 매핑이 잘못됐다. 99%는 실패다. 100%여야 한다.

**구현 방법:** 모든 유전자를 `clamp(lo, hi)` 범위 매핑으로만 해석한다. 조건부 분기로 "이 값이면 안 됨"을 처리하려 들면 폐쇄성이 깨진다. 대신 **범위 자체를 항상 유효하게 설계**한다.

### 지역성 (Locality)
> 수열의 작은 변화 → 표현형의 작은 변화.

이게 깨지면 탐색 공간이 절벽투성이가 되어 진화도, 보간도, 사용자의 점진적 튜닝도 불가능해진다.

**측정:** 게놈 거리 `d_g`와 표현형 거리 `d_p`의 상관. 게놈 쌍을 무작위로 수천 개 뽑아 `(d_g, d_p)` 산점도를 찍는다. 단조 증가하고 분산이 작아야 한다. Spearman ρ > 0.7 정도를 목표로.
- `d_g` = 정규화 L1/L2
- `d_p` = 도메인 의존. 형태면 Chamfer 거리, 통계량이면 특징 벡터 거리.

**실패 신호:** 한 유전자가 이산 분기를 유발하는데 연속 구간에 놓여 있다. → 그 유전자를 이산 층으로 승격시켜라 (§2).

### 조합성 (Compositionality)
> 부분열이 독립적 의미를 갖는다.

"다리 유전자"를 떼어 다른 개체에 이식할 수 있어야 재조합이 의미를 갖는다.

**측정:** 계층 경계에서 자른 크로스오버의 자손이 양쪽 부모의 특징을 알아볼 수 있게 섞는가. 무작위 위치 크로스오버와 비교했을 때 유효율·품질이 유의미하게 높아야 한다.

**구현 방법:** 게놈을 **의미 구간으로 분할**하고, 재조합은 반드시 구간 경계에서만 일어나게 한다.

### 정렬 (Alignment)
> 의미적으로 가까운 것이 수열 공간에서도 가깝다.

늑대와 여우가 늑대와 문어보다 가까워야 한다. 이게 성립해야 "비슷한 것 더 만들기", 보간, 검색이 작동한다.

**측정:** 사람이 매긴 유사도 순위 vs 게놈 거리 순위의 상관.

## 2. 가장 중요한 원칙: 이산과 연속의 분리

**위상(topology)은 게놈의 연속 부분에 절대 들어가면 안 된다.**

- 위상 = 부품이 몇 개고 어떻게 연결되는가. **이산적**이고, 바뀌면 하위 자산이 전부 무효가 된다.
- 비례(allometry) = 같은 위상 안에서의 크기·각도·비율. **연속적**이고, 마음껏 바꿔도 안전하다.

이 둘을 한 수열에 섞으면 지역성이 파괴된다. 유전자 하나를 1만큼 올렸는데 다리가 4개에서 6개가 되면, 그건 매끄러운 공간이 아니다.

```
[체제 코드]  ← 이산. 소수(3~5개). 각각 별도의 자산 세트를 요구한다.
──────────── 아래는 체제 코드에 의해 해석이 달라진다 ────────────
[연속 게놈]  ← 무한한 변형. 자산은 그대로 재사용된다.
```

### 자연이 주는 근거

캄브리아기 이후 체제는 거의 변하지 않았다. 척추동물은 5억 년간 사지동물 체제에 갇혀 있다. 기린의 목뼈는 7개로 인간과 같다. 박쥐 날개는 늘어난 손가락이다. Hox 유전자를 건드려 체절 수를 바꾸는 돌연변이는 거의 항상 치명적이다.

**진화의 거의 전부는 allometry다.** 문(門)은 30여 개뿐이고 종은 수백만이다.

### 실무 함의

비용이 이산 쪽에 몰려 있다. 새 체제 하나 = 새 애니메이션 세트, 새 검증기, 새 UI, 새 밸런스. 그러니:

> **체제는 아끼고, 연속 축에서 다양성을 뽑아라.**

체제를 늘리고 싶은 충동이 들면, 먼저 물어라 — "이걸 기존 체제의 극단적 allometry로 표현할 수 없나?"

## 3. 계층 제약 사슬

게놈은 평평한 배열이 아니라 **계층**이다. 상위 층이 하위 층의 *해석*과 *유효 범위*를 결정한다.

```
L0  체제        ← 이산. 나머지 전부의 의미를 규정한다.
L1  구조 규칙   ← 재귀/반복 규칙의 파라미터. 골격, 분기, 체절.
L2  비례        ← L1이 만든 구조의 각 부위 스케일.
L3  살 / 채움   ← L2의 구조 위에 붙는 표면·부피.
L4  표면        ← 색, 무늬, 재질. 다른 층에 영향 없음.
```

**핵심:** 각 층은 **바로 위 층이 만들어낸 슬롯에만 값을 채운다.** 자기 마음대로 새 슬롯을 만들지 않는다. 이 제약 사슬이 폐쇄성의 구현체다.

부수 효과로 유용한 성질이 따라온다:
- **L4만 바꾸면 같은 개체의 색 변종**이 나온다 (스킨/희귀도에 그대로 쓸 수 있다).
- **L0만 바꾸면** 완전히 다른 종이 나온다 (돌연변이 확률을 층별로 다르게 줘라 — 상위 층일수록 낮게).
- 층 경계 = 자연스러운 크로스오버 지점.

### 층별 돌연변이율

상위 층일수록 낮게. 자연의 그것과 같다.

```
L0: 0.001   L1: 0.02   L2: 0.15   L3: 0.15   L4: 0.3
```

## 4. 이식 절차

새 도메인에 적용할 때의 순서. **이 순서를 지켜라** — 뒤에서부터 하면 반드시 다시 짠다.

### 1단계 — 체제를 세어라
"이 도메인의 대상들은 몇 가지 근본적으로 다른 *구조*를 갖는가?"

무기라면: 날붙이 / 둔기 / 사격 / 지팡이. 건물이라면: 탑 / 홀 / 격자 / 유기적.
답이 10개를 넘으면 너무 잘게 쪼갠 것이다. 다시 묶어라.

### 2단계 — 각 체제의 재귀 규칙을 찾아라
그 구조를 *만들어내는* 절차는 무엇인가. 청사진이 아니라 **레시피**여야 한다.

좋은 신호: "N번 반복한다", "각도 θ로 분기한다", "확산시킨다", "임계값을 넘으면 갈라진다".
나쁜 신호: "정점 좌표 목록", "부품 인덱스 배열". → 그건 직접 인코딩이고, 진화하지 않는다.

### 3단계 — 규칙의 파라미터를 나열하고 층으로 묶어라
각 파라미터에 대해 물어라: **"이 값을 조금 바꾸면 결과가 조금 바뀌는가?"**
- 예 → 연속 층
- 아니오 → 이산 층으로 승격, 또는 재설계

### 4단계 — 모든 파라미터를 clamp 범위로 매핑하라
```
value = lo + (byte / 255) * (hi - lo)
```
`lo`, `hi`는 **양 극단이 모두 유효한** 범위여야 한다. 여기서 폐쇄성이 결정된다.

### 5단계 — 계층 간 상호 제약을 넣어라
`팔 굵기 ≤ f(몸통 굵기)` 같은 것. 이게 폐쇄성의 마지막 조각이다.
단, **거부가 아니라 사상(mapping)으로** 하라. "범위를 벗어나면 거부"가 아니라 "상위 층 값에 따라 하위 층의 범위가 좁아진다".

### 6단계 — 4법칙을 측정하라
눈으로 보고 만족하지 마라. 폐쇄성 100%, 지역성 ρ, 조합성 유효율. 숫자를 로그로 남겨라.

## 6. 형태가 곧 기능이어야 한다

생성만으로는 예쁜 장난감이다. **표현형에서 기능/스탯을 *도출*할 때** 비로소 세계가 된다.

핵심은 스탯을 게놈에 *따로 적지 않는* 것이다. 그러면 형태와 능력이 따로 논다.

> **스탯은 게놈의 함수가 아니라, 표현형의 함수여야 한다.**

```
게놈 ──[전개]──▶ 표현형 ──[측정]──▶ 능력
                    ↑
              여기서 읽어낸다
```

다리가 길면 빠르다 — 게놈에 "속도" 유전자가 있어서가 아니라, 디코드된 다리 길이를 *재서* 속도를 계산하기 때문이다. 부피가 크면 체력이 높다. 표면적이 넓으면 열을 빨리 잃는다.

이렇게 하면:
- 밸런스가 자동으로 일관된다 (형태를 속일 수 없다).
- 트레이드오프가 공짜로 생긴다 (크면 강하지만 느리다).
- **선택압이 생긴다.** 선택압이 생기면 세계가 스스로 종을 만들기 시작한다.

이게 창발의 문턱이다. 여기를 넘기 전까지는 절차적 생성기고, 넘고 나면 생태계다.

## 7. 도메인 이식 예시

|---|---|---|---|---|---|---|
| 생물 | 이족/사족/절지/사행 | 척추 체절, 사지 분기 | 본 길이 스케일 | SDF 살 반경 | 색, 무늬 | 다리 길이→속도, 부피→체력 |
| 무기 | 날/둔기/사격/지팡이 | 자루-머리 재귀 분할 | 길이·질량 비 | 단면 프로파일 | 재질, 각인 | 질량중심→휘두름 속도, 날 각→관통 |
| 재질 | 금속/유기/결정/직물 | 반응확산 시드 | 결정립 크기 | 층 두께 | 반사율 | 밀도→무게, 결정립→강도 |
| 지형 | 대륙/군도/협곡/평원 | 판구조 골격, 침식 반복 | 고도 스케일 | 퇴적 두께 | 바이옴 | 경사→이동비용, 습도→식생 |
| 건축 | 탑/홀/격자/유기 | 방 분할 문법 | 스팬·층고 | 벽 두께 | 재료 | 하중경로→구조 안정성 |
| 스킬 | 지속/즉발/설치/변신 | 효과 트리 분기 | 계수·쿨다운 | 판정 형태 | VFX | 판정 부피×계수→기대 DPS |

패턴이 보일 것이다. **어느 도메인이든 "체제 → 재귀 구조 → 비례 → 채움 → 표면" 이라는 같은 뼈대가 나온다.** 이게 우연이 아닌 이유는, 이것이 정보를 계층적으로 압축하는 유일하게 안정적인 방식이기 때문이다.

## 8. 한 문장 요약

> 통일해야 할 것은 수열이 아니라 **메타 문법**이다 —
> *"게놈은 계층적이고, 각 층은 상위 층에 의해 제약되며, 임의의 값이 언제나 유효한 결과를 낳고, 능력은 형태에서 읽어낸다."*
> 그 아래에는 도메인마다 다른 문법을 꽂아 넣으면 된다.

---

## 부록 — 검증 하네스 (도메인 무관)

```python
def audit(decode, genome_len, phenotype_distance, n=10_000):
    # 1. 폐쇄성 — 반드시 1.0
    genomes = [random_bytes(genome_len) for _ in range(n)]
    valid = sum(is_valid(decode(g)) for g in genomes) / n

    # 2. 지역성 — 게놈 거리 vs 표현형 거리의 순위 상관
    pairs = sample_pairs(genomes, 2000)
    dg = [l1(a, b) / genome_len for a, b in pairs]
    dp = [phenotype_distance(decode(a), decode(b)) for a, b in pairs]
    locality = spearman(dg, dp)

    # 3. 조합성 — 계층 경계 크로스오버 vs 무작위 지점 크로스오버
    aligned = quality(crossover_at_layer_boundary(pairs))
    naive   = quality(crossover_at_random_point(pairs))

    # 4. 다양성 — 표현형 특징 공간의 유효 차원
    feats = [features(decode(g)) for g in genomes]
    diversity = effective_rank(pca(feats))

    return dict(closure=valid, locality=locality,
                composability=aligned / naive, diversity=diversity)
```

**합격선:** `closure == 1.0`, `locality > 0.7`, `composability > 1.5`, `diversity`는 게놈 길이의 절반 이상.

이 넷을 통과하지 못한 게놈은 생성기일 뿐 진화 가능한 표현이 아니다.
