## NOW — 현재

- **완료**: 최소 원장 코어 + feature-0001(보존)·0002(정수)·0003(태양=유일 원점).
- **검증됨**: feature-0004(엔트로픽) **step 1~2** — (1) 국소장 3D 복셀 `M:<voxel>` 도입, 죽음·이동 소산을 국소장으로, 엔트로픽 확산 + 심우주 복사. (2) `FIELD` 복셀 스냅샷 방송 + 뷰어 3D 볼류메트릭으로 **확산 전파를 시각화**. (재응집·아이템 = feature-0005 로 이관.)
- **완료(추가)**: feature-0005(결정화) **step 1~4 검증됨** — (1) 결정 = 확산·복사 순회 밖(=면역)인 정적 저엔트로피 섬. (2) 개별 discrete `I:<seq>`(위치·종·잔고), **죽음 → 결정 분해**(+국소장), **종** 생성 다양성. (3) **반응(화학)**: 같은 종=융합/다른 종=화합+반응열 방출, 개수 묶고 종 창발. (4) **물질 상태 = 밀도 regime**: 저=기체(등방 확산)·중=액체(응집·중력 침강·바닥 고임·수면·저증발)·고=고체(석출), `fieldPhase(농도)` 유도·임계 통과로 상전이. 후속: 상호작용(채집·용해).
- **완료(추가)**: feature-0006(생명체 **자기유지**) **step 1~2 검증됨** — 능동적 저엔트로피 섬 `C:<seq>`. (1) 매 대사 틱마다 스스로: **갈구**(국소장→생명체) → **생사판정**(최소 예비 아래면 붕괴→분해) → **물질대사**(생명체→심우주, 엔트로피 세금). 풍요=용량 근처 안정 생존 / 고갈=유한 틱 아사(항상성). 죽으면 결정+국소장으로 분해. (2) **성장·스탯**: 흑자 지속 → `size`↑(용량·갈구·대사·예비 비례, hard-won), 큰 몸은 세계가 못 받치면 몰락(죽음) → 세계 풍요도가 크기 상한을 정한다. 자기유지는 이로써 닫힘.
- **완료(추가)**: feature-0007(채집·섭취) **step 1~2 검증됨** — 아이템 = 에너지의 결정체. (1) 생명체가 근접 결정(`HARVEST_RADIUS` 안)을 흡수한다(결정→생명체, `HARVEST_RATE*size`, 확산 갈구보다 큼 = **증폭**). 결정은 정적·면역이지만 생명이 오면 질서가 풀려 먹히고, 다 먹히면 소멸. **생태 루프**: 죽음→결정→다른 생명체의 채집. (2) **종별 효과**: 결정 종(species)마다 흡수 배율이 다르다(`crystalYield`) — 같은 잔고라도 고효율 종은 크게 들이켜 빨리 성장, 저효율 종은 천천히("아이템이 나의 에너지에 영향을 줄 수 있는 형태"). 후속: 장착·발산 증폭(feature-0008 정합).
- **진행 중**: feature-0008(발산·전투=포식) **step 1 검증됨** — 생명체가 에너지를 폭발적으로 발산해 근접한 **더 작은** 생명체를 공격해 에너지를 **강탈**한다. forage·harvest 가 수동적 저장고를 긁는 것이라면 강탈은 *저항하는* 다른 생명에서 뜯어내는 세 번째 free energy 수입 — (1) 발산 비용(질서 깨는 일→SINK, 열) (2) **손실적 회수**(효율<1, 나머지는 국소장으로 흩어짐 = 얻는 것 < 뺏는 것, 2법칙·10% 법칙). 강자→약자 **포식 위계** 창발(size< 규칙), 뜯겨 죽은 먹이는 결정을 남겨 채집(0007)으로 되먹임. 후속: 스킬·방출형·아이템 발산 증폭.
- **흐름**: `태양 → 생명체 →(대사)→ 심우주` + `국소장 →(갈구)→ 생명체` + `결정 →(채집·종별 배율)→ 생명체` + `생명체 →(강탈=포식, 손실적)→ 생명체 + 국소장 + 심우주` + `태양 → 국소장(기체·액체=밀도 regime) → 심우주` + `국소장/생명 →(과포화·죽음·전투사)→ 결정(고체·정적·면역·종 다양) →(반응)→ 결정'/국소장` — 열린 흐름 + 세 상태 + 정적 섬(결정)·능동 섬(생명체)·포식 위계.
- **검증 상태**: `npm test` **67/67** (기존 40 + 생명체 13 + 채집 7 + 전투 7). 보존 **여섯 곳** 합 = 10⁹(태양·국소장·심우주·결정·플레이어·생명체). 라이브 봇 6기 + 먹이 웅덩이: 생명체(초록 구체)가 국소장을 갈구하고 **곁의 결정을 종별 배율로 채집(`[채집]`)** 해 **성장(❋❋)**, 커진 개체는 **곁의 작은 생명체를 강탈(`[강탈]`/`[발산]`)** 해 사냥한다(포식 위계).
