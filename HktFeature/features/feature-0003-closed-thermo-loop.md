# feature-0003 — 서버(SOURCE)는 유일한 에너지 원점(태양)이며, 세계는 태양에서 흘러나온다

> 상태: 🟢 검증됨 (상시 재현) · **feature-0004 로 개정됨**(아래 개정 노트) · 작업 방식: [CLAUDE.md](../CLAUDE.md)

> ⚠️ **개정 노트 (feature-0004 엔트로픽)**: 이 feature 는 원래 `SINK→SOURCE` 태양 순환으로
> 세계를 **닫힌 루프**로 만들어 영속을 샀다. 그러나 그 순환은 "소산된(죽은) 에너지가 태양으로
> 되돌아간다"는 **물리적 거짓**이었다. [feature-0004](feature-0004-entropic.md) 가 이 텔레포트를
> **삭제**하고 죽음/소산을 *그 자리 국소장*(`M:<region>`)으로 돌렸다. 이제 흐름은 닫힌 루프가
> 아니라 **열린 흐름**(`태양 → 생명 → 국소장 → 심우주`)이며, 영속은 태양의 방대함이 주는
> *실용적 영속*이다(심우주의 단조 증가 = 엔트로피의 화살은 실재). 아래 원문 중 "순환/닫힌 루프"
> 부분은 이 노트로 대체되며, 여전히 참인 부분(태양=유일 원점·이동은 소산·보존)은 유지된다.

## 명제 (개정)

서버(SOURCE)는 유일한 에너지 원점(태양)이다 — 생성기가 아니라 **저엔트로피의 원천**. 방출된 에너지는 소산되어 국소장에 흩어지고, 엔트로픽 확산을 거쳐 일부는 심우주(SINK)로 영영 손실된다. 세계는 태양에서 흘러나오는 **열린 흐름**이며, 태양의 방대함으로 실용적으로 영속한다.

<details><summary>원문 명제 (feature-0004 이전 — 닫힌 루프)</summary>

서버(SOURCE)는 유일한 에너지 생성 장(태양)이다 — 생성기가 아니라 **순환의 원점**. 방출된 에너지는 소산(SINK)을 거쳐 SOURCE 로 되돌아온다. 세계는 닫힌 열역학 루프(`SOURCE → 생명 → SINK → SOURCE`)이며 영속한다.
</details>

## 최종 목적 (측정 가능)

**어느 순간에도 `자유(플레이어) + 태양(SOURCE) + 소실(SINK) = 창세 총량(10⁹)` 이고, 태양은 마르지 않는다.**

- 소산: 활동(현재는 이동)은 에너지를 SINK 로 흩는다 → SINK 잔고가 오른다.
- 순환: 태양 순환이 주기(`RECYCLE_INTERVAL_TICKS`)마다 SINK 전량을 SOURCE 로 되돌린다 → SINK 잔고가 0 으로 떨어진다.
- 영속: 이동↔순환을 무한 반복해도 SOURCE 는 하한 위에 머물고(고갈 없음), 총합은 불변.

## 접근 — "생성"이 아니라 "순환"으로 영속

에너지를 새로 만들지 않는다. 두 저수지(태양·소실) 사이를 닫힌 이체로 돌린다.

- 창세: 전 에너지가 SOURCE 에 적립(feature-0001). SINK 는 0 으로 함께 열린다.
- 방출 = 소산: 이동 비용은 `player→SINK` 이체(예전 `player→SOURCE` 를 대체). "방출된 에너지는 소산으로 흩어진다".
- 태양 순환: 매 `RECYCLE_INTERVAL_TICKS` 틱마다 `SINK→SOURCE` 로 소산분 전량 복귀. 서버 내부 저수지 간 이체(region=null)라 방송·체크섬과 무관한 무음 순환.
- 닫힌 루프라 총합은 여전히 10⁹ — 순환은 보존을 깨지 않는다(feature-0001 의 따름정리).

## 검증 (항상 가능)

```bash
npm test        # test/thermo.test.js
./run.sh 8      # 라이브 — [원장] 줄의 소실(SINK)이 차올랐다 태양 순환에 0 으로 떨어진다
```

- **자동**: `test/thermo.test.js` 가 (a) 창세에 SINK=0 (b) 이동이 SINK 로 소산 → 순환 후 SINK=0·SOURCE 전량 복귀·총합 불변 (c) 이동↔순환 8주기 반복에도 태양이 하한 위·총합 10⁹·`자유+태양+소실=10⁹` 를 단언.
- **직관**: 봇 요약 `[원장] … 태양 … · 소실 N …` 에서 소실이 **차올랐다 0 으로 떨어지는 맥동**을 눈으로 본다(라이브 실측: 소실 28→117→0, 태양 ~10⁹ 유지, 총합 10⁹). 브라우저 뷰어 우상단 `☀ 태양 · 소실` 도 같은 맥동을 전시.
- **강제 지점**: 소산·순환 모두 `ledger.transfer` 를 지나는 이체 — 닫힌 루프가 보존을 보장한다.
