# feature-0009 — 발산: 생명체가 에너지를 발산해 파이어볼(투사체)을 쏜다

> 상태: 🟡 진행 중 (step 1~4 검증됨) · 작업 방식: [CLAUDE.md](../CLAUDE.md)
> 배경: [feature-0008](feature-0008-emit-predation.md)(강탈=포식)에서 분리된 트랙. 발산에는 두 원리가 있다 — **포획(수입)** 은 0008, **파괴(지출)** 는 이 feature.
> 정합: 발산이 만든 파이어볼이 *터지는* 것(폭발)은 **물질의 사건**이라 별개다 → [feature-0013](feature-0013-material-property-stimulus.md) 규칙 D(폭발).

## 명제

생명체는 내부 에너지를 폭발적으로 **발산**해 비생명 농축 에너지 덩어리(**파이어볼=투사체**)를 만들어 표적 자리로 보낸다. 발산은 **생명의 행위**이자 **순수 지출**이다 — 먹지 않으며(회수 없음), 제 에너지를 덜어 투사체에 싣는다. 여기서 생명체의 관여는 **끝난다**. 그 덩어리가 *터지는* 것은 생명이 아니라 **물질의 사건**(폭발)이므로 다른 feature(0013 규칙 D)가 맡는다. 강탈(0008)이 "어떻게 먹고 사는가"(수입)라면, 발산은 "어떻게 (못 먹는 상대를) 치는가"(지출)다.

## 왜 발산과 폭발을 가르는가 (불변 원칙 ②)

**발산(생명의 행위)** 과 **폭발(물질의 사건)** 은 주체가 다른 다른 사건이다 — 폭발은 생명만의 일이 아니다(폭탄·과충전 결정도 터진다). 한 함수에 뭉치면 "폭발 = 생명이 하는 일"이 되어 개념이 틀어진다. 그래서 이 세계에서는:

| 층 | 무엇 | 주체 | feature |
|---|---|---|---|
| **발산(emission)** | 내부 에너지를 밀어내 투사체를 **낳는다** | **생명체**(살아있어야 함) | **이 feature (0009)** |
| **투사체(파이어볼)** | 농축 에너지 덩어리가 표적으로 간다 | 비생명 transient 엔티티(`B:`) | 0009 이 생성 · 0013 이 소멸 |
| **폭발(detonation)** | 저장 질서를 다채널(열복사·압력·파편)로 터뜨린다 | **물질**(파이어볼·폭탄·결정) | [feature-0013](feature-0013-material-property-stimulus.md) 규칙 D |

파이어볼(`B:<seq>`)이 발산과 폭발을 잇는 **경계 엔티티**다: 0009 가 만들고(생명체→파이어볼), 0013 이 터뜨린다(파이어볼→세계). 파이어볼은 **캐스터 자리에서 표적 자리로 날아간다**(step4 비행, 눈에 보이는 투사체) — 착탄(≤한 걸음)하거나 수명이 다하면 그 자리서 터진다. 근접(≤한 걸음) 표적은 같은 틱 착탄(사실상 즉발), 원거리는 몇 틱 날아간다.

## 강탈 vs 발산 — 흐름의 위상이 다르다 (feature-0008 경계)

| | **강탈 (feature-0008, 포식)** | **발산 (이 feature)** |
|---|---|---|
| 원리 | **수입** — free energy 획득 | **지출** — 투사체를 만들어 던진다 |
| 결합 | 밀착(근접), 커플링 | 원거리(투사) |
| 표적 에너지 종착 | 일부를 **내가 붙잡음**(포획) | 발산은 표적을 직접 만지지 않는다 — 파이어볼이 가서 *터진다*(0013) |
| 캐스터 손익 | 순증 가능(먹는다) | **순손실만**(먹지 않는다·회수 없음) |
| 조준 | 먹이 = size< (강자→약자) | **먹을 수 없는 상대 = size ≥**(약자·동급→상대) |

두 능력은 **크기로 겹침 없이 갈린다**: 먹을 수 있으면(더 작으면) 강탈해 먹고, 못 먹으면(같거나 크면) 파이어볼을 던진다. 그래서 **약자가 강자를 어쩌지 못하는 포식(0008)의 한계를, 발산(0009)이 뚫는다** — 못 먹는 강자·동급에게 폭탄을 던지는 원거리 지출이 약자의 유일한 반격 수단이다.

## 최종 목적 (측정 가능)

1. **발산 = 투사체 생성**: 발산은 `생명체 → 파이어볼(B:)` 이체를 만든다 — 제 에너지를 투사체에 싣는다(생성).
2. **회수 없음(순수 지출)**: 발산·폭발의 어떤 흐름도 캐스터로 돌아가지 않는다(강탈과 대비: 강탈=내가 큼 / 발산=내가 줌).
3. **조준 = 먹을 수 없는 상대**: 근접 강탈(사거리 200, 먹이=size< 만)보다 **긴 사거리**(투사)에서, **먹을 수 없는 상대(size ≥ 자신)** 를 겨눈다 — 강탈과 겹치지 않고, 약자도 강자를 겨눈다.
4. **생명/폭발 분리**: 생명체는 파이어볼을 만들 뿐, *터지는* 다채널 파괴(연소·용해·파괴·AoE·완전 연소)는 feature-0013 규칙 D 가 맡는다(주체가 다르다).
5. **결정론 + 보존 불변**: 같은 배치·이벤트열이면 결과가 비트 단위로 동일하고, 전 풀 합계 = 10⁹ (파이어볼은 터지며 소멸).

## 원장 매핑 — 파이어볼 풀(B:) 하나 추가

한 발의 발산(캐스터 A)은 두 이체로 회계된다(전부 `ledger.transfer` → 보존·정수):

- **① 발사 비용**: `A → SINK` (`burst`) = 만들어 쏘는 일(열로 손실). `DISCHARGE_COST×size`.
- **② 파이어볼 장전**: `A → B:<seq>` (`emit`) = 제 에너지를 투사체에 싣는다(폭약). `DISCHARGE_POWER×size`. **여기서 생명체의 관여 끝.**

그다음 파이어볼의 *터짐*은 feature-0013 규칙 D(`#detonate`)가 이어받는다: payload(B:)를 열복사(결정 열)+압력(파편)+잔여 분산(심우주·국소장)으로 흩고, 반경 내 먹을 수 없는 상대(size≥)에 damage(표적 질서→세계)를 준다. **어느 흐름도 캐스터로 안 간다**(회수 없음). 자세한 회계는 feature-0013 규칙 D 참조.

**조준 규칙**: 사거리(`DISCHARGE_RADIUS`) 안 **먹을 수 없는 상대(size ≥ 자신)** 의 가장 가까운 하나 — 파이어볼이 그 자리로 간다. **결정론**: seq 오름차순 + 순수 클램프(rng 미사용).

### 구현 요지 (튜닝 근거)

- **파이어볼이 경계다**: 발산(0009)은 `생명체→B:` 까지만, 폭발(0013 규칙 D)은 `B:→세계` 부터. 이 한 엔티티로 "생명의 행위"와 "물질의 사건"이 코드에서 정직하게 갈린다. 새 현상(시한 폭탄·과충전 결정 자폭)은 파이어볼 대신 다른 물질을 `#detonate` 에 흘리면 그대로 터진다(주인이 물질이므로 확장이 자연스럽다).
- **발사자는 제 폭발에 안 맞는다**: 폭발은 생명 무관이지만, 파이어볼은 발사자를 삼키지 않는다(`fb.caster` 제외) — 멀리 쏘았다는 최소 정합. 그 외 반경 내 size≥ 상대는 모두 휩쓴다(AoE).
- **비용 = 발사 + 장전**: 회수 없는 순수 지출이라 발산은 비싸다(`(COST+POWER)×size` + 예비). 남발하면 제 에너지가 마르는 대가가 붙어 "값비싼 반격"으로 균형이 선다.
