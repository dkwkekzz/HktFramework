# feature-0009 — 발산·파괴: 표적의 질서를 세계로 흩어버린다 (방출형)

> 상태: 🟡 진행 중 (step 1 검증됨) · 범위(AoE)·불속성 증폭은 후속 · 작업 방식: [CLAUDE.md](../CLAUDE.md)
> 배경: [feature-0008](feature-0008-emit-predation.md)(강탈=포식)에서 분리된 트랙. 발산에는 두 원리가 있다 — **포획(수입)** 은 0008, **파괴(방출)** 는 이 feature.

## 명제

생명체는 내부 에너지를 폭발적으로 **방출**해 표적의 질서를 **파괴**한다 — 회수하지 않는다. 발사체(파이어볼)로 표적에 무질서(열)를 꽂아, 표적이 유지하던 에너지를 **심우주(열)+국소장(연기)** 으로 흩어버린다. 캐스터는 **순수 지출**만 하고(먹지 않는다), 표적은 붕괴해 사라진다 — 세게 맞으면 **완전 연소**(잔해 결정조차 없이 전소). 파괴는 세계에 엔트로피를 주입하는 행위다.

## 강탈 vs 방출 — 흐름의 위상이 다르다 (feature-0008 경계)

| | **강탈 (feature-0008, 포식)** | **방출 (이 feature, 파괴)** |
|---|---|---|
| 원리 | **수입** — free energy 획득 | **파괴** — 엔트로피 주입 |
| 결합 | 밀착(근접), 커플링 | 원거리(투사) |
| 붕괴 에너지 종착 | 일부를 **내가 붙잡음**(포획) | **아무도 안 붙잡음** — 심우주·국소장으로 흩어짐 |
| 캐스터 손익 | 순증 가능(먹는다) | **순손실만**(먹지 않는다) |
| 표적 | 먹이 = size< (강자→약자) | **먹을 수 없는 상대 = size ≥**(약자·동급→상대) |

두 능력은 **크기로 겹침 없이 갈린다**: 먹을 수 있으면(더 작으면) 강탈해 먹고, 못 먹으면(같거나 크면) 방출로 부순다. 즉 **"내가 얻는가"가 곧 검증 명제** — 강탈은 표적 에너지가 `victim → attacker` 로 흐르지만(내가 큼), 방출은 표적 에너지가 절대 캐스터로 가지 않는다(내가 줄 뿐). forage·harvest·강탈이 "어떻게 먹고 사는가"(수입)라면, 방출은 "어떻게 부수는가"(소비)다. 그래서 **약자가 강자를 어쩌지 못하는 포식(0008)의 한계를, 방출(0009)이 뚫는다** — 못 먹는 강자·동급을 태우는 원거리 파괴가 약자의 유일한 반격 수단이다.

## 최종 목적 (측정 가능)

1. **회수 없음**: 방출은 캐스터 잔고를 늘리지 않는다 — 표적이 잃은 에너지는 그 어떤 tx 로도 캐스터에게 가지 않는다(강탈과 대비: 강탈=내가 큼 / 방출=내가 줌).
2. **파괴 = 분산**: 표적이 잃은 damage 는 **심우주(열)+국소장(연기)** 으로 흩어진다. 캐스터 발산 비용도 심우주로.
3. **원거리·먹을 수 없는 상대**: 근접 강탈(사거리 200, 먹이=size< 만)보다 **긴 사거리**(투사)에서, **먹을 수 없는 상대(size ≥ 자신)** 를 친다 — 강탈과 겹치지 않고, 약자도 강자를 태운다.
4. **완전 연소**: 방출로 예비 아래로 떨어진 표적은 그 자리서 전소한다 — **잔해 결정 없이** 남은 에너지도 전부 열+연기로 흩어져 사라진다.
5. **결정론 + 보존 불변**: 같은 배치·이벤트열이면 결과가 비트 단위로 동일하고, 전 풀 합계 = 10⁹ — "사라진다"는 엔티티 소멸일 뿐, 에너지는 보존된다(세계를 데운다).

## 원장 매핑 — 새 풀 없음, "회수 없는" 파괴 엣지

한 발의 방출(캐스터 A → 표적 V)은 **회수 없는** 이체들로 회계된다(전부 `ledger.transfer` → 보존·정수):

- **① 발산 비용**: `A → SINK` (`burst`) = 투사체를 만드는 폭발적 소모(열). 강탈보다 비싸다(회수가 없으므로).
- **② 파괴 damage**: `damage = min(DISCHARGE_POWER×size, V잔고)` 만큼 표적 질서가 무너진다.
- **③ 분산(회수 없음)**: damage 중 `BURN_PCT` 는 `V → SINK`(태워 열로), 나머지는 `V → 국소장`(연기로). **어느 것도 A 로 가지 않는다** — 이것이 강탈과의 결정적 차이다.
- **④ 완전 연소**: ②·③ 뒤 V 가 예비(`DEATH_THRESHOLD×size`) 아래면 남은 전부를 같은 방식(열+연기)으로 흩고 V 를 제거한다 — 잔해 결정 없음(`#decompose` 경로를 **쓰지 않는다**, 전소이므로).

**표적 규칙**: 사거리(`DISCHARGE_RADIUS`) 안 **먹을 수 없는 상대(size ≥ 자신)** 의 가장 가까운 하나 — 강탈(먹이=size<)과 겹치지 않게 갈랐다(먹을 수 있으면 강탈, 못 먹으면 방출). **결정론**: seq 오름차순 + 순수 클램프(rng 미사용) → 확산·성장·전투 결정론 불변. 새 풀 없이 **회수 없는 파괴 엣지**만 얹는다.

### 구현 요지 (튜닝 근거)

- **"회수 없음"이 곧 이 feature 의 정체성**: 강탈(0008)에서 `victim→attacker` 흐름만 빼고 그 자리를 `victim→SINK/국소장` 으로 바꾼 것 — 골격은 같고 종착 하나만 *캐스터*에서 *세계*로 옮겼다. 이 한 끗이 "먹는다(수입)"와 "부순다(파괴)"를 가른다. 그래서 검증도 "discharge tx 가 생명체로 가는가?"만 보면 된다(가면 강탈, 안 가면 방출).
- **완전 연소는 `#decompose` 를 쓰지 않는다**: 굶어 죽음·강탈사는 잔해가 결정+국소장으로 남지만(0005/0006/0008), 전소는 *맹렬한 파괴*라 질서 잔해(결정)를 남기지 않는다 — 남은 에너지까지 열+연기로 흩어 "흔적 없이 사라진다". 같은 죽음이라도 *어떻게 죽느냐*가 잔해를 정한다(굶주림/포식=결정, 전소=무).
- **size≥ 표적 = 약자의 반격이자 겹침 없는 분업**: 포식(0008)은 강자→약자 일방이라 약자는 당하기만 한다. 방출을 **먹을 수 없는 상대(size≥)** 로 겨누게 해, 강탈(먹이=size<)과 크기로 깔끔히 갈랐다 — 먹을 수 있으면 강탈(포식자가 제 먹이를 태우는 낭비 없음), 못 먹으면 방출. 그래서 약자·동급이 강자를 원거리에서 태울 수 있고, 순수 지출(안 먹음)이라 남발하면 제 에너지가 마르는 대가가 붙어 "값비싼 반격"으로 균형이 선다.
