# feature-0020 — 동면 생명체 저해상도 갱신: 거시가 예측하고, 관측자는 해석한다

> 상태: 🟡 **진행 중** (step 1~2 검증됨 — 군집 통계 + 군집 갈구·대사·생사) · 작업 방식: [CLAUDE.md](../CLAUDE.md)
> 계보: [feature-0016](feature-0016-view-relevancy.md) step 3 후보("동면 정교화")를 **별도 명제로 분리**해 승계했다 —
> 0016 은 "관측 경계"(무엇을 시뮬하는가)의 명제로 완결됐고, 이 feature 는 "관측 밖 세계의 거시 동역학"(관측 안 하는
> 것을 *어떻게* 굴리는가)이라는 **다른 주체의 다른 사건**이다(불변 원칙 ②).
> 이론적 기초: [microcosm/systems.pdf](../../microcosm/systems.pdf) (소스: systems.tex) — 재규격화군·보편성.

## 명제

**거시적인 관점에서 하부 개체의 에너지 흐름을 예측한다. 그리고 관측자는 그것을 해석할 뿐이다.**

관측 밖 생명체(동면 군집)는 개체 단위로 시뮬되지 않는다. 대신 지역(region)별 **군집 통계(거시 변수)** 가
보존 하에 느리게 갱신되고, 다시 관측되는 순간 개체는 그 거시 상태와 **정합하는 미시 상태로 해석(복원)** 된다.
서버 부하는 여전히 관측 규모에 상한(0016 계승)이면서, **관측 없는 세계에도 시간이 흐른다.**

## 왜 이 feature 인가 — 지금의 동면은 "시간 정지"다

feature-0016 step 2 의 동면(`server/game.js #dormant`, `#metabolizeCreatures` 첫 줄 게이트)은 **완전 정지**다:
관측 밖 야생 생명체는 갈구·대사·성장·아사·욕구·전투가 전부 멈추고 잔고가 동결된다(`test/materialize.test.js`
"동면 — 관측 없는 야생 생명체는 아사하지 않는다"). 값싸고 보존 자명하지만 부작용이 있다:

- **세계의 비대칭** — 관측 밖 결정은 에너지로 환원돼 확산·복사(엔트로피)에 참여하는데("관측 없는 질서는
  흩어진다"), 생명체만 시간이 얼어 엔트로피 밖에 서 있다. 정적 섬은 흐르고 능동 섬은 멈추는 건 물리적으로
  뒤집힌 그림이다 — 질서 유지 비용(대사)을 내는 쪽은 오히려 생명이다.
- **관측이 세계를 만든다는 착시** — 오래 자리를 비웠다 돌아와도 봇들이 그대로다(굶지도 크지도 죽지도 않음).
  "보이지 않는 나무도 서버에서는 자란다"(0016 의 존재/관측 분리)가 생명체에서만 깨진다.
- **부하 관점의 여지** — 완전 정지가 아니라도, 개체 순회를 군집 단위 이체 몇 건으로 접으면 부하 상한(관측
  규모 비례)은 그대로 지킬 수 있다.

## 이론적 기초 — systems.pdf 를 이 feature 로 번역한다

[systems.pdf](../../microcosm/systems.pdf)(하나의 규칙, 여덟 층위)의 뼈대와 이 feature 의 대응:

1. **불변 규칙(6칸 템플릿)** — *단위 → 경계 → 상호작용 → 흐름 → 피드백 → 창발*. 층이 바뀌면 규칙이 아니라
   **명사만 바뀐다**. 이 세계에 적용하면: 개체 층(단위=생명체, 흐름=갈구/대사)의 한 층 위에 **군집 층**
   (단위=지역 동면 군집, 흐름=군집 총 갈구/총 대사)이 있고, 두 층은 같은 문법을 쓴다. 즉 저해상도 갱신은
   새 규칙의 발명이 아니라 **같은 규칙을 한 층 위에서 적는 것**이다.
2. **결합 동역학계** — `ẋᵢ = f(xᵢ) + ΣWᵢⱼ·g(xᵢ,xⱼ) + Iᵢ − γxᵢ`. 개체의 대사 순환(feature-0006:
   갈구 `+I`, 기초대사 `−γx`, 생사판정 = 고정점 안정성)이 이미 이 꼴이다. 군집 변수(잔고 합 E, 개체 수 N)도
   같은 꼴의 방정식을 따른다 — 합산이 선형 항을 보존하기 때문(갈구 총량 = Σ개체 갈구, 대사 총량 = Σ개체 대사).
3. **재규격화군(RG)·거칠게 보기** — 작은 단위들을 블록으로 묶어 평균 변수로 치환하고 반복하면 **무관한
   미시 세부는 0 으로 줄고 관련 변수 몇 개만 살아남는다**. 이것이 이 feature 의 핵심 정당화다:
   **관측 밖에서 개체별 궤적(누가 어느 틱에 얼마를 먹었나)은 "무관한 세부"고, 살아남는 관련 변수는 군집의
   에너지 흐름(총 갈구·총 대사·총 잔고)이다.** 미시를 시뮬하지 않아도 거시 법칙만으로 계를 예측할 수 있다 —
   동면은 렌더 LOD 가 아니라 **시뮬의 LOD** 다.
4. **관측 시 복원 = 중심극한정리의 역방향 읽기** — "세부는 씻겨나가고 형태만 남는다"이므로, 거시 상태와
   정합하는 **어떤** 미시 배분이든 세계는 구분할 수 없다. 따라서 재관측 시 개체 잔고를 결정론적 규칙으로
   배분해도(아래 설계) 관측자가 보는 세계는 정합적이다. **관측자는 거시를 해석할 뿐이다** — 명제의 후반부.
5. **정직한 경계선(문서 3장)** — RG 는 평형 임계현상에서만 엄밀하다. 생명체는 비선형(생사판정 = 임계 문턱,
   성장 = 이력 의존)이라 군집 합산이 개체 시뮬과 **정확히** 일치하지 않는다. 그래서 이 feature 의 측정 목적은
   "일치"가 아니라 **"거시 변수의 궤적이 상한 오차 안에서 닮는다"** 로 세운다(아래 최종 목적 4). 문서의
   표현을 빌리면 이는 정리가 아니라 *강한 유비 + 부분적 형식화*이며, 오차를 측정하는 것 자체가 검증이다.

## 물리적 환원 (불변 원칙 ②) — 주체를 가른다: 개체의 사건 vs 군집의 사건

| | **개체 (관측 안, 활성)** | **군집 (관측 밖, 동면)** |
|---|---|---|
| 주체 | 생명체 하나 (능동 섬) | 지역의 동면 군집 (거시 단위) |
| 사건 | 갈구·대사·성장·죽음·욕구·전투 | 총 갈구·총 대사·(설계 결정: 아사) |
| 변수 | 잔고·위치·size·desires·소유 | N(개체 수)·E(잔고 합)·S(size 합) |
| 시간 해상도 | 매 대사 틱 (`CREATURE_METABOLISM_INTERVAL_TICKS`=1) | 느린 주기 (`DORMANT_LOWRES_INTERVAL_TICKS`≫1, 신설) |
| 보존 | ledger.transfer | ledger.transfer (동일 — 회계는 층을 모른다) |

- **정체성은 개체에, 에너지 흐름은 군집에.** 0016 이 세운 원칙("생명체는 정체성을 지녀 환원하지 않는다")은
  그대로다: 동면 중에도 개체 레코드(id·seq·위치·size·desires·소유)는 **동결 유지**된다. 군집으로 위임되는 것은
  **에너지 흐름(잔고의 증감)뿐**이다. systems.pdf 1장의 "단위는 교체돼도 전체 정체성은 유지된다"(정체성=관계
  패턴)를 뒤집어 쓰면 — 여기서는 거꾸로 **개체 정체성을 지키면서 흐름만 거시화**한다. "나갔다 온 봇이 딴 봇"이
  되지 않는 경계가 이 분리다.
- **욕구·전투·이동은 군집의 사건이 아니다.** 절차(욕구 수행)·포식·발산은 표적·거리 등 미시 정보에 의존하는
  개체의 사건이라 거시화할 수 없다 — 동면 중 계속 정지(0016 그대로). 저해상도 갱신은 **대사 순환(갈구·대사·
  생사)만** 다룬다. 개체 사건을 군집에 뭉치면 불변 원칙 ② 위반이다.

## 최종 목적 (측정 가능)

1. **관측 밖에도 시간이 흐른다**: 야생 생명체를 관측 밖에 두고 충분히 굴리면 잔고가 **변해 있다**
   (지금은 동결 — `materialize.test.js` 의 동면 케이스가 반대를 검증하므로 그 케이스를 이 명제로 교체).
2. **보존 불변**: 저해상도 갱신을 아무리 돌려도 전 풀 합계 = 10⁹ (군집 이체도 전부 ledger.transfer).
3. **부하 상한 유지**: 관측 밖 지역의 생명체 갱신 비용이 **개체 수가 아니라 군집(지역) 수**에 비례한다 —
   저해상도 틱의 이체 건수 = O(동면 지역 수), O(동면 개체 수) 아님. (개체 배분은 관측 시 1회 또는 느린
   주기 1회 — 아래 설계 결정 D-4.)
4. **거시 예측의 닮음**: 같은 시드·같은 초기 세계를 (a) 게이트 OFF(전 개체 활성) (b) 게이트 ON + 저해상도로
   굴렸을 때, 지역별 거시 변수(N·E)의 궤적이 **정의된 상한 오차 안**에서 닮는다 — "거시가 미시를 예측한다"의
   측정. 오차 상한 자체가 튜닝 대상(첫 구현은 관대하게, 예: 장기 시뮬 후 E 상대 오차 ≤ 20%).
5. **정체성 연속**: 관측 밖에 나갔다 돌아온 개체는 **같은 개체**다 — id·seq·위치·size·소유가 유지되고
   잔고만 군집 흐름만큼 변한다.
6. **소유 예외 불변**: 소유 생명체(아바타)는 여전히 절대 동면하지 않는다(0016 그대로).

## 설계 — 코드 앵커와 함께

결선 지점 (`server/game.js`):

- `#dormant(cre)` — 동면 판정: `!cre.owner && !#regionActive(cre.x, cre.y)`. 유지(0016 그대로).
- `#refreshActiveRegions()` — 틱 맨 앞에서 관측 지역 합집합 갱신. 유지.
- `dormantClusters()` — **step 1**: 동면 개체의 지역별 군집 집계 {n·e·s·creatures(seq 순)}, 순수 읽기.
  라이브는 `index.js` 가 이따금 `[동면 군집]` 로그로 노출(관전 채널).
- `#metabolizeCreatures()` — 활성 대사. `if (this.#dormant(cre)) continue;` 로 동면 개체를 건너뛰는 것은
  유지 — 대신 아래 군집 패스가 그들의 에너지를 흐르게 한다.
- `#lowresDormant()` — **step 2**: 군집 갈구·생사·대사(위 "군집 패스" 절). `tick()` 에서
  `#metabolizeCreatures()` 직후, `gateByObservation && tickCount % DORMANT_LOWRES_INTERVAL_TICKS === 0`
  일 때 돈다 — 활성 개체 대사와 같은 국면에서 세계 에너지를 다툰다. 게이트 OFF 면 무동작(규칙 검증
  테스트는 전 세계 시뮬 그대로 — 0016 과 같은 결).
- 상수는 `shared/constants.js`: 기존 `CREATURE_FORAGE_RATE`=5 · `CREATURE_BASAL_COST`=3 ·
  `CREATURE_DEATH_THRESHOLD`=60 을 그대로 쓰고(같은 물리), 신설 `DORMANT_LOWRES_INTERVAL_TICKS`=32
  (확산 주기의 배수). 결정론에 영향을 주는 시뮬 상수이므로 CVar 아니라 헤더 상수(루트 컨벤션).

### 군집 패스 — `server/game.js #lowresDormant()` (step 2 에서 구현)

`DORMANT_LOWRES_INTERVAL_TICKS`(=32, `shared/constants.js`) 마다, `gateByObservation` 일 때만, `tick()` 의
활성 대사 직후에 돈다:

1. **군집 집계** — `dormantClusters()`(step 1) 재사용: 동면 개체를 지역별 {n·e·s·creatures(seq 순)} 로 버킷.
   집계 순회는 O(동면 개체 수)지만 상태 없음·단순 — 개체별 매 틱 3이체 대비 여전히 헐하다.
2. **군집 갈구** — 같은 복셀(materialKey)에 선 개체들의 수요(`FORAGE_RATE×size×K` 합)를 국소장 공급과
   **한 번에** 대조하고 size 비례로 배분(D-5). 공급=수요면 몫이 정확히 개체 수요와 같고(정수), 부족하면
   모두가 제 비율로 굶는다 — 내림 잔여(≤개체 수−1 양자)는 국소장에 남아 확산한다. 용량 초과분은
   transfer 클램프로 국소장에 남는다.
3. **생사판정** — 갈구 후에도 잔고 < `DEATH_THRESHOLD×size` 면 `#killCreature`(기존 분해 경로 재사용 —
   죽음 규칙을 복제하지 않는다. 잔해 결정은 다음 틱 탈구체화로 국소장에 녹는다).
4. **군집 대사** — `BASAL×size×K` 를 SINK 로.

전부 `ledger.transfer`(클램프) → 보존 자명. rng 미사용·seq 오름차순 → 결정론(관측 조건부, 0016 과 동일).
활성 대사와 갈구→생사→대사 순서까지 같다 — **같은 문법, 다른 층위**(systems.pdf 6칸 템플릿의 "명사만 바뀐다").

### 설계 결정 (step 2 에서 확정)

backlog 의 원 질문 "능동 섬의 '에너지로만'을 어디까지 허용할지(정체성 연속성과의 균형)"를 구체 결정으로 쪼개
다음과 같이 확정했다:

- **D-1. 시간 스케일 = 시간 등가** — 갱신량에 배수 K=interval 을 곱해 활성 시뮬과 같은 속도로 흐른다.
  존재/관측 분리가 깔끔(관측이 물리 상수를 바꾸지 않는다). "곰의 겨울잠" 서사(진짜 느린 대사)가 필요해지면
  `DORMANT_RATE_SCALE < 1` 상수 하나로 후퇴 가능. 관측 밖 대량 아사 우려는 라이브 재가열(`index.js`,
  서식지·소유 개체 기준)이 완충한다 — 문제가 실측되면 그때 조정.
- **D-2. 동면 중 죽음 = 허용** — 아사는 분해(결정+국소장)라 보존이 지켜지고, "관측 없는 질서는 흩어진다"
  (0016 창발)와 정합. 금지(잔고 바닥 동결)는 보존 하 무한 연명 = 공짜 질서라 기각. 소유 예외는 논외(애초에
  동면 안 함).
- **D-3. 성장 = 보류(정지 유지)** — 성장은 이력 의존(연속 흑자 카운트)이라 거시화 시 왜곡이 크고, size
  변화는 군집 집계를 바꿔 순환 의존이 생긴다. 후속 step 여지.
- **D-4. 배분 시점 = eager** — 군집 계산 직후 개체 잔고에 즉시 배분. 회계 단순·개체 풀 항상 진실(체크섬·
  스냅샷·죽음 판정 보정 불요). 이체 건수 O(동면 개체 수)/저해상도틱이지만 느린 주기(1/K)라 상한은 지킨다.
  기각한 대안 *lazy*(지역 군집 풀에 총량만 두고 재관측 순간 배분 — 진짜 O(지역 수), "관측자가 해석한다"의
  문자 그대로)는 개체 잔고를 읽는 모든 곳에 "군집 몫 포함" 보정이 필요해 회계가 복잡 — 부하가 실측으로
  문제일 때 step 을 나눠 간다. (명제의 "관측자는 해석할 뿐"은 eager 에서도 성립 — 배분 규칙이 결정론적
  해석 함수다.)
- **D-5. 배분 규칙 = size 비례(내림), 잔여는 국소장 잔류** — 활성 갈구(size 비례)와 같은 문법. 내림 잔여
  (≤개체 수−1 양자)는 억지로 재배분하지 않고 국소장에 남아 확산한다 — 정수·클램프·rng 금지.

### 검토한 다른 방법

| 방법 | 판단 |
|---|---|
| **군집 통계 갱신** (채택) | RG 정당화 그대로 — 관련 변수(E·N)만 굴리고 세부는 배분 규칙(해석)에 맡긴다. 기존 원장·죽음 경로 재사용 |
| 완전 정지 유지 (현행) | 값싸지만 시간 정지의 비대칭(위 "왜") — 이 feature 가 고치려는 것 |
| 개체 시뮬을 느린 주기로 | 부하가 여전히 O(동면 개체 수)×(모든 규칙) — 접는 게 없다. 거시 층의 이점(예측 가능·통계 노출)도 없음 |
| 생명체도 에너지로 환원(결정처럼) | 정체성 파괴 — 0016 이 명시적으로 기각한 경계("나갔다 온 봇이 딴 봇"). 불변 원칙 ② 위반 |
| 확률적 군집 모델(출생·사망률 rng) | 확산 결정론(시드 rng 규약)과 충돌 위험 + 검증(재현) 어려움 — 정수·클램프·결정론 문법을 벗어난다 |
