# feature-0002 — 에너지는 전부 정수다

> 상태: 🟢 검증됨 (상시 재현) · 작업 방식: [CLAUDE.md](../CLAUDE.md)

## 명제

에너지는 전부 정수다 — 부동소수 에너지는 존재하지 않는다. 원장·tx 스트림·화면 어디에도 소수점 에너지가 나타나지 않는다.

## 최종 목적 (측정 가능)

**어떤 시퀀스를 거쳐도 모든 풀 잔고가 정수이고, 비정수 이체는 원장이 기각한다.**

- 측정량: 모든 `pool.balance` 에 대해 `Number.isInteger(balance) === true`. 반례 개수 = 0.
- 비정수 `want` 를 넣은 `transfer` 는 **0 을 반환**하고 잔고를 바꾸지 않는다.

## 접근 — 정수성을 "검사"가 아니라 "관문"으로 강제

소수가 생긴 뒤 잡지 않는다. 소수가 **원장에 들어오지 못하게** 유일한 관문에서 막는다.

- `shared/ledger.js` `transfer()` 가드: `!Number.isInteger(want)` 면 즉시 0 반환 — 비정수는 이체 자체가 불성립.
- 에너지를 만드는 모든 산식은 정수 양자화: 이동 비용 `moveCost = floor(거리/보폭)`(실수 거리·잔여를 정수 비용으로), 상수(`WORLD_SOURCE_INITIAL`·`SPAWN_GRANT`…)는 전부 정수 리터럴.
- 부동소수는 **결정론에 못 쓴다**(플랫폼별 반올림 차이) — 이 관문이 재현성의 전제이기도 하다.

## step 로그

| step | 한 일 | 검증 |
|---|---|---|
| 1 | 최소 코어 정수성 명문화·회귀 고정 — `ledger.transfer` 비정수 기각 + `moveCost` floor 양자화를 테스트로 못박음(코드 변경 없음, 이미 구조적으로 성립). | `npm test` — `test/integer.test.js` 4종(비정수 기각·이동비용 정수·상수 정수·시퀀스 후 전 풀 정수) |

## 검증 (항상 가능)

```bash
npm test        # test/integer.test.js
./run.sh 8      # 라이브 — 봇/뷰어의 에너지·tx 값이 전부 정수(소수점 없음)
```

- **자동**: `test/integer.test.js` 가 (a) 소수 `want` 이체 기각(잔고 불변) (b) 임의 실수 거리에서도 `moveCost` 가 정수 (c) 창세·스폰 상수 정수 (d) 접속·이동 폭풍 후 전 풀 잔고가 정수임을 단언.
- **직관**: 브라우저 뷰어의 에너지 바·tx 스트림, 봇 요약의 `E####` — 어디에도 소수점이 없다. 사람이 한눈에 "정수뿐"임을 본다.
- **강제 지점**: `shared/ledger.js` `transfer()` — 비정수는 관문을 통과하지 못한다.
