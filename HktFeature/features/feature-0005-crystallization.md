# feature-0005 — 결정화: 에너지는 응집되어 정적인 형태(결정)가 된다

> 상태: 🟡 진행 중 (roadmap 확정 · step 1 예정) · 작업 방식: [CLAUDE.md](../CLAUDE.md)

## 명제

에너지는 **결정화**된다 — 공간에 흩어져 있는 국소장(중등급)이 국소적으로 과포화되면 그 일부가 **정적 저엔트로피 형태(결정 `I:<id>`)** 로 동결한다. 결정은 스스로 에너지 질서를 *능동적으로 유지하지 않는다*(일하지 않는다) — 잠긴 국소 최소점에 수동으로 갇혀 있을 뿐이다. 그래서 **정적**이며, 엔트로픽 확산·복사에 **면역**이다(가만두면 잔고가 변하지 않는다). 얼마나 응집했는가(응집량)와 무엇과 반응하는가(반응 상대)에 따라 채집물·장착 아이템·기체/액체/고체 같은 **복합적 세계**를 표현한다 — 현실의 화학반응과 같은 결이다.

## 저엔트로피의 두 전략 — 결정은 生命의 대척점 (feature-0004 정합)

feature-0004 는 세계를 **열린 흐름 + 등급**으로 세웠다: `태양(고) → 생명 → 국소장(중, 확산) → 심우주(저, 손실)`. 국소장은 *무질서한 중등급*이라 스스로 이웃으로 새고(diffuse) 심우주로 복사(radiate)된다. 결정은 이 엔트로픽 흐름에 **저항하는 반대 극**이다. 엔트로피의 조류에 맞서는 저엔트로피 섬에는 두 종류가 있다:

| | 질서 유지 방식 | 성질 | 엔트로픽 흐름 |
|---|---|---|---|
| **생명** | **능동** — 에너지를 계속 써서 응집 유지(이동·활동) | 動的 | 활동분을 국소장으로 소산 |
| **결정 `I:<id>`** | **동결** — 잠긴 국소 최소점에 수동으로 갇힘, 일 안 함 | **靜的** | **확산·복사에 면역** |
| 국소장 `M:<voxel>` | 무질서 | 흩어짐 | 확산·복사에 지배 |

즉 **"정적인 이유"가 곧 검증 명제**가 된다 — 결정은 능동적으로 질서를 유지하지 않기에 스스로 자라지도 못하지만, 동결된 최소점이라 **확산·복사 틱을 아무리 돌려도 잔고가 불변**이다. 반면 같은 자리 국소장은 계속 샌다. 비전문가도 한눈에 본다: *결정 잔고 = 수평선, 국소장 = 심우주로 흘러내리는 곡선.*

## 최종 목적 (측정 가능)

1. **정적성(면역)**: 결정 `I:<id>` 의 잔고는 확산·복사 틱을 N회 돌려도 불변이다. 반면 같은 위치의 국소장은 감소한다(심우주로 복사·이웃으로 확산).
2. **과포화 핵생성**: 국소장 농도가 임계(포화)를 넘을 때만 결정이 석출된다. 결정 총량은 농도(과포화도)에 통계적으로 비례하고, 석출은 **자기 제한**이다(장을 포화까지 끌어내리면 멈춘다 — 현실의 침전 평형). 희귀도 = 열역학적 improbability(에너지가 국소에 쌓인 저엔트로피 요동 자체가 드문 사건).
3. **상호작용(채집·용해)**: 생명이 결정과 근접하면 정적 질서가 풀린다 — 결정 → 생명(채집) 또는 결정 → 국소장(용해).
4. **반응(화학)**: 두 결정(또는 결정+생명)이 만나면 규칙에 따라 에너지가 재분배/방출된다 — 결합(더 큰 결정)·분해(국소장으로 방출). 조합 → 결정론적 산물 + 방출량, 보존 유지.
5. **물질 상태(gas/liquid/solid)**: 응집도(결합 에너지 밀도)로 상태를 라벨링한다 — 낮으면 기체(국소장에 가까움), 중간 액체, 높으면 고체(결정). 임계를 넘으면 상전이(석출↔용해)한다.
6. **결정론 + 보존 불변**: 같은 시드·이벤트열이면 결정 배치·잔고가 비트 단위로 동일하고, 위 어떤 흐름에도 전 풀 합계 = 10⁹ (feature-0001 회귀).

## 원장 매핑 — 보존은 공짜로 유지된다

- **결정 풀**: `I:<id>` — 에너지를 쥔 풀. 국소장(`M:`)과 달리 확산·복사 순회 대상이 **아니므로** 면역은 코드가 아니라 *루프 대상에서 빠지는 것*으로 자연히 성립한다.
- **결정화(석출)**: `국소장 → 결정` 이체, `cause: 'crystallize'`. 과포화(농도 > 포화 임계) 시 초과분의 일부가 결정으로 옮겨진다 → 자기 제한.
- **강제 지점**: 모든 흐름이 `ledger.transfer` 관문을 지난다 → 전 풀 합 = 10⁹ 는 얹어도 깨지지 않는다.
- **동기화 등급(단계적)**: step 1 은 결정을 `region=null` 서버 내부 풀 + **읽기 전용 스냅샷 방송**(`CRYSTAL`, FIELD 와 같은 성격)으로 둔다 — 공간 미러링·체크섬 편입은 상호작용이 필요한 step 2 에서 `region=key` 로 승격한다.

## step 로드맵 (점진 구축 — 한 step = 한 커밋)

| step | 목표 | 핵심 | 검증 |
|---|---|---|---|
| **1** | **결정 코어 (정적성 + 과포화 핵생성)** | `I:<voxel>` 풀(내부, 확산·복사 면역) · 과포화 석출(국소장→결정, 자기 제한) · `CRYSTAL` 방송 + 뷰어 이산 결정 마커 | `crystal.test.js` — 정적성(면역)·임계(과포화에서만)·자기 제한·결정론·보존(다섯 곳 합 = 10⁹) + 뷰어(국소장 뜨거운 복셀에 결정이 맺히고, 국소장은 새어도 결정은 그대로) |
| 2 | **상호작용 (채집·용해)** | 생명 근접 시 결정 → 생명(채집) / 결정 → 국소장(용해). 결정을 `region=key` 로 승격해 체크섬·ENTER·미러에 편입 | 근접 채집 이체·미러 정합·보존 |
| 3 | **반응 (화학)** | 결정에 조성/이력을 부여, 조합 규칙 → 결합(큰 결정)·분해(국소장 방출) + 방출량 | 특정 조합 → 결정론적 산물·방출·보존 |
| 4 | **물질 상태 (gas/liquid/solid)** | 응집도(결합 에너지 밀도) 구간 → 상태 라벨 + 상전이(석출↔용해 임계) | 응집도별 상태 라벨·상전이 관측 |

> **범위 원칙**: 각 step 은 *직관적으로 검증 가능*할 때만 닫는다(CLAUDE.md 불변 원칙). step 1 은 상호작용·반응·상태를 포함하지 않는다 — "정적 저엔트로피 형태가 과포화에서 맺히고 가만두면 불변"이라는 가장 좁고 한눈에 갈리는 핵심만 세운다.

## feature-0004 와의 정합

feature-0004 의 예정 step 3(재응집·재료·아이템·`I:<id>` 결정화)를 **이 feature 로 이관**한다. feature-0004 는 *엔트로픽 조류*(확산·복사, step 1~2 검증됨)에서 닫고, *조류에 맞서 맺히는 질서 섬*(결정화)은 feature-0005 가 맡는다 — 개념이 깔끔하게 갈린다.
