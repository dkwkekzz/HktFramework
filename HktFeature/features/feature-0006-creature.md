# feature-0006 — 생명체: 스스로 에너지 질서를 유지한다

> 상태: 🟡 진행 중 (step 1 검증됨) · 성장·아이템·발산·죽음의 반응은 후속 · 작업 방식: [CLAUDE.md](../CLAUDE.md)

## 명제

생명체(creature)는 **능동적 저엔트로피 섬**이다. 스스로 에너지 질서를 유지한다 — 살아있음 자체가 비용이라(물질대사) **지속해서 에너지를 소모하며 무언가를 해야 하고**, 그 비용을 대기 위해 **세계로부터 에너지를 갈구**하고, 내부 에너지의 질서를 유지하면서 세계를 살아간다. **유지를 못하게 되면 죽는다.** 이 갈구하고 질서를 유지하는 과정을 게임 컨텐츠로 해석한다 — 이것이 공격하고 스킬을 쓰며 스탯이 올라가는 과정이 되고, 아이템(에너지의 결정체)을 획득해 이 과정을 증폭시킨다. 생명체가 파괴되면 그 에너지는 결정체로 나타나거나 주변 에너지와 결합해 반응하며 복합체를 더 풍성하게 한다.

## 생명 = 세 번째 저엔트로피 전략 (feature-0004·0005 정합)

feature-0004 는 세계를 **열린 흐름 + 등급**으로 세웠다: `태양(고) → 국소장(중, 확산) → 심우주(저, 손실)`. feature-0005 는 그 조류에 맞서 **동결로** 질서를 지키는 정적 섬(결정)을 세웠다. 생명체는 세 번째 극이다 — **능동적으로 에너지를 써서** 질서를 지킨다:

| | 질서 유지 방식 | 성질 | 엔트로픽 흐름 |
|---|---|---|---|
| 결정 `I:<id>` | **동결** — 잠긴 최소점에 수동으로 갇힘, 일 안 함 | 靜的 | 확산·복사에 **면역** |
| **생명체 `C:<id>`** | **능동** — 계속 에너지를 써서 질서를 유지(대사) + 세계에서 보충(갈구) | **動的** | 대사분을 심우주로 **export** |
| 국소장 `M:<voxel>` | 무질서 | 흩어짐 | 확산·복사에 지배 |

이것이 **dissipative structure**(Prigogine) 다: 저엔트로피 섬은 **기울기 에너지를 제 몸으로 통과시키고 엔트로피를 밖으로 버려야만** 존재한다. 그래서 생명체는 자기 폐기물(대사분)을 재섭취할 수 없고(심우주로 새 나감), **끊임없이 세계로부터 갈구해야만** 산다. 결정은 가만두면 영원하지만 생명체는 갈구를 멈추면 죽는다 — **"정적 vs 동적"이 곧 검증 명제**가 된다.

> **feature-0005 표 정련**: feature-0005 는 생명의 활동분을 "국소장으로 소산"이라 적었다. 이를 정련한다 — 생명의 *지속적 질서 유지 비용*(basal metabolism)은 되돌아오지 않는 손실(심우주 export)이고, *죽음*(구조 붕괴)의 잔해만 국소장·결정으로 국소 산란한다. 플레이어 *이동* 소산은 여전히 국소장으로(feature-0004 불변). 이 구분이 "왜 생명체는 세계로부터 갈구해야만 하는가"를 명료히 한다.

## 최종 목적 (측정 가능)

1. **물질대사 = 지속 소모**: 생명체는 매 대사 틱 basal 을 심우주로 방출한다(SINK 단조 증가 — feature-0004 화살 유지). 갈구 없이는 잔고가 basal/틱씩 줄어 **유한·예측된 틱 안에** 최소 예비 아래로 떨어져 죽는다.
2. **갈구 = 세계로부터 흡수**: 그 자리 국소장에 에너지가 있으면 생명체가 흡수해(field→creature) 내부 질서를 보충한다.
3. **항상성(생존 ↔ 아사)**: forage ≥ metabolism 인 **풍요로운 국소장** → 생명체는 오래 산다(잔고가 용량 근처에서 안정). **고갈된 국소장** → 굶어 죽는다. 이 둘이 한눈에 갈린다 — 항상성이 곧 검증 명제.
4. **죽음의 분해**: 굶어 죽으면 잔해가 결정(“파괴되면 결정체가 나타난다”)+국소장(거름)으로 흩어진다(feature-0005 죽음 경로 공유).
5. **결정론 + 보존 불변**: 같은 시드·배치·이벤트열이면 생명체 잔고/생사가 비트 단위로 동일하고, 위 어떤 흐름에도 전 풀 합계 = 10⁹ (feature-0001 회귀).

## 원장 매핑 — 보존은 공짜로 유지된다

- **생명체 풀**: `C:<seq>` — 위치를 가진 **개별** discrete 객체(잔고는 원장 풀에). 확산·복사·석출 순회 밖이라 오직 대사 루프만이 잔고를 움직인다. region=null(step 1) → 읽기 전용 스냅샷 방송(`CREATURE`, CRYSTAL 과 같은 성격).
- **흐름** (전부 `ledger.transfer` 관문 통과 → 보존·정수 강제):
  - **스폰**: `SOURCE → 생명체` (`spawn`). 저엔트로피 주입 — feature-0003(태양 = 유일 원점).
  - **갈구**: `국소장 → 생명체` (`forage`). 세계의 흩어진 에너지를 흡수(무음 내부 이체).
  - **물질대사**: `생명체 → 심우주` (`metabolize`). 살아있음의 엔트로피 세금 = 되돌아오지 않는 손실(무음 내부 이체).
  - **죽음**: `생명체 → 결정 + 국소장` (`crystallize` + `death`, feature-0005 `#decompose` 공유 — 근처 플레이어 시야에 방송).
- **강제 지점**: 모든 흐름이 `ledger.transfer` 를 지난다 → 전 풀 합 = 10⁹ 는 얹어도 깨지지 않는다.
- **결정론**: 대사·갈구는 순수 클램프 이체(rng 미사용) → 확산 rng 스트림을 건드리지 않는다. 죽음의 종 추첨만 `crystalRng`(분리된 스트림).

### 구현 요지 (튜닝 근거)

- **대사는 심우주로, 죽음은 국소장·결정으로**: 지속적 질서 유지 비용(basal)을 심우주(되돌아오지 않는 손실)로 보낸 것이 핵심이다 — 이래야 생명체가 자기 폐기물을 재섭취하지 못해 **세계로부터 갈구할 수밖에** 없고(dissipative structure), 아사가 `잔고/basal` 로 깔끔히 예측돼 한눈에 검증된다. 죽음의 잔해만 국소장·결정으로 국소 산란한다(feature-0005 정합).
- **임계 > 0 = 잔해가 남는다**: `DEATH_THRESHOLD=60` 을 0 위에 둬 굶어 죽을 때 ~예비만큼 에너지가 남아 결정으로 응결한다("파괴되면 결정체가 나타난다"). 에너지를 지닌 채 죽으면(전투·강탈, 후속 step) 더 풍성한 드랍이 된다 — 같은 분해 경로, 남은 양만 다르다.
- **라이브 먹이 웅덩이는 진입점 전용**: 봇은 유한한 이동 에너지원(수입 없음)이라 세계엔 지속 influx 가 없다 — 창세 그대로면 생명체는 곧 굶는다. 그래서 `index.js` 에서만 생명체 자리에 국소장 웅덩이를 한 번 부어(SOURCE→국소장, 보존·창세 0 불변) 갈구할 세계를 준다. 자동 테스트는 이 시딩을 직접 제어해 풍요/고갈을 재현한다 — 둘 다 같은 규칙.
