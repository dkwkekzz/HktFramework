# feature-0003 — 태양(SOURCE)은 세계의 유일한 에너지 원점이다

> 상태: 🟢 검증됨 (상시 재현) · 작업 방식: [CLAUDE.md](../CLAUDE.md)

## 명제

태양(SOURCE)은 세계의 유일한 에너지 원점이다. 창세에 전 에너지가 태양에 있고, 태양만이 저엔트로피 에너지를 세계로 내보낸다(스폰). 에너지는 새로 생성되지 않으며, 어떤 에너지도 태양으로 다시 들어오지 않는다 — 세계의 모든 흐름은 태양에서 나온 에너지의 재분배일 뿐이다.

## 최종 목적 (측정 가능)

**태양은 순수한 원천이다 — 태양으로 *들어오는* 이체는 하나도 없고, 태양 잔고는 스폰으로만 줄어든다.**

- 창세: `태양 잔고 = 창세 총량 = 10⁹`.
- 유일 방출구: `SOURCE → player`(스폰)만이 태양에서 에너지를 꺼낸다.
- 태양은 마르지만(스폰마다 감소) 방대하여 실용적으로 고갈되지 않는다 — 이 "영원한 태양"이 세계가 허용하는 유일한 비물리 가정이다(그 뒤의 흐름은 전부 물리, feature-0004).

## 접근 — "생성"이 아니라 "원점"으로

에너지를 만드는 코드는 없다. 창세에 전 에너지를 단일 태양 풀(`W:SRC`)에 적립하고, 이후 모든 규칙은 그 총량의 재분배(이체)로만 기술한다.

- 창세: `ledger.createPool(W:SRC, 10⁹)`. 세계의 에너지는 여기서 출발한다.
- 스폰만이 인출: `SOURCE → player` 는 태양이 에너지를 세계로 내보내는 유일한 경로.
- 태양은 받지 않는다: 소산·죽음·확산·복사(feature-0004)는 태양을 거치지 않는다. 흩어진 에너지는 국소장·심우주로 가지 태양으로 되돌아오지 않는다.

## step 로그

| step | 한 일 | 검증 |
|---|---|---|
| 1 | 태양(`W:SRC`)에 창세 총량 적립 + 스폰(`SOURCE→player`)을 유일한 방출구로 확립. | `test/game.test.js` — 스폰이 `SOURCE→player` 이체이고 태양 잔고가 `10⁹−스폰` 임을 단언 |
| 2 | 태양을 순수 원천으로 확정 — 소산·죽음이 국소장으로 가고 태양은 에너지를 받지 않는다(feature-0004). | `test/thermo.test.js` — 죽음·이동이 태양이 아닌 국소장으로, 태양은 죽음 에너지를 받지 않음을 단언 |

## 검증 (항상 가능)

```bash
npm test        # game.test.js(스폰=SOURCE→player) · thermo.test.js(태양은 받지 않는다)
./run.sh 8      # 라이브 — [원장]·뷰어의 태양 잔고가 스폰만큼만 줄고 그 외엔 불변
```

- **자동**: `game.test.js` 가 스폰 = `SOURCE→player` 인출임을, `thermo.test.js` 가 죽음·소산이 태양이 아닌 국소장으로 흩어지고 태양이 그 에너지를 받지 않음을 단언한다.
- **직관**: 봇/뷰어의 `☀ 태양 N` 값이 스폰 수에 따라서만 줄고(8봇 = 10⁹−8×스폰), 이동·죽음으로는 변하지 않는다 — 태양이 유일한 방출구임을 눈으로 본다.
- **강제 지점**: 태양을 목적지로 하는 이체가 코드 어디에도 없다 — 태양은 구조적으로 순수 원천이다.
