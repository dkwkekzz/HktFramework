# feature-0008 — 발산·행동: 생명체가 에너지를 발산해 다른 생명을 포식한다(전투)

> 상태: 🟢 검증됨 (step 1~2) · 아이템 효과는 **획득(feature-0014)+공명(feature-0015)** 으로 분리 · 작업 방식: [CLAUDE.md](../CLAUDE.md)
> 배경: feature-0006(생명체 자기유지)에서 갈구·질서 유지를 **게임 컨텐츠(공격·스킬)** 로 해석하는 트랙. "이것이 공격하고 스킬을 사용하며 스탯이 올라가는 과정이 될 것이다".

## 명제

생명체는 내부 에너지를 **폭발적으로 발산**하여 행동한다 — 근접한 다른 생명체를 공격해 그 에너지를 **강탈**한다(전투). forage(국소장)·harvest(결정)가 *가만히 있는 저장고*를 그냥 줍는 것이라면, 강탈은 **자기를 지키고 있는(방어력이 있는) 다른 생명체**에서 뜯어내는 세 번째 free energy 수입이다. 상대에게 **방어력**이 있으니 (1) 먼저 그 방어를 깨는 값을 치러야 하고(**발산 비용** → 열/심우주), (2) 방어를 깨서 쏟아진 에너지도 전부는 못 챙긴다(**효율<1**, 나머지는 국소장으로 흩어짐). 그래서 "채집"이 아니라 "전투"로 보인다 — 상대에게 방어력이 있어서일 뿐, 물리적으로는 **포식(predation)** 이다. **방어가 약한(작은) 개체를 방어가 센(큰) 개체가 사냥하는 포식 위계가 창발**하고, 뜯겨 죽은 자는 방어력을 잃고 결정을 남겨 생태 루프를 심화한다.

## 왜 결정은 "줍고" 생명은 "싸워야" 하나 — 답은 **방어력**이다

한 문장으로: **결정은 방어력이 0, 살아있는 생명은 방어력이 있다.** 그래서 결정은 다가가면 그냥 흡수(채집)되고, 생명은 뚫어야(전투) 뺏을 수 있다.

- **방어력이 뭔데?** = **"살아있다"는 것 그 자체**다. 살아있음 = 제 몸(질서)이 흩어지지 않게 **끊임없이 붙잡고 있음**(feature-0006 대사). 그 붙잡는 힘이 곧 방어력이다. 죽으면 붙잡기를 멈추고 → 방어력 0 → 결정이 되어 그냥 채집 대상이 된다.
- **국소장·결정 = 방어력 0.** 가만히 있는 저장고(퍼진 에너지·얼어붙은 덩어리·사체). 아무도 안 지키니 다가가면 그냥 흘러든다 — **줍기**(공짜).
- **살아있는 생명 = 방어력 있음.** 지키고 있으니 뺏으려면 **뚫어야** 한다 — **전투**. 뚫는 데엔 두 대가가 붙는다:
  - **① 뚫는 값** — 상대 방어를 깨는 일. 되돌아오지 않는 열로 나간다(발산 비용 → 심우주).
  - **② 새는 값** — 방어를 깨서 쏟아진 에너지도 **전부는 못 챙긴다**(효율<1). 못 챙긴 건 국소장으로 흩어진다.

즉 **전투 = 내 공격력(발산 파워) vs 상대 방어력(살아서 지키는 힘)**. 공격력이 방어를 이겨야 뜯고, 이겨도 손에 남는 건 뺏은 것보다 적다.

### 이 한 줄이 게임 규칙 셋을 저절로 만든다

| 방어력에서 나오는 것 | 게임에서 보이는 모습 |
|---|---|
| 방어를 뚫어도 새는 값(효율<1) | **얻는 것 < 뺏는 것** — 무한히 살쪄서 커지지 못한다(생태학 ~10% 법칙, 먹이사슬 상한) |
| 방어력 = 크기(size) 에 비례 | **큰 놈은 못 뚫는다** → 방어 약한(작은) 먹이만 사냥 → **포식 위계** 창발 |
| 죽으면 방어력 0 | **산 먹이는 뜯고(강탈), 사체는 줍는다(채집)** — 같은 놈도 죽는 순간 줍기 대상이 됨 |

두 흡수(채집·강탈)를 "다 같은 채집"으로 뭉치면 이 셋이 전부 사라진다 — 그래서 가른다.

### 분리선은 "결정이냐 생명이냐"가 아니라 "방어력이 있냐 없냐"다

앞선 질문("결정이든 생명이든 에너지 가져오는 건 똑같지 않나?")의 답이 여기 있다: **맞다, 명사로는 같다. 다른 건 방어력이다.** `I:`(결정)·`C:`(생명체)는 이 세계가 방어력 유무를 표시한 *현재의 이름표*일 뿐, 진짜 기준은 **"지금 자기를 지키고 있는가(=저항하는가)"**다. 증거 둘:

- **같은 물질이 선을 넘는다**: 생명체가 죽으면 결정이 된다(`#decompose`). 살아있을 땐 방어력이 있어 **강탈**해야 하고(비싸고 손실적 = 산 먹이 사냥), 죽어 방어력이 0이 되면 **채집**으로 값싸게 줍는다(사체 청소). 대상의 종류가 아니라 **지금 지키느냐**가 회계를 가른다.
- **반례가 경계를 조인다**: 그래서 "결정이라고 다 줍는 대상"은 아니다 — feature-0009/0013 의 **과충전 결정 자폭**은 결정인데 *능동적으로 터진다*(제 에너지를 스스로 방출). 이건 강탈(줍기)이 아니라 **물질의 폭발**(feature-0013 규칙 D) 몫이다. **판정은 언제나 이름이 아니라 "지금 제 질서를 지키/터뜨리는가"로 한다**(불변 원칙 ②).

> **물리적 정체(한 줄)**: 여기서 "방어력=살아서 지키는 힘"의 정체는, 생명이 대사로 자유에너지를 끊임없이 흘려보내며 2법칙에 맞서 제 질서를 유지하는 **비평형 소산구조**(Prigogine)라는 것이다. 뚫는 값·새는 값(효율<1)은 그 질서를 깨는 일과, 깨서 풀려난 에너지를 다 못 잡는 2법칙에서 나온다 — 이것이 생태학 ~10% 법칙의 바탕이다.

## 최종 목적 (측정 가능)

1. **강탈**: 사거리(`ATTACK_RADIUS`) 안 공격은 먹이→포식자로 에너지를 옮긴다(먹이↓·포식자↑).
2. **발산 비용 = 엔트로피 화살**: 공격은 포식자 에너지를 소모해 심우주로 방출한다(SINK 단조 증가). 대상이 없으면 발산하지 않는다.
3. **손실적(효율<1)**: 포식자가 **얻는 것 < 먹이가 잃는 것** — 나머지는 국소장으로 흩어진다(세계로 방출). 2법칙·10% 법칙의 결.
4. **포식 창발 (방어력 위계)**: **방어가 센(큰) 개체가 방어가 약한(작은) 개체를 사냥한다**(size< 규칙 = 방어력 크기 순, 강자→약자 일방). 방어력이 곧 크기라 성장(0006/0007)이 포식자가 되는 전제 — 한눈에 갈리는 위계.
5. **전투사 → 생태 루프**: 뜯겨 예비 아래로 떨어진 먹이는 죽어 결정을 남긴다(feature-0005/0006 `#decompose` 공유) → 다른 생명이 채집(0007).
6. **결정론 + 보존 불변**: 같은 배치·이벤트열이면 전투 결과가 비트 단위로 동일하고, 전 풀 합계 = 10⁹.

## 원장 매핑 — 새 풀 없음, 생명체 간 엣지만 추가

한 번의 공격(포식자 A → 먹이 V)은 **세 갈래 이체**로 회계된다(전부 `ledger.transfer` 관문 → 보존·정수 자동):

- **① 발산 비용 (방어 뚫는 값)**: `A → SINK` (`burst`) = 상대 방어(질서)를 깨는 일. `ATTACK_COST×A.size + CREATURE_DEFENSE×prey.size` — 기본 발산 + **상대 방어력만큼** 더(step2). 되돌아오지 않는 열(엔트로피 화살).
- **② 상대 질서 붕괴**: `damage = min(ATTACK_POWER×size, V잔고)` 만큼 풀려난다.
- **③ 손실적 회수**: `damage` 중 **효율%** 만 `V → A` (`attack`, 강탈, 용량 클램프), 못 붙잡은 나머지는 `V → 국소장` (`attack`, 흩어짐). 효율 = `CAPTURE_PCT` + **무기 공명**(feature-0015, 소유 아이템이 있으면 흩어질 몫을 더 붙잡음 — 아이템 무소모). 공명 없으면 기본 효율.

**포식 규칙**: 각 생명체는 사거리 안에서 **자기보다 작은(`size <`)** 잔고 있는 가장 가까운 먹이 하나를 친다(강자→약자, 상호 교착 없음). **결정론**: seq 오름차순 순회 + 순수 클램프(rng 미사용) → 확산·성장 결정론 불변. 새 풀·새 상태 없이 **생명체 간 상호작용 엣지**만 얹는다. `#combat()` 은 대사(`#metabolizeCreatures`) 앞에서 돈다 — 이번 틱에 뜯긴 먹이가 곧이어 대사 순환에서 예비 아래로 떨어지면 죽어 분해된다(전투사 → 결정).

>
> **경계 — 강탈(수입) vs 방출(파괴)은 다른 원리**: 이 feature 는 **커플링된 손실적 포획(수입 스펙트럼의 끝: forage→harvest→강탈)** 만 담는다. 표적을 먹지 않고 **파괴만** 하는 발산(파이어볼·범위·원거리 = 표적 에너지를 캐스터가 아니라 세계/심우주로 흩어버림, 순수 지출)은 흐름의 위상이 근본적으로 다르므로 **[feature-0009](feature-0009-discharge-destruction.md)** 로 분리한다.

### 구현 요지 (튜닝 근거)

- **강탈은 반드시 손실적**: `victim→attacker` 100% 이동은 너무 깔끔해 비물리적이다 — 남의 질서를 부수며 그 에너지를 전부 회수하면 2법칙 위반. `CAPTURE_PCT<100` 으로 **얻는 것 < 뺏는 것**을 강제하고 나머지를 국소장으로 흘려, 포식이 세계를 먹이면서도(생태 되먹임) 무한 성장은 못 하게 했다(먹이사슬 상한).
- **발산 비용은 심우주로**: 질서를 깨는 일(cost)을 SINK(되돌아오지 않는 열)로 보낸 것이 핵심 — 대사(basal)와 같은 결이라 "공격엔 진짜 대가가 있다"가 SINK 단조 증가로 한눈에 검증되고, 굶주린 개체는 발산할 예비가 없어 사냥을 못 한다(예비 가드).
- **size< 포식 규칙**: 상호 교착(동급 난투 → 동반 자멸)을 피하고 **성장→포식** 위계를 명확히 했다. size 1 은 사냥을 못 하니 forage·harvest 로 먼저 커야 포식자가 된다 — feature-0006(성장)·0007(채집)이 0008(포식)의 전제가 되어 트랙이 자연히 이어진다.
- **방어력 = 뚫는 값(수입 아님)**: 상대 방어력은 damage 를 깎거나 회수를 줄이는 게 아니라 **뚫는 값(SINK 로 나가는 열)** 을 키운다 — "살아서 지키는 힘을 부수는 데 진짜 에너지가 든다"가 SINK 로 정직하게 드러난다(대사·발산 비용과 같은 결). 회수(capture)를 건드리지 않아 "공격력=붙잡는 이득 / 방어력=뚫는 비용"이 깔끔히 갈리고, 순이득이 늘 양이라 포식은 유지되되 방어 센 상대는 값이 덜 남는다(먹이사슬 상한과 같은 방향).
- **아이템 효과는 강탈에 하드코딩하지 않는다 (교훈)**: "무기 강탈 증폭"을 곁 결정 소모(`W→A`)로 세웠던 것은 소화를 무기로 위장한 개념 오류였다. 아이템을 *지니는 것*(소유)과 지닌 것이 *힘을 내는 것*(공명)은 강탈과 다른 주체·사건이므로 별도 feature 로 갈랐다(불변 원칙 ②). `#strike` 는 공명 효율만 읽어 쓴다 — 아이템 획득·소유·소모 여부는 feature-0014/0015 의 몫.
