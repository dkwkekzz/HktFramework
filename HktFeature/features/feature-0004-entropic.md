# feature-0004 — 엔트로픽: 에너지는 높은 확률로 흩어질 뿐, 세계는 평형으로 향한다

> 상태: 🟢 검증됨 (step 1~2) · 재응집·결정화는 [feature-0005](feature-0005-crystallization.md) 로 이관 · 작업 방식: [CLAUDE.md](../CLAUDE.md)

## 명제

에너지의 흐름은 물리학의 법칙(엔트로피 제2법칙)을 참고한다. 에너지는 강제로 이동하지 않는다 — **엔트로픽 법칙에 따라 높은 확률로 흩어질 뿐**이다. 개별 이체는 확률적이되(오르막도 가능), 앙상블은 압도적으로 고농도→저농도(down-gradient)이며, 세계는 평형(최대 엔트로피 = 균일)으로 향한다. 되돌아오지 않는 손실(복사)이 있어 엔트로피는 단조 증가한다(시간의 화살).

## 최종 목적 (측정 가능)

1. **결정론**: 같은 시드·이벤트열이면 확산 결과가 비트 단위로 동일하다(재현 가능).
2. **엔트로픽 편향**: 이웃 국소장 사이 이체 방향 확률은 `concFrom/(concFrom+concTo)` — 고농도일수록 나갈 확률↑, 농도가 같으면 1/2(순 흐름 0 = 평형).
3. **평형 수렴**: 한 곳에 몰린 국소장은 확산으로 균일해진다 — 스프레드(최대−최소)가 급감한다.
4. **엔트로피의 화살**: 심우주(SINK)는 **단조 증가**한다(복사는 되돌아오지 않는다).
5. **보존은 불변**: 위 어떤 흐름에도 전 풀 합계 = 10⁹ (feature-0001 회귀).

## 접근 — 결정론 규칙을 확률 과정으로, 에너지를 "등급"으로

엔트로피는 양이 아니라 **품질/등급**의 문제다. 에너지를 세 등급으로 흐르게 한다:

| 등급 | 정체 | 풀 | 재응집 |
|---|---|---|---|
| 고 (저엔트로피) | 태양 — 영원한 저엔트로피 원천(스폰으로만 방출) | `W:SRC` | 원천 |
| **중** | **국소장 — 흩어진 에너지가 국소에 쌓인 것(거름·재료의 씨앗)** | **`M:<voxel>`** (3D 복셀) | ✅ (채집·제작·섭취는 후속 step) |
| 저 (고엔트로피) | 심우주 — 복사로 새어나간 진짜 손실 | `W:SINK` | ❌ 손실 |

흐름(전부 `ledger.transfer` 관문 통과 → 보존·정수 강제):
- **스폰**: `태양 → 생명` (저엔트로피 주입).
- **이동/죽음 = 소산**: `생명 → "그 자리" 국소장`. 활동 에너지·응집 소멸분이 국소로 흩어진다.
- **엔트로픽 확산(핵심 법칙)**: `국소장 ↔ 이웃 국소장`. 시드 동전이 방향을 정하되 **높은 확률로 down-gradient** → 균일로 수렴.
- **복사(엔트로피 세금)**: `국소장 → 심우주`. 아주 작은 일부가 영영 손실(단조 증가). 정수 유지를 위해 확률 반올림(기대율 = 잔고/`RADIATE_DIVISOR`).

## 열린 흐름 — 죽음은 태양이 아니라 국소장으로

세계의 흐름은 **열린 흐름**이다: `태양 → 생명 → 국소장 → 심우주`. 죽음/소산은 태양으로 되돌아가지 않는다 — 시체의 응집이 풀리면 에너지는 *주변으로 흩어져 국소적으로 재응집(거름·광물·재료)* 하므로, 그 자리 국소장으로 간다.

> **feature-0005 정합**: 죽음은 이제 두 갈래로 분해된다 — 단단한 잔해는 그 자리에 **결정으로 응결**(개별·종을 가진 채집물), 무른 조직은 국소장으로 흩어진다. 즉 죽음은 `생명 → 결정 + 국소장`. 국소장 갈래는 위 서술 그대로다. 상세는 [feature-0005](feature-0005-crystallization.md).

영속은 태양의 방대함이 주는 *실용적 영속*이다 — 심우주(SINK)의 단조 증가(엔트로피의 화살)는 실재한다. 세계가 허용하는 비물리 가정은 "영원한 태양"([feature-0003](feature-0003-energy-source.md)) 하나뿐이고, 그 뒤의 흐름(확산·죽음·재응집·손실)은 전부 물리다.

### 이관·후속

- **재응집(재료·아이템) → [feature-0005](feature-0005-crystallization.md) 로 이관**: 국소장에서 에너지를 끌어올려 이산 아이템 `I:<id>` 로 결정화하는 재응집(희귀도 = 열역학적 improbability)은 별도 feature 로 분리했다. 0004 는 *엔트로픽 조류*(확산·복사)에서 닫고, *조류에 맞서 맺히는 질서 섬*(결정화)은 0005 가 맡는다.
- **(선택) 국소장 체크섬 편입**: 국소장은 읽기 전용 스냅샷으로 동기화된다(무결성은 보존·정수 관문이 보장). 필요해지면 `region=key` 로 올려 체크섬 격자에 편입할 수 있다.

## 검증 (항상 가능)

```bash
npm test        # test/thermo.test.js (엔트로픽 5종) + game.test.js (소산→국소장)
./run.sh 6      # 라이브 — [원장] 줄의 국소장이 차오르고 심우주가 단조 증가(↑)
```

- **자동**: `test/thermo.test.js` 가 (a) 창세 국소장·심우주 0 (b) 죽음·이동이 태양 아닌 국소장으로 (c) `entropicOutProb` 편향 + 몰린 장이 확산으로 균일 수렴(스프레드 급감) (d) 같은 시드 → 비트 동일 (e) 심우주 단조 증가·네 등급 합 = 10⁹ 를 단언.
- **직관**: 봇/뷰어의 `태양 · 국소장 · 심우주(↑)` — 이동하면 국소장이 차오르고, 심우주가 결코 줄지 않고 오른다(엔트로피의 화살). 라이브 실측: 총 10⁹ 불변, 태양 999,998,200(=10⁹−6×스폰), 국소장 상승, 심우주 1↑, 체크섬 OK.
- **강제 지점**: 확산·복사·소산 모두 `ledger.transfer` 를 지난다 — 보존·정수는 관문의 성질이라 엔트로피를 얹어도 깨지지 않는다.
