# feature-0013 — 물질 속성·자극·상태전이: 물질은 속성에 따라 자극에 반응해 상태가 전이한다

> 상태: 🟡 진행 중 (규칙 A·B·C·D 검증됨: 연소·용해·파괴·폭발+자폭) · feature-0005(결정) 위에 얹음 · 작업 방식: [CLAUDE.md](../CLAUDE.md)
> 정합: **폭발(규칙 D)** 은 물질의 사건 — feature-0009(생명체의 발산=파이어볼 생성)가 만든 투사체의 착탄, 그리고 **과충전 결정의 자폭**(생명 무관)이 같은 규칙으로 터진다. "발산(생명)≠폭발(물질)"을 주체로 가른다(CLAUDE.md 불변 원칙 ②).

## 명제

결정(물질)은 단일 종(species) 정수를 넘어 **계층화된 속성**을 가진다. 세계는 **자극**(열·물리력·전기·부식)을 방출·전달하고, 각 물질은 제 속성에 따라 그 자극에 **반응**하며, 동적 상태가 **임계**를 넘으면 **상태가 전이**한다(연소·용해·파괴 …). 온도·내구도 같은 동적 상태는 전부 **에너지로 환원**된다 — 자극 = 에너지 이체, 온도 = 결정에 실린 열(heat) 에너지, 내구도 = 결정 잔고. 그래서 보존 10⁹을 유지한 채, **소수의 보편 규칙에서 수백 가지 상호작용이 창발**한다(불이 번지고, 얼음이 녹고, 바위가 부서진다).

## 왜 에너지 환원인가 (프로젝트 불변 원칙 정합)

이 프로젝트의 뿌리는 **에너지 보존(10⁹) + 직관적 검증**이다(CLAUDE.md). 온도·내구도를 *보존과 무관한 마법의 숫자*로 두면 두 뿌리가 흔들린다. 대신 **에너지로 환원**하면:

- **보존이 공짜다** — 모든 자극·상태전이가 `ledger.transfer` 관문을 지나므로 전 풀 합계는 얹어도 깨지지 않는다.
- **눈으로 검증된다** — "불이 결정에서 결정으로 번진다"가 원장 이체로 드러난다: 뜨거운 결정이 이웃을 데우고, 흡수한 열이 발화점을 넘으면 그 이웃이 점화되어 스스로 타며 다음을 데운다. 비전문가도 한눈에 본다.
- **하나의 세계관** — feature-0004~0012 가 이미 "모든 것은 에너지의 흐름"으로 서 있다(태양·국소장·생명·결정). 온도=열, 내구도=응집 에너지로 두면 새 물질 규칙이 그 세계관에 매끄럽게 얹힌다.

> 비에너지 동적 상태(젖음·오염 등)는 feature-0006 의 `size`·`growth` 처럼 **순수 상태 변수**(보존 무관)로 둘 수 있다 — 후속 step. 에너지 효과만 원장을 지난다.

## 세 기둥 → 에너지 매핑

| 기둥 | 사용자 모델 | 에너지 환원 (이 feature) |
|---|---|---|
| **① 속성 계층** | 정적 태그 · 임계 · 동적 상태 | 태그·임계 = **종별 상수 테이블**(데이터 주도) · 동적 상태 = 에너지(**온도=heat, 내구도=잔고**) + 비에너지 상태(젖음·오염=순수 스탯, 후속) |
| **② 자극·매개체** | 열·물리력·전기·부식을 방출/전달 | 자극 = **에너지 이체**(열원→표적 heat) · 매개체 = **국소장 확산(=열전도)** + 전도체 태그 배율 |
| **③ 상태전이 규칙엔진** | 임계 넘으면 결과 | **보편 규칙**: `동적상태 ≥ 임계 (+태그) → 에너지 재분배 + 상태 변경`. 연소·용해·파괴 |

## ① 속성 계층 (데이터 주도)

- **정적 태그(Static Tags)**: 종별 비트집합 — `고체·금속·유기물·가연성·전도체·자성체` …. 상수 테이블(종→태그). 복잡한 연산 전에 **반응 여부를 빠르게 거른다**(가연성 아닌 결정은 연소 규칙을 아예 건너뜀).
- **임계 데이터(Thresholds)**: 종별 상수 — `발화점`(heat 임계) · `녹는점`(heat 임계) · `파괴강도`(물리력 임계) · `인장강도`. 데이터 테이블.
- **동적 상태(Dynamic States)**: `온도` = 결정에 실린 heat(에너지, 원장 추적) · `내구도` = 결정 잔고(기존 `I:` 풀) · (후속) `젖음·오염` = 순수 스탯.

## ② 자극·매개체 분리

- **자극(Stimulus) = 에너지 이체.** 열원 결정은 반경 안 표적의 heat 로 에너지를 방출한다(불 → 나무). 표적은 제 태그에 따라 흡수(가연성이면 온도↑). **물리력**은 강탈(0008)·방출(0009)의 damage 가 곧 물리력 자극 — 파괴강도를 넘으면 파쇄. 전기·부식은 후속.
- **매개체(Medium) = 국소장.** 국소장 확산(feature-0004)이 곧 **열전도** — 뜨거운 자리의 heat 가 이웃으로 번진다. 전도체 태그는 전달 배율을 키운다(후속).
- **핵심**: 불과 나무의 상호작용을 짜지 않는다. `불 = 반경 안 heat 방출 객체`, `나무 = heat 흡수 → 온도↑ → 발화점 넘으면 스스로 방출` 만 정의하면, 둘의 만남은 규칙엔진에서 **창발**한다.

## ③ 상태전이 규칙엔진 (보편 규칙)

규칙 = `조건(동적상태 ≥ 임계 [+태그]) → 결과(에너지 재분배 + 상태 변경)`. 엔진은 매 틱 각 결정에 적용 가능한 규칙을 실행한다. **개방형**(데이터/레지스트리로 규칙을 얹는다 — feature-0011 `registerDesire` 와 같은 결).

- **규칙 A (연소)**: `온도 ≥ 발화점 & 가연성` → `Burning` 부여 → 매틱 내구도(잔고) 일부를 heat 로 전환해 ① 이웃(반경 안 결정 heat) ② 국소장(연기) ③ 심우주(복사 손실)로 방출 → 이웃 온도↑ → **연쇄 점화**. 내구도 0 → 전소(소멸).
- **규칙 B (상전이/용해)**: `온도 ≥ 녹는점` → 고체 태그 해제 → 결정 잔고를 국소장으로 **용해**(feature-0005 step5 흡수) → 액체 밴드 편입(feature-0005 step4). 임계 아래로 식으면 재석출(가역).
- **규칙 C (파괴)**: `단일 판정 물리력 ≥ 파괴강도` → 내구도를 **파편(debris) 결정들 + 국소장**으로 분해. 강탈/방출 damage 가 트리거. 못 넘으면 흠집만.
- **규칙 D (폭발/detonation)**: **농축 에너지 덩어리**(파이어볼·**과충전 결정**·후속 시한 폭탄)가 저장 질서를 **순간에** 방출한다. 트리거는 둘 — 생명체가 쏜 파이어볼의 착탄(feature-0009), 그리고 **임계 에너지 밀도 초과**(`CRYSTAL_DETONATE_THRESHOLD`)로 자연 결정이 불안정해진 **자폭**(생명 무관, 아무도 안 건드려도 터진다 = 폭발의 주인이 물질임을 증명). 자폭은 blind AoE(크기 안 가리고 반경 내 모든 생명을 침) — 발산의 size≥ 분업과 다르다. 안정 물질(재료 raw·산물 crafted)은 임계를 넘어도 면역(반응 면역과 같은 정합). 연소(A)가 에너지 물질의 *느린* 발열 분해라면, 폭발은 *격렬한* 극단 — **같은 규칙엔진 계열이되 방출이 압력파로 반경에 전파**하는 점이 새롭다(연소·용해·파괴는 국소, 폭발은 원거리). 폭발파는 착탄점 둘레(`DISCHARGE_BLAST_RADIUS`)에 두 자극을 침착하고, 각 물질은 제 속성대로 반응한다: **열복사**(반경 내 결정 heat 에 열 침착 → 규칙 A·B 가 가연성=연소·비가연성=용해로 가름)·**압력**(물리력 → 규칙 C 로 취성 결정 파괴). 반경 내 생명(size≥ 캐스터)엔 거리 감쇠 damage(표적 질서→세계, 완전 연소). **주체는 물질이다**(생명 무관 — 폭탄·결정도 터진다) — 생명체의 *발산*(파이어볼 생성)은 [feature-0009](feature-0009-discharge-destruction.md)가 맡고, 이 규칙은 그 결과물이 *터지는* 사건만 맡는다. 불속성은 폭발 '전부'가 아니라 열 채널 하나의 증폭원(연쇄 발화=sympathetic detonation)일 뿐이다.

## 최종 목적 (측정 가능)

1. **자극 전달 보존**: 열원→표적 heat 이체는 정확히 이체량만 옮긴다(방출 = 흡수 + 손실, 총합 불변).
2. **연소 연쇄**: 가연성 결정 열에서 한쪽을 점화하면 발화점을 넘는 순서로 이웃이 점화되고, 각 결정은 내구도가 소진되며 전소한다 — **눈으로 불이 번진다**. 총 방출 heat = 소진된 내구도 합(보존).
3. **상전이**: 온도가 녹는점을 넘으면 고체 태그가 풀리고 결정→국소장 용해. 임계 아래로 식으면 재석출(가역).
4. **파괴**: 물리력이 파괴강도를 넘는 타격은 결정을 파편으로 분해(잔고 = 파편합 + 국소장, 보존). 못 넘으면 흠집만.
5. **데이터 주도**: 태그·임계·규칙은 상수 테이블/레지스트리로 정의되고, 새 물질/규칙은 **데이터만 얹어 엔진 무수정 실행**(개방 재증명).
6. **결정론 + 보존 불변**: 같은 시드·이벤트열이면 비트 동일, 전 풀 합 = 10⁹ (feature-0001 회귀).

## step 1 상세 설계 — 연소(불 번짐)

**데이터(상수 테이블)**
- `MATERIAL_TAGS[species]` — 종별 정적 태그 집합. step 1 은 `FLAMMABLE`(가연성)만 쓴다. 유기물 종을 가연성으로 표시.
- `IGNITION_HEAT[species]` — 발화점(heat 임계). 가연성 종만 유의미.
- 시뮬 상수: `BURN_RATE`(매틱 heat 로 전환하는 내구도, ×?) · `BURN_EMIT_RADIUS`(연소열 전파 반경) · `BURN_TO_NEIGHBOR_PCT`/`BURN_TO_SINK_PCT`(방출 heat 의 이웃/심우주 분배; 나머지는 국소장=연기) · `HEAT_COOL_DIVISOR`(온도의 자연 냉각=heat→국소장/심우주 소산, 가역·자기 제한).

**온도(heat) 저장 — 보존 유지**
- 각 결정에 결부된 **heat 를 원장이 추적**한다(온도 = 흡수한 열 에너지). 두 가지 구현 후보 중 하나로 확정(구현 시):
  - (a) 결정별 heat 풀(예: `H:<seq>`) — 온도가 결정마다 독립. 사용자 모델("나무 자신의 온도")에 가장 충실. 보존 카테고리 하나 추가.
  - (b) 국소장 복셀의 heat 성분을 온도로 사용 — 확산이 곧 열전도라 매개체가 공짜. 코어 최소. 온도가 복셀 단위(≈리전).
- 권고: 사용자 모델 충실도를 위해 **(a) 결정별 heat**, 단 열 *전파*는 반경(BURN_EMIT_RADIUS) 방출 + 국소장 확산을 겸용. 보존 readout 에 `열` 카테고리를 더한다(총합 10⁹ 불변).

**틱 루프(규칙엔진, 확산·결정화 뒤)**
1. **자극 흡수/전도**: 열원(예: 라이브 진입점이 SOURCE→heat 로 점화, 또는 Burning 결정의 방출)이 반경 안 결정 heat 로 이체.
2. **규칙 A 판정**: 각 결정에 대해 `heat ≥ IGNITION_HEAT[species] & FLAMMABLE` 이면 `burning=true`.
3. **연소 실행**: 각 `burning` 결정은 `BURN_RATE` 만큼 내구도(잔고)를 heat 로 전환해 반경 안 결정(BURN_TO_NEIGHBOR) + 국소장(연기) + 심우주(복사 손실)로 분배 → 이웃 온도↑(연쇄). 잔고 0 → 소멸(전소, 잔해 없음 — feature-0009 "완전 연소"와 결).
4. **냉각(가역)**: `burning` 아닌 결정의 heat 는 `HEAT_COOL_DIVISOR` 로 국소장/심우주로 서서히 소산 → 발화점 아래로 식으면 점화 안 됨(자기 제한).

**방송/뷰어**: `CRYSTAL` 스냅샷에 `heat`(또는 온도 비율)·`burning` 을 실어 뷰어가 결정을 **달아오름(주황→적열)**·불꽃으로 그린다(읽기 전용 표시값, FIELD 와 같은 성격).

**검증 (직관적)**
- 자동(`test/fire.test.js`): ① 자극 이체 보존 ② 발화점 미만 미점화·초과 점화 ③ 가연성 결정 3개 일렬 → 순차 점화(연쇄) ④ 전소로 소멸 + 총 방출 heat = 소진 내구도 ⑤ 비가연성 태그는 미점화(필터) ⑥ 결정론 ⑦ 전 풀 합 = 10⁹.
- 시각(`npm run shot`/데모): 가연성 결정 열을 놓고 한쪽 점화 → 불이 이웃으로 번지며 각 결정이 달아올라 전소하는 세 시점 캡처.
