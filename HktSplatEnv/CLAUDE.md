# CLAUDE.md — HktSplatEnv

정적 오픈월드를 3DGS(가우시안 스플랫)로 그려내는 **단독 프로젝트**. 무-빌드 웹(classic
`<script>` + Spark ESM), 주석 한국어. 현황·명제는 [STATE.md](STATE.md), 외부 개요·실행·검증은
[README.md](README.md).

이 문서는 **얇게** 유지한다 — 목표·불변 원칙·작업 방식만 담고 거의 바꾸지 않는다. 진행 현황과
논의한 feature 명제는 [STATE.md](STATE.md) 에 쌓는다.

## 목표

- **대규모 상용 오픈월드 MMORPG 급 퀄리티의 정적 대상**을 그린다 — 돌·나무·언덕·구름 등
  움직이지 않는 존재만. 캐릭터·생명(동적) 경로는 이 프로젝트 밖이다.
- **무한 스트리밍**을 전제로 한다 — 월드는 끝이 없고, 카메라 주변만 타일로 로드·해제된다.
  어떤 좌표에서 시작하든 같은 결과가 나와야 한다(결정론).

## 지켜야 할 사항

- **무대는 로드/생성한다** — 정적 대상은 렌더 속성(색·명암)을 절차 함수로 직접 생성해도 된다.
  지형·식생 명암은 생성 시 `f_dc`(SH DC) 에 굽는다. 이건 정적 무대의 원리이며, 동적 생명의
  "상태에서 유도" 규칙과는 별개다.
- **월드는 순수 함수** `world(x,z) → {height, biome}` — 타일은 그 함수를 들여다보는 창일 뿐이다.
  시드 + 월드 좌표만으로 어느 창이든 독립 생성하므로 창 경계 연속성이 자동 보장된다(봉합 코드
  불필요). 타일 이음새 = 전역 셀 격자 + 셀 내부 지터.
- **스폰 결정론** — 식생·개체 스폰은 좌표·시드 해시(`scatter.candidates`)로만 결정한다.
  `Math.random` 금지(스트리밍 연속성이 깨진다). 정적↔동적 승격 계약 상수는 `scatter.PROMOTE_CFG`
  단일 원본.
- **Spark(WebGL2) 전용** — 렌더러는 Spark 하나뿐이고 WebGPU·생명 경로는 없다. `vendor/spark/`
  (three r180 ESM)는 무대 렌더 전용이며 모듈 스코프로 격리한다 — 밖으로 three 객체를 내보내지
  않는다(노출 API 는 숫자/문자열/콜백뿐).
- **하드코딩 지양** — 매직 넘버·임계값은 상수/노브로 노출하되, 결정론에 영향을 주는 값(스폰
  해시·타일 격자)은 헤더 상수로 고정한다.

## 작업 방식

1. [STATE.md](STATE.md) 에서 현재 작업 상태와 다음 명제를 고른다.
2. 구현한다 — 위 「지켜야 할 사항」을 어기지 않는지 확인.

4. [STATE.md](STATE.md) 에 명제·상태를 갱신하고 커밋한다.
