# ROADMAP — 프로젝트 전체 작업 순서 (수정 가능)

> **이 문서 = "무엇을, 어떤 순서로"의 권위(ordering SSOT) — 프로젝트 전체.** 트랙별 step + 트랙 활성화 마일스톤(◆)을 한곳에서 본다.
> 새 세션은 *자기 트랙 섹션*을 위에서 아래로 읽어 **첫 미완료(☐)** 를 다음 step 으로 *자동 선택*한다(완료 판별 = 그 트랙 `STATE.md` §7 INDEX). 사용자가 매번 지정하지 않아도 된다.
> *왜*(존재론)는 [SPINE.md](SPINE.md) · 트랙별 현재 상세는 각 트랙 `STATE.md`. **계획은 살아있다** — 세계가 드러나며 재정렬·삽입·삭제 가능(한 step = 한 조각, 더 떠오르면 전가).

## 쓰기 규칙 (disjoint 유지)

- **각 트랙은 ROADMAP 의 *자기 섹션*만 갱신**한다(atom 섹션은 atom 세션이 ☐→☑). 섹션이 갈려 동시 세션도 충돌 없음.
- 트랙 활성화 마일스톤(◆)·전체 arc 는 프로젝트 차원 — 드물게 손본다.

## 트랙 활성화 순서

🟢 **atom**(지금) ──▶ ◆ **render**(0002 빛 뒤) ──▶ ◆ **net**(공유 세계 풍부해진 뒤). 게이트 상세는 [SPINE.md](SPINE.md) §7.

## atom 트랙 — 세계의 법칙  (현재 상세 [atom/STATE.md](atom/STATE.md))

### Phase A — 원자가 존재한다
- ☑ **0001** 자유 운동 + 공용 하네스 (원자가 존재·떠다님 / 보존·결정론 앵커)

### Phase B — 빛
- ☐ **0002** `emit` — 전자 들뜸→자발 방출, 광자 λ=hc/ΔE (스펙트럼선 창발). *ledger 에 들뜸·광자 에너지 가법.*
  - ◆ **마일스톤**: 0002 닫으면 **render 트랙 깨우기**("HGO render 트랙 시작") — 읽을 빛이 생김.

### Phase C — 화학
- ☐ **0003** `coulomb` — 전하 간 끌림/밀침 (첫 원자-원자 힘)
- ☐ **0004** `collide` — 충돌·운동E↔들뜸(여기·흡수)
- ☐ **0005** `bond` — 결합(이온·공유)→분자(연결 성분 *측정*, author 아님)

### Phase D — 핵
- ☐ **0006** `decay` — 핵 안정성·방사 붕괴(비가역 + 에너지)
- ☐ **0007** `fuse` — 융합·Δm→E (무거운 원소·별의 씨앗)

### Phase E — 별·순환
- ☐ **0008** `gravity` — 중력 모임 (원자 군집)
- ☐ **0009** `ignite` — 별 점화·핵합성
- ☐ **0010** `cycle` — 죽음·분산→다음 별 (척도 분리 순환 닫음 = self-running 세계)
  - ◆ **마일스톤**: 공유 세계가 충분히 풍부해지면 **net 트랙 깨우기**("HGO net 트랙 시작").
