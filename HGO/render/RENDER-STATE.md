## 1. NOW

- **닫힌 렌즈**: **렌즈-006 (L-bond)** — *원자가 분자로 묶인 걸 본다.* 게이트 해제: atom 트랙이 step-0010(bond, 이온결합 비탄성 포획)·step-0012(valence, 원자가 한계=\|전하\|→이량체)를 실어 스냅샷이 **결합 목록 `sim.bonds`**(=`[i,j]` 원자 인덱스 쌍, 연결 성분의 간선)을 내보낸다 → blocked 해제. 렌더가 그 결합쌍을 *읽어* **결합한 두 원자를 잇는 선**(분자 윤곽)으로: `bondSegment(bond,sim,cam)`(두 원자 투영 → 선분 {a,b}, 무효 인덱스/뒤쪽이면 null — 순수·헤드리스 검증) + `drawBonds` 가 구의 하층에 청백 구조선(원근 굵기). **결합 0이면 선 author 0**(격자처럼 무대 톤 — 시뮬 양 거짓 인코딩 안 함). 위치=두 원자의 sim (rx,ry,0) 그대로. (직전 **렌즈-005 L-recoil**: 운동량→빛 줄기 — 눈 검증 ⏳.)
- **한 줄 상태**: 결합 장면(step-0010~0012)에서 짝지은 원자들이 *선으로 이어져 분자(이량체)가 보인다* — 어느 원자가 결합인가는 시뮬이 측정한 sim.bonds 를 읽을 뿐(연성 author 0). 알리바이 성립(**atom/ diff 0** — diff 는 `render/`(engine·validate·RENDER) + `HGO/viewer.html`(범례 1줄)만).
- **다음**: §2 — 가능 정제 칸 소진. 남은 렌즈는 시뮬 선행 대기(온도/열=L-T, 결합 깸·도플러색, 전파 트레일).

## 2. NEXT

> 렌더는 시뮬과 직교 — 큰 호는 [RENDER.md](RENDER.md) §4 렌즈 로스터가 SSOT. 여기선 *다음 한 렌즈*만.

### 다음 렌즈 후보 (▶ 가능한 것만)

- **L-bond — ✅ 렌즈-006 닫힘**: 결합쌍 `sim.bonds`([i,j]) → 결합선(분자 윤곽). 후속 정제 여지: *분자(연결 성분)별 묶음 색·윤곽 채움*(연결 성분을 측정해 같은 분자를 한 덩이로) · 결합 차수/길이 표시 — 단, 시뮬이 그 양(결합 E 국소화·차수)을 내보낸 뒤.
- **L-recoil — ✅ 렌즈-005 닫힘**: 운동량(px,py) → 빛 줄기. 후속 정제 여지: *전파 트레일*(출생 rx0,ry0→현 위치 전체 자취 — 이미 데이터 있음, 광자 escape(step-0007)로 누적 유계) · 도플러 색이동 시각화.
- **L-line (정제) — ✅ 렌즈-004 닫힘**: 전이선별 빈도 집계 완료. 후속: 선폭(도플러/자연폭)·로그 세기축 — 시뮬이 그 양을 내보낸 뒤.
- **⛔ L-T (blocked)**: 흑체 온도색은 시뮬이 *열/온도*를 의미 있게 굴린 뒤(현재 자유 운동만 — 온도가 정적). 속도→색은 atom 뷰어가 이미 함; 렌더는 *방출색*에 집중.

> **게이트 규율**: 즉시 가능 정제 칸(L-line 빈도·L-recoil 방향·L-bond 결합)을 모두 소진. 남은 렌즈(L-T 온도, L-bond 분자 묶음색·결합 깸, L-recoil 트레일)는 *시뮬 선행*을 기다린다 — 근사 author 금지(RENDER §3). atom 트랙이 열·연결성분 색·결합 차수를 실으면 그때 깬다.

## 4. DURABLE CONSTRAINTS — 모든 렌즈가 지킬 정전 사실

- **시뮬 알리바이**: 렌더 diff 는 `render/`(+ 스킬)에만. `atom/` 비변경 → 골든 해시 비트 불변. 커밋 전 `git status` 확인.
- **author 0**: 색·이펙트는 시뮬 양의 함수일 뿐(RENDER §3). 종류별 색 박기·없는 분포 합성 금지.
- **정규화는 측정**: 화면 창(λ→nm·속도→hue)은 데이터에서 *잰* 범위로. 손으로 박은 임계 금지.
- **읽기 전용 로드**: atom 엔진은 `require`/`<script src=../atom/...>` 로 *읽기만*. 시뮬 객체(atoms·photons)에 렌더 필드 쓰지 않음(섬광 등은 렌더 전용 병렬 배열).
- **한 커밋 = 한 렌즈**: 더 떠올라도 다음 렌즈로 전가.
