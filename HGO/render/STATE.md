- **L-catalyst (▶ 즉시 가능·가장 오래된 잔여 flux 부채)**: flux 둘째 보존량 `p`(step-0010 arc E·κ 변조 촉매) → magnitude 글로우(measure 범위 정규화·L-glow/L-isotope 동형). p 가 q 의 교환률을 국소 변조하나 p 농도 자체는 색 채널 0(q 가 어디서 빨리 도는지는 보이나 촉매가 어디 있나는 미독). catalyst 장면(step-0010) 늘 실림·연속 읽기. atom/비촉매 flux 장면엔 p 없어 0(author 0).
- **L-flow — ✅ 렌즈-021 닫힘**: flux 셀 파동 운동량 `v`(=dq/dt 부호 스칼라·arc F step-0011 관성) → 발산 글로우(부호=톤 차오름 호박·빠짐 파랑·세기=|v|/max|v| 측정·L-ion 동형). 밝기(L-glow=q magnitude)는 진폭만 보여 마루(차오름)·골(빠짐)이 똑같던 것을 흐름 방향으로. **β붕괴 함정 재현**: L-voxel 게이트의 "L-velocity 로 파동 이미 보임"이 거짓(flux vx,vy=0·운동량은 스칼라 a.v) — 미검증 "이미 보임"으로 안 닫고 읽음. atom 장면엔 a.v 없어 0(author 0).
- **L-voxel — ✅ 렌즈-022 닫힘**: cell(공간 격자) → 복셀 큐브 밭 = 3D CA 외형(색조=q밴드 `c0`·밝기/불투명도=q magnitude 측정 범위 정규화 — 들뜬 cell 빛나는 큐브·평형 cell 투명한 빈 공간·flow 글로우 유지). 현 L-3d 음영 구 글리프 대신 큐브(`isCellGrid` 격자 측정 — 흩어진 원자는 구 유지·회귀 0). **게이트 충족**: flux 가 관성 파동으로 v·국소 에너지를 cell 에 실음(arc F step-0011·L-flow 로 확인). 사용자 지적("공 더미가 아니라 CA 셀 기준으로")이 계기. **불투명도는 *국소 에너지/|q편차|* 대신 *q magnitude 측정 범위 excitation*(L-glow 동형)으로 — 편차/maxDev 정규화는 평형 근방 잔차를 재증폭해 "평형 투명"과 충돌(L-glow DC 교훈), 측정 범위는 균일 필드(range 0)서 깔끔히 빈 공간**. 후속 여지: 큐브 면 컬링/인스턴싱 성능·고분자=큐브 사슬(원자 사슬 장면 생기면).
- **⛔ L-T (blocked)**: 운동 E(속도 *크기*) → 흑체 *온도색*. 시뮬이 온도/열을 의미 있게 굴린 뒤(현재 자유 운동만 — 온도 정적). 속도 *벡터*는 L-velocity 가 이미 읽음(운동 방향) — L-T 는 *열 의미화*(색)라 별개·여전히 대기.
- **⛔ L-nuc (blocked)**: 붕괴·융합 *순간* 섬광/입자 줄기. 시뮬이 *이벤트 신호*(변환 타임스탬프·방출 입자)를 내보낸 뒤. 현재 scene 불리언·nuc/lep 장부만 → glow author 금지.
- **L-core — ✅ 렌즈-020 닫힘**: 원자 구조 운명 `core`(1=결속 코어·0=분산 헤일로) → 점선 운명 테(measureCoreClasses 두 분류 공존·coreBound 결속/분산·결속 청록·분산 보라). atom-0100 재감사 신규 미독 per-atom 채널(c0 와 같은 류). Otsu 임계 결정(어느 원자를 남기나)을 보임. 한 분류만/core 없으면 테 0(author 0).
- **L-population — ✅ 렌즈-019 닫힘**: 원자 출신 집단 `c0`(어느 별/우물/세대 풀) → 배경 오라 골든각 그룹 색조(measurePopulations·populationHue·moleculeHue 동일 사상). atom-0100 재감사가 잡은 신규 미독 per-atom 채널(분자 색조 L-molecule 의 원자판). 단일 집단/c0 없으면 오라 0(author 0).
- *즉시-가능 잔여 0* — 신규 per-atom 키 c0(L-019)·core(L-020) 둘 다 해소. `seed`=RNG 메타·`rest0`=플래그·`nuc/lep`=장부(빛 아님)·결합 종류화=거리로 기하적 이미 보임·변환 토글=scene-static(타이밍 0). 새 즉시-가능 per-entity/전역 미독 시각 채널 없음(atom-0100 실 스냅샷 재감사 확인).
- **L-escape — ✅ 렌즈-018 닫힘**: 탈출 누적 `sim.escaped`({E,px,py,count}) → 좌상단 HUD 게이지(화살=net 운동량 방향·등방 고리=복사 탈출·개수·E). **실 스냅샷 재감사가 잡은 전역 누적 부채**(문서 §2 계약에 없던 양·핵 장면 step-0032~38). nuc/lep 장부와 달리 실제 방출 입자 → 광자 스펙트럼 띠처럼 집계 오버레이. 스칼라라 크기 정규화 없이 방향·개수·E 정확 읽기. L-nuc(변환 *순간 위치*)는 escaped 가 총합만이라 여전히 blocked.
- **L-velocity — ✅ 렌즈-017 닫힘**: 원자 속도 벡터 `vx,vy` → 운동 자취(photonStreak 동형·머리=현 위치·꼬리=−속도·길이 ∝ |v|/maxV·정지 0). 온도색(L-T)과 별 채널(운동 방향 vs 열 의미화). 광자 L-recoil 의 원자판.
- **L-scatter — ✅ 렌즈-016 닫힘**: 광자 산란 횟수 `nscatter` → 산란 흐림 헤일로(L-glow 동형·직진 0).
- **L-source — ✅ 렌즈-015 닫힘**: 광자 방출 원소 `srcZ` → 출처 고리 색조(L-element 동일 사상·단일 원소 0).
- **L-isotope — ✅ 렌즈-013 닫힘**: 중성자 수 `N`(동위원소) → 안쪽 동심 코어 밝기(측정 N 범위 정규화·중성자↑ 밝은 코어·단일 동위원소 코어 0). 크기(Z+N)와 직교. 계약 감사 마지막 즉시-가능 신규 채널 부채 해소.
- **L-ion — ✅ 렌즈-012 닫힘**: 전하 `Z−e`(이온화) → 구 테두리 고리(부호 발산·양이온 따뜻·음이온 차가움·중성 0·세기 |Q|/maxQ 측정). author 0(발산 정규화·중성 고리 0).
- **L-element — ✅ 렌즈-011 닫힘**: 원자 양성자 수 `Z`(원소) → 구 색조(측정 Z 범위 정규화·연속 사상). 핵 변환(decay·fuse, step-0031~38)이 Z 를 바꿔도 안 보이던 것을 색 이동으로 표시 — atoms 채널의 미사용 필드 Z 를 읽음. author 0(범위 정규화·단일 원소 무채색).
- **L-Ebond — ✅ 렌즈-010 닫힘**: 결합 E `sim.bonds[k][2]`=Eabs → 결합선 밝기 등급(maxE 정규화). bonds 채널 마지막 미사용 필드를 읽음 → atom-0034 까지 따라잡음. 후속 여지: 결합 길이(두 원자 측정 거리) → 굵기 — 즉시 가능(위치 읽기).
- **L-order — ✅ 렌즈-009 닫힘**: 결합 차수 `sim.bonds[k][3]` → 평행선 수(단일·이중·삼중). 게이트(step-0018 bondOrder) 충족돼 깸.
- **L-bond — ✅ 렌즈-006 닫힘**: 결합쌍 `sim.bonds`([i,j]) → 결합선(분자 윤곽). 후속 정제 여지: *분자(연결 성분)별 묶음 색·윤곽 채움*(연결 성분을 측정해 같은 분자를 한 덩이로) — 즉시 가능(연결 성분은 bonds 간선의 측정·읽기).
- **⛔ L-nuc (blocked)**: 붕괴·융합 *순간* 플래시/입자 줄기는 시뮬이 *이벤트 신호*(변환 타임스탬프·방출 입자)를 내보낸 뒤. 현재 scene 불리언 `decayActive`/`fuseActive`·per-atom `nuc`/`lep`(보존 장부, 빛 아님)만 → glow author 금지. 변환 *결과*(원소 바뀜)는 이제 **L-element(렌즈-011)가 Z→색으로 표시** — *순간*(섬광)만 신호 대기.
- **L-glow — ✅ 렌즈-008 닫힘**: 들뜸 준위 x → 등급 광원 밝기. 미사용 계약 채널(§2 "들뜸 x=밝기")을 불리언→등급으로 정제. 후속 여지: *방출 직전 충전 펄스*(준위 상승 애니메이션 — 시뮬이 준위 전이 타임스탬프를 내보낸 뒤).
- **L-trail — ✅ 렌즈-007 닫힘**: 출생→현재 실변위 자취. 후속 정제 여지: *도플러 색이동*(접근/후퇴 광자 λ 이동 — 시뮬이 광원 속도를 광자 λ 에 실은 뒤) · 시간 적분 잔광(누적 프레임 페이드).
- **L-recoil — ✅ 렌즈-005 닫힘**: 운동량(px,py) → 빛 줄기 글리프(정규화 방향 지시자). L-trail(007)이 실거리 자취로 보완.
- **L-line (정제) — ✅ 렌즈-004 닫힘**: 전이선별 빈도 집계 완료. 후속: 선폭(도플러/자연폭)·로그 세기축 — 시뮬이 그 양을 내보낸 뒤.
- **⛔ L-T (blocked)**: 흑체 온도색은 시뮬이 *열/온도*를 의미 있게 굴린 뒤(현재 자유 운동만 — 온도가 정적). 속도→색은 atom 뷰어가 이미 함; 렌더는 *방출색*에 집중.

> **게이트 규율**: 렌즈-009(L-order)·010(L-Ebond)이 bonds 채널의 미사용 필드(차수 bond[3]·E bond[2])를 모두 읽어 **render 가 atom-0034 까지 따라잡음** — 현재 렌더 가능한 모든 방출 채널 소진. *즉시 가능 잔여 칸*: 연결 성분 묶음색·결합 길이(이미 실린 위치/간선의 읽기). 남은 *시뮬 선행* 렌즈(L-T 온도, L-nuc 변환 이벤트, 도플러색)는 그 신호를 실을 때까지 비워 둔다 — 근사 author 금지(RENDER §3). 핵 변환(0031~34)의 *결과*는 위치·질량 채널로 이미 표시, *순간*만 대기.

## 4. DURABLE CONSTRAINTS — 모든 렌즈가 지킬 정전 사실

- **시뮬 알리바이**: 렌더 diff 는 `render/`(+ 스킬)에만. `atom/` 비변경 → 골든 해시 비트 불변. 커밋 전 `git status` 확인.
- **author 0**: 색·이펙트는 시뮬 양의 함수일 뿐(RENDER §3). 종류별 색 박기·없는 분포 합성 금지.
- **정규화는 측정**: 화면 창(λ→nm·속도→hue)은 데이터에서 *잰* 범위로. 손으로 박은 임계 금지.
- **읽기 전용 로드**: atom 엔진은 `require`/`<script src=../atom/...>` 로 *읽기만*. 시뮬 객체(atoms·photons)에 렌더 필드 쓰지 않음(섬광 등은 렌더 전용 병렬 배열).
- **한 커밋 = 한 렌즈**: 더 떠올라도 다음 렌즈로 전가.
