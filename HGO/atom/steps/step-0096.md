# step-0096 — 이봉 골 자동 임계 Otsu (기운 이봉서 코어 보존)

> 한 조각: 새 게이트 `disperseAutoOtsu` — disperse 의 코어/겉 자동 경계를 q-분위수(0087) 대신 Otsu(class-간 분산 최대)로 *두 모드 사이 골*에 박는다. 0087 의 한계(q-분위수는 *모집단 비율 50/50 가정* → 기운 이봉서 경계가 코어 안에 박혀 코어 침식)를 해소. 기운 이봉(다수 코어 + 소수 겉)서 median 코어 R_g 37.5(침식) ≫ Otsu 4.43(보존). disperseAutoOtsu=0 → q-분위수·회귀 0.

## 무엇을 더했나 (게이트 `disperseAutoOtsu` + `otsuThreshold` 헬퍼)

`otsuThreshold(vals)` — 정수 deg 분포의 이봉 골을 class-간 분산 최대로 찾는다:

- 각 후보 임계 t(deg≤t = 겉·deg>t = 코어)서 두 class 의 가중치 w0·w1·평균 μ0·μ1 → σ²_b = w0·w1·(μ0−μ1)².
- σ²_b 최대인 t = *두 모드 사이 골*. 정수 히스토그램 1패스 O(range).
- **모집단 비율 가정 0**: q-분위수(0087)는 분포를 *비율*로 자른다(중앙값=50/50) → 기운 분포서 경계가 한 모드 안에 박힘. Otsu 는 *값의 골*로 자른다 → 비율 무관.

**게이트**: disperseAutoOtsu=0 → 0087 q-분위수 경로(else 분기 = 옛 코드 그대로·비트 동일·회귀 0). 1 → Otsu.

## 한계 (정직)

- **단봉/평탄 분포서 Otsu 임의성**: deg 가 단봉(골 없음)이거나 평탄하면 Otsu 골이 모호 — class-간 분산이 평평해 경계가 흔들릴 수 있다(이봉일 때만 robust). 단봉서는 q-분위수가 외려 안전(분포 모양 판별 후 선택은 미).
- **deg 가 진짜 코어/겉을 대표한다는 가정**: 국소 이웃 수(coolR)가 밀도 대리 — 다중 스케일 구조(코어 안 부코어)는 단일 Otsu 임계로 못 가름(다단 임계 미).
- **정적 무대 측정**: 중력 0 으로 임계 효과를 격리했다 — 진화하는 별(밀도 분포가 시간에 따라 변형)서 Otsu 가 골을 *매 tick 추종*하는지는 0087 동적 무대 + Otsu 결합으로 별도 확인.

## 쉽게 풀어 쓴 설명

별이 무거운 원소를 *코어에 보존*하면서 *겉껍질만 별풍으로 날리려면*, "어디까지가 코어이고 어디부터가 겉인가"의 경계를 잘 정해야 한다. 지난 step(0087)에서는 밀도 순으로 줄 세워 *중간(중앙값)*을 경계로 삼았다. 그런데 이건 "코어와 겉이 반반"이라고 가정한 셈이다.

문제: 코어가 *훨씬 많고*(150개) 겉이 *적으면*(50개), 중앙값(100번째)은 *코어 한가운데*에 떨어진다 — 그러면 코어의 절반을 "겉"으로 잘못 분류해 날려버린다(코어 침식). 측정해 보니 중앙값 방식은 코어 크기(R_g)가 4.43에서 **37.5로 폭발**했다 — 코어가 부서진 것이다.

이번엔 **Otsu** 방식을 썼다 — 비율을 가정하지 않고, 밀도 분포에서 *두 봉우리 사이의 골짜기*를 직접 찾는다. 결과: 코어 R_g가 **4.43 그대로** 유지됐다(코어 보존). 그러면서도 겉껍질은 R_g 44.84로 멀리 날아갔다(별풍은 유지) — 코어 보존과 겉 별풍을 동시에 해냈다. 운동량·에너지 정확 보존, 끄면 옛 방식 그대로(골든 480/480).
