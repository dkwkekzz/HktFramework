# step-0022 — 보편 파울리 반발 (중성 포함 excluded-volume — 중성 등속운동 해소)

> 새 법칙 `pauli`(게이트 `kPauli`) — *모든 쌍*(전하 게이트 없음)에 단거리 반발 U=kP/(r²+ε²)²(force ∝ 1/r⁶). coulomb·repulse 가 하전 쌍만 작용해 중성 원자가 등속 직진하던 것을 해소 — 중성 원자도 접촉서 밀어내 *겹침 방지·소프트 충돌*. 장면: `step-0022` ([viewer.html#step-0022](../viewer.html#step-0022)). 검증: `node engine/verify.js step-0022`.

| 원자 요건 (SPINE §3) | 이 step | 상태 |
|---|---|---|
| 4 위치·운동 | 중성 원자가 *부피*를 가짐 — 등속 직진 대신 접촉서 튕김·편향(소프트 충돌) | 🟡 |
| 2 에너지·흐름 | 보편 반발 PE 항 — 모든 쌍의 excluded-volume 위치 에너지(KE↔PE 연속) | 🟡 |

## 0. 쉽게 풀어 쓴 설명

**이 단계가 답한 질문**(= 이 세션 내내 짚은 "원자가 등속운동만 한다"의 핵심): "step-0019 쿨롱·step-0020 반발 코어는 *전하를 가진* 원자에만 작용했다. 그래서 **중성 원자**(전자 수 = 양성자 수, q=0)는 서로를 *전혀 못 보고* 직선으로 등속 직진했다 — 심지어 서로 겹쳐 통과했다. 어떻게 중성 원자도 서로 부딪히게(자연스럽게 움직이게) 하나?"

**핵심 아이디어 — 부피는 전하와 무관하다**: 원자가 서로 못 뚫는 이유는 전하가 아니라 **파울리 배타**(전자 구름이 겹치면 강하게 밀어냄)다 — 이건 *부피*이고 중성이든 이온이든 똑같이 있다. 그래서 기존 반발 코어(`repulse`)에 붙어 있던 *전하 게이트를 떼어내* 새 법칙 `pauli` 를 만들었다: **모든 쌍**(중성 포함)에 단거리 반발을 싣는다. 이제 중성 원자도 가까워지면 서로 밀어낸다 → 겹쳐 통과하지 못하고 *튕기거나 휜다*.

**왜 repulse 보다 가파른가 — 접촉에서만**: excluded-volume(부피)은 *접촉할 때만* 작용해야 한다. 멀리서까지 균일하게 밀면 기체 전체가 팽창해 버린다. 그래서 반발을 더 가파르게 했다 — 힘이 거리의 6승(1/r⁶)으로 떨어진다(쿨롱 1/r³·반발 코어 1/r⁴보다 빠름). 결과: 멀리선 거의 0, 접촉 거리(~3) 안에서만 급격히 세진다 = 진짜 "부피".

**무엇을 발견했나**(700 tick · 시드 5개 동일 — rng 미사용 순수 결정론, 중성 H 2쌍, kP=6·ε=2):
- **중성 정면 튕김(excluded-volume)** — 정면으로 접근하던 중성 쌍의 속도 vxA 가 +0.15 → 감속(최근접 거리 **3.45** 까지만 접근, 0 으로 붕괴·통과 안 함) → **−0.144** 로 *반전*. 겹쳐 통과하던 중성이 이제 *튕긴다*. 거의 완전 탄성(속력 회복).
- **중성 빗겨 편향(산란)** — 빗겨(impact parameter 2) 접근하던 중성 쌍이 옆으로 밀려 vy 가 0 → **−0.06** *창발*. 직진이 아니라 *휜다*.
- **둘 다 중성(q=0)** — 쿨롱·반발 코어는 무효(전하 0). 순수하게 새 파울리 효과만으로 일어난 일.
- **총 에너지 유계 보존** — |Δ(KE+PE)| ≈ **2.06e-5**. 운동량·전하 머신 1e-9(쌍별 등·반작용).

**왜 중요한가**: 세션 내내 보이던 "원자가 등속운동만 한다"의 *중성 원자 절반*이 풀렸다. 이전엔 하전 원자만 쿨롱·반발로 휘었고 중성은 직진했는데, 이제 **모든 원자가 부피를 가지고 서로 부딪힌다**. 이것이 물질의 부피·소프트 충돌의 토대이고, (다음에 중성 인력을 더하면) 응집·결정의 전제다.

**솔직한 한계**: ① *반발만* — 중성 원자는 이제 밀어내기만 하지 *끌어당기지 않는다*. 그래서 중성 원자는 여전히 대부분 직진하다 *접촉 시에만* 튕긴다(완전한 "자연스러운 군집 운동"엔 중성 인력=반데르발스/중력 필요 — 후속 후보 K/Phase E). ② *결정론 시연용 2체* — 다체 기체의 충돌 통계·평균자유행로는 후속. ③ 우물 없음(순수 반발) → 결합 안 함(결합은 인력 필요). ④ kP·사거리는 토이 노브(실제 원자 반지름 보정 후속). ⑤ O(n²) 쌍 — 연속력이 셋(쿨롱·반발·파울리)으로 늘어 공간 분할 더 임박(STATE 🟡). ⑥ collide(step-0009 이산 탄성 충돌)와 공존 — 둘 다 켜면 중복 가능, 장면이 택일(이 장면은 pauli 단독).

## 1. 가설

`pauli` 게이트가 의도한 현상을 수치로 보이는가:

1. **중성 정면 튕김(excluded-volume)** — 정면 접근 중성 쌍의 vxA 반전(+u→<0). 중성도 안 뚫는다.
2. **중성 빗겨 편향(산란)** — 빗겨 접근 중성 쌍의 vyC 창발(0→유의). 직진이 아니라 휜다.
3. **둘 다 중성(q=0)** — 쿨롱·반발 코어 무효, 순수 파울리 효과. 총 E 유계·운동량 머신은 verify ②.

## 2. 무엇을 더했나 (한 조각)

- `engine/hgo-laws.js`: 법칙 `pauli`(게이트 `kPauli`·연화 `coulombSoft` 공유) + `LAW_ORDER` 끝자리. F = −kP·4/s2³·d (s2=r²+ε²), *전하 게이트 없음*(모든 쌍), 쌍별 등·반작용(운동량 정확). 반음시 오일러 자연 합류.
- `engine/hgo-kernel.js`: ledger 에 *파울리 PE 항* `pauliPE` 가법(kPauli 게이트 — 미설정 → 0, 과거 장부 불변). U=Σ_{모든 쌍} kP/(r²+ε²)²(힘과 정확 일치).
- `engine/scenes.js`: 장면 `step-0022`(중성 H 2쌍 — 정면 튕김·빗겨 편향, kPauli 단독, rng 미사용 순수 결정론).

## 4. 척추 체크 (SPINE §5)

1. **단일 척추** ✅ — 새 자료형 0. 부피·반발은 *위치 r* 의 함수, 전하와 무관(파울리 = 부피). 게이트만 떼어 보편화.
