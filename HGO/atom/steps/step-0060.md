# step-0060 — Barnes-Hut 무게중심 쿼드트리 가속 합산 (측정·새 법칙 0·cellPairs 의 장거리판)

> 한 조각: 장거리 1/r²(gravity·coulomb)를 O(n log n) 으로 줄이는 **Barnes-Hut 무게중심 쿼드트리**(`L.bhForces`)를 세우고, θ→0 시 전쌍과 *같은 항*임을 측정한다. force 미배선(LAW_ORDER 불참)·새 법칙 0 = 골든 보존 = 회귀 0. 0054 cellPairs → 0055 collide 와 같은 "먼저 옳게, 나중에 배선" 분리.

## 더한 것

`engine/hgo-laws.js` 에 `bhForces(atoms, theta, W, H, soft)` 함수(LAW_ORDER·DEFAULTS 미참여) + export. 단거리 셀 리스트(`cellPairs`)의 *장거리판*이다.

- **왜 셀이 안 되나**: gravity·coulomb 은 1/r² — 먼 원자도 *집단으로* 무시 못 할 인력을 준다. 컷오프하면 누락이 커 셀 리스트(0054) 부적합.
- **Barnes-Hut 원리**: 무대를 쿼드트리(정사각 4분할)로 쪼개 각 노드의 *총질량·무게중심*을 계산. 한 원자가 노드를 볼 때 노드 크기 s, 거리 d 가 `s/d < θ` 면 그 노드 전체를 *무게중심 한 점*으로 lump(한 번에). 아니면 자식으로 펼침. → 상호작용 O(n)→O(log n), 전체 O(n²)→**O(n log n)**.
- **가속식**: `g_i = Σ m_j·d/s2^1.5`(질량가중 1/r² *가속*·mi 무관 → 노드 총질량으로 lump 가능). gravity 힘 식(0028)과 한 출처.

## θ→0 동치 — *비트* 동일이 아니라 *같은 항·재정렬 ~머신* (정직)

θ=0 이면 `s² < θ²·d² = 0` 이 항상 거짓 → 어떤 노드도 lump 안 됨 → 모든 잎(단일 원자)까지 펼쳐 **전쌍과 같은 항 집합**을 합산한다. 상호작용 수도 brute 와 정확히 같다(999000=999000·load-bearing).

단 합 *순서*는 트리 DFS(공간 순)라 brute(j=0,1,2,… 순)와 달라, 부동소수 덧셈 재정렬로 maxDiff **2.22e-14**(~머신). collide(0055)의 *비트* 동일과 다른 점: collide 는 쌍별 독립 편집이라 정렬로 순서를 맞춰 비트 동일했지만, 가속은 *누산*이라 순서가 곧 마지막 ULP를 바꾼다. "같은 항·다른 순서" — 근사 아님. (회귀 0 보장은 *비트*가 아니라 LAW_ORDER 불참 → 골든 보존서 온다.)

## 쉽게 풀어 쓴 설명

중력·전기력은 *멀리까지* 미친다 — 가까운 원자만 봐선 안 되고, 먼 별도 당긴다. 그래서 "옆 칸만 보기"(step-0054~59 의 격자) 가 안 통한다. 원자 1000개면 한 원자가 999개를 다 봐야 해서 총 100만 번 계산.

Barnes-Hut 의 꾀: **멀리 있는 원자 무리는 뭉뚱그려 본다.** 안드로메다 은하의 별 하나하나를 따로 당기는 게 아니라 "저 멀리 은하 한 덩어리"로 치는 것과 같다. 무대를 점점 잘게 나눈 *상자 트리*를 만들고, 충분히 멀고 작은 상자는 그 상자의 *무게중심 한 점*으로 갈음한다. 가까운 것만 낱낱이 보고 먼 것은 뭉친다 → 100만 번이 **39만 번**으로 줄었다(오차 2.1%).

"얼마나 뭉칠지"는 노브 θ가 정한다 — θ=0 이면 아무것도 안 뭉쳐 *전부 낱낱이*(느리지만 정확히 전쌍과 같은 답·오차 2e-14, 컴퓨터 한계 수준), θ를 키우면 더 거칠게 뭉쳐 더 빠르지만 오차가 는다. **느린 정확한 길과 빠른 거친 길이 θ로 이어져 있고, θ=0 에서 둘이 정확히 만난다** — 이게 안전장치다.

이 step 은 *트리를 만들고 옳음을 쟀을* 뿐, 아직 실제 힘에 연결하진 않았다(중력 연결 0061·전기력 연결 0062·다체 측정 0063 예정). 격자를 0054 에서 만들고 0055 에서 충돌에 연결한 것과 똑같은 순서다.

## 한계 / 전가

- **토러스 min-image COM 은 토이 근사**: 주기 경계의 정확한 장거리 합은 Ewald/PM 가 필요(min-image 는 가장 가까운 상(像)만). θ>0 상대오차(2~13%)가 일반 BH보다 큰 것은 이 경계 효과 + min-image 상쇄 때문. 정밀 주기 합은 후속(PM/Ewald).
- force 미배선 — gravity(0061)·coulomb(0062) 에 게이트 `farField` 로 배선(off → 전쌍 brute = 회귀 0·on → 트리). PE 정합(E 완화)은 그때.
- θ=0.2 가 정확도(2.1%)·속도(39%) 둘 다 만족하는 NP=1000 무대. 더 큰 N 일수록 BH 이점 큼(O(n log n) vs O(n²)).
