# step-0062 — Barnes-Hut 트리를 coulomb 에 배선 (전하가중 트리·하전만 평균 가속 차감·중성 불변)

> 한 조각: step-0061 의 트리를 coulomb 에 배선한다. gravity(질량가중)와 동형이되 *전하가중*. 핵심 차이: 쿨롱은 전하 의존이라 중성이 안 움직여야 한다 → 평균 가속 차감을 *하전 원자에서만* 해 px·py 머신 + 중성 brute 정확 일치.

## 더한 것

- `engine/hgo-laws.js` `bhForces` 에 `charged` 인자(기본 falsy → 질량가중·0060/0061 비트 불변). 켜면 단극자 weight = 전하(Z−e)·node.q=Σq 합산(무게중심은 *늘 질량가중* — far ref 무해).
- `coulomb` 에 게이트 `farField`: =0(기본) → 전쌍 brute(비트 동일·회귀 0). =1 → `bhForces(charged=1)` 가 쿨롱장 F_i 를 돌려주고 가속 a_i=−(kc·q_i/m_i)·F_i.

## gravity 와 차이 — 전하 의존과 중성 불변

gravity(0061)는 *질량가중 평균 가속* 차감(등가원리·중력 보편)으로 운동량을 복원했다. 쿨롱은 **전하 의존** — 중성(q=0)은 brute 에서 아예 안 움직인다. 그래서 균일 차감을 *모두*에게 하면 중성이 움직여 brute 와 어긋난다.

**해소**: BH 인공 net force 를 *하전 원자에서만* 질량가중 평균 가속 `c′ = Σ_q m·a / Σ_q m` 로 뺀다 → `Σ_q m·(a−c′) = 0` → px·py **머신**. 중성은 차감도 안 받아 **불변**(brute 정확 일치·측정 0.00e+0). 하전끼리 상대 가속 `(a_i−c′)−(a_j−c′)=a_i−a_j` 불변 → 쿨롱 상대 동역학 보존.

## 쉽게 풀어 쓴 설명

step-0061 에서 중력을 빠른 트리로 계산했듯, 이번엔 *전기력*을 같은 트리로 계산한다. 다른 점: 중력은 *질량*이 끄는 힘이라 모든 게 당겨지지만, 전기력은 *전하*가 끄는 힘이라 **전하 없는(중성) 원자는 전기력을 안 느낀다**. 그래서 트리의 "뭉친 점"이 가진 건 질량이 아니라 *알짜 전하*(+와 −를 합친 값)다.

step-0061 의 "세계 전체 떠밀림 빼기"(운동량 보존 트릭)를 여기 그대로 쓰면 문제가 생긴다 — 중성 원자까지 떠밀려 움직여버린다(원래 안 움직여야 하는데). 그래서 떠밀림 보정을 *전하 있는 원자에게만* 적용했다. 결과: 운동량은 컴퓨터 한계 수준(1e-16)으로 지켜지고, **중성 원자는 빠른 방식이든 느린 방식이든 한 치도 안 움직인다**(차이 정확히 0). 전기력의 "전하 가진 것만 반응한다"는 성질이 빠른 근사 후에도 그대로 살아있다.

이로써 *장거리* 힘 둘(중력·전기력) 다 Barnes-Hut 트리로 가속됐다 — 단거리 5종(0054~59) + 장거리 2종(0061~62) = **모든 힘이 O(n²) 를 벗어났다**. 이제 더 큰 세계(다체 핵합성·별 군집)를 굴릴 토대가 섰다(다음 측정 0063).
