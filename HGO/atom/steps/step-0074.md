# step-0074 — Morse 비조화 결합 (bondMorse)

> 한 조각: **결합 퍼텐셜을 조화 → Morse 로 정밀화하는 게이트 `bondMorse`** — 유한 해리에너지(가열하면 결합이 끊긴다) + 비대칭 우물(열팽창). 게이트=0 → 조화 bondSpring·회귀 0. 분자→물질로 가는 정밀화.

## 무엇을·왜

`bondSpring`(0026)의 결합 퍼텐셜은 *조화* U=½kS(r−r₀)² 다. 두 가지가 비물리적이다:
1. **무한 우물** — 아무리 가열해도 결합이 r₀ 로 복귀한다. 결합이 *절대 안 끊긴다*(실제 분자는 충분히 가열하면 해리한다).
2. **대칭** — 우물이 r₀ 좌우 대칭 → 진동의 시간 평균 길이가 정확히 r₀(열팽창 0). 실제 결합은 비대칭이라 가열하면 평균 길이가 늘어난다(열팽창).

`bondMorse`(기본 0 → 조화·회귀 0) 가 Morse 퍼텐셜로 바꾼다:

> U = D·(1 − e^{−α(r−r₀)})²

- **유한 깊이 D**(해리에너지): r≫r₀ 면 U→D 로 평탄·복원력 dU/dr=2Dα·x(1−x)→0(x=e^{−α(r−r₀)}). KE>D 면 결합이 우물을 탈출해 *해리*한다.
- **비대칭**: 밂쪽(r<r₀, x>1)은 가파르고 당김쪽(r>r₀, x<1)은 완만 → 진동 평균 길이가 r₀ 보다 길다(열팽창).
- 평형 r=r₀(x=1·dU/dr=0)·기질은 bondSpring 과 동일(연속 보존력·symplectic 적분·쌍별 등반작용 → 운동량 머신·E 유계). force(`bondSpring`)와 ledger PE(`bondSpringPE`) 양쪽에 같은 게이트.

## 한계 / 전가

- **단일 r₀·D·α**: 토이 — 원소·결합 종류별 D·α·r₀ 가 아니라 전역 노브. 실제는 결합쌍(C−C·C=O…)마다 다르다 — 결합 종류별 파라미터(Z·order 함수)는 후속.
- **해리 후 간선 잔존**: Morse 가 해리해도 `sim.bonds` 간선은 남는다(force→0 이라 무해하나 위상은 "결합"). 거리 임계로 간선을 *떼는* unbond 연동(거리형 해리)은 후속 — 현재 unbond 는 충돌 KE 기준(0016).
- **저E 진폭 차**: KE=½D 서 이미 Morse 진폭(maxR 6.46) > 조화(5.41) — 비조화는 *모든* E 서 작동(완전 일치는 극저E 뿐). 의도된 물리.
- **라이브 경로 격리**: Morse 효과는 cache run(bonds 프리셋)서 측정(createSim 이 bonds 미전달 → 라이브는 자유 드리프트·0071 패턴).
- **전가**: 결합 종류별 파라미터·거리형 해리 unbond·핵합성 산물 분자 무대서 Morse.

## 쉽게 풀어 쓴 설명

지금까지 우리 세계의 화학 결합은 *완벽한 용수철*이었습니다(0026). 두 원자가 용수철로 이어져 적당한 거리(r₀=4)에서 진동하죠. 그런데 이 용수철엔 비현실적인 점이 둘 있었습니다. 첫째, 아무리 세게 잡아당겨도 *절대 안 끊어집니다* — 용수철이 무한히 강하거든요. 둘째, 양쪽으로 똑같이 늘었다 줄었다 해서 가열해도 평균 길이가 안 변합니다.

실제 분자 결합은 다릅니다. 충분히 뜨거우면(에너지가 결합력 D를 넘으면) *끊어지고*, 결합은 늘어나는 쪽이 줄어드는 쪽보다 더 잘 늘어나서(비대칭) 가열하면 평균적으로 길어집니다(열팽창 — 물건이 뜨거우면 부푸는 이유). 이걸 정확히 담는 게 100년 된 "모스 퍼텐셜"입니다.

이번에 `bondMorse` 스위치로 결합을 완벽한 용수철에서 진짜 모스 결합으로 바꿨습니다. 측정 결과:
- **약하게 흔들면**: 모스든 용수철이든 둘 다 r₀ 근처에서 안정하게 진동했습니다(안 끊김).
- **세게 흔들면(결합력 D 초과)**: 모스 결합은 *끊어져* 두 원자가 멀어졌고(거리 45까지!), 용수철은 여전히 r₀ 근처에 *영원히* 붙어 있었습니다. 결합이 끊어지는 건 순전히 모스 퍼텐셜 덕분이라는 게 깔끔하게 갈렸습니다.
- **약하게 흔든 평균 길이**: 모스는 5.10 으로 r₀=4 보다 *길었고*(열팽창), 용수철은 4.04 로 r₀ 그대로였습니다(대칭).

에너지와 운동량은 정확히 보존됐고, 스위치를 끄면 예전 용수철과 비트 단위로 똑같습니다. 이로써 분자가 *부서질 수도, 부풀 수도* 있게 됐습니다 — "원소 → 분자 → 물질"로 가는 길에서 결합을 한층 진짜답게 만든 것입니다.
