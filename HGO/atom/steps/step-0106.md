# step-0106 — z축 자유 드리프트 (`drift3d`) · 세계가 3D로 열린다

> 한 조각: **원자 다발에 세 번째 좌표 `rz·vz` 를 더해 자유 운동을 2D → 3D 로 연다.** 게이트 `drift3d`(=0 → z 완전 불활성·과거 2D 비트 동일·회귀 0). 닫힌 장부에 z운동량 `pz` 추가. z 에 작용하는 *힘*은 후속 step 이 각 force 법칙에 가법 — 이번은 *드리프트* 한 조각.
>
> 뷰어: `viewer.html#step-0106` · 검증: `node engine/verify.js step-0106`

## 무엇을 더했나

0105 까지 원자의 위치는 `rx, ry` 두 좌표뿐이었다 — 시뮬은 *평면 세계*였고, 렌더(L-3d 렌즈)만 그 z=0 평면을 3D 카메라로 비췄을 뿐 실제 운동은 2D 였다. 이 한계가 화학 결합 기하(0099 VSEPR)에서 직접 드러났다: 정사면체(메탄 109.5°)·팔면체 같은 *입체* 배치는 평면에선 진짜로 표현 못 하고 2D 토이로만 두었다.

이 step 은 그 근원에 *세 번째 좌표 하나*를 더한다 — **새 자료형이 아니라 원자 다발의 양 하나(z)** 가 늘 뿐(SPINE 단일 척추). 더한 것:

1. **`integrate` z 드리프트** (`hgo-laws.js`): `drift3d` 게이트가 켜지고 원자가 `vz` 를 가지면 깊이 `D` 토러스에서 `rz += vz·dt` 로 z 를 굴린다. relCap 과 합성되면 γ 에 `vz²` 가 포함돼 광속 상한 `|v_coord|<c` 가 3D 로 확장된다.
2. **z운동량 `pz`** (`hgo-kernel.js` ledger): `pz = Σ m·vz` 가 닫힌 장부에 추가된다. 운동E `½m·v²` 도 `vz²` 를 포함한다.
3. **해시에 `rz·vz`** (`hgo-kernel.js` hashState): *정의됐을 때만* 섞어 골든 회귀 앵커가 3D 상태를 동결한다.
4. **토러스 깊이 `D`** (`hgo-sim.js` createSim): `spec.D || spec.W` — 미설정이면 W(2D 무대 무영향).
5. **장부 키 `pz`** (`verify.js`): 검증기가 z운동량 보존을 자동 감사.

## 회귀 0 — 어떻게 과거를 안 깼나

핵심은 **"정의됐을 때만"(가법 규칙)** 이다. 과거 0001~0105 의 모든 장면은 원자에 `rz·vz` 가 *없다*:

- **ledger**: `vz = a.vz || 0` → 0 → `v2` 와 `pz` 가 과거값 그대로(`pz=0` 가법은 다른 항 불변).
- **hashState**: `a.rz !== undefined` 가 거짓 → z 를 안 섞음 → 해시 비트 동일.
- **integrate**: `drift3d` 기본 0 → `vz=0` → γ 도 드리프트도 과거와 동일.
- **createSim**: `D = spec.D || spec.W` → 과거 spec 엔 D 없으니 W → 미사용.

⇒ 풀 골든 대조 **525/525 기존 앵커 비트 동일**(0106 만 신규 +5). 회귀 0 입증.

## 쉽게 풀어 쓴 설명

지금까지 이 세계의 원자들은 *종이 위*에서만 움직였다 — 가로(x)·세로(y) 두 방향뿐. 화면은 3D 처럼 보였지만 그건 카메라가 입체로 비춰준 *착시*였고, 알맹이는 평평했다. 그래서 분자가 진짜 입체 모양(예: 메탄의 정사면체)을 못 가졌다.

이번에 **깊이(z) 한 방향을 더했다.** 이제 원자는 종이를 뚫고 앞뒤로도 움직일 수 있다. 실험 장면에서 원자 세 개에 z 방향 속도를 주니 60틱 동안 깊이로 **72만큼 이동**했다(평면에선 0). 동시에 새로 추가한 *깊이 운동량(pz)* 은 힘이 없으니 **한 치도 안 새고 보존**됐다.

가장 중요한 건 **안전하게 더했다는 것**이다. 깊이 스위치(`drift3d`)를 끄면 z 는 *완전히 없던 일*이 되어, 과거에 만든 105개 장면이 **마지막 비트까지 똑같이** 재현된다(530개 골든 해시 전부 일치). 새 차원을 열되 옛 세계는 한 톨도 안 흔든 셈이다.

이건 *첫 조각*일 뿐이다 — 원자들은 이제 3D 공간을 *떠다닐* 수 있지만, 서로 z 방향으로 *밀고 당기는 힘*(쿨롱·결합·중력의 z 성분)은 아직 없다. 그건 다음 step 들이 힘 법칙 하나씩 3D 로 확장하며 채운다. 그때 비로소 진짜 정사면체 분자·입체 별이 창발한다.
