# step-0067 — 핵 껍질 닫힘 마법수 보정 nucShell (이중마법수 안정섬·B(Z,N) 에 껍질 보너스·붕괴 종점이 마법수로 이동)

> 한 조각: 게이트 `nucShell` 로 결합에너지 B(Z,N) 에 껍질 닫힘 보너스 δ_shell=aShell·(magic(Z)+magic(N)) 를 얹는다. 마법수(2·8·20·28·50·82·126)서 핵이 유난히 단단 — 매끈 질량공식이 못 잡는 *불연속 안정섬*. nucShell=0 → 미가법 → 비트 동일(회귀 0).

## 더한 것

`engine/hgo-kernel.js`:
- `BIND.aShell=0.8`·`MAGIC=[2,8,20,28,50,82,126]`·`isMagic(n)`·`shellDelta(Z,N)=aShell·(isMagic(Z)+isMagic(N))`.
- `binding(Z,N,pair,shell)` 4번째 인자 `shell` — falsy → 정확히 옛 값(회귀 0)·truthy → `+shellDelta`. `bindingDelta` 도 `shell` 관통.

게이트 `nucShell` 를 *세 곳 모두* 관통(정합 강제 — 변환 Q=실제 ΔB):
- `ledger`(정지질량 rest=A−B): `binding(...,pr,sh)`.
- `decay`(β⁻ ΔB⁻·β⁺ ΔB⁺): `bindingDelta(...,dp,sh)`·`binding(...,dp,sh)`.
- `fuse`(ΔB_fus): `binding(...,pr,sh)`.

`nucShell:0` 를 DEFAULTS 에 추가. LAW_ORDER 불변(force 법칙 아님 — binding 의 게이트일 뿐, levelEZ·massDefect 와 같은 *레저/변환 게이트*).

## 왜 정합이 필수인가 (0040~41 결합E 게이트 정합의 계승)

질량공식이 정지질량(M=A−B)·붕괴 발열(ΔB)·융합 발열(ΔB_fus) 셋을 *동시에* 정한다. 셋이 *같은 B* 를 안 쓰면 변환 Q ≠ 실제 정지질량 변화 → 장부 누수. 그래서 껍질 항을 셋 다 같은 `nucShell` 게이트로 관통한다 — rest 의 −B 도, 변환 Q 의 ΔB 도 같은 껍질 보너스를 포함 → Q·B·L·E·px·py **머신** 닫힘(0040 의 `useBind=mf||md` 정신).

## 쉽게 풀어 쓴 설명

원자핵이 얼마나 단단히 묶였는지는 지금까지 *매끈한 공식*으로만 쟀다(부피·표면·전기 반발·양성자-중성자 균형). 하지만 실제 핵에는 전자처럼 *껍질*이 있어, 양성자나 중성자 수가 딱 떨어지는 수(**마법수**: 2, 8, 20, 28, 50, 82, 126)일 때 껍질이 꽉 차며 *유난히 단단*해진다 — 매끈 공식엔 안 보이는 봉우리다. 양성자와 중성자가 *둘 다* 마법수면(이중마법수: ⁴He, ¹⁶O, ⁴⁰Ca…) 더더욱 단단하다.

이번 step 은 그 봉우리를 결합 공식에 더했다(스위치 `nucShell`·꺼두면 옛날과 비트까지 똑같음). 결과:
- **이중마법수가 도드라진다**: ¹⁶O·⁴⁰Ca 는 매끈 값보다 +1.6 더 단단(마법수 두 개분)·평범한 핵(⁶C 의 ¹³C 등)은 보너스 0.
- **붕괴가 마법수에서 멈춘다**: 중성자가 많은 핵은 베타붕괴로 양성자 수를 늘려가며 "가장 단단한" 곳으로 굴러간다. 매끈 공식만 쓰면 질량수 22 짜리는 양성자 10개(네온)에서 멈추는데, 껍질 봉우리를 켜면 **양성자 8개(마법수)에서 멈춘다** — 8 이 안정섬이라 거기서 굴러가기를 멈춘다.

중요한 건 이걸 *손으로 박지 않았다*는 것이다. "원소 X 는 안정하다"고 표를 만든 게 아니라, 결합 공식에 껍질 항 하나를 더하니 *붕괴가 알아서* 마법수에서 멈췄다(창발). 그리고 에너지 장부는 한 톨도 안 샌다 — 핵이 더 단단해진 만큼(정지질량이 줄어든 만큼) 발열이 정확히 맞아떨어진다.

## 한계 / 전가

- 마법수 보너스는 *정수 일치* 토이(정확히 마법수일 때만 +aShell·계단)다. 실제는 마법수 *근처*서 부드럽게 봉우리(껍질 간격·서브셸) — 부드러운 봉우리·서브셸·변형(deformed)·섬은 후속 정밀화.
- aShell=0.8 은 ΔB<c 유지용 토이 상수(결정론 상수라 헤더 고정). 절대 척도는 토이.
- 마법수 이동이 *이중마법수 종점*(양쪽 다 마법)까지 가는 A 는 매끈 골짜기가 이미 거기 있어(A=16·28·40·48) 이동이 안 보임 — A=22 는 *단일 마법(Z=8) 이동*을 깨끗이 보여줌. 이중마법 종점 이동은 더 큰 aShell 필요(전가).
- render: 핵 안정성은 내부 장부(Z 변환은 0065 의 L-element 부채로 이미 추적) — 별도 관측 양 0.
