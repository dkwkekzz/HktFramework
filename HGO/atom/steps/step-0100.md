# step-0100 — 결합 종류 통합 게이트 bondKindPair (한 토글이 D·α·r_eq 세 축 동시)

> 한 조각: 통합 게이트 `bondKindPair` — 0089 D(깊이)·0094 α(폭)·0095 r_eq(길이)의 *개별 게이트 셋*을 한 토글로 묶는다. 실제로 한 결합은 셋을 *함께* 정한다(C–C 는 깊고 가파르고 길다·H–H 는 얕고 완만하고 짧다). morseD·morseAlpha·morseReq 의 pair 조건에 `|| bondKindPair` OR 배선 → 한 토글로 셋 동시 원소쌍 의존. 새 물리 아닌 *일관성/편의* — 한 게이트 = 일관된 결합 종류. bondKindPair=0 → 세 개별 게이트만(0095~ 비트 동일·회귀 0).
> 뷰어: [viewer.html#step-0100](../../viewer.html#step-0100)

## 무엇을 더했나 (통합 게이트 `bondKindPair` — 세 pair-함수 OR)

```
morseD:     if (knobs.bondMorsePair      || knobs.bondKindPair) D *= √(Za·Zb)
morseAlpha: if (knobs.bondMorseAlphaPair || knobs.bondKindPair) α *= √(Za·Zb)
morseReq:   if (knobs.bondReqPair        || knobs.bondKindPair) req *= (∛Za+∛Zb)/2
```

- 한 토글이 세 기하 축(깊이 D·폭 α·길이 r_eq)을 *동시에* 원소쌍 의존으로 만든다 → 일관된 "결합 종류"(C–C vs H–H)를 한 번에.
- **정확 동치**: OR 배선이라 `bondKindPair=1` 은 `bondMorsePair=bondMorseAlphaPair=bondReqPair=1` 과 *비트 동일*(같은 D·α·r_eq 값). 새 물리 0 — 세 개별 게이트의 합집합을 정확히 재현하는 편의/정합 게이트.
- **회귀 0**: `bondKindPair=0` → 각 조건이 개별 게이트로 환원 → 0089~0099 비트 동일.

## 한계 (정직)

- **편의 게이트(새 물리 0)**: bondKindPair 는 세 개별 게이트의 *합집합*일 뿐 — 세 축을 *연결*(D↔α↔r_eq 상관, 예: Badger 규칙 k_force ↔ r_eq)하지는 않는다. 실제 화학의 축간 상관(짧은 결합 = 강한 결합)은 후속.
- **차수 통합 미포함**: bondMorseOrder/bondMorseOrderNL(0090/0098 차수 축)은 *결합 차수* 의존이라 *원소쌍* 통합(bondKindPair)에 안 묶었다 — 차수는 직교 축(같은 원소쌍도 단·이·삼중). 차수까지 묶는 "완전 결합 종류"는 후속.
- **단일 함수형(√Z·∛Z 토이)**: 세 축 다 √(ZaZb) 또는 ∛Z 토이 — 실제 주기율표 비단조(전기음성도·껍질)는 미반영. 정밀 함수형은 후속.

## 쉽게 풀어 쓴 설명

지난 세 step(0089·0094·0095)에서 결합의 세 가지 기하 성질을 각각 만들었다 — 우물 *깊이*(얼마나 단단한가), *폭*(얼마나 뻣뻣한가), *길이*(평형 거리). 그런데 이걸 각각 따로 켜는 스위치 3개로 두었다. 실제로는 한 결합이 이 셋을 *동시에* 가진다 — 탄소-탄소 결합은 깊고·가파르고·길고, 수소-수소는 얕고·완만하고·짧다.

이번엔 스위치 *하나*(`bondKindPair`)로 셋을 한꺼번에 켜게 했다. 켜면 C–C 가 H–H 대비 깊이 6배·뻣뻣함 6배·길이 1.82배 — 세 축이 한 번에 갈린다. 실제로 C–C 결합이 더 긴 거리(3.63)에 안착하고 H–H 는 짧게(2.25) 안착했다.

그리고 확인: 이 하나의 스위치를 켠 결과가 옛 스위치 3개를 다 켠 결과와 *글자 하나 틀리지 않고 똑같았다*(비트 동일). 즉 새로운 물리를 더한 게 아니라, 흩어진 세 스위치를 "결합 종류 하나"로 깔끔하게 묶은 것이다. 에너지·운동량 보존(0.17%), 끄면 옛 방식(개별 스위치) 그대로(골든 500/500).
