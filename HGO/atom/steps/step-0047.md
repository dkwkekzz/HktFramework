## 0. 쉽게 풀어 쓴 설명

**이 단계가 답한 질문**: "이 세계에서 *그 무엇도 빛보다 빠를 수 없다*(c = 최고속)를 — `if (속도 > c) 잘라내기` 같은 손질 없이, 보존 장부도 안 깨고 — 어떻게 박는가?"

**무엇을 만들었나**: 여태 원자는 매 틱 `위치 += 속도·dt` 로 움직였고, *좌표속도(공간을 실제 가로지르는 속도)에 상한이 없었다*. 자연 단위에서 빛의 속도는 c=1 인데, 수소가 빛을 쏠 때의 반동(step-0003)이나 고에너지 융합(step-0046) 반동은 속력이 ~0.5c 를 넘봤고 — 원리상 c 를 넘을 수도 있었다. 즉 "빛이 최고속"이라는 가장 기본적인 약속이 코드에 *없었다*.

순진한 해법 — "속력이 c 넘으면 c 로 잘라라" — 은 함정이다. 속도를 그냥 깎으면 그만큼의 **운동량과 운동에너지를 몰래 버리는** 셈이라, 한 톨도 안 새야 하는 닫힌 장부가 깨진다. 그래서 *자르지 않고 다시 해석*했다. 저장된 속도 (vx,vy) 를 **고유속도(celerity)** — 즉 "운동량을 질량으로 나눈 양" — 으로 본다. 그러면:

- **운동량** p = m·u 는 손도 안 댄다 → 장부 그대로 닫힘. (게다가 이건 진짜 *상대론적 운동량* γ·m·v 와 정확히 같다.)
- **공간을 가로지르는 실제 속도** = u / √(1 + u²/c²) 인데, 이 식은 u 가 아무리 커도 *절대 c 를 못 넘는다*. u=100 이어도 좌표속도는 0.99995, u→∞ 라도 c 에 *가까워질 뿐 닿지 않는다*.

드리프트(위치 갱신)는 *위치만* 바꾸므로 — propagate(step-0004)와 똑같이 — 에너지·운동량·전하·바리온·렙톤 전부 **보존-자명**이다(잔차 정확히 0). 그리고 게이트(`relCap`)를 끄면 좌표속도 = 고유속도(원시 v) 라 과거 전 장면과 *비트까지 똑같다*(회귀 0).

**무엇을 발견했나**(시드 평균, `verify` 출력 그대로):
- **인과율 상한**: relCap=1 이면 모든 celerity 의 좌표속도가 c(=1) 이하. 최고 celerity u=100 도 **0.99995 < 1**.
- **창발 공식 정합**: 측정 좌표속도가 정확히 `u/√(1+u²)` — u=1 → **0.70711**, u=5 → **0.98058** (머신 정밀도). 어디에도 `if(v>c)` 분기를 안 적었는데 상한이 *나왔다*.
- **대조(게이트 끄면 c 돌파)**: relCap=0 이면 좌표속도 = celerity 그대로 — u=2 → **2.0**, u=20 → **20.0**, 둘 다 c 를 한참 넘는다. 레일이 *실제로 일을 한다*는 증거.
- **단조 점근**: celerity 가 커질수록 좌표속도도 커지되 *전부* c 미만 (0.44721 < 0.70711 < 0.89443 < 0.98058 < 0.99875 < 0.99995 < 1) — c 에 *도달은 0*.
- **운동량 보존(클램프와 결정적 차이)**: relCap 을 켜든 끄든 최종 총 운동량 px = **128.5**(=초기 Σm·u)로 *동일*. 레일은 *위치*만 바운드하고 *운동량*은 안 깎는다.

**왜 중요한가**: ① 세계에 **인과율의 상한**이 생겼다 — 이제 그 무엇도 빛보다 빨리 공간을 가로지를 수 없고, 이건 author 한 상수가 아니라 "고유속도 → 좌표속도" 환산 *함수형*에서 나온다. ② 고에너지 Phase(핵융합·붕괴 반동)가 더 거세져도 원자가 c 를 돌파해 *무대를 한 틱에 건너뛰는*(터널링) 비물리를 막는 **안전망**이다. ③ 단순 클램프가 못 하는 것 — *운동량을 보존하면서* 속도를 바운드 — 을 "celerity 재해석" 한 수로 해냈다. 척추의 "author 하지 말고 굴려서 얻는다"를 *광속 상한*에서 다시 증명.

**솔직한 한계**: ① **에너지는 아직 토이** — 운동량은 상대론적(γmv)인데 KE 는 여전히 Newtonian-in-celerity(½mu²)다. 완전 상대론적 KE=(γ−1)mc² 는 후속 정밀화(STATE §3 ⬜ 상대론적 운동). 저속에선 둘이 일치, 고속에서 갈린다. ② 이 step 은 *드리프트*(자유 전파)에만 상한을 건다 — 충돌·산란이 상대속도를 *좌표속도가 아닌 celerity* 로 보는 미세 불일치는 relCap=1 인 무대에서만 의미가 있고(과거 전 장면은 relCap=0 → 무영향), 완전 상대론적 충돌학은 별도 step. ③ 게이트는 *옵트인* — 기존 장면들은 relCap=0 이라 거동 불변. 이 레일을 실제 시뮬에 *켜는* 것은 고에너지 무대가 필요해질 때 장면별로. ④ 광자(propagate)는 이미 `kProp=1 → 정확히 c` 라 이 레일과 무관(광자는 늘 c, 원자만 sub-c).

## 1. 가설

저장 속도 (vx,vy) 를 고유속도 u 로 재해석하고 드리프트에서 좌표속도 v_coord=u/√(1+|u|²/c²) 를 쓰면: **모든 좌표속도가 c 미만**(상한 창발)이고, 측정값이 **u/√(1+u²)** 공식과 일치하며(author 0), 게이트를 끄면 **c 돌파**(대조)가 보이고, celerity↑ 에 **단조 점근**(전부<c)하며, **운동량은 켜고/끄고 불변**(레일은 위치만 바운드). 드리프트는 위치만 바꾸므로 **닫힌 장부**(보존-자명)와 **회귀 0**(게이트=0 → 원시 v)을 깨지 않는다.

## 2. 메커니즘 (더한 것 — 게이트 1 + 장면 1, 하네스 가법만)

- **게이트 `relCap`**(`engine/hgo-laws.js` `DEFAULTS`, 기본 0): 끄면 early 분기 없이 원시 v → 회귀 0.
- **`integrate` 가법 분기**(`engine/hgo-laws.js`): relCap 켜지면 `γ=√(1+(vx²+vy²)/c²)`, 좌표속도 `vx/γ, vy/γ` 로 위치 갱신. **저장 v(=celerity)·운동량·E 는 불변** — 위치만. relCap=0 이면 분기 미진입 → `a.vx*dt` 그대로(직전 비트).
- **장면 `step-0047`**(`engine/scenes.js`): celerity 집단 u∈{0.5,1,2,5,20,100}(질량1·전하0·들뜸0)·무대 2000²·t=10. `measure(rc,u,t)`(단일 원자 좌표속도)·`momentum(rc,t)`(총 px) 헬퍼로 가설 5항을 *고정 시드 엔진 재사용*으로 측정(하네스 미변경). 라이브 init 은 relCap=1 집단으로 장부·결정론 기둥.
- **장부·해시 무변경**: 드리프트는 보존-자명이라 `hgo-kernel.js` 손대지 않음. `hashState` 가 이미 `rx,ry` 를 섞어 상한 적용이 step-0047 해시에 자동 반영, 과거(relCap=0 → 미적용)는 비트 불변.
