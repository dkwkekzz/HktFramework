# step-0088 — 밀도 게이트 cellPairs 배선 (공용 `degField`)

> 한 조각: coolOuter(0083)·disperse(0085 disperseOuterDeg·0087 disperseAutoDeg)의 국소 밀도 deg 1패스를 brute O(n²) → cellPairs 셀 이웃으로(공용 `degField`). 0054~64 가 모든 *힘*을 셀 배선한 것의 *밀도판*. cut=coolR≤spatialCut 이라 셀폭≥coolR → 셀 deg 가 brute deg 와 *정확 동일*(누락 0)·deg 는 횟수라 쌍 순서 무관 → 켜도 비트 동일·회귀 0.

## 무엇을 더했나 (헬퍼 1개 — deg 패스를 셀에 배선)

공용 헬퍼 `degField(sim, radius)` 추가 — coolOuter·disperse 의 deg 1패스를 *대체*(LAW_ORDER·DEFAULTS 불변·새 LAW 0):

- **spatialHash=0**: brute O(n²)(반경 radius 내 쌍 카운트) — 0083~87 비트 동일.
- **spatialHash=1**: `cellPairs(atoms, cut=radius)` 셀 이웃만 검사. cut=radius(≤spatialCut)이라 셀폭≥radius → radius 내 어떤 쌍도 같은/이웃 셀 → deg *정확 동일*(근사 아님). deg 는 *횟수*(증가 순서 무관)라 cellPairs 의 쌍 순서가 brute 와 달라도 deg 배열 비트 동일.

**왜**: 0083/0085/0087 의 밀도 1패스가 유일하게 남은 O(n²) brute 였다(0085/0087 한계 명시). 힘은 0054~64 가 모두 셀/BH 로 O(n log n) 화했는데 밀도만 brute 였다 — degField 가 그 격차를 메운다.

**회귀 0 알리바이**: 기존 scene 은 spatialHash=1 → 이제 셀 deg 경로를 탄다. degField 변경 *후* 골든 대조가 **435/435 PASS**(0083~87 stored golden 은 brute-deg 로 생성) ⇒ 셀-deg 가 brute-deg golden 과 비트 동일. 즉 "켜도 비트 동일"이 골든으로 증명됨.

## 한계 (정직)

- **분위수 정렬(0087)은 여전히 전역**: degField 는 deg *집계*만 셀화했다. 0087 의 분위수 임계 계산은 여전히 분산 후보 deg 전체 정렬(O(m log m)·m=후보 수) — 이건 deg 집계와 별개·작음.
- **cut=coolR 가정**: degField 는 cut=radius 로 호출돼 셀폭≥radius 를 보장한다. coolR > spatialCut 이면 셀폭<coolR 가능 → 이웃 셀 밖 누락 위험(현 scene 은 coolR 5 ≤ spatialCut 8 안전). coolR>spatialCut 무대선 셀 반경 확장(±2) 필요 — 후속.
- **이벤트형 fuse 의 셀(spatialHash)과 deg 셀이 같은 게이트**: 둘 다 spatialHash 로 묶여, 힘 셀은 끄고 deg 셀만 켜는 분리는 불가(현재 무해·필요 시 별 게이트).

## 쉽게 풀어 쓴 설명

별이 "코어냐 겉껍질이냐"를 판단하려면 각 원소의 *주변 이웃 수(밀도)*를 세야 한다(0083·0085·0087). 그런데 이걸 *모든 원소 쌍을 일일이* 비교해서 셌다 — 원소 400개면 약 16만 번 비교(O(n²)). 힘 계산은 이미 0054~64에서 "근처 칸(셀)만 보기"로 빠르게 바꿨는데, 밀도 세기만 옛날 방식으로 남아 있었다.

이번엔 밀도 세기도 같은 "셀(칸)" 방식으로 바꿨다. 핵심은 *정확히 같은 답*이 나와야 한다는 것. 칸 크기를 이웃 반경보다 크게 잡으면, 반경 안의 어떤 쌍도 *같은 칸이나 바로 옆 칸*에 있으니 하나도 안 놓친다. 실제로 측정하니 셀 방식과 일일이 세는 방식의 이웃 수 차이가 **정확히 0**(완전 일치)이었고, 비교 횟수는 16만 번에서 **253번**으로 줄었다(0.16%).

답이 한 비트도 안 바뀌므로, 이 변경 *후에* 옛 결과들과 대조해도 전부 그대로다(골든 440/440). 더 빨라지되 세계는 똑같이 굴러간다 — 순수한 가속이다.
