# step-0083 — 국소 냉각 → 이산 분자: 코어는 뜨겁게 외곽만 식힌다 (새 법칙 `coolOuter`)

> 한 조각: 새 법칙 `coolOuter` — damp(0024)의 *국소 밀도 게이트* 판. 각 원자의 국소 이웃 수(밀도)를 세, *저밀도 외곽만* 점성 냉각하고 *고밀도 코어는 뜨겁게* 둔다. 0082 의 밀집 네트워크(분자 2개·최대 17원자)를 **이산 소분자(분자 6개·최대 8원자)**로 쪼개되 코어 융합(maxZ 26)은 유지. 전역 damp 는 점화 전 코어까지 식혀 별이 죽는다(maxZ 1) — *국소성*이 열쇠. kCoolOuter=0 → 0082 비트 동일·회귀 0.

## 무엇을 더했나 (법칙 1개 + 노브 3개)

`coolOuter`(노브 `kCoolOuter`·반경 `coolR`·밀도 문턱 `coolDeg`) — `damp`(0024 근접 쌍 점성 소산)에 **국소 밀도 게이트**를 더한 판:

1. **1패스(국소 밀도 측정)**: 각 원자의 반경 `coolR` 내 이웃 수 `deg[i]` 를 센다(= 국소 밀도). 전역 조율자 0 — 각 원자+이웃만(척추 ③).
2. **2패스(외곽만 냉각)**: *양쪽 다* 저밀도(`deg ≤ coolDeg`)인 근접 쌍만 `damp` 와 동형으로 상대속도 점성 감쇠(vcom 불변 → px·py 머신·상대 KE→복사 바스 = E 닫힘). 고밀도 코어 원자(`deg > coolDeg`)는 게이트서 빠진다 → 고온 유지 → 융합 계속.

`kCoolOuter=0` → early-return → 0082 비트 동일(회귀 0). LAW_ORDER 에 `damp` 뒤 한 자리·이벤트/소산 법칙(tick 당 1회).

**왜**: 0082 산물 분자는 *밀집 네트워크*였다(냉각 없어 산물이 식으며 흩어지지 못함). 진짜 별 바깥 화학은 산물이 *식으며 흘러* 이산 분자를 이룬다. 그런데 전역 `damp` 는 점화 *전* 코어까지 식혀 별을 죽인다. 해법은 *국소* 냉각 — 코어는 뜨겁게, 외곽만 식힘.

- **밀도 측정 O(n²) 브루트**: coolOuter 1패스 이웃 수가 전쌍 O(n²)(측정 scene N=400 규모선 충분). 대규모선 cellPairs(0054) 배선 필요 — 후속(damp/collide 와 동형 셀 배선).

## 쉽게 풀어 쓴 설명

지난 step(0082)에서 별이 만든 무거운 원소들이 결합해 분자가 됐는데 — 문제는 그게 깔끔한 작은 분자가 아니라 17개가 한 덩어리로 엉긴 *큰 뭉치*였다. 진짜 별이라면 만들어진 원소가 *식으면서 흩어져* 물 분자(H₂O) 같은 작은 분자가 돼야 한다. 식히는 게 필요했다.

그런데 문제: 그냥 전체를 식히면(전역 냉각) 별이 *켜지기도 전에* 식어서 아예 타지 않는다. 별은 한가운데가 펄펄 끓어야 핵융합이 일어나기 때문. 그래서 이번엔 **"한가운데는 뜨겁게, 바깥쪽만 식히는"** 새 규칙을 만들었다(`coolOuter`).

방법은 간단하고 *국소적*이다: 각 원자가 "내 주변에 이웃이 몇이나 있나" 센다. 이웃이 빽빽하면(한가운데·고밀도) → 안 식힌다. 이웃이 듬성하면(바깥쪽·저밀도) → 식힌다. 한가운데가 어딘지 좌표로 박지 않고 *밀도로 측정*한다 — 별이 움직여도 알아서 따라간다.

결과: 분자가 **6개로 늘고 가장 큰 덩어리가 17→8개로 절반**으로 쪼개졌다(더 이산적). 그러면서도 한가운데 융합은 그대로(원소 번호 26까지). 비교로, *같은 세기*로 전체를 식히면(전역 damp) 별이 안 켜진다(원소 번호 1). 즉 "한가운데를 안 식히는" *국소성*이 핵심이었다. 그리고 식히며 뺀 에너지는 빠짐없이 복사 창고로 들어가 장부는 0.51%만 흔들리며 닫혔다.
