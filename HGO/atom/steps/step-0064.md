# step-0064 — 공간 분할 셀 리스트를 fuse 에 배선 (핵 융합도 셀 이웃만·collide/bond 와 동형·다체 핵합성 토대)

> 한 조각: 게이트 `spatialHash` 를 핵 융합 `fuse` 에 배선한다. collide(0055)·bond(0059)와 *동형* — cellPairs 로 이웃 쌍만 훑되 (i,j) 정렬해 brute 순서와 맞춰 **비트 동일**(켜도 회귀 0). 새 법칙 0(기존 fuse 에 셀 경로 추가만). 이것이 막혀 다체 핵합성 시계열이 N 을 못 키웠다 — 그 토대다.

## 더한 것

`engine/hgo-laws.js` `fuse` 의 이중 루프를 `tryFuse(i,j)→bool` 로 추출하고, 게이트 `spatialHash` 로 두 경로를 가른다:

- `spatialHash=0`(기본) → 전쌍 brute `for i<j { if tryFuse break }` — 과거 전 장면 **비트 동일**(회귀 0).
- `spatialHash=1` → `cellPairs(atoms, fuseR)` 로 R 내 쌍만 모아 **(i,j) 오름차순 정렬** 후, `consumed[i]`(=brute break 등가)로 처리.

브루트의 `continue` 는 전부 `tryFuse` 내 `return false`, `break` 는 `return true`+`consumed[i]` 로 등가 변환. 노브·`LAW_ORDER` 변경 없음 — `fuse` 함수 내부 경로만 추가.

## 왜 비트 동일인가 (collide/bond 와 같은 논거 + break 의 등가)

`cellPairs`(0054)는 R 내 쌍을 brute 와 **같은 집합**으로 준다(누락·과잉 0·근사 아님). 결정적 추가 논거: **brute 의 이중 루프(외 i↑·내 j↑)는 정확히 *사전식 (i,j) 순서*** 로 쌍을 처리한다. 셀 쌍을 (i,j) 오름차순 정렬하면 같은 사전식 순서가 된다.

`fuse` 의 `break`("원자 i 는 이번 tick 한 번만 합쳐짐")는 셀 경로서 `consumed[i]` 플래그로 등가 표현 — i 가 한 번 융합하면 i 의 잔여 쌍을 건너뛴다. `dead[]`(소비된 b)·`bath` 적재가 처리 순서에 의존하지만 그 순서가 같으므로 합체 결과·바스 E 가 **비트까지 동일**(켜도 회귀 0). R 밖 쌍은 cellPairs 가 안 주지만, brute 경로서도 `d2>R2 → return false`(no-op·break 안 함)라 *합체 집합*이 정확 같다.

fuse 는 collide/bond 처럼 *순간 합체*(질량중심 vcom 잠금·바스 E 회계)라 연속 PE 항이 없다 → 컷오프-PE shift 불필요(연속력 pauli·vdw·repulse 0056~58 과 다름). 그래서 켜도 *근사*가 아니라 *비트 동일*이다.

## 쉽게 풀어 쓴 설명

지금까지 두 핵이 융합할 수 있는지 보려면 **모든 원자 쌍**을 일일이 확인해야 했다 — ²H 원자 160개면 12720쌍. 하지만 융합은 *닿을 만큼 가까운*(반경 3 이내) 쌍에서만 일어난다. 그래서 무대를 작은 격자 칸으로 나누고 각 원자는 *자기 칸과 옆 칸*만 본다. 거리 계산이 12720번 → **814번(6.4%)** 으로 줄었다.

핵심은 충돌·결합 배선 때와 같다 — "빨라졌지만 **결과가 한 치도 안 달라졌다**". 옆 칸만 보는 빠른 방식과 전부 보는 느린 방식이 만든 융합(127개)이 *완전히 똑같다*(비트 단위 동일). 까다로운 점은 융합이 원자 *개수를 줄인다*(둘 → 하나)는 것 — 그래서 처리 *순서*가 결과를 바꿀 수 있다. brute 의 이중 루프가 사실 정확히 "작은 번호부터" 순서로 돈다는 걸 이용해, 셀 쌍도 같은 순서로 정렬하니 결과가 비트까지 맞는다.

왜 중요한가? 별 내부의 핵합성(가벼운 핵 → 무거운 핵 사다리)을 *큰 무리*로 시계열로 보려면 융합이 빨라야 한다(0048·0053 은 정면 쌍만 토이로 봤다). 이 배선이 그 다체 핵합성 시계열(다음 step)의 토대다.

## 한계 / 전가

- fuse 의 셀 경로는 *합체*만 가속. 핵+화학 동시 무대(fuse 압축 ↔ bonds 인덱스 어긋남)는 여전히 미해결(STATE §3·load-bearing 아님).
- 측정 무대는 barrier=0·gamow 0 결정론 융합(비트 동일 증명용) — Gamow 율(rng) 경로도 같은 사전식 순서라 비트 동일이나, 이 무대는 단순화.
- 남은 O(n²)는 없다(모든 단거리 5종 셀 + 이벤트형 fuse·장거리 2종 BH 완결). 토러스 min-image COM 토이·BH 단극자는 별개 정밀화(Ewald/PM·멀티폴).
