# step-0073 — 핵+화학 동시 무대 (fuseRebond·#D 해소)

> 한 조각: **융합 압축이 결합 간선 인덱스를 재배선하는 게이트 `fuseRebond`** — 열린 이슈 #D 해소. 핵 변환(fuse)과 화학 결합(bond)을 *한 무대*서. 게이트=0 → 옛 거동·회귀 0.

## 무엇을·왜 (#D)

열린 이슈 #D(review-0041-0050·STATE §3): `fuse` 가 두 핵을 합치면 `sim.atoms` 를 *압축*한다(죽은 원자를 배열서 제거 → 인덱스가 당겨짐). 그런데 `bonds` 간선은 *원자 인덱스*를 저장한다(`[i, j, …]`). 그래서 결합이 살아있는 무대에서 융합을 켜면 **간선이 어긋난다** — 인덱스 i 가 가리키던 원자가 압축으로 다른 원자가 되거나 아예 범위를 벗어난다. 이 때문에 핵 변환과 화학 결합을 *한 무대*에서 함께 굴릴 수 없었다(지금까지 fuse 장면엔 bonds 가 없어 안전했을 뿐).

`fuseRebond`(기본 0 → 옛 거동·압축만·회귀 0) 가 해소한다. =1 이면 압축과 함께:
- **ⓐ 끊김** — 소비된 원자(융합에 먹힌 원자)에 닿은 결합은 끊는다(핵반응이 화학 결합을 파괴). per-bond E(`e[2]`, bondLocalE)는 복사 바스로 환원 → 전역 `sim.bondE` 와 동기 차감 → **E 닫힘**.
- **ⓑ 재배선** — 살아남은 결합은 *새 인덱스*로 옮긴다. remap 이 단조(인덱스 순 push)라 `i<j` 순서·키 규약(`i*n+j`)이 보존된다. `bondKeys` 는 새 n 으로 재생성(다음 tick `bond()` 의 중복 가드가 정합).

기존 fuse 장면(0033·0064·0065·0068·0070·0072)은 bonds 가 없어 이 분기를 안 탄다 → **비트 불변**(=0 이든 =1 이든 회귀 0).

## 한계 / 전가

- **끊김 = 결합 파괴**: 융합에 먹힌 원자의 결합은 *끊는다*(에너지는 바스로 보존). 대안 — 결합을 *product 로 이전*(융합핵이 결합을 계승)도 가능하나 화학적으로 핵반응이 결합을 깨는 게 더 자연(전가).
- **bondKeys 의 n 의존**: 키가 `i*n+j` 라 n 변할 때마다 재생성해야 정합한다(fuse 압축이 유일한 n 변경처라 거기서 처리). 안정 id(원자별 불변 식별자)면 n 무관 — 더 견고하나 큰 변경(전가).
- **unbond+rebond 미검**: 이 장면은 unbond 없음(결합 깸은 융합 경로만). unbond 도 bondKeys 미갱신 기존 거동 — rebond 와 무관(별도).
- **전가**: 핵합성 산물이 *분자*를 이루는 풍부한 무대(C·O → 분자·물질)·Morse 비조화 결합·안정 id.

## 쉽게 풀어 쓴 설명

우리 세계엔 두 가지 큰 사건이 있습니다 — 핵이 *합쳐지는* 융합(원자 두 개가 하나가 됨)과 원자들이 *손을 잡는* 화학 결합. 그런데 이 둘을 한 무대에서 같이 돌리면 문제가 생겼습니다. 융합으로 원자가 사라지면 컴퓨터는 원자 목록을 "당겨서" 빈자리를 메웁니다(3번 원자가 사라지면 4번이 3번 자리로). 그런데 화학 결합은 "5번과 7번이 손잡고 있다"처럼 *번호*로 기록돼 있어서, 목록이 당겨지면 그 번호가 엉뚱한 원자를 가리키게 됩니다. 결합이 깨지거나 존재하지도 않는 원자를 가리키죠.

이번에 더한 `fuseRebond`("융합 후 결합 다시 잇기")가 이걸 고칩니다. 융합으로 목록이 당겨질 때마다, 결합 기록의 번호도 같이 새 번호로 고쳐 줍니다. 그리고 융합에 먹혀 사라진 원자의 결합은 깨끗하게 끊고(그 결합에 담겼던 에너지는 빛 창고로 보존), 살아남은 결합은 새 번호로 다시 잇습니다.

측정해 보니, 이 기능을 켜면 잘못된 결합(존재하지 않는 원자를 가리키는 "허공 결합")이 **0개**, 끄면 **6개** 생겼습니다. 그러면서 한 무대에서 융합 51번과 결합 47개가 동시에 일어났고, 분자 5개가 정상적으로 측정됐습니다. 에너지·전하·핵자·운동량은 컴퓨터 정밀도까지 한 톨도 안 샜고요.

이게 왜 중요하냐면 — 이제 별이 핵융합으로 무거운 원소를 만들면서 *동시에* 그 원소들이 화학 결합으로 분자를 이룰 수 있게 됐기 때문입니다. 핵(원소를 만드는 일)과 화학(분자를 만드는 일)이 따로 놀던 걸 한 세계로 합친 겁니다. "원소 → 분자 → 물질"로 가는 다리가 놓였습니다.
