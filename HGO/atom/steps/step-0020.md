# step-0020 — 반발 코어 (단거리 반발 → 쿨롱과 균형 → 평형 결합 길이 r_eq 창발)

> 새 법칙 `repulse`(게이트 `kRepulse`) — *단거리 반발 코어* U=kR/(r²+ε²)(force ∝ 1/r⁴). 쿨롱 인력(1/r³)과 균형하는 지점에서 **평형 결합 길이 r_eq** 가 창발한다. 장면: `step-0020` ([viewer.html#step-0020](../viewer.html#step-0020)). 검증: `node engine/verify.js step-0020`.

| 원자 요건 (SPINE §3) | 이 step | 상태 |
|---|---|---|
| 1 원소·결합 | 결합이 비로소 *고정 거리*(r_eq)를 가짐 — "괴이한 기하"의 길이 축 해소 | 결합 기하 🟡 |
| 2 에너지·흐름 | 반발 PE 항 추가 — 쿨롱 인력 PE 와 합쳐 *우물*(최소 PE = 안정 평형) 형성 | 🟡 |
| 4 위치·운동 | 두 연속력의 합이 *안정 평형 위치*(복원력)를 만듦 — 진동(결합의 떨림)의 근원 | 🟡 |

## 0. 쉽게 풀어 쓴 설명

**이 단계가 답한 질문**: "step-0019 쿨롱력은 거리에 따라 변하는 첫 힘이었지만 *평형점이 없었다* — 반대전하는 서로 끝없이 끌려 골 바닥(연화 ε)으로 떨어져 진동만 했다. 결합에 *고정된 길이*가 없다는 뜻이다. 어떻게 하면 두 원자가 *특정 거리*에서 멈춰 서게(평형 결합 길이를 갖게) 할 수 있나?"

**핵심 아이디어 — 두 힘의 줄다리기**: 자연의 결합은 *끌어당기는 힘*과 *너무 가까우면 밀어내는 힘*의 균형으로 거리가 정해진다(원자가 서로 뚫고 들어갈 수 없는 것 = 파울리 반발). 그래서 쿨롱 인력 위에 **단거리 반발 코어**를 하나 더 얹었다. 이 반발은 거리가 가까울수록 *훨씬 가파르게*(쿨롱 힘이 1/r³로 줄 때 반발은 1/r⁴로 줆) 세지도록 설계했다 — 그래서 **가까이서는 반발이 이기고(밀어냄), 멀리서는 쿨롱 인력이 이긴다(당김)**. 두 힘이 정확히 비기는 단 하나의 거리 = **평형 결합 길이 r_eq**. 거기서 원자는 멈춰 선다.

**왜 "창발"인가**: r_eq 를 코드에 박지 않았다(`if (거리==4.5)` 같은 건 없다). 단지 두 연속력(인력·반발)을 더했을 뿐인데, 그 합이 만드는 **PE 우물의 바닥**에서 r_eq 가 *측정으로* 나온다. 노브 값에서 분석적으로도 예측된다: r_eq² + ε² = (2·kR / (kC·|qa·qb|))². 이 장면(kC=1, kR=2.5, ε=2, ±1 이온)에선 r_eq = √(25−4) = √21 ≈ **4.583**. 시뮬레이션이 정확히 이 값으로 수렴한다.

**안정 평형 — 양쪽서 되돌아온다**: 진짜 평형이라면 *밀려나도 다시 돌아와야* 한다. 그래서 세 쌍을 동시에 띄워 시연했다 — 각 쌍은 토러스에서 멀리 떨어뜨려 *서로 간섭 없이* 자기 짝만 느끼게 했고, 셋 다 정지 상태로 출발한다:
- **쌍 A**(거리 = r_eq 에서 출발): 순 힘이 0 이라 *그 자리에 머문다*.
- **쌍 B**(r_eq *바깥*에서 출발): 인력이 이겨 *안으로* 당겨진다.
- **쌍 C**(r_eq *안쪽*에서 출발): 반발 코어가 이겨 *밖으로* 밀려난다 — 골로 붕괴하지 않는다.

밖에서도 안에서도 r_eq 로 되돌아온다 = **안정 평형**. 이게 결합이 *떨면서도 일정한 길이를 유지*하는(분자 진동) 이유다.

**기질 재사용**: 새 적분기·새 보존 회계는 없다. step-0019 의 *반음시(symplectic) 적분*(속도→위치 순서, 에너지 유계 보존)·*PE 항 가법*·*연화 ε* 를 그대로 쓴다. 반발도 보존력(F=−∇U)이라 ledger 에 반발 PE 항만 하나 더했다. 끄면(`kRepulse=0`) 힘·PE 둘 다 사라져 step-0019 비트 동일(회귀 0).

**무엇을 발견했나**(600 tick · 시드 5개 동일 — rng 미사용 순수 결정론, r_eq≈4.583):
- **평형 유지** — 쌍 A 가 4.583 에서 출발해 **4.709**(편차 0.13)로 머문다. 순 힘 ≈ 0 = 결합 길이의 정의.
- **인력 복원** — 쌍 B 가 6.875(=1.5·r_eq)에서 **3.37** 로 안으로 당겨진다(r_eq 가로질러 진동).
- **반발 복원·붕괴 방지** — 쌍 C 가 2.75(=0.6·r_eq)에서 **8.93** 으로 밖으로 밀려난다(붕괴 없이 r_eq 위로).
- **총 에너지 유계 보존** — |Δ(KE+PE)| ≈ **2.37e-5**(연속력 2개여도 안 흘러감). 운동량·전하 머신 1e-9.

**왜 중요한가**: 이로써 "괴이한 기하"의 *길이 축*이 닫혔다 — 결합이 비로소 *실제 결합 길이*를 가진다. 이전엔 `bond` 가 포획 순간 거리에 속도만 잠갔을 뿐(위상만), 충돌·반동에 흩어졌다. 이제 인력↔반발 우물이 거리를 *물리적으로 고정*한다. 다음은 이 평형 위에서 진짜 결합(쿨롱+포획)을 닫고, 각도(VSEPR)는 다체 배치로 따라온다.

**솔직한 한계**: ① *각도*는 아직 없다 — r_eq 는 두 원자 거리뿐, 분자 모양(결합각)은 다체 후속. ② 반발은 *하전 쌍*만(쿨롱과 같은 게이트) — 보편 파울리 배타(중성 포함 excluded-volume)·반데르발스는 후속(중성 원자는 여전히 등속). ③ 에너지 머신 0 아님(symplectic 유계 진동, E 만 완화) — 연속력의 본질 비용. ④ r_eq 우물 깊이·세기는 노브 토이(kR 임의) — 실제 결합 에너지와의 보정은 후속. ⑤ O(n²) 쌍 — 연속력이 둘(쿨롱+코어)로 늘어 공간 분할 시점 더 임박(STATE 🟡). ⑥ 이 장면은 *고립 쌍* 시연 — 다체 군집의 r_eq 격자(결정 구조)는 후속.

## 1. 가설

`repulse` 게이트가 의도한 현상을 수치로 보이는가:

1. **평형 길이 r_eq 유지** — 쌍 A(r_eq 정지 출발)가 머문다(|dA − r_eq| < 0.3). 순 힘 0 = 결합 길이의 정의.
2. **인력 복원** — 쌍 B(r > r_eq)가 안으로(dB < 초기 0.95배). 평형 밖에선 인력 우세.
3. **반발 코어 복원·붕괴 방지** — 쌍 C(r < r_eq)가 밖으로(dC > 초기 1.05배 & dC > ε). 평형 안에선 반발 우세.

→ 양쪽서 r_eq 로 복원 = **안정 평형**(결합이 떨며 일정 길이 유지).

## 2. 무엇을 더했나 (한 조각)

- `engine/hgo-laws.js`: 법칙 `repulse`(게이트 `kRepulse`·연화 `coulombSoft` 공유) + `LAW_ORDER` 끝자리. F = −kR·2/s2²·d (s2=r²+ε²), 쿨롱과 같은 쌍·게이트, 쌍별 등·반작용(운동량 정확). 반음시 오일러에 자연 합류.
- `engine/hgo-kernel.js`: ledger 에 *반발 PE 항* `repulsePE` 가법(kRepulse 게이트 — 미설정 → 0, 과거 장부 불변). U=Σ kR/(r²+ε²)(힘과 정확 일치, 쿨롱 PE 와 한 쌍).
- `engine/scenes.js`: 장면 `step-0020`(고립 ±이온 3쌍 = 평형/밖/안, dt=0.05·kRepulse=2.5, rng 미사용 순수 결정론).

## 4. 척추 체크 (SPINE §5)

1. **단일 척추** ✅ — 새 자료형 0. 반발력·PE 는 *다발의 양*(전하 q=Z−e·위치 r)의 함수. r_eq 는 author 한 상수 아닌 *두 힘 합의 측정*.
2. **창발 환원** ✅ — `if (거리==r_eq)` author 분기 0. 평형 길이는 인력(1/r³)·반발(1/r⁴) 합의 우물에서 자동 창발. 노브에서 분석 예측(r_eq=√21)과 수치 일치.
3. **국소 상호작용** ✅ — *그 두 하전 원자*만(min-image). 전역 조율자 0(쿨롱과 같은 쌍 게이트).
4. **닫힌 장부** ✅ — 운동량·Q·B·L 머신 1e-9(쌍별 등·반작용). 에너지는 반발 PE 항 추가 + symplectic 유계 보존(E 만 완화, drift 0).
