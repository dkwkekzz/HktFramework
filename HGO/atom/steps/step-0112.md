# step-0112 — force 법칙 3D 화 (`drift3d` 게이트) · 세계가 평면 붕괴 → 구(球) 붕괴

> 한 조각: **세계를 *모양 짓는* 힘들 — 중력·파울리·융합 — 을 z 축까지 확장한다.** 0111 이 `rz·vz` 좌표와 *자유 드리프트*만 열었다면(힘은 2D), 이 step 은 그 위에 *힘*을 3D 로 올려 가스가 *원반*이 아니라 *구(球)*로 무너지게 한다. 모든 z 항은 게이트 `drift3d` 뒤 — `drift3d=0`(기존 110 장면)이면 z 항이 정확히 0 → 비트 동일·회귀 0.
>
> 뷰어: `viewer.html#world` · 검증: `node engine/verify.js world`

## 무엇을 더했나

0111 의 한계는 그 step 주석이 직접 말했다: *"z 운동·힘은 후속 step 이 각 force 법칙에 가법(이번은 드리프트 한 조각)"*. 즉 원자는 `rz` 를 가졌지만 **중력·파울리·융합이 z 를 보지 않아** 가스가 xy 평면으로만 뭉쳤다(팬케이크). 이 step 이 그 세 힘을 3D 로 올린다 — 새 자료형 0, 기존 쌍별 거리 계산에 `dz` 한 성분을 더할 뿐:

1. **`gravity` (brute)** (`hgo-laws.js`): `dz = minImage(b.rz−a.rz, D)` → `s2 += dz²` → `a.vz += fz/ma·dt; b.vz −= fz/mb·dt`(등·반작용 → `pz` 머신 보존). BH 트리(`bhForces`)는 2D 라 3D 무대는 `farField=0`(brute) 경로.
2. **`pauli` (`doPair`)** (`hgo-laws.js`): 같은 `dz` 확장 → z 반발(구 압력 지지·원반 붕괴 방지). brute·cellPairs 공용 `doPair` 한 곳만 손댐.
3. **`fuse` (`tryFuse`)** (`hgo-laws.js`): 접촉 거리 `d2 += dz²`·법선 `nz`·상대 KE `dvz`·합체 속도 `vcz = (ma·a.vz+mb·b.vz)/M`(z 운동량 보존하며 융합). z 로 멀면 융합 안 함(거짓 융합 차단).
4. **PE 헬퍼** (`hgo-kernel.js` `gravityPE`·`pauliPE`): `dz` 항 가법 → ledger 가 3D 거리로 PE 합산(force 와 정합).
5. **광자 깊이** (`hgo-laws.js` `emit` + `render.js`): `emit` 이 방출 원자의 `rz` 를 광자에 실음(`rz: a.rz`) → 렌더가 `p.rz` 깊이서 그림. 빛이 원자와 같은 z 에서 빛나 3D 일관(2D 장면 `a.rz` 미존재 → undefined → render `p.rz||0`=0 → 비트 동일).

게이트는 전부 `const d3 = sim.knobs.drift3d`. `d3=0` 이면 `dz=0`·`nz=0`·`dvz=0`·vz 미기록 → 2D 경로로 *비트 환원*.

**통합 무대 둘**(`scenes.js`·새 법칙 0·기존 검증 노브 조합 → 골든 보존):
- **`world`** — 3D 항성로: ²H 가스 *구* 가 중력으로 모여(3D 관성반경 21.5→10.8 *그리고* z 폭 12.6→6.1 둘 다 붕괴 = 진짜 구) 융합 점화(maxZ 11·L-element 색 이동)·복사 순환 발광(광자 896·emit 끄면 0)·산물 분산.
- **`garden`** — 빛나는 화학 정원(2D·화학 결합 법칙은 아직 2D): 따뜻한 C+H 가스가 분자로 피고(연결 성분 36개) 끊임없이 맺고 끊으며(형성 99·해리 55·평균 속력 1.02) 결합 에너지가 복사 순환으로 빛난다(광자 32). 옛 `world.html` 의 *과감쇠 정적 격자* 실패를 *감쇠 없는 동적 평형*으로 뒤집은 무대.

## 회귀 0 — 어떻게 과거를 안 깼나

모든 z 항이 `drift3d` 게이트 뒤. 기존 110 장면은 `drift3d` 미설정(=0) → `d3` 거짓 → `dz/nz/dvz` 분기 미진입·vz 미기록·PE z 항 0 → 쌍별 힘·거리·합체가 *비트까지* 2D 와 동일. 광자 `rz` 는 hashState 가 안 섞는 필드라(from/to/E/rx/ry 만) 2D 골든 불변. 골든 555 기존 앵커 전부 일치로 실측 확인.

## 한계 · 다음

- **화학 힘은 아직 2D**: coulomb·repulse·vdw·bondSpring·bondAngle 은 z 를 안 봄 → 정사면체/팔면체 VSEPR(0099 한계)는 여전히 2D 토이. `garden` 이 2D 인 이유. 후속: 이 힘들도 같은 `dz` 패턴으로 3D 화(0113~).
- **pauli/vdw 셀 컷오프 2D**: `cellPairs` 가 xy 거리로 binning → 3D 에서 힘 적용 집합과 `pauliPE` 3D 컷오프 집합이 미세 불일치(force≠−∇U 작은 누수). E 완화 범위라 verify 통과·셀의 3D 화(옥트리) 후속.
- **recoil·광자 운동량 2D**: 3D 별의 복사압이 xy 평면만(pz 미변경 → 장부는 닫힘). 후속.
- **z-주기 잠재 분기**: 힘·integrate 는 `sim.D||sim.W`, PE 는 `knobs.D||W` — 현재 모든 3D 장면이 `sim.D==sim.W` 라 일치하나, 둘이 다른 장면이 생기면 분기. 후속 정련.
- **BH 트리 2D**: `farField=1`(O(n log n)) 은 2D 전용 → 3D 무대는 brute(O(n²)). N 큰 3D 무대는 느림(옥트리 후속).
- **`chooseSubSteps` z 복원**(이 step 에서 함께 수정): adaptSub 시험 kick 이 drift3d 에서 vz 를 쓰는데 vx/vy 만 복원하던 잠재 누수를 vz 도 save/restore 로 메움(d3 게이트 → 비-3D 비트 동일).
