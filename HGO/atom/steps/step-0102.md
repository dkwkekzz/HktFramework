# step-0102 — D↔α 상관 (둘째 Badger 축: 깊은 결합일수록 가파르다)

> 한 조각: 결합 강성 축 α 를 *깊이 축 D* 의 함수로 묶는 게이트 `bondAlphaD`. 0101 이 α↔r_eq(길이)를 묶었다면 이 step 은 α↔D(깊이) — α 가 이제 D·r_eq 두 축에 연결된다. 노브=0 → α 불변 → 0101~ 비트 동일(회귀 0).

## 왜 이 조각인가 — 척추 정합

실측 화학에서 강성(힘 상수)은 결합 길이뿐 아니라 **결합 세기(깊이 D)**와도 묶여 있다 — **강한(깊은) 결합일수록 가파르다**. 0101 이 α↔r_eq 한 축을 묶었으니, 이 step 은 α↔D 둘째 축을 묶어 강성이 *두 축* 모두에서 창발하게 한다. Morse `k=2Dα²` 가 이제 D(직접)·α(D 경유) **양쪽**에서 강성을 받는다 — 결합 종류의 내적 정합.

**author 분기 0**: `if(isStrongBond)` 가 아니라 *D 의 멱함수* — D 가 종류(0089)서 창발하면 강성도 따라 창발한다(척추 체크 ①②). 깊이 편차가 0인 결합(H–H)은 `(base/base)^q=1` → 무영향 = 상관이 진짜 D 의 함수임을 분리 입증.

*한계*: `morseAlpha` 는 결합 간선의 차수 `e[3]` 를 못 보므로 D_eff 를 order=1 로 계산 — 차수별 깊이→α 연계는 후속.

## 쉽게 풀어 쓴 설명

지난 step(0101)에서 "긴 결합은 무르다"는 규칙을 넣었다. 이번엔 짝이 되는 규칙 — **"강한(깊게 붙은) 결합은 빳빳하다"** — 를 넣었다. 둘 다 결합의 *빳빳함*(강성)을 다른 성질과 묶는 규칙인데, 0101 은 *길이*와, 이번 0102 는 *세기(깊이)*와 묶는다. 이제 결합의 빳빳함은 따로 정하는 값이 아니라 길이·세기에서 *자동으로 따라오는* 값이 됐다.

확인은 0101 과 똑같은 방식이다. ① 깊게 붙은 탄소 결합(C–C)에 똑같은 힘을 줬더니, 규칙을 켜자 **덜 늘어났다**(1.14 → 0.46, 절반 이하). 더 빳빳해졌다는 뜻이다. ② 반대로 *기준 세기*인 수소 결합(H–H)은 규칙을 켜도 **전혀 변하지 않았다**(똑같이 4.094). 즉 "세기가 기준보다 깊어진 결합만" 골라 빳빳하게 만든 것이지, 전체를 일률적으로 건드린 게 아니다. 진짜로 *깊이와 빳빳함이 연결*된 것이다.
