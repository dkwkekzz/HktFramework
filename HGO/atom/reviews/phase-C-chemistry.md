## 1. 이론적 배경 — 왜 이 물리인가

Phase B 까지 원자는 *빛으로만 간접 연결*됐다(서로 통과). Phase C 는 **직접 상호작용 — 화학**이다. 핵심 이론은 두 단계로 나뉜다.

### 1.1 이산 교환 — 충돌·포획 (닫힌 형식)
- **탄성 충돌**(0009): 접촉 시 법선 방향 운동량 교환(당구공). 운동량이 빠른→느린 원자로 *퍼진다* = 열화·확산(온도의 토대). 닫힌 형식이라 KE·운동량 머신 보존.
- **이온결합**(0010): 차가운 *반대 전하* 쌍이 비탄성 포획 → 질량중심 속도로 잠김. 사라진 상대 KE 는 *결합 E 저장고*(bondE)로 park(보존). **분자 = author 객체가 아니라 *결합 간선의 연결 성분*으로 측정**(`if(isWater)` 0).
- **화학량론·원자가**(0012·0017·0018): 결합 수 한계가 *전하 |Z−e|* 또는 *외각 껍질 빈자리*(옥텟 마법수 [2,10,18,36])에서 창발 — H1·C4·O2·He0. 다중 공유(이중·삼중) = 빈자리만큼 → O=O·N≡N.
- **결합 깸**(0016): bond 의 정확한 역연산 — 충돌이 흔든 상대 KE > 저장 결합 E 면 끊김. 형성↔해체 순환.

### 1.2 연속 보존력 — 기하의 근원 (symplectic 전환)
이산 교환엔 *평형 길이·각도*가 없다(포획 순간 거리에 속도만 잠금 → "괴이한 기하"). 진짜 거리 의존 힘을 넣으려면 **반음시(symplectic) 적분**이 열쇠 — 에너지가 *유계 진동*(drift 0)이라 연속력을 처음 허용한다(E 만 완화).
- **쿨롱장**(0019): 첫 연속 보존력 F=kC·qa·qb/r²(연화 ε). 첫 위치 에너지(PE) 항 → KE↔PE 교환.
- **평형 결합 길이 r_eq**(0020·0026): 쿨롱 인력 ↔ 반발 코어 균형점에서 *r_eq 창발*(하전) · 중성 공유결합은 `bondSpring` 간선 복원력으로 r_eq 부여.
- **보편력 → 응집**(0022~0025): pauli(excluded-volume 1/r⁶, 전하 무관)+vdw(약인력 1/r⁴) → **vdW 우물**에서 중성 원자 응집. damp(점성 소산)가 진동 KE 를 복사 바스로 빼 *응고*(상전이 미시판).
- **결합 각도**(0027): 한 중심 결합쌍에 각도 복원력 → VSEPR 평형각(118.44° 복원). 길이+각도 = **분자 모양**이 닫힘.

## 2. 게임에서 어떻게 풀고 어떻게 보이나

- **시뮬**: 충돌·결합은 닫힌 형식 이산 교환(머신 보존), 연속력은 symplectic(E 완화). 분자는 *측정*(연결 성분), 원자가·r_eq·각도는 *힘 균형서 창발*.
- **렌더**(render 트랙, 읽기): 결합 간선 `sim.bonds` → **분자 결합선**(L-bond) · 차수 → **평행선**(단일·이중·삼중, L-order) · 결합 E → **선 밝기**(L-Ebond). 화학발광(0011, bondE→광자)은 결합이 *빛으로 새어나오는* 것을 L-λ 로. 응집·응고가 원자 군집으로 보인다. "분자 모양"이 코드의 실루엣이 아니라 *힘이 만든 배치*로 화면에 뜬다.

## 3. 목표에 어떻게 도달하고 있나

큰 목표의 **물질의 씨앗**. 원자가 *만나 튕기는* 데서(0009) → *묶이고*(0010) → *분자로 측정되고*(연결 성분) → *기하(길이·각도)까지* 닫혔다(0027). 다양성(이온·공유·다중 결합·분자 모양)이 전부 author 없이 전하·빈자리·힘 균형서 창발 — "굴려서 얻는다"가 화학에서 입증됐다.

- **비용(공개)**: 연속력이 E 머신 0 을 포기(symplectic 유계 진동·완화) + 전쌍 O(n²)([README.md](README.md) 이슈 #5·#6). 정직한 트레이드오프.
- **남은 것(미도달)**: 다체 각도 평형·θ₀ 전자쌍 수 창발·Morse 정련은 후속(load-bearing 아님). 결합 E 의 *빛 방출* 정밀화는 Phase B 와 맞물림.

> **다음 Phase 로**: 결합 *기하*가 닫혔으니 다음 척도는 *더 크다* — 보편 원거리 인력(중력, 0028~)이 다체를 모으는 Phase E(별·순환)의 씨앗으로, *더 작다* — 핵 변환(붕괴·융합)이 Phase D 로. 둘 다 이미 실린 *측정·보존·창발* 위에 얹힌다.
