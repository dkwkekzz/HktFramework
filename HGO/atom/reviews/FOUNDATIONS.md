# FOUNDATIONS — 근본부터 푼 이론 (왜 이렇게 만드는가)

> 묶음 리뷰(`review-NNNN-MMMM.md`)가 *무엇을·정합한가*라면, 이 문서는 **왜 애초에 이런 설계인가**를 비전문가도 따라올 수 있게 푼다 — step 문서의 "쉽게 풀어 쓴 설명"을 트랙 전체로 끌어올린 *교육 레이어*.
>
> 권위가 아니라 *해설*이다. 정전(canonical) 철학·존재론은 [../../SPINE.md](../../SPINE.md)(§0~4)·[../../CLAUDE.md](../../CLAUDE.md), 현재는 [../STATE.md](../STATE.md). 이 문서는 그것을 *말로* 풀 뿐 — 충돌하면 SPINE 이 맞다.

---

## 1. 출발점 — 게임 세계는 보통 어떻게 만들어지나

보통 게임은 세계를 *종류*로 만든다:

```
Fire 클래스  { 데미지, 색=빨강, 번짐 }
Water 클래스 { 끄기, 색=파랑, 흐름 }
Tree 클래스  { 탈수있음, 불붙음 }
```

"불·물·나무"가 **코드에 박힌 종류**고, "불이 나무에 닿으면 탄다" 같은 규칙을 *사람이 하나하나 적는다*. 이게 "얕은 철학으로 현실을 모방"이다.

치명적 한계: **세계는 author 가 적어준 만큼만 굴러간다.** 불+물=증기, 불+기름, 불+얼음… 조합이 폭발하고, 안 적은 일은 *절대* 안 일어난다. 세계가 "살아있지" 않고 "각본대로"만 움직인다.

---

## 2. HGO 의 도박 — 종류를 없애고 "보존량 다발" 하나만 둔다

HGO 는 정반대다. **세계에 자료형은 딱 하나** — *보존되는 양들의 다발*:

```
원자 = { Z=양성자수, N=중성자수, e=전자수, x=들뜸준위, 위치, 속도 }
```

"수소" 클래스는 없다. 수소 = `Z`가 1인 원자. 물 분자 = `Z`들이 결합한 *덩어리*. 별 = 원자가 중력으로 모인 *배치*. 전부 **이 다발의 값과 배치**일 뿐. 핵심 통찰:

> **다양성을 "병렬로 만든 종류"가 아니라 "같은 다발의 양이 다른 것"으로 만들면, 종류 간 상호작용을 일일이 적을 필요가 없다.**

불·물 상호작용을 적는 대신 "전하가 반대면 끌린다"는 **법칙 하나**만 적으면 — 수소-산소든 나트륨-염소든 *자동* 적용. 조합 폭발이 사라진다. 세계가 author 의 분량이 아니라 **법칙에서** 굴러간다. (SPINE §0·핵심 한 줄)

---

## 3. "법칙에서 굴러가게" 하는 세 기둥

종류를 없앴으니 세계를 굴리는 건 법칙이다. 그게 진짜 세계처럼 굴러가려면 세 가지가 필수다.

### 기둥 A — 보존 법칙 (닫힌 장부)

실제 우주가 안 무너지는 이유는 **보존**이다. 에너지·운동량·전하는 *옮겨다니고 모습을 바꿔도 총합이 안 변한다*. 왜 필수인가:

1. **세계가 안 샌다** — 에너지가 슬금슬금 늘면 폭발, 줄면 동결사. 보존 없으면 *순환* 못 하고 한쪽으로 래칫된다. "스스로 굴러가는 세계"는 보존 위에서만 가능.
2. **검증의 닻** — 새 법칙을 더했는데 장부가 안 닫히면 *버그*다. "총 에너지 변화 = 0"이 매 step 거짓말 탐지기다.

`hgo-kernel.js`의 `ledger()` 가 4대 보존량을 합산(SPINE §2):
- **Q 전하** = Σ(Z−e) · **B 바리온** = Σ(Z+N) · **L 렙톤** = Σe · **E 에너지** = 정지질량+운동+들뜸+결합+복사 (**e=mc²**)

### 기둥 B — 국소성 (전역 조율자 없음)

실제 우주엔 "전체를 내려다보며 조율하는 신"이 없다. 한 원자는 **자기 + 바로 옆 원자**하고만 상호작용하고, 빛도 광속으로 *전파*돼 도달해야 영향을 준다. 왜 필수인가:

1. **창발의 조건** — "별·분자" 같은 큰 구조가 *국소 규칙의 반복*에서 *저절로* 생겨야 진짜 창발. 전역에서 "여기 별을 놓아라"는 author 다.
2. **MMO 로 가는 길** — 최종 목표는 공유 세계의 네트워크 복제(net 트랙). 상호작용이 국소면 세계를 공간으로 쪼개 여러 서버가 나눠 계산할 수 있다. 전역 조율자가 있으면 못 쪼갠다.

> ⚠ 이 기둥은 *완벽히는* 못 지킨 곳이 있다 — `reheat`·`chemilum` 이 전역 reservoir(바스·bondE)를 읽는다(척추 체크 ③ 긴장, [review-0001-0010.md](review-0001-0010.md) §2·이슈 #1). *의도된 토이 단순화*지 위반은 아니나, 국소 복사장으로 가는 게 숙제.

### 기둥 C — 결정론 (같은 시드 → 비트까지 같은 결과)

물리 법칙은 아니지만 *엔지니어링 필수*:
- **MMO 공유**: 모든 플레이어가 각자 컴퓨터에서 돌려도 *똑같이* 나와야 복제 성립. `Math.random` 금지 → 시드 의사난수(`mulberry32`)만.
- **재현 가능한 검증**: "골든 해시"(동결 시나리오 결과)가 회귀를 잡는 닻.

## 4. 왜 step 이 *그 순서*인가 — 각 step 이 메운 이론적 빈칸

세 기둥을 박고 나면 step 은 "가장 단순한 것부터 하나씩" 쌓는 일이다. 각 step 은 *직전의 이론적 빈칸 하나*를 메우고, 그게 다음의 전제가 된다 — 전부 보존·국소·결정론을 깨지 않으면서.

| step | 무엇 | 메운 빈칸 |
|---|---|---|
| 0001 | 빈 무대 + 자유운동 | 굴리기 전에 *무대가 보존·결정론을 지키는지*부터 증명 |
| 0002 emit | 빛 방출 | 색을 코드에 안 박고 λ=hc/ΔE 에서 *스펙트럼선 창발* |
| 0003 recoil | 반동 | 빛이 운동량 나르며 운동량 보존 — 도플러가 공짜로 |
| 0004 propagate | 전파 | 빛이 날아가야 *다른* 원자에 도달(국소성!) |
| 0005 scatter | 산란 | 식기만 하던 세계에 *역류* = 순환 씨앗 |
| 0006 scatterV2 | 산란 정밀화 | 거친 단순화 교정 — 노브 끄면 옛 동작 그대로(회귀 0) |
| 0007 escape | 광자 소멸 | 무한 누적을 *지우지 않고* 바스로 이전(보존) |
| 0008 reheat | 재가열 | 바스 E 되돌림 = **순환 첫 닫힘** |
| 0009 collide | 충돌 | **첫 직접 원자-원자 상호작용** = 화학의 문 |
| 0010 bond | 결합 | **분자를 코드에 안 박고 측정** |

**패턴**: 빛(B) → 빛의 순환 → 첫 접촉 → 결합(C). (이후 0011~ 은 각 묶음 리뷰가 같은 식으로.)

## 5. 가장 깨끗한 예 — 빛은 어떻게 시뮬되고 그려지나 (2트랙)

"굴려서 얻는다 + 시각화는 물리의 하류"가 가장 또렷이 드러나는 게 빛이다. 빛은 **두 트랙으로 분업**된다:

```
atom 트랙 (시뮬)            render 트랙 (그리기)
빛을 *만든다*      ─읽기전용→  빛을 *번역한다*
광자 생성·운동·소멸          양 → 색·밝기·줄기
쓰기 O                       쓰기 X (atom diff 0)
```

render 가 atom 을 *절대 안 건드려서*(폴더 disjoint) 결정론이 자동 보존된다 — 같은 시드 → 같은 세계 → 같은 화면.

### 5.1 광자 = 두 트랙을 잇는 다리

```
photon = { E, lambda(→색), rx,ry(→위치), rx0,ry0(→자취),
           px,py(→빛줄기), from,to(→스펙트럼선), birth }
```
모든 필드는 *시뮬이 물리적으로 채운 것*. render 는 "어느 필드를 어느 시각 채널로" 고를 뿐 새 값을 안 만든다.

### 5.2 시뮬 — 광자의 일생 (atom, 6 법칙)
태어나고(emit) → 운동량 얻고(recoil) → 날고(propagate) → 산란하고(scatter) → 바스로 죽고(escape) → 되살아남(reheat). 시뮬이 끝나면 `sim.photons` 가 *지금 날고 있는 광자들*을 담는다.

### 5.3 렌더 — 양을 픽셀로 (render, 렌즈)
- **L-λ**(`spectral.js`): 광자 `λ`를 *실제 가시광 스펙트럼 곡선*(Dan Bruton)에 통과. 측정된 λ 범위를 400~700nm 에 정규화 — `if(원소==산소) 파랑` 0줄. "수소가 빨갛다"가 *물리에서* 나온다.
- **L-line**: `from,to` 빈도 → 하단 스펙트럼 띠
- **L-recoil**: `px,py` → 빛 줄기 · **L-trail**: `rx0,ry0→rx,ry` → 전파 자취 · **L-glow**: 원자 `x` → 들뜸 헤일로

author 0 이 코드로 강제된다: 운동량 0 광자는 줄기 함수가 `null` 반환 → 안 그림. *시뮬이 안 낸 양은 author 하지 않는다*(RENDER §3).

### 5.4 한 광자의 전 생애
```
[시뮬] emit→광자 탄생 → recoil→운동량·λ이동 → propagate→광속 직진
[스냅샷] sim.photons = [{E,λ,rx,ry,rx0,ry0,px,py,from,to}, …]
[렌더] λ→가시광 곡선→빨강 RGB · streak/trail 기하 · 가법 합성 · 스펙트럼 띠
[화면] 빨간 빛 줄기 + 하단 빨강 선 — "빨강"은 파장이 곡선을 통과한 창발 결과
```

## 6. 한 문장 요약

> **종류를 코드에 박는 대신 보존량 다발 하나만 두고, 국소 법칙을 결정론적으로 한 개씩 쌓으면 — 색·분자·순환 같은 다양성이 author 없이 *창발*하고, 세계는 author 의 분량이 아니라 법칙에서 스스로 굴러간다. 보존(장부)·국소성·결정론은 그걸 가능케 하는 동시에 매 step 을 거짓말 탐지기로 검증하는 토대다.**
