# reviews/ — 묶음 리뷰 (10 step 단위 회고 + 척추 정합성 + 이슈 원장)

> atom 트랙의 닫힌 step 들을 **10개 묶음**으로 회고한다. step 문서가 *한 조각의 역사*라면, 리뷰는 *묶음의 정합성 감사*다. 방법·포맷은 `.claude/skills/hgo-atom-review/SKILL.md`.
>
> 리뷰는 문서의 PASS 주장이 아니라 **실물 코드(`../engine/*.js`) + verify 재현**으로 판정한다. 닫힌 리뷰 문서는 이후 불변(역사) — 단 §2 열린 이슈 원장만 묶음마다 갱신된다(해소분 떨굼).
>
> 권위 분리: 현재·다음 = [../STATE.md](../STATE.md) · 척추 = [../../SPINE.md](../../SPINE.md). 리뷰는 **읽기 회고 + 전방 권고**일 뿐 STATE 를 대체하지 않는다(STATE 가 step 진행의 SSOT). 리뷰가 찾은 load-bearing 이슈는 권고로 남고, 다음 atom-step 세션이 STATE §2/§3 로 흡수한다.

## 3. 묶음 경계 규칙

- **10 step = 1 리뷰**. 마지막 묶음이 10 미만이면(예: 0031~0037) 그대로 닫고 다음 10 개 도달 시 새 묶음.
- 리뷰는 **닫힌 step 만** 다룬다(STATE NOW 가 가리키는 미닫힘 step 제외).
- render 트랙 이슈는 여기 적지 않는다(`../../render/STATE.md` 소관) — 단, atom 이 *방출해야 render 가 그릴 수 있는* 신호(이벤트 타임스탬프 등)는 atom 이슈로 기록 가능.
