## 1. NOW

- **닫힌 step**: [step-0004](steps/step-0004.md) — **빛이 날아간다(광자 전파 — 운동량 방향으로 광속 c 직진)**. 셋째 법칙 `propagate`(노브 `kProp`, `LAW_ORDER` 에 `recoil` 뒤). step-0003 이 실은 운동량이 *방향*을 주므로 광자가 그 방향으로 광속 c 직진(토러스 wrap) — 복사장이 방출점에 고이지 않고 *공간으로 퍼진다*. **위치만** 바뀌어 장부는 step-0003 그대로 닫힘(잔차 **2.27e-13**, 보존-자명). 평균 속력 측정 **정확히 1**(=c)·직진 광자 **38/38** 거리=c·나이·결정론·골든 **20/20**. "광속"은 author 아닌 *질량 0 → E=pc* 창발.
- **한 줄 상태**: 빛이 *공간적 실체*가 됐다 — 한 원자의 빛이 *다른* 원자에 도달 가능(흡수의 전제). `kProp=0` 이면 step-0003 와 비트 동일(회귀 0, 골든 15 보존). 광자는 아직 *흡수·소멸 없이* 누적되고(🔴), 세계는 여전히 *식기만* 한다(재여기 없음 🔴).
- **다음**: **step-0005** (§2) — 1순위: 흡수·여기(공명 광자 흡수 → x↑ + 광자 소멸 → 🔴 식기만 함 **&** 🔴 누적 동시 해소). 한 step = 한 조각.

## 2. NEXT

> 큰 호(arc)의 서사(원자→빛→화학→핵→별)는 [SPINE.md](SPINE.md) §8 로드맵이 SSOT. STATE 는 *다음 한 조각*과 직전 2~3 step 만.

직전 흐름: **step-0003**(둘째 법칙 `recoil` — 광자 운동량/빛↔운동 결합) → **step-0004**(셋째 법칙 `propagate` — 광자가 광속 c 직진/빛의 공간화). 이제 광자가 *다른* 원자에 도달하므로, 빛의 *재흡수*(순환 씨앗 + 누적 정리)를 얹는다.

### step-0005 가설 (▶ 즉시 다음 step)

**흡수·여기 (B)** — 방출의 역. 광자가 원자에 도달해 **공명**(광자 E ≈ 준위차 ΔE) 하면 흡수돼 원자 `x↑`(들뜸) + 광자 *소멸*:

- **닫힌 장부**: 광자 E → 들뜸 E 전환 + 광자 운동량 → 원자 운동량(흡수 반동, recoil 의 역). E·px·py 동시 보존.
- **두 🔴 동시 해소**: 들뜸이 *재공급*되어 세계가 식기만 하지 않고(🔴 재여기), 광자가 *소멸*해 무한 누적도 멈춘다(🔴 누적).
- ⚠ **광자↔원자 매칭은 공간/공명 질의** → §3 ⬜ 최적화 의존. 단순화로 먼저: 근접(반경 내) + 공명 허용오차. O(n·광자) 수용("먼저 옳게").
- **더하는 것(공통 형식)**: `engine/hgo-laws.js` 에 법칙 `absorb` 1개 + 노브 `kAbsorb` 1개 + `LAW_ORDER` 한 자리(노브=0 → early-return → 회귀 0). `engine/scenes.js` 에 `step-0005` 장면 한 항. 보존항은 *미존재 시 no-op* 가법.
- **닫는 조건**: 회귀 0(새 노브=0 → step-0004 비트 동일·골든 가법) + 닫힌 장부 + 결정론 + 가설 수치(흡수 count>0·들뜸 재증가·광자 감소).
- **전가**: 쿨롱·결합·핵은 Phase C~. 공간 분할 최적화는 별도.

> **활성 게이트(이미 도달)**: 방출+반동(요건3)이 실렸다 → **render 트랙** 깨울 때(SPINE §7). 별도 세션이 `render/` + `hgo-render-step` SKILL+STATE 를 만들며 atom 스냅샷 `sim.photons`(λ=hc/ΔE·px·py)를 *읽기만* 한다(시뮬 불가침). atom 트랙은 계속 굴린다.
> **주의**: 최적화(이웃 질의·공간 분할)는 여전히 미룬다(§3 ⬜) · 광자 누적(흡수·소멸 없음) 정리는 후보(B)(C)가 맡음.

직교/휴면: net 트랙은 아직 깨우지 않는다 — 활성 게이트는 [SPINE.md](SPINE.md) §7.

## 3. OPEN GAPS — 열린 격차 (척추 용어, 매 step 하나씩 메움)

| 마커 | 격차 | 상태 |

| 🟡 | **상호작용이 없다** | step-0002 가 첫 법칙 `emit`(자발 방출)을 얹음 — 단, *단일 원자 내부* 전이일 뿐 아직 원자-원자 상호작용(쿨롱·충돌)은 0. Phase C 부터. |
| 🔴 | **세계가 식기만 한다(재여기 없음)** | 방출·반동(0002·0003)은 들뜸을 *소비*만 — 흡수·여기(충돌/광자 흡수 → x↑)가 없어 단조 냉각. step-0004 후보(B)가 순환의 씨앗. |
| 🔴 | **광자 무한 누적(소멸 없음)** | step-0004 가 전파(광속 직진)는 넣었으나 *흡수·소멸*이 0 → `sim.photons` 무한 누적(긴 런서 비대). step-0005 흡수가 공명 광자 *소멸*로 정리(전파는 위치만 풀 뿐 개수 안 줄임). |
| 🔴 | **준위 에너지가 Z 무시(He/C/O 가 수소 스펙트럼)** | `levelE(x)` 는 슈뢰딩거 *수소* 고유값 E∝1/n² 만 — Z 무관. 실제 수소형 단전자 이온은 E∝**Z²**, 다전자 중성원자는 닫힌 형식 없음(전자 차폐). 현재 He(Z2)·C(Z6)·O(Z8)가 전부 수소선을 냄. *궤도(보어 기각분)가 아닌 고유값 그림은 정합* — Z·차폐 정밀화는 별도 step. |
| ⬜ | **성능 최적화(이웃 질의·공간 분할)** | 원자-원자 상호작용(쿨롱·충돌)·광자-원자 흡수가 자리 잡으면 O(n²). *먼저 옳게, 나중에 빠르게* — 셀/필드 격자·spatial hash 는 별도 트랙/step. |
| ⬜ | **상대론적 운동(c=1 근처 반동)** | step-0003 반동은 Newtonian ½mv² — 자연 단위 c=1 에서 수소 반동 속력이 ~0.5c. 보존은 정확하나 상대론적 보정 미반영(토이 모형). 정밀화 step 에서. |
| ⬜ | **렙톤 수·중성미자 회계** | 초기엔 e 보존으로 단순화(SPINE §2). 약붕괴(p↔n) step 에서 정련. |
| ⬜ | **껍질 채움(파울리·스핀)** | 외각 전자 수로 단순화(SPINE §3 요건4-4). 원자가·스펙트럼 정밀화 step 에서. |

## 4. DURABLE CONSTRAINTS — 모든 step 이 지킬 정전(canonical) 사실

> 여러 step 이 *반복* 참조하는 불변만. 단일 step 의 발견·한계 전문은 `step-NNNN.md`(여기 누적 금지).

- **회귀 0**: 새 항을 끄면(노브=0) 직전 step 과 **비트 동일**(verify `reg`, maxDiff=0). step-0002~ 부터 적용(0001 은 결정론·보존이 앵커).
- **닫힌 장부**: Q·B·L·E 보존 잔차 ≤ 미시 ~1e-6 / 거시 ~1e-7. *비가역(핵 변환) ≠ 비보존* — 원소가 바뀌어도 E·Q·B 는 닫힘.
- **결정론**: 같은 시드 2회 → 전 원자 비트 비교 + 상태 해시 일치. **`Math.random` 금지**(시드 의사난수만).
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **척추 체크 4항**(SPINE §5): ① 단일 척추(다양성은 새 자료형 아닌 *다발의 양*) ② 창발 환원(author 분기 0 — 원소/분자는 측정) ③ 국소 상호작용(전역 조율자 0) ④ 닫힌 장부(비가역이라도 보존).
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가.
- **시각화는 물리의 하류**: 렌더 트랙은 스냅샷을 *읽기만* — 색·이펙트는 방출 스펙트럼서 창발, 형태/색 author 금지.
