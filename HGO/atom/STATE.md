## 2. NEXT

> 큰 호(arc)의 서사(원자→빛→화학→핵→별)는 [SPINE.md](SPINE.md) §8 로드맵이 SSOT. STATE 는 *다음 한 조각*과 직전 2~3 step 만.

직전 흐름: **step-0022**(`pauli` — 보편 단거리 반발, 중성 포함 excluded-volume) → **step-0023**(`vdw` — 보편 약한 인력, pauli 와 vdW 우물 → **중성 군집/응집**). **Phase C** — 모든 원자가 끌고 밀며 응집·진동(등속운동 문제 완결). 다음은 응집을 키워 상전이(액/고체)로 가거나 소산·결합 기하·중력을 닫는다.

### step-0024 가설 (▶ 즉시 다음 step — 한 조각)

**후보 M · 다체 응집 상전이 (액/고체·결정 격자)** ← *권장(step-0023 vdW 우물 직접 키움)*. 4원자 토이를 넘어 큰 중성 군집(수십 개)에서 vdW+pauli 가 *질서 있는 격자*(결정 구조·최밀 충전)나 액적을 만드는지 측정(평균 배위수·동경분포). 난이도 중.

**후보 N · 소산 (복사 감쇠 → 우물 수렴)** — 보존계라 응집이 *호흡*만 한다(가라앉지 않음). 진동 KE 를 광자/들뜸으로 빼는 감쇠 → 진짜 *응고*(우물 바닥 수렴). 닫힌 장부 유지(KE→복사 E).

**후보 L · 중성 공유결합 길이 (유효 결합장)** — 중성 공유결합(step-0017)에 유효 인력장으로 r_eq 부여.

**후보 J · 결합각 (다체 VSEPR)** · **후보 D · 핵 붕괴 (Phase D)** · **중력(1/r² 원거리 인력 — Phase E)**.

- **더하는 것(공통)**: 법칙/게이트 1개 + 노브 + `engine/scenes.js` 장면 `step-0024` 한 항(노브=0 → 회귀 0). 새 함수/reservoir 필요 시 가드 가법.
- **닫는 조건**: 회귀 0(노브=0 → step-0023 비트 동일·골든 가법) + 닫힌 장부(연속력은 E 완화 가능) + 결정론 + 가설 수치.
- **전가**: 나머지 후보 · 다체 충돌 통계 · 쿨롱 결합 에너지 기반 깸 · 부껍질·파울리·스핀 정밀화 · **O(n²) 공간 분할 최적화(연속력 넷 — 시점 임박)**.

> **활성 게이트(이미 도달)**: 방출+반동(요건3)이 실렸다 → **render 트랙** 깨울 때(SPINE §7). 별도 세션이 `render/` + `hgo-render-step` SKILL+STATE 를 만들며 atom 스냅샷 `sim.photons`(λ=hc/ΔE·px·py)를 *읽기만* 한다(시뮬 불가침). atom 트랙은 계속 굴린다.
> **주의**: 원자-원자 상호작용이 둘로 늘었다(0009 collide·0010 bond — 둘 다 전쌍 O(n²)) → 공간 분할 최적화(§3 🟡) 검토 시점 도래.

직교/휴면: net 트랙은 아직 깨우지 않는다 — 활성 게이트는 [SPINE.md](SPINE.md) §7.

## 4. DURABLE CONSTRAINTS — 모든 step 이 지킬 정전(canonical) 사실

> 여러 step 이 *반복* 참조하는 불변만. 단일 step 의 발견·한계 전문은 `step-NNNN.md`(여기 누적 금지).

- **닫힌 장부**: Q·B·L·E 보존 잔차 ≤ 미시 ~1e-6 / 거시 ~1e-7. *비가역(핵 변환) ≠ 비보존*. **예외(연속력, 0019~)**: symplectic 적분의 E 는 *유계 진동*(drift 0)이라 머신 0 불가 — `scene.ledgerTol` 로 E 만 완화(0019: 3e-3). Q·B·L·운동량은 *늘* 머신 1e-9(쌍별 등반작용).

- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **척추 체크 4항**(SPINE §5): ① 단일 척추(다양성은 새 자료형 아닌 *다발의 양*) ② 창발 환원(author 분기 0 — 원소/분자는 측정) ③ 국소 상호작용(전역 조율자 0) ④ 닫힌 장부(비가역이라도 보존).
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가.
