## 1. NOW

- **닫힌 step**: [step-0017](steps/step-0017.md) — **공유결합(중성 원자가 외각 껍질을 공유 — 이온결합 옆 둘째 선택성)**. `bond` 게이트 `bondCovalent`(=0 → 이온만·step-0016 바이트 동일 → 회귀 0): *중성*(q=0) 원자 쌍이 *외각 껍질 빈자리*(다음 닫힌 껍질 2·10·18 까지 부족분 `covVacancy`)를 공유해 결합. 공유 원자가 = 빈자리 → **H 1·C 4·O 2·He 0(noble)** 이 e 다발+마법수서 창발(author 0). 포획·reservoir·분자 측정은 이온 기계 재사용 — 바뀐 건 *국소 선택 규칙*뿐. 공유결합 **57회**·빈자리 초과 원자 **0**·He 결합 **0**·최대 차수 **4.2**(탄소 4결합)·분자 9.4개. 장부 잔차 **2.27e-13**. 골든 **85/85**(80 보존+5 가법).
- **한 줄 상태**: Phase C — 결합에 *종류*가 생김(이온=전자 전이 + 공유=전자 공유). 둘 다 다발(전하 vs 빈자리)서 측정으로 갈림(author 분기 0). 탄소 4결합 → 사슬·유기 분자 토대. 껍질(파울리) 토이 첫 도입.
- **다음**: **step-0018** (§2) — 1순위: 쿨롱장(연속 1/r²·고위험) · 핵 붕괴(Phase D·모델 선행) · 결합 차수(이중·삼중) · 극성 공유결합. 한 step = 한 조각.

## 2. NEXT

> 큰 호(arc)의 서사(원자→빛→화학→핵→별)는 [SPINE.md](SPINE.md) §8 로드맵이 SSOT. STATE 는 *다음 한 조각*과 직전 2~3 step 만.

직전 흐름: **step-0016**(`unbond` 법칙 — 충돌이 흔든 결합 *상대 KE > e[2]* 면 깸, bond 의 역) → **step-0017**(`bondCovalent` 게이트 — 중성 원자가 외각 껍질 빈자리 공유로 결합, 공유 원자가 H1·C4·O2·He0 창발). **Phase C** — 결합에 *종류*(이온·공유)가 생기고 껍질(파울리) 토이가 들어왔다. 다음은 연속 *쿨롱장*·*핵 붕괴*(Phase D)·*결합 차수*로 간다.

### step-0018 가설 (▶ 즉시 다음 step — 한 조각)

**후보 E · 결합 차수 (이중·삼중 결합 — π 공유)** ← *권장(공유결합 직접 잇기·저위험)*. 현 공유결합은 간선 1개(단일 결합)뿐. 빈자리가 둘 이상이면 *같은 쌍*이 여러 전자쌍 공유(O=O 이중, N≡N 삼중) — 간선 차수/다중 흡수. step-0017 빈자리 기계 직접 확장, 닫힌 장부 재사용. 난이도 중.

**후보 B · 쿨롱장 (연속 1/r²)** — 거리 의존 끌림/밀침. PE 항 + 심플렉틱 적분(에너지 드리프트 1e-9 관건). ⚠ 닫힌 장부 1e-9 와 충돌 가능 — tolerance·ledger 재정의 필요할 수 있어 *사용자 판단* 권장. step-0009 부터 미뤄둔 정공법.

**후보 D · 핵 붕괴 (Phase D)** — 결합에너지 reservoir 모델 + (원소 변환 시) 렙톤 회계 선행 필요(STATE ⬜). 한 조각 초과 가능 — 우선 Z 불변 핵 이성질체 전이/감마 방출 토이로 좁히는 안.

- **더하는 것(공통)**: 법칙/게이트 1개 + 노브 + `engine/scenes.js` 장면 `step-0018` 한 항(노브=0 → 회귀 0). 새 함수/reservoir 필요 시 가드 가법.
- **닫는 조건**: 회귀 0(노브=0 → step-0017 비트 동일·골든 가법) + 닫힌 장부 + 결정론 + 가설 수치.
- **전가**: 나머지 후보 · 극성 공유결합(부분 전하) · 깸 각도 등방 분산(scatterV2 동형) · 연쇄 해리 측정 검증 · 부껍질(s·p·d)·파울리·스핀 정밀화(껍질 토이→실제) · 스펙트럼 정밀화(Slater·미세구조) · O(n²) 공간 분할 최적화(시점 도래).

> **활성 게이트(이미 도달)**: 방출+반동(요건3)이 실렸다 → **render 트랙** 깨울 때(SPINE §7). 별도 세션이 `render/` + `hgo-render-step` SKILL+STATE 를 만들며 atom 스냅샷 `sim.photons`(λ=hc/ΔE·px·py)를 *읽기만* 한다(시뮬 불가침). atom 트랙은 계속 굴린다.
> **주의**: 원자-원자 상호작용이 둘로 늘었다(0009 collide·0010 bond — 둘 다 전쌍 O(n²)) → 공간 분할 최적화(§3 🟡) 검토 시점 도래.

직교/휴면: net 트랙은 아직 깨우지 않는다 — 활성 게이트는 [SPINE.md](SPINE.md) §7.

## 4. DURABLE CONSTRAINTS — 모든 step 이 지킬 정전(canonical) 사실

> 여러 step 이 *반복* 참조하는 불변만. 단일 step 의 발견·한계 전문은 `step-NNNN.md`(여기 누적 금지).

- **회귀 0**: 새 항을 끄면(노브=0) 직전 step 과 **비트 동일**(verify `reg`, maxDiff=0). step-0002~ 부터 적용(0001 은 결정론·보존이 앵커).
- **닫힌 장부**: Q·B·L·E 보존 잔차 ≤ 미시 ~1e-6 / 거시 ~1e-7. *비가역(핵 변환) ≠ 비보존* — 원소가 바뀌어도 E·Q·B 는 닫힘.
- **결정론**: 같은 시드 2회 → 전 원자 비트 비교 + 상태 해시 일치. **`Math.random` 금지**(시드 의사난수만).
- **수치 = verify 출력**: 모든 문서 수치는 시드 [42, 7, 1234, 99, 2026] 평균으로 재현.
- **척추 체크 4항**(SPINE §5): ① 단일 척추(다양성은 새 자료형 아닌 *다발의 양*) ② 창발 환원(author 분기 0 — 원소/분자는 측정) ③ 국소 상호작용(전역 조율자 0) ④ 닫힌 장부(비가역이라도 보존).
- **한 step = 한 조각**: 더 떠올라도 다음으로 전가.
- **시각화는 물리의 하류**: 렌더 트랙은 스냅샷을 *읽기만* — 색·이펙트는 방출 스펙트럼서 창발, 형태/색 author 금지.
