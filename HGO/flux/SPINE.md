# FLUX-SPINE — flux 트랙 척추 (단일 국소 규칙 설계도 · 모든 step 작업 전 필독)

> 이 문서는 HGO **flux 트랙의 척추**다 — *세계엔 규칙이 단 하나다.* atom 트랙(법칙 ~26개의 파이프라인)과 **직교**하며, 그 트랙의 교훈에서 태어났다: 다양성은 법칙을 쌓아 author 하는 게 아니라, **하나의 국소 규칙을 척도 분리로 굴려** 창발시킨다.
>
> 권위 분리: 큰 목표는 [../CLAUDE.md](../CLAUDE.md), 현재 위치는 [STATE.md](STATE.md), 실행 절차는 `.claude/skills/hgo-flux-step/SKILL.md`. 렌더는 [../render/RENDER.md](../render/RENDER.md) 계약을 *그대로* 재사용(§7). **step 작업 전 이 문서 · STATE 필독.**
>
> 핵심 한 줄: **코딩할 건 함수 하나다.** 이웃과 · 보존되는 양을 · 기울기에 비례해 · 문턱을 넘을 때 비선형으로 · 주고받는다. (**보존 · 촉매 · 임계**) 층(물질·구조·흐름)은 이 규칙 위에서 *척도 분리*로 창발한다 — author 하지 않는다.

---

## 0. 왜 이 트랙이 따로 있나 — atom 의 교훈

atom 트랙은 "원자를 타입으로 박지 마라"는 **자료형의 통일**은 지켰으나, *법칙*은 emit·recoil·scatter·bond·coulomb·fuse·decay… ~26개를 손으로 박았다. author 를 데이터에서 법칙으로 옮겼을 뿐, "난잡·복잡"은 법칙 층에 그대로 쌓였다.

flux 트랙은 그 모순을 정면으로 푼다: **법칙도 단 하나다.** 원소·결합·빛·붕괴에 *대응하는 층*은 별도 법칙이 아니라, 같은 규칙이 *다른 척도*에서 보일 때 나타나는 *국면(regime)*이다. 이것이 "스스로 굴러가는 세계"의 가장 깊은 형태다 — 굴림이 author 분량과 완전히 분리된다.

> flux 는 atom 을 대체하지 않는다 — **가설을 싸게 검증하는 평행 트랙**이다. "단일 규칙이 정말 층을 창발시키는가"를 atom 의 자산(렌더러·뷰어·검증 골격)을 재사용해 확인한다.

---

## 1. 세계의 자료형 — 보존량 다발 (척추 변수)

세계는 동일한 **셀(cell/grain)** 들로만 구성된다. 각 셀은 *이름이 아니라* 다음 양들의 다발이다:

| 기호 | 양 | 무엇을 정하나 |
|---|---|---|
| **q** | 보존되는 양(스칼라, 1개 이상) | 규칙이 이웃과 *주고받는* 대상. 닫힌 장부의 골격 |
| **r** | 위치(2D) | 이웃 관계·기울기의 전제. 렌더 좌표 |
| **(이웃)** | 위상(격자 또는 반경) | "이웃" = 규칙의 유일한 비국소 입력 (전역 조율자 0) |

> 별도의 `Solid`·`Fluid`·`Front` 클래스는 없다 — 전부 같은 다발의 *q 배치*다. 처음엔 **q 스칼라 1개**로 시작한다(가장 단순한 기질). 둘째 보존량(촉매 변수)이 *필요해질 때* step 으로 더한다 — 단, 그것도 *새 법칙이 아니라 같은 규칙의 추가 채널*이다.

---

## 2. 무엇이 보존되는가 — 닫힌 장부 (척추의 골격)

규칙은 q 를 셀 사이로 *옮길* 뿐, 만들거나 없애지 않는다. **Σq 는 머신 정밀도로 불변**이어야 한다 — 이 장부가 닫혀야 세계가 새지 않고 *순환*한다.

| 보존량 | 정의 | 비고 |
|---|---|---|
| **총량 Q** | Σ qᵢ | 엄격 보존. 규칙의 반대칭(§3)이 보장 — 머신 정밀도 |
| **(척도별 분포)** | q 의 히스토그램·기울기장 | 보존 안 됨(흐름). *창발 측정*의 대상 — 층은 여기서 읽는다 |

> **결정적 정합**: 규칙은 비선형·비가역(문턱 아래 동결, 위 사태)이어도 **Σq 장부는 닫힌다**. *비가역 ≠ 비보존* — atom 의 결정(핵반응이 Z·N 바꿔도 E·Q·B 닫힘)을 flux 로 가져온 모습이다. 사태(avalanche)는 q 를 재배치하되 총량은 정확히 보존.

---

## 3. 단일 규칙 — 한 함수 (이 트랙의 전부)

코딩해야 할 건 *딱 이것 하나*다. 셀 i 와 그 이웃 j 사이의 **플럭스**:

```
F(i→j) = κ · Φ( qᵢ − qⱼ )          // i 가 j 에게 주는 양

  여기서 d = qᵢ − qⱼ            (기울기 — 이웃 간 차)
        Φ(d) = sign(d) · max(0, |d| − θ)^α     // 문턱 θ, 비선형 지수 α
```

이 한 줄이 세 성질을 *동시에* 만족한다:

- **보존** — `F(i→j) = −F(j→i)` (Φ 가 d 의 홀함수 → 부호 반전). i 가 잃는 만큼 j 가 정확히 얻는다 ⇒ Σq 불변(머신 정밀도). *author 한 회계 아님 — 반대칭이 보존을 강제.*
- **촉매** — 플럭스가 기울기 `d` 에 비례(α=1 이면 선형 확산, α>1 이면 큰 차일수록 가속). "기울기에 비례해 주고받는다" = 차이가 곧 구동력. (둘째 채널을 더하면 *그 채널이 κ 를 변조* = 진짜 촉매 — §1 후속.)
- **임계** — `max(0, |d| − θ)` 가 문턱 게이트. `|d| < θ` 면 플럭스 0(**동결**), 넘으면 비선형(α)으로 급증(**사태**). "문턱을 넘을 때 비선형적으로" = 임계.

**갱신**(동기, 결정론): `qᵢ ← qᵢ − Σⱼ F(i→j)`, `qⱼ ← qⱼ + F(i→j)`. 한 tick = 모든 이웃 쌍에 이 함수 한 번. **그게 끝이다.**

> 노브: `κ`(교환률) · `θ`(문턱) · `α`(비선형 차수) · 이웃 위상(격자/반경). 이 4개가 규칙의 *모든* 자유도다 — step 이 노브를 *더하지 않는다*(atom 의 ~120 노브 대비). 결정론: rng 는 *초기 배치*에만, 규칙 자체는 결정론.

## 4. 척도 분리 — 층은 창발한다 (author 0, 이 트랙의 가설)

같은 규칙이 *q 배치의 척도*에 따라 다른 국면을 보인다 — 이것이 "층"이다:

- **동결 층(물질)**: 국소 기울기가 θ 아래 → 플럭스 0 → 셀이 *굳는다*. 고체·경계·구조의 토대.
- **임계 층(구조)**: 기울기가 θ 근처 → 사태가 자기조직화 임계(SOC, 모래더미형) → *척도 불변* 도메인·전선(front)·멱법칙. 다양성이 여기서 난다.
- **확산 층(흐름)**: 기울기가 θ 위로 충분 → 매끄러운 흐름 → 평형화·온도·확산.

**같은 한 규칙**이다. 무엇이 층을 가르나? *q 가 놓인 척도*(국소 기울기의 크기)뿐 — author 한 분기가 아니라 **측정으로 드러나는 국면**이다. 빠른 작은 척도(국소 평형)와 느린 큰 척도(전역 흐름)의 **시간 분리**가 곧 층 분리다. (atom 의 "빠른 비가역 + 느린 순환"을 단일 규칙으로 환원한 형태.)

> 이 §4 가 트랙의 *증명 대상*이다: "단일 규칙 + 척도 분리 → 창발 층"이 참인지 step 으로 검증한다. 거짓이면(층이 안 나오면) 규칙을 *최소로* 정련(둘째 채널·이웃 위상)하되, **법칙 수는 1을 유지**한다.

## 5. 한 step 이 더하는 것 — *법칙이 아니라 창발 관찰* (atom 과 결정적 차이)

atom 의 "한 step = 법칙 1개"는 flux 에서 **금지**다(규칙은 step-0001 에 *고정*). flux 의 한 step 이 더하는 것은 둘뿐:

1. **장면(scene)** — `engine/scenes.js` 에 초기 q 배치 + 노브(κ·θ·α) + watch(창발 지표) + assert(가설 수치) 한 항. *어떤 척도/초기조건이 어떤 층을 드러내는가*의 한 실험.
2. **창발 측정(measure)** — 그 층을 *읽는* 지표 함수(히스토그램·도메인 수·사태 크기 분포·기울기장). **author 한 라벨이 아니라 측정.**

> 예외 — 규칙 정련: §4 검증이 "현 규칙으론 이 층이 불가능"을 증명하면, *그때만* 규칙을 최소 수정(노브 추가가 아니라 함수 형태 정련)하고 **모든 과거 장면이 비트까지 재현되는지**(회귀 0) 확인한다. 규칙 수정은 *드물고 무거운* 사건 — 매 step 의 기본은 "장면 + 측정".

**더할 것 = 장면 1항 + 측정 1개. 복사되는 html·panel·verify 는 0개**(§6, 공용 하네스 1벌).

## 6. 작업 구조 — 누적 폐기, 공용 하네스 (atom 에서 계승)

- **복사 금지**: 뷰어·검증기·골든은 **공용 1벌**. step 마다 복제하지 않는다. 한 step = 장면 한 항 + 측정 1개 + `steps/step-NNNN.md` 1개.
- **부트스트랩(step-0001)**: 공용 하네스가 *한 번* 만든다 — `engine/flux-kernel.js`(이웃·수학 유틸) · `engine/flux-laws.js`(**단일 규칙 함수 1개**) · `engine/flux-sim.js`(상태·tick) · `engine/scenes.js`(레지스트리) · `engine/verify.js`(공용 헤드리스 검증) · `engine/validate/`(골든 해시). 이후 step 은 이 하네스를 *건드리지 않는다*.
- **단일 뷰어**: 트랙은 자기 뷰어를 두지 않는다 — 공유 `../viewer.html`(루트)가 `?track=flux` 로 이 트랙 엔진을 load(§7). 엔진은 atom 과 동일하게 `HGO.kernel/laws/sim/scenes` 전역에 등록한다(뷰어 트랙 무관).
- **크기 예산**: STATE ≤ 20KB · `step-NNNN.md` ≤ 14KB("쉽게 풀어 쓴 설명" 절 필수) · SPINE 거의 불변.

## 7. 렌더 계약 — 기존 렌더러 *그대로* 재사용 (atom 과 직교)

flux 는 렌더러를 새로 만들지 않는다. `../render/engine/render.js`·`spectral.js` 와 공유 뷰어를 **불변**으로 재사용한다. 조건은 하나: **flux sim 이 렌더가 읽는 스냅샷 채널을 내보낸다**([../render/RENDER.md](../render/RENDER.md) §2 계약).

| 렌더가 읽는 채널 | flux 가 채우는 법 |
|---|---|
| `atoms: [{rx,ry, …}]` | 셀의 위치(rx,ry) + q 를 렌더 채널에 사상 |
| 색·밝기 | **보존량 q → 렌더가 이미 읽는 스칼라 채널**(예: 밝기/색조)로 노출 — author 분기 0, 측정 정규화만 |
| `photons`·`bonds`·`escaped` | flux 엔 없음 → **빈 배열/0**(렌더는 빈 채널을 그냥 안 그림 — RENDER.md §2 "없으면 없음") |

> 핵심: render.js 는 *한 줄도 안 고친다.* flux 의 일은 **계약에 맞는 스냅샷을 내보내는 것**뿐(step-0001 의 sim 책임). 색·형태 author 0 — q 를 읽어 번역할 뿐(render 트랙의 불가침, RENDER.md §3). 정확한 q→채널 사상은 step-0001 에서 정하고, 그 전엔 위치+단일 스칼라(밝기)로 시작한다.
>
> **직교 보장**: flux step 은 `../render/`·`../atom/` 을 만지지 않는다. 뷰어 트랙 선택화 배선(`../viewer.html`)은 공유 셸 변경(SPINE §6.1 정신) — render 트랙이 소유하나 flux 부트스트랩이 트랙 매니페스트 한 줄만 더한다.

## 8. 로드맵 — 큰 호(arc)의 서사 (이 절이 arc SSOT)

| arc | 목표(창발 층) | 검증 신호 |
|---|---|---|
| **A — 규칙 기질** | step-0001: 단일 규칙 + 닫힌 장부 + 결정론. 기질 위 자유 확산 | Σq 불변·회귀 0·재현 |
| **B — 임계** | θ 게이트로 동결↔사태 전이. SOC(사태 크기 멱법칙) | 사태 분포·임계 θc 측정 |
| **C — 구조** | 임계 근처 도메인·전선 창발(척도 불변 패턴) | 도메인 수·상관 길이 |
| **D — 척도 분리** | 빠른 국소 평형 + 느린 전역 흐름 = 층 공존 | 시간 척도 분리 측정 |
| **E — 다채널** | 둘째 보존량(진짜 촉매)으로 반응-확산 패턴 | 패턴 형성(튜링형) |

> arc 는 *층*을 센다(법칙이 아니라). 각 arc 는 "이 층이 단일 규칙에서 정말 나오는가"의 가설 — §4 의 증명 대상을 쪼갠 것.

## 9. 검증 4기둥 (매 step 통과해야 닫을 수 있다)

1. **회귀 0** — 규칙은 고정. 새 장면이 과거 장면의 골든 해시를 바꾸지 않는다(규칙 정련 시에도 비트 재현 의무).
2. **닫힌 장부** — Σq 가 머신 정밀도로 불변(반대칭 알리바이). verify 가 tick 전후 Σq 출력.
3. **결정론** — 같은 시드 → 같은 세계 → 같은 해시(rng 는 초기 배치만).
4. **창발 측정(author 0)** — 층은 *측정*으로 드러난다. 장면 assert 가 "이 척도에서 이 지표가 이 값"을 수치로 — `if(이건 고체)` 류 라벨 author 금지.

`node engine/verify.js step-NNNN` 가 4기둥 + 장면 assert 를 수치 출력. 문서의 모든 수치는 이 출력 그대로.

## 10. 빠른 참조

- **단일 규칙**: `F(i→j) = κ·sign(d)·max(0,|d|−θ)^α`, `d=qᵢ−qⱼ`. 보존(반대칭)·촉매(∝d)·임계(θ 게이트).
- **자료형**: 셀 = `{q, rx, ry}` + 이웃. 타입 분기 0.
- **한 step**: 장면 1항 + 측정 1개 (법칙 *아님* — 규칙은 step-0001 고정).
- **렌더**: 기존 렌더러 불변 재사용 — flux 는 RENDER.md §2 계약 스냅샷만 내보냄.
- **뷰어**: 공유 `../viewer.html?track=flux`. 엔진은 `HGO.kernel/laws/sim/scenes` 등록.
- **금지**: 법칙 추가 · 노브 남발 · 종류 라벨 author · 렌더/atom 트랙 만지기 · 하네스 복사.
