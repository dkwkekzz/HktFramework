# step-0001 — 부트스트랩: 기질 + 단일 규칙 + 닫힌 장부

> flux 트랙의 첫 step. 공용 하네스를 *한 번* 세우고, 세계의 **유일한 법칙**을 코딩하고, 그것이 닫힌 장부 위에서 처음 도는 것을 검증한다. 이후 어떤 step 도 법칙을 더하지 않는다(SPINE §5).
>
> 뷰어: [`../viewer.html?track=flux#step-0001`](../../viewer.html?track=flux#step-0001)

## 무엇을 했나

1. **공용 하네스**(이 트랙에서 다신 안 만든다):
   - `engine/flux-kernel.js` — 이웃 위상(격자 토러스 간선)·rng(mulberry32)·질량·상태 해시.
   - `engine/flux-laws.js` — **단일 규칙 함수 1개**. 이게 트랙의 전부.
   - `engine/flux-sim.js` — 셀 상태 + tick + 렌더 계약 스냅샷.
   - `engine/scenes.js` — 장면 레지스트리 + step-0001 장면 1항.
   - `engine/verify.js` + `engine/validate/golden-flux.json` — 공용 헤드리스 4기둥 검증 + 골든.
2. **단일 규칙**(`flux-laws.js`, SPINE §3 그대로):
   ```
   F(i→j) = κ · sign(d) · max(0, |d| − θ)^α      (d = qᵢ − qⱼ)
   ```
   - **보존** — `F(i→j) = −F(j→i)` (홀함수). 간선마다 −F/+F 한 쌍 → Σq 불변.
   - **촉매** — 플럭스 ∝ 기울기 d (α=1 선형 확산).
   - **임계** — `max(0,|d|−θ)`: 문턱 θ 아래 동결, 위 비선형.
3. **첫 장면**(`step-0001`): 24×24 격자(576 셀), 중앙 5×5 블롭(q≈11) + 배경(q≈1). θ=0 → 순수 확산.

```

✓ 결정론: hash 69424498 == 69424498
✓ 회귀 0: 골든 69424498 == 69424498
✓ Σq 보존(닫힌 장부): Δ=0.00e+0
✓ 확산 평형화(spread↓): 10.009577 → 0.135614
✓ 평형 미완(아직 비0 — 완전 평탄 아님): spread=0.135614

```

- **Σq 정확 보존**: 200 tick 동안 총량 변화 Δ=0 (반대칭이 강제 — 부동소수 반올림조차 안 샘).
- **확산 평형화**: 블롭과 배경의 차(spread)가 10.01 → 0.136 으로 단조 감소. 규칙이 기울기를 메운다.
- **결정론**: 같은 시드 두 번 → 같은 해시. (브라우저 전역 로드 경로도 별도 스모크로 확인.)

## 쉽게 풀어 쓴 설명

세계를 바둑판(24×24=576칸)으로 생각하자. 각 칸에는 "양"(q)이 담겨 있다 — 물병에 든 물이라고 보면 된다. 처음엔 **한가운데 칸들에만 물이 가득**(q≈11) 차 있고 나머지는 거의 비어(q≈1) 있다.

규칙은 **딱 하나**다: *옆 칸과 물 높이가 다르면, 높은 쪽에서 낮은 쪽으로 흘려보낸다.* 얼마나? 높이 차에 비례해서(많이 차이 날수록 많이). 이게 전부다. 별도의 "고체", "액체" 같은 규칙은 없다.

이 한 규칙을 200번 반복하니:
- 가운데 뭉쳐 있던 물이 **사방으로 번져** 결국 거의 평평해졌다(높이 차 10 → 0.14). 누가 "퍼져라"라고 시킨 게 아니라, 옆 칸과 주고받는 규칙만으로 저절로 그렇게 됐다.
- **물의 총량은 정확히 그대로**(738.927…). 한 칸이 잃은 만큼 옆 칸이 정확히 얻기 때문에, 세계 전체의 물은 한 방울도 늘거나 줄지 않는다. 이게 "닫힌 장부" — 세계가 새지 않는다는 뜻이다.

지금은 문턱(θ)을 0으로 둬서 "조금만 차이 나도 무조건 흐르는" 가장 단순한 확산만 봤다. 다음엔 문턱을 올려서 *어느 정도 쌓여야만 와르르 흐르는*(모래더미처럼) 임계 현상을 볼 차례다 — 같은 규칙, 노브만 다르게.
