# step-0018 — arc G: 무에서 물질(뜨거운 잡음→브리더 자발 형성)

> 지금까지 브리더는 *손으로 펄스를 놓아* 만들었다. 진짜 "스스로 굴러가는 세계"라면 *featureless 한 잡음*에서 물질이 스스로 응결해야 한다 — 모듈레이션 불안정으로. 뷰어: [../viewer.html?track=flux#step-0018](../viewer.html?track=flux#step-0018)

## 무엇을 했나 (장면 1항 + 측정 1개)

- **장면**: `hotSpec(2, 0.05, 2)` — 균일 q=1 + 결정론 노이즈(±1, 셀 인덱스 해시·rng 미사용 → 비트 재현), v=0, inertial·α=2·κ=0.05. *손으로 놓은 펄스 없음* — featureless 한 뜨거운 잡음.
- **측정**: `spontaneousMeasure` — 역참여비 P=(Σe²)²/Σe⁴(=실효 들뜸 셀 수, 낮을수록 국소)·지속 peak 를 비선형(α=2)·선형(α=1)로 비교. 비선형이 잡음을 봉우리로 모으면 P↓·peak↑. ΣQ 비트 보존도.

## 쉽게 풀어 쓴 설명

진짜로 "스스로 굴러가는 세계"라면, 누가 일일이 원자를 *놓아 주지 않아도* 물질이 스스로 생겨야 한다. 그래서 이번엔 펄스를 놓는 대신, 온 격자에 *제멋대로의 작은 출렁임*(뜨거운 잡음)만 깔고 굴렸다 — 특별한 자리 하나 없이 사방이 비슷하게 어수선한 상태.

선형(α=1)으로 굴리면 이 어수선함은 그냥 *어수선한 채로* 남는다(에너지가 668개나 되는 셀에 퍼져 있음, 봉우리 1.75). 그런데 비선형(α=2)으로 굴리면, 우연히 조금 높은 곳이 주변을 더 끌어당겨 *점점 더 높아지는* 되먹임이 일어난다(이걸 "모듈레이션 불안정"이라 한다). 그 결과 에너지가 더 적은 셀(592개)로 *모이고* 봉우리가 2.33 로 *솟는다*. 즉 **featureless 한 잡음에서 물질(국소 봉우리=브리더 씨앗)이 스스로 응결**한다. 무에서 패턴이 나오는, 이 트랙의 큰 목표를 향한 한 걸음이다.

## 한계 / 열린 격차

- **모듈레이션 불안정의 *씨앗*이지 깨끗한 정상 브리더 격자 아님** — 봉우리들이 생기지만 여전히 어수선한 배경과 섞여 있다(P 592, 한 덩어리는 아님). 응결한 봉우리가 *진짜 브리더*(대역 밖 진동수)인지는 개별 확인 안 함 — 통계(P·peak)로만 봄.
- **개체수 안정성은 별도** — 응결한 다체 상태가 *지속*하는지(한 덩어리로 안 붕괴) 는 step-0020 에서 1200틱으로 측정.
- **온도(amp)·κ 의존 미탐사** — amp=2~3 에서 확인. 임계 온도(국소화 onset)·상전이는 후속.
