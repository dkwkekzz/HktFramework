- **법칙은 1개**: 규칙 함수 `rule()` 는 step-0001 에 고정. 이후 step 은 *법칙을 추가하지 않는다*(장면+측정만, SPINE §5). 둘째 채널 p(step-0010·촉매)·b(step-0021·원자가)도 *새 법칙 아님* — 같은 `rule()` 을 각 채널에 적용 + 변조/교차항(SPINE §1·§3). 규칙 정련(applyCoupled/applyInertial/applyValence 가법)은 전부 opt-in(`knobs.gamma`/`inertial`/`valence`) 게이트 — 노브 없으면 비트 불변(회귀 0 의무·검증됨).

- **Σq 불변(비트 정확)**: 규칙의 반대칭(`F(i→j)=−F(j→i)`)이 보존을 강제 — author 한 회계 아님(SPINE §2). q 가 고정소수점 정수라 같은 정수 F 가 ±로 가 **정확** 상쇄(머신 정밀도가 아니라 비트 0). float 누적 금지.
