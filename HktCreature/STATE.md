## 현재 명제

- **[완료] M1 — 기본 스켈레톤 로드 + 그 위에 절차 살**: HktCharacter 로더 방식으로 Mixamo
  베이스(X Bot 남 / Y Bot 여, with-skin)를 로드해 트윈 교차 리그에서 구동 뼈(65개)를 선정하고,
  아티스트 스킨은 숨긴 채 그 스켈레톤에 절차 살(SkinnedMesh)을 붙였다. Mixamo 클립(대기/걷기/
  뛰기)을 월드 공간 리타깃(`bakeClip`)해 재생하면 살이 skinning 으로 뼈를 따라 변형한다.
  베이스 전환(남↔여)·굵기 슬라이더·표시 토글(살/원본 스킨/본)·발 접지.
  - 로드·리타깃 코어는 `creature.js` 로 뽑아 main.js(무대)·verify(검증)가 공유.
  - **이전 M0(코드-리그: rig.js/rig-template.js)는 폐기** — 기본 스켈레톤 로드로 전환.

## 검증 (2026-07-12, M1)

**게이트 = `npm run check` (verify + build + shot).** 모든 세션은 변경을 닫기 전 이걸
통과시키고, 결과 보고 시 `test/out/*.png` 를 첨부한다(캡처 육안).

### 데이터 레벨 — `npm run verify` (Node, 공유 코어를 실물 에셋에 구동) — 전체 통과:
- **A. 기본 스켈레톤 로드**: X Bot 129본→구동 65, Y Bot 117본→구동 65(트윈 교차 처리),
  표준 부위(hips/lefthand/rightfoot) 매핑, rest 접지 발바닥 y≈0.
- **B. 로드 스켈레톤에 살 부착**: SkinnedMesh 정점 2016, skinWeight 합=1, skinIndex 전부 유효
  로드 뼈, 살이 로드 스켈레톤 뼈에 직접 바인딩, rest 스키닝 유한.
- **C. Mixamo 리타깃 구동**: idle/walk/run 각 58트랙 구움, 전부 로드 뼈 타깃(미매칭 0).
- **D. 재생→변형**: 접지 사전측정 root.y 유한, 걷기 재생으로 살 정점 이동(Δ≈212), 포즈
  스키닝 정점·뼈 행렬 NaN 0.

### 픽셀 레벨 — `npm run shot` (실제 Chromium 렌더 + 자동 판정) — 전체 통과:
- 대기/걷기/뛰기/본오버레이 각각 크리처가 화면의 ~9% 를 덮음(실제 렌더).
- 대기↔걷기 셀 그리드 차 ≈28 → 살이 Mixamo 포즈를 따라 실제로 변형.
- 페이지 에러 0. 스크린샷 `test/out/{idle,walk,run,walk-bones}.png`(육안 첨부).
