`npm run verify` (Node, 브라우저 없이 실물 코어 구동) — 전체 통과:

- **A. 코드-리그**: buildRig 가 57본 생성, Hips 루트, 표준 이름(접두사 없음), 부모-자식
  계층이 템플릿과 일치, Skeleton 역-bind 57개 생성.
- **B. 절차 살**: SkinnedMesh 정점 2016 / 삼각형 3528, skinWeight 합=1(정규화),
  skinIndex 전부 유효 뼈, 살이 22개 뼈에 분산 바인딩.
- **C. Mixamo 그대로**: idle/walk/run FBX 각 44개 트랙 타깃이 **전부** 리그 뼈에 매칭
  (이름 정규화만으로 리타깃 없이 바인딩).
- **D. 실제 구동**: walk 재생으로 LeftArm Δ≈14.9cm 이동, 뼈 월드 행렬 NaN 0, 스키닝 정점 유한.
